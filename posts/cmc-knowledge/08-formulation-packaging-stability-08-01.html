冷冻干燥的本质与工艺结构：去除溶剂延长蛋白药物保质期的核心原理

回答BioCloudHub

冷冻干燥（Lyophilization / Freeze-drying）是通过去除或限制溶液中促进化学和物理降解的水分，从根本上延长热敏性蛋白质类药物保质期的制剂技术。其核心是利用冰晶升华原理，在高度真空环境下将已冻结的固态水直接转化为水蒸气，绕过液态相变。

冷冻干燥的物理基础

水在压力—温度坐标系中存在三相点（Triple Point）：温度 0.01°C，压力 611.73 Pa（约 0.006 atm）。当系统压力降至三相点压力以下时，冰可直接升华为水蒸气而不经历融化，这是冻干工艺的物理基础。

工艺的两大核心过程与三个步骤

冷冻（Freezing）
    大部分溶剂转化为固态冰晶
        ↓
干燥（Drying）
    ┌─────────────────────────────────────────────┐
    │                                             │
    初级干燥（Primary Drying）          次级干燥（Secondary Drying）
    真空条件下冰晶升华（去除自由水）       脱除残余结合水至目标含量
    通常去除 95–98% 水分                 将残余水分降至 < 1–3%

冷冻干燥的本质

干燥过程是在低温低压下的传热传质过程：

  • 传热：搁板供热提供升华所需潜热（每克冰升华约需 2.5–2.8 kJ），驱动冰晶升华
  • 传质：水蒸气从产品升华面向冷凝器迁移，低温冷凝器（通常 -50 ~ -80°C）不断将水蒸气凝华为冰，维持升华的浓度梯度驱动力

与普通加热干燥的本质区别：冻干时物料中的水分在 0°C 以下的固态表面升华，物质本身剩留于冻结时的冰架子中，因此干燥后产品体积不变、呈疏松多孔的海绵状结构。

冷冻干燥原理：三相图与升华干燥的物理基础

回答BioCloudHub

水的三相图与冻干的理论基础

水在压力—温度坐标系中存在固（冰）、液（水）、气（水蒸气）三态共存的三相点（0.01°C，611.73 Pa）：

  • 当系统压力**低于三相点压力（611.73 Pa）**时，液态水不能稳定存在
  • 此时升温只会使固态冰直接转变为水蒸气（升华），而不经过融化阶段

冷冻干燥正是利用这一原理：先将产品冻结，再在三相点压力以下抽真空，使冰通过升华而非融化去除。

升华需要能量

冰升华是强吸热过程：每克冰完全升华约需吸收 2.8 kJ 热量。因此冻干过程中必须向产品提供适量热量（搁板加热），且必须恰到好处：

  • 热量不足 → 升华速率下降，干燥周期延长，生产效率低
  • 热量过多 → 产品温度升高超过崩解温度或共熔点 → 塌陷/熔化

冰架子结构的意义

产品在升华后，原来由冰晶占据的空间变为空腔，形成疏松多孔的蛋糕状结构（冰架子），正是这种结构赋予了冻干产品：

  • 优良的复水性（大比表面积，水分子易进入）
  • 良好的气体传质通道（水蒸气逸出路径通畅）
  • 整体积形态不变（体积与冻结时相同）

冻干保护剂的分类体系与各类别的作用机制

回答BioCloudHub

冷冻干燥过程会对蛋白质造成两类应力：冻结应力（冰晶机械力、浓缩效应、界面应力）和干燥应力（水化层去除导致蛋白质构象去稳定）。冻干保护剂通过多种机制对抗这两类应力，须根据产品特性进行系统筛选和组合。

分类一：按分子量分类

类别代表物质主要作用方式
低分子量化合物蔗糖、海藻糖、甘露醇、甘氨酸在冻干过程中直接发挥保护作用（替代水的氢键，形成玻璃态基质）
高分子量化合物葡聚糖、羟乙基淀粉、PVP主要促进低分子量保护剂的作用（提升 Tg'，改善冻干块结构）

实践中通常将低分子量和高分子量化合物配合使用，以获得最佳保护效果。

分类二：按功能分类

功能类别代表物质作用机制
冻干保护剂蔗糖、海藻糖在干燥过程中以氢键替代水分子与蛋白质结合（水替代假说），维持蛋白质天然构象
填充剂甘露醇、甘氨酸结晶形成支撑骨架（"scaffolding"），防止有效组分随水蒸汽升华逸散，赋予制品良好的外观形态
抗氧化剂甲硫氨酸、维生素 E 类似物清除 ROS，防止蛋白质在冻干过程及储存中发生氧化变质
酸碱调整剂（缓冲剂）组氨酸、柠檬酸盐、磷酸盐在冻干过程和储存中将产品 pH 维持在活性物质最稳定的区域（注意磷酸盐在冻干中 pH 漂移问题）

分类三：按物质种类与注意事项

糖类（最核心的冻干保护剂）

蔗糖（最常用）和海藻糖：结构中的多个羟基可取代蛋白质表面与水的氢键，形成均匀的非晶态玻璃态基质包裹蛋白质。

关键注意事项： 糖和醇类保护效果与浓度直接相关，但当浓度超过一定水平（如蔗糖 > 20% w/v）后保护能力趋于饱和，过高浓度反而可能在冻干过程中促进蛋白质变性或降低崩解温度。通常蔗糖/海藻糖的最适浓度为 5–15%（w/v）。

醇类

  • 甘露醇：慢速预冻时会结晶，形成结晶性支撑骨架（填充剂），为活性组分提供物理支撑，且不与活性组分发生化学反应。快速预冻时甘露醇可能呈非晶态，须在退火（Annealing）步骤中诱导结晶
  • 甘油：低温保护剂，但在冻干条件下会使 Tg' 显著降低（甘油为液态增塑剂），通常不推荐用于需要低残余水分的冻干制剂

氨基酸类

氨基酸具有酸碱两性（兼性离子），能在冻干和低温保存中抑制溶液 pH 变化；同时许多氨基酸（如甘氨酸）也是良好的填充剂，结晶形成支撑结构。

盐类

主要作为缓冲剂使用，但须特别注意冻干过程中的 pH 漂移风险——磷酸钠缓冲液中磷酸氢二钠（Na₂HPO₄）比磷酸二氢钠（NaH₂PO₄）更早结晶，导致缓冲液在冻结前 pH 向酸性漂移，可能引起蛋白质酸变性。组氨酸缓冲液在冻干过程中 pH 较稳定，是单抗冻干制剂的优选缓冲体系。

冻干制剂处方开发的通用考量：API 性质、溶剂选择与辅料设计

回答BioCloudHub

冻干制剂处方开发须从 API（活性药物成分）的理化性质出发，系统评估溶剂、保护剂和附加剂的选择，形成兼顾稳定性、安全性和生产可行性的整体方案。

第一步：评估 API 性质（决定后续所有选择的起点）

API 性质对后续辅料和工艺的影响
溶解度决定可配制的最高浓度；低溶解度须评估是否可通过处方优化（pH 调节、助溶剂）提高
拟配制浓度与装量决定固形物总量，进而决定冻干时间和最终蛋糕厚度
最高耐受温度确定初级干燥的搁板温度上限（不能超过蛋白质的崩解温度）
化学稳定性（已知敏感性）对氧化敏感 → 须添加抗氧化剂和惰性气体覆盖；对酸敏感 → 避免冻干中 pH 漂移
与辅料的相容性须评估还原糖（葡萄糖、乳糖）是否与蛋白质发生 Maillard 反应
与包材的相容性蛋白质与橡胶胶塞可能存在吸附和浸出物交互，须开展 E&L 研究

第二步：冻干溶剂选择

注射剂的溶剂首选注射用水（WFI），只有当 WFI 无法满足 API 溶解度或稳定性要求时，才考虑非水溶剂。

理想的冻干非水溶剂须满足三个条件：

  1. 凝固点高（有利于在较高温度下实现预冻，减少能耗）
  2. 挥发性强（在干燥阶段能高效从产品中去除）
  3. 能与水混溶（便于与水性活性成分均匀混合）

常见非水溶剂：叔丁醇（最常用，凝固点 25.5°C，具备上述三个特性）、异丙醇、乙醇、丙二醇（适合某些特殊分子）。

第三步：保护剂与附加剂的组合设计

基于 API 性质和稳定性研究结果，设计保护剂组合：

  • 通常以 **蔗糖或海藻糖（5–10%）**作为主要冻干保护剂
  • 若需改善蛋糕外观，加入结晶性填充剂（甘露醇，通常 1–3%）
  • 若对氧化敏感，加入甲硫氨酸（0.1–1 mmol/L）作为游离 Met 保护剂
  • 固形物总量（蛋白质 + 糖类 + 其他辅料）通常控制在 4–25% w/v 范围内，以保证可接受的崩解温度和冻干周期

冻干升华干燥阶段的塌陷（Collapse）：机制、温度参数与预防策略

回答BioCloudHub

塌陷是冻干初级干燥阶段最严重的缺陷之一，不仅影响产品外观，还可能导致残余水分升高、复溶时间延长和活性损失，须从处方和工艺两个层面系统预防。

塌陷的形成机制（六步骤链式过程）

  1. 初级干燥推进 → 产品形成"外层已干层 + 内层冻结层"的双层结构
  2. 已干层为多孔疏松结构（水蒸气逸出通道），依赖其固体骨架维持结构完整性
  3. 当搁板温度过高或崩解温度（Tc）设定过低 → 已干层温度升高
  4. 已干层从玻璃态（高刚性）转变为橡胶态（低刚性，有粘性）
  5. 多孔结构发生塌陷，水蒸气逸出通道堵塞 → 升华速率骤降
  6. 剩余热量使冻结层温度升高超过共熔点 → 产品熔化或起泡 → 批次报废

三个关键温度参数的关系

Tc（崩解温度）≈Tg′（玻璃转化温度）≲Te（共熔点）T_c\text{（崩解温度）} \approx T_{g'}\text{（玻璃转化温度）} \lesssim T_e\text{（共熔点）} Tc​（崩解温度）≈Tg′​（玻璃转化温度）≲Te​（共熔点）

实践控制原则： 初级干燥阶段须将产品温度始终控制在崩解温度（Tc）以下。若某产品的 Tc > Te，则以共熔点 Te 为基准即可；若 Tc < Te（玻璃化体系），则须以更严格的 Tc 为基准。

常见冻干保护剂的 Tg' / Tc 参数比较

保护剂典型 Tg'（°C）对冻干工艺的影响
甘露醇（结晶型）+2（共熔点 Te ≈ -1.5°C）结晶性体系，Tc 较高，初级干燥温度窗口宽
海藻糖-28 ~ -30Tg' 高于蔗糖，初级干燥温度约束相对宽松
蔗糖-32 ~ -34最常用，须注意控制初级干燥温度
蔗糖 + 甘露醇（组合）中间值，依比例组合使用可提升整体 Tc，改善操作窗口

提高崩解温度的处方策略

  • 优先选用高 Tg' 保护剂（海藻糖优于蔗糖）
  • 适当添加高分子量赋形剂（如羟乙基淀粉、PVP）以提升混合体系的 Tg'
  • 避免添加会显著降低 Tg' 的成分（如甘油、山梨醇）

冻干制剂常见外观缺陷：六类问题的原因与解决思路

回答BioCloudHub

冻干制剂的外观质量是放行检测的重要指标，各类外观缺陷均有特定的形成机制和针对性的工艺改进方向。

缺陷一：塌陷（Collapse）

  • 现象：蛋糕结构崩溃，多孔结构消失，产品变成密实的熔融物
  • 根本原因：初级干燥阶段产品温度超过崩解温度（Tc）
  • 预防措施：降低搁板温度使产品温度低于 Tc；优化处方提升 Tc；退火步骤促进保护剂结晶

缺陷二：回融（Meltback）

  • 现象：蛋糕底部出现融化液化区，形成空洞或湿润区域
  • 根本原因：初级干燥结束时部分西林瓶底部仍有残余冰（初级干燥时间不足）；进入次级干燥后，这部分残余冰融化形成液态水，浸润已干燥产品
  • 预防措施：延长初级干燥时间；在初级干燥与次级干燥之间增加安全保留时间；通过 PAT（过程分析技术，如压力升试验或质谱监测）确认初级干燥完成

缺陷三：萎缩（Shrinkage/Collapse-induced Shrinkage）

  • 现象：蛋糕体积缩小，脱离瓶壁，外形不饱满
  • 根本原因：水分升华速率过快导致已干外壳致密化，内部水蒸气逸出受阻；产品固形物浓度过低，支撑骨架不足
  • 预防措施：加入或增加填充剂（甘露醇、甘氨酸）；采用退火步骤改善冰晶尺寸和结构；降低初级干燥搁板升温速率

缺陷四：开裂/掉底（Cracking/Vial Bottom Detachment）

  • 现象：西林瓶底部玻璃开裂脱落（掉底），或蛋糕表面出现裂缝
  • 根本原因（多因素）：
    • 瓶子质量：低硼硅玻璃耐冷热冲击能力差，瓶底内应力超标（用偏光镜检查，出现过多紫色应力条纹的瓶子须剔除）
    • 预冻速率过快：水冻成冰体积膨胀，对瓶体产生膨胀力；推荐在共熔点以上某一温度保温均化后再降温
    • 瓶底与瓶身温差过大（> 15–20°C）：热应力导致玻璃脆性断裂
    • 装量过多/样品过厚：冻结时冰柱厚度大，温度均匀性差
  • 预防措施：优选中硼硅玻璃瓶（国内淘汰低硼硅已是趋势）；降低预冻速率；在共熔点以上保温使瓶内温度均匀化

缺陷五：爬壁（Crawling）

  • 现象：西林瓶内壁上附着大量粉末
  • 根本原因：初级干燥开始时，未冷冻液体局部沸腾（马朗戈尼流效应），产品喷溅并粘附在温度较低的瓶壁上
  • 预防措施：增加退火步骤（Annealing），使产品完全结晶/固化后再进入干燥阶段；选用表面能与该产品匹配的西林瓶材质；添加能防止产品迁移的处方组分

缺陷六：冻干块颜色/外观异常

  • 现象：蛋糕颜色异常（黄色、棕色）、质地不均
  • 可能原因：上游原液本身颜色异常（见本页原液颜色章节）；复溶溶剂残留；处方辅料降解（PS80 氧化）
  • 调查方向：确认是上游来源还是冻干过程引入，针对性改进

冻干曲线的制订与优化：五类决定性因素的系统考量

回答BioCloudHub

冻干曲线（Lyophilization Cycle / Recipe）是描述冻干全程中搁板温度、箱内压力随时间变化的程序化操作规程，是冻干工艺开发的核心输出。制订冻干曲线须综合考量以下五类因素。

因素一：产品品种的理化性质

  • 共熔点（Te）/ 崩解温度（Tc）/ 玻璃转化温度（Tg'）：是设定预冻目标温度和初级干燥搁板温度上限的关键约束
  • 残余水分需求：要求残余水分较低（< 1%）的产品须延长次级干燥时间；要求不那么严格的（< 3%）可缩短干燥周期
  • 结晶性行为：含甘露醇的处方须在退火（Annealing）阶段确保甘露醇结晶完全（慢速预冻有利于结晶），防止非晶态甘露醇在储存中延迟结晶导致蛋糕开裂

因素二：容器装量

  • 容器总装量越多（干燥箱总药品量），冻干时间越长
  • 每支西林瓶的装量越多（药液厚度越大），初级干燥所需时间越长（传质路径越长）
  • 冻干曲线须在代表性装量（与商业化生产规格一致）下开发和确认

因素三：容器类型与传热特性

容器类型传热特性对冻干的影响
底部平整、壁薄的中硼硅玻璃瓶传热好，温度均匀性佳首选，干燥时间较短
底部不平整、壁厚的玻璃瓶传热差干燥时间延长，且瓶底与搁板接触不均
金属托盘（原料药冻干）导热性最好干燥效率高，但托盘须保持平整以保证传热均匀

因素四：冻干设备的性能规格

同一产品在不同型号冻干机上需要不同的冻干曲线，不可直接套用其他设备的曲线，关键性能参数包括：

  • 搁板温度均匀性（板间差 vs. 板内区域差）
  • 冷凝器最低温度和冰负荷能力（决定捕获水蒸气的上限）
  • 冻干箱与冷凝器之间的水蒸气流动阻力（阻力越小，升华效率越高）
  • 真空泵的抽速和稳定性

因素五：自动化控制与冻干曲线的执行

现代冻干机通过计算机控制系统按照预设冻干曲线自动执行，包括：

  • 自动阶梯式或线性降温（预冻）
  • 自动抽真空（精确控制箱内压力至目标值）
  • 自动搁板升温（初级和次级干燥的温度斜坡控制）
  • 在线 PAT 工具（如压力升测试 Manometric Temperature Measurement, MTM）实时判断初级干燥终点

冻融稳定性研究：蛋白质结构损伤的机制与研究设计要点

回答BioCloudHub

冻融稳定性（Freeze-Thaw Stability）研究评估原液（和某些中间产品）在经历一次或多次冻结-化冻循环后的质量保持情况，是原液储存管理和运输验证的数据基础。

冻融过程中蛋白质损伤的四类机制

损伤机制描述典型影响
冰晶机械损伤冰晶形成时体积膨胀，对蛋白质分子产生物理剪切力导致聚集体增加（SEC 可检测）
浓缩效应（Cryo-concentration）溶质随冻结推进被浓缩，蛋白质、盐类、辅料局部浓度急剧升高局部高浓度促进分子间聚集；pH 偏移
气液界面应力冰-水界面能量高，蛋白质在界面处展开疏水残基暴露，形成不可逆聚集
缓冲液 pH 漂移磷酸盐缓冲液中 Na₂HPO₄ 比 NaH₂PO₄ 更早结晶，导致在冻结过程中 pH 显著向酸性偏移（可偏移 1–2 pH 单位）pH 偏移引起电荷变化和蛋白质稳定性降低

保护策略

  • 添加冻干/冻融保护剂（蔗糖 5–10%）替代蛋白质表面的水化层
  • 选用在冻融中 pH 稳定的缓冲液（组氨酸缓冲液是单抗的优选，冻结时 pH 变化最小）
  • 控制冻融速率：受控速冻（Controlled-rate Freezing）可减少冰晶大小的不均匀性；快速化冻（水浴 37°C）可减少化冻时蛋白质在高浓度区域的暴露时间

研究设计要点

设计参数典型设置说明
冻融循环次数1、3、5 次（对比）确认最大允许冻融次数，通常 ≤ 3 次
冻融温度冻：-20°C 或 -80°C；融：2–8°C 或室温须与实际生产/使用温度一致
评估项目SEC（聚集体）、CE-SDS（片段）、活性（效价）、外观（浑浊度）、DLS（粒径）优先检测对冻融最敏感的指标
参照组未冻融样品（T₀）所有结果须与未冻融对照组比较

热稳定性分析：蛋白质高级结构质量控制的关键表征项目

回答BioCloudHub

热稳定性（Thermal Stability）是评估蛋白质抵抗热诱导不可逆结构破坏能力的关键指标，在生物制品质量控制中具有重要地位，既是候选分子筛选的早期指标，也是制剂处方优化和批次放行表征的依据。

热稳定性的物理化学本质

蛋白质的三级和四级结构通过大量的非共价相互作用（疏水相互作用、氢键、盐桥、范德华力）维持，这些相互作用在高温下逐渐被热运动破坏：

  • 当热量增加超过蛋白质内部稳定力时，分子内键断裂 → 蛋白质展开（Unfolding）
  • 展开后暴露疏水核心 → 分子间疏水聚集 → 不可逆变性
  • 变性的蛋白质通常完全失去生物学活性

主要热稳定性分析方法

方法英文缩写核心输出特点
差示扫描量热法DSCTm（熔化温度）、ΔH（焓变）、ΔS（熵变）、ΔG（自由能）热力学参数最全面；金标准；样品量相对较多（通常 1 mg/mL × 300 μL）
差示扫描荧光法DSF / nanoDSFTm、荧光强度变化曲线高通量；样品量极少（10–100 μg）；适合早期候选分子筛选
圆二色光谱CD（远紫外）α-螺旋/β-折叠比例随温度变化反映二级结构完整性
内源荧光光谱Intrinsic fluorescenceTrp 荧光强度和波长随温度变化反映三级结构（Trp 微环境）的热变化

Tm 的质量意义

  • Tm 越高，蛋白质在储存温度（通常 2–8°C 或 25°C）下距离去折叠区域越远，构象稳定性越好
  • 典型单抗的 Tm 值：Fc CH2 结构域（65–75°C）、Fab 结构域（75–85°C）、Fc CH3 结构域（80–90°C）
  • 批次放行和稳定性研究中，Tm 的显著下降（通常 > 2°C）提示蛋白质高级结构发生了变化，须进行根本原因调查

容器相关可提取物与浸出物（E&L）：塑料包材三类风险的系统管理

回答BioCloudHub

与药品直接或间接接触的塑料包材（一次性储存袋、灌装管道、预灌封注射器塑料筒体等）是可提取物（Extractables）和浸出物（Leachables）的主要来源，须建立系统的风险识别和控制体系。

三类核心风险

风险一：渗透（Permeation）

  • 挥发性成分（如残余溶剂、O₂、水蒸气）通过容器壁向内外双向渗透
  • 影响：水蒸气渗透入冻干品 → 残余水分升高 → 稳定性下降；O₂ 渗透入液体制剂 → 氧化降解加速
  • 控制：选用低气体渗透率的包材材质；低氧充氮灌装；冻干品铝塑复合膜包装

风险二：浸出（Leaching）

  • 塑料配方中的添加剂（增塑剂、抗氧化剂 BHT/Irganox、润滑剂）迁移到产品中
  • 影响：浸出物可能影响产品效价（与蛋白质相互作用）、诱导聚集或具有毒理学风险
  • 控制：选用添加剂种类少、用量低的医用级塑料；开展 E&L 研究，确认浸出物在安全阈值以下

风险三：吸附（Adsorption）

  • 药物分子（蛋白质）或离子吸附到塑料材料表面
  • 影响：导致蛋白质浓度下降（实际给药量低于标示量）；高度稀释溶液（低浓度蛋白）风险更大
  • 控制：评估蛋白质在不同容器材质表面的吸附量；选用低蛋白吸附材质；添加 PS80 等表面活性剂降低蛋白与表面的非特异性吸附

可提取物研究先于浸出物研究的逻辑

可提取物（在极端条件下的最大化提取值）代表浸出物的上限。若可提取物水平已经过安全性评估且处于可接受范围，浸出物（实际使用条件下更低的迁移量）通常也在安全范围内。因此：

  • 无论是否开展浸出物研究，可提取物研究都是必须完成的基础工作
  • 可提取物研究结果为浸出物研究的必要性和设计提供依据

原液常见颜色表现及异常颜色的临床研究影响

回答BioCloudHub

单抗原液的正常颜色范围

单克隆抗体原液的颜色受蛋白质浓度、芳香氨基酸（Tyr、Trp）的吸收特性和潜在修饰的综合影响：

颜色描述典型情形质量评估
无色透明低浓度（< 10 mg/mL）正常状态正常
浅黄色高浓度（> 50 mg/mL）时芳香氨基酸的累积吸收效应正常，多数高浓度单抗的典型颜色
棕红色B12-抗体共价复合物；铁催化的 Trp 大量氧化异常，须立即调查
浅粉色少量 B12 与抗体游离 Cys 结合须调查，评估 B12 暴露情况
深棕色严重 Maillard 反应产物；高度 Trp 氧化严重异常，须报废并开展根本原因调查

颜色变化的双重影响

影响一：产品质量与安全性信号

  • 储存过程中颜色显著加深意味着化学降解（氧化、Maillard 反应）正在发生，提示产品可能存在质量问题
  • 颜色超标批次须启动 OOS（超标）调查和根本原因分析，评估该批次产品的安全性和有效性是否受到影响

影响二：临床双盲研究的完整性

这是颜色问题在药物开发中最容易被低估的影响：

  • 双盲临床试验设计要求活性药物与安慰剂（通常无色透明液体）外观无法区分
  • 若抗体产品在储存期间颜色显著加深，安慰剂与活性药物颜色差异将导致去盲，破坏双盲设计的科学有效性
  • 严重时须中止或重新设计临床试验，造成重大项目延误和成本损失

原液颜色质量标准与异常颜色的根本原因调查框架

回答BioCloudHub

法规颜色标准

  • 单抗原液（DS）的典型颜色为淡黄色或接近无色（Near Colorless to Pale Yellow）
  • 欧洲药典规定用于临床试验的 DS 应为无色或接近无色
  • 放行质量标准通常描述为：无色至浅黄色，必要时设定半定量标准（如颜色 ≤ 黄色 5 号参比液）
  • 颜色定量检测：分光光度法测定 450 nm 吸光度（A₄₅₀），或与比色标准液（Y 系列）目视比较

重要原则： 颜色异常并不必然意味着安全性或有效性问题，但须触发系统调查和评估，调查结论须有充分依据。

异常颜色的根本原因（Root Cause）调查框架

一旦发现 DS 颜色超标，须按以下层次系统排查：

第一层：上游工艺来源

疑似原因调查指标
铁离子浓度过高（催化 ROS → Trp 氧化）培养基铁离子检测；收获液铁残留量；纯化后产品铁含量
维生素 B12 浓度过高或光转化CD 培养基 B12 含量；培养区域光照记录（是否有波长 400–600 nm 光暴露）
核黄素（B2）过量培养基 B2 浓度

第二层：下游纯化工艺来源

疑似原因调查指标
层析洗脱条件异常洗脱液颜色跟踪（从哪步开始出现颜色）
B12-抗体复合物未被有效去除离子交换层析或疏水层析对复合物的分离能力

第三层：储存过程来源

疑似原因调查指标
光照暴露（Trp 光氧化）储存记录中是否有光照暴露；包材遮光性能
储存温度偏离（加速化学反应）温度记录
包材可溶出物（有色化合物迁移）包材 E&L 数据；更换包材后颜色变化情况

颜色调查完成后的批次处置原则

  1. 确认颜色异常原因是工艺问题（非稳定性降解）→ 评估产品质量属性（活性、纯度），若符合质量标准，经风险评估后可考虑放行
  2. 确认颜色异常来自化学降解（活性/纯度已受影响）→ 批次报废，启动 CAPA
  3. 颜色原因不明 → 在调查期间暂停放行，待根本原因明确后再作处置决定

过滤器完整性测试：法规要求、测试类型与操作时机

回答BioCloudHub

除菌过滤是无菌注射制剂生产的最终无菌保证步骤之一，过滤器完整性测试（Filter Integrity Testing）是验证过滤器在使用过程中始终保持除菌截留能力的关键质控手段，须严格按照法规要求执行。

各主要法规的完整性测试要求

法规机构核心要求
中国 GMP（2010 版）附录应定期检查除菌过滤器和呼吸过滤器的完整性；未明确是灭菌前还是灭菌后；建议每批生产结束后、灭菌前进行
欧盟 GMP须在使用前及使用后立即进行完整性测试；2017 年修订版要求非最终灭菌药品须在线进行完整性检测
FDA可在过滤前进行，应当在过滤后进行日常测试（使用后测试是强制性的）
PDA过滤前后均须进行完整性测试
WHO使用前进行，使用后立即进行；推荐方法：起泡点、扩散流速或压力保持法

完整性测试的两类方法

类型代表方法特点适用场景
破坏性测试细菌挑战试验（Bacterial Challenge Test）以确定细菌截留能力为目的；试验后过滤器报废通常由供应商完成，用于确认除菌级别；用户不做
非破坏性测试起泡点（Bubble Point）、扩散流/前进流（Diffusion Flow）、水侵入法（Water Intrusion）、压力保持法（Pressure Hold）不损坏过滤器；可在生产现场操作用户日常使用中必须进行的测试

所有非破坏性测试须与细菌挑战试验关联

非破坏性完整性测试的通过/失败判断标准须与细菌挑战试验结果相关联，才能有效代表除菌效率。供应商须提供经过关联验证的完整性测试参数（通常在产品质量证书 CoA 上标注）。

完整性测试的三个操作时机

时机目的优先级
灭菌前检查套筒安装密封性、管路连接完整性和过滤器本身初始状态辅助检查，非强制
灭菌后、使用前评估灭菌过程（高压蒸汽、γ 辐照等）对完整性的影响建议开展
使用后（必须）确认过滤器在实际过滤过程中保持完整性，为当批产品的无菌性提供依据强制执行（FDA/EU/WHO 要求）
