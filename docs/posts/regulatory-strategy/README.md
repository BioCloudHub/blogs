# 法规注册策略知识库

围绕生物制品全球注册的战略思考与实操路径，覆盖中美欧主要监管体系、CTD 撰写、沟通会议策略与上市后生命周期管理。

## 主题覆盖

- **全球监管体系**：FDA、EMA、NMPA、PMDA 监管结构与法律基础
- **ICH 指南体系**：Q/S/E/M 系列指南结构与 CMC 申报落地
- **CTD/eCTD 撰写**：Module 1-5 结构定位与 Module 3 CMC 撰写策略
- **IND/IMPD 申报**：内容要求、Pre-IND 会议与欧盟临床试验申请
- **BLA/MAA 申报**：内容结构、审评流程与 Pre-BLA 会议准备
- **FDA 沟通会议**：Type A/B/C 分类、资料准备与策略设计
- **EMA 科学建议**：科学建议程序、PRIME 与并行咨询
- **NMPA 注册路径**：注册分类、审评流程与 CDE 沟通
- **上市后变更管理**：变更分级、可比性方案与法规期望
- **加速审批路径**：AA 路径、附条件批准与验证性研究
- **儿科用药计划**：PSP/PIP 要求、适应症外推与法规激励
- **生物类似药注册**：351(k) 路径、逐步递进相似性与互换性
- **孤儿药与突破性疗法**：认定标准、获益与策略运用
- **全球同步注册**：MRCT、多中心策略与中美欧 CMC 协调
- **药学变更桥接**：各阶段 CMC 变更策略与桥接研究设计
- **说明书与标签**：USPI/SmPC 结构、变更管理与可读性

## 浏览方式

使用左侧导航栏按主题层级浏览，每个主题拆分为 **2 个子专题**，每个子专题包含 **法规体系与框架** 与 **策略应用与案例** 两个问答页面。
