# GMP 与质量体系知识库

围绕生物制品 GMP 生产与质量控制需求，系统化梳理 GMP 法规要求、质量体系要素与监管合规实践。

## 主题覆盖

- **GMP 法规基础与原则**：法规发展史、核心理念与生物制品特殊要求
- **质量风险管理**：ICH Q9 框架、风险评估工具与生命周期整合
- **偏差与 CAPA 系统**：偏差调查方法论、CAPA 有效性评估
- **变更控制**：变更分级、注册影响评估与上市后变更管理
- **验证与确认**：验证主计划、URS/FS/DS 与设备确认
- **数据完整性与 CSV**：ALCOA+ 原则、计算机化系统验证与审计追踪
- **供应商管理**：审计与评估、物料放行与供应链追溯
- **文件管理体系**：SOP 系统、批记录设计与文件生命周期
- **内审与检查应对**：内审程序、法规检查准备与整改回复
- **工艺验证全生命周期**：PPQ 策略、持续工艺确认与 CPV
- **清洁验证**：MACO 与 PDE 计算、多产品共线评估
- **无菌保证体系**：洁净室分级、环境监测与 APS
- **委托生产与质量协议**：CDMO 质量监督与职责划分
- **质量文化与人因工程**：行为标准、心理安全与偏差文化

使用左侧导航栏按主题层级浏览，每个主题拆分为 **2 个子专题**，每个子专题包含 **基础知识认知** 与 **实践案例研判** 两个问答页面。
