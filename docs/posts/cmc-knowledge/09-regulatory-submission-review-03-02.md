## 申报资料规范性问题的四类典型缺陷：格式逻辑、前后一致性、翻译质量与数据呈现

:::answer

申报资料的规范性问题往往比技术问题更容易被忽视，但却直接影响 CDE 审评人员对申请人研发水平的整体印象和评价。以下四类缺陷来源于 CDE 审评经验分享，是申报资料自查的重要参照。

**第一类：资料位置错放、格式不规范、逻辑性差**

- 研究数据未放置在 CTD 对应模块的正确位置（如工艺验证数据未在 3.2.S.2.5 中呈现，而分散在其他章节）；
- 模块间缺少交叉引用（Cross-Reference），审评人员难以追溯数据来源；
- 资料整体缺乏逻辑层次——从"问题"到"研究设计"再到"数据"再到"结论"的叙述链条断裂；
- 附件和正文之间的关联不清晰。

**第二类：前后表述不一致**

不一致问题是审评中最常被标注的规范性缺陷，涉及范围广泛：

| 不一致类型      | 典型问题                                                   | 高风险位置                           |
| --------------- | ---------------------------------------------------------- | ------------------------------------ |
| 生产商名称/地址 | 申请表填写的地址与申报资料正文不一致                       | 申请表 ↔ S.2.1 ↔ P.3.1 ↔ 制检规程    |
| 术语和定义      | 同一参数在不同章节使用不同名称（如"收获液"vs"收获上清液"） | S.2.2 ↔ S.2.4 ↔ 质量标准             |
| 缩略词          | 缩略词在一处定义，其他处未重新定义或首次出现未定义         | 建议每章开头提供该章节的缩略词列表   |
| 数据值          | 同一批次的检测结果在不同章节呈现的数值不一致               | S.4.4（批分析）↔ S.7.3（稳定性数据） |

**第三类：翻译不准确、不专业、可读性差**

对于中文申报资料中涉及的技术术语翻译，须使用业内通用的标准译法：

| 错误译法     | 正确译法           | 领域规范用词                       |
| ------------ | ------------------ | ---------------------------------- |
| "SDS 一页码" | SDS-PAGE           | 十二烷基硫酸钠-聚丙烯酰胺凝胶电泳  |
| "细胞银行"   | 细胞库             | 主细胞库（MCB）/ 工作细胞库（WCB） |
| "蛋白质 A"   | Protein A（蛋白A） | 不翻译或写蛋白A（专有名词）        |

这类翻译错误不仅降低资料可读性，更会令审评人员对申请人的专业水平产生质疑。

**第四类：数据简单堆砌，缺乏分析和解读**

这是技术内容层面最普遍的缺陷，直接影响申报资料的说服力：

**缺陷场景一：稳定性数据未进行趋势分析**

仅将每个时间点的原始检测数据堆砌成表格，未做关键项目（如聚体、电荷变体）的**趋势图**和**统计分析**（如线性回归预测有效期）。正确做法：提供关键 CQA 随时间变化的折线图，并说明变化趋势是否在可接受范围内。

**缺陷场景二：测序图谱未标注关键序列**

测序结果仅提供原始图谱，未对连接子区段、CDR 区、改构序列等关键部位进行高亮标注。正确做法：在图谱上明确标注参考序列位置，便于审评人员快速核查。

**缺陷场景三：工艺规程中关键参数缺失或表述不规范**

工艺规程中仅描述操作步骤，未以**表格或流程图**形式明确上游/下游关键工艺参数（CPP）的控制范围，也未解释参数设定的合理性依据。

**缺陷场景四：电泳图谱为低质量复印件**

提供的 SDS-PAGE 等电泳图谱因为是复印件或低分辨率扫描件，主带位置模糊、杂带无法辨别。正确做法：提供原始数字图像，分辨率须足以清晰辨别各条带的位置和相对强度，并标注分子量 Marker、pI 标准（等电聚焦电泳）、标准 DNA 加量（核酸检测）及供试品上样量。

:::

## 工艺验证资料不充分的四类核心问题及 BLA 申报的验证数据要求

:::answer

工艺验证是 BLA 申报的核心 CMC 内容之一，申报资料中工艺验证数据不充分是最常见的技术性缺陷，常导致 CDE 大量发补。以下四类问题来源于 CDE 审评经验分享。

**第一类：验证规模和工艺不具有代表性**

- 提交的工艺验证数据来自**小规模实验室批次**，而非商业化生产规模（Commercial Scale）；
- 用于验证的工艺与拟上市工艺存在实质性差异（如设备型号不同、关键参数范围不同），但未进行等效性论证；
- **BLA 要求：** 工艺验证须采用**商业化规模、代表性工艺和批次**（至少连续 3 批），验证数据须直接支持拟上市产品的生产。

**第二类：验证方案中验收标准不明确**

- 验证方案（Validation Protocol）中仅描述检测内容，未预先设定**预定验收标准（Pre-defined Acceptance Criteria）**；
- 验收标准设定过于宽泛（如 SEC 主峰 ≥ 80%），缺乏科学依据；
- 正确做法：验收标准须在验证执行前锁定，且须基于工艺表征数据（CPP-CQA 关系）和临床批次历史数据合理设定。

**第三类：仅验证操作参数，缺少过程控制和工艺性能评估**

- 验证仅关注工艺参数是否在设定范围内（参数合规性确认），而未评估**过程控制水平**（IPC 检测结果趋势）和**整体工艺性能**（产品质量属性的批间一致性）；
- 缺少工艺性能统计分析（如关键 CQA 的 Cpk 计算）；
- 正确做法：须同时呈现：① 参数控制记录（均在设定范围内）；② 中间体检测结果（均符合接受标准）；③ 成品质量属性批间一致性分析（关键 CQA 数据分布）；④ 工艺能力指数（Cpk/Ppk）分析。

**第四类：缺乏全生命周期管理和持续工艺验证（CPV）意识**

- 申报资料中仅呈现 PPQ 批次的静态验证数据，未提及<strong>持续工艺确认（Continued Process Verification, CPV）</strong>的设计和计划；
- 缺乏对商业化生产过程中持续监控关键 CQA 和 KPP 趋势的策略描述；
- 正确做法（符合 FDA 三阶段验证框架）：在 PPQ 数据基础上，须提供 CPV 计划（如多变量统计过程控制 MSPC、周期性回顾时间表、趋势预警机制）。

**BLA 申报工艺验证数据的最优实践**

> 提交上市申请时，应采用商业化规模、代表性工艺和批次（**至少连续 3 批**），在可行情况下考察工艺**最差条件（Worst-Case）**，以充分确认拟上市工艺的稳健性。

:::

## 变更研究不充分的核心问题：工艺演变历史的可比性论证与关键临床前的变更控制原则

:::answer

**变更研究不充分的战略重要性**

"阐述拟上市工艺和产品与已通过临床试验验证的产品之间的相关性"是上市申请申报资料中**问题最多、最常被发补**的内容之一。这一章节（CTD 3.2.S.2.6 生产工艺的开发）的核心目标是构建完整的"工艺演变历史链"——向审评人员证明：从早期临床批次到商业化批次，产品质量属性保持了根本一致性，任何变更均经过充分的可比性研究支持。

**国际通行的变更管理原则**

| 阶段                       | 允许的工艺状态                         | 关键要求                                                     |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------ |
| 早期临床（I/II 期）        | 允许必要的工艺和规模变更               | 须评估变更对产品质量的影响，记录变更历史                     |
| **关键性临床（III 期）前** | **应确定拟上市规模和工艺**（工艺冻结） | 这是工艺演变的重要节点，此后的变更成本极高                   |
| III 期后～上市申报前       | **应尽量避免发生变更**                 | 若确实需要变更，须尽早开展研究，确保变更后产品能用于关键临床 |

**变更研究不充分的常见缺陷**

**缺陷一：工艺演变历史描述缺失或不完整**

- 未列出临床开发期间发生的所有重要变更（如：工艺放大、设备变更、培养基优化、纯化步骤调整）；
- 未说明每次变更的原因和时间节点；
- 正确做法：建立**变更历史表**，按时间顺序记录所有变更，标注每次变更前后生产批次的批号、规模和用途。

**缺陷二：可比性数据不充分或分析不深入**

- 仅提供变更前后批次的原始检测数据，未进行<strong>头对头（Head-to-Head）</strong>的系统性比较分析；
- 未对变更影响较大的质量属性进行专项深入分析（如糖型分布、电荷变体谱）；
- 缺少对"哪些属性发生了可接受的变化，哪些属性可能存在差异及其临床影响评估"的系统性讨论。

**缺陷三：桥接研究数据不充分**

- 若变更发生在 III 期临床开始后，须提供变更后产品与 III 期临床用产品之间的**可比性桥接数据**；
- 若可比性研究结论不确定，须评估是否需要非临床或临床桥接研究，申报文件须清晰说明判断依据。

:::

## 治疗用生物制品注册分类体系：三大类别的定义、核心特征与申报路径差异

:::answer

**中国治疗用生物制品注册分类（2020 版药品注册管理办法）**

中国对治疗用生物制品实施三大类注册分类体系，不同类别的申报要求（技术评价路径、临床数据要求、CMC 深度）存在显著差异。

**第 1 类：创新型生物制品**

- **定义：** 境内外均未上市的治疗用生物制品（全球首创）；
- **技术评价路径：** 须提供完整的非临床（体外、体内药效、毒理学）和临床（I～III 期）数据；
- **CMC 要求：** 最高——须建立从头开始的完整 CMC 开发体系。

**第 2 类：改良型生物制品**

包含以下几种改良方式：

| 改良类型                               | 典型示例                       | CMC 特点                         |
| -------------------------------------- | ------------------------------ | -------------------------------- |
| 已上市制品的剂型/给药途径优化          | 皮下注射 → 口服制剂            | 须论证新剂型的安全性和有效性改进 |
| 增加新适应症/改变用药人群              | 现有适应症扩展至儿科           | 须提供新适应症的临床数据         |
| 已上市制品组成新复方制品               | 两个已上市单抗组成双特异性制剂 | 须论证复方的安全性/有效性优势    |
| 重大技术改进（如重组技术替代组织提取） | 凝血因子从血浆提取到重组表达   | 须完成可比性研究证明产品等效性   |
| 改变氨基酸位点/表达系统/宿主细胞       | pI 改造、CHO→HEK293            | 须评估改变对产品特性的影响       |

**第 3 类：境内或境外已上市生物制品**

| 子类 | 定义                                               | 主要特点                                                                |
| ---- | -------------------------------------------------- | ----------------------------------------------------------------------- |
| 3.1  | 境外生产、境外已上市、境内未上市的生物制品申请进口 | 依托境外已有临床数据，须额外提交中国人群数据                            |
| 3.2  | 境外已上市、境内未上市的生物制品申请境内生产上市   | 须完成生产场地转移和技术转让，提供可比性数据                            |
| 3.3  | **生物类似药（Biosimilar）**                       | 须完成系统性药学相似性研究 + 非临床 + 临床 PK/PD + 必要时临床有效性研究 |
| 3.4  | 其他生物制品                                       | 具体要求视产品类型而定                                                  |

## 临床研发期间与监管机构沟通的战略时机：II 期结束后沟通的核心议题与 CMC 关联

:::answer

**监管沟通的战略价值**

与监管机构（CDE/FDA 等）的正式沟通是降低临床开发风险、避免上市申报阶段重大补件的最有效手段之一。申请人应在临床研发各个阶段保持密切沟通，尤其是以下关键节点。

**II 期临床结束后沟通（EOP2 Meeting）：最重要的沟通节点**

**为什么这个节点最重要：**

- EOP2 沟通确定的 III 期临床设计将直接决定未来上市申请能否成功；
- 此节点之后，III 期临床的样本量、主要终点和统计方案将基本锁定，再调整成本极高；
- 若 EOP2 的沟通缺失，常见后果是 III 期完成后发现试验设计存在根本性缺陷，导致无法支持上市申请。

**EOP2 沟通的核心议题**

| 议题类别         | 具体沟通内容                                                                     |
| ---------------- | -------------------------------------------------------------------------------- |
| 获益-风险评估    | 基于 I/II 期数据，监管机构对产品当前的获益-风险平衡的初步评价                    |
| III 期临床设计   | 试验类型（优效性/非劣效性）、患者群体选择、富集策略、随机化方案                  |
| 主要终点         | 有临床意义的终点指标（OS、PFS、ORR 等）的合理性确认                              |
| 统计方案         | 样本量计算依据、统计假设、显著性水平、多重性处理                                 |
| 安全性关注       | 若早期数据发现潜在安全信号，沟通中须明确监管机构对风险管理的期望                 |
| **CMC 状态确认** | **拟用于 III 期临床的工艺是否已锁定？商业化工艺与 III 期工艺的关系是否已明确？** |

**CMC 视角下 EOP2 沟通的关键意义**

从 CMC 角度，EOP2 沟通是确认以下重要问题的最佳时机：

- 确认拟上市工艺已基本确定（工艺冻结节点）；
- 确认监管机构对已发生的工艺变更（I 期→II 期期间）的可比性研究是否满意；
- 了解监管机构对 CMC 关键数据包的期望（如病毒清除验证的具体要求、稳定性数据的充分性）；
- 明确是否有特殊的 CMC 合规要求（如特定杂质的控制策略）。

**沟通频率与动态性**

适应症、现有治疗选择、产品获益、风险和风险管理策略等可能随药物研发进展而变化，须及时与监管机构保持沟通，不能仅依赖初始方案一成不变地执行 III 期临床。

:::

## 分析方法变更的评估框架：触发条件、风险分级、新旧方法等效性证明与再验证要求

:::answer

**分析方法变更的触发场景**

分析方法变更（Analytical Method Change）通常由以下情形触发：

- **工艺变更触发：** 生产工艺发生变更后，原有分析方法可能不适用于变更后产品的检测（如工艺引入的新型杂质无法被原方法检出）；
- **技术升级驱动：** 更先进的分析技术出现（如以 CE-SDS 替代 SDS-PAGE，以 iCIEF 替代传统 IEF），可提供更高精度和重现性；
- **法规更新要求：** 药典版本升级或监管机构发布新指导原则，要求使用更先进或更严格的方法；
- **方法自身局限暴露：** 方法持续使用过程中发现原有方法存在系统性偏差、选择性不足等问题。

**分析方法变更的评估步骤**

```
识别方法变更需求
        ↓
基于风险评估确认是否需要方法再开发/再验证
（评估维度：原方法是否仍适用？差距是否影响产品质量控制？）
        ↓
方法再开发（如需要）
        ↓
新方法的全面方法学验证
（须覆盖所有相关验证参数：专属性、线性、准确度、精密度、LOD/LOQ、耐用性）
        ↓
新旧方法对比研究（等效性研究）
（对代表性样品同时用新旧方法检测，统计学评估等效性）
        ↓
评估原有质量标准是否适用于新方法
（如方法灵敏度提升，可能须相应收严限度；反之须论证合理性）
```

**等效性研究的核心要求**

- 须选用**代表性样品**（包括已知含不同水平杂质的样品、降解样品等）覆盖方法的检测范围；
- 等效性判断须基于预定的统计标准（如 90% CI 的等效性检验，或确定系数 R² ≥ 0.99）；
- **灵敏度原则：** 通常情况下，新方法的灵敏度（LOD/LOQ）应**不低于**旧方法，若新方法灵敏度降低，须有充分的科学依据论证这一降低不影响对产品质量的有效控制。

**FDA/ICH 的再验证触发条件**

FDA 和 ICH Q2(R2) 规定，以下情形须对分析方法进行**部分或全部再验证**：

- 原料药合成路线或生物制品表达系统变更；
- 药物制剂配方（辅料组成或比例）发生改变；
- 生产工艺（关键步骤或设备）发生变更；
- 分析方法本身的参数（溶剂、色谱柱、检测器、试剂）发生变更。

**分析方法的持续监测（方法生命周期管理）**

方法验证完成并实施后，须在日常使用中**持续监测**方法性能：

- 通过系统适用性参数（SSP）的趋势分析，早期发现方法性能漂移；
- 定期（如年度）对方法性能进行回顾评估，判断是否需要开展方法持续确认；
- 建立方法变更历史档案，确保变更的可追溯性。

:::

## 分析方法在不同申报阶段的递进要求：从 IND 到 BLA 的方法成熟度演进路径

:::answer

**分析方法生命周期与申报阶段的对应关系**

分析方法的研究须与药物开发阶段相匹配，随开发进展逐步深化，不能一蹴而就，也不能在关键申报节点出现方法成熟度不足的情况。

**各申报阶段的分析方法要求**

| 开发阶段                   | 方法成熟度要求                     | 核心工作                                                                                                  |
| -------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **临床前研究阶段**         | 方法可行，能区分产品与主要杂质即可 | 平台方法适用性评估，发现开发难点                                                                          |
| **IND 申报阶段**           | 基本的方法确认（Qualification）    | 关键安全性检测方法（无菌、内毒素、效价）须完成初步确认；放行方法须有基本可行性数据支持                    |
| **临床 I/II 期**           | 方法持续优化，开始系统验证         | 放行方法逐步完善；稳定性方法开发；效价方法（最难开发）须重点关注                                          |
| **确证性临床（III 期）前** | 放行和稳定性方法完成验证           | **建议在确证性临床开展前完成全面方法学验证**（ICH Q2(R2) 期望），确保临床用样品与商业化样品的质控方法一致 |
| **BLA 申报阶段**           | 全面完整的方法学验证报告           | 所有放行方法须有完整验证报告；转移报告（如适用）；方法学问题须提前解决                                    |
| **上市后**                 | 持续监测和必要时更新               | CPV 框架下的持续方法确认；因工艺变更引发的方法再验证                                                      |

**为什么必须在确证性临床前完成方法验证**

- 确证性临床（III 期）用样品的质量控制方法须与商业化产品保持一致，若方法在 III 期后发生重大变更，须对 III 期样品与变更后方法下的产品进行可比性研究；
- 如果 III 期后发现方法存在根本缺陷（如专属性不足）而须完全重新开发，将导致大量时间损失，严重影响 BLA 申报时间节点。

:::

## 上市后分析方法变更的合规路径：适用性重新评估、验证策略与新旧方法桥接要求

:::answer

**上市后分析方法变更的驱动因素**

生物制品上市后，以下情形可能触发分析方法的重新评估和更新：

- **关联生产变更：** 生产场地变更、生产规模放大、新剂型引入、工艺重大变更，均可能导致原有分析方法不再适用于新工艺产品的检测；
- **技术升级迭代：** 随着分析科学的发展，自动化程度高、重现性好、灵敏度高的新型分析技术逐步替代传统方法（例如数字 PCR 替代 qPCR、质谱肽图替代传统 HPLC 肽图）。

**分析方法变更的风险评估与分级**

须对每项方法变更进行**全面的风险评估**，基于以下维度确定变更风险等级和研究策略：

| 风险因素                | 高风险情形                   | 低风险情形                   |
| ----------------------- | ---------------------------- | ---------------------------- |
| 检测原理是否改变        | 从生物学方法改为物理化学方法 | 同类方法的技术升级           |
| 是否影响核心 CQA 的检测 | 主峰纯度、效价检测方法变更   | 辅助性检测（如外观）方法变更 |
| 是否影响杂质的检出限度  | 新方法灵敏度低于旧方法       | 新方法灵敏度等同或更高       |
| 变更是否有跨机构影响    | 方法须在多个实验室使用       | 仅在单一实验室使用           |

**上市后方法变更的核心研究内容**

**① 提供变更分析方法的理由和依据**

须从科学（方法性能改进）、法规（满足最新要求）或技术可行性（旧方法设备停产）等角度提供清晰的变更理由。

**② 对新方法进行全面方法学验证**

按照 ICH Q2(R2) 开展新方法的完整验证，验证参数的覆盖程度须与变更级别匹配：

- 重大方法变更（如检测原理改变）：须全面验证所有相关参数；
- 较小改变（如同类设备升级）：可进行简化验证（部分参数验证），但须有科学依据支持简化的合理性。

**③ 采用变更前后方法对代表性样品进行比对分析**

- 选用能覆盖整个测量范围的代表性样品（包括正常样品、边界样品、降解样品）；
- 同一批次样品用新旧方法平行检测，进行统计学等效性评估；
- 若比对研究结果显示新旧方法存在系统性偏差，须分析偏差来源，并评估是否影响产品质量控制决策。

**④ 评估原有质量标准对新方法的适用性**

当新方法的灵敏度或精密度优于旧方法时，原有质量标准限度（如 HCP < 100 ppm）须重新评估：

- 旧方法的限度是否基于旧方法的 LOQ 设定的？
- 新方法更低的 LOQ 是否提示原限度应相应收严？

:::

## 分析方法在 CTD 申报资料中的定位：各类研究在 M3 模块的准确放置规则

:::answer

**CTD 模块定位原则**

按照 ICH M4Q（CTD 质量部分）的结构要求，分析方法相关的不同内容须放置在 Module 3 的不同层级，错误定位是申报资料规范性问题的常见来源之一。

**分析方法各类研究在 CTD 中的定位**

| 研究类型                     | CTD 位置                               | 内容说明                                                                                     |
| ---------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------- |
| **方法开发过程记录**         | **通常无需在 CTD 中提交**              | 方法开发的探索性研究记录为内部文件，申报资料中无需完整呈现                                   |
| **方法详细描述（SOP 级别）** | 3.2.S.4.2（原液）/ 3.2.P.5.2（制剂）   | 确定的分析方法须在此章节进行完整、可执行的描述（仪器、试剂、系统适用性、操作步骤、结果计算） |
| **方法学验证数据**           | 3.2.S.4.3（原液）/ 3.2.P.5.3（制剂）   | 所有验证参数的数据和验证报告须在此提供                                                       |
| **分析方法转移研究报告**     | 3.2.S.4.3 或 3.2.P.5.3（方法验证部分） | 若发生方法转移，转移方案和结果报告在方法验证部分提供                                         |
| **质量标准**                 | 3.2.S.4.1 / 3.2.P.5.1                  | 最终放行质量标准（含所有检测项目、方法和限度）                                               |
| **批分析结果**               | 3.2.S.4.4 / 3.2.P.5.4                  | 代表性批次的检测结果（须与质量标准对照判断是否合格）                                         |

**对非药典方法的特殊要求**

> 申报资料须提供**所有用于原液和制剂放行检验的非药典方法**的完整方法学验证资料。

对于药典方法（如《中国药典》或 USP 收载的方法），须提供适用性研究（Suitability Study）数据，证明该通用方法在具体产品条件下仍能达到预期的检测性能。

**验证报告呈现格式的最佳实践**

- 建议以**汇总表格**形式对方法学验证结果进行总结（验证参数、可接受标准、实测结果、评估结论的列表式呈现），便于审评人员快速扫览；
- 在汇总表之后，在子单元中提供每个验证参数的详细实验设计和结果数据；
- 所有原始数据（色谱图、计算表格）须作为附件提供，不能仅呈现汇总数字。

:::

## 申报资料常见问题——分析方法缺陷：方法落后、系统适用性缺失与检测项目缺项

:::answer

**CDE 审评中分析方法常见问题汇总（来源：CDE 分享）**

**第一类：方法落后，不具有专属性或不满足当前分析要求**

> 典型问题：企业仍在使用 SDS-PAGE 控制纯度和分子大小异构体，而非 CE-SDS。

| 落后方法             | 现代替代方法                 | 替换的核心理由                                                                                   |
| -------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------ |
| SDS-PAGE（凝胶电泳） | CE-SDS（毛细管凝胶电泳）     | CE-SDS 精确度更高、定量更准确、重复性 RSD < 2%（SDS-PAGE 半定量，RSD 可达 10%+），已成为行业标准 |
| 传统 IEF 电泳        | iCIEF/cIEF（毛细管等电聚焦） | 分辨率更高，自动化，可精确定量各电荷变体比例                                                     |
| Dot Blot 残余 DNA    | qPCR 或 ddPCR                | 灵敏度提升 3～4 个数量级（从 ng 到 pg 级），可定量                                               |
| 传统 ELISA HCP       | LC-MS 辅助 HCP 分析          | LC-MS 可识别具体 HCP 种类，发现 ELISA 漏检的高风险 HCP                                           |

**第二类：系统适用性要求不全面**

- 色谱分析方法未明确**色谱柱温度**（色谱柱温度对分离效果影响显著，须作为系统适用性控制参数）；
- 鉴别检测项目缺少**一致性判定标准**（如肽图鉴别仅要求"图谱相似"，但未规定相似度计算方法和判定阈值）；
- 生物活性测定方法缺少**平行线适用性检验**（对于使用 4PL 拟合的细胞法，须预定平行线合格标准）。

**第三类：检测项目缺项或质量标准拟定不合理**

| 缺陷类型         | 具体问题                                                | 改正建议                                             |
| ---------------- | ------------------------------------------------------- | ---------------------------------------------------- |
| 检测项目缺项     | 制剂质量标准缺少异常毒性（国内 BLA 要求）和关键辅料含量 | 补充相关检测项目                                     |
| 制剂特有属性缺失 | 预充式注射剂制剂质量标准缺少剂量准确度（Dose Accuracy） | 增加注射剂量重现性验证                               |
| CDR 区控制缺失   | 肽图检测项目未专门对 CDR 区肽段进行鉴别确认             | 在肽图质量标准中明确 CDR 区特征肽段的识别要求        |
| 限度未设定       | 电荷异质性的酸性峰/碱性峰仅报告检测值，未拟定接受限度   | 须基于历史数据统计设定可接受范围，不能仅为"报告结果" |

**第四类：方法描述不规范**

- 引用药典通则**未注明版本号**（如仅写"参照药典通则 0501"，未注明 2020 版）；
- 文字描述和格式与药典通则原文不一致（须逐字与药典核对，或明确注明"修改内容"）；
- 涉及积分计算（如 SEC-HPLC 主峰面积百分比）的检测项目，未提供**特征图谱**（空白对照图谱 + 典型样品图谱 + 典型系统适用性图谱）作为附件。

:::

## 申报资料常见问题——分析方法验证缺陷：参数不全、接受标准设定与 LOQ 定义的典型错误

:::answer

**第一类：验证参数不全面，缺少必要项目**

**典型缺陷一：产品相关杂质峰的精密度/准确度未验证**

对于 SEC-HPLC 中的高分子量（HMW）峰和低分子量（LMW）峰，许多申请人仅验证了**主峰**的精密度和准确度，而遗漏了 HMW 和 LMW 峰的验证。

这一缺陷的后果是：无法证明方法对低水平聚体（如 HMW 1%～2% 水平）的定量准确性，而这正是最关键的控制维度。

**正确做法：** 须专门配制含不同水平 HMW（通过热应力样品）的混合样品，在 LOQ～规格上限范围内验证 HMW 峰的准确度（加标回收率 80%～120%）和精密度（CV% ≤ 20%）。

**典型缺陷二：耐用性考察不充分**

- 仅考察了样品放置稳定性（样品在检测前室温放置 X 小时后测定值不变），而**未考察分析方法本身的潜在影响因素**（如色谱柱批次差异、流动相 pH ±0.1 的变化、柱温 ±2℃ 的变化）；
- 正确做法：对影响分析结果的关键方法参数进行系统性扰动实验（Robustness Study），通常采用 Plackett-Burman 部分因子设计同时评估 5～7 个因素。

**第二类：可接受标准拟定不合理（过宽）**

| 验证参数                   | 通行业界标准                 | 常见错误（过宽设置）                                                   |
| -------------------------- | ---------------------------- | ---------------------------------------------------------------------- |
| HPLC 纯度分析重复性（RSD） | ≤ 2%                         | 有公司设置 ≤ 10%，导致无法有效监控批间一致性                           |
| 准确度（回收率）           | 98%～102%                    | 有公司设置 85%～115%（更适用于生物活性方法，不适用于物理化学纯度方法） |
| 生物活性方法重复性         | ≤ 25%～30%（细胞法固有变异） | 有公司模仿化学方法设置 ≤ 2%，导致方法验证无法通过                      |

**核心原则：** 可接受标准须与分析方法的类型（物理化学法 vs. 生物学方法）、检测对象（主峰 vs. 微量杂质）相匹配，不能一刀切。

**第三类：定量限（LOQ）的设置位置错误**

**具体问题描述：**

部分企业将宿主细胞残留蛋白（HCP）和 Protein A 残留的 ELISA 检测方法的 **LOQ 设置在标准曲线的中下段**（而非最低点附近），这导致逻辑上的矛盾：标准曲线的下段数据点实际上未经过严格的 LOQ 验证（未验证其准确度和精密度），却被包含在"可用"的测量范围内。

**正确定位：** LOQ 须设置在**标准曲线的最低验证浓度点**（即经过 LOQ 验证的最低浓度），该浓度须低于质量标准限度，确保方法能可靠地检测到不合格品。

:::

## 申报资料常见问题——分析方法转移缺陷：比对研究缺失与差异分析不充分

:::answer

**方法转移（Method Transfer）的监管要求**

分析方法转移是指将经过验证的分析方法从发送实验室（Sending Site）正式传递给接收实验室（Receiving Site）的过程，须通过**转移研究（Transfer Study）**证明接收实验室能够可靠地重现该方法并获得等效的检测结果。

**常见缺陷一：发生方法转移但未开展比对研究**

某些情况下，企业在以下场景发生了实质性的方法转移，却未开展规范的比对研究：

- 方法开发实验室 → QC 放行实验室；
- 研发场地 → 商业化生产场地 QC 实验室；
- 国内实验室 → 海外合作方实验室（License-out 场景）。

**监管机构的期望：** 任何发生了方法转移的情形，均须在 CTD 的方法验证章节（3.2.S.4.3 或 3.2.P.5.3）提供转移研究报告，包括：转移方案（预定样品、检测项目、可接受标准）和转移结果（发送方与接收方的平行检测数据比对）。

**常见缺陷二：比对实验存在差异但未分析原因**

某些企业提供了比对研究数据，但发送方和接收方对相同样品的检测结果存在统计学显著差异，申报资料中却未对这一差异进行分析和解释。

审评人员看到"转移失败"却没有原因分析，会产生以下疑问：接收方实验室的能力是否满足要求？差异是否影响质量控制决策？后续是如何解决的？

**正确处理方式：**

1. 明确差异的来源（是操作差异、设备差异、试剂批次差异还是系统性方法问题）；
2. 分析差异的规模（在方法精密度范围内的随机误差 vs. 超出方法精密度的系统性偏差）；
3. 说明已采取的纠正措施和再验证结论；
4. 提供证明差异不影响产品质量控制决策的数据支持。

:::

## BLA 阶段辅料方法验证的实际要求：内毒素/微生物限度的处理原则

:::answer

**核心结论**

BLA 阶段，制剂辅料（如缓冲液盐类、蔗糖、聚山梨酯等）的分析方法验证须完成，**包括内毒素检测和微生物限度检测**（若辅料有相应的质量标准要求）。

**实际操作中的处理逻辑**

| 辅料类型                      | 验证要求                                              | 是否必须写入申报资料                           |
| ----------------------------- | ----------------------------------------------------- | ---------------------------------------------- |
| 药典收载辅料                  | 进行适用性确认（Suitability Study）即可，无需完整验证 | 通常仅说明"符合药典要求"，可不提交详细验证报告 |
| 非药典辅料                    | 须进行全面方法学验证（包括内毒素和微生物限度方法）    | 须写入申报资料（P.4.3）                        |
| 涉及内毒素/微生物的新检测方法 | 即使是药典方法，若适用条件特殊，须提供适用性数据      | 建议在 P.4.3 中提供，即使监管机构未强制要求    |

**关于是否写入申报资料的实践建议**

虽然内毒素和微生物限度的辅料验证数据在实际申报中有时不被要求提交，但**建议在内部存档**，原因：

- 现场检查（PAI）时可能被要求提供；
- 若后续发生辅料供应商变更（新辅料批次的内毒素水平变化），有基线数据可供参考；
- 对于高风险辅料（动物源性或新型辅料），监管机构在审评中可能主动要求提供。

:::

## IND 阶段 DS 和 DP 异地生产的合规要求与运输管控关键点

:::answer

**IND 阶段异地生产的法规可行性**

在 IND 阶段，原料药（DS）和制剂（DP）在**不同生产场地**生产是被允许的，这在实践中非常普遍，原因包括：

- DS 通常由专业的 CMO（合同制造商）在其具有生物反应器设施的工厂生产；
- DP 灌封可能在具备 GMP 灌装能力的另一合格 CMO 完成；
- 申请人可能在 IND 阶段尚未建设自有商业化生产设施。

**核心合规要求：DS 运输过程的监控**

当 DS 和 DP 在不同地点生产时，DS 从原液生产场地到制剂灌封场地的**运输过程**成为质量控制的关键风险点：

| 监控维度         | 具体要求                                                                          |
| ---------------- | --------------------------------------------------------------------------------- |
| **温度监控**     | 全程实时温度记录（数据记录仪），须覆盖从装箱到接收的完整运输链                    |
| **运输条件验证** | 须提供运输条件验证数据，证明在预期温度范围（如 -70℃ 干冰运输）下，DS 质量维持稳定 |
| **温度偏差处理** | 须建立运输温度偏差的处置程序（如出现短暂温升，如何评估对 DS 质量的影响）          |
| **包装完整性**   | 运输包装须有防破损、防泄漏设计，并经过跌落测试等包装验证                          |

**DS 运输验证的稳定性数据要求**

若 DS 须在运输温度（如 -70℃ 以下冻存运输）以外经历暂时的不同温度（如从 -70℃ 冻存取出、装箱过程中在 2～8℃ 条件下短暂暴露），须有相应的**中间温度稳定性数据**支持这段暴露时间的可接受性。

**商业化阶段的要求升级**

IND 阶段允许简化的运输管控，但在 BLA 申报阶段，须提供完整的**DS 运输验证报告**（包括温度分布研究、包装性能验证），作为 CMC 资料的组成部分（通常在 3.2.P.3.3 中引用）。

:::

## BLA 申报批分析与稳定性批次的选择策略：代表性原则与工艺变更的桥接要求

:::answer

**批分析和稳定性研究批次选择的总体原则**

> 一般提交**最具有代表性**的批次数据，须覆盖最终商业化工艺下的生产状态。

**代表性批次的定义**

- 须采用与拟上市商业化工艺**实质相同**的工艺生产（如规模、设备、关键参数均与拟上市工艺一致）；
- 须包含用于支持 BLA 申报的关键数据批次：临床 III 期研究用批次（临床批）+ 商业化工艺验证批次（PPQ 批）。

**典型的批次覆盖策略（无工艺变更情况）**

| 批次类型               | 在批分析中的作用                            | 在稳定性研究中的作用             |
| ---------------------- | ------------------------------------------- | -------------------------------- |
| 早期临床批（I/II 期）  | 可包含，用于展示工艺演变历史                | 早期加速稳定性参考               |
| 确证性临床批（III 期） | **必须包含**，为工艺的临床验证基础          | **必须包含**，支持上市有效期     |
| PPQ 批（商业化验证批） | **必须包含**（≥3 批连续），证明商业化可行性 | **必须包含**，提供最新稳定性状态 |

**有工艺变更情况下的桥接要求（最复杂场景）**

若在开发过程中发生了影响产品质量的**重要工艺变更**，批次选择须能完整呈现变更前后产品的可比性：

```
工艺版本 A（I 期临床）→ 工艺版本 B（II 期）→ 工艺版本 C（III 期）→ 商业化工艺 D
         ↑可比性研究             ↑可比性研究              ↑可比性研究
         (A→B)                  (B→C)                    (C→D)
```

- 每次重要变更前后均须选取代表性批次进行头对头可比性分析；
- 申报资料须清晰呈现**完整的工艺演变历史链**，从早期临床到商业化批次的每次变更均有数据支撑；
- 若某次变更引入了产品质量属性的改变（即使在可接受范围内），须说明改变的临床影响评估。

:::

## BLA 阶段过程中控（IPC）方法的验证要求：是否必须验证及申报资料中的呈现方式

:::answer

**核心结论：IPC 方法须验证，但可进行简化**

BLA 申报阶段，生产过程中控（In-Process Control, IPC）检测方法**须进行验证**，但监管机构允许根据方法类型和风险水平进行简化验证（Abbreviated Validation）。

**IPC 方法的特殊性**

IPC 方法的验证要求与放行方法（Release Method）有所不同：

| 比较维度 | 放行方法验证                             | IPC 方法验证                       |
| -------- | ---------------------------------------- | ---------------------------------- |
| 监管要求 | 全面验证（ICH Q2(R2) 所有相关参数）      | 可简化（风险相应参数）             |
| 验证参数 | 专属性、线性、准确度、精密度、LOD/LOQ 等 | 可聚焦于精密度（重复性）和工作范围 |
| 目的     | 支持产品批放行决策                       | 监控工艺状态，非最终放行依据       |

**简化验证的科学依据**

IPC 检测通常用于**实时监控工艺状态**而非最终产品放行，因此：

- 若 IPC 结果不符合，通常触发调查或工艺调整，不直接决定产品合格/不合格（最终依赖放行检测）；
- IPC 对精密度的要求往往高于准确度，重复性（精密度）验证须重点关注；
- IPC 方法的风险程度决定验证的深度——关键 IPC（如病毒灭活步骤的 pH）须严格验证，辅助 IPC 可简化。

**是否写入申报资料**

> **建议写入申报资料中，在 3.2.S.4.3（原液）和 3.2.P.5.3（制剂）的分析方法验证章节中呈现。**

理由：

- IPC 方法验证数据支持了工艺验证（PPQ）中 CPP 控制范围的设定，是工艺合理性的直接证据；
- 现场检查（PAI）时可能被审查；
- 未来工艺变更时，有 IPC 方法的历史验证数据便于评估是否需要再验证。

**特殊情况的处理**

若 IPC 方法与放行方法相同（如同一个 SEC-HPLC 方法既用于中间体过程控制也用于成品放行），则放行方法的全面验证可以覆盖 IPC 的验证需求，无需重复验证。

:::

## IND 申报批分析批次数量与两批次的工艺一致性：硬性要求与实践建议

:::answer

**IND 批分析批次数量：建议两批次**

目前中美欧 IND 申报的行业惯例是提交**至少两批次**批分析数据，企业通常采用以下组合：

- **第一批：毒理批次（安全性研究批次）**——用于支持临床前毒理研究；
- **第二批：GMP 临床批次**——用于支持临床试验启动，并证明 GMP 生产能力。

两批次策略的价值在于：提供最低限度的批间一致性证据，证明工艺具备基本的可重现性。

**两批次稳定性数据的工艺一致性：无硬性要求但须做可比性**

IND 申报中，两批次（毒理批 + 临床批）的稳定性研究**不要求工艺完全一致**，但须满足以下条件：

**须做好毒理批次和临床批次的可比性研究**，包含三个核心维度：

| 可比性维度       | 具体内容                                                                             | 意义                                     |
| ---------------- | ------------------------------------------------------------------------------------ | ---------------------------------------- |
| 工艺差异分析     | 列出两批次工艺的所有差异（如培养基批次不同、纯化规模不同），并评估每个差异的潜在影响 | 证明差异在可接受范围内，不影响产品安全性 |
| 质量属性比对分析 | 两批次关键 CQA（聚体、电荷变体、糖型、效价）的头对头对比                             | 证明两批次产品质量基本一致               |
| 稳定性数据比对   | 两批次的稳定性研究结果（即使时间点可能不同）进行趋势比较                             | 证明两批次的稳定性特征相似               |

**申报资料中的呈现位置**

- 可比性研究报告建议写入 **3.2.P.2.6（制剂产品开发——相容性章节，但实际上可比性研究通常放在 3.2.P.2.3 或单独章节）**或 3.2.S.2.6（原料药生产工艺开发）；
- 参照 CTD 格式规范，可比性数据通常在工艺开发历史（S.2.6）部分作为变更史的一部分呈现。

:::

## 生物制品 BLA 申报时运输验证的强制要求与稳定性研究的整合

:::answer

**核心结论：BLA 申报须完成运输验证**

生物制品在 BLA 申报阶段，须提供**运输验证（Transportation Validation）**数据，以及运输条件下的**稳定性研究（In-Transit Stability）**数据。这是原料药包装系统（S.6）和制剂包装系统（P.7）适用性论证的组成部分。

**运输验证的核心内容**

**① 温度分布研究（Temperature Mapping）**

- 对代表性运输包装方案进行全程温度监控，证明在预期运输条件（最长运输时间、极端环境温度）下，DS 或 DP 能够维持在规定储存温度范围内；
- 须覆盖不同季节（夏季高温 + 冬季低温）和不同运输路线（陆运/空运）的代表性条件。

**② 运输包装性能验证**

- 测试包装在运输应力（振动、跌落、冲击）下的完整性和保护效果；
- 须符合 ISTA 3H、ASTM D4169 等运输包装验证标准（视申报地区要求而定）。

**运输期间的稳定性研究**

须有数据支持 DS 或 DP 在运输全程（包括中转、清关等可能的延误情况）的质量稳定性：

- 对代表性批次在模拟运输条件下（如 -70℃ 干冰运输 72 小时 + 中转温度波动）进行稳定性考察；
- 考察项目须覆盖与运输应力最相关的质量属性（外观、聚体、活性等）；
- 须建立运输温度超出规定范围时的偏差处置 SOP，包含温度偏差对产品质量影响的评估框架。

**运输验证在 CTD 中的位置**

运输验证和运输稳定性数据通常在以下位置引用：

- **S.6（原料药包装系统）**：DS 的运输包装说明和验证数据；
- **P.7（制剂包装系统）**：成品的运输包装说明和验证数据；
- **S.7.1 / P.8.1（稳定性总结）**：运输稳定性研究结果的简要描述。

:::

## IND 阶段一次性袋子的相容性研究要求：风险评估优先原则与供应商数据的应用

:::answer

**官方法规层面：IND 阶段无强制要求**

目前中美欧监管机构均未明确规定生物制品 IND 申报阶段须强制完成一次性系统（Single-Use Systems, SUS，包括一次性储液袋、管路、过滤器等）的可提取物/浸出物（E&L）相容性研究。

**然而：被监管机构质疑时的应对策略**

尽管无强制要求，若在审评过程中（或 IND 受理时的技术审评）被监管机构提出质疑，须能提供充分的理由证明 IND 阶段使用的一次性袋子不会对产品质量和患者安全产生不可接受的风险。

**最低限度的应对策略：风险评估 + 供应商数据**

| 应对层次             | 具体措施                                                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 第一层：风险评估     | 评估一次性袋子材质（如 EVA、多层 PE 共挤）的固有 E&L 风险级别；评估接触条件（接触温度、接触时间、溶液 pH）对浸出的影响             |
| 第二层：供应商数据   | 从一次性袋子供应商（如 Sartorius、Cytiva、Thermo Fisher）获取该材料的通用 E&L 研究报告（提取物研究报告），作为安全性证明的参考依据 |
| 第三层（若质疑较强） | 对实际接触条件下（接触时间、温度、溶液）的浸出物进行初步检测，至少覆盖关键风险化合物                                               |

**IND 向 BLA 的升级要求**

进入 BLA 阶段后，须完成符合监管机构要求的完整 E&L 研究（包括可提取物研究和基于稳定性样品的浸出物研究），并在申报资料 S.6 和 P.7 中提供完整数据。建议在临床 II 期结束前即启动 BLA 阶段的 E&L 研究，留出足够的研究周期（通常需要 12～18 个月）。

:::

## IND 阶段制剂辅料证明文件要求：LOA 的充分性与其他证明文件的豁免依据

:::answer

**核心结论：IND 阶段提供 LOA 即可**

在 IND 阶段，制剂辅料仅需提供**分析证书（LOA，Letter of Analysis / Certificate of Analysis, CoA）**，无需同时提交购买发票或供货协议。

**LOA 的法规定位**

LOA（CoA）是供应商对该批次辅料的质量检验结论文件，包括：

- 辅料名称、规格、批号；
- 各检测项目的检测结果和合格判定；
- 供应商信息和出具日期。

LOA 的提交，证明了该辅料批次符合声明的质量标准，这是 IND 阶段辅料控制的基本要求。

**IND 与 BLA 辅料证明文件要求的差异**

| 证明文件类型                        | IND 阶段要求             | BLA 阶段要求                                                  |
| ----------------------------------- | ------------------------ | ------------------------------------------------------------- |
| LOA/CoA                             | **必须提供**             | **必须提供**                                                  |
| 购买发票                            | 无需提供                 | 通常无需提供（供应商审计时可能涉及）                          |
| 供货协议（Quality Agreement）       | 无需提供                 | **建议签订**（BLA 阶段供应商管理要求升级，须建立质量协议）    |
| 供应商 GMP 证书                     | 可选，高风险辅料建议提供 | **须提供**（动物源性辅料、高风险辅料须有供应商 GMP 审计证明） |
| 变更通知协议（Change Notification） | 无需                     | **BLA 阶段建议建立**，确保供应商变更能及时通知                |

**高风险辅料的额外要求（即使在 IND 阶段）**

对于以下类型的辅料，即使在 IND 阶段，也建议提供 LOA 之外的额外文件：

- **动物源性辅料（如人源白蛋白、动物来源明胶）：** 须提供 TSE/BSE 安全性证明文件；
- **首次使用的新辅料：** 须提供基本的安全性数据（符合 ICH Q7 要求的说明材料）。

:::

## EOPC 遗传稳定性研究的强制检测项目：插入基因完整性与染色体稳定性的系统评估

:::answer

**EOPC 遗传稳定性研究的法规依据**

根据《中国药典》三部、ICH Q5B（表达载体）和 ICH Q5D（细胞基质）等指导原则，生产终末细胞（EOPC）须开展系统性的**遗传稳定性研究**，证明在整个商业化生产代次范围内，目的基因的结构和表达状态保持稳定。

**EOPC 遗传稳定性研究的核心检测项目**

| 研究项目                 | 具体内容                                                               | 检测方法                                | 监管意义                                 |
| ------------------------ | ---------------------------------------------------------------------- | --------------------------------------- | ---------------------------------------- |
| **插入基因拷贝数**       | 目的基因（重链、轻链）在生产末期细胞中的拷贝数，与 MCB/WCB 进行比较    | Southern Blot / qPCR / ddPCR            | 检测是否发生拷贝数丢失（提示基因不稳定） |
| **插入染色体的位点**     | 目的基因在宿主细胞染色体中的整合位点，确认无明显整合位点迁移           | FISH（荧光原位杂交）/ 全基因组测序      | 检测染色体重排是否导致整合位点变化       |
| **插入基因的序列**       | 目的基因（编码目标蛋白的全序列），与原始设计序列 100% 比对             | DNA 测序（Sanger 或 NGS 全覆盖）        | 确认生产过程中无点突变积累               |
| **目的基因表达水平**     | 与 MCB/WCB 相比，EOPC 的 mRNA 水平（转录水平）和蛋白表达量（翻译水平） | RT-qPCR（mRNA）/ 发酵工艺表达量（蛋白） | 检测启动子/增强子活性是否随代次退化      |
| **表达产物的分子完整性** | EOPC 生产的目标蛋白一级结构（肽图 + 质谱）与 MCB 来源产品的一致性      | LC-MS/MS 肽图                           | 排除翻译准确性随代次下降的可能           |

**为什么这些研究对 EOPC 特别重要**

EOPC 代表细胞在**最大允许传代代次（MLPC）**的生物学状态——这是整个生产周期中遗传漂移积累最多的时间点。若在 EOPC 状态下细胞的遗传稳定性仍符合标准，则可以证明在整个商业化生产周期内（从 WCB 接种到 EOPC），细胞的遗传完整性得以维持。

**EOPC 研究的监管申报要求**

- 须至少完成 **1 次全面的 EOPC 检定**（通常在 BLA 申报前完成，使用商业化规模的代表性生产运行产生的 EOPC）；
- 当生产工艺发生改变（如规模变更、培养基变更）时，须重新评估是否须对 EOPC 进行再检定；
- EOPC 的检定结果须与 MCB 检定结果进行比对，须在申报资料（3.2.S.2.3）中提供检定结果总结和比较分析。
