## 细胞株稳定性研究的法规驱动与核心价值

:::answer

细胞株稳定性研究是保证生物制品从研发到商业化生产全程质量一致性的基础性工作，其必要性来源于动物细胞的内在生物学特性与法规的双重驱动。

**稳定性研究的生物学必要性**

动物细胞（尤其是 CHO 细胞）具有高度的基因组可塑性，这一特性既是其表达外源蛋白的优势所在，也是其潜在不稳定性的根源：

- CHO 细胞对外来插入基因具有极强的耐受性，使基因工程成为可能
- 但同样因为这种可塑性，细胞株在长期传代过程中可能发生宿主染色体重排、目的基因拷贝数减少、转录活性丧失、表型/基因型漂移等变化
- 上述任何一类变化均可能导致目的蛋白的产量下降或质量属性改变，危及产品的安全性和有效性

**法规要求的明确规定**

中国药典（2020 版三部）、FDA、EMA 和 ICH 等主要监管指南均对细胞株稳定性提出了明确要求。中国药典的核心要求聚焦两个原则：

1. **单克隆来源**：生产用细胞株必须来源于单个细胞（单克隆性），确保遗传背景均一
2. **稳定而连续生产**：细胞株须能在规定的传代范围内稳定生产出质量和产量符合预期的产品

> **关键触发条件：** 当生产工艺发生变化时（如培养基变更、培养工艺调整、反应器规模变更），须重新开展细胞株稳定性研究，以重新证明在新工艺条件下的稳定性。

:::

## CHO 细胞株不稳定性的分子机制：基因组可塑性驱动的多层次变化

:::answer

理解细胞株不稳定性的根本原因，是设计有效稳定性研究和实施风险控制措施的前提。

**根本原因：CHO 细胞基因组的固有不稳定性**

CHO 细胞的基因组不稳定性根植于其历史：

- CHO-ori 细胞最初被永生化后，经历了多轮随机诱变和化学处理以生成 CHO-DG44 和 CHO-K1 宿主细胞
- 这一过程已发生数百代传代，积累了大量染色体异常，包括缺失、重复和易位
- CHO 染色体具有高度的单倍体发生率（Haploidization），导致基因组高度不对称

**不稳定性的四类表现形式**

| 不稳定类型                     | 分子机制                                       | 对生产的影响                |
| ------------------------------ | ---------------------------------------------- | --------------------------- |
| **染色体重排**                 | 宿主细胞染色体结构异常                         | 影响目的基因的转录活性      |
| **目的基因拷贝数丢失**         | 位于染色体臂末端的基因（易丢失位置）随传代减少 | 产量下降                    |
| **转录沉默（Gene Silencing）** | 甲基化等表观遗传修饰使启动子失活               | 表达量下降，但 DNA 水平未变 |
| **基因型 / 表型漂移**          | DNA 修复和转录机制缺陷导致突变背景率较高       | 产品质量属性（CQA）发生偏移 |

**生产细胞系的特殊风险**

将目的基因整合到宿主细胞中时，整合位点的随机性（位置效应）是不稳定性的重要来源：

- 整合到转录活跃的常染色质区域 → 高表达，稳定性相对较好
- 整合到异染色质区域或染色体末端 → 低表达，拷贝数丢失风险高，转录沉默更易发生
- 宿主细胞本身的基因组不稳定性会传递到生产细胞系，且可能被进一步放大

:::

## 筛选压力与细胞株稳定性的动态平衡：压力设置的量化考量

:::answer

筛选压力（Selection Pressure）是维持外源基因在宿主细胞中稳定表达的重要手段，其设置须在稳定性保障与细胞生长效率之间寻求平衡。

**筛选压力的作用机制**

CHO 细胞转染系统中，选择性标记（如谷氨酰胺合成酶 GS、二氢叶酸还原酶 DHFR）与目的基因共整合。当选择性代谢底物（MTX、MSX 等）存在时：

- 携带选择性标记的细胞才能存活
- 在高浓度选择压力下，细胞倾向于扩增基因拷贝数以获得更强的选择性耐受能力，同时目的基因的拷贝数也随之增加

**筛选压力对稳定性的双向影响**

| 筛选压力状态             | 对目的基因的影响                                                   | 对细胞生长的影响               |
| ------------------------ | ------------------------------------------------------------------ | ------------------------------ |
| **压力过低（撤除压力）** | 外源基因拷贝数迅速下降，经历短暂下降期后趋于稳定（新的低拷贝稳态） | 细胞生长恢复正常               |
| **压力适中**             | 维持目的基因拷贝数在稳定水平，防止不利突变累积                     | 细胞生长与表达量平衡           |
| **压力过高**             | 高拷贝数，表达量高，稳定性较好                                     | 细胞生长速率下降，生产成本增加 |

**关键实践结论**

- 降低筛选压力后，细胞株会经历一个**外源基因拷贝数和表达量迅速下降的过程，随后趋于稳定**
- 外源基因整合到染色体两臂末端的细胞克隆拷贝丢失倾向更明显
- 通常需要**维持合适的选择压力**来防止目的基因拷贝数减少或突变，但须通过实验优化找到最佳压力水平
- 在不确定细胞系稳定性时，建议**同时开展带筛选压力和不带筛选压力的两组实验**，对比结果以全面评估稳定性

:::

## 细胞株稳定性研究的四类型与法规要求

:::answer

《中国药典》2020 版三部明确规定，生产者须具有目的基因稳定性资料，稳定性研究须覆盖 MCB/WCB 与 EOPC 之间的一致性。

**四类稳定性研究的内容与目的**

**类型一：重组细胞的遗传稳定性研究**

- **研究方法**：将细胞进行传代，在特定代次（如 P5、P10、P15、P20）冻存，复苏后检测
- **检测项目**：
  - 插入基因拷贝数（Southern Blot / qPCR 法）
  - 插入染色体的整合位点（FISH / 全基因组测序）
  - 插入基因的 DNA 序列（NGS 测序）
  - 目的基因 mRNA 表达水平
- **判断标准**：高代次与低代次细胞的遗传参数无显著漂移

**类型二：目的基因表达稳定性研究**

- **研究方法**：将传至不同代次的细胞采用缩小模型工艺进行培养生产
- **检测项目**：各代次细胞的产物表达量（Titer）、比生产速率（Qp）
- **判断标准**：业界共识为最高限传代次与初始代次间的表达量变化应控制在 **30% 以内**

**类型三：目的产品持续生产稳定性**

- **研究方法**：不同代次细胞在缩小模型工艺中进行完整的 Fed-batch 培养
- **检测项目**：各代次细胞生长性能、代谢参数、蛋白表达量和关键质量属性（CQA）
- **判断标准**：不同代次的细胞生长、蛋白表达和蛋白质量与初始代次具有可比性（通常 ≤ 30% 偏差）

**类型四：保存条件下的稳定性**

- **研究方法**：每隔半年到 1 年复苏一支细胞库（MCB 或 WCB）进行生产运行
- **检测项目**：细胞复苏率（活率）、生长性能、产量
- **判断标准**：复苏后生产运行正常，与历史数据可比

:::

## 细胞株稳定性研究的 IND 与 BLA 分阶段要求

:::answer

细胞株稳定性研究的深度和规模随开发阶段递进，IND 和 BLA 阶段的要求存在系统性差异。

**IND 阶段：快速、有限的早期稳定性评估**

| 维度         | IND 阶段要求                                                                         |
| ------------ | ------------------------------------------------------------------------------------ |
| 研究用细胞库 | 采用 **PCB（Pre-clinical Cell Bank）** 开展有限稳定性研究                            |
| 研究规模     | 可在**摇瓶或小型反应器**规模下开展，不要求生产规模                                   |
| 工艺要求     | 可不采用最终确定的工艺（Fed-batch 模式），快速获得数据支持申报节奏                   |
| 传代考察节点 | 通常传至 P5、P10、P15、P20 各代次冻存后复苏生产                                      |
| 重点考察项目 | 各代次细胞生长性能、代谢状态和产量稳定性；如已有合适分析方法，可同时评估关注质量属性 |
| 目的         | 快速满足临床样品供应和 IND 申报的基本数据要求                                        |

**BLA 阶段：严格、全面的商业化验证**

| 维度         | BLA 阶段要求                                                               |
| ------------ | -------------------------------------------------------------------------- |
| 研究用细胞库 | 须对 **MCB 和 WCB** 分别开展稳定性研究                                     |
| 研究规模     | 须在**生产规模或经过资质确认（SDQ）的缩小模型**中进行                      |
| 工艺要求     | **必须采用最终的商业化生产工艺**（不同工艺条件下细胞株稳定性存在显著差异） |
| 传代考察节点 | 与 IND 阶段相同（P5、P10、P15、P20），但须在验证的缩小模型中执行           |
| 重点考察项目 | 全面评估：细胞生长、代谢、产量、蛋白质量（CQA）和遗传稳定性                |
| 目的         | 证明在整个商业化生产限传代次内，产品质量和产量的一致性和可预测性           |

:::

## 细胞株稳定性的四维评价指标与可接受标准

:::answer

判断细胞株是否稳定须从四个维度综合评估，各维度具有不同的可接受标准和监管关注重点。

**维度一：生长特性稳定性**

各代次细胞在当前工艺条件下的生长和代谢参数应无显著变化，关注指标包括：活细胞密度峰值（VCD peak）、积分活细胞密度（IVCD）、细胞活率曲线、葡萄糖消耗/乳酸生成动态。

> **例外情形的合理解读：** 实际项目中常见随传代次数增加活细胞密度峰值提升的现象（细胞适应性增强）。若伴随该变化的产量、质量、遗传指标均符合要求，且密度增加不影响工艺稳定性和可放大性，通常认为该情形可以接受，不应机械地以"曲线一致"为唯一标准。

**维度二：生产产量稳定性**

- 各代次细胞在当前工艺条件下的产物表达量应无显著变化
- **行业可接受标准（无法规明文规定，业界共识）**：最高限传代次与初始代次间的表达量变化 **≤ 30%**，认为细胞株在产量方面是稳定的
- 须同时评估绝对 Titer 和比生产速率（Qp）两个维度

**维度三：产物质量稳定性**

各代次细胞产物的关键质量属性应无显著变化，评估项目通常包括：

| CQA 类别   | 代表指标                                       |
| ---------- | ---------------------------------------------- |
| 大小均一性 | 聚合体水平（SEC）、片段含量（CE-SDS）          |
| 电荷均一性 | 酸性峰/主峰/碱性峰比例（iCIEF / IEX-HPLC）     |
| 糖基化     | N 糖谱（Man5、G0F、G1F、G2F 等）、岩藻糖化水平 |
| 翻译后修饰 | Met 氧化、Asn 脱酰胺、C 末端 Lys 异质性        |

以最高限传代次与初始代次的各质量指标比较作为判定基础，变化须在统计学显著差异界限内。

**维度四：遗传稳定性**

各代次细胞的基因组序列和目的蛋白氨基酸序列须保持一致：

- **基因组层面**：DNA 序列一致（NGS 测序），基因拷贝数无显著变化（qPCR）
- **蛋白层面**：目的蛋白氨基酸序列无突变（肽图 + LC-MS/MS，序列覆盖率 ≥ 95%）
- **替代方法（进度压力下的权宜策略）**：当时间紧迫无法完成测序时，可通过分子量分析（完整质谱）和肽图分析间接证明氨基酸序列一致性，但此类数据说服力有限，不适合作为 BLA 申报的主要证据

:::

## 降低细胞株不稳定性的五类工程策略

:::answer

多种工程和工艺策略可从不同层面降低细胞株不稳定性风险，并缩短项目开发周期。

**策略一：定点整合（Site-Specific Integration）——消除位置效应**

随机整合是传统 CHO 细胞株开发中不稳定性的主要来源。定点整合技术通过将目的基因导向染色体上已知的高表达、稳定的"安全港"位点，消除位置效应：

- **基因编辑工具**：ZFN（锌指核酸酶）、TALEN、CRISPR-Cas9
- **典型应用**：CHO-GS 敲除细胞宿主（用 ZFN 法敲除 GS 基因，而非传统化学诱变法），减少多步扩增过程中的转基因丢失和沉默
- **优势**：定点整合细胞株拷贝数预测性强，传代稳定性显著提升

**策略二：优化调控元件——增强转基因表达的持久性**

通过在表达载体设计中整合特定的基因组调控元件，抵抗转录沉默：

- **基质附着区（MARS / SAR 元素）**：与强启动子（如 CMV）结合使用，被报道可使单克隆生产力提高 12 倍以上，且在传代过程中维持更高效的表达
- **绝缘子（Insulator）序列**：在目的基因两侧加入绝缘子 DNA，阻断周围染色质的沉默效应向目的基因区域扩展，克服位置效应

**策略三：提高选择压力——维持基因拷贝数的稳定**

- 适当提高选择压力浓度（MSX/MTX）可增加细胞株稳定的概率，但须平衡对细胞生长状态的负面影响
- 高筛选压力下细胞倾向于维持多拷贝基因整合，但生长速率可能下降，增加生产成本

**策略四：优化培养条件——工艺依赖性稳定性的准确评估**

培养条件（pH、温度、补料策略）会影响细胞株的稳定性表现，这也意味着：最终细胞株稳定性研究**须在已经确定的生产工艺条件下进行**，才具有代表性。在不同培养条件下获得的稳定性数据不能互相替代。

**策略五：克服位置效应的两种通用方法**

1. **定点整合**（见策略一）：将目的基因整合到染色体上转录活跃的特定位点
2. **侧翼绝缘子序列**：在目的基因两侧加入绝缘子 DNA（如鸡 β-球蛋白 HS4 绝缘子），从表观遗传层面隔离周围染色质环境的影响

## 冷冻干燥原理：三相图与升华干燥的物理基础

:::answer

冷冻干燥（Lyophilization / Freeze-drying）是利用水在低温低压条件下可直接从固态（冰）升华为气态而不经过液态的物理特性，在不破坏热敏性物质的前提下实现干燥保存。

**水的三相图与冷冻干燥的物理基础**

水在压力-温度坐标系中存在三个相：固态（冰）、液态（水）和气态（水蒸气），三相交汇于**三相点**（Triple Point）：

- 温度：**0.01°C**
- 压力：**611.73 Pa（约 0.006 atm）**

当系统压力降至三相点压力以下时，水不再存在液态，固态冰可直接转化为水蒸气（升华），而不经历融化过程。

**冷冻干燥的技术实现路径**

1. **将样品冻结**：使样品中的水分全部转变为固态冰（温度须低于样品的共熔点/玻璃转化温度）
2. **在三相点压力以下抽真空**：系统真空度须低于 611 Pa，确保冰不融化而直接升华
3. **供热驱动升华**：提供足够的升华潜热（每克冰升华约需 **2.5 kJ** 的热量），维持冰的持续升华
4. **冷凝器捕获水蒸气**：真空系统中的低温冷凝器（通常 -50 ~ -80°C）将水蒸气凝华为冰，不断降低腔内水蒸气分压，维持升华方向的驱动力

> **关键物理意义：** 冷冻干燥的本质是在低温低压条件下的**传热传质过程**——供热（传热）促进升华，水蒸气从固体表面逸出并向冷凝器迁移（传质）。两者的协同控制是冻干工艺优化的核心。

:::

---

## 冷冻干燥的三阶段流程：预冻、初级干燥与次级干燥的工艺逻辑

:::answer

冷冻干燥过程包含三个严格衔接的阶段，每个阶段均有特定的物理目标和关键控制参数。

**阶段一：预冻（Pre-freezing / Freezing）**

**目的**：将样品中的自由水全部转化为固态冰，为升华阶段做准备。

关键要求：

- 样品须完全冻结，冻结温度须<strong>低于共熔点（Eutectic Temperatur）</strong>数度，确保无液态水残留
- **预冻速率**影响冰晶形态：快速预冻（quench freezing）形成细小均匀的冰晶，慢速预冻形成大冰晶
- 冰晶越大，初级干燥效率越高（大冰晶升华后留下较大孔道，利于水蒸气逸出）；但大冰晶可能对蛋白质结构造成机械损伤
- **壳式预冻（Shell Freezing）**：将冻干瓶置于低温液体中旋转，使液体沿瓶壁内圆周结冻，形成薄层冰壳，最大化气固接触面积，提升初级干燥效率

**阶段二：初级干燥（Primary Drying / Sublimation）**

**目的**：在真空条件下使样品中的冰（自由水）直接升华为水蒸气，并经冷凝器捕获。

关键控制参数：

- **真空度**：须低于三相点压力（611 Pa），通常控制在 **50–200 μbar**
- **搁板温度**：须高于冻结样品当前温度（提供升华所需能量），但须低于共熔温度或崩解温度（防止样品融化）
- **这一阶段约去除 95–98% 的水分**，产品呈现已干层（多孔疏松结构）与冻结层共存的状态
- 升华面（Interface）随时间从外向内推进，已干层厚度持续增加，其多孔结构是水蒸气逸出的唯一通道

**阶段三：次级干燥（Secondary Drying / Desorption）**

**目的**：去除初级干燥后残留的结合水（吸附于固体物质表面的水分子），将残余水分降至产品要求的范围（通常 < 1–3%）。

关键要求：

- 搁板温度可适当升高（通常升至 20–40°C），加速水分子从固体基质中脱附
- **次级干燥对于产品的长期储存稳定性至关重要**：残余水分是水解降解（脱酰胺）和化学降解反应的催化剂和底物，残余水分越低，储存稳定性通常越好
- 终点判断：通常以质谱检测出水分呈现平台期，或产品温度与搁板温度趋于一致为参考

:::

## 冻干工艺的核心控制要素：预冻温度、升华热平衡与冻干曲线自动化控制

:::answer

冻干工艺的成功高度依赖于对三个核心控制参数的精准把握，任何失控均可能导致产品质量缺陷（崩解、起泡、含水量超标）或生产周期延长。

**控制要素一：预冻温度的精准设定**

预冻温度须严格控制在共熔点以下数度：

| 预冻温度偏差                         | 后果                                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------ |
| **预冻温度不够低（样品未完全冻结）** | 抽真空升华时样品膨胀起泡，产品外观严重缺陷                                                 |
| **预冻温度过低（无必要的超低温）**   | 不必要的能耗增加；对某些生物药品，过低温度会降低蛋白质冻干后的存活率（如某些酶的低温失活） |

**控制要素二：升华阶段的热平衡管理**

升华是强吸热过程（每克冰升华约吸收 **2.8 kJ** 热量），供热须恰到好处：

| 供热状态     | 后果                                                                 |
| ------------ | -------------------------------------------------------------------- |
| **供热不足** | 样品温度下降，蒸气压降低，升华速率减慢，干燥时间延长，生产效率下降   |
| **供热过量** | 冰层温度升高超过共熔点，局部或全部融化，出现"干缩起泡"现象，产品报废 |

**控制要素三：冻干曲线的制订与自动化执行**

冻干曲线（Lyophilization Cycle / Recipe）是描述整个冻干过程中温度（搁板温度、产品温度）、压力随时间变化的程序化规程：

- 每种产品须基于实验结果（共熔点测量 + 小规模优化实验）制订专属冻干曲线
- **不同型号冻干机的冻干曲线不可直接套用**，冻干机的性能差异（搁板温度均匀性、冷凝器效率、抽真空速率）会显著影响最优曲线参数
- 现代冻干设备通过计算机控制系统按照预设冻干曲线自动执行，减少人工干预的操作变异

:::

---

## 冻干曲线制订的四类关键影响因素

:::answer

制订冻干曲线须综合考虑四类因素，确保在产品质量保障前提下最大化生产效率。

**因素一：制品品种的物理化学特性**

- **共熔点（Eutectic Temperature）**：是预冻温度和初级干燥温度的关键约束参数，共熔点低的制品须在更低温度下冻干，导致更高能耗
- **崩解温度（Collapse Temperature, Tc）**与**玻璃转化温度（Tg'）**：决定初级干燥阶段的温度上限。三者关系通常为 Tc ≈ Tg' + 约 2°C < Te（共熔温度），须以崩解温度为准控制初级干燥产品温度
- **残余水分要求**：低残余水分要求的制品须延长次级干燥时间，增加总冻干周期
- **大分子链状化合物的收缩效应**：部分制品在特定温度下发生收缩卷曲，冻干块状物与容器底部脱离，影响传热，须在曲线设计时规避该温度区间

**因素二：容器装量**

- 干燥箱总装量和单容器装量均正相关于干燥时间：装量越多，水分质量越大，干燥时间越长
- 冻干开发阶段须在代表性装量（与生产规格一致）下建立曲线，不可将小装量数据直接外推至大装量生产

**因素三：容器类型与传热特性**

| 容器类型                 | 传热特性   | 对冻干的影响                       |
| ------------------------ | ---------- | ---------------------------------- |
| 底部平整、壁薄的玻璃瓶   | **传热好** | 干燥时间短                         |
| 底部不平整、壁厚的玻璃瓶 | 传热差     | 干燥时间延长                       |
| 金属托盘                 | 导热性最好 | 传热高效，但较薄的托盘受热可能变形 |

**因素四：冻干机的性能规格**

冻干机的以下性能参数直接决定可实现的冻干曲线：

- 搁板之间及同一搁板各区域的温度均匀性（温差越小，产品批内一致性越好）
- 冷凝器最低温度和冰负荷能力（决定捕获水蒸气的效率上限）
- 冻干箱与冷凝器之间水蒸气流动阻力（阻力越小，升华速率越高）
- 真空泵的抽速和稳定性（维持低真空度的能力）

:::

## 升华干燥阶段的塌陷（Collapse）：形成机制、判断依据与预防策略

:::answer

塌陷（Collapse）是冻干初级干燥阶段最严重的质量缺陷之一，发生后产品多孔结构被破坏，不仅影响外观，还可能导致复溶性下降和稳定性恶化。

**塌陷的形成机制**

在初级干燥过程中，随着升华面向内推进，产品形成"外层已干 + 内层冻结"的双层结构：

1. 已干层结构疏松多孔，为水蒸气提供逸出通道
2. 当搁板供热过量或产品本身的崩解温度（Tc）较低时，已干层温度升高，物质从玻璃态转变为橡胶态，**失去刚性变得有粘性**
3. 多孔结构塌陷，水蒸气逸出通道被堵塞
4. 升华速率骤降，多余热量使冻结层温度上升至共熔点以上，产品开始融化或起泡
5. 冻干失败，批次报废

**温度的层次关系**

$$T_c\text{（崩解温度）} \approx T_{g'}\text{（玻璃转化温度）} \lesssim T_e\text{（共熔温度）}$$

崩解温度与共熔温度的相对大小决定了初级干燥的控制策略：

| 情形                          | 控制策略                                         |
| ----------------------------- | ------------------------------------------------ |
| **Tc > Te（大多数制品）**     | 以共熔温度 Te 为基准，控制产品温度略低于 Te 即可 |
| **Tc < Te（玻璃化冻结制品）** | 以崩解温度 Tc 为基准（更严格），须控制在 Tc 以下 |

**提高崩解温度的处方策略**

崩解温度取决于制品本身的物理性质和保护剂的种类。优先选用高崩解温度的保护剂，可使初级干燥在较高温度下进行，降低能耗、缩短时间：

| 保护剂     | 典型 Tg' / Tc            | 对冻干工艺的影响                       |
| ---------- | ------------------------ | -------------------------------------- |
| 甘露醇     | +2°C（Eutectic，结晶性） | 共熔点高，可在相对较高温度下冻干       |
| 海藻糖     | -28 ~ -30°C              | Tg' 较高于蔗糖，初级干燥温度约束较宽松 |
| 蔗糖       | -32 ~ -34°C              | 最常用，Tg' 较低，须注意温度控制       |
| 羟乙基淀粉 | 较高（依分子量）         | 高 Tg'，可与糖类组合使用提升整体 Tc    |

:::

## 冻干制剂的优缺点与剂型选择逻辑

:::answer

冻干制剂（Lyophilized Formulation）并非首选剂型，须在与液体制剂充分比较后，基于产品稳定性数据作出选择决策。

**冻干制剂的核心优势**

| 优势                          | 具体说明                                                       |
| ----------------------------- | -------------------------------------------------------------- |
| **维持生物活性**              | 低温干燥过程不引起蛋白质变性，微生物失活但蛋白质活性保留       |
| **减少挥发性/热敏性成分损失** | 低温操作避免了高温灭菌导致的热降解                             |
| **抑制降解反应**              | 去除水分后，水解、脱酰胺等依赖水分子的化学降解反应速率大幅降低 |
| **维持原始状态**              | 干燥后体积和形状基本不变，冻干块外观均匀                       |
| **复水性好**                  | 多孔结构使复溶快速（通常 < 2 分钟），便于临床使用              |
| **储存条件宽松**              | 某些冻干制剂可在室温（2–25°C）储存，相比液体制剂降低冷链成本   |

**冻干制剂的主要局限性**

| 局限             | 具体说明                                                                             |
| ---------------- | ------------------------------------------------------------------------------------ |
| **工艺复杂**     | 冻干工艺开发（共熔点测定、曲线优化）周期长，成本高                                   |
| **对容器要求高** | 须使用管制西林瓶（而非安瓿或预灌封注射器），增加包材成本                             |
| **使用不便**     | 须在使用前加入稀释液（注射用水或生理盐水）复溶，增加操作步骤，存在复溶操作错误的风险 |
| **灌装体积限制** | 每瓶装液量有限，高剂量制品须增加每次使用的西林瓶数量                                 |

**液体制剂 vs. 冻干制剂的决策逻辑**

```
首选方案：液体制剂
（简单、低成本、患者使用便捷）

↓ 若液体制剂在任何可行处方下
  均无法满足稳定性要求

转为冻干制剂
（须验证冻干保护剂的有效性 + 完整的冻干工艺开发）
```

:::

## 生物类似药稳定性研究：参比品可比性研究的稳定性设计要求

:::answer

生物类似药（Biosimilar）的稳定性研究不仅须证明自身产品在贮存条件下的质量维持能力，更须设计专门的对比研究以支持与原研参比药（Reference Product, RP）的相似性比较。

**生物类似药稳定性研究的三类别**

| 研究类型                         | 方法                                           | 核心目的                                                 |
| -------------------------------- | ---------------------------------------------- | -------------------------------------------------------- |
| **长期稳定性研究（实时稳定性）** | 实际贮存条件（如 2–8°C），按规定时间点持续取样 | 确定有效期，是贮存条件和有效期设定的主要依据             |
| **加速稳定性研究**               | 高于实际贮存条件（如 25°C），加速降解          | 了解产品在短期偏离贮存条件时的稳定性；快速支持有效期预测 |
| **强制降解研究（应力研究）**     | 极端条件（高温/光照/反复冻融/极端 pH）         | 揭示降解途径和降解产物；筛选稳定性指示性分析方法         |

**与原研参比药的可比性稳定性研究**

强制降解研究的特殊价值在于：在短时间内揭示原研药和生物类似药**降解途径是否一致**，这是比较稳定性的重要维度。若原研药和生物类似药在相同应力条件下产生不同类型或比例的降解产物，须深入评估差异的原因和临床相关性。

**缩小规模的代表性要求**

稳定性研究须采用与生产过程相同或相似条件的缩小规模进行评估，确保稳定性数据对商业化批次具有代表性。

:::

## 工艺变更后的稳定性影响评估：ICH Q5E 框架下的决策逻辑

:::answer

工艺变更（无论大小）都可能影响产品稳定性，须系统评估变更对稳定性的潜在影响，以决定是否需要启动新的稳定性研究。

**工艺变更影响稳定性的特殊敏感性**

蛋白质对工艺变更高度敏感，以下类型的变更须特别关注对稳定性的影响：

- 缓冲液组成变更（pH、离子种类和浓度）
- 保藏和储存条件变更
- 有机溶剂使用变更
- 容器密闭系统变更（不同品牌/规格的西林瓶、胶塞）

**稳定性研究能发现结构确证研究发现不了的差异**

稳定性研究具有独特的灵敏度优势，可检测出结构确证研究无法识别的细微差异。典型案例：

- **痕量蛋白酶的存在**：只有在放置一段时间后蛋白降解才能被检测出，初始状态下无法发现
- **容器密封系统渗漏的二价离子**：密闭容器系统微量渗漏的二价离子（如 Zn²⁺）可激活痕量蛋白酶，仅通过实时稳定性研究才能发现

**变更后稳定性研究的执行框架（ICH Q5E）**

1. **评估变更是否影响稳定性**：基于变更类型和已知的降解机制，进行科学评估
2. **确定稳定性研究方案**：实时稳定性 + 加速稳定性的组合（通常 ≥ 3 批样品）
3. **结果分析**：加速和强制降解研究为变更前后提供直接可比性数据，可显示差异并作为结构确证的补充
4. **确定控制点**：若发现新差异，需在生产工艺和储存过程中增加控制点（如充氮密封、避光包装、温度控制等）

:::

## 下游工艺中二硫键还原对单抗各纯化步骤的影响分析

:::answer

二硫键的正确配对是维持抗体高级结构和生物功能的结构基础，下游纯化过程中的还原条件（如低 pH、强还原环境）可能引发不同程度的二硫键还原，须在各工艺步骤中评估其影响。

**背景：二硫键还原的来源与检测**

- 二硫键还原（游离巯基增加）可来源于：培养基中还原剂残留（如半胱氨酸）、特定工艺步骤的化学还原（如低 pH 处理）
- 传统检测方法（CEX-HPLC、AEX-HPLC）对二硫键还原的灵敏度有限，应采用更专一的方法（如 Ellman 法检测游离 -SH、非还原 CE-SDS）进行监测

**步骤一：Protein A 亲和层析**

- 单抗主要通过 Fc 区与 Protein A 配体结合，二硫键还原的单抗虽高级结构有所改变，但 Fc 区结合位点仍保持足够的亲和力
- 研究结论：**二硫键还原对 Protein A 亲和层析步骤无明显影响**，捕获收率和纯度不受影响

**步骤二：低 pH 病毒灭活**

- 证据不一致：部分研究表明低 pH 步骤后二硫键还原水平升高可能促进聚集；另一些研究未观察到明显趋势
- 当前共识：聚集的驱动因素可能主要是**分子固有特性**（如抗体分子类型 IgG1/IgG2、疏水性），二硫键还原的作用是次要的，但特定分子须通过实验个案分析（详见本系列病毒灭活章节）

**步骤三：离子交换层析（CEX / AEX）**

- 二硫键还原可能改变抗体的表面电荷分布，理论上影响 IEX 色谱行为
- 研究数据：低还原（>95% 完整单抗）vs. 高还原（67% 完整单抗）样品的 AEX 和 CEX 峰形总体相似，主要差异为在洗脱末端出现更长的**拖尾峰**
- 实践结论：两者色谱图之间的差异非常细微，**很难仅凭色谱图识别二硫键还原或判断还原水平**
- 建议：在下游纯化过程中，应采用更快速和准确的专一性分析方法（Ellman 法 + 非还原 CE-SDS）监测二硫键还原，而非依赖 IEX 色谱图

:::

## AEX 弱吸附模式去除 HCP：高于流穿模式的杂质清除能力

:::answer

阴离子交换层析（Anion Exchange Chromatography, AEX）是单抗纯化工艺中精纯步骤的标配，通常以流穿（Flow-through）模式运行。但弱吸附（Weak Partitioning, WP）模式可显著提升 HCP 等杂质的清除能力，是工艺优化的重要策略。

**经典流穿模式的原理与局限**

传统 AEX 流穿条件：pH 低于目标蛋白 pI、低电导（约 4 mS/cm），使单抗带正电荷流穿，HCP、DNA、病毒等带负电荷杂质结合树脂：

- **优势**：操作简单，收率高
- **局限**：HCP 去除能力有限，通常 < **1 LRV**（对数去除值），对某些丰度较高的酸性 HCP 清除不充分

**弱吸附模式的工作原理**

弱吸附模式通过调整 pH 和电导率，使单抗以较弱的亲和力与 AEX 填料结合，而 HCP 仍以较强亲和力结合：

- **目标参数**：选择合适的 pH 和电导率，使产品分配系数 **k' 在 1–3 之间**（最优）
- 在此条件下，单抗与填料弱结合，HCP 与填料强结合，二者的分离选择性大幅提升

**弱吸附模式的性能优势**

| 指标         | 流穿模式    | 弱吸附模式                  |
| ------------ | ----------- | --------------------------- |
| HCP 去除能力 | < **1 LRV** | 可达 **4 LRV**              |
| 操作复杂度   | 低          | 较高（须优化 pH/电导/载量） |
| 收率         | 高（>98%）  | 略低（可通过中间洗提高）    |
| 柱载量       | 高          | 须适当降低（避免产品溢出）  |

弱吸附模式在某些情况下去除 HCP 效果如此显著，以至于可能实现两步柱（Protein A + AEX 弱吸附）完成原本需要三步柱（Protein A + AEX + CEX）才能达到的纯度目标，**有助于简化工艺流程**。

**弱吸附模式的优化策略**

- **增加中间洗（Intermediate Wash）**：在上样后、洗脱前增加一步中间洗，进一步去除弱结合杂质，同时提高产品回收率
- **提高载量**：在允许范围内适当提高载样量，通过高载量下的排阻效应进一步分离单抗与 HCP
- **参数矩阵优化（DoE）**：系统考察 pH / 电导率 / 载量的组合效应，找到 HCP 去除率与收率的最优平衡点

## 小分子药物与生物制剂的核心差异：结构复杂性决定开发策略的根本不同

:::answer

小分子药物和生物制剂（大分子药物）代表了两种本质上不同的治疗模式，其结构特性的差异决定了开发策略、制造工艺和质量控制体系的系统性不同。

**结构复杂性的本质差异**

| 维度           | 小分子药物                           | 生物制剂                                               |
| -------------- | ------------------------------------ | ------------------------------------------------------ |
| 分子量         | 通常 < 500 Da                        | 通常 > 10,000 Da（单抗 ~150 kDa）                      |
| 结构明确性     | 化学结构精确确定，可用分子式完整描述 | 高度复杂，含翻译后修饰（糖基化、氧化等），难以完全确证 |
| 批次一致性     | 化学合成，批间一致性极高             | 生物系统表达，批间存在固有异质性                       |
| 对工艺的敏感性 | 相对不敏感                           | **极其敏感**："工艺即产品"（Process is the Product）   |

**给药途径与剂型灵活性**

小分子药物可制成多种剂型（口服片剂/胶囊、注射剂、吸入剂、栓剂等），为临床提供极大灵活性。生物制剂因分子量大、不耐酶解，通常**仅能通过注射途径给药**（静脉、皮下、肌肉），口服生物利用度接近于零（肠道蛋白酶降解）。

**制造工艺的复杂性差异**

生物制剂的制造涉及细胞培养、纯化、制剂等多个高度复杂的工艺步骤，每步须经过精心设计和密切监控：

- 生产设施、设备和工艺与化学药品根本不同
- 工艺细节的细微变化可能导致产品质量属性的改变，即"工艺变化 = 产品变化"
- 这种复杂性使竞争对手**极难复制完全相同的生物制品**，也是为何生物类似药开发须进行全面的可比性研究

**ADME 研究的差异**

- 小分子药物：经典 ADME 研究，主要通过肝脏 CYP450 酶代谢，可预测药物相互作用
- 生物制剂：无 CYP450 代谢，通过蛋白酶水解和靶点介导清除（TMDD）消除；ADME 研究方法须专门设计（如同位素标记追踪法），评估更为复杂

**仿制药 vs. 生物类似药**

小分子药物专利到期后可通过相对简单的研究（BE 研究 + 化学等同性证明）获批仿制药。生物类似药的批准须经历全面的相似性研究（物理化学、生物功能、临床药理），成本远高于化学仿制药。

:::
