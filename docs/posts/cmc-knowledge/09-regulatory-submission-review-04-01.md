## IND 申报阶段生物学活性质控的最低要求：结合活性的适用性与风险边界

:::answer

IND 申报阶段对生物学活性检测方法的要求相对灵活，但须充分理解其适用边界和潜在监管风险。

**结合活性作为 IND 阶段效价测定的可接受性**

对于 IND 申报，采用**结合活性**（如靶抗原 ELISA 结合法、SPR 亲和力测定）作为效价指标是可以接受的，理由如下：

- IND 阶段产品批次有限，基于细胞的功能性效价测定方法可能尚未开发完善
- 结合活性能够间接反映抗体的构象完整性（正确折叠的抗体才具备正常的抗原结合能力）
- 一期临床试验的主要目的是安全性评估，对效价方法的精确性要求相对宽松

**使用结合活性方法的潜在风险**

| 风险点 | 说明 |
|---|---|
| 监管接受度不确定性 | 不同审评员对"结合活性是否足以代表生物学活性"的判断可能存在差异 |
| 方法局限性 | 结合活性无法反映效应功能（ADCC、CDC 等）的完整性，若产品 MoA 依赖于效应功能，则仅凭结合活性无法完整表征产品的功能完整性 |
| 后续升级压力 | BLA 申报时通常须建立更能反映临床效应的功能性效价方法，IND 阶段若仅用结合活性，后续须建立桥接关系 |

**最优实践建议**

- 在 IND 申报资料中，明确说明所选效价方法的科学合理性，并指出 BLA 阶段将如何升级
- 尽早评估产品的作用机制（MoA），若 MoA 主要依赖效应功能（如 ADCC），则建议尽早开发基于细胞的效价方法，而非仅依赖结合活性
- 在 Pre-IND Meeting 中与 CDE/FDA 就效价方法进行沟通，提前明确监管接受度

:::

## IND 与 BLA 质量标准的差异化制定逻辑：从宽松到收紧的演进策略

:::answer

IND 和 BLA 的质量标准并非一成不变，而是随产品知识和批次数据积累而动态演进，其核心逻辑是：**数据越充分，标准越精准、越具体**。

**IND 阶段质量标准的特点**

- **数据基础薄弱**：生产批次数量有限（通常 1–3 批），统计学基础不足
- **来源依赖先验知识**：参照同类产品经验、法规指南和历史数据设定，范围通常较宽泛
- **目的**：保证临床试验样品的安全性，能够支持临床样品的批次放行即可

**BLA 阶段质量标准的特点**

- **数据基础充分**：多批次（通常 ≥ 10–15 批）商业化工艺批次的历史数据支撑
- **基于实际数据收紧**：通过统计分析（通常以批次数据均值 ± 3σ 或 95% 可信区间）确定更精准的限度
- **典型收紧案例**：3 年长期稳定性研究显示多批次 SEC 单体含量均 > 98%，则 BLA 阶段将标准从 IND 阶段的"≥ 95%"收紧至"≥ 98%"

**特殊情形：BLA 阶段标准可能反向删除某些 IND 项目**

并非所有质量标准项在 BLA 阶段都会保留或收紧。若经过充分的风险评估后，某检测项对产品安全性或有效性的贡献极低，或可通过工艺控制保障（如无需逐批检验），则 BLA 阶段可考虑从放行标准中删除该项，以提高效率。

**关键原则**

质量标准的动态调整须有充分的科学依据和数据支撑，任何变化（收紧或删除）须在 BLA 申报资料中提供合理解释，并在技术上证明变更后的标准仍能保证产品质量。

:::

## Pre-IND Meeting 的必要性与正确使用策略

:::answer

Pre-IND Meeting（IND 申报前沟通交流会议）是与监管机构建立早期对话的关键机制，对降低申报风险和提高申报质量具有重要价值。

**法规依据**

依据《国家药品监督管理局关于调整药物临床试验审评审批程序的公告》（2018 年第 50 号），申请人在提出**新药首次药物临床试验申请（IND）之前**，应向药品审评中心（CDE）提出沟通交流会议申请。该规定明确建议（非强制）申请人主动寻求监管沟通。

**为什么强烈建议提交 Pre-IND Meeting 申请**

| 价值维度 | 具体效益 |
|---|---|
| **提前识别申报风险** | 确认监管机构对关键 CMC 策略（如效价方法选择、病毒清除策略）的接受意愿 |
| **对齐 CMC 研究方向** | 避免在 CMC 研究方向上走弯路，尤其对于国内外双报项目 |
| **明确资料完整性要求** | 提前了解 CDE 对于特定品种或特定开发阶段资料的具体要求和侧重点 |
| **减少补充资料风险** | 预先对齐减少正式申报后因理解差异而被 CDE 要求补充资料的概率 |
| **建立与审评机构的沟通渠道** | 为后续临床期间变更、可比性研究等事宜建立良好的沟通基础 |

**Pre-IND Meeting 的准备策略**

- 提前准备结构化的问题清单，聚焦产品特异性的关键 CMC 问题（如病毒安全性策略、UPB 检测计划、稳定性数据要求）
- 准备简要的产品概述和当前 CMC 研究进展摘要，使审评员快速了解背景
- 对于中美双报项目，建议同步与 FDA 进行 Pre-IND Meeting（通常通过 Type B Meeting）

:::

## IND 与 BLA 阶段表征研究的深度要求差异：渐进式研究的合规性逻辑

:::answer

产品表征研究（Characterization）的深度须与开发阶段相匹配，在 IND 和 BLA 之间存在显著的阶段性差异，体现了"循序渐进（Step-wise）"的生物制品开发理念。

**IND 阶段：适当表征，重点确保安全性**

IND 阶段不要求进行全面的产品表征研究，"适当的表征研究"即满足要求：

| 表征项目 | IND 阶段要求 | 说明 |
|---|---|---|
| 一级结构（分子量、N/C 端） | 须开展 | 确认蛋白质骨架完整性 |
| 纯度（SEC、CE-SDS） | 须开展 | 安全性相关，须确认无高水平聚集体或片段 |
| 效价/结合活性 | 须开展 | 批次放行必需 |
| 电荷异质性（iCIEF/IEX） | **可暂不要求** | 高阶表征，对安全性直接影响有限，IND 阶段可不强制 |
| 高级结构（DSC/CD） | 可选 | 若有条件，建议开展以建立基线数据 |
| 糖型分析 | 可适当简化 | 基本 N 糖谱即可，不要求完整糖组学 |
| 修饰位点分析（氧化/脱酰胺） | 可适当简化 | IND 阶段可仅做有限位点的定性分析 |

**BLA 阶段：全面表征，覆盖所有已知 CQA**

BLA 申报须对产品进行全面的表征研究，覆盖所有可能影响安全性和有效性的质量属性：

- 完整的一级结构确证（肽图，序列覆盖率 ≥ 95%）
- 完整的高级结构表征（二级/三级/四级结构）
- 完整的糖型分析（高分辨率 N 糖谱，含各糖型定量）
- 完整的修饰分析（所有关键位点的氧化、脱酰胺定量）
- 完整的电荷异质性表征及各峰的化学归属

**表征深度的阶段性演进意义**

IND 阶段的有限表征数据为后续 BLA 全面表征建立基线，两阶段数据的对比为可比性研究提供纵向数据链。

:::

## IND 阶段细胞库稳定性研究的最低要求：PCB/RCB 足以支持，WCB/MCB 并非强制

:::answer

细胞库稳定性研究在 IND 和 BLA 阶段的要求存在实质性差异，IND 阶段的灵活性设计是基于此阶段工艺尚未锁定的客观现实。

**IND 阶段的基本要求：PCB/RCB 稳定性研究即可**

- IND 阶段**没有强制要求**开展 MCB 和 WCB 的稳定性研究
- 开展 PCB（Pre-clinical Cell Bank）或 RCB（Research Cell Bank）的有限稳定性研究即可满足 IND 申报要求

**不强制要求 WCB/MCB 稳定性研究的根本原因**

- IND 阶段不可能建立能够代表商业化生产规模的经资质确认的缩小模型（SDM）
- 在非代表性缩小模型或摇瓶条件下开展的 MCB/WCB 稳定性研究，其工艺通常无法代表最终商业化生产工艺，数据的外推性有限
- 强制开展意义不大，反而会消耗大量时间资源（通常 WCB 稳定性研究需要 3–6 个月），延误 IND 申报节奏

**IND 阶段细胞株稳定性研究的实用建议**

- 开展 PCB 的预稳定性研究（PDL0 对比 PDL30–45），初步评估克隆的稳定性倾向
- 通过 PDL0 和 PDL45 的预实验判断 WCB 稳定性，确定最终克隆，可节约约 **1 个月**的研究时间
- 若对平台细胞株有充分信心（来自同类项目的先验知识），可先建立 MCB 或 WCB，后续并行开展稳定性研究，可缩短约 **2 个月**的开发时间

**BLA 阶段的升级要求**

BLA 阶段须使用 MCB 和 WCB，在经过资质确认的生产规模或缩小模型中，采用最终商业化生产工艺开展全面的细胞株稳定性研究（详见细胞株稳定性专项章节）。

:::

## IND 与 BLA 申报 CMC 研究理念的系统性差异：安全性优先到全面验证的演进框架

:::answer

IND 和 BLA 的 CMC 研究理念反映了药物开发"循序渐进（Step-wise）"原则，两个阶段的核心差异在于研究深度、验证严格性和数据要求。

**IND 阶段 CMC 研究的核心理念：以安全性为锚点，循序渐进**

IND 阶段的 CMC 研究根据临床阶段递进而深化：

| 临床阶段 | CMC 研究重点 | 关键活动 |
|---|---|---|
| **I 期** | 安全性保障 | 细胞库检定（MCB/WCB/EOPC 基本项目）；UPB 微生物和病毒污染检测；物料控制；下游病毒清除工艺初步验证 |
| **II 期** | 工艺稳定性 | 工艺参数初步优化；中间产品时限研究；分析方法初步开发 |
| **III 期** | 商业化准备 | 工艺参数范围确认（PC 研究）；分析方法验证；商业化包材确认；稳定性数据积累 |

**BLA 阶段 CMC 研究的核心要求：全面验证，保障上市后大规模使用**

- **对象扩大**：产品面向更广泛的患者群体，安全性事件的影响面更大
- **法规严格性**：中国药典、美国药典、ICH 和 PDA 指南中明确规定的要求均主要针对 BLA 阶段产品
- **数据完整性**：须提供完整的工艺验证数据包、完整的稳定性数据包（至少覆盖申请有效期的实时数据）、完整的可比性研究数据（若存在工艺变更）

**IND 阶段的监管弹性与风险管理原则**

- 现行法规（中国药典、ICH、PDA 指南）对 IND 申报的许多 CMC 内容**未作明确强制规定**
- 企业须根据**风险管理、成本控制和先验知识**自主制定 IND 阶段的研究活动计划
- 对于边界情况或不确定性，**建议主动与 CDE 沟通**，而非仅依赖内部判断，避免在申报时出现意外挑战

:::

## IND 申报所需稳定性数据的最低要求：动态视角下的数据支持策略

:::answer

IND 申报的稳定性数据要求体现了"支持临床试验阶段使用"的核心原则，而非"建立完整有效期"的目标。

**最低稳定性数据要求**

- 提供 DP（制剂）**至少 1 个月**的稳定性数据可支持 IND 申报的基本需求
- 建议提供至少**一批代表性批次**的稳定性数据，时间点涵盖 0、1、3、6 个月（若已获得更长时间的数据）

**对样品批次的特殊说明**

IND 申报稳定性数据对样品规格要求相对灵活：

- 研发批次（非中试规模）的稳定性数据可作为**支持性数据**提交
- 不要求必须具备完整的"1 个月 + 3 个月 + 6 个月"时间序列，有什么数据提供什么，但须说明数据的局限性
- 批次的生产工艺须与计划用于临床的工艺具有合理的可比性

**动态视角：稳定性数据随临床进展持续积累**

监管机构关注的核心是**产品的安全性风险**，稳定性数据是用来**支持临床试验特定阶段**的工具：

- IND 阶段的短期稳定性数据支持早期临床样品的供应（如 6 个月有效期支持一期试验用药供应）
- 随着临床进展（从 I 期到 III 期），须持续积累更长期的稳定性数据，逐步建立正式的有效期
- 目前国内很多 IND 申报后直接跳至三期，监管机构以"动态视角"审核稳定性数据，须保证临床全程样品质量有稳定性数据支撑

**实用建议**

- 在 IND 申报同时启动长期稳定性研究，积累实时数据
- 设定稳定性研究样品的生产时间，确保在临床样品预期使用期届满前有足够的稳定性数据支撑
- 临床期间若发现稳定性趋势异常，须按变更程序及时报告并重新评估临床用药的安全性

:::

## UPB 检测的批次要求：IND/BLA 阶段须逐批检测，上市后可评估减少

:::answer

未处理收获液（Unprocessed Bulk Harvest, UPB）的检测批次要求随产品研发阶段变化，但核心原则是——在临床试验期间须对每批次进行检测，上市后在充分评估基础上可精简。

**IND 阶段**

须对**每批次用于临床试验的 UPB** 进行检测，不允许以单次检测代表多批次，原因如下：

- IND 阶段工艺尚未完全稳定，不同批次之间污染风险差异较大
- 用于临床试验的样品直接用于人体，须保证每批样品均经过安全性核查
- UPB 是整个生产工艺中病毒污染最易检出的工序，此阶段检测可有效发现偶发性污染

通常 IND 阶段每批 UPB 须检测的项目包括：

| 检测项目 | 必须/建议 |
|---|---|
| 无菌检查 / 微生物限度 | **必须** |
| 支原体检查 | **必须** |
| 外源病毒因子（体外法） | **必须** |
| 特定外源病毒因子（如适用） | 依风险评估 |
| 逆转录病毒颗粒定量（电镜法） | **建议**（用于下游病毒清除能力评估的初始病毒量基线） |

**BLA 阶段**

与 IND 阶段相同，须对用于批次放行的每批 UPB 进行检测，确保商业化生产每批产品的安全性。

**上市后：经评估可减少检测项目**

上市许可获批后，经充分风险评估（基于多批次 UPB 检测历史数据、工艺一致性验证结果），可向监管机构申请减少或优化 UPB 的例行检测项目，但须在监管机构批准后方可实施。

:::

## BLA 阶段 EOPC 检测批次要求：商业化规模代表性是核心判断标准

:::answer

生产终末细胞（End of Production Cells, EOPC）的检测须能代表商业化生产条件下细胞的最终状态，批次数量的最低要求以"代表性"为核心判断原则。

**法规要求与执行标准**

- BLA 阶段须提供**至少 1 批能够代表商业化生产规模**的 EOPC 检测数据
- "代表商业化生产规模"的含义：EOPC 须来自在生产规模（或经资质确认的缩小模型）下，使用最终商业化工艺培养至限传代次上限的细胞

**EOPC 检测的主要项目**

EOPC 检测项目与 MCB 全面检定项目一致或更严格，通常包括：

| 检测类别 | 具体项目 |
|---|---|
| 遗传稳定性 | 插入基因拷贝数、整合位点、DNA 序列完整性 |
| 生物安全性 | 外源/内源病毒因子、逆转录病毒检测、支原体检查 |
| 细胞鉴别 | STR / 同工酶谱（与 MCB 比对） |
| 成瘤性/致瘤性 | 成瘤性试验（特别是永生化细胞系来源的基质）|
| 一般安全性 | 无菌检查 |

**EOPC 检测与 UPB 检测的关系**

EOPC 和 UPB 的检测侧重不同，两者相互补充：

- **EOPC**：评估细胞库在整个生产使用周期后的遗传和生物安全性状态（更注重**细胞**层面的稳定性）
- **UPB**：评估每批生产中收获液的病毒和微生物污染状态（更注重**批次产品**层面的安全性）

:::

## 中美双报对 MCB/WCB 检测机构的资质要求：须选择符合双报要求的认可机构

:::answer

中美双报项目中，MCB 和 WCB 的检测机构须同时满足中美两国监管机构的认可要求，这是双报策略中容易被忽视的关键细节。

**为什么检测机构的选择至关重要**

- 中国 NMPA 要求细胞库检定须在**经国家认可的检测机构**（通常为 NIFDC 或省级药检院授权机构）进行，或由生产单位在经认可的 GMP 条件下自检
- 美国 FDA 对检测机构无明确官方认可清单，但要求相关检测须在**符合 GLP 或 GMP 条件**的实验室执行，检测方法须与美国药典（USP）或 ICH 相关要求匹配
- 若在国内机构完成的检测无法被 FDA 认可（如方法不符合 USP 标准，或机构缺乏相应资质证明），则须重复检测，造成时间和成本浪费

**双报检测机构选择的实践建议**

1. **优先选择具备双报能力的 CRO/CDMO**：部分合同检测机构已建立同时符合 NMPA 和 FDA 要求的检测体系，可一次检测同时支持两个申报
2. **确认检测方法的跨法规兼容性**：检测方法须同时符合中国药典（ChP）通则和美国药典（USP）相应章节的要求；若存在差异，须分别执行
3. **提前与两国监管机构沟通**：在确定检测机构前，建议通过 Pre-IND Meeting 与 CDE 和 FDA 分别确认检测方案的可接受性
4. **建立完整的检测记录可追溯性**：所有检测记录须满足两国的数据完整性（Data Integrity）要求（符合 ALCOA+ 原则）

:::

## IND 申报阶段技术转移工作的触发条件：GMP 批次是核心判断标准

:::answer

技术转移（Technology Transfer）是将研发工艺系统性地传递至生产场地的正式活动，其在 IND 阶段的必要性取决于生产批次是否进入 GMP 体系。

**IND 阶段技术转移的触发逻辑**

| 生产场景 | 是否需要正式技术转移 | 原因 |
|---|---|---|
| 研发实验室自行生产临床前样品（非 GMP） | **不需要** | 研发实验室内部的工艺迭代不构成正式技术转移 |
| 将工艺从研发实验室转移至 GMP 生产场地 | **需要** | 涉及受 GMP 监管的生产活动，须按照技术转移程序执行 |
| CMO/CDMO 承接临床样品 GMP 生产 | **需要** | 外部生产场地的 GMP 批次须经过正式技术转移确认 |

**GMP 批次技术转移的核心活动**

在涉及 GMP 生产的 IND 阶段，技术转移须包括以下核心内容（可根据阶段适当简化）：

- 工艺文件（工艺规程、批记录模板）的起草和审核
- 分析方法转移（确保接收方能够正确执行关键检测方法，达到转移接受标准）
- 关键设备和工艺参数的确认（DQ/IQ/OQ/PQ 安装运行性能确认）
- 工程批次（Engineering Run）的执行和评估
- 工程批次数据包的审核和转移确认报告的签署

**IND 阶段技术转移的简化策略**

相比 BLA 阶段的完整技术转移，IND 阶段可采用以下简化原则：

- 重点确认关键工艺步骤（如细胞培养放大、层析步骤、制剂灌装）的可重复性
- 分析方法转移可聚焦于与安全性直接相关的关键检测项目（效价、纯度、生物安全）
- 工程批次结果评估以"是否满足临床供样质量要求"为核心，而非追求与研发批次的完全一致性

:::

## IND 申报两批次规模不一致的可接受性：须提供批次间可比性研究

:::answer

IND 申报阶段，两个生产批次的规模不一致是常见且可接受的情形，但须在申报资料中提供科学的可比性研究数据，以证明规模差异不影响产品质量。

**可接受性的法规基础**

IND 阶段处于工艺开发的早期，工艺放大往往尚未完成，不同批次的生产规模可能处于不同的放大阶段（如从摇瓶到小型反应器，再到中型反应器）。监管机构认可这一现实，允许不同规模批次用于 IND 申报，但须满足可比性研究的要求。

**可比性研究的内容与深度**

IND 阶段批次间可比性研究（不同规模）须覆盖以下内容：

| 比较维度 | 核心比较项目 |
|---|---|
| 细胞生长性能 | VCD 曲线、活率曲线、IVCD 比较 |
| 代谢指标 | 葡萄糖/乳酸动态，氨积累趋势 |
| 产量 | Titer 对比（允许一定范围内的差异）|
| 产品质量（关键 CQA） | SEC（聚体）、CE-SDS（纯度）、糖型（主要糖型分布）、效价 |

**IND 阶段可比性研究的接受标准**

IND 阶段的可比性研究不要求两批次在所有 CQA 上完全等效，而是须证明：

- 关键安全性相关指标（无菌、内毒素、聚集体水平）在可接受范围内
- CQA 变化趋势合理，可用工艺放大的已知规模效应解释
- 差异不会对临床用药的安全性产生影响

**申报资料中的呈现方式**

在 CTD 格式的 CMC 申报资料中，须在工艺开发历史章节（Section 3.2.S.2.6）中对不同规模批次的可比性进行叙述性说明，并附上关键质量数据的比较表格。

:::

## 分析方法变更后的验证要求：基于风险评估的差异化验证策略

:::answer

分析方法发生变更后，是否需要重新验证以及验证的范围，须基于变更的性质和对方法性能的潜在影响进行系统性风险评估，而非一律全面重新验证。

**变更类型与验证需求的关联矩阵**

| 变更类型 | 对方法性能的影响 | 验证需求 |
|---|---|---|
| 仪器品牌/型号变更（检测原理不变） | 低 | 系统适用性确认即可 |
| 色谱柱供应商变更（规格参数相同） | 低至中 | 精密度、专属性的确认性试验 |
| 关键试剂批次变更（如 ELISA 抗体批次） | 中 | 方法适用性确认，特别是灵敏度和特异性 |
| 检测步骤修改（如稀释方案、孵育时间） | 中至高 | 部分再验证（根据受影响的验证参数） |
| 检测原理变更（如从 ELISA 改为 SPR） | 高 | **全面重新验证**，并与原方法建立桥接关系 |
| 适用产品扩展（用于新产品的已验证方法） | 依产品差异 | 方法适用性确认（专属性、回收率等） |

**风险评估的核心考量因素**

- 变更步骤在方法流程中的位置（前处理 vs. 检测步骤 vs. 计算方法）
- 变更对方法关键性能参数（专属性、灵敏度、精密度、线性）的潜在影响方向和量级
- 方法的预期用途（批次放行方法 vs. 稳定性研究方法 vs. 过程控制方法）

**关键原则**

- 无论是否需要全面验证，任何分析方法变更均须有**书面风险评估记录**，说明变更的性质、预期影响和采取的确认措施
- 对于放行标准使用的关键方法（如效价、SEC 纯度），任何变更均须谨慎对待，即使风险评估结论为"低风险"，也建议完成一定程度的性能确认实验
- 变更后方法的实验室内部转移，须按照方法转移的标准程序执行

:::

## 工艺验证三批与注册申报三批的关系：无必然对应，均可作为注册批次

:::answer

工艺验证（Process Validation）批次和注册申报批次在概念上相互独立，两者的对应关系须基于监管要求和项目实际情况综合判断。

**两类批次的定义与目的**

| 批次类型 | 定义 | 主要目的 |
|---|---|---|
| **工艺验证批次（PPQ Batch）** | 在商业化生产条件下，按照最终锁定的工艺参数生产，用于系统性证明工艺的可重复性和产品质量一致性 | 工艺性能确认（Process Performance Qualification） |
| **注册申报批次** | 用于支持上市申请中产品质量标准、稳定性研究和可比性研究的批次 | 提供监管审评所需的产品质量基线数据 |

**两类批次的重叠与独立性**

- **完全重叠（工艺验证批次 = 注册申报批次）**：最常见且最高效的方式，工艺验证的三批 PPQ 批次同时作为注册申报的支持批次，一批次数据服务两个目的
- **完全独立**：若注册申报批次为工艺验证前的工程批次或临床批次，且其工艺与最终商业化工艺之间存在差异，则须提供可比性研究数据
- **动态现场检查三批**：中国 NMPA 在上市申请审评过程中进行动态现场检查，要求检查现场连续生产三批，这三批也可作为注册申报批次（若质量数据满足要求）

**实践建议**

- 在项目规划阶段，明确工艺验证批次与注册申报批次的关系，避免重复生产造成成本浪费
- 注册申报批次的生产须覆盖预期的最大生产规模（或有充分数据支持放大外推），以确保注册批次数据对商业化生产的代表性

:::

## 中美 IND 申请 CMC 要求的关键差异：大分子生物药的核心异同点

:::answer

中国加入 ICH（2017 年 6 月）后，中国 NMPA 与美国 FDA 的 CMC 要求逐步趋同，但在部分领域仍存在实质性差异，对于中美双报项目须充分了解并提前规划。

**总体趋同趋势**

- 2017 年起，中国的创新药物研发要求逐步与 ICH 标准接轨，CMC 申报资料的 CTD 格式要求基本一致
- 对于大分子生物药，中美两国的 CMC 要求基本一致，均遵循 ICH Q5A/B/C/D/E 等生物技术/生物制品系列指南

**关键差异点**

| 比较维度 | 中国 NMPA | 美国 FDA | 实践影响 |
|---|---|---|---|
| **申报审评制度** | IND 申请须经批准（60 天等待期，超期未反馈视为默许）| 报备制（30 天默许期），通常更快速 | 中国时间窗口更长，须提前规划 |
| **病毒清除要求** | 要求更为全面，须提供完整的两步正交病毒清除验证（低 pH + 纳滤）数据，BLA 阶段要求尤为严格 | 同样要求，但某些情形下在 IND 阶段有更多弹性 | 病毒清除研究须优先启动 |
| **输液系统相容性** | 未特别强调 | **更严苛**，要求评估药物与输液袋（PVC 或非 PVC）、输液管的相容性（浸出物和吸附） | 中美双报须开展额外的 E&L 研究 |
| **小分子药物 CMC** | 对生产过程、杂质控制要求更为细致 | 相对灵活 | 小分子适用（生物药主要遵循 ICH）|
| **原辅料溯源** | 对动物源性原辅料（如胰酶、血清）的溯源和病毒安全性要求严格，须提供完整的 TSE/BSE 评估 | 同样要求，但评估细节略有差异 | 须建立完整的动物源材料溯源档案 |

**双报项目的实用策略**

- 在项目启动阶段即识别中美双报的差异点，提前规划额外所需的研究（如输液系统相容性研究）
- 建立"一套核心研究，差异部分分别补充"的双报框架，最大化数据复用率
- 尽早与两国监管机构分别进行 Pre-IND 沟通，对齐双报策略

:::

## IND 与 BLA 阶段国内分段生产政策：BLA 阶段须符合新规监管框架

:::answer

分段生产（Divided Manufacturing）是指原液和制剂（或 ADC 的不同生产阶段）在不同地点分别完成的生产模式，其在 IND 和 BLA 阶段的政策框架存在重要差异。

**IND 阶段：灵活性较大，无明确禁止**

- 对于原液和制剂的分段生产、ADC 裸抗和 ADC 原液/制剂的分段生产，目前国内**并没有明确的禁止性规定**
- 申请人可以根据实际生产能力、委托生产安排等情况灵活选择是否分段生产
- IND 阶段分段生产的关键要求：须能够追溯每段生产的质量数据，原液和制剂的批记录须相互关联

**BLA 阶段：须符合新法规框架（征求意见稿条款）**

根据《中华人民共和国药品管理法实施条例（征求意见稿）》第六十九条【分段生产管理】：

> "对于生产工艺、设施设备有特殊要求的创新药，或者临床急需等药品，经**国务院药品监督管理部门批准**，可以分段生产。"

BLA 阶段分段生产的核心监管要求：

1. **须经批准**：不再是默许，须主动申请并获得监管机构的批准
2. **统一质量保证体系**：药品上市许可持有人（MAH）须建立覆盖药品生产**全过程和全部生产地址**的统一质量保证体系
3. **持续合规**：确保药品生产过程在所有分段生产地址均持续符合法定要求

**实践建议**

- 在项目立项阶段即明确是否计划分段生产，评估是否满足"有特殊要求"或"临床急需"的条件
- 若计划 BLA 阶段分段生产，须尽早与 CDE 沟通，确认分段生产申请的可行性和时间安排
- MAH 须建立清晰的质量协议（Quality Agreement），明确分段生产各方的质量责任边界

:::

## BLA 阶段中美欧微生物稳定性检测要求的核心差异：FDA USP<51> 挑战试验的特殊要求

:::answer

对于需要在临床使用前复溶和/或进一步稀释的注射剂产品，使用稳定性（In-Use Stability）的微生物考察要求在中、美、欧之间存在关键差异，双报项目须特别注意。

**共同原则：中美欧均要求同时考察理化和微生物指标**

对于使用前须进行配制/稀释的注射剂，各国（地区）均要求在使用稳定性研究中同时评估：

- **理化稳定性**：聚合体水平、活性、pH、颜色/澄明度（同一）
- **微生物安全性**：在拟定的储存时限内微生物不超标（各国要求存在差异）

**FDA 的特殊要求：USP<51> 微生物挑战试验**

FDA 在通常情况下要求按照 **USP<51> 抗菌效能试验**进行微生物挑战：

- **试验设计**：将规定的挑战微生物（金黄色葡萄球菌、铜绿假单胞菌、大肠埃希菌、白假丝酵母菌、黑曲霉菌等）接种至产品中，在拟定储存时限内监测微生物数量变化
- **"无增长"判断标准**：在拟定的储存时限内，微生物增加量不超过 **0.5 log₁₀**，则视为"无增长"
- **豁免条件**：若产品使用说明规定室温下使用时间 < **4 小时**，或冷藏条件下使用时间 < **24 小时**，FDA 通常**不要求**提供微生物挑战数据

**中国和欧盟的要求**

- 中国和欧盟同样要求进行使用稳定性的微生物考察，但对于具体试验设计（如是否须开展挑战试验）的强制性要求相对 FDA 更为灵活
- 通常，在无防腐剂单次使用的无菌注射剂中，若能够证明使用时间内微生物限度符合规定，不强制要求 USP<51> 挑战试验

**双报项目的实践策略**

- 以 FDA 最严格的 USP<51> 挑战试验要求为设计基准，同时满足中国和欧盟的要求
- 若产品使用时间设计为室温 < 4 小时，可豁免 FDA 的微生物挑战要求，在 CTD 资料中明确说明此设计理由

:::

## BLA 阶段细胞库稳定性研究中易被忽略的两类问题

:::answer

在 BLA 阶段细胞库稳定性研究中，有两类问题在申报时经常被遗漏，导致审评时被要求补充资料，须在研究设计阶段即予以关注。

**易被忽略问题一：细胞库贮存条件下的稳定性考察**

- **常见遗漏情形**：申请人完成了传代稳定性研究（考察不同代次的产量和质量）但遗漏了细胞库在冻存条件下的长期稳定性考察
- **法规要求**：须提供细胞库（MCB 和 WCB）在拟定贮存条件（通常为液氮气相，< -135°C）下的稳定性数据，证明细胞库在有效使用期内的活率和生产能力不发生显著下降
- **具体内容**：通常每 6–12 个月复苏一支细胞库，检测复苏活率、生长特性和生产能力（对比历史基线数据）
- **建议措施**：在 MCB/WCB 建立完成后即启动贮存稳定性监测计划，避免申报时因数据不足而延误

**易被忽略问题二：传代稳定性研究须使用商业化工艺**

- **常见遗漏情形**：传代稳定性研究使用的是早期开发阶段的非最终工艺（如早期培养基、早期补料策略）
- **法规要求**：BLA 阶段的传代稳定性研究须**模拟实际商业化生产时的细胞培养工艺**进行细胞传代，以真实代表商业化生产中细胞传代过程中的稳定性变化
- **核心问题**：在非代表性工艺条件下获得的稳定性数据，无法外推至商业化生产，可能导致在实际商业化生产中出现未预期的稳定性问题
- **建议措施**：在工艺最终锁定后，若此前开展的稳定性研究使用的是旧工艺，须评估是否需要在新工艺条件下补充稳定性研究数据

:::

## 药典放行检验项目体系：六大类别的完整框架与选择原则

:::answer

产品放行检验项目的设计须兼顾法规要求、产品特性和质量控制的科学性，形成一套能够全面、有效保证产品质量的检测体系。

**六大类别的国内外药典通用放行检定项目**

| 类别 | 代表检测项目 | 选择重点 |
|---|---|---|
| **01 鉴别试验** | SDS-PAGE 分子量、肽图（序列确认）、特异性 ELISA | 确认产品身份，必须与参比品比对 |
| **02 纯度与杂质** | SEC-HPLC（单体/聚体/片段）、CE-SDS（非还原/还原）、iCIEF/IEX-HPLC（电荷变体）；HCP、HCD、Protein A 残留 | 建议使用**机理互补**的两种以上方法组合评估同一纯度维度 |
| **03 效价** | 结合效价（靶点 ELISA/SPR）；体内活性；比活（活性/含量） | 推荐尽可能反映或模拟产品**作用机制（MoA）**或临床效应的方法；至少包含一种功能性评价 |
| **04 蛋白含量** | A₂₈₀ 法（主要方法）；BCA 法（补充验证） | 与效价联合计算比活，监测批间一致性 |
| **05 安全性试验** | 无菌检查（ChP 1101 / USP <71>）；细菌内毒素（LAL 法 / rFC 法）；异常毒性检查（依产品类型）| 每批放行必须检测，不可豁免 |
| **06 其他物理化学检测项目** | 外观（颜色/澄明度）；可见异物；不溶性微粒（光阻法/显微计数法）；pH；渗透压；装量；稳定剂含量；冻干品水分 | 依剂型（液体制剂 vs. 冻干制剂）差异化选择 |

**放行检验项目选择的核心原则**

- **QA 相关性**：须纳入所有已识别为 CQA 的检测项目；对非 CQA 属性，经风险评估后可不纳入（如通过工艺控制保障）
- **生产工艺关联性**：与特定工艺步骤关联的工艺残留（HCP、HCD、Protein A、残余溶剂）须针对该工艺特点设计
- **法规要求**：注册国药典或监管机构的具体规定须满足（如中国药典三部通则的特定要求）
- **数据积累与动态更新**：放行检验项目须随产品知识积累（批次数据、稳定性数据、临床安全性数据）定期评审和更新，而非一成不变

:::
