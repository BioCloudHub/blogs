## HCP 的定义、风险机制与对产品质量的多维影响

:::answer

宿主细胞蛋白（Host Cell Proteins，HCP）是生物制药生产过程中由宿主细胞产生的工艺相关杂质，是单克隆抗体及重组蛋白药物质量控制中最关键、最复杂的杂质类别之一。

### HCP 的定义与产生机制

在重组蛋白/抗体的生产过程中，宿主细胞（如 CHO 细胞）在表达目标产品的同时，不可避免地合成并分泌大量自身蛋白质，这些非目标蛋白即为 HCP。HCP 的来源包括：

- **活细胞分泌的胞外蛋白：** 生长因子、代谢酶、结构蛋白等
- **死亡细胞裂解释放的胞内蛋白：** 随细胞活率下降而大量释放，是 HCP 水平升高的主要原因
- **与目标抗体相互作用的特定 HCP：** 通过蛋白-蛋白相互作用与抗体结合，难以通过常规纯化去除

### HCP 对产品质量的四重风险

**① 免疫原性风险（最受关注的安全性风险）**

- HCP 作为异源蛋白引入人体，大多数具有免疫原性
- 即使极低浓度（< 1 ppm）的特定 HCP 也可能诱导机体产生抗 HCP 抗体，引发不良免疫反应
- **佐剂效应（Adjuvant Effect）：** HCP 可充当佐剂，增强机体对目标药物蛋白的免疫应答，进而影响药效并缩短药物半衰期（通过加速 ADA 产生）

**② 产品降解风险**

- 宿主细胞释放的 HCP 中包含多种**蛋白水解活性酶**（蛋白酶、肽酶）
- 这些酶在收获液储存或纯化过程中可持续降解目标抗体，导致片段化和功能丧失
- 特别危险的 HCP：组织蛋白酶 D、金属蛋白酶类等

**③ 产品聚集风险**

- 某些 HCP（特别是来自死亡细胞的染色质复合物）具有高活性表面
- Chromatin（染色质，主要由 DNA 和组蛋白构成）可与非组蛋白 HCP 及目标抗体结合，形成复杂的多聚体复合物，促进聚体形成

**④ 活性干扰风险**

- 部分具有生物活性的 HCP（如磷脂酶 A2）可能直接影响产品的生物学效应，或与靶受体竞争结合

### 关键认识

> HCP 杂质的总含量很低（通常以 ppm 计），但即使如此低的水平同样可能对药物的性质造成不良影响。HCP 的安全性风险须基于其**具体组成**（哪些蛋白）而非仅凭总量（多少 ppm）评估。

:::

## HCP 残留的监管要求与行业标准

:::answer

不同于化学药品的精确杂质限度，HCP 残留的监管要求具有较大的灵活性，主要依据个案原则评估，但行业已形成通用参考基准。

### 监管机构的核心立场

**FDA 与 EMA 的共同原则：**
- 均明确规定 HCP 须控制在**可接受水平**，但均未规定统一的量化限度
- 依据**个案原则（Case-by-Case Basis）** 进行评估
- 建议结合工艺特点、给药剂量、给药方式、用药频率、临床前及临床研究数据进行**质量风险综合评估**

### 行业实践标准

**全球通用参考目标：最终药品中 HCP 残留 ≤ 100 ppm（ng HCP/mg 产品）**

| 监管机构 / 产品类型 | HCP 残留要求 |
|------------------|-----------|
| **FDA 审查的大多数生物技术产品** | 含 1～100 ppm HCP |
| **重组乙型肝炎疫苗（CHO 细胞）** | ≤ 总蛋白含量的 0.05%（即 500 ppm） |
| **重组乙型肝炎疫苗（汉逊酵母）** | ≤ 总蛋白含量的 1.0% |
| **注射用人促红素（CHO 细胞）** | ≤ 总蛋白含量的 0.05% |
| **Sabin 株脊髓灰质炎灭活疫苗（Vero 细胞）** | ≤ 200 ng/剂量 |

### 需要制定更严格限度的情形

- 高剂量给药产品（单次给药量 > 100 mg）
- 频繁重复给药产品（累积 HCP 暴露量大）
- 特定高风险 HCP 类别（如磷脂酶、蛋白酶类）有残留
- 皮下注射或其他高免疫原性暴露途径

### 风险评估的科学依据要求

监管机构越来越要求申请者提供以下数据支持 HCP 限度的合理性：
- 工艺中 HCP 的蛋白质组学鉴定（具体是哪些蛋白）
- 各关键 HCP 的风险分级（基于免疫原性、酶活性等）
- 经验证的 HCP 检测方法（覆盖率数据）
- 临床前毒理研究数据

:::

## HCP 去除工艺的四步纯化体系概览

:::answer

单克隆抗体生产中 HCP 的去除依赖下游纯化的多步骤协同作用，每个纯化步骤从不同维度贡献 HCP 的去除能力，形成互补的 HCP 控制链路。

### HCP 去除的四步纯化体系

| 纯化步骤 | HCP 去除机制 | 典型去除效率 | 在整体策略中的定位 |
|---------|-----------|-----------|----------------|
| **① 深层过滤** | 机械截留 + 静电吸附 + 疏水吸附 | 50%～90%（视滤器类型） | 第一道屏障，初步去除，减轻后续步骤负担 |
| **② 亲和层析（Protein A）** | 高度选择性捕获抗体，HCP 流穿 | **> 90%**（最有效的单步） | 主要去除步骤，效率最高 |
| **③ 离子交换层析（AEX/CEX）** | 基于电荷差异分离 | 数倍～数十倍减少 | 精纯步骤，去除残余 HCP 至规格以内 |
| **④ 混合层析（Mixed-mode）** | 离子交换 + 疏水相互作用协同 | 高于单一模式 | 处理难去除 HCP 的专项步骤 |

### 典型 HCP 去除链路数量级变化
```
上清液 HCP（100%，通常 10,000～100,000 ppm）
    ↓ 深层过滤（去除 50%～90%）
    ↓ Protein A 层析（去除 > 90%，流穿机制）
    ↓ 精纯步骤（AEX + CEX，进一步 10～100 倍减少）
原液 HCP（目标 < 100 ppm）
```

:::

## 深层过滤去除 HCP 的机制与工艺优化要点

:::answer

深层过滤（Depth Filtration）在 HCP 去除方面具有被行业长期低估的潜力，其多重互补的分离机制使其不仅是澄清工具，也是 HCP 控制的重要前处理步骤。

### HCP 去除的三重分离机制

**① 机械截留（Size-based Sieving）**

- 截留细胞碎片、大颗粒聚集体及与 HCP 结合的颗粒
- 间接去除与颗粒相关联的 HCP（通过去除其载体颗粒）

**② 静电吸附（Electrostatic Adsorption）**

- 带正电荷的深层滤器介质（硅藻土、纤维素等在中性 pH 下带正电）吸附带负电荷的 HCP
- 大多数 HCP 的等电点为 4～6，在中性 pH 下呈负电性，与带正电介质发生静电相互作用
- 同一机制同时去除带负电的宿主细胞 DNA 和内毒素（LPS）

**③ 疏水相互作用（Hydrophobic Interaction）**

- 深层滤器介质中的疏水性纤维捕获具有疏水表面区域的 HCP
- 对于疏水性特征明显的特定 HCP（如膜蛋白片段）尤为有效

### 关键工艺注意事项

**饱和效应（Saturation Effect）：**

> 一旦深层滤器达到饱和状态，随着载量增加 HCP 将会流穿。

因此，在选择滤器和确定操作参数时，须同时评估两个载量指标：
- **澄清载量（Clarification Capacity）：** 单位面积可处理的料液体积
- **HCP 去除载量（HCP Removal Capacity）：** 单位面积可去除的 HCP 总量

**仅关注澄清载量而忽略 HCP 去除载量，是工程实践中最常见的设计缺陷。**

**多阶段过滤策略：**

- 串联多级深层滤器（孔径从大到小递减）能更好地去除 HCP
- 典型配置：粗过滤（>10 μm）→ 深层过滤（含吸附介质）→ 除菌过滤（0.2 μm）
- 每级滤器的 HCP 去除机制互补，总去除效率显著高于单级过滤

**上样液质量的影响：**

- 发酵液或离心后的收获液的组成对 HCP 有效去除有很大影响
- 细胞活率低（> 10% 死细胞）→ 大量胞内酶和 HCP 释放 → 深层过滤 HCP 去除负担显著增加
- **建议：** 优化上游工艺，在细胞活率仍较高时（≥ 70%）进行收获，可显著降低 HCP 基线水平

:::

## Protein A 亲和层析去除 HCP 的机制与洗涤策略优化

:::answer

Protein A 亲和层析是整个单抗纯化链路中 HCP 去除效率最高的单步操作，通常一步可去除 > 90% 的 HCP，但残余 HCP 的来源和去除机制须深入理解才能进行有效的工艺优化。

### Protein A 步骤 HCP 去除的基本原理

- 目标抗体通过 Fc-Protein A 特异性结合吸附在填料上
- 大多数 HCP 不与 Protein A 结合，在上样和洗涤过程中**流穿**去除
- 洗脱时，目标抗体在低 pH（3.2～3.8）下释放，进入产品收集步骤

### Protein A 洗脱液中 HCP 残留的主要来源

**关键发现（对工艺优化至关重要）：**

> Protein A 洗脱液中 HCP 的残留，**主要是通过 HCP 与抗体之间的相互作用**（而非 HCP 与 Protein A 填料的直接相互作用）残留下来的。

**含义：** HCP 不是直接结合在 Protein A 填料上随抗体洗脱，而是通过与抗体本身的蛋白-蛋白相互作用（疏水、静电、范德华力等）"搭便车"随抗体一同洗脱。

HCP 与抗体相互作用的三种典型模式：
- 非特异性疏水相互作用
- 静电相互作用（特别是在碱性抗体与酸性 HCP 之间）
- 与抗体 Fab 或 Fc 区域的特异性结合（部分 HCP）

### 中间洗涤（Intermediate Wash）的优化策略

**优化目标：** 破坏 HCP 与抗体之间的相互作用，而非简单地破坏 HCP 与 Protein A 的相互作用。

| 洗涤策略 | 优化参数 | 适用的 HCP 类型 | 注意事项 |
|---------|---------|--------------|---------|
| **pH 中间洗涤** | 介于平衡（pH 7.0）和洗脱（pH 3.4）之间的 pH（如 pH 5.0～6.0） | 依赖静电相互作用的 HCP | 仅去除与填料弱结合的 HCP，不能打破强蛋白-蛋白相互作用 |
| **高盐洗涤（NaCl 添加）** | NaCl 0.5～2.0 M | 通过疏水或盐桥与抗体结合的 HCP | 须验证高盐条件下抗体不发生构象变化 |
| **精氨酸添加** | L-精氨酸 0.5～1.0 M | 通过疏水性相互作用与抗体结合的 HCP | 精氨酸特异性破坏蛋白-蛋白疏水相互作用，对许多 HCP 有效 |
| **尿素添加** | 低浓度（1～2 M），避免过度变性 | 强疏水相互作用的 HCP | 须验证目标抗体在此条件下的稳定性 |
| **低 pH 洗涤** | pH 4.0～4.5 | 多种 HCP | **风险：可能导致抗体部分洗脱，造成收率损失**，须谨慎 |

### 填料选择对 HCP 去除的影响

在工艺开发阶段，选择合适的 Protein A 亲和层析填料本身就能降低 HCP 的非特异性吸附：
- 填料基质（琼脂糖 vs 聚合物骨架）影响疏水性和非特异性吸附倾向
- 填料的配基密度影响 HCP 与配基的非特异性相互作用
- **建议：** 在 DoE 工艺开发阶段系统评估 3～4 种主流 Protein A 填料（如 MabSelect PrismA、Capto MabSelect、CaptureSelect IgG-Fc 等）的 HCP 去除性能，选择最优配置

## 离子交换层析去除 HCP 的原理与操作模式选择

:::answer

离子交换层析（IEX）是精纯阶段最主要的 HCP 去除手段，阴离子交换（AEX）和阳离子交换（CEX）两种方式在操作模式和去除机制上存在根本差异，须根据产品特性合理选择。

### 阴离子交换层析（AEX）去除 HCP

**科学依据：利用单抗与 HCP 等电点的系统性差异**

| 组分 | 典型等电点（pI） | 在 pH 6.5～8.0 下的净电荷 | 与 AEX 填料的行为 |
|-----|--------------|----------------------|----------------|
| **单克隆抗体（IgG）** | 6.5～9.0（通常 > 8） | **正电荷** | ❌ 不结合 → **流穿收集** |
| **HCP（大多数）** | 4.0～6.0 | **负电荷** | ✅ 结合填料 → 被截留去除 |
| **宿主细胞 DNA** | < 4.0 | **强负电荷** | ✅ 强结合 → 被去除 |
| **内毒素（LPS）** | 酸性 | **负电荷** | ✅ 结合 → 被去除 |

**AEX 流穿模式的优势：**
- 操作简便，目标抗体直接收集于流穿液
- 可同时去除 HCP、DNA、内毒素，去除谱宽
- 已有大量病毒清除验证数据（非包膜病毒 LRV ≥ 2 log）

**AEX 关键操作参数：**
- 缓冲液 pH：通常 6.5～8.0（须高于大多数 HCP 的 pI，低于单抗 pI）
- 电导率：低电导（< 10 mS/cm），确保 HCP 与填料的有效结合
- 上样量：须控制不超过 HCP 去除载量，避免 HCP 突破

### 阳离子交换层析（CEX）去除 HCP

**操作模式：结合-洗脱模式（Bind & Elute）**

在低 pH（4.5～6.5）条件下，单克隆抗体（pI > 8）带正电荷，与阳离子交换填料（磺酸基 −SO₃⁻）结合；同时 HCP 等杂质在此条件下部分流穿或在梯度洗脱时与抗体分离。

**CEX 步骤的主要去除目标：**

| 杂质 | CEX 去除机制 |
|-----|-----------|
| **HCP** | 部分 HCP 在 CEX 结合条件下不结合（流穿）或结合强度与抗体不同（梯度洗脱时分离）|
| **残余 Protein A（rProtein A）** | 脱落的 Protein A 片段在 CEX 中的保留时间与抗体不同，可通过洗脱梯度分离去除 |
| **聚集体** | 聚集体与 CEX 填料的结合强度通常强于单体，在梯度洗脱中可实现分离 |

:::

## 混合层析去除 HCP 的优势与工艺参数优化

:::answer

混合模式层析（Mixed-mode Chromatography，MMC）通过在单一填料上实现多种相互作用机制的协同，在去除特定难去除 HCP 方面展现出优于单一模式层析的选择性。

### 混合层析的分离机制

混合模式层析填料同时包含**离子交换**和**疏水相互作用**两种功能基团（有时还包括氢键相互作用），通过多种弱相互作用的协同，对具有特定理化特征的分子实现精细分离。

**关键理解：**
- 抗体表面疏水基团和带电荷的分布与大多数 HCP 表面分布存在显著差异
- 这种差异在多模式相互作用下被放大，使 MMC 展现出高于单一模式填料的选择性和特异性

### 核心控制参数

混合模式层析的结合和洗脱条件精细，须同时优化两个关键参数：

| 参数 | 控制的相互作用 | 优化目标 |
|-----|-------------|---------|
| **pH** | 主要控制**离子交换相互作用**和结合能力 | 调节抗体与填料的静电结合强度，保证高回收率 |
| **电导率（盐浓度）** | 决定**疏水相互作用**的强度 | 调节分离能力；高盐抑制疏水相互作用，可用于洗脱 |

**两参数的相互依赖性：** pH 和盐浓度须联合优化（DoE 实验），单变量优化通常无法找到最优工艺窗口。

### 添加剂的使用

在混合层析缓冲液中添加特定添加剂可进一步提高分离性能和选择性：
- **精氨酸：** 破坏疏水性蛋白-蛋白相互作用，改善峰形
- **聚乙二醇（PEG）：** 调节疏水环境，影响蛋白质与填料的接触方式
- **低浓度有机溶剂：** 调节疏水作用强度（须验证对目标蛋白稳定性无影响）

### 混合层析的代表性填料

| 填料名称 | 主要功能基团 | 主要应用 |
|---------|-----------|---------|
| CHT（羟基磷灰石）| 磷酸根（离子交换）+ 钙离子（金属螯合）| 去除 HCP、rProtein A、聚集体和核酸 |
| Capto MMC | 苯甲酸基（疏水）+ 磺酸基（阳离子） | 去除 HCP、聚集体 |
| Capto adhere | N-苄基-N-甲基乙醇胺（阴离子交换 + 疏水）| 流穿模式去除 HCP 和 DNA |

:::

## HCP 的形成原因：染色质复合物的核心作用

:::answer

深入理解 HCP 的形成机制，特别是染色质（Chromatin）复合物的作用，对于设计有效的上游控制策略和下游去除工艺具有重要的科学指导意义。

### Chromatin 是 HCP 积累的核心驱动因素

**细胞死亡 → Chromatin 释放 → HCP 复合物形成：**
```
死亡细胞裂解
      ↓
Chromatin 释放（主要成分：DNA + 组蛋白）
      ↓
高活性表面（组蛋白带强正电荷 + DNA 带强负电荷）
      ↓
非特异性结合非组蛋白 HCP 和目标抗体
      ↓
形成 Chromatin-HCP-抗体 多聚体复合物
      ↓
该多聚体与 Protein A 树脂的结合比单独抗体更牢固
      ↓
洗脱过程中，Chromatin 复合物随抗体洗脱 → HCP 残留
```

**关键认识：**
- 死亡宿主细胞释放的 Chromatin 是聚体形成和 HCP 污染来源的主要原因之一
- 结合在 Protein A 上的 Chromatin 多聚体（Leachates）是 Protein A 洗脱液中 HCP 污染的主要来源之一
- 这解释了为什么降低收获时细胞活率对 HCP 水平的影响如此显著

### 培养工艺对 HCP 组成的影响

不同的上游培养策略会显著影响 HCP 的数量和组成：

| 培养模式 | HCP 特征 | 纯化挑战 |
|---------|---------|---------|
| **批次培养（Batch）** | HCP 积累量相对较少 | — |
| **补料分批培养（Fed-batch）** | HCP 积累更多（活细胞持续分泌 + 死细胞释放） | 需要更强的 HCP 去除能力 |
| **灌流培养（Perfusion）** | 延长培养过程中 HCP 组成可能随时间发生变化 | 须监控不同时间点收获液的 HCP 谱变化 |

**培养温度对 HCP 的影响（文献数据）：**

- 在对数细胞生长期晚期使用**温和低温条件（32～34°C）**，可减少约 44% 的细胞内蛋白酶类 HCP 和约 27% 的伴侣蛋白（Chaperone）类 HCP
- 温和低温条件通过抑制细胞凋亡，减少与凋亡相关 HCP 的表达
- **需注意：** 来自亚低温生物反应器的 HCP 在下游纯化步骤中可能更难去除（可能与其结构特性变化有关）

### 降低 HCP 水平的系统性上游策略

| 策略 | 机制 | 效果 |
|-----|-----|-----|
| **维持高细胞活率收获（≥ 70%）** | 减少死亡细胞裂解释放的 Chromatin 和胞内酶 | 直接降低 HCP 基线水平 |
| **培养中后期温度偏移** | 减缓代谢，延缓凋亡，减少胞内蛋白释放 | 降低特定类别 HCP 的表达 |
| **选择低 HCP 分泌的克隆** | 克隆筛选阶段评估 HCP 分泌谱 | 从源头控制（最根本的策略） |
| **优化补料策略** | 避免营养剧烈波动导致的应激性蛋白分泌 | 降低 HCP 总量 |

:::

## 如何系统降低 HCP 水平：从上游到下游的综合策略

:::answer

HCP 控制是上下游工艺一体化管理的典型案例，须在细胞株选择、培养工艺、纯化策略和检测方法四个维度协同发力。

### 上游工艺层面的降低策略

**① 细胞株和克隆层面**

- 不同克隆在 HCP 分泌谱上存在显著差异（Valente 等人研究发现，相同条件下培养的不同年龄的 CHO-K1 细胞，92 种 HCP 存在差异表达，其中 34 种被报道难以通过纯化去除，17 种已知与 mAb 强烈相互作用）
- **建议：** 在克隆筛选阶段，将 HCP 分泌水平和 HCP-抗体相互作用倾向纳入筛选指标

**② 培养工艺层面**

| 调控手段 | 对 HCP 的影响 |
|---------|-----------|
| 控制细胞活率（收获时 ≥ 70%） | 减少死亡细胞来源的 HCP（特别是胞内蛋白酶类） |
| 培养后期温度偏移（37°C → 33°C） | 减缓代谢，降低蛋白酶类和伴侣蛋白类 HCP 的积累量 |
| 优化补料策略（避免营养突变） | 减少应激性 HCP 分泌 |
| 灌流培养（持续移除培养液）| 减少细胞外 HCP 的积累（但需注意延长培养后 HCP 组成的变化） |

### 下游工艺层面的优化策略

- **深层过滤：** 选择高 HCP 去除载量的滤器，采用多级过滤策略
- **Protein A 中间洗涤：** 优化洗涤缓冲液（添加精氨酸、NaCl 等），破坏 HCP-抗体相互作用
- **精纯步骤组合：** AEX（流穿去除 HCP/DNA）+ CEX（去除剩余 HCP + 聚集体）+ CHT（处理难去除 HCP）

### 检测与监控层面

- 建立基于质谱（LC-MS/MS）的 HCP 蛋白质组学鉴定体系，识别特定高风险 HCP
- 对高风险 HCP（如磷脂酶 A2、脂蛋白脂酶等）建立靶向定量方法（靶向 MRM）
- 在工艺开发阶段对各纯化步骤进行 HCP 质量平衡分析，识别 HCP 去除的限速步骤

:::

## HCP 的检测方法体系：ELISA 与 Western Blot 的比较

:::answer

HCP 的定量检测是生物制品质量控制的核心项目，须选择具有充分灵敏度、特异性和覆盖率的方法。

### 主要检测方法比较

**① ELISA（酶联免疫吸附测定法）—— 行业标准方法**

**检测原理（三明治 ELISA 模式）：**
```
特异性多克隆抗 HCP 抗体固定在酶标板（捕获）
          ↓
加入待测样品，HCP 与捕获抗体结合
          ↓
加入酶标记的二抗（检测抗体，识别 HCP 的不同表位）
          ↓
加入底物，酶催化显色
          ↓
吸光度测定，通过标准曲线换算 HCP 浓度
```

| 性能特征 | 说明 |
|---------|-----|
| **灵敏度** | 通常 LOD < 1 ng/mL，LOQ < 5 ng/mL，满足 < 100 ppm 的检测需求 |
| **优点** | 灵敏；可量化 HCP 总量；适合批放行的高通量检测；商品化试剂盒可用 |
| **局限性** | 取决于检测抗体的覆盖率（Coverage）；可能漏检未被抗体覆盖的 HCP 种类 |
| **关键验证要求** | 须进行覆盖率研究（通常 ≥ 70%覆盖率为可接受标准）；须验证目标蛋白的基质效应 |

**② Western Blot 法**

| 性能特征 | 说明 |
|---------|-----|
| **优点** | 免疫特异性强；可分离并识别多种 HCP 组分；提供 HCP 的分子量信息 |
| **局限性** | **仅能进行限量分析，无法定量**；灵敏度低于 ELISA；操作复杂，不适合生产质控 |
| **适用场景** | 工艺开发阶段的 HCP 组成分析；鉴定特定 HCP 的存在；申报资料中的补充表征 |

**③ LC-MS/MS（质谱法）—— 新兴补充方法**

| 性能特征 | 说明 |
|---------|-----|
| **优点** | 可直接鉴定具体 HCP 种类（蛋白质组学鉴定）；不依赖抗体覆盖率；灵敏度可达 ppm 甚至亚 ppm 级别 |
| **局限性** | 成本高；通量相对较低；须专业的生物信息学数据分析 |
| **适用场景** | 覆盖率研究（验证 ELISA 试剂盒对工艺 HCP 的覆盖情况）；鉴定高风险 HCP；BLA 申报中的深度表征 |

:::

## 残余 DNA 的检测方法体系：从传统杂交法到 qPCR

:::answer

宿主细胞残余 DNA（Residual Host Cell DNA）是生物制品的重要工艺相关杂质，须采用经验证的方法进行定量检测，并依据法规要求控制在规定限度以内。

### 各检测方法概览

**① 地高辛标记探针杂交法（Slot Blot Hybridization）**

**检测原理：**
- 采用地高辛（Digoxigenin）标记的宿主细胞基因组 DNA 片段制成特异性探针
- 待测样品变性后固定于尼龙膜，与标记探针进行同源 DNA 杂交
- 通过酶联显色（碱性磷酸酶标记抗地高辛抗体）定量检测杂交信号
- 信号强度与样品中残余 DNA 含量正相关

**方法特点：** 灵敏度高；特异性检测宿主细胞 DNA；但操作复杂，探针制备是关键步骤。

**② 荧光染色法（PicoGreen 法）**

**检测原理：**
- PicoGreen 试剂与双链 DNA（dsDNA）发生插入式结合，形成高荧光强度的荧光复合物
- 荧光强度与 dsDNA 含量成正比（检测范围通常 0.5 pg/mL ～ 1 μg/mL）

**方法特点：** 操作简便；不需要探针制备；但**检测所有来源的 dsDNA**（非宿主细胞特异性），可能存在假阳性。

**③ 定量 PCR 法（qPCR）—— 推荐方法**

**检测原理：**
- 设计针对宿主细胞基因组特异性 DNA 序列的引物/探针（如 CHO 特异性重复元件）
- 实时 PCR 扩增并定量靶 DNA，以已知浓度标准品建立标准曲线

**法规地位：** 《中华人民共和国药典》2020 年版第三部已推荐使用定量 PCR 法。

**qPCR 的优势：**

| 比较维度 | 杂交法 | PicoGreen 法 | qPCR 法 |
|---------|-------|------------|---------|
| 特异性 | 高（宿主细胞特异） | 低（检测所有 DNA） | **最高**（序列特异） |
| 操作复杂性 | 高 | 低 | 中 |
| 耗时 | 长（3～5 天） | 短（数小时） | **短**（数小时） |
| 定量准确性 | 中 | 中 | **高** |
| 一致性与可比性 | 中 | 中 | **高** |

### 残余 DNA 检测的质量控制要点

- 须使用与宿主细胞相同来源的基因组 DNA 制备标准曲线
- 须在代表性的产品基质中进行加标回收试验，验证方法的基质效应
- 采用 qPCR 法时，须设置阳性对照、阴性对照和基质对照（空白基质加标）

:::

## 残余 Protein A 的检测方法与干扰排除

:::answer

Protein A（rProtein A）残留是单克隆抗体纯化工艺中特有的工艺相关杂质，其免疫原性要求对残留量进行精确定量，须选择并验证能有效排除基质干扰的检测方法。

### 为什么选择 ELISA 法

- Protein A 种类比较单一（相比 HCP 的复杂混合物）
- 与目标抗体分子具有较强的特异性结合力
- 可以制备高质量的特异性抗 Protein A 抗体
- ELISA 法自然成为检测 Protein A 残留的**首选方法**

### 商品化试剂盒的局限性与干扰排除

**核心挑战：结合了药物蛋白的 Protein A 的漏检问题**

在产品收集步骤中，部分 Protein A 在脱落时仍与目标抗体（药物蛋白）相结合。当使用商品化 Protein A 检测试剂盒时，存在以下干扰：
```
问题 1：位阻效应（Steric Hindrance）
结合了抗体分子的 Protein A → 抗体遮蔽 Protein A 的捕获抗体结合位点
→ 导致 Protein A 漏检（假阴性）

问题 2：二抗结合受阻
结合在 Protein A 上的抗体分子 → 阻碍酶标二抗（抗 Protein A）的结合
→ 进一步导致检测信号降低
```

### 干扰试验设计要求

使用商品化 Protein A 检测试剂盒前，须进行干扰试验（Interference Study）以排除上述影响：

| 干扰试验内容 | 方法 |
|-----------|-----|
| **基质效应评估** | 在空白产品基质中添加已知量 Protein A 标准品，计算回收率（应在 80%～120%） |
| **结合态 Protein A 释放** | 采用酸处理（如 pH 2.0）或变性剂（如 8 M 脲）处理样品，使 Protein A 从抗体上释放后再检测 |
| **试剂盒适用性确认** | 比较处理前后的检测结果，评估结合态 Protein A 的漏检比例 |

### 高灵敏度替代检测方法

| 方法 | 优势 | 适用场景 |
|-----|-----|---------|
| **增强型 ELISA（加变性处理）** | 释放与抗体结合的 Protein A，提高检测回收率 | 常规批放行 |
| **LC-MS/MS（靶向 MRM）** | 不受抗体结合状态影响；绝对定量；LOD < 1 ng/mL | 验证研究；特殊情况 |
| **表面等离子体共振（SPR）** | 实时、无标记检测 | 研究开发阶段 |

:::

## 抗体蛋白结构表征项目的完整体系框架

:::answer

抗体蛋白结构表征是 CMC 申报数据包的核心组成部分，须系统覆盖从氨基酸序列到空间构象的所有结构层次，建立全面的产品分析数据档案。

### 结构表征的四大维度

蛋白质是由不同氨基酸连接形成的多聚体，通过正确折叠形成特定构型发挥生物学功能。翻译后修饰（PTM）在特定位置发生，影响蛋白质的结构和功能，须全面检测。
```
抗体蛋白结构表征体系
├── 01 一级结构表征
│     ├── 分子量（完整 / 去糖基化 / 轻链 / 重链）
│     ├── N 端序列分析
│     ├── C 端序列分析
│     ├── C 端赖氨酸（K）缺失比例分析
│     ├── 肽图（Peptide Mapping）+ 翻译后修饰定位
│     └── 二硫键配对分析
│
├── 02 高级结构表征
│     ├── 二级结构（CD 远紫外区）
│     ├── 三级结构（CD 近紫外区）
│     ├── 热稳定性（DSC）
│     └── 动态构象（HDX-MS / FTIR）
│
├── 03 蛋白异质性表征
│     ├── 电荷异质性（CEX-HPLC / cIEF）
│     ├── 糖基化异质性（N 糖谱分析）
│     ├── 大小异质性（SEC-HPLC / CE-SDS）
│     └── 翻译后修饰谱（去酰胺化、氧化、糖化等）
│
└── 04 杂质检测
      ├── HCP（ELISA）
      ├── DNA（qPCR / 杂交法）
      └── Protein A 残留（ELISA）
```

:::

## 一级结构表征：分子量精确测定方法与信息解读

:::answer

分子量（Molecular Weight，MW）测定是蛋白质结构鉴定的第一步，高分辨质谱分析可提供精确的分子量信息，并从中推断蛋白质的修饰状态和结构完整性。

### 检测方法：LC-MS 高分辨质谱

**技术原理：**
1. 蛋白质样品经液相色谱（通常为反相 LC，C4 或 C8 柱）分离脱盐
2. 进入质谱仪后，蛋白质在 ESI（电喷雾离子化）源中形成多电荷离子（[M+nH]ⁿ⁺）
3. 质谱检测各电荷态离子的 m/z（质荷比）信号
4. 通过**去卷积分析（Deconvolution）**，将多电荷谱图转换为单一中性分子量分布图

### 不同层次的分子量测定策略

| 分析对象 | 样品处理 | 获得信息 |
|---------|---------|---------|
| **完整抗体（Intact mAb）** | 直接脱盐分析 | 完整分子量（含全部 N 糖）；糖型分布初步判断 |
| **去糖基化抗体（Deglycosylated）** | PNGase F 酶切去除 N 糖 | 去糖基化分子量（确认氨基酸序列完整性）；排除糖型影响 |
| **轻链（LC）** | DTT 还原 + 烷基化后 LC-MS | 轻链分子量（确认链间二硫键打断） |
| **重链（HC）** | 同上 | 重链分子量（去糖基化后的重链） |
| **去糖基化轻链/重链** | 去糖基化 + 还原 | 单独分析糖基化与序列贡献 |

### 分子量偏差的诊断价值

| 测定质量与理论质量的关系 | 可能的解释 |
|----------------------|---------|
| 精确符合（< 5 ppm 偏差） | 序列和修饰状态正常 |
| **+162 Da（一个糖基化位点）** | 非糖基化样品中存在糖化（Glycation）修饰 |
| **+16 Da** | 蛋氨酸或色氨酸氧化（+16 Da/位点）|
| **−1 Da** | 天冬酰胺（Asn）去酰胺化（Asn → Asp，失去 NH₂ 得到 OH，净变化 +0.984 Da，约 +1 Da） |
| **较大偏差（> 100 Da）** | 可能存在截断（Clipping）、错误折叠或大规模修饰 |

:::

## 一级结构表征：N 末端序列分析方法与法规要求

:::answer

N 末端序列分析是生物药申报的必检项目，须系统掌握其生物学意义、检测方法和法规地位。

### N 末端序列的生物学重要性

蛋白质的生物合成起始于 N 末端，N 末端序列的组成直接影响：

| 生物学维度 | 具体影响 |
|----------|---------|
| **蛋白质半衰期（N 末端规则）** | 特定 N 末端氨基酸（如 Arg、Lys 等）可被 N 末端识别蛋白识别，触发蛋白质降解 |
| **亚细胞定位** | 信号肽序列（位于 N 末端）引导蛋白质靶向特定细胞器或分泌途径 |
| **翻译后修饰起点** | N 末端是多种 PTM 的发生位置（如 N 端乙酰化、N 端焦谷氨酸化） |
| **结构与功能** | N 末端参与特定的蛋白质-蛋白质相互作用界面 |

### 主要检测方法：Edman 降解法

**原理：**
```
蛋白质 N 末端游离氨基
    ↓ 异硫氰酸苯酯（PITC）与 N 末端氨基反应，形成苯硫代氨基甲酰衍生物
    ↓ 酸性条件下，N 末端氨基酸以噻唑啉酮形式断裂
    ↓ 转化为更稳定的苯乙内酰硫脲（PTH）衍生物
    ↓ HPLC 分析鉴定 PTH-氨基酸种类
    ↓ 暴露出下一个氨基酸，重复循环
```

**方法特点：**
- 经典方法，已有几十年应用历史，技术成熟
- 每次循环鉴定一个氨基酸，可连续测定 15～25 个氨基酸序列
- 对封闭 N 末端（如 N 端乙酰化、N 端焦谷氨酸化）无法读取（需特殊处理）

### 法规要求

**中国药典（2020 版）《人用重组 DNA 蛋白制品总论》：**
- 通过 Edman 降解法分析 N 末端的 **15 个氨基酸序列**是生物药申报时的**必检项目**
- 同时是已上市生物药的年检项目（Lot Release Testing）

### N 末端异质性的常见情形

| N 末端变异类型 | 来源 | 对产品的影响 |
|-------------|-----|-----------|
| **N 末端焦谷氨酸化（pyrGlu）** | N 末端 Gln/Glu 环化 | 造成 Edman 降解无信号（封闭末端）；通常不影响活性 |
| **信号肽不完整切除** | 信号肽酶切割位置变异 | 在 N 末端序列中出现额外氨基酸 |
| **N 末端异质性** | 翻译起始位点的变异 | 产生多种 N 末端序列的混合物 |

:::

## 一级结构表征：C 末端序列分析方法与技术选择

:::answer

C 末端序列分析是蛋白质一级结构表征中比 N 末端分析技术难度更高的项目，因为 C 末端通常缺乏反应活性基团，且天然存在较多加工异质性。

### C 末端序列的重要性

**C 末端是蛋白质的重要结构与功能区域：**
- 对于 IgG 抗体，C 末端赖氨酸（Lys447）的加工状态直接影响产品的电荷均一性
- C 末端序列影响蛋白质的识别、降解和信号传导
- 由于翻译后在细胞内须经进一步加工（羧肽酶切割等），不能简单从基因序列预测 C 末端状态

### 主要检测方法及其原理

**① 羧肽酶法（Carboxypeptidase Method）**

- 羧肽酶从 C 末端逐一水解氨基酸，通过 LC-MS 或 LC-FLD 鉴定释放的氨基酸种类
- 根据不同时间点氨基酸的释放动力学，推断 C 末端序列
- **优点：** 成本低，操作相对简便
- **局限性：** 对特殊氨基酸（如 Pro）或碱性残基的酶解效率差，不适用于所有 C 末端类型

**② 化学法（Chemical Methods）**

- 通过特定化学试剂（如硫氰酸铵/乙酸酐，Akabori 试剂等）对 C 末端进行标记和裂解
- **局限性：** 操作复杂，条件苛刻，实际应用较少

**③ 串联质谱法（LC-MS/MS，最主流方法）**

**技术路线：**
```
蛋白质 → 酶切（胰酶/Lys-C/Asp-N）→ 肽段混合物
    ↓
液相色谱分离肽段
    ↓
一级质谱（MS1）：选择 C 末端肽段离子
    ↓
二级质谱（MS2）：碎片离子分析（y 离子系列确认 C 末端序列）
    ↓
结合数据库搜索软件（如 Mascot、Byonic）分析 C 末端序列
```

**方法优势：**
- 无需特殊的 C 末端特异性试剂
- 可精确鉴定 C 末端序列至单个氨基酸
- 可同时鉴定 C 末端修饰（如赖氨酸糖化、酰胺化等）

:::

## 一级结构表征：C 末端赖氨酸缺失比例分析

:::answer

C 末端赖氨酸（C-terminal Lysine，C-term K）缺失是 IgG 型单克隆抗体最普遍的加工异质性之一，须进行定性和定量分析，并将其纳入产品质量控制体系。

### C 末端 K 缺失的产生机制

IgG1/IgG4 重链在基因编码层面含有 C 末端赖氨酸（Lys447）：
- 细胞内羧肽酶 B 在蛋白质分泌过程中对 C 末端 Lys 进行不完整切除
- 结果：同一批次产品中同时存在保留 Lys（+1 个正电荷）和切除 Lys 的两种分子形式
- 由于 IgG 含有两条重链，实际可能存在 3 种 C 末端状态（0、1、2 个 Lys 保留）

**对电荷异质性的影响：**
- 每保留一个 C 末端 Lys（+1 正电荷）→ 抗体 pI 升高约 0.1～0.2 个单位
- 在 CEX-HPLC 中，C 末端 Lys 保留的分子出峰较晚（碱性峰），形成碱性变体

### 法规要求（ICH Q6B 强制要求）

> 在 ICH Q6B 生物技术产品测试程序指南中，**C 末端 K 缺失测定是强制性的**（N 和 C 末端测序均为强制检项）。

### 检测方法

| 方法 | 特点 | 定量能力 |
|-----|-----|---------|
| **等电聚焦（IEF）/ 毛细管等电聚焦（cIEF）** | 通过 pI 变化间接反映 K 缺失状态 | 半定量（需与参比品比较）|
| **CEX-HPLC** | 通过电荷变体图谱分析 K 缺失导致的碱性峰比例 | 半定量（与其他碱性变体混合）|
| **LC-MS 肽图法（最准确方法）** | 胰酶消化后 LC-MS 分析 C 末端肽段的序列 | **精确定量**（缺失 K 与未缺失 K 的 C 末端肽段面积比） |

### LC-MS 肽图法的技术细节

**分析原理：**
- 抗体经胰酶消化，C 末端生成两种多肽：
  - 含 Lys 的 C 末端肽段（...序列-K）
  - 不含 Lys 的 C 末端肽段（...序列）
- 两种肽段的分子量差异为 128.09 Da（Lys 残基的分子量）
- 通过 LC-MS 同时定量两种 C 末端肽段的面积，计算 K 缺失比例

**计算方式：**
```
K 缺失比例（%）= 
    不含 K 的 C 末端肽段面积 / （含 K + 不含 K 的 C 末端肽段面积之和）× 100%
```

### C 末端 K 缺失对临床的影响

- **静脉注射产品：** 血液中含有羧肽酶，静脉注射后 C 末端 Lys 被迅速清除，**不影响 PK**
- **批间一致性：** 须监控 C 末端 K 缺失比例的批间变异，确保产品一致性（通常要求主峰比例 ± 15%以内变化）
- **工艺变更评估：** 培养条件变化（pH、温度、培养时间）可能影响细胞内羧肽酶活性，进而改变 K 缺失比例，须纳入可比性研究评估指标

:::
