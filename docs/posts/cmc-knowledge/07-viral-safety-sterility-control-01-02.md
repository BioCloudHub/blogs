## 细胞鉴别试验：方法体系与适用场景

:::answer

细胞鉴别试验是确保细胞库身份唯一性和排除交叉污染的基础质控措施，须在细胞库建立和生产终末阶段系统开展。

### 实施时机

以下三类情形**必须**进行细胞鉴别试验：
1. 新建细胞系/株（首次建立时）
2. 细胞库建立时（MCB 和 WCB 各自独立鉴别）
3. 生产终末细胞（EOPC）

**鉴别目的：** 确认为本细胞（Identity），且无其他细胞的交叉污染（Cross-contamination Absence）。

### 六类鉴别方法及适用性

| 方法类别 | 代表技术 | 鉴别层次 | 特点 |
|---------|---------|---------|-----|
| **细胞形态观察** | 倒置显微镜观察形态特征 | 粗筛 | 快速简便；特异性低；作为补充 |
| **生物化学法** | **同工酶试验**（LDH、G6PD、NP 等） | 种属特异性 | 操作简单；常用于细胞库种属确认 |
| **免疫学检测** | 组织相容性抗原（MHC）、种特异性免疫血清 | 种属特异性 | 须高质量特异性抗体 |
| **细胞遗传学检测** | 染色体核型分析、标记染色体检测 | 染色体水平 | 评估遗传稳定性；可检测染色体异常 |
| **遗传标志检测** | **STR（短串联重复序列）**；RFLP-PCR；EPIC-PCR | 细胞株特异性（高度特异） | **工业首选**；DNA 指纹图谱，可区分不同细胞株 |
| **其他方法** | 杂交法、PCR 法、报告基因法 | 分子水平 | 针对特定目的基因的存在与表达 |

**法规要求：** 须至少选择上述一种或几种方法对细胞进行**种属鉴别**（确认物种来源）和**细胞株间鉴别**（确认为特定细胞株，无其他细胞系混入）及专属特性的鉴别。

### 同工酶试验详解（最常用方法之一）

**适用场景：** CHO-K1、HEK293、BHK21 等主流宿主细胞的种属确认。

**CHO-K1 细胞推荐酶组合：**
- 乳酸脱氢酶（Lactate Dehydrogenase，LDH）
- 6-磷酸葡萄糖脱氢酶（Glucose-6-Phosphate Dehydrogenase，G6PD）
- 核苷磷酸化酶（Nucleoside Phosphorylase，NP）

**方法步骤：** 细胞裂解液 → 非变性凝胶电泳 → 特异性酶显色底物染色 → 与标准 CHO-K1 参比图谱比对

**判断标准：** 样品同工酶图谱与标准 CHO-K1 的迁移模式完全相同，则判定为与 CHO-K1 细胞系同系，无其他种属细胞混入。

### STR 分析（最高特异性方法）

STR 分析可将细胞株鉴别精度提升至单个克隆水平，是 FDA 和 EMA 越来越推荐的细胞鉴别方法：
- 检测基因组中多个 STR 位点的等位基因长度
- 每个细胞株具有独特的 STR 图谱（类似 DNA 指纹）
- 可与细胞系数据库（如 ATCC STR 数据库）进行比对
- 须记录并归档 MCB 建立时的 STR 基准图谱，用于后续 WCB 和 EOPC 的一致性比较

:::

## 细胞培养污染识别：五类污染微生物的形态特征

:::answer

当培养液出现异常时，通过显微镜下的形态特征可以对污染微生物种类进行初步判断，为后续的鉴定和处置提供方向。

### 五类污染微生物的形态辨识

**① 细菌（Bacteria）**

| 特征 | 描述 |
|-----|-----|
| 形态 | 杆状、球状或螺旋状 |
| 显微镜下表现 | 倒置显微镜下呈**黑色细沙状**，密度高，形状规则 |
| 培养液变化 | **浑浊变黄**（pH 下降，培养基 pH 指示剂变色） |
| 对细胞影响 | 影响**明显**，细胞迅速死亡 |
| 确认方法 | 革兰氏染色 + 普通光学显微镜 |

**② 霉菌（Mold）**

| 特征 | 描述 |
|-----|-----|
| 形态 | **长管状菌丝**（管径较粗，有明显的分隔） |
| 显微镜下表现 | 初期培养液清亮，37°C 培养 2～3 天后出现**絮状漂浮物**，可见明显丝状团状菌体 |
| 培养液变化 | 培养液**清亮**（早期），后期可见肉眼可见菌落 |
| 对细胞影响 | 比细菌缓慢，但最终导致细胞死亡 |

**③ 支原体（Mycoplasma）**

| 特征 | 描述 |
|-----|-----|
| 形态 | 丝状和分枝形状（无细胞壁） |
| 显微镜下表现 | **倒置显微镜下不可见**（过小，< 0.5 μm；缺乏细胞壁，不折射光线）；此为危险特征——污染后细胞外观几乎正常 |
| 培养液变化 | **可能轻微浑浊**，但有时几乎正常 |
| 对细胞影响 | 隐性污染，细胞生长减缓，代谢异常，产品质量受影响，但细胞不立即死亡 |
| **检测必要性** | **必须用专项检测方法（培养法 + DNA 荧光染色法）才能确认** |

**④ 真菌（Fungi，如酵母）**

| 特征 | 描述 |
|-----|-----|
| 形态 | 管状（菌丝型）或圆形出芽（酵母型） |
| 显微镜下表现 | 培养液清亮，显微镜下有**丝状物**；早期类似死细胞碎片，呈**珊瑚状**清晰小块，后期可见细黑色丝状物 |
| 区别于死细胞碎片 | 形状规则、数量非常多、可成团生长 |

**⑤ 原虫（Protozoa）**

| 特征 | 描述 |
|-----|-----|
| 形态 | 圆形或不规则型 |
| 显微镜下表现 | 大量细小点状物，具有**轻微活动性** |
| 对细胞影响 | 细胞可生长但**繁殖速度明显减慢**，细胞状态不佳（边缘不清楚，透明度降低） |

### 快速响应流程

```
发现培养液异常
    ↓
倒置显微镜观察形态（初步判断污染类型）
    ↓
培养液 pH 检查（变黄提示细菌/真菌；不变提示支原体）
    ↓
隔离可疑培养物，启动污染调查
    ↓
确认污染种类（必要时送微生物鉴定）
    ↓
废弃污染批次，溯源分析（操作记录、环境监控、物料批次）
    ↓
针对性纠正措施（CAPA）
```

## 工艺污染物对蛋白质稳定性的多维影响

:::answer

生产过程中，多种来源的工艺污染物可通过直接化学反应或间接机制影响蛋白质制品的稳定性，须在工艺设计和质量控制中系统识别和控制。

### 主要污染物种类与稳定性影响机制

**① 金属离子污染（最常见的工艺污染物）**

| 来源 | 不锈钢工艺设备渗出；原材料（培养基、缓冲液）中的微量金属 |
|-----|-------|
| **直接影响机制** | 金属直接与蛋白质的 His、Cys、Met 等含配位原子的氨基酸残基结合，降低构象稳定性 |
| **间接影响机制** | 金属催化氧化（Fenton 反应，Fe²⁺/Cu²⁺ + H₂O₂）→ 蛋白质残基羰基化、Met 氧化、Trp 氧化 |
| **其他效应** | 促进分子内或分子间的交联反应，导致蛋白质裂解或聚集 |
| **控制策略** | 优先使用**一次性系统（Single-use Systems）**，从根本上消除金属设备渗出来源 |

**② 残留有机溶剂**

| 溶剂类型 | 对蛋白质的影响 |
|---------|------------|
| 甘油 | 低浓度可增强稳定性，但高浓度可促进聚集 |
| 乙醇 | 破坏蛋白质疏水核心，促进解折叠和聚集 |
| 2,2,2-三氟乙醇（TFE） | 可稳定二级结构（如 α 螺旋），但高浓度下促进聚集 |

**③ 残留消毒剂**

| 消毒剂 | 对蛋白质的影响 |
|-------|------------|
| 次氯酸（NaClO） | 强氧化剂，氧化 Met、Trp、His 残基；破坏二硫键；导致聚集 |
| 过氧乙酸（Peracetic Acid，PAA）| 同上，常用于设备消毒后须充分清洗以去除残留 |

**④ 残留蛋白水解酶**

- 来自宿主细胞 HCP 中的蛋白酶（如组织蛋白酶 D）
- 催化目标蛋白的肽键水解，产生片段
- 片段可成为聚集的核（Nucleation Seeds），进一步促进聚集体形成
- 蛋白酶还可催化聚山梨酯（Polysorbate 80/20）水解，产生游离脂肪酸，间接影响蛋白质稳定性

**⑤ 包装材料浸出物（Leachables/Extractables）**

- 来自塑料容器、一次性储袋、硅胶管等产品接触表面
- 典型浸出物：抗氧化剂（如 BHT、BHA）、增塑剂、残留单体
- 须在制剂开发阶段进行相容性研究，评估浸出物对蛋白质稳定性的影响

**⑥ 常用赋形剂的杂质**

| 赋形剂 | 已知杂质 | 对蛋白质的影响 |
|-------|---------|------------|
| 蔗糖 | 纳米颗粒 | 可充当聚集核，促进蛋白聚集 |
| PEG（聚乙二醇） | 过氧化物、甲醛 | 氧化蛋白质（过氧化物）；导致甲基化修饰（甲醛） |
| 聚山梨酯（PS 20/80）| 游离脂肪酸（酶解产物）| 降低蛋白质溶解度，促进聚集；可能与蛋白疏水区相互作用 |

:::

## 低 pH 病毒灭活的原理、参数设计与产品质量影响

:::answer

低 pH 孵育（Low pH Incubation）是单克隆抗体纯化流程中最重要的病毒灭活步骤，针对包膜病毒（Enveloped Viruses）具有高效的灭活能力，通常位于 Protein A 层析洗脱之后。

### 病毒灭活原理

**靶点：包膜病毒的脂质膜和包膜蛋白**

```
低 pH 条件（pH 3.2～3.8）
    ↓
病毒包膜中的脂质双层和包膜蛋白发生酸性变性
    ↓
包膜蛋白构象改变，失去与宿主细胞受体的结合能力
    ↓
病毒无法进入宿主细胞 → 感染性丧失
```

**选择性：** 包膜病毒（如 XMuLV、HIV、HBV、HCV 等）对低 pH 高度敏感；非包膜病毒（如 MVM、PPV）则对低 pH 具有较强抵抗力（须依赖其他步骤如病毒过滤去除）。

### 关键工艺参数

| 参数 | 典型范围 | 作用 |
|-----|---------|-----|
| **孵育 pH** | 3.2～3.8（通常 pH 3.5） | 核心灭活参数，须低于病毒包膜蛋白变性阈值 |
| **孵育时间** | ≥ 60 分钟（通常推荐 > 30～60 min） | 确保充分灭活；时间过短可能灭活不彻底 |
| **孵育温度** | 室温（15～25°C） | 温度过低会降低灭活速率 |
| **蛋白浓度** | 须在工艺范围内验证 | 高浓度蛋白质可对病毒产生一定保护作用 |

### Worst-Case 设计原则

病毒灭活验证研究须采用<b>最差条件（Worst-Case Conditions）</b>设计，以确保在最不利情况下工艺仍能实现充分的病毒灭活：

| Worst-Case 参数 | 选择依据 | 说明 |
|--------------|---------|-----|
| **较短孵育时间** | 操作允许范围的下限 | 时间越短，灭活效率越低，代表最差情况 |
| **较低孵育温度** | 操作允许范围的下限 | 低温抑制蛋白变性，降低灭活速率 |
| **较高 pH**（pH 接近上限） | 在设定范围上限 | pH 越高（越接近中性），包膜蛋白变性越弱 |
| **较高蛋白浓度** | 操作允许范围的上限 | 高蛋白浓度对病毒有一定保护效应 |

**验证指标（LRV）：** 最差条件下，包膜病毒（以 XMuLV 为模型病毒）的对数减少值（Log Reduction Value，LRV）通常要求 **≥ 4 log₁₀**（即病毒滴度减少 10,000 倍）。

### 低 pH 对抗体质量的不利影响

低 pH 孵育在灭活病毒的同时，对目标抗体存在多种潜在的不利影响，须在参数优化时综合平衡：

| 不利影响 | 机制 | 控制策略 |
|---------|-----|---------|
| **聚体形成增加** | 低 pH 使抗体暴露疏水基团，促进分子间聚集 | 优化 pH 下限（不低于 3.2）；孵育后快速中和 |
| **脱酰胺化加速** | 酸性条件加速 Asn 脱酰胺化（Asn → Asp）| 控制孵育时间，避免不必要的延长 |
| **蛋白片段化** | 极端酸性条件可水解酸敏感肽键（如 Asp-Pro 键）| 控制 pH 不低于设定下限 |
| **酸性电荷变体增加** | 与脱酰胺化和构象变化相关 | 工艺表征中监控电荷变体比例变化 |

**处置方案：**
- 低 pH 孵育完成后，用 Tris 等弱碱溶液快速中和
- 中和过程中常伴随 HCP 和核酸的沉淀析出，须通过**二次深层过滤**去除
- 适当增大收获澄清步骤（Step 5）的深层过滤面积，可减轻 pH 中和步骤产生的沉淀对过滤膜的堵塞压力

## 低 pH 病毒灭活的 Worst-Case 实验设计案例

:::answer

Worst-Case 实验设计是病毒灭活验证的核心方法，须基于工艺参数范围系统设计，以下以 A-Mab 案例研究中的 XMuLV 灭活实验为例说明设计思路。

### 实验设计框架

**验证目的：** 证明在生产过程中可能遇到的最不利参数组合下，低 pH 步骤仍能实现充分的包膜病毒灭活（LRV ≥ 4 log₁₀）。

### A-Mab 案例 XMuLV 灭活的 Worst-Case 参数设置

| 参数 | 常规操作值 | Worst-Case 设定值 | 选择依据 |
|-----|---------|----------------|---------|
| **孵育 pH** | 3.5 | **3.8**（上限） | 高 pH = 弱灭活条件 |
| **孵育时间** | 60 分钟 | **30 分钟**（下限） | 短时间 = 弱灭活条件 |
| **孵育温度** | 20°C | **15°C**（下限） | 低温 = 弱灭活条件 |
| **蛋白浓度** | 10 mg/mL | **20 mg/mL**（上限） | 高浓度 = 对病毒有保护 |

### 实验模型病毒的选择

**XMuLV（鼠白血病病毒，Xenotropic Murine Leukemia Virus）** 是低 pH 灭活验证最常用的模型病毒：
- 包膜病毒，对低 pH 敏感
- 是 CHO 细胞内源性逆转录病毒的相关病毒
- 代表性广泛，验证数据可被监管机构接受

### 实验结果解读标准

| 结果 | 判定 | 后续行动 |
|-----|-----|---------|
| Worst-Case 条件下 LRV ≥ 4 log₁₀ | ✅ 验证通过 | 确认操作参数范围，纳入工艺验证报告 |
| Worst-Case 条件下 4 > LRV ≥ 2 log₁₀ | ⚠️ 部分合格 | 收窄参数范围（不允许接近 worst-case 边界操作）|
| Worst-Case 条件下 LRV < 2 log₁₀ | ❌ 验证失败 | 须重新设计工艺参数，增加安全余量 |

:::

## 病毒风险控制的三层策略体系

:::answer

病毒对生物制品安全性的威胁可导致灾难性后果（如早期因子产品的 HIV 污染事件），须建立多层防御的系统性风险控制体系，而非依赖单一控制措施。

### 三层风险控制体系

```
第一层：源头预防——控制原材料和工艺，减少病毒污染引入
    ↓
第二层：过程监测——利用检测手段及时发现已发生的污染
    ↓
第三层：工艺清除——在纯化步骤中建立足够的病毒灭活去除能力
```

### 各层次的具体措施

**第一层：源头预防**

| 控制对象 | 具体措施 |
|---------|---------|
| **细胞库** | 对 MCB、WCB 进行全面病毒检测（内源性 + 外源性），确保建库起点无病毒污染 |
| **动物源性原材料** | 血清须来自低风险来源地区（BSE/TSE 认证）；优先使用无动物源性原材料 |
| **重组原材料** | 培养基成分、酶（胰酶等）须提供病毒检测证明；优先使用重组来源 |
| **生产环境** | GMP 洁净生产环境；严格人员和物料流向管理 |

**第二层：过程监测**

| 检测时机 | 检测对象 | 目的 |
|---------|---------|-----|
| 细胞库建立后 | MCB、WCB 全面病毒检定 | 确认建库前无病毒污染 |
| 每批生产结束后 | 未纯化收获物（UPB）病毒检测 | 发现生产过程中可能引入的外源病毒 |
| 达到最高代次后 | 生产终末细胞（EOPC）病毒检测 | 证明生产过程中无病毒积累 |

**第三层：工艺清除**

| 病毒清除步骤 | 类型 | 主要清除病毒类型 | 典型 LRV |
|-----------|-----|--------------|---------|
| **低 pH 孵育** | 专属灭活步骤 | 包膜病毒（XMuLV 等）| ≥ 4 log₁₀ |
| **病毒过滤（纳滤）** | 专属去除步骤 | 包膜和非包膜病毒（≥ 20 nm）| ≥ 4 log₁₀ |
| **阴离子交换层析** | 非专属清除步骤 | 包膜和非包膜病毒（带负电荷时）| 1～3 log₁₀ |
| **Protein A 层析** | 非专属清除步骤 | 部分包膜病毒 | 1～2 log₁₀（通常不用于声明）|

### 病毒清除验证的整体设计原则（ICH Q5A）

- **正交性（Orthogonality）：** 须包含至少两个**正交的专属**病毒清除步骤（如低 pH 灭活 + 病毒过滤），两个步骤的清除机制须完全不同
- **模型病毒选择：** 须包含包膜病毒和非包膜病毒的代表性模型病毒
- **累积 LRV：** 所有步骤的 LRV 相加，须证明整体病毒清除能力足够安全（通常要求包膜病毒总 LRV ≥ 10 log₁₀）

:::

## 纯化各步骤对病毒的清除贡献与评估方法

:::answer

单克隆抗体纯化流程中，多个步骤具有病毒清除能力，但法规上只有经过验证的步骤才能被计入病毒清除声明（Viral Clearance Claim）。

### 各纯化步骤的病毒清除能力

| 纯化步骤 | 清除机制 | 可清除的病毒类型 | 是否可用于清除声明 |
|---------|---------|--------------|----------------|
| **深层过滤** | 物理截留（大颗粒）+ 静电吸附 | 大颗粒病毒（有限） | 通常贡献很小，不单独用于声明 |
| **Protein A 亲和层析** | 选择性结合 + 低 pH 洗脱 | 部分包膜病毒 | 可计入，但 LRV 通常 < 2 log₁₀，不作为主要声明步骤 |
| **低 pH 孵育** | 包膜变性 / 蛋白变性 | **包膜病毒（主要靶向）** | ✅ **专属灭活步骤，必须验证** |
| **阴离子交换层析（AEX）** | 静电吸附（流穿模式） | 包膜和非包膜病毒（带负电荷）| ✅ 可计入，通常 LRV 1～3 log₁₀ |
| **阳离子交换层析（CEX）** | 根据结合/洗脱条件 | 部分病毒 | 较小贡献，通常不单独声明 |
| **纳滤（病毒过滤）** | 物理尺寸排阻（20 nm 截留）| **包膜和非包膜病毒（≥ 20 nm）** | ✅ **专属去除步骤，必须验证** |

### AEX 清除病毒的机制

在 AEX 流穿模式的标准条件下（中性 pH，低电导）：
- 病毒颗粒（等电点通常为 4～6）在中性 pH 下**带负电荷**，与 AEX 填料（带正电荷的配基）发生静电吸附，被截留在柱上
- 目标抗体（pI > 8，在中性 pH 下带正电荷）**不与填料结合，直接流穿**收集
- 这一天然的电荷差异使 AEX 同时实现了 HCP/DNA 去除和病毒清除的双重目标

**验证要求：** AEX 步骤的病毒清除须经过独立的病毒清除验证研究，使用代表性模型病毒（包膜型如 XMuLV；非包膜型如 MVM）在 worst-case 条件下进行验证。

:::

## 低 pH 病毒灭活的主要问题：不均一性与搅拌控制

:::answer

低 pH 病毒灭活在中试规模和商业化生产规模的实施中面临一个关键工程挑战：大体积溶液的 pH 均一性问题，可导致病毒灭活不彻底，须通过搅拌工艺设计加以解决。

### pH 不均一性的根本原因

```
从 Protein A 洗脱到低 pH 病毒灭活步骤

小试规模（< 10 L）：调酸液加入后可快速混匀，pH 均一
         ↓ 规模放大
中试/生产规模（100 L ～ 1000 L 以上）：
         ↓
洗脱液体积大幅增加 → 调酸液加入速度相对缓慢
         ↓
在 pH 调节过程中，溶液内部存在 pH 梯度
         ↓
部分区域 pH 仍高于灭活有效 pH → 该区域病毒未被充分灭活
         ↓
整体计算的灭活时间不能代表所有病毒颗粒实际暴露于有效 pH 的时间
         ↓
病毒灭活不彻底风险
```

### 解决方案：搅拌辅助病毒灭活

**实施要求：** 须在低 pH 病毒灭活工艺中采用**搅拌工艺（Agitation）**，确保溶液在短时间内充分混匀。

**搅拌速度的优化原则：**

| 优化目标 | 参数要求 |
|---------|---------|
| **混匀效率（Mixing Efficiency）** | 须在设定的 pH 调节时间内实现溶液的充分均一，通常要求 t₉₅（达到 95% 混匀度）< 5 分钟 |
| **对蛋白质的剪切力最小化** | 搅拌转速须控制在不引起蛋白质变性或聚集的范围内 |

**验证方法：**
- 使用示踪剂（如 pH 敏感荧光染料）在实际生产规模容器中测定混匀时间
- 在工艺表征研究中，将"混匀时间"作为关键工艺参数（KPP）纳入评估

### 工艺放大的注意事项

| 放大规模 | 特别关注点 |
|---------|---------|
| **实验室规模 → 中试规模** | 须重新验证搅拌条件；不能直接套用小试的 pH 调节速率 |
| **中试规模 → 商业化规模** | 容器高径比（H/D）变化影响混匀效率；须进行规模特定的混匀时间研究 |
| **一次性容器（Single-use）** | 不同品牌/型号一次性容器的混合性能差异显著，须单独验证 |

:::

## 病毒过滤的原理、关键考察点与工艺优化

:::answer

病毒过滤（Virus Filtration，纳滤）是单克隆抗体纯化中最可靠的专属病毒去除步骤，通过物理尺寸排阻机制实现对包膜和非包膜病毒的高效去除，不依赖病毒的化学特性。

### 病毒过滤的工作原理

**尺寸排阻（Size Exclusion）：** 病毒过滤器（通常截留分子量相当于 20 nm 孔径）通过物理孔径将病毒颗粒截留在膜上，同时允许目标抗体（直径约 10～15 nm）透过。

**病毒大小参考：**

| 病毒类型 | 典型直径 | 过滤截留情况 |
|---------|---------|-----------|
| 小鼠细小病毒（MVM）| ~18 nm（非包膜）| 20 nm 滤膜可部分截留（边界情况，须验证）|
| PPV（猪细小病毒）| ~20～25 nm（非包膜）| 20 nm 滤膜有效截留 |
| XMuLV（逆转录病毒）| ~100 nm（包膜）| 20 nm 滤膜完全截留 |
| HIV | ~100 nm（包膜）| 完全截留 |

### 过滤操作模式选择

**死端过滤（Dead-end Filtration）—— 工业标准选择**

| 特征 | 说明 |
|-----|-----|
| 操作模式 | 料液垂直流过滤膜，无切向流动 |
| 优点 | **操作简单**；系统设计简单；无额外剪切力 |
| 缺点 | 随着膜面积的堵塞，过滤速度（Flux）逐渐衰减 |

**切向流过滤（TFF）—— 通常不推荐用于病毒过滤**

- 操作复杂；
- 切向流产生的**剪切力可能造成抗体聚集**，引入新的质量风险
- 在特殊情况下可考虑，但须进行额外的聚集体产生风险评估

### 关键考察参数与工艺优化

**① 过滤载量（Throughput Capacity）优化**

病毒过滤器价格昂贵（**单位膜面积约为 0.2 μm 无菌过滤器的 10 倍**），提高单位面积通量是降低生产成本的关键：

| 影响因素 | 对通量的影响 | 优化方向 |
|---------|-----------|---------|
| **抗体浓度** | 浓度越高，通量越低（蛋白堵膜） | 确定最佳上样浓度（通常 5～20 mg/mL，须实验确定）|
| **料液中的聚集体** | 聚集体是堵膜的主要原因 | 须在病毒过滤前进行预过滤 |
| **操作压力（TMP）** | 高压短期提高通量，但加速堵膜 | 控制在适当范围，通常 10～30 psi |
| **料液温度** | 低温增加粘度，降低通量 | 在工艺规定温度下操作 |

**② 预过滤要求（必须设置）**

> 病毒过滤通常置于纯化完成之后。尽管如此，病毒过滤前须使用 0.2 μm 或 0.1 μm 的无菌过滤器或深层过滤器进行预过滤。

预过滤的目的：
- 去除宿主细胞杂质（HCP、DNA 颗粒）
- 去除抗体聚集体（最主要的堵膜原因）
- 防止微生物污染（保证过滤液的无菌性）

**③ 衰减速度监控**

过滤流速随时间衰减是病毒过滤的固有特性，须监控：
- **过滤速度（Flux）vs 时间曲线**：评估堵膜速度
- **标准化通量（Normalized Flux）**：校正压力和面积因素
- **总载量（Total Throughput）**：确认单位膜面积可过滤的总蛋白量（g/m²）

:::

## 微生物负荷控制：生产规模的无菌保障体系

:::answer

随着生产规模放大，微生物污染（Bioburden）的风险也相应增加，须建立系统化的环境控制体系，从空气、水和容器具三个维度综合管控。

### 微生物来源与控制措施

| 微生物来源 | 控制措施 | 处理系统 |
|----------|---------|---------|
| **空气** | 洁净空调系统（HVAC）对空气进行过滤处理；A/B/C/D 级洁净区分级管理 | HEPA 过滤器（效率 ≥ 99.97%，拦截 0.3 μm 颗粒）|
| **制药用水** | 纯化水系统（PW）或注射用水系统（WFI）| 多效蒸馏或超滤/反渗透 + 持续循环保温 |
| **容器具（不可灭菌的）** | 一次性（Single-use）系统，出厂已验证无菌 | γ 射线辐照灭菌 |
| **容器具（可灭菌的）** | 高压蒸汽灭菌（121°C，15 min）或干热灭菌（250°C）| 高压灭菌锅（Autoclave）|

### 层析柱的在位消毒（CIP/SIP）

层析填料无法进行高温蒸汽灭菌，须采用化学消毒方法：

**推荐方案：** NaOH（0.5 mol/L）与层析填料接触 ≥ 15 分钟

| 参数 | 要求 |
|-----|-----|
| NaOH 浓度 | 0.5 mol/L（对大多数常见微生物有效）|
| 接触时间 | ≥ 15 分钟 |
| 适用填料 | 须确认填料对 0.5 M NaOH 的耐受性（参考供应商规格）|
| 验证内容 | 须验证清洁效果（微生物挑战试验），并确认对填料性能无显著损害 |

### 微生物负荷的过程监控

- **环境监控（EM）：** 洁净区须定期进行浮游菌、沉降菌和表面微生物计数
- **中间体微生物限度检查：** 关键中间体（如收获液）须进行微生物限度检测
- **生物负荷趋势分析：** 连续批次的微生物负荷数据须进行统计趋势分析，超过警戒限时须调查原因

:::

## 污染物与杂质的定义区别

:::answer

在生物制品质量控制体系中，"污染物"和"杂质"是两个常被混淆但具有本质区别的概念，须准确理解以便正确分类、采用合适的控制策略和准确描述申报文件。

### 定义比较

| 概念 | 官方定义 | 来源性质 | 控制策略 |
|-----|---------|---------|---------|
| **杂质（Impurities）** | 生产过程中引入的，与生产工艺和产品相关的分子变异体或原物料相关物质 | 生产工艺**预期过程**的产物 | 通过工艺优化和纯化步骤控制至规格限度以内 |
| **污染物（Contaminants）** | 带入的**非生产工艺预期**部分的外源性物质 | **非预期**、外源性引入 | 通过 GMP 控制和生产体系预防，一旦发现须废弃受影响的批次 |

### 杂质的典型分类

**产品相关杂质：**
- 聚集体、片段、电荷变体、糖基化变体等

**工艺相关杂质：**
- HCP（宿主细胞蛋白）
- 残余 DNA
- 残余 Protein A
- 培养基成分残留（如 Pluronic F-68）

### 污染物的典型分类

**生物性污染物：**
- 细菌、真菌、支原体、病毒等微生物

**化学性污染物：**
- 非预期引入的化学物质（如清洁剂残留、消毒剂残留）

**实践意义：** 杂质须在质量标准中设定可接受限度，属于正常存在于产品中的成分；而污染物一旦检出通常导致该批次产品被拒绝放行，不存在"可接受的污染物含量"的概念。

:::

## 病毒控制的完整策略框架

:::answer

生物制品病毒安全控制须遵循 ICH Q5A（病毒安全性评价）和 ICH Q5D（细胞基质来源和鉴定）的两大核心指导原则，通过多层次协同控制将病毒污染风险降至最低。

### 病毒控制的五个关键节点

**① 细胞库检测——源头控制**

细胞是生产药物的主要原材料，药典规定须建立三级细胞库（种子细胞库、主细胞库、工作细胞库）。MCB 和 WCB 须进行：
- 内源性逆转录病毒检测（针对 CHO 等细胞系固有的逆转录病毒序列）
- 外源性病毒因子检测（证明建库过程无外源病毒污染）

**② UPB 检测——生产过程监控**

未纯化收获物（Unprocessed Bulk，UPB）检测可发现生产过程中新引入的病毒污染：
- 在每批收获后对收获液进行检测
- 检测项目与 WCB/MCB 类似（外源病毒检测、支原体等）
- 相当于对生产过程进行实时病毒污染监控

**③ EOPC 检测——代次稳定性确认**

生产终末细胞（End of Production Cells，EOPC）检测：
- 对达到最高限定代次的细胞进行检定
- 证明在整个生产周期内无病毒积累或基因组不稳定性导致的内源性逆转录病毒激活

**④ 物料控制——原料来源风险管控**

- 动物源性原材料（血清、胰酶等）须有 TSE/BSE 合格证明
- 须提供病毒检测证明（特别是牛源/猪源特异性病毒：BVDV、PPV、PCV 等）
- 优先使用无动物源性或重组来源原材料，从根本上规避动物源性病毒风险

**⑤ 病毒去除和灭活工艺验证——最后防线**

须对下游纯化中的关键病毒清除步骤进行正式的病毒清除验证（Viral Clearance Study）：

| 验证步骤 | 目标病毒类型 | 必须验证的要求 |
|---------|-----------|------------|
| 低 pH 孵育 | 包膜病毒（XMuLV 代表）| Worst-case 条件下 LRV ≥ 4 log₁₀ |
| 病毒过滤（纳滤）| 包膜和非包膜病毒 | 代表性模型病毒 LRV ≥ 4 log₁₀ |
| AEX 层析 | 可选，作为额外贡献 | 非专属步骤，需谨慎声明 |

:::

## MCB 中逆转录病毒阳性的分析与处置策略

:::answer

CHO 细胞等主流哺乳动物宿主细胞系已知含有内源性逆转录病毒相关序列（Endogenous Retroviral Elements，EREs），MCB 检出逆转录病毒活性时须按照规范的分步鉴定流程进行分析，区分内源性无感染力颗粒和外源性感染性病毒，作出科学的安全性判定。

### 逆转录病毒的检测方法体系

**四种互补方法，须联合使用：**

**① 逆转录酶活性测定（RT Assay）**

- **方法：** 产品增强的逆转录酶活性测定法（PERT，Product-Enhanced Reverse Transcriptase Assay）—— 较传统 RT 活性测定灵敏度高 10,000 倍以上
- **意义：** 逆转录酶阳性提示可能有逆转录病毒存在，但不能确认是否具有感染性
- **重要注意：** 细胞中某些正常成分（如端粒酶、非逆转录病毒来源的逆转录酶）也具有逆转录酶活性，因此 RT 阳性结果须进一步通过其他方法确证

**② 透射电镜检查法（TEM）**

- **方法：** 取至少 1 × 10⁷ 个活细胞，采用超薄切片法制备样品，进行透射电子显微镜观察
- **意义：** 可**直接观察到病毒颗粒的形态和结构**，鉴定颗粒类型（A/B/C/D 型逆转录病毒颗粒的形态学特征各异），并进行颗粒数量的半定量估计
- **局限性：** 不能区分有感染性和无感染性颗粒

**③ PCR 法及其他特异性体外检测法**

| 方法 | 适用场景 |
|-----|---------|
| **逆转录病毒 PCR** | 种属特异性检测（如 CHO 细胞使用鼠逆转录病毒特异性引物）；在 RT 结果不明确或不适用时使用 |
| **免疫荧光法** | 检测病毒特异性抗原 |
| **ELISA 法** | 检测病毒特异性抗原 |
| **定量 PCR（qPCR）** | 逆转录病毒颗粒的**绝对定量**（颗粒数/mL）|

**④ 感染性试验（Infectivity Assay）**

- **方法：** 将待检细胞（上清液或细胞裂解物）接种至逆转录病毒**敏感指示细胞**，培养后检测指示细胞中是否出现病毒感染迹象
- **意义：** 这是**唯一能证明是否有感染性逆转录病毒颗粒存在的方法**
- **指示细胞选择：** 须根据待检细胞的种属来源，选择不同或多种敏感细胞（如 mink 肺细胞 Mv1Lu、XC 细胞、PG-4 细胞等）

### 各方法检测特性对比

| 方法 | 提示信息 | 能否确认感染性 | 能否定量 |
|-----|---------|-------------|--------|
| RT 活性测定 | 可能有逆转录病毒存在 | ❌ 否 | 相对活性值 |
| 透射电镜 | 证明是否有病毒颗粒 + 形态鉴定 | ❌ 否 | 半定量 |
| PCR/免疫荧光 | 证明特异性序列/抗原存在 | ❌ 否 | ✅ 定量（qPCR）|
| **感染性试验** | **证明是否有感染性颗粒** | ✅ **是** | 感染单位（TCID₅₀）|

### 结果判断与处置决策

| 检测结果组合 | 判定 | 处置措施 |
|-----------|-----|---------|
| RT 阳性 + 电镜见颗粒 + 感染性试验阴性 | 存在非感染性内源性颗粒（CHO 细胞常见）| 须进行下游工艺病毒清除验证，证明生产工艺能有效清除 |
| RT 阳性 + 电镜见颗粒 + 感染性试验阳性 | 存在**感染性逆转录病毒** | **该细胞基质不得用于生产**（须废弃，重新筛选细胞株）|
| RT 阳性 + 电镜未见颗粒 + 感染性试验阴性 | 非病毒来源的 RT 活性 | 补充 PCR 确认；进行风险评估 |

:::

## 微生物限度检查：非无菌产品的过程控制标准

:::answer

微生物限度检查（Bioburden Testing）适用于非最终灭菌的中间产品，是评估生产环境微生物控制状态的重要过程检测项目。

### 检测方法、标准与法规依据

| 项目 | 详情 |
|-----|-----|
| **检测方法** | 微生物计数法（菌落计数） |
| **放行标准** | **≤ 1 CFU / 10 mL**（该标准为常见中间体标准，具体须按产品质量标准规定） |
| **法规依据** | 《中国药典》2020 版三部通则 **1105** 非无菌产品微生物限度检查：微生物计数法 |

### 微生物计数法的操作要点

**① 薄膜过滤法（首选方法）：**
- 将规定量样品通过 0.45 μm 微孔滤膜过滤
- 滤膜分别转移到需氧菌培养基（CASE：胰酪大豆胨琼脂，TSA）和真菌培养基（SDA：沙堡弱琼脂）上培养
- 培养温度：细菌 30～35°C，培养 5 天；真菌 20～25°C，培养 5 天
- 计数各板上的菌落数

**② 倾注平板法 / 涂布平板法：**
- 适用于低黏度、低浓度样品
- 直接将样品与培养基混合或涂布在培养基表面计数

### 微生物限度与无菌检查的区别

| 比较维度 | 微生物限度检查 | 无菌检查 |
|---------|------------|---------|
| **适用对象** | 非无菌产品（中间体）| 最终产品（须达到无菌要求）|
| **控制目标** | 微生物数量 < 限度值 | 绝对无菌（不得检出任何微生物）|
| **法规依据** | 药典通则 1105 | 药典通则 1101 |
| **接受标准** | 数值限度（如 ≤ 1 CFU/10 mL）| 无菌生长 |

:::

## 无菌检查：最终产品的无菌性确认

:::answer

无菌检查（Sterility Testing）是原液和成品放行的必检项目，用于确认产品不含任何存活的微生物，是生物制品安全性的最终把关检测。

### 检测方法、标准与法规依据

| 项目 | 详情 |
|-----|-----|
| **首选方法** | **薄膜过滤法（Membrane Filtration Method）** |
| **放行标准** | **供试品应无菌生长**（即培养 14 天后，所有培养基均无微生物生长）|
| **法规依据** | 《中国药典》2020 版三部通则 **1101** 无菌检查法 |

### 薄膜过滤法的操作规范

**核心要求：**
- 通常采用**封闭式薄膜过滤器（Closed System）**，减少操作中的外源污染风险
- 滤膜孔径须 **≤ 0.45 μm**（标准孔径）
- 标准滤膜直径约 50 mm；若使用其他尺寸，须重新验证稀释液和冲洗液体积

**过滤后分别转移到两种培养基：**

| 培养基 | 目标微生物 | 培养温度 | 培养时间 |
|-------|---------|---------|---------|
| **硫乙醇酸盐流体培养基（FTM）** | 需氧菌 + **厌氧菌** | 30～35°C | ≥ 14 天 |
| **胰酪大豆胨液体培养基（TSB）** | 需氧菌 + 真菌 | 20～25°C | ≥ 14 天 |

**方法适用性（系统适用性试验 SST）：**

须使用以下六种标准菌株进行方法验证，证明方法能有效检出目标微生物：

| 阳性对照菌株 | 代表性 |
|-----------|------|
| 金黄色葡萄球菌（*Staphylococcus aureus*）| 革兰阳性需氧菌 |
| 铜绿假单胞菌（*Pseudomonas aeruginosa*）| 革兰阴性需氧菌 |
| 枯草芽孢杆菌（*Bacillus subtilis*）| 芽孢杆菌 |
| 生孢梭菌（*Clostridium sporogenes*）| 厌氧菌 |
| 白色念珠菌（*Candida albicans*）| 真菌（酵母） |
| 黑曲霉（*Aspergillus brasiliensis*）| 真菌（霉菌） |

### 结果判定

| 培养结果 | 判定 |
|---------|-----|
| 所有培养基 14 天后均澄清（无微生物生长）| ✅ **无菌，符合规定** |
| 任何一个培养基出现浑浊 | 须进一步确认（转种新鲜培养基复试）|
| 确认为微生物生长 | ❌ **不符合规定，该批次不得放行** |

:::

## 分枝杆菌检查：培养法操作规范与结果判定

:::answer

分枝杆菌（Mycobacteria）检查是细胞库检定的必要项目之一，因为分枝杆菌生长极为缓慢（代时可长达 24 小时），须专用培养基和较长的培养周期才能检出。

### 检测流程

**① 样品制备**

- 取细胞裂解物（须充分裂解，释放胞内分枝杆菌）

**② 接种至适宜固体培养基**

常用培养基：

| 培养基 | 特点 |
|-------|-----|
| **罗氏培养基（Löwenstein-Jensen）** | 蛋类为基础的固体培养基，传统标准方法 |
| **Middlebrook 7H10 培养基** | 化学成分限定，生长较罗氏培养基快 |

**③ 接种量和重复数**

- 每个培养基接种 **1 mL**
- 每种培养基做 **3 个重复**
- 同时设置**阳性对照**：不高于 100 CFU 的草分枝杆菌（*Mycobacterium phlei*）菌液

**④ 培养条件与观察**

| 参数 | 要求 |
|-----|-----|
| 培养温度 | **37°C** |
| 培养时间 | **56 天**（分枝杆菌生长极缓慢，须足够长的观察期） |
| 阳性对照 | 须在培养结束时有菌生长（验证培养基有效性） |

### 结果判定

| 观察结果 | 判定 |
|---------|-----|
| 阳性对照有菌生长 + 供试品培养基**无分枝杆菌生长** | ✅ **合格** |
| 阳性对照有菌生长 + 供试品培养基**有可疑生长** | ❌ **不合格**，须启动调查 |
| 阳性对照无菌生长 | 试验无效，须重新进行（培养基或操作问题）|

:::

## 支原体检查：双法并行体系与操作规范

:::answer

支原体（Mycoplasma）检查是细胞库和生物制品检定中最重要的安全性检查项目之一，因为支原体污染隐蔽性强（无细胞壁，普通光学显微镜不可见），须采用专项检测方法。

### 法规要求的双法并行

对于以下检测对象，须**同时进行培养法和指示细胞培养法（DNA 染色法）**：
- 主细胞库（MCB）
- 工作细胞库（WCB）
- 病毒种子批
- 对照细胞
- 临床治疗用细胞

对于病毒类疫苗的病毒收获液和原液，采用**培养法**检查。

### 方法一：培养法（28 天法）

**培养基选择：**
- 支原体**液体**培养基（变色培养基，pH 变化指示生长）
- 支原体**半流体**培养基 / 支原体琼脂培养基（菌落观察）

**操作步骤：**

```
取每支装量 10 mL 的液体培养基各 4 支 + 半流体培养基各 2 支
          ↓
每支接种供试品 0.5～1.0 mL
          ↓
36°C ± 1°C 培养 21 天
          ↓
第 7 天：从 4 支液体培养基中取 2 支进行次代培养
    → 各转种至液体培养基各 2 支 + 半流体培养基各 2 支
    → 继续培养 21 天，每 3 天观察一次
          ↓
培养结束：观察颜色变化（培养基变色提示支原体代谢活动）
```

**结果判定：**

| 培养结果 | 判定 | 后续操作 |
|---------|-----|---------|
| 所有培养基**无**支原体生长（不变色）| ✅ **合格** | — |
| 疑有支原体生长（变色） | 须复试 | 取**加倍量**供试品重复试验 |
| 复试**无**生长 | ✅ **合格** | — |
| 复试**有**生长 | ❌ **不合格** | 废弃该批次，溯源污染来源 |

### 方法二：指示细胞培养法（DNA 荧光染色法）

**原理：**
- 将供试品接种于无污染的**指示细胞**（如 Vero 细胞）中培养 3～5 天
- 用 Hoechst 33258 或 DAPI 等特异性**荧光染料**染色
- 支原体若存在，会附着在宿主细胞表面/胞内，其 DNA 被荧光染料染色，在荧光显微镜下可见分布于细胞周围的点状或丝状荧光

**结果判断：**

| 荧光观察结果 | 判定 |
|-----------|-----|
| 指示细胞表面**无**支原体 DNA 着色 | ✅ **阴性，合格** |
| 指示细胞表面**可见**点状/丝状荧光（支原体 DNA 信号）| ❌ **阳性，不合格**（须复试确认）|

:::

## 病毒因子检查：细胞形态观察与血吸附试验

:::answer

细胞形态观察结合血吸附试验是外源病毒因子检查的基础方法之一，通过持续观察细胞的形态变化和病毒感染的标志性反应来排除外源病毒污染。

### 试验设计

**接种与培养：**
- 接种至少 **6 个**细胞培养瓶或培养皿（保证统计意义）
- 细胞长成单层或达到一定数量后换**维持液**（低血清或无血清维持培养基）
- 持续培养 **2 周（14 天）**
- 逐日镜检细胞，记录形态变化

**观察指标：**
- 细胞形态是否保持正常特征
- 是否出现细胞病变效应（CPE：Cell Cytopathic Effect）：如细胞变圆、脱落、融合（合胞体形成）、聚集、出现包涵体等

### 血吸附试验（Hemadsorption Test）

**时机：** 在培养 14 天后，取 1/3 的细胞培养瓶或培养皿进行血吸附试验。

**方法原理：** 某些病毒（如副黏病毒、正黏病毒等）感染细胞后，在细胞表面表达病毒血凝素（Hemagglutinin），可与红细胞表面唾液酸受体结合，使红细胞吸附在感染细胞表面——即血吸附现象（Hemadsorption）。

**操作步骤：**

```
加入 0.2%～0.5% 豚鼠红细胞和鸡红细胞混合悬液
          ↓
一半样品：2～8°C 孵育 30 分钟（低温，适合血凝素结合）
一半样品：20～25°C 孵育 30 分钟（室温，适合不同类型病毒）
          ↓
各自进行镜检，观察红细胞是否吸附在细胞表面
```

**结果标准：**
- **阴性（合格）：** 不同温度条件下均无红细胞吸附现象
- **阳性（不合格）：** 任一温度条件下出现红细胞聚集吸附于细胞表面

:::

## 病毒因子检查：多指示细胞接种培养法检测外源病毒因子

:::answer

体外多指示细胞接种培养法（In vitro Indicator Cell Culture Method）是外源病毒因子检查的核心方法，通过将待检样品接种到多种不同来源的指示细胞系，利用病毒对特定细胞的感染性进行外源病毒的广谱筛查。

### 检测设计的"广谱性"原则

任何单一细胞系对所有病毒的敏感性都有限，须使用多种不同来源的指示细胞，最大化检测的病毒覆盖范围：

**法规要求的三类指示细胞（至少须包含）：**

| 指示细胞类型 | 代表性细胞系 | 检测目标病毒 |
|-----------|-----------|-----------|
| **猴源细胞** | Vero（非洲绿猴肾）/ BSC-1 | 猿猴来源病毒、SV40 等 |
| **人二倍体细胞** | MRC-5 / WI-38 | 人源病毒（CMV、腺病毒等） |
| **同种属、同组织类型细胞** | 与生产细胞来源相同（如 CHO 来源细胞）| 检测亲缘性病毒（宿主细胞敏感的特定病毒）|

### 检测流程

**① 样品接种**

```
制备待检细胞的活细胞或细胞裂解物
          ↓
每种指示细胞接种 ≥ 10⁷ 个活细胞或相当量裂解物
接种量须占维持液 ≥ 1/4（确保足够的感染剂量）
每种指示细胞至少接种 2 瓶（1 瓶用于第 7 天传代，1 瓶持续培养）
```

**② 培养与盲传**

```
培养 7 天
    ↓ 第 7 天
取各指示细胞 1 瓶，收获上清或裂解物
接种至新鲜制备的相应指示细胞（盲传 1 代）
          ↓
与初次接种的另 1 瓶继续培养至第 14 天（共 14 天）
          ↓
观察期末，进行血吸附试验和红细胞凝集试验
```

**③ 血吸附试验（终期检测）**

参照前节所述方法，在 2～8°C 和 20～25°C 两个温度条件下进行。

**④ 红细胞凝集试验（Hemagglutination Test）**

- 取细胞培养**上清液**（含有可能分泌的病毒颗粒）
- 从原倍起进行倍比稀释
- 加入混合红细胞（豚鼠 + 鸡红细胞），2～8°C 孵育 30 分钟后，20～25°C 孵育 30 分钟
- 观察是否出现红细胞凝集（类似 HAI 试验原理）

### 结果判定标准

| 检测结果 | 判定 |
|---------|-----|
| 所有指示细胞均**无 CPE**（细胞病变效应） | ✅ 合格 |
| 血吸附试验：两个温度条件均**阴性** | ✅ 合格 |
| 红细胞凝集试验：**阴性** | ✅ 合格 |
| 任何指示细胞出现 CPE 或凝集阳性 | ❌ 不合格（须启动调查，排除是否为待检细胞裂解物干扰）|

### CMV 的特殊检测要求

> 若已知待检细胞可支持人或猴巨细胞病毒（Cytomegalovirus，CMV）的生长，则须在接种人二倍体细胞后**至少观察 28 天**（而非标准的 14 天），须无 CPE，且血吸附和红细胞凝集试验均须为阴性。

**原因：** CMV 复制周期长，CPE 出现较晚，标准 14 天观察期可能无法检出低滴度的 CMV 污染。

### 阳性对照的设置要求

试验须设立完整的阳性对照体系，确认检测系统的有效性：

| 阳性对照类型 | 目的 |
|-----------|-----|
| **CPE 阳性对照病毒** | 确认指示细胞可产生可观察的细胞病变效应 |
| **血吸附阳性对照** | 确认血吸附试验系统可检出阳性结果（如副流感病毒感染细胞）|
| **血凝阳性对照** | 确认红细胞凝集试验系统有效（如流感病毒） |
