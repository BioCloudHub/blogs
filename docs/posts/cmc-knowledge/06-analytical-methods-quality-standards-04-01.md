## DoE 中分辨率（Resolution）的含义与实验设计选择

:::answer

分辨率（Resolution）是部分析因实验设计（Fractional Factorial Design）中描述效应混杂程度的核心指标，分辨率越高，效应混杂越少，实验结果的解释能力越强。在 CMC 工艺开发的风险筛选和工艺表征（PC）阶段，理解分辨率对于制定高效的 DoE 方案至关重要。

### 分辨率的定义与混杂关系

| 分辨率（Roman 数字）         | 混杂程度                                               | 可识别的效应                                       | 典型应用场景                                                    |
| ---------------------------- | ------------------------------------------------------ | -------------------------------------------------- | --------------------------------------------------------------- |
| **Ⅲ（Resolution III）**      | 主效应与二阶交互作用混杂                               | 可鉴定主效应；无法区分主效应与二阶交互作用         | 参数初筛（Screening），因子数量多（8～15 个），快速缩小候选范围 |
| **Ⅳ（Resolution IV）**       | 二阶交互作用之间相互混杂，但主效应与二阶交互作用可分离 | 可分辨主效应和二阶交互作用；二阶交互作用间相互混淆 | 筛选关键因子，初步评估二阶交互效应的可能性                      |
| **Ⅴ（Resolution V）**        | 主效应和二阶交互作用均可单独估计，三阶交互作用存在混杂 | 完整估计主效应和所有二阶交互作用                   | 工艺表征（PC）研究；较少因子的深度分析                          |
| **全析因（Full Factorial）** | 无混杂                                                 | 所有主效应和交互作用均可独立估计                   | 因子数量少（≤ 5 个）时使用；最高解析度                          |

### 分辨率选择的实践原则

**筛选实验（Screening Phase）：** 通常选择 Resolution III 或 IV，以最少的实验次数从 10～20 个因子中识别出关键的 3～5 个 CPP 候选因子。

**工艺表征实验（PC Phase）：** 须采用 Resolution V 或全析因设计，确保主效应和二阶交互作用均能被独立估计，支持设计空间（Design Space）的建立。

**混杂模式的重要性：** 在报告 DoE 结果时，须明确声明实验的分辨率和混杂模式，以便审评者正确解读结果的局限性。例如，Resolution III 的筛选实验结论不能用于声明某因子"对 CQA 无影响"，因为其影响可能被其他混杂效应掩盖。

## 质量标准制订的原则与框架（ICH Q6B）

:::answer

质量标准（Specifications）是生物技术产品上市许可的核心文件，其制订须遵循科学性、合理性和与产品开发数据一致性的基本原则，以 ICH Q6B 为主要指导原则。

### 质量标准的官方定义

> **质量标准**是一个包括检测、参照分析方法和验收标准的列表，验收标准以限度值、范围或描述检测项目的其他标准予以表示。

质量标准的核心功能是确保原液（Drug Substance，DS）和成品（Drug Product，DP）的质量和批间一致性，而非建立产品的全部特征描述。

### 质量标准与整体控制策略的关系

质量标准是总控制策略（Overall Control Strategy）的组成部分之一，须与其他控制维度协同：

```
整体控制策略
├── 全面的产品特性分析（开发阶段）← 为质量标准提供科学依据
├── GMP 生产规范
├── 经验证的生产工艺（工艺控制）
├── 原材料检测（物料控制）
├── 过程控制检测（IPC）
├── 质量标准（放行检测）← 本节重点
└── 稳定性试验（货架期保证）
```

### 质量标准制订的五大内容维度

ICH Q6B 规定，质量标准须涵盖以下维度（各维度详见后续专项知识点）：

| 维度                                   | 核心内容                                                         |
| -------------------------------------- | ---------------------------------------------------------------- |
| **① 质量特性分析（Characterization）** | 理化结构特征、生物学活性、免疫化学性质、纯度和杂质的全面表征     |
| **② 物理化学性质**                     | 一级结构、高级结构、糖基化等翻译后修饰                           |
| **③ 生物活性**                         | 效价测定方法；与临床机制相关的体外/体内活性测定                  |
| **④ 免疫化学性质**                     | 抗原结合亲和力、特异性、交叉反应性（主要针对抗体类产品）         |
| **⑤ 纯度、杂质、含量**                 | 多方法联合纯度测定；产品相关物质、产品相关杂质、工艺杂质分类管理 |

### 验收标准制订的数据依据

验收标准的建立须基于：

- 临床前和/或临床研究用批次的分析数据
- 用于批间一致性研究的批次数据（通常至少 10～20 批）
- 稳定性研究数据（须覆盖整个货架期）
- 相关开发阶段的历史数据

:::

## 质量特性分析：质量标准建立的必要前提

:::answer

质量特性分析（Characterization）是制定质量标准验收标准的科学基础，须在产品开发过程中系统开展，并在工艺发生重大变更时重新进行。

### 质量特性分析的触发时机

| 触发场景               | 要求                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------ |
| **产品开发过程中**     | 须持续积累各批次的全面表征数据                                                       |
| **工艺发生明显变更时** | 须重新进行全面质量特性分析，评估变更对产品属性的影响                                 |
| **申报时**             | 须将产品与内部参比物质（Reference Standard）进行比较；如有可能，与对应的天然成分比较 |

### 参比物质（Reference Standard）的建立要求

| 类型                                         | 定义                           | 建立要求                                                                 |
| -------------------------------------------- | ------------------------------ | ------------------------------------------------------------------------ |
| **一级参考品（Primary Reference Standard）** | 代表产品全面质量特性的基准样品 | 须采用能代表生产和临床研究用样品的代表性批次制备；经全面质量特性分析表征 |
| **工作参考品（Working Reference Standard）** | 用于日常批次放行检验           | 须用一级参考品标化；当批次耗尽时须重新标化，确保跨批次一致性             |
| **专用参考品**                               | 针对特定检测项目               | 对产品相关物质、产品相关杂质和工艺相关杂质，有时须分别建立专用参考品     |

### 表征技术的持续更新原则

> 新的分析技术在不断发展，现有分析方法在不断改进，应合理采用这些方法。

实践含义：当更先进的技术（如 HDX-MS、NMR、原子力显微镜等）能提供更多或更准确的产品结构信息时，须评估纳入表征体系的必要性，并在 BLA 申报时体现最新分析技术的应用。

:::

## 物理化学性质：从一级结构到高级结构的全面表征

:::answer

物理化学性质的表征是单克隆抗体结构确证（Structural Characterization）的核心，须从一级结构到高级结构逐层系统建立分析数据包。

### 表征层次体系

**① 一级结构（Primary Structure）**

| 表征内容              | 分析方法                        | 法规要求                                                   |
| --------------------- | ------------------------------- | ---------------------------------------------------------- |
| 氨基酸序列确认        | 肽图法（LC-MS/MS）+ Edman 测序  | 须证明序列与设计序列完全一致                               |
| 翻译后修饰（PTM）定位 | 肽图 LC-MS/MS                   | N 糖位点、二硫键、脱酰胺化位点等须全部确认                 |
| 末端序列分析          | N 末端测序；C 末端 Lys 比例检测 | 确认加工异质性的来源和水平                                 |
| 二硫键配对            | 非还原肽图 + MS/MS              | 须确认所有 16 个（IgG1/4）或 18 个（IgG2）二硫键的正确配对 |

**② 高级结构（Higher Order Structure，HOS）**

| 表征内容          | 分析方法                                 | 可获得的信息                                       |
| ----------------- | ---------------------------------------- | -------------------------------------------------- |
| 二级结构          | **圆二色谱（CD，远紫外区 190～230 nm）** | α 螺旋、β 折叠、转角和不规则卷曲的比例             |
| 三级结构          | **圆二色谱（CD，近紫外区 250～350 nm）** | 色氨酸、苯丙氨酸、酪氨酸侧链排布；二硫键微环境     |
| 热稳定性          | **差示扫描量热法（DSC）**                | 蛋白质熔解温度（Tm）；展开焓；结构域稳定性         |
| 动态构象          | **氢氘交换质谱（HDX-MS）**               | 溶液状态下各结构域的动态柔性；构象可比性评估       |
| 固体/溶液状态结构 | **傅里叶转换红外光谱（FTIR）**           | 固体制剂中的二级结构；浓缩样品分析                 |
| 精细三维结构      | **X 射线晶体学 / 冷冻电镜（cryo-EM）**   | 原子分辨率结构（主要用于研究，非常规批放行）       |
| 溶液状态结构      | **核磁共振（NMR）**                      | 溶液中特定区域的构象；适用于较小蛋白质（< 50 kDa） |

### 异质性的科学处理原则

生物技术产品具有固有的结构异质性，须区分以下两类情况：

| 类型                                           | 定义                                                              | 处理方式                             |
| ---------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------ |
| **产品相关物质（Product-related Substances）** | 来源于预期翻译后修饰或生产/储存过程形成的变体，性质与预期产品可比 | 视为产品的组成部分，须确保批间一致性 |
| **产品相关杂质（Product-related Impurities）** | 活性、有效性或安全性与预期产品不可比的变体                        | 须作为杂质单独控制，制订认可标准     |

:::

## 生物活性表征：效价测定方法的选择与要求

:::answer

生物学活性（Biological Activity）评价是与产品结构确证同等重要的步骤，是生物技术药物质量标准的核心指标，须采用能反映产品作用机制（MoA）的有效方法进行测定。

### 生物活性与含量的区别

| 概念                 | 测量维度                   | 单位                                         | 方法类型                   |
| -------------------- | -------------------------- | -------------------------------------------- | -------------------------- |
| **效价（Potency）**  | 产品发挥特定生物效应的能力 | 生物活性单位（U），或与参比品的相对效力（%） | 生物学测定（细胞、动物等） |
| **含量（Quantity）** | 蛋白质物质的量             | 质量（mg/mL）                                | 理化方法（UV280、BCA 等）  |

**重要原则：** 含量检测不能替代效价测定——高含量样品不必然具有高生物活性（如氧化或折叠异常的蛋白质）。

### 生物活性测定方法的三大类型

**① 基于动物的生物学活性检测（In vivo Methods）**

- 测定生物机体对产品产生的整体生物反应（如体重增长、肿瘤缩小、免疫应答）
- 通量低，变异大（CV 可达 50%）
- 监管趋势：尽可能用体外方法替代（3R 原则）

**② 基于细胞培养的生物学活性检测（Cell-based Methods）**

- 在细胞水平测定产品的生化和生理效应（细胞增殖、抑制、ADCC 等）
- 直接反映 MoA，监管机构优先接受
- 典型应用：ADCC 活性（FcγRⅢa 结合细胞系）、CDC 活性、细胞增殖抑制

**③ 生化方法（Biochemical Methods）**

- 利用酶反应速率或免疫相互作用（如配体/受体结合试验）测定生物活性
- 通量高，变异小（CV < 20%）
- 局限：不能反映全部生物活性，通常作为主要效价方法的补充

### 效价测定的相对效力计算

生物活性测定通常以**相对效力（Relative Potency，RP）** 表示，须以参比标准品为对照：

- 样品和参比品须具有平行的量效曲线（Parallelism）才能进行相对效力计算
- 平行性验证须作为方法适用性（System Suitability）的一部分在每次运行中确认

:::

## 免疫化学性质：抗体类产品的特有表征要求

:::answer

对于抗体类产品（单抗、双抗、ADC 等），免疫学性质的全面鉴定是结构确证的必要组成部分，须从结合特异性、亲和力到表位分析系统开展。

### 免疫化学性质表征的核心内容

**① 抗原结合特异性（Binding Specificity）**

| 表征内容                       | 分析方法                   | 目的                                     |
| ------------------------------ | -------------------------- | ---------------------------------------- |
| 与纯化靶抗原的结合试验         | ELISA、SPR（Biacore）、BLI | 确认抗体可特异性识别目标抗原             |
| 抗体亲和力（Affinity，Ka/Kd）  | SPR、BLI                   | 定量描述单价结合强度                     |
| 抗体亲合力（Avidity）          | ELISA、细胞结合试验        | 描述双价抗体与细胞表面抗原的整体结合强度 |
| 交叉反应性（Cross-reactivity） | 与相关抗原的结合测定       | 评估非靶向结合，支持安全性评估           |

**② 抗原表位分析（Epitope Mapping）**

| 方法                   | 原理                                   | 信息                                |
| ---------------------- | -------------------------------------- | ----------------------------------- |
| 肽段扫描 ELISA         | 覆盖抗原全序列的重叠肽段与抗体结合检测 | 线性表位定位                        |
| HDX-MS                 | 与抗原结合前后的氢氘交换差异           | 构象表位定位                        |
| X 射线晶体学 / cryo-EM | 抗原-抗体复合物结构解析                | 精确到原子分辨率的表位-抗原界面信息 |

### 免疫化学性质作为放行检验标准的要求

若将免疫化学方法（如 ELISA、Western Blot）用于产品的批放行检验，须：

- 提供所用检测抗体（Detection Antibody）的全部相关材料（来源、特异性、验证数据）
- 证明检测抗体与目标产品的结合具有高度特异性，不与制品中其他成分发生非特异性反应
- 建立该抗体的批次一致性和稳定性管理体系

:::

## 纯度定义、产品相关物质与杂质的分类管理原则

:::answer

生物技术产品的"纯度"概念比小分子化学药品更为复杂，须从多维度理解，并建立基于风险的分类管理体系。

### 纯度测定的挑战

- **绝对纯度测定困难：** 不同分析方法对纯度的敏感性不同，无法通过单一方法给出绝对纯度值
- **历史方法局限：** 以往用比活（Units/mg）表示相对纯度，但结果同样高度依赖于所用活性测定方法
- **最佳实践：** 联合多种互补原理的方法测定纯度（如 SEC + CE-SDS + CEX）

### 产品相关变体的三类分类

| 类别                                           | 定义                                           | 来源                                                  | 处理方式                             |
| ---------------------------------------------- | ---------------------------------------------- | ----------------------------------------------------- | ------------------------------------ |
| **预期产品（Intended Product）**               | 设计的目标分子                                 | —                                                     | 质量标准的核心                       |
| **产品相关物质（Product-related Substances）** | 活性、有效性和安全性与预期产品可比的变体       | 翻译后修饰（糖型变体、电荷变体等）或生产/储存过程形成 | **视为产品组成部分**；控制批间一致性 |
| **产品相关杂质（Product-related Impurities）** | 活性、有效性或安全性与预期产品**不可比**的变体 | 聚集体（高免疫原性）、降解片段等                      | **视为杂质**；须单独设立限度控制     |

### 产品相关物质的认定标准

产品变体被认定为"产品相关物质"（而非杂质）须满足：

1. 其物理化学性质与预期产品可比（结构类似）
2. 其生物学活性、有效性和安全性（包括免疫原性）与预期产品可比
3. 在临床前和临床开发中使用的批次中一致存在

**实践意义：** 若工艺变更导致异质性图谱发生变化（某类变体的比例显著改变），须重新评估这些改变的影响，可能需要开展可比性研究，甚至非临床/临床桥接研究。

### 纯度方法的选择原则

- 对于批次放行检验，须选用一套适宜的纯度测定方法，并论证其合理性
- 不同方法检测的杂质类型不同，须确保组合方法覆盖所有主要杂质来源
- 须在质量标准中明确产品相关物质的单独和/或合计认可标准

:::

## 含量测定与高级结构分析方法

:::answer

抗体含量（Protein Quantity）测定和高级结构（HOS）分析是质量标准中物理化学性质部分的两个互补维度——含量测定确保剂量准确性，高级结构分析确保折叠正确性。

### 蛋白含量测定方法

| 方法                     | 原理                                                                   | 特点                                                             |
| ------------------------ | ---------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **UV280 吸光度法**       | 蛋白质在 280 nm 处的特征性紫外吸收（主要来源：Trp、Tyr、Phe 和二硫键） | 快速、无损；须已知消光系数（ε₂₈₀）；受样品浊度影响               |
| **氨基酸分析（AAA）**    | 酸水解蛋白质后，各氨基酸经衍生化定量                                   | **含量绝对值的金标准**；用于标化 ε₂₈₀ 和参考品；操作复杂         |
| **BCA 法 / Bradford 法** | 总蛋白与试剂的显色反应                                                 | 非特异性（检测所有蛋白）；受赋形剂干扰；不适用于纯品含量精确测定 |

### 高级结构分析核心方法

**圆二色谱（Circular Dichroism，CD）— 最常用的 HOS 分析工具**

| 检测区域        | 波长范围    | 获得信息                                                                                | 典型应用                                         |
| --------------- | ----------- | --------------------------------------------------------------------------------------- | ------------------------------------------------ |
| **远紫外区 CD** | 190～230 nm | **二级结构**：α 螺旋（~208, ~222 nm）、β 折叠（~218 nm）比例                            | 批次一致性；工艺变更可比性；制剂稳定性           |
| **近紫外区 CD** | 250～350 nm | **三级结构**：芳香族氨基酸侧链（Trp ~280 nm，Phe ~262 nm，Tyr ~275 nm）和二硫键的微环境 | 更敏感的结构变化检测；热应激或储存导致的构象变化 |

**其他高级结构方法的应用场景：**

| 方法                       | 主要应用                                                          |
| -------------------------- | ----------------------------------------------------------------- |
| **差示扫描量热法（DSC）**  | 测定 Tm（热融点），评估蛋白热稳定性；比较工艺变更前后的构象稳定性 |
| **氢氘交换质谱（HDX-MS）** | 高灵敏度检测溶液状态下构象可比性；识别局部结构变化                |
| **FTIR**                   | 固体制剂中二级结构分析；浓缩蛋白溶液分析                          |

:::

## 分析方法的参比标准品与验证要求（ICH Q6B）

:::answer

参比标准品（Reference Standards）和分析方法验证是质量标准科学性的双重支柱，两者缺一不可，共同保证检测结果的准确性和可靠性。

### 参比标准品的建立体系

**对于新分子实体（New Molecular Entity，NME）：**

由于申报时通常无法获得国际标准品（International Standard）或国家标准品，须建立内部参比标准品体系：

```
内部参比标准品体系
├── 一级参考品（Primary Reference Standard）
│     - 用代表性批次制备（须已用于临床研究）
│     - 经全面质量特性分析表征
│     - 如能获得国际/国家标准品，须用其标化
│
└── 工作参考品（Working Reference Standard）
      - 用一级参考品标化
      - 用于日常批次检验
      - 批次耗尽时须重新制备并重新标化
```

**参考品的配套资料要求（申报时须提供）：**

- 制造和/或纯化方法
- 质量特性分析数据
- 储存条件和稳定性保证方案
- 制剂处方（含稳定化赋形剂）

### 分析方法验证的法规依据

> 申报者在向管理部门申报资料时，须按 ICH 指导原则"分析方法的验证：定义与命名"和"分析方法的验证：方法学"的内容，对质量标准中采用的分析方法进行验证。

**关键原则：** 生物技术产品的理化分析方法验证可参照化学药品验证原则（ICH Q2(R1)），但须结合生物制品的特点综合考量；生物学测定方法的验证则须遵循生物制品专用指导原则。

:::

## 蛋白糖化的分析方法：硼酸亲和色谱与 LC-MS

:::answer

蛋白糖化（Glycation）是赖氨酸残基氨基与还原糖（主要是培养基中的葡萄糖）发生非酶促 Maillard 反应的产物，是单克隆抗体的重要酸性电荷变体来源，须纳入产品表征和质量监控体系。

### 糖化的化学本质

```
赖氨酸 Lys-NH₂ + 葡萄糖 → Amadori 产物（果糖赖氨酸）
                             ↓
             (+162 Da 分子量增加 / 赖氨酸正电荷被中和)
             ↓
         pI 降低 → 酸性电荷变体（在 CEX-HPLC 中先洗脱）
```

### 方法一：硼酸亲和色谱法（Boronate Affinity Chromatography）

**分离原理：**

- 在碱性 pH 条件下，硼酸形成四面体阴离子，与糖化氨基酸上的 **1,2-顺式二醇（cis-diol）** 之间发生高度特异性且可逆的酯化反应
- 非糖化 mAb → 不与柱结合 → 在流动相中洗脱（流穿）
- 糖化 mAb → 与硼酸柱特异性结合 → 用竞争性洗脱液（山梨醇阶梯梯度）洗脱

**方法特点：**

- 选择性强，专一检测糖化修饰
- 可直接定量糖化比例
- 操作相对简便，适合常规监控

### 方法二：LC-MS 分析（定位与定量）

LC-MS 可从两个维度分析糖化：

**（1）整体分子水平分析（Intact Mass）：**

- 每个糖化位点使分子量增加 **+162 Da**（一分子己糖）
- 通过完整抗体 LC-MS，可确定糖化位点的数量（0、1、2... 个位点）
- 适用于糖化水平的初步筛查

**（2）肽段水平分析（Peptide Mapping / PTM Analysis）：**

- 通过还原/烷基化后酶切（胰酶或 Lys-C）获得肽段
- LC-MS/MS 精确定位发生糖化的具体氨基酸残基（赖氨酸位置）
- 评估该位点的糖化是否位于功能区域（CDR、FcRn 结合区等），判断是否影响生物学活性

**糖化控制的关键策略：** 降低培养基中葡萄糖浓度（将葡萄糖维持在低浓度范围，如 1～5 mM），是控制糖化水平最有效的上游手段。

:::

## 二硫键的表征方法与 IgG 亚型差异

:::answer

二硫键的数量和正确配对是 IgG 抗体的关键质量属性（CQA），错误配对（二硫键错配）会导致蛋白质折叠异常、生物活性丧失，甚至诱发免疫反应。

### 不同 IgG 亚型的二硫键数量

| IgG 亚型                 | 链内二硫键（Intrachain） | 链间二硫键（Interchain）  | 总二硫键数量                |
| ------------------------ | ------------------------ | ------------------------- | --------------------------- |
| **IgG1**                 | 12 个                    | 4 个（2 重-轻 + 2 重-重） | **16 个**                   |
| **IgG4**                 | 12 个                    | 4 个（同 IgG1）           | **16 个**                   |
| **IgG2**                 | 12 个                    | 6 个（2 重-轻 + 4 重-重） | **18 个**                   |
| **依那西普（融合蛋白）** | —                        | —                         | **29 个**（含多种错配形式） |

### 二硫键表征的两大分析目标

1. **验证正确的二硫键配对**（主要结构）
2. **识别并量化二硫键错配形式**（变体结构）

### 二硫键分析的主要方法

**方法一：非还原肽图 + 质量分析**

```
蛋白质（不还原）→ 酶切（Lys-C 或胰酶）→ LC-MS 分析
                                          ↓
                         含二硫键的肽段（质量为两个肽段之和 - 2Da）
                         vs 游离巯基肽段
                                          ↓
                         确定二硫键连接的肽段组合
```

**方法二：MS/MS 二级质谱碎片分析**

- 对含二硫键的肽段进行碰撞诱导解离（CID）或电子转移解离（ETD）
- 通过碎片离子的质量确认二硫键连接的具体氨基酸残基（定位到单个 Cys）

**方法三：还原与非还原对比分析**

- 非还原条件（保留二硫键）vs 还原条件（打断所有二硫键）的酶切质量图谱对比
- 通过分子量差异推断二硫键的连接模式

### 二硫键表征在法规申报中的要求

- 须在 DS 表征部分提供完整的二硫键图谱
- 须证明生产工艺能稳定产生正确的二硫键配对（批间一致性）
- 工艺变更后须重新验证二硫键结构的完整性

:::

## 分析方法验证概述：目的、适用范围与生物制品特殊考量

:::answer

分析方法验证（Analytical Method Validation）是将分析方法从"可用"变为"合规可用"的关键步骤，是质量标准建立的必要前提。

### 方法验证的核心目的

> 质控分析方法验证是证明采用的方法适合于相应检测要求，具有相当的准确性和可靠性，进而可以达到控制产品质量的目的。

**关键原则：只有经过验证的分析方法才能用于控制产品质量。**

### 须进行验证的分析项目

| 检测类别                            | 验证必要性 |
| ----------------------------------- | ---------- |
| **鉴别试验**                        | 必须验证   |
| **杂质检查（限量/定量）**           | 必须验证   |
| **原液或制剂中有效成分含量测定**    | 必须验证   |
| **生物活性测定（效价）**            | 必须验证   |
| **其他质控方法（如 pH、渗透压等）** | 必要时验证 |

### 生物制品方法验证的特殊考量

**相对于化学药品的差异：**

| 方面                 | 化学药品                                     | 生物制品                                                      |
| -------------------- | -------------------------------------------- | ------------------------------------------------------------- |
| **方法变异性**       | 通常 CV < 5%                                 | 理化法 CV < 20%；生物学法 CV 可达 30%～50%                    |
| **标准接受程度**     | 严格统一标准                                 | **判断标准可适当灵活**，以能有效控制产品质量为基本标准        |
| **参考依据**         | 主要参照 ICH Q2(R1)                          | 理化法参照 ICH Q2(R1)；生物学测定参照各国生物制品验证指导原则 |
| **基准文件（国内）** | 《化学药物质量控制分析方法验证技术指导原则》 | 《生物制品质量控制分析方法验证技术审评一般原则》              |

### 方法验证与产品注册的关系

若未经必要的质控分析方法验证，或拟定方法难以控制产品质量，监管机构将无法对申报品种的质量可控性作出肯定评价，直接影响产品注册申请的审评结果。

:::

## 生物学测定常用方法的类型与技术特点

:::answer

生物学测定（Biological Assay）是生物制品区别于化学药品的核心分析手段，须根据产品特性选择能最好反映产品生物学特性的一种或多种测定方法。

### 生物学测定的基本原则

- **单一方法的局限性：** 一种测定方法仅能反映制品某一方面的特性，且方法变异通常较大
- **多方法联用的必要性：** 为更好控制产品质量，必要时须同时采用多种方法进行测定，形成互补的测定体系

### 常用生物学测定方法分类

**① 酶反应试验（Enzymatic Assays）**

| 特征         | 说明                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| **原理**     | 体外检测产品促进酶分子活化的能力，或产品本身的酶活性，通过底物的化学变化（颜色、荧光、发光）定量 |
| **主要用途** | 酶、辅酶、激酶、激活剂、抑制剂等的活性测定                                                       |
| **精密度**   | 方法变异相对较小（CV < 20%），结果比较准确                                                       |
| **典型案例** | 溶圈法（重组链激酶溶血活性）；底物水解法（脂酶、蛋白酶活性）                                     |

**② 细胞测定试验（Cell-based Assays）**

| 特征         | 说明                                                                              |
| ------------ | --------------------------------------------------------------------------------- |
| **原理**     | 产品作用于靶细胞，产生可测定的生物应答（增殖/抑制/凋亡/信号激活等）               |
| **精密度**   | CV 约 30%（细胞本身具有固有生物变异性）                                           |
| **精度保证** | 须精心操作（固定传代次数细胞、严格培养条件、标准曲线并行）                        |
| **监管地位** | 对于通过细胞效应（ADCC/CDC/靶点抑制）发挥疗效的产品，是监管机构优先接受的效价方法 |

**③ 结合试验（Binding Assays）**

| 特征         | 说明                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| **原理**     | 不依赖活的生物系统，基于产品与靶分子的结合特性（抗原-抗体、受体-配体等） |
| **精密度**   | CV 通常 5%～20%                                                          |
| **局限性**   | **不能单独作为制品效力测定的依据**——结合量不等于生物活性                 |
| **适用场景** | 纯化过程监控；作为主要效价方法的结构功能相关分析补充                     |

**④ 动物体内试验（In vivo Animal Studies）**

| 特征         | 说明                                                          |
| ------------ | ------------------------------------------------------------- |
| **原理**     | 动物模型中整体测定产品的生物学效应                            |
| **精密度**   | CV 可达 50%                                                   |
| **主要问题** | 周期长（数天至数周）；动物用量大；个体差异高                  |
| **替代趋势** | 3R 原则推动下，监管机构鼓励以体外方法替代，须提供充分科学依据 |

:::

## 分析方法验证的核心参数体系

:::answer

分析方法验证须根据方法的用途，有针对性地验证适用的参数，并非所有方法都须验证所有参数，须在科学判断的基础上选择和组合。

### 各类检测方法须验证的参数矩阵

| 验证参数             | 鉴别试验 | 杂质检查（限量） | 杂质检查（定量） | 含量测定 | 生物活性测定 |
| -------------------- | -------- | ---------------- | ---------------- | -------- | ------------ |
| 专属性               | ✅       | ✅               | ✅               | ✅       | ✅           |
| 准确性               | —        | —                | ✅               | ✅       | ✅（回收率） |
| 精密度（重复性）     | —        | —                | ✅               | ✅       | ✅           |
| 精密度（中间精密度） | —        | —                | ✅               | ✅       | ✅           |
| 精密度（重现性）     | —        | —                | 如需要           | 如需要   | 如需要       |
| 线性                 | —        | —                | ✅               | ✅       | ✅           |
| 范围                 | —        | —                | ✅               | ✅       | ✅           |
| 检测限度（LOD）      | —        | ✅               | —                | —        | 如适用       |
| 定量限度（LOQ）      | —        | —                | ✅               | —        | 如适用       |
| 耐用性               | ✅       | ✅               | ✅               | ✅       | ✅           |

### 各参数的精要定义

**① 专属性（Specificity）**

在其他组分（杂质、降解物、赋形剂等）共存时，准确可靠测定目标分析物的能力。

生物学方法专属性验证的三个典型场景：

- **免疫印迹（WB）鉴别：** 须首先确认检测抗体的特异性，再验证产品中其他组分不引起非特异性反应
- **细胞活性测定：** 须证明目标分析物与特定细胞应答之间的相关性；可通过加入特异性抗体或抑制剂的封闭实验验证
- **HCP ELISA：** 须验证大量目的蛋白存在时不影响 HCP 的准确检测（基质效应验证）

**② 精密度（Precision）**

多次重复测定结果的接近程度，以变异系数（CV%）表示。分三个层次：

| 精密度层次                               | 定义                                                       | 考察维度                 |
| ---------------------------------------- | ---------------------------------------------------------- | ------------------------ |
| **重复性（Repeatability）**              | 同一实验室、同一操作者、同一天、相同设备，短时间内的精密度 | n ≥ 6                    |
| **中间精密度（Intermediate Precision）** | 同一实验室内，不同天/不同操作者/不同设备间的精密度         | 至少 2 天/2 人/2 设备    |
| **重现性（Reproducibility）**            | 不同实验室间的精密度                                       | 通常在方法转移验证中评估 |

生物学测定方法精密度的可接受标准（参考值）：

| 方法类型             | CV% 可接受范围 |
| -------------------- | -------------- |
| 酶法                 | < 20%          |
| 结合试验（ELISA 等） | < 20%          |
| 细胞试验             | < 30%          |
| 动物试验             | < 50%          |

**注意：** 当药物的临床效应（疗效/不良反应）对给药剂量高度敏感时，须对生物活性测定方法的精密度提出更高要求。

:::

## 分析方法验证：线性、范围与检测限度详解

:::answer

线性、范围和检测限度是方法定量能力的核心表征参数，三者紧密关联，须系统验证并在方法报告中完整记录。

### 线性（Linearity）

**定义：** 在给定范围内，检测结果与供试品中被分析物的浓度（含量）成比例的程度。

**验证要求：**

- 至少覆盖 **5 个浓度水平**，均匀分布于范围内
- 以信号对浓度作图，进行线性回归分析
- 报告：相关系数（R²，通常要求 ≥ 0.99）、Y 轴截距、回归斜率、残差分析

**生物学方法的特殊情况：**

- 许多生物学测定方法（如 Sigmoidal 量效曲线）无法在全部浓度范围呈线性
- 此时须进行数学转换（如 log-logit 转换）后评估线性，或采用非线性模型描述量效关系
- 报告中须明确说明线性范围的局限性

### 范围（Range）

**定义：** 在满足准确性、精密度和线性要求的前提下，被分析物的最高至最低浓度的区间。

**验证原则：**

- 验证范围须覆盖质量标准规定范围的两端及以外
- 示例：若标准规定生物活性为标示量的 80%～120%，则验证范围应至少设定为标示量的 **70%～130%**

**与线性和精密度的关系：** 范围验证可与线性研究合并进行（在验证线性的同时，在范围末端额外评估精密度和准确性），减少验证工作量。

### 检测限度（LOD）

**定义：** 供试品中被分析物能够被检测到的最低量（不要求精确定量）。

| 测定方法     | 原理                                           | 判断标准                       |
| ------------ | ---------------------------------------------- | ------------------------------ |
| **信噪比法** | 将已知低浓度样品的信号与空白信号进行比较       | 信噪比（S/N）= **3:1 或 2:1**  |
| **直观法**   | 分析一系列已知浓度样品，确定能可靠检测的最低量 | 视觉或仪器可明确区分阳性与阴性 |
| **统计法**   | 基于空白样品信号的标准差（σ）计算              | LOD = 3.3 × σ / 斜率           |

### 定量限度（LOQ）

**定义：** 在准确性和精密度均达到要求时，能够准确定量的最低分析物浓度。

| 测定方法     | 判断标准                                                         |
| ------------ | ---------------------------------------------------------------- |
| **信噪比法** | 信噪比（S/N）= **10:1**                                          |
| **统计法**   | LOQ = 10 × σ / 斜率                                              |
| **直观法**   | 在 LOQ 浓度下，精密度（CV%）和准确性（回收率）须同时满足预设标准 |

**LOD vs LOQ 的关系：** LOQ 通常是 LOD 的 3～10 倍；对于杂质定量检测，LOQ 是实际用于设定检测下限的参数。

### 耐用性（Robustness）

**定义：** 试验参数被有意进行微小改变时，测量结果不受影响的能力。

| 须考察的参数变化         | 示例            |
| ------------------------ | --------------- |
| 温度                     | 培养温度 ± 2°C  |
| 时间                     | 反应时间 ± 10%  |
| 试剂质量                 | 不同批次试剂盒  |
| pH                       | 缓冲液 pH ± 0.1 |
| 细胞代次（细胞测定方法） | P+1 至 P-1 代次 |

**耐用性研究的输出：** 建立<strong>系统适用性参数（System Suitability Parameters）</strong>清单，确保在每次实际测定前确认分析系统处于正常工作状态。

:::

## HCP 检测方法的阶段选择策略

:::answer

宿主细胞蛋白（HCP）检测方法须根据产品开发阶段进行系统规划，不同阶段对方法的专属性要求不同，须在效率与风险控制之间动态平衡。

### 分阶段 HCP 检测方法选择策略

| 开发阶段                    | 推荐方法                                               | 理由                                                     |
| --------------------------- | ------------------------------------------------------ | -------------------------------------------------------- |
| **早期开发（研发至 Ph2）**  | 商品化通用 HCP ELISA 试剂盒（如 Cygnus CHO HCP ELISA） | 快速可用；无需自建方法；成本低；适合快速推进             |
| **晚期临床（Ph3）及上市后** | **平台工艺 HCP 方法**或**上游工艺专属 HCP 方法**       | 专属性更强；覆盖率更高；监管机构期望更高水平的方法专属性 |

### 商品化试剂盒沿用至 Ph3/上市的条件

若希望将商业化试剂盒应用于临床三期和上市后，须充分满足以下条件：

- **覆盖率研究（Coverage Analysis）：** 证明试剂盒中的多克隆抗体对本工艺产生的 HCP 谱具有充分覆盖率（通常要求 ≥ 70%）
- **2D DIGE（二维差异凝胶电泳）/ LC-MS HCP 鉴定：** 鉴定工艺产生的 HCP 种类，与试剂盒抗体的覆盖情况比对
- **残余高风险 HCP 的靶向监控：** 对试剂盒覆盖不足的高风险 HCP（如磷脂酶 A2、溶菌酶等），须开发专属检测方法

### 关键试剂更换的一致性验证

由于 HCP ELISA 试剂盒来自外部供应商，生产方对其控制有限，当关键试剂（如检测抗体、标准品）批次更换时：

- 须进行**方法一致性验证（Bridging Study）**，证明更换前后的检测结果具有可比性
- 须在变更管理体系中记录，必要时通知监管机构

### HCP 方法的验证要求

对于 HCP ELISA 方法，须重点验证：

- **专属性：** 目的蛋白（大量存在）不干扰 HCP 检测（基质效应）
- **回收率（Spike Recovery）：** 在产品基质中添加已知量 HCP 标准品，证明方法检测准确
- **精密度：** 批内和批间 CV%
- **最低检测浓度（LOD）和定量限（LOQ）**

:::

## HCP 去除机制：深层过滤的静电与疏水双重作用

:::answer

深层过滤（Depth Filtration）在单克隆抗体生产中不仅用于澄清（去除细胞和细胞碎片），还通过多种互补机制实现对可溶性 HCP 的有效去除，是下游纯化链条中 HCP 控制的第一道屏障。

### 深层过滤去除 HCP 的双重机制

**① 静电吸附机制（Electrostatic Adsorption）**

- 深层滤器中含有带正电荷的介质组分（主要是硅藻土，在抗体纯化的典型 pH 条件下带正电）
- 大多数 HCP 的等电点（pI）为 4～6，在中性 pH 下带负电荷
- 静电吸引力使带负电的 HCP 被带正电的深层滤膜介质捕获和截留
- 同样机制也可去除带负电的宿主细胞 DNA 和内毒素（LPS）

**② 疏水相互作用机制（Hydrophobic Interaction）**

- 部分深层滤器的填充介质含有疏水性纤维（纤维素等）
- 具有疏水表面区域的 HCP 可通过疏水相互作用被捕获在介质表面
- 疏水性 HCP（如某些膜蛋白片段、脂蛋白）的去除主要依赖此机制

**③ 尺寸截留机制（Size Exclusion）**

- 细胞碎片、聚集性 HCP 复合物等大颗粒因尺寸大于滤器孔道而被物理截留
- 此机制与前两种机制协同，形成多层次的 HCP 去除体系

### 深层过滤去除 HCP 的影响因素

| 影响因素               | 对 HCP 去除的影响                                               |
| ---------------------- | --------------------------------------------------------------- |
| **上样液 pH**          | pH 影响 HCP 和介质的电荷状态；通常在 pH 5～7 时静电吸附效果最佳 |
| **电导率（盐浓度）**   | 高盐浓度会屏蔽静电相互作用，降低 HCP 的静电吸附去除率           |
| **滤器类型与表面化学** | 不同品牌/型号的深层滤器表面化学不同，HCP 去除能力存在显著差异   |
| **上样量和流速**       | 上样量过大会导致 HCP 突破；流速过快会缩短接触时间，降低吸附效率 |
| **细胞活率（上游）**   | 低细胞活率导致高 HCP 浓度和高 DNA 浓度，增加深层过滤的负担      |

### 深层过滤在整体 HCP 控制中的定位

```
HCP 控制链路（各步骤的典型去除效果）

收获时 HCP（100%）
    ↓ 深层过滤（去除 50%～90%，取决于滤器类型和条件）
    ↓ Protein A 层析（去除 90%～99%，通过流穿去除）
    ↓ 低 pH 病毒灭活（少量沉淀 HCP）+ 二次深层过滤
    ↓ CEX/AEX 精纯（进一步去除至 ppm 级别）
原液（通常 < 100 ppm = 100 ng/mg）
```

**关键认识：** 深层过滤虽然对 HCP 总量去除效率有限（相比 Protein A 层析），但其对**特定类型 HCP 的预去除**（特别是带负电 HCP 和大颗粒 HCP 复合物）可以显著降低后续 Protein A 层析的 HCP 负担，间接提升整体纯化链路的 HCP 清除效率和填料寿命。

:::
