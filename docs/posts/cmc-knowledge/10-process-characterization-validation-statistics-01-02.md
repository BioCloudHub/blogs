## 工艺验证第一阶段：工艺设计的核心活动与目标

:::answer

工艺设计（Process Design）是工艺验证三阶段生命周期中的基础阶段，其产出直接决定后续工艺确认和持续工艺确认的科学依据质量。

**定义**

工艺设计是在开发和放大活动过程中获得的知识基础上，**对商业化制造工艺进行定义**的活动。目标是设计出适合始终如一地生产符合质量属性产品的日常商业化制造工艺。

**核心活动清单**

| 活动类别 | 具体内容 |
|---|---|
| **CQA 确定** | 结合实验数据、文献和风险评估，识别并确定产品的关键质量属性（CQA）和关键过程属性（KPA） |
| **工艺表征研究** | 通过系统的单因素/DOE 研究，确定关键工艺参数（CPP）和关键过程参数（KPP），以及参数对 CQA 的量效关系 |
| **设计空间（Design Space）定义** | 基于工艺表征数据，建立多维度的工艺参数可接受范围，并明确边界条件 |
| **控制策略制定** | 建立涵盖工艺参数控制范围、过程检测项目、放行标准的整体控制策略 |
| **知识积累与记录** | 捕获并记录工艺开发决策、实验依据和结论，供后续阶段引用 |

**GMP 合规性要求**

- 工艺设计阶段的**早期研究**不要求严格按照 GMP 要求执行，但须遵循科学原则并保持良好的记录规范（GDocP）
- 对后续阶段（工艺确认/工艺性能确认）有直接使用价值的关键决策和数据解释，须进行**充分文件化记录和内部审核**，确保数据的可追溯性和可信度
- 在此阶段充分利用**风险评估工具**（如 FMEA、鱼骨图）进行系统性风险识别和管理

**常见误区**

工艺设计阶段最常见的不足是知识积累不系统、记录不完整，导致进入工艺确认阶段时无法提供充分的科学依据，出现"工艺验证通过但工艺原理不清楚"的情形，这是 BLA 审评中被频繁指出的问题。

:::

## 工艺验证第二阶段：工艺确认（PPQ）的双要素与 GMP 要求

:::answer

工艺确认（Process Qualification, PQ）是对工艺设计进行实际评估的阶段，须在商业化规模下完成，通过后产品方可投入市场销售。

**工艺确认的两个核心要素**

```
工艺确认（PQ）
    │
    ├── 2a 阶段：厂房、设施、设备的验证/确认
    │    （与传统概念的 IQ/OQ/PQ 设备确认对应）
    │    ├── 安装确认（IQ）
    │    ├── 运行确认（OQ）
    │    └── 性能确认（PQ）
    │
    └── 2b 阶段：工艺性能确认（PPQ, Process Performance Qualification）
         （与传统概念的"3 批验证"对应，但有重要演进）
         ├── 在商业化规模批量下运行
         ├── 须结合批量放大因素制定工艺参数
         └── 完成后，已生产批次允许上市销售
```

**2b 阶段（PPQ）的关键规定**

- 工艺性能确认是针对**商业化规模批量**开展的，不接受以小试或中试规模数据代替
- 工艺参数的设定须充分考虑**批量放大（Scale-up）因素**；若工艺设计阶段已有充分的支持性数据，不是所有商业化批量的工艺参数都需要重新开发
- 若批量在工艺设计阶段到工艺确认阶段保持不变，则工艺设计阶段的研究数据可直接用于工艺性能确认，减少重复工作

**GMP 合规性要求**

工艺确认阶段须**严格遵守 GMP 要求**，具体包括：
- 厂房、设施、设备的验证/确认须在 PPQ 执行之前完成（前置条件）
- 所有操作须按照已批准的 GMP 批生产规程（Batch Manufacturing Record）执行
- 取样计划须在 PPQ 方案中预先规定，不得事后调整

**PPQ 完成后的市场准入**

通过 2b 阶段（PPQ）验证后，已生产的产品允许用于销售——这是工艺验证生命周期中一个重要的商业里程碑。但上市后仍须持续开展第三阶段（持续工艺确认）。

:::

## 工艺验证第三阶段：持续工艺确认（CPV）的监控机制

:::answer

持续工艺确认（Continued Process Verification, CPV）是在日常商业化生产过程中，通过持续的数据收集和统计分析，确保工艺始终处于受控状态的长期管理活动。

**持续工艺确认的本质**

CPV 的目标是获得并维持工艺处于**受控状态的持续性保证**——不是一次性的验证活动，而是贯穿产品整个商业化生命周期的持续监控体系。

**CPV 与年度质量回顾（APR）的区别**

| 对比维度 | 持续工艺确认（CPV） | 年度质量回顾（APR） |
|---|---|---|
| **监控频率** | 每批次打点，实时监控，定期报告（频率高于 APR） | 通常每年一次，年底统计 |
| **监控方式** | 在预先建立的控制图上每批次记录数据点，及时识别异常趋势 | 年度数据汇总统计后分析趋势 |
| **响应速度** | 出现超控制限或不良趋势时**即时分析和响应** | 全年数据汇总后方能识别趋势问题 |
| **工具方法** | 统计过程控制（SPC）：控制图（Xbar-R、Xbar-S）、Cpk 计算 | 统计汇总、趋势分析 |
| **关系定位** | CPV 结果可为 APR 提供数据输入 | APR 可引用 CPV 报告中的监控结论 |

**CPV 的核心操作要素**

1. **建立控制限（Control Limits）：** 基于工艺验证批次数据（通常 ≥ 25 批次），建立均值控制图（Xbar-Chart）和极差控制图（R-Chart）的上下控制限（UCL/LCL）
2. **逐批打点：** 每批生产完成后，将关键工艺参数和关键质量属性数据录入控制图
3. **趋势识别规则：** 应用 Western Electric 或 Nelson 控制图判读规则，识别失控（Out-of-Control）和不良趋势信号
4. **定期报告：** 按预定频率（如季度）生成 CPV 报告，报告工艺稳定性状态

**3a 和 3b 子阶段的区分**

通过 PPQ（2b）后：
- **3a 阶段（强化监控）：** 对高风险、工艺能力低（Cpk < 1.33）的关键工艺参数维持高强度取样和监控频率
- **3b 阶段（常规监控）：** 当统计学证据充分证明变异可控且可接受（Cpk ≥ 1.33）后，转为正常取样频率和常规监控

:::

## 工艺验证"连续三批"的合规解读与执行要点

:::answer

"连续三批"是工艺验证中最常被误解的概念之一，须从法规原文和实际执行两个层面准确理解其含义。

**"连续"的正确含义**

"连续"并不要求三批次在时间上紧密相连，其合规解读包括以下两个要素：

**要素一：不能包含失败批次**

- 连续三批必须均为**成功的批次**（所有验证指标均符合验收标准）
- 若中间某批次失败，须按照偏差管理程序处理，调查根因并采取纠正措施后，**重新从第一批开始计数**，直到重新积累连续三批成功数据
- "成功"的判定标准须在 PPQ 方案中预先明确定义

**要素二：时间间隔较长时的前提条件**

- 允许批次之间存在**较长的时间间隔**（如因市场需求）
- 允许三批验证批次之间**穿插生产其他品种**的批次
- 但时间跨度**不建议过大**（过长间隔可能意味着设备状态、人员技能、物料特性的变化，须重新评估先决条件）
- 若批次间隔较长，**每批 PPQ 运行前均须重新确认所有先决条件仍然满足**（如设备状态、分析方法有效性、关键物料批次适用性等）

**"连续三批"的法规依据对比**

| 法规/指南 | 具体表述 | 关键要点 |
|---|---|---|
| **中国 GMP 确认与验证附录** | 企业通常应当至少进行连续三批成功的工艺验证 | "通常"和"至少"意味着不是绝对要求，企业须提供批次选择的合理依据 |
| **FDA 工艺验证指南（2011）** | 未规定最小批次数，强调科学论据支持批次数选择 | FDA 不以"3 批"为黄金标准，鼓励使用统计学方法确定恰当批次数 |
| **ICH Q8/Q9/Q10** | 未规定具体批次数，基于风险和统计学证据 | 与 FDA 立场一致，科学依据优先于固定批次数 |

**最佳实践建议**

对于首次工艺验证（新产品上市），建议：
- 在较短时间窗口内（如 3~6 个月）完成三批次，减少时间相关变量干扰
- PPQ 批次计划提前与商业化生产计划协调，避免不必要的中断
- 若必须跨越较长时间，须在 PPQ 方案中预先制定"间隔过长时的重新确认触发标准"

:::

## 工艺验证前分析方法验证的必要性与顺序要求

:::answer

分析方法验证与工艺验证之间存在明确的前置依赖关系，是工艺验证合规执行的基础性前提。

**法规要求（中国 GMP 2010 版）**

中国 GMP 2010 版附录《确认与验证》明确规定：**工艺验证前，需要完成分析方法的确认与验证**。

核心逻辑：工艺验证的目的是证明工艺能够稳定生产符合质量标准的产品，而"符合质量标准"的判定依赖于分析检测——若分析方法本身的准确性、专属性和精密度未经验证，则工艺验证的检测结果不具有法规支撑力，工艺验证结论无效。

**分析方法与工艺验证的顺序关系**

```
分析方法开发 → 分析方法验证/确认（ICH Q2(R2)）
                              ↓
              工艺验证方案制定（PPQ Protocol）
                              ↓
              工艺验证执行（PPQ Batches）
                              ↓
              工艺验证报告（PPQ Report）
```

**PPQ 前须完成验证的方法类型**

| 方法类型 | 验证要求 |
|---|---|
| **放行检测方法（Release Methods）** | 须完成完整的方法验证（ICH Q2(R2)：专属性、准确性、精密度、线性、范围、耐用性） |
| **关键中间体检测方法（IPC Methods）** | 须至少完成方法确认（Method Qualification），证明方法适合其预期用途 |
| **稳定性指示方法（Stability-Indicating Methods）** | 须完成强制降解试验确认方法的稳定性指示能力 |
| **非关键过程监控方法** | 可简化验证（仅确认适用性），但须有书面记录 |

**时间线规划建议**

分析方法验证通常需要 3~6 个月（含报告撰写和审批），须在 PPQ 启动时间节点前足够提前启动，避免成为 PPQ 执行的延误瓶颈。

:::

## 工艺验证参数覆盖范围：是否需要验证上下限

:::answer

工艺验证是否需要系统验证参数的上下限（即操作边界），是工艺验证策略设计中的核心决策之一，须在风险和资源之间取得平衡。

**核心参考依据：PDA TR60 验证策略设计**

PDA 技术报告 60（PDA TR60: Process Validation: A Lifecycle Approach）提供了两种主要的工艺验证策略，可结合使用：

**策略一：极限法（Worst-Case / Bracketing Approach）**

- 在参数范围的**上下限（Extreme Values）**下运行验证批次，涵盖参数空间的边界条件
- 若上下极限均通过验证，则理论上其间的所有参数值均被覆盖
- 适用场景：参数独立性强、边界条件明确、设备操作能力可精确设定

**策略二：矩阵法（Matrix Approach）**

- 在多个参数的不同组合水平下开展系统性实验（通常结合 DOE 设计）
- 通过统计模型分析参数对输出的影响，识别参数间的相互作用
- 适用场景：参数间存在相互作用、需要建立设计空间模型

**在工艺验证批次中的参数范围设定原则**

工艺验证（PPQ）批次通常在工艺参数的**正常操作范围（Normal Operating Range, NOR）**内运行，而非在极限条件下运行：
- 极限条件下的验证通常已在工艺表征阶段（第 1 阶段）通过缩小模型完成
- PPQ 批次在 NOR 内运行，主要目的是在商业化规模下确认工艺的可重现性
- 若工艺表征阶段的极限研究数据充分，PPQ 通常不需要在极限条件下重复验证

**常见实操误区**

一个常见误区是认为"工艺验证必须在上下限分别做三批次"——这会导致工作量极大增加。正确做法是：工艺表征阶段通过缩小模型系统研究参数极限，工艺验证（PPQ）阶段在商业化规模下验证正常操作范围内的可重现性。

:::

## 工艺验证批次数量：三批是否足够的科学判断

:::answer

"三批"工艺验证是监管实践中约定俗成的做法，但其科学合理性须基于具体工艺特性和统计学原则进行评估。

**各国法规对批次数量的明确态度**

| 法规机构 | 对批次数量的表述 | 核心立场 |
|---|---|---|
| **FDA（2011 工艺验证指南）** | **未规定最小批次数**；强调企业须对自己选定的批次数有可靠的科学论据 | 科学依据优先于固定数字；鼓励统计学方法 |
| **中国 GMP 确认与验证附录** | "企业**通常**应当**至少**进行连续三批成功的工艺验证" | "通常"和"至少"表明三批是**最低基准**，不是上限；工艺复杂、风险高时须更多 |
| **EMA（工艺验证指南）** | 建议至少三批代表性批次，高风险工艺考虑更多批次 | 与中国 GMP 立场一致，三批为常规最低要求 |

**三批次的统计学局限性**

从统计学角度，三批次的样本量极小，其局限性包括：
- 三批次数据的均值和方差的置信区间非常宽，无法可靠代表工艺的整体变异特性
- 三批均成功并不能保证第四批、第五批也一定成功（统计功效不足）
- 这也是 FDA 2011 指南引入**持续工艺确认（第三阶段）**的根本原因——通过上市后持续积累数据不断完善对工艺的统计学理解

**何时需要超过三批次**

在以下情形中，须认真评估是否需要超过三批的工艺验证：
- 工艺复杂度高，CPP 多，参数间相互作用显著
- 工艺能力（Cpk）评估显示变异较大（Cpk < 1.33）
- 历史数据不足，工艺开发阶段批次较少
- 产品为高风险产品（如用于严重疾病的生物药，失败批次对患者供应有重大影响）
- 使用了新设备、新技术或新操作人员

**中国 GMP 的补充要求**

工艺验证批量须与**预定的商业化批量一致**，不接受以小批量代替；持续工艺确认须对后续商业化生产批次的信息和数据持续收集和评估。

:::

## 工艺验证参数范围：关键工艺参数与所有参数的覆盖策略

:::answer

工艺验证中参数覆盖范围的策略制定须在科学严谨性和资源效率之间取得平衡，参数分类的准确性是关键前提。

**前提一：确保工艺参数分类的合理性**

开展工艺验证前，须确认 CPP（关键工艺参数）/ KPP（关键过程参数）/ Non-KPP 的分类过程符合以下要求：
- 分类依据来自系统性的风险评估（FMEA 等工具）和实验数据支撑，而非主观判断
- 每个参数的分类决策均有书面记录和合理解释
- 分类结论已经内部审核，并与监管机构（如需要）进行了沟通

**参数分类的定义**

| 参数类别 | 定义 | 对 PPQ 的要求 |
|---|---|---|
| **CPP（关键工艺参数）** | 对关键质量属性（CQA）有显著影响的工艺参数；在工艺表征中已通过实验证明其显著性 | PPQ 须对 CPP 进行明确监控和记录；参数须在设计空间内运行 |
| **KPP（关键过程参数）** | 需要监控但对 CQA 影响程度相对较低的参数 | PPQ 须记录和监控，但接受标准可相对宽松 |
| **Non-KPP（非关键参数）** | 经风险评估证明对 CQA 影响可忽略的参数 | PPQ 须记录，但通常不设严格验证接受标准 |

**核心策略建议：PPQ 中包含所有工艺参数**

尽管工艺验证的核心关注点是 CPP，但实践中建议在 PPQ 中**记录和监控所有工艺参数**，理由是：

1. **工艺性能的整体评估：** 工艺验证的本质是证明整个工艺（而非仅个别参数）能够稳定重现合格产品；仅监控 CPP 可能遗漏参数间相互作用对产品质量的影响
2. **参数分类准确性的安全网：** 若工艺相对复杂或工艺理解在工艺设计阶段尚不完全充分，参数分类可能存在偏差；记录所有参数可在 PPQ 批次中发现异常时回溯评估分类的准确性
3. **审评合规性：** 审评机构（特别是 CDE）倾向于要求提供全面的工艺性能数据，仅提供 CPP 数据可能引发补充问题

:::

## 工艺验证与 PPQ 的关系：概念边界与阶段划分

:::answer

PPQ（工艺性能确认）仅是工艺验证生命周期中第二阶段的核心活动，与传统概念的"工艺验证"存在重要区别，须正确理解其边界。

**工艺验证的完整生命周期定义（FDA 2011）**

FDA 2011 工艺验证指南将工艺验证定义为：**"在工艺设计到商业生产的全过程，不断收集和评价数据，以建立科学证据，证明工艺能够始终如一产出优质产品。"**

**三阶段框架完整结构**

```
第1阶段：工艺设计（Process Design）
  ├── 工艺表征研究（CQA识别、风险评估、DOE）
  ├── CPP/KPP 鉴定
  ├── 设计空间定义
  └── 控制策略制定
  
  ↓ 工艺设计输出（商业化工艺定义）
  
第2阶段：工艺确认（Process Qualification）
  ├── 2a 阶段：设施、设备验证确认（IQ/OQ/PQ）
  └── 2b 阶段：工艺性能确认（PPQ）
       ├── 商业化规模批次（通常 ≥ 3 批）
       ├── 预定验收标准
       └── 完成后产品可上市销售
  
  ↓ 上市销售许可
  
第3阶段：持续工艺确认（Continued Process Verification, CPV）
  ├── 3a：高风险参数强化监控（直到 Cpk 达标）
  └── 3b：常规统计过程控制（SPC）
```

**PPQ 与传统"三批验证"的演进**

| 演进维度 | 传统"三批验证"概念 | 当前 FDA 工艺验证指南下的 PPQ |
|---|---|---|
| **批次数量** | 三批被视为"黄金标准"，固定不变 | 三批是最常见做法，但非强制；须有统计学和科学依据支持批次数选择 |
| **验证逻辑** | 三批通过 = 工艺验证完成 | PPQ 完成仅是阶段性里程碑，须通过 CPV 持续积累证据 |
| **基础要求** | 主要关注 PPQ 批次本身 | PPQ 须以充分的工艺设计（阶段 1）研究为科学基础 |
| **上市后义务** | 无明确持续监控要求 | 须持续开展第三阶段（CPV），确保工艺始终受控 |

**重大变更后的路径**

一旦发生重大变更（如生产规模放大、关键设备更换、工艺参数重大调整），须**回到第一阶段**重新评估，根据变更范围决定是否需要重新进行工艺表征研究和 PPQ。

:::

## 中间品增加检验指标是否触发工艺验证

:::answer

中间品新增检验指标通常不触发工艺再验证，但须完成相应的分析方法合规性确认工作。

**判断逻辑**

工艺再验证的触发条件是**工艺本身发生了实质性变更**（如工艺参数、操作步骤、设备、规模的变更），而新增一个中间品检验指标属于**质量控制体系的完善**，不改变工艺本身，因此：
- **不触发工艺再验证**（工艺参数、操作步骤均未改变）
- **须完成：** 新增检验项目的分析方法确认或验证（确保方法适合其预期用途）
- **建议开展：** 对新增指标的历史批次数据进行回顾性评估，与新增指标的检测结果对比，评估工艺一致性

**须完成的三项工作**

| 工作内容 | 要求 |
|---|---|
| **新增方法的确认/验证** | 若为药典方法，通常需要完成方法确认（Qualification）；若为非药典方法，须完成完整方法验证（ICH Q2(R2)） |
| **历史批次对比评估** | 对代表性历史批次补充检测新增指标，建立历史基线数据，确认历史批次均符合新增指标的可接受标准 |
| **质量标准更新** | 将新增检验项目正式纳入中间品质量标准，更新生产规程 |

**注意事项**

若新增的检验指标揭示了此前工艺中存在的潜在质量问题（如检测发现历史批次中新指标存在不合格情况），则须进行根因调查，可能触发工艺改进，进而触发工艺验证。

:::

## 工艺验证核心法规指南体系：中国/FDA/EMA 对照

:::answer

熟悉各主要法规机构的工艺验证指南体系，是设计合规验证策略和向不同市场申报的基础。

**工艺验证主要法规指南汇总**

**中国法规体系**

| 文件 | 发布机构 | 核心内容 |
|---|---|---|
| **2010 版 GMP 附录《确认与验证》** | NMPA（原 CFDA） | 确认与验证的基本原则、验证类型、最低批次要求（至少连续三批成功） |
| **药品生产验证指南** | NMPA | 对 GMP 确认与验证附录的详细补充说明，提供具体实操指导 |

**FDA 法规体系**

| 文件 | 发布机构 | 核心内容 |
|---|---|---|
| **FDA Process Validation: General Principles and Practices（2011）** | FDA CDER/CBER | 三阶段工艺验证生命周期框架的核心文件；强调科学和统计学依据优先；适用于 API 和制剂产品 |
| **PDA TR60: Process Validation: A Lifecycle Approach** | PDA | 对 FDA 2011 指南的详细技术补充，提供验证策略（极限法、矩阵法）的具体方法论 |

**EMA 法规体系**

| 文件 | 发布机构 | 核心内容 |
|---|---|---|
| **EMA Guideline on Process Validation for Finished Products（2014）** | EMA | 化学药品和制剂的工艺验证指南，覆盖传统工艺验证方法 |
| **EMA Guideline on Process Validation for the Manufacture of Biotechnology-derived Active Substances（2015）** | EMA | 生物技术来源活性物质的工艺验证特殊要求，特别关注生物制品的复杂性和工艺可变性 |

**各体系的核心差异**

| 差异维度 | 中国 GMP | FDA 2011 | EMA 2014/2015 |
|---|---|---|---|
| 最低批次要求 | 至少连续三批 | 未规定，须科学论据支持 | 通常至少三批代表性批次 |
| 对生命周期方法的接受度 | 引入持续工艺确认概念（中西结合） | 明确要求三阶段生命周期方法 | 支持生命周期方法，接受传统方法 |
| 生物制品特殊要求 | 参照生物制品 GMP 附录 | CBER 有针对生物制品的特殊指导 | 有专门的生物技术产品工艺验证指南 |

## 工艺验证类型的完整分类与适用场景

:::answer

工艺验证按启动时机和研究方式可分为四大类型，每种类型的适用场景和 GMP 合规要求各有不同。

**四大验证类型对比**

**① 首次验证（前瞻性验证 / Prospective Validation）**

- **适用场景：** 新处方、新产品、新工艺的首次商业化验证
- **执行时机：** 在商业化生产开始前完成（前置于销售）
- **核心要求：** 基于预先制定的方案，在商业化规模下完成规定批次（通常 ≥ 3 批），验证通过后方可销售
- **特殊例外（同步验证）：** 以下极个别情形允许使用同步验证方式替代前瞻性验证：
  - 市场需求极少，无法积累足够批次进行前瞻性验证（如孤儿药）
  - 因药物短缺，强制要求前瞻性验证会给患者带来安全风险

**② 变更验证（Change Validation）**

- **适用场景：** 生产工艺、设备、场地、原材料等发生变更后的重新验证
- **执行方式：** 可采用前瞻性验证或同步验证（取决于变更风险等级）
- **关键文件：** 须先完成变更评估（变更分类、影响评估），变更评估结论支持前置（BLA 前）或后置（BLA 后）申报

**③ 定期再验证（Periodic Revalidation）**

- **适用场景：** 无重大变更，但按照验证主计划（VMP）规定的周期进行的常规再确认
- **执行方式：** 可采用同步验证或回顾性验证
- **重要例外：** 无菌工艺等**高风险工艺不允许采用回顾性验证**（必须是前瞻性或同步验证）

**④ 持续工艺确认（Continued Process Verification, CPV）**

- **法规来源：** FDA 2011 工艺验证指南引入的新概念（中国 GMP 2010 版也引入了该概念）
- **执行方式：** 在商业化生产全程持续监控（非一次性验证活动）
- **与传统再验证的关系：** 持续工艺确认的结果为判断是否需要定期再验证提供科学依据；若 CPV 数据显示工艺持续受控（Cpk 稳定、无异常趋势），可作为简化或豁免定期再验证的依据

:::

## Verification、Validation 与 Qualification 的精确概念辨析

:::answer

这三个英文术语在生物制药 GMP 体系中均译为某种形式的"验证/确认"，但其适用对象、技术内涵和侧重点有明显区别，混用会导致文件体系不规范。

**三个概念的核心定义对比**

| 术语 | 中文常用译法 | 定义 | 适用对象 |
|---|---|---|---|
| **Validation（验证）** | 验证 | 通过提供客观证据，对特定的**预期用途或应用要求**已得到满足的认定；强调"目的适合性（Fitness for Purpose）" | 分析方法、生产工艺、清洁程序、计算机化系统等**过程和方法** |
| **Qualification（确认）** | 确认（设备/系统确认） | 通过提供客观证据，对特定的**规定要求**已得到满足的认定；强调"规格符合性（Conformance to Specification）"；着重于资格认证 | 厂房设施（洁净级别）、工艺系统、生产设备、分析设备、计算机设备等**硬件和系统** |
| **Verification（验证）** | 核实/确认（软件） | 通过检查和提供客观证据，确认规定要求已得到满足；在软件工程中特指**软件系统是否正确地反映了需求** | 主要用于计算机化系统和软件的需求核实；在 GMP 中也用于物料的供应商认证确认 |

**Qualification 的四个阶段**

设备和系统的 Qualification 通常分为四个阶段（不同类型设备要求不同）：

| 阶段 | 缩写 | 验证内容 | 适用设备范围 |
|---|---|---|---|
| **设计确认** | DQ | 确认设计方案满足 GMP 要求和用户需求 | 新建厂房、定制设备 |
| **安装确认** | IQ | 确认设备按设计和规格正确安装 | 所有受控设备 |
| **运行确认** | OQ | 确认设备在规定的运行范围内按预期功能运行 | 控制设备、测量仪器、分析仪器 |
| **性能确认** | PQ | 确认设备在正常使用条件下始终能达到预期性能 | 控制设备、测量仪器、分析仪器 |

**实际操作的分级要求**

- **普通设备（如搅拌桶）：** 技术验收 + IQ 即可
- **控制设备、测量仪器（如生物反应器、天平）：** 技术验收 + IQ + OQ + PQ
- **分析仪器（如 HPLC、CE）：** 技术验收 + IQ + OQ + PQ，建议同时进行风险评估
- **计算机化系统（如 SCADA、LIMS）：** 须同时符合 GAMP 5 的软件验证要求

**定期再确认（Requalification）要求**

设备完成初次 Qualification 后，须按照已制定的再确认计划**定期进行再确认**（通常每年一次，或在发生影响设备性能的变更后立即进行），以证明设备仍处于受控状态。

:::

## 工艺表征与工艺验证的关系：从阶段定位到时序依赖

:::answer

工艺表征研究（Process Characterization Study, PC Study）是工艺验证生命周期中第一阶段（工艺设计）的核心科学活动，为后续工艺验证提供参数设定的科学依据。

**工艺表征在工艺验证体系中的位置**

```
工艺表征研究（阶段 1 的核心活动）
    ├── 风险评估：鉴定潜在 CPP/KPP
    ├── 缩小模型建立与确认
    ├── 单因素/DOE 实验（参数-CQA 量效关系）
    ├── 设计空间边界确定
    └── 控制策略框架建立
           ↓ 输出：商业化工艺参数操作范围 + CQA 可接受标准
           
工艺性能确认（PPQ，阶段 2b 的核心活动）
    ├── 商业化规模批次（PPQ 方案基于工艺表征输出制定）
    └── 验证工艺在商业化规模下的可重现性
```

**时序依赖关系（关键规定）**

**工艺表征研究须在 PPQ 批次运行之前完成**，核心理由：
- PPQ 方案（Protocol）中的工艺参数操作范围须有工艺表征数据支撑
- PPQ 方案中的 CQA 可接受标准须基于工艺表征研究建立
- 若工艺表征研究未完成即启动 PPQ，则 PPQ 方案的科学依据不足，工艺验证结论面临审评质疑

**先 PPQ 后工艺表征的风险**

国内部分企业存在"先做工艺验证，事后补工艺表征研究"的情况，这种做法的主要风险是：工艺表征研究确定的参数操作范围/设计空间可能与已完成的工艺验证（PPQ）所用的参数设定不一致，导致：
- 需要重新评估 PPQ 批次数据的有效性
- 可能须重新开展 PPQ（工艺验证失效的风险）
- BLA 申报时面临资料逻辑不一致的审评风险

:::

## 工艺表征研究的科学目的与监管意义

:::answer

工艺表征研究（Process Characterization, PC）是系统探究工艺参数对产品质量属性影响规律的科学活动，是现代生物药 CMC 开发的核心方法论组成部分。

**工艺表征研究的精确定义**

工艺表征研究是一系列研究活动，旨在：
1. **探究量效关系：** 确定工艺参数（输入）对产品质量属性（输出）的影响方向和程度（量效关系曲线）
2. **鉴定关键参数：** 区分对 CQA 有显著影响的 CPP 与影响可忽略的 Non-KPP
3. **定义设计空间：** 建立满足 CQA 要求的工艺参数多维可接受范围
4. **建立控制策略：** 为操作范围、报警限和行动限提供科学依据

**FDA 工艺验证指南的核心观点**

FDA 认为生产企业在开始 PPQ 时往往**尚不完全了解生产工艺输入变异的全貌**（full extent of input variation），因此工艺表征研究的目的之一是：**通过系统性实验设计来估计和量化工艺的变异性**，而非简单地寻找"通过点"。

**监管申报的体现要求**

工艺表征研究内容须在 CTD 申报资料中明确体现，位于：

| CTD 章节 | 内容 |
|---|---|
| **3.2.S.2.5** | 原料药（DS）的工艺验证/评价（包含工艺表征研究结论） |
| **3.2.P.3.5** | 制剂（DP）的工艺验证/评价 |

工艺表征研究是向监管机构展示**生产企业对生产工艺深度理解**的核心渠道，也是证明工艺控制策略科学性的重要依据。中国自 2017 年加入 ICH 后，工艺表征逐渐成为生物药 CMC 开发中不可或缺的研究环节。

:::

## 开展工艺表征研究的法规必要性

:::answer

工艺表征研究的必要性在中国、美国和 ICH 框架下均有明确的法规依据，其开展已从"最佳实践"演变为监管合规的基本要求。

**法规依据体系**

**美国 FDA：**

FDA 2011 工艺验证指南第一阶段（工艺设计）明确指出：工艺表征研究是确定工艺参数与产品质量关系、**建立工艺设计空间**的核心活动，是工艺验证生命周期的基础。强调"不能简单地依靠三批 PPQ 来认为工艺已被充分理解"。

**中国 GMP 附录 11（确认与验证）：**

明确要求：
- 企业应当有书面文件确定**关键质量属性（CQA）**和**关键工艺参数（CPP）**
- 须明确常规生产和工艺控制中的**关键工艺参数范围**
- 须根据对产品和工艺知识的理解**定期更新**上述信息

上述"关键工艺参数"和"参数范围"通常只能通过系统的工艺表征实验来确定，难以仅凭文献推断。

**ICH Q8/Q9/Q10 框架（QbD 理念）：**

- ICH Q8（药物研发）：设计空间（Design Space）的建立须以实验数据为基础，工艺表征研究是建立设计空间的核心方法
- ICH Q9（质量风险管理）：工艺表征中的风险评估（FMEA、鱼骨图）是识别潜在 CPP 的规范化工具
- ICH Q10（药物质量体系）：工艺知识管理（Process Knowledge Management）须持续积累和更新，工艺表征研究是知识积累的核心来源

**实际审评压力**

CDE 在 BLA 审评中越来越关注 3.2.S.2.5 章节的工艺表征研究质量，特别是：
- CPP 鉴定是否有充分的实验数据支持（而非仅凭经验分类）
- 设计空间的边界是否通过实验确认
- 控制策略与工艺表征结论的逻辑一致性

:::

## 工艺表征研究的必要前提条件

:::answer

开展工艺表征研究须具备以下五类前提条件，缺少任何一类均会影响研究结果的可靠性和可用性。

**前提一：CQA 和 KPA 的明确定义**

- 通过文献研究、实验数据（特别是早期工艺开发数据）和参考同类产品，明确产品的**关键质量属性（CQA）**和**关键过程属性（KPA）**
- 须为每个 CQA 和 KPA 设定**参考范围（Reference Range）**，作为工艺表征研究中判断参数影响显著性的评判基准
- CQA 和 KPA 的定义须有明确的科学理由，并与产品安全性和有效性挂钩

**前提二：生产工艺的充分定义**

- 生产工艺须已明确确定（工艺流程图、主要操作步骤），并对每个操作单元进行了系统分解和参数定义
- 须建立每个操作单元的**参数清单**，包括：操作名称、参数名称、当前设定值、初步评估的参数范围
- 工艺须已完成至少基本规模的运行验证（工艺打通），避免工艺表征研究期间工艺流程本身发生根本性调整

**前提三：实验设备和分析平台**

- **上游工艺：** 需要能够模拟商业化生产过程的生物反应器（通常 1~15 L 台式反应器，须经过缩小模型确认）
- **下游工艺：** 层析系统（ÄKTA 等）、超滤系统、其他分离纯化设备（须与商业化设备等效确认）
- **分析平台：** 支持所有 CQA 检测的分析方法和仪器（HPLC、CE、ELISA 等），这些方法须已完成至少基本的方法确认

**前提四：缩小模型（Scale-down Model）**

- 工艺表征研究的大量实验须在**缩小模型**下完成（在商业化规模下直接开展所有工艺表征实验是不可行的，成本过高且物料不足）
- 缩小模型须通过**等效性确认（Scale-down Model Qualification）**，证明其能够代表商业化生产规模的工艺性能
- 等效性确认的核心指标：缩小模型与商业化规模在关键参数（VCD、活率、Titer、产品质量属性）上的一致性

**前提五：物料准备**

- 上游工艺表征研究须有充足的细胞库（WCB 或研究细胞库）支撑多批次实验
- 下游工艺表征研究须有足够量的**来自商业化生产规模的上游料液**（HCCF）用于下游各步骤的参数研究——这是组织工艺表征研究计划时最常被低估的物料需求，须提前规划生产运行时机

:::

## 工艺表征研究的实验方法选择：四种主要方法

:::answer

工艺表征实验的方法选择应基于风险评估结论，针对不同类型的参数和研究目的采用不同的实验设计方法。

**方法选择的总体原则**

应根据**风险评估（FMEA）的结论**确定每个工艺参数适用的研究方法：
- 评估得分高（潜在 CPP）的参数 → 须通过实验系统确认其对 CQA 的影响显著性
- 评估得分低（潜在 Non-KPP）的参数 → 可通过 Worst-Case 研究或文献支持确认其影响可忽略

**四种主要实验方法**

**① DOE 研究（Design of Experiments，实验设计）**

- **适用场景：** 须同时研究多个参数的效应和参数间交互作用时
- **设计类型：** 全因子设计（Full Factorial）、部分因子设计（Fractional Factorial）、响应面设计（Box-Behnken、Central Composite Design）
- **优势：** 高效（用较少实验次数覆盖多参数的影响）；可量化参数间交互作用；为建立数学模型（设计空间）提供数据基础
- **局限：** 需要较多样品量；设计和分析需要统计学专业知识

**② 单因素研究（One Factor at a Time, OFAT）**

- **适用场景：** 研究单个参数对 CQA 的影响，其他参数固定在目标值
- **优势：** 设计简单，结果直观，易于解释
- **局限：** 无法捕获参数间交互作用；工作量随参数数量线性增加

**③ Worst-Case 研究（最差条件研究）**

- **适用场景：** 验证参数在设计范围边界（上限或下限极值）时，产品质量仍符合可接受标准
- **设计逻辑：** 将多个参数同时设定在最不利方向的极值，设计"最差条件组合"
- **优势：** 直接验证边界条件的安全性，为参数范围设定提供最强的"安全证明"
- **注意：** Worst-Case 须基于风险评估合理定义，不能随意设定为历史最差值

**④ 种子链研究（Seed Train Studies）**

- **适用场景：** 评估上游工艺中细胞扩增过程（种子链 N-1、N-2 等）的参数对最终生产阶段产品质量的影响
- **研究内容：** 种子细胞状态（活率、密度）、传代间隔、培养基批次、传代代次对最终产品 Titer 和质量属性的影响

:::

## 工艺表征研究的分析方法：确认还是验证

:::answer

工艺表征研究中使用的分析方法的合规性要求是一个常被误解的问题，其要求低于正式的方法验证，但高于完全未经验证。

**参考依据（PDA TR60）**

PDA 技术报告 60 明确规定：工艺表征研究所用的分析方法须经过**确认（Qualification）或验证（Validation）**——使用的术语是"qualification or validation"，而非仅"validation"。

**实践含义：方法确认（Qualification）通常足够**

工艺表征研究不需要对分析方法进行完整的全参数方法验证（ICH Q2(R2) 的全套验证），方法确认（Qualification）通常满足要求：

| 要求等级 | 适用场景 | 须完成的参数 |
|---|---|---|
| **方法验证（Validation）** | 放行检测方法（Release Methods）；稳定性检测方法 | ICH Q2(R2) 全套参数（专属性、准确性、精密度、线性、范围、检测限、定量限、耐用性） |
| **方法确认（Qualification）** | 工艺表征研究用分析方法；过程中间控制（IPC）方法 | 专属性、精密度（批内）、准确性（基本范围内），以及与已验证方法的可比性 |

**方法确认的最低要求**

对于工艺表征研究使用的方法，至少须证明：
- **专属性（Specificity）：** 方法能够区分目标分析物与潜在干扰物
- **精密度（Precision）：** 批内重复性（通常 CV ≤ 15%，对于生物活性方法）
- **可接受范围内的准确性（Accuracy）：** 标准样品或参比品的回收率在合理范围内
- **与已放行方法的可比性：** 若工艺表征方法与已验证的放行方法不同，须提供方法可比性数据

**重要说明**

若工艺表征研究中的分析方法同时也是（或计划成为）放行检测方法，则须按照放行方法的要求完成完整的方法验证，而非仅方法确认。

:::

## 工艺表征研究的六步基本流程

:::answer

工艺表征研究须按照系统性的六步流程有序开展，每步均有明确的输入、活动内容和输出。

**六步流程总览**

```
第一步：鉴定 CQAs 和 KPAs
    ↓
第二步：定义生产工艺
    ↓
第三步：执行风险评估（FMEA）
    ↓
第四步：建立缩小模型并确认等效性
    ↓
第五步：工艺参数研究（DOE/OFAT/Worst-Case）
    ↓
第六步：定义设计空间，制定控制策略
```

**各步骤详解**

| 步骤 | 主要活动 | 关键输出 |
|---|---|---|
| **第一步：CQA/KPA 鉴定** | 结合文献、历史数据和早期研发数据，识别影响产品安全性和有效性的关键质量属性 | CQA 清单 + 每个 CQA 的参考范围 |
| **第二步：工艺定义** | 系统梳理生产工艺流程，对每个操作单元进行参数分解，建立完整的工艺参数清单 | 工艺流程图 + 所有参数清单（含当前设定值和初步范围） |
| **第三步：风险评估（FMEA）** | 对所有工艺参数进行 FMEA 风险评分（严重性 × 发生率 × 可检测性），鉴定潜在 CPP/KPP | 风险评估矩阵 + 潜在 CPP/KPP 优先级排序 |
| **第四步：缩小模型建立** | 设计并建立代表商业化规模的缩小模型，通过等效性实验完成模型确认 | 缩小模型确认报告（Qualification Report） |
| **第五步：工艺参数研究** | 基于风险评估结论，针对高风险参数开展 DOE/OFAT/Worst-Case 实验 | 参数-CQA 量效关系数据 + 参数显著性统计分析结论 |
| **第六步：设计空间定义** | 基于参数研究数据，建立设计空间模型；制定涵盖 CPP 操作范围的控制策略 | 设计空间（Design Space）+ 控制策略文件 |

:::

---

## 工艺表征第三步：FMEA 风险评估鉴定潜在 CPP/KPP

:::answer

风险评估是工艺表征研究中将"工艺参数清单"转化为"优先实验参数"的关键步骤，FMEA（失效模式和影响分析）是最常用的工具。

**FMEA 在工艺表征中的具体应用**

对已建立的工艺参数清单（第二步输出），针对每个参数与每个 CQA 的组合，评估以下三个维度：

| 评估维度 | 评分含义 | 典型评分范围 |
|---|---|---|
| **严重性（Severity, S）** | 若该参数偏离设定值，对该 CQA 造成的最大潜在影响程度 | 1（影响可忽略）~ 5（影响严重） |
| **发生率（Occurrence, O）** | 该参数在正常生产中偏离设定值的可能性 | 1（极不可能）~ 5（频繁发生） |
| **可检测性（Detectability, D）** | 若发生偏差，现有过程控制（IPC）检测到该偏差的能力 | 1（非常容易检测）~ 5（几乎无法检测） |

**风险优先数（RPN）计算**

$$RPN = S \times O \times D$$

**风险分级与实验策略**

| RPN 分级 | 参数分类结论 | 后续实验策略 |
|---|---|---|
| **高 RPN（> 预设阈值，如 12~25）** | 潜在 CPP，须通过实验确认其对 CQA 的影响显著性 | 列入 DOE 或单因素研究计划，系统研究参数-CQA 量效关系 |
| **中 RPN（预设中间范围）** | 潜在 KPP，须监控但影响程度可能较低 | 可通过 Worst-Case 研究或回顾性数据确认，不一定需要 DOE |
| **低 RPN（< 预设阈值）** | 潜在 Non-KPP，影响可忽略 | 文献支持 + 历史数据回顾即可，无需专门实验确认 |

**FMEA 评分的主观性管理**

FMEA 评分存在一定主观性，须通过以下措施控制偏差：
- **多学科团队参与：** 评分应由工艺开发、质量、分析等多个专业领域的专家共同完成
- **评分规则预先统一：** 在开始评分前明确各分级的判断标准，避免不同人员理解不一致
- **文件化记录：** 每个参数的评分依据须有明确的书面说明，支持后续审计追溯

:::

## 工艺表征第四步：缩小模型的建立与等效性确认

:::answer

缩小模型（Scale-down Model）是在研发规模设备上重现商业化生产工艺关键特性的简化系统，是工艺表征研究、病毒清除验证和工艺优化的核心实验平台。

**建立缩小模型的必要性**

| 原因 | 说明 |
|---|---|
| **资源效率** | 商业化规模（如 2000 L 生物反应器）运行成本极高；工艺表征研究需要数十至数百个实验条件，必须在小规模下完成 |
| **实验灵活性** | 小规模设备（1~15 L 生物反应器，小型层析柱）可以快速精确调节参数，满足 DOE 实验设计的操作精度需求 |
| **法规要求** | 病毒清除验证（Viral Clearance Validation）须在缩小模型规模下完成，FDA/EMA 均要求提供缩小模型等效性证明 |

**缩小模型等效性确认（Scale-down Model Qualification）**

等效性确认是证明缩小模型与商业化规模工艺等效的正式实验程序：

**上游缩小模型（细胞培养）的等效性指标**

| 指标类别 | 典型等效性要求 |
|---|---|
| 细胞生长动力学 | 缩小模型 VCD 峰值、活率曲线、倍增时间与商业化规模一致（±20% 以内） |
| 代谢特征 | 葡萄糖消耗速率、乳酸生成、氨积累浓度与商业化规模可比 |
| 溶氧（DO）控制 | 缩小模型 DO 控制策略与商业化规模等效（通气方式、搅拌速率的体积校正） |
| 产物质量 | Titer（g/L）、糖型分布、电荷变体 Profile、聚集体水平与商业化规模可比 |

**下游缩小模型（层析/超滤等）的等效性指标**

| 操作单元 | 关键等效参数 |
|---|---|
| 层析（Protein A、IEX、HIC） | 线速（cm/h）、载量（g/L 树脂）、缓冲液用量（CV）、各步骤停留时间与商业化规模一致 |
| 超滤/渗滤（UF/DF） | 膜面积与体积比、TMP（跨膜压）、渗滤体积数（N × dv）与商业化规模等效 |
| 病毒灭活（低 pH、S/D） | 关键参数（pH、温度、时间）精确控制，与商业化规模等效 |

**等效性确认报告的文件要求**

等效性确认报告须包含：缩小模型与商业化规模的并行运行数据对比、等效性判定依据（预先设定的可接受标准）、等效性结论声明，并须由质量部门审批。

:::

## 工艺表征第五步：工艺参数研究的实施要点

:::answer

工艺参数研究是工艺表征研究中工作量最大的实验执行阶段，其设计质量和执行规范性直接决定研究结论的可靠性。

**实施的基本前提**

完成以下四个前期步骤后，方可进入工艺参数研究实验执行：
- **前提一：** CQA/KPA 已明确定义，检测方法已确认或验证
- **前提二：** 生产工艺已充分定义，参数清单完整
- **前提三：** FMEA 风险评估已完成，优先研究参数已确定
- **前提四：** 缩小模型已建立并通过等效性确认

**实验设计的核心要素**

| 要素 | 设计内容 |
|---|---|
| **参数范围设定** | 基于工艺开发历史数据和 FMEA 结论，设定每个参数的研究范围（高值、低值、中心值）；范围须超出正常操作范围（NOR）以覆盖潜在的边界条件 |
| **实验设计类型** | 根据参数数量和相互作用假设，选择 DOE 类型（全因子、部分因子、响应面）；涉及极限验证时采用 Worst-Case 设计 |
| **样本重复** | 关键 CQA 检测须有足够的重复次数以支持统计学分析（通常每个实验条件至少 2~3 次平行检测） |
| **物料一致性** | 同一 DOE 研究的所有实验须使用同批次的细胞库和物料（减少批次间变异对结果的干扰） |

**数据分析与结论输出**

实验数据须经过统计学分析，主要包括：
- **方差分析（ANOVA）：** 评估各参数对 CQA 影响的统计显著性（通常 p < 0.05 为显著）
- **主效应图（Main Effects Plots）：** 可视化参数对 CQA 的影响方向和程度
- **交互效应图（Interaction Plots）：** 识别参数间是否存在交互作用
- **响应面模型（Response Surface Model）：** 建立参数-CQA 的数学模型，用于设计空间的定义

**工艺参数研究的核心输出**

- **CPP 确认列表：** 统计显著性证明为关键参数的最终 CPP 清单
- **参数操作范围（Proven Acceptable Range, PAR）：** 各 CPP 经实验证明的可接受操作范围
- **设计空间边界数据：** 为定义多维设计空间提供的实验数据基础

:::
