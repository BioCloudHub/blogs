## 病毒清除验证的法规依据与 GMP 合规要求

:::answer

**法规要求的核心出处**

GMP 明确要求：**下游纯化工艺中的除病毒步骤必须经过验证**，验证数据须作为申报资料（IND 和 BLA）的核心组成部分，以证明生产工艺对潜在病毒污染的清除能力满足监管机构的安全性要求。

**为什么验证是强制性要求**

生物制品在生产过程中面临来自多个来源的病毒污染风险（细胞基质、原材料、生产环境等），而对每批产品进行全面的病毒检测既不可行（成本高、周期长）、也不充分（阴性检测结果不能排除低水平病毒存在的可能性）。因此，监管机构的逻辑是：通过**前瞻性的工艺验证**，证明生产工艺本身具备足够的病毒清除能力，即"工艺保障安全性"，而非单纯依赖产品检测。

**国内外核心法规体系**

| 法规/指南                                                        | 发布机构   | 状态                         |
| ---------------------------------------------------------------- | ---------- | ---------------------------- |
| ICH Q5A(R1)（1999）                                              | ICH        | 现行版，修订版（R2）正在制定 |
| 《中国药典》三部·生物制品病毒安全性控制（2020版）                | 国家药典委 | 现行版                       |
| 生物组织提取制品和真核细胞表达制品病毒安全性评价技术审评一般原则 | CDE        | 2005年发布                   |
| 血液制品去除/灭活病毒技术方法及验证指导原则                      | NMPA       | 2002年发布                   |

**验证数据在申报中的应用时机**

- **IND 申报阶段：** 须提供初步的病毒安全性评估（证明工艺具有基本清除能力），可使用平台技术数据支持，不要求全面验证；
- **BLA 申报阶段：** 须提供完整的病毒清除验证报告，覆盖所有特定病毒清除步骤，使用代表性缩小模型，选用合适的指示病毒，在最差条件下进行验证。

## 病毒的结构特征、危害机制与生物制品生产中的主要污染来源

:::answer

**病毒的基本定义与结构**

病毒（Virus）是一种个体极微小、结构简单的**非细胞型生物**，其核心特征包括：

- 只含**一种核酸**（DNA 或 RNA，二者不能共存）；
- 必须在**活细胞内寄生**，依赖宿主细胞的代谢机器进行复制增殖；
- 不能独立进行代谢活动，不能在无细胞的培养基上生长。

**病毒的结构层次**

| 结构层次                   | 组成                                   | 功能                                   |
| -------------------------- | -------------------------------------- | -------------------------------------- |
| 核心                       | 核酸（DNA 或 RNA）                     | 携带遗传信息，决定病毒的复制和感染特性 |
| 衣壳（Capsid）             | 蛋白质亚单位（衣壳粒）                 | 保护核酸，介导与宿主细胞的识别结合     |
| 核衣壳                     | 核酸 + 衣壳                            | 病毒的最小感染单位                     |
| 包膜（Envelope，部分病毒） | 来源于宿主细胞膜的脂双层，含糖蛋白刺突 | 参与细胞识别，对低 pH/S/D 处理敏感     |

**有包膜 vs. 无包膜病毒的质控意义**

这一区分对病毒清除工艺设计具有决定性意义：

| 类别       | 代表病毒                                      | 对低 pH 灭活的敏感性         | 对纳滤的截留性     |
| ---------- | --------------------------------------------- | ---------------------------- | ------------------ |
| 有包膜病毒 | MuLV（~80 nm）、BVDV（~60 nm）、HIV           | **高度敏感**（脂膜被破坏）   | 较大，易截留       |
| 无包膜病毒 | MVM（~20 nm）、PPV（~20 nm）、Reo-3（~70 nm） | **基本无效**（无脂膜可破坏） | 小颗粒，截留难度高 |

**生物制品生产中病毒的主要来源**

```
细胞株（宿主细胞）
├── 内源性逆转录病毒序列（ERV，CHO 细胞基因组整合）
└── 传代历史中引入的外源病毒

培养基及原辅料
├── 牛血清（BVDV、BPV 等牛源病毒）
├── 胰酶（PPV 等猪源病毒）
└── 其他动物源性添加剂

生产环境
├── 操作人员（呼吸道病毒、皮肤携带病毒）
├── 水系统和空调系统
└── 污染物料的交叉传播
```

:::

## 细胞库阶段的污染控制策略：三类风险的系统识别与预防措施

:::answer

**细胞库（MCB/WCB）阶段的核心污染风险**

细胞库的建立和维护是整个生物制品生产的起点，这一阶段的污染控制质量直接影响所有后续批次的安全性。须重点关注以下三类污染风险。

**风险一：支原体污染（来自细胞本身和动物源性材料）**

- **污染来源：** 细胞株原始来源（如人源组织来源的细胞系）可能携带支原体；建库过程中使用的牛血清、胰酶等动物源性原材料可能含有支原体；
- **特殊风险：** 支原体可通过 0.22 μm 过滤器，因此常规除菌过滤无法去除；
- **控制措施：** MCB 建立时须进行支原体检测（培养法 + 指示细胞法）；使用经验证的无支原体来源的原材料；尽可能采用无血清化学限定培养基。

**风险二：建库过程中开放性操作引入的污染**

- **污染来源：** 细胞库建立过程涉及多次开放性操作（传代、分装、冻存等），每次开放操作均为环境微生物（细菌、真菌）提供进入机会；
- **控制措施：** 在 B 级背景 A 级区域（GMP 规定）进行细胞库建立操作；严格执行无菌操作规程（SOP）；建库批次完成后进行细菌/真菌无菌检查。

**风险三：病毒污染（来自细胞本身和动物源性材料）**

- **污染来源：** 细胞株本身的内源性逆转录病毒（ERVs）；动物源性原材料（牛血清→牛源病毒；胰酶→猪源病毒）；建库过程中偶发的外源病毒引入；
- **控制措施：** MCB 须完成系统性外源病毒因子检测（体内法 + 体外法）；逆转录病毒须多方法联合检测；完成牛源/猪源性病毒专项检测（若历史上使用过相关来源原材料）。

**细胞库表征检测的完整性要求**

《中国药典》三部规定：MCB 建立后须至少进行一次**全面检定**；每次从 MCB 建立新的 WCB，须按规定项目检定；当生产工艺发生改变时，应重新对 EOPC 进行检测。

:::

## 细胞培养阶段的污染控制策略：培养基风险、开放操作与动物源性材料管理

:::answer

**细胞培养阶段的特殊挑战**

与细胞库建立相比，细胞培养（上游生产）阶段面临更长的运行周期（Fed-batch 通常 10～14 天）和更大的操作规模，一旦发生污染，其经济损失和质量影响远大于细胞库阶段，且污染可能在一定时间后才被发现（尤其是支原体）。

**风险一：培养基引入支原体污染**

- **风险来源：** 传统含血清培养基中的牛血清是支原体的主要来源（牛血清中口腔支原体和精氨酸支原体的自然携带率不可忽视）；
- **控制措施：**
  - 采用化学限定培养基（CDM）替代含血清培养基（最根本的解决方案）；
  - 若必须使用含血清培养基，须对每批牛血清进行支原体检测并建立供应商审计体系；
  - 在培养基配制后、使用前进行支原体快速检测（PCR 法）；
  - 对进入生产环境的所有培养基实施除菌过滤（0.22 μm）。

**风险二：开放性操作引入污染**

- **风险来源：** 种子细胞接种、补料添加、取样操作等均可能引入环境微生物；
- **控制措施：**
  - 尽可能采用密闭系统（Closed System）减少开放操作节点；
  - 所有开放操作在 B 级背景下的 A 级区域进行；
  - 建立无菌操作技能培训和考核体系；
  - 对培养液定期进行无菌性快速检测（环境监控）。

**风险三：动物源性材料引入病毒污染**

- **风险来源：** 补料液中含有水解物（动物来源）、生长因子（动物来源）等组分，可能携带动物源病毒；
- **控制措施：**
  - 优先选用重组技术生产或化学合成的培养基组分；
  - 所有动物源性原料须经过来源控制、检测和必要的病毒灭活处理；
  - 建立原料供应商的病毒安全性文件档案（TSE/BSE 证书、来源声明）；
  - 对使用一次性耗材（储液袋、管路、过滤器）须进行浸出物/可提取物评估，排除其作为病毒载体的可能性。

**上游工艺过程中间体控制检测项（关键放行指标）**

| 检测项目        | 检测时机          | 目的                 |
| --------------- | ----------------- | -------------------- |
| 无菌检查        | 收获前 / 关键节点 | 检出细菌/真菌污染    |
| 支原体检测      | 每批收获液        | 检出支原体污染       |
| 外源病毒（UPB） | 收获液            | 检出外源病毒污染     |
| 细胞活率        | 每日监控          | 间接反映培养环境异常 |

:::

## 纯化工艺阶段的污染控制策略：无菌保障、支原体风险与微粒控制

:::answer

**纯化工艺阶段的特殊性**

与上游细胞培养相比，纯化工艺阶段的产品处于逐步澄清和浓缩的状态，微生物污染造成的影响更为直接——一旦污染发生，不仅影响该批次产品的质量，还可能污染整个纯化系统（层析柱、超滤系统、缓冲液系统等），导致后续批次连带受影响。

**风险一：人员操作引入支原体污染**

- **风险来源：** 纯化操作中，操作人员本身（口腔支原体、呼吸道）是主要的环境支原体来源；
- **特殊性：** 单抗纯化过程中使用的含蛋白质的缓冲液为支原体的生长提供了丰富营养，比常规缓冲液更易促进支原体繁殖；
- **控制措施：** 操作人员须穿戴符合规定的防护装备（口罩、手套、专用操作服）；密闭操作系统；定期对纯化间空气进行支原体监测（环境监测计划）。

**风险二：单抗制品的特殊微生物生长促进效应**

这是单抗产品纯化阶段特有的风险：高浓度抗体溶液（富含氨基酸、辅因子等）为细菌和支原体提供了比常规缓冲液更优越的营养环境，使微生物一旦污染后具有更强的生长和繁殖能力。

- **控制措施：** 缩短纯化工艺的连续操作时长（设定中间产物保存时限）；对纯化中间体定期进行生物负载（Bioburden）检测；层析设备和超滤系统须定期进行化学清洁（CIP）验证；层析介质须定期进行再生和消毒（0.5M NaOH 清洗是常见的病毒/微生物灭活手段）。

**风险三：无菌操作的 GMP 要求**

- 纯化工艺须在符合 GMP 要求的洁净区域进行；
- 最终除菌过滤须在 B 级背景下的 A 级环境中进行；
- 关键操作的环境监控须纳入常规监测计划（定期采样，悬浮粒子、微生物）。

:::

## 制剂生产阶段的污染控制策略：外源微粒、内源性微粒与车间布局的三维控制

:::answer

**制剂生产阶段的污染特征**

制剂生产是产品与患者最近的一个生产环节，这一阶段的污染控制不仅关乎产品的微生物安全性，还须特别关注**微粒污染**（Particulate Contamination）——包括外源引入的微粒和产品本身在制剂过程中产生的内源性微粒。

**风险一：外源性微粒的引入**

外源性微粒来源于生产环境和设备：

| 微粒来源                        | 典型粒径           | 控制手段                            |
| ------------------------------- | ------------------ | ----------------------------------- |
| 玻璃碎片（来自安瓿、西林瓶）    | 可见～不可见       | 玻璃瓶质量控制 + 灌装设备维护       |
| 金属颗粒（来自灌装设备磨损）    | 不可见             | 设备材质选择（316L SS）+ 定期维护   |
| 硅油液滴（来自胶塞/注射器内壁） | 不可见（1～10 μm） | 硅油用量优化 + 一次性密封系统       |
| 橡胶颗粒（来自胶塞）            | 不可见             | 胶塞清洗工艺 + 材质认证             |
| 纤维（来自洁净服/过滤器）       | 可见               | 无纤维脱落洁净服 + 过滤器完整性测试 |

**风险二：内源性微粒（产品相关颗粒）**

内源性微粒是由产品蛋白质本身在制剂过程中产生的：

- **蛋白质聚集颗粒（Protein Particles）：** 高浓度制剂在混合、过滤、灌装过程中受到的机械应力（剪切、搅拌）可诱导蛋白聚集；
- **冻融诱导聚集：** 冻干和复溶过程中的热应力和冰晶损伤；
- **光诱导聚集：** 光敏感氨基酸（Met、Trp、Phe）在光照下发生氧化，诱导聚集；

内源性微粒控制须从制剂配方（辅料保护）、工艺参数（混合速度、泵速）、包材选择（遮光）等多个维度综合管理。

**风险三：厂房设施与车间布局的污染控制能力**

GMP 合规的厂房设施设计是污染控制的物理基础：

- **单向气流（Laminar Flow）** 保护灌装区域（A 级）免受环境污染；
- **压差梯度设计：** 关键区域保持正压，防止低洁净级区域的空气流向高洁净级区域；
- **人物流分离：** 物料和人员进出路线的严格分隔，防止交叉污染；
- **设备清洁和灭菌（CIP/SIP）** 的可验证性——设备设计须无死角，所有接触产品的表面均可达、可清洗；
- **一次性系统（Single-Use Systems）的应用：** 减少清洁验证负担，降低交叉批次污染风险，但须评估浸出物/可提取物的安全性。

:::

## 下游病毒灭活与去除工艺的方法分类、LRV 水平与多重屏障体系的累积计算

:::answer

**工艺方法分类**

病毒去除/灭活方法按作用机制可分为两大类：

**灭活法（使病毒失活，不去除颗粒）**

| 方法                          | 有效对象       | 典型 LRV | 局限                         |
| ----------------------------- | -------------- | -------- | ---------------------------- |
| 低 pH 灭活（pH 3.5～3.7）     | **有包膜病毒** | 4～6 log | 对无包膜病毒无效             |
| 有机溶剂/去污剂（S/D）法      | **有包膜病毒** | 4～6 log | 对无包膜病毒无效；须去除残留 |
| 热力消毒（巴氏消毒，60℃/10h） | 部分有/无包膜  | 4～6 log | 可能影响蛋白活性             |
| 辐射（UV/Gamma）              | 广谱           | 2～4 log | 可能损伤产品；实验室研究为主 |

**去除法（物理去除病毒颗粒）**

| 方法                      | 有效对象                    | 典型 LRV                | 优势                                           |
| ------------------------- | --------------------------- | ----------------------- | ---------------------------------------------- |
| 纳滤（20 nm 截留）        | **有/无包膜病毒（≥20 nm）** | MuLV ≥6 log；MVM ≥4 log | 对无包膜病毒有效，是细小病毒的唯一可靠去除手段 |
| 层析（Protein A/CEX/AEX） | 多种类型                    | 2～5 log                | 各层析对不同类型病毒有不同程度的吸附/截留      |

**典型单抗工艺的累积病毒清除能力**

| 工艺步骤               | MuLV（有包膜）LRV | MVM（无包膜）LRV |
| ---------------------- | ----------------- | ---------------- |
| Protein A 亲和层析     | 2～4 log          | 0～1 log         |
| 低 pH 病毒灭活         | **4～6 log**      | ≈0 log（无效）   |
| CEX 阳离子层析         | 2～4 log          | 1～3 log         |
| AEX 阴离子层析（流穿） | 2～4 log          | 2～4 log         |
| 纳滤（20 nm）          | **≥6 log**        | **≥4 log**       |
| **累积总计（典型）**   | **≥16～20 log**   | **≥5～8 log**    |

**行业基准要求**

根据 ICH Q5A 和国内法规，对于主要风险病毒，工艺的整体累积清除能力通常期望达到 **≥6 log**（即 100 万倍清除）；抗体药物工艺通常可远超此要求（可达 15～20 log 以上），提供了充足的安全边际。

:::

## 病毒清除验证的缩小模型要求：代表性条件设计与模型等效性证明

:::answer

**缩小模型的必要性**

病毒清除验证不得在商业化规模的 GMP 生产设施中进行（防止病毒污染生产环境），须在专用的生物安全实验室中，使用<strong>小规模缩小模型（Scale-down Model）</strong>开展。缩小模型须通过验证（Qualification），证明其对商业化生产工艺具有代表性。

**缩小模型须代表的关键参数体系**

高质量的缩小模型须在以下维度与商业化生产工艺保持等效：

**层析步骤的等效性参数**

| 参数类别     | 须保持等效的具体参数                                 |
| ------------ | ---------------------------------------------------- |
| 设备与介质   | 层析设备类型、层析介质型号和批次                     |
| 柱几何参数   | 床高（Bed Height）须与商业化规模一致                 |
| 操作参数     | 线性流速（Linear Flow Rate, cm/h）须与商业化规模一致 |
| 接触时间     | 过柱时间（Residence Time）须等效                     |
| 缓冲液条件   | 缓冲液组成、pH、离子强度                             |
| 产品相关参数 | 蛋白浓度（上样液和洗脱液）、盐浓度                   |
| 洗脱方案     | 梯度或步进洗脱方案须类似商业化工艺                   |

**纳滤步骤的等效性参数**

| 参数               | 须等效理由                     |
| ------------------ | ------------------------------ |
| 滤器型号和批次     | 不同批次的截留能力一致性须验证 |
| 跨膜压力（TMP）    | 影响截留效率                   |
| 上样蛋白浓度       | 高浓度蛋白影响通量和截留       |
| 过滤体积（总通量） | 影响截留效率下降趋势           |
| 温度               | 影响料液流变性                 |

**模型等效性的证明方式**

- 通过使用相同工艺参数（模型工艺 vs. 商业化工艺），比较蛋白收率、产品质量属性（聚体、电荷变体）、杂质清除水平（HCP、HCD）等关键性能指标；
- 通常须提供 ≥3 批代表性运行数据，统计证明模型与商业化规模在关键性能上无显著差异。

:::

## 病毒清除验证最差条件设计：各工艺步骤关键参数的最差方向与科学依据

:::answer

**最差条件设计的核心原则**

病毒清除验证须在**最差工艺条件（Worst-Case Conditions）**下进行，其目的是证明：即使在生产实际中参数控制处于允许范围的最不利端，工艺步骤仍然能够提供足够的病毒清除能力。最差条件≠极端破坏性条件，而是在**工艺可接受范围内（PAR）**对病毒清除最不利的参数组合。

**低 pH 病毒灭活步骤的最差条件**

| 参数     | 最差条件方向                          | 科学依据                                                   |
| -------- | ------------------------------------- | ---------------------------------------------------------- |
| pH 值    | **最高接受值**（如 pH 3.8）           | pH 越高，灭活效率越低；pH 3.8 比 pH 3.5 的灭活效率显著降低 |
| 灭活时间 | **最短时间**（如 30 min 而非 60 min） | 接触时间不足是最常见的灭活失效原因                         |
| 灭活温度 | **最低温度**（如 15℃）                | 低温降低化学反应速率，减缓病毒结构破坏速度                 |
| 蛋白浓度 | **最高浓度**                          | 高蛋白可能对病毒产生"保护效应"，干扰直接 pH 作用           |

**纳滤步骤的最差条件**

| 参数                 | 最差条件方向           | 科学依据                                             |
| -------------------- | ---------------------- | ---------------------------------------------------- |
| 滤器完整性（起泡点） | 最接近规格下限的滤器   | 代表最差完整性状态下的截留能力                       |
| 蛋白浓度             | 最高                   | 高蛋白引起膜孔堵塞，可能同时降低病毒和蛋白的通过效率 |
| 总过滤体积           | 最大批量               | 过大通量可能导致膜性能衰减                           |
| 料液 pH 和离子强度   | 最不利于静电截留的条件 | 高盐/pH 偏移影响吸附截留组分                         |

**层析步骤的最差条件**

| 参数           | 最差条件方向                         | 科学依据                                 |
| -------------- | ------------------------------------ | ---------------------------------------- |
| 上样蛋白载量   | 最高                                 | 高载量可能降低病毒的结合/去除效率        |
| 线性流速       | 最高                                 | 高流速缩短样品在柱内的接触时间           |
| 缓冲液离子强度 | 最不利于病毒吸附的盐浓度             | 高盐屏蔽静电作用，降低病毒对介质的吸附   |
| 介质使用寿命   | **旧介质（超过建议使用次数的介质）** | 老化介质的病毒截留能力可能下降（见下文） |

**特别注意：层析介质寿命对病毒清除能力的影响**

这是层析步骤验证中容易被忽视的关键点：层析介质随使用次数增加，可能因配基降解、微粒堆积、化学损伤等原因导致病毒去除能力下降。

**验证要求：**

1. 须考察旧介质（通常为使用至推荐周期末端的"寿命末期"介质）的病毒清除能力；
2. 须对比分析新介质和旧介质病毒清除能力的差异，差异须在可接受范围内；
3. 若旧介质的 LRV 显著低于新介质，须重新评估介质使用周期的上限设定。

**层析步骤验证的额外数据分析要求**

除常规的 LRV 计算外，还须：

- 分析各阶段收集液（流穿液、洗涤液、洗脱液）中病毒的分布，了解病毒在哪个阶段被主要去除；
- 进行**残留携带（Carryover）试验**：验证前一次操作中吸附的病毒是否在清洗再生后被有效洗脱，不残留在介质上影响下一批次。

:::

## 有效病毒清除步骤的量化判断标准与整体病毒安全评价的计算方法

:::answer

**单步骤清除能力的三级判断标准**

根据 ICH Q5A 和行业实践，对单个工艺步骤病毒清除能力的判断，通常采用以下量化分级：

| LRV 范围     | 判断结论                                        | 在整体评估中的应用                           |
| ------------ | ----------------------------------------------- | -------------------------------------------- |
| **≥ 4 log**  | **有效病毒清除步骤（Effective Step）**          | 可计入整体累积清除能力                       |
| **1～3 log** | **有部分清除能力的步骤（Partially Effective）** | 可以计入整体清除能力，但贡献有限，须谨慎使用 |
| **< 1 log**  | **无清除能力（Ineffective）**                   | **不计入**整体清除能力的累积计算             |

**整体病毒安全评价的计算方法**

整体病毒安全评价并非简单地将所有步骤的 LRV 相加，须遵循以下系统性评价框架：

**第一步：各步骤 LRV 的独立评估**

对每个工艺步骤单独进行病毒清除验证，确定其对各指示病毒的 LRV 值（在最差条件下）。

**第二步：步骤分类**

将每个步骤分类为有效步骤、部分有效步骤或无效步骤（依据上表标准）。

**第三步：累积 LRV 计算**

将所有有效步骤（≥4 log）的 LRV 值累积相加。部分有效步骤（1～3 log）可以谨慎纳入，须有充分说明。

**第四步：安全性边际评估**

计算"每剂量病毒引入风险"：

$$\text{每剂量病毒量（理论）} = \frac{\text{潜在病毒污染水平（最坏假设）}}{\text{稀释因子} \times 10^{\text{累积LRV}}}$$

**监管机构的核心要求**

> 每剂量最终产品中潜在病毒的理论残余量，须低于<strong>百万分之一（10⁻⁶）</strong>的概率水平。

这意味着：如果假设原始污染水平为 10⁶ TCID₅₀/mL（理论最坏情况），则工艺须能提供足以将其降低至 <1 TCID₅₀/剂量（10⁻⁰ 水平）所需的总 LRV，即 ≥6 log 的有效清除能力。

**工艺设计建议**

- **实施两种不同原理的有效步骤**（如低 pH 灭活 + 纳滤），作为病毒安全控制的核心柱石；
- **其中至少一个步骤须对无包膜病毒有效**（纳滤是目前唯一被普遍认可的针对无包膜病毒的有效步骤）；
- 层析步骤（Protein A、CEX、AEX）的病毒清除贡献作为补充，不应作为单独的安全保障措施。

:::

## 先验知识在病毒清除评估中的应用边界：适用条件、代表性证明与局限性

:::answer

**先验知识应用的概念**

在某些情况下，生产企业可能无法或不需要对每个新产品的每个工艺步骤进行全套病毒清除验证，而是利用已有的<strong>先验知识（Prior Knowledge）</strong>（来自其他产品或行业公开数据）来支持新产品同一工艺步骤的病毒安全性评估。ICH Q5A(R1) 允许在特定条件下合理使用先验知识。

**先验知识应用的适用前提**

先验知识仅可用于**基于相同平台技术、类似工艺步骤**的情况下，须同时满足以下条件：

**条件一：充分理解病毒清除机制**

不同工艺步骤的病毒清除依赖特定的物理化学机制，须能清晰阐明该步骤的清除原理（如低 pH 灭活依赖包膜脂膜破坏，纳滤依赖粒径排阻），并证明新产品的工艺条件足以激活该机制。

**条件二：明确所有影响病毒清除的工艺参数**

须有充分的研究数据表明：哪些工艺参数影响该步骤的病毒清除效率，以及这些参数在新产品工艺中的实际值与先验知识来源产品的参数相比是否等效或更优。

**条件三：证明病毒与产品之间的相互作用不影响清除**

产品本身（如高浓度蛋白质、特殊辅料）可能影响病毒的灭活动力学或过滤截留效率（如蛋白质对病毒的"保护效应"）。须证明新产品与先验知识来源产品在此方面具有等效性。

**条件四：证明工艺中间体组成的代表性**

这是最关键也最容易被忽视的条件：

> 工艺中间体的**组成**（缓冲液成分、pH、蛋白浓度、杂质水平的组合）可能对病毒清除率产生显著影响。即使是看似微小的差异（不同批次的 HCP 含量差异、不同培养基组成导致的代谢产物差异），也可能改变病毒清除效率。

因此，须明确证明：为其他产品产生先验知识的工艺中间体组成，与新产品工艺中间体组成具有**足够的相似性（代表性）**。

**先验知识的来源类型**

| 来源类型                         | 适用程度                     | 注意事项                             |
| -------------------------------- | ---------------------------- | ------------------------------------ |
| 企业内部同平台其他产品的验证数据 | 较强（可控条件下获得）       | 须证明工艺参数和中间体组成的等效性   |
| 行业文献和公开数据               | 较弱（需谨慎评估）           | 须了解具体实验条件，避免过度外推     |
| 过滤器供应商提供的验证数据       | 中等（通常使用通用测试溶液） | 须证明通用测试条件对实际产品的代表性 |

**先验知识的局限性**

即使满足上述所有条件，先验知识的应用仍存在固有局限：

- 对于新型工艺步骤（首次使用该方法）或非标准条件，先验知识的可靠性显著降低；
- 若新产品与先验知识来源产品在特定步骤之前的处理策略差异显著（如一个在中性 pH 处理，另一个在酸性 pH 处理），须重新考虑中间体代表性；
- 监管机构（尤其是 FDA）对先验知识的接受度因产品类型和风险水平而异，高风险产品（如用于高脆弱性患者的产品）通常期望进行独立验证。

:::

## 低 pH 病毒灭活工艺表征研究：关键参数体系、工艺耐受边界与质量影响评估

:::answer

**低 pH 病毒灭活的工艺表征目标**

低 pH 病毒灭活步骤的工艺表征（Process Characterization）旨在系统建立工艺参数与病毒灭活效果、产品质量属性之间的定量关系，为工艺操作范围（Operational Range）和可接受范围（Proven Acceptable Range, PAR）的确立提供数据支持。

**关键工艺参数体系**

**核心参数（病毒灭活效果的主要决定因素）**

| 参数     | 典型商业化控制范围         | 最差条件方向        | 灭活失效的主要风险                |
| -------- | -------------------------- | ------------------- | --------------------------------- |
| 灭活 pH  | 3.5～3.7（目标 3.6）       | pH 偏高（>3.8）     | pH > 3.8 时 MuLV 灭活效率显著降低 |
| 灭活时间 | 60～90 min（通常 ≥60 min） | 时间偏短（<60 min） | 接触时间不足是最常见灭活失效原因  |
| 灭活温度 | 15～25℃（室温）            | 温度偏低（<15℃）    | 低温降低反应速率                  |
| 蛋白浓度 | 通常 <5 mg/mL              | 浓度偏高            | 高蛋白可能对病毒有保护效应        |

**pH 对灭活动力学的非线性影响（重要认知）**

低 pH 灭活的有效性对 pH 值极度敏感，且影响是非线性的：

- **pH 3.5～3.7：** 有效灭活范围，MuLV 在 30 min 内通常可实现 ≥4 log 清除；
- **pH 3.8：** 灭活效率已有显著下降（可能降至 2～3 log）；
- **pH >4.0：** 灭活效率进一步大幅下降，不能作为有效灭活步骤；
- **pH <3.5：** 灭活效率继续提升，但蛋白聚集风险显著增加（尤其是初始聚集倾向较高的抗体）。

这种"窗口效应"要求在工艺开发中精确确定最优 pH 范围，并在验证中充分测试 pH 上限（最差条件）。

**对产品质量属性的影响评估**

低 pH 处理可能对产品产生以下质量影响，须在工艺表征中进行系统评估：

| 质量属性           | 潜在影响机制                         | 监控检测项              |
| ------------------ | ------------------------------------ | ----------------------- |
| 蛋白聚集（HMW）    | 酸性条件下静电排斥减弱，疏水暴露增加 | SEC-HPLC 聚体%          |
| 电荷变体（酸性峰） | 低 pH 可能加速天冬酰胺脱酰胺         | IEX-HPLC / iCIEF 电荷谱 |
| 生物学活性         | 抗体 Fab 区在极低 pH 下可能构象改变  | ELISA 结合活性          |
| Fc 功能            | CH2 区对低 pH 的耐受性因分子不同而异 | FcRn 结合（SPR）        |

:::

## 除病毒纳滤工艺：进料预处理对通量的决定性影响与蛋白浓度优化策略

:::answer

**纳滤性能的主要影响因素**

除病毒纳滤（Virus Filtration, VF）步骤的工艺性能（通量、收率、病毒截留能力）高度依赖于以下两个关键因素：**进料溶液中的蛋白质浓度**和**杂质水平（尤其是大分子杂质）**。这两个因素决定了纳滤步骤所需的滤膜面积和操作时间。

**进料溶液位置的影响**

在不同纯化步骤的位置放置纳滤步骤，进料液的组成差异显著：

| 纳滤步骤位置           | 典型蛋白浓度       | 典型杂质水平                | 对纳滤的影响                 |
| ---------------------- | ------------------ | --------------------------- | ---------------------------- |
| Protein A 之后（早期） | 较低（稀释洗脱液） | 较高（HCP、HCD 较多）       | 杂质堵塞风险高，需更大膜面积 |
| 精纯步骤之后（晚期）   | 较高（可能已浓缩） | 较低（精纯后 HCP/HCD 极低） | 蛋白浓度成为主要限制因素     |

通常认为将纳滤置于精纯步骤之后（杂质水平较低）更有利于降低膜堵塞风险，但需要注意高蛋白浓度对通量的负面影响。

**蛋白浓度对纳滤性能的影响机制**

较高的蛋白浓度会降低纳滤过程的速率和通量，原因包括：

- **浓差极化（Concentration Polarization）：** 蛋白质在膜表面积聚，形成高浓度边界层，增加渗透阻力；
- **凝胶层（Gel Layer）形成：** 极端情况下，膜表面形成蛋白质凝胶层，严重降低通量；
- **蛋白-膜相互作用：** 特定蛋白质与膜材料的非特异性相互作用可能导致不可逆通量衰减。

**蛋白浓度管理策略**

- 若进料蛋白浓度过高，可通过**适当稀释**降低进料浓度，提高纳滤通量和载量；
- 稀释会增加总体积，须平衡通量改善与操作时间延长之间的权衡；
- 须在工艺开发中系统考察不同蛋白浓度下的通量和载量曲线，确定最优操作范围。

**进料预过滤的关键作用**

纳滤之前的<strong>预过滤（Pre-filtration）</strong>是提升纳滤性能最有效、性价比最高的手段：

- **目标：** 去除可能堵塞纳滤膜的大分子杂质——蛋白质聚集体（HMW）、DNA 片段、细胞碎片、胶体颗粒等；
- **效果：** 适当的预过滤可将纳滤膜面积需求降低**近 10 倍**；
- **常用预过滤器：** 0.1～0.45 μm 孔径的除菌级过滤器或深层过滤器（取决于杂质颗粒大小）；
- **注意：** 预过滤须不影响产品收率（确认产品不被预过滤器吸附）。

:::

## 上游污染控制总体策略：污染控制策略（CCS）体系的建立与系统性管理框架

:::answer

**污染控制策略（CCS）的定义**

污染控制策略（Contamination Control Strategy, CCS）是指：基于对当前产品和工艺的理解，为确保工艺性能和产品质量，制定一套**有计划的、系统性的**针对微生物（细菌、真菌、支原体）、内毒素/热原和微粒的控制措施体系。

CCS 包含的控制维度：

- 活性物质、辅料、成品的组成与成分控制；
- 设施和设备运行状态的控制；
- 过程控制（工艺参数监控、环境监控）；
- 成品质量标准；
- 监控方法和监控频次的设定。

**为什么需要系统性 CCS 而非分散的单点措施**

生物制品的污染控制具有高度复杂性——污染来源多样（人员、环境、设备、物料）、传播途径复杂（气溶胶、直接接触、间接传播）、某些污染（支原体）难以及时发现。分散的、单一的控制措施（如仅依赖无菌检查）往往难以：

- 形成系统性防控体系；
- 帮助管理者对污染控制状态进行整体把控；
- 在污染事件发生后快速找到根本原因（Root Cause）并制定有效的纠正措施。

**系统性 CCS 的建立方法**

**第一步：污染源识别**

系统梳理产品整个生产过程中所有可能的污染来源，建立"污染源地图"：

| 阶段       | 污染源类别                       | 典型污染物         |
| ---------- | -------------------------------- | ------------------ |
| 细胞库建立 | 细胞本身、动物源性原料、开放操作 | 支原体、病毒       |
| 细胞培养   | 培养基、补料液、操作人员         | 支原体、细菌、真菌 |
| 收获与澄清 | 环境、设备表面                   | 细菌、真菌         |
| 纯化       | 操作人员、设备、缓冲液           | 细菌、支原体       |
| 制剂与灌装 | 环境、包材、设备                 | 细菌、微粒         |

**第二步：风险评估**

对每类污染源进行风险评估（可能性 × 影响程度），识别高风险控制点（Critical Control Points, CCPs）。

**第三步：控制措施设计**

针对每个高风险控制点，设计具体的控制措施，形成 CCS 矩阵（污染源 → 风险等级 → 控制措施 → 监控方法 → 监控频次 → 责任部门）。

**第四步：持续监控与改进**

建立 CCS 的效果评估机制（关键微生物指标的趋势分析），当监测数据出现趋势性偏差时，及时调查并更新 CCS。

:::

## 上游污染物分类与快速鉴别：细菌、真菌、支原体的特征识别与四种控制手段

:::answer

生物制品上游培养过程中的常见污染物分为四类：**细菌、真菌、支原体、病毒**。前三类（细菌、真菌、支原体）为微生物污染，第四类（病毒）为病毒污染，各自的检测方法和控制策略有本质差异。

**四类污染物的快速特征对比**

| 污染物       | 粒径范围           | 0.22 μm 过滤可去除     | 光学显微镜可见      | 培养液浑浊               | 发现速度          |
| ------------ | ------------------ | ---------------------- | ------------------- | ------------------------ | ----------------- |
| 细菌         | 0.5～5 μm          | ✓                      | ✓（菌体清晰可见）   | 通常浑浊                 | 快（1～2天）      |
| 真菌（霉菌） | 2～数百 μm（菌丝） | ✗（菌丝太大）          | ✓（丝状菌丝）       | 通常不浑浊（表面漂浮物） | 较快（2～5天）    |
| 真菌（酵母） | 3～10 μm           | ✓（但孢子可能通过）    | ✓（卵圆形）         | 轻度浑浊                 | 较快              |
| 支原体       | 0.1～0.3 μm        | ✗（可通过 0.22 μm 膜） | ✗（光学镜下不可见） | 通常**不浑浊**           | **极慢/难以发现** |
| 病毒         | 0.02～0.3 μm       | ✗（依赖纳滤 20 nm）    | ✗                   | 不浑浊                   | 仅通过专项检测    |

:::

## 上游污染一：细菌污染的来源分析、培养液特征与显微镜下鉴别要点

:::answer

**细菌污染的来源**

细菌污染是细胞培养中**最常见**的污染类型，其来源可归纳为以下几类：

| 污染来源           | 典型情形                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| **实验室环境**     | 开放培养皿、培养瓶时环境中细菌直接落入培养液                                                      |
| **操作人员**       | 皮肤表面细菌、飞沫（即使戴口罩也存在风险）、不规范无菌操作                                        |
| **实验用具**       | 未经充分灭菌的容器、移液管、培养基等                                                              |
| **培养基制备**     | 培养基灭菌不彻底（高压灭菌参数不足）；灭菌后冷却过程中污染                                        |
| **抗菌素使用不当** | 在培养液中添加青霉素/链霉素（预防剂量）可以抑制部分细菌，但不能杀灭耐药菌，且会掩盖慢性低水平污染 |

**常见污染细菌种类**

- **革兰氏阳性菌（G⁺）：** 枯草芽孢杆菌（Bacillus subtilis）、葡萄球菌（Staphylococcus spp.）、链球菌（Streptococcus spp.）；
- **革兰氏阴性菌（G⁻）：** 大肠埃希菌（E. coli）、假单胞菌（Pseudomonas spp.）——后者还是除菌过滤验证中的标准挑战菌。

**细菌污染的宏观与镜下特征**

**宏观特征（肉眼观察）：**

- 培养液通常出现**明显浑浊**（常规细菌）——培养液从清亮变为乳白色或云雾状；
- 培养液 pH 明显下降（细菌代谢产生乳酸、有机酸）；
- 少数情况下（革兰氏阴性菌低密度污染），培养液肉眼可能无明显改变，须每日仔细镜检。

**显微镜检特征：**

- 在倒置光学显微镜下，可见**大量游动的细小颗粒**（细菌菌体）散在细胞间隙；
- 被污染的细胞出现：胞浆内大量颗粒形成 → 细胞变圆 → 细胞从培养壁脱落 → 细胞死亡；
- 污染进程迅速：通常在污染后 **1～2 天**内即可肉眼观察到明显变化。

**发现细菌污染后的处置**

1. 立即隔离被污染的培养容器，防止扩散；
2. 弃置被污染的细胞（不得继续传代）；
3. 对生物安全柜、孵箱进行彻底消毒；
4. 排查污染来源（培养基、操作记录回溯）；
5. 若使用抗菌素，须评估其是否掩盖了早期污染信号，考虑停用并加强无菌操作培训。

:::

## 上游污染二：真菌污染的种类差异、季节性规律与菌丝/酵母的镜下区分特征

:::answer

**真菌污染的特点与危害**

真菌（霉菌和酵母菌）是细胞培养中另一类**常见污染源**，其特殊危害在于：

- 霉菌可通过**孢子繁殖**，一旦孢子散播，极易在培养设施中大范围扩散；
- 真菌污染往往在**早期不引起培养液浑浊**，容易被延迟发现；
- 真菌会释放**次级代谢物**（毒素），对细胞产生毒害，导致细胞活力下降、生长速度减缓，甚至死亡。

**两类真菌污染的特征对比**

| 特征             | 霉菌（Mold，丝状真菌）                                               | 酵母菌（Yeast，单细胞真菌）                                          |
| ---------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 代表种类         | 烟曲霉（Aspergillus fumigatus）、黑曲霉（A. niger）、毛霉（Mucor）等 | 白色念珠菌（Candida albicans）、酿酒酵母（Saccharomyces cerevisiae） |
| 形态             | 丝状、管状、树枝状菌丝                                               | 卵圆形或球形，可见出芽                                               |
| 在培养液中的表现 | 短期内通常**不浑浊**，可在培养液表面形成**白色/黄色斑点状漂浮物**    | 可导致培养液**轻度至明显浑浊**                                       |
| 显微镜下特征     | 高倍镜下可见**纵横交错的丝状/管状/树枝状菌丝**穿插在细胞间           | 可见散在分布于细胞周边的**卵圆形颗粒**，部分可见出芽                 |
| 对细胞影响       | 竞争营养 + 毒素释放 → 细胞活力渐进性下降                             | 竞争营养 + 培养液 pH 变化                                            |
| 季节性规律       | **霉雨季节（梅雨期）尤为严重**                                       | 全年可见                                                             |

**真菌污染的防控措施**

- 实验室保持低湿度（相对湿度 <60%），减少霉菌孢子萌发的条件；
- 培养箱内水盘水须添加抑菌试剂（如硫酸铜、苯扎氯铵）；
- 严格避免使用过期培养基（真菌可在低温储存的培养基中以孢子形式存活）；
- 规范操作人员的穿戴（无孢子释放的专用洁净服）；
- 对培养设施进行定期的表面消毒（70% 乙醇 + UV 照射）。

:::

## 上游污染三：支原体的生物学特性、隐蔽性来源与检测方法的选择逻辑

:::answer

**支原体的生物学特性**

支原体（Mycoplasma）是一类大小介于细菌和病毒之间的**原核微生物**，在生物制品生产中被视为最难控制的污染物之一，其特殊性在于：

| 特性               | 描述                             | 质控意义                                                      |
| ------------------ | -------------------------------- | ------------------------------------------------------------- |
| 粒径极小           | 0.1～0.3 μm                      | **可轻易穿透 0.22 μm 和 0.45 μm 除菌过滤器**，常规过滤无效    |
| 无细胞壁           | 无刚性细胞壁（仅细胞膜）         | 对 β-内酰胺类抗生素（青霉素）天然耐药；对温度和渗透压变化敏感 |
| 光学显微镜不可见   | 光学镜下无法分辨                 | 常规镜检无法发现支原体污染，须专门检测方法                    |
| 与宿主细胞紧密结合 | 可直接紧密结合于细胞膜           | 支原体能在细胞表面形成稳定的共存关系，导致隐蔽性污染          |
| 污染具有隐蔽性     | 被污染细胞培养液通常**不浑浊**   | 无法通过培养液外观判断是否有支原体污染                        |
| 与宿主长期共存     | 大部分细胞被污染后似乎无明显变化 | 支原体可能长期存在而不被发现，导致细胞遗传物质损伤积累        |

**细胞培养中常见的支原体种类**

| 支原体种类                               | 来源                 | 污染频率           |
| ---------------------------------------- | -------------------- | ------------------ |
| 口腔支原体（Mycoplasma orale）           | 人类口腔（操作人员） | **极高（最常见）** |
| 精氨酸支原体（M. arginini）              | 牛血清               | **极高**           |
| 莱氏无胆甾原体（Acholeplasma laidlawii） | 环境                 | 较高               |
| 猪鼻支原体（M. hyorhinis）               | 猪胰酶               | 较高               |
| 肺炎支原体（M. pneumoniae）              | 人类呼吸道           | 较低               |
| 发酵支原体（M. fermentans）              | 人类泌尿生殖道       | 较低               |

> 前四类占据细胞培养支原体污染的**绝大比例（>90%）**，是重点监控对象。

**支原体对细胞的慢性危害**

虽然支原体感染不像细菌污染那样会迅速导致细胞死亡，但其慢性影响对生物制品生产危害极大：

- **抑制细胞生长：** 支原体与宿主细胞竞争营养物质（尤其是精氨酸、胆固醇），导致细胞增殖速率下降；
- **染色体畸变（Chromosomal Aberration）：** 某些支原体可诱导宿主细胞染色体损伤，影响细胞遗传稳定性；
- **影响产品质量：** 支原体感染可能影响细胞的糖基化等翻译后修饰，导致产品质量属性漂移；
- **可能影响病毒检测结果：** 支原体污染可能影响用于外源病毒检测的指示细胞的活性和敏感性，导致假阴性结果。

**支原体检测方法的选择**

| 检测方法                       | 原理                                            | 优势                                | 局限                                                 | 应用场景                     |
| ------------------------------ | ----------------------------------------------- | ----------------------------------- | ---------------------------------------------------- | ---------------------------- |
| 培养法（固体/液体培养基）      | 支原体在专用培养基上形成特征性"荷包蛋"菌落      | 直接观察，无假阳性                  | 周期长（7～28 天），某些支原体不可培养               | 细胞库最终放行检测（药典法） |
| 指示细胞法（Hoechst 荧光染色） | 支原体 DNA 被 DAPI/Hoechst 染色后在荧光镜下可见 | 可检测不可培养支原体                | 须有指示细胞；操作繁琐                               | 批放行检测                   |
| PCR / qPCR                     | 扩增支原体特异性 16S rRNA 基因序列              | **最快（1天内）**；高灵敏度；高通量 | 可能检测到死菌 DNA（假阳性问题）；须设计泛支原体引物 | 快速筛查；原料放行检测       |
| ELISA（商业化试剂盒）          | 抗支原体抗体检测                                | 操作简便                            | 特异性取决于试剂盒设计；通量有限                     | 辅助检测                     |

**《中国药典》的规定**

《中国药典》三部要求，MCB/WCB 的支原体检测须同时采用**培养法 + 指示细胞培养法**两种方法，批放行检测可采用以上方法之一，且须经过方法适用性试验。

**支原体污染发现后的处置**

一旦确认支原体污染：

1. 立即停用被污染的细胞库/批次；
2. 隔离污染区域，防止扩散；
3. 调查污染来源（牛血清来源、操作人员来源、培养基来源）；
4. **严禁**尝试用抗生素（如泰乐菌素等支原体敏感抗生素）"治疗"被污染的生产用细胞——支原体一旦污染 GMP 生产细胞库，该细胞库通常须废弃，并从未污染的备份中重新建立。

:::
