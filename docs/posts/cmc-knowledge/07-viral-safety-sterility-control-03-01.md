## 无菌保障的两种工艺路线：非最终灭菌与最终灭菌工艺

:::answer

无菌制剂采用何种工艺生产，由产品的理化特性（热稳定性、辐射敏感性等）决定，须在产品研发早期基于"质量源于设计"（QbD）理念确定工艺路线，并贯穿整个产品生命周期。

### 两种工艺路线的核心区别

| 比较维度                | **非最终灭菌工艺（无菌生产工艺）**                                 | **最终灭菌工艺**                                             |
| ----------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------ |
| **适用产品**            | 热不稳定、辐射敏感的蛋白质类药物（单克隆抗体、重组蛋白等）         | 热稳定的小分子注射剂（大容量/小容量注射液）                  |
| **灭菌时机**            | 灌装**之前**（通过除菌过滤 + 无菌操作）                            | 灌装**之后**（产品在最终容器中灭菌）                         |
| **核心原理**            | 通过无菌系统环境 + 无菌操作法 + 除菌过滤，以**防止污染**为核心目标 | 通过湿热灭菌（121°C/15 min）或其他手段在最终容器中消灭微生物 |
| **关键操作环境**        | 灌装和密封须在 **B 级背景中的 A 级**（最高洁净度）中进行           | 灌装和密封在 **C 级背景下的 A 级**即可                       |
| **无菌保证水平（SAL）** | **较低**（影响无菌操作的因素多）                                   | **更高**（终端灭菌工艺的 SAL 可达 10⁻⁶）                     |
| **成本**                | 较高（高洁净度要求，严格环境控制）                                 | 相对较低                                                     |

### 无菌保证水平（SAL）的含义

**SAL（Sterility Assurance Level）** 是指产品经灭菌/除菌后微生物残存的概率：

- 数值越小，产品中微生物存在的概率越小，安全性越高
- 最终灭菌产品通常要求 SAL ≤ 10⁻⁶（即每百万件产品中允许存在 1 件非无菌品的概率）
- 无菌生产工艺由于影响因素多，其 SAL 通常高于最终灭菌工艺，因此须通过更严格的工艺验证来弥补

### 无菌工艺有效性的评价重点

对于非最终灭菌工艺，评价有效性的重点不在于单次检测结果，而更注重：

1. **工艺设计的合理性**（除菌过滤膜的规格、连接系统的密封性）
2. **设备与工艺的充分验证**（包括培养基灌装试验/工艺模拟试验，APS）
3. **按照验证后工艺严格执行**（操作规程的遵循）
4. **环境监控体系的完整性**（A/B 级区域的动态监控）

### 无菌注射剂的特殊安全要求

注射剂可直接进入血液循环，发挥药效快，但如产品本身不是无菌的，病人面临的生命威胁极其严重。这是注射剂无菌要求比口服制剂更严格的根本原因。

:::

## 无菌灌装工序：高风险操作步骤的关键控制要点

:::answer

无菌灌装是非最终灭菌生产工艺中风险最高的单元操作，除菌过滤后的产品将直接暴露于环境中，任何操作失误均可导致批次污染，须在严格的工艺控制和环境监控下进行。

### 工艺操作要点

**灌装前准备：**

- 工器具（灌装针、硅胶管、储液容器等）的清洗和高压灭菌（或伽马射线灭菌）
- 灌装设备的部件装配，须在 A 级保护下进行
- 灌装程序参数的设定和设备调试（须有批记录记录所有参数）

**灌装操作环境：**

- **关键操作区域：** A 级单向流（洁净度 ISO 5 级）
- **背景环境：** B 级（洁净度 ISO 7 级，动态条件下）
- 须尽可能缩短灌装和密封的时间（减少产品的开放暴露时间）

### 过程控制参数

| 控制参数         | 控制目标                                                      |
| ---------------- | ------------------------------------------------------------- |
| **灌装网带速度** | 影响每瓶的灌装时间和暴露时间；须与灌装量要求匹配              |
| **装量控制**     | 确保每瓶装量符合质量标准（通常 ± 2%～5%）；须定期抽样称量检查 |

### 环境监控要求

灌装过程中须持续监控以下指标（动态监控），所有数据须纳入批记录：

| 监控项目       | 监控方法               | A 级警戒限（动态） | A 级行动限（动态） |
| -------------- | ---------------------- | ------------------ | ------------------ |
| **浮游菌**     | 主动空气采样           | < 1 CFU/m³         | 1 CFU/m³           |
| **表面微生物** | 接触碟（RODAC）        | < 1 CFU/碟         | 1 CFU/碟           |
| **沉降菌**     | 被动空气采样（沉降碟） | < 1 CFU/4 h        | 1 CFU/4 h          |

### 工艺模拟试验（培养基灌装试验，APS）

无菌生产工艺须定期进行**培养基灌装试验（Aseptic Process Simulation，APS / Media Fill）**，以证明整个灌装工艺和环境的无菌保证能力：

- 用培养基（通常为胰酪大豆胨液体培养基，TSB）替代产品进行全流程模拟灌装
- 灌装后的培养基瓶在 20～25°C 和 30～35°C 各培养 7 天（共 14 天）
- 接受标准：≥ 5,000 瓶时，不得出现任何一瓶阳性（污染率 = 0）

:::

## 填料寿命终点的病毒清除能力验证要求

:::answer

层析填料的重复使用是降低生物制品生产成本的重要手段，但填料多次使用后其病毒清除能力是否维持是监管机构关注的关键问题，须通过专门的填料寿命研究加以验证。

### 填料寿命研究的双重目标

填料寿命研究须同时证明两件事：

| 验证目标             | 评估内容                                                                       |
| -------------------- | ------------------------------------------------------------------------------ |
| **常规性能维持**     | 柱效（板高 HETP）、载量、背压、产品纯度和回收率在循环次数范围内无显著变化      |
| **病毒清除能力维持** | **寿命终点（Resin at End-of-Life，REOL）时，填料的病毒清除效果须与新填料相当** |

### 需要进行寿命终点病毒清除研究的关键步骤

根据行业实践，以下两类层析步骤须在填料寿命终点时进行病毒清除研究：

**① Protein A 亲和层析（捕获步骤）**

- 寿命使用后的 Protein A 填料可能因多次碱性清洗（NaOH）导致配基降解
- 配基降解改变填料表面化学特性，可能影响对目标抗体的选择性吸附和病毒的非特异性截留能力
- 须在填料使用至循环次数上限后进行 XMuLV 等模型病毒的清除验证

**② 阴离子交换层析（精纯步骤）**

- AEX 填料多次使用后表面电荷密度可能下降
- 须验证填料寿命终点时的病毒清除能力仍满足设计目标（LRV ≥ 设定值）

### 验证设计的关键考量

- **规模一致性：** 寿命终点验证须在与生产规模成比例的小规模模型柱上进行，须证明小规模与生产规模的水动力学等效性
- **病毒模型选择：** 与常规病毒清除验证使用相同的模型病毒（确保数据的可比性）
- **最差条件原则：** 须在寿命终点最差情况的条件下进行（如填料已经历最大循环次数）

### BLA 申报要求

商业化申报时须提交填料寿命终点的病毒清除数据，证明整个产品生命周期内（按设定的填料使用寿命计）病毒清除能力的持续有效性。

:::

## 重视生物制品病毒安全性评价的历史教训与现实意义

:::answer

历史上的多起严重病毒污染事件深刻揭示了生物制品病毒安全控制的极端重要性，这些事件直接推动了现行 ICH Q5A 等法规框架的建立。

### 历史重大病毒污染事件

| 时间                | 事件                                                                                 | 后果                                                                                         |
| ------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| **1950 年代**       | 脊髓灰质炎疫苗受到猿猴病毒 **SV40** 的污染（用于制备疫苗的 Vero 猴肾细胞携带 SV40）  | 数以百万计的疫苗接种者暴露于 SV40，长期健康影响的评估持续至今                                |
| **1980～1990 年代** | 日本、美国、法国、德国等国血友病患者因使用病毒污染的血液/血液制品感染 **HIV 或 HCV** | **上万人感染 HIV**，多个国家发生重大公共卫生危机，多名政府官员和制药企业高管因此受到法律追究 |
| **1980～1990 年代** | 工程菌和工程细胞生产的生物制品中间产物存在病毒污染报道                               | 推动了对生物制品病毒安全性评价体系的系统性重建                                               |

### 病毒污染的双重风险

1. **产品安全性风险：** 感染性病毒随药品进入患者体内，可导致严重疾病乃至死亡
2. **生产环境与操作者安全风险：** 病毒污染可扩散至生产环境，危及生产操作人员健康

### 当前状况与监管逻辑

> 到目前为止，从细胞系提取的生物技术产品**还没有发生传播病毒的问题**。

这一良好记录并非偶然，而是严格的病毒安全控制体系（细胞库检测 + 过程检测 + 病毒清除验证）共同作用的结果。如果放松任何一个环节，历史上的悲剧随时可能重演。

**监管的根本逻辑：** 由于细胞系来源的生物技术产品固有地存在病毒污染的危险性（内源性逆转录病毒 + 外源性病毒），安全保证只能通过**系统性的测试计划 + 生产过程中病毒清除/灭活能力的验证**来实现，而不能依赖单次检测结果。

:::

## 生物制品生产中的潜在病毒来源分析

:::answer

系统了解病毒污染的潜在来源，是建立有效预防措施的前提。生物制品生产中的病毒污染来源可分为两大类：细胞库相关来源和生产过程引入来源。

### 细胞库中可能存在的病毒

**① 内源性逆转录病毒（ERV，Endogenous Retroviruses）**

- 逆转录病毒基因组整合于宿主细胞染色体中，**从一代细胞直接传给下一代细胞**，无法通过常规操作去除
- 通常处于静默状态，但在特定条件下可能被激活，表达出感染性病毒颗粒
- CHO 细胞含有内源性逆转录病毒相关序列，须通过 PERT 检测和电镜评估其表达状态

**② 外源病毒进入 MCB 的五条途径**

| 入侵途径               | 具体情形                                                       |
| ---------------------- | -------------------------------------------------------------- |
| 来源于受感染动物的细胞 | 从携带潜伏性病毒的动物提取的原代细胞，如猴肾细胞（含 SV40）    |
| 使用病毒建立细胞系     | 某些细胞系用病毒转化建立（如 SV40 转化细胞），病毒整合于基因组 |
| 受污染的生物试剂       | 动物血清（牛血清 → BVDV；猪源胰酶 → PPV/PCV）中的病毒          |
| 细胞操作过程污染       | 不规范的细胞培养操作引入外来病毒                               |
| 生产过程引入的外源病毒 | 操作人员、环境、设备表面等途径                                 |

### 生产过程中外源病毒的进入途径

| 来源                 | 说明                                                   |
| -------------------- | ------------------------------------------------------ |
| **受污染的生物试剂** | 血清、生长因子等动物源性原材料中的潜在病毒             |
| **病毒载体**         | 利用病毒作为载体表达特定编码蛋白基因（基因治疗领域）   |
| **Protein A 亲和柱** | 如亲和柱制备过程中使用了受污染的原材料，可能将病毒引入 |
| **受污染的赋形剂**   | 组方用辅料中的潜在污染                                 |
| **培养基操作污染**   | 批量培养基配制过程中的污染                             |

### 早期监测的重要性

> 对细胞培养的参数进行监控有助于**早期发现**可能污染的外源病毒。

一旦生产过程中某批次发现病毒污染，须对工艺流程进行彻底检查，追溯污染来源（细胞库 → 原材料 → 操作过程），并评估是否须对工艺进行全面重新设计。

## 生物技术产品病毒安全性控制的三条基本原则

:::answer

根据 ICH Q5A，控制生物技术产品的潜在病毒污染，须遵循三条相互联系、层层递进的基本原则，三条原则共同构成完整的病毒安全保障体系。

### 三条基本原则

**原则一：选择和检测用于生产的细胞系及其他原材料，使其对病毒污染风险降到最低**

- 细胞库（MCB/WCB）须进行全面的病毒检定（内源性 + 外源性）
- 动物源性原材料须提供 BSE/TSE 证明和相关病毒检测报告
- 优先选用化学成分限定的无动物源性原材料（CDM，Chemically Defined Media）

**原则二：通过试验评估生产工艺去除和/或灭活病毒的能力**

- 对专属病毒清除步骤（低 pH 灭活、病毒过滤）进行正式的病毒清除验证
- 评估非专属步骤（亲和层析、离子交换层析）的贡献
- 须采用代表性模型病毒，在 worst-case 条件下进行，计算 LRV

**原则三：在生产过程中对原材料和中间产物进行检测**

- 生产过程中对未加工收获物（UPB）进行病毒检测
- 对生产终末细胞（EOPC）进行检定
- 建立过程检测的触发机制（如检出异常立即启动调查）

### 三条原则的协同关系

```
原则一（源头预防）
    ↓
尽量降低病毒进入生产体系的概率
    ↓
原则二（工艺验证）
    ↓
证明即使有病毒进入，下游工艺也能有效清除
    ↓
原则三（过程监测）
    ↓
实时检测是否有病毒在生产过程中出现
```

三条原则相互补充：没有任何一条原则单独足够——仅靠检测不能保证安全，仅靠工艺清除不能替代检测，仅靠原材料控制不能替代工艺验证。

:::

## 细胞库各级别的病毒控制检测策略

:::answer

细胞库不同级别的检测要求反映了分层管理的原则，检测深度和重复次数须与各级细胞库在生产中的角色和风险层次相匹配。

### MCB（主细胞库）的病毒检测要求

MCB 是整个生产体系的"质量黄金标准"，须进行最全面的病毒检测：

**① 内源性病毒检测**

- 逆转录酶活性测定（PERT 法）
- 透射电镜（TEM）观察病毒样颗粒
- 感染性逆转录病毒检测（敏感指示细胞接种）

**② 外源性非内源性病毒检测**

- 体内接种试验（乳鼠、成鼠、豚鼠等动物模型）
- 体外多种指示细胞接种试验

**③ 物种特异性病毒试验（重要特例）**

- 对于含人或非人灵长目动物配体的**杂交细胞系**（如杂交瘤细胞）：须进行人或非人灵长目病毒的专项测定（这类污染极其有害）
- **小鼠抗体产生试验（MAP, Mouse Antibody Production Test）：** 用于检测鼠源细胞系中可能存在的鼠源特异性病毒（如鼠痘病毒、鼠肝炎病毒等）

### WCB（工作细胞库）的病毒检测要求

WCB 是生产的直接起始物料，须进行外源病毒检测：

- 可对 WCB 进行直接测定，或对从 WCB 来源的体外传代限度内的细胞进行测定
- **豁免情况：** 若已对 MCB 进行了相应的非内源性病毒测试，且已对达到或超过 WCB 传代限度的细胞进行了外源病毒测试，则不必再对原有 WCB 作类似试验
- WCB **一般不须**进行小鼠抗体产生试验（MAP）

### 体外传代限度内生产用细胞的病毒评估

- 某些内源性病毒在 MCB 和 WCB 阶段可能未被检测出，须对在体外传代限度之内的细胞进行评价
- 至少应进行一次适当的试验（如体内和体外试验），进一步确保生产过程不受外源病毒污染
- **异常处置：** 若检测出外源病毒，须全面检查工艺流程查明污染来源，必要时对工艺进行全面重新设计

:::

## 未加工收获液（UPB）的病毒检测：过程监控的核心节点

:::answer

未加工收获液（Unprocessed Bulk，UPB）检测是生产过程病毒监控的最关键节点，为整个病毒安全控制体系提供生产批次层面的实时安全保证。

### UPB 的定义与采样意义

**UPB 定义：** 未加工收获液包括集中回收的一批或多批细胞和培养基的混合物。对于使用中空纤维或类似装置的灌流系统，UPB 通常是直接从发酵罐收获的液体。

**为什么 UPB 是最佳病毒检测时机？**

- 从生产反应罐中取得的 UPB 样品代表了病毒污染发生后**浓度最高、最易被检测到**的状态
- 在后续纯化步骤中，病毒可能被清除（清除的目的之一），反而降低检测灵敏度
- **例外情形：** 若 UPB 对指示细胞有毒性（如培养基中含有抑制细胞生长的成分），可在部分初加工后（如深层过滤后）进行测试

### 申报要求

> 在上市注册申请（BLA/NDA）时，至少须上报**三批中试生产规模**的 UPB 病毒检测资料。

这意味着 UPB 病毒检测数据须覆盖工艺开发的关键阶段，且须在代表商业化生产条件的中试规模下获得。

### UPB 检测与 EOPC 检测的互补关系

| 检测对象 | 检测目的                                     | 可检出的污染类型                       |
| -------- | -------------------------------------------- | -------------------------------------- |
| **UPB**  | 监控每批生产过程中是否引入外源病毒           | 单批次的外源病毒污染                   |
| **EOPC** | 监控整个生产周期（完整代次范围）内的细胞变化 | 代次延伸过程中病毒积累或内源性病毒激活 |

:::

## 下游病毒清除工艺体系：五步骤的机制与参数控制

:::answer

在单克隆抗体的下游纯化工艺中，多个步骤具有病毒清除能力，须系统理解各步骤的机制、关键参数和局限性，才能设计出科学合理的病毒安全保障体系。

### 五大病毒清除步骤综览

| 步骤                       | 清除机制                  | 针对病毒类型                    | 典型 LRV 范围 | 是否专属                |
| -------------------------- | ------------------------- | ------------------------------- | ------------- | ----------------------- |
| **Protein A 亲和层析**     | 流穿去除 + 低 pH 洗脱灭活 | 包膜病毒（主）                  | 1～4 log₁₀    | ❌ 非专属（LRV 变异大） |
| **低 pH 孵育**             | 包膜蛋白变性              | **包膜病毒**                    | ≥ 4 log₁₀     | ✅ **专属灭活步骤**     |
| **S/D（有机溶剂/去垢剂）** | 脂质膜溶解                | **包膜病毒**                    | ≥ 4 log₁₀     | ✅ **专属灭活步骤**     |
| **AEX 层析**               | 静电吸附（流穿模式）      | 包膜和非包膜病毒                | 1～4 log₁₀    | ✅ 可作为专属步骤验证   |
| **病毒过滤（纳滤）**       | 物理尺寸排阻              | **包膜和非包膜病毒（≥ 20 nm）** | ≥ 4 log₁₀     | ✅ **专属去除步骤**     |

### Protein A 层析的病毒清除机制

Protein A 步骤的病毒清除作用包含两部分：

**① 上样阶段流穿（Flow-through）**：大多数病毒不与 Protein A 填料特异性结合，在上样和洗涤过程中流穿而被去除

**② 洗脱阶段低 pH 灭活**：Protein A 洗脱使用低 pH 缓冲液（pH 3.2～3.8），对共洗脱的包膜病毒有一定灭活作用

**LRV 变异性大的原因：**

- 病毒可与目标抗体发生**非特异性相互结合**，随抗体一同洗脱，导致病毒"隐藏"于产品中随洗脱液流出
- 添加 Triton X-100、尿素或异丙醇等试剂阻断病毒与单抗的非特异结合后，可**显著提高 Protein A 步骤的病毒清除效果**

### AEX 层析病毒清除的关键工艺参数

影响 AEX 病毒清除效果的因素：

| 参数             | 最优条件                                     | 说明                                 |
| ---------------- | -------------------------------------------- | ------------------------------------ |
| **pH**           | 中性或弱碱性（pH 6.5～8.0）                  | 确保病毒带负电荷与填料结合           |
| **电导率**       | 低电导（< 10 mS/cm）                         | 低盐条件有利于静电吸附               |
| **LRV 上限**     | 通常可达 ≥ 4 log₁₀                           | 在最优条件下稳定实现                 |
| **样品杂质水平** | 残余 DNA 和 HCP 越低，AEX 病毒清除效果越稳定 | 高杂质竞争结合位点，降低病毒结合容量 |
| **介质使用周期** | 须在寿命终点验证病毒清除能力                 | 填料老化可能影响电荷密度             |

### 病毒过滤的减压敏感性问题（重要更新认知）

> 2011 年发现**减压操作**（Pressure Drop）会导致细小病毒泄露，业界随即更新了认知。

**传统认知（错误）：** 在高压下操作是最差情况，低压不影响病毒清除效果

**更新认知（正确）：** 减压已被证明在不同程度上影响大多数病毒过滤器对<strong>细小病毒（Parvovirus）</strong>的去除效果，且呈现高度的产品依赖性

**减压影响机制：** 减压导致过滤流速下降 → 病毒颗粒在膜表面的扩散效应增加 → 小尺寸病毒（接近膜孔径的细小病毒）的逃逸几率增大

**工艺验证影响：** 病毒过滤的 worst-case 验证须同时考察高压和减压（含压力突降）两种极端条件。

:::

## 病毒灭活/去除工艺验证的设计原则与关键考虑因素

:::answer

病毒清除验证是生物制品上市申报的核心安全性数据包，须在具备相应资质的实验室（BSL-2）由经验丰富的专业人员进行，验证研究须在 QA 监管下进行并经质量负责人批准。

### 模型病毒的选择原则

病毒清除验证须使用**代表性模型病毒**，而非真正的人用病原性病毒（出于安全考虑）。

**选择原则（参考 ICH Q5A）：**

| 类别                     | 选择依据                             | 代表性模型病毒                               |
| ------------------------ | ------------------------------------ | -------------------------------------------- |
| **与宿主细胞相关的病毒** | 与生产细胞种属相同或相关的病毒       | XMuLV（CHO 细胞来源）、BVDV（牛血清来源）    |
| **包膜病毒代表**         | 代表对低 pH 等灭活方法敏感的病毒类型 | XMuLV（逆转录病毒）、BVDV（黄病毒）          |
| **非包膜病毒代表**       | 代表对多种灭活方法耐受的高风险病毒   | MVM（细小病毒，最难去除的模型病毒之一）、PPV |
| **大尺寸病毒**           | 代表可被物理方法（纳滤）截留的病毒   | 疱疹病毒（HSV）、腺病毒                      |

**不同步骤的病毒种类考虑：**

- 亲和层析（Protein A）通常在低 pH 灭活之前，涉及的病毒种类可能更为丰富
- 没有要求所有病毒类型在一步工艺中均能有效去除，须结合步骤特点合理选择

### 病毒加标浓度的确定

基于经验数据：不同层析系统可实现 2～5 个 log 的病毒去除，因此：

> **建议加标病毒浓度须大于目标值至少 1 个 log**，以防止去除后病毒无法检出（低于检测限），导致无法计算实际去除效果。

**最低加标浓度公式：** 初始加标 ≥ (目标 LRV + 1 log + 检测方法 LOD)

### Worst-Case 条件的参数设置

| 参数类型     | 最差条件设定                                                     | 理由                       |
| ------------ | ---------------------------------------------------------------- | -------------------------- |
| **病毒滴度** | 尽可能高（实际加标上限）                                         | 模拟最不利的病毒污染情况   |
| **灭活时间** | 操作范围**下限**                                                 | 时间最短，灭活最不充分     |
| **灭活温度** | 操作范围**下限或上限**（取决于哪个对蛋白稳定性或灭活效率更不利） | 低温降低灭活速率           |
| **蛋白浓度** | 操作范围**上限**                                                 | 高浓度蛋白对病毒有保护效应 |
| **上样体积** | 操作范围**上限**                                                 | 高载量可能导致突破         |

### 小规模至商业化规模的一致性评估

> 病毒灭活/去除验证**不得在商业化规模厂房进行加样（病毒）验证**，因此须采用小规模实验进行。

**放大评估的必要性：** 须对小规模实验与商业化规模之间的工艺一致性进行充分评估，并对不一致方面进行讨论：

- 关键参数（pH、电导率、温度、蛋白浓度）在两个规模下的一致性
- 混合时间和 pH 均一性（对低 pH 孵育步骤尤为关键）
- 必要时在商业化条件下进行无病毒加标的参数考察

:::

## 病毒清除研究的局限性：正确理解 LRV 的边界

:::answer

病毒清除研究的目的是定量评估工艺的病毒清除能力，但研究本身存在多种固有局限性，监管机构和申报者须理性看待 LRV 数据，避免对工艺安全性作出不切实际的估计。

### 七类主要局限性

**① 体外培养病毒与天然病毒的差异**

- 用于验证的病毒制品通常在**组织培养中生产**，其理化特性（纯度、凝集度、感染滴度）可能与实际生产中可能存在的天然病毒有所不同
- 天然病毒可能存在病毒聚集物（Viral Aggregates），对多种灭活方法具有更强的耐受性，而体外培养病毒通常较均一

**② 双相灭活动力学的风险**

- 病毒感染性的灭活常遵循**双相曲线**：先有快速起始阶段，接着是较慢的阶段
- 初始快速灭活阶段逃逸的病毒可能对后续阶段具有**更强的耐受性**
- 若以总时间内的平均 LRV 计算，可能**高估实际灭活效果**（特别是仅关注开始阶段的快速灭活）

**③ LRV 加和的局限性**

> **将各步骤 LRV 简单相加，尤其将下降较少（低于 1 log₁₀）步骤的因子相加，可能对去除病毒的实际能力估计过高。**

- 各步骤的清除机制须真正正交（互相独立），才能合理相加
- 两次使用相同或几乎相同机制的步骤，其 LRV 值**不能叠加计算**

**④ LRV 永远不等于零病毒残留**

- LRV 是感染性下降的对数值，即使实现 8 log₁₀ 的下降，理论上也仅是将病毒浓度降低了 10⁸ 倍，而非消灭至零
- 例如：初始 8 log₁₀ 的病毒滴度，经过 8 log₁₀ 的清除，结果为每毫升 1 个感染单位（不是零）

**⑤ 小规模与生产规模的差异**

- 尽管小规模设计时已尽量模拟生产规模，但中试规模生产与大规模生产之间仍存在差异（混合时间、流速分布、温度梯度等）
- 这些差异可能导致实际生产规模的病毒清除效果与小规模验证结果存在偏差

**⑥ 类似机制步骤的累积估计问题**

生产过程中若存在多个具有相似灭活机制的步骤，将其 LRV 相加可能**对整体清除病毒能力产生过高估计**：

- 两次低 pH 步骤（如 Protein A 低 pH 洗脱 + 低 pH 孵育）的 LRV 不能简单叠加

**⑦ 检测方法灵敏度的限制**

- 当残余病毒浓度低于检测方法的定量限（LOQ）时，LRV 的计算基于 LOQ 而非实际测定值
- 这可能使实际 LRV **被低估**（保守计算）或**计算不准确**

### 正确使用病毒清除数据的原则

- 须使用正交的、机制不同的多步清除方案，而非依赖一步高 LRV
- 须合理设定病毒安全边际（Safety Margin），不依赖于接近理论限的极端 LRV 声明
- 须综合考虑临床剂量、病毒暴露量和每剂量病毒残留量，而非单独关注 LRV 数值

:::

## 除病毒过滤（纳滤）的工作原理与性能指标

:::answer

除病毒膜过滤（Virus Filtration，Nanofiltration）是单克隆抗体生产流程中最可靠的专属病毒去除步骤，通过物理尺寸排阻机制实现，是下游纯化工艺不可或缺的安全保障步骤。

### 双重去除机制

**① 粒径排阻（主要机制）**

- 病毒颗粒尺寸大于滤膜孔径（通常 20 nm），被物理截留于滤膜表面
- 产品（mAb，直径约 10～15 nm）小于孔径，穿过滤膜收集于滤液中
- 对于直径 ≥ 20 nm 的病毒（包括包膜病毒如 XMuLV ~100 nm，非包膜病毒如 PPV ~20～25 nm）均有效

**② 吸附机理（补充机制）**

- 对于尺寸接近或略小于膜孔的病毒（如边界情况），通过电荷、范德华力、氢键等作用力实现额外捕获
- 增加了对尺寸处于分界线的小病毒的去除保障

### 滤膜设计与产品回收率

- 基于粒径排阻的除细小病毒滤膜设计用来清除直径 ≥ 20 nm 的病毒
- 对于分子量 < 170 kDa 的蛋白产品（单抗 ~150 kDa 在此范围内），**回收率通常 > 98%**
- 工业界对各品牌滤膜的验证一致证明对 XMuLV（~100 nm）具有高效清除能力

### 病毒清除效果的量化

**LRV（对数减少值，Log Reduction Value）：**

$$LRV = \log_{10} \left( \frac{\text{过滤前病毒滴度} \times \text{过滤前体积}}{\text{过滤后病毒滴度} \times \text{过滤后体积}} \right)$$

**法规要求参考（来源于 CHO 细胞系生物产品）：**

| 病毒类型                     | 总体清除要求                   |
| ---------------------------- | ------------------------------ |
| 内源性逆转录病毒（如 XMuLV） | 约 **12～18 log₁₀** 的总清除率 |
| 外源性病毒                   | 约 **6 log₁₀** 的清除率        |

这相当于要求每 10⁶ 剂量中残余病毒颗粒少于 1 个，以保证患者用药安全。

### 影响病毒过滤性能的关键参数

| 参数                          | 对过滤的影响                    | 优化方向                                |
| ----------------------------- | ------------------------------- | --------------------------------------- |
| **样品蛋白浓度**              | 浓度升高 → 通量降低（蛋白堵膜） | 须实验确定最佳浓度（通常 5～20 mg/mL）  |
| **pH**                        | 影响蛋白质和病毒的电荷状态      | 在蛋白稳定 pH 范围内，通常偏中性较好    |
| **电导率**                    | 低盐条件可能增加蛋白-膜相互作用 | 须实验优化，避免过低导致通量过低        |
| **操作压力（TMP）**           | 高压提高初始通量但加速堵膜      | 须在供应商推荐范围内操作；避免压力突降  |
| **聚合物（Polysorbate）含量** | 高浓度表面活性剂可能影响膜结构  | 控制制剂中 Polysorbate 浓度在规格范围内 |
| **温度**                      | 低温增加溶液粘度，降低通量      | 在工艺规定温度范围内操作                |

:::

## 污染物的法规定义与在质量标准中的特殊处置原则

:::answer

污染物（Contaminants）在生物制品质量标准中具有特殊的处置逻辑，与杂质（Impurities）的管理方式存在根本性差异，须严格区分并按照相应法规框架处理。

### 污染物的官方定义（ICH Q6B）

> **产品污染物**是指带入的**非生产工艺预期部分**的外源性物质，如化学及生化物质（微生物蛋白酶）和/或微生物。

### 污染物与杂质的管理差异

| 管理维度         | 杂质（Impurities）     | 污染物（Contaminants）                   |
| ---------------- | ---------------------- | ---------------------------------------- |
| **性质**         | 生产工艺预期产生的物质 | 非预期引入的外源性物质                   |
| **控制目标**     | 控制在规格限度以内     | **严格避免**；不存在"可接受的污染物水平" |
| **质量标准处理** | 设定验收标准（行动限） | 通常不设行动限，检出即为不合格           |

### 外源性病毒和支原体的特殊处置原则

> 对于外源性病毒和支原体污染，**行动限不再适用**，而应考虑采用 ICH Q5A 和 ICH Q5D 提出的原则进行控制。

**实践含义：**

- 常规杂质（HCP、DNA、Protein A 残留）可以设定可接受限度（如 HCP < 100 ppm），在限度内的产品可以放行
- 但外源性病毒和支原体一旦在产品中检出，该批次产品**必须废弃**，不存在"病毒残留 < X ppm 可以放行"的概念
- 生产环境中检出相关污染须启动调查和纠正措施（CAPA）

### 预防污染的 GMP 措施

生产操作中须采取以下措施防止污染和混淆：

1. 生产前确认无上次生产遗留物（清场确认）
2. 防止尘埃的产生和扩散（粉尘控制）
3. 不同品种、规格在同一生产间不得同时进行（时间/空间隔离）
4. 防止气体、蒸汽、喷雾物或生物体引起的交叉污染（气流管理）
5. 设备和容器须有清晰的状态标识（防混淆）

:::

## 微生物限度检查与无菌检查的核心区别

:::answer

微生物限度检查和无菌检查是两种容易混淆但用途和法规要求截然不同的微生物控制方法，须准确区分其适用场景、判定标准和操作环境要求。

### 核心定义区别

| 比较维度     | **无菌检查**                   | **微生物限度检查**                 |
| ------------ | ------------------------------ | ---------------------------------- |
| **目的**     | 检查是否有**任何活微生物存在** | 检查活微生物数是否**超出规定限度** |
| **控制原则** | 不允许任何活微生物存在         | 只要求微生物数控制在限度范围内     |
| **适用制剂** | 注射剂、滴眼剂等无菌制剂       | 片剂、口服液等非无菌制剂           |
| **法规依据** | 药典通则 1101                  | 药典通则 1105                      |

### 操作环境要求

| 要求         | 无菌检查                                    | 微生物限度检查                                                     |
| ------------ | ------------------------------------------- | ------------------------------------------------------------------ |
| **环境级别** | 洁净度 **A 级**（ISO 5 级）单向流或隔离系统 | 万级（10,000 级，ISO 7 级）以下局部 **100 级**（ISO 5 级）单向气流 |
| **操作要求** | 严格无菌操作                                | 严格无菌操作（防止再污染）                                         |
| **额外要求** | 须验证单向气流区域和工作台清洁度            | —                                                                  |

### 判定标准差异

**无菌检查（更严格）：**

- 合格：供试品管**均澄清**，或虽显浑浊但经确证**无菌生长**
- 不合格：供试品管中任何一管显浑浊并确证有菌生长（除非能充分证明试验结果无效）

**微生物限度检查（设限度）：**

| 制剂类型         | 细菌限度      | 霉菌/酵母菌限度 |
| ---------------- | ------------- | --------------- |
| 口服给药液体制剂 | ≤ 100 CFU/mL  | ≤ 100 CFU/mL    |
| 口服给药固体制剂 | ≤ 1,000 CFU/g | ≤ 100 CFU/g     |

### 培养条件差异

| 参数         | 无菌检查  | 微生物限度检查              |
| ------------ | --------- | --------------------------- |
| **培养时间** | **14 天** | 细菌 3 天，霉菌/酵母菌 5 天 |
| **培养基**   | FTM + TSB | 两者均须使用                |

:::

## 在线灭菌（SIP）的定义与应用场景

:::answer

在线灭菌（Sterilization-in-Place，SIP）是大规模生物制药生产中确保生产设备无菌性的关键工艺操作，须与在线清洁（CIP，Cleaning-in-Place）配合使用。

### 定义

> **在线灭菌（SIP）：** 指该生产系统或设备在**原安装位置不移动**的条件下，通过通入蒸汽（饱和蒸汽）进行灭菌的操作。

### SIP 与传统高压灭菌（Autoclave）的区别

| 比较维度       | 在线灭菌（SIP）                                      | 传统高压灭菌（Autoclave）  |
| -------------- | ---------------------------------------------------- | -------------------------- |
| **设备移动**   | 不需要移动                                           | 须将器具移入灭菌锅         |
| **适用对象**   | 固定安装的大型设备（生物反应器、管道、层析柱外壳等） | 可移动的小型器具、培养基等 |
| **密封完整性** | 须验证整个管道系统的密封性                           | 相对简单                   |
| **操作规模**   | 大规模生产的标准操作                                 | 实验室规模和中试规模       |

### SIP 在单抗生产中的典型应用

| 应用场景                     | SIP 的作用                       |
| ---------------------------- | -------------------------------- |
| **生物反应器（Bioreactor）** | 接种前对反应器和管道系统进行灭菌 |
| **培养基配制系统**           | 确保培养基储罐和管道的无菌状态   |
| **收获系统**                 | 确保收获管道和容器的无菌性       |

### SIP 验证要求

SIP 系统须经过正式验证，以证明在所有设备死角（Cold Spots）均能达到足够的灭菌效果：

- 须在最难加热的位置（死角）放置温度探针和生物指示剂
- 验证内容：温度均一性（确认所有部位均达到灭菌温度）、灭菌时间（维持灭菌温度的时间）、生物指示剂（嗜热脂肪芽孢杆菌）的杀灭效果

:::

## 病毒清除工艺评价不充分的常见问题与解决路径

:::answer

病毒清除工艺评价不充分是生物制品申报中最常见的技术缺陷之一，审评机构的核心关切是验证研究是否准确反映了生产工艺对病毒的实际清除能力。

### ICH Q5A 的核心要求

> 病毒去除和/或灭活方法的评价和鉴定对生物技术产品的安全性起着重要作用。病毒清除研究的目的是**评价那些被认为可有效灭活/去除病毒的工艺步骤**，并**定量评估病毒的整体下降水平**。

**具体做法：** 有目的地将一定量的病毒**加入到原料和/或各工艺步骤的抽样样本中**（Spike Study），通过研究在后续工艺步骤样本中的病毒量来确定该工艺步骤对病毒的清除能力。

### 常见评价不充分的表现形式

| 问题类型                | 具体表现                                                                 |
| ----------------------- | ------------------------------------------------------------------------ |
| **病毒模型选择不当**    | 仅使用单一模型病毒；未包含非包膜病毒（如 MVM）；模型病毒与工艺特点不匹配 |
| **Worst-case 设计不足** | 未在最差条件下进行验证；参数范围覆盖不全                                 |
| **步骤不完整**          | 缺少专属的正交病毒清除步骤（须至少包含低 pH 灭活和病毒过滤两个专属步骤） |
| **加标浓度不足**        | 加标量过低导致检测下限前病毒已无法检测，无法计算真实 LRV                 |
| **规模代表性不足**      | 小规模验证与商业化规模的工艺一致性未经评估                               |
| **填料寿命考虑缺失**    | 未对填料寿命终点进行病毒清除验证                                         |
| **过滤减压风险未评估**  | 病毒过滤验证未考察减压操作对细小病毒清除的影响                           |

### 构建充分验证数据包的关键要素

1. **覆盖包膜和非包膜病毒**（至少各一种模型病毒）
2. **至少两个正交专属清除步骤**（清除机制完全不同）
3. **所有步骤均在 worst-case 条件下验证**
4. **验证在 QA 监督下进行，报告经质量负责人批准**
5. **提供小规模与生产规模的一致性评估**

:::

## 生物制品病毒清除工艺步骤体系

:::answer

多数生物制药企业采用系列隔离策略（Defense-in-Depth），将多个具有不同机制的病毒清除步骤串联使用，以实现累积足够高的病毒清除能力。

### 五类常用病毒清除工艺步骤

**① 澄清深层过滤**

- 通过吸附作用去除病毒，与澄清功能协同
- **局限性：** 属于低压操作，缩小模型的流速分布难以匹配大膜的流速，可重复性问题导致**难以用于病毒清除验证**，通常不计入病毒清除声明

**② 低 pH 孵育法（专属灭活步骤）**

- pH 3.0～4.0 的环境使病毒表面电荷改变，包膜蛋白空间结构发生不可逆改变
- 能灭活多种**脂包膜病毒**；对非脂包膜病毒无效
- 通常紧接 Protein A 层析之后，利用洗脱液本身的低 pH 特性实施

**③ 有机溶剂/去垢剂法（S/D 法，专属灭活步骤）**

- 磷酸三丁酯（TNBP）和非离子化去污剂（Triton X-100 或 PS80，0.5～1.0%）组合
- 专门**灭活脂包膜病毒**，对非脂包膜病毒无效
- 须在后续工艺中彻底去除 S/D 试剂（通过层析步骤或萃取）

**④ 除病毒膜过滤法（纳滤，专属去除步骤）**

- 物理去除原理，不依赖病毒化学特性
- 可清除**各种类型**的病毒（包膜和非包膜，只要 ≥ 20 nm）
- 须考察蛋白浓度、流速、过滤量及前后滤膜完整性

**⑤ 层析法（Protein A 和离子交换）**

- 具有一定的非专属病毒清除能力
- AEX 层析在中性 pH 低盐条件下通常可实现 ≥ 4 log₁₀ 的病毒清除（可作为专属步骤验证）
- **BLA 申报要求：** 须评估新旧填料的病毒清除能力；一般情况下，新旧填料的病毒清除能力没有显著差异，但须通过数据证明

### 多步骤联用策略的设计原则

> 以上方法能分别清除脂包膜病毒与非脂包膜病毒，通常选择**二步或多步联用**，以起到更好的清除效果。

**典型的两步正交组合（行业标准）：**

- **低 pH 孵育**（包膜病毒灭活）+ **纳滤**（包膜和非包膜病毒物理去除）
- 两步机制完全不同（化学灭活 vs 物理截留），互为正交，LRV 可合理叠加

:::

## S/D 法（有机溶剂/去垢剂）病毒灭活的工作原理

:::answer

有机溶剂/去垢剂法（Solvent/Detergent Treatment，S/D 法）是除低 pH 灭活之外的重要替代病毒灭活方法，特别适用于对酸敏感的生物制品，须深入理解其灭活机制和靶向特性。

### 灭活原理

**核心靶点：病毒的脂质包膜（Lipid Envelope）**

```
加入有机溶剂（TNBP，磷酸三丁酯）
    ↓
TNBP 渗入并溶解病毒脂质膜（类似有机溶剂溶解脂类的原理）
          +
加入非离子型去污剂（Triton X-100 / PS80）
    ↓
去污剂作用于病毒脂质膜，使脂质从病毒表面**脱落**
          ↓
病毒包膜结构被破坏
          ↓
病毒失去与宿主细胞黏附和感染细胞的能力
          ↓
**包膜病毒被有效灭活**
```

**关键优势：** 蛋白质分子的结构受 S/D 处理的影响非常小（TNBP 和 Triton X-100 是温和试剂，不会使蛋白质变性），因此 S/D 法**对目标蛋白药物的质量影响极小**。

### 灭活的靶向特异性

| 病毒类型                                       | S/D 灭活效果    | 原因                             |
| ---------------------------------------------- | --------------- | -------------------------------- |
| **脂包膜病毒**（HIV、HBV、HCV、XMuLV、RSV 等） | ✅ **有效灭活** | 含有脂质双层膜，是 S/D 作用靶点  |
| **非脂包膜病毒**（HAV、MVM、PPV、细小病毒等）  | ❌ **无效**     | 无脂质包膜，S/D 试剂无法发挥作用 |

这一靶向特异性是 S/D 法的核心局限：**非包膜病毒须依赖其他步骤（纳滤、高 pH 等）去除**。

:::

## S/D 法的工业应用历史、优势与适用产品范围

:::answer

S/D 法发现于 20 世纪 80 年代，最初应用于血浆制品领域，随后逐步扩展至整个生物制药领域，是历史上经过最广泛临床验证的病毒灭活方法之一。

### 历史发展脉络

- **研究发现：** 通过研究发现 Triton X-45 等非离子型表面活性剂与磷酸三丁酯（TNBP）组合可有效破坏乙肝病毒等包膜病毒的脂质膜
- **临床验证：** S/D 法作为**血浆病原体灭活技术**，是最早得到医疗界认可并投入临床使用的病毒灭活方法
- **FDA 许可：** 通过 FDA 许可，用于浓缩的人血液 Ⅷ 因子的病毒灭活
- **广泛应用：** 已广泛用于各类血液制品和生物制品的生产

### S/D 法的核心优势

**① 灭活效果完全**

- 能完全有效灭活**胞内、胞外病毒性病原体**及附着在细胞上的病原体
- 对多种不同的包膜病毒（HIV、HBV、HCV、HTLV-I/II、CMV 等）均能发挥有效灭活作用

**② 选择性进入细胞（血液制品特性）**

- 所选试剂能选择性地进入细胞且不损伤细胞
- 经处理后的红细胞不产生新抗原或抗体，对人体无害

**③ 对产品蛋白影响小**

- 与热灭活法（可能影响蛋白质构象）相比，S/D 法在温和条件下进行，对蛋白质结构影响极小
- **蛋白相容性高**，可插入到现有或新开发的纯化工艺中

**④ 工艺整合灵活性**

- 易于整合到现有纯化流程中，不需要特殊设备
- 工艺参数（TNBP/Triton X-100 浓度、温度、时间）相对简单，易于验证

### 适用场景

- 目标分子对酸敏感（pH < 3.5 时稳定性差），无法采用低 pH 孵育法
- 需要替代或补充低 pH 灭活步骤时
- 血液制品、重组凝血因子、抗体融合蛋白等产品的病毒灭活

:::

## S/D 法病毒灭活的操作注意事项与局限性

:::answer

S/D 法虽然有效且对蛋白质温和，但在实施过程中有多个关键注意事项须严格遵守，以确保灭活效果的可靠性和避免引入新的质量风险。

### 四大关键注意事项

**① 预过滤去除颗粒性物质**

> 待灭活的制品中，可能存在**颗粒性物质**会将病毒包裹其中，导致 S/D 试剂无法接触到病毒。

解决方案：须对制品**事先进行 1 μm 或更高精度的过滤**，去除颗粒后再进行 S/D 灭活。

**理由：** 病毒藏匿于蛋白聚集体或颗粒内部时，会形成物理屏障阻止 S/D 试剂接触病毒脂质膜，导致灭活不完全。

**② S/D 加入后充分混匀**

- 加入 S/D 后制品须**充分混匀**，确保 S/D 试剂均匀分布
- 如加入 S/D 后需要进行过滤，须确保过滤后 S/D 浓度仍在有效范围内（过滤可能吸附部分 S/D 试剂）

**③ 确保容器壁附着制品的处理**

> S/D 试剂要能够与**混合容器内每一滴制品**接触，特别是罐壁、罐顶附着的制品，在灭活工艺结束后可能又滴入罐内形成未处理制品的污染。

推荐操作程序：

```
加入 S/D → 充分混合均匀
    ↓
将混合后的制品泵入**另一容器**（转移罐）
    ↓
在转移罐中按规定温度和时间执行灭活程序
    ↓
（原容器中残留的附壁液体不会回流至已灭活的制品中）
```

**④ 病毒灭活区域的隔离**

> 病毒灭活间与后面的生产工序间须**物理分开**，以防止造成交叉污染。

- 病毒灭活区须有独立的人员流向和物料流向
- 灭活后产品在转移至后续生产工序前，须通过传递窗而非直接通行
- 空气流向须从"已灭活区"到"含活性病毒区"（而非反向），防止气溶胶污染

### S/D 法的主要局限性

| 局限性                       | 说明                                                                    |
| ---------------------------- | ----------------------------------------------------------------------- |
| **对非脂包膜病毒无效**       | HAV、MVM、PPV 等无包膜病毒完全不受 S/D 影响，须通过其他步骤（纳滤）去除 |
| **S/D 试剂残留问题**         | 须在后续工艺中彻底去除 TNBP 和 Triton X-100；残留须低于安全限度并经验证 |
| **潜在的基因毒性**           | TNBP 具有一定的基因毒性，须严格控制产品中的残留量                       |
| **凝血因子减低（血浆制品）** | 处理血浆时，某些凝血因子活性可能轻度降低，须监控                        |

### S/D 试剂残留的去除与检测

| S/D 试剂                | 去除方法                                               | 残留检测方法          |
| ----------------------- | ------------------------------------------------------ | --------------------- |
| **TNBP（磷酸三丁酯）**  | 油萃取或层析步骤（疏水相互作用层析、Protein A 后洗涤） | GC（气相色谱）或 HPLC |
| **Triton X-100**        | 层析步骤（特别是疏水作用层析 HIC 或阴离子交换 AEX）    | HPLC-UV 检测          |
| **PS80（聚山梨酯 80）** | 层析步骤                                               | HPLC 或比浊法         |

:::
