## EOPC 与 UPB 检测方案设计：互补性逻辑、执行建议与工艺变更触发的重评估要求

:::answer

### 两种检测策略的互补逻辑

EOPC 和 UPB 检测是病毒安全性控制的两个**互补而非替代**的维度。仅靠一种无法完整覆盖生产过程中所有的病毒安全性风险：

| 单独策略                | 可覆盖的风险                                             | 无法覆盖的风险                                           |
| ----------------------- | -------------------------------------------------------- | -------------------------------------------------------- |
| **仅 EOPC（一次检定）** | 细胞株在整个传代过程中的遗传稳定性；内源性病毒累积性变化 | 批次特异性外源病毒污染（某批原材料或操作引入的偶发事件） |
| **仅 UPB（每批检测）**  | 每批生产过程中可能引入的外源病毒；批次微生物安全性       | 细胞层面的遗传漂移和内源性病毒的渐进性变化               |
| **EOPC + UPB（推荐）**  | **全面覆盖：细胞层面 + 生产批次层面**                    | —                                                        |

### UPB 优于单独 EOPC 的三大技术优势

**优势一：检出窗口最优**

UPB 是整个生产工艺中**病毒污染最易检出**的节点。下游纯化的多步病毒清除步骤会将病毒滴度大幅降低（低 pH + 纳滤的总清除因子通常 ≥ 8 log₁₀），导致在纯化后的中间体和原液中几乎无法检出已存在的病毒污染。UPB 检测等于在污染被"稀释"之前进行截获。

**优势二：排除处理带来的假阴性**

EOPC 样品须经过细胞裂解、提取等处理步骤，这些操作可能降低病毒滴度或破坏病毒活性，引入假阴性风险。UPB 直接取自收获液，**未经任何额外操作和处理**，病毒以天然形态存在，检测结果最可靠。

**优势三：实现批次级别安全覆盖**

每批临床用样品均经过独立的 UPB 检测，即使某批次偶发性引入病毒污染，也能在产品到达患者前被检出并截获。

### IND 阶段 UPB 检测的执行建议

建议对每批用于临床试验的药物，在 UPB 阶段完成以下标准检测包：

| 检测项目                            | 执行频率                            | 方法                                |
| ----------------------------------- | ----------------------------------- | ----------------------------------- |
| 微生物负荷（生物负荷）或无菌        | 每批                                | 薄膜过滤法 / 需氧培养基直接法       |
| 支原体                              | 每批                                | 培养法 + DNA 染色法（药典要求）     |
| 外源病毒因子（体外细胞接种法）      | 每批                                | 多种指示细胞接种，观察 CPE 和血吸附 |
| 特定外源病毒因子（PCR）             | 每批（适用时）                      | 针对已知风险病毒（PCV、BVDV 等）    |
| 逆转录病毒颗粒定量（TEM + RT 活性） | **仅前 3 批**（建立基线后可不重复） | 透射电镜 + PERT qPCR                |
| 细菌内毒素                          | 每批                                | LAL 法（凝胶法/动态比浊法）         |

### 工艺重大变更须重新评估的触发条件

以下工艺变更应触发对细胞培养收获液病毒颗粒数量的**重新评估**（重新进行逆转录病毒颗粒定量）：

| 变更类型                                | 重评估原因                                                                |
| --------------------------------------- | ------------------------------------------------------------------------- |
| **制备规模变更**（如从 200 L → 2000 L） | 培养条件（剪切力、溶氧梯度、pH 梯度）改变可能影响细胞内源性病毒的表达水平 |
| **培养基变更**（新供应商、新配方）      | 培养基中的营养成分和添加剂可能影响逆转录病毒颗粒的产生速率                |
| **培养方式变更**（分批→流加→灌流）      | 不同培养模式下细胞代谢状态和生长密度差异显著，可能影响 RVLP 产生水平      |
| **宿主细胞变更**（新 MCB/WCB 批次）     | 新细胞批次可能存在 RVLP 表达的差异（尽管来自同一 MCB）                    |

## 研发到 GMP 批次的技术转移策略：可参考依据与风险评估框架

:::answer

### 技术转移的类型与法规背景

技术转移（Technology Transfer）是指将已在研发实验室验证的工艺方法，转移到 GMP 生产设施进行首次 GMP 生产的过程。对于 IND 申报而言，**从研发批次（研发实验室）到 GMP 批次（GMP 设施）的技术转移**是申报路径上的关键风险节点。

### 技术转移的参考依据

| 法规/指南                                       | 主要内容                                       | 适用场景         |
| ----------------------------------------------- | ---------------------------------------------- | ---------------- |
| **ISPE Technology Transfer Guide（2003/2014）** | 技术转移的系统化方法、知识管理、可比性研究框架 | 通用技术转移参考 |
| **WHO TRS 961（2011）**                         | 药物生产中的技术转移指南，适用于生物制品       | 国际申报参考     |
| **中国 GMP 技术转移指南（2011）**               | 国内 GMP 框架下的技术转移要求                  | 国内申报参考     |
| **ICH Q10（药品质量体系）**                     | 将技术转移纳入生命周期管理的质量体系框架       | 质量管理体系指导 |

> **重要原则：** 从研发批次（non-GMP 设施）转移到 non-GMP 生产设施、或转移到正式 GMP 设施之前的 non-GMP 批次，相关技术转移活动可参考 GMP 技术转移指南，具体活动内容由企业**依据风险评估**确定，须与后续 GMP 生产的连贯性相匹配。

### 技术转移中的五大可比性评估维度

技术转移后通常需开展逐步的可比性评估，参照可比性研究思路进行：

```
工艺可比性
  └── 关键工艺参数（CPP）在新设施的重现性
  └── 同一规模下工艺过程数据对比（VCD、活力、代谢参数、Titer）

        ↓

中间过程控制可比性
  └── 关键中间体（Protein A 洗脱液、CEX 洗脱液等）的质量属性对比
  └── 过程控制参数（pH、电导率、浊度等）的批间一致性

        ↓

放行数据可比性
  └── 原液和成品放行检测数据与研发批次历史数据的统计比较
  └── 核心 CQA（聚集体、电荷变体、纯度、效价）的可比性

        ↓

稳定性研究可比性
  └── 转移后 GMP 批次与研发批次在相同储存条件下的稳定性趋势对比
  └── 强制降解（加速热应力、氧化）样品的降解行为比较

        ↓

产品表征可比性
  └── 高阶结构（CD、DSC）；详细糖型；详细电荷变体种类鉴定
  └── 结合亲和力（SPR/ELISA）；细胞活性
```

### 技术转移规划的实践要点

- **提前规划设备等同性：** 新旧设施的关键设备（生物反应器类型/体积、层析系统、过滤设备）差异须在转移前完成等同性评估，预判可能影响产品质量的设备差异。
- **并行运行（Parallel Runs）：** 在条件允许时，进行新旧设施的小规模并行生产，先期识别工艺差异，降低正式转移的失败风险。
- **工艺转移方案（Transfer Protocol）：** 须制定详细的书面方案，明确验收标准（Acceptance Criteria），以客观数据判断转移是否成功。

:::

## 美国 FDA 的组织架构与生物药审评归口：CDER vs. CBER 的历史变迁

:::answer

### FDA 的法律地位与职能

**FDA（Food and Drug Administration，美国食品药品监督管理局）** 是美国**卫生与公共服务部（HHS）** 的下属联邦机构，具有独立执法权。其核心职能是确保在美国境内销售的食品、药品、医疗器械、化妆品和其他公共健康相关产品的安全性、有效性和质量。

FDA 通过以下方式履行职能：

- 制定和执行相关法规政策
- 审批产品的市场准入
- 开展上市后监督和监管活动
- 向公众提供产品安全信息和指导

### 生物药审评归口的历史变迁（2004 年改革）

**2004 年 10 月 FDA 改革** 是生物药监管历史上的重要里程碑，将大量生物技术药物的审评职责从 CBER 转移至 CDER：

| 审评中心                           | 全称                                         | 审评产品范围                                                                                                              |
| ---------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **CDER（药品评估和研究中心）**     | Center for Drug Evaluation and Research      | 2004 年后负责：重组蛋白、单克隆抗体、细胞因子、酶类、免疫调节剂（**除疫苗和变态反应产品**）、生长因子等治疗用生物技术药物 |
| **CBER（生物制品评估和研究中心）** | Center for Biologics Evaluation and Research | 保留职责：疫苗、血液制品、变态反应产品、组织和细胞产品、基因治疗产品                                                      |

> **实践意义：** 对于单克隆抗体、重组蛋白等治疗用生物药，申报 FDA 时应向 **CDER** 递交（而非 CBER）；但基因治疗产品、细胞治疗产品和疫苗仍向 **CBER** 递交。准确判断目标审评中心，是提高审报效率的基础。

### 主要监管部门联系方式与资源

| 资源类型                      | 链接/说明                                   |
| ----------------------------- | ------------------------------------------- |
| CDER 官网                     | www.fda.gov/drugs                           |
| CBER 官网                     | www.fda.gov/biologicsbloodvaccines          |
| FDA 电子政务系统（eCTD 提交） | eSubmitter 系统                             |
| FDA 指导文件数据库            | www.fda.gov/regulatoryinformation/guidances |

## FDA 生物药七步审评流程：从临床前到获批上市的完整路径

:::answer

### 七步审评流程总览

FDA 对生物药（以单克隆抗体为代表）的审评遵循以下标准化七步流程：

```
过程一：临床前研究（Pre-clinical Studies）
  ├── 体外活性研究（IC50、结合亲和力、作用机制验证）
  ├── 动物毒理学研究（急性毒性、重复给药毒性、GLP 规范）
  └── 临床前 CMC 研究（工艺建立、质量标准草案）
        ↓
过程二：递交 IND 申请（Filing IND Application）
  ├── 向 FDA 提交 IND 申报资料
  ├── FDA 30 天审评期（无反对即默示许可）
  └── 可能开展 Pre-IND 会议（可选）
        ↓
过程三：I 期临床试验（Phase I）
  ├── 主要目的：安全性评估；确定 MTD 和 RP2D
  ├── 受试者：通常健康志愿者或患者（视产品毒性）
  └── 关键 CMC：临床批次 GMP 生产；UPB 检测；稳定性数据支持
        ↓
过程四：II 期临床试验（Phase II）
  ├── 主要目的：初步有效性和剂量摸索；扩大安全性数据
  ├── 受试者：目标疾病患者
  └── 关键里程碑：End-of-Phase 2 会议（EOP2，最重要的里程碑会议）
        ↓
过程五：III 期临床试验（Phase III）
  ├── 主要目的：大样本确证有效性；全面安全性评估
  ├── 受试者：大规模目标患者群（通常 > 300 人）
  └── 关键 CMC：工艺锁定；PPQ（工艺性能确认）；全面稳定性
        ↓
过程六：新药注册申请（BLA Submission）
  ├── 向 FDA 提交 BLA（Biologics License Application）
  ├── 60 天内 FDA 决定是否受理
  └── 标准审评：10 个月（PDUFA 承诺）；优先审评：6 个月
        ↓
过程七：获得批准（Approval）
  └── FDA 发放生物制品许可证（BL）→ 产品上市销售
```

### 关键时间节点参考

| 阶段               | 典型持续时间                    | 主要 CMC 活动                         |
| ------------------ | ------------------------------- | ------------------------------------- |
| 临床前 → IND       | 约 18 个月（标准）              | 细胞株建立、工艺开发、毒理批 GMP 生产 |
| IND → I 期结束     | 1～2 年                         | 临床批次生产、UPB 检测、初步稳定性    |
| I 期 → II 期结束   | 2～4 年                         | 工艺优化、规模放大、方法验证启动      |
| II 期 → III 期结束 | 3～5 年                         | 工艺锁定、PPQ、全面稳定性             |
| BLA 审评           | 10 个月（标准）/ 6 个月（优先） | 审评期间回应 FDA 问询                 |

## IND 申请的法律定义、申报目的与审批机制

:::answer

### IND 的法律定义

**IND（Investigational New Drug，研究性新药申请）** 是指尚未获得 FDA 上市批准、正在进行各阶段人体临床试验的新药的注册申请。在 FDA 框架下，IND 本质上是申请人向 FDA 申请豁免 21 CFR 312 法规中"新药须获上市批准方可用于人体"这一基本要求，以便在安全前提下开展临床研究。

### IND 申请的核心目的

IND 申请的根本目的是：**向 FDA 提供足够的数据，证明拟定的临床试验计划在科学上合理、在安全性上可接受**。具体而言，须证明：

| 证明维度               | 所需证据类型                                            |
| ---------------------- | ------------------------------------------------------- |
| **药物安全性（首要）** | 非临床毒理学数据；CMC（工艺控制和产品质量）数据         |
| **科学合理性**         | 作用机制假说；临床前 PK/PD 数据；I 期方案设计的科学依据 |
| **受试者保护**         | 知情同意程序；安全性监测计划；DSMB 设置                 |

### FDA 的 IND 审批机制（默示许可制）

FDA 的 IND 审评采用**默示许可制（Implied Authorization）**：

- 申请人递交 IND 申请后，FDA 有 **30 天**审评期。
- 若 30 天内 **FDA 未提出反对意见**，申请人即可自动启动 I 期临床试验，**无需等待 FDA 的明确批准通知**。
- 若 FDA 发现临床试验存在不可接受的安全性风险，可发出 **Clinical Hold（临床试验暂停）通知**，要求申请人在解决指出问题前不得启动或继续临床试验。

> **与中国的对比：** 中国采用"报批制"，申请人须等待 CDE 发放临床试验批件方可启动临床试验（60 个工作日等待期）；而 FDA 的默示许可制允许在无反对意见时自动启动，将监管重心后移至临床阶段监管。

:::

## FDA BLA 审评机制：PDUFA 时限承诺、审评决定类型与 10 万页档案要求

:::answer

### BLA 与 NDA 的区别

| 申请类型                                 | 全称             | 适用产品                                          |
| ---------------------------------------- | ---------------- | ------------------------------------------------- |
| **BLA（Biologics License Application）** | 生物制品许可申请 | 生物制品（单抗、重组蛋白、疫苗、细胞/基因治疗等） |
| **NDA（New Drug Application）**          | 新药申请         | 化学合成小分子药物                                |

单克隆抗体和重组蛋白须提交 **BLA**（由 CDER 审评）。

### BLA 的提交与审评流程

```
III 期临床试验完成
  │
  ▼
Pre-BLA 会议（可选，推荐）
  └── 就 BLA 格式、内容完整性、未决问题与 FDA 提前沟通
  │
  ▼
递交 BLA 申请（通常 > 10 万页数据资料）
  │
  ▼ 60 天内
FDA 决定是否受理（Filing Decision）
  ├─ 受理（File）→ 正式审评启动
  └─ 拒绝受理（Refuse to File, RTF）→ 申请人须完善资料后重新提交
  │
  ▼ 受理后
标准程序审评（Standard Review）：10 个月内完成（PDUFA 承诺）
优先审评（Priority Review）：6 个月内完成
  │
  ▼
审评决定
  ├─ 批准（Approval）→ 发放 BLA 批准函（Approval Letter）→ 产品上市
  ├─ 完全回复函（Complete Response Letter, CRL）→ 须解决指出问题后重新提交
  └─ 要求补充信息（Information Request, IR）→ 审评期间的澄清请求
```

### PDUFA（处方药申请者付费法案）的审评时限保证

PDUFA（Prescription Drug User Fee Act）设定了 FDA 的审评时限承诺：

- **标准程序：** 90% 以上受理申请须在 **10 个月内**完成审评。
- **优先审评：** 90% 以上受理申请须在 **6 个月内**完成审评。

优先审评的申请条件：用于治疗严重疾病，且获批后对现有疗法的安全性或有效性具有**显著改善**的药物。

### 典型 BLA 资料体量

一份完整的单抗 BLA 申报资料通常包含超过 **10 万页数据**，主要由以下部分组成：

| 模块                   | 大致内容                                                 |
| ---------------------- | -------------------------------------------------------- |
| M2（通用技术文件摘要） | 质量/非临床/临床摘要，约 500～1000 页                    |
| M3（质量 CMC）         | 结构表征、工艺验证、稳定性、质量标准等，约 3000～8000 页 |
| M4（非临床研究报告）   | 药理学、毒理学、代谢研究，约 5000～15000 页              |
| M5（临床研究报告）     | 所有 I/II/III 期临床研究报告，约 50000～80000 页         |

:::

## FDA 四大加快审批途径：快速通道、突破性疗法、加速批准与优先审评的适用条件与特权

:::answer

### 加快审批途径概述

为缩短针对严重或危及生命疾病的创新药物上市时间，FDA 设置了四种正式的加快审批机制，每种机制针对不同的申请条件，提供不同层次的优惠待遇：

### 四种途径对比

| 途径                                   | 申请时机                          | 核心申请条件                                                                                                       | 主要优惠                                                                       |
| -------------------------------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| **快速通道（Fast Track）**             | 临床开发早期（甚至 Pre-IND 阶段） | ① 用于治疗严重疾病 ② 临床/非临床数据显示能填补临床用药空缺；或认定为抗感染新药                                     | 滚动审评（Rolling Review）；更频繁的 FDA 沟通交流                              |
| **突破性疗法（Breakthrough Therapy）** | I 期初期数据获取后                | ① 用于治疗严重疾病 ② 初步临床数据显示对现有疗法有**重要临床终点的明显改善**                                        | 快速通道所有特权 + 高级管理者和资深审评人参与 + 早在 I 期即可开始 FDA 密集指导 |
| **加速批准（Accelerated Approval）**   | BLA 提交时                        | ① 针对医疗需求未满足的严重疾病 ② 基于<strong>替代终点（Surrogate Endpoint）</strong>批准（须在上市后验证临床终点） | 早于常规临床终点验证完成前即可上市                                             |
| **优先审评（Priority Review）**        | BLA 提交时                        | ① 用于治疗严重疾病 ② 获批后对现有疗法的安全性或有效性具有**显著改善**                                              | 审评时限从 10 个月缩短至 **6 个月**                                            |

### 突破性疗法认定的战略价值

突破性疗法认定是目前最具价值的加快审批工具，其核心特权包括：

1. **超早期密集 FDA 指导：** 早在 I 期临床开发阶段即可与高级 FDA 官员开展实质性科学讨论，对试验设计、终点选择、统计方法等关键问题获得早期指导。
2. **跨学科协作审评：** FDA 组建包含多学科（临床、CMC、统计、监管）专家的团队，主动协作推进开发计划，而非被动等待申请人提交资料。
3. **滚动审评（Rolling Review）：** 申请人可将 BLA 模块在完成后逐步提交，而无需等待所有模块全部完成后一次性提交，大幅缩短最终审评等待时间。

### 申请突破性疗法认定的实操建议

- **申请时机：** 在获得显示"明显改善重要临床终点"的初步临床数据后尽快申请（通常为 I/II 期初步数据）。
- **申请材料：** 须提供以下内容：①初步临床试验数据及统计分析；②对照现有疗法的比较结论；③拟定的开发计划概要。
- **审批速度：** FDA 须在收到申请后 **60 天内**作出是否授予突破性疗法认定的决定。

:::

## 返工工序的监管申报要求：注册许可的前置策略

:::answer

### 返工的法规定义与监管关注

**返工（Reprocessing）** 是指在生产过程中，某步骤未达到预期质量标准时，对同批次产品重新进行该步骤或补充步骤的操作。在 GMP 规范中，返工（特别是关键工序的返工）须受到严格管控，因为：

- 返工操作可能改变产品的质量属性（如影响纯度、聚集体、活性）。
- 未经注册的返工操作在申报层面属于重大偏差，可能触发批次报废决定。
- 监管机构（FDA、NMPA）对常规性返工持审慎态度，须提供充分的科学依据。

### 获得返工工序注册许可的策略

对于生产中**可预见性发生**的返工情形（如某批次纯度轻微偏低须重新过柱），建议在注册文件中提前申报：

| 申报要求             | 具体内容                                                                                            |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| **明确返工工序描述** | 在注册文件（CTD M3.2.S.2 / M3.2.P.3）中详细描述可能触发返工的条件及返工操作步骤                     |
| **研究数据支持**     | 提供返工前后产品质量对比数据（关键 CQA 的可接受性）；返工不会对安全性产生不利影响的证明             |
| **确认方案**         | 提交经过验证的返工工序确认方案（Reprocessing Qualification Protocol），证明返工工序的一致性和有效性 |
| **批次限制**         | 明确规定单批次最多允许返工的次数（通常不超过 1～2 次），防止无限循环返工                            |

### 返工与重加工（Reworking）的区别

| 概念                     | 定义                                                   | 监管处理                                     |
| ------------------------ | ------------------------------------------------------ | -------------------------------------------- |
| **返工（Reprocessing）** | 在同一工艺步骤的批准操作范围内重复该步骤（如重新纯化） | 须有预设的返工规程；需提前在注册文件中申报   |
| **重加工（Reworking）**  | 采用不同于原批准方法或附加步骤处理不符合标准的产品     | 须额外验证；通常须提交补充申请获批后方可实施 |

:::

## 蛋白药物结构确证的申报资料内容：九大分析维度与方法选择框架

:::answer

### 结构确证在 CMC 申报中的特殊地位

蛋白药物的结构确证（Structural Characterization）是产品质量研究中的一项重要内容，但由于其研究方法和目的不同于常规质控：

- **大部分结构确证项目不列入常规质控标准**（因为方法复杂、批批检成本高），而是在申报阶段通过全面表征来"奠定知识基础"。
- 结构确证的目的是**建立产品的"分子指纹"**，为后续生物类似药比较研究和工艺变更后可比性研究提供参照基准。
- 重组蛋白须结合多种结构确证手段（**多维度正交表征**），单一方法无法完整描述复杂生物大分子。

### 九大结构确证维度

**① 分子量测定**

| 方法                       | 精度             | 适用场景                       |
| -------------------------- | ---------------- | ------------------------------ |
| SEC-MALS（多角度激光散射） | 高（绝对分子量） | 天然条件下分子量和聚集状态     |
| ESI-MS（电喷雾质谱）       | 极高（Da 级）    | 完整分子的精确分子量（含 PTM） |
| MALDI-TOF                  | 高               | 粗略分子量；糖蛋白异质性       |

**② N 端分析（N-terminal Sequencing）**

- Edman 降解法测定 N 端 15～20 个氨基酸序列。
- 与理论序列比对，确认 N 端加工正确性（是否有信号肽切除；N 端 Gln 是否环化为 pyroGlu）。

**③ C 端测定（C-terminal Analysis）**

- C 端赖氨酸（Lys）切除情况的定量分析（CHO 表达抗体 C 端 Lys 通常部分或完全切除）。
- 方法：LC-MS/MS 肽图分析；C 端特异性酶（羧肽酶 B）处理后 MALDI。

**④ 肽图分析（Peptide Mapping）**

- 核心方法：蛋白酶切（胰蛋白酶/LysC/AspN）→ RP-HPLC 分离 → LC-MS/MS 鉴定。
- 确认完整氨基酸序列（目标覆盖度 > 95%）；鉴定 PTM 位点和类型（脱酰胺、氧化、糖化等）；定位二硫键。

**⑤ 巯基和二硫键分析**

| 分析维度            | 方法                                                      |
| ------------------- | --------------------------------------------------------- |
| 游离巯基（-SH）定量 | Ellman 试剂（DTNB 法）；荧光标记法                        |
| 二硫键定位          | 非还原条件酶切 + LC-MS/MS（鉴定含二硫键的二硫连接肽段对） |
| 二硫键错配分析      | 与理论配对比较，鉴定非正常配对                            |

**⑥ 蛋白质翻译后修饰（PTM）分析**

| 修饰类型               | 分析方法                         |
| ---------------------- | -------------------------------- |
| 脱酰胺（Deamidation）  | LC-MS/MS 肽图；δ 质量 +0.984 Da  |
| 甲硫氨酸氧化（Met Ox） | LC-MS/MS 肽图；δ 质量 +15.995 Da |
| N 端 pyroGlu 化        | LC-MS/MS；Edman 降解确认         |
| 异构化（Asp → isoAsp） | LC-MS/MS（借助 Asp-N 消化）      |

**⑦ 糖基化结构分析（N-Glycan Profiling）**

- PNGase F 释放 N-糖 → 2-AB 荧光标记 → HILIC-FLD/LC-MS 定量糖型分布。
- 须鉴定并定量所有主要 N-糖型（G0F、G1F、G2F、高甘露糖型、唾液酸化型等）。
- 特别关注 Neu5Gc 含量（CHO 细胞可产生，须证明其水平可接受）。

**⑧ 高级结构分析（Higher-order Structure, HOS）**

| 方法                    | 分析对象                                   |
| ----------------------- | ------------------------------------------ |
| 远紫外 CD（Far-UV CD）  | 二级结构（α-螺旋、β-折叠、β-转角比例）     |
| 近紫外 CD（Near-UV CD） | 三级结构（芳香族氨基酸和二硫键的手性环境） |
| DSF（差示扫描荧光法）   | 热稳定性（Tm1、Tm2）                       |
| DSC（差示扫描量热法）   | 热稳定性（精确 Tm、ΔH）                    |
| HDX-MS（氢氘交换质谱）  | 溶液中蛋白质的动态高级结构（表位 mapping） |

**⑨ 其他（化学偶联修饰制品的特殊要求）**

对 ADC（抗体药物偶联物）等化学偶联修饰制品，还须对以下内容进行确证：

- **偶联位点鉴定：** 通过 LC-MS/MS 确认偶联发生的具体氨基酸残基。
- **平均 DAR（Drug-to-Antibody Ratio）：** HIC-HPLC 或 SEC-MS 测定偶联药物的平均数量。
- **DAR 分布（Species Distribution）：** 分别定量 DAR0、DAR2、DAR4、DAR6、DAR8 等组分。

:::

## 工艺变更后稳定性研究的设计原则：桥接策略与变更影响评估

:::answer

### 稳定性研究桥接的法规要求

**ICH Q5C（生物技术产品及生物制品的稳定性研究）** 和 **ICH Q5E（可比性研究）** 共同要求：当工艺变更可能影响产品稳定性时，须进行稳定性试验，并与变更前规模生产样品的**历史稳定性数据**进行比较。

> **关键判定：** 若可证明变更前后稳定性试验具有可比性，则可将变更前的稳定性数据**桥接（Bridge）** 至变更后产品，支持相同有效期的延续，而无需从头积累完整的实时稳定性数据。

### 稳定性桥接的适用条件与不适用条件

| 情形                               | 是否可桥接      | 理由                                             |
| ---------------------------------- | --------------- | ------------------------------------------------ |
| 工艺微小变更（不影响产品质量属性） | ✅ 可桥接       | 可比性研究证明质量属性无差异，稳定性行为预期一致 |
| 处方微调（赋形剂浓度小幅变化）     | 需具体评估      | 须加速和强制降解数据比较，确认降解趋势无差异     |
| 剂型变更（液体 → 冻干）            | ❌ 不可桥接     | 完全不同的降解路径，须重新开展完整稳定性研究     |
| 活性成分浓度重大调整               | ❌ 通常不可桥接 | 蛋白质浓度变化直接影响聚集速率和降解速率         |
| 包材变更（不同容器/胶塞）          | 需具体评估      | 须评估浸出物变化和容器密封完整性对稳定性的影响   |

### 工艺变更后稳定性方案设计要点

**加速和强制降解稳定性（最重要的比较工具）**

| 应力类型 | 条件                                 | 作用                               |
| -------- | ------------------------------------ | ---------------------------------- |
| 热应力   | 40℃/75% RH，1、3、6 个月（液体制剂） | 加速聚集、氧化、脱酰胺等化学降解   |
| 氧化应力 | 0.01%～0.1% H₂O₂ 处理                | 专项评估 Met 氧化倾向              |
| 光照应力 | ICH Q1B 标准光照条件                 | 评估光降解敏感性                   |
| 冻融应力 | -30℃ ↔ RT，3～5 个循环               | 评估冻融循环稳定性（聚集体、活性） |
| 机械应力 | 振荡（150 rpm，48 h）                | 模拟运输条件                       |

**长期实时稳定性**

若证明变更可比，可根据**有限的变更后长期稳定性数据**（如 3 个月实时）+ **已批准的稳定性研究方案**（承诺持续监测），申请支持全效期批准。

:::

## IND 申报中病毒清除验证的标准要求：各步骤的病毒选择与重复性设计

:::answer

### IND 阶段病毒清除验证的整体框架

FDA IND 阶段病毒清除验证（相较 BLA 阶段有所简化）须覆盖以下三类工艺步骤：

**第一步：低 pH 病毒灭活（或 S/D 法）**

| 要素         | 要求                                                                    |
| ------------ | ----------------------------------------------------------------------- |
| 实验设计     | **重复两次独立试验**（同一批样品运行两次，操作独立）                    |
| 验证病毒数量 | **1 种病毒**（MuLV，鼠白血病病毒）                                      |
| 病毒选择依据 | MuLV 代表 CHO 细胞内源性逆转录病毒样颗粒（RVLPs）；有包膜；对低 pH 敏感 |
| LRV 目标     | ≥ 4 log₁₀（每次独立实验）                                               |

**第二步：层析工艺（通常选择阴离子交换层析）**

| 要素         | 要求                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| 实验设计     | **重复两次独立试验**                                                                                 |
| 验证病毒数量 | **2 种病毒**（MuLV + MVM）                                                                           |
| 工艺选择     | 通常考察 **AEX（阴离子交换层析，流穿模式）** 的病毒去除能力（中性 pH 下病毒带负电，被 AEX 填料吸附） |
| 覆盖逻辑     | MuLV（有包膜，代表 RVLPs）+ MVM（无包膜，细小病毒，代表耐受性强病毒）                                |

**第三步：除病毒过滤（纳滤，20 nm）**

| 要素         | 要求                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------ |
| 实验设计     | **重复两次独立试验**                                                                       |
| 验证病毒数量 | **2 种病毒**（MuLV + MVM）                                                                 |
| 原理         | 尺寸排阻：20 nm 孔径可物理截留 MuLV（~100 nm）和 MVM（~18～22 nm，接近孔径，验证极端情况） |

### 三步骤的病毒覆盖矩阵

```
          低 pH 灭活   AEX 层析   除病毒过滤（纳滤）
MuLV         ✅          ✅           ✅
MVM          —           ✅           ✅
总步骤         1           1           1（各验证两次）
```

> **正交性要求：** 三个步骤的作用机制完全不同（化学灭活 / 静电吸附 / 物理截留），满足 ICH Q5A 对"正交病毒清除步骤"的要求，即使某一步骤失效，其他步骤仍可提供有效保护。

:::

## BLA 申报病毒清除验证的升级要求：四种病毒覆盖与更严格的 LRV 期望

:::answer

### BLA 阶段验证要求的升级逻辑

BLA 阶段（商业化上市申报）相比 IND 阶段，病毒清除验证的要求显著升级，主要体现在：

- **更多病毒种类：** IND 阶段通常 2 种（MuLV + MVM），BLA 阶段须达到 **4 种病毒**（覆盖更广泛的病毒特性范围）。
- **更严格的总清除因子：** BLA 阶段 FDA/EMA 期望整体工艺（多步骤之和）提供足够的安全裕度（通常总 LRV ≥ 6 log₁₀ 被认为有意义）。

### BLA 阶段的四种推荐病毒

| 病毒                        | 类型       | 包膜       | 大小         | 选择理由                                               |
| --------------------------- | ---------- | ---------- | ------------ | ------------------------------------------------------ |
| **MuLV（鼠白血病病毒）**    | 逆转录病毒 | 有包膜     | ~100 nm      | 代表 CHO 细胞内源性 RVLPs；对低 pH 灭活的模型病毒      |
| **MVM（鼠微小病毒）**       | 细小病毒   | **无包膜** | ~18～22 nm   | 最小、最耐受的病毒；主要验证纳滤效果；低 pH 无效       |
| **PRV（伪狂犬病病毒）**     | 疱疹病毒   | 有包膜     | ~120～200 nm | 对低 pH 具有一定耐受性的有包膜病毒代表；验证灭活稳健性 |
| **Reo-3（3 型呼肠孤病毒）** | 呼肠孤病毒 | **无包膜** | ~80～85 nm   | 中等大小无包膜病毒；补充 MVM 的无包膜病毒覆盖          |

### BLA vs. IND 病毒验证要求对比

| 要素         | IND 阶段                    | BLA 阶段                               |
| ------------ | --------------------------- | -------------------------------------- |
| 验证病毒种类 | 2 种（MuLV + MVM）          | **4 种**（MuLV + MVM + PRV + Reo-3）   |
| 低 pH 步骤   | 1 种病毒（MuLV），重复 2 次 | 通常 2 种病毒（MuLV + PRV），重复 2 次 |
| 层析步骤     | 2 种病毒，重复 2 次         | 2 种病毒，重复 2 次（覆盖有/无包膜）   |
| 纳滤步骤     | 2 种病毒，重复 2 次         | 2～4 种病毒，重复 2 次                 |
| 总体评估     | 两个正交专属步骤            | 多步骤正交组合；须提供总清除因子计算   |

### BLA 阶段病毒安全性总结报告要求

BLA 申报须提供完整的病毒安全性总结，包含：

1. **病毒清除验证汇总表（Virus Clearance Summary Table）：** 每步骤每种病毒的 LRV，各步骤数据的来源批次和重复次数。
2. **总清除因子计算：** 将各步骤 LRV 相加，评估整体工艺对不同类型病毒（有/无包膜）的总清除能力。
3. **缩小模型等同性确认：** 提供验证缩小模型与商业化生产规模的等同性证明数据。

:::

## 中美申报病毒清除验证的三大差异：指示病毒选择、工艺步骤与重复性标准

:::answer

### 差异维度一：指示病毒的选择原则

| 维度              | 国内（NMPA）                                                                                                                                            | 国外（FDA/EMA/ICH Q5A）                                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **规定方式**      | **详细具体：明确指出病毒类型**（如特定指导原则明确要求验证方案须选择单链/双链 RNA 及 DNA、脂包膜/非脂包膜、强/弱抵抗力、大/小颗粒等不同类型病毒的代表） | **原则性要求，不硬性规定具体病毒**：仅要求尽可能选择与污染产品最相似的"特异性指示病毒"，以及理化性质范围较宽的"非特异性指示病毒" |
| **方法-病毒匹配** | 明确各方法对应的推荐病毒（如 S/D 法 → 脂包膜病毒；膜过滤 → 小粒径病毒）                                                                                 | 申请人自主选择，须说明选择依据的科学合理性                                                                                       |

### 差异维度二：工艺步骤验证范围

| 工艺步骤                          | NMPA 要求         | FDA/EMA 要求                             |
| --------------------------------- | ----------------- | ---------------------------------------- |
| 低 pH 孵育                        | ✅ 必须           | ✅ 必须                                  |
| 病毒过滤（纳滤）                  | ✅ 必须           | ✅ 必须                                  |
| **层析工艺（AEX/CEX/Protein A）** | ❌ 通常不强制要求 | **✅ 建议包含（IND 阶段尤以 AEX 为主）** |
| 其他灭活步骤（S/D、UVC）          | 视具体工艺        | 视具体工艺                               |

### 差异维度三：重复性验证设计

| 维度             | 国内（NMPA）                            | 国外（ICH Q5A/FDA）                                      |
| ---------------- | --------------------------------------- | -------------------------------------------------------- |
| **批次要求方式** | 通常要求 **3 个不同批次样品**各进行验证 | **至少 2 次独立研究**（可用同一批样品重复 2 次）         |
| **"批次"的定义** | 强调样品来源的多样性（3 个不同批次）    | 强调**操作独立性**（2 次独立运行，操作者/时间/设备独立） |
| **主要目的**     | 证明不同批次样品的验证结果一致性        | 证明验证方法本身的重现性（操作一致性）                   |

> **双报策略的注意点：** 这两种"3 批次"和"2 次独立运行"的要求在技术上可以同时满足——即对 3 批不同的样品，每批分别进行 2 次独立运行，既满足 NMPA 对批次多样性的要求，也满足 FDA 对操作重现性的要求，但资源消耗较大，须在项目立项时预先规划。

### 国内申报指示病毒选择的具体指导原则要求

根据国内指导原则的要求，验证研究选择的病毒应至少包括：

| 病毒特性维度 | 须覆盖的代表性情形                            |
| ------------ | --------------------------------------------- |
| 核酸类型     | 单链 RNA、双链 RNA、单链 DNA、双链 DNA        |
| 包膜状态     | 脂包膜病毒（有包膜）+ 非脂包膜病毒（无包膜）  |
| 物理化学抗性 | 强抵抗力病毒（PPV、MVM 等）+ 弱抵抗力病毒     |
| 颗粒大小     | 大颗粒病毒（> 100 nm）+ 小颗粒病毒（< 30 nm） |

:::

## WCB 变更的申报内容与风险分级：新建工作细胞库的标准评估框架

:::answer

### 变更背景与触发原因

工作细胞库（WCB）变更是生物药商业化生产中最常见的变更类型之一，通常由以下原因触发：

- **现有 WCB 即将耗尽**（安瓿数量不足以支撑后续生产批次）
- **生产能力扩大**（需增加更多安瓿应对产能需求）
- **现有 WCB 出现质量问题**（如冻存活力不达标）

### 典型变更内容描述

**标准 WCB 更新（从同一 MCB 新建 WCB）：**

> 按照之前申报建库的工艺，从已获批的 MCB 复苏，新建 WCB，以满足后续稳定持续生产的需求。

### 变更风险分级评估

当新建 WCB 满足以下所有条件时，通常可评定为**微小（Minimal）** 或**中等偏小（Minor）** 风险等级：

| 评估维度               | 与现 WCB 的关系                                       | 风险影响                                           |
| ---------------------- | ----------------------------------------------------- | -------------------------------------------------- |
| **来源一致性**         | 新 WCB 和现 WCB 都来源于**同一已获批 MCB**            | **极低**（MCB 已获监管部门批准，遗传背景完全一致） |
| **传代次数**           | 新 WCB 传代次数与现 WCB 保持一致                      | 低（代次相同则传代相关风险等同）                   |
| **制备规模**           | 新 WCB 制备规模与现 WCB 保持一致                      | 低（规模相同则工艺重现性等同）                     |
| **制备方法**           | 新 WCB 制备方法不变（培养基、冻存保护剂、降温程序等） | 低                                                 |
| **主要制备设备**       | 主要设备基本一致（同型号生物反应器、冻存仪等）        | 低                                                 |
| **主要工艺参数**       | 关键工艺参数基本一致（温度、降温速率、冻存浓度等）    | 低                                                 |
| **检验方法和质量标准** | 与现 WCB 完全相同                                     | 低（检验结果可直接类比）                           |

### 新建 WCB 须完成的检定项目

即使评定为微小变更，新建 WCB 仍须按药典要求完成相应检定：

| 检定类别                   | 新建 WCB（来自同一 MCB）必须检定项目                           |
| -------------------------- | -------------------------------------------------------------- |
| 细胞鉴别                   | ✅ 必须（防止建库过程中交叉污染）                              |
| 细菌真菌检查（无菌）       | ✅ 必须                                                        |
| 支原体检查                 | ✅ 必须                                                        |
| 体外细胞接种法（外源病毒） | ✅ 必须（可简化，无需动物接种）                                |
| 细胞形态观察及血吸附       | ✅ 建议                                                        |
| 动物体内接种法             | **❌ 通常可省略**（MCB 已完成；新 WCB 直接来自 MCB，风险极低） |
| 鸡胚体内接种法             | **❌ 通常可省略**（同上）                                      |
| 成瘤性/致瘤性              | **❌ 通常可省略**（细胞株特性未变，MCB 数据已覆盖）            |

### 变更的申报路径建议

| 变更评定                   | 申报类型                            | 主要支持数据                                        |
| -------------------------- | ----------------------------------- | --------------------------------------------------- |
| 微小变更（条件均满足）     | 年度报告（Annual Report）           | WCB 检定合格报告；细胞活力数据；与现 WCB 的简要比较 |
| 中等变更（部分条件不满足） | CBE-30（变更发生后 30 天内提交）    | WCB 全面检定报告；可比性研究数据                    |
| 重大变更                   | PAS（上市前补充申请，须批准后实施） | 全面检定 + 可比性研究 + 必要时病毒清除能力再验证    |

:::

## FDA 细胞库管理的核心指导文件：监管框架与适用场景

:::answer

### FDA 细胞库管理的主要法规依据

FDA 对生物药生产用细胞库的要求分散于多个层次的法规和指导文件中，以下是最核心的参考文件：

| 文件名称                                                                                                                                       | 类型              | 主要内容                                                                                   |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------ |
| **21 CFR 610.18 – Cultures（培养）**                                                                                                           | 法规条款          | 用于生产生物制品的活细胞培养物的一般要求；规定细胞库须定期检测以确保培养物未受外来因子污染 |
| **Points to Consider in the Characterization of Cell Lines Used to Produce Biologicals（细胞系特性分析考量要点）**                             | 指导文件          | 生产用细胞系的全面表征要求；MCB/WCB 的建立和检定；遗传稳定性；逆转录病毒检测               |
| **Points to Consider in the Manufacture and Testing of Monoclonal Antibody Products for Human Use（人用单抗产品生产和检验考量要点，PCT1997）** | 指导文件          | 单抗生产的特定细胞库要求；UPB 检测要求；病毒安全性综合评估                                 |
| **Chemistry, Manufacturing, and Controls Changes to an Approved Application: Certain Biological Products（已获批生物制品 CMC 变更）**          | 指导文件          | 各类细胞库变更（MCB 更换、WCB 新建等）的申报分类和数据要求                                 |
| **CPG M7356.002M – Surveillance Inspections of Protein Drug Substance Manufacturers（蛋白原液生产企业监督检查）**                              | 符合性指南（CPG） | FDA 检查员评估蛋白原液生产商的 GMP 合规性，包括细胞库管理的检查重点                        |
