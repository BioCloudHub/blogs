## CQA 与 PTM 的关系：从分子修饰到质量属性的转化逻辑

:::answer

**CQA 的定义与范畴**

关键质量属性（Critical Quality Attributes, CQAs）是指对药品安全性和有效性有直接影响、须维持在适当限度或范围内的物理、化学、生物学或微生物特性。对于单克隆抗体，主要的 CQA 包括：

| CQA 类别 | 典型指标 | 对安全性/有效性的潜在影响 |
|---|---|---|
| 结构完整性 | 片段化程度、二硫键配对 | 效价下降、半衰期缩短 |
| 聚集状态 | 聚体含量（可溶性/不可溶性） | 免疫原性风险增加 |
| 电荷分布 | 酸性峰/碱性峰/主峰比例 | 亲和力、PK、ADCC 效应改变 |
| 糖基化构型 | N 糖谱、唾液酸含量、岩藻糖化水平 | ADCC/CDC 效应、半衰期、免疫原性 |
| 氧化修饰 | Met/Trp 氧化水平 | FcRn 结合下降，半衰期缩短 |
| 脱酰胺化 | Asn/Gln 脱酰胺水平 | CDR 区结合活性下降 |

**KPI 的定义与区别**

关键工艺性能指标（Key Performance Indicators, KPIs）是反映工艺执行状态的指标，若不能有效控制，将导致工艺无法达到预期目标（如 Titer、活细胞密度、细胞活率等）。KPI 不等同于 CQA，前者反映工艺效率，后者反映产品质量。

**PTM 与 CQA 的转化路径**

在抗体药物生产过程中，细胞培养阶段产生的各类翻译后修饰（PTMs）是 CQA 差异的主要来源：

```
细胞培养工艺参数（温度/pH/DO/补料）
        ↓
细胞代谢状态与酶活性变化
        ↓
翻译后修饰（糖基化、氧化、脱酰胺、C末端Lys切除等）
        ↓
蛋白质理化性质改变（电荷、疏水性、构象）
        ↓
影响 CQA（结合活性、PK、ADCC/CDC、免疫原性）
```

PTM 还可能引起抗体理化性质的间接变化——改变与 Fc 受体的相互作用、降低抗体稳定性、诱导聚集、增加免疫原性。因此，理解 PTM 的形成机制及其工艺驱动因素，是实现 CQA 精准控制的基础。

:::

## 糖基化修饰（Glycosylation）：酶促连接反应与单抗 Fc 的核心修饰位点

:::answer

**糖基化的本质**

糖基化是蛋白质合成过程中寡糖链附着到蛋白质特定位点的酶促反应，发生于内质网和高尔基体中，是真核细胞蛋白质最普遍、最复杂的翻译后修饰之一。

**两种糖基化类型的核心区别**

| 特征 | N-连接糖基化（N-Glycosylation） | O-连接糖基化（O-Glycosylation） |
|---|---|---|
| 连接氨基酸 | 天冬酰胺（Asn，N） | 丝氨酸（Ser）或苏氨酸（Thr） |
| 识别序列 | NXS/T（X ≠ Pro） | 无固定基序 |
| 发生位置 | 内质网（起始），高尔基体（加工） | 高尔基体（N 糖修饰完成后） |
| 糖链核心结构 | 固定的 Glc₃Man₉GlcNAc₂ 前体 | 多样（GalNAc、GlcNAc 等） |
| 单抗中重要性 | **极高**（Fc Asn297 为核心 CQA） | 相对次要（部分 Fc 融合蛋白含有） |

**单克隆抗体的糖基化位点特征**

- 绝大多数 IgG 单抗**仅有一个主要 N 糖基化位点**：重链 CH2 区的 Asn297（编号依 EU 命名体系）
- 该位点的 N 糖修饰是维持 Fc 构象完整性、介导 ADCC/CDC 效应功能的结构基础
- 约 30% 的人血清 IgG 在 Fab 区也含有额外的 N 糖基化位点（如西妥昔单抗），但重组单抗中此情形较少见
- O 糖基化在铰链区偶有报道，通常不作为关键 CQA 控制

**糖基化对单抗质量属性的系统性影响**

糖基化修饰与以下多个 CQA 维度直接关联，须在工艺开发中系统评估：

- **稳定性**：无糖链的 Fc 在热应激下更易聚集，对蛋白酶更敏感
- **ADCC 效应**：核心岩藻糖含量与 FcγRIIIa 亲和力负相关；去岩藻糖化可使 ADCC 提升数十倍
- **CDC 效应**：末端半乳糖（G1F/G2F 水平）与 C1q 结合及 CDC 活性正相关
- **药代动力学（PK）**：高甘露糖型加速体内清除，唾液酸化延长半衰期
- **免疫原性**：非人源单糖（αGal、Neu5Gc）诱发免疫应答风险

:::

## 糖化修饰（Glycation）：非酶促反应与 CQA 影响的边界判断

:::answer

**糖化与糖基化的本质区别**

糖化（Glycation）和糖基化（Glycosylation）是两种截然不同的化学反应，在概念上极易混淆：

| 维度 | 糖基化（Glycosylation） | 糖化（Glycation） |
|---|---|---|
| 反应性质 | **酶促反应**（高度特异） | **非酶促反应**（Maillard 反应，随机） |
| 发生位置 | 内质网/高尔基体（细胞内） | 细胞外（培养液中，储存过程中） |
| 连接方式 | 共价糖苷键（N 或 O 连接） | 共价席夫碱（不稳定）→ Amadori 产物（稳定） |
| 反应底物 | 特异性 NXS/T 序列或 Ser/Thr | 赖氨酸（Lys）侧链 ε-氨基 / N 端 α-氨基 |
| 可控性 | 高（通过工艺调控糖基化酶活性） | 中（通过控制葡萄糖/乳糖浓度） |

**糖化修饰的形成机制**

还原性糖（葡萄糖、果糖、半乳糖等）通过 Maillard 反应与蛋白质游离氨基共价结合：

$$\text{蛋白质-NH}_2 + \text{葡萄糖} \xrightarrow{\text{非酶促}} \text{席夫碱（不稳定）} \xrightarrow{\text{重排}} \text{Amadori 产物（稳定糖化产物）}$$

**糖化修饰对单抗质量的影响**

- **电荷异质性**：糖化修饰引入中性/弱酸性基团，可轻度影响等电点，是酸性峰的次要来源之一
- **聚集体**：糖化可增加蛋白质表面疏水性，促进聚集倾向
- **CDR 区功能影响**：虽然多数研究报道 Fc Lys 糖化不影响抗原结合，但 CDR 区发生糖化可能干扰抗原-抗体相互作用
- **免疫原性**：人体血浆蛋白普遍存在 10–20% 糖化（生理性），一般不增加免疫原性风险；晚期糖化终末产物（AGEs）则与病理状态相关

**工艺控制策略**

- 控制培养液中葡萄糖浓度（通常维持在 1–4 g/L），避免长期高糖暴露
- 优化补料策略，避免葡萄糖浓度峰值过高（>6 g/L）
- 适当缩短培养周期（减少糖化积累时间）

:::

## 高甘露糖型（High-Mannose）的定义、形成机制与质量影响

:::answer

**定义与结构特征**

高甘露糖型（High-Mannose Type, HM）N 糖是指糖链核心结构仅含甘露糖残基、未完成复杂型加工的 N 糖，结构通式为 Man₅₋₉GlcNAc₂（其中 Man5 最具代表性）。

**形成机制：高尔基体甘露糖酶切割不完全**

N 糖前体（Glc₃Man₉GlcNAc₂）转移至 Asn297 后，在内质网和高尔基体中经历一系列甘露糖苷酶的修剪：

```
Man₉GlcNAc₂ → Man₈GlcNAc₂ → Man₇GlcNAc₂ → Man₆GlcNAc₂
    → Man₅GlcNAc₂ （α-甘露糖苷酶 I 修剪完成）
        → 进入复杂型加工路径（GnT-I 作用）
```

当 **α-甘露糖苷酶 I 或 II 活性受抑**，或 **GnT-I（N-乙酰葡萄糖胺转移酶 I）活性不足**，蛋白质在 Man₅～Man₉ 阶段即提前离开高尔基体，导致高甘露糖型积累。

**高甘露糖型对单抗质量的双刃剑效应**

| 质量维度 | 影响方向 | 机制说明 |
|---|---|---|
| ADCC 效应 | ↑ 增强 | 高甘露糖型不含核心岩藻糖，去岩藻糖化效果增强 FcγRIIIa 结合 |
| 半衰期 | ↓ 缩短 | 肝脏巨噬细胞表面甘露糖受体（MR）结合 Man₅₋₉，介导内吞清除 |
| CDC 效应 | ↓ 减弱 | 高甘露糖型末端无半乳糖，与 C1q 的结合能力降低 |
| 免疫原性 | ↑ 增加风险 | 高甘露糖结构在哺乳动物系统中具有较强免疫原性（树突状细胞 C 型凝集素受体识别） |
| 批间一致性 | 风险 | Man5 水平对培养条件高度敏感，批间波动较大 |

> **整体评估：** 对于大多数治疗性单抗，高甘露糖型是需要严格控制的"低质量"糖型，尤其应将 Man5 水平纳入克隆筛选指标和批放行质量标准，生产工艺应尽量降低其比例。

:::

## N 糖合成路径简析：从前体组装到复杂型成熟的关键节点

:::answer

理解 N 糖合成的关键节点，是实施糖型工艺调控的分子基础。以下以 IgG 单抗 Fc Asn297 为例，梳理 N 糖从前体到复杂型的合成路径：

**第一步（内质网细胞质侧）**

在多萜醇焦磷酸载体上，依次添加 2 个 GlcNAc 和 5 个甘露糖，形成 GlcNAc₂Man₅ 中间体，直接利用 UDP-GlcNAc 和 GDP-Man 作为核苷酸糖供体。

**第二步（内质网腔内侧）**

GlcNAc₂Man₅ 翻转至内质网腔内，继续添加 4 个甘露糖和 3 个葡萄糖，形成完整前体 Glc₃Man₉GlcNAc₂（此步骤利用多萜醇磷酸-糖作为供体）。

**第三步（内质网 → 高尔基体转运）**

- 寡糖转移酶（OST）将 Glc₃Man₉GlcNAc₂ 整体转移至抗体 Asn297
- α-葡萄糖苷酶 I/II 切除 3 个 Glc；α-甘露糖苷酶 I 切除 4 个 Man → 形成 Man₅GlcNAc₂
- **若蛋白在此阶段提前离开高尔基体 → 高甘露糖型（Man₅～Man₉）**

**第四步（高尔基体内复杂型加工）**

Man₅GlcNAc₂ 在高尔基体中经历两类酶促反应，形成复杂型 N 糖：

| 酶 | 反应类型 | 产物 | 对功能的影响 |
|---|---|---|---|
| GnT-I（N-乙酰葡萄糖胺转移酶 I） | 添加 GlcNAc（天线 α1-3 臂） | 杂合型/复杂型前体 | 必需步骤，缺失导致高甘露糖积累 |
| α-甘露糖苷酶 II | 切除 2 个 Man | Man₃GlcNAc₂ 核心 | 复杂型合成必经步骤 |
| GnT-II | 添加第二个 GlcNAc（α1-6 臂） | 双天线复杂型骨架 | 建立双天线结构 |
| GnT-III | 添加分支 GlcNAc（bisecting） | 含分支 GlcNAc 的复杂型 | 抑制岩藻糖化，增强 ADCC |
| FUT8（α1-6 岩藻糖转移酶） | 添加核心岩藻糖 | G0F 等含岩藻糖糖型 | 降低 FcγRIIIa 结合，减弱 ADCC |
| β4-半乳糖转移酶 | 添加半乳糖 | G1F、G2F | 促进 CDC；提升 C1q 结合 |
| α2-3/α2-6 唾液酸转移酶 | 添加唾液酸 | G1FS1、G2FS2 等 | 影响 ADCC、半衰期、抗炎功能 |

> **关键节点总结：** GnT-I 是高甘露糖型进入复杂型加工的"门控酶"，其活性受渗透压、pH、金属离子等工艺参数调节，是高甘露糖型工艺调控的核心靶点。

:::

## 高甘露糖型的多维工艺调控策略

:::answer

高甘露糖型（尤其是 Man5）的水平受多个工艺层面因素的影响，需从细胞株、培养基、过程参数等角度系统干预。

**调控维度一：细胞株工程——从源头降低高甘露糖型**

- **克隆筛选**：Man5 水平是克隆评估的关键 CQA 指标之一，应在早期筛选阶段即纳入考量，选择高 Titer、低 Man5 的克隆作为主克隆
- **基因工程提升 GnT-I 活性**：在表达载体中共同过表达 GnT-I，或通过定向突变优化内源 GnT-I 的催化效率，从根本上提高复杂型加工能力，降低高甘露糖型比例

**调控维度二：渗透压——对 Man5 影响最显著的过程参数**

- 高渗透压通过降低 GnT-I mRNA 水平并影响 GnT-I 蛋白稳定性，抑制复杂型 N 糖的加工，导致高甘露糖积累
- 定量数据：CHO 细胞表达的 IgG 单抗，渗透压从 300 mOsm/kg 升至 400 mOsm/kg，Man5 水平从约 **5% 升至约 27%**，影响幅度极为显著
- **控制策略**：生产培养后期避免渗透压过度升高（建议控制在 350–400 mOsm/kg 以内），优化补料策略以减缓渗透压的累积速率

**调控维度三：培养周期——时间积累效应的双重机制**

- Man5 水平随培养时间延长而升高：在 CHO 细胞 Fed-batch 培养中，培养 21 天的 Man5 水平约为培养 7 天的 2 倍（NS0 细胞系有类似趋势）
- 原因一：随培养时间延长，渗透压持续累积升高，间接抑制 GnT-I 活性
- 原因二：培养后期微环境恶化（氨积累、pH 漂移、代谢废物积累），直接影响甘露糖酶和 GnT-I 等糖基化酶的活性与稳定性
- **控制策略**：在保证产量的前提下，合理控制培养周期（通常 ≤ 14 天），避免培养末期质量属性的显著漂移；在关键 CQA 允许范围内确定最优收获时间点

**调控维度四：氯化锰（MnCl₂）添加——提升半乳糖化兼降低 Man5**

- Mn²⁺ 是高尔基体内多种糖基转移酶（包括半乳糖转移酶）的辅因子，可显著提高酶催化效率
- 研究表明，添加 **0.25–1 μmol/L MnCl₂** 能有效提高 G1F 和 G2F 含量，从而：
  - 促进 Man5 进一步加工为复杂型，降低 Man5 比例
  - 同时提升末端半乳糖水平，增强 CDC 效应
- **注意**：Mn²⁺ 浓度过高（>5 μmol/L）可能对细胞产生毒性，并干扰其他金属离子的代谢平衡，须通过 DoE 确定最优添加量

**调控维度五：pH——高尔基体内 pH 梯度的严格维持**

高尔基体不同腔室维持严格的 pH 梯度，对糖基化酶活性至关重要：

| 细胞器区域 | pH 范围 | 功能 |
|---|---|---|
| 内质网 | ~7.0–7.2 | N 糖前体转移，早期加工 |
| 顺式高尔基体（cis） | ~6.7 | Man₉ → Man₅ 修剪 |
| 中间高尔基体（medial） | ~6.0–6.3 | GnT-I/II、FUT8 反应 |
| 反式高尔基体（trans）/ TGN | ~5.5–6.0 | 半乳糖基化、唾液酸化 |

pH 干扰对 Man5 的影响：

- **细胞质 pH 偏低**：内质网-高尔基体间运输能力下降，并可能诱导高尔基体降解，导致产量下降和 HM 含量升高
- **弱碱（培养基 pH 偏高）**：升高高尔基体内腔 pH，干扰半乳糖基转移酶和唾液酸转移酶活性（这些酶在偏酸性环境中活性更高），使复杂型加工不完全，HM 含量上升
- **结论**：细胞外培养液 pH 偏高或偏低，均可打破不同细胞器间的 pH 梯度，增加 HM 含量；对于 HM 敏感的项目，pH 控制精度需提高至 ±0.1 以内

**调控维度六：培养基组分——胆碱与其他营养因子的影响**

- **胆碱（Choline）**：细胞膜磷脂（磷脂酰胆碱、鞘磷脂）合成的必需前体，胆碱限制导致膜结构异常，进而影响内质网和高尔基体的结构完整性及糖基化加工能力，表现为 Man5 升高、Titer 下降、聚集体增加
- **精氨酸、鸟氨酸**：影响细胞氮代谢，间接调节高尔基体微环境，报道对 HM 水平有一定影响
- **培养基配方差异**：同一 CHO 细胞系在不同培养基中，Man5 变化范围可达 3–16%，提示培养基筛选阶段应将 Man5 纳入评估指标

**高甘露糖型工艺调控策略汇总**

| 调控手段 | 对 Man5 的影响方向 | 关键机制 | 操作可行性 |
|---|---|---|---|
| 克隆筛选（低 Man5 克隆） | ↓↓ 显著降低 | 遗传背景决定基础糖型 | 高（早期介入） |
| 过表达 GnT-I | ↓↓ 显著降低 | 提升复杂型加工能力 | 中（基因工程介入） |
| 降低培养液渗透压 | ↓ 降低 | 保护 GnT-I 活性和稳定性 | 高（工艺调整） |
| 缩短培养周期 | ↓ 降低 | 减少时间积累效应 | 高（工艺设计） |
| 添加 MnCl₂（0.25–1 μmol/L） | ↓ 降低 | 提升糖基转移酶辅因子 | 高（培养基添加） |
| 维持适宜培养液 pH（6.9–7.2） | ↓ 降低 | 维持高尔基体 pH 梯度 | 高（过程控制） |
| 优化培养基（足量胆碱） | ↓ 降低 | 维持膜结构完整性 | 高（培养基设计） |

:::

## 唾液酸化修饰：半衰期调控与免疫原性的双重效应

:::answer

**唾液酸的结构特征**

唾液酸（Sialic Acid）是一类具有 9 碳骨架和吡喃糖结构的酸性氨基糖，是神经氨酸（Neuraminic Acid）的衍生物，位于糖蛋白糖链的非还原末端。在哺乳动物系统中最主要的两种形式为：

- **N-乙酰神经氨酸（NANA / Neu5Ac）**：人体内的主要形式，所有细胞系均可合成
- **N-羟乙酰神经氨酸（NGNA / Neu5Gc）**：仅存在于鼠源细胞系（NS0、SP2/0）及部分 CHO 表达产物中，人体不能合成 Neu5Gc，存在预存抗体

**唾液酸含量的细胞系差异**

| 来源 | 唾液酸含量 | 唾液酸形式 |
|---|---|---|
| 人体血清 IgG | ~10% | 仅 Neu5Ac（α2-6 连接为主） |
| CHO 细胞表达单抗 | **< 2%**（极低） | Neu5Ac（α2-3 连接为主） |
| CHO 细胞表达 Fc 融合蛋白 | 可达 10–30%（较高） | Neu5Ac（α2-3 连接为主） |
| NS0 / SP2/0 细胞表达单抗 | 中等 | Neu5Ac + Neu5Gc（α2-6 连接为主） |

> **原因解析：** CHO 细胞 Fc N 糖末端的唾液酸化程度天然较低（半乳糖基化不完全限制了唾液酸连接位点），且以 α2-3 连接为主（不具备人体 α2-6 连接唾液酸的功能）。Fc 融合蛋白的功能蛋白区域往往含有更多糖基化位点，唾液酸化程度因此显著高于单抗。

**唾液酸化对单抗质量属性的多维影响**

**影响一：半衰期延长（主要正面效应）**

- 糖蛋白糖链末端若未连接唾液酸，裸露的半乳糖/GlcNAc 末端可被肝脏**无唾液酸糖蛋白受体（ASGPR）**识别，介导受体介导的内吞和溶酶体降解，大幅缩短半衰期
- 唾液酸化屏蔽末端半乳糖，使蛋白逃脱 ASGPR 介导的清除
- 典型案例：TNFR-Fc 抗体融合蛋白体内半衰期与唾液酸含量显著正相关

**影响二：电荷异质性（酸性峰来源）**

- 唾液酸本身为酸性（pKa ≈ 2.6），携带阴离子，增加蛋白净负电荷
- 唾液酸化程度增加 → 酸性峰比例升高，在 IEX 分析中酸性峰左移增大

**影响三：ADCC 效应减弱**

- Fc 上高唾液酸化（尤其末端唾液酸覆盖率高）可通过空间位阻减弱 FcγRIIIa 与 Fc 的结合
- 高唾液酸化还可能诱导铰链区构象改变，使 Fab 从双价转为单价模式，影响膜抗原结合

**影响四：免疫原性风险（Neu5Gc 特有）**

- 人体不含 Neu5Gc，但体内存在预存抗 Neu5Gc 抗体
- NS0/SP2/0 细胞表达的单抗含一定量 Neu5Gc，可能引起免疫应答
- 研究表明：单抗 Fc 上含 ≥ 2 个 Neu5Gc 修饰时，才能与抗 Neu5Gc 抗体有效结合（免疫原性较弱）

**抗炎功能（高唾液酸化 Fc 的特殊效应）**

- IVIG 的抗炎作用来源于其中高唾液酸化（α2-6 连接）Fc 组分
- α2-6 唾液酸化使 Fc 构象更紧密，增强与 DC-SIGN（免疫负调节受体）的亲和力，发挥抗炎效应
- **注意：** CHO 细胞表达单抗的唾液酸为 α2-3 连接，**不具备**这一抗炎功能；NS0/SP2/0 细胞（α2-6 连接）具有此功能，但存在 Neu5Gc 免疫原性风险

**唾液酸含量的检测方法比较**

| 方法 | 原理 | 优点 | 局限 |
|---|---|---|---|
| **间苯二酚法** | 比色法，唾液酸与间苯二酚显色 | 快速简便，可参照药典（ChP 通则 3102） | 灵敏度低，线性范围窄，非特异性 |
| **酶法** | 唾液酸酶水解 + 酶联反应定量 | 特异性高，准确 | 成本高，操作复杂，线性范围窄 |
| **HPLC 法** | 荧光衍生化 + 反相/离子交换分离 | 快速、灵敏、重现性好、线性范围宽 | 需衍生化前处理 |
| **LC-MS/MS** | 质谱精确定量 | 最高专属性，可区分 Neu5Ac/Neu5Gc | 仪器成本高，方法复杂 |

> **推荐策略：** 常规批次放行建议采用 HPLC 法；结构确证研究采用 LC-MS/MS；药典合规场景可参考间苯二酚法（ChP 三部通则 3102）。

:::

## 氧化修饰（Oxidation）：Met/Trp 氧化对 Fc 功能与稳定性的关键影响

:::answer

**氧化修饰的本质**

蛋白质氧化是由活性氧（ROS）诱导的氨基酸侧链共价修饰，本质是电子转移反应：

$$\text{Met} + \text{ROS} \xrightarrow{} \text{甲硫氨酸亚砜（MetO）} \xrightarrow{\text{高氧化压力}} \text{甲硫氨酸砜（MetO}_2\text{）}$$

氧化产物分子量增加 **+15.99 Da**（亚砜）或 +31.99 Da（砜），可通过 LC-MS 精确检测。

**主要氧化位点与各位点的功能影响**

| 氧化位点 | 位置 | 溶剂暴露 | 主要功能影响 |
|---|---|---|---|
| **Met252**（CH2 末端） | Fc CH2-CH3 界面 | 中等 | Protein A、FcRn 结合显著下降，半衰期缩短 |
| **Met428**（CH3 结构域） | Fc CH2-CH3 界面 | 中等 | 同 Met252，与多种配体结合位点紧邻 |
| Trp（CDR 区） | 可变区 | 高度暴露 | 抗原结合亲和力下降（CDR 区构象改变） |
| Met（CDR 区） | 可变区 | 依序列 | 个别抗体报道影响结合活性 |

**氧化对电荷异质性的间接影响**

- 氧化过程中**净电荷无直接改变**（亚砜不带电荷）
- 但氧化改变了蛋白质空间构象，使局部带电基团的溶剂暴露程度发生变化，导致蛋白质表面电荷分布改变
- 研究表明，Met 氧化可导致酸性电荷变体或碱性电荷变体的生成（取决于构象改变的方向）

**氧化的主要来源**

- **细胞培养阶段**：培养液中的金属离子（Fe²⁺、Cu²⁺）催化 Fenton 反应产生 ROS；高 DO 水平增加氧化风险
- **纯化阶段**：光照（尤其 UV 暴露）、过氧化氢残留（清洁剂）、臭氧接触
- **制剂与储存阶段**：温度升高、光照、包材中的过氧化物可溶出物
- **操作过程**：泵、过滤器等引入的金属离子污染

**工艺控制策略**

- 上游：在培养基中添加抗氧化剂（如 L-色氨酸、N-乙酰半胱氨酸），减少 ROS 积累；铁离子浓度超标（高铁培养基）可导致 ROS 增多并引起药液颜色变化，需控制铁离子形态和浓度
- 纯化：避免非必要 UV 照射，选用不含过氧化物的缓冲液辅料（避免使用劣质 Tween 80）
- 制剂：添加蛋氨酸作为竞争性抗氧化剂；添加 EDTA 螯合金属离子；避光包装

:::

## 脱酰胺化（Deamidation）：Asn/Gln 修饰与 CDR 区结合活性的关键联系

:::answer

**脱酰胺化的化学本质**

脱酰胺化是蛋白质在生产、储存过程中最常见的化学降解反应之一，使酰胺基（-CONH₂）水解为羧基（-COOH），引入负电荷，是酸性电荷变体的重要来源。

**两类脱酰胺位点的反应机制与速率**

**天冬酰胺（Asn）脱酰胺——主要且快速**

在 pH > 7 的条件下，Asn 通过五元环**琥珀酰亚胺（Asu）中间体**发生脱酰胺，产物以约 **1:3 比例**生成 Asp 和 isoAsp 的混合物：

$$\text{Asn} \xrightarrow{pH>7} \text{Asu（中间体）} \xrightarrow{H_2O} \text{Asp（25\%）+ isoAsp（75\%）}$$

- 最敏感基序：**Asn-Gly（NG）** > Asn-Ser（NS）> Asn-Thr（NT）
- CDR 区序列柔性高、溶剂暴露度大，脱酰胺速率显著高于 Fc 区

**谷氨酰胺（Gln）脱酰胺——次要且缓慢**

Gln 通过六元环**戊二酰胺（glutarimide）中间体**发生脱酰胺，反应速率比 Asn 慢得多：

$$\text{Gln} \xrightarrow{} \text{戊二酰胺中间体} \xrightarrow{H_2O} \text{isoGlu + Glu}$$

**影响脱酰胺速率的主要因素**

| 影响因素 | 对脱酰胺的影响 | 机制 |
|---|---|---|
| pH | pH 升高显著加速（碱性催化） | OH⁻ 催化去质子化，促进环化 |
| 温度 | 温度升高加速 | Arrhenius 效应，升温 10°C 速率约增 2–3 倍 |
| 序列上下文 | NG 基序最敏感 | Gly 的小侧链允许主链充分旋转，利于 Asu 环化 |
| 蛋白构象（高级结构） | 展开态加速 | 溶剂暴露 Asn 更易反应 |
| 时间 | 线性积累 | 储存时间越长，脱酰胺程度越高 |

**脱酰胺对单抗功能的影响**

- **CDR 区脱酰胺（高风险）**：Asn → Asp/isoAsp 引入额外负电荷并改变 CDR 构象，损害抗原结合特异性和亲和力；CDR 区柔性（Flexibility）降低可导致不同 CDR 环之间的相互作用受影响
- **Fc 区 Asn384 脱酰胺（低风险）**：位于 CH3 结构域，远离 FcRn 和 FcγR 结合位点，通常不影响效应功能和 PK；但 Asu 中间体可能影响局部稳定性
- **总体原则**：CDR 区 > Fc 区；isoAsp 的生成比 Asp 对构象影响更大（异构化改变主链走向）

**工艺控制策略**

- 上游：将培养 pH 控制在较低范围（6.9–7.1）可有效减缓脱酰胺速率
- 纯化：缩短中间体的暴露时间，避免在碱性 pH 下长时间保存中间体
- 制剂：选择弱酸性配方 pH（5.0–6.5）；加速稳定性实验应将脱酰胺作为主要考察指标；分子改造（位点突变）可从根本上消除高风险脱酰胺位点

:::

## 摇瓶培养中 CO₂ 的控制逻辑与浓度设定原则

:::answer

CO₂ 在动物细胞培养中扮演双重角色：**细胞代谢产物**（需移除以防积累）和**pH 缓冲体系的必需组分**（培养液 NaHCO₃/CO₂ 缓冲对的关键）。

**摇瓶（培养箱）中 CO₂ 的控制机制**

- 培养箱内置**红外 CO₂ 传感探头**，实时监测箱内气相 CO₂ 浓度
- 通过 PID 控制器自动调节 CO₂ 注入量，维持设定浓度
- 设定浓度与培养基中 **NaHCO₃ 浓度**密切相关：NaHCO₃ 浓度高的培养基需要较高 CO₂ 浓度以维持 pH，反之则低

**CO₂ 浓度设定的计算逻辑**

培养液 pH 由 Henderson-Hasselbalch 方程决定：

$$\text{pH} = 6.1 + \log\frac{[\text{HCO}_3^-]}{0.03 \times p\text{CO}_2(\text{mmHg})}$$

实践中，常规动物细胞培养 CO₂ 浓度设定在 **5–10%**，具体值依培养基 NaHCO₃ 浓度与目标 pH（通常 7.0–7.2）联合确定。

**温度对 CO₂ 溶解度的影响**

CO₂ 在水中的溶解度随温度升高而降低（Henry 定律）。降温培养时（如从 37°C 降至 31°C），CO₂ 溶解度增大，相同箱内 CO₂ 浓度对应更高的液相 pCO₂，需注意防止 pCO₂ 过高抑制细胞生长。实施降温策略时，建议同步降低培养箱 CO₂ 设定浓度或加强气体交换。

:::

## CO₂ 的两大来源：生物来源与非生物来源的量化解析

:::answer

**来源一：生物来源（细胞有氧呼吸）**

细胞通过 TCA 循环（三羧酸循环）有氧代谢产生 CO₂，生物来源的 CO₂ 总量由三个参数决定：

$$\text{CO}_2\text{（生物来源）} \propto q_{CO_2} \times \text{VCD}_{peak} \times \Delta t_{viable}$$

- $q_{CO_2}$：细胞 CO₂ 比生成速率（与氧耗速率 OUR 正相关）
- $\text{VCD}_{peak}$：培养过程最高活细胞密度
- $\Delta t_{viable}$：有效活细胞维持时间

高密度培养（VCD > 20 × 10⁶ cells/mL）时，生物来源 CO₂ 生成速率显著上升，是大规模反应器中 pCO₂ 积累的主要驱动因素。

**来源二：非生物来源（pH 调控介入）**

| 非生物来源 | 机制 | 量化影响 |
|---|---|---|
| 培养基中 NaHCO₃ 电离 | NaHCO₃ → Na⁺ + HCO₃⁻，HCO₃⁻ + H⁺ → H₂CO₃ → CO₂ + H₂O | 随培养基配方固定，一般贡献较稳定 |
| 补加碱液（Na₂CO₃/NaHCO₃） | 碱液在酸性培养液中释放 CO₂ | pH 控制越频繁，非生物 CO₂ 来源越大 |
| 通入气态 CO₂ | 直接溶入培养液 | 仅用于 pH 降低操作（pH 调高时不通 CO₂） |

**pCO₂ 积累的规模效应**

摇瓶和小规模反应器中，因培养体积小、气液比例合理，pCO₂ 通常维持在可接受范围（30–80 mmHg）。大规模反应器（≥ 200 L）中，以下因素导致 pCO₂ 积累风险显著增加：

- 液柱高度增大，气泡在液相中停留时间延长，CO₂ 溶入量增加
- 大规模反应器每单位体积的通气量（vvm）相对较小，CO₂ 移除效率降低
- 高细胞密度培养时，生物来源 CO₂ 生成速率更高

**实用控制指标**

建议将生产反应器 pCO₂ 维持在 **50–100 mmHg** 的范围内，超过 **140 mmHg** 时需采取干预措施（增大大泡通气量、降低培养液液位或调整 sparger 设计）。

:::

## pCO₂ 对细胞培养的系统性影响：从宏观性能到微观代谢的多层次作用

:::answer

pCO₂ 对细胞培养的影响是多层次的，且双向有害：高 pCO₂ 抑制细胞生长和产物表达，而低 pCO₂ 同样不可接受。

**高 pCO₂ 对细胞密度和活率的影响（实验数据汇总）**

| 研究条件 | pCO₂ 变化 | 细胞密度 | 细胞活率 |
|---|---|---|---|
| CHO，10 L 灌注，37°C | 35→148 mmHg | 8.9→5.9 × 10⁶ cells/mL（↓34%） | 79→58%（↓21%） |
| CHO，Fed-batch，37°C | 升至 150 mmHg | 无显著影响 | 无显著影响 |
| CHO，Fed-batch，33°C | 升高 pCO₂ | 15–20→5–8 × 10⁵ cells/mL（↓显著） | 无显著影响 |

**高 pCO₂ 对细胞代谢的影响**

- 渗透压恒定时，pCO₂ 升至 140 mmHg，杂交瘤细胞**葡萄糖比消耗速率和乳酸比生成速率下降约 40–50%**，氨比生成速率无变化
- 代谢抑制反映了 TCA 循环活性下降，细胞能量供给减少

**高 pCO₂ 对产物表达和质量的影响**

- 渗透压 310 mOsm/kg 时，pCO₂ 从 36 升至 140 mmHg → 产物比生产速率（Qp）下降 **10%**
- pCO₂ 升至 195 mmHg → Qp 进一步下降 **33%**
- pCO₂ 还影响高尔基体内的糖基化加工酶活性和核苷酸糖底物供给，可改变 N 糖谱（尤其影响唾液酸化和半乳糖化水平）

**低 pCO₂ 同样不可接受**

- 摇瓶实验证实：**完全去除培养环境 CO₂ 导致 CHO 细胞无法生长**
- CO₂/HCO₃⁻ 是多种酶催化反应的底物，是细胞维持胞内 pH 和碳酸酐酶（CA）正常功能的必需组分
- 过度通气（大量大泡）在大规模反应器中可导致 pCO₂ 过低，影响细胞生长

**pCO₂ 影响细胞的微观机制**

- **胞内 pH 改变**：CO₂ 自由通透细胞膜，胞外 pCO₂ 升高导致胞内 CO₂ 浓度同步升高，胞内 pH 下降，影响酶活性和信号通路
- **细胞膜通透性改变**：高 CO₂/HCO₃⁻ 影响细胞膜磷脂组成和流动性，改变营养物质摄取和废物排出效率
- **蛋白物化属性改变**：高 pCO₂ 条件下，CO₂ 与蛋白质 N 端 α-氨基形成氨基甲酸酯（Carbamylation），可能改变抗体表面电荷属性

**pCO₂ 与渗透压的协同效应**

高 pCO₂ 和高渗透压往往同时出现（补料和碱液添加同时提高二者），二者对细胞的负面影响具有叠加效应。在工艺设计时，应将 pCO₂ 和渗透压作为一对协同控制参数，而非独立考虑。

**工艺控制建议汇总**

| 控制目标 | 具体措施 |
|---|---|
| 维持 pCO₂ 在 50–100 mmHg | 大孔径 sparger 负责 CO₂ 移除，确保足够大泡通气量（≥ 0.02 vvm） |
| 降温时防止 pCO₂ 升高 | 同步降低培养箱 CO₂ 设定值或增大换气量 |
| 大规模放大时提升 CO₂ 移除能力 | 优化 sparger 设计（大泡为主），适当降低培养液液位 |
| 平衡高密度培养与 CO₂ 移除 | 采用灌注工艺持续更新培养液，降低 CO₂ 积累 |

:::

## 培养基抗氧化剂的添加：减少 ROS 与防止高铁诱导颜色变化

:::answer

**问题背景**

在细胞培养过程中，培养基中的铁离子（尤其是 Fe²⁺/Fe³⁺）可通过 Fenton 反应催化活性氧（ROS）的产生，引发以下双重问题：

1. **蛋白质氧化**：ROS 与 Met、Trp 等氨基酸反应，增加氧化修饰水平，影响 CQA
2. **原液颜色变化（DS Coloration）**：铁离子或 ROS 与培养液中的有机成分（如 Tyr、Trp、His、色氨酸降解产物）发生氧化缩合反应，生成黄色至棕色的发色团，导致收获液和原液颜色异常

**高铁培养基的颜色变化机制**

$$\text{Fe}^{2+} + \text{H}_2\text{O}_2 \xrightarrow{\text{Fenton}} \text{Fe}^{3+} + \cdot\text{OH}(\text{羟自由基})$$

$$\cdot\text{OH} + \text{芳香族氨基酸（Trp、Tyr）} \rightarrow \text{氧化缩合产物（有色）}$$

**抗氧化剂的作用机制与常用选项**

| 抗氧化剂 | 作用机制 | 添加浓度范围 | 注意事项 |
|---|---|---|---|
| L-蛋氨酸 | 竞争性 ROS 清除剂，优先被氧化保护其他 Met | 0.5–5 mmol/L | 验证对细胞活力和产品质量无不良影响 |
| N-乙酰半胱氨酸（NAC） | 抗氧化剂兼 GSH 前体，清除 H₂O₂ 和自由基 | 0.1–1 mmol/L | 高浓度可能影响细胞生长 |
| 维生素 E（Trolox） | 脂溶性抗氧化剂，保护细胞膜脂质 | 0.05–0.5 mmol/L | 溶解度有限 |
| EDTA | 金属离子螯合剂，阻断 Fenton 反应催化 | 0.01–0.1 mmol/L | 同时影响其他二价金属离子（Mn²⁺、Zn²⁺） |
| 半胱氨酸 | 还原性氨基酸，清除 ROS | 培养基标准组分 | 高浓度可能影响二硫键形成 |

**颜色控制的综合策略**

- **铁离子形态管理**：优先使用以螯合形式存在的铁（如柠檬酸铁、EDTA 铁），减少游离 Fe²⁺/Fe³⁺ 浓度
- **抗氧化剂组合**：单一抗氧化剂往往不足，推荐使用多种抗氧化剂组合（如 Met + NAC + EDTA）
- **光照控制**：避光操作，减少光氧化引发的颜色变化
- **温度控制**：较低培养温度下氧化反应速率减慢，有助于减少颜色变化

> **颜色作为工艺监控指标：** DS 颜色通常以 ASTM/EP 比色法或分光光度法（420 nm / 450 nm 吸光度）量化，颜色超标往往提示氧化应激问题，需回溯培养基铁离子水平、通气量和操作流程。

:::
