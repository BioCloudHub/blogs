## 电荷异质性的本质：翻译后修饰对蛋白表面电荷的系统性改变

:::answer

重组单克隆抗体的电荷异质性（Charge Heterogeneity）是由多种翻译后修饰（Post-Translational Modifications, PTMs）引起的蛋白质表面净电荷差异，在离子交换色谱（IEX）中表现为酸性峰、主峰（主成分）和碱性峰三组分布。

**电荷异质性的形成机制**

几乎所有翻译后修饰都会通过以下两种途径改变蛋白表面电荷分布：

- **直接改变电荷基团数量**：如唾液酸化引入阴离子、脱酰胺引入额外羧基、C 末端赖氨酸保留增加正电荷
- **间接引起构象改变**：如糖基化、二硫键错配改变蛋白空间结构，使带电基团的暴露程度发生变化

**IEX 峰分布与修饰来源对应关系（以 CEX 为例）**

| 洗脱区域 | 电荷特征 | 主要修饰来源 |
|---|---|---|
| 酸性峰（主峰前洗脱） | 净负电荷增多 | 唾液酸化、Asn 脱酰胺、糖化（赖氨酸/N 端）、抗体片段 |
| 主峰 | 参考电荷状态 | 目标蛋白的主要分子形式 |
| 碱性峰（主峰后洗脱） | 净正电荷增多 | C 末端 Lys 不完全切除、Asn 异构化（Asu）、焦谷氨酸不完全环化 |

> **细胞系差异：** SP2/0 或 NS0 细胞表达的单抗，酸性峰以唾液酸化为主；CHO 细胞表达的单抗唾液酸化程度相对较低，脱酰胺是酸性峰的重要来源之一。碱性峰在大多数 IgG1 单抗中以 C 末端赖氨酸不均一性为主要来源。

**电荷异质性的质量控制意义**

- 电荷变体可影响抗体的结合活性、生物学功能（ADCC/CDC）、药代动力学（PK）和免疫原性
- 电荷异质性是抗体药物工艺开发中重要的 CQA 候选项，需建立稳定的检测方法和合理的质量限度
- 降低酸性变体比例通常优先于碱性变体，尤其是 CDR 区修饰引起的酸性变体，对效价影响更为显著（如曲妥珠单抗酸性变体与 HER2 的亲和力明显下降）

:::

## 酸性变体的分子来源：七类修饰的机制与风险分级

:::answer

酸性变体是电荷异质性中对药效影响更为深远的组分，其来源涵盖多种翻译后修饰，需从结构层面逐一理解。

**主要来源一：唾液酸化（Sialylation）**

唾液酸（N-乙酰神经氨酸，Neu5Ac）本身携带阴离子（pKa ≈ 2.6），连接于糖链末端后直接增加蛋白净负电荷。唾液酸含量受细胞系、培养条件和糖基化酶活性影响，CHO 细胞表达的单抗 Fc 段唾液酸化程度通常较低，但 SP2/0 和 NS0 细胞可能更高。

**主要来源二：Asn 脱酰胺（Deamidation）**

- Asn 脱酰胺是酸性峰最重要的化学降解来源之一，反应路径为：Asn → 琥珀酰亚胺（Asu）中间体 → Asp + isoAsp 混合物
- 脱酰胺反应最常发生于 Asn-Gly（NG）、Asn-Ser（NS）序列基序，CDR 区高度暴露且柔性较大的区域尤为易感
- CDR 区脱酰胺可直接降低抗体-抗原结合亲和力；Fc 区保守位点 Asn384（CH3 结构域）发生脱酰胺，因远离 FcRn 和 FcγR 结合位点，通常不影响效应功能
- 反应速率受 pH（碱性加速）、温度和氨基酸序列上下文影响

**主要来源三：糖化（Glycation）**

- 葡萄糖或乳糖通过非酶促 Maillard 反应，与赖氨酸（Lys）侧链氨基或 N 端 α-氨基共价结合
- 高葡萄糖浓度培养条件可增加糖化程度（Yuk 等）
- 糖化发生于全分子，无特定"热点位点"，通常对抗原结合能力影响有限；CDR 区发生糖化也被报道不影响结合能力（Quan 等）
- 人体血浆蛋白普遍存在 10–20% 的糖化，一般认为不增加免疫原性风险

**其他酸性来源汇总**

| 修饰类型 | 形成机制 | 风险程度 |
|---|---|---|
| 非典型/三硫键 | 二硫键重排，铰链区三硫键（-S-S-S-） | 低（不影响 IgG2 热稳定性） |
| 马来酸修饰 | 马来酸与重/轻链 N 端氨基反应 | 中（依位置而定） |
| Cys104 半胱酰胺化 | 重链 CDR3 游离 Cys 与半胱氨酸结合 | 高（热稳定性下降，聚集倾向增加） |
| 抗体裂解片段 | 蛋白酶水解或化学断裂 | 高（影响效价和安全性） |
| 还原糖糖化（赖氨酸/组氨酸/精氨酸） | Maillard 反应，羰基与氨基反应 | 中（批次间差异风险） |

:::

## 碱性变体的分子来源：六类修饰的机制与可控性分析

:::answer

碱性变体在多数单抗产品中对药效的负面影响小于酸性变体，但某些碱性修饰（如 CDR 区 Asu、Met 氧化）仍具有显著的质量风险。

**主要来源一：C 末端赖氨酸不完全切除（C-terminal Lys Heterogeneity）**

- IgG1 重链 C 末端通常携带赖氨酸（PGK 序列），胞内羧肽酶 B（CBP）负责切除，但酶切不完全，导致产物中同时存在 0K、1K、2K 三种形式
- C 末端 Lys 不完全切除是碱性峰最主要的来源，在 IgG1 单抗中比例通常最高
- 迄今研究表明：C 末端 Lys 差异不影响抗原结合、Fc 效应功能（ADCC/CDC）、FcRn 结合和体内半衰期；DSC 研究也证实其不影响 IgG1 热力学稳定性
- 可通过在纯化工艺中加入羧肽酶 B（CpB）处理步骤，将 Lys 完全切除，从而消除该来源的碱性异质性

**主要来源二：琥珀酰亚胺（Asu）形成**

- Asu 是 Asn 脱酰胺（酸性变体）和 Asp 异构化（碱性变体）的共同中间产物，结构取决于水解方向
- Asu 自身呈碱性，是碱性峰的重要来源；但 Asu 经水解后可生成 Asp（趋向中性/酸性）或 isoAsp（酸性变体）
- CDR 区 Asu 的形成影响抗体-抗原结合能力和效价

**其他碱性来源汇总**

| 修饰类型 | 形成机制 | 质量影响 |
|---|---|---|
| N 端 Gln 焦谷氨酸环化不完全 | Gln 未完全环化为 pGlu，残余 Gln 保留正电荷 | 低（N 端修饰通常不影响活性） |
| Met 氧化（Met252/428） | 温度或光照氧化，影响 Fc 区 Met 残基 | 高（Protein A/FcRn 结合下降，半衰期缩短） |
| 脯氨酸酰胺化 | C 末端序列为 PGK，Lys 切除后 Pro 酰胺化 | 中（需个案评估） |
| 未成形/错配二硫键 | 重链可变区游离巯基残留 | 中（影响折叠稳定性） |
| 信号肽不完全去除 | 残余信号肽序列保留 | 中（结构异质性增加） |
| 含糖基化重链的特殊洗脱行为 | 含短寡糖或特定 N 糖的重链 CEX 洗脱偏碱性 | 低（功能影响需个案评估） |

:::

## 电荷变体对安全性与有效性的影响：位置决定风险等级

:::answer

电荷变体对抗体功能的影响，**高度依赖于修饰的发生位置**，而非修饰类型本身。这一原则是评估电荷变体临床相关性的核心逻辑。

**原则一：酸性变体的不利影响通常大于碱性变体**

- 酸性变体可导致单抗体内滞留时间缩短、血液清除率加快，整体对药效不利
- 典型案例：曲妥珠单抗的酸性变体与 HER2 的结合能力下降，抗增殖作用减弱
- 碱性变体则在多数情况下对药效产生中性或正面影响：碱性变体通常显示更强的靶点亲和力及更强的 ADCC 效应

**原则二：等电点（pI）差异影响体内分布和代谢**

一般认为，若电荷变体与主峰的 pI 差异 > 1，则在组织分布和药代动力学方面会产生较大差异，需在生物等效性和 PK 研究中重点关注。

**修饰位置与功能影响的对应关系**

| 修饰位置 | 代表修饰 | 对结构稳定性 | 对效价（ADCC/CDC） | 对 PK |
|---|---|---|---|---|
| N 端（重链/轻链） | pGlu 环化不完全、信号肽残留 | 无显著影响 | 无影响 | 无显著影响 |
| C 末端 | Lys 不完全切除、Pro 酰胺化 | 无显著影响 | 无影响 | 无影响 |
| CDR 区 | Asn 脱酰胺、Asu 形成、Cys104 半胱酰胺化 | 热稳定性下降，聚集倾向增加 | 抗原结合力显著下降 | 受影响（清除率可能变化） |
| Fc CH2（Met252/428） | Met 氧化 | 热稳定性下降 | FcγR 亲和力略降 | 半衰期显著缩短 |
| Fc CH3（Asn384） | 脱酰胺 | 无显著影响 | FcRn/FcγR 不受影响 | 半衰期无影响 |
| 铰链区 | 三硫键 | 不影响热稳定性（IgG2） | 效价不变 | 无显著影响 |

> **结论：** N/C 末端的修饰通常为低风险区域；CDR 区和 Fc CH2 靠近配体结合位点的修饰为高风险区域，需要重点监控和工艺控制。唾液酸化一般不影响抗体效价，但对 PK 有潜在影响。

:::

## 上游调控：培养工艺参数对电荷异质性的定向干预

:::answer

上游工艺参数是调控抗体电荷异质性最直接、成本最低的手段，多个参数对酸性峰和碱性峰均有显著影响。

**参数一：pH——影响酸性峰的关键工艺参数**

- pH 是影响脱酰胺反应速率最重要的参数之一：随着 pH 升高，Asn→Asu 的脱酰胺速率显著加快，酸性变体比例上升
- 实践策略：**降低培养体系 pH**（如从 7.2 降至 6.9）可有效减少酸性变体含量
- pH 同时影响唾液酸转移酶活性，间接调节唾液酸化水平

**参数二：温度——显著影响酸性峰，机制独特**

- 降低培养温度可有效降低酸性电荷变体含量，提高主峰比例
- 机制：降温可降低羧肽酶 B（CBP）的转录水平，从而**抑制 C 末端赖氨酸的切除**，增加含 Lys 的变体（碱性倾向），相对降低酸性变体比例
- 降温同时减缓化学降解反应（脱酰胺、氧化）速率，具有综合改善作用
- 注意：过低温度可能引起其他 CQA 变化（聚体增加，参见聚体章节）

**参数三：培养基金属离子——精准调控 C 末端 Lys 变体**

| 金属离子 | 对碱性羧肽酶的影响 | 对 C 末端 Lys 的影响 | 净效果 |
|---|---|---|---|
| 铜离子（Cu²⁺）升高 | 抑制胞内外碱性羧肽酶活性 | Lys 切除减少，保留更多含 Lys 变体 | 碱性峰比例上升 |
| 锌离子（Zn²⁺）升高 | 激活碱性羧肽酶活性 | Lys 切除更完全 | 碱性峰比例下降 |

**参数四：关键添加剂的影响**

| 添加剂 | 对电荷异质性的影响 | 机制 |
|---|---|---|
| 丁酸钠（NaB） | 碱性物质显著增加，电荷异质性整体加大 | 抑制 HDAC，改变基因表达谱，影响翻译后修饰酶活性 |
| 生物类黄酮 | 酸性物质减少 | 抗氧化作用，减少氧化修饰引起的酸性变体 |
| 硫代硫酸盐 | 酸性物质增加 | 与抗体反应形成硫代酯键，引入负电荷 |
| 丙三醇、NaCl（高浓度） | 脱酰胺增加 | 渗透应激诱导翻译后修饰速率改变 |
| 地塞米松、氢化可的松 | 影响糖基化和电荷分布 | 激素调控细胞代谢和翻译后修饰酶表达 |

**参数五：光照——小规模培养中不可忽视的干扰因素**

- 冷模实验表明，光照是引起小规模反应器（摇瓶/小反应器）中酸性变体偏高的重要原因
- 机制：光照可能引起单抗空间结构及表面电荷分布改变（如 Met 光氧化），影响 IEX 洗脱行为
- 实践建议：小规模实验应注意避光操作，实验室级反应器加装遮光套，排查光照因素后再进行工艺参数研究

**上游参数调控总结**

| 工艺参数变化 | 酸性峰变化 | 碱性峰变化 | 主峰变化 |
|---|---|---|---|
| pH 降低 | ↓ | ↑ | ↑ |
| 温度降低 | ↓ | 轻微↑ | ↑ |
| Cu²⁺浓度升高 | — | ↑ | ↓ |
| Zn²⁺浓度升高 | — | ↓ | ↑ |
| 添加丁酸钠 | — | ↑↑ | ↓ |
| 避光培养 | ↓ | — | ↑ |

## 下游调控：离子交换层析分离电荷变体的策略与局限

:::answer

当上游工艺调控不足以将电荷变体控制在质量限度内时，下游纯化工艺（尤其是离子交换层析）可作为精细调控手段。

**首选技术：离子交换层析（IEX）**

离子交换层析（CEX 或 AEX）是分离电荷变异体最成熟、最广泛使用的技术，分离效果取决于树脂选择和洗脱策略的协同优化：

**洗脱方式一：盐浓度梯度洗脱（最常用）**

- 原理：带电荷的盐离子（如 NaCl）以浓度依赖的方式竞争树脂上的官能团，蛋白按照与树脂亲和力从弱到强的顺序依次洗脱
- 优势：操作稳定，重现性好，工业放大成熟
- 局限：对 pI 差异较小的变体分辨率有限

**洗脱方式二：pH 梯度洗脱**

- 原理：在接近蛋白 pI 的 pH 范围内操作（CEX 模式：pH 低于 pI；AEX 模式：pH 高于 pI），利用 pH 变化改变蛋白净电荷，实现差异洗脱
- 优势：对电荷变体的分辨率通常高于盐梯度，峰形更尖锐
- 挑战：工业规模 pH 梯度控制复杂，需精确配制缓冲液；增加操作步骤数量和时间，提高成本

**补充技术选项**

| 技术 | 特点 | 适用场景 |
|---|---|---|
| 膜层析（Membrane Chromatography） | 流速快，结合能力相对较低 | 流穿模式去除电荷变体，适合低载量场景 |
| 混合模式色谱（Mixed-Mode） | 高盐浓度下操作，宽操作窗口，高选择性 | 电荷变体 + 聚体联合去除；成本高，优化复杂，一般作为备选 |
| Protein A 亲和层析 | 不能分离电荷变体 | 仅用于 IgG 捕获，不具备电荷分离能力 |

**下游电荷变体调控的现实局限**

- 生产规模产能有限，层析柱体积与分离能力存在天花板，无法无限提高分辨率
- 过度依赖下游分离会降低收率，增加工艺成本，且难以实现批次间的高度一致性
- 更深刻理解蛋白-树脂相互作用、建立基于机理的色谱模型（如 IEX 等温线模型），将大幅减少对大型 DoE 的依赖，实现更高效的工艺开发

> **总体策略建议：** 优先通过上游工艺调控将电荷变体控制在合理范围，下游层析工艺作为精细调整手段，二者结合可最大程度保障质量一致性和生产效率。

:::

## CO₂ 在细胞培养中的双重角色：来源分类与浓度控制

:::answer

CO₂ 在动物细胞培养中既是细胞代谢的产物，也是维持培养液 pH 缓冲体系的必需组分，其分压（pCO₂）的精确控制是工艺稳定性的重要保障。

**摇瓶培养中 CO₂ 的控制方式**

- 培养箱通过红外探头实时监测箱内 CO₂ 浓度，并以 PID 控制器调节 CO₂ 注入量
- 常规动物细胞培养 CO₂ 设定浓度为 **5–10%**，具体值与培养基中 NaHCO₃ 浓度及培养温度匹配确定
- 培养温度越低，CO₂ 溶解度越大，相同箱内 CO₂ 浓度对应更高的液相 pCO₂，需在降温工艺时关注

**CO₂ 的来源分类**

**生物来源（细胞代谢）**

细胞有氧呼吸通过 TCA 循环产生 CO₂，生物来源 CO₂ 总量与以下三个参数正相关：

$$\text{CO}_2\text{（生物来源）} \propto q_{CO_2} \times \text{VCD}_{peak} \times \Delta t$$

其中 $q_{CO_2}$ 为 CO₂ 比生成速率，$\text{VCD}_{peak}$ 为最高活细胞密度，$\Delta t$ 为高密度维持时间。

**非生物来源（pH 控制介入）**

- 培养基中 NaHCO₃ 作为 pH 缓冲剂，电离后 HCO₃⁻ 与 H⁺ 结合生成 H₂CO₃，进而分解为 CO₂
- 培养过程中添加的碱液（Na₂CO₃、NaHCO₃）在酸性环境中释放 CO₂
- 大规模反应器中，非生物来源 CO₂ 在 pH 调控频繁时不可忽视

:::

## 高 pCO₂ 对细胞生长、代谢与产物质量的多维影响

:::answer

pCO₂ 对细胞的影响是多层次的，不仅影响宏观培养性能，还通过胞内 pH 改变、膜通透性变化和酶活性调节，深入影响细胞的生理代谢过程。

**pCO₂ 对细胞密度和活率的影响**

不同研究的结论存在一定差异，反映了细胞系和培养条件的个体化特征：

| 研究条件 | pCO₂ 变化 | 细胞密度变化 | 细胞活率变化 |
|---|---|---|---|
| CHO 细胞，10 L 灌注，37°C | 35→148 mmHg | 8.9→5.9 × 10⁶ cells/mL（↓34%） | 79→58%（↓21%） |
| CHO 细胞，37°C | 升至 150 mmHg | 无显著影响 | 无显著影响 |
| CHO 细胞，33°C | 升高 | 15–20→5–8 × 10⁵ cells/mL（↓显著） | 无显著影响 |

**pCO₂ 对细胞代谢的影响**

- 当渗透压一定，pCO₂ 升至 140 mmHg 时，杂交瘤细胞葡萄糖比消耗速率和乳酸比生成速率下降约 40–50%
- 氨比生成速率（反映谷氨酰胺代谢）在上述条件下无显著变化

**pCO₂ 对产物表达量的影响**

- 渗透压 310 mOsm/kg 时，pCO₂ 从 36 升至 140 mmHg，CHO 细胞比生产速率（Qp）下降 10%
- pCO₂ 进一步升至 195 mmHg，Qp 下降 33%
- CO₂ 过度移除（pCO₂ 过低）同样有害：摇瓶实验中去除培养环境 CO₂ 导致 CHO 细胞无法生长，证明适量 CO₂ 是细胞正常生长的必需条件

**pCO₂ 对产品质量的影响**

- 高 pCO₂ 影响高尔基体内的糖基化加工酶活性和糖核苷酸底物（UDP-半乳糖、CMP-唾液酸）的供给，可能改变 N 糖谱
- 胞内 HCO₃⁻ 浓度改变影响细胞内 pH 稳态和蛋白折叠环境，可影响蛋白质量属性（如聚合体、电荷异构体）

**工艺控制建议**

- 生产反应器中建议将 pCO₂ 控制在 **50–100 mmHg** 范围内，避免超过 140 mmHg 的抑制阈值
- 大规模反应器中 CO₂ 移除能力相对有限，应通过优化 sparger 设计（大孔径）、增大通气速率和适当降低培养液高度来提升 CO₂ 脱除效率
- 降温工艺中，由于 CO₂ 溶解度增大，需特别关注 pCO₂ 的变化，必要时增大大泡通气量

:::

## 蛋白糖基化的分类：N 糖与 O 糖的结构基础与位点特征

:::answer

糖基化是真核细胞蛋白质最重要的翻译后修饰之一，也是生物药异质性的主要来源。理解 N 糖和 O 糖的结构基础是糖型质量控制的前提。

**N 糖基化（N-Linked Glycosylation）**

- **连接位点**：发生在蛋白质 NXS/T 序列基序中的天冬酰胺（Asn, N）残基上（X 为除 Pro 外的任意氨基酸），通过 N-糖苷键连接
- **发生位置**：内质网（ER）中，伴随蛋白折叠同步进行，随后在高尔基体中进一步加工
- **三种主要 N 糖型结构**：
  - **高甘露糖型（High-Mannose）**：仅含甘露糖，分子量小，ADCC 增强但半衰期可能缩短
  - **复杂型（Complex）**：含 GlcNAc、半乳糖、岩藻糖和唾液酸，是哺乳动物细胞表达单抗的主要糖型
  - **杂合型（Hybrid）**：兼具高甘露糖和复杂型结构特征

**O 糖基化（O-Linked Glycosylation）**

- **连接位点**：发生在丝氨酸（Ser, S）或苏氨酸（Thr, T）的羟基上，通过 O-糖苷键连接
- **发生时机**：在蛋白 N 糖基化修饰和折叠完成后，在高尔基体中进行
- **常见核心单糖**：N-乙酰半乳糖胺（GalNAc）为最常见起始单糖，向外延伸形成黏液素类 O 糖结构，其他包括 GlcNAc、木糖、甘露糖、海藻糖等

**糖基化的两种异质性来源**

- **点不均一性（Site Occupancy Heterogeneity）**：并非所有 NXS/T 基序或 Ser/Thr 位点都一定发生修饰，导致糖基化位点占用率不均一
- **微不均一性（Micro-Heterogeneity）**：即使同一位点被修饰，不同单体分子上该位点的糖型结构也不尽相同，由高尔基体中各糖基转移酶的竞争性反应决定

:::

## N 糖的生物合成路径：从内质网到高尔基体的分步加工机制

:::answer

N 糖的生物合成是一个高度有序的多酶级联过程，分为两个主要阶段，跨越内质网和高尔基体两个细胞器。

**第一阶段：内质网中的核心糖链组装与转移**

1. 在内质网细胞质侧，以多萜醇焦磷酸盐（Dolichol-PP）为载体，在酶促作用下依次添加 2 个 GlcNAc 和 5 个 Man，直接利用 UDP-GlcNAc 和 GDP-Man 作为核苷酸糖供体
2. 完成初步组装后，中间产物经跨膜易位翻转至内质网腔内侧
3. 在腔内侧继续添加 4 个 Man 和 3 个 Glc，形成 Glc₃Man₉GlcNAc₂ 的完整前体结构（此步骤利用多萜醇-磷酸-糖作为中间供体）
4. 在**寡糖转移酶（OST）**的作用下，完整的 Glc₃Man₉GlcNAc₂ 前体转移至新生蛋白质正在折叠的天冬酰胺残基上，此过程与蛋白质正确折叠同步进行

**第二阶段：内质网与高尔基体中的修剪与重建**

蛋白质从内质网转运至高尔基体（顺面→中间面→反面）的过程中，N 糖经历"修剪"和"重建"两类反应：

**修剪酶（切除单糖）**

| 酶 | 切除目标 | 生成结构 |
|---|---|---|
| α-葡萄糖苷酶 I/II | 末端 3 个 Glc | Man₉GlcNAc₂ |
| α-甘露糖苷酶 I | 4 个 Man | Man₅GlcNAc₂（复杂型前体） |
| α-甘露糖苷酶 II | 2 个 Man | Man₃GlcNAc₂（核心结构） |

**重建酶（添加单糖）**

| 酶 | 添加单糖 | 对功能的影响 |
|---|---|---|
| GnT-I / GnT-II | GlcNAc（天线臂延伸） | 复杂型 N 糖骨架建立 |
| GnT-III | 分支 GlcNAc | 抑制岩藻糖化，增强 ADCC |
| α1-6 岩藻糖转移酶（FUT8） | 岩藻糖（核心） | 降低 FcγRIIIa 亲和力，减弱 ADCC |
| β4-半乳糖转移酶 | 半乳糖 | 影响 CDC 效应（利妥昔单抗相关） |
| α2-3/α2-6 唾液酸转移酶 | 唾液酸 | 影响半衰期、ADCC 及抗炎功能 |

蛋白质在高尔基体不同区段即可离开，导致糖链加工程度不同，形成糖谱的高度异质性。这也解释了为什么即使工艺稳定，N 糖型仍不可避免地存在分布。

> **工程应用意义：** 了解各加工酶的节点，可以通过基因工程手段定向改变糖型：敲除 FUT8 →无岩藻糖单抗（增强 ADCC）；过表达 GnT-III → 分支 GlcNAc 增加（抑制岩藻糖化）；培养基中添加 Mn²⁺/丁酸盐 → 半乳糖含量提升（增强 CDC）。

:::

## N 糖型命名体系：从结构描述到简化命名的实用指南

:::answer

N 糖结构的完整描述需涵盖单糖类型、连接位置和连接构象三个维度，不同命名体系在精确性和易用性之间有所权衡。

**三种主要命名体系**

| 命名体系 | 提出机构 | 特点 | 适用场景 |
|---|---|---|---|
| IUPAC 系统命名 | 国际纯粹与应用化学联合会 | 最精确，包含全部结构信息；书写复杂，难以记忆 | 学术发表，结构确证文件 |
| CFG 符号表示法 | 功能糖组学联合会 | 图形化，用不同几何形状代表不同单糖 | 糖科学家学术交流 |
| Oxford 命名法 | 牛津大学糖生物学系 | 文字缩写形式，平衡了准确性和简洁性 | 治疗性蛋白 N 糖质控，行业通用 |

**单克隆抗体 N 糖的简化命名规则**

由于单抗 Fc 上 N 糖型相对简单（绝大部分只在重链 Asn297 位点修饰），且由哺乳动物细胞表达（连接构象固定），通常采用简化命名：

| 简化名称 | Oxford 描述 | 结构特征 |
|---|---|---|
| G0 | FA2 | 复杂型双天线，含核心岩藻糖，无末端半乳糖 |
| G0F | FA2 | G0 + 核心岩藻糖（F = Fucose） |
| G1F | FA2G1 | G0F + 1 个末端半乳糖 |
| G2F | FA2G2 | G0F + 2 个末端半乳糖 |
| G0F+GlcNAc（bisecting） | FA2B | G0F + 分支 GlcNAc |
| Man5 | M5 | 高甘露糖型，含 5 个甘露糖 |
| G2FS1 / G2FS2 | FA2G2S1/S2 | 含唾液酸的复杂型（α2-3 或 α2-6） |

> **质控实践：** 在 CMC 申报文件中，N 糖型分析通常报告各主要糖型的相对百分比（百分比之和 ≈ 100%），同时计算 G0F%、G1F%、G2F%、Man5%、唾液酸含量等关键指标。这些数据在批次放行和可比性研究中均为必要数据项。

:::

## N 糖型对单克隆抗体结构与功能的系统性影响

:::answer

N 糖修饰对单抗的结构稳定性、效应功能（ADCC/CDC）、体内半衰期和免疫原性均有深远影响，是单抗 CQA 清单中最复杂的一项。

**糖链对 Fc 构象的结构维持作用**

- Fc CH2 区域的 N 糖（G0 糖型）与 Fc CH2 结构域之间存在 **52 个疏水性相互作用**，维持 CH2 的"开放式"构象
  - 核心岩藻糖：7 个相互作用
  - α1-6 臂半乳糖：27 个相互作用
  - α1-3 臂糖链深入两条重链 Fc 所形成的腔内，两条糖链的甘露糖间存在互补相互作用，对 CH2-CH2 界面稳定性至关重要

- **无糖链的 Fc 后果**：CH2 结构域轻度扩张（SEC 洗脱时间提前），热稳定性下降（加速稳定性实验中更易聚集），ADCC 和 CDC 效应消失，对蛋白酶敏感性增加

**N 糖结构对 ADCC 的影响**

| 糖型变化 | 对 FcγRIIIa 亲和力 | ADCC 效应 | 机制 |
|---|---|---|---|
| 去除核心岩藻糖 | 显著增强（10–100 倍） | 显著增强 | 核心岩藻糖的空间位阻解除，Fc-FcγRIIIa 界面紧密接触 |
| 增加分支 GlcNAc | 增强 | 增强 | 分支 GlcNAc 阻碍岩藻糖化，间接实现去岩藻糖效果 |
| 高甘露糖型 | 增强 | 增强 | 高甘露糖本身无岩藻糖 |
| 高唾液酸化 | 减弱（与 DC-SIGN 亲和力增强） | 减弱 | 构象改变使 Fab 从双价变单价；Fc-CyRIIIa 结合受阻 |

**代表性工程技术：** POTeLlIGeNT 技术（FUT8 敲除 CHO 细胞）产生无核心岩藻糖单抗；Glycart-Roche 技术（过表达 GnT-III）已成功应用于上市产品 Obinutuzumab（GA101）。

**N 糖结构对 CDC 的影响**

- 利妥昔单抗的研究表明：Fc N 糖末端**半乳糖含量**与其 CDC 效应正相关，去除末端半乳糖导致 CDC 效应下降
- 高甘露糖型单抗的 CDC 效应减弱（因高甘露糖末端不含半乳糖）
- 工艺调控手段：培养基中添加嘧啶核苷、MnCl₂ 和外源半乳糖，可提升 G1F/G2F 比例，增强 CDC 活性

**N 糖结构对半衰期的影响**

| 机制 | 相关糖型 | 对半衰期影响 |
|---|---|---|
| FcRn 循环保护 | 所有 Fc N 糖型（整体影响小） | 无显著差异（空间位阻阻止 ASGPR 结合） |
| 无唾液酸糖蛋白受体（ASGPR）清除 | 末端半乳糖暴露 | 缩短（如 EPO 高唾液酸化可避免清除，延长半衰期） |
| 甘露糖受体介导内吞 | 高甘露糖型 | 缩短（存在争议，但高甘露糖型缩短半衰期已获广泛认可） |
| Met 氧化（Fc CH2 Met252/428） | — | 显著缩短（Protein A/FcRn 结合下降） |

**N 糖结构与免疫原性**

- 鼠源性细胞（SP2/0、NS0）表达的单抗含有非人源单糖：**α-半乳糖（αGal）** 和 **羟乙酰神经氨酸（Neu5Gc）**
- CHO 细胞只含痕量 Neu5Gc，αGal 含量极低；SP2/0 和 NS0 细胞 Neu5Gc 含量相对较高
- 西妥昔单抗（SP2/0 表达）的 Fab N 糖末端 αGal 引发强烈 IgE 介导的超敏反应，是典型的非人源糖引起免疫副反应的案例
- 单抗 Fc 上的 αGal 通常不引起免疫副反应（人体预存抗 αGal IgE 无法与 Fc 内腔的糖链结合）
- 只有含 2 个及以上 Neu5Gc 的单抗才能与抗 Neu5Gc 抗体结合，Fc 上 Neu5Gc 的免疫原性较弱

**高唾液酸化糖型与抗炎功能**

- IVIG 的抗炎作用主要来自其中高唾液酸化（α2-6 连接）的 Fc 组分，唾液酸化使 Fc 构象更紧密，与 DC-SIGN 亲和力增强，发挥免疫负调节作用
- CHO 细胞表达的唾液酸为 **α2-3 连接**，不具备 IVIG 的抗炎功能；NS0/SP2/0 细胞表达的唾液酸为 **α2-6 连接**，具有潜在抗炎活性
- GlycoFi 技术通过在酵母中改造 14 种糖合成酶，实现了具有人类样高唾液酸化 N 糖（α2-6 连接）的抗体表达

:::

## 蛋白聚集体的形成机制：多通路共价与非共价聚合

:::answer

蛋白聚集体（Aggregates）是治疗性蛋白最重要的安全性相关 CQA，因其潜在的免疫原性风险而受到监管机构的高度关注。聚集体的形成机制复杂，涉及多个分子层面的相互作用。

**聚集体的定义与分类**

聚集体通常指由两个或多个蛋白分子通过分子间作用力形成的稳定复合物，分为：

| 分类维度 | 类型 | 特征 |
|---|---|---|
| 结合力性质 | 可逆聚集体 | 氢键、疏水相互作用形成，可通过稀释、pH 调整复溶 |
| 结合力性质 | 不可逆聚集体 | 共价键（如分子间二硫键）形成，不可逆 |
| 聚集程度 | 可溶性聚集体（二聚体、小聚体） | SEC 可检测；具有较高免疫原性风险 |
| 聚集程度 | 不可溶聚集体（大颗粒、沉淀） | 光阻法、NTA 可检测；生产工艺中需尽量消除 |

**聚集体形成的五条主要通路**

**通路一：蛋白结构破坏诱导聚合**

物理应力（高温、剪切力、冻融循环）或化学应力（pH 极端、氧化）破坏蛋白质天然构象，使疏水核心暴露，暴露的疏水残基相互吸引形成聚合物。

**通路二：构象改变诱导不可逆聚合**

蛋白去折叠（Unfolding）后形成展开中间态，该中间态具有强烈聚集倾向。若聚合发生后蛋白链间相互缠绕，则形成不可逆大聚集体，裂解后不再溶解。

**通路三：核聚生长机制**

两分子蛋白首先形成稳定二聚体（成核），二聚体作为"种子"（Seed）持续招募单体分子，聚集体逐步增大（成长期）。这种核聚（Nucleation-Dependent Polymerization）机制具有明显的滞后期特征。

**通路四：Fab/Fc 区错误折叠诱导的聚合**

单抗的 Fab 段（含 CDR 区）和 Fc 段均可发生折叠异常：

- 轻链/重链的正确折叠、未折叠及错误折叠均可产生聚集体
- 未正确组装的轻链/重链在胞内可形成聚集体，尤其在内质网折叠负荷过高时（如低温诱导 LC/HC 高表达但内质网加工速率跟不上）
- 可溶聚集体裂解后因疏水面充分暴露，通常不再溶解

**通路五：二硫键异常驱动的共价聚合**

- 游离巯基（未成键的半胱氨酸 -SH）是共价聚集体形成的重要驱动因素
- 游离 -SH 与另一分子的游离 -SH 或正常二硫键发生巯基-二硫键交换（Thiol-Disulfide Exchange），导致分子间二硫键形成
- 游离巯基含量减少（被氧化形成分子间二硫键）是共价聚合体增加的直接标志

:::

## 工艺参数对聚集体的影响：上游关键变量的调控逻辑

:::answer

聚集体水平受多个上游工艺参数影响，各参数对聚集体的作用方向和机制不同，需综合权衡。

**参数一：培养温度——双向影响，低温倾向增加聚体**

- **现象**：降低培养温度（如从 37°C 降至 31–33°C）通常导致聚集体水平升高
- **机制**：低温增加 LC/HC 的 mRNA 稳定性，促进轻链和重链的表达量提升，但内质网蛋白折叠加工能力（依赖分子伴侣活性）未能等比增强，导致"加工瓶颈"——未正确折叠的蛋白积累，聚集倾向增加
- **权衡**：降温虽增加聚体，但同时减少酸性变体、提升主峰比例，需根据 CQA 优先级综合评估

**参数二：搅拌转速——高转速增加聚体**

- **现象**：搅拌转速升高促进聚集体水平提升
- **机制**：高转速产生较大剪切力，机械应力破坏细胞的翻译后修饰加工环境（细胞损伤 → 胞内蛋白释放/折叠异常），同时剪切力直接作用于已分泌的抗体分子，诱导其构象变化和聚集
- **控制建议**：在满足 DO 和混合需求的前提下，尽量降低搅拌转速；放大过程中以恒定 Tip Speed（叶端线速度）为原则，控制最大剪切力

**参数三：消泡剂——降低聚体**

- **现象**：添加消泡剂（如 Polysorbate 80、Poloxamer 188）可降低聚集体含量
- **机制**：消泡剂缓解气泡破碎和搅拌产生的剪切应力对细胞的不利影响，有助于细胞维持正常翻译后修饰加工能力；表面活性剂还可竞争吸附于气液界面，减少蛋白分子在界面处的展开和聚集
- **注意**：消泡剂浓度过高本身可能影响细胞活力和产品质量，需验证最适浓度范围

**参数四：渗透压——适当提高有助于降低聚体**

- **现象**：适度高渗条件有助于降低蛋白聚集水平
- **机制**：高渗条件下细胞代谢状态改变（更偏向分泌模式），胞内蛋白折叠环境改善；高渗透压还可提高培养液中的相容性溶质浓度，在溶液层面对蛋白起到稳定作用
- **交互效应**：提高 pH 与渗透压的组合干预可协同降低聚体水平，但需注意高 pH 对脱酰胺的加速作用

**工艺参数对聚集体影响的汇总**

| 工艺参数变化 | 聚集体水平 | 注意事项 |
|---|---|---|
| 温度降低 | ↑（通常增加） | 与电荷变体改善效果权衡 |
| 搅拌转速升高 | ↑（增加） | 控制 Tip Speed 上限 |
| 添加消泡剂 | ↓（降低） | 验证消泡剂类型和浓度 |
| 渗透压适度提高 | ↓（降低） | 避免渗透压过高导致细胞凋亡 |
| pH 适度提高 | 可能↓ | 与脱酰胺风险权衡 |
| DO 过高（>80%） | 可能↑（氧化诱导） | 控制 DO 上限 |

:::

## 纯化过程中高浓度蛋白聚体的预防策略

:::answer

在层析纯化（尤其是亲和层析洗脱和超滤浓缩）过程中，局部高蛋白浓度是诱导聚集的重要风险节点。

**风险节点一：层析洗脱峰高浓度区域**

- 层析柱洗脱时，目标蛋白以高于最终产品浓度的状态存在于洗脱液中，部分条件下蛋白-树脂相互作用可能促进聚集
- **验证手段**：通过批次结合实验（Batch Binding Assay）评估高密度结合状态下蛋白的聚集倾向；随后以柱层析实验确认实际过柱操作的聚集情况
- 若批次结合不形成聚集体，但柱层析后聚集体增加，提示聚集发生于洗脱阶段（局部高浓度 + 洗脱条件的联合效应）

**风险节点二：超滤浓缩高浓度阶段**

- 超滤（UF）过程中蛋白浓度持续升高，至终浓度阶段（如 20–100 mg/mL）聚集风险最大
- **精氨酸的保护效果**：在超滤缓冲液中添加精氨酸（Arg）可显著抑制聚集体形成——精氨酸通过弱疏水相互作用与蛋白表面疏水区域结合，降低蛋白间疏水聚集倾向；相同机制在柱层析洗脱缓冲液中也有效
- **膜和装置选择**：不同截留分子量（MWCO）的超滤膜、不同浓缩装置（搅拌池 vs. 切向流过滤，TFF）对聚集体的影响不同，应通过比较实验确认最优选择
- **工艺参数优化**：控制 TFF 跨膜压差（TMP），避免过高压力导致膜面局部浓度积累；冷环境（2–8°C）操作可降低聚集速率

**精氨酸在聚集控制中的双重应用**

| 应用场景 | 作用机制 | 典型浓度 |
|---|---|---|
| 超滤浓缩缓冲液 | 降低蛋白-蛋白疏水聚集 | 50–200 mmol/L |
| 柱层析洗脱缓冲液 | 抑制树脂上高密度结合蛋白的聚集 | 100–500 mmol/L |
| 制剂配方 | 长期储存中稳定高浓度蛋白 | 50–150 mmol/L |

:::

## 糖基化修饰分析：Fc 融合蛋白的结构确证与唾液酸定量

:::answer

真核细胞表达的 Fc 融合蛋白存在 N 糖和 O 糖修饰，糖基化结构和组成的全面解析是产品质量控制和工艺监控的重要环节。

**Fc 融合蛋白糖基化分析的特殊性**

- Fc 融合蛋白的功能蛋白区域可能存在 N 糖和 O 糖修饰（取决于序列中的修饰位点），Fc 结构域仅存在 N 糖基化修饰
- CHO 细胞表达的 Fc 融合蛋白主要 N 糖型为 G0F、G1F 和 G2F，同时含微量高甘露糖型和唾液酸化糖型
- 唾液酸含量直接影响蛋白净电荷，是电荷变异体分布的重要因素，与体内半衰期密切相关

**糖基化结构分析技术**

**一级技术：LC-MS/MS（液质联用）**

- 通过酶切（如 PNGaseF 释放 N 糖，O-糖酶释放 O 糖）结合 LC-MS/MS 分析，完成以下表征：
  - 糖基化修饰位点的鉴定（确认哪些 Asn/Ser/Thr 被修饰）
  - 各位点的寡糖组成分析（糖型种类及相对比例）
  - 修饰位点的占用率（Site Occupancy）定量
  - 唾液酸含量（定性 + 定量）

**二级技术：荧光标记糖谱分析（HILIC-FLD）**

- PNGaseF 酶切后，N 糖以荧光染料（如 2-AB 或 InstantAB）标记，经亲水相互作用色谱（HILIC）分离后荧光检测，获得 N 糖型分布图谱（Glycan Profile）
- 操作简便，通量较高，是批次常规检测的首选方法，与 LC-MS 互补

**唾液酸含量测定**

唾液酸含量是 Fc 融合蛋白的关键质量属性，常用检测方法：

| 方法 | 依据 | 特点 |
|---|---|---|
| 间苯二酚显色法 | 《中国药典》三部通则 3102 | 操作简便，适合常规放行检测；非特异性，检测总唾液酸含量 |
| 液相色谱法（HPLC） | 荧光衍生化 + 反相或离子交换分离 | 专属性高，可区分 Neu5Ac 和 Neu5Gc，适合结构表征 |
| LC-MS/MS | — | 最高专属性，可定位修饰位点，适合深度结构研究 |

**分析结果在质控中的应用**

- N 糖谱（尤其是 G0F%、G1F%、G2F%、高甘露糖%、唾液酸%）作为批次放行检测项目，需建立控制范围
- 工艺变更前后的 N 糖谱比对是可比性研究的核心数据项
- 生物类似药研发中，多批次原研药的 N 糖型数据构成"参考范围"，用于指导工艺开发和产品质量匹配

:::
