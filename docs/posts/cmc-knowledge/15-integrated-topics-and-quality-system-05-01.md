## ICH Q5A 病毒安全性核心术语：病毒分类与清除概念体系

:::answer

ICH Q5A《源自人或动物细胞系的生物技术产品的病毒安全性评价》是生物制品病毒安全性评估的核心国际指南，以下术语是理解病毒清除研究设计和申报逻辑的基础。

**病毒的基本定义（词条 56）**

病毒（Virus）是指在细胞内复制并可致病的感染性因子，具有以下决定性特征：

- 只含有**一种核酸**（RNA 或 DNA），不同时含有两者
- **不能**以其遗传物质形式生长、进行二分裂繁殖
- 必须劫持宿主细胞的复制机制才能增殖

**病毒来源的四类分类（ICH Q5A 框架）**

| 病毒类型              | 词条 | 定义                                                                                                                      | 典型来源                                       | 对生产的影响                            |
| --------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | --------------------------------------- |
| **外源病毒**          | 57   | 非故意引入的污染病毒                                                                                                      | 原材料（动物源性培养基、血清）、操作人员、环境 | 须通过原材料检测和工艺控制预防          |
| **内源病毒**          | 58   | 其基因组整合于宿主细胞生殖细胞基因组中的病毒体；在本指南中，为无限繁殖细胞基质故意引入的非整合病毒（如 EBV、BPV）也属此类 | CHO 细胞中的逆转录病毒样颗粒（RVLP）           | 须通过病毒安全评价和清除验证管控        |
| **非内源病毒**        | 59   | MCB（主细胞库）中存在的外源病毒（与内源病毒相对）                                                                         | 建库过程中引入的污染                           | 须在细胞库建立时检测并排除              |
| **病毒样颗粒（VLP）** | 64   | 电镜下可见、形态与已知病毒相似的结构                                                                                      | CHO 细胞内源性的 RVLP                          | 须通过透射电镜（TEM）检测并进行风险评估 |

**病毒清除研究设计的关键概念**

**① 非特异模型病毒（词条 60）**

用于为生产工艺消除病毒能力**定性**的病毒。其目的不是代表某种特定的污染病毒，而是对**纯化工艺总体病毒清除效能**进行定性评估。

**② 相关病毒（词条 61）**

用于工艺评价研究的病毒，包括：

- 已鉴定的病毒
- 已知病毒的同一种类
- 已知可污染细胞培养物或其他生产用材料/试剂的病毒

**③ 特异模型病毒（词条 62）**

与已知或可疑病毒**密切相关**（同种或同属）的病毒，与已见或所疑病毒具有类似的物理化学特性。当生产所用细胞系或原材料中存在已知病毒时，须使用特异模型病毒进行清除验证。

**病毒消除的两种机制（词条 63、65）**

| 机制         | 词条     | 方法                                                               | 代表步骤                                 |
| ------------ | -------- | ------------------------------------------------------------------ | ---------------------------------------- |
| **病毒去除** | 65       | 用**物理方法**将病毒颗粒从产品中**分离**（仍可能存在，只是被分离） | 纳滤（20 nm 过滤）、层析分离、沉淀       |
| **病毒灭活** | 包含于63 | 将病毒感染性**灭活**（破坏病毒结构使其失去感染能力）               | 低 pH 处理、S/D 法、高温处理（60°C/10h） |

**工作细胞库（WCB）的定义（词条 66）**

工作细胞库（Working Cell Bank）是在规定培养条件下扩增主细胞库（MCB）获得的**匀质细胞悬液**，经分装成多个等份制备而成。WCB 是日常生产的直接起始材料，每批生产取用一支 WCB 安瓿，MCB 作为长期备份。

:::

## ICH Q5B 表达构建体与细胞库术语：从基因到细胞系的核心定义

:::answer

ICH Q5B《用于生产重组 DNA 蛋白产品的细胞所含表达构建体的分析》定义了理解重组蛋白生产的分子生物学基础术语。

**表达系统核心术语**

**① 表达构建体（词条 67）**

含有重组蛋白编码序列和其**表达所需全部调控元件**的表达载体。表达构建体是细胞株开发的核心组件，其设计直接决定目的蛋白的表达水平和稳定性。

**② 侧翼控制区（词条 68）**

与产品编码序列的 **5' 和 3' 末端相邻**的非编码核苷酸序列，包含影响编码序列转录、翻译和稳定性的重要调控元件：

| 元件类型                    | 功能                                  |
| --------------------------- | ------------------------------------- |
| 启动子（Promoter）          | 驱动转录起始（如 CMV、EF1α 强启动子） |
| 增强子（Enhancer）          | 增强转录效率（如 CMV IE 增强子）      |
| 剪接序列（Splice Sequence） | 确保正确的 mRNA 加工                  |
| Kozak 序列                  | 优化翻译起始效率                      |
| poly-A 信号                 | 影响 mRNA 稳定性                      |

**注意**：侧翼控制区**不包括**复制起点和抗生素耐药基因区域。

**③ 整合位点（词条 69）**

表达构建体一个或多个拷贝**整合进宿主细胞基因组**的位点。整合位点的染色质活性状态直接影响目的基因的表达水平（热点 vs 沉默区域），这也是定点整合技术（CRISPR、RMCE）相比随机整合的核心优势所在。

**细胞库体系术语**

**④ 主细胞库（MCB，词条 71）**

在指定条件下从**选定的细胞克隆**制备的单批细胞，分装至多个容器并在规定条件下储存（通常 -196°C 液氮）。

关键要点：

- MCB 通常用于制备**所有**工作细胞库
- 对新的 MCB 进行的检定试验应与原有 MCB **相同**
- MCB 是商业化生产的最终质量溯源起点

**⑤ 工作细胞库（WCB，词条 74）**

在规定培养条件下培养 MCB 并经等量分装获得的**来源相同的匀质细胞悬液**的容器集合。每批生产从 WCB 取用一支安瓿，MCB 仅作长期备用，通常不直接用于生产。

**⑥ 体外细胞龄（词条 70）**

从 MCB 小瓶融化至生产容器收获产品的时间跨度，可用以下方式量度：

- 培养所耗的**时间**（小时/天）
- 细胞数**倍增水平**（PDL，Population Doubling Level）
- **传代次数**（当细胞以规定步骤稀释传代时）

体外细胞龄是细胞稳定性研究（EOPC，生产终末细胞）设计的基础，须覆盖 MCB 传代数 + 生产传代数 + 安全余量。

**⑦ 试生产规模（词条 72）**

能代表和模拟生产规模重组蛋白生产的规模。关键要求：除生产**规模**外，细胞扩增、收获和产品纯化的方法均须与生产规模**一致**。试生产规模数据是支持商业化工艺的重要桥接证据。

:::

## ICH Q5C 稳定性研究核心术语：降解产物、杂质与半成品的精准定义

:::answer

ICH Q5C《生物技术产品的稳定性测试》定义了生物制品稳定性研究中最核心的概念，这些定义对质量标准制定和稳定性研究方案设计具有直接指导意义。

**五大核心术语的精确区分**

| 术语                | 词条 | 定义                                                                                     | 典型例子                              |
| ------------------- | ---- | ---------------------------------------------------------------------------------------- | ------------------------------------- |
| **结合物**          | 75   | 活性成分通过共价或非共价键与载体连接，以增强效力或稳定性                                 | 抗体-抗原结合物（诊断用）；PEG 化蛋白 |
| **降解产物**        | 76   | 原液随时间发生变化而产生的物质（可在生产过程中或储存中发生）                             | 脱酰胺体、氧化物、聚合体、水解片段    |
| **杂质**            | 77   | 非原液本身成分、非赋形剂、非制剂添加剂，却存在于原液和制剂中的任何其他成分               | HCP、HCD、Protein A 残留、降解产物    |
| **半成品**          | 78   | 生产过程中的关键中间物质，非原液也非成品，通常可定量并经质量标准判断合格后方可进入下一步 | 各层析步骤的洗脱液；UF/DF 中间体      |
| **生产规模的产品**  | 79   | 在能够提供上市销售的生产规模下生产的产品                                                 | 商业化批次（PPQ 批次）                |
| **试生产/中试规模** | 80   | 能代表和模拟生产规模生产原液和制剂的规模，除规模外各工艺方法须与生产规模一致             | 商业化生产规模的 10% 或以上           |

**关键理解：降解产物 vs 产品相关杂质 vs 产品相关物质**

这三个概念极易混淆，在质量标准制定中须精确区分：

```
分子变异体分类决策树
预期产品的分子变异体
        ↓
其活性、效能和安全性与预期产品具有可比性？
    ↙ 否                         ↘ 是
产品相关杂质               具有活性且对安全性/有效性无害影响？
（须纳入杂质控制）              ↙ 是               ↘ 否
                        产品相关物质              须进一步评估
                     （不列为杂质，但             安全性和有效性
                      须表征并监控）
```

**半成品控制的实践要点**

半成品需建立**独立的可接受标准**，包括：

- 产量指标（步骤回收率，如效价/蛋白含量）
- 关键杂质（如 HCP、HCD 的步骤去除效果）
- 安全性指标（微生物限度、内毒素）
- 物理化学参数（pH、外观、浓度）

只有满足半成品标准的中间体才能进入下一步工艺，这是分段质量控制策略的核心。

:::

## ICH Q5D 细胞基质来源与鉴定术语：细胞系类型与传代体系

:::answer

ICH Q5D《用于生物技术产品生产的细胞基质的来源和鉴定》定义了生产用细胞系的类型和管理体系。

**细胞库体系的层级结构**

**① 细胞库（词条 81）**

活细胞被等量均一地独立分装后保存于规定条件下的细胞保存库。**每一个独立包装均可代表未分装前的完整细胞系**——这一特性确保了每次生产起始材料的一致性。

**② 细胞系的三种基本类型**

| 类型                           | 词条 | 定义                                                               | 生物制药应用                                     |
| ------------------------------ | ---- | ------------------------------------------------------------------ | ------------------------------------------------ |
| **细胞系**                     | 82   | 来自原代细胞，经一系列培养传代能被建库的细胞群                     | 通用概念，包括所有下述类型                       |
| **传代细胞系（永生化细胞系）** | 83   | 具有**无限生长能力**的细胞系，以前称"建株细胞"                     | CHO、NS0、HEK293、Vero——所有主流生物制品生产宿主 |
| **二倍体细胞系**               | 84   | 染色体成双（整倍体）、体外寿命**有限**的细胞系，结构与来源细胞一致 | MRC-5（人二倍体细胞）——用于病毒疫苗生产          |

**传代细胞系（永生化细胞）的特殊安全考量**

传代细胞系的"永生化"特性（无限增殖能力）本身是一个安全性因素——它表明细胞已经发生了某种程度的遗传改变，可能含有潜在的病毒性物质（如 CHO 细胞中的内源性逆转录病毒样颗粒）。这正是为什么 ICH Q5A 对此类细胞的病毒安全评价要求最为严格。

**③ 体外细胞传代周期（词条 85）**

从 MCB 小瓶融化至生产容器收获的时间，与 ICH Q5B 词条 70 定义相同：可以用时间、倍增水平或传代次数表示。

**④ 母细胞（词条 86）**

可用于产生细胞基质或中间细胞系的细胞。在不同表达系统中的称谓：

- **微生物表达系统**（大肠杆菌/酵母）：称"宿主细胞"
- **杂交瘤技术**：称"融合细胞"（亲代 B 细胞与骨髓瘤细胞的融合产物）

:::

## ICH Q5E 可比性研究术语：工艺变更后产品质量等同性的证明框架

:::answer

ICH Q5E《生物技术产品的可比性：生产过程改变引发的质量、安全性和有效性问题》提供了生物药工艺变更管理的核心法规框架。

**四个核心术语的精确定义与内在逻辑**

**① 质量属性（词条 90）**

被选取有助于表明产品质量的**一种分子或产品特性**。质量属性涵盖以下总体定义范畴：

| 质量属性维度           | 内容               | 典型检测                   |
| ---------------------- | ------------------ | -------------------------- |
| **鉴别**               | 证明产品是预期分子 | 肽图、分子量（完整/还原）  |
| **纯度**               | 产品相关物质/杂质  | SEC-HPLC、CE-SDS、HCP、HCD |
| **效价**               | 生物活性           | 细胞效价、靶点结合（SPR）  |
| **产品稳定性**         | 抵抗降解的能力     | 加速稳定性、强制降解       |
| **外源因子相关安全性** | 病毒、支原体等     | 细胞库检定、工艺验证       |

**注意**：质量标准中只是选择了质量属性的**一部分**进行检测，并非所有质量属性都需要纳入放行标准。

**② 可比性（词条 88）**

可比性的含义是**工艺变更前后产品质量属性具有高度相似性**，且对当前药品的安全性或有效性（包括免疫原性）没有负面影响。

这一定义中的关键要点：

- "高度相似性"不等于"完全相同"——生物药的固有异质性决定了两个批次之间不可能完全一样
- 结论以**产品质量属性分析**为基础
- 在某些情况下，非临床或临床数据能补充支持这一结论（当质量属性分析无法完全消除疑虑时）

**③ 可比性研究（词条 89）**

包括**试验设计、研究实施和数据评估**在内的完整活动，目的是判断变更前后产品是否具有可比性。

可比性研究的三步法框架：

```
可比性研究三步法（ICH Q5E）
步骤 1：质量可比性（必须）
├── 全面的分析表征（理化 + 生物学活性 + 杂质）
├── 变更前后批次的统计学比较
└── 评估质量差异的临床相关性

步骤 2：非临床可比性（如需要）
├── 体外结合/功能研究
└── 体内药理学/毒理学研究（当质量步骤不充分时）

步骤 3：临床可比性（如需要）
├── 临床 PK/PD 研究
└── 临床安全性/有效性研究（当非临床步骤不充分时）
```

**④ 可比性桥接研究（词条 87）**

通过提供**非临床或临床研究数据**，允许将以当前工艺生产药品的现有数据**外推**到变更工艺生产的药品。当质量可比性研究发现差异，但能通过桥接研究证明这些差异不具有临床意义时，可用桥接研究支持可比性结论。

:::

## ICH Q6B 生物技术产品质量标准术语体系

:::answer

ICH Q6B《生物技术产品的质量标准：测试程序和验收标准》是生物制品质量标准制定的核心指南，以下术语构成质量标准体系的概念基础。

**质量标准相关核心术语（词条 91–93）**

| 术语         | 词条 | 精确定义                                                                                         | 实践应用                                                           |
| ------------ | ---- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| **验收标准** | 91   | 原液、成品或生产阶段其他材料须符合的、相应分析方法对应的**可接受数值限度、范围或其他适宜检测值** | 放行标准（Release）和货架期标准（Shelf-life）的数值来源            |
| **行动限**   | 92   | 用于评价**不太关键工艺步骤**一致性的内部值                                                       | 内控值，通常严于验收标准；超出行动限须调查但不必然导致放行失败     |
| **生物活性** | 93   | 产品达到预期生物效力的特有能力；效价是生物活性的定量测定结果                                     | 是生物制品区别于化学药的核心 CQA；须建立基于作用机制的效价检测方法 |

**杂质的法规分类体系（词条 94、100、104、105、106）**

```
杂质完整分类框架（ICH Q6B）
所有存在于原液/成品中的非预期组分
        ↓
├── 污染物（词条 94）：引入的外源性物质
│   ├── 化学性：溶剂残留、清洁剂
│   ├── 生化性：培养基残留
│   └── 微生物：细菌、支原体、病毒
│
├── 工艺相关杂质（词条 104）：来源于生产工艺
│   ├── 细胞基质来源：HCP、宿主细胞 DNA（HCD）
│   ├── 细胞培养物来源：抗生素、诱导剂、培养基成分
│   └── 下游工艺来源：Protein A 残留、层析填料浸出物
│
└── 产品相关组分（按安全性/有效性影响进一步分类）
    ├── 产品相关杂质（词条 105）：分子变异体，活性/效能/安全性不可比
    │   示例：错误折叠体、截短体、氧化损伤活性降低的变体
    └── 产品相关物质（词条 106）：具有活性且对安全有效性无害
        示例：单抗的脱糖基化变体（若不影响活性）
```

**原液与成品的定义（词条 97、98）**

| 术语                           | 词条 | 定义                               | 关键内容                                                                              |
| ------------------------------ | ---- | ---------------------------------- | ------------------------------------------------------------------------------------- |
| **原液（Drug Substance，DS）** | 98   | 最终可与辅料一起制成成品的物质     | 由预期产品 + 产品相关物质 + 产品相关杂质 + 工艺相关杂质组成；也可能含缓冲剂等辅料成分 |
| **成品（Drug Product，DP）**   | 97   | 含有原液并通常与辅料放在一起的药品 | 是患者最终使用的产品形式，须满足额外的制剂要求                                        |

**参考物质体系（词条 101、102）**

| 类型                      | 词条 | 定义                                         | 用途                                                     |
| ------------------------- | ---- | -------------------------------------------- | -------------------------------------------------------- |
| **内部级参考物质（IRS）** | 101  | 生产企业用代表批次制备的经质量特性分析的物质 | 用于各批产品的生物学检测和理化试验；用于标定工作参考物质 |
| **内部工作参考物质**      | 102  | 制备方法与 IRS 相似，用一级参考物质标定获得  | 用于个别问题批次的评价和常规检验对照                     |

**质量标准的完整定义（词条 107）**

质量标准是一份包括**检测项目、参照的分析方法和适宜验收标准**的列表，须同时满足：

- 由生产企业提出并论证其科学合理性
- 经药品监管部门审评同意并作为**批准条件**
- "符合质量标准"指根据所列方法检测，结果符合验收标准

:::

## ICH Q7 原料药 GMP 核心术语（词条 108–147）：从 API 定义到验证体系

:::answer

ICH Q7《活性药物成分（API）的优良制造规范》为原料药（包括生物技术来源的 API）的生产建立了 GMP 要求框架，以下术语是理解 API 生命周期管理的基础。

**API 及其生产的核心定义（词条 108–127）**

| 术语                | 词条 | 精确定义                                                                                                   | 关键区分点                                                         |
| ------------------- | ---- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **接受标准**        | 108  | 检测结果的可接受量化限度、范围或其他合适测定值                                                             | 与 ICH Q6B 词条 91 定义一致，强调基于方法的定量标准                |
| **API（原料药）**   | 109  | 旨在供生产药物制剂的活性成分，在疾病诊断/治疗/缓减/处置/预防及影响人体结构和功能方面发挥药理或其他直接效应 | 对生物药而言，原液（DS）即为 API                                   |
| **API 起始物料**    | 110  | 用于生产 API 且成为该 API 结构重要组成部分的原料/中间体/API；通常具有明确的化学性质和结构                  | 须在申报中明确定义；对生物药通常为表达载体和宿主细胞系             |
| **批（Batch/Lot）** | 111  | 一个工艺或工艺系列中生产的、在特定限度内具有**均一性**的一定量物料                                         | 批量可以是固定量或固定时间间隔的产量                               |
| **批号**            | 112  | 标明批次的数字/字母/符号的**唯一组合**，可确定生产和分销的历史                                             | 追溯性的核心工具；变更（如返工）须在批号中体现                     |
| **生物负荷**        | 113  | 原材料/API 中微生物的**水平和类型**（有害或无害）；不超标时不被认为是污染                                  | 与无菌（Sterility）的区别：生物负荷允许一定数量微生物存在          |
| **污染**            | 116  | 生产/抽样/包装/储存/运输过程中混入原材料/中间体/API 中的化学或微生物性质的杂质或外来物质                   | 与杂质的区别：污染是意外引入的外来物质，杂质包括工艺固有产生的物质 |
| **关键**            | 118  | 描述为保证药品符合要求而确立的**应被控制在预先确定范围内**的工艺步骤/条件/参数                             | "关键"的判定基于风险评估而非主观判断                               |
| **母液**            | 126  | 结晶分离后剩余的液体；可能含有未反应原料、中间体、一定浓度 API 和/或杂质                                   | 可以被进一步使用（须有工艺验证支持）                               |

**返工、重新加工与再处理的三者区分（词条 138、140）**

| 概念         | 词条 | 定义                                                                                                 | 关键判断                                       |
| ------------ | ---- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **返工**     | 138  | 将中间体或 API（包括不合格者）**重新引入工艺**（如重复结晶）；这些操作是**已确立的生产工艺的一部分** | 须预先在工艺中定义；须经验证；批号须加返工标识 |
| **重新加工** | 140  | 对不合格中间体或 API 进行**与已确定工艺不同**的一步或多步操作（如用不同溶剂重结晶）                  | 须额外评估对产品质量的影响；监管风险更高       |
| 正常工艺继续 | —    | 生产过程控制测试表明未完成的工艺步骤的继续进行                                                       | **不属于**返工，是正常工艺的组成部分           |

**验证体系的核心定义（词条 143–147）**

| 术语         | 词条 | 定义                                                                                                           |
| ------------ | ---- | -------------------------------------------------------------------------------------------------------------- |
| **质量标准** | 143  | 包含认可标准（或相关标准）及其量化限值/范围的分析方法列表；建立物料适用性判断标准                              |
| **验证**     | 144  | 确保具体工艺/方法/系统能产生符合预设接受标准结果的**文件化方案**                                               |
| **验证方案** | 145  | 描述验证方法及具体认可标准的书面计划，须含设备、CPP/操作范围、产品特征、取样、数据收集要求、验证次数和认可标准 |
| **预期收率** | 146  | 基于前期数据推测的、任何合适生产步骤中预期得到的物料量或理论百分比                                             |
| **理论收率** | 147  | 不考虑任何损失或操作失误，以实际投入物料量计，某步骤**应得到**的产量；是计算步骤收率的分母                     |

## ICH Q8 工艺验证与 QbD 核心术语：从设计空间到 PAT

:::answer

ICH Q8《药物研发》引入了质量源于设计（QbD）理念，以下术语是现代生物制药工艺开发的核心概念框架。

**ICH Q8 五大核心术语精解**

**① 持续工艺确认（词条 148）**

工艺验证的**另一种方法**，通过持续监控和评价生产工艺性能来确保工艺处于受控状态。

```
传统工艺验证 vs 持续工艺确认
传统验证：设计→确认（IQ/OQ/PQ）→批准上市→定期再验证
持续确认：设计→上市→持续监控（统计过程控制 SPC）→实时质量保证
```

持续工艺确认（CPV）是实现<strong>实时放行检测（RTR）</strong>的技术前提，代表了生物制药质量管理的高级阶段。

**② 设计空间（词条 149）**

设计空间是**已被证明能保证产品质量**的输入变量（物料属性）和工艺参数的**多维组合和交互作用**的范围。

关键法规含义：

- 在设计空间**内**的变动：监管上**不被视为变更**
- 超出设计空间：视为变更，须启动上市后变更申请
- 设计空间由申报者提出，经监管当局**审评批准**

**③ 正式实验设计/DOE（词条 150）**

一种确定工艺**影响因素与工艺输出之间相互关系**的、系统的、有序的方法。DOE 是建立设计空间的核心工具，也是工艺表征研究的标准方法论。

**④ 过程分析技术 PAT（词条 152）**

通过**实时测定**原料、中间体和过程中的关键质量和性能属性，建立设计、分析及生产控制体系，确保最终产品质量。

PAT 的三大关键特征：

- **实时性**：在工艺过程中测定（而非终产品检测）
- **预测性**：建立过程参数与产品质量的定量模型
- **反馈性**：实时数据驱动工艺参数的自适应调整

常见 PAT 工具：在线 Raman 光谱（葡萄糖/乳酸监测）、在线 ORP（氧化还原电位）、在线生物量传感器

**⑤ 工艺稳健性（词条 153）**

工艺承受**物料波动及工艺/设备改变**而不造成负面质量影响的能力。工艺稳健性研究通过 Worst-case 设计和多变量 DOE 来评估和证明，是支持宽泛的设计空间和减少工艺失败的关键。

**生命周期（词条 151）**

产品从开始研发到上市，直至产品终止上市的**整个过程**。ICH Q8 强调，质量必须通过贯穿整个生命周期的持续知识积累和工艺理解来保证，而非仅在特定时间点的快照式验证。

:::

## ICH Q10 药品质量体系术语：从工艺能力到知识管理

:::answer

ICH Q10《药品质量体系》定义了现代药品制造质量管理的总体框架，以下术语是建立药品质量体系的概念基础。

**工艺管理核心术语（词条 154–160）**

**① 工艺能力（词条 154）**

工艺生产出**满足所有要求**的产品的能力。在统计学上，可用工艺能力指数（Cp、Cpk）定量表达：

| 能力指数   | 计算                     | 含义                           |
| ---------- | ------------------------ | ------------------------------ |
| Cp         | (规格上限-规格下限) / 6σ | 工艺固有精度（不考虑均值偏移） |
| Cpk        | min(CPU, CPL)            | 考虑均值偏移的实际能力         |
| Cpk ≥ 1.33 | —                        | GMP 生产通常要求的最低能力指数 |

**② 变更管理（词条 155）**

提出、评估、批准、实施和回顾分析变更的**系统性方法**。完整的变更管理流程包括：

- 变更申请（变更描述、影响评估）
- 变更评估（风险评估、法规影响分析）
- 变更批准（内部批准 + 必要时监管申报）
- 变更实施（验证、培训、文件更新）
- 变更回顾（有效性确认、趋势分析）

**③ 纠正措施 vs 预防措施（词条 158、164）**

| 措施类型           | 词条 | 定义                                                   | 触发条件                                  |
| ------------------ | ---- | ------------------------------------------------------ | ----------------------------------------- |
| **纠正措施（CA）** | 158  | 消除**已发现的违规或非期望状况的原因**所采取的措施     | 已发生的不合格事件（OOS、偏差、客户投诉） |
| **预防措施（PA）** | 164  | 消除**潜在的违规或潜在的非期望状况的原因**所采取的措施 | 风险评估发现的潜在风险（FMEA、趋势分析）  |

**关键区分**：纠正措施是防止事件**再次发生**，预防措施是防止事件**发生**。

**④ 控制策略（词条 157）**

根据当前对产品和工艺的理解而产生的**一系列有计划的控制**，保证工艺性能和产品质量。控制策略是 ICH Q10 的核心，涵盖：

- 物料属性控制（原料、辅料）
- 厂房和设备运行条件控制
- 过程控制（CPP 范围、IPC 检测）
- 成品质量标准
- 以及相应的监控方法和频次

**质量管理体系支柱术语（词条 160–172）**

| 术语                    | 词条 | 定义                                                                           | 实践意义                                        |
| ----------------------- | ---- | ------------------------------------------------------------------------------ | ----------------------------------------------- |
| **知识管理**            | 160  | 收集、分析、储存和传递与产品/生产工艺/组分相关信息的系统性方法                 | 是 QbD 理念落地的基础；历史批次数据的积累和应用 |
| **持续改进**            | 156  | 提高满足要求的能力的经常性活动                                                 | 通过 CAPA、工艺优化、分析方法改进持续提升       |
| **药品质量体系（PQS）** | 163  | 在质量方面指导和控制制药公司而建立的管理体系                                   | 整合 GMP、ICH Q8/Q9/Q10 要求的综合体系          |
| **受控状态**            | 172  | 一系列能**始终如一**地持续保证工艺性能和产品质量的控制所处的状态               | 工艺验证和 CPV 的终极目标                       |
| **质量风险管理**        | 170  | 贯穿产品生命周期的对药品质量风险进行**评估、控制、沟通和回顾分析**的系统化过程 | ICH Q9 详细规定；FMEA、故障树分析是核心工具     |
| **高级管理层**          | 171  | 在最高级别上指导和控制公司、具有权力和责任调动资源的人员                       | ICH Q10 明确要求高级管理层对质量体系负最终责任  |

:::

## 上市申请获益-风险评估框架：治疗背景与现有治疗选择的系统论证

:::answer

药品上市申请中的获益-风险评估（Benefit-Risk Assessment）是监管机构批准决策的核心依据。获益-风险论证须遵循系统化的框架，以下是第一个关键维度——治疗背景的全面评估。

**治疗背景评估的两大核心要素**

**要素一：拟治疗疾病背景**

| 评估内容             | 具体指标                                                             | 资料来源                  |
| -------------------- | -------------------------------------------------------------------- | ------------------------- |
| **适应症定义**       | 预期临床用途（治疗/预防/诊断）、目标人群、治疗目标（治愈/缓解/控制） | 临床方案、流行病学文献    |
| **疾病负担**         | 发病率、患病率、死亡率、病程持续时间                                 | 注册数据库、文献综述      |
| **生活质量影响**     | 与健康相关的生活质量（HRQoL）评分                                    | QALY、患者报告结局（PRO） |
| **亚组差异**         | 不同亚组（按年龄、严重程度、分子分型）的临床结局差异                 | 亚组分析数据              |
| **社会公共卫生影响** | 感染性疾病的传播控制；对医疗资源的消耗                               | 流行病学模型              |

**要素二：现有治疗选择**

| 评估内容             | 关注维度                                             |
| -------------------- | ---------------------------------------------------- |
| **已批准治疗方案**   | 有效性、安全性、耐受性、依从性、局限性               |
| **按药理类别分析**   | 不同机制类别药物的优缺点比较                         |
| **其他干预措施**     | 临床指南推荐的非药物干预（手术、物理治疗、饮食调整） |
| **未满足的临床需求** | 现有治疗的不足之处；新药的潜在临床价值               |
| **地区差异**         | 如不同国家/地区现有治疗选择存在重大差异，须说明      |
| **无有效治疗的情形** | 若无现有有效治疗，须明确说明（支持低阈值批准）       |

**对 CMC 申报的意义**

治疗背景的充分论证直接影响对 CMC 风险的接受程度——对于严重疾病且无有效治疗手段的情形，监管机构通常愿意接受相对较高的 CMC 不确定性，允许"适度"条件下加快批准。反之，对于有良好现有治疗选择的适应症，CMC 要求通常更为严格。

:::

## 上市申请中的获益证据质量评估框架

:::answer

获益评估须基于对临床试验有效性数据的系统性分析，不仅关注终点指标的数值，更须评估证据的质量、外推性和临床意义。

**获益证据评估的七个维度**

**① 临床试验的优势与局限性**

评估试验设计对有效性评价的潜在影响：

- 盲法设计（随机双盲 > 开放标签）
- 对照选择（安慰剂 / 阳性对照 / 历史对照）
- 终点的合理性和客观性
- 样本量和统计效能

**② 终点与临床结局的相关性**

| 终点类型            | 临床相关性                             | 监管接受程度       |
| ------------------- | -------------------------------------- | ------------------ |
| 总生存期（OS）      | 金标准，直接反映患者获益               | 最高               |
| 无进展生存期（PFS） | 替代终点，与 OS 相关性较强             | 高（肿瘤学）       |
| 病理完全缓解（pCR） | 替代终点，加速批准途径可接受           | 中等（须后续验证） |
| 生物标志物变化      | 替代终点，需证明与临床结局的预测性关联 | 低（须充分验证）   |

**③ 亚组人群的差异化获益**

对存在未满足需求的亚组（如对现有治疗无充分反应的患者）须单独分析其获益，这对于监管审评中的受益人群精准定义至关重要。

**④ 获益结果的一致性**

跨不同临床试验和跨不同疗效指标的结果一致性，是获益证据可靠性的关键支撑。单一研究的孤立阳性结果说服力显著低于多研究一致阳性。

**⑤ 外推性（Generalizability）**

临床试验结果能否推广至真实医疗实践中使用该药物的人群？须关注：

- 临床试验排除标准（如老年患者、肾功能不全患者）
- 合并症患者的预期疗效
- 合并用药的潜在影响

**⑥ 药物重要特征对获益的贡献**

给药途径（口服 vs 注射）、给药频率（每日 vs 每月）、给药方便性等特征虽非药效学获益，但对患者依从性和临床结局有实质性影响，应在获益论证中适当体现。

**⑦ 暴露-效应关系**

药物浓度（如 AUC、Cmin）与获益之间的定量关系，是优化给药方案和支持特殊人群剂量调整的科学依据。清晰的 PK/PD 关系增强了获益论证的科学可信度。

:::

## 上市申请安全性信号的全面评估方法论

:::answer

安全性评估是获益-风险评估的另一核心维度，须对不良事件进行多角度的系统性分析，以确定真实的风险水平和可管理性。

**不良事件评估的五大维度**

**① 时间进程（Temporal Pattern）**

| 时间模式           | 临床含义                     | 风险管理含义                            |
| ------------------ | ---------------------------- | --------------------------------------- |
| 初期高发、随后降低 | 耐受现象；可能与 PK 适应相关 | 加强初始治疗期监测；提供预处理方案      |
| 频率随时间相对恒定 | 持续性风险，非累积           | 定期监测即可                            |
| 随暴露累积而增加   | 累积毒性；剂量依赖性损伤     | 须考虑治疗总剂量限制；定期评估获益-风险 |

**② 严重程度与可逆性评估**

- **严重程度（CTCAE 分级）**：1–5 级，5 级为致死性
- **可逆性**：停药后是否可恢复至基线？需要多长时间？
- **个体影响**：对单个患者生活质量的实际影响
- **公众健康影响**：如为传染性的不良反应（如肝炎再激活）

**③ 监测与预防的可行性**

| 可管理性等级 | 特征                                       | 临床接受度                 |
| ------------ | ------------------------------------------ | -------------------------- |
| 高度可管理   | 常规实验室检查即可监测（如血常规、肝功能） | 高                         |
| 中度可管理   | 需要专科监测（如眼科检查）                 | 中等，需要 REMS 或风险教育 |
| 难以管理     | 发生突然、无预警信号（如心源性猝死）       | 低，须严格适应症限制       |

**④ 对依从性的影响**

不良事件导致患者中断治疗会直接影响疗效——严重或难以耐受的不良事件是治疗失败的重要原因，须在安全性论证中明确量化。

**⑤ 风险的亚组变异性**

不同患者特征对不良事件发生率的影响须系统分析：

| 变异因素                    | 典型影响                         | 风险管理应用     |
| --------------------------- | -------------------------------- | ---------------- |
| 年龄（老年患者）            | 肾功能下降影响药物清除           | 剂量调整建议     |
| 肝/肾功能                   | 影响代谢和排泄，放大毒性         | 禁忌症或剂量调整 |
| 遗传多态性（如 HLA 基因型） | 特异质毒性（如阿巴卡韦超敏反应） | 基因型筛查       |
| 合并用药                    | 药物-药物相互作用                | 联合用药限制     |

:::

## 上市申请获益-风险评估中的不确定性识别与论证

:::answer

任何上市申请中都存在不同程度的不确定性，对不确定性的诚实识别和系统论证是高质量申报文件的标志，也是监管机构信任的基础。

**七类主要不确定性来源与应对策略**

**① 疾病认知局限**

- 患者群体的疾病异质性导致难以精确预测疗效
- 疾病自然史、危险因素和预后标志物的认知不足
- **应对**：明确研究人群的纳入/排除标准，为外推性提供合理边界

**② 研究设计局限**

- 临床试验患者数量有限，高危亚组可能被排除
- 长期数据缺乏（尤其对于加速批准的产品）
- 真实世界用药行为与试验条件的差异
- **应对**：上市后承诺研究（Post-marketing Commitment）；注册数据库研究

**③ 统计不确定性**

- 基于抽样导致的预估疗效变异（置信区间宽度）
- 数据缺失和方案依从性差导致的偏倚
- **应对**：充分的统计效能计算；多重敏感性分析；完整报告 ITT 和 PP 分析结果

**④ 联合用药机制的未知**

- 与其他药物的相互作用机制未充分研究
- 联合用药的潜在增效或毒性叠加
- **应对**：体外 DDI 研究；主要联合用药的临床 PK 研究

**⑤ 风险管理策略的可行性**

- 临床试验中密集监测条件在真实临床实践中难以复制
- 监测频率降低可能导致不良事件被漏检
- **应对**：基于真实世界条件制定风险最小化措施；必要时 REMS 或教育材料

**⑥ 患者观点的局限性**

- 临床试验中获取患者观点（如对风险-获益权衡的偏好）的机会有限
- **应对**：患者报告结局（PRO）研究；患者焦点小组；患者代表参与审评

**⑦ CMC 相关不确定性**

> 药物生产中引入新技术或控制策略，或与药物制剂/生产有关的其他潜在问题，是获益-风险评估中需明确考量的不确定性来源之一。

这一条款明确将 CMC 质量风险纳入整体获益-风险框架，说明 CMC 研究的充分性直接影响上市申请的批准概率。

**不确定性论证的黄金原则**

> 申报方主动、诚实、全面地论证不确定性，比监管机构在审评过程中自行发现不确定性，能够建立更高的监管信任度，并为风险管理策略的制定提供更充分的科学依据。

:::

## 常用 S/D 病毒灭活试剂体系：TNBP、Triton X-100 与 Tween 80 的特性与应用

:::answer

溶剂/去污剂（S/D）法是血液制品和部分生物制品生产中**有包膜病毒灭活**的标准工艺，通过破坏病毒包膜的脂质双层使病毒失活。

**S/D 灭活的作用原理与局限性**

```
S/D 法灭活原理
有机溶剂（S）：溶解脂质
去污剂（D）：增溶并破坏脂质双层结构
        ↓
有包膜病毒（HIV、HBV、HCV、HTLV 等）包膜脂质双层破坏
        ↓
病毒感染能力丧失（灭活）

局限性：对无包膜病毒（HAV、B19 细小病毒等）无效
```

**主要 S/D 试剂的特性对比**

| 试剂                        | 类型           | 特性                                                   | 主要用途                                                |
| --------------------------- | -------------- | ------------------------------------------------------ | ------------------------------------------------------- |
| **TNBP（磷酸三丁酯）**      | 有机溶剂       | 最主要的 S/D 有机溶剂；脂溶性强，有效溶解病毒包膜      | 单独使用或与去垢剂联用；在血浆制品中应用最广泛          |
| **Triton X-100**            | 非离子型去污剂 | **去垢剂能力最强**；辛苯聚乙二醇类；有效分散和溶解脂质 | 与 TNBP 联用（最常用组合：0.3% TNBP + 1% Triton X-100） |
| **Tween 80（聚山梨酯 80）** | 非离子型去污剂 | 去垢能力相对较弱；但毒性低，易从产品中去除             | 与 TNBP 联用（0.3% TNBP + 1% Tween 80）                 |

**S/D 组合策略**

TNBP 可以：

- **单独使用**：依赖溶剂自身的溶脂能力
- **与 Triton X-100 联用**：最强灭活效果，适合高病毒污染风险的产品
- **与 Tween 80 联用**：灭活效果略低于 Triton X-100 组合，但产品去除更容易

**S/D 处理后的试剂去除验证要求**

S/D 试剂本身对产品质量有潜在影响（Triton X-100 的可提取物和浸出物问题），须通过以下步骤去除并验证：

- **工艺去除**：C18 吸附、溶剂萃取、超滤（UF/DF）
- **残留检测方法**：HPLC 检测 TNBP 和 Triton X-100 残留量
- **安全限度**：须通过毒理学风险评估确定可接受残留限度

:::

## 分析方法生命周期管理（AQbD）：从 ATP 到持续性能监测的完整框架

:::answer

**AQbD 的理念起源**

分析质量源于设计（Analytical Quality by Design，AQbD）是将 QbD 的理念、方法和工具**应用于分析方法的开发和维护**，从而获得满足预期性能要求的质量可靠分析方法。

两大国际指导原则推动了 AQbD 的实施：

- **ICH Q14**（分析方法开发，草案）
- **USP-NF 通则 <1220>**（分析方法生命周期）

**分析方法生命周期的六个阶段**

```
分析方法全生命周期管理
① 开发（Development）
   ├── 基于 ATP 定义性能要求
   ├── 筛选分析技术和方法参数
   └── 建立方法设计空间
         ↓
② 确认（Qualification）
   ├── 适用性验证（方法是否适合预期用途）
   └── 关键方法参数识别
         ↓
③ 验证（Validation）
   ├── ICH Q2(R2) 规定的验证项目
   └── 准确度、精密度、专属性、LOD/LOQ、线性、耐用性
         ↓
④ 转移（Transfer）
   ├── 方法转移方案（AMTP）设计
   └── 接收实验室的平行验证（AMTR）
         ↓
⑤ 变更（Change）
   ├── 变更影响评估（是否需要部分/全部再验证）
   └── 变更记录与批准
         ↓
⑥ 持续性能监测（Continued Performance Monitoring）
   ├── 日常系统适用性试验（SST）
   ├── 统计过程控制（SPC）趋势监控
   └── 方法性能定期审查（与 PQR 联动）
```

**分析目标概况（ATP）的核心概念**

**ATP（Analytical Target Profile）**是根据分析方法的预期用途所提出的**对分析检测方法性能要求**的规格文件，是 AQbD 方法开发的起点和判断标准。

ATP 的制定须基于以下考量因素：

| 考量因素                 | 内容                                                          |
| ------------------------ | ------------------------------------------------------------- |
| **分析方法的预期目的**   | 放行检验？稳定性监测？工艺过程控制？                          |
| **与质量属性的关联性**   | 该方法检测的 CQA 对产品安全/有效性的重要性                    |
| **对分析方法性能的要求** | 精密度（重复性/中间精密度）、准确度、专属性、耐用性的量化指标 |
| **技术因素**             | 现有分析平台的能力；样品量限制；分析时间要求                  |
| **商业因素**             | 检测成本；规模化实施的可行性；仪器在质量实验室的可及性        |

**ATP 与 QTPP 的类比关系**

```
产品研发（QbD）         分析方法开发（AQbD）
QTPP（目标产品质量概况）  ←→  ATP（分析目标概况）
CQA（关键质量属性）       ←→  CMA（关键方法属性）
CPP（关键工艺参数）       ←→  CMP（关键方法参数）
设计空间               ←→  方法可操作设计区域（MODR）
```

**ICH Q14 的战略意义**

ICH Q14（分析方法开发）草案首次在国际层面将 AQbD 理念系统化，与 USP <1220> 配合，为全球生物制药企业建立了分析方法生命周期管理的统一框架，代表了分析方法管理从"一次验证终身有效"向"持续性能保证"的范式转变。

:::

## 生物制品生物学活性的检测方法与生命周期演进策略

:::answer

**生物学活性的核心地位**

生物学活性（Biological Activity，又称效价 Potency）是生物大分子的<strong>关键质量属性（CQA）</strong>，是区别生物制品与化学药物的核心特征。与理化分析方法相比，生物活性检测方法的开发和应用更加复杂和耗时，但其与产品疗效的关联性最为直接。

**生物活性检测方法随开发阶段的演进**

```
生物活性检测方法的生命周期演进
临床前研发阶段
├── 检测目的：初步评价活性
└── 方法选择：靶点结合分析（ELISA/SPR/BLI）
   优点：快速、简便、高通量
   局限：仅反映结合能力，不能完整反映功能活性
        ↓
IND 申报 / 临床 I–II 期
├── 检测目的：证明活性，支持初始剂量设计
└── 方法选择：开发基于作用机制的体外细胞活性方法
   优点：与体内疗效机制直接相关
   局限：变异系数大（通常 20–30%），方法开发耗时
        ↓
BLA 申报 / 商业化
├── 检测目的：批放行、稳定性研究、可比性研究
└── 方法选择：经充分验证的体外细胞活性方法（首选）
   替代：基于相关性建立的理化替代方法
        ↓
上市后（数据积累充足后）
└── 理化方法替代体外细胞活性：如胰岛素用 HPLC 定量确定活性单位
   前提：须充分证明理化指标与生物活性的相关性
```

**动物实验替代的伦理要求与技术路径**

基于实验动物保护和 3R 原则（Replacement, Reduction, Refinement），监管机构要求**尽可能采用效果相同或更优的体外生物学方法替代动物实验**。常见的替代策略：

| 替代层次             | 策略                                                       | 代表案例                              |
| -------------------- | ---------------------------------------------------------- | ------------------------------------- |
| **完全替代**         | 用体外细胞效价替代动物体内效价                             | 大多数细胞效价方法                    |
| **理化替代**         | 用经过相关性验证的理化方法替代体外细胞方法                 | HPLC 定量胰岛素；SE-HPLC 评估某些蛋白 |
| **替代靶点结合替代** | 当细胞方法变异过大时，以经相关性验证的结合分析作为中间过渡 | SPR 亲和力测定作为辅助                |

**体外细胞活性方法开发的关键考量**

| 设计要素         | 关键问题                                                          |
| ---------------- | ----------------------------------------------------------------- |
| **报告系统选择** | 荧光素酶报告基因（高灵敏度）vs 天然信号通路检测（更接近生理机制） |
| **靶细胞选择**   | 稳定转染的报告细胞系 vs 原代细胞（变异更大但更具生理相关性）      |
| **参考物质设计** | 内部参考物质（IRS）的批次选择和赋值方法                           |
| **方法精密度**   | 实验室内精密度（%CV ≤ 25%）和中间精密度目标                       |
| **线性范围**     | 确保待测样品浓度在方法线性范围内                                  |

:::
