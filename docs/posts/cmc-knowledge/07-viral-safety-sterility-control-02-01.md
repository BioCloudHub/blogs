## 外源病毒因子检测：动物体内接种法的接种方案、判定标准与异常处置规范

:::answer

**方法定位**

动物体内接种法（In Vivo Animal Inoculation）是外源病毒因子检测的经典方法之一，通过将待检细胞培养上清液（或细胞裂解物）接种于不同种类的动物和鸡胚，利用动物体对广谱病毒的易感性检测未知外源病毒，是体外法的重要补充。

**接种方案设计（《中国药典》三部要求）**

待检细胞至少须接种以下 **4 组受试系统**，且须同时进行（并行设计）：

| 接种系统             | 适用条件           | 接种方式                | 观察目的                       |
| -------------------- | ------------------ | ----------------------- | ------------------------------ |
| 乳鼠                 | 所有细胞           | 颅内 + 腹腔同时接种     | 检测嗜神经病毒、肠道病毒等     |
| 成年小鼠             | 所有细胞           | 颅内 + 腹腔 + 皮下接种  | 检测多种病毒（比乳鼠谱系略窄） |
| 鸡胚（两组不同日龄） | 所有细胞           | 卵黄囊 + 尿囊腔分别接种 | 检测流感病毒、禽源病毒等       |
| 豚鼠                 | **新建细胞**须增加 | 腹腔接种                | 检测腺病毒、副流感病毒等       |

**特殊情形的额外要求**

- **原代猴肾细胞：** 还须采用**家兔体内接种法**或**兔肾细胞培养法**，专项检查猴疱疹 B 病毒（B Virus, Macacine herpesvirus 1）——该病毒对人类具有极高致死性，是灵长类来源细胞的特殊风险点。

**判定标准（观察期末合格条件）**

| 受试系统           | 合格判定标准                                              |
| ------------------ | --------------------------------------------------------- |
| 乳鼠和成年小鼠     | ≥80% 接种动物健存，且未显示可传播性因子或其他病毒感染迹象 |
| 鸡胚（卵黄囊接种） | ≥80% 鸡胚存活，且未显示病毒感染                           |
| 鸡胚（尿囊腔接种） | ≥80% 存活，且**尿囊液红细胞凝集试验（HAI）为阴性**        |
| 豚鼠               | ≥80% 健存，且未显示可传播性因子或其他病毒感染             |
| 家兔               | ≥80% 健存，且未显示病毒感染（包括接种部位损伤）           |

**异常情况的处理规程**

**动物出现疾病/死亡时：**

1. 立即对死亡动物进行**大体解剖**观察（脏器外观、出血点等）；
2. 进行**组织学检查**（病理切片），确认死亡原因；
3. 若死亡原因明确为**动物间相互撕咬**（非感染性），且死亡率 >20%，则该试验**判为无效，须重试**；
4. 若动物显示有病毒感染迹象，须采用<strong>细胞培养法或分子生物学方法（如 PCR）</strong>对可疑病毒进行鉴定，确认病毒种类。

**与体外法的互补关系**

动物体内接种法能检测对已知指示细胞不敏感的病毒，弥补体外细胞培养法的盲区。在完整的外源病毒检测方案中，体内法须与体外法（多种指示细胞系共培养）**联合使用**，共同构成细胞基质外源病毒检测的双重保障体系。

:::

## 逆转录病毒及内源性病毒检测：多方法联合策略与感染性试验的决策逻辑

:::answer

**检测背景**

哺乳动物细胞（尤其是啮齿类细胞如 CHO、NS0、Sp2/0）基因组中天然整合有**内源性逆转录病毒序列（Endogenous Retroviral Sequences, ERVs）**，可能在特定条件下产生逆转录病毒颗粒。此外，细胞库建立和传代过程中也可能引入**外源性逆转录病毒**污染。逆转录病毒检测须多方法联合，各方法检测维度互补。

**四种检测方法的原理与适用范围**

**① 逆转录酶活性测定（RT Activity Assay）**

- **原理：** 逆转录病毒携带逆转录酶（RT）；通过 PERT（产物增强逆转录酶测定）或 PBRT（荧光产物增强逆转录酶测定）法，检测细胞培养上清中的 RT 酶活性；
- **灵敏度：** PERT/PBRT 法灵敏度极高，可检测极低水平的 RT 活性；
- **局限：** 细胞中某些内源性成分（如端粒酶、线粒体 DNA 聚合酶）也具有逆转录酶样活性，可能产生**假阳性结果**；
- **结论：** RT 阳性≠存在感染性逆转录病毒，须进一步确认。

**② 透射电镜检查（TEM）**

- **原理：** 对细胞超薄切片进行电镜观察，直接鉴定是否有病毒颗粒及其形态；
- **操作要求：** 须取至少 **1×10⁷ 个活细胞**制备超薄切片进行观察；
- **价值：** 可直接可视化病毒颗粒的存在（A 型、B 型、C 型颗粒的形态学区分）；
- **局限：** 仅能检测颗粒**是否存在**，不能判断是否具有感染性；操作复杂，通量低。

**③ 种属特异性 PCR / 免疫学方法**

- **适用场景：** RT 活性结果不明确，或不能采用 RT 活性测定时的替代方法；
- **主要方法：** 逆转录病毒 PCR（RT-PCR / 定量 qPCR）、免疫荧光法（IFA）、ELISA 法；
- **PCR 的额外价值：** 定量 PCR 法可对逆转录病毒颗粒进行**定量**，不仅判断存在与否，还可评估颗粒载量水平；
- **种属特异性设计：** 须根据细胞来源选择针对性的检测靶标（如 CHO 细胞选择小鼠白血病病毒 MuLV 相关序列）。

**④ 感染性试验（Infectivity Assay）**

- **原理：** 将待检细胞的培养上清液/裂解物接种于**逆转录病毒敏感细胞系**（如 Mus dunni、SIRC、PG4 等），经培养后检测是否出现感染性病毒复制；
- **价值：** 这是判断是否存在**具有感染能力的逆转录病毒**的唯一直接证据，是其他方法均无法替代的；
- **细胞选择：** 须根据待检细胞的种属来源，选择不同或多种敏感细胞进行检测（同种来源的病毒敏感细胞最优先）。

**四种方法的联合决策逻辑**

```
逆转录酶活性测定（PERT/PBRT）
        ↓
阴性 → 可排除大多数逆转录病毒风险（须结合其他结果综合判断）
        ↓
阳性 → 必须进行下列确认实验：
        ├── 透射电镜检查（确认是否有病毒颗粒形态）
        ├── PCR 法（确认颗粒是否含有特异性病毒核酸序列）
        └── 感染性试验（确认是否存在具有感染性的病毒颗粒）
```

**关键监管要求**

**可产生感染性逆转录病毒颗粒，且下游纯化工艺不能证明病毒被充分清除的细胞基质，不得用于生物制品生产。** 这是《中国药典》三部和 ICH Q5A 的明确要求，是细胞基质可用性的绝对红线。

:::

## 牛源性病毒检测：检测触发条件、操作规范与检测豁免的前提要求

:::answer

**检测触发条件**

若在**生产企业建立细胞库之前**，细胞基质在建立或传代历史中使用了**牛血清**（牛胎血清 FBS、小牛血清 NCS 等），则该细胞基质携带牛源性病毒的风险显著升高，须对所建立的 MCB 或 WCB 和/或生产终末细胞（EOPC）至少进行**一次**牛源性病毒检测。

**牛血清的主要病毒污染风险**

牛血清是生物制品生产中引入外源病毒的最主要历史风险来源，常见的需要关注的牛源性病毒包括：

| 病毒种类                        | 分类             | 特点                                         |
| ------------------------------- | ---------------- | -------------------------------------------- |
| 牛病毒性腹泻病毒（BVDV）        | RNA 病毒，有包膜 | 牛血清中最常见的病毒污染，可能持续污染细胞库 |
| 牛细小病毒（BPV）               | DNA 病毒，无包膜 | 对多种灭活方法（低 pH、热处理）有较强抵抗力  |
| 牛腺病毒（BAdV）                | DNA 病毒         | 多种血清型                                   |
| 牛呼吸道合胞病毒（BRSV）        | RNA 病毒，有包膜 | —                                            |
| 牛海绵状脑病朊蛋白（BSE/prion） | 非常规传染因子   | 非病毒，但须通过来源地控制                   |

**检测规范**

- 取待检细胞的培养上清液，制备相当于 **≥10⁷ 个活细胞/mL** 的裂解物进行检测；
- 检测方法须参照<strong>《中国药典》三部通则 3604</strong>（动物细胞基质生产生物制品的病毒安全性检测方法）执行；
- 须对牛源性病毒进行系统性筛查（通常至少覆盖 BVDV、BPV 等主要风险病毒）。

**检测豁免的前提条件（两者须同时满足）**

| 豁免条件                            | 具体要求                                                       |
| ----------------------------------- | -------------------------------------------------------------- |
| 条件一：后续生产不再使用牛血清      | 生产过程的所有步骤（培养基、补料液等）已完全改为无动物源性成分 |
| 条件二：MCB 和/或 EOPC 检测结果阴性 | 细胞库层面已证明无牛源性病毒污染                               |

同时满足上述两个条件，则**后续生产批次可不再重复进行牛源性病毒检测**，无需将其纳入常规批次检测项目。

**现代生产实践**

目前大多数主流 CHO 细胞培养已改用**化学限定培养基（Chemically Defined Medium, CDM）**，完全不含动物源性成分，从源头消除了牛源性病毒引入的风险，是降低此类检测要求的最根本策略。

:::

## 猪源性病毒检测：胰酶使用的风险溯源、检测要求与重组胰酶的特殊考量

:::answer

**检测触发条件**

若在**生产企业建立细胞库之前**，细胞基质在建立或传代历史中使用了**猪源胰酶**（或其他来源的动物源性胰酶），则须对所建立的 MCB 或 WCB 和/或超过生产限定水平的细胞至少进行**一次**与胰酶来源动物相关的外源性病毒检测。

**胰酶的主要病毒污染风险**

| 胰酶来源 | 主要风险病毒          | 特点                                                                                |
| -------- | --------------------- | ----------------------------------------------------------------------------------- |
| 猪源胰酶 | **猪细小病毒（PPV）** | 无包膜小型 DNA 病毒，对物理化学灭活手段抵抗力极强；历史上曾导致多起生物制品污染事件 |
| 牛源胰酶 | **牛细小病毒（BPV）** | 同属细小病毒，特性与 PPV 相似                                                       |

**猪细小病毒（PPV）的特殊风险**

PPV 因其无包膜结构和较小的粒径（18～26 nm），对**低 pH 灭活**（不能有效灭活无包膜病毒）、**有机溶剂/去污剂（S/D）处理**（S/D 法仅对有包膜病毒有效）等常规灭活方法不敏感，是生物制品病毒安全性控制的重要挑战之一。纳滤（≤20 nm 截留孔径）是目前有效去除 PPV 的关键工艺步骤。

**检测豁免的前提条件**

| 豁免条件 | 具体要求                                          |
| -------- | ------------------------------------------------- |
| 条件一   | 后续生产过程中不再使用任何动物源性胰酶            |
| 条件二   | MCB 和/或 EOPC 检测结果显示无相关动物源性病毒污染 |

**重组胰酶的特殊评估要求**

若使用**重组胰酶（Recombinant Trypsin）**（如来自 Aspergillus niger 或 Pichia pastoris 等微生物表达体系），须根据该重组胰酶**具体生产工艺的特点**，评估可能引入的外源性病毒种类，并据此确定须检测的病毒种类和适用检测方法，不能简单套用猪源胰酶的检测框架。

**行业实践趋势**

类似牛血清的替代策略，越来越多的企业已将猪源/牛源胰酶替换为重组胰酶（如 TrypLE™, Novozymes' Tryzan®），从根本上消除细小病毒引入的风险，是提升生物制品病毒安全性水平的重要工艺改进方向。

:::

## 特定病毒的靶向检测：细胞种属特异性风险识别与 CHO 细胞鼠细小病毒监控

:::answer

**特定病毒检测的必要性**

部分细胞基质对某些特定病毒具有种属特异性易感性，而标准的体外广谱外源病毒检测方案（使用 MRC-5、Vero、BHK21 等常规指示细胞系）可能无法检出这类病毒。须基于细胞的特性、传代历史和培养工艺，针对性地设计特定病毒检测方案。

**关键示例：CHO 细胞与鼠细小病毒（MVM）**

**背景与风险**

中国仓鼠卵巢细胞（CHO 细胞）对<strong>鼠微小病毒（Minute Virus of Mice, MVM）</strong>和<strong>鼠细小病毒（Mouse Parvovirus, MPV）</strong>具有特异性易感性——这类无包膜小型 DNA 病毒可通过原材料（啮齿类动物来源的生物材料）或环境污染（动物饲养设施附近）进入生产设施。

| 特点               | 描述                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------ |
| 病毒类型           | 无包膜，单链 DNA 病毒，粒径约 18～25 nm                                                          |
| 对灭活方法的抵抗力 | 极强——低 pH 灭活、S/D 处理均无效                                                                 |
| 有效去除方法       | 纳滤（20 nm 截留）；病毒清除验证中作为**最难去除病毒**的代表性毒种（MVM 作为指示病毒的核心理由） |
| 历史事件           | 多起商业化生物制品生产设施发生过 MVM 污染事件，导致重大生产损失                                  |

**CHO 细胞鼠细小病毒检测要求**

- MVM 和 MPV 须纳入 CHO 细胞基质的**定期检测项目**（不仅限于建库时）；
- 检测方法：PCR 法（高灵敏度，推荐 qPCR）是主要手段，可辅以细胞感染性试验；
- 在生产过程监控中，通常对收获液进行 MVM 检测，作为批放行的安全性检项之一。

**其他种属特异性高风险病毒举例**

| 细胞来源              | 特定风险病毒                  | 检测方法                |
| --------------------- | ----------------------------- | ----------------------- |
| 人源细胞（如 HEK293） | EBV、CMV、HIV、HCV、HBV       | 特异性 PCR / ELISA      |
| 灵长类来源细胞        | 猴疱疹 B 病毒（B virus）、SIV | 体内接种（家兔）+ PCR   |
| 小鼠杂交瘤细胞        | 小鼠白血病病毒（MuLV）、MVM   | PERT + PCR + 感染性试验 |

:::

## 细胞基质成瘤性检查：检测原则、半数致瘤量（TPD₅₀）评估与豁免条件

:::answer

**成瘤性的定义**

成瘤性（Tumorigenicity）检查是确定细胞基质在动物体内是否能够**直接形成肿瘤（致瘤性）**的鉴定试验，是对细胞本身生物学特性的评估，与细胞 DNA 的基因毒性（致瘤性/oncogenicity）是两个不同维度的概念。

**哪些情况须进行成瘤性检查**

| 情形                                 | 要求                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------ |
| 新建细胞系/株                        | **必须进行**成瘤性检查                                                   |
| 新型细胞基质                         | **必须进行**                                                             |
| 代次相关成瘤性的细胞（如 Vero 细胞） | **必须进行**——已证明低代次无成瘤性，但超过一定代次（169 代）则具有成瘤性 |
| 用于疫苗生产的细胞系/株              | **必须进行**（但未经遗传修饰的二倍体细胞证明无成瘤性后，可不作常规要求） |

**哪些情况可豁免成瘤性检查**

| 情形                                             | 说明                                                                                      |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| 已证明具有成瘤性的传代细胞用于**治疗性制品**生产 | 如 BHK21、CHO、HEK293、C127、NS0 等——已有充分证据证明具有成瘤性，进一步检查无额外信息价值 |
| 杂交瘤细胞（本身即成瘤性细胞）                   | 细胞类型属成瘤性细胞，无需重复检查                                                        |

**成瘤性阳性细胞的定量分析要求**

对于新建细胞或新型细胞基质中**具有成瘤性**的情况，须采用定量方法进一步分析成瘤性的大小，核心指标：

**半数致瘤量（TPD₅₀，Tumor Producing Dose 50%）**

- 定义：在动物模型中使 50% 受试动物形成肿瘤所需的细胞数量；
- 通过 TPD₅₀ 值可定量评估细胞成瘤性的强弱，并结合生产工艺（如纯化后产品中残余活细胞数量）和产品给药剂量，进行成瘤性风险评估。

**检测方法**

- **体内法（In Vivo，标准方法）：** 将待测细胞皮下注射免疫缺陷鼠（如裸鼠 Nude Mice、SCID 小鼠），观察肿瘤形成情况，是成瘤性评价的金标准；
- **体外法（参考方法）：** 软琼脂克隆形成试验（Soft Agar Colony Formation）或器官培养试验，适用于低代次、在动物体内无成瘤性的传代细胞系，体外法结果只作为**参考**，不能替代体内法。

:::

## 细胞基质致瘤性检查：与成瘤性的本质区别、适用范围与进行性结节的处置要求

:::answer

**致瘤性（Oncogenicity）与成瘤性（Tumorigenicity）的核心区别**

| 概念                         | 检查目的                                                     | 作用主体          | 本质问题                                                 |
| ---------------------------- | ------------------------------------------------------------ | ----------------- | -------------------------------------------------------- |
| **成瘤性**（Tumorigenicity） | 检测细胞本身是否能在动物体内形成肿瘤                         | 完整的活细胞      | 细胞是否有"形成肿瘤"的表型能力                           |
| **致瘤性**（Oncogenicity）   | 检测细胞成分（DNA 或裂解物）是否能使正常细胞永生化或形成肿瘤 | 细胞 DNA 或裂解物 | 细胞中是否存在"致瘤性因子"（如致癌基因、致瘤性病毒序列） |

**致瘤性检查的设计逻辑**

致瘤性检查旨在保证细胞基质中**不存在可使正常细胞永生化并具有形成肿瘤能力的因子**，潜在风险来源：

- 来源于**肿瘤的细胞**（如肿瘤衍生细胞系）含有致瘤性物质的理论风险较高；
- 因未知机制形成肿瘤表型的细胞也存在类似风险；
- 细胞 DNA 中整合的**致瘤性病毒序列**（如 SV40 T 抗原、EBV EBNA 等）。

**哪些情况须进行致瘤性检查**

| 情形                                                         | 要求         |
| ------------------------------------------------------------ | ------------ |
| **新型细胞基质**，特别是成瘤性为阳性的细胞，用于**疫苗生产** | **必须进行** |

**哪些情况豁免致瘤性检查**

| 情形                                                                 | 说明           |
| -------------------------------------------------------------------- | -------------- |
| 已建株的二倍体细胞（MRC-5、2BS、KMB17、WI-38、FRhL-2）新建主细胞库   | **不要求**进行 |
| 已建株或有充分应用经验的连续传代细胞（CHO、NS0、Sp2/0、低代次 Vero） | **不要求**进行 |

**检测方法选择**

检测方式须根据细胞基质的表型或来源特点进行针对性选择：

| 怀疑风险类型                                   | 推荐检测材料               | 理由                                           |
| ---------------------------------------------- | -------------------------- | ---------------------------------------------- |
| 疑似有**致瘤性病毒**（根据细胞来源或表型推测） | 细胞基质**裂解物**接种动物 | 完整病毒颗粒存在于裂解物中，可检测病毒致瘤活性 |
| 细胞基质具有**成瘤性表型**                     | 细胞 **DNA** 接种动物      | 检测 DNA 层面是否携带致癌基因序列              |

**进行性结节的进一步研究要求**

若在致瘤性检查动物中出现**进行性结节（Progressive Nodules）**，须开展以下进一步研究：

1. **鉴别致瘤性因子的性质**（是病毒还是 DNA 序列介导）；
2. **鉴别致瘤性活性的类型**（永生化活性还是直接致瘤活性）；
3. **综合评估细胞的可适用性**——判断该细胞基质是否仍可用于生产，或须通过工艺改进消除相关风险后方可使用。

:::

## 低 pH 病毒灭活工艺：作用原理、关键工艺参数与中间体质量控制

:::answer

**工序定位**

低 pH 病毒灭活是单抗下游纯化工艺中**病毒灭活**的核心步骤，通常位于 Protein A 亲和层析洗脱之后。根据 ICH Q5A 的要求，生物制品的病毒安全性应至少采用**两种基于不同原理**的方法进行控制，行业推荐采用 **3 种互补方法**（低 pH 灭活 + AEX 流穿 + 纳滤除病毒）构建多重屏障体系。

**作用原理**

将 Protein A 洗脱液的 pH 降低至 **3.6～3.7**（弱酸性），维持一定时间，可有效灭活**有包膜病毒**（脂包膜在酸性条件下结构破坏，病毒失去感染能力）：

- **有效灭活范围：** 有包膜病毒，如小鼠白血病病毒（MuLV）、HIV、HCV 等；
- **无效灭活对象：** 无包膜病毒（如细小病毒 PPV/MVM）——低 pH 对无包膜病毒基本无灭活效果，这是该步骤的关键局限。

**关键工艺参数（CPPs）及其影响**

| 参数     | 关键控制范围                 | 影响说明                                                        |
| -------- | ---------------------------- | --------------------------------------------------------------- |
| 灭活 pH  | **3.6～3.7**（目标值）       | pH > 3.8：灭活效率显著降低；pH < 3.6：蛋白聚体形成风险增加      |
| 灭活时间 | 通常 ≥60 min（根据验证确定） | 时间不足→灭活不完全；时间过长→蛋白降解风险升高                  |
| 灭活温度 | 通常 15～25℃（室温）         | 温度过低降低灭活效率；需在验证中确认温度影响                    |
| 蛋白浓度 | 通常 ≤5 mg/mL                | 高浓度蛋白可缓冲 pH，影响实际酸碱环境；须验证高浓度时的灭活效果 |
| 搅拌状态 | 持续温和搅拌                 | 确保 pH 均匀分布，避免局部 pH 偏差导致灭活不均                  |

**中间体控制检测项**

| 检测项目               | 控制目的                                         |
| ---------------------- | ------------------------------------------------ |
| 蛋白浓度（UV280）      | 确认灭活前后产品损失在可接受范围                 |
| SEC-HPLC（聚体分析）   | 监控低 pH 处理对蛋白聚集的影响，排除聚体超标     |
| CEX 电荷变体谱         | 监控低 pH 是否引发脱酰胺等化学降解导致酸性峰增加 |
| pH（灭活过程在线监控） | 实时确认 pH 维持在目标范围，防止 pH 漂移         |

**S/D 法的替代应用**

对于在低 pH 条件下**不稳定**的目标蛋白，可采用**有机溶剂/去污剂（S/D）法**替代：

- **方法原理：** 用 Tri(n-butyl)phosphate（TNBP）+ 非离子去污剂（如 Polysorbate 80 或 Triton X-100）的混合物，破坏有包膜病毒的脂膜，使其失去感染能力；
- **有效范围：** 同样只对**有包膜病毒**有效；
- **局限：** TNBP 和去污剂须在后续步骤中完全去除（通过色谱或萃取），须验证去除效果和残留量符合安全性要求。

:::

## 除病毒纳滤工艺：双重清除机制、验证要求与工艺参数优化考量

:::answer

**除病毒纳滤的定位**

除病毒过滤（Virus Filtration，VF）是病毒**物理去除**的核心工艺步骤，与低 pH 灭活（化学/物理灭活有包膜病毒）形成互补：纳滤能有效去除**无包膜小型病毒**（如细小病毒 MVM/PPV），弥补低 pH 灭活的盲区，是多重病毒安全屏障体系中不可或缺的组成部分。

**双重清除机制**

**① 粒径排阻（Size Exclusion，主要机制）**

- 病毒颗粒物理尺寸大于滤膜有效孔径 → 被机械截留在膜上游，目标蛋白（分子量远小于病毒）穿过滤膜收集；
- 典型设计：20 nm 孔径滤膜（如 Millipore Viresolve® Pro、Pall Ultipor® DV20）可有效截留 ≥20 nm 的病毒颗粒（包括最难去除的细小病毒）；
- 对 80～100 nm 的大型病毒（如 MuLV）的去除对数减少值（LRV）通常 **≥4 log**（行业验证数据一致）。

**② 吸附机制（Adsorptive Capture，辅助机制）**

- 对于尺寸接近或略小于膜孔的病毒，通过膜表面与病毒颗粒之间的**静电相互作用、范德华力、氢键**等分子间作用力捕获；
- 吸附贡献与膜材料、溶液 pH、离子强度密切相关，是粒径排阻的有益补充。

**指示病毒与清除验证的核心要点**

| 指示病毒               | 类型                     | 选择理由                                                         |
| ---------------------- | ------------------------ | ---------------------------------------------------------------- |
| 小鼠细小病毒（MVM）    | 无包膜，单链 DNA，~20 nm | 粒径最小，代表最难去除的病毒，是纳滤验证的**关键挑战性指示病毒** |
| 小鼠白血病病毒（MuLV） | 有包膜，~80～100 nm      | 代表有包膜大型病毒，验证纳滤的广谱性                             |

**除病毒过滤工艺的三级考察维度（开发→验证→生产）**

**开发阶段考察：**

| 考察项目         | 目的                                         |
| ---------------- | -------------------------------------------- |
| 过滤通量（L/m²） | 确认单位膜面积可处理的料液量，确定膜面积需求 |
| 过滤速率（LMH）  | 确认过滤时间在工艺可接受范围内               |
| 产品收率（%）    | 确认目标蛋白不被显著吸附（须 ≥90%）          |
| 蛋白质量属性     | 确认过滤不引起聚体升高或其他质量属性变化     |

**验证阶段考察：**

- **滤器截留能力（病毒 LRV）：** 使用 MuLV 和 MVM 两个关键指示病毒，在**最差条件**下进行病毒清除验证；
- **批内和批间一致性：** 同一批次的不同滤器及不同批次滤器，病毒截留能力须保持一致；
- **不同膜面积型号的一致性：** 若生产中使用不同面积型号（如 0.1 m²→0.5 m²→2 m²），须验证各规格的截留能力等效性；
- 验证须在**小规模缩小模型**（Scale-down Model，与商业化工艺具有代表性）中进行，不得在商业化规模下进行加毒（spiking）实验。

**关键工艺参数的最差条件设计**

| 参数                 | 最差条件方向               | 理由                                                 |
| -------------------- | -------------------------- | ---------------------------------------------------- |
| 过滤压力             | 最高允许压力               | 高压力可能破坏病毒颗粒，使其变形穿透，测试最严苛条件 |
| 蛋白浓度             | 最高                       | 高蛋白浓度可能堵塞膜孔，降低截留效率                 |
| 过滤体积（通量）     | 最大                       | 过大通量可能导致膜堵塞和截留效率下降                 |
| 滤器完整性（起泡点） | 最低接受值（接近规格下限） | 代表最差完整性状态下的截留能力                       |

:::

## 高浓度无菌注射液灌装的技术挑战与工程解决策略

:::answer

**核心挑战：高粘度制剂的流动性与灌装精度**

高浓度单抗制剂（通常蛋白质浓度 >100 mg/mL，部分产品达 150～200 mg/mL）因蛋白质分子间相互作用显著增强，表现为**粘度大幅升高**（可达普通制剂的 10～100 倍）：

- 粘度高 → 流动性差，自然排空困难；
- 粘稠药液倾向于**粘附**在容器壁、管道内壁、过滤器滤壳及灌装针头等表面；
- 导致**灌装收率降低**（药液损失）和**灌装精度控制难**（装量偏差大）。

**四类工程解决措施**

**① 混合容器和缓冲容器的设计优化**

- 选择容积尽可能**小**的容器（仅满足混合和缓冲体积需求），减少药液在容器表面的吸附量；
- 容器形状设计应**简洁、无死角**，以利于在重力或气压辅助下自然排空；
- 材质选择须对高浓度蛋白质溶液的表面吸附最小（如预处理的不锈钢或特种硅化玻璃内衬）。

**② 过滤系统的药液回收优化**

- 选择**尺寸合适**的过滤器（膜面积和壳体容积与实际过滤量匹配，不宜过大）；
- 过滤完成后，考虑将**滤壳内腔及滤器与灌装系统之间的管路中的残余药液**通过气压排入灌装系统，而非废弃，显著提升回收率；
- 对过滤系统设计追加**药液回收管路设计**（如可排气的过滤器出口）。

**③ 灌装管路系统设计优化**

| 优化措施                         | 目的                                     |
| -------------------------------- | ---------------------------------------- |
| 减少转换接头数量                 | 降低局部流阻，减少死体积                 |
| 避免变径设计（灌装袋→泵管→针头） | 减少管径变化处的药液滞留                 |
| 适当增大管路和泵管内径           | 降低粘流阻力，提高流动性                 |
| 针内径与剂量管路内径匹配         | 避免针内径过小导致流速受限，灌装精度下降 |
| 缩短灌装针到灌装泵的管路长度     | 降低整体系统死体积                       |

**④ 模拟灌装（Mock Fill）验证**

- 在正式灌装前，使用**与生产药液粘度相近的模拟液**（如相同粘度的甘油水溶液）进行模拟灌装；
- 系统测试并记录：装量精度（均值和 RSD%）、灌装速率、回收率；
- 据测试结果对灌装系统参数（泵速、针头型号、压力设置等）进行调整；
- 模拟灌装完成后（或同时进行培养基模拟灌装 Media Fill），方可进行正式生产。

**收率目标与控制标准**

高浓度制剂灌装过程中，通常设定以下目标：

- 灌装装量精度（RSD%）：通常 ≤ 2.0%；
- 药液总回收率：通常设定 ≥ 97%（须根据具体工艺验证确认）；
- 任何低于设定回收率的批次须进行偏差调查，分析损失来源并采取纠正措施。

## 除病毒过滤原理详解：粒径排阻与吸附截留的协同机制及工艺能力边界

:::answer

**两种清除机制的协同作用**

除病毒过滤膜（Virus Removal Filters）不同于普通除菌过滤膜（0.22 μm），其有效孔径为 **15～25 nm**（如 20 nm 截留级别），通过以下两种机制协同去除病毒：

**机制一：粒径排阻（Size Exclusion / Size-Based Retention）**

- **基本原理：** 病毒颗粒物理尺寸 > 滤膜孔径 → 物理截留；目标蛋白（IgG 约 10 nm 水动力学直径）< 滤膜孔径 → 穿透通过；
- **截留效率与病毒粒径的关系：** 病毒粒径越大，被截留的概率越高（基于概率模型）；
- **典型截留效率（工业验证数据）：** 20 nm 孔径滤膜对直径 20 nm 的细小病毒 LRV ≥ 4 log，对直径 80～100 nm 的 MuLV LRV 通常 ≥ 6 log。

**机制二：吸附截留（Adsorptive Capture）**

- **适用对象：** 尺寸接近或略小于膜孔的病毒颗粒，以及通过物理排阻刚好处于临界状态的病毒；
- **作用力类型：** 静电相互作用（膜表面电荷与病毒表面电荷的静电吸引）；范德华力（非特异性近程吸引）；氢键（病毒衣壳蛋白与膜表面极性基团）；
- **影响因素：** 溶液 pH（影响电荷状态）、离子强度（屏蔽静电相互作用）、蛋白浓度（竞争性吸附）。

**关键能力边界**

| 参数                           | 能力范围                                              |
| ------------------------------ | ----------------------------------------------------- |
| 可有效去除的病毒粒径           | 通常 ≥ 20 nm（20 nm 截留膜）                          |
| 典型病毒 LRV（MuLV，80 nm）    | ≥ 6 log（行业标准验证结果）                           |
| 典型病毒 LRV（MVM/PPV，20 nm） | ≥ 4 log（最难去除，关键验证指标）                     |
| 无法有效去除                   | 支原体（200～300 nm，但不是病毒）、朊蛋白（非颗粒性） |

**纳滤在多重病毒安全屏障中的不可替代性**

在单抗工艺的多重病毒安全屏障中，纳滤因其机制独特性（物理截留，与低 pH 灭活的化学机制完全不同），是无包膜小型病毒（细小病毒，ICH Q5A 要求的最难去除病毒代表）的**唯一可靠工艺性去除步骤**。完整的病毒安全策略须确保纳滤步骤的稳健性（包括工艺参数控制和过滤后完整性测试）。

:::

## 非最终灭菌产品过滤除菌的 GMP 法规要求：关键条款解读与合规操作规范

:::answer

**适用法规**

2010 版 GMP 附录一《无菌药品》第七十五条明确规定了非最终灭菌产品的过滤除菌技术要求，以下为核心条款的逐条解读及实践合规要点。

**条款一：不可替代性原则**

> "可最终灭菌的产品不得以过滤除菌工艺替代最终灭菌工艺。"

- **含义：** 最终灭菌（如湿热灭菌、干热灭菌）的无菌保障水平（SAL，通常为 10⁻⁶）高于过滤除菌（依赖过滤器完整性），且更可靠；
- **实践要求：** 在产品开发阶段须首先评估产品是否可进行最终灭菌，只有在产品因热敏感或其他特性**不能在最终包装中灭菌**时，才允许采用过滤除菌。

**条款二：孔径要求**

> "可用 0.22 μm（更小或相同过滤效力）的除菌过滤器将药液滤入预先灭菌的容器内。"

- **除菌级定义：** 除菌级过滤器须经过微生物截留验证（通常以缺陷假单胞菌为挑战菌，≥10⁷ CFU/cm² 的挑战浓度下，滤液无菌），并非单纯孔径规格；
- **0.1 μm 过滤器：** 在需要去除支原体的特殊场景下使用，0.22 μm 对支原体截留率不足。

**条款三：除菌过滤的固有局限性**

> "由于除菌过滤器不能将病毒或支原体全部滤除，可采用热处理方法来弥补除菌过滤的不足。"

- 这一条款明确了 0.22 μm 除菌过滤的适用范围局限——仅能去除细菌，不能有效去除病毒（20 nm 除病毒纳滤才能有效去除小型病毒）；
- 须与产品病毒安全性策略综合考量，不能将除菌过滤误认为具有病毒去除功能。

**条款四：双重过滤的风险降低措施**

> "宜安装第二只已灭菌的除菌过滤器再次过滤药液（冗余过滤），最终的除菌过滤滤器应当尽可能接近灌装点。"

- **冗余过滤器的设计原则：** 参见本站除菌过滤系统设计章节（主过滤器 + 冗余过滤器的完整性测试规则）；
- **接近灌装点的要求：** 最终除菌过滤器与灌装针之间的管路须保持无菌，管路越短，再污染风险越低。

**条款五：使用后完整性测试（强制要求）**

> "除菌过滤器使用后，必须采用适当的方法立即对其完整性进行检查并记录。"

完整性测试的主流方法对比：

| 方法                          | 原理                               | 适用性                           |
| ----------------------------- | ---------------------------------- | -------------------------------- |
| 起泡点试验（Bubble Point）    | 测定湿润膜中最大孔径所需的最小气压 | 单次快速检测，适合常规使用后测试 |
| 扩散流试验（Diffusive Flow）  | 测定气体通过湿润膜的扩散速率       | 定量，对多层膜或大面积膜更适合   |
| 压力保持试验（Pressure Hold） | 密封系统内气压维持能力             | 用于系统密闭性确认               |

**条款六：验证要求**

> "过滤除菌工艺应当经过验证，验证中应当确定过滤一定量药液所需时间及过滤器两侧的压力。"

同一规格和型号的除菌过滤器使用时限通常**不得超过一个工作日**（须经过验证，某些特殊工艺可有不同要求）。

:::

## 除病毒过滤工艺开发阶段的综合考量：通量评估、批间一致性与规模放大的三维验证框架

:::answer

**工艺开发阶段的三大核心考察维度**

除病毒过滤工艺在正式验证前，须在开发阶段完成对滤器性能的系统性考察，以确保验证研究能够针对最相关的工艺条件和风险点进行设计。

**维度一：滤器对料液的处理能力（通量和收率）**

| 考察项目                | 评估内容                         | 开发目标                           |
| ----------------------- | -------------------------------- | ---------------------------------- |
| 单位面积通量（L/m²）    | 确认每 m² 膜面积可处理的料液总量 | 通量须满足生产批量需求，且留有余量 |
| 过滤速率（LMH，L/m²/h） | 确认过滤时间在生产可接受范围内   | 避免过滤时间过长影响产品稳定性     |
| 蛋白质收率（%）         | 确认产品无显著吸附损失           | 通常要求 ≥95%（视工艺可接受程度）  |
| 通量衰减曲线            | 评估堵塞风险，判断最大可过滤体积 | 通量衰减须在可接受范围内（<30%）   |

**维度二：病毒截留的稳健性（一致性验证）**

**同批次内的一致性：**

- 考察同一批次多个滤器单元对相同病毒（MuLV 和 MVM）的截留能力是否一致；
- 接受标准：各单元 LRV 值差异不超过 ±0.5 log（典型参考值）。

**不同批次间的一致性：**

- 考察不同生产批次的同款滤器在相同条件下的 LRV 是否稳定；
- 通常须测试 **≥3 批次**滤器，证明批次间截留性能的可重现性；
- 这是滤器供应商资质评估和变更控制管理的重要依据。

**不同膜面积型号的一致性（最常被忽视的维度）：**

- 生产规模放大时，通常须切换至更大面积的滤器型号（如从 0.02 m² → 0.1 m² → 0.5 m²）；
- 须验证**不同膜面积规格的滤器**在单位面积病毒截留能力上是否等效；
- 若供应商提供了跨规格等效性数据，须结合实际产品特性进行确认，不可直接套用。

**维度三：最差条件的设定（为验证阶段做准备）**

开发阶段还须识别并确认**影响病毒截留效果的最差工艺条件**，用于指导后续验证研究的设计：

| 参数               | 最差条件方向           | 识别方法     |
| ------------------ | ---------------------- | ------------ |
| 过滤压力           | 最高允许值             | 压力梯度实验 |
| 蛋白质浓度         | 最高值                 | 浓度梯度实验 |
| pH 和离子强度      | 最不利于静电截留的条件 | DoE 系统筛选 |
| 过滤通量（总体积） | 最大批量               | 通量衰减实验 |

:::

## 病毒安全性控制的总体原则：风险评估、全过程控制与全生命周期管理的三层框架

:::answer

**三层控制框架概述**

根据《中国药典》三部（生物制品病毒安全性控制通则）和 ICH Q5A(R1) 的要求，生物制品病毒安全性控制应建立在系统性风险评估基础上，并贯穿于产品的全生命周期。三层框架如下：

**第一层：风险评估（Risk Assessment）**

生物制品理论上均存在病毒污染的潜在风险，但不同产品的风险程度受以下因素影响：

| 风险因素                       | 影响维度                                                       |
| ------------------------------ | -------------------------------------------------------------- |
| 生产细胞基质（宿主细胞类型）   | 啮齿类细胞含内源性逆转录病毒序列；灵长类来源细胞含特定病毒风险 |
| 原材料来源（牛血清/胰酶等）    | 动物源性原材料引入特定动物源病毒的风险                         |
| 生产工艺（细胞培养、纯化步骤） | 开放操作步骤增加外源病毒引入风险                               |
| 临床给药途径                   | 注射给药（高风险）vs. 口服给药（低风险）                       |
| 适用人群                       | 免疫功能低下患者对病毒感染更敏感                               |

**第二层：全过程控制（Process-Wide Control）**

病毒安全性控制须体现在质量控制的全过程，构成三个相互支撑的控制维度：

```
维度一：原辅料来源控制
（细胞基质/菌毒种/血浆/动物来源材料的病毒检测和来源控制）
                ↓
维度二：工艺病毒清除能力
（特定病毒灭活/去除步骤 + 工艺过程的固有清除作用）
                ↓
维度三：产品病毒污染检测
（中间产物和成品的病毒检测，含收获液 UPB 检测）
```

三个维度缺一不可，须有机整合形成系统性防控体系。

**第三层：全生命周期管理（Lifecycle Management）**

- **工艺变更影响评估：** 任何影响病毒清除步骤的工艺变更（如 pH 调整、过滤器型号变更、缓冲液成分调整），均须评估其对病毒清除能力的影响，根据影响程度进行确认（Qualification）或再验证（Revalidation）；
- **上市后监测追溯：** 通过持续的批次放行检测和上市后不良事件监测，追溯产品病毒安全性状态；
- **新风险响应：** 当行业出现新的病毒污染事件（如 2009 年 MVM 污染事件）或监管机构发布新的技术要求时，须及时评估对本产品的适用性并相应更新控制策略。

**重组治疗性生物制品的特殊关注点**

- **动物细胞表达体系：** 须重点关注工艺过程的病毒清除能力（低 pH + AEX + 纳滤的多重屏障）；
- **原材料与辅料：** 须评估所有进入生产过程的外源性物料（培养基组分、过滤器材、一次性系统耗材）引入病毒的潜在风险；
- **工程细胞基质：** 须对工程细胞中整合的外源基因及其对细胞行为的影响进行评估。

:::

## 病毒安全性的原材料来源控制体系：起始原材料与工艺原辅料的分级管理策略

:::answer

**来源控制的战略意义**

"多重屏障体系"的最前端是**从源头切断病毒引入的途径**——如果能在原材料进入生产之前确认无病毒污染，则大幅降低了下游工艺的清除压力和风险。

**起始原材料的分类管控**

**① 生产用细胞基质**

- 须符合《生物制品生产检定用动物细胞基质制备及质量控制》规定；
- 细胞库（MCB/WCB/EOPC）须完成系统性外源病毒因子检测（体内法 + 体外法 + 逆转录病毒检测）；
- 详见 GMP 细胞库表征章节。

**② 人血液制品生产用原料血浆**

- 须实施**供血浆者筛查**（健康问卷 + 体格检查 + 行为风险评估）；
- 单份血浆须进行病毒检测（NAT 核酸检测，覆盖 HIV、HCV、HBV 等必检病毒）；
- 合并血浆（Mini-pool 或大池混合）须进行更灵敏的 NAT 检测（检测阈值更低）；
- 即使供血者和血浆检测均为阴性，仍须在生产工艺中实施病毒灭活/去除步骤（S/D 法 + 纳滤等），因为存在"窗口期"阴性样品的风险。

**③ 动物来源生物材料（免疫血清、体液、器官等）**

- 严格控制**供体动物来源**：不得使用来自疫区的动物；
- 实施检疫/检疫期管理（隔离观察期）；
- 保持动物清洁卫生，建立异常动物处置规程；
- 发现存在健康隐患的动物须及时处理或淘汰，相关记录须完整保存。

**原材料及辅料的来源控制原则**

在选择用于生物制品生产的原辅料时，遵循以下优先级原则（从高到低）：

| 优先级       | 材料类型                                             | 安全性水平                   |
| ------------ | ---------------------------------------------------- | ---------------------------- |
| **首选**     | 重组技术生产的生物材料（替代动物源性生物材料）       | 病毒风险最低                 |
| **次选**     | 化学合成材料（替代生物来源材料）                     | 无生物来源病毒风险           |
| **第三选**   | 低风险动物来源材料（来自清洁级动物，有完整来源追溯） | 风险中等                     |
| **谨慎使用** | 高风险动物来源材料（如人血浆来源组分）               | 须配套完整的病毒安全控制体系 |

**化学限定培养基（CDM）的推广意义**

从病毒来源控制的视角看，将传统含血清培养基替换为**完全化学限定培养基（Chemically Defined Medium, CDM）**，是近年来生物制品行业降低病毒安全风险的最重要工艺升级之一——从根本上消除了牛血清（含 BVDV、BPV 等风险）和胰酶（含 PPV 等风险）引入的外源性病毒污染途径。

:::

## 生产过程病毒控制：工艺固有清除能力与特定病毒清除步骤的设计原则

:::answer

**两类病毒清除机制的区分**

生产工艺过程对病毒的控制来源于两个层面，须清晰区分，分别验证：

| 类别                 | 定义                                                                                                 | 验证要求                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **工艺固有清除能力** | 非专门设计用于去除病毒、但在生产过程中客观上具有一定病毒清除作用的步骤（如各类层析步骤、超滤步骤等） | 须通过验证定量评估，但参数控制难度高，清除水平可变                               |
| **特定病毒清除步骤** | 专门设计并加入生产工艺中，专门用于去除/灭活病毒的步骤（低 pH 灭活、S/D 处理、纳滤等）                | **必须经过专项验证**，须明确关键工艺参数和控制范围，这些步骤是病毒安全保障的核心 |

**特定病毒清除步骤的设计原则**

**① 方法选择须基于综合评估**

选择病毒清除方法时，须综合以下因素：

- **潜在污染病毒的特性：** 有包膜 vs. 无包膜；大型 vs. 小型；DNA vs. RNA；
- **产品特性：** 目标蛋白在各种灭活/去除条件下的稳定性；
- **作用机制互补性：** 各步骤须基于不同原理（化学灭活 + 物理去除），避免对同类病毒的"串联重复"。

**② 关键工艺参数的明确与控制**

每个特定病毒清除步骤须明确<strong>影响病毒清除效果的关键工艺参数（CPPs）</strong>及其设定范围，包括：

- 低 pH 灭活：pH 值、温度、时间、蛋白浓度；
- 纳滤：过滤压力、料液浓度、滤器完整性（起泡点）；
- S/D 处理：溶剂浓度、去污剂浓度、处理温度和时间。

**③ 对产品质量属性影响的评估**

某些灭活/去除步骤可能影响产品质量：

- 低 pH 处理 → 可能引发蛋白聚集（pH <3.6）或脱酰胺（酸性条件）；
- S/D 处理 → 去污剂残留须验证去除效果；
- 高温处理 → 可能导致蛋白质变性；

须根据这些影响进行综合评估，在**病毒清除能力**和**产品质量保护**之间取得最优平衡。

**典型单抗工艺的多重屏障能力汇总**

| 工艺步骤           | 作用类型           | MuLV（有包膜）LRV | MVM（无包膜）LRV |
| ------------------ | ------------------ | ----------------- | ---------------- |
| Protein A 亲和层析 | 工艺固有清除（弱） | 2～4 log          | 0～1 log         |
| 低 pH 病毒灭活     | 特定灭活           | **≥4～6 log**     | ≈0（无效）       |
| CEX/AEX 层析       | 工艺固有清除       | 2～4 log          | 1～3 log         |
| 纳滤（20 nm）      | 特定去除           | **≥6 log**        | **≥4 log**       |
| **总计（典型）**   | —                  | **≥16 log**       | **≥5 log**       |

**抗体工艺可达约 20 个 log 的总病毒去除能力**，充分保障了产品的病毒安全性。

:::

## 产品病毒污染的检测体系：检测策略设计原则、方法选择与阳性结果处置规程

:::answer

**检测设计的核心考量**

病毒污染检测结果的准确性受多种因素影响，须系统考量后确定最优检测策略：

- **粗品（未纯化中间体）的细胞毒性：** 细胞培养收获液中可能含有高浓度的代谢产物（乳酸、氨、细胞碎片），对病毒指示细胞具有细胞毒性，影响体外病毒检测的灵敏度；
- **病毒活性的工艺依赖性：** 经过低 pH 处理等某些工艺步骤后，病毒已被部分灭活，在这些步骤之后的中间产物中检测不到活病毒，但不意味着该步骤之前没有污染；
- **最优取样时间点：** 通常须综合以上因素，选择**最适合检测的生产阶段**的中间产物进行取样，并须评估该阶段是否代表最高风险状态。

**检测方法的选择原则**

| 方法类别                     | 代表方法                       | 适用场景                                   |
| ---------------------------- | ------------------------------ | ------------------------------------------ |
| 细胞培养法（体外感染性检测） | 多种指示细胞系共培养，观察 CPE | 广谱外源病毒筛查，检测有感染性的病毒       |
| 核酸扩增技术（NAT）          | PCR / RT-PCR / qPCR / NGS      | 检测特定病毒或未知病毒核酸，不依赖病毒活性 |
| 免疫学方法                   | ELISA、IFA                     | 特定病毒抗原的定量检测                     |
| 透射电镜                     | 形态学直接观察                 | 确认颗粒形态，辅助鉴定                     |

**检测阴性结果的解读注意事项**

病毒检测阴性结果**不能完全证明无病毒污染存在**，须排除以下导致假阴性的情况：

1. **取样量不足：** 低污染水平可能因稀释效应导致漏检；
2. **病毒含量低于检测方法的 LOD：** 须验证检测方法的检测灵敏度满足目标要求；
3. **检测方法不适用于特定病毒：** 某些病毒对常规指示细胞不易感，需要使用特异性方法（如 PCR）；
4. **样品中存在抑制因素：** 培养基成分或产品本身可能抑制病毒复制或 PCR 扩增。

**外源病毒检出时的强制处置程序**

一旦中间产物检出外源病毒污染：

1. **立即停止进一步加工：** 污染中间产物不得继续用于后续工艺步骤；
2. **成品不得放行：** 同批次成品须被隔离，直至完成偏差调查；
3. **污染溯源调查：** 系统追查污染来源（细胞库、培养基、原材料、环境、设备等），形成完整的偏差报告；
4. **防控措施制定：** 根据污染来源制定有效的纠正和预防措施（CAPA），防止类似污染再次发生；
5. **监管机构通报（如适用）：** 若污染发生在商业化生产阶段，可能须按照当地法规要求向监管机构报告。

:::

## 除菌过滤细菌截留试验：挑战菌选择、最差条件设计与验证方案的关键要素

:::answer

**试验目的与核心逻辑**

细菌截留试验（Bacterial Retention Test）是除菌过滤验证的核心内容，通过在**最差工艺条件**下，以大量挑战微生物（通常 ≥10⁷ CFU/cm²）挑战受试过滤器，直接验证过滤器在实际使用条件下能否实现可靠除菌。

**标准挑战微生物：缺陷型假单胞菌（Brevundimonas diminuta）**

| 特性     | 参数                                     | 意义                                                      |
| -------- | ---------------------------------------- | --------------------------------------------------------- |
| 菌体尺寸 | 直径约 0.3～0.4 μm；长度 0.6～1.0 μm     | 是已知最小的水生细菌之一，对 0.22 μm 过滤器具有最高挑战性 |
| 形态要求 | 须为单一的、分散的细胞（非簇状）         | 聚集体会高估过滤器截留能力，须在验证前确认分散状态        |
| 活度确认 | 须在产品溶液条件下验证存活率（活度实验） | 若产品有抑菌性，须确认微生物在过滤过程中保持存活          |

**使用其他细菌替代的条件**

若缺陷型假单胞菌不能代表最差条件（如产品中存在能促进其生长但对其他菌不利的特殊成分），则须考虑采用其他细菌，但须满足：细菌足够细小（能够挑战 0.22 μm 过滤器），并能代表产品生产过程中可能存在的最小微生物。

**验证用滤膜的选择要求**

| 要求项目       | 具体规定                                                                           |
| -------------- | ---------------------------------------------------------------------------------- |
| 批次数量       | 须包括**多个批次（通常三个批次）**                                                 |
| 膜材质         | 须与实际生产中所用过滤器**材质完全相同**                                           |
| 关键批次       | 至少须有**一个批次为低起泡点（低规格）滤膜**——代表完整性测试接近规格下限的最差状态 |
| 起泡点接近限值 | 一般使用完整性值不高于标准限值 **110%** 的滤膜，模拟最差完整性状态                 |

**阳性对照的必要性**

- 须选用 **0.45 μm 孔径滤膜**作为每个试验的**阳性对照**；
- 阳性对照的作用：验证挑战微生物确实能够穿过 0.45 μm 膜（证明培养制备的细菌尺寸和浓度达到设计要求），才能有效挑战 0.22 μm 的受试滤膜；
- 三个批次的 0.22 μm 测试滤膜和 0.45 μm 对照滤膜须在**同一试验系统中并行在线进行**挑战试验，确保试验条件一致。

**过滤条件对截留结果的影响**

| 过滤参数      | 对截留结果的影响                   | 最差条件方向                     |
| ------------- | ---------------------------------- | -------------------------------- |
| 过滤温度      | 影响细菌活性和溶液流变性           | 须在验证中考察温度范围           |
| 过滤时间      | 长时间过滤可能导致细菌穿透滤膜增加 | 最长过滤时间（生产实际最大时间） |
| 过滤批量      | 高体积过滤可能降低截留效率         | 最大批量                         |
| 跨膜压差/流速 | 高压力/流速增加穿透风险            | 最大允许压差/最高流速            |

:::

## 除菌过滤器灭菌操作规范：在线蒸汽灭菌、离线灭菌与辐射灭菌的技术要点

:::answer

**灭菌的必要性**

除菌过滤器在使用前须经过**灭菌处理**，以确保过滤器本身不引入微生物污染，从而维持过滤后药液的无菌状态。根据安装方式和设备条件的不同，常用的灭菌方法有三种。

**方法一：在线蒸汽灭菌（SIP，Sterilization In Place）**

**适用场景：** 固定安装的不锈钢过滤系统，蒸汽可直接通过管路引入。

**关键操作要点：**

1. **排除非冷凝气体和冷凝水：** 灭菌开始前，须将滤器及管道中的空气（非冷凝气体）和冷凝水完全排出，防止其形成"冷点"（局部温度低于灭菌温度，导致灭菌不彻底）；
2. **最冷点温度监控：** 灭菌过程中，过滤系统内部**最冷点须达到设定灭菌温度**（如 121℃），须通过温度探针监控并记录；
3. **压差控制（关键安全要求）：** 整个灭菌过程中，滤芯上下游**压差须始终不超过滤芯在该特定温度下可承受的最大压差**（超压可能导致膜损坏，影响完整性）；
4. **降温操作：** 灭菌完成后，须引入**洁净的无菌空气或其他惰性气体**降温，降温时须**维持一定的正向压力**（防止污染气体倒流，保持系统无菌状态）。

**方法二：离线灭菌器灭菌（外部高压灭菌）**

**适用场景：** 可拆卸的过滤器组件，在高压灭菌器（Autoclave）中灭菌后转移安装。

**关键操作要点：**

- 通常采用**脉动真空灭菌（Pulsed Vacuum Sterilization）**方法，通过反复抽真空和充蒸汽确保蒸汽穿透滤器各处；
- 滤器的进口端和出口端（无论是芯+不锈钢套筒形式还是囊式滤器）**均须能透过蒸汽**，否则内部可能存在灭菌死角；
- **灭菌参数须遵循供应商提供的规范**（温度、时间、压力参数），防止温度过高导致：高分子聚合物材质性质不稳定（Tg 超出）；膜物理完整性受损；可提取物水平升高；
- 转移和安装过程须严格无菌操作，避免灭菌后再次污染。

**方法三：辐射灭菌（Gamma Irradiation）**

**适用场景：** 一次性使用系统（Single-Use Systems, SUS）中的过滤器、储液袋、软管等预灭菌耗材。

**关键注意事项：**

- 辐射灭菌的累积剂量效应（Cumulative Dose Effect）：一次性耗材通常**不应重复辐射灭菌**，因为多次辐射会导致材料降解（可提取物水平升高、强度下降）；
- 若同一一次性系统需要同时进行辐射灭菌和蒸汽灭菌，须通过专项验证证明两者叠加不会导致不可接受的材料变化或可提取物超标。

**罐体呼吸器的特殊灭菌方式**

对于生物反应器/储罐配套的呼吸器滤芯，可采用**反向进蒸汽**方式进行在线灭菌（蒸汽从罐体内侧反向穿过滤芯，从上游排出）：

- 此方式灵活，适合罐体配套灭菌；
- **须严格控制反向压差**（不超过滤芯在灭菌温度下的可耐受最大压差）；
- **建议使用带卡入式接口的滤芯**（不建议直插式），以确保反向灭菌时滤芯与壳体的密封性。

:::

## 病毒清除验证的必要性与法规依据：ICH Q5A 框架与国内外法规体系概览

:::answer

**为什么必须进行病毒清除验证**

**工业背景与合规必要性：**

CHO 细胞等哺乳动物细胞在培养过程中有可能发生**外源性病毒污染**（如环境引入、原材料携带）；CHO 细胞基因组本身整合有内源性逆转录病毒样颗粒（A 型颗粒），在特定条件下可以产生颗粒。

**各主要药监机构均要求：**

- 在**临床试验申报（IND）前**，须提供初步的病毒清除评估数据（证明工艺具有基本的清除能力）；
- 在**上市申请（BLA/NDA）阶段**，须提供完整的病毒清除验证报告，证明商业化生产工艺能够可靠清除潜在病毒污染，以确保临床患者用药安全。

**主要适用法规体系**

| 法规/指导原则                                                                   | 发布机构        | 适用范围                                                               |
| ------------------------------------------------------------------------------- | --------------- | ---------------------------------------------------------------------- |
| **ICH Q5A(R1)**（1999，修订中）                                                 | ICH             | 来自人或动物来源细胞系的生物技术产品的病毒安全性评价——**行业黄金标准** |
| 《中国药典》三部·生物制品病毒安全性控制（2020版）                               | NMPA/国家药典委 | 国内申报的核心法规依据                                                 |
| 生物组织提取制品和真核细胞表达制品的病毒安全性评价的技术审评一般原则（2005.12） | CDE             | 国内申报的技术审评指导                                                 |
| 血液制品去除/灭活病毒技术方法及验证指导原则（2002）                             | NMPA            | 专门针对血液制品                                                       |
| PDA Technical Report No.83（2019）                                              | PDA             | 生物制造中病毒污染的风险缓解、准备与应对（行业技术报告）               |
| FDA Process Validation Guidance（2011）                                         | FDA             | 工艺验证一般原则（含病毒清除验证相关要求）                             |

**ICH Q5A 对病毒清除研究的核心定义**

根据 ICH Q5A（第 7 页）的原文描述，病毒清除研究的目标是：

> "评估可认为在灭活/去除病毒方面有效的工艺步骤，并定量估算病毒减少的总体水平……这应通过在粗材料和/或不同分级中故意添加（"加标/Spiking"）大量病毒来实现……如果通过较少步骤证明了足够的清除效果，则没有必要评估或表征制造过程的每一步。"

**关键含义解读：**

1. **"加标（Spiking）"是核心技术手段：** 须主动向工艺进料中加入已知量的指示病毒，以定量评估各步骤的清除能力（而非被动等待检测）；
2. **"足够的清除效果"决定步骤选择：** 无需验证所有工艺步骤，只须选择对病毒安全性有实质贡献的步骤进行验证；
3. **"定量估算总体减少水平"：** 须以对数减少值（Log Reduction Value, LRV）定量报告每步清除能力和总清除能力。

:::

## 病毒清除工艺的方法分类与典型 LRV 水平：单抗工艺多重屏障的能力评估框架

:::answer

**病毒清除工艺的方法分类**

病毒去除/灭活方法可按作用机制分为以下几类，须根据目标病毒特性（有/无包膜、大/小颗粒）选择适宜的方法组合：

| 方法类别   | 具体方法                              | 有效性范围                        |
| ---------- | ------------------------------------- | --------------------------------- |
| **灭活法** | 低 pH 灭活                            | **有包膜病毒**（脂膜溶解）        |
|            | 热力消毒法（Pasteurization, 60℃/10h） | 部分有包膜和无包膜病毒            |
|            | 有机溶剂/去污剂（S/D）法              | **有包膜病毒**（脂膜溶解）        |
|            | 辐射消毒法（UV/Gamma）                | 广谱，但可能影响产品活性          |
|            | 化学消毒法（活化 Aziridines 等）      | 广谱                              |
| **去除法** | 纳滤（15～20 nm 孔径）                | **有包膜和无包膜病毒**（≥20 nm）  |
|            | 层析法（多种类型）                    | 部分有包膜病毒，依赖电荷/疏水差异 |
|            | 沉淀法                                | 有限                              |

**典型单抗工艺各步骤的病毒 LRV（参考值）**

| 工艺步骤               | 有包膜病毒（MuLV）LRV | 无包膜病毒（MVM/PPV）LRV | 备注                         |
| ---------------------- | --------------------- | ------------------------ | ---------------------------- |
| Protein A 亲和层析     | 2～4 log              | 0～1 log                 | 洗脱步骤中已有部分病毒清除   |
| **低 pH 病毒灭活**     | **≥4～6 log**         | ≈0（无效）               | 核心有包膜病毒灭活步骤       |
| CEX 阳离子层析         | 2～4 log              | 1～3 log                 | 依赖电荷差异的去除           |
| AEX 阴离子层析（流穿） | 2～4 log              | 2～4 log                 | DNA/内毒素去除同时有病毒吸附 |
| **纳滤（20 nm）**      | **≥6 log**            | **≥4 log**               | 核心无包膜病毒去除步骤       |
| **总计（典型）**       | **≥16～20 log**       | **≥5～8 log**            | 多重屏障体系的综合防护能力   |

**国际法规对 LRV 水平的参考要求**

根据 ICH Q5A 和《血液制品去除/灭活病毒技术方法及验证指导原则》，对生物制品病毒安全性的基本要求：

- 对**特定灭活步骤**（如低 pH 灭活）：单步 LRV 要求通常 ≥4 log；
- **累积去除率（整个工艺）：** 对相关病毒的总清除能力通常期望 ≥6 log（即 100 万倍减少）；
- 行业实践中，典型单抗工艺的总 LRV 通常远超 6 log（可达 15～20 log 以上），提供了充足的安全边际。

:::

## 病毒清除验证设计的关键决策要素：毒种选择、浓度设计与最差条件的四维框架

:::answer

**验证设计的总体原则**

病毒清除验证研究的核心目标是：在**最差工艺条件**下，通过**加标（Spiking）**实验定量评估工艺步骤对相关病毒的清除能力，为产品的病毒安全性提供定量数据支持。验证设计须覆盖以下四个关键决策维度。

**维度一：毒种选择（Virus Selection）**

根据 ICH Q5A、《生物组织提取制品和真核细胞表达制品病毒安全性评价技术审评一般原则》和《血液制品去除/灭活病毒技术方法及验证指导原则》，毒种选择须覆盖以下特性维度的病毒，以确保验证的覆盖全面性：

| 特性维度   | 覆盖要求                                                                           |
| ---------- | ---------------------------------------------------------------------------------- |
| 基因组类型 | 单链 RNA（ssRNA）、双链 RNA（dsRNA）、单链 DNA（ssDNA）、双链 DNA（dsDNA）均须覆盖 |
| 包膜特征   | 有包膜病毒 + 无包膜病毒                                                            |
| 抵抗力强弱 | 强抵抗力（如细小病毒）+ 弱抵抗力（如有包膜病毒）                                   |
| 颗粒大小   | 大颗粒（80～120 nm）+ 小颗粒（18～30 nm）                                          |

**不同申报阶段的毒种配置**

| 阶段     | 核心毒种                                                                                               | 说明                             |
| -------- | ------------------------------------------------------------------------------------------------------ | -------------------------------- |
| IND 阶段 | 逆转录病毒（MuLV）、细小病毒（MVM/PPV）、疱疹病毒（HSV 或 PRV）                                        | 覆盖关键类别，初步证明清除能力   |
| BLA 阶段 | 3～5 种，通常增加呼肠孤病毒（Reovirus 3）、小核糖核酸病毒（如脊髓灰质炎病毒 Polio）、多瘤病毒（BKV）等 | 全面覆盖，提供充分的安全性数据包 |

**维度二：毒种浓度设计（Spiking Concentration）**

- 毒种浓度（以 TCID₅₀/mL 或 pfu/mL 表示）须**足够高**，以确保即使经过一定程度的病毒清除后，仍有可检测量的病毒（防止清除后病毒浓度低于检测方法 LOD，导致无法计算实际 LRV）；
- 行业经验参考：毒种浓度须大于目标 LRV 至少 **1 个 log**（即目标 4 log 清除，则初始浓度须 ≥5 log TCID₅₀/mL）；
- 过高的毒种浓度可能超出实际真实污染情形，但目前监管机构仍要求尽可能高的初始浓度，以增加试验说服力。

**维度三：最差条件设计（Worst-Case Conditions）**

验证须在以下**最差工艺条件**下进行，以保守代表生产中可能出现的各种情形：

| 参数                     | 最差条件方向                 | 理由                         |
| ------------------------ | ---------------------------- | ---------------------------- |
| 病毒滴度（spiking 浓度） | 最高可行浓度                 | 最严苛挑战                   |
| 灭活时间                 | **最短时间**（低 pH 灭活）   | 代表生产中时间控制失误的情形 |
| 温度                     | 最低温度（有要求时）         | 低温可能降低化学灭活效率     |
| 上样蛋白浓度             | 最大值                       | 高蛋白可能影响灭活/去除效率  |
| 上样体积                 | 最大批量                     | 过大体积可能降低截留效率     |
| pH 值（低 pH 灭活）      | 最高接受 pH 值（最不利条件） | pH 越高灭活效率越低          |

**维度四：规模考量（Scale Considerations）**

**核心合规要求：** 病毒灭活/去除验证**不得在商业化规模厂房进行加标验证**（防止病毒污染生产环境）。须在专用的**生物安全实验室**（BSL-2 或以上）中，采用**小规模缩小模型**开展验证研究。

**因此须特别关注：**

- 缩小模型须经过充分验证（Qualification），证明其对商业化工艺的**代表性**（关键工艺参数相同或等效）；
- 对于小规模与商业化之间存在**不一致**的方面（如混合时间差异、气液比差异等），须有充分的科学讨论和分析；
- 病毒清除验证须在 **QA 监管条件下**进行，验证报告须经质量负责人（QP）审批，方可作为申报资料使用。

:::

## 病毒清除验证常用指示病毒体系：四维覆盖原则、各阶段毒种配置与选择依据

:::answer

**指示病毒（Model Virus）的概念**

在实际生产环境中，对每一种可能出现的污染病毒进行逐一验证，既不现实（时间/成本），也没有必要。科学界和监管机构提出了**指示病毒（Model Virus）**的概念：选择一组能够代表不同类别病毒特性的"模型病毒"，通过验证这些指示病毒的清除能力，推断对其所代表类别病毒的清除能力。

**四维覆盖原则（ICH Q5A 要求）**

有效的指示病毒体系须覆盖以下四个维度的对比组合：

| 维度     | 对比组合                                                                         |
| -------- | -------------------------------------------------------------------------------- |
| 核酸类型 | 单链 RNA（ssRNA）vs. 双链 RNA（dsRNA）vs. 单链 DNA（ssDNA）vs. 双链 DNA（dsDNA） |
| 包膜特征 | 有脂包膜（Enveloped）vs. 无包膜（Non-enveloped）                                 |
| 抵抗力   | 强抵抗力（Hard to inactivate）vs. 弱抵抗力（Easy to inactivate）                 |
| 颗粒大小 | 大颗粒（> 80 nm）vs. 小颗粒（< 30 nm）                                           |

**常用指示病毒及其选择理由**

| 指示病毒         | 缩写  | 类型                   | 代表意义                                                                | 主要验证步骤             |
| ---------------- | ----- | ---------------------- | ----------------------------------------------------------------------- | ------------------------ |
| 小鼠白血病病毒   | MuLV  | ssRNA，有包膜，~80 nm  | 代表内源性逆转录病毒（CHO 细胞相关）；有包膜，相对易清除                | 低 pH 灭活、层析步骤     |
| 小鼠细小病毒     | MVM   | ssDNA，无包膜，~20 nm  | **关键挑战性指示病毒**；代表最难灭活/去除的无包膜小型病毒（细小病毒类） | 纳滤（最关键）、层析步骤 |
| 猪细小病毒       | PPV   | ssDNA，无包膜，~20 nm  | 与 MVM 互补，代表细小病毒类；与胰酶来源相关                             | 纳滤                     |
| 呼肠孤病毒 3 型  | Reo-3 | dsRNA，无包膜，~70 nm  | 代表无包膜、中等大小病毒；已知能在 CHO 细胞中复制                       | 低 pH、层析、纳滤        |
| 伪狂犬病毒       | PRV   | dsDNA，有包膜，~150 nm | 代表有包膜大型 DNA 病毒（疱疹病毒类）                                   | 低 pH 灭活、层析步骤     |
| 牛病毒性腹泻病毒 | BVDV  | ssRNA，有包膜，~60 nm  | 代表来自牛血清的可能污染病毒（黄病毒科）                                | 低 pH 灭活               |
| 辛德比斯病毒     | SIN   | ssRNA，有包膜，~70 nm  | 代表有包膜 RNA 病毒；高感染性的指示病毒                                 | 低 pH 灭活、层析         |

**各申报阶段的毒种配置建议**

**IND 阶段（早期评估，重点覆盖关键风险）：**

- 必须覆盖：**MuLV**（逆转录病毒的代表性指示病毒）、**MVM 或 PPV**（细小病毒，最难清除类别）；
- 可选增加：**PRV 或 HSV**（疱疹病毒类）；
- 目的：证明工艺具有对关键病毒类别的基本清除能力，支持 IND 申报。

**BLA 阶段（全面验证，须提供完整的病毒安全性数据包）：**

- 通常须覆盖 **3～5 种**指示病毒，除 MuLV 和 MVM 外，还须增加：
  - **Reo-3**（无包膜，中等大小，代表已知可在生产细胞中复制的病毒）；
  - **BVDV 或 SIN**（有包膜 RNA 病毒，与牛血清来源风险相关）；
  - 视产品具体情况，可能还须增加其他特定指示病毒。

**常用指示病毒数据参考**

| 指示病毒 | 典型 LRV（低 pH 灭活）    | 典型 LRV（纳滤 20 nm） | 难度分级             |
| -------- | ------------------------- | ---------------------- | -------------------- |
| MuLV     | ≥4～6 log（灵敏，易清除） | ≥6 log                 | 较易                 |
| MVM      | ≈0（低 pH 无效）          | ≥4 log                 | **最难**（验证重点） |
| Reo-3    | ≥1～2 log                 | ≥3～4 log              | 中等                 |
| PRV      | ≥4 log                    | ≥5 log                 | 较易                 |
| BVDV     | ≥4 log                    | ≥5 log                 | 较易                 |

:::
