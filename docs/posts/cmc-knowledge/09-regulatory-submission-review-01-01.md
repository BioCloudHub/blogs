## IND 申报中表达载体构建的资料要求：信息完整性与基因操作安全性评估

:::answer

### 申报要求的核心逻辑

表达载体是生产用细胞株的基因工程基础，其构建信息直接关系到产品的遗传稳定性和安全性评估，因此须在 IND 申报 CMC 模块中提供完整的载体构建资料。

### 必须提供的信息

**① 基本信息**

| 信息类别           | 具体内容                                                             |
| ------------------ | -------------------------------------------------------------------- |
| **载体名称与来源** | 载体商业名称或内部编号；来源机构（商业购买或自行构建）               |
| **载体结构**       | 完整的载体图谱（包括所有功能元件的位置和方向）                       |
| **遗传特性**       | 复制起始位点、启动子、增强子、选择标记基因、多克隆位点等关键元件描述 |

**② 重组载体构建资料**

- **克隆筛选方法：** 阳性克隆的筛选策略（抗生素筛选、酶切鉴定等）。
- **酶切鉴定结果：** 限制性内切酶酶切图谱，证明目的基因正确插入预期位置。
- **核苷酸序列信息：** 插入基因完整序列 + 表达载体两侧端控制区的核苷酸序列。
- **测序结果比对：** 提供测序彩图，并与设计（理论）序列逐一比较，说明测序结果是否符合设计，明确标注任何差异及其影响评估。

**③ 辅助基因的安全性评估（如适用）**

若对表达载体进行了基因操作并引入了辅助基因（如转移酶基因、病毒基因片段等），须专项评估以下内容：

| 评估维度               | 具体要求                                               |
| ---------------------- | ------------------------------------------------------ |
| **表达调控状态**       | 辅助基因是否处于活性表达状态；是否受可控启动子调控     |
| **表达产物残留量**     | 在终产品中辅助基因编码蛋白的残留水平                   |
| **对制品安全性的影响** | 残留辅助基因产物是否具有免疫原性、毒性或其他安全性风险 |
| **对制品有效性的影响** | 辅助基因表达是否干扰目的蛋白的活性或稳定性             |

> **实践建议：** 在载体设计阶段即应考虑监管要求，避免引入不必要的辅助序列；若必须引入，须在研发早期即建立残留量检测方法，为申报积累数据。

:::

## 细胞库标签命名与台账管理：药典要求与可追溯性实践

:::answer

### 法规依据与管理目的

细胞库的标签和台账管理是 GMP 合规的基础要求，目的是确保每支细胞库安瓿的**完整追溯性（Traceability）**——从任何一支安瓿，须能追溯到其生产批次、代次、检定结果和储存历史。

### 台账管理要求

每种细胞库（MCB、WCB、研发细胞库）须**分别建立独立台账**，台账须详细记录以下信息：

| 台账记录项目 | 说明                                         |
| ------------ | -------------------------------------------- |
| **放置位置** | 液氮罐编号；罐内具体位置（层/格/位）         |
| **容器编号** | 每支安瓿的唯一编号                           |
| **分装数量** | 本批次总冻存安瓿数量                         |
| **冻存日期** | 细胞冻存的操作日期                           |
| **取用记录** | 每次取用的日期、取用人员、取用数量、剩余数量 |
| **检定状态** | 对应批次的检定结果和日期（合格/待检/不合格） |

### 每支细胞安瓿的标签要求

每支细胞库安瓿须粘贴或印刻包含以下信息的标签，确保信息与台账完全对应：

| 标签信息                   | 内容要求                                   |
| -------------------------- | ------------------------------------------ |
| **细胞系/株名称**          | 标准化的细胞株名称（不允许使用非标准缩写） |
| **代次（Passage Number）** | 精确记录冻存时的传代次数                   |
| **批号（Lot Number）**     | 细胞库生产批次的唯一标识符                 |
| **编号**                   | 安瓿在本批次内的序号                       |
| **冻存日期**               | 操作日期（YYYY-MM-DD 格式）                |
| **贮存容器编号**           | 所在液氮罐的编号                           |

### 细胞库管理的额外最佳实践

- **异地备份：** MCB 须至少在两个物理隔离的地点（不同建筑或不同城市）分开储存，防止单一地点事故（火灾、液氮泄漏）导致细胞株永久丢失。
- **台账电子化与纸质双备份：** 电子台账便于检索和趋势分析；纸质备份防止电子系统故障。
- **定期盘点：** 至少每年对细胞库安瓿数量进行实物盘点，与台账核对，确保库存准确。

:::

## 细胞冻存活率与复苏活率的药典规定及工艺控制要点

:::answer

### 药典规定的核心数值

| 检查节点           | 活力要求  | 检查目的                                                       |
| ------------------ | --------- | -------------------------------------------------------------- |
| **冻存前细胞活力** | **≥ 90%** | 确保起始细胞质量良好，排除因冻存前已大量死亡导致复苏后活力不足 |
| **复苏后细胞活力** | **≥ 80%** | 证明冻存和复苏过程不对细胞造成过度损伤，保障生产可靠性         |

### 为什么活力要求有 10% 的容差

冻融过程本身对细胞造成一定的可逆和不可逆损伤（冰晶形成、渗透压波动、冷冻保护剂毒性等），合理的容差反映了这一生物学现实，同时设定了可接受的工艺损失下限。

### 确保细胞活力达标的关键工艺控制

**冻存前质量控制：**

| 控制参数           | 要求                                                | 意义                                                                     |
| ------------------ | --------------------------------------------------- | ------------------------------------------------------------------------ |
| **冻存前培养状态** | 细胞处于对数生长期（Exponential Phase），活力 ≥ 90% | 对数期细胞代谢最旺盛，冻存后复苏率最高                                   |
| **冻存浓度**       | 通常 5×10⁶～1×10⁷ 细胞/mL                           | 浓度过高易造成冻存过程中局部温度不均匀                                   |
| **冷冻保护剂**     | 10% DMSO（最常用）+ 血清或无血清替代物              | DMSO 防止细胞内冰晶形成；须现配现用（DMSO 有细胞毒性，接触时间不宜过长） |
| **降温速率**       | −1℃/min（使用程序降温仪）                           | 过快：冰晶损伤细胞膜；过慢：溶质效应（细胞脱水皱缩）                     |

**复苏操作控制：**

- **快速解冻：** 37℃ 水浴迅速解冻（约 1～2 min），防止缓慢解冻过程中冰晶重新形成造成损伤。
- **快速稀释 DMSO：** 复苏后立即逐滴加入预热培养基稀释，降低 DMSO 浓度（> 1% DMSO 对细胞有毒性）。
- **代表性样品复苏验证：** 须取**可代表冻存全过程**（即从第一批冻存到最后一批冻存的代表性时间段）的冻存管进行复苏验证，而非仅取质量最好的样品。

### 活力测定方法

- **台盼蓝排斥法（Trypan Blue Exclusion）：** 最常用；活细胞膜完整，不摄取台盼蓝（透明）；死细胞膜破损，被染成蓝色。
- **自动细胞计数仪（如 Vi-CELL、Cedex）：** 通过图像分析自动计算活力，减少人为误差，适合 GMP 生产中的常规检测。

:::

## 国内外 IND 申报中病毒去除验证的关键差异：工艺步骤、批次要求与重复性标准

:::answer

### 病毒清除验证的两大差异维度

**差异一：验证工艺步骤的数量**

| 申报机构             | 最低病毒清除验证步骤要求                                                           | 说明                                                                      |
| -------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **NMPA（中国 IND）** | 通常选择 **低 pH 孵育 + 膜过滤（纳滤）** 两个专属步骤                              | 国内指导原则暂无硬性规定须包含层析步骤；但建议提供完整的正交清除体系      |
| **FDA（美国 IND）**  | 除低 pH 和膜过滤外，**还需包含层析工艺（亲和层析 + 离子交换层析）** 的病毒去除验证 | ICH Q5A 推荐多步骤正交体系；FDA 期望在 IND 阶段即提供更完整的工艺清除证据 |

**差异二：验证批次数量与重复性要求**

| 申报机构                | 批次数量要求                                    | 重复性研究要求                                                 |
| ----------------------- | ----------------------------------------------- | -------------------------------------------------------------- |
| **NMPA**                | 通常需要 **3 个批次**                           | 指导原则无硬性规定，但 3 批次数据可提供基本重复性证明          |
| **FDA（ICH Q5A 要求）** | 明确要求 **至少两次独立研究**证实清除的可重复性 | 通常操作：同一批样品**重复两次独立运行**（非两个不同样品批次） |

> **注意区别：** NMPA 要求的是"3 个样品批次"（通常指 3 批不同的收获液/中间体），而 FDA 要求的是"2 次独立的研究运行"（可以是同一批样品重复操作）——两者对"批次"的定义不同，须仔细区分。

### 层析法病毒去除的原理

层析法通过利用病毒颗粒与目标蛋白在**固定相亲和力或相互作用强度**上的差异，实现病毒与样品的分离：

| 层析模式                        | 主要去除机制                                             | 典型 LRV               |
| ------------------------------- | -------------------------------------------------------- | ---------------------- |
| **Protein A 亲和层析**          | 非特异性吸附（病毒被截留于洗涤步骤）                     | 1～4 log₁₀             |
| **阳离子交换层析（CEX）**       | 电荷分布差异（带正电抗体结合，部分病毒不结合或结合不同） | 1～3 log₁₀             |
| **阴离子交换层析（AEX，流穿）** | 静电吸附（中性 pH 下病毒带负电，被填料吸附）             | **2～5 log₁₀（较高）** |

### 双报策略建议

- 采用**以 NMPA 要求为最高基准**的策略组织病毒清除研究（3 批次 + 完整步骤），可自然满足 FDA 要求，避免后期补充验证。
- 缩小模型须在工艺验证前完成确认（SDM Qualification），所有病毒验证实验须在具备 BSL-2 资质的实验室进行。

:::

## UPB 与 EOPC 检测批次的中美差异：检测时机、批次要求与 EOPC 与毒理批的关联

:::answer

### 基本概念回顾

| 缩写     | 全称                                    | 定义                                                                 |
| -------- | --------------------------------------- | -------------------------------------------------------------------- |
| **UPB**  | Unprocessed Bulk（未纯化收获液）        | 固液分离后、进入纯化步骤前的细胞培养收获液                           |
| **EOPC** | End of Production Cells（生产终末细胞） | 生产过程结束时代表最高传代代次的细胞，用于遗传稳定性和病毒安全性评估 |

### 中美申报要求对比

| 检测项目          | NMPA（中国）IND 阶段                          | FDA IND 阶段                                                  |
| ----------------- | --------------------------------------------- | ------------------------------------------------------------- |
| **UPB 检测批次**  | **3 批次**（含 non-GMP 批次和 GMP 批次均可）  | **1 个 GMP 批次**                                             |
| **EOPC 检测时机** | IND 阶段要求，**1 批次 EOPC，最好为毒理批次** | IND 阶段**不要求**；须在**临床 3 期**开展；BLA 申报前必须完成 |
| **检测内容**      | 遗传稳定性（序列、拷贝数）+ 病毒安全性        | 同左（但时间节点不同）                                        |

### EOPC 与毒理批次的关联：为什么推荐毒理批次作为 EOPC？

- **毒理批次（Toxicology Batch）** 是用于开展 GLP 毒理学研究的批次，其工艺代表性是 IND 申报的核心要求。
- 若毒理批次同时作为 EOPC 检定批次，可实现"一批两用"——既满足 NMPA 对 EOPC 检定的要求，又为毒理批次的工艺代表性提供细胞遗传稳定性背书。
- 从逻辑上，毒理批次的生产细胞代次通常接近或达到生产最高代次上限，天然符合 EOPC 的定义。

### EOPC 检测的核心项目

| 检测类别       | 主要项目                                               |
| -------------- | ------------------------------------------------------ |
| **遗传稳定性** | 目的基因序列（无突变）；拷贝数稳定性                   |
| **细胞生物学** | 核型分析（染色体数目和形态）                           |
| **病毒安全性** | 体外细胞接种法；逆转录病毒 TEM + RT 活性；必要时支原体 |

## IND 申报质量标准的中美差异：完整性要求、报告格式与放行范围设定

:::answer

### 核心差异总览

| 差异维度           | NMPA（中国）IND 要求                   | FDA IND 要求                                               |
| ------------------ | -------------------------------------- | ---------------------------------------------------------- |
| **质量标准完整性** | **须提供完整质量标准**，不可缺项       | 提供质量标准，但**允许部分项目仅报告结果**（无须设定限度） |
| **电荷异质性**     | **须纳入质量标准**，设定可接受范围     | 可"仅报告结果"（Report Result），无须设定合格/不合格限度   |
| **糖型分析**       | **须纳入质量标准**                     | 可"仅报告结果"                                             |
| **放行范围**       | IND 阶段相对宽松；须有数据支撑说明依据 | 允许**较宽的放行范围**（宽松接受标准）                     |
| **安全性相关项目** | 须有严格限度                           | 重点关注；**须有明确限度**                                 |

### NMPA 完整质量标准的意义

NMPA 要求 IND 阶段即提供完整质量标准（含电荷异质性、糖型等），其背后逻辑是：

- **提高申报门槛**：确保申请人对产品质量属性有基本认知，降低临床试验中出现质量问题的风险。
- **建立基线数据**：早期设定的质量标准是后期上市申报（BLA）时缩紧限度的数据基础。
- **体现对患者保护的监管理念**：即使在早期临床阶段，也要对产品质量有约束性承诺。

### FDA 的"报告结果"理念

FDA 对于早期阶段的部分质量属性（如糖型、电荷变体分布）允许仅"报告结果"（Report Result Only），不设定具体合格/不合格限度，原因是：

- 早期批次数量少（1～2 批），统计基础不足以科学设定有意义的数值限度。
- 电荷异质性和糖型等属性与安全性的直接关联尚在研究中，过早设定严格限度可能限制工艺改进空间。
- 数据积累到临床 3 期和上市申报时，再基于充分的多批次数据建立合理的质量标准。

### 各开发阶段质量标准的演化建议

| 开发阶段              | NMPA 标准策略                          | FDA 标准策略                         |
| --------------------- | -------------------------------------- | ------------------------------------ |
| **IND（临床 I 期）**  | 完整标准，宽松限度（基于 1～2 批数据） | 核心安全性项目有限度；其余可报告结果 |
| **临床 II 期**        | 收紧部分关键 CQA 限度                  | 开始建立更多项目的数值限度           |
| **临床 III 期 / BLA** | 基于多批次数据设定最终商业化标准       | 全面标准，基于 PPQ 批次数据设定限度  |

## FDA 与药物发起人会议体系：四类会议的目的、时机与核心议题

:::answer

### FDA 会议体系概述

FDA 与药物发起人之间的正式沟通会议按**药物开发阶段**设置了四种主要类型，每种会议都有其特定目的和最佳召开时机：

```
药物研发时间轴
  │
  IND 前 ─── Pre-IND 会议
  │             目的：审查动物试验数据；就 I 期设计达成一致
  │
  I 期结束 ─── End-of-Phase 1 会议（EOP1）
  │             目的：审评 II 期对照临床试验计划
  │
  II 期结束 ─── End-of-Phase 2 会议（EOP2）
  │             目的：确认 III 期设计安全性和充分性；儿科计划评估
  │
  III 期结束 ─── Pre-NDA/Pre-BLA 会议
                目的：解决上市申请中的未决重大问题
```

### 四类会议详解

**① Pre-IND 会议（IND 前协商会议）**

- **目的：** 审查首次进行人体试验所需动物研究数据，就 I 期临床方案达成一致。
- **关键议题：** 动物毒理数据是否支持拟定的起始剂量；CMC 信息是否足以支持 I 期；特殊监管通道（突破性疗法、快速通道、孤儿药）的申请策略。
- **时限：** 60 天（从 FDA 收到会议请求起算）。

**② I 期结束会议（End-of-Phase 1 Meeting, EOP1）**

- **目的：** 在 I 期数据基础上审评 II 期对照临床试验计划，包括剂量设计、试验终点、患者群体等关键参数。
- **CMC 关注点：** I 期期间工艺变更的影响评估；II 期临床批次的生产计划。

**③ II 期结束会议（End-of-Phase 2 Meeting, EOP2）——最重要的里程碑会议**

- **目的：** 确认 III 期临床试验设计的安全性和充分性；评估现有研究和计划中是否充分评估儿科人群（PREA 要求）；评估支持上市申请所需的其他补充信息。
- **CMC 关注点：** 商业化生产工艺是否与临床批次一致；工艺验证（PPQ）计划；稳定性数据策略；比较性研究的充分性。

> **EOP2 会议是最重要的里程碑**：此后进入 III 期，工艺重大变更的代价极高，且须重新建立临床可比性。因此，须在 EOP2 前完成工艺锁定（Process Freeze）。

**④ Pre-NDA/Pre-BLA 会议（上市申请前会议）**

- **目的：** 发现任何影响上市申请成功的未解决重大问题；确认提交格式和内容；讨论是否需要审评会议（Advisory Committee）。
- **CMC 关注点：** 确认申报文件的完整性；讨论工艺验证批次数据的充分性；稳定性数据和有效期支持。

:::

## Pre-IND 会议的适用场景、会议内容与申请条件

:::answer

### 什么是 Pre-IND 会议

Pre-IND 会议（Pre-Investigational New Drug Meeting）是指**在发起人递交 IND 申请前**，自愿向 FDA 递交会议申请，就关键科学和法规问题获得 FDA 早期指导意见的正式沟通渠道。

- **会议形式：** 电话会议或面对面会议（视议题复杂性而定）。
- **会议时限：** 从 FDA 收到会议请求起算 **60 天**内召开。
- **自愿性：** 并非强制要求，由发起人自行决定是否申请。

### 须召开 Pre-IND 会议的典型场景

FDA 在以下情况下**强烈建议**发起人召开 Pre-IND 会议：

| 情形                                                   | 原因                                  |
| ------------------------------------------------------ | ------------------------------------- |
| 药物预期用于治疗**严重或危及生命**的疾病               | 临床紧迫性高，须尽早确认开发路径      |
| 药物存在**新适应症**（区别于已批准用途）               | 监管要求可能与历史先例不同            |
| 没有适用的**最新监管指导文件**                         | 缺乏现成的法规参考，须直接与 FDA 讨论 |
| 发起人对**药物研发缺乏经验或存在疑问**                 | 早期获得专业指导，避免资源浪费        |
| 存在**重要的药理学或毒理学问题**                       | 安全性信号须在进入人体前得到 FDA 认可 |
| 药物是<strong>新分子实体（NME）</strong>或全新作用机制 | 无历史先例参考，监管路径须提前确认    |
| 希望申请**突破性疗法、快速通道或孤儿药**认定           | 申请条件和策略须与 FDA 提前确认       |

> **建议原则：** "寻求科学建议永远不会太早"——FDA 和欧洲监管机构的明确立场是，越早进行监管咨询，越有利于降低研发风险。

### Pre-IND 会议的主要议题

**科学议题：**

- 已完成动物试验获得的数据（剂量、毒性、NOAEL）是否足以支持拟定的临床 I 期方案。
- I 期临床试验的设计（样本量、研究设计、临床终点、统计方法、安全性监测）。
- 辅料的安全性（是否已有人体使用数据支持）。

**CMC 议题：**

- 现有 CMC 信息是否足以支持临床试验计划：
  - 原液和成品的生产过程及控制过程的完整性。
  - 药物检验和规格（是否达到 IND 申报标准）。
  - 确保临床试验中药物稳定性所需的数据（是否有足够的稳定性支持数据）。
  - 辅料与 API 的化学相容性。

**监管策略议题：**

- 突破性疗法（Breakthrough Therapy）申请的资质评估。
- 快速通道（Fast Track）指定的申请策略。
- 孤儿药（Orphan Drug）认定的可行性。
- 儿科研究计划（Pediatric Study Plan, PSP）的初步讨论。

:::

## Pre-IND 会议的申请流程、书面请求要素与会议执行规范

:::answer

### 标准申请与会议流程

```
Step 1：制作并递交书面请求（Written Meeting Request）
  │     包含产品信息、问题列表、参与者名单等（见下表）
  │
  Step 2：FDA 收到请求后 21 天内回应（同意/拒绝通知）
  │     同意通知中包含指定的法规计划经理（Regulatory Project Manager, RPM）
  │
  Step 3：发起人递交简要文件（Briefing Document）
  │     须在预期会议日期前至少 1 个月递交
  │
  Step 4：FDA 内部准备（收到简要文件后）
  │     FDA 召开内部讨论会；形成初步解答；准备初步会议反馈
  │
  Step 5：初步会议反馈（Preliminary Meeting Comments）发出
  │     约在预期会议前 2～3 天由 FDA 发送给发起人
  │     ← 发起人应仔细阅读，提取未解决的 1～2 个关键问题，在会议上集中讨论
  │
  Step 6：会议召开
  │     FDA 介绍议程 → 集中讨论未解决问题 → 会议结束前总结要点/决定/行动项
  │
  Step 7：正式会议记录（Official Meeting Minutes）
        FDA 在会议结束后 30 天内寄送正式最终会议记录
```

### 书面请求（Written Meeting Request）的必备内容

| 要素                     | 具体内容要求                                                                  |
| ------------------------ | ----------------------------------------------------------------------------- |
| **产品基本信息**         | 产品名称、申请编号（如有）、药物化学名称及结构                                |
| **研发背景**             | 预期适应症或产品的研发环境（Brief Development Context）                       |
| **会议类型**             | 明确标注为"Pre-IND 会议"申请                                                  |
| **会议目的声明**         | 简要声明会议目的及目标（1～2 段）                                             |
| **会议议程**             | 按讨论顺序列出议题                                                            |
| **问题列表（最重要！）** | 按学科分类（CMC、药理毒理、临床）的具体问题列表；每个问题须提供背景和提问目的 |
| **参与者名单**           | 发起人方的参会人员（姓名、职位、所属机构）                                    |
| **会议时间偏好**         | 3 个可行的会议时间窗口（便于 FDA 协调）                                       |
| **会议形式**             | 电话/面对面（视复杂性选择）                                                   |
| **简要文件递交日期**     | 预计提交 Briefing Document 的日期                                             |

### 问题列表的撰写要点

**问题列表（Questions List）是书面请求中最重要的内容**，须遵循以下原则：

- **严格按学科分类：** CMC 问题、药理毒理问题、临床问题分开列示，便于 FDA 分配给相应的审评专家。
- **每个问题须包含：** ①问题背景（现有数据摘要）；②具体问题（是/否型或开放型）；③提问目的（希望 FDA 提供什么层面的指导）。
- **问题数量控制：** 通常 5～10 个实质性问题；过多问题会降低每个问题的讨论深度。

### 初步会议反馈的战略价值

初步会议反馈是极具价值的 FDA 书面意见，发起人须深入研究：

- FDA 的初步反馈通常可以解决书面请求中大多数问题，因此**会议时间应聚焦于初步反馈中尚未解决的 1～2 个最关键问题**，而非重新讨论已有明确答复的问题。
- 初步反馈具有一定的约束力（虽然非正式），可作为后续开发决策的参考依据。

:::

## 抗体药物质量分析与质量标准的核心内容框架

:::answer

### 质量标准的层级结构

抗体类生物制品须针对以下三个层级分别制定相应的质量标准：

```
原料药（DS, Drug Substance）原液
  └── 须有独立的原液质量标准

半成品（Drug Product Bulk / In-process Intermediate）
  └── 视工艺需要，部分中间体须设定接收标准

成品（DP, Drug Product）
  └── 须有完整的成品放行质量标准
```

### 质量标准的五大属性类别

**① 理化性质（Physicochemical Properties）**

| 检测项目  | 代表性方法           | 信息维度               |
| --------- | -------------------- | ---------------------- |
| 外观/颜色 | 目视检查；分光光度计 | 物理状态、颜色、澄清度 |
| pH        | pH 计                | 制剂缓冲体系完整性     |
| 渗透压    | 冰点降低法           | 注射耐受性             |
| 分子量    | SDS-PAGE；质谱       | 分子完整性一级验证     |
| 肽图      | LC-MS/MS             | 一级序列确认           |

**② 生物活性（Biological Activity / Potency）**

| 方法类型 | 代表性方法                     | 作用机制覆盖  |
| -------- | ------------------------------ | ------------- |
| 结合活性 | ELISA；SPR（Biacore）          | 抗原-抗体结合 |
| 细胞活性 | 报告基因法；ADCC RGA；增殖抑制 | 依产品 MOA    |

**③ 含量（Quantity）**

- 蛋白含量（A280 UV 法，基于消光系数）；须明确消光系数的测定方法和依据。

**④ 纯度与杂质（Purity & Impurities）**

| 检测维度     | 方法                                 | 覆盖内容                     |
| ------------ | ------------------------------------ | ---------------------------- |
| 大小异质性   | SEC-HPLC                             | 聚集体（HMWS）、片段（LMWS） |
| 电荷异质性   | icIEF、CEX-HPLC                      | 酸性变体、主峰、碱性变体     |
| 分子完整性   | CE-SDS（R/NR）                       | 轻重链完整性；非共价聚集     |
| 工艺相关杂质 | ELISA（HCP、Protein A）；qPCR（HCD） | 宿主细胞残留物               |

**⑤ 常规检查（General Quality Tests）**

- 安全性：细菌内毒素（LAL 法）、无菌检查、异常毒性。
- 外观：可见异物、不溶性微粒。
- 包装完整性：容器密封完整性（CCI）。

### 多批次检测记录的重要性

- 质量标准中的数值范围须基于**多批次实测数据的统计分析**（均值 ± nσ 或工艺能力分析），而非主观设定。
- IND 阶段批次数量有限时，可采用宽松限度并说明依据；随临床推进不断收紧。

:::

## 聚集体含量（SEC 单体纯度）在各临床阶段的接受标准演化策略

:::answer

### 核心问题：为什么聚集体须分阶段收紧

聚集体（Aggregates，HMWS）是抗体药物最重要的产品相关杂质之一，与免疫原性风险直接相关，但在研发早期批次数量有限时，无法基于充分统计数据设定精确限度。

### 各临床阶段的典型接受标准

| 开发阶段                      | 典型聚集体限度（HMWS）        | 说明                                                                              |
| ----------------------------- | ----------------------------- | --------------------------------------------------------------------------------- |
| **临床 I 期（IND 阶段）**     | **< 10%**（以安全保障为导向） | 批次数少（1～2 批），统计基础不足；宽松限度以确保不因限度过严导致临床批次无法放行 |
| **临床 II 期**                | **< 5%**                      | 批次积累增加，可适当收紧；工艺也在优化中                                          |
| **临床 III 期 / 上市（BLA）** | **2%～3%**（基于多批次统计）  | 商业化工艺稳定；须基于 PPQ 批次数据科学设定                                       |

### 限度设定的科学依据

- **以工艺能力（Cpk）为基础：** 商业化阶段限度 = 均值 + 3σ（以批次数据集计算），确保正常生产条件下规格可持续满足。
- **结合免疫原性风险评估：** 若 CDR 区域外的聚集体对活性无影响，可相对宽松；若聚集体与活性降低相关，须更严格。
- **参考行业先例和上市产品：** 已上市同类单抗产品的聚集体限度（多在 2%～5% 范围）可作为科学参考，但须有自身数据支撑。

### 注意：不同方法检测结果的差异

- SEC-HPLC 测定的聚集体含量受流动相条件影响；可逆聚集体（稀释后可解离）会导致 SEC 低估真实聚集体含量。
- 须结合 AUC（分析超速离心）或 DLS（动态光散射）进行辅助表征，尤其对于高浓度制品。

:::

## 与监管机构合作和沟通的策略框架：早期咨询的价值与多学科议题覆盖

:::answer

### 监管沟通的战略意义

与监管机构的紧密合作是成功研发药物的关键要素，**将监管建议提前纳入试验计划**可以：

- 降低因不符合监管要求而导致临床批次无效的风险。
- 减少后期代价高昂的补充研究需求。
- 提高首次审评通过率，加快产品上市速度。

### "越早咨询越好"的监管理念

欧美监管机构（FDA、EMA）的明确立场：**"寻求科学建议永远不会太早（It is never too early to seek scientific advice）"**。

这一理念的实践含义：

| 早期咨询的典型问题类型 | 举例                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| **产品质量（CMC）**    | 创新分子的质量属性如何定义；生产工艺的可接受范围；生物类似药的相似性评价标准 |
| **研究设计**           | 是否接受新颖的临床研究设计（适应性设计、篮式研究）                           |
| **PK/PD 建模**         | PBPK 模型是否可用于支持剂量选择                                              |
| **生物标志物**         | 特定生物标志物是否被接受作为临床终点的替代                                   |
| **终点选择**           | 硬终点（总生存期）vs. 替代终点（PFS、ORR）的监管接受度                       |

### 中国 CDE 的沟通机制

中国药品审评中心（CDE）提供多种发起人-监管机构沟通渠道：

| 沟通类型                              | 适用场景                         | 特点                          |
| ------------------------------------- | -------------------------------- | ----------------------------- |
| **一般技术问题咨询（沟通交流 A 类）** | 关键核心问题（如重大安全性问题） | 优先，45 天内完成             |
| **沟通交流 B 类**                     | IND/NDA/BLA 过程中的重要技术问题 | 60 天内完成（面谈或书面答复） |
| **沟通交流 C 类**                     | 一般性技术问题                   | 75 天内书面答复               |

> **建议：** 对于首次国内申报的创新药物，IND 申报前提交 B 类沟通交流请求（就关键 CMC 技术问题获得 CDE 反馈）是降低申报风险的有效策略，类似于 FDA 的 Pre-IND 会议机制。

:::

## IND 申报 18 个月 Timeline 的规划逻辑：关键路径控制与风险平衡策略

:::answer

### 18 个月 Timeline 的合理性基础

18 个月是业界对从 DNA（目的基因获取）到 IND 申报完成（获得许可开展临床试验）这一全过程的**典型工期估算**，适用于常规单抗类生物药（非生物类似药）的标准开发路径。

### 关键路径上的必经节点（串行活动）

以下活动须**顺序完成**，构成整个 Timeline 的关键路径（Critical Path）：

```
Step 1：目的基因获取 + 表达载体构建（DNA 合成，通常 2～4 周）
  ↓
Step 2：稳定转染 + Stable Pool 建立（6～8 周）
  ↓
Step 3：单克隆筛选（法规要求：生产用细胞株必须为单克隆细胞株）
        ← 这是最关键的法规约束节点，必须完成后才能推进工艺开发
  ↓
Step 4：细胞株筛选 + Fed-batch 工艺评估（8～12 周）
  ↓
Step 5：工艺优化 + 中试规模生产（MCB/WCB 建立）
  ↓
Step 6：毒理批次 GMP 生产
  ↓
Step 7：动物毒理学研究（GLP 毒理，通常 12～26 周）
  ↓
Step 8：CMC 资料整理 + IND 申请文件撰写
  ↓
IND 申报
```

> **法规硬约束：** 法规明确要求生产用细胞株**必须是单克隆细胞株**，因此单克隆筛选完成是推进后续所有活动的前提条件。在实际操作中，**不可采用 Stable Pool（稳定混合池）作为生产细胞株**用于临床批次生产。

### 如何评估缩短 Timeline 的可行性

将 18 个月压缩至 15 个月或 12 个月须从**时间-风险-技术**三角关系进行综合评估：

| 潜在加速措施                                        | 时间节省 | 风险代价                                               | 是否值得                     |
| --------------------------------------------------- | -------- | ------------------------------------------------------ | ---------------------------- |
| **跳过 Stable Pool Fed-batch 评估，直接单克隆铺板** | 2～4 周  | 筛选到符合要求的克隆概率降低；后期克隆失败风险升高     | 视项目竞争压力而定           |
| **CMC 研究与毒理同步启动（部分并行）**              | 4～6 周  | 毒理批次工艺可能与最终选定工艺不同，须评估工艺变更影响 | 常见策略，须有严格的工艺控制 |
| **压缩稳定性研究时间点**（仅收集 3 月数据支持 IND） | 3 个月   | IND 阶段稳定性数据有限，后期须追赶；通常可接受         | 普遍采用                     |
| **同时进行工艺开发和方法开发**（而非顺序）          | 4～8 周  | 方法可能须随工艺优化而调整，导致重复工作               | 高效但须协调管理             |

### 关键管理原则

- **识别关键路径 vs. 非关键路径活动：** 仅加速关键路径上的活动才能真正缩短总 Timeline；非关键路径上的加速没有意义。
- **风险评估先于时间压缩：** 任何"快捷方式"都须评估对后期项目成功率的影响，时间节省的价值须大于潜在的失败风险成本。

:::

## 已建株细胞系的来源证明资料要求：历史追溯与传代记录的完整性

:::answer

### 为什么须提供细胞来源证明

已建株的细胞系（如从 ATCC、DSMZ 等细胞库获取的细胞株，或从其他机构转让获取的细胞）在用于生物药生产前，须提供完整的**来源追溯文件（Provenance Documentation）**，以：

- 证明细胞株的遗传身份（确认为所称的细胞系）。
- 建立监管要求的**可追溯性（Traceability）** 记录链。
- 评估历史传代过程中可能引入的污染或遗传变异风险。

### 须从来源机构获取的信息

来源证明须从能提供**初始细胞历史及溯源性书面证明材料的机构**获得（如 ATCC 提供的产品规格书和来源证明），并提供该细胞在该机构的**详细传代记录**，包括：

| 记录内容           | 具体要求                                                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **原始来源**       | 细胞株的最初建立时间、来源物种和组织（如人肾细胞、中国仓鼠卵巢等）                                                                               |
| **传代历史**       | 在来源机构保存期间的完整传代次数记录                                                                                                             |
| **培养条件**       | 每次传代所用培养基种类；培养温度和条件                                                                                                           |
| **原材料详细信息** | 培养过程中使用的**所有原材料**（血清、胰蛋白酶、生长因子等）的：种类、来源（供应商）、批号、生产日期、有效期、制备或使用方法、质量标准及检测结果 |
| **检测记录**       | 来源机构对该细胞株完成的安全性检测结果（如无菌、支原体等）                                                                                       |

### 原材料信息完整性的重要性

原材料的详细信息对于以下评估至关重要：

- **TSE/BSE 风险：** 历史上是否使用过牛源成分（血清、牛血白蛋白）；来源地区和组织类型。
- **外源病毒风险：** 是否使用过猪源胰蛋白酶（PCV 风险）；人源成分（HBV/HIV 风险）。
- **细胞株遗传完整性：** 传代过程中是否使用可能影响基因表达的化学物质（如 MSX 选择压力）。

> **实践建议：** 从知名公认的细胞库（ATCC、DSMZ、RIKEN BRC）获取细胞株，可获得最完整的来源证明文件。若为合作机构转让的细胞，须在细胞转让协议中明确包含完整传代记录的提供义务。

## 三级细胞库体系（中国药典）：MCB/WCB/细胞种定义与二级管理的特殊条件

:::answer

### 三级细胞库体系定义

**《中国药典》** 规定生物制品生产用细胞库采用三级管理体系：

```
细胞种（Cell Seed / Primary Seed Stock）
  │── 来源于原始来源机构或内部建立的最初代次细胞
  │── 特征：代次最低，遗传物质最接近原始状态
  │── 用途：扩增制备 MCB；不直接用于生产
  │
  ↓ 扩增
主细胞库（MCB, Master Cell Bank）
  │── 由细胞种扩增制备；GMP 条件下建立；须全面检定（14 项）
  │── 特征：提供整个产品生命周期所需细胞的"主备份"
  │── 用途：仅用于扩增制备 WCB；不直接用于生产
  │
  ↓ 扩增
工作细胞库（WCB, Working Cell Bank）
  │── 由 MCB 扩增制备；GMP 条件下建立；须按规定项目检定
  │── 特征：每次生产的直接起始物料
  └── 用途：直接用于每批产品的生产启动
```

### 为什么采用三级管理体系

三级体系的设计目的是实现**两层保护**：

- **MCB 作为战略储备：** 数量通常数百至数千支，存放于两个异地液氮罐，在整个商业化生命周期内不轻易动用；一旦 WCB 耗尽，可从 MCB 重新制备 WCB。
- **WCB 作为生产缓冲：** 每次生产从 WCB 取用，保护 MCB 免受频繁使用导致的风险。

### 二级管理的例外情况

在**某些特殊情况**下，可采用**细胞种 + MCB 二级管理体系**（跳过 WCB 层），但须满足：

- 须获得**国务院药品监督管理部门（即 NMPA）的明确批准**。
- 须提供充分的科学依据，说明二级体系的安全性和适用性。

**适用二级管理的典型场景（参考）：**

- 某些小批量、小市场的孤儿药产品（总生产批次少，三级体系维护成本与获益不成比例）。
- 特殊细胞基质（如 iPSC 衍生细胞）的管理，尚无成熟的三级体系经验。

:::

## IND 申报上游工艺杂质的 ISF 评估：适用物料范围与评估框架

:::answer

### ISF 评估的背景

**ISF（Impurity Safety Failure / Safety Assessment）** 评估是针对生物药生产工艺中使用的辅助性化学物质，评估其在终产品中的潜在残留水平是否构成患者安全性风险的系统性分析。

### 须进行 ISF 评估的上游工艺物料

| 物料类别                     | 代表性物质                                                             | 评估重点                                                            |
| ---------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **细胞保护剂**               | **Pluronic F-68（PF-68）**                                             | 在终产品中的残留量；溶血毒性；对蛋白质稳定性的影响                  |
| **冷冻保护剂**               | **DMSO（二甲亚砜）**                                                   | 细胞库冻存中使用；ICH Q3C Class 3 溶剂；PDE = 50 mg/day；通常低风险 |
| **消泡剂**                   | 植物油来源消泡剂；硅油类消泡剂                                         | 残留量；对下游纯化工艺的干扰；患者安全性                            |
| **选择标记药物（筛选压力）** | **MSX（蛋氨酸亚砜亚胺）**（GS 系统）；**MTX（氨甲蝶呤）**（DHFR 系统） | 在生产工艺中的持续存在量；MSX 的神经毒性；MTX 的抗代谢毒性          |
| **其他添加物**               | 丁酸钠（增强表达）；铜离子（影响糖型）                                 | 残留量；毒性数据；对患者的潜在暴露                                  |

### ISF 评估的决策框架

```
确认物料的实际使用量和使用阶段
  │
  ├─ 评估该物料在下游工艺中的清除能力（通过下游验证数据或文献）
  │
  ├─ 计算理论最大残留量（Worst Case）
  │     = 使用量 × （1 - 清除率）
  │
  ├─ 与安全阈值比较（参考 ICH Q3C/Q3D；毒理数据库；文献）
  │
  └─ 判定
        ├─ 残留量 << 安全阈值 → 低风险，无需设定残留限度 ✅
        └─ 残留量接近或超过安全阈值 → 须建立残留检测方法，设定限度 ⚠️
```

### DMSO 的 ISF 评估结论（典型案例）

如前文所述，DMSO 属于 ICH Q3C **Class 3 溶剂**（人体低毒），PDE = **50 mg/day**。在细胞库冻存中使用的 DMSO 不直接接触生产批次，因此通常评估结论为**低风险，无需在放行质量标准中设定 DMSO 残留检测**。

:::

## NMPA 与 FDA 的监管理念差异：IND 审评重点与质量安全观的本质区别

:::answer

### 两个监管机构的核心理念对比

| 差异维度                 | NMPA（中国）                                                              | FDA（美国）                                                            |
| ------------------------ | ------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **IND 阶段审评严格程度** | **较为严格**：对 CMC 信息完整性要求高；须提供完整质量标准；多批次病毒验证 | **相对宽松**：重点关注安全性；允许较宽的质量标准；部分项目可仅报告结果 |
| **审评侧重点**           | 安全性 + 药效学/CMC 并重                                                  | **安全性优先**：I 期主要评估安全性，对药效要求相对少                   |
| **数据要求量**           | 通常要求更多批次（如 3 批 UPB vs. FDA 的 1 批）                           | 接受较少批次但质量须高（须为 GMP 批次）                                |
| **方法验证要求**         | **主要方法均须系统方法学验证** + 验证报告                                 | 安全性相关方法须完整验证；其余方法做确认即可                           |

### NMPA 审评趋势：加速向 ICH 靠拢

**2017 年中国正式加入 ICH（人用药品注册技术要求国际协调委员会）** 是中国药品监管史上的重要里程碑，标志着中国药品审评正式纳入国际技术标准体系：

| 变化维度   | 加入 ICH 前                      | 加入 ICH 后（2017 年至今）                                 |
| ---------- | -------------------------------- | ---------------------------------------------------------- |
| 技术标准   | 主要参考中国药典和国内指导原则   | 逐步采纳 ICH 指导文件（Q1～Q14 等）                        |
| 申报格式   | 中国格式（CTD 格式部分采用）     | 全面采用 CTD 格式                                          |
| 审评理念   | 注重数据完整性；风险意识相对保守 | 引入 QbD 理念；风险评估导向                                |
| 与国际接轨 | 双报须准备两套资料               | 双报的重叠性显著增加；一份资料可同时满足中美要求的比例提高 |

### FDA 对 I 期安全性优先的科学依据

FDA 在 I 期临床阶段重点关注安全性而非药效，基于以下科学逻辑：

- I 期的主要目的是**确定安全剂量范围（MTD/MAD）**，而非证明疗效。
- 在 I 期尚不需要知道产品是否有效，但**绝对需要知道产品是否安全**。
- 早期对产品安全性的充分了解可以保护受试者，并指导后续剂量选择。

### 双报策略的实践建议

基于以上差异，采用**以 NMPA 要求为最高标准**组织 IND 申报工作，通常可自然满足 FDA 要求：

| 申报项目       | 以 NMPA 为基准           | 满足 FDA 效果                        |
| -------------- | ------------------------ | ------------------------------------ |
| 结构表征批次   | 2～3 批                  | FDA 仅需 1 批 ✅ 超额满足            |
| 质量标准完整性 | 完整（含糖型、电荷变体） | FDA 允许部分报告结果 ✅ 满足         |
| 方法验证       | 所有主要方法全验证       | FDA 仅需安全性方法全验证 ✅ 超额满足 |
| 病毒验证批次   | 3 批次                   | FDA 仅需 1 GMP 批次 ✅ 超额满足      |

:::

## UPB 检测批次的中美差异：GMP vs. non-GMP 批次要求与检测策略

:::answer

### UPB 检测的目的

**UPB（Unprocessed Bulk，未纯化收获液）** 检测是通过对收获液进行病毒安全性、微生物和遗传稳定性的综合评估，证明生产起始物料（细胞）的安全性。UPB 检测结果是整个工艺病毒安全性证明链条的**起点**。

### 中美批次要求对比

| 维度             | NMPA（中国）IND 阶段               | FDA IND 阶段                                        |
| ---------------- | ---------------------------------- | --------------------------------------------------- |
| **批次数量**     | **2～3 批次**（通常要求 3 批次）   | **1 个 GMP 批次**                                   |
| **批次质量要求** | 可包含 **non-GMP 批次和 GMP 批次** | **建议仅 GMP 批次**（non-GMP 批次数据的代表性存疑） |

### 批次类型对数据质量的影响

| 批次类型         | 特点                                                  | 数据价值                                           |
| ---------------- | ----------------------------------------------------- | -------------------------------------------------- |
| **non-GMP 批次** | 在研发实验室（非 GMP 设施）生产；工艺可能尚未最终确定 | 可提供早期工艺探索数据；但对商业化工艺的代表性有限 |
| **GMP 批次**     | 在 GMP 设施生产；按照完整 GMP 规程执行；工艺基本锁定  | 代表性强；数据可直接支持申报                       |

### NMPA 允许 non-GMP 批次的背景原因

NMPA 允许 non-GMP 批次参与 UPB 检测，主要反映了国内 IND 申报阶段的实际情况：

- 在研发早期，GMP 设施可能尚未建立或尚未具备生产能力。
- 允许 non-GMP 批次提交，降低了早期申报的门槛，支持创新药物的加速开发。
- 但 non-GMP 批次数据须说明其与 GMP 批次的工艺等同性。

### 策略建议

- 尽量**以 GMP 批次作为 UPB 检测的主要批次**，non-GMP 批次数据作为辅助参考。
- 若资源允许，早期建立一个 GMP 批次的 UPB 数据，可同时满足 NMPA 和 FDA 的要求，避免后期补做。
- UPB 检测须与收获液的其他质量检测（支原体、微生物限度、内毒素）联合执行，形成完整的收获前质量控制数据包。

:::
