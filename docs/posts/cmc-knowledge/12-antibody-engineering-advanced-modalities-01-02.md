## 抗感染抗体药物的三大核心挑战：机制、单抗局限与模型缺失

:::answer

### 挑战概述

抗感染抗体药物的开发难度远高于肿瘤领域，根本原因在于以下三大系统性挑战相互交织、互相制约。

### 挑战一：感染机制研究不足——药物设计的"暗箱"

明确的感染机制是靶点选择和抗体设计的前提。尽管蛋白质组学、结构生物学和免疫学近年来取得重大进展，但仍存在大量关键知识空白：

| 未解难题类型     | 具体表现                                                          | 对药物开发的影响                     |
| ---------------- | ----------------------------------------------------------------- | ------------------------------------ |
| 入胞机制         | 病原体是否仅通过单一受体/配体介导入胞，不同通路间是否存在交互冗余 | 单靶点阻断效果不稳定，体内外活性脱节 |
| 免疫逃逸机制     | 病原体如何诱导机体免疫抑制，哪些免疫细胞参与及其相互关系          | 难以设计联合免疫激活策略             |
| 慢性感染的持久性 | 潜伏感染（如 HSV、EBV、HIV）的再激活机制                          | 缺乏清除潜伏库的策略依据             |

> **核心矛盾**：许多抗体在体外（in vitro）显示出优秀的抗感染活性，但体内（in vivo）效果大打折扣——这往往源于体内复杂免疫微环境和多通路冗余感染机制的影响。

### 挑战二：单一单抗效果受限——单一特异性的内在局限

| 抗体类型              | 优点                                   | 缺点                                                                           |
| --------------------- | -------------------------------------- | ------------------------------------------------------------------------------ |
| **抗血清/多克隆抗体** | 同时靶向多个抗原和表位，抗感染疗效确切 | 免疫原性强、批间稳定性差、质控困难、毒副作用大                                 |
| **单克隆抗体**        | 高纯度、批间一致性好、免疫原性低       | **只识别单一表位**，面对复杂感染疗效有限，且易诱导耐药（病毒单点突变即可逃逸） |

**耐药性问题的本质：** 病毒突变速率极快（尤其是 RNA 病毒），单一表位的单抗一旦遇到该表位的突变逃逸株，将完全失效。这也是为什么靶向保守表位的**广谱抗体**和**鸡尾酒疗法**成为重要策略。

### 挑战三：缺乏合理的体内外评价模型——研发效率的瓶颈

| 模型缺口来源             | 典型案例                                                                           | 问题本质                                           |
| ------------------------ | ---------------------------------------------------------------------------------- | -------------------------------------------------- |
| **病原体种属嗜性差异**   | HBV 不能感染小鼠肝细胞（缺乏人源 NTCP 受体），乙肝药物缺乏标准啮齿类模型           | 无法在常规小鼠上复制自然感染过程                   |
| **免疫系统差异**         | 小鼠与人体在 FcγR 亚型、补体系统、NK 细胞数量等方面存在显著差异                    | 抗体的 Fc 效应功能无法在普通小鼠中准确预测人体反应 |
| **人源化动物模型的局限** | 人源化小鼠（如 NSG-SGM3）免疫功能不完整，难以评估完整的天然免疫-适应性免疫协同效应 | 无法真实模拟人体感染后的免疫应答全过程             |

> **应对策略**：建立灵长类动物（NHP）模型、人源化小鼠模型、类器官（Organoid）感染模型，以及体外人 PBMC 共培养系统，多模型交叉验证。

:::

## 抗感染抗体药物的六大发展趋势：从单一到组合的策略演进

:::answer

### 六大策略总览

针对抗感染抗体面临的挑战，业界形成了六个相互补充的发展方向：

| 策略                    | 核心逻辑                       | 解决的主要问题                |
| ----------------------- | ------------------------------ | ----------------------------- |
| **鸡尾酒疗法**          | 多种单抗联合使用               | 单抗效果有限 + 耐药性         |
| **重组多克隆抗体**      | 多个抗体基因在同一细胞系共表达 | 鸡尾酒疗法的研发/注册成本过高 |
| **ADC（抗体偶联药物）** | 抗体携带抗感染活性小分子       | 单纯抗体杀伤力不足            |
| **双特异性抗体**        | 同时靶向两个抗原或募集效应细胞 | 单靶点阻断不充分              |
| **糖工程改造抗体**      | 优化 Fc 糖基化增强效应功能     | 免疫效应机制激活不足          |
| **广谱抗体**            | 靶向高度保守的病毒功能域       | 突变逃逸和株间交叉保护        |

## 鸡尾酒疗法：多抗体协同的联合防线

:::answer

### 核心策略逻辑

鸡尾酒疗法（Antibody Cocktail Therapy）通过将**识别不同抗原表位**或**不同抗原靶点**的单克隆抗体进行组合，构建多层次、多机制的抗感染防线：

```
单抗 A（靶向表位 1）+ 单抗 B（靶向表位 2）+ 单抗 C（靶向靶点 Y）
          ↓
多重阻断：病毒即使在表位 1 发生突变，仍被单抗 B 或 C 覆盖
          ↓
降低耐药性风险（病毒需要在多个位点同时发生突变才能完全逃逸）
```

### 双重获益

**① 增强疗效**：不同机制协同（中和 + ADCC + CDC），覆盖更广的病毒亚型和突变逃逸株

**② 降低耐药**：病毒需要在多个关键位点同时突变才能完全逃逸，概率极低

### 代表性临床成功案例

| 产品                                                 | 靶点组合                      | 适应证   | 获批情况         |
| ---------------------------------------------------- | ----------------------------- | -------- | ---------------- |
| **REGEN-COV（Casirivimab + Imdevimab）**             | SARS-CoV-2 S 蛋白两个不同表位 | COVID-19 | FDA EUA（2020）  |
| **ZMapp**                                            | 埃博拉病毒 GP 蛋白三个表位    | 埃博拉   | 临床研究         |
| **Inmazeb（Atoltivimab + Maftivimab + Odesivimab）** | 埃博拉 GP 蛋白三个表位        | 埃博拉   | FDA 批准（2020） |

### 开发挑战

- **法规复杂性**：多个单抗联合用药在某些法规框架下需分别完成安全/有效性评价和注册申报
- **生产挑战**：多种单抗混合的制剂稳定性、相互作用、比例控制需要系统研究
- **成本压力**：多个候选抗体的并行开发显著增加研发投入

:::

## 重组多克隆抗体：多抗体"一锅出"的工程化解决方案

:::answer

### 技术定义与核心突破

**重组多克隆抗体（Recombinant Polyclonal Antibody，rpAb）** 是利用**位点特异性基因整合技术（Site-specific Integration）**，将多个抗体基因整合到宿主细胞染色体的**同一特定位置**，实现多个抗体在单一细胞系中稳定、均衡表达。

### 相比鸡尾酒疗法的核心优势

| 维度           | 鸡尾酒疗法                          | 重组多克隆抗体                                   |
| -------------- | ----------------------------------- | ------------------------------------------------ |
| **生产方式**   | 多个独立细胞系分别生产，后期混合    | 单一细胞系一次性生产多种抗体                     |
| **注册路径**   | 每个单抗组分须独立申报              | 作为单一药物注册（监管路径简化）                 |
| **批间稳定性** | 各组分比例难以精确控制，批间变异大  | 基因整合位置固定，各抗体表达量稳定，批间一致性高 |
| **成本**       | 高（多个独立的工艺开发 + 注册费用） | 相对低（单一生产工艺）                           |
| **质控复杂度** | 高（需对每个组分分别检测）          | 中（多组分混合产品的表征技术要求高）             |

### 技术实现路径

```
筛选多个针对不同表位的单抗基因（VH/VL）
          ↓
通过位点特异性重组酶（如 Cre-lox、FLP-FRT）
将多个抗体基因盒整合至宿主细胞染色体同一位点
          ↓
各抗体基因在相同染色质环境下转录
→ 表达水平、细胞生长速率、遗传稳定性趋于一致
          ↓
单一发酵批次生产多种抗体的混合物
```

### 代表技术平台

- **Symphogen（丹麦）**：Sym004（靶向 EGFR 多表位重组多克隆抗体，用于结直肠癌）是该技术路线的先行者

> **质量控制挑战**：多组分混合产品的特性表征是 CMC 的核心难点，需建立能够分辨和定量各个抗体组分的高分辨率分析方法（如 CEX + MS 联用），以确保批间组成一致性。

:::

## 抗感染 ADC：靶向递送抗感染活性载荷的新策略

:::answer

### 设计逻辑

将 ADC 概念从抗肿瘤领域延伸至抗感染，核心思路是：

```
靶向病原体/感染细胞的抗体（特异性）
    +
抗病毒/抗菌活性小分子（杀伤力）
    =
抗感染 ADC（特异性 + 高效载荷）
```

| ADC 组分             | 抗肿瘤 ADC                        | 抗感染 ADC                            |
| -------------------- | --------------------------------- | ------------------------------------- |
| **抗体（靶向部分）** | 肿瘤细胞表面抗原（HER2、CD30 等） | 病毒表面蛋白、细菌表面多糖/蛋白抗原   |
| **连接子**           | 可裂解（pH/酶敏感）或不可裂解     | 与抗肿瘤 ADC 类似，需根据递送场景设计 |
| **载荷（Payload）**  | 细胞毒素（MMAE、DM1、DXd 等）     | 抗病毒小分子、抗菌素、溶菌酶等        |

### 抗感染 ADC 的潜在应用场景

- **抗病毒**：靶向 HIV 感染的 CD4+ T 细胞或巨噬细胞，递送抗病毒核苷类似物，清除潜伏病毒库
- **抗细菌**：靶向多重耐药菌（如 MRSA）表面特异性蛋白，精准递送抗生素载荷，绕过细菌的外排耐药机制
- **抗胞内病原体**：结合靶向感染细胞的抗体，将抗胞内寄生虫药物递送至细胞内靶部位

### 面临的特殊挑战

| 挑战             | 说明                                                           |
| ---------------- | -------------------------------------------------------------- |
| **靶抗原选择**   | 需要在病原体感染细胞表面高表达，且在正常细胞表面不表达或低表达 |
| **载荷耐药性**   | 抗菌素类载荷可能面临细菌耐药问题，需选择新作用机制的载荷分子   |
| **连接子稳定性** | 需要在血浆中稳定，但在到达感染部位后能有效释放载荷             |

:::

## 双特异性抗体用于抗感染：双重阻断与免疫细胞招募

:::answer

### 抗感染双特异性抗体的两大主要策略

**策略一：双重靶点阻断（Dual Blocking）**

同时阻断病原体利用的两条独立入胞通路或两个关键功能域，克服单靶点阻断的逃逸风险：

```
双特异性抗体
    ├── 臂 A → 结合病毒受体结合位点（RBD）
    └── 臂 B → 结合病毒融合蛋白（FP）
          ↓
双重阻断：入胞 + 膜融合 → 病毒无法感染细胞
```

**策略二：免疫细胞招募（Immune Cell Engagement）**

将效应免疫细胞（NK 细胞、T 细胞、巨噬细胞）定向招募至病原体感染部位，增强局部杀伤：

```
双特异性抗体
    ├── 臂 A → 结合病原体/感染细胞表面抗原
    └── 臂 B → 结合效应细胞（NK 细胞 NKp46 或 T 细胞 CD3ε）
          ↓
形成免疫突触（Immunological Synapse）
          ↓
效应细胞定向杀伤病毒感染细胞
```

### 抗感染双特异性抗体的研究进展

| 靶点组合                        | 病原体     | 策略类型                             | 阶段            |
| ------------------------------- | ---------- | ------------------------------------ | --------------- |
| HIV gp120 × CD3                 | HIV        | T 细胞招募，清除潜伏感染细胞         | 临床前/早期临床 |
| SARS-CoV-2 RBD × ACE2（解毒版） | SARS-CoV-2 | 阻断 + 中和协同                      | 研究阶段        |
| HBsAg × CD3/NKG2D               | HBV        | 免疫效应细胞招募，清除 HBsAg+ 肝细胞 | 临床前          |

## 广谱抗体：靶向保守功能域的跨株交叉保护

:::answer

### 广谱抗体的定义与核心价值

**广谱抗体（Broadly Neutralizing Antibody，bNAb）** 是指能够中和同一种病毒多个亚型、多个变异株，甚至跨越远缘病毒株的单克隆抗体。其核心价值在于：

- **克服突变逃逸**：靶向高度保守的功能必需位点，病毒突变该位点将丧失感染能力
- **预防性保护潜力**：一种广谱抗体可能覆盖未来可能出现的新变异株
- **简化开发流程**：无需针对每个新变异株重新开发抗体

### 广谱中和的两大作用机制

**机制一：靶向病原体高度保守的功能必需位点**

这些位点是病毒感染宿主的"功能咽喉要道"，发生突变将直接影响感染能力，因此在进化压力下高度保守：

| 病毒           | 保守靶点                                                  | 广谱抗体代表                           |
| -------------- | --------------------------------------------------------- | -------------------------------------- |
| **HIV**        | CD4 结合位点（CD4bs）、膜近端外部区域（MPER）、V1/V2 顶部 | VRC01（靶向 CD4bs）、10E8（靶向 MPER） |
| **流感病毒**   | 血凝素茎部（HA Stem）——所有流感亚型保守                   | MHAA4549A（Genentech）、VIS410         |
| **SARS-CoV-2** | Spike 蛋白受体结合域（RBD）的 ACE2 结合界面保守残基       | S2E12、COG-112 等                      |
| **RSV**        | F 蛋白融合前构象（Pre-F）的抗原位点 Ø（高度保守）         | Nirsevimab（Beyfortus）                |

**机制二：宿主受体竞争结合（Host Receptor Mimicry）**

广谱抗体模拟宿主受体的结合界面，竞争性阻断病毒与受体的相互作用：

```
病毒必须结合宿主受体才能入胞（如 HIV gp120 必须结合 CD4）
          ↓
广谱抗体模拟 CD4 的结合界面，高亲和力占据 CD4 结合位点
          ↓
封闭该保守位点 → 对所有依赖该位点入胞的 HIV 株均有效
（病毒突变此位点 → 无法与 CD4 结合 → 丧失感染能力，自然淘汰）
```

### 广谱抗体的开发挑战

- **获取难度高**：广谱中和活性通常需要经历<strong>体细胞超突变（Somatic Hypermutation）</strong>的高度成熟，筛选效率低
- **亲和力-广谱性的权衡**：高度广谱的抗体往往对单一亚型的亲和力低于株特异性抗体
- **保守表位的可及性**：保守位点通常被糖链或空间位阻遮蔽，抗体难以接近

## 免疫检查点靶点概览：T 细胞活化的双重闸门

:::answer

### 免疫检查点的生物学意义

**免疫检查点（Immune Checkpoint）** 是免疫系统中防止过度激活和自身免疫损伤的内源性负调控机制。肿瘤细胞可利用这些机制实现**免疫逃逸（Immune Evasion）**，而针对免疫检查点的抗体（Immune Checkpoint Inhibitor，ICI）则通过解除这种抑制，重新激活抗肿瘤免疫应答。

### 两大核心检查点的作用节点

```
T 细胞活化的两个关键节点：

节点 1：T 细胞活化启动阶段（淋巴结）
→ CTLA-4 在此节点发挥抑制作用（与 CD28 竞争结合 B7 分子）

节点 2：T 细胞效应阶段（肿瘤微环境）
→ PD-1/PD-L1 在此节点发挥抑制作用（肿瘤细胞表达 PD-L1 抑制浸润 T 细胞）
```

| 特征         | **CTLA-4**                             | **PD-1/PD-L1**                             |
| ------------ | -------------------------------------- | ------------------------------------------ |
| **作用节点** | T 细胞活化启动阶段（淋巴结）           | T 细胞效应阶段（肿瘤微环境）               |
| **表达位置** | 活化 T 细胞、Treg                      | T 细胞（PD-1）；肿瘤细胞、APCs（PD-L1）    |
| **联合使用** | 与抗 PD-1 联合（协同增效，但毒性叠加） | 与抗 CTLA-4 联合（Nivolumab + Ipilimumab） |
| **毒性特点** | 免疫相关不良事件（irAE）较重           | irAE 相对较轻（单药）                      |

## PD-1/PD-L1 靶点：肿瘤免疫治疗的核心通路

:::answer

### PD-1 的分子生物学

**PD-1（Programmed Death-1，程序性死亡受体 1，CD279）** 是 CD28 超家族的抑制性受体，在以下细胞上广泛表达：

- **效应 T 细胞**（CD4+ Th1、CD8+ CTL）：活化后上调，慢性感染/肿瘤中持续高表达（T 细胞耗竭标志）
- **调节性 T 细胞（Treg）**：维持免疫耐受
- **B 细胞、NK 细胞、单核细胞**：在特定活化状态下表达

### PD-1/PD-L1 通路的双重功能

**生理功能（保护性）：**

```
外周组织 T 细胞表达 PD-1
          ↓ 结合组织细胞表达的 PD-L1
抑制 T 细胞活化（防止自身免疫性组织损伤）
→ 预防自身免疫疾病（如 I 型糖尿病、类风湿关节炎）
```

**病理功能（被肿瘤利用）：**

```
肿瘤细胞在 IFN-γ 等信号刺激下上调 PD-L1 表达
          ↓ 结合浸润 T 细胞表面 PD-1
抑制肿瘤特异性 T 细胞的细胞毒活性
→ 肿瘤免疫逃逸，不被免疫系统清除
```

### PD-1 vs PD-L1：两种拮抗策略的比较

| 维度                | 抗 PD-1 单抗                                     | 抗 PD-L1 单抗                                                            |
| ------------------- | ------------------------------------------------ | ------------------------------------------------------------------------ |
| **作用对象**        | 阻断 T 细胞上的 PD-1                             | 阻断肿瘤细胞/APC 上的 PD-L1                                              |
| **对 PD-L2 的影响** | 同时解除 PD-L2 介导的抑制                        | 不影响 PD-1/PD-L2 通路                                                   |
| **Fc 效应功能**     | 通常需要沉默 Fc（防止消耗 T 细胞）               | 通常保留部分 Fc 功能                                                     |
| **代表药物**        | 帕博利珠单抗（Keytruda）、纳武利尤单抗（Opdivo） | 阿替利珠单抗（Tecentriq）、度伐利尤单抗（Imfinzi）、阿维单抗（Bavencio） |

| 药物                                       | 靶点  | 公司        | 代表适应证                                      |
| ------------------------------------------ | ----- | ----------- | ----------------------------------------------- |
| **帕博利珠单抗**（Pembrolizumab/Keytruda） | PD-1  | MSD         | 黑色素瘤、NSCLC、MSI-H 泛癌种（全球销售额第一） |

| **度伐利尤单抗**（Durvalumab/Imfinzi）     | PD-L1 | AstraZeneca | NSCLC（III 期，放化疗后巩固）、胆道癌           |

### PD-1 抑制剂与 CTLA-4 抑制剂联合的协同机制

```
CTLA-4 抑制剂（作用于淋巴结）
→ 促进更多肿瘤特异性 T 细胞激活和扩增
          +
PD-1 抑制剂（作用于肿瘤微环境）
→ 解除浸润 T 细胞的耗竭状态，恢复杀伤功能
          ↓
协同增强抗肿瘤免疫（Nivolumab + Ipilimumab 联用方案）
```

## CTLA-4 靶点：T 细胞活化启动阶段的关键检查点

:::answer

### CTLA-4 的分子机制

**CTLA-4（Cytotoxic T-Lymphocyte Antigen 4，CD152）** 是表达于活化 T 细胞和调节性 T 细胞（Treg）表面的抑制性跨膜受体：

**T 细胞活化的竞争性调节：**

```
T 细胞活化需要双信号：
    信号 1：TCR 识别 MHC-抗原肽
    信号 2：CD28 与 APC 上的 B7（CD80/CD86）结合 → 活化信号

CTLA-4 的抑制机制：
    CTLA-4 对 B7 的亲和力远高于 CD28（~20 倍）
          ↓
    CTLA-4 竞争性结合 B7，剥夺 CD28 共刺激信号
          ↓
    T 细胞活化受到抑制 / T 细胞无能（Anergy）
```

### CTLA-4 在肿瘤免疫逃逸中的作用

肿瘤细胞可通过多种机制激活 CTLA-4 通路：

1. **Treg 上高表达 CTLA-4**：Treg 通过 CTLA-4 下调 APC 的 B7 表达（Trans-endocytosis），削弱效应 T 细胞的共刺激信号
2. **肿瘤微环境中 CTLA-4 表达上调**：持续的抗原刺激导致肿瘤浸润 T 细胞 CTLA-4 表达增加
3. **记忆性 T 细胞的形成受阻**：CTLA-4 激活后阻止记忆性 T 细胞的生成，降低长期免疫保护

### CTLA-4 抑制剂的作用

**伊匹木单抗（Ipilimumab/Yervoy，BMS）** 是全球首个获批的免疫检查点抑制剂（2011 年 FDA 批准，用于黑色素瘤），开创了肿瘤免疫治疗的新时代。

| 特性         | 说明                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| **抗体类型** | 全人源 IgG1（具有效应功能，可清除 Treg）                                     |
| **主要机制** | 竞争性阻断 CTLA-4/B7 相互作用 + ADCC 清除肿瘤微环境中的 Treg                 |
| **临床使用** | 单药（黑色素瘤）或与 Nivolumab 联合（黑色素瘤、肾癌、NSCLC、MSI-H 结直肠癌） |
| **主要毒性** | 免疫相关不良事件（irAE）发生率较高：结肠炎、肝炎、内分泌病变                 |

> **下一代 CTLA-4 抑制剂**：Tremelimumab（AstraZeneca，IgG2 亚型，Fc 效应功能弱）、AGEN1181（Fc 工程化增强 Treg 清除能力）——通过优化 Fc 功能在保留疗效的同时降低毒性。

:::

## HER2 靶点（开发策略视角）：从单抗阻断到 ADC 的靶向升级

:::answer

### HER2 的致癌机制与靶向价值

**HER2（Human Epidermal Growth Factor Receptor 2）** 是 ErbB 家族唯一无已知特异性配体的受体，通过与其他家族成员形成**异二聚体**激活信号，其致癌机制涵盖：

| 致癌机制                 | 具体效应                                              |
| ------------------------ | ----------------------------------------------------- |
| **抑制凋亡**             | PI3K/AKT 持续激活 → BCL-2/BCL-xL 上调 → 细胞凋亡抵抗  |
| **促进增殖**             | MAPK/ERK 通路持续激活 → 细胞周期加速                  |
| **增加侵袭力**           | MMP（基质金属蛋白酶）上调 → 细胞外基质降解 → 浸润转移 |
| **促进血管和淋巴管新生** | VEGF 表达上调 → 肿瘤供血建立                          |

### 赫赛汀（曲妥珠单抗）的多重作用机制

曲妥珠单抗不仅是单纯的信号阻断剂，具备多重作用机制：

1. **结合 HER2 胞外域 IV（Domain IV）**：阻断 HER2/Src 激酶相互作用，抑制下游信号
2. **引起 HER2 受体下调**：促进 HER2 蛋白内化和降解，降低细胞表面 HER2 密度
3. **ADCC 效应**：IgG1 Fc 段招募 NK 细胞，杀伤 HER2 阳性肿瘤细胞
4. **阻断 HER2 胞外域剪切**：阻止 MMP 对 HER2 胞外域的蛋白酶切割（剪切后残余 p95-HER2 持续活化）

### HER2 靶向药物的多代演进

| 药物类型      | 代表药物                     | 靶向机制                                     | 克服的问题                      |
| ------------- | ---------------------------- | -------------------------------------------- | ------------------------------- |
| 人源化单抗    | 曲妥珠单抗                   | HER2 Domain IV 阻断 + ADCC                   | —                               |
| 人源化单抗    | 帕妥珠单抗                   | HER2 Domain II（二聚化界面）阻断             | 联合用药，互补阻断位点          |
| ADC           | T-DM1（Kadcyla）             | HER2 靶向 + DM1 微管抑制剂                   | 曲妥珠单抗耐药后                |
| ADC（新一代） | T-DXd（Enhertu）             | HER2 靶向 + DXd（Top1 抑制剂）+ 强旁观者效应 | HER2 低表达 + 更强旁观者效应    |
| Fc 工程化单抗 | Margetuximab                 | HER2 阻断 + 增强 ADCC（S239D/I332E）         | 克服 FcγRIIIa 多态性限制        |
| 小分子 TKI    | 拉帕替尼、奈拉替尼、图卡替尼 | 胞内激酶域抑制（可逆/不可逆）                | 脑转移（图卡替尼 BBB 穿透性好） |

### HER2 检测与伴随诊断（CDx）

HER2 状态检测是所有 HER2 靶向治疗的前提：

| 检测方法                 | 检测内容           | 结果判读                        |
| ------------------------ | ------------------ | ------------------------------- |
| **IHC（免疫组化）**      | 蛋白表达水平       | 0/1+/2+/3+；3+ 为阳性           |
| **FISH（荧光原位杂交）** | 基因拷贝数/扩增    | HER2:CEP17 比值 ≥2.0 为扩增阳性 |
| **NGS**                  | 基因突变/扩增/表达 | 综合判断                        |

> **HER2 低表达（HER2-low）** 定义为 IHC 1+ 或 IHC 2+/FISH 阴性——T-DXd 的强旁观者效应使其在 HER2-low 患者中也显示疗效，极大扩展了可治疗人群。

## VEGF 靶点（开发策略视角）：肿瘤与眼科的双线布局

:::answer

### VEGF 在肿瘤微环境中的特殊地位

在众多血管生成因子中，VEGF 被选为**肿瘤治疗主要靶点**，是多重机制共同作用的结果：

**① 肿瘤细胞基因突变驱动 VEGF 高表达**：

- HIF-1α（低氧诱导因子）在实体瘤低氧区域稳定积累 → VEGF 基因转录大幅上调
- VEGFR 在许多实体瘤细胞上发生基因扩增/突变 → 自分泌激活环路

**② 肿瘤微环境协同促进 VEGF 表达**：

```
肿瘤微环境
    ├── 低氧（Hypoxia）→ HIF-1α 激活 → VEGF↑
    ├── 炎症因子（TNF-α、IL-6）→ NF-κB 激活 → VEGF↑
    └── 肿瘤相关巨噬细胞（TAM）→ 分泌 VEGF → 促进血管生成
```

**③ VEGF 的双重促肿瘤作用**：

- 促进新生血管为肿瘤提供营养和氧气
- 增加血管通透性 → 肿瘤细胞更易进入循环 → 促进转移

### 抗 VEGF 治疗的耐药机制

| 耐药类型       | 机制                                       | 应对策略                                          |
| -------------- | ------------------------------------------ | ------------------------------------------------- |
| **原发耐药**   | FGF、PDGF、Ang-2 等替代血管生成通路活跃    | 联合靶向多通路（如 VEGF+Ang-2 双靶点：Faricimab） |
| **获得性耐药** | 周细胞覆盖血管增加，肿瘤血管成熟化         | 联合化疗、免疫治疗                                |
| **血管正常化** | 低剂量抗 VEGF 促进血管正常化，改善药物递送 | 与化疗/免疫治疗联合（时机窗口）                   |

## CD20 靶点（开发策略视角）：三代抗体的技术迭代逻辑

:::answer

### CD20 的靶点价值再析

**CD20（MS4A1 编码）** 在 B 细胞相关恶性肿瘤中的应用已超过 25 年，其靶点优越性源于：

- 在 B 细胞淋巴瘤、毛细胞白血病（HCL）、慢性淋巴细胞白血病（B-CLL）以及黑色素瘤干细胞中均有表达

- 不游离脱落（No Shedding），不发生显著内化（有利于持续效应）

### 三代抗 CD20 单抗的技术迭代

| 代别       | 代表药物                                                             | 技术特点                                               | 核心改进                                      |
| ---------- | -------------------------------------------------------------------- | ------------------------------------------------------ | --------------------------------------------- |
| **第一代** | 利妥昔单抗（Rituximab/美罗华）、替伊莫单抗（Zevalin）                | 人鼠嵌合体 IgG1                                        | 开创 B 细胞靶向治疗先河，ADCC + CDC 双重效应  |

> **第三代的设计逻辑**：Obinutuzumab 通过去岩藻糖化增强 ADCC，同时通过分子构象改变增强与 B 细胞的直接结合和凋亡诱导，在 CLL 中已证明优于利妥昔单抗。

## TNF-α 靶点（开发策略视角）：自身免疫疾病的致病机制与精准阻断

:::answer

### TNF-α 在自身免疫疾病中的致病网络

TNF-α 通过多条平行的致病通路协同驱动自身免疫疾病的进展：

**① 内皮细胞活化 → 炎症细胞渗入：**

```
TNF-α → 内皮细胞 ICAM-1/VCAM-1/E-Selectin 上调
       + VEGF 上调 → 血管通透性增加
          ↓
白细胞（中性粒细胞、巨噬细胞）与内皮细胞黏附
          ↓
渗透至滑膜/皮肤等炎症靶器官 → 局部炎症 + 血管翳形成
```

**② 肝脏急性期反应驱动：**

- TNF-α → 肝细胞产生 CRP、血清淀粉样蛋白（SAA）→ 系统性炎症标志物升高

**③ 关节破坏的多细胞级联：**

```
TNF-α 作用于：
    破骨细胞 → 骨侵蚀
    滑膜细胞 → MMP（基质金属蛋白酶）、胶原酶分泌 → 软骨破坏
    软骨细胞 → PGE2（前列腺素 E2）分泌 → 疼痛和炎症
```

**④ 次级细胞因子级联放大：**

```
TNF-α → 滑膜细胞/巨噬细胞/纤维母细胞
          ↓
IL-1β（加重滑膜炎）、IL-8（趋化中性粒细胞）分泌增加
          ↓
炎症正反馈循环，组织损伤持续加重
```

### 不同 TNF-α 抑制剂对 tmTNF 的差异性作用

| 药物                           | tmTNF 结合 | 反信号效应    | 临床意义                                |
| ------------------------------ | ---------- | ------------- | --------------------------------------- |
| 英夫利昔单抗（IgG1 单抗）      | ✓          | ✓（强）       | 可直接杀伤分泌 TNF-α 的巨噬细胞         |
| 阿达木单抗（IgG1 单抗）        | ✓          | ✓（中等）     | 同上                                    |
| 赛妥珠单抗（PEG-Fab，无 Fc）   | ✓          | ✗（无 Fc 段） | 仅中和 sTNF，无反信号和 ADCC            |
| 依那西普（TNFRII-Fc 融合蛋白） | 弱         | 弱            | 主要中和 sTNF 和 LTα，对 tmTNF 亲和力低 |

> **临床意义**：tmTNF 结合和反信号效应可能是解释不同 TNF-α 抑制剂在结核、肠道感染等感染性并发症风险差异的机制之一（英夫利昔单抗对 tmTNF 的强结合与其更高的结核激活风险相关）。

## GLP-1R 靶点：代谢性疾病与肥胖治疗的明星靶点

:::answer

### GLP-1R 的分子结构与信号通路

**GLP-1R（胰高血糖素样肽-1 受体）** 属于 **G 蛋白偶联受体（GPCR）B 簇——胰高血糖素受体亚家族**：

- **基因位置**：人 6 号染色体 6p21，编码 463 个氨基酸
- **结构特征**：七次跨膜核心域（7-TMD）+ 较大的 N 端胞外域（ECD）

**受体激活的信号通路：**

```
GLP-1 / GLP-1R 激动剂 + GLP-1R
          ↓ 受体构象变化
Gs 蛋白解离 → 腺苷酸环化酶（AC）激活 → cAMP 升高
          ↓
PKA 激活 → KATP 通道关闭 → 胰岛 β 细胞去极化 → Ca²⁺ 内流
          ↓
胰岛素囊泡分泌（葡萄糖依赖性）
```

> **关键特性——葡萄糖依赖性**：GLP-1R 激活仅在血糖升高时促进胰岛素分泌，血糖正常时不促进（低血糖风险极低），这是 GLP-1R 激动剂优于磺脲类的核心安全优势。

### GLP-1R 的多组织表达与全身效应

| 表达组织        | GLP-1R 激活后的主要效应                              | 临床价值                                                     |
| --------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| **胰岛 β 细胞** | 促胰岛素合成/分泌，促 β 细胞增殖，抑制凋亡           | 降糖（核心）                                                 |
| **胰岛 α 细胞** | 抑制胰高血糖素分泌（葡萄糖依赖性）                   | 减少餐后血糖波动                                             |
| **胃肠道**      | 抑制胃排空 + 抑制胃液分泌 → 延缓营养吸收             | 降低餐后血糖峰值，产生饱腹感                                 |
| **下丘脑/脑干** | 抑制食欲中枢（弧状核 NPY/AgRP 神经元）→ 减少食物摄入 | **减重效应**（Semaglutide 减重可达 15%+）                    |
| **心血管系统**  | 保护内皮细胞，抗炎，改善心肌能量代谢                 | MACE（主要心血管不良事件）风险降低（LEADER、SUSTAIN-6 试验） |

## CD19 靶点：B 细胞恶性肿瘤全线覆盖的枢纽靶点

:::answer

### CD19 的分子特征与靶点价值

**CD19（人 16 号染色体 16p11.2 编码，556 个氨基酸，95 kDa 跨膜糖蛋白）** 是 B 细胞发育全程（造血干细胞 → 成熟 B 细胞）的稳定表面标志，在 B 细胞活化信号传导中发挥**共受体（Co-receptor）**的核心作用：

```
BCR（B 细胞受体）复合物信号 + CD19/CD21/CD81 共受体复合物
          ↓
Lyn 激酶磷酸化 CD19 胞内区 YXXM 基序
          ↓ 招募 PI3K
PI3K/AKT 信号放大（BCR 信号强度可放大 1000 倍以上）
          ↓
B 细胞活化、增殖、分化为浆细胞
```

### CD19 在 B 细胞恶性肿瘤中的表达

| 肿瘤类型                          | CD19 阳性率                                    |
| --------------------------------- | ---------------------------------------------- |
| B 细胞急性淋巴细胞白血病（B-ALL） | **~80%**                                       |
| B 细胞淋巴瘤                      | **~88%**                                       |
| B 细胞慢性淋巴细胞白血病（CLL）   | **~100%**                                      |
| 多发性骨髓瘤（部分亚型）          | 低（CD19 表达下调，但 CD19+ 骨髓瘤干细胞存在） |

> **CD19 vs CD20 的靶点选择**：CD19 的表达比 CD20 更早（从祖 B 细胞即开始），覆盖范围更广，且在部分 CD20 表达缺失的复发/耐药 B-ALL 患者中 CD19 仍保留表达。

CD19 靶向治疗正延伸至 B 细胞介导的自身免疫疾病（RA、多发性硬化、SLE），Inebilizumab（抗 CD19，同时覆盖 CD19+浆母细胞）已在 NMOSD 中获批，提示 CD19 靶点在自身免疫领域的潜力。

## CD3 靶点：T 细胞导向双特异性抗体的核心效应臂

:::answer

### CD3 复合物的结构与功能

**CD3 复合物** 是 T 细胞受体（TCR）信号转导的核心辅助结构，由四条蛋白链组成：

```
TCR-CD3 复合物结构：
    TCRα/TCRβ（抗原识别）
        +
    CD3γ（γ 链）
    CD3δ（δ 链）     ← 胞外结构域，与 bsTCE 抗体结合的靶点
    CD3ε × 2（ε 链）
    CD3ζ × 2（ζ 链）← 胞内 ITAM 基序，信号转导核心
```

### T 细胞活化的双信号要求

T 淋巴细胞活化需要两个独立信号同时存在：

| 信号                       | 来源                                | 传导通路                                 | 缺失后果                                      |
| -------------------------- | ----------------------------------- | ---------------------------------------- | --------------------------------------------- |
| **第一信号（特异性信号）** | APC 表面 MHC-肽复合物 + TCR/CD3     | ITAMs 磷酸化 → ZAP70 激活 → 下游激酶级联 | T 细胞无反应（仅第一信号 → T 细胞无能）       |
| **第二信号（共刺激信号）** | APC 表面 B7（CD80/86）+ T 细胞 CD28 | PI3K/AKT、NFκB 激活                      | T 细胞凋亡（仅第一信号而无共刺激 → 克隆无能） |

### 双特异性 T 细胞接合器（bsTCE）的工作原理

抗 CD3 双特异性抗体（bsTCE，Bispecific T-Cell Engager）是目前最热门的 CD3 应用方向：

```
bsTCE 设计：
    臂 A → 结合肿瘤细胞表面抗原（CD19、BCMA、EGFR 等）
    臂 B → 结合 T 细胞 CD3ε
          ↓
物理连接肿瘤细胞和 T 细胞，形成人工免疫突触
          ↓
T 细胞即使无需经典的 MHC-肽识别，也能被激活并杀伤肿瘤
（绕过了肿瘤的 MHC-I 下调逃逸机制）
          ↓
穿孔素/颗粒酶介导的肿瘤细胞裂解
```

### bsTCE 设计的关键参数优化

| 设计维度         | 当前主流策略            | 背后逻辑                                                                      |
| ---------------- | ----------------------- | ----------------------------------------------------------------------------- |
| **CD3 端价数**   | 单价（一个 CD3 结合臂） | 双价 CD3 结合导致 T 细胞非特异性激活，细胞因子风暴风险高；单价 CD3 结合更安全 |
| **CD3 端亲和力** | 中等亲和力（nM 级别）   | 过高亲和力 → 系统性 T 细胞激活毒性；过低亲和力 → 效率不足                     |
| **肿瘤靶点端**   | 单价或双价，高亲和力    | 确保 bsTCE 优先结合肿瘤细胞，而非游离于血液中                                 |

### 血液瘤 vs 实体瘤 bsTCE 的发展差异

| 肿瘤类型   | 发展速度 | 主要挑战                                                       | 代表获批产品                                                                 |
| ---------- | -------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **血液瘤** | 快 ✓✓    | 相对较小（靶细胞可及性好）                                     | Blinatumomab（CD19×CD3）；Teclistamab（BCMA×CD3）；Mosunetuzumab（CD20×CD3） |
| **实体瘤** | 慢       | 肿瘤微环境免疫抑制强；T 细胞浸润不足；细胞因子风暴风险更难控制 | 多数仍在临床阶段                                                             |

## DRD2 靶点：多巴胺通路的神经系统与肿瘤双重意义

:::answer

### DRD2 的分子生物学基础

**多巴胺 D2 受体（DRD2，Dopamine D2 Receptor）** 是 G 蛋白偶联受体（GPCR）家族成员，与多巴胺通路的多个关键分子共同构成中枢神经系统的重要信号网络：

| 通路关键分子            | 功能                                         | 临床应用                               |
| ----------------------- | -------------------------------------------- | -------------------------------------- |
| **DRD2**                | 多巴胺信号的后突触受体，抑制性 Gi 蛋白偶联   | 抗帕金森（激动剂）、抗精神病（拮抗剂） |
| **多巴胺转运体（DAT）** | 多巴胺的突触前重摄取，调控突触间隙多巴胺浓度 | 影响多巴胺能药物的体内 PK 过程         |
| **酪氨酸羟化酶（TH）**  | 多巴胺合成的限速酶（酪氨酸 → L-DOPA）        | 帕金森病的关键病理靶点                 |

### DRD2 在帕金森病治疗中的核心作用

帕金森病（PD）的核心病理是**黑质纹状体多巴胺能神经元进行性变性**，导致纹状体多巴胺缺乏：

```
正常状态：黑质 DA 神经元 → 释放多巴胺 → 纹状体 DRD1/DRD2 激活 → 运动协调
          ↓ 帕金森病时
黑质 DA 神经元变性死亡 → 多巴胺缺乏 → 纹状体失调 → 运动障碍（静止性震颤、僵直、运动迟缓）
```

**主要治疗药物的作用靶点：**

| 药物                   | 机制                                                  | 靶点               |
| ---------------------- | ----------------------------------------------------- | ------------------ |
| **多巴丝肼（美多巴）** | L-DOPA（多巴胺前体）补充 + 苄丝肼（外周脱羧酶抑制剂） | 补充多巴胺         |
| **普拉克索**           | DRD2/DRD3 激动剂（优先激动 D3）                       | DRD2/DRD3 直接激动 |
| **罗匹尼罗**           | DRD2/DRD3 激动剂                                      | DRD2/DRD3 直接激动 |

> **临床挑战**：多巴丝肼和普拉克索的临床疗效个体差异显著，部分源于 DRD2 和 DAT 的**基因多态性**差异（如 DRD2 Taq1A 多态性影响受体表达密度）。

### DRD2 在肿瘤领域的新发现

DRD2 在肿瘤生物学中的多重功能正在被揭示，主要在乳腺癌（BrCa）的研究中取得进展：

| DRD2 的抗肿瘤功能    | 具体机制                                                       |
| -------------------- | -------------------------------------------------------------- |
| **与生存时间正相关** | DRD2 高表达与 HER2 阳性乳腺癌患者更长生存期相关                |
| **促进化疗敏感性**   | DRD2 表达促进 BrCa 细胞对紫杉醇的敏感性                        |
| **抑制肿瘤发生**     | DRD2 异位表达显著抑制 BrCa 体内肿瘤形成                        |
| **诱导细胞死亡**     | 体内外均可诱导肿瘤细胞凋亡和坏死                               |
| **抑制 NF-κB 信号**  | 通过与 β-arrestin2、DDX5、eEF1A2 相互作用抑制 NF-κB 激活       |
| **调节肿瘤微环境**   | 促进肿瘤相关巨噬细胞（TAM）M1 极化 + 触发 GSDME 介导的细胞焦亡 |

> **转化潜力**：DRD2 作为肿瘤抑制因子的发现，提示多巴胺受体激动剂（如已上市的帕金森病药物普拉克索）可能具有抗肿瘤的潜在再利用（Drug Repurposing）价值。

## 钙离子通道（Calcium Channel）靶点：精准调控的钙信号传导机制

:::answer

### 钙离子通道的生物学定位

**钙离子通道（Calcium Channel）** 是严格控制 Ca²⁺ 进入细胞的跨膜蛋白复合物。Ca²⁺ 作为第二信使，参与几乎所有重要的细胞生理功能：

| Ca²⁺ 信号相关功能 | 具体效应                                                            |
| ----------------- | ------------------------------------------------------------------- |
| **心脏收缩**      | L 型钙通道（Cav1.2）介导心肌兴奋-收缩偶联                           |
| **神经递质释放**  | P/Q 型（Cav2.1）和 N 型（Cav2.2）控制突触前 Ca²⁺ 进入，触发囊泡融合 |
| **基因转录**      | Ca²⁺/CaM → CaMKII/NFAT 激活 → 基因表达调控                          |
| **细胞凋亡**      | 过度 Ca²⁺ 超负荷激活 Calpain，触发凋亡通路                          |
| **免疫细胞激活**  | T/B 细胞活化依赖 Ca²⁺-NFAT 通路（CRAC 通道，Orai1/STIM1）           |

### 钙调蛋白（CaM）介导的通道自调节机制

每个钙离子通道与一个**钙调蛋白（Calmodulin，CaM）分子**结合，形成精准的 Ca²⁺ 浓度感受-反馈调节系统：

```
Ca²⁺ 进入细胞 → 与通道结合的 CaM 感应局部 Ca²⁺ 变化
          ↓
CaM C 端小叶（C-lobe）感应局域高浓度 Ca²⁺ 振荡
    （由主通道 Ca²⁺ 流直接引起）→ 快速钙依赖性失活（CDI）
CaM N 端小叶（N-lobe）感应来自更远源头的全局低浓度 Ca²⁺ 变化
    → 钙依赖性促进（CDF，Ca²⁺-dependent facilitation）
          ↓
实现通道活性的双向精细调节
```

### 钙离子通道的药物靶点应用

| 通道类型                | 分布                          | 相关疾病                 | 代表药物                                        |
| ----------------------- | ----------------------------- | ------------------------ | ----------------------------------------------- |
| **L 型（Cav1.2/1.3）**  | 心脏、血管平滑肌、胰岛 β 细胞 | 高血压、心律失常、心绞痛 | 氨氯地平、硝苯地平（CCB 类降压药）              |
| **P/Q 型（Cav2.1）**    | 脑突触前终端                  | 偏头痛、共济失调         | 加巴喷丁（N-型钙通道间接调节）                  |
| **N 型（Cav2.2）**      | 脊髓感觉神经元                | 神经病理性疼痛           | 齐考诺肽（Ziconotide，鞘内注射 N 型通道阻断剂） |
| **T 型（Cav3.x）**      | 心脏起搏细胞、神经元          | 癫痫、心律失常           | 依托琥珀酰胺（Ethosuximide，T 型通道阻断）      |
| **CRAC（Orai1/STIM1）** | 免疫细胞                      | 炎症、自身免疫           | Tozasertib（在研 Orai1 抑制剂）                 |

## TOP2（拓扑异构酶 II）靶点：DNA 拓扑结构调控与化疗药物作用机制

:::answer

### DNA 拓扑异构酶的生物学功能

**DNA 拓扑异构酶（DNA Topoisomerase）** 是细胞核内的一类酶，通过催化 DNA 链的切断和重连，控制 DNA 的拓扑状态（超螺旋、连接数等），是 DNA 复制、转录和染色体分离的必要酶。

哺乳动物中存在两大类：

| 类型                      | 机制                                               | 功能                              |
| ------------------------- | -------------------------------------------------- | --------------------------------- |
| **Top1（拓扑异构酶 I）**  | 切断 DNA 单链 → 允许解旋 → 重新连接                | 消除 DNA 复制和转录中的正超螺旋   |
| **Top2（拓扑异构酶 II）** | **切断 DNA 双链** → 另一段 DNA 双链穿过 → 重新连接 | 解开 DNA 双链缠结、解链染色体分离 |

### Top2 的两个亚型

| 亚型                 | 表达模式                         | 功能特点                                                      |
| -------------------- | -------------------------------- | ------------------------------------------------------------- |
| **Top2α（Top IIα）** | 增殖细胞中高表达，分裂期尤为显著 | 主要参与 DNA 复制和染色体分离，是肿瘤的核心靶点               |
| **Top2β（Top IIβ）** | 分化/静止细胞中表达              | 主要参与基因转录调控；心脏毒性（蒽环类药物）可能与 Top2β 相关 |

### Top2 抑制剂（毒素类）的作用机制

**Top2 毒素类药物**与经典的酶抑制剂不同，其作用机制是**稳定 DNA-Top2 共价可裂解复合物（Cleavable Complex）**：

```
正常情况：Top2 切断 DNA 双链 → DNA 双链穿过 → 断口重新连接（完整反应）

Top2 毒素介入：
    稳定 DNA-Top2-药物三元复合物（可裂解复合物无法重连）
          ↓
    当 DNA 复制叉或转录复合物碰到"冻结的"可裂解复合物时
          ↓
    产生永久性双链断裂（DSB）
          ↓
    激活 ATM/ATR/Chk1/2 DNA 损伤检查点 → 细胞周期停滞
          ↓
    p53 激活 → Caspase 级联 → 细胞凋亡
```

> **核心逻辑**：Top2 毒素**将酶转变为毒素（Enzyme-to-Poison Conversion）**——被固定的 Top2 不再是有用的酶，而变成了造成 DNA 损伤的"凶器"。

### 代表性 Top2 靶向药物

| 药物                            | 类型                   | 稳定的复合物类型       | 主要适应证               |
| ------------------------------- | ---------------------- | ---------------------- | ------------------------ |
| **多柔比星（Doxorubicin）**     | 蒽环类（嵌入型）       | Top2α-DNA 可裂解复合物 | 乳腺癌、淋巴瘤、白血病   |
| **依托泊苷（Etoposide/VP-16）** | 表鬼臼毒素（非嵌入型） | Top2α-DNA 可裂解复合物 | 小细胞肺癌、生殖细胞肿瘤 |
| **米托蒽醌（Mitoxantrone）**    | 蒽二酮类               | Top2-DNA 可裂解复合物  | AML、多发性硬化（MS）    |

### Top2 在 ADC 领域的应用

**拓扑异构酶 I 抑制剂（DXd，SN-38）** 作为 ADC 载荷已在 T-DXd（Enhertu）等产品中大放异彩，而 **Top2 抑制剂（PBD 类、蒽环类）** 同样作为 ADC 载荷用于多种产品，如 Loncastuximab tesirine（载荷为 PBD 二聚体，靶向 Top2 相关 DNA 损伤）。

## AR（雄激素受体）靶点：前列腺癌治疗的核心驱动因子

:::answer

### AR 的分子结构与转录因子功能

**雄激素受体（Androgen Receptor，AR，NR3C4）** 是核受体超家族（Nuclear Receptor Superfamily）成员，属于**配体依赖性转录因子**：

```
雄激素（睾酮/DHT）进入细胞
          ↓ 与 AR 配体结合域（LBD）结合
AR 构象改变 → 热休克蛋白（HSP90）解离
          ↓
AR 同二聚体化 → 入核转运
          ↓ 结合雄激素反应元件（ARE）
目标基因转录激活（PSA、TMPRSS2 等）
          ↓
前列腺细胞增殖、存活、分化
```

### AR 在前列腺癌中的核心驱动作用

前列腺癌（PCa）是 AR 信号驱动的典型实体瘤：

| 阶段                                  | AR 的作用                                                          | 治疗策略                             |
| ------------------------------------- | ------------------------------------------------------------------ | ------------------------------------ |
| **局限性前列腺癌**                    | AR 驱动前列腺上皮细胞增殖                                          | 手术/放疗                            |
| **转移性激素敏感性前列腺癌（mHSPC）** | 高度依赖睾酮（经典 AR 信号）                                       | 雄激素剥夺治疗（ADT）：手术/药物去势 |
| **转移性去势抵抗性前列腺癌（mCRPC）** | AR 通过扩增/突变/剪接变异体（AR-V7）维持活性（低睾酮环境下仍活跃） | 新一代 AR 通路抑制剂（ARSI）         |

### AR 靶向药物的三代发展

| 世代                    | 代表药物                                                                    | 作用机制                                          | 耐药机制                                    |
| ----------------------- | --------------------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------- |
| **第一代抗雄激素**      | 比卡鲁胺、氟他胺                                                            | 竞争性拮抗 AR LBD                                 | AR 突变（LBD 突变）→ 拮抗剂变激动剂         |
| **第二代 ARSI**         | 恩扎鲁胺（Enzalutamide）、阿帕他胺（Apalutamide）、达罗他胺（Darolutamide） | 高亲和力 AR 拮抗剂，同时阻断 AR 核转运和 DNA 结合 | AR 基因扩增、AR-V7（缺失 LBD 的剪接变异体） |
| **CYP17A1 抑制剂**      | 阿比特龙（Abiraterone/泽珂）                                                | 抑制肾上腺和肿瘤内的雄激素合成（雄激素来源清除）  | AR 扩增，AR 点突变，肾上腺代偿增加          |
| **AR 降解剂（PROTAC）** | ARV-110（在研）、ARV-766（在研）                                            | 靶向 AR 诱导其泛素化降解（绕过 LBD 突变）         | 开发阶段                                    |

### AR 作为转录因子靶向的挑战与新策略

与其他靶点不同，AR 作为**转录因子**，其**N 端域（NTD）和 DNA 结合域（DBD）**是"无序结构"，难以被传统小分子或抗体靶向：

| 挑战                   | 说明                                    | 应对策略                                         |
| ---------------------- | --------------------------------------- | ------------------------------------------------ |
| 转录因子的"不可成药性" | NTD 无明确配体结合口袋                  | PROTAC 降解剂；靶向 N-C 端相互作用               |
| AR-V7 剪接变异体       | 缺失 LBD，不受恩扎鲁胺等 LBD 拮抗剂影响 | 靶向 DBD 或 NTD 的小分子；PROTAC（可降解 AR-V7） |
| 整合信号的复杂性       | AR 与 PI3K/AKT、WNT 等通路交叉对话      | 联合治疗（AR 拮抗 + PI3K/AKT 抑制）              |
