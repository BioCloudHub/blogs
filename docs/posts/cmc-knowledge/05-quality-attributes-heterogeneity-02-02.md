## 抗体电荷异质性的知识体系概览：形成机制、分析方法与调控策略

:::answer

**为什么电荷异质性是抗体药物的核心质量属性**

抗体的电荷异质性（Charge Heterogeneity）是指同一批次单抗中存在的多种带电荷形式，通常通过离子交换色谱（IEX）或毛细管等电聚焦电泳（cIEF/iCIEF）分析，表现为酸性峰（Acidic Variants）、主峰（Main Peak）和碱性峰（Basic Variants）的分布格局。

**电荷异质性的主要来源**

| 修饰类型                         | 所在位置         | 电荷影响方向               | 主要来源               |
| -------------------------------- | ---------------- | -------------------------- | ---------------------- |
| C 端赖氨酸不完全剪切（Lys clip） | 重链 C 端        | 碱性化（+1 正电荷/链）     | 细胞内羧肽酶活性差异   |
| N 端焦谷氨酸化（pyroGlu）        | 重链 / 轻链 N 端 | 酸性化（消除正电荷）       | N 端 Gln/Glu 自发环化  |
| 脱酰胺（Deamidation）            | Asn/Gln 残基     | 酸性化（引入负电荷）       | 化学降解，热/碱促进    |
| 氧化（Oxidation）                | Met、His、Trp    | 可引起微弱酸性化           | 氧化剂、光照、金属离子 |
| 唾液酸化（Sialylation）          | 糖基化结构       | 酸性化（唾液酸携带负电荷） | 细胞内糖基化酶活性     |
| 糖基化缺失/变化                  | Asn297           | 影响整体电荷分布           | 培养条件变化           |

**分析方法体系**

| 分析目的                 | 常用方法                             |
| ------------------------ | ------------------------------------ |
| 电荷变体谱分析（常规）   | IEX（离子交换色谱）：CIEC、CEX-HPLC  |
| 等电点测定与电荷变体分辨 | cIEF、iCIEF（毛细管等电聚焦电泳）    |
| 电荷变体结构鉴定         | LC-MS/MS 肽图分析（Peptide Mapping） |
| 批间一致性监控           | IEX 相对峰面积百分比                 |

**工艺调控的核心思路**

电荷异质性的调控策略分两个层面：① **上游调控**——通过培养条件优化（pH、温度、补料策略）影响修饰形成；② **下游调控**——通过阳离子交换层析（CEX）对电荷变体进行富集或去除，精确控制酸性峰/碱性峰比例，满足产品质量规格要求。

:::

## 生物反应器中二氧化碳的来源分类、代谢影响机制与工艺控制策略

:::answer

**CO₂ 的来源分类**

生物反应器中的 CO₂ 来源分为两类：

| 来源类型   | 具体来源                                              | 主导培养模式              |
| ---------- | ----------------------------------------------------- | ------------------------- |
| 生物来源   | 细胞有氧代谢（TCA 循环）产生的 CO₂                    | 各种培养模式均有          |
| 非生物来源 | 培养基中的 NaHCO₃；为维持 pH 加入的 CO₂/NaHCO₃/Na₂CO₃ | 连续培养/灌流培养中更显著 |

- 在**批式或补料批次（Fed-batch）培养**中，CO₂ 主要由细胞代谢产生；
- 在**连续/灌流培养**中，由于培养基持续流加，非生物来源的 CO₂（碳酸盐缓冲体系）贡献显著增加。

**CO₂ 积累对细胞和工艺的影响机制**

CO₂ 极易溶于水（溶解度远高于 O₂），通过气液界面和细胞膜快速扩散进入细胞，引发以下级联效应：

**① pH 下降（最主要机制）**

```
CO₂ + H₂O → H₂CO₃ → H⁺ + HCO₃⁻
```

pCO₂ 升高 → 溶液中 H⁺ 浓度增加 → pH 下降 → 加入碱液（NaHCO₃/Na₂CO₃）补偿 → 渗透压升高。

**② 渗透压升高（间接效应）**

持续加碱 → 渗透压上升 → 细胞膜离子交换活性改变 → 胞内离子浓度增加 → 对胞内酶活性产生不利影响（尤其是糖基化相关酶）。

**③ 细胞代谢抑制**

研究显示，pCO₂ 升高会：

- 降低 CHO 细胞的葡萄糖和谷氨酰胺比消耗速率；
- 降低乳酸比生产速率（但对氨的比生成速率无显著影响）；
- 显著抑制产物表达——pCO₂ 从 36 mmHg 提高至 140 mmHg 和 190 mmHg 时，CHO 细胞生产 tPA 的比生成速率（Qp）分别下降 10% 和 33%（Kimura 等）。

**④ 糖基化质量属性影响**

pCO₂ 过高可影响高尔基体内部 pH 梯度，干扰糖基转移酶活性（尤其是半乳糖基转移酶），导致高甘露糖型（High Mannose）比例升高，糖型成熟度下降。

**CO₂ 毒性阈值**

当生物反应器内 CO₂ 浓度（以气相百分比计）达到 **15%～20%** 时，会对细胞产生明显毒害作用，是工艺控制的关键警戒线。

**工艺控制策略**

| 控制手段                   | 效果              | 适用性                 |
| -------------------------- | ----------------- | ---------------------- |
| 增大深层通气量（底部进气） | 显著降低 pCO₂     | 最有效，优先采用       |
| 使用大泡分布器（毫米级）   | 显著增强 CO₂ 排出 | 适合商业化大罐         |
| 增加表层通气量             | 对 pCO₂ 影响较小  | 辅助手段               |
| 改变搅拌转速               | 对 pCO₂ 影响较小  | 效果有限               |
| NaHCO₃ 缓冲体系            | 缓冲 pH 波动      | 浓度超出范围时效果有限 |

> **工程矛盾：** 为满足大规模高密度培养的供氧需求，微泡分布器（microsparger）被广泛采用——微泡增大气液接触面积，提高 KLa；但微泡在液体中停留时间长，O₂ 持续溶解导致气泡直径缩小，**CO₂ 移除速率随之降低**，形成供氧与排 CO₂ 的工程矛盾。实践中需通过大泡 + 微泡分布器组合使用来平衡两者。

:::

## 单抗 N-糖高甘露糖型的生物合成路径与形成机制

:::answer

**N-糖合成的细胞器分工**

N-糖的合成是一个在内质网（ER）和高尔基体（Golgi）中依次完成的多步骤酶催化过程，内质网负责核心寡糖的合成与转移，高尔基体负责糖链的修剪、加工和延伸。

**N-糖合成的四步核心路径**

**第一步（内质网表面）：** 核心寡糖组装

在多萜醇磷酸（Dolichol-P）载体上，由 GDP-Man 和 UDP-GlcNAc 依次添加，合成含 **2 个 GlcNAc + 5 个甘露糖**的前体多糖（GlcNAc₂Man₅）。

**第二步（内质网腔）：** 葡萄糖和甘露糖扩展

GlcNAc₂Man₅ 进一步添加 3 个葡萄糖残基和 4 个甘露糖残基，形成 **3Glc-GlcNAc₂Man₉**（14 糖核心寡糖）。

**第三步（内质网腔）：** 转移至蛋白 + 初步修剪

3Glc-GlcNAc₂Man₉ 通过寡糖基转移酶（OST）连接至抗体 **Asn297 位**（序列共识：Asn-X-Ser/Thr），随后在葡糖苷酶 I/II 和甘露糖苷酶的作用下依次切除 3 个葡萄糖残基和 1 个甘露糖残基，剩余 **GlcNAc₂Man₈**。

**第四步（高尔基体）：** 复杂型 N-糖的成熟

携带 GlcNAc₂Man₈ 的抗体进入高尔基体，甘露糖苷酶 I/II 继续切除高甘露糖残基；随后糖基转移酶添加岩藻糖（Fuc）、N-乙酰葡糖胺（GlcNAc）、半乳糖（Gal）、唾液酸（NeuAc/NeuGc），最终合成成熟的复杂型 N-糖结构（如 G0F、G1F、G2F 等）。

**高甘露糖型的形成原因**

高甘露糖型（High Mannose，Man5～Man9）的出现，根本原因在于**高尔基体内的甘露糖修剪过程不完全**，主要触发机制包括：

- **酶活性下降：** 甘露糖苷酶 I/II 活性受培养条件（低温、高 pCO₂、渗透压）影响而降低；
- **底物竞争与酶系统过载：** 比生产速率（qp）过高时，胞内蛋白浓度过大，糖基化酶系统处理能力达到瓶颈；
- **核苷酸糖底物（UDP-GlcNAc 等）供给不足：** 培养后期底物可及性降低，限制糖链延伸；
- **胞内运输障碍：** pH 偏差导致内质网-高尔基体间转运效率下降。

**行业控制标准**

针对抗体药物，Man5（最常见的高甘露糖型）含量通常控制在 **10% 以内**，高敏感型适应症（如需要强效 ADCC）有时可宽松至 15%，具体须结合临床前 PK/PD 数据确认。

:::

## 高甘露糖修饰的两面性：免疫原性与清除风险 vs. ADCC 增强效应的权衡

:::answer

**不利方面：免疫原性与加速清除**

**① 高免疫原性风险**

大多数研究证实，高甘露糖结构具有较强的**免疫原性**。在哺乳动物细胞表达系统中，即使是正常水平的高甘露糖型，其本身已是控制目标；高甘露糖比例过高会增加产品免疫反应风险，尤其对于反复给药的慢性病治疗产品。

**② 体内快速清除（半衰期缩短）**

糖蛋白（包括重组单抗）在体内的清除途径除 FcRn 通路外，还涉及两类受体：

| 受体                        | 位置                         | 识别结构          | 清除机制 |
| --------------------------- | ---------------------------- | ----------------- | -------- |
| 无唾液酸糖蛋白受体（ASGPR） | 肝脏                         | 末端半乳糖/GlcNAc | 内吞降解 |
| 甘露糖受体（MR）            | 肝脏巨噬细胞（Kupffer 细胞） | 末端甘露糖        | 内吞降解 |

含有高甘露糖结构的单抗（Fc 段甘露糖暴露）可被甘露糖受体识别并通过内吞作用加速清除，导致血浆半衰期显著缩短，从而降低其效应功能持续时间。

> **注意文献争议：** 部分文献报道，血清中存在甘露糖苷酶可降解高甘露糖型 N-糖（Man7～9 被转化为 Man5），使得体内实际暴露的高甘露糖比例低于体外检测值；因此高甘露糖型对半衰期的影响程度存在争议。但**主流共识仍认为高甘露糖型（尤其是 Man5）可缩短单抗半衰期**，应严格控制其比例。

**有利方面：ADCC 增强效应**

岩藻糖（Fucose）的存在会减弱抗体 Fc 与效应细胞上 **FcγRIIIa**（CD16）的结合，从而降低 ADCC（抗体依赖性细胞毒性）效应。由于**高甘露糖型结构均为去岩藻糖化（Afucosylated）**，含高甘露糖型的单抗与 FcγRIIIa 的结合亲和力更高，ADCC 活性较含岩藻糖的单抗更强。

**权衡决策框架**

| 维度            | 高甘露糖含量升高的影响   | 决策倾向     |
| --------------- | ------------------------ | ------------ |
| 免疫原性        | 升高                     | 降低         |
| 半衰期（PK）    | 缩短                     | 降低         |
| ADCC 活性（PD） | 增强                     | 视适应症而定 |
| 给药剂量        | 可能需增加（因半衰期短） | 增加生产成本 |

**行业实践：** 利用高甘露糖增强 ADCC 效应的项目通常给药剂量较高，且须在临床前阶段充分建立 PK/PD 的定量关系，并在 CMC 开发中建立可靠的高甘露糖型控制策略。

## 高甘露糖修饰的工艺调控一：培养条件（温度、pH、渗透压、培养时间）的影响机制

:::answer

培养条件是调控高甘露糖型水平的最直接手段，以下四个参数对糖基化质量属性影响最为显著。

**① 温度**

低温培养（亚低温策略，通常 33～35℃，相比常规 36～37℃）对糖基化的影响机制：

- 核苷酸糖供体（UDP-GlcNAc、UDP-Gal 等）的合成量减少；
- 负责糖链延伸的糖基转移酶（尤其是 **UDP-半乳糖基转移酶**）表达量和活性下降；
- UDP-GlcNAc 的细胞内转运速率降低（但 GnT-I 表达水平不受影响）。

综合结果：低温培养可能导致半乳糖化水平下降，未完全加工的糖型（包括 HM）比例升高。**UDP-半乳糖基转移酶的合成与活性是亚低温条件下糖基化变化的关键决定因素。**

**② pH**

pH 对糖基化的影响通过以下路径实现：

- **细胞质 pH 降低：** 内质网-高尔基体间转运能力下降；在极端情况下可诱导高尔基体降解，导致 HM 含量升高。
- **弱碱（高 pH）：** 高尔基体内腔 pH 值升高，干扰糖基转移酶功能，尤其影响半乳糖基转移酶和唾液酸转移酶（这些酶在低 pH 环境下活性更高）——pH 偏高反而抑制糖型向更成熟的复杂型转化。

**结论：** 不同细胞器之间须维持严格的 pH 梯度（ER 内腔 pH 约 7.0～7.2，顺式高尔基体 pH 约 6.7，反式高尔基体 pH 约 6.0）；pH 偏高或偏低均会导致 HM 含量增加，但机制不同。

**③ 渗透压**

极端高渗条件对糖基化的影响：

- 高渗（如 > 400 mOsm/kg）会抑制细胞生长，降低细胞活率和 Titer；
- 导致 Man5（最常见 HM 种类）含量显著升高；
- 机制分析：高渗与正常条件下 **GnT-I 的 RNA 转录水平无显著差异**，HM 升高主要由于糖基化途径相关酶的**比活（Specific Activity）下降**所致；
- **缓解措施：** 可通过添加<strong>渗透压保护剂甜菜碱（Betaine）</strong>降低高渗引起的 HM 升高。

**④ 培养时间**

延长培养时间虽可显著提高蛋白产量，但培养后期糖基化加工质量往往下降：

- 核苷酸糖底物（UDP-GlcNAc、UDP-Gal）的**可及性成为瓶颈**，底物供给不足限制糖链延伸；
- 高尔基体相关酶（甘露糖苷酶、糖基转移酶）的表达量或活性在培养后期下降；
- 结果：HM 比例随培养时间延长而升高，糖型成熟度下降。

**四个参数的综合管理建议**

在工艺开发中，上述四个参数往往相互耦合（如低温→代谢减缓→pH 稳定性变化→渗透压波动），须通过 DoE 系统评估其交互作用，并在工艺表征阶段建立各参数对 HM 影响的定量关系。

:::

## 高甘露糖修饰的工艺调控二：培养基组分（胆碱、氨基酸）与金属离子（Mn²⁺）的调节机制

:::answer

**培养基组分的影响**

培养基组成对高甘露糖型水平的影响已被大量研究证实——**同一 CHO 细胞系使用不同培养基时，HM 水平变化范围可达 5%～16%**，充分说明培养基优化是控制糖基化质量属性的重要工艺杠杆。

**关键组分：胆碱（Choline）**

胆碱是培养基中常见的必需组分，在糖基化调控中的作用机制：

- 胆碱是生物膜合成（磷脂酰胆碱和鞘磷脂）的重要前体，在支持细胞生长和单抗生产中不可或缺；
- 胆碱浓度不足时：细胞活率下降、单抗 Titer 降低、聚集体增加，**Man5（HM 主要形式）含量升高**；
- 通过提高培养基中胆碱浓度，可有效缓解上述质量偏差。

**其他影响 HM 水平的培养基组分**

| 组分                 | 影响方向                    | 机制概述                                                 |
| -------------------- | --------------------------- | -------------------------------------------------------- |
| 精氨酸（Arginine）   | 影响 HM 水平（浓度依赖）    | 精氨酸参与细胞能量代谢和 NO 合成，高浓度时可能影响糖基化 |
| 鸟氨酸（Ornithine）  | 影响 HM 水平                | 参与尿素循环，与精氨酸代谢关联                           |
| 精氨酸酶（Arginase） | 影响精氨酸水平，间接影响 HM | 催化精氨酸分解，降低精氨酸可及性                         |

**金属离子：Mn²⁺ 的精准调控**

Mn²⁺（锰离子）是糖基化途径中多种关键酶（特别是 **GnT-I，N-乙酰葡糖胺基转移酶 I**）的辅因子，是调节 HM 含量最有效的微量元素干预手段。

**Mn²⁺ 对各高甘露糖亚型的差异影响：**

| HM 亚型 | Mn²⁺ 添加后的变化     | 机制解析                                                                |
| ------- | --------------------- | ----------------------------------------------------------------------- |
| Man5    | 显著下降              | GnT-I 的直接底物是 Man5，Mn²⁺ 加速 GnT-I 周转率，Man5 被优先加工        |
| Man6    | 下降（幅度小于 Man5） | Man5 被消耗后，Man6→Man5 的前置步骤可能因 Man5 积累而减速，但整体下降   |
| Man7    | 基本不受影响          | 原因：α1,2-甘露糖苷酶（负责 Man7→Man6）为**钙依赖性酶**，不受 Mn²⁺ 调节 |

**操作要点：**

- 适度补充 Mn²⁺（约 **1 μM**）可有效加速 GnT-I 周转率，降低 HM 总量，尤其是 Man5；
- 剂量须严格控制：过量 Mn²⁺ 对细胞有毒性，并可能影响其他质量属性（如电荷变体分布）；
- Mn²⁺ 通常通过补料（Feed）方式添加，在工艺开发阶段需系统优化浓度和添加时机。

:::

## 高甘露糖修饰的工艺调控三：分子类型（LC 同型）、比生产速率与培养模式的影响

:::answer

**① 分子类型：轻链同型（LCκ vs. LCλ）的差异**

研究表明，抗体轻链（LC）的同型类别会显著影响 HM 水平：

| 轻链同型    | HM 水平  | 波动性 | 原因                                                                          |
| ----------- | -------- | ------ | ----------------------------------------------------------------------------- |
| κ 型（LCκ） | 相对较低 | 较稳定 | 胞内组装速度较快，在高尔基体内停留时间正常                                    |
| λ 型（LCλ） | 相对较高 | 较大   | 胞内组装（轻链+重链配对）较慢，抗体在内质网停留时间延长，导致高甘露糖前体积累 |

**工程意义：** 在候选分子筛选阶段，若候选抗体为 LCλ 同型，应在工艺开发早期即关注 HM 的控制策略，必要时在 CMC 开发阶段建立针对性的培养基优化或 Mn²⁺ 添加策略。

**② 比生产速率（qp，Specific Productivity）**

高强化工艺条件下，qp 与 HM 水平之间存在正相关趋势：**qp 越高，HM 水平往往越高。** 原因包括：

- **空间位阻效应：** 胞内目标蛋白浓度过高，糖基化加工酶在对底物发挥作用时受到空间阻碍；
- **细胞器和酶系统过载：** qp 过高导致高尔基体处理能力达到极限，部分蛋白在糖基化成熟前即被转运至细胞外，携带未成熟糖型（即 HM）。

**工程意义：** 在工艺强化（如采用高细胞密度策略、高比生产速率诱导条件）与糖基化质量之间须寻求平衡，不能一味追求高产量而忽视质量属性的变化。

**③ 培养模式：灌流 vs. 补料批次**

| 比较维度 | 灌流培养（Perfusion）                                                                          | 补料批次（Fed-batch）                            |
| -------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| HM 水平  | 通常更低，且稳定                                                                               | 相对较高，随培养时间延长升高                     |
| 原因     | 持续补充新鲜培养基，核苷酸糖底物供应充足，抑制性副产物（乳酸、氨）持续稀释，酶系统处于相对稳态 | 培养后期底物耗竭，副产物积累，糖基化加工质量下降 |
| 例外     | 灌流率过低→营养限制→HM（Man5）升高                                                             | —                                                |

**综合调控策略优先级建议**

1. **首选：** 培养基优化（Mn²⁺ 添加、胆碱补充）——效果最稳定，批间一致性好；
2. **次选：** 工艺参数调整（pH 控制、温度策略、渗透压管理）——需结合 DoE 系统评估；
3. **考虑：** 培养模式切换（Fed-batch → Perfusion）——对稳定 HM 效果好，但工艺复杂度大幅提升；
4. **下游把关：** CEX 或其他精纯步骤对 HM 水平的微调——有效但受到分辨率限制。

:::

## CQA 与 KPA 的定义、评估框架与逆向推导方法

:::answer

**关键质量属性（CQA）的标准定义**

根据 ICH Q8（R2）：关键质量属性（Critical Quality Attribute, CQA）是指物理、化学、生物学或微生物学的性质或特征，应当维持在适当的限度、范围或分布内，以保证预期的产品质量。

CQA 的核心判断标准：**该属性是否直接或间接影响产品的安全性（Safety）、有效性（Efficacy）或可比性（Comparability）？**

**KPA（重要工艺属性）的定义与区别**

重要工艺属性（Key Process Attribute, KPA）是评估工艺性能的属性，如果超出范围，可能导致工艺失败（而非直接影响产品质量）。KPA 须针对每一个工艺步骤（上下游各单元操作）分别设定，与 CQA 形成互补的双层质量控制体系。

| 概念 | 影响对象          | 一旦超出范围的后果     | 设定层级           |
| ---- | ----------------- | ---------------------- | ------------------ |
| CQA  | 产品安全性/有效性 | 产品质量不符合要求     | 最终产品及中间体   |
| KPA  | 工艺稳定性/重现性 | 工艺失败或批次偏差     | 各单元操作分别设定 |
| CPP  | 工艺参数控制      | 对 CQA 产生显著影响    | 各工序关键参数     |
| CMA  | 原辅料质量        | 影响产品质量或工艺性能 | 原辅料属性         |

**CQA 评估的逆向推导方法**

CQA 评估遵循从终产品向原辅料的**逆向推导逻辑**：

```
最终产品 CQA 评估
        ↓（逆向逐工序推导）
中间产品关键质量属性评估（定义为 CQA）
        ↓
原辅料关键物料属性评估（定义为 CMA）
```

**重要原则：** 物料属性可以**跨越工序传递或影响**（如上游工艺的蛋白糖型可传递至最终产品），评估须采用**所有工序联合的矩阵式方法**，而非仅在相邻工序之间分析。

**CQA 的动态性**

CQA 的确定不是一次性的，而是随药品开发生命周期持续演化：

- **早期开发（IND 阶段）：** 基于先验知识、文献、同类产品数据初步确定潜在 CQA，指导工艺开发方向；
- **临床阶段：** 随临床前/临床数据积累（PK/PD 相关性、免疫原性研究），动态调整 CQA 清单；
- **BLA 申报阶段：** 通过工艺表征数据（DoE、参数相关性研究）最终确定经验证的 CQA 及其可接受范围。

:::

## 关键质量属性的风险评估工具与量化方法

:::answer

**CQA 评估的核心逻辑**

CQA 的评估本质是一种**质量风险管理（Quality Risk Management, QRM）**活动，核心问题是：某个质量属性对产品临床安全性和有效性的影响有多大，以及当前对该属性与临床结局关系的认知有多深。

**常用风险评估工具**

| 工具 | 全称                                         | 核心算法          | 适用场景                                         |
| ---- | -------------------------------------------- | ----------------- | ------------------------------------------------ |
| RRF  | Risk Ranking and Filtering（风险排序与过滤） | 影响度 × 不确定性 | 属性优先级排序，特别适合质量属性众多时的初步筛选 |
| PHA  | Preliminary Hazards Analysis（初步危险分析） | 定性风险矩阵      | 开发早期、数据有限时的半定量评估                 |
| PQAA | Product Quality Attribute Assessments        | 多维度权重评分    | 系统性质量属性综合评估，适合 BLA 阶段            |

**两套量化评分公式**

```
工具一：关键性（Risk Score）= 影响度（Impact）× 不确定性（Uncertainty）

工具二：关键性（RPN）= 严重性（Severity）× 可能性（Likelihood）
```

> **选择原则：** 工具一（影响度 × 不确定性）更适合早期阶段——当数据有限时，"不确定性"更能体现知识缺口；随着开发深入，逐步转向工具二（严重性 × 可能性）的定量评估模式。不同工具的评估结果可能有所差异，最终决策更取决于**对产品和工艺的理解深度**，而非工具本身。

**评估结果的两个区分**

| 评估结论     | 后续管理要求                                                                            |
| ------------ | --------------------------------------------------------------------------------------- |
| 确定为 CQA   | 须明确列入生产工艺规程或质量标准，执行严格工艺控制或 GMP 管理；须给出评估理由和控制方案 |
| 确定为非 CQA | 可不列入质量标准，通过其他质量管理手段（如工艺监控）进行管理                            |

**CQA 评估在产品生命周期中的作用**

CQA 评估贯穿药品研发全生命周期，其结果直接影响：① 控制策略的制定；② 放行和稳定性质量标准的建立；③ 工艺表征研究的设计；④ 工艺验证方案的范围；⑤ 可比性研究的关键属性选择。

:::

## 单抗典型关键质量属性（CQA）分类汇总与监管要求

:::answer

单抗类生物药的 CQA 体系通常涵盖以下五大类别，各类属性在安全性、有效性和生产质量控制中分别承担不同功能。

**第一类：产品相关质量属性（Product-Related Variants）**

| 属性                        | 典型分析方法     | CQA 评估核心依据                    |
| --------------------------- | ---------------- | ----------------------------------- |
| 高分子量物质（聚集体，HMW） | SEC-HPLC         | 免疫原性风险（最高优先级 CQA）      |
| 低分子量物质（片段，LMW）   | CE-SDS（非还原） | 效力降低风险                        |
| 酸性/碱性变异体             | IEX、cIEF        | 对 PK/活性的潜在影响                |
| 高级结构（二级/三级结构）   | DSC、CD、HDX-MS  | 影响折叠与活性                      |
| 氨基酸序列（一级结构）      | LC-MS/MS 肽图    | 产品鉴别与完整性的基础              |
| 糖基化谱（N-糖型分布）      | 荧光 HPLC、LC-MS | 影响 Fc 效应功能（ADCC/CDC/半衰期） |

**第二类：工艺相关杂质（Process-Related Impurities）**

| 属性                | 典型分析方法                  | 来源                   |
| ------------------- | ----------------------------- | ---------------------- |
| 宿主细胞 DNA（HCD） | qPCR                          | 细胞裂解释放           |
| 宿主细胞蛋白（HCP） | ELISA（多克隆/单克隆）、LC-MS | 上游培养/收获          |
| Protein A 残留      | ELISA                         | Protein A 层析配基脱落 |
| 残余培养基组分      | 适用方法                      | 批次差异               |

**第三类：生物活性（Biological Activity）**

| 属性                        | 典型分析方法            |
| --------------------------- | ----------------------- |
| 相对结合活性（靶抗原结合）  | ELISA、Biacore（SPR）   |
| Fc 效应功能活性（ADCC/CDC） | 细胞报告基因法、PBMC 法 |
| FcRn 结合活性               | SPR（与半衰期相关）     |

**第四类：常规质量属性（General Quality Attributes）**

蛋白含量（A280）、pH、渗透压摩尔浓度、颜色与澄清度、可见异物、水分含量（冻干制剂）、容器密封完整性。这类属性通常不被列为最高优先级 CQA，但须在质量标准中规定并放行检测。

**第五类：安全性相关（Safety-Critical Attributes）**

| 属性       | 检测方法            |
| ---------- | ------------------- |
| 支原体     | 指示细胞培养法、PCR |
| 外源病毒   | 体内/体外法         |
| 微生物限度 | 培养计数法          |
| 细菌内毒素 | LAL 鲎试验          |

## 关键质量属性的三层控制策略：原材料控制、工艺控制与检测体系的设计逻辑

:::answer

根据 ICH Q10 的定义，控制策略（Control Strategy）是指"根据当前对产品和工艺的理解而产生的一系列保证工艺性能和产品质量的有计划的控制"，覆盖从原辅料到最终产品的全链条质量保障体系。

**控制策略的三大支柱**

**支柱一：原辅料/输入材料控制**

根据输入材料对产品和工艺带来的潜在风险高低分级管理：

| 风险等级 | 典型材料举例                 | 最低控制要求                                                                         | 额外控制要求                                                                                               |
| -------- | ---------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 低风险   | 药典级原料、已上市商业培养基 | 供应商 GMP 证书 + 出厂检测报告；关键项目（鉴别、内毒素、微生物）用户内控；供应商审计 | —                                                                                                          |
| 高风险   | 非药典级原料、动物来源组分   | 上述所有要求                                                                         | 建立企业内部控制标准；动物来源材料须提供 TSE/BSE 安全证书；通过工艺表征研究量化其对 CQA 和工艺变异性的贡献 |

**支柱二：工艺控制**

工艺控制包含两个层次：

**① 工序控制（In-Process Controls, IPC）**

对每个单元操作的中间产品（中间体）设定关键质量属性的监测和放行标准，确保异常批次在工序内被拦截，不流入下一步骤。

**② 工艺参数控制**

通过工艺开发和工艺表征研究，建立各工艺参数（温度、pH、流速、载量等）的：

- **设定点（Set-Point）：** 目标操作值
- **操作范围（Operational Range, OR）：** 日常生产可接受的波动范围，须在 CR（控制范围）内
- **可接受范围（Acceptable Range, PAR）：** 工艺表征确立的参数边界，超出可能影响 CQA

**支柱三：检测（Testing）**

不同属性的检测策略因其风险等级而异：

| 检测类型                       | 目的                               | 频率                   |
| ------------------------------ | ---------------------------------- | ---------------------- |
| 工艺中控（IPC）                | 实时监控工艺状态，指导操作决策     | 每批、工序中实时       |
| 批放行检测（Lot Release）      | 保证每批产品符合质量标准后方可放行 | 每批                   |
| 工艺监控（Process Monitoring） | 监控工艺长期稳定性和趋势           | 周期性（多批汇总分析） |
| 表征检测（Characterization）   | 建立产品知识，支持 BLA 申报        | 特定研究批次           |
| 可比性检测（Comparability）    | 工艺变更前后质量一致性确认         | 变更前后对比批次       |

:::

## 关键质量属性（CQA）的完整定义与全生命周期管理要求

:::answer

**标准定义（ICH Q8 R2）**

关键质量属性（CQA）是与产品安全性和有效性直接相关的质量属性，须控制在适当的限度分布范围内，以确保产品质量符合预定要求。

**生物大分子 CQA 的特殊性**

生物大分子（如单抗）的 CQA 具有以下特点，区别于小分子药物：

- **结构复杂性：** 分子本身具有多层次结构（一级～四级结构）和翻译后修饰（糖基化、氧化、脱酰胺等），可监测属性数量远多于小分子；
- **动态性：** CQA 的清单和范围随开发阶段积累的数据而持续更新完善，早期不能一次性确定所有 CQA；
- **工艺依赖性：** 生物制品的 CQA 很大程度上由生产工艺决定，工艺变更可能改变 CQA 的分布。

**CQA 确定时的主要考量因素**

1. **临床前/临床/上市后研究数据：** PK/PD 相关性、免疫原性研究、毒理学研究；
2. **生产工艺能力：** 工艺是否能够稳定、可重现地控制该属性；
3. **工艺连续性与稳定性：** 该属性是否在多批次间保持稳定，批间变异是否可接受；
4. **同类产品数据：** 已上市产品（原研或仿制）的质量规格和研究数据提供参考依据；
5. **药典要求：** 国内外药典（《中国药典》、USP、EP）对特定属性的明确规定。

**CQA 在产品开发核心活动中的中心地位**

```
CQA 确定
    ↓              ↓              ↓              ↓
控制策略设计  放行质量标准  工艺表征研究  可比性研究设计
    ↓              ↓              ↓
工艺验证方案  稳定性方案   BLA 申报策略
```

CQA 不仅是产品质量标准的核心，更是整个 CMC 开发策略的出发点。一旦 CQA 评估出现偏差（漏评或误评），可能导致整个控制策略体系的失效。

:::

## 抗体化学降解一：氧化机制、敏感位点与对电荷异质性的影响

:::answer

**氧化降解的生物学背景**

氧化反应是抗体药物化学降解中最常见的类型之一，不仅影响产品在储存期间的稳定性，还会直接导致抗体有效性降低（特别是活性位点附近的氧化修饰）。氧化包括两种形式：

- **主动氧化：** 在氧化剂（过氧化物、活性金属离子如 Fe²⁺/Cu²⁺、光照、辐照）存在下发生；
- **自发氧化（Autoxidation）：** 在无外部氧化剂的条件下缓慢自发进行，长期储存中尤为重要。

**抗体分子中的主要氧化敏感位点**

| 氨基酸残基      | 氧化产物                 | 典型位置                                          | 对活性的影响                                                          |
| --------------- | ------------------------ | ------------------------------------------------- | --------------------------------------------------------------------- |
| 甲硫氨酸（Met） | 甲硫氨酸亚砜（Met-O）    | Fc 区 Met252、Met428（FcRn 结合区域附近）；CDR 区 | Met252/428 氧化可降低 FcRn 结合，缩短半衰期；CDR 区氧化影响靶抗原结合 |
| 组氨酸（His）   | 2-氧代组氨酸、天冬氨酸等 | CDR 区、Fc 铰链区                                 | CDR 区氧化影响抗原结合亲和力                                          |
| 半胱氨酸（Cys） | 二硫键错配、亚磺酸/磺酸  | 链间/链内二硫键位置                               | 影响分子折叠和聚集体形成                                              |
| 色氨酸（Trp）   | 羟色氨酸、犬尿氨酸       | CDR 区（部分抗体）                                | 影响抗原结合                                                          |

**二硫键相关的特殊氧化**

二硫键形成涉及两个半胱氨酸巯基（-SH）的氧化，既可发生在单个分子内部（形成正确的折叠结构），也可发生在分子间（导致聚集体形成）。错配的分子间二硫键是聚集体生成的重要途径之一，并对 CEX 电荷谱产生影响。

**氧化对电荷异质性谱的影响**

甲硫氨酸氧化（Met→Met-O）在 CEX 谱上通常表现为**酸性峰增加**，这是因为氧化引入极性基团，改变了蛋白局部电荷分布，使产品保留时间发生偏移。

**工艺防护措施**

| 防护手段                                         | 应用阶段       |
| ------------------------------------------------ | -------------- |
| 控制制剂中金属离子水平（EDTA 螯合）              | 制剂开发       |
| 避光操作和包材遮光                               | 生产和储存     |
| 控制溶液 pH（碱性条件加速氧化）                  | 制剂缓冲液设计 |
| 充 N₂/惰性气体保护（降低溶解氧）                 | 原液灌装和储存 |
| 添加抗氧化剂（如甲硫氨酸、抗坏血酸，视制剂需求） | 制剂配方设计   |

:::

## 抗体化学降解二：脱酰胺机制、异天冬氨酸形成路径与对电荷异质性的影响

:::answer

**脱酰胺反应的化学本质**

脱酰胺（Deamidation）是指天冬酰胺（Asn）或谷氨酰胺（Gln）残基在环酰亚胺（Succinimide）中间体的参与下，侧链酰胺基团（-CONH₂）发生水解，失去 NH₃，转变为酸性残基的化学降解过程。

**脱酰胺的反应路径（以 Asn 为例）**

```
天冬酰胺（Asn，-CONH₂）
        ↓  临近残基质子供体参与（通常为 Ser、Thr）
环酰亚胺中间体（Succinimide）
        ↓  自发水解（两个路径）
天冬氨酸（Asp，正常构型，约 25%）
+
异天冬氨酸（iso-Asp，β-连接，约 75%）
```

**脱酰胺的关键影响因素**

| 因素     | 对脱酰胺速率的影响                                                                |
| -------- | --------------------------------------------------------------------------------- |
| 序列背景 | Asn-Gly 序列最易发生脱酰胺；Asn-Ser、Asn-Thr 次之；Asn-Pro 最稳定（Pro 阻断环化） |
| pH       | 碱性 pH（> 8）显著加速脱酰胺；酸性 pH 相对稳定                                    |
| 温度     | 升温加速脱酰胺；低温保存有助于抑制                                                |
| 局部构象 | 暴露（Solvent-exposed）残基比埋藏残基脱酰胺速率快                                 |

**脱酰胺对抗体质量属性的影响**

| 质量属性   | 影响                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 电荷异质性 | 引入负电荷（Asn → Asp/isoAsp）→ 在 CEX 谱上表现为**酸性峰增加**       |
| 活性       | CDR 区的脱酰胺（尤其是 Asn-Gly 位点）可能降低靶抗原结合亲和力         |
| 稳定性     | isoAsp 使肽键从 α 连接变为 β 连接，引入不正常连接，影响局部构象稳定性 |

**脱酰胺与 C 端 Lys clip 在 CEX 谱上的区分**

两者均导致 CEX 谱的峰面积变化，但方向相反：

- **C 端 Lys 不完全裂解** → 碱性峰增加（残余 Lys 携带正电荷）
- **脱酰胺** → 酸性峰增加（引入负电荷）

通过 LC-MS/MS 肽图分析可精确定位脱酰胺位点和定量脱酰胺程度，是鉴别和控制电荷变体的关键手段。

:::

## 生物反应器放大中二氧化碳积累的工程机制与系统性应对策略

:::answer

**放大中 CO₂ 积累的根本成因**

CO₂ 在水中的溶解度约为 O₂ 的 25 倍（亨利定律常数差异），这意味着即使等量产生，CO₂ 比 O₂ 更难被通气驱除。同时，细胞每消耗 1 分子 O₂，就会产生约 1 分子 CO₂（呼吸商 RQ ≈ 1），造成长期积累。

**放大特有的 CO₂ 积累加剧因素**

随着反应器体积增大，以下工程因素共同导致 CO₂ 积累问题在大规模培养中比小规模严重得多：

| 工程因素             | 小规模（2L） | 大规模（2000L+） | 对 CO₂ 积累的影响                                        |
| -------------------- | ------------ | ---------------- | -------------------------------------------------------- |
| 表面积/体积比（A/V） | 高           | 低               | A/V 降低→顶空通气排 CO₂ 贡献减小                         |
| 混合时间             | 秒级         | 数十秒～分钟级   | 长混合时间→CO₂ 局部浓度梯度加剧                          |
| 液柱高度             | 低           | 高               | 液柱高→底部气泡停留时间长→O₂ 更多溶解，同时 CO₂ 排出受阻 |
| 鼓泡通气量           | 低           | 高               | 高密度培养需更高 O₂ 供应→微泡被大量使用→CO₂ 移除受限     |

**CO₂ 积累的级联影响链**

```
pCO₂ 升高
    ↓
pH 下降 → 补加碱液 → 渗透压升高
    ↓                    ↓
胞内 pH 降低         胞内离子浓度增加
    ↓                    ↓
酶活性受抑制         酶活性受影响
    ↓                    ↓
细胞生长减缓/代谢改变 + 产物 Qp 下降 + 糖基化质量下降（HM 升高）
```

**CO₂ 分压的量化影响（研究数据）**

- pCO₂ 从 **36 mmHg** 提升至 **140 mmHg**：Qp 下降约 **10%**；
- pCO₂ 从 **36 mmHg** 提升至 **190 mmHg**：Qp 下降约 **33%**；
- pCO₂ 超过 **150 mmHg**（约对应气相 CO₂ 浓度 15%～20%）：细胞开始产生明显毒性效应。

**工程控制策略的优先级与效果对比**

| 策略                 | CO₂ 降低效果          | 副作用                           | 推荐场景         |
| -------------------- | --------------------- | -------------------------------- | ---------------- |
| 增大底部深层通气量   | ✓✓✓ 显著              | 气泡剪切力增加                   | 首选策略         |
| 使用大泡分布器       | ✓✓✓ 显著              | 气泡剪切力（但大泡剪切低于微泡） | 与微泡组合使用   |
| 增加表层通气量       | ✓ 有限                | —                                | 辅助             |
| 改变搅拌转速         | ✗ 基本无效            | 影响剪切和混合                   | 不推荐           |
| 使用 NaHCO₃ 缓冲     | 缓冲 pH 但不降低 pCO₂ | 增加渗透压                       | 配合使用         |
| 降低培养基碳酸盐含量 | ✓ 减少非生物 CO₂ 来源 | 需验证对 pH 缓冲能力的影响       | 培养基优化时考虑 |

**微泡与大泡的工程权衡**

微泡分布器（microsparger）产生微米级气泡，气液接触面积大、O₂ 传质效率高（KLa 高）；但微泡在液体中停留时间长，O₂ 持续溶解使气泡直径缩小，CO₂ 扩散进入气泡的驱动力降低，CO₂ 移除速率随之下降。

**最优工程方案：** 微泡分布器（供 O₂）+ 大泡分布器（排 CO₂）组合使用，分别满足供氧需求和 CO₂ 去除需求，是商业化大规模生物反应器的最佳实践。

:::

## 电荷异质性对抗体药物 PK/PD 的影响：净电荷改变与组织分布的定量关系

:::answer

**电荷改变影响抗体 PK 的基本原理**

抗体表面的净电荷通过影响其与组织细胞膜、血管内皮细胞及各类受体的静电相互作用，进而改变药物的药代动力学（PK）和组织分布特征：

- **阳离子化（pI 升高）：** 增加与带负电荷细胞膜的非特异性结合，倾向于增加血浆清除率（清除加快），同时影响组织分布（更多进入组织）；
- **阴离子化（pI 降低）：** 减少组织非特异性摄取，但也可能增加血浆清除率（通过不同机制）。

**电荷变体对 PK 影响的量化阈值**

| pI 变化幅度                            | 对 PK 的影响                             |
| -------------------------------------- | ---------------------------------------- |
| 0.1～0.2 单位（如 C 端 Lys clip 造成） | 对 IV 给药的 PK 通常无显著影响           |
| 1 个单位或以上                         | 可能导致可测量的 PK 变化，须进行专项研究 |

> **给药途径差异：** 对于**皮下（SC）给药**，即使轻微的电荷差异也可能影响抗体从皮下组织到淋巴系统的吸收和分布，这一影响往往大于同等 pI 变化对 IV 给药的影响，是 SC 制剂开发中须重点关注的质量属性。

**最常见的 IgG1 电荷异质性来源：C 端赖氨酸剪切**

IgG1 重链 C 端赖氨酸（Lys）残基会被细胞内羧肽酶 D 不完全裂解，导致：

- 完全裂解（K0）：碱性峰比例正常；
- 不完全裂解（K1 或 K2）：保留 1 或 2 个 C 端 Lys，每保留 1 个 Lys 带 1 个正电荷，导致碱性峰增加；
- 即使在血液中存在羧肽酶，IV 给药后 C 端 Lys 变体的 PK **不受显著影响**——这是因为 Lys 裂解不影响 FcRn 结合位点，且血浆中羧肽酶也会继续处理残余 Lys。

**电荷对 ADCC/ADCP 效应的潜在影响**

电荷变化（尤其是 CDR 区电荷改变）可能影响抗体与靶抗原的结合动力学，进而间接影响 ADCC/ADCP 效应功能。CEX 精纯步骤可通过控制电荷变体比例，维持批间效应功能的一致性。

:::

## 糖型对抗体药物生物学活性的系统影响：Fc 效应功能、PK 与半衰期的多维调控

:::answer

**Fc 糖基化的结构基础**

绝大多数 IgG 抗体（个别改构抗体如 N297A 突变除外）均在 **CH2 结构域 Asn297 位**（保守序列：Asn-X-Ser/Thr）存在 N-糖基化修饰。这一糖基化侧链深嵌于 CH2 结构域内腔，通过改变 Fc 构象，调控 Fc 与 FcγR（Fcγ 受体）和 C1q 的结合效率，进而影响抗体的效应功能。

部分抗体（如含融合蛋白结构域的）在 Fab 区也存在 N-糖基化位点，须分别评估其对功能的影响。

**主要糖型对效应功能和 PK 的影响矩阵**

| 糖型修饰                        | ADCC 效应                    | CDC 效应             | 半衰期（PK）           | 免疫原性 |
| ------------------------------- | ---------------------------- | -------------------- | ---------------------- | -------- |
| 岩藻糖化（G0F/G1F/G2F，含 Fuc） | 减弱（与 FcγRIIIa 亲和力低） | 正常                 | 正常                   | 低       |
| 去岩藻糖化（G0/G1/G2，无 Fuc）  | 显著增强（5～50 倍）         | 正常或略增           | 正常或略缩短           | 较低     |
| 高甘露糖型（Man5～9）           | 增强（去岩藻糖化结构）       | 正常                 | 缩短（甘露糖受体清除） | 较高     |
| 高半乳糖化（G2F/G2）            | 略增强                       | 增强（C1q 结合增加） | 正常                   | 低       |
| 唾液酸化（SA-G2F 等）           | 减弱                         | 略减弱               | 可能延长               | 低       |
| 无半乳糖（G0F/G0）              | 正常或略减弱                 | 减弱                 | 可能延长 20%～40%      | 低       |

> **特殊发现：** 研究发现，糖基化侧链上**无半乳糖结构**的 IgG1 和 IgG2（G0F 型），其体循环半衰期可能比其他形式长 **20%～40%**，可能的原因是半乳糖基化形式与 FcγRI 的亲和力更高，导致加速清除，而去半乳糖型受体介导清除减少。

**ADCC 增强策略中的糖基化工程**

在以 ADCC 为主要作用机制的抗体药物（如曲妥珠单抗生物类似药、抗 CD20 单抗）的开发中，通过去岩藻糖化策略增强 ADCC 是常见的分子工程手段：

- **细胞株工程：** α-1,6-岩藻糖基转移酶（FUT8）基因敲除的 CHO 细胞系
- **培养基干预：** 添加岩藻糖合成抑制剂（如 2-fluorofucose）
- **代价：** 去岩藻糖化可能小幅增加清除速率，须结合 PK 数据综合评估

:::

## Man5 高甘露糖型对抗体 PK/PD 的定量影响与行业控制标准

:::answer

**Man5 的体内 PK 影响**

**清除动力学差异（关键实验数据）**

与含低 Man5（5%～7%）的抗体批次相比，含 **100% Man5** 的抗体在动物模型中显示出显著更快的血浆清除速率，可能机制是通过肝脏 Kupffer 细胞表面的甘露糖受体（Mannose Receptor）介导的内吞清除（受体介导的药物消除）。

**高甘露糖亚型的体内转化**

Man7～Man9 等较高阶高甘露糖型，似乎可在血清中通过 α-甘露糖苷酶降解转化为 Man5。这意味着：体内最终起清除作用的主要是 Man5，而非更高阶的 HM 亚型。

**高甘露糖型的双重效应总结**

| 效应维度     | 高 Man5 含量的影响                             |
| ------------ | ---------------------------------------------- |
| PK（半衰期） | 缩短（甘露糖受体介导加速清除）                 |
| ADCC 效应    | 增强（去岩藻糖化结构，FcγRIIIa 亲和力高）      |
| 免疫原性     | 升高（高甘露糖具有较强免疫原性）               |
| 给药剂量需求 | 可能需增加（半衰期短，需更频繁给药或更高剂量） |

**行业控制标准与策略**

| 开发阶段                 | Man5 控制标准（参考）                        | 依据                       |
| ------------------------ | -------------------------------------------- | -------------------------- |
| 早期研发（IND 前）       | ≤10%（通常以 5% 为控制目标）                 | 行业经验，基于 PK 安全边际 |
| BLA 申报                 | 由工艺表征和临床 PK 研究确定，与具体产品相关 | 须有 PK/PD 数据支撑        |
| 以 ADCC 增强为目标的产品 | 可允许更高 Man5（须有临床 PK 数据支持）      | 权衡 ADCC 增益与 PK 代价   |

**Man5 对 PK 影响的定量关系示意**

研究数据显示，Man5 水平在 5%～7% 范围内时对 PK 影响不显著；当 Man5 水平超过 20%～30% 时，PK 改变开始显现；100% Man5 时清除速率显著加快。但具体临界值因产品而异，须通过专项 PK 研究确认。

## 一级结构 N/C 端异质性：焦谷氨酸化封闭、C 端赖氨酸剪切的形成机制与质量控制

:::answer

**N 端异质性：焦谷氨酸化（PyroGlu Formation）**

**形成机制**

当抗体重链或轻链 N 端第一个氨基酸为**谷氨酰胺（Gln）**（少数情况下为谷氨酸 Glu）时，在偏酸性或稍高温度条件下，N 端氨基与侧链酰胺/羧基发生**自发环化**，脱氨形成**焦谷氨酸（PyroGlu，pGlu）**，从而使 N 端被封闭（去除了正电荷的 α-氨基）。

```
N 端 Gln（+NH₂-）→ 焦谷氨酸（环状，N 端封闭）+ NH₃
```

**对电荷和分析的影响**

- 焦谷氨酸化去除了 N 端正电荷（α-氨基 pKa ≈ 8）→ **酸性化效应**（相当于减少一个正电荷）；
- 在 CEX 谱上表现为酸性峰增加；
- 在 N 端测序（Edman 降解）中，焦谷氨酸化的 N 端无法被正常降解，须先用**焦谷氨肽酶（PyroGlutamate Aminopeptidase）**处理，去除焦谷氨酸封闭后再进行测序。

**C 端异质性：赖氨酸不完全剪切（C-terminal Lys Clipping）**

**形成机制**

IgG1、IgG2、IgG4 重链 C 端编码一个赖氨酸（Lys）残基，在细胞内**羧肽酶 D（Carboxypeptidase D）**的作用下，该 Lys 在蛋白加工过程中被裂解去除。然而，羧肽酶活性受细胞培养条件影响，导致 Lys 剪切不完全，形成：

| 重链 C 端状态        | 说明                 | CEX 电荷影响        |
| -------------------- | -------------------- | ------------------- |
| K0（两条链均剪切）   | 完全剪切，最成熟形式 | 基准                |
| K1（一条链保留 Lys） | 一条重链未剪切       | 碱性化（+1 正电荷） |
| K2（两条链保留 Lys） | 两条重链均未剪切     | 碱性化（+2 正电荷） |

**NC 端异质性的监管认知**

目前已有充分研究证明，重组抗体普遍存在 N/C 端异质性，且**没有证据表明 N/C 端异质性对抗体安全性和有效性产生显著影响**。因此，N/C 端异质性通常不被列为最高优先级 CQA，但须通过 IEX 或 CEX 分析进行监控，确保批间一致性。

**C 端赖氨酸的工程去除策略**

部分企业通过**基因水平设计**（在表达载体中直接去除 C 端 Lys 编码序列），从根本上消除 C 端赖氨酸异质性，简化质量控制策略。这是 BLA 申报中控制碱性变异体的一种常见手段。

## 糖基化修饰的系统认知：N-糖与 O-糖的结构基础、分析方法与关键质量控制指标

:::answer

**N-糖与 O-糖的结构区分**

| 维度         | N-糖基化（N-Glycosylation）       | O-糖基化（O-Glycosylation）         |
| ------------ | --------------------------------- | ----------------------------------- |
| 连接位点     | Asn（天冬酰胺）                   | Ser（丝氨酸）或 Thr（苏氨酸）的羟基 |
| 序列共识     | Asn-X-Ser/Thr（X ≠ Pro）          | 无特定共识序列                      |
| 发生场所     | 内质网（初步）+ 高尔基体（成熟）  | 高尔基体                            |
| 主要结构类型 | 高甘露糖型、杂合型、复杂型        | 核心 1/2 结构（O-GalNAc 为主）      |
| 抗体典型位置 | Fc 区 Asn297（必需）；部分 Fab 区 | 融合蛋白序列中的 Ser/Thr            |

> **特殊情况：** 个别改构 IgG1（N297A 突变）不含 Fc 糖基化，用于特殊需求（如需要消除 Fc 效应功能的应用场景）。

**糖基化对抗体功能的双向调控**

| 修饰类型                              | 功能影响                                            |
| ------------------------------------- | --------------------------------------------------- |
| 高半乳糖化（G2F/G2）                  | 提高 CDC 效应（通过增强 C1q 结合）                  |
| 低岩藻糖（G0/G1/G2，无 Fuc）          | 增强 ADCC 和 ADCP 效应（FcγRIIIa 亲和力显著提升）   |
| α1,3-半乳糖（非人糖型，来自鼠源细胞） | 临床免疫原性风险（人体天然存在抗-Gal 抗体）         |
| NGNA（N-乙酰神经氨酸，鼠源特有）      | 免疫原性风险，CHO 细胞也会低水平产生                |
| 高甘露糖型                            | 增强 ADCC（去岩藻糖），缩短半衰期（甘露糖受体清除） |

**代表性上市抗体的糖基化位点举例**

| 产品                             | N-糖位点                | O-糖位点 | 特点                               |
| -------------------------------- | ----------------------- | -------- | ---------------------------------- |
| 阿巴西普（Abatacept，融合蛋白）  | 3 个                    | 4 个     | 融合蛋白结构，糖基化位点多样       |
| 依那西普（Etanercept，融合蛋白） | 3 个                    | 13 个    | O-糖位点极多，是融合蛋白的特有挑战 |
| 西妥昔单抗（Cetuximab）          | Fab 区 + Fc 区均有 N-糖 | —        | Fab 区糖基化直接影响抗原结合特性   |

**寡糖分布分析方法**

| 分析层次             | 方法                           | 输出信息                               |
| -------------------- | ------------------------------ | -------------------------------------- |
| 寡糖分布（比例分析） | 荧光 HPLC（2-AB 标记）或 LC-MS | 各 N-糖亚型（G0F/G1F/G2F/Man5 等）占比 |
| 糖链结构鉴定         | 多种糖苷酶逐步酶切 + 质谱      | 单糖连接方式、分支结构                 |
| 批间一致性监控       | IEX/HILIC-HPLC                 | 关键糖型（如 Man5、G0F）的批间稳定性   |

**质量控制重点**

在抗体质控中，并非所有糖型均需同等严格控制，优先关注的糖型须结合产品的作用机制（MOA）确定：

- 以 **ADCC 为主**的产品（如赫赛汀类）：重点控制岩藻糖化比例；
- 需要控制免疫原性的产品：重点控制 α1,3-半乳糖、NGNA 等非人糖型；
- 所有抗体：Man5 须控制在 ≤10%（行业通行标准）。

## CO₂ 在细胞培养中的双重角色：必需代谢组分与潜在毒性物质的浓度边界

:::answer

**CO₂ 的生理必需性**

CO₂ 并非单纯的代谢废物，在适当浓度范围内对细胞生长不可或缺：

- CO₂ 是碳酸盐缓冲体系（CO₂/HCO₃⁻/H₂CO₃）的核心组分，在维持细胞培养液 pH 稳定方面不可替代；
- CO₂ 参与细胞内碳骨架的合成（如嘌呤合成、脂肪酸合成中的羧化反应）；
- 在**密闭瓶培养**中，CO₂ 浓度偏低（<1%）时细胞容易受损；开放培养（培养箱）须维持 **5% CO₂** 的气体环境以补充培养液中 CO₂/HCO₃⁻。

**CO₂ 与 pH 的联动调控**

在细胞培养过程中，pH 的动态变化受两类来源的 CO₂ 共同影响：

```
细胞代谢产生 CO₂ + NaHCO₃ 缓冲体系
                ↓
培养液 pH 下降（偏酸）
                ↓
通入 CO₂ 或加入 NaHCO₃/Na₂CO₃ 补偿
                ↓
维持 pH 在目标范围（6.8～7.4）
```

**不同细胞类型对 pH 的耐受差异**

| 细胞类型                     | pH 耐受特点                        |
| ---------------------------- | ---------------------------------- |
| 原代培养细胞                 | 对 pH 变动耐受性差，须严格控制     |
| 永生细胞系（如 CHO、HEK293） | 耐受性较强，但仍需维持在合理范围   |
| 恶性细胞系                   | 耐受性最强                         |
| 所有细胞                     | 对碱性变化耐受性通常低于对酸性变化 |

**最适 pH 范围：** 大多数哺乳动物细胞在 **pH 6.8～7.4** 条件下最适生长；低于 pH 6.8 或高于 pH 7.6 均对细胞有害，可导致退变或死亡。

**CO₂ 浓度的安全边界**

| CO₂ 水平        | 细胞反应                         |
| --------------- | -------------------------------- |
| <1%（密闭瓶中） | 细胞容易受损                     |
| 1%～5%          | 适宜（开放培养标准条件）         |
| 5%～15%         | 对代谢有抑制，须监控 pH 和渗透压 |
| >15%～20%       | 明显毒性作用，通常不可接受       |

**pH 缓冲体系设计原则**

- **封闭式培养（密封瓶/袋）：** 磷酸盐缓冲剂 + NaHCO₃ 可提供 CO₂ 来源，但 CO₂ 易逸出，须在封闭环境下使用；
- **开放式培养（摇瓶/反应器）：** 须持续通入含 5% CO₂ 的气体，同时配合 NaHCO₃ 缓冲体系，维持 pH 稳定；
- **大规模反应器：** pH 调控需要 CO₂ 通气（降 pH）和碱液补加（升 pH）双向精密控制，并结合在线 pH 传感器（单次使用或可原位校准型）实现闭环反馈。

:::
