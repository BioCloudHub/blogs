## Worst-case 工艺参数研究的设计逻辑与实施框架

:::answer

**Worst-case 研究的定义与目的**

Worst-case（最差条件）研究是工艺表征（Process Characterization）的核心活动之一，旨在评估工艺参数在极端条件下对产品关键质量属性（CQA）的影响，为设计空间（Design Space）的边界定义和工艺稳健性证明提供科学依据。

**参数筛选的方法论：从风险评估到 Worst-case 范围确定**

在开展 Worst-case 研究之前，必须先通过<strong>风险评估（FMEA 或因果矩阵）</strong>对所有工艺参数进行打分排序，识别对 CQA 影响程度最高的参数子集，集中资源针对高风险参数开展 Worst-case 研究。

**典型案例：低 pH 病毒灭活步骤的 Worst-case 参数设计**

低 pH 病毒灭活是抗体下游纯化中的关键安全性步骤，通过风险评估对该步骤的全部工艺参数打分后，通常识别出以下四个高评分参数：

| 参数         | 对 CQA 的影响方向                                 | Worst-case 设计逻辑                                    |
| ------------ | ------------------------------------------------- | ------------------------------------------------------ |
| **pH**       | 过低 → 蛋白变性/聚集增加；过高 → 病毒灭活效果不足 | 双向：测试 pH 上限（安全性挑战）和 pH 下限（质量挑战） |
| **抗体浓度** | 高浓度下蛋白-蛋白相互作用增强，聚集风险升高       | 测试最高预期蛋白浓度                                   |
| **时间**     | 过短 → 病毒灭活不完全；过长 → 蛋白降解累积        | 双向：最短时间（安全性挑战）和最长时间（质量挑战）     |
| **温度**     | 温度变化影响蛋白稳定性和病毒灭活速率              | 双向：最低温度（灭活效率）和最高温度（蛋白稳定性）     |

**Worst-case 研究范围的确定原则**

```
Worst-case 范围设计流程
正常操作范围（NOR）
        ↓ 扩展至
验证范围/操作范围（VAR/PAR）
        ↓ 在边界处设置
Worst-case 研究点（通常为参数范围的上下限组合）
        ↓ 评估
CQA 响应（聚集体、片段、效价、颜色等）
        ↓ 确认
设计空间边界是否可接受
```

**多参数 Worst-case 的组合设计**

当同时研究多个参数时，Worst-case 不必对所有参数同时取极值（全因子设计），而应基于科学理解选择**最可能同时发生的不利参数组合**，或采用中心复合设计（CCD）、Box-Behnken 设计等统计学实验设计方法，以有限的实验次数高效覆盖设计空间。

:::

## ISF 评估的前提背景：工艺相关杂质的安全性分类体系

:::answer

**安全性控制的核心逻辑**

药物最重要的两个特征是**安全性**和**有效性**，其中安全性是 IND 申报中监管机构最优先关注的评价维度。生产工艺中可能存在多种影响药物安全性的物质，须在申报前进行系统性识别和控制。

**工艺相关杂质的分类体系**

```
影响药物安全性的物质分类
├── 工艺相关杂质（来源于生产工艺）
│   ├── 生物学活性杂质（具有生物活性，对患者有潜在药理/免疫效应）
│   │   ├── HCP（宿主细胞蛋白）← 免疫原性风险
│   │   ├── HCD（宿主细胞 DNA）← 致癌性风险
│   │   └── Protein A（亲和层析填料残留）← 免疫反应风险
│   │
│   └── 非生物学活性杂质（主要为化学毒性风险）
│       ├── 消泡剂（如聚山梨酯、聚醚类）
│       ├── DMSO（二甲基亚砜）
│       ├── 有机溶剂残留
│       └── 其他工艺化学品
│
├── 产品相关杂质（降解产物、聚集体、片段等）
│
└── 污染物（微生物、内毒素、病毒等外源因子）
```

**ISF 工具的适用范围**

ISF（Inherent Safety Factor，固有安全系数）专门用于评估**非生物学活性杂质**的安全性，原因在于：

- 生物学活性杂质（HCP、HCD、Protein A）需通过专属的免疫毒理学研究和特异性检测方法控制，不适合用单一毒性参数（LD50）衡量
- 非生物学活性杂质的毒理学数据（LD50）相对容易获取，ISF 计算方法简便可行

:::

## ISF 安全性评估的计算方法、判断阈值与分级决策流程

:::answer

**ISF 的核心计算公式**

$$ISF = \frac{LD_{50}}{\text{每剂量中的杂质含量}}$$

**参数获取方法**

| 参数               | 来源                                                    | 注意事项                                                                         |
| ------------------ | ------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **LD₅₀**           | ECHA 化学品数据库、PubChem、Sigma-Aldrich SDS、相关文献 | 通常以 mg/kg（大鼠口服或静脉注射）表示，计算时需换算为与临床给药途径匹配的数值   |
| **每剂量杂质含量** | 基于上游生产过程中杂质的**最大预期含量**计算            | 采用 Worst-case 假设：下游纯化步骤对该杂质**无任何去除能力**，即以最不利情形评估 |

**Worst-case 假设的合理性**

"下游无去除能力"的假设看似保守，但这是 ISF 评估的设计初衷——**如果在最不利条件下 ISF 仍 > 1000，则无论实际去除效率如何，产品安全性均有充分保障**，无需额外进行实测验证。

**三级分级决策流程**

```
计算 ISF = LD₅₀ / 每剂量最大杂质含量（Worst-case）
                ↓
        ISF > 1000？
        ↙              ↘
    是                   否
    ↓                    ↓
✅ 直接评估为安全    检测实际纯化后样品中的杂质含量
无需进一步测试       重新计算 ISF（基于实测值）
                         ↓
                   ISF > 1000？
                   ↙            ↘
               是                  否
               ↓                   ↓
         ✅ 评估为安全        ⚠️ 开展 Spiking 研究
                               评估下游工艺对该杂质
                               的实际去除能力（Log 去除值）
```

**Spiking 研究的含义**

当 ISF < 1000 时，须开展 Spiking 研究（加标研究），具体方法：

- 在上游样品中人为加入已知浓度的杂质
- 运行代表性的下游纯化工艺
- 检测各步骤和最终产品中的杂质残留量
- 计算每步骤的去除因子（Reduction Factor）和总去除能力（LRV）
- 结合实测去除能力重新评估终产品中的杂质暴露量和安全性

:::

## ISF 判断阈值设定为 1000 的科学依据

:::answer

**两种毒理学评估指标的比较**

在杂质安全性评估中，理论上应使用<b>NOAEL（无可见不良反应剂量水平）</b>进行计算，因为 NOAEL 代表的是"未观察到有害作用的剂量"，更直接反映临床安全性相关性：

| 指标      | 定义                       | 临床相关性                 | 数据可获得性                                |
| --------- | -------------------------- | -------------------------- | ------------------------------------------- |
| **NOAEL** | 未观察到有害作用的最高剂量 | 高（直接反映安全暴露窗口） | **低**（大多数工艺化学品无公开 NOAEL 数据） |
| **LD₅₀**  | 半数致死量（动物急性毒性） | 中（与慢性毒性无直接关联） | **高**（几乎所有化学品均有公开数据）        |

**1000 倍阈值的推导逻辑**

```
科学依据链
研究发现：LD₅₀ 通常是 NOAEL 的 10～100 倍（物质依赖）
                ↓
为覆盖这一不确定范围，引入安全系数：10 倍
                ↓
理论安全阈值 = LD₅₀ / 杂质含量 > (NOAEL × 10～100) / 杂质含量 × 10
                ↓
简化为：当 ISF > 1000 时，理论上杂质水平低于 NOAEL
                ↓
患者暴露量不会引发可观察到的不良反应
```

**关键结论**

> **ISF > 1000** = 杂质含量 < LD₅₀/1000 ≈ 杂质含量 < NOAEL（含 10 倍安全边际）

这一判断阈值保守地涵盖了 LD₅₀ 与 NOAEL 之间的转换不确定性（10–100 倍），并额外叠加了 10 倍安全系数，确保充分的安全性保障。

**ISF 评估的局限性与补充注意事项**

- LD₅₀ 通常来自动物急性口服/注射毒性试验，不能完全代表人体静脉注射长期暴露的毒理学风险
- 对于已知具有特殊毒理学关注的物质（如基因毒性、内分泌干扰、致敏性），ISF 评估不适用，须采用化合物特异性毒理学数据
- ISF 评估是**筛选工具**，不能替代完整的非临床安全性研究

:::

## 糖工程改造抗体：去岩藻糖化增强 ADCC 的机制与技术策略

:::answer

**ADCC 效应的生物学基础**

抗体依赖细胞介导的细胞毒性（ADCC）是 IgG1 类抗体发挥抗肿瘤和抗感染功能的核心机制，其效应强度由 Fc 区与 NK 细胞/巨噬细胞表面 <strong>FcγRIIIa（CD16a）</strong>的结合亲和力决定。

**核心岩藻糖对 ADCC 的抑制机制**

Fc 区 Asn297 位点的 N-糖链中的<strong>核心岩藻糖（α-1,6-岩藻糖）</strong>通过与 FcγRIIIa 的 N-糖链产生空间位阻，显著削弱 Fc-FcγRIIIa 的结合亲和力：

```
标准 IgG1（含核心岩藻糖）
Fc 糖链岩藻糖 ← 产生空间位阻 → FcγRIIIa 结合受阻
                                    ↓
                         ADCC 效应强度：基准水平

去岩藻糖化 IgG1
Fc 糖链无岩藻糖 → 消除空间位阻 → FcγRIIIa 结合亲和力大幅提升（5–50 倍）
                                    ↓
                         ADCC 效应强度：显著增强
```

**糖工程改造的主要技术平台**

| 技术                   | 原理                                                                     | 代表企业/产品                                           |
| ---------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| **FUT8 基因敲除**      | 敲除 α-1,6-岩藻糖转移酶基因，阻断核心岩藻糖添加                          | Biowa（Potelligent® 平台）→ 莫格利珠单抗（Poteligeo）   |
| **过表达 GnT-III**     | 引入 β-1,4-N-乙酰葡萄糖胺转移酶 III，增加平分型 GlcNAc，间接阻断岩藻糖化 | Roche/Glycart（GlycoMab® 技术）→ 奥比妥珠单抗（Gazyva） |
| **岩藻糖竞争性抑制剂** | 培养基中添加 2-脱氧-2-氟岩藻糖（2FF）竞争性抑制 GDP-岩藻糖合成           | 工艺添加剂，无需基因编辑                                |
| **体外酶法去岩藻糖化** | 使用专属糖苷酶体外移除岩藻糖                                             | 研究工具，产业化应用有限                                |

**去岩藻糖化的临床意义**

去岩藻糖化技术使抗体在相同剂量下实现更强的 ADCC 效应，对以下应用场景具有特别价值：

- FcγRIIIa 低亲和力基因型（F/F 或 F/V）患者——去岩藻糖化可弥补基因型带来的疗效差异
- 需要强 ADCC 效应的肿瘤适应症（如 B 细胞淋巴瘤、乳腺癌）
- 抗感染抗体（需要高效介导免疫效应细胞清除感染细胞）

:::

## 中间产品储存稳定性：储存条件设计与 pH 缓冲体系的关键影响

:::answer

**中间产品稳定性研究的法规要求**

中间产品（包括各层析步骤的洗脱液、超滤中间体）和原液均须具备稳定性研究数据支持，方可确定批准的储存条件和最大储存时间（Hold Time）。这是 GMP 合规要求，也是批记录中的关键控制点。

**抗体中间产品储存的通用原则**

在适当缓冲液体系下，单克隆抗体在 **2–8°C** 通常可稳定储存至少 7 天。但实际储存时间取决于：

| 影响因素       | 关键考量                                                                     | 评估方法                                |
| -------------- | ---------------------------------------------------------------------------- | --------------------------------------- |
| **缓冲液 pH**  | pH 须处于抗体稳定区间（通常 pH 5–8），远离等电点（pI）以防止溶解度下降和聚集 | pH 稳定性研究（不同 pH 梯度加速稳定性） |
| **缓冲液种类** | 磷酸盐、醋酸盐、柠檬酸盐、组氨酸盐的缓冲能力和兼容性差异                     | 缓冲液筛选实验                          |
| **蛋白浓度**   | 高浓度条件下分子间相互作用增强，聚集风险升高                                 | 浓度依赖性稳定性研究                    |
| **温度**       | 2–8°C 为标准；-80°C 用于长期储存原液                                         | 实时 + 加速稳定性研究                   |
| **容器相容性** | 玻璃或塑料容器对蛋白的吸附和浸出物风险                                       | 容器相容性研究                          |

**pH 不适合储存时的处理策略**

某些层析步骤（如低 pH 病毒灭活后、Protein A 酸性洗脱后）的洗脱液 pH 不适合直接储存，需在储存前调节 pH：

```
处置流程
低 pH 洗脱液（pH ~3.5）
        ↓ 病毒灭活保持时间结束后
中和/调节至适合储存的 pH（如 pH 5.5–6.5）
        ↓
进行 pH 适合性确认（确认调节后 pH 稳定）
        ↓
按批准的储存条件储存（2–8°C，时间 ≤ 验证的 Hold Time）
```

**中间体储存稳定性研究的最低要求**

- 至少覆盖拟定的最长储存时间（Hold Time）
- 储存温度须包括拟定温度和一个加速温度
- 评估项目须包含关键 CQA（外观、聚集体/片段、效价）和安全性指标（微生物、内毒素）

:::

## 影响抗体在哺乳动物细胞中表达的五大因素

:::answer

抗体分子在哺乳动物细胞（主要为 CHO）中的表达是一个从 DNA 到功能蛋白的复杂多步骤过程，每一步都可能成为限速环节。

**五大影响因素的系统梳理**

**① 转录效率**

- 启动子强度（CMV、EF1α、CAG 等启动子的活性差异）
- 染色体整合位点的转录活性（热点 vs 沉默区域）
- 增强子元件（HNRPA2B1、MARs 等绝缘子和基质附着区）

**② mRNA 的加工**

- 剪接信号的效率（内含子的正确剪接）
- 5' 加帽和 3' 多聚腺苷酸化效率
- mRNA 二级结构对加工效率的影响

**③ mRNA 的稳定性与翻译效率**

- mRNA 5' UTR 的二级结构影响核糖体结合和翻译起始
- Kozak 序列的优化（强 Kozak 共识序列提升翻译起始效率）
- mRNA 3' UTR 中稳定性元件和降解信号的分布

**④ 抗体基因拷贝数**

基因拷贝数受以下因素综合决定：

```
基因拷贝数的决定因素
├── 染色体整合区域的染色质状态（开放 vs 封闭）
├── 整合于宿主染色体的具体位置（基因组热点 vs 沉默区）
├── 转染质粒的拷贝数和整合方式（单拷贝 vs 多拷贝整合）
└── 基因扩增（DHFR/MTX 或 GS/MSX 系统）
```

**⑤ 翻译后加工、分泌与稳定性**

这是治疗性抗体质量的最关键决定因素：

| 翻译后过程     | 具体内容                     | 质量影响                            |
| -------------- | ---------------------------- | ----------------------------------- |
| **正确折叠**   | 二硫键形成、域间相互作用     | 折叠错误 → 聚集、降解、活性丧失     |
| **糖基化修饰** | Asn297 N-糖链添加和加工      | 糖型决定 Fc 效应功能、PK 和免疫原性 |
| **信号肽切割** | 引导分泌的信号肽正确切割     | 切割不完全 → 异质性增加             |
| **组装**       | 重链-重链、重链-轻链正确配对 | 错误配对 → 非活性聚集体             |

:::

## 提高抗体在 CHO 细胞中高效表达的三大工程化策略

:::answer

针对上述表达限制因素，研究者发展了多种提高重组抗体产量的工程化策略，以下三种策略是工业界最常用的技术路线。

**策略一：定点整合（Site-specific Integration）**

**背景与挑战**

哺乳动物细胞基因组中存在 ≥15,000 个潜在整合位点，外源基因随机整合后，由于整合位点邻近的调控元件差异，不同克隆的表达水平差异可高达 1000 倍以上，导致筛选工作量巨大。

**解决方案**

将外源基因靶向整合到**基因组热点（Genomic Hot Spot）**——这些位点两侧存在强有力的正向调控元件，可持续驱动高水平转录。

| 定点整合技术                   | 原理                                                       | 优势                         |
| ------------------------------ | ---------------------------------------------------------- | ---------------------------- |
| **Flp-In 系统**                | 利用 FLP 重组酶将基因插入预先确认的热点位点（含 FRT 位点） | 整合位点固定，批间一致性高   |
| **CRISPR/Cas9 靶向整合**       | 在特定基因组位点（如 AAVS1）引入 DSB，利用 HDR 精准整合    | 灵活性高，可针对任何验证热点 |
| **RMCE（重组酶介导盒式交换）** | 利用 Cre/lox 或 Flp/FRT 系统替换预集成的占位盒             | 可实现多基因模块的精准替换   |

**策略二：共扩增基因系统（Co-amplification Strategy）**

**DHFR/MTX 扩增系统（最经典、最广泛使用）**

```
DHFR/MTX 扩增系统工作原理
含 dhfr 基因和目的基因（抗体）的质粒
        ↓ 转染
CHO DHFR⁻ 细胞（内源 DHFR 基因缺陷）
        ↓ 在选择培养基中筛选
仅含 dhfr 基因的克隆可在无次黄嘌呤培养基中存活
        ↓ 逐步提高 MTX 浓度
DHFR 被 MTX 竞争性抑制 → 细胞为存活须扩增 dhfr 基因
        ↓ 串联扩增效应
与 dhfr 物理连接的目的基因同步共扩增
        ↓ 最终结果
dhfr 及侧翼序列可扩增至上千个拷贝
目的基因高水平表达
```

**GS/MSX 扩增系统（另一主流平台）**

谷氨酰胺合成酶（GS）/甲硫氨酸磺酰亚胺（MSX）系统原理与 DHFR 类似，是 Lonza（现已被 UCB 收购）平台的核心技术，常用于 NS0 和 CHO 细胞系。

**策略三：弱化筛选基因（Attenuated Selection Marker）**

**核心原理**

适当降低筛选标记基因（neo、dhfr、tk 等）的表达强度，使筛选压力提升，细胞为了存活，只有将表达载体整合于转录活性高的基因组区域才能获得足够的选择标记表达量。

```
弱化选择标记的筛选逻辑
弱启动子驱动筛选标记（低表达）
        ↓ 选择压力
整合于活跃转录区域的克隆 → 选择标记表达量达到存活阈值 → 存活
整合于沉默区域的克隆 → 选择标记表达量不足 → 死亡
        ↓ 筛选结果
存活克隆大概率整合于转录活跃区域 → 目的基因也在高表达环境中 → 高产克隆富集
```

:::

## NMPA 与 FDA 在 CMC 放行方法和原材料要求上的关键差异

:::answer

在进行中美双报（双申报）策略规划时，准确理解 NMPA 和 FDA 在 CMC 要求上的差异是避免申报失败的关键。以下是最常见的几个关键差异点。

**放行方法的差异**

| 检测项目                   | NMPA（中国）要求                          | FDA（美国）要求                                         |
| -------------------------- | ----------------------------------------- | ------------------------------------------------------- |
| **异常毒性检测（APT）**    | **DP（制剂）放行时必须开展**              | 通常不要求，已被现代分析方法和工艺控制替代              |
| **微生物限度检测菌种来源** | 来自 **CMCC（中国医学细菌保藏管理中心）** | 来自 **ATCC（美国典型培养物保藏中心）**                 |
| **支原体检测时机**         | 通常要求对 DS 和 DP 均检测                | **建议** 对 DS 进行支原体检测（非强制要求，但强烈推荐） |

**原材料要求的差异**

| 维度                 | NMPA 要求                                                          | FDA 要求                                          |
| -------------------- | ------------------------------------------------------------------ | ------------------------------------------------- |
| **原辅料标准**       | 优先使用符合**中国药典（ChP）或美国药典（USP）**药用级标准的原辅料 | 优先使用符合**美国药典（USP）**药用级标准的原辅料 |
| **国产原辅料认可度** | 符合 ChP 药用级标准的国产原辅料通常可被接受                        | 须符合 USP 标准或提供与 USP 标准的可比性数据      |

**强制降解研究的差异**

| 要求级别         | NMPA                             | FDA                                                    |
| ---------------- | -------------------------------- | ------------------------------------------------------ |
| **强制降解实验** | **强制要求**，必须开展并提交数据 | **仅推荐**，非强制性要求（ICH Q1A 倾向性指导，不强制） |

**双报策略的实践建议**

```
双报 CMC 策略核心原则
以更严格的要求为准（通常为 NMPA 要求）
        ↓
例如：必须开展异常毒性 + 强制降解研究
        ↓
额外满足 FDA 特有要求（如 USP 标准原辅料）
        ↓
建立桥接矩阵：明确哪些研究数据可被两国监管机构共同接受
```

:::

## 外观检查：目测法的标准与法规依据

:::answer

**外观检查的方法与评判标准**

外观检查是原液（DS）放行检测中最基础的检测项目之一，采用**目测法（Visual Inspection）**进行评估。

| 检测维度     | 描述方式              | 典型评价项目                       |
| ------------ | --------------------- | ---------------------------------- |
| **物理性状** | 定性描述（固体/液体） | 液态原液：澄清或微乳光泽的液体     |
| **色泽**     | 与参比色标比较        | 无色至淡黄色（具体色号依产品规格） |
| **澄清度**   | 与参比浊度比较        | 澄明或具有轻微乳光（溶液制剂）     |
| **可见异物** | 在适宜光照下旋转检查  | 无可见颗粒物、纤维或其他异物       |

**外观检查的操作规范要点**

- 检验背景：白色/黑色双背景交替检查（检测不同颜色异物）
- 光照条件：符合各药典规定的照度要求（中国药典：1000–1500 lx）
- 检查时间：每支样品旋转检查不少于规定时间
- 检验人员：须经过培训和视力检查，定期进行资质确认

**外观不合格的常见原因**

| 异常表现     | 可能原因                                | 处置方向                   |
| ------------ | --------------------------------------- | -------------------------- |
| 颜色偏黄加深 | 氧化降解（Trp 氧化产生 N-甲酰犬尿氨酸） | 调查降解原因，改善除氧措施 |
| 浑浊/沉淀    | 蛋白聚集、pH 偏移、冻融损伤             | 调查工艺异常，评估可比性   |
| 可见颗粒     | 蛋白聚集体、滤器纤维、外源污染          | 调查来源，必要时报废       |

:::

## DS 与 DP 放行检测项目的差异逻辑

:::answer

DS（原液）和 DP（制剂）在放行检测项目上的差异，根本上由**风险管理理念**和**制造工艺特性**决定，而非随意取舍。

**核心决策原则**

> 若某杂质在 DS→DP 生产过程中不会额外引入，且 DS 阶段已有充分控制数据，则 DP 中无需重复检测同一杂质——这是减少不必要检测的科学依据。

**DS/DP 主要差异检测项对比**

| 检测项目                | DS 检测             | DP 检测         | 差异理由                                           |
| ----------------------- | ------------------- | --------------- | -------------------------------------------------- |
| **HCP（宿主细胞蛋白）** | ✅ 必检             | 通常省略        | DP 生产不引入新 HCP；DS 步骤已充分去除并有数据支持 |
| **HCD（宿主细胞 DNA）** | ✅ 必检             | 通常省略        | 同上                                               |
| **Protein A 残留**      | ✅ 必检             | 通常省略        | Protein A 来自 DS 纯化步骤；DP 配制不引入          |
| **微生物限度**          | ✅ 检测（限度标准） | 替换为无菌检查  | DS→DP 经除菌过滤，DP 须证明无菌（更严格要求）      |
| **无菌检查**            | 通常不要求          | ✅ 必检         | DP 为最终注射用制剂，无菌是绝对要求                |
| **水分（残余水分）**    | 不适用（液态 DS）   | ✅ 冻干制剂必检 | 冻干制剂水分含量影响稳定性                         |
| **异常毒性（APT）**     | 不要求              | ✅ NMPA 要求    | 对患者直接给药的最终制剂须进行整体生物安全性确认   |
| **不溶性微粒**          | 通常不要求          | ✅ 必检         | DP 为注射剂，微粒直接入血，须符合药典微粒限度      |

**微生物控制的转变逻辑（DS→DP）**

```
DS 阶段：微生物限度检测
（允许存在少量微生物，限度控制）
        ↓
DS→DP 关键步骤：除菌过滤（0.22 μm 无菌过滤）
        ↓
DP 阶段：无菌检查
（不允许存在任何活微生物）
```

:::

## 主分子的选择与序列优化：通过分子设计降低开发风险

:::answer

**成药性风险的序列层面预防策略**

主分子的选择和序列优化是成药性评估（Developability Assessment）的核心活动，目标是在进入细胞株开发前，通过分子设计消除或降低已知的序列相关稳定性风险。

**常见序列热点（Liability）及对应优化策略**

| 序列风险类型                     | 位置                                               | 影响                                     | 优化策略                                        |
| -------------------------------- | -------------------------------------------------- | ---------------------------------------- | ----------------------------------------------- |
| **脱酰胺热点（NG/NS/NT motif）** | CDR 区域（影响最大）、CH1                          | 产生酸性变体，影响活性和稳定性           | 定点突变 Asn → Gln 或 Ser → Ala                 |
| **未配对半胱氨酸**               | 可变区或引入的工程突变                             | 形成非天然二硫键，导致聚集和异质性       | 删除未配对 Cys，或引入配对 Cys 形成设计性二硫键 |
| **CDR 区 N-糖基化位点**          | CDR（N-X-S/T 基序）                                | 糖型异质性，影响抗原结合亲和力批间稳定性 | 突变破坏 NXS/T 糖基化共识序列                   |
| **O-糖基化位点**                 | Ser/Thr（尤其铰链区附近）                          | 增加异质性，可能影响 Fc 效应功能         | 设计时减少 Ser/Thr 密集区域                     |
| **酸水解敏感序列（Asp-Pro）**    | 任意位置                                           | 产生特异性肽键水解片段（DP 位点）        | 替换 Asp-Pro 为保守氨基酸对（如 Glu-Pro）       |
| **Met 氧化热点**                 | 露出溶剂的 Met29（VH）、Met83（VH）、Fc Met252/428 | 影响 Fc-FcRn 结合和抗原结合              | 定点突变 Met → Leu/Val，或优化存储条件          |

**三步主分子优化工作流**

```
步骤 1：In silico 序列风险筛查
├── 脱酰胺/氧化热点预测（EpiSweep、Optimus 等工具）
├── T 细胞表位预测（免疫原性风险，EpiMatrix、NetMHCIIpan）
└── CDR 糖基化位点和不稳定 motif 识别
        ↓
步骤 2：瞬转表达验证（小规模快速评估）
├── 产量评估（效价 mg/L）
├── 初步质量评估（SEC 纯度、CE-SDS 纯度、糖型）
└── 活性确认（靶点结合 KD）
        ↓
步骤 3：稳定性研究（加速筛选）
├── 冻融循环（3 次）
├── 加速稳定性（40°C，2 周）
├── 光照稳定性（ICH Q1B 条件）
└── 低 pH 孵育（模拟 Protein A 洗脱条件，pH 3.5，30 min）
```

:::

## 抗体分子固有物理化学性质对稳定性的影响：IgG 亚型、等电点与序列设计

:::answer

**IgG 亚型对稳定性的影响**

在 IgG 四个亚型中，**IgG1 是稳定性最佳的亚型**，是治疗性抗体和融合蛋白开发的首选骨架：

| IgG 亚型 | 铰链区二硫键数 | 耐酸碱性 | 稳定性特点                                                               | 适用场景                                   |
| -------- | -------------- | -------- | ------------------------------------------------------------------------ | ------------------------------------------ |
| **IgG1** | 2              | **最强** | 稳定，二硫键结构简单，工艺兼容性好                                       | 大多数治疗性单抗、Fc 融合蛋白              |
| IgG2     | 4              | 中等     | 二硫键复杂，易发生二硫键错配（产生 IgG2-A、IgG2-B、IgG2-A/B 同分异构体） | 不推荐融合蛋白；特殊靶点（如 PCSK9）可考虑 |
| IgG3     | 多（15）       | 较弱     | 铰链区极长，对蛋白酶高度敏感，半衰期短                                   | 治疗药物中基本不使用                       |
| IgG4     | 2              | 中等     | 铰链区半分子交换问题（Fab 臂交换），引入 S228P 突变可稳定                | 需要低 Fc 效应功能的场景（如 CD3 双抗）    |

**融合蛋白的 Fc 亚型选择建议**

```
融合蛋白设计的 Fc 亚型选择逻辑

需要 Fc 效应功能（ADCC/CDC）？
├── 是 → 优选 IgG1（可进一步去岩藻糖化增强 ADCC）
└── 否 → 优选 IgG1（稳定性优势）或 IgG4（降低 Fc 效应，需 S228P 突变稳定化）

糖型对药效有影响？
├── 有影响（如抗体 Fc 效应功能相关）→ 需关注糖型控制策略
└── 无影响 → IgG1 或 IgG4 均可考虑，根据稳定性优选 IgG1
```

**等电点（pI）对稳定性的影响**

抗体的 pI 通过影响分子表面电荷分布，对多个稳定性维度产生影响：

| pI 特征            | 对稳定性的影响                                                            | 对制剂的影响                                                         |
| ------------------ | ------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **pI 过高（> 9）** | 高正电荷密度，分子间静电排斥弱，聚集倾向增加                              | 与带负电荷的容器表面接触可能形成沉淀性聚集；皮下注射局部刺激风险升高 |
| **pI 适中（6–9）** | 净电荷适中，通常较稳定                                                    | 制剂 pH 选择灵活性较大                                               |
| **pI 过低（< 5）** | 高负电荷密度，可能影响 FcRn 结合（FcRn 在酸性条件下与 Fc 结合依赖正电荷） | PK（半衰期）可能受影响                                               |

**关键原则**：分子设计阶段须避免 pI 过高（> 9.5），必要时通过定点突变调整 pI 至合理范围。

:::

## 高浓度蛋白制剂的成药性评估：皮下注射制剂开发的挑战与判断节点

:::answer

**高浓度制剂需求的临床驱动力**

皮下注射（SC）制剂在临床应用中具有显著的便利性优势（患者自行给药、居家使用），已成为生物药商业化的重要差异化特征。然而，SC 给药的体积限制（通常 ≤ 1 mL/次注射，最大 2 mL）与生物药的高治疗剂量需求之间产生了根本矛盾，推动了**高浓度蛋白制剂**的开发需求。

**高浓度制剂的风险阈值与评估触发条件**

| 浓度范围       | 制剂开发风险等级 | 成药性评估要求                                    |
| -------------- | ---------------- | ------------------------------------------------- |
| < 20 mg/mL     | 低               | 常规制剂开发，无特殊高浓度评估要求                |
| 20–50 mg/mL    | 中等             | 关注黏度和聚集体；常规稳定性研究                  |
| **> 50 mg/mL** | **高**           | **成药性评估阶段必须重点评估高浓度可行性**        |
| > 100 mg/mL    | 极高             | 可能面临黏度过高（> 50 cP）和注射困难的根本性挑战 |

**高浓度制剂面临的三大挑战**

**① 黏度问题**

- 分子间相互作用（疏水性、静电）在高浓度下显著增强
- 黏度过高导致注射困难（须 < 20–50 cP，取决于注射装置）
- 改善策略：添加黏度降低剂（组氨酸、精氨酸、NaCl 浓度优化）

**② 聚集体增加**

```
聚集与浓度的关系
蛋白浓度 ↑ → 分子碰撞频率 ↑ → 疏水核心暴露增加 → 聚集倾向 ↑
```

研究数据证实，聚集体水平随制剂浓度的提升而非线性增加，这对冻融稳定性和货架期构成额外挑战。

**③ 注射部位耐受性**

- 高浓度、高渗透压制剂可能导致注射部位疼痛和炎症反应
- 高 pI 分子在皮下局部中性 pH 环境中容易形成沉淀

**成药性评估的高浓度特殊检测内容**

- **黏度测量**（流变仪，目标 < 20 cP @ 20–50 mg/mL）
- **浓缩可行性**（超滤至目标浓度，监控聚集体和黏度变化）
- **高浓度稳定性**（目标浓度下的加速稳定性）
- **注射力评估**（不同针头规格下的注射阻力）
- **皮下吸收预测**（FcRn 介导的 PK 行为）

**融合蛋白和双特异性抗体的特殊注意事项**

这两类分子通常具有更复杂的结构和更高的聚集倾向，在成药性评估过程中须**重点评估**高浓度制剂可行性，不能简单参照常规单抗的经验数据。

:::

## 分析方法验证的项目与指标体系

:::answer

**验证的分析项目类型**

根据 ICH Q2(R2) 和《中国药典》通则，须进行方法学验证的分析项目包括：

| 分析项目类型              | 典型检测                                   | 验证重点                               |
| ------------------------- | ------------------------------------------ | -------------------------------------- |
| **鉴别试验**              | 肽图、IEF、毛细管电泳                      | 专属性（能正确区分目标分子与其他物质） |
| **杂质测定（限度）**      | 外观、颜色限度检查                         | 专属性、检测限                         |
| **杂质测定（定量）**      | SEC-HPLC 聚集体、CE-SDS 片段、IEX 电荷变体 | 精密度、准确度、定量限、线性           |
| **含量测定（含量/效价）** | UV280 蛋白含量、细胞效价、ELISA            | 准确度、精密度、线性、范围             |
| **特性参数**              | 药物溶出度、释放度（缓释制剂）             | 重现性、耐用性                         |

**验证指标的完整体系**

| 验证指标                                 | 定义                                                | 适用分析项目           |
| ---------------------------------------- | --------------------------------------------------- | ---------------------- |
| **准确度（Accuracy）**                   | 测定值与真实值的接近程度（回收率）                  | 含量测定、定量杂质     |
| **重复性（Repeatability）**              | 同一实验室同一操作者在短时间内的精密度              | 所有定量方法           |
| **中间精密度（Intermediate Precision）** | 同一实验室不同日期、不同操作者、不同仪器            | 所有定量方法           |
| **重现性（Reproducibility）**            | 不同实验室间的精密度（方法转移验证）                | 方法转移场景           |
| **专属性（Specificity）**                | 在干扰物存在下准确测定目标的能力                    | 鉴别、杂质、含量测定   |
| **检测限（LOD）**                        | 可被检测但无需定量的最低量                          | 限度检查、鉴别         |
| **定量限（LOQ）**                        | 可准确定量的最低量（通常 ≥ 10 倍信噪比）            | 定量杂质测定           |
| **线性（Linearity）**                    | 响应与浓度的比例关系（通常 5 个浓度点，r² > 0.999） | 含量测定、定量杂质     |
| **范围（Range）**                        | 准确性和精密度可接受的浓度区间                      | 含量测定、定量杂质     |
| **耐用性（Robustness）**                 | 方法参数小幅变动时结果的稳定性                      | 商业化方法、转移前验证 |

**生物制品分析方法验证的特殊要求**

- 效价（生物活性）方法须额外验证**相似性**（与参比品活性一致性）
- 糖型分析方法须验证**批间重现性**（糖型谱比较）
- 免疫原性（ADA）分析须验证**药物干扰（Drug Tolerance）**和**基质效应**

:::

## 过滤工艺的产品完整性测试与再验证触发条件

:::answer

**基于产品的过滤器完整性标准验证**

过滤器使用后的完整性测试是生物制品无菌保证的关键控制点，其润湿介质的选择须根据实际工艺情况确定：

| 润湿介质选择         | 适用场景                                                 | 额外要求                                                                 |
| -------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------ |
| **水（水基标准）**   | 过滤纯水性缓冲液，与供应商水基标准相符                   | 直接应用供应商提供的完整性标准                                           |
| **产品（药液润湿）** | 产品含有机溶剂、表面活性剂或高蛋白浓度，影响膜的润湿特性 | **必须进行产品相关完整性标准的专项验证**，确立适用该产品的完整性判定阈值 |

**产品相关完整性验证的实验室规模研究**

实验室规模下按比例缩小（Scale-down）的研究是产品完整性试验的**第一步**，须证明：

- 缩小模型与商业规模的相关性（水力学等效性）
- 产品润湿条件下完整性测试结果的重现性
- 完整性合格标准与除菌保证水平（SAL ≥ 10⁻⁶）的关联性

**再验证的触发条件**

完成初始过滤工艺验证后，以下任何变更均须评估是否需要开展再验证：

```
再验证触发条件评估清单
工艺参数变更：
├── 单位面积流速超过已验证流速 → 触发再验证
├── 过滤压差超过验证压差上限 → 触发再验证
├── 过滤时间超过验证时间范围 → 触发再验证
├── 过滤面积不变但提高过滤量 → 触发再验证
└── 过滤温度发生变化 → 评估是否触发

产品/制剂变更：
└── 产品处方改变（如 pH、赋形剂、蛋白浓度）→ 触发再验证

过滤器相关变更：
├── 过滤器灭菌条件或灭菌方式改变 → 触发再验证
├── 过滤器生产商改变 → 触发再验证
├── 过滤器生产工艺变更（供应商通知）→ 触发评估，通常触发再验证
└── 过滤器膜材或结构性组成改变 → 触发再验证
```

**再验证的范围界定原则**

再验证不必重复全部初始验证活动，可基于变更影响评估，**针对性地重新验证受影响的参数和特性**：

- 仅工艺参数变更（如流速提高）→ 重新验证细菌截留性能和完整性
- 过滤器供应商变更 → 须进行完整的等效性验证（包括细菌截留、化学兼容性、完整性标准）

:::

## 生产工艺控制合理性：CDE 挑战点与应对策略

:::answer

**CDE 常见审评挑战问题**

在 IND/BLA 申报 CMC 审评中，生产工艺控制合理性是高频被质询的领域，常见问题包括：

| 挑战类型               | 典型表现                                           | 监管关注点                                   |
| ---------------------- | -------------------------------------------------- | -------------------------------------------- |
| **工艺稳健性不足**     | 批次之间关键质量属性差异较大，批间 CV 超出合理范围 | 工艺未充分优化即推进申报；CPP 范围控制不严格 |
| **过程控制缺失**       | 缺少中间体的系统性控制，尤其是安全性相关指标       | 微生物限度、内毒素未在关键步骤（如 UPB）检测 |
| **关键步骤认定不充分** | 关键步骤的确认缺乏科学依据，仅凭经验判断           | 风险评估不系统，CQA-CPP 关联证据不足         |

**法规对工艺控制合理性的要求**

根据 CDE 技术指南要求，生产工艺应满足以下核心要求：

> 生产工艺应**稳定可控**，并有明确的过程控制参数，以确保制品安全有效、质量可控。工艺的确定应建立在对目标制品的质量属性、生产工艺的深入理解和全面设计的基础上。

**关键步骤确定的科学依据**

```
关键步骤识别方法论
全工艺参数识别（所有步骤的所有参数）
        ↓
风险评估（FMEA/鱼骨图/因果矩阵）
        ↓
对 CQA 影响评分（严重性 × 发生概率 × 可检测性）
        ↓
高评分参数 → 识别为关键工艺参数（CPP）
        ↓
CPP 所在步骤 → 识别为关键步骤（Critical Step）
        ↓
为关键步骤制定可接受标准（CPP 控制范围 + 中间体质量标准）
```

**中间体控制作为风险降低的核心手段**

对于已识别的关键步骤，建立**中间体检测和控制体系**是降低风险的直接措施：

| 中间体              | 建议检测项目                                     | 检测目的                   |
| ------------------- | ------------------------------------------------ | -------------------------- |
| 未处理收获液（UPB） | 微生物限度、内毒素、支原体（首批须检）、外源因子 | 安全性确认，收获合格性判断 |
| Protein A 洗脱液    | pH、效价、HCP（可选）                            | 捕获步骤效率监控           |
| 病毒灭活后中间体    | pH、时间、温度（CIP 参数记录）、效价             | 病毒灭活参数合规性确认     |
| 各层析步骤洗脱液    | 效价、关键杂质（根据步骤功能）、微生物限度       | 纯化效率监控               |
| UF/DF 中间体        | 蛋白浓度、渗透压、pH、内毒素                     | 浓缩换液效果确认           |

**申报策略建议**

- 在 IND 申报资料中，清晰呈现关键步骤识别的**风险评估方法和结果**
- 提供至少 3 批次的批次数据，证明关键步骤参数的控制一致性
- 对安全性相关指标（微生物、内毒素）的检测频率和控制标准提供科学依据

:::
