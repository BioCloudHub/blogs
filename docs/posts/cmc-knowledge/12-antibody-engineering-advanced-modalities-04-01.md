## ADC 药物靶点分类：血液肿瘤与实体瘤的靶点选择逻辑

:::answer

### ADC 靶点的核心选择标准

无论血液瘤还是实体瘤，理想的 ADC 靶点应满足以下基本条件：

| 标准 | 具体要求 | 临床意义 |
|------|---------|---------|
| **肿瘤特异性高表达** | 在肿瘤细胞表面高度且均匀表达 | 保证 ADC 足量到达肿瘤，最大化有效载荷递送 |
| **正常组织低/不表达** | 在非靶组织上表达极低或缺失 | 降低脱靶毒性，扩大治疗窗口 |
| **高效内化能力** | 抗体结合后能被快速、高效地内化至溶酶体 | 内化是载荷释放的必要前提；低内化率是 ADC 失败的重要原因之一 |
| **靶点稳定性** | 不易因突变或下调而发生耐药 | 避免肿瘤通过靶抗原丢失/下调逃避 ADC 杀伤 |
| **表面循环能力** | 内化后能在肿瘤细胞表面循环再表达 | 使单个肿瘤细胞能重复摄取 ADC，提高累计载荷递送量 |

### 血液肿瘤 ADC 靶点：高密度均匀表达的免疫谱系标志物

血液肿瘤靶点的核心优势在于：免疫谱系特异性抗原在恶性血细胞表面高水平、**广泛均匀**表达，内化效率高，且与正常血细胞（造血干细胞）的表达差异相对清晰。

| 靶点 | 主要表达肿瘤 | 代表上市 ADC |
|------|-----------|-----------|
| **CD33** | AML（急性髓系白血病） | Gemtuzumab ozogamicin（Mylotarg） |
| **CD30** | 霍奇金淋巴瘤、间变大细胞淋巴瘤 | Brentuximab vedotin（Adcetris） |
| **CD22** | B 细胞 ALL、NHL | Inotuzumab ozogamicin（Besylomab） |
| **CD79b** | 弥漫大 B 细胞淋巴瘤（DLBCL） | Polatuzumab vedotin（Polivy） |
| **CD19** | B-ALL、DLBCL | Loncastuximab tesirine（Zynlonta） |
| **BCMA** | 多发性骨髓瘤 | Belantamab mafodotin（Blenrep） |

### 实体瘤 ADC 靶点：肿瘤相关膜蛋白与促癌通路关键受体

实体瘤靶点面临的核心挑战是靶抗原在正常组织中往往也有不同程度的表达（"肿瘤相关抗原"而非"肿瘤特异性抗原"），需要精准设计治疗窗口：

| 靶点 | 主要表达肿瘤 | 代表上市 ADC |
|------|-----------|-----------|
| **HER2** | 乳腺癌、胃癌、肺癌、结直肠癌 | T-DM1（Kadcyla）、T-DXd（Enhertu） |
| **TROP2** | 三阴乳腺癌、尿路上皮癌、肺癌 | Sacituzumab govitecan（Trodelvy） |
| **Nectin-4** | 尿路上皮癌 | Enfortumab vedotin（Padcev） |
| **FRα（叶酸受体α）** | 卵巢癌、肺癌（腺癌）、子宫内膜癌 | Mirvetuximab soravtansine（Elahere） |
| **TF（组织因子）** | 宫颈癌、非小细胞肺癌 | Tisotumab vedotin（Tivdak） |
| **EGFR** | NSCLC、结直肠癌、头颈鳞癌 | 多款在研 |

> **实体瘤 ADC 的旁观者效应（Bystander Effect）**：当载荷释放后能穿透细胞膜进入邻近细胞（膜通透性载荷，如 DXd），可杀伤抗原阴性的异质性肿瘤细胞，弥补实体瘤靶抗原不均匀表达的缺陷。T-DXd 的强旁观者效应是其在 HER2 低表达患者中仍有显著疗效的核心机制之一。

## ADC 靶点选择方法：靶点优先法与不可知论法的策略比较

:::answer

### 两大靶点选择方法框架

| 维度 | 靶点优先法（Target-First） | 不可知论法（Agnostic Approach） |
|------|------------------------|---------------------------|
| **出发点** | 已有明确靶点候选，围绕该靶点开发抗体 | 先筛选能结合并内化肿瘤细胞的抗体，再追溯识别靶点 |
| **靶点知识** | 需要先验知识（靶点表达模式、丰度、内吞特性） | 无需先验靶点知识 |
| **说服力** | 高——靶点适宜性和新颖性论证充分 | 相对低——需要额外时间确认靶点的临床价值 |
| **速度** | 慢——抗体内化验证前需大量前期工作 | 快——可直接产生用于验证假说的试剂 |
| **靶点偏好** | 可针对任何预先设计的靶点 | 偏向筛选高表达的表面抗原（高表达靶点更容易被筛选到） |
| **适用场景** | 已有靶点验证数据，需快速推进 | 探索性研究，发现新靶点或验证新内化抗体 |

### 靶点优先法的抗体产生策略

当靶点已知时，可采用多种抗原形式产生抗体：

| 免疫原形式 | 优点 | 适用场景 |
|----------|------|---------|
| **纯化蛋白（全长或结构域）** | 抗原均一，质量可控 | 胞外域结构清晰的靶点 |
| **cDNA 构建物（DNA 免疫）** | 可呈现天然构象；覆盖多个表位 | 难以表达的多次跨膜蛋白 |
| **工程表达细胞** | 天然膜蛋白构象，含翻译后修饰 | 构象依赖性表位，膜蛋白靶点 |
| **病毒样颗粒（VLP）** | 高密度展示抗原，免疫原性强 | 病毒靶点，或需要高效免疫的场景 |

### 不可知论法的抗体筛选流程

```
原发肿瘤细胞或肿瘤细胞系（免疫源）
          ↓ 免疫骆驼/小鼠/噬菌体文库淘选
筛选与肿瘤细胞特异性结合的抗体
          ↓ 内化活性评估（细胞毒素探针标记 / 荧光共定位）
筛选能高效内化至溶酶体的抗体
          ↓ 质谱学（免疫沉淀 + LC-MS/MS）
追溯识别内化抗体的肿瘤细胞表面靶蛋白
          ↓
验证靶点的临床相关性（肿瘤表达谱 + 预后数据）
```

### 抗体来源渠道对比

| 来源 | 技术 | 特点 |
|------|------|------|
| 杂交瘤（免疫小鼠） | 传统杂交瘤 | 成熟，但周期较长，全人源化需额外工程化 |
| B 细胞分离 + V 基因克隆 | 单 B 细胞测序 | 快速，可直接获得人源抗体 |
| 噬菌体展示文库 | 体外筛选 | 无需免疫动物，可针对有毒/自身抗原 |
| 转基因动物（人源化小鼠） | 体内免疫 | 直接产生全人源抗体 |

## ADC 靶点选择趋势：11 个已验证靶点与在研管线格局分析

:::answer

### 靶点筛选的基本要求体系

ADC 靶点的严格筛选是决定药物治疗窗口宽窄的首要因素，核心要求包括：

```
理想 ADC 靶点选择金字塔：

         ① 肿瘤特异性高表达（正常组织低/不表达）
                    ↓
         ② 抗体结合后高效内化（进入溶酶体途径）
                    ↓
         ③ 靶点稳定，不易突变或下调（耐药风险低）
                    ↓
         ④ 靶点在肿瘤细胞表面可循环再利用
                    ↓
         ⑤ 可与旁观者效应协同（实体瘤靶点额外考量）
```

### 已上市 ADC 药物的 11 个靶点全览

目前全球已上市 ADC 药物覆盖 11 个靶点：

| 靶点 | 肿瘤类型 | 代表上市 ADC |
|------|---------|-----------|
| **CD33** | 血液（AML） | Gemtuzumab ozogamicin |
| **CD30** | 血液（HL、sALCL） | Brentuximab vedotin |
| **HER2** | 实体瘤（乳腺、胃、肺） | T-DM1、T-DXd |
| **CD22** | 血液（B-ALL） | Inotuzumab ozogamicin |
| **CD79b** | 血液（DLBCL） | Polatuzumab vedotin |
| **Nectin-4** | 实体瘤（尿路上皮癌） | Enfortumab vedotin |
| **BCMA** | 血液（多发性骨髓瘤） | Belantamab mafodotin |
| **EGFR** | 实体瘤（NSCLC） | Patritumab deruxtecan（在审）|
| **CD19** | 血液（DLBCL） | Loncastuximab tesirine |
| **TF（组织因子）** | 实体瘤（宫颈癌） | Tisotumab vedotin |
| **FRα（叶酸受体α）** | 实体瘤（卵巢癌） | Mirvetuximab soravtansine |

### 在研管线热门靶点分析（425 款在研 ADC）

**HER2——全球管线最拥挤的靶点（国内尤甚）**

- 全球在研数量：约 25 款（占全部 ADC 管线约 36%）
- 已获批适应证：乳腺癌（HER2+/HER2-low）、胃癌、肺癌（腺癌）
- 代表突破：T-DXd（Enhertu）已在结直肠癌中展示出色疗效，拓展至 HER2-low 乳腺癌，颠覆 HER2 阳性判读标准
- **国内问题**：大量企业对标 T-DM1/DS-8201a，HER2 靶点严重扎堆，差异化竞争压力极大

**TROP2——覆盖多个大癌种的新星靶点**

- 全称：人滋养细胞表面糖蛋白抗原 2（Trophoblast Cell Surface Antigen 2）
- 促肿瘤机制：调节钙离子信号通路 + 调控细胞周期蛋白表达 + 降低纤黏蛋白黏附 → 促进肿瘤细胞生长、增殖和转移
- 高表达肿瘤：三阴乳腺癌（TNBC）、尿路上皮癌、NSCLC、胰腺癌、结肠癌、卵巢癌
- 代表药物：Sacituzumab govitecan（Trodelvy，IMMU-132），FDA 2020 年批准

**EGFR——传统靶点在 ADC 领域的再生机遇**

- 多种上皮来源实体瘤（NSCLC、结直肠癌、胰腺癌、肾癌、膀胱癌）存在 EGFR 高表达
- ADC 模式可绕过小分子 TKI 的耐药问题（如 T790M、C797S 突变），通过细胞毒载荷直接杀伤
- 代表进展：Patritumab deruxtecan（HER3-DXd，靶向 EGFR 家族 HER3）在 EGFR 突变 NSCLC 中展示明确疗效

**c-Met——高潜力但开发较早期的靶点**

- 全称：细胞间质上皮转换因子（Mesenchymal-Epithelial Transition factor），受体酪氨酸激酶家族
- 异常激活方式：基因扩增（胃癌、肺癌）、外显子 14 跳跃突变（NSCLC）、过表达（多种实体瘤）
- c-Met 通路激活促进肿瘤侵袭性生长和转移（HGF/c-Met 轴）
- 小分子抑制剂已获批 4 款（卡马替尼、特泊替尼等），ADC 仍处于早期临床阶段

### 双靶点 ADC：下一代靶点开发方向

| 策略 | 理论优势 | 代表方向 |
|------|---------|---------|
| **双抗体靶向 ADC** | 同时结合两个肿瘤抗原，提高肿瘤选择性 | HER2 双表位双抗-ADC |
| **双靶点 ADC** | 载荷同时靶向两个肿瘤驱动通路 | PDL1/PDL2 双抗-ADC（兼具免疫激活） |
| **CLDN9/CLDN6 双靶** | 提高 Claudin 家族覆盖范围 | 卵巢癌、睾丸癌等 CLDN6 高表达肿瘤 |

## ADC 药物热门靶点深度解析：HER2、TROP2、EGFR 与 c-Met

:::answer

### HER2——ADC 领域的"王者靶点"

**为何 HER2 是 ADC 最理想的靶点之一：**

| 靶点特性 | HER2 的表现 |
|---------|-----------|
| 肿瘤高表达 | 乳腺癌 25-30%、胃癌 10-30%、肺癌腺癌等多瘤种均有扩增 |
| 内化效率 | 抗体结合后可通过受体介导的内吞作用高效内化 |
| 靶点稳定性 | 基因扩增驱动，不易通过点突变完全逃逸 |
| 已验证的安全性 | 曲妥珠单抗 25+ 年临床数据证明靶向 HER2 的安全性 |

**HER2-low（低表达）的定义与 T-DXd 的突破：**

```
HER2 传统阳性定义：IHC 3+ 或 IHC 2+/FISH+（约 15-20% 乳腺癌）
HER2-low 定义：IHC 1+ 或 IHC 2+/FISH-（约 45-55% 乳腺癌）

T-DXd（Enhertu）的旁观者效应极强：
→ 即使 HER2 低表达细胞内化的 ADC 较少
→ 释放的 DXd 可穿透细胞膜扩散至邻近细胞（抗原阴性细胞亦被杀伤）
→ HER2-low 乳腺癌患者 PFS 显著获益（DESTINY-Breast04 试验）
```

### TROP2——三阴乳腺癌和尿路上皮癌的关键靶点

**TROP2 促肿瘤的分子机制：**

```
TROP2 高表达
    ↓
① 调节钙离子信号通路 → 促进细胞增殖
② 细胞周期蛋白（Cyclin D1/E）上调 → G1/S 期加速
③ 降低纤黏蛋白（Fibronectin）介导的细胞黏附 → 促进迁移和转移
④ MAPK/ERK、PI3K/AKT 通路激活 → 细胞存活
```

**Sacituzumab govitecan（Trodelvy）的成功要素：**
- 抗体：人源化抗 TROP2 IgG1（hRS7）
- 连接子：可水解的碳酸酯连接子（CL2A）——在肿瘤微环境的低 pH 下加速水解，中等稳定性
- 载荷：SN-38（伊立替康的活性代谢物，Top1 抑制剂），高效旁观者效应
- DAR：约 7.6（高 DAR，载荷量大，适合靶点中等表达密度的 TROP2）

### EGFR ADC 的特殊挑战

EGFR 作为 ADC 靶点面临的核心难题是**正常皮肤/消化道上皮的 EGFR 表达**导致脱靶毒性（皮肤毒性、消化道毒性），需要通过以下策略优化治疗窗：

- 选用内化效率更高的抗体（减少非内化型抗体的系统毒性）
- 选用旁观者效应适中的载荷（不希望过强的旁观者效应加重皮肤毒性）
- 精确控制 DAR（避免高 DAR 带来的额外非特异性毒性）

### c-Met ADC 的开发挑战与机遇

c-Met 扩增/突变是多种肿瘤（NSCLC MET exon14 跳跃突变约 3-4%、胃癌 MET 扩增约 5-20%）的重要耐药机制，c-Met 靶向 ADC 可在 MET 通路抑制基础上叠加细胞毒杀伤：

- **机遇**：MET 扩增/过表达患者对 c-Met 高度依赖，靶点驱动明确
- **挑战**：MET 扩增具有肿瘤内异质性（克隆性 vs 亚克隆性），ADC 疗效预测需要精准的伴随诊断

## HER2 靶向 ADC 的开发挑战：从异质性到多样化分子设计

:::answer

### HER2 的分子生物学特征

HER2（ErbB2）是 EGFR 家族（HER1/2/3/4）的唯一成员，其特殊之处在于：

- **无已知特异性配体**，但可与 HER1/3/4 形成异二聚体，成为最强的促增殖信号组合（尤其是 HER2-HER3 二聚体激活 PI3K/AKT 通路）
- 是家族中**唯一可与任何其他成员形成二聚体**的受体，处于中枢调控位置
- HER2 扩增/过表达导致持续性受体信号激活，无需配体刺激

### HER2 靶向 ADC 的核心开发挑战：异质性问题

**异质性来源：**

```
抗体（mAb）
    × 连接子（Linker，可切割/不可切割）
        × 有效载荷（Payload，种类和特性）
            × 偶联位点（随机 Lys/Cys vs 定点偶联）
                × DAR（药抗比，0-8+）
                          ↓
产生数百万计不同形式的 ADC 分子混合物
（异质性直接影响稳定性、PK 和清除率）
```

**异质性对 ADC 性能的影响：**

| 异质性维度 | 对药物性质的影响 |
|----------|--------------|
| DAR 分布宽泛 | 低 DAR 物种疗效不足；高 DAR 物种（DAR≥8）易聚集、疏水性强、非特异性清除快 |
| 偶联位点不同 | 不同位点偶联的 ADC 体内 PK 特性（消除速率、分布）显著不同 |
| 药物分子批次差异 | 工业化生产批间一致性面临巨大挑战 |

### HER2 靶向 ADC 的分子设计多样化（机遇与挑战并存）

**抗体臂的选择扩展：**

| 抗体类型 | 优势 | 代表方向 |
|---------|------|---------|
| 单克隆抗体（mAb） | 成熟，PK 特性明确 | T-DM1、T-DXd |
| 双特异性抗体（BsAb） | 同时结合 HER2 两个表位，增加内化效率 | Zanidatamab-zovto（HER2/HER2 双表位 ADC，在研） |
| 纳米抗体（Nb） | 体积小，肿瘤穿透力强，可多价偶联 | 研究阶段 |

**有效载荷扩展至非传统细胞毒素：**

| 载荷类型 | 举例 | 特点 |
|---------|------|------|
| 微管蛋白抑制剂 | DM1（Emtansine）、MMAE | 经典，对增殖期细胞高效 |
| Top1 抑制剂 | DXd（Deruxtecan）、SN-38 | 旁观者效应强，DAR 高（~8） |
| DNA 损伤剂 | PBD 二聚体、Calicheamicin | 超强效，治疗窗窄 |
| 蛋白质毒素 | 假单胞菌外毒素（PE38） | 高效，但免疫原性风险高 |
| 免疫刺激剂（ISAC） | STING 激动剂、TLR 激动剂 | 双重：细胞毒 + 免疫激活（新方向） |
| siRNA | 靶向肿瘤驱动基因 | 基因沉默型 ADC（探索阶段） |

## N-糖结构与 ADCC、ADCP 效应的关系：Fc 糖基化工程的分子机制

:::answer

### Fc N-糖的基本结构

IgG1 的 Fc 段 CH2 区 **Asn-297** 位携带复杂型双天线 N-糖链，其组成直接决定 Fc 与各类 FcγR 的结合亲和力，进而调控 ADCC 和 ADCP 效应：

```
复杂型双天线 N-糖基本结构：
    Man（甘露糖）
   /
GlcNAc — GlcNAc（核心）— [±核心岩藻糖（Fuc）]
   \
    Man
   / \
GlcNAc  GlcNAc（± 分支 GlcNAc）
   |        |
 [±Gal] [±Gal]
   |        |
[±Sia]  [±Sia]（唾液酸）
```

### 各糖型修饰对 ADCC 效应的影响机制

| 糖型修饰 | 对 ADCC 的影响 | 分子机制 |
|---------|--------------|---------|
| **去核心岩藻糖（Afucosylation）** | **显著增强（5～50 倍）** ✓✓✓ | 岩藻糖位于 CH2 Asn-297 糖链核心 GlcNAc 的 α1-6 位；其存在产生空间位阻，阻碍 Fc 与 FcγRIIIa 的 N162 糖链间的直接接触（糖-糖相互作用）；去除岩藻糖后，Fc/FcγRIIIa 结合亲和力提升 5～50 倍 |
| **增加分支 GlcNAc（β1-4-GlcNAc 转移酶过表达）** | **增强** ✓✓ | 分支 GlcNAc 的存在本身会空间位阻地抑制核心岩藻糖的生成（岩藻糖转移酶底物竞争），间接产生去岩藻糖化效果；罗氏 GlycoArt 技术（Obinutuzumab）即基于此原理 |
| **高甘露糖型 N-糖** | **中等增强** ✓ | 高甘露糖型糖链天然缺少核心岩藻糖，机制与去岩藻糖类似 |
| **增加半乳糖化（Galactosylation）** | **轻度增强（有条件）** | 半乳糖与 FcγRIIIa 不同 N-糖结合，调节 Fc-FcγRIIIa 相互作用；但在有岩藻糖存在的情况下结果变异大（从无效应到有效）；在去岩藻糖背景下效果更稳定 |
| **唾液酸化（Sialylation）** | **减弱** ✗ | 高唾液酸化削弱 Fc/FcγRIIIa 结合亲和力；唾液酸修饰可能变构铰链区，使 Fab 从双价变为单价结合，影响膜抗原聚集和效应触发 |

### 工程实现去岩藻糖化的技术路径

| 技术 | 方法 | 代表产品 |
|------|------|---------|
| **FUT8 基因敲除（KO）** | 敲除 α-1,6-岩藻糖转移酶（FUT8），宿主细胞无法添加核心岩藻糖 | Mogamulizumab（KHK 平台） |
| **过表达 GnT-III（β-1,4-GlcNAc 转移酶）** | 增加分支 GlcNAc，竞争性抑制岩藻糖转移 | Obinutuzumab（Roche GlycoMab） |
| **岩藻糖类似物（2-F-Fucose）** | 添加岩藻糖竞争性类似物，抑制岩藻糖代谢途径 | 研究工具 |
| **培养基优化** | 控制培养基岩藻糖和甘露糖浓度 | 工艺调控策略 |

### 糖型对 ADCP 效应的影响

ADCP 的主要效应受体为 **FcγRIIa（CD32a）**，目前研究数据相对有限：

| 糖型修饰 | 对 ADCP 的影响 |
|---------|--------------|
| 去核心岩藻糖 | 增强 ADCP（FcγRIIa 亲和力同步提升）|
| 去末端半乳糖 | 增强 ADCP |
| 含末端 Neu5Gc（非人源唾液酸） | 增强 ADCP（通过 Siglec 受体介导机制，需进一步研究） |

## 影响 ADC 有效性的关键物理化学因素

:::answer

### ADC 有效性的决定因素体系

ADC 的最终疗效是抗体靶向性、载荷杀伤力和整体 ADME 特性的综合体现，关键影响因素包括：

### 一、偶联方式（Conjugation Chemistry）

| 偶联类型 | DAR 均一性 | 对 PK 的影响 | 疗效/安全性 |
|---------|----------|------------|-----------|
| **赖氨酸随机偶联** | 极差（每条抗体 ~40 个赖氨酸，偶联位点数百万种组合） | PK 变异大，高 DAR 物种快速清除 | 治疗窗窄 |
| **半胱氨酸随机偶联**（还原链间二硫键） | 中等（DAR 0/2/4/6/8 分布） | 较赖氨酸改善，但高 DAR 物种仍有问题 | T-DM1 采用此策略 |
| **定点偶联（Site-specific）** | 均一（DAR 2 或 4，均一分布） | PK 一致、可预测 | 治疗窗显著扩大 |

### 二、DAR（药抗比）

| DAR 范围 | 影响 |
|---------|------|
| DAR 0（未偶联抗体） | 竞争靶点，稀释 ADC 效应，降低有效浓度 |
| DAR 1-2 | 疗效可能不足，但 PK 好，安全性高 |
| **DAR 2-4（最优范围）** | 疗效与安全性的最佳平衡点 |
| DAR 6-8 | 疏水性增加 → 聚集倾向强 → 非特异性清除加快 → 系统毒性风险增加 |
| DAR > 8 | 通常不接受，治疗窗极窄 |

### 三、连接子长度与位阻

- 连接子**过短**：载荷被包埋在抗体空间位阻内，释放效率低，溶酶体降解不充分
- 连接子**过长**（高疏水性）：促进 ADC 分子聚集，增加免疫原性，非特异性组织摄取
- **亲水性 PEG 连接子**：可改善溶解度，减少聚集倾向（现代 ADC 设计趋势）

### 四、半衰期

- ADC 在血浆中的半衰期过短 → 无法到达足够数量的肿瘤细胞
- 影响因素：高 DAR（加速非特异性清除）、载荷疏水性（增加肝脏摄取）、ADA 产生（免疫介导清除）

### 五、连接子稳定性与异质性的综合影响

```
连接子不稳定 → 载荷在血循环中过早释放
          ↓
正常组织暴露于游离载荷（细胞毒素）
          ↓
脱靶毒性（骨髓抑制、肝毒性、神经毒性等）
          ↓
治疗窗缩窄，最大耐受剂量（MTD）降低
```

## 纳米抗体（Nanobody）：结构基础、独特优势与开发局限

:::answer

### 纳米抗体的发现与结构特征

**纳米抗体（Nanobody，Nb）** 源于骆驼科动物（骆驼、单峰驼、羊驼）外周血中天然存在的一类**缺失轻链的重链抗体（HcAb）**。其可变区结构域（**VHH**）即为纳米抗体：

```
普通 IgG：VH-CH1-Fc (重链) + VL-CL (轻链) — 四链异二聚体（~150 kDa）
HcAb（骆驼）：VHH-CH2-CH3 — 双链同二聚体，无轻链（~80 kDa）
纳米抗体（VHH）：单个 VHH 结构域（~15 kDa，晶体 2.5 nm × 4 nm）
```

**VHH 的独特结构特点（vs 传统抗体 VH）：**

| 结构特征 | VHH（纳米抗体） | 传统 VH |
|---------|--------------|--------|
| CDR3 长度 | 更长（平均 16-17 aa vs 12 aa），可形成凸环结构 | 较短 |
| 亲水残基 | 框架区第 37/44/45/47 位替换为亲水残基 | 第 37/44/45/47 位为疏水残基（VL 配对界面） |
| 二硫键 | 额外的 CDR1-CDR3 二硫键（部分 VHH） | 通常无 CDR 内二硫键 |
| 溶解性 | 高，无聚集倾向 | 单独 VH 易与其他蛋白聚集 |

**编码基因特征：**

- VHH 基因由 ~360 bp 组成（极小的编码序列）
- 便于基因工程操作：多价串联、Fc 融合、PEG 化、药物偶联等
- 可在大肠杆菌、酵母（毕赤酵母）等微生物系统中高效表达，无需哺乳动物细胞系

### 纳米抗体的核心优势

| 优势维度 | 具体表现 | 与传统单抗的比较 |
|---------|---------|--------------|
| **体积极小** | ~15 kDa，2.5 nm | 传统 IgG ~150 kDa，~10 nm |
| **强组织穿透力** | 可深入实体瘤、进入隐蔽表位（酶活性位点、受体凹槽） | IgG 因体积大，实体瘤穿透受限 |
| **高热/pH 稳定性** | 80°C 仍维持活性；在极端 pH（含胃液）中稳定 | IgG 通常 50°C 即失活 |
| **人 VH3 高同源性** | VHH 与人 VH 家族 3 同源性约 85% | 免疫原性低，慢性病治疗适用 |
| **微生物表达** | 大肠杆菌/酵母高效表达（无需哺乳动物细胞系） | IgG 需要 CHO/NS0 等哺乳动物细胞 |
| **基因工程兼容性** | 单基因表达，易于多价串联、融合蛋白构建 | 重轻链配对复杂，工程化改造难度更大 |
| **吸入给药潜力** | 可雾化，直接作用于肺部病灶（呼吸道感染治疗） | IgG 难以雾化，肺部生物利用度低 |

### 纳米抗体的主要局限性

| 局限 | 根本原因 | 解决策略 |
|------|---------|---------|
| **血浆半衰期极短**（< 1 小时） | 分子量（~15 kDa）远低于肾小球滤过阈值（~69 kDa），肾脏快速清除 | ① Fc 融合（→ ~40 kDa FcAb 形式，FcRn 介导循环延长至 ~21 天）② PEG 化（增大流体力学半径）③ 白蛋白结合（通过抗白蛋白 Nb 结合白蛋白，借助 FcRn 循环） |
| **无 ADCC/CDC 效应** | 缺少 Fc 段，无法与 FcγR 和 C1q 结合 | Fc 融合（引入效应功能）；或将 Nb 用于纯定向递送（无需 Fc 效应的场景） |
| **动物来源依赖** | 需从骆驼科动物获取 HcAb 免疫库 | 转基因小鼠（可产生 HcAb 的小鼠）；合成文库（完全人工构建 VHH 文库） |
| **研发流程生物危害** | 筛选过程涉及噬菌体、质粒、抗生素和重组 DNA | 标准实验室 BSL-2 管理；相对传统单抗风险并不高 |
| **胞内递送挑战** | 纳米抗体表达载体如何进入靶细胞（用于胞内靶点） | 基因治疗载体（AAV、慢病毒）介导胞内表达；细胞穿透肽（CPP）融合 |

:::

## 纳米抗体在癌症治疗中的四大应用模式

:::answer

### 纳米抗体用于癌症治疗的核心优势

相较于传统单克隆抗体，纳米抗体在肿瘤治疗中的核心优势在于：

- **更强的实体瘤穿透能力**：分子量小（~15 kDa），可均匀渗透实体瘤组织，而 IgG（~150 kDa）在肿瘤内分布通常不均匀（结合位点屏障效应，Binding Site Barrier）
- **无 Fc 段**：可作为纯粹的"靶向载体"，不触发非预期的 Fc 效应（也不会被 FcR 表达细胞非特异性摄取）
- **易于工程化修饰**：可与效应分子、药物、放射性核素、光敏剂等共价偶联

### 应用模式一：纳米抗体-效应分子偶联

**原理：** 利用纳米抗体作为靶向"运输工具"，将蛋白毒素、酶等效应分子精准递送至肿瘤细胞，在靶部位富集发挥杀伤效应，减少全身毒性。

**代表研究案例：**

| 组合 | 靶点 | 机制 |
|------|------|------|
| 抗 VEGFR2 Nb-假单胞菌外毒素 A | VEGFR2 | 靶向抑制肿瘤血管内皮细胞 |
| 抗 MHC-II Nb-DMⅠ（微管蛋白抑制剂） | MHC-II | 靶向 MHC-II 阳性肿瘤细胞 |
| 双价抗 EGFR Nb-TRAIL（凋亡诱导配体） | EGFR | 联合靶向阻断 + 凋亡诱导 |
| 抗 CEA Nb-β 内酰胺酶 + 药物前体 | CEA（癌胚抗原） | 抗体导向酶前体药物疗法（ADEPT） |

### 应用模式二：纳米抗体-药物传递系统（纳米颗粒/脂质体）

**原理：** 将纳米抗体与包裹药物的纳米颗粒（脂质体、胶束等）偶联，利用纳米抗体的靶向性将疏水性药物以亲水形式精准递送，大剂量给药同时减少系统毒性。

**设计优势：**
- 疏水载荷（如紫杉醇、阿霉素）可被包封在亲水纳米颗粒内，改善溶解度和稳定性
- 大分子纳米颗粒在血液循环中半衰期延长（EPR 效应增强肿瘤蓄积）
- 一个纳米颗粒可携带大量药物分子（高载药量），实现大剂量单次给药

**代表研究案例：**

| 体系 | 靶点/载荷 | 双重效应 |
|------|---------|---------|
| 抗 EGFR Nb-脂质体（包裹 IGF-R1 激酶抑制剂） | EGFR + IGF-R1 | 同时阻断 EGFR（Nb）和 IGF-R1（载荷） |
| 抗 EGFR Nb-胶束（包裹阿霉素） | EGFR | EGFR 下调 + 肿瘤细胞增殖抑制 |
| 生物素酰化抗 EGFR Nb-链霉亲和素胶粒 | EGFR（肝肿瘤） | 精准递送至 EGFR+ 肝肿瘤 |

### 应用模式三：纳米抗体-放射性核素治疗（放射免疫疗法）

**原理：** 放射性同位素标记纳米抗体，利用纳米抗体的肿瘤靶向性将放射性核素精准递送至肿瘤，发挥局部高剂量放射治疗效应，最小化对健康组织的影响。

**相比放射性标记 IgG 的优势：**

| 特性 | 放射性标记 IgG | 放射性标记纳米抗体 |
|------|-------------|----------------|
| 肿瘤渗透性 | 低（体积大，分布不均） | **高**（体积小，均匀渗透） |
| 靶向特异性 | 中等 | **高** |
| 血液清除 | 慢（半衰期长，血液放射剂量高） | 快（可选快速清除模式，降低血液毒性） |
| 非靶组织背景 | 高（Fc 在肝脾等高 FcγR 器官积聚） | **低**（无 Fc 段，非特异性摄取少） |

> **FDA 批准现状**：目前仅批准一种放射性同位素标记的抗 CD20 单抗（替伊莫单抗，IgG 基础），而多个放射性标记纳米抗体处于临床研究阶段，尤其在前列腺癌（抗 PSMA Nb）和骨髓瘤（抗 CD38/BCMA Nb）领域进展积极。

### 应用模式四：纳米抗体-光动力治疗（光免疫疗法）

**原理：** 光动力疗法（PDT）结合光敏剂和特定波长光照射，在肿瘤部位产生活性氧（ROS），选择性杀伤肿瘤细胞。纳米抗体作为靶向载体，将光敏剂精准递送至肿瘤，形成靶向光动力疗法（Targeted PDT）。

**优势：** 将 PDT 的微创、低系统毒性与纳米抗体的肿瘤靶向性结合，同时借助分子成像技术实现诊疗一体化（Theranostics）：

```
抗 EGFR 纳米抗体-光敏剂复合物
          ↓ 静脉给药
靶向富集于 EGFR 高表达肿瘤
          ↓ 特定波长光照射
光敏剂激发 → 活性氧（ROS）大量产生
          ↓
肿瘤细胞氧化性损伤 → 凋亡/坏死
（同时可通过荧光成像实时监测药物分布）
```

:::

## 纳米抗体吸入给药：呼吸道感染治疗的新策略

:::answer

### 吸入给药的药动学优势

**吸入式给药（Inhalation Drug Delivery）** 通过呼吸道将药物直接递送至肺泡或病变部位，具有以下独特优势：

```
肺泡给药的优势参数：
    肺泡表面积：~70 m²（极大的吸收面积）
    肺泡壁厚：仅 2 层细胞（肺泡上皮 + 毛细血管内皮，共约 0.5 μm）
    肺毛细血管血流量：~5 L/min（等于全部心输出量）
          ↓
药物可在数秒内被大量吸收入循环（气体麻醉药、吸入β2激动剂等的起效基础）
或在肺部病灶实现高浓度局部作用（治疗肺炎、哮喘、COPD 的优选途径）
```

### 传统单抗吸入给药的困境

| 挑战 | 具体问题 |
|------|---------|
| **雾化稳定性差** | IgG（~150 kDa）结构复杂，雾化过程中剪切力和气液界面张力可导致变性/聚集 |
| **肺部生物利用度低** | IgG 分子量大，难以跨越肺上皮屏障；Fc 介导的非特异性 FcRn 循环复杂化肺部 PK |
| **剂量需求大** | 静脉注射 IgG 效率低（肺部靶组织浓度不足），须高剂量 → 成本高、副作用风险大 |
| **开发周期长** | 无法快速针对突变病毒株（如流感新亚型、SARS-CoV-2 变异株）快速开发新药 |

### 纳米抗体吸入给药的解决方案

| 优势 | 机制 |
|------|------|
| **雾化稳定性优异** | 单链结构，高热/pH 稳定性，雾化过程中不变性/聚集 |
| **高肺部生物利用度** | 分子量小（~15 kDa），在肺部组织中扩散快，浓度高 |
| **少量即有效** | 直接在感染部位（呼吸道黏膜/肺泡）富集，所需有效剂量低 |
| **快速开发** | 单基因编码，噬菌体展示快速筛选，从新病毒株出现到候选纳米抗体筛选完成可在数周内实现 |

### 呼吸道病毒治疗的典型应用

- **SARS-CoV-2**：多个吸入式抗 RBD 纳米抗体处于临床研究阶段，直接中和鼻咽/肺部病毒
- **RSV（呼吸道合胞病毒）**：吸入式纳米抗体靶向 F 蛋白保守位点，适用于高危婴幼儿预防
- **流感病毒**：靶向 HA 茎部保守位点的广谱纳米抗体（可覆盖多种流感亚型）

- **CAR 靶点**：BCMA（B 细胞成熟抗原）

```
单一 scFv CAR：对 BCMA 低表达细胞敏感性低；可能因抗原下调而耐药

    ③ 纳米抗体的紧凑结构 → CAR-T 细胞表面 CAR 密度更高
```

## 纳米抗体的应用挑战与技术解决方案

:::answer

### 主要应用挑战及对应解决策略

**挑战一：胞内靶点的纳米抗体递送**

神经退行性疾病（阿尔茨海默病、帕金森病）中，靶蛋白（Tau、α-synuclein）位于细胞内，传统抗体在具有还原性的细胞质中无法正确折叠，而纳米抗体可保持稳定结构（单链，无链间二硫键依赖）。**挑战在于如何递送纳米抗体进入细胞**。

解决策略：
- **基因治疗**：将 VHH 编码基因装入 AAV 载体（仅 ~360 bp），通过 AAV 介导体内转导，细胞自行表达纳米抗体（胞内抗体，Intrabody）
- **细胞穿透肽（CPP）融合**：与 TAT、Penetratin 等 CPP 融合，增强纳米抗体的细胞穿透能力

**挑战二：筛选亲和力不足的问题**

初次筛选可能获得一价亲和力较低的纳米抗体（脱落速率快）。

解决策略：
- **噬菌体展示亲和力成熟**：经噬菌体展示筛选后，VHH 的亲和力通常可提升 ~1.5 倍
- **随机重组文库（Domain Shuffling）**：通过 DNA 重组技术获得随机重组的直系同源基因片段，构建多样性更高的文库，筛选更稳定、更高亲和力的 VHH

**挑战三：抗原本身的特殊性（毒性/传播性/低免疫原性靶点）**

当靶抗原具有毒性、高度传染性或免疫原性低时，**体内免疫骆驼并不可行**。

解决策略：
- **非免疫合成文库淘选**：使用预构建的人工合成 VHH 文库，通过体外亲和筛选直接获得特异性纳米抗体
- **核糖体展示技术**：完全体外展示和选择，无需活细胞或噬菌体，可处理毒性/传染性抗原
- **转基因小鼠（可产生 HcAb）**：通过 B 细胞体内亲和成熟获得高质量 VHH，绕过骆驼科动物饲养依赖

:::

## ADC 四要素：Linker 设计原则与关键性质

:::answer

### ADC 四大核心要素概览

ADC 药物的"魔法"效果取决于四个关键要素的精心整合：

```
ADC 四要素：
    ① 抗体（Antibody）— 靶向性
    ② 有效载荷（Payload）— 杀伤力
    ③ 连接子（Linker）— 稳定性与释放控制
    ④ 偶联技术（Conjugation）— 均一性与定点精准性
```

### Linker 的三大核心功能要求

**要求一：血液循环中的稳定性**

```
Linker 在血液循环中应保持高度稳定
    → 防止细胞毒载荷在到达肿瘤前提前释放
    → 防止游离载荷对正常组织造成损伤（脱靶毒性）
    → Linker 稳定性 ↑ = 治疗窗 ↑ = 安全性 ↑
```

临床证据：有研究显示，没登素生物碱类 ADC（登山列卡）的 Linker 稳定性与不良反应呈**负相关**（稳定性越好，不良反应越少）。

**要求二：肿瘤细胞内的快速裂解**

```
ADC 被内化至溶酶体后，Linker 必须快速裂解
    → 及时释放具有活性的细胞毒载荷
    → 内化后裂解速率越快，胞内有效载荷浓度越高，杀伤力越强
```

**要求三：疏水性控制**

```
疏水性 Linker + 疏水性 Payload
    → 促进 ADC 分子聚集
    → 引发免疫原性（聚集体触发 B 细胞/树突细胞）
    → 加速非特异性清除（巨噬细胞摄取聚集体）

解决策略：
    引入亲水性 PEG 间隔臂（Spacer）
    → 改善 ADC 溶解度
    → 降低聚集倾向
    → 改善 PK（减少非特异性清除）
```

### 两大类 Linker 对比

| Linker 类型 | 裂解机制 | 代表结构 | 主要特点 |
|-----------|---------|---------|---------|
| **可切割 Linker** | 肿瘤细胞特异性环境触发裂解 | — | ADC 的主要类型 |
| &nbsp;— 酸敏感（pH 敏感） | 溶酶体低 pH（~4.5-5.5）水解 | 腙键（Hydrazone） | 早期 ADC（Mylotarg），溶酶体特异性 |
| &nbsp;— 蛋白酶敏感 | 溶酶体组织蛋白酶（Cathepsin B/D）裂解 | 缬氨酸-瓜氨酸（VC）二肽 | 最主流（T-DM1、Brentuximab vedotin 的 MC-VC-PABC） |
| &nbsp;— 谷胱甘肽敏感 | 细胞内高浓度谷胱甘肽（GSH，10 mM vs 细胞外 20 μM）还原 | 二硫键 Linker | 血液/胞外稳定，胞内迅速还原裂解 |
| &nbsp;— 可水解 | pH 依赖的酯键/碳酸酯键水解 | CL2A（Sacituzumab govitecan） | 中等稳定性，兼具旁观者效应潜力 |
| **不可切割 Linker** | 不被酶或化学条件裂解；需抗体被溶酶体完全降解后才释放 Linker-Payload 复合物 | Thioether（SMCC，T-DM1 使用）、Maleimide | 稳定性最好；释放的载荷为 Linker-氨基酸-Payload 复合物，需载荷本身有足够细胞穿透能力 |

:::

## ADC 发展史：三代技术演进与四要素的系统性迭代

:::answer

### 三代 ADC 的核心技术演进

```
ADC 发展时间轴：

1970s-1990s     2000-2015         2015-至今
    |               |                 |
第一代 ADC      第二代 ADC         第三代 ADC
鼠源单抗       人源化/全人源单抗    优化单抗 + 定点偶联
传统化疗药     高效细胞毒素        多样化 Payload
不可裂解 Linker 可裂解 Linker      位点特异性 Linker
随机赖氨酸偶联  赖氨酸/半胱氨酸     位点特异偶联
                随机偶联           均一 DAR（2/4）
```

### 第一代 ADC：概念验证阶段

**技术特征：**
- 抗体：鼠源单克隆抗体（HAMA 反应严重，体内半衰期短）
- 有效载荷：丝裂霉素 C、伊达比星、蒽环类、阿霉素、长春花碱、甲氨蝶呤等（效价相对较低，需高 DAR 才能有效）
- 连接子：不可裂解连接物（酰胺键、琥珀酰亚胺键），偶联后稳定但释放效率低
- 结果：多数临床失败，原因是靶点选择不佳、抗体免疫原性强、偶联效率低

### 第二代 ADC：有效性提升但治疗窗仍窄

**关键技术进步（距第一代约 10 年进化）：**
- 抗体：人源化/全人源单抗（半衰期显著延长，免疫原性大幅降低）
- 有效载荷：新型超高效细胞毒素（毒力比第一代高 **100-1000 倍**），如 MMAE（微管蛋白抑制剂）、DM1（美登素衍生物）、Calicheamicin（DNA 链断裂剂）
- 连接子：可裂解连接子（VC-PABC、腙键等），实现溶酶体特异性载荷释放

**代表药物：**

| 药物 | 靶点 | 适应证 | 获批年份 |
|------|------|-------|---------|
| Brentuximab vedotin（Adcetris） | CD30 / MMAE | 霍奇金淋巴瘤 | 2011（FDA） |
| Ado-trastuzumab emtansine（Kadcyla/T-DM1） | HER2 / DM1 | HER2+ 乳腺癌 | 2013（FDA） |
| Inotuzumab ozogamicin（Besylomab） | CD22 / Calicheamicin | B-ALL | 2017（FDA） |

**第二代局限：**
- 治疗窗口仍偏窄（低 DAR 物种疗效不足；高 DAR 物种毒性增加）
- 脱靶毒性来源：游离载荷、非特异性内化（FcγR 介导摄取）
- 未结合的裸抗体竞争肿瘤靶点，稀释 ADC 有效浓度

### 第三代 ADC：均一性与多样化设计的时代

**关键技术突破——位点特异性偶联：**

```
传统随机赖氨酸偶联的问题：
    一条 IgG 上约 40 个赖氨酸残基可供偶联
    → 偶联位点理论组合：数百万种
    → 产生 DAR 0/1/2/.../8 的混合物
    → 每个 DAR 下还有多种不同位点组合
    → 批次间一致性面临极大挑战

位点特异性偶联的解决方案：
    通过工程化手段将偶联位点限定在特定位置
    → 均一 DAR（通常为 2 或 4）
    → 批次间一致性大幅提升
    → PK/安全性/疗效可预测性增强
```

**位点特异性偶联的主要技术路线：**

| 技术 | 偶联位点 | 原理 | 代表应用 |
|------|---------|------|---------|
| **工程化半胱氨酸（THIOMAB）** | 引入的游离 Cys 残基（如 Ser239Cys） | 在特定位置引入非天然 Cys，不还原链间二硫键 | Genentech THIOMAB 技术 |
| **非天然氨基酸（UAA）** | 引入对乙酰苯丙氨酸（pAcF）等 UAA | 通过正交 tRNA/aaRS 系统遗传编码 UAA，利用 oxime/Click 化学偶联 | Sutro Biopharma 平台 |
| **酶介导偶联（SMARTag/Sortase）** | 特定肽段序列 | 转谷氨酰胺酶（mTG）识别 Gln297 或工程化 Q/LLQG 序列催化偶联 | Pfizer SMARTag；AstraZeneca 平台 |
| **糖基化位点偶联** | Asn-297 N-糖链末端 | 氧化糖链末端半乳糖 → 醛基，与氨基氧/肼 Payload 偶联 | Synaffix GlycoConnect 技术 |

**代表第三代 ADC：**

| 药物 | 靶点 | 偶联特点 | 关键创新 |
|------|------|---------|---------|
| Polatuzumab vedotin（Polivy） | CD79b / MMAE | 半胱氨酸随机偶联，DAR ~3.5 | 与 R-CHP 联合用于一线 DLBCL |
| Enfortumab vedotin（Padcev） | Nectin-4 / MMAE | 半胱氨酸随机偶联，DAR ~3.8 | Nectin-4 新靶点验证 |
| T-DXd（Enhertu）| HER2 / DXd | 酶催化定点偶联，均一 DAR ~8 | 高 DAR + 强旁观者效应，HER2-low 获益 |

## ADC 在血液循环中的稳定性：从血管到肿瘤的安全递送

:::answer

### ADC 体内递送的全程挑战

ADC 从注射部位到发挥疗效，需要经历以下关键环节，每个环节都可能影响最终疗效和安全性：

```
静脉注射
    ↓
血液循环（数小时到数天）
    ↓ 面临：血浆蛋白酶、谷胱甘肽、pH、免疫系统
肿瘤血管外渗（EPR 效应）
    ↓ 面临：肿瘤微环境的酶/pH 差异
肿瘤间质扩散（受分子大小制约）
    ↓
靶细胞结合（靶抗原密度依赖）
    ↓
内化（内吞作用）
    ↓
溶酶体降解 → 载荷释放
    ↓
细胞内靶点作用（DNA/微管蛋白等）
    ↓
肿瘤细胞死亡
```

### 血液循环阶段的关键稳定性需求

**理想状态：ADC 在血液中应表现得"像裸抗体一样"**

| 稳定性威胁 | 机制 | 可能后果 |
|----------|------|---------|
| **Linker 水解/酶切** | 血浆蛋白酶（丝氨酸蛋白酶、半胱氨酸蛋白酶）; 血浆酸性微环境 | 游离细胞毒素释放 → 系统毒性（骨髓抑制、肝毒性、神经毒性） |
| **DAR 降低（脱药）** | 疏水性高 DAR 物种的非特异性清除（网状内皮系统摄取） | 有效 ADC 浓度下降 → 疗效降低 |
| **ADA（抗药抗体）产生** | 免疫系统识别 ADC（尤其是 Linker-Payload 部分） | 加速 ADC 清除、输液反应、ADA 干扰疗效 |
| **蛋白质折叠/聚集** | 高疏水性载荷导致 ADC 聚集 | 聚集体半衰期短；免疫原性强；可能触发细胞因子释放 |

### Linker 稳定性的量化评估策略

**体外评估：**
- 人血浆孵育（37°C，7-14 天）：HPLC/LC-MS 追踪游离载荷释放量
- 谷胱甘肽稳定性测试（10 mM GSH，模拟胞内还原环境 vs 20 μM GSH，模拟胞外环境）
- 加速稳定性测试（40°C、pH 4-8 范围）

**体内评估：**
- 大鼠/灵长类 PK 研究：同时测定总抗体、结合型 ADC（≥1 个 payload）、游离 payload 浓度
- DAR 随时间变化趋势（质谱分析，评估体内脱药速率）

> **关键参数指标**：ADC 体内研究需同步追踪三条 PK 曲线——**总抗体（TAb）**、**结合型 ADC（cADC）**、**游离载荷（Free Drug）**。三者的相对变化趋势反映 Linker 稳定性和体内脱药行为，是决定 ADC 治疗窗的核心 PK 数据。

:::
