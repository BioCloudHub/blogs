## 质量研究不充分的常见缺陷与法规合规要求

:::answer

质量研究不充分是 CDE 审评过程中最常见的 CMC 缺陷之一，直接影响申报资料的质量和审评结论。理解法规对质量研究的系统性要求，是构建合规 CMC 数据包的前提。

**CDE 审评中的典型挑战点**

- 参比品检定和产品表征研究不充分
- 用于表征研究的批次和样品不具有代表性（未覆盖工艺变化范围）
- 表征项目不全面，遗漏关键质量属性

**法规对抗体药物质量研究的全面要求**

监管机构要求采用现有先进分析手段，从物理化学、免疫学、生物学等角度对制品进行全面分析，提供尽可能详尽的信息，以反映产品内在的天然质量属性。

**抗体特性分析的必要项目**

| 分析类别 | 具体检测项目 |
|---|---|
| **结构特征** | 结构完整性、氨基酸序列（包括 N/C 末端测序）、二级结构（CD、FTIR）、二硫键连接图谱 |
| **翻译后修饰** | N-糖基化（糖型分布）、O-糖基化（如适用）、脱酰胺、氧化、焦谷氨酸环化 |
| **生物学特性** | 抗原特异性、亲和力（KD 值）、特异的生物学活性（效价）、与人体组织的交叉反应性 |
| **亚类鉴别** | IgG 亚类鉴定（IgG1/2/3/4）、轻链类型（κ/λ） |
| **异质性** | 电荷变异体、大小变异体（聚集体、片段）、疏水性变体 |

**特殊产品的额外要求**

对于通过片段化（如 Fab、F(ab')₂）或偶联修饰（如 ADC、放射性标记）的制品，须额外：
- 确定生产工艺对抗体质量属性的影响
- 建立针对特殊结构的专属分析方法（如 DAR 分布检测、偶联位点分析）

**质量研究的生命周期特征**

```
研发早期：
  初步表征，确定产品基本质量属性
    ↓
工艺优化阶段：
  随工艺演进持续积累表征数据
  不断完善产品质量概况（Product Quality Profile）
    ↓
代表性批次的周期性监测：
  建立产品质量属性的历史数据库
  验证工艺一致性
    ↓
申报阶段：
  基于充分的表征数据建立科学合理的质量标准
```

**应对策略**

- 按法规要求建立完整的参比品检定体系（理化、生物学、安全性三维度）
- 表征研究的批次应覆盖研发阶段的代表性批次（含早期、优化后、工艺变更前后）
- 建立并持续完善产品表征数据包，作为质量标准制定和工艺变更评估的科学基础

## 早期制剂 QTPP 的制定逻辑：临床需求与商业化目标的双重平衡

:::answer

目标产品质量概况（QTPP，Quality Target Product Profile）是制剂研发的战略起点，早期 QTPP 的制定须同时兼顾临床试验的实际需求和后期商业化的可行性。

**早期制剂 QTPP 的两大核心来源**

**① 临床方案驱动的 QTPP**

早期临床用制剂的首要目的是支持临床试验，其 QTPP 须满足临床使用场景的特殊需求，而非简单复制商业化制剂的标准：

| 临床特殊场景 | 对 QTPP 的特殊要求 |
|---|---|
| 安慰剂对照设计 | 制剂外观、颜色须与安慰剂高度一致，不得泄露盲态 |
| 多剂量给药 | 需评估多次给药的化学稳定性和微生物稳定性 |
| 特殊给药途径（如鞘内注射）| 对无菌性、渗透压、pH 的要求更为严格 |
| 剂量探索设计 | 制剂需支持宽范围的剂量调整（如不同浓度规格或稀释操作）|

**② 项目开发策略对 QTPP 的决定性影响**

项目的整体研发策略是影响早期制剂开发方向的最核心因素：

```
策略类型A：快速临床靶点验证（Speed-first）
  → 优先选择简单处方（如简单缓冲液 + 已知辅料）
  → 接受更宽的质量标准
  → 降低早期投入，快速进入临床
  → 适用场景：高失败风险的早期靶点验证

策略类型B：快速商业化（Commercial-ready）
  → 早期即开展系统处方前研究（Preformulation）
  → 评估关键风险（聚集、降解、溶解度等）
  → 制定风险控制计划和开发总路线图
  → 适用场景：靶点已验证、商业化前景明确的项目
```

**早期 QTPP 的关键考量要素**

| QTPP 要素 | 早期临床阶段 | 商业化阶段 |
|---|---|---|
| 剂型 | 可接受溶液（需冷冻储存）| 优先冻干粉针（延长货架期）|
| 给药途径 | 严格按临床方案 | 与商业化给药途径一致 |
| 强度（浓度）| 支持临床剂量范围 | 覆盖批准适应症的全部剂量 |
| 货架期 | 满足临床试验周期（通常 12～24 个月）| 商业化要求（通常 24～36 个月）|
| 容器密封系统 | 研究级别（可接受西林瓶 + 胶塞）| 须经完整相容性研究 |

**避免的早期误区**

- 不能因早期处方简单而违背基本制剂原理（如忽视 pH 对蛋白稳定性的影响）
- 即便采用简单处方，也应在设计之初考虑商业化的可转化性
- 早期投入少量时间评估处方风险，往往可节约后期大量开发时间

:::

## CAR-T 疗法的原理、制造工艺与临床影响因素

:::answer

CAR-T（嵌合抗原受体 T 细胞）疗法是近年来最具突破性的肿瘤免疫治疗手段之一，代表了从"外源性药物"到"活体细胞药物"的治疗范式转变。

**基本原理**

CAR-T 疗法通过基因工程技术对患者自体 T 细胞进行改造，使其表达能够特异性识别肿瘤抗原的嵌合抗原受体（CAR），从而赋予 T 细胞直接识别并杀伤肿瘤细胞的能力，绕过了传统 T 细胞活化所需的 MHC 限制。

**CAR 的结构组成**

```
CAR 结构（从胞外到胞内）：
  ├─ 抗原识别域（scFv）：识别肿瘤表面特异性抗原
  ├─ 铰链区：连接 scFv 与跨膜域，提供柔性
  ├─ 跨膜域：锚定 CAR 于 T 细胞膜
  ├─ 共刺激域（CD28 或 4-1BB）：增强 T 细胞激活和持久性
  └─ CD3ζ 信号域：启动 T 细胞杀伤信号级联
```

**CAR 识别肿瘤抗原后的杀伤机制**

```
CAR 与肿瘤抗原结合
    ↓
T 细胞激活（免疫通路上调）
    ↓
分泌颗粒酶（Granzyme）+ 穿孔素（Perforin）
  → 直接溶解肿瘤细胞
分泌 GM-CSF、IFN-γ 等炎症因子
  → 招募巨噬细胞等固有免疫细胞协同杀伤
```

**影响 CAR-T 疗效的四大关键因素**

**① 患者自身条件**

- T 细胞数量和质量：前期化疗或晚期疾病可导致 T 细胞数量不足或功能受损
- 高脑内肿瘤负荷：可能引发致命的不良反应，须谨慎评估给药时机

**② CAR-T 制造工艺与质量控制**

每个制造步骤均须精密设计和严格质控：

| 制造步骤 | 关键质控点 |
|---|---|
| T 细胞采集（白细胞单采）| 细胞数量、活力、T 细胞纯度 |
| 细胞激活（CD3/CD28 信号）| 激活效率、细胞表型 |
| 基因改造（病毒转导 / 电穿孔）| CAR 转导效率、拷贝数、插入位点 |
| 体外扩增 | 扩增倍数、CAR⁺细胞比例、细胞活力 |
| 配制与冻存 | 终产品浓度、纯度（CD4:CD8 比例）、无菌性 |

- **纯度的重要性：** 已有案例显示，T 细胞中混入 B 细胞杂质可导致患者对 CAR-T 疗法产生抗性，充分说明细胞纯度控制的关键性

**③ 肿瘤自身特性**

- **抗原逃逸：** 肿瘤细胞下调靶抗原表达，逃脱 CAR-T 识别（如 CD19 阴性复发）
- **CAR-T 持续性不足：** 约 50% 的患者在接受抗 CD19/CD22 CAR-T 疗法一年内肿瘤复发
- **应对策略：** 双靶点 CAR-T（同时靶向 CD19 + CD22）可降低单靶点逃逸风险

**④ 不良反应管理**

- **细胞因子释放综合征（CRS）：** 大量细胞因子释放引发全身炎症反应，严重时危及生命
- **免疫效应细胞相关神经毒性综合征（ICANS）：** 可能引发神经系统损伤
- 严重不良反应的提前干预（如托珠单抗、地塞米松）可能影响最终疗效，须权衡

:::

## 已批准基因疗法的里程碑回顾与技术分类

:::answer

基因疗法经历了数十年的研发挫折后，自 2012 年起进入加速获批阶段，形成了基于 AAV、逆转录病毒和溶瘤病毒等多种技术平台的多元化治疗体系。

**全球基因疗法获批里程碑**

| 获批年份 | 药物名称 | 技术平台 | 适应症 | 批准机构 |
|---|---|---|---|---|
| 2012 年 | Glybera（格列贝拉）| AAV1 | 家族性脂蛋白脂肪酶缺乏（LPLD）| EMA（有条件）|
| 2015 年 | IMLYGIC（T-VEC）| 基因修饰 HSV-1 | 黑色素瘤（不可切除）局部治疗 | FDA |
| 2016 年 | Strimvelis | γ-逆转录病毒 | ADA-SCID（腺苷脱氨酶缺乏致严重联合免疫缺陷）| EMA |
| 2017 年 | KYMRIAH（Tisagenlecleucel）| 慢病毒 CAR-T | ALL（急性淋巴细胞白血病）+ NHL | FDA |
| 2017 年 | YESCARTA（Axicabtagene）| 逆转录病毒 CAR-T | 非霍奇金淋巴瘤（NHL）| FDA |
| 2017 年 | LUXTURNA（Voretigene）| AAV2 | RPE65 突变相关视网膜营养不良 | FDA |

**三大技术平台的特征对比**

**AAV（腺相关病毒）平台**

- 非整合型（主要以附加体形式存在），插入突变风险低
- 多种血清型覆盖不同靶组织（AAV9 跨越血脑屏障，AAV5 靶向肝脏）
- 包装容量有限（< 4.7 kb），适合小基因替代疗法
- 免疫原性相对较低，适合体内（in vivo）基因递送

**逆转录病毒/慢病毒平台**

- 整合型：基因稳定整合至宿主基因组，适合需要长期表达的离体（ex vivo）细胞治疗
- 主要用于 CAR-T 制造（慢病毒）和干细胞基因治疗（γ-逆转录病毒）
- 插入突变风险须通过整合位点分析评估

**溶瘤病毒平台（T-VEC）**

- 经基因改造的 HSV-1，在肿瘤细胞内特异性复制并裂解肿瘤
- 同时激活局部和系统性抗肿瘤免疫反应
- 局部注射，主要用于实体瘤局部治疗

**CMC 视角：基因疗法的特殊质量挑战**

- 病毒载体的物理化学表征（病毒滴度、全/空颗粒比）
- 基因组完整性验证（避免不完整基因组）
- 细胞产品（CAR-T）的活性、纯度和安全性检测
- 生物安全性评估（外源性病毒检测）

## 药物安全性的重要性与 CMC 视角的系统性保障框架

:::answer

安全性是药品最根本的属性，是所有监管决策的核心出发点。理解 CMC 如何系统性保障药物安全性，有助于建立正确的质量研究优先级。

**药物安全性的核心认知**

**药品的三大特性及其逻辑关系**

```
安全性（Safety）← 最根本前提
    ↓
有效性（Efficacy）← 安全前提下的治疗价值
    ↓
质量可控性（Quality Controllability）← 保障前两者一致性的手段
```

**安全性的相对性原则**

药品安全是"可接受风险水平"的概念，而非追求"零风险"：
- **狭义安全性：** 按规定适应症和用法用量使用后，产生不良反应的程度
- **广义安全性：** 涵盖药品质量问题、不合理用药和药品不良反应
- 药品最终上市是**利益-风险权衡**的结果，风险须控制在可接受范围内

**法规角度的安全性要求**

无论是 IND 还是 BLA 申报，凡涉及可能提高安全性风险的操作和变更，均需进行充分研究和论证，这是监管机构审查的核心关注点。

**CMC 保障药物安全性的四大控制维度**

**① 物料控制（源头控制）**

```
风险来源：
  ├─ 生产原材料来源复杂（动物源性、人源性）
  ├─ 可能引入外源因子（病毒、支原体）
  └─ 可能引入毒性化学物质

控制手段：
  ├─ 供应商审核（GMP 认证、现场审计）
  ├─ 原材料质量标准建立（企业内控标准）
  ├─ 批次放行检测（关键质量指标检验）
  └─ 细胞库检定（外源因子全项检测）
```

**② 杂质控制**

- 产品相关杂质（聚集体、碎片、电荷变异体）须控制在合理限度内
- 工艺相关杂质（HCP、DNA、Protein A 浸出物）须符合法规和安全性要求
- 须建立基于毒理学评估的杂质可接受限度

**③ 污染控制**

- 原液：微生物限度检测（bioburden control）
- 制剂（成品）：无菌检测（sterility testing）
- 中间体：微生物限度监控（防止培养过程污染扩大）

**④ 病毒控制（生物制品特有的重大安全挑战）**

病毒污染可发生于生物制品生产全流程任一环节：

```
控制层次一：物料源头控制
  ├─ 无动物源性证明（TSE/BSE 声明）
  └─ 细胞库病毒检测（MCB/WCB 全项检定）

控制层次二：生产过程监控
  ├─ 生产过程取样检测
  └─ 环境监控（确认无外源污染引入）

控制层次三：工艺清除验证
  ├─ 病毒清除验证研究（缩小规模模型）
  └─ 证明纯化工艺对病毒的有效去除能力（正交步骤）
```

## IND 阶段与 BLA 阶段生产工艺控制的关键差异

:::answer

IND 和 BLA 两个阶段对生产工艺的要求存在系统性差异，这反映了药物开发从"探索性"到"确认性"的阶段性演进逻辑。

**五大维度的阶段性差异对比**

**① 工艺验证要求**

| 维度 | IND 阶段 | BLA 阶段 |
|---|---|---|
| 工艺验证状态 | 不要求验证工艺，探索性生产可接受 | 必须采用经过完整验证的工艺进行生产 |
| GMP 要求程度 | 符合基本 GMP 原则即可 | 完整商业化 GMP 要求 |

**② 细胞株稳定性研究**

| 维度 | IND 阶段 | BLA 阶段 |
|---|---|---|
| 研究模型 | 不要求缩小模型，小规模研究可接受 | 须采用能代表商业化生产规模的缩小模型 |
| 研究深度 | 初步稳定性评估 | 覆盖最大传代代次（PDL）的完整稳定性研究 |

**③ 病毒清除验证研究**

| 维度 | IND 阶段 | BLA 阶段 |
|---|---|---|
| 验证要求 | 不强制要求缩小规模验证；可提供初步评估 | 必须采用代表生产规模的缩小模型完成正式病毒清除验证 |
| 病毒种类覆盖 | 可用模型病毒替代 | 须包含特异性病毒和非特异性指示病毒 |

**④ 产品表征研究**

| 维度 | IND 阶段 | BLA 阶段 |
|---|---|---|
| 研究深度 | 适当表征（如电荷异质体可不强制要求）| 必须对产品进行全面表征（所有质量属性）|
| 分析方法 | 开发中方法（经确认）| 经过完整验证的方法 |

**⑤ 产品质量标准**

| 维度 | IND 阶段 | BLA 阶段 |
|---|---|---|
| 标准严格程度 | 相对宽泛，基于早期批次数据 | 须严格，有合理的科学依据 |
| 制定依据 | 少量批次数据 + 文献参考 | 多批次数据 + 工艺控制 + 临床研究结果 + 工艺验证数据 |

**阶段性演进的战略意义**

```
IND 阶段（快速学习）：
  ├─ 容忍工艺探索性，允许不完善
  ├─ 重点：证明安全性，支持早期临床
  └─ 快速积累工艺和产品知识

临床 II/III 阶段（固化工艺）：
  ├─ 关键工艺参数逐步确定
  ├─ 质量标准逐步收紧
  └─ 准备 BLA 的全面数据包

BLA 阶段（验证确认）：
  ├─ 基于充分数据证明工艺可重现、产品质量一致
  └─ 建立商业化可持续的质量体系
```

:::

## 控制策略的定义框架与构建逻辑

:::answer

控制策略（Control Strategy）是现代质量管理体系（ICH Q10）的核心概念，是连接工艺理解与产品质量保证的关键桥梁。

**ICH Q10 的标准定义**

"根据当前对产品和工艺的理解而产生的一系列保证工艺性能和产品质量的有计划的控制。这些控制可包括与原料药和制剂的物料与组分、厂房和设备运行条件、过程控制、成品质量标准相关的参数和特性，以及相应的监控方法和频次。"

**控制策略的核心逻辑**

```
工艺理解（Process Understanding）
  ↓（工艺表征研究积累）
识别关键质量属性（CQAs）
  ↓（DoE、多变量分析）
确定关键工艺参数（CPPs）
  ↓（风险评估）
建立控制策略
  ↓（验证和确认）
持续工艺确认（CPV）
```

**控制策略在生物药 CMC 中的重要意义**

- **法规合规基础：** ICH Q8/Q9/Q10 均强调基于风险的控制策略制定
- **质量保证机制：** 通过系统性控制确保每批次产品的 CQAs 在可接受范围内
- **变更管理支撑：** 成熟的控制策略为工艺变更评估提供科学依据
- **申报资料核心：** BLA 申报中工艺控制策略的完整性和科学性是监管审评的重点

**PDA TR60 对控制策略建立的补充指导**

有效的工艺控制策略建立是第一阶段（工艺设计）最重要的成果之一，其制定是一个迭代过程，从研发早期开始，随工艺和产品知识的积累不断完善。一个稳健的控制策略须涵盖工艺中所有单元操作的全部控制要素。

:::

## 控制策略的三大组成要素：物料控制、工艺控制与检测

:::answer

控制策略由三个相互关联的核心要素构成，三者共同形成保障产品质量的完整防线。

**要素一：输入物料控制（Material Control）**

基于物料变化对产品和工艺潜在风险的差异，实行分级管控：

**低风险物料**（如药典级原材料、已上市原材料）：
- 要求供应商提供生产许可证或 GMP 证书
- 要求供应商出厂检测报告（CoA）
- 使用方对关键项目建立检测（鉴别、微生物限度、内毒素、异常毒性）
- 对供应商开展定期审计

**高风险物料**（如非药典级、动物来源的原材料）：
- 在低风险物料控制要求基础上增加：
- 建立企业自身的内控标准
- 动物来源物料须提供相应合规证书（TSE/BSE 声明、原产地证明）
- 须研究并理解该物料对产品和工艺变异性的贡献（通过工艺表征研究）
- 制定针对性的风险缓解措施

**要素二：工艺控制（Process Control）**

**工艺参数控制层次：**

```
设定点（Set-Point）：目标工艺参数值
    ↓
操作范围（Operating Range，NOR）：正常操作允许的波动范围
    ↓
可接受范围（Acceptable Range，PAR）：经验证的参数范围
    ↓
关键工艺参数（CPP）：超出范围将影响 CQA 的参数
```

**工艺控制执行手段：**
- 标准操作规程（SOPs）：规范每个单元操作的执行方式
- 在线传感器监测：温度、pH、DO、流速、压力等关键参数实时监控
- 中间体检验：各步骤收获液的关键指标检测（如步骤回收率、纯度）

**要素三：检测（Testing）**

并非所有质量属性都需要相同频率的检测，须建立分层检测体系：

| 检测类别 | 目的 | 频率 |
|---|---|---|
| **工艺中控检测（IPC）** | 实时监控工艺状态，支持实时决策 | 每步骤/规定时间点 |
| **放行检测（Release Testing）** | 确认每批次产品符合质量标准 | 每批次必检 |
| **工艺监控（Process Monitoring）** | 趋势分析，识别工艺漂移 | 定期（如季度/年度）|
| **表征和可比性检测（Characterization & Comparability）** | 深入产品理解，支持变更评估 | 工艺变更时、定期表征 |

:::

## 工艺控制策略的制定流程与阶段性实施路径

:::answer

工艺控制策略的制定和实施是一个随项目推进持续演进的过程，不同阶段的控制策略成熟度和严格程度有所不同。

**工艺控制策略制定的总体流程**

```
Step 1：初步风险评估
  识别可能影响 CQA 的潜在工艺参数（pCPP，潜在关键工艺参数）
    ↓
Step 2：工艺表征研究（Process Characterization，PC）
  通过 DoE 等实验设计系统研究 pCPP 对 CQA 的影响
  确定真正的 CPP 及其设计空间（Design Space）
    ↓
Step 3：制定控制策略
  基于 CPP 和设计空间，制定操作范围、监控方法和频率
    ↓
Step 4：工艺验证确认
  通过工艺验证批次验证控制策略的有效性
    ↓
Step 5：持续工艺确认
  商业化生产中持续监控，验证控制策略长期有效性
```

**各开发阶段的控制策略成熟度**

**IND 申报前（Early Development）**

- 基于历史数据、先验知识（平台工艺数据）和初步控制能力
- 制定基础版生产工艺控制策略，体现在工艺规程中
- 以批记录形式执行，完整记录工艺参数

**工艺验证阶段一：Process Design（Stage 1）**

- 完成工艺表征研究
- 经风险评估制定系统化的控制策略
- 确定 CPP、操作范围和监控要求

**工艺验证阶段二：Process Qualification（Stage 2）**

- 通过 PPQ 批次验证控制策略的有效性
- 完成后进行风险评估，评估是否需要升级控制策略
- 形成最终的商业化控制策略文件

**上市后：Continued Process Verification（Stage 3）**

- 持续收集商业化批次数据（SPC 统计过程控制）
- 定期评审控制策略的有效性（年度产品回顾 APR）
- 发现系统性问题时启动控制策略优化

:::

## PAT 过程分析技术在控制策略中的应用与实施路径

:::answer

过程分析技术（Process Analytical Technology，PAT）是 FDA 倡导的、以实时监测为核心的现代制药质量管理工具，代表了从"成品检验把关"到"过程实时控制"的质量理念升级。

**PAT 的定义与监管背景**

FDA 将 PAT 定义为：以实时监测（如在加工中）原材料、中间体和过程的关键质量和性能特征为手段，建立起来的一种设计、分析和控制生产的系统。PAT 计划的核心目标是推动制药行业：
- 识别对质量至关重要的参数
- 找到最适合测量这些参数的技术
- 基于实时数据实现生产过程的主动控制

**PAT 在中间过程控制中的应用思路**

**选择 PAT 切入点的原则**

优先选择与产品关键质量属性（CQAs）直接关联的关键工艺参数（CPPs）：

| 制剂类型 | 典型 PAT 应用场景 | 监测参数 |
|---|---|---|
| 固体制剂 | 颗粒水分检测 | 近红外光谱（NIR）实时监测水分 |
| 固体制剂 | 混合均一性 | NIR 或拉曼光谱实时监测含量均一性 |
| 液体生物制品 | 生物反应器在线监测 | pH、DO、pCO₂、葡萄糖、乳酸在线传感器 |
| 层析纯化 | UV 在线监测 | 实时追踪蛋白洗脱峰，动态决定收集时机 |

**PAT 实施的分阶段策略**

```
第一阶段：数据积累（非用于放行）
  部署 PAT 传感器，与传统离线方法并行运行
  积累足够数量的数据集，建立 PAT 与质量属性的相关模型
  评估数据稳定性和方法可靠性

第二阶段：验证与评估
  当积累的数据分析显示足够稳定性后
  开展正式的方法验证
  对监管机构的沟通和申报准备

第三阶段：用于中间产品或最终产品的放行
  PAT 参数正式用于实时放行决策（RTR，Real-Time Release）
  持续积累数据，开展趋势分析
  建立应急程序（PAT 传感器故障时的备选方案）
```

**关键要求：建立应急程序**

PAT 传感器故障不应导致生产中断，须预先制定：
- 传感器故障的识别和报警机制
- 切换到传统离线检测方法的操作程序
- 不同故障场景下的决策树（继续生产 / 暂停 / 报废）

:::

## 强制降解试验：稳定性研究的基础性实验设计

:::answer

强制降解试验（Stress Testing / Forced Degradation Study）是稳定性研究体系的重要组成部分，通过主动加速降解来全面了解产品的降解途径、降解产物和分析方法的指示稳定性能力。

**强制降解试验的核心目的**

- **识别降解产物：** 系统揭示产品在各种应力条件下可能产生的降解产物，建立完整的降解产物谱
- **阐明降解途径：** 理解分子降解的化学机制（氧化、水解、光降解等）
- **验证分析方法的指示稳定性（Stability-indicating）：** 确认所用分析方法能够区分原始分子与降解产物，证明方法的专属性
- **预测长期稳定性风险：** 为加速试验和长期稳定性研究提供科学依据

**强制降解试验的六大条件类型**

| 应力类型 | 典型条件 | 主要揭示的降解途径 |
|---|---|---|
| **高温** | 高于加速温度 10℃（如 50℃、60℃）| 热降解、聚集、化学修饰 |
| **高湿** | 相对湿度 ≥ 75% RH | 水解反应、结晶行为变化 |
| **氧化** | H₂O₂（如 0.01%～1%）/ 金属离子催化 / 紫外光氧化 | Met/Trp/His 氧化修饰 |
| **光照** | ICH Q1B 标准条件（可见光 + 近紫外光）| 光氧化、光异构化 |
| **酸水解** | 低 pH 溶液（如 pH 2～3）| Asp 异构化、肽键水解 |
| **碱水解** | 高 pH 溶液（如 pH 11～12）| Asn 脱酰胺、Cys 氧化、β-消除 |

**实施的关键注意事项**

- **批次要求：** 通常仅需对一批原料药进行强制降解试验
- **降解程度控制：** 降解程度过低不能有效识别降解产物；过高可能产生在实际储存中不会出现的人为产物（一般降解 10%～30% 较为合理）
- **方法专属性确认：** 在降解条件下，须确认 HPLC/CE 等分析方法能够有效分离原始分子和各降解产物
- **光稳定性试验：** 是强制降解试验的法定组成部分，须按 ICH Q1B 的标准条件执行

**与常规稳定性试验的关系**

```
强制降解试验（研发阶段）：
  目的：了解降解机制，验证分析方法
  条件：极端，快速产生降解
    ↓（为以下试验提供指导）
加速稳定性试验（如 40℃/75%RH，6 个月）：
  目的：预测产品稳定性，支持申报
    ↓
实时稳定性试验（2～8℃/25℃，长期）：
  目的：确认货架期，支持有效期申报
```

:::

## ISF（杂质安全系数）评估：原理、计算方法与完整应用流程

:::answer

ISF（Impurity Safety Factor，杂质安全系数）是评估非生物学活性工艺相关杂质安全性的定量工具，为早期临床阶段的杂质风险管理提供了系统化的评估框架。

**ISF 评估的应用背景**

生产工艺中存在的各类物质均须评估其对患者的潜在安全性风险，尤其在 IND 申报阶段，对可能影响药物安全性的物质进行系统评估是监管合规的核心要求。

**工艺相关杂质的分类与评估方法**

```
工艺相关杂质
  ├─ 具有生物学活性杂质：HCP、宿主细胞 DNA、Protein A 等
  │   → 不适用 ISF 评估，须个案毒理学评估 + 专属检测方法控制
  └─ 无生物学活性杂质：消泡剂（Pluronic F68）、DMSO、MSX、二甲基硅油等
      → 适用 ISF 定量评估
```

**ISF 计算公式与基础参数**

```
ISF = LD₅₀ / 每剂量中的杂质含量

其中：
  LD₅₀ = 半数致死量（可从文献或数据库查询各种动物的 LD₅₀ 值）
  每剂量中的杂质含量 = 基于生产过程中杂质的最大量计算

关键前提：
  基于下游纯化工艺对该杂质无任何去除能力（Worst-Case 最差情境）
  此时计算的是杂质暴露量的最高值
```

**ISF 评估的三步决策流程**

```
Step 1：基于 Worst-Case 计算初始 ISF
  （假设下游无去除，计算杂质最大暴露量）
  ↓
ISF > 1000？
  ├─ 是 → 安全性评估通过，无需进一步研究
  └─ 否 → 进入 Step 2

Step 2：在后续纯化步骤中检测实际杂质含量
  （基于实际清除数据重新计算 ISF）
  ↓
检测后 ISF > 1000？
  ├─ 是 → 安全性评估通过
  └─ 否 → 进入 Step 3

Step 3：开展 Spiking 研究
  （验证下游工艺对该杂质的实际清除能力）
  明确清除倍数 → 重新评估最终 ISF
  若 ISF 仍 < 1000 → 须采取降低杂质水平的工艺改进措施
```

**毒性评价指标的选择与转换**

**两大毒性指标的比较**

| 指标 | 含义 | 优点 | 局限性 |
|---|---|---|---|
| **LD₅₀** | 半数致死量（50%动物死亡的剂量） | 数据广泛可及，查询方便 | 基于死亡终点，非人类安全阈值 |
| **NOAEL** | 未观察到有害作用的剂量水平 | 更接近人类临床安全阈值 | 大多数物质数据难以查到 |

**ISF 判断阈值 1000 的科学依据**

研究显示，通常物质的 LD₅₀ 值是 NOAEL 值的 **10～100 倍**：

```
NOAEL 推算逻辑：
  NOAEL ≈ LD₅₀ / 100（保守估算）

ISF 判断标准：
  若 ISF（基于 LD₅₀）> 1000
  则杂质水平 < LD₅₀ / 1000 ≈ NOAEL / 10
  此前提下，理论上不会观察到有害作用
  
∴ ISF > 1000 → 安全（保守但合理的安全阈值）
```

**常见工艺相关杂质的 ISF 评估参数**

| 杂质 | 典型 LD₅₀（小鼠，iv）| 安全系数换算（人体：0.081）| 评估建议 |
|---|---|---|---|
| Pluronic F68 | 1000 mg/kg | 81 mg/kg（人体）| 毒性极低，通常 ISF >> 1000 |
| MSX（蛋氨酸亚砜亚胺） | 100 mg/kg | 8.1 mg/kg（人体）| 须结合实际用量评估 |
| DMSO | ~14,500 mg/kg（经口）| — | 极低毒性，通常安全 |
| 二甲基硅油 | > 10,000 mg/kg | — | 毒性极低，ISF 通常极高 |

> **重要提醒：** ISF 评估工具仅适用于无生物学活性的工艺相关杂质。对于 HCP、Protein A、宿主细胞 DNA 等具有生物学活性的杂质，须采用专属检测方法控制，不能用 ISF 替代。

:::

## 细胞增殖抑制法：靶向阻断生长信号的效价测定

:::answer

细胞增殖抑制法是针对以阻断细胞生长信号为作用机制的治疗性抗体的经典生物活性测定方法，通过检测抗体对靶细胞增殖的抑制能力来评估其生物学活性。

**方法原理**

抗体与细胞表面生长因子受体（或其配体）结合，阻断促增殖信号通路，导致靶细胞增殖受到剂量依赖性抑制，通过检测细胞存活率评估抗体效价。

**三大靶点的经典测定体系**

**① 抗 VEGF 抗体：人脐静脉内皮细胞（HUVEC）增殖抑制法**

```
原理：
  VEGF（血管内皮生长因子）刺激 HUVEC 细胞增殖
  抗 VEGF 抗体中和 VEGF，阻断 VEGF-VEGFR 结合信号
  抗体剂量依赖性地抑制 HUVEC 增殖

测定体系：
  靶细胞：HUVEC（人脐静脉内皮细胞）
  刺激因子：重组人 VEGF（固定浓度）
  检测终点：细胞活力（MTT/WST-1/CellTiter-Glo 发光法）
  报告曲线：sigmoid 型剂量-效应曲线，计算相对效价
```

**② 抗 HER2 抗体：HER2⁺ 乳腺癌细胞增殖抑制法**

```
靶细胞选择：
  BT474（高表达 HER2 + ER⁺，激素受体阳性）
  SK-BR-3（高表达 HER2，三阴性）
  SKOV3（卵巢癌细胞，HER2 扩增）

机制：
  抗体与 HER2 受体结合 → 阻断 HER2 二聚化和下游 PI3K/AKT/MAPK 信号传导
  → 剂量依赖性抑制细胞增殖
```

**③ 抗 EGFR 抗体：EGFR⁺ 肿瘤细胞增殖抑制法**

```
靶细胞选择：
  DiFi 细胞（结直肠癌，EGFR 高表达）
  A431 细胞（人鳞状上皮癌，EGFR 极高表达）

机制：
  抗体特异性结合并封闭 EGFR → 阻断 EGF 与受体结合
  → 阻断 RAS-MAPK 和 PI3K-AKT 信号通路 → 抑制细胞增殖
```

**细胞增殖抑制法的关键质控要求**

- **细胞传代控制：** 须使用规定传代数范围内的细胞，高传代数细胞可能失去 HER2/EGFR 敏感性
- **刺激因子质量：** VEGF 等刺激因子的活性批次间须一致，建议建立参考批次
- **阳性对照：** 每次测定须包含效价已知的参比品作为系统适用性确认
- **剂量-效应曲线拟合：** 采用四参数逻辑斯谛（4PL）模型拟合，计算 EC₅₀ 和相对效价

:::

## 细胞毒性法：凋亡通路介导的生物活性测定

:::answer

细胞毒性法（Cell Cytotoxicity Assay）适用于通过激活或阻断细胞凋亡通路发挥作用的治疗性生物制品，如 TNF 抑制剂（通过阻断 TNF-α 诱导的细胞凋亡评估活性）或细胞毒性融合蛋白。

**细胞凋亡的两条主要通路（测定方法设计基础）**

```
细胞凋亡两大通路：
  
① 线粒体依赖途径（内源性途径）：
  细胞内应激 → Bcl-2 家族激活 → 细胞色素 C 释放
  → Caspase-9 激活 → Caspase-3/6/7 级联 → 细胞凋亡

② 死亡受体介导途径（外源性途径）：
  TNF-α/FasL 与受体结合 → FADD 募集
  → Pro-caspase-8 自我活化 → 活性 Caspase-8
  → 激活 Caspase-3/6/7 → 细胞凋亡
```

**重组人 II 型 TNF 受体-抗体融合蛋白的活性测定（代表性案例）**

```
目的产品：依那西普（Etanercept）类产品（TNFR2-Fc 融合蛋白）

测定原理：
  TNF-α 激活 U-937 细胞（人组织细胞淋巴瘤，对 TNF 敏感）中的 Caspase 3/7
  融合蛋白竞争性结合 TNF-α，阻断其与细胞表面受体的结合
  → 抑制 Caspase 3/7 的活化程度与融合蛋白浓度正相关

检测终点：
  采用 Caspase-Glo 3/7 检测试剂盒（荧光素酶化学发光信号）
  信号强度与 Caspase 3/7 活性成正比
  通过信号抑制曲线计算相对效价
```

**抗 TNF-α 单抗的替代细胞毒性测定体系**

| 靶细胞 | 细胞来源 | 使用原理 |
|---|---|---|
| L929（小鼠成纤维细胞）| 小鼠 | 对 TNF-α 诱导的凋亡高度敏感；抗体抑制 TNF 杀伤作用 |
| WEHI164（小鼠纤维肉瘤细胞）| 小鼠 | 对 TNF-α 敏感；常用于 TNF 中和活性测定 |

**测定注意事项**

- L929 细胞须在放线菌素 D 存在下才对 TNF-α 高度敏感（抑制 RNA 合成，增加凋亡敏感性）
- 细胞传代数影响对 TNF-α 的敏感性，须严格控制传代范围
- 需确认靶细胞 TNF 受体（TNFR1/TNFR2）表达水平的批次间一致性

:::

## 补体依赖的细胞毒性法（CDC）：Fc 介导效应功能的标准测定

:::answer

CDC（Complement-Dependent Cytotoxicity，补体依赖的细胞毒性）活性测定适用于以 CD20、CD52 等为靶点的单抗药物，评估抗体通过激活补体经典途径裂解靶细胞的效应功能。

**CDC 杀伤机制**

```
抗体（IgG1/IgG3）与靶细胞表面抗原结合（形成免疫复合物）
    ↓
C1q 结合至抗体 Fc 区（Fc 区 CH2 域 234-237 位氨基酸区域）
    ↓
激活经典补体活化途径（C1 → C4 → C2 → C3 → C5 → C5b-9）
    ↓
在细胞膜上装配攻膜复合物（MAC，Membrane Attack Complex）
    ↓
MAC 在细胞膜打孔 → 细胞外离子大量内流 → 细胞肿胀裂解
```

**CDC 测定的标准体系（以抗 CD20 单抗为例）**

```
测定体系组成：
  靶细胞：Raji、WIL2-S（高表达 CD20 的 B 淋巴细胞）
  待测物：系列稀释的抗 CD20 单抗
  补体：人血清（正常人混合血清）或豚鼠血清

测定流程：
  抗体与靶细胞孵育 → 加入补体 → 孵育（通常 37℃，1～2 小时）
  → 检测细胞存活率（染色法或发光法）

报告曲线：
  以抗体浓度为 X 轴，细胞死亡率为 Y 轴
  4PL 拟合，计算 EC₅₀，换算为相对效价
```

**补体质量控制的关键性**

补体是 CDC 测定中最不稳定、最难控制的组分：

| 控制维度 | 具体要求 |
|---|---|
| 补体来源 | 正常人混合血清（多人混合降低个体差异）/ 豚鼠血清（较稳定）|
| 热不稳定性管理 | 严禁反复冻融（每次取用后即分装储存于 -80℃）|
| 效力确认 | 每批次须用参比品确认补体效力，设定使用浓度范围 |
| 批次间一致性 | 建立补体参考批次，新批次补体须与参考批次比较效力 |

**CDC 与 ADCC 的协同关系**

对于 IgG1 亚型靶向 CD 分子的单抗，CDC 和 ADCC 是两个互补的效应机制，在质量标准中通常须分别建立独立的活性测定方法：
- CDC 测定：评估补体激活能力（与 C1q 结合）
- ADCC 测定：评估 NK 细胞介导的杀伤能力（与 FcγRIIIa 结合）

:::

## 抗体依赖性细胞介导细胞毒性（ADCC）的报告基因法测定

:::answer

ADCC（Antibody-Dependent Cell-mediated Cytotoxicity，抗体依赖性细胞介导的细胞毒性）是 IgG1 亚型抗体最重要的效应功能之一，基于报告基因法的 ADCC 测定已成为质量控制实验室的标准方法。

**传统 ADCC 方法的局限性**

传统方法使用新鲜制备的外周血单个核细胞（PBMC）或 NK 细胞作为效应细胞，存在以下严重缺陷：
- **细胞来源变异性大：** 不同供者的 PBMC 中 NK 细胞比例和 FcγRIIIa（CD16）多态性差异显著
- **制备过程复杂：** 密度梯度离心分离 PBMC，操作繁琐，批次间重现性差
- **高背景值：** 新鲜 PBMC 自身活化背景高，影响测定特异性
- **效应细胞稳定性差：** 须即时使用，无法批量制备和长期储存

**报告基因法（Reporter Gene Assay，RGA）的原理**

```
分子机制：
  靶细胞与 FcγRIIIa⁺ 效应细胞通过抗体"桥联"
      ↓
  FcγRIIIa（CD16）被激活
      ↓
  NFAT（活化 T 细胞核因子）信号通路激活
      ↓
  NFAT 应答元件驱动荧光素酶报告基因表达
      ↓
  荧光素酶催化底物发光（化学发光信号）
  信号强度 ∝ ADCC 效应强度
```

**标准报告基因 ADCC 测定体系**

| 组成要素 | 具体使用 | 关键特征 |
|---|---|---|
| **靶细胞** | WIL2-S（人 B 淋巴细胞，高表达 CD20）| 须稳定高表达目的抗原 |
| **效应细胞** | 工程改造的 Jurkat 细胞 | 稳定过表达 FcγRIIIa（CD16a）+ NFAT 驱动荧光素酶报告基因 |
| **检测读数** | 荧光素酶化学发光（Luminescence）| 与 NFAT 激活程度正相关 |

**报告基因法的核心优势**

- **重现性优异：** 使用稳定细胞系，批次间变异显著低于 PBMC 法
- **操作简便：** 无需新鲜分离效应细胞，标准化程度高
- **专属性强：** 信号直接反映 FcγRIIIa 激活，特异性好
- **适用范围广：** 可用于评价人鼠嵌合、人源化、全人源和糖基化改造的各类 CD20 单抗

**在质量控制中的扩展应用**

报告基因法 ADCC 测定可用于：
- 评价糖基化修饰（岩藻糖含量）与 ADCC 活性的关系
- 工艺稳定性评价（比较不同批次 Fc 糖基化差异对功能的影响）
- 生物类似药的可比性研究
- Fc 工程化改造效果的验证（如去岩藻糖化单抗 ADCC 增强效果评价）

:::

## 异常毒性与急性毒性：目的、剂量与给药速度的本质区别

:::answer

异常毒性检查和急性毒性试验是两个易被混淆的安全性评价手段，但二者在检测目的、剂量设计和给药条件上存在根本性差异。

**核心区别对比**

| 比较维度 | 异常毒性检查（Abnormal Toxicity Test）| 急性毒性试验（Acute Toxicity Study）|
|---|---|---|
| **检测目的** | 检查药品批次中是否存在超出正常范围的外源性毒性物质（污染、降解产物等），是批次放行控制 | 评估大剂量单次给药时药品本身对动物的毒性反应，确定毒性剂量范围（LD₅₀）|
| **剂量设计** | 固定剂量（通常为临床剂量的一定倍数），较低 | 多剂量组设计，通常远高于临床剂量，目标产生明显毒性 |
| **给药速度** | 快速（标准：5 秒内注射 0.5 mL）| 可较慢，速度依据研究设计 |
| **给药速度例外** | 若临床需缓慢给药，异常毒性给药时间可延长至 30 秒（05 版药典规定）| 按研究设计执行 |
| **观察指标** | 给药后特定时期内的死亡和异常反应 | 毒性症状、死亡、体重变化、病理学检查 |
| **应用阶段** | 产品批次放行控制（每批次质检）| 新药开发临床前安全性评估（一次性研究）|

**异常毒性检查的法规背景**

中国药典（生物制品部分）要求对特定生物制品（如疫苗、血液制品）开展异常毒性检查，作为批放行检测的必要项目，以排查批次特异性的安全性风险（如生产过程中引入的意外毒性物质）。

**急性毒性试验的科学意义**

急性毒性试验是新药临床前毒理学评估的基础性研究：
- 确定药物的 LD₅₀ 值（支持 ISF 评估中毒性阈值的查询）
- 评估毒性症状和靶器官毒性
- 为慢性毒性研究的剂量设计提供依据
- 支持临床试验起始剂量的风险评估

:::

## 标准比色法：颜色检查的操作规范与判定标准

:::answer

颜色检查是注射用生物制品的必检项目之一，标准比色法是中国药典规定的经典检验方法，通过与标准比色液对比评估供试品的颜色深浅。

**中国药典三部规定的操作规程**

**操作步骤**

```
供试品管：
  取规定量供试品
  加水溶解
  置于 25 mL 纳氏比色管中
  加水稀释至 10 mL

对照管：
  取规定色调和色号的标准比色液 10 mL
  置于另一支 25 mL 纳氏比色管中

观察方式：
  两管同置白色背景上
  自上向下透视（透射光观察）
  或同置白色背景前，平视观察（比较整体颜色深浅）
```

**判定标准**

- **合格：** 供试品管呈现的颜色不深于对照管（颜色深浅一致或比对照管浅）
- **不合格：** 供试品管颜色明显深于对照管

**特殊情况处理：颜色接近或色调不一致**

当供试品管与对照管颜色深浅非常接近，或色调不完全一致（如供试品偏黄、对照偏橙），导致目视观察无法明确判断时：

须改用**第三法（色差计法）**测定，以色差计的测量结果作为最终判定依据。

**标准比色液的制备体系**

中国药典颜色标准液采用黄绿色（Y 系列）、棕红色（YB 系列）等标准色号体系：

| 色调 | 典型应用场景 |
|---|---|
| Y（黄色系）| 大多数注射用蛋白制品（通常允许轻微黄色）|
| YB（棕黄色系）| 部分颜色较深的制品 |

**颜色检查在生物制品质量控制中的意义**

- **直接反映产品变化：** 异常颜色（粉色、棕色、深黄色）提示产品可能发生降解、氧化或受到外源物质污染
- **与工艺相关杂质关联：** VB12 蓄积（粉色）、铁离子/铜离子参与的氧化反应（棕色/黄色）
- **批次放行的必检项目：** 颜色超标须触发偏差调查，评估对产品安全性和有效性的影响

## 关键质量属性（CQA）与关键工艺参数（CPP）的精确定义

:::answer

CQA 和 CPP 是现代药物开发（基于 ICH Q8/Q9/Q10 的 QbD 框架）中最核心的两个技术概念，二者之间的关联关系是建立科学控制策略的基础。

**关键质量属性（CQA）的定义**

**ICH Q8 定义**

关键质量属性（Critical Quality Attributes）是指物质（药品或活性成分）具备的直接或间接影响物质安全性、鉴别、强度（效价）、纯度的物理、化学、微生物学方面的特性，且其不符合要求会对患者造成危害（安全性和有效性方面的严重后果）。

**CQA 的判定标准**

```
某质量属性是否为 CQA 的判定维度：
  ①  若该属性超出可接受范围，是否会影响患者安全性？
  ②  若该属性超出可接受范围，是否会影响治疗有效性？
  ③  该属性与产品的预期作用机制（安全有效性）的关联强度

判定结论：
  以上任意一项答案为"是"，且风险程度较高 → 确定为 CQA
  以上所有项目影响均可忽略 → 非 CQA（仍须表征，但不纳入 CPP 关联研究）
```

**单抗的典型 CQA 类别**

| 质量属性类别 | 典型 CQA 示例 | 影响的产品特性 |
|---|---|---|
| **效力** | 抗原结合活性（KD）、ADCC 效价、ELISA 效价 | 有效性 |
| **大小变异体** | 单体纯度、聚集体含量、碎片含量 | 安全性（免疫原性）+ 有效性 |
| **电荷变异体** | 酸性峰、碱性峰比例 | 稳定性、有效性（CDR 区变异体）|
| **糖基化** | 岩藻糖含量、半乳糖化程度、甘露糖含量 | 有效性（ADCC/CDC）+ 免疫原性 |
| **氧化修饰** | Met/Trp 氧化比例 | 活性（CDR 区氧化）+ 稳定性 |
| **无菌性** | 无菌检测结果 | 安全性 |
| **内毒素** | 细菌内毒素水平 | 安全性 |

**关键工艺参数（CPP）的定义**

**ICH Q8 定义**

关键工艺参数（Critical Process Parameter）是指其变化会对关键质量属性产生影响，因此须对其进行监测或控制，以确保工艺能够生产出符合预期质量要求产品的工艺参数。

**CQA 与 CPP 的关联关系**

```
CPP（工艺输入）─────────────→ CQA（产品输出）

示例：
  细胞培养 pH（CPP）─────────→ 电荷变异体分布（CQA）
  培养温度（CPP）──────────→ 聚集体含量（CQA）
  层析洗脱 pH（CPP）──────→ 单体纯度（CQA）
  糖基化相关补料（CPP）──→ 岩藻糖含量（CQA）
```

**CPP 的识别路径**

```
工艺知识积累（文献、平台数据）
    ↓
初步风险评估（FMEA）→ 识别 pCPP（潜在 CPP）
    ↓
工艺表征实验（DoE）→ 量化 pCPP 对 CQA 的影响
    ↓
统计分析确定显著性（主效应、交互效应）
    ↓
确定真正的 CPP + 设计空间（Design Space）
    ↓
制定控制策略（操作范围、监控方法）
```

:::

## 抗体原液与成品的放行控制体系与微生物控制策略

:::answer

原液（Drug Substance，DS）和成品（Drug Product，DP）的放行控制体系在微生物检测项目的选择上存在重要区别，须根据产品类型和生产阶段进行合理分配。

**微生物限度 vs 无菌检测的选用逻辑**

| 检测项目 | 适用阶段 | 原理 |
|---|---|---|
| **微生物限度（Bioburden）** | 原液放行 + 中间体检测 | 检测非无菌样品中微生物的数量和类别；原液通常不要求完全无菌，但须控制生物负荷在可接受水平 |
| **无菌检测（Sterility）** | 制剂（成品）放行 | 检测成品是否完全无菌；注射用制剂须通过无菌检测 |

**原液阶段的微生物控制策略**

原液通常在生物反应器生产后经多步层析纯化，在原液配制和中间储存阶段须控制生物负荷：

- 限度通常设定为：≤ 10 CFU/mL（可根据产品特性调整）
- 对于高风险中间体（如灌装前原液），限度须更严格
- 必要时开展内毒素检测（LAL 法），确保内毒素水平符合要求

**成品阶段的无菌保证**

注射用制剂须满足法规规定的无菌要求：

- 终端灭菌产品：无菌保证水平（SAL）≤ 10⁻⁶
- 无菌灌装产品（大多数蛋白制品）：须通过无菌工艺验证（培养基灌装模拟试验）+ 成品无菌检测

**中间体的微生物控制**

各纯化步骤的中间体（如 Protein A 洗脱液、离子交换层析收获液）须建立微生物限度控制：
- 保存时间和温度须经稳定性研究验证
- 超过规定保存时限的中间体须废弃

**与批放行的整合**

原液放行须完成微生物限度检测（及内毒素检测），并经 QA 授权人员审核后方可放行至制剂工序；成品放行则须完成无菌检测（结果通常需 14 天）。对于成品的快速放行，可通过完善的无菌工艺验证和过程控制，减少对最终无菌检测的依赖。

:::

## 原液混匀工艺步骤：操作目的与关键控制参数

:::answer

原液混匀是制剂生产前的重要工艺步骤，确保原液成分均匀分布是后续制剂配制精度和产品批次一致性的前提。

**工艺背景与应用场景**

原液混匀操作主要发生在以下两种情形：

| 场景 | 操作需求 |
|---|---|
| **冻融后混匀** | 原液经冻存后解冻，冻融过程可能导致浓度分布不均（溶质在冻结界面的聚集效应），须充分混匀确保均一性 |
| **添加辅料/稀释后混匀** | 在原液基础上添加新物料（如稳定剂、缓冲液调节剂），须充分混匀使添加物分布均匀 |

**工艺控制要点**

**搅拌方式的选择**

| 搅拌方式 | 适用场景 | 风险注意点 |
|---|---|---|
| 磁力搅拌 | 小体积（< 10 L），实验室规模 | 磁子材质须与产品相容；避免过强搅拌引起气-液界面处的聚集 |
| 搅拌桨（顶部搅拌）| 中大体积，工业化规模 | 转速需优化，避免剪切力过大引起蛋白降解 |
| 翻滚混合（Rocking）| 一次性袋体（Single-Use Bag）| 适合低剪切力要求的高浓度蛋白溶液 |

**关键控制参数**

- **搅拌转速（Mixing Speed）：** 须在足以实现均匀混合的转速范围内，同时避免产生过强剪切力（尤其对高浓度蛋白溶液，高剪切力可导致聚集体形成）
- **搅拌时间（Mixing Duration）：** 须经验证确认，在规定时间内混合均一性达到要求（可通过取多点样品检测浓度均一性验证）

**均一性验证方法**

- 在混匀完成后，从容器的不同位置（顶部、中部、底部）取样
- 检测蛋白浓度（A280 法）和关键质量属性（如外观、pH）
- 各取样点数据的相对标准偏差（RSD）须在规定限度内（通常 < 2%）

**注意事项**

- 混匀时须防止气泡产生（气泡界面处蛋白易变性聚集），建议采用低速搅拌
- 混匀过程须在规定温度下进行，避免温度波动影响蛋白稳定性
- 混匀完成后须取样确认，不得假设已均匀

:::

## 蛋白质量属性（Quality Attribute）的系统分类与表征框架

:::answer

质量属性（Quality Attribute，QA）是产品质量研究的核心对象，对蛋白质药物的全面质量属性研究是建立产品质量标准和工艺控制策略的科学基础。

**质量属性的标准定义**

质量属性是指药品的物理、化学、生物学、微生物学等特性，其变化会对产品的安全性和有效性产生潜在影响。全面的质量属性研究（特性分析）是产品质量标准制定的重要基础。

**生物制品质量属性的系统分类**

**① 产品相关物质与杂质**

| 类别 | 含义 | 典型示例 |
|---|---|---|
| **产品相关物质** | 分子变异体，其活性与目标产品一致，视为产品的组成部分 | N-末端焦谷氨酸环化（活性保留）、某些电荷变异体 |
| **产品相关杂质** | 分子变异体，活性、有效性或安全性与目标产品不可比 | 高分子量聚集体、氧化变体（CDR 区氧化）、严重脱酰胺变体 |

**② 抗体产品相关杂质的主要类型**

| 杂质类型 | 形成原因 | 检测方法 |
|---|---|---|
| 聚集体（Aggregates）| 分子间非共价或共价相互作用 | SEC-HPLC、DLS |
| 降解产物/碎片（Fragments）| 蛋白酶切割、化学水解 | SDS-PAGE（还原/非还原）、CE-SDS |
| 电荷异构体（Charge Isoforms）| 脱酰胺、末端处理、异构化 | CEX-HPLC、iCIEF |
| 疏水性变体（Hydrophobic Variants）| 氧化、构象变化 | HIC、RP-HPLC |
| 糖型变体（Glycoforms）| 糖基化修饰差异 | HILIC-UPLC、LC-MS |

**③ 工艺相关杂质（须在生产中去除）**

- 细胞基质来源：HCP、宿主细胞 DNA
- 细胞培养来源：抗生素、诱导剂、培养基残留成分
- 下游工艺来源：Protein A 浸出物、有机试剂、层析介质碎片

**④ 其他质量属性类别**

- **微生物学属性：** 无菌性、生物负荷、内毒素、支原体
- **物理属性：** 外观、颜色、澄清度、可见异物、装量
- **效力属性：** 生物学活性（效价）、与靶分子的结合活性

**疫苗产品相关杂质的特殊性**

疫苗类产品的产品相关杂质与单抗不同，主要包括：
- 无活性的病毒颗粒（空壳颗粒）
- 非目的范围的多糖成分（糖缀合疫苗）
- 包装不完整的病毒样颗粒（VLP 疫苗）

**质量属性研究与 CQA 确定的关系**

```
全面质量属性表征（所有可能影响安全有效性的属性）
    ↓
基于科学和风险评估，筛选出 CQA（关键质量属性）
    ↓
CQA 纳入质量标准（放行检测）
    ↓
非 CQA 属性纳入产品表征（周期性监控）
```

> **核心原则：** 质量属性研究应基于"全面优先"的原则——宁可在早期研究中覆盖更多属性，再通过科学评估筛选 CQA，而不是一开始就主观限制研究范围，从而遗漏潜在的关键质量风险。

:::
