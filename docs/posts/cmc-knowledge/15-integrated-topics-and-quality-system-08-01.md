## PB 试验设计矩阵的三大构造规则

:::answer

Plackett-Burman（PB）试验设计矩阵每次可以有不同的具体排列，但所有有效的 PB 矩阵必须同时满足以下三个数学约束条件：

**三大矩阵构造规则**

| 规则 | 内容 | 数学表达 |
|------|------|---------|
| **规则 1：每行高水平因子数** | 每行中高水平（+1）的因子数为 N/2 个 | 每行 +1 个数 = N/2 |
| **规则 2：每行低水平因子数** | 每行中低水平（-1）的因子数为 N/2 - 1 个 | 每行 -1 个数 = N/2 - 1 |
| **规则 3：每列高低水平均衡** | 每一列的高水平和低水平因子数相等，均为 N/2 个 | 每列 +1 个数 = 每列 -1 个数 = N/2 |

**理解这三条规则的意义**

规则 1 和规则 2 共同保证了**每行总因子数** = N/2 + (N/2 - 1) = N - 1（即不含哑列时的实际因子列数）。规则 3 保证了设计的**正交性**——每个因子的高低水平在整个实验中出现次数相等，这是能够独立估计每个因子主效应的数学基础。

正是由于这种正交性，PB 设计能够用远少于全因子设计的实验次数，对多个因子进行**无混淆的主效应估计**（代价是无法识别交互作用）。

:::

## PB 试验设计矩阵的构建三原则与生成方法

:::answer

PB 矩阵的生成遵循一套确定性规则，理解这三个构建原则有助于手动生成或验证 PB 矩阵：

**三个构建原则**

| 原则 | 规则 | 说明 |
|------|------|------|
| **原则 1（第一行）** | 高低水平排列任意，满足三大矩阵规则即可 | 第一行是矩阵生成的"种子行" |
| **原则 2（最后一行）** | 全部为低水平（-1）| 固定规则，不可改变 |
| **原则 3（中间各行）** | 每行将上一行**末列移至本行首列**，其余列依次右移一位 | 循环移位（Cyclic shift）规则 |

**循环移位规则的直观示意（以 N=12 为例）**

```
第 1 行：[+, +, -, +, +, +, -, -, -, +, -]  ← 种子行
第 2 行：[-, +, +, -, +, +, +, -, -, -, +]  ← 末位移至首位
第 3 行：[+, -, +, +, -, +, +, +, -, -, -]  ← 以此类推
...
第 11 行：[-, -, +, -, -, -, +, +, +, -, +]
第 12 行：[-, -, -, -, -, -, -, -, -, -, -]  ← 全低水平（固定末行）
```

**PB 试验次数 N 的规律**

- N 必须是 **4 的倍数**
- N **不取** 2 的整数次幂（以区别于全因子设计）
- 常用的试验次数 N：**12、20、24、28、36、40、44、48**

每个 N 对应的最大可估计因子数为 N - 1（其中可能含若干哑列用于误差估计）。

:::

## PB 实验 R² 偏低的原因诊断与改进方向

:::answer

在 PB 筛选实验中，如果模型拟合的 R²（决定系数）偏低，通常意味着模型对数据变异的解释能力不足，须从以下两个方向进行诊断：

**两类 R² 偏低的根本原因**

**原因一：中心点波动较大导致因子显著性被稀释**

- 中心点（Center Point）的设置是为了估计纯误差和检测非线性
- 若中心点的重复实验结果波动过大（试验误差大），则纯误差估计值偏高
- 结果：即使因子确实有影响，其效应也可能被大的试验误差"淹没"，导致 p 值偏大（因子不显著），R² 偏低

**诊断方法**：单独分析中心点的批内重复性（计算 %RSD），若 %RSD > 10–15%，则需先解决测量系统或试验执行的变异来源。

**原因二：存在因子间的交互作用或因子的二次项效应**

- PB 设计的关键局限：**无法估计因子间的交互作用**（主效应与两因子交互作用完全混淆）
- 若实际系统中存在显著的交互作用，这部分变异将无法被 PB 模型的主效应项所解释，导致模型 R² 偏低
- 同理，若因子对响应有非线性（二次）效应，PB 的两水平设计也无法捕捉

**对应改进策略**

| 问题类型 | 改进方案 |
|----------|---------|
| 中心点波动大 | 优化测量系统（MSA 研究）；规范化试验执行操作 |
| 疑似存在交互作用 | 升级至**分辨率 IV 以上的部分析因设计**（可估计交互作用）|
| 疑似存在非线性效应 | 在已筛选出的显著因子上，后续开展响应面设计（CCD/BBD）|

:::

## PB 实验设计的四大注意事项

:::answer

**注意事项一：因素的选择——宁多勿漏**

应尽量将所有可能影响响应变量的因素纳入试验，不因"感觉影响不大"而主观排除（这正是筛选实验的目的——用数据说话）。只需避免选取**工程上不可能实现的因素**。

**注意事项二：水平的选择——覆盖实际操作空间**

每个因素的高低水平应尽量**涵盖该因素允许取值的最大合理范围**，原则是：
- 范围过窄：因子效应被低估，可能错误地判断为"不显著"
- 范围过宽：超出工艺约束，可能引入非线性效应（PB 无法检测）

**注意事项三：现场试验——控制无关变量干扰**

试验时须尽量**随机化试验顺序**（避免系统误差），并控制非试验因素的干扰（如操作员变化、设备状态变化、时间效应）。必要时采用<strong>区组化（Blocking）</strong>处理无法消除的系统干扰。

**注意事项四：测量系统评估先于结果记录**

在测量响应变量结果之前，**必须先对测量系统进行评估（MSA，测量系统分析）**：
- 分辨率（精度）须足以区分因子效应
- 重复性（Repeatability）和再现性（Reproducibility）须满足 %GR&R < 30% 的基本要求
- 只有测量系统确认可接受后，才能开始正式收集试验数据

:::

## PB 设计 vs 部分析因设计的选择判据

:::answer

多因子筛选实验面临两种主要设计方案的选择，核心权衡是**实验效率**与**交互作用估计能力**之间的取舍。

**两种设计方案的系统对比**

| 对比维度 | PB 设计 | 部分析因设计（分辨率 ≥ IV）|
|----------|---------|------------------------|
| **实验次数** | 更少（N = 12 可容纳 11 个因子）| 更多（如 2^(11-7) = 16 次用于 11 个因子）|
| **交互作用估计** | **完全无法估计**（主效应与交互作用高度混淆）| 分辨率 IV：主效应与两因子交互作用**不混淆** |
| **模型风险** | 若交互作用显著，模型可能失效（R² 低）| 能识别主要交互作用，模型更可靠 |
| **适用场景** | 交互作用先验知识少但确认主要因子 | 存在已知或疑似的交互作用时 |
| **后续升级** | 发现显著因子后升级至 RSM | 可直接扩充为响应面设计 |

**选择决策逻辑**

```
因子数量 > 8 个？
    ↓ 是
先验知识是否提示存在显著交互作用？
    ↙ 否                    ↘ 是
优先使用 PB 设计        使用分辨率 IV 以上
（更少实验次数筛选）      的部分析因设计
    ↓
PB 结果是否 R² 偏低？
    ↓ 是（疑似交互作用）
升级至部分析因设计（分辨率 IV）
验证交互作用假设
```

**实践建议**

在生物制药工艺表征中，由于工艺参数（如 pH、温度、补料量）之间常存在已知的生物学交互作用，推荐在确认因子重要性后，尽快过渡至**分辨率 IV 或 V 的部分析因设计**，以获得更可靠的工艺知识，支持设计空间的建立。

:::

## 灭菌工艺参数 D 值：杀菌能力的时间度量标准

:::answer

**D 值的精确定义**

D 值（Decimal Reduction Time，十倍减少时间）是指在**一定灭菌条件（特定温度、特定灭菌方式）下，将微生物数量降低 90%（即残存率降至 10%，或对数减少 1 个 log）所需的时间**。

```
D 值与微生物数量的关系
初始菌数（N₀）
    ↓ 经过 1 个 D 值时间
N₀ × 10⁻¹ = 0.1 N₀（残存 10%）
    ↓ 再经过 1 个 D 值时间
N₀ × 10⁻² = 0.01 N₀（残存 1%）
    ↓ 经过 n 个 D 值时间
N = N₀ × 10⁻ⁿ
```

**D 值的书写规范**

D 值须注明参照温度，以 **D_T** 表示：

| 示例 | 含义 |
|------|------|
| **D₁₂₁°C = 1.5 min** | 在 121°C 条件下，杀灭 90% 微生物需要 1.5 分钟 |
| **D₁₂₁°C = 0.5 min** | 在 121°C 条件下，杀灭 90% 微生物需要 0.5 分钟 |

**D 值的变化规律**

D 值不是固定值，受以下因素影响：

| 影响因素 | 影响方向 |
|----------|---------|
| **微生物种类** | 嗜热脂肪芽孢杆菌（BI）D 值 >> 大肠杆菌 D 值 |
| **灭菌温度** | 温度升高 → D 值显著降低（对数线性关系，Z 值描述） |
| **灭菌方式** | 湿热 vs 干热 vs 辐射 → D 值不同 |
| **微生物所处环境** | 干燥、蛋白质保护 → D 值升高 |

**自然界微生物的参考值**

> 自然界存在的微生物（非芽孢）D₁₂₁°C 一般小于 **0.5 分钟**；嗜热脂肪芽孢杆菌（灭菌 BI）D₁₂₁°C 通常为 **1.0–1.5 分钟**。

**D 值的测定方法**

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| **阴性分数法（Fraction Negative Method）** | 基于多管多时间点的阳性/阴性结果统计 | 低菌量时更准确 |
| **存活曲线法（Survivor Curve Method）** | 直接测定不同时间点的存活菌数，拟合线性曲线斜率 | 常规应用 |

:::

## 灭菌工艺参数 F 值与 F₀ 值：杀菌强度的综合度量

:::answer

**F 值的定义**

F 值是指在**基准温度（Reference Temperature）下，杀死一定数量对象菌（特定菌）所需热处理时间（分钟）**，即该菌的杀菌值（Lethality Value）：

- 低酸性食品和制药行业：基准温度通常取 **121°C（250°F）**
- 湿热灭菌中，在 121°C 时的 F 值记为 **F₀**（F-nought）

**F₀ 的物理含义与计算**

$$F_0 = \int_0^t 10^{\frac{T - 121}{z}} dt$$

其中：
- T：被灭菌物品内部实际温度（°C）
- 121：基准温度（°C）
- z：Z 值（温度每升高 z°C，D 值降低 90% 所对应的温度变化量；湿热灭菌通常 z = 10°C）
- t：灭菌时间（分钟）

**D 值、F₀ 值与无菌保证水平（SAL）的关系**

```
灭菌保证计算逻辑
已知：初始生物负荷 N₀，目标菌的 D₁₂₁°C
所需 F₀ = D₁₂₁°C × (log N₀ - log N_f)
例：N₀ = 10⁶，目标 N_f = 10⁻⁶（SAL = 10⁻⁶）
所需灭菌 log 减少数 = 6 - (-6) = 12 个对数级
所需 F₀ = D₁₂₁°C × 12
```

**F₀ 值在工艺验证中的应用**

F₀ 值可用于**不同灭菌程序的杀菌强度对比**：同样的 F₀ 值，无论通过何种温度-时间组合实现，其对参照菌的杀灭效果等效。这一特性使 F₀ 成为灭菌工艺开发和验证的核心工具。

:::

## 影响 F₀ 值的五大关键因素

:::answer

F₀ 值是灭菌效果的综合量化指标，但其准确性和实际杀菌效果受以下五类因素的影响：

**① 温度（最关键因素）**

由 F₀ 计算公式可知，F₀ 随产品内部温度 T 呈**指数变化**——温度即使有很小的偏差，对 F₀ 值的影响也会非常显著。

关键要求：**F₀ 值的计算须基于灭菌物品内部的实际测量温度**，而非灭菌腔室的温度（两者之间可能存在温差，即热穿透滞后）。

| 温度偏差 | 对 F₀ 的影响（z = 10°C）|
|----------|----------------------|
| +2°C（123°C vs 121°C）| F₀ 增加约 58% |
| -2°C（119°C vs 121°C）| F₀ 降低约 37% |

**② 被灭菌物的物理特性**

| 物理特性 | 对热穿透的影响 |
|----------|-------------|
| 大小（体积）| 体积越大，达到中心温度的时间越长（升温滞后）|
| 形状 | 形状影响热传导路径（球形 vs 扁平容器）|
| 热穿透系数（k）| 导热性差的材料（如塑料）热穿透更慢 |

**③ 溶液特性**

- **溶液黏度**：黏度越高（如含糖、蛋白质的溶液），对流传热能力越弱，热穿透越慢
- **填充量**：相同容器不同填充量（Fill Volume）会改变热穿透时间，须分别验证

**④ 被灭菌物的数量及摆放**

- 容器的装载量（Load）和摆放方式影响蒸汽/热水的流动和分布
- 热点和冷点（Cold Spot，最难达到灭菌温度的位置）须通过热分布研究（Heat Distribution Study）确认

**⑤ 初始生物负荷**

- 初始生物负荷（Bioburden）越高，达到 SAL 目标所需的 F₀ 值越大
- 生物指示剂（BI，如嗜热脂肪芽孢杆菌）的初始数量直接影响灭菌验证的挑战性
- 因此，控制灭菌前的生物负荷（通过过滤、物料控制）是降低所需灭菌强度的重要手段

:::

## DS 放行质量标准中的七大生化检测项目

:::answer

原液（Drug Substance，DS）放行的生化检测项目（Biochemical Release Tests）是保证生物制品批次质量合规的核心控制环节，覆盖产品身份、安全性和功能性三个维度。

**七大生化检测项目完整框架**

| 检测项目 | 检测目的 | 主要方法 | 典型接受标准 |
|----------|---------|---------|------------|
| **① 宿主残留 DNA（HCD）** | 控制宿主细胞基因组 DNA 残留，降低整合/致癌风险 | qPCR（Threshold 法）| ≤ 10 ng/剂（WHO 推荐）|
| **② 宿主细胞蛋白（HCP）** | 控制宿主细胞分泌蛋白残留，避免免疫原性和安全性风险 | Sandwich ELISA（通用或特异性）| 通常 ≤ 100 ppm（依产品而定）|
| **③ Protein A 残留** | 控制亲和层析 Protein A 配基的浸出残留（细胞毒性和免疫原性风险）| Sandwich ELISA（Protein A 特异性）| 通常 ≤ 5–10 ng/mg |
| **④ 内毒素** | 检测热原性革兰氏阴性菌内毒素，避免热原反应 | 鲎试剂法（LAL）：凝胶法/终点显色法 | 依据 L = K/M 计算（K = 5 EU/kg/h for IV）|
| **⑤ 支原体** | 检测支原体污染（细胞培养过程的隐性污染）| 培养法（需 28 天）+ PCR 法（快速）| 无支原体（阴性）|
| **⑥ 结合活性** | 确认产品与靶点的结合能力（功能性鉴别）| ELISA/SPR/BLI（表面等离子共振/生物膜干涉）| 相对参比品：通常 80–125% |
| **⑦ 细胞活性（效价）** | 直接测定与作用机制相关的生物学活性（功能性放行）| 细胞效价（如 ADCC、CDC、增殖抑制等）| 相对参比品：通常 60–150% |

**生化检项与理化检项的互补关系**

生化检项不能单独代表完整的 DS 质量标准，需与理化检项（SEC 纯度、CE-SDS、iCIEF、肽图等）共同构成完整的放行标准体系：
- 理化检项→评估产品相关物质和杂质（纯度/异质性）
- 生化检项→评估工艺相关杂质（安全性）和生物功能（有效性）

:::

## IND/BLA 阶段规模变化的法规要求与可比性研究深度

:::answer

生产规模的变化（Scale Change）在生物制药开发全周期中不可避免，但不同申报阶段对可比性研究的要求深度存在显著差异。

**IND 阶段与 BLA 阶段的规模变化要求对比**

| 维度 | IND 阶段 | BLA 阶段 |
|------|---------|---------|
| **法规灵活度** | 灵活，可根据开发需求进行规模变化 | 严格，规模变化须满足全面监管要求 |
| **可比性研究深度** | 开展可比性研究即可（基于有限批次）| 须开展**系统性**可比性研究 |
| **批次数要求** | 无固定要求，通常 ≥ 2 批 | 须有统计学支持的充足批次数据 |
| **CQA 覆盖范围** | 重点关注安全性/有效性相关 CQA | 全套 CQA 的完整比较 |
| **监管申报** | 通常无需单独申报，告知即可 | 重大规模变化须在 BLA 补充申请中申报 |

**规模变化可比性研究的核心原则（ICH Q5E）**

规模变化被视为一种工艺变更，可比性研究须证明：

```
规模变化可比性研究三步验证框架
步骤 1：质量可比性
├── 全套理化 + 生化 CQA 的批次比较
├── 统计学等效性分析（TOST 或置信区间法）
└── 关键 CQA 差异的临床相关性评估
        ↓（若质量数据不足以支持结论）
步骤 2：非临床可比性
└── 体外功能研究（结合活性/效价）
        ↓（若非临床数据不足以支持结论）
步骤 3：临床可比性
└── PK 桥接研究（必要时）
```

:::

## IND/BLA 阶段生物学活性评价方法的法规要求差异

:::answer

生物学活性（效价，Potency）是生物制品的关键质量属性，但不同开发阶段对评价方法的类型和深度要求不同。

**两阶段的生物活性评价方法要求**

| 申报阶段 | 可接受方法 | 法规依据 |
|----------|-----------|---------|
| **IND 阶段** | 结合活性（如 ELISA、SPR）**也可接受** | 早期阶段：机制研究尚未完成，以结合活性作为功能性替代 |
| **BLA 阶段** | 须同时提供**结合活性 + 细胞活性** | 上市申请须建立与作用机制直接相关的效价方法 |

**结合活性 vs 细胞活性的本质区别**

| 维度 | 结合活性（Binding Activity）| 细胞活性（Cell-based Potency）|
|------|---------------------------|------------------------------|
| **测量内容** | 药物与靶点结合的亲和力/特异性 | 药物引发的细胞生物学效应 |
| **与疗效关联** | 间接（结合是活性的前提，但不等于活性）| 直接（与体内作用机制一致）|
| **方法复杂度** | 相对简单、重复性好（CV < 10%）| 复杂、变异大（CV 通常 20–30%）|
| **法规接受度** | IND 阶段接受；BLA 阶段作为辅助 | BLA 阶段必须，优先于结合活性 |
| **代表方法** | ELISA、SPR（Biacore）、BLI | ADCC、CDC、增殖抑制、信号通路报告基因 |

**效价方法的生命周期演进（策略建议）**

```
IND 早期 → 结合活性（快速建立，支持首次人体试验）
        ↓
IND 中期 → 开始开发基于作用机制的细胞效价方法
        ↓
BLA 申报 → 细胞效价作为主效价；结合活性作为支持性方法
        ↓
上市后（数据充足时）→ 评估是否可用理化替代方法（如胰岛素的 HPLC 定量）
```

:::

## 抗体人源化的四代演进历程与核心驱动逻辑

:::answer

从第一代全鼠源抗体到现代全人源化抗体，治疗性抗体的人源化历程经历了四个重要阶段，核心驱动力是不断降低免疫原性风险。

**四代抗体的发展时间线**

```
1986：第一代鼠源单抗（OKT3，FDA 批准）
   ├── 特点：可变区和恒定区均为鼠源
   ├── 问题：引发 HAMA（人抗鼠抗体）免疫应答
   └── 问题：血清半衰期短（缺乏 FcRn 再循环）
        ↓
约 1990s：第二代嵌合抗体（如利妥昔单抗）
   ├── 特点：人源恒定区 + 鼠源可变区（约 25% 鼠源）
   ├── 改善：降低 HAMA 应答频率和强度
   └── 局限：可变区仍为鼠源，仍可引发 HACA（人抗嵌合抗体）
        ↓
约 1990s–2000s：第三代人源化抗体（如曲妥珠单抗）
   ├── 特点：人源框架区 + 鼠源 CDR（CDR 移植），约 5–10% 鼠源
   ├── 改善：进一步降低免疫原性
   └── 局限：CDR 移植可能降低亲和力，需回复突变优化
        ↓
约 2000s 至今：第四代全人源化抗体（如阿达木单抗、帕尼单抗）
   ├── 特点：可变区和恒定区均为人源（0% 鼠源）
   ├── 技术：噬菌体展示技术 + 表达人源抗体库的转基因小鼠
   └── 局限：仍可能引发 ADA（个体遗传背景、抗独特型应答等）
```

**抗体人源化的核心设计原理**

人源化改造的基本原则是：**保留与抗原结合的关键序列（CDR 区），同时用人源序列替换其余框架区域**，在维持亲和力和特异性的同时，最大程度地减少非人源序列带来的免疫原性风险。

抗体 CDR（互补决定区）的氨基酸序列和空间结构是决定抗体特异性和亲和力的关键因素——正是因为 CDR 必须维持鼠源序列才能保留结合功能，完全消除免疫原性在技术上具有一定挑战。

:::

## 抗体人源化的五种主要技术方法对比

:::answer

**方法一：基于框架区同源性的 CDR 移植（最经典方法）**

将非人源抗体的 CDR 区移植到与原框架区同源性最高的人源抗体框架区（受体框架）上。

**核心挑战**：CDR 环的方向和构象受邻近框架区残基（游标区残基，Vernier Zone）影响，直接移植常导致亲和力显著下降。

**解决方案**：回复突变（Back-mutation）——将人源框架区中影响 CDR 构象的关键游标区残基回复为鼠源氨基酸，以恢复亲和力。

**方法二：基于胚系基因的 CDR 移植**

使用**人类胚系基因**（而非成熟 IgG 序列）作为 CDR 受体框架，优势在于：
- 胚系基因含有较少的体细胞超突变（SHM），与人免疫系统的"自我"识别更一致
- 理论上比成熟 IgG 框架具有更低的免疫原性

**方法三：抗体表面重塑（Surface Resurfacing）**

只替换抗体可变区**表面暴露的氨基酸残基**（而非全部框架区），保留内部埋藏的鼠源残基：
- 原则：仅将暴露于溶剂的表面残基替换为人源同类残基
- 优势：对抗体稳定性和亲和力影响最小
- 局限：人源化程度低于完整 CDR 移植

**方法四：特异性决定残基（SDR）移植**

进一步精简移植内容——仅移植 CDR 序列中**对抗原结合活性绝对必要的关键残基**（SDR），而非整个 CDR 序列：
- 最大程度减少移植入人源框架的鼠源序列数量
- 最小化 CDR 中潜在 T 细胞表位的携带量
- 是降低人源化抗体可变区免疫原性风险最彻底的移植策略

**方法五：全人源化技术（噬菌体展示 + 转基因小鼠）**

| 技术平台 | 原理 | 代表产品 |
|----------|------|---------|
| **噬菌体展示（Phage Display）** | 在噬菌体表面展示人源抗体库，通过目标抗原筛选高亲和力全人源抗体；或将鼠源重链与人源轻链库配对筛选 | 阿达木单抗（Humira）|
| **转基因小鼠（如 HuMAb、XenoMouse）** | 将小鼠抗体基因座替换为人类抗体基因座，免疫后直接产生全人源抗体 | 帕尼单抗（Vectibix）|

**五种方法的综合比较**

| 方法 | 人源化程度 | 亲和力保留风险 | 免疫原性风险 | 工程复杂度 |
|------|-----------|-------------|------------|---------|
| CDR 移植（同源框架）| ★★★★☆ | 中（需回复突变）| 低 | 中 |
| 胚系基因 CDR 移植 | ★★★★☆ | 中 | 更低 | 中 |
| 表面重塑 | ★★★☆☆ | 低 | 中 | 低 |
| SDR 移植 | ★★★★★ | 高（移植序列最少）| 最低 | 高 |
| 全人源化（技术平台）| ★★★★★ | 低（直接筛选）| 最低 | 高（平台依赖）|

:::

## ADC 有效载荷导致的毒性：脱靶、肿瘤外毒性的机制解析

:::answer

**核心悖论：有效载荷毒性而非靶点决定毒性特征**

ADC 设计的理论基础是"靶向抗原决定毒性"，但临床经验表明：**与 ADC 相关的大多数不良事件在频谱、发生率和严重程度上与有效载荷骨架相似**——共享相同有效载荷的不同 ADC 通常具有相似的毒性特征，而不管靶抗原差异如何。

**ADC 毒性的两大分类**

| 毒性类型 | 定义 | 主要来源 |
|----------|------|---------|
| **脱靶、肿瘤外毒性** | 与抗体靶向的抗原**无关**的毒性 | 有效载荷过早解偶联后游离于体循环 |
| **靶向、肿瘤外毒性** | 抗体与**非恶性组织**中的同源抗原结合产生的毒性 | 靶抗原在正常组织中的低水平表达 |

**脱靶、肿瘤外毒性的核心机制**

```
ADC 在体循环中的脱靶毒性路径
ADC 静脉给药后进入体循环
        ↓
连接子过早水解/断裂（不稳定性）
        ↓
游离有效载荷释放至体循环
（通常为亲脂性细胞毒性分子，可穿透细胞膜）
        ↓
自由扩散至肿瘤外非靶向组织（骨髓、肝脏、神经系统等）
        ↓
进入非靶向非恶性细胞，产生细胞毒性
        ↓
典型不良反应：
├── 骨髓抑制（中性粒细胞减少、血小板减少）← MMAE/DM 类常见
├── 肝毒性 ← 肝脏高摄取
├── 周围神经病变 ← 微管蛋白类有效载荷
└── 眼毒性（角膜病）← 特定有效载荷特征
```

**连接子稳定性与脱靶毒性的关系**

ADC 脱靶毒性的严重程度直接与**连接子在体循环中的稳定性**正相关：连接子越稳定（如不可裂解型），游离有效载荷释放越少，脱靶毒性越低；但同时，肿瘤内的有效载荷释放效率也可能受影响。

:::

## ADC 抗体靶向导致的毒性：靶向、肿瘤外效应的机制与规避

:::answer

**靶向、肿瘤外毒性的发生逻辑**

尽管 ADC 的大部分毒性由接头-有效载荷复合物决定，但具有**相同有效载荷和接头**的不同 ADC，其不良事件也可能因靶抗原不同而存在显著差异——这正是靶向、肿瘤外毒性的体现。

**两类 ADC 毒性机制的对比**

| 毒性机制 | 有效载荷脱靶毒性 | 抗体靶向毒性 |
|----------|--------------|------------|
| **决定因素** | 有效载荷类型和连接子稳定性 | 靶抗原在非恶性组织中的表达 |
| **预测性** | 可通过有效载荷化学结构和体外稳定性预测 | 须通过靶抗原的组织表达谱（如 IHC 数据库、HPA）预测 |
| **跨产品一致性** | 相同有效载荷的 ADC 毒性特征相似 | 不同靶抗原的 ADC 毒性特征各异 |
| **控制策略** | 优化连接子稳定性；降低有效载荷亲脂性 | 靶点选择时优先正常组织低/不表达的抗原 |

**靶点选择的安全性评估框架**

为降低靶向、肿瘤外毒性，靶抗原选择须满足：

```
理想 ADC 靶点的安全性评估标准
靶抗原在肿瘤细胞上：高表达（确保有效载荷有效递送）
        +
靶抗原在非恶性细胞上：低表达或不表达（减少正常组织损伤）
评估工具：
├── HPA（人类蛋白质图谱）：正常组织 IHC 数据库
├── GeneCards/GTEx：基因组织表达谱
├── 靶抗原的已知生理功能评估（必要靶点的正常功能风险）
└── 动物毒理学（非人灵长类动物）：正常组织摄取和毒性评估
```

:::

## 产品放行管理：GMP 第二百三十条的法规要求与执行规范

:::answer

产品放行是 GMP 体系中确保药品安全性和有效性的最终关口，GMP 第二百三十条对每批药品放行的最低要求做出了明确规定。

**放行前质量评价的六项必须确认内容**

| 序号 | 确认内容 | 实践含义 |
|------|---------|---------|
| **① 工艺/方法经过验证** | 主要生产工艺和检验方法须经过验证（含确认）| 未经验证的工艺不得用于商业化放行 |
| **② 检查/检验全部完成** | 所有必需的检查和检验项目须已完成，并综合考虑实际生产条件和批记录 | 不得在检验结果未完整的情况下预先放行 |
| **③ 主管人员签名** | 所有必需的生产和质量控制活动均已完成并经相关主管人员签字确认 | 签字代表责任，须在检查完成后实施 |
| **④ 变更处理完毕** | 所有变更须按相关规程处理完毕；需监管部门批准的变更须已获批准 | 未审批完成的变更不得放行相关批次 |
| **⑤ 变更/偏差已取样检验** | 对变更或偏差已完成所有必要的取样、检验、检查和审核 | 偏差的影响须在放行前完全评估 |
| **⑥ 偏差已彻底处理** | 所有与该批相关的偏差须有明确解释或已经彻底调查和适当处理；关联批次须一并处理 | 未关闭的偏差是放行的阻断项 |

**放行决策的三种结论**

药品的质量评价须有**明确的结论**，不得含糊：
- **批准放行（Approved）**：各项要求均满足，质量受权人（QP）签名放行
- **不合格（Rejected）**：不符合放行标准，须隔离并按不合格品处理
- **其他决定**（如待查/扣留）：特殊情况下的临时处置状态

**质量受权人（QP）的法定职责**

> 每批药品均应当由**质量受权人**签名批准放行——这是 GMP 的刚性要求，放行权不得委托给非质量受权人实施。

质量受权人须在综合评估以上六项内容并确认满足后，方可签署放行文件，承担该批产品的最终质量责任。

:::

## 库存管理体系：合理库存目标与循环盘点的实施逻辑

:::answer

库存管理是生产计划和成本控制的基础支撑系统，在生物制药中尤其需要结合物料的批号管理、储存条件和有效期管理进行系统性设计。

**库存管理的四大核心功能**

| 功能模块 | 具体内容 | 管理工具 |
|----------|---------|---------|
| **账务管理** | 仓库和货位的入/出库管理；单据管理（入库单、出库单、领料单）| ERP 系统（SAP/Oracle）|
| **物流管控** | 及时反映各种物资的仓储位置和流向，为生产和成本核算提供依据 | WMS（仓库管理系统）|
| **库存分析** | 库存资金占用、物资积压、短缺/超储、ABC 分类（按价值重要性分级）| 统计报表 + BI 工具 |
| **批号追踪** | 实现专批专管（一批号一仓位），保证从原材料到成品的全程批号可追溯 | 批次追踪记录（Batch Record）|

**ABC 库存分类管理策略**

| 分类 | 特征 | 管理策略 |
|------|------|---------|
| **A 类（高价值/高重要性）** | 占总金额约 70–80%，品种少（约 10–20%）| 严格管控，精准备货，最小安全库存 |
| **B 类（中等）** | 占总金额约 15–25%，品种中等 | 常规管控，定期复查库存水平 |
| **C 类（低价值/低重要性）** | 占总金额约 5%，品种最多 | 批量采购，降低管理成本 |

**循环盘点（Cycle Count）vs 年度盘点**

循环盘点是代替年度全面盘点的现代库存管理方式：按照物料的 ABC 分类，每月/每季对高价值物料进行滚动盘点，全年覆盖所有物料——既保证了盘点精度，又不影响日常运营。

:::

## 仓库与存储管理：GMP 合规的物料接收与 FIFO 管理规范

:::answer

**仓库管理的 GMP 核心要求**

生物制药原材料和成品的仓储管理须满足以下核心原则：

**① 原材料接收规范**

- 到货时须核对品名、规格、数量、供应商、批号、到期日/复验期
- 须对运输状态进行评估（特别是需要冷链的生物制品原料）
- 待检状态挂牌（黄标），检验合格后转为放行状态（绿标）

**② FIFO（先进先出，First In First Out）管理**

FIFO 是生物制药仓储管理的基本原则，通过 WMS（仓库管理系统）的条形码/RFID 扫描系统强制执行：
- 同一物料的先入库批次须优先出库使用
- 防止有效期较早的物料被积压
- 系统自动推荐出库批次，减少人工错误

**③ PFEP（为每个零件做计划，Plan For Every Part）**

PFEP 是精益供应链中对每种物料的存储、消耗和补货进行精细化规划的方法：

```
PFEP 对每种物料的关键信息规划
├── 物料基本信息（料号、描述、规格）
├── 使用频率（每日/每周用量）
├── 供应商信息（交货周期、最小订货量）
├── 存储要求（温度/湿度/洁净级别）
├── 安全库存水平（Safety Stock Level）
└── 再订购点（Reorder Point）
```

**存储环境的条件管理**

| 存储类型 | 温度要求 | 典型物料 |
|----------|---------|---------|
| 常温库 | 15–30°C | 辅料、包装材料、部分培养基 |
| 冷藏库（2–8°C）| 2–8°C | 细胞库安瓿、冷链原材料、酶类 |
| 冷冻库（-20°C）| ≤ -20°C | 质粒 DNA、酶、部分原辅料 |
| 超低温库（-80°C）| ≤ -80°C | 原液（DS）、工作细胞库（WCB）|
| 液氮储罐（-196°C）| -196°C | 主细胞库（MCB）长期保存 |

:::

## 运输管理的规范化体系与装载效率优化

:::answer

**运输管理的核心规范内容**

对运输流程的规范化管理须覆盖以下关键要素：

**① 供应商供货方式定义**

对每个供应商均须明确定义以下运输参数：

| 参数 | 定义内容 |
|------|---------|
| 运输方式 | 公路/铁路/航空/海运；冷链还是常温 |
| 运输线路 | 起点→终点的具体路径；中转节点 |
| 到货时间 | 到货时间窗口（如每周二上午 8–12 点）|
| 发运频次 | 每日/每周/按需；与生产计划联动 |

**② 冷链运输的特殊要求（生物制品）**

生物制品原材料（如细胞库、血清、酶类）和成品（如制剂成品）的冷链运输须特别关注：
- 温度记录仪（Data Logger）随货记录全程温湿度
- 验证冷链包装（冰盒/干冰）在最长运输时间内的维温能力
- 到货时审查温度记录，超温须启动偏差调查

**③ 运输装载率优化**

通过以下措施提升运输效率：
- 定期对运输车辆装载率进行统计分析
- 联合客户、工厂人员和供应商进行三方协同优化
- 合并小批量运输，提高整体经济效益

:::

## 采购管理的三步标准流程

:::answer

生物制药原材料（原辅料、耗材、包装材料）的采购管理须遵循规范化的三步流程，确保供应商质量和物料供应的可靠性。

**采购三步流程的完整框架**

**第一步：确定供货渠道（供应商筛选与批准）**

基于市场分析，从以下维度综合评估潜在供应商：

| 评估维度 | 关键考量 |
|----------|---------|
| **质量** | 供应商 GMP 资质；历史质量记录；产品 CoA（分析证书）质量 |
| **价格** | 单价和总体成本（含运输、检验、库存成本）|
| **距离（交货期）** | 地理位置与交货周期；是否有备用库存 |
| **生产能力** | 能否满足商业化规模的持续供货需求 |
| **服务能力** | 技术支持、应急响应能力 |
| **财务稳定性** | 供应商的持续经营能力 |

供应商入选后须经过正式的**供应商审计（Supplier Audit）**和**质量协议（Quality Agreement）**签署。

**第二步：落实采购合同**

与批准供应商洽谈并签署采购合同，明确：
- **供货价格**：含阶梯价格（批量优惠）
- **数量**：最小订货量（MOQ）和最大供货量
- **质量要求**：物料规格书（Material Specification）和检验要求
- **交货时间**：正常交货周期和紧急交货能力
- **交货地点**：DDP（完税后交货）还是 FOB 等贸易术语

**第三步：安排运输验货**

- 落实物料运输的具体时间、方式和到货时间窗口
- 到货验收：**现场验收**（到货时逐箱检查）+ **实验室抽验**（按质量标准检验）
- 验收内容：品种、规格、数量的核实；包装完整性；批号和有效期确认
- 保证物料**保质、保量、按时**送达

:::

## 入库管理：物料验收、放行与合理存放的规范体系

:::answer

入库管理是供应链质量控制的关键节点，包含物料验收（身份/数量确认）和物料放置（合规存储）两个核心环节。

**入库管理的两大核心环节**

**环节一：物料验收（Receiving Inspection）**

验收须做到"三相符"：

```
三相符验收标准
实物 ↔ 送货单据（品名/规格/数量一致）
         ↕
送货单据 ↔ 采购合同要求（规格/批号/有效期符合约定）
         ↕
物料 ↔ 质量标准（随附 CoA + 入厂检验）
```

**如发现质量问题**：须立即将物料置于隔离状态（红标）并向主管部门报告，不得在质量问题明确处置前将物料移入合格品区。

**环节二：物料放置（Storage Placement）**

合理存放须综合考虑三个维度：

| 考量维度 | 原则 | 具体措施 |
|----------|------|---------|
| **货物特性** | 按存储条件要求（温度/湿度/避光）存放 | 冷链物料入冷库；避光物料用遮光包装 |
| **存取频率** | 常用物料放在进出方便的位置（如货架前排或靠近出口）| 按周转率设定货位优先级 |
| **管理便捷** | 堆放方式和标志便于日常清点和 FIFO 管理 | 同一物料同一货位；标识完整（物料名/批号/状态/有效期）|

**GMP 对物料储存状态标识的要求**

| 物料状态 | 标识颜色（常规约定）| 含义 |
|----------|-----------------|------|
| 待检（Quarantine）| 黄色 | 已到货，等待检验结果 |
| 合格（Approved）| 绿色 | 检验合格，可用于生产 |
| 不合格（Rejected）| 红色 | 检验不合格，待销毁或退货 |
| 待定（On Hold）| 蓝色/白色 | 特殊情况下的临时状态 |

:::
