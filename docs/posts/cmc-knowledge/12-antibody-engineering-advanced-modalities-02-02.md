## 细菌内毒素国家标准品：来源、效价标定与核心用途

:::answer

**来源与制备**

细菌内毒素国家标准品系自<strong>大肠埃希菌（Escherichia coli）</strong>提取精制，并以**细菌内毒素国际标准品**（WHO 标准品）进行效价标定，确保其量值可溯源至国际标准。

**核心用途**

国家标准品在内毒素检测体系中处于最高级别，主要承担以下职能：

| 用途类别                 | 具体应用                                               |
| ------------------------ | ------------------------------------------------------ |
| 鲎试剂灵敏度标定与复核   | 用于新鲎试剂批次的灵敏度确认和已用批次的定期复核       |
| 工作标准品效价标定       | 作为上级标准品标定实验室日常使用的细菌内毒素工作标准品 |
| 仲裁检验                 | 当检测结果存在争议时，以国家标准品检验结果为准         |
| 干扰试验                 | 用于供试品干扰试验中编号 B 和 C 溶液的制备             |
| 凝胶法鲎试剂灵敏度复核   | 每批次鲎试剂使用前的灵敏度确认试验                     |
| 光度法标准曲线可靠性验证 | 浊度法和显色基质法中标准曲线的绘制与验证               |

**使用注意事项**

- 标准品须按说明书要求在规定条件下储存（通常为 -20°C 或 -70°C），避免反复冻融
- 复溶后须在旋涡混合器上充分混匀（≥15 分钟），确保均匀分散
- 每次使用前须确认标准品在有效期内，并记录批号、复溶时间和使用量
- 工作标准品须定期回溯比对国家标准品，确保检测体系的量值传递链完整

## 注射制剂渗透压的设计原则与配方优化策略

:::answer

**渗透压的生理基础与重要性**

注射制剂的渗透压设计直接影响注射部位的耐受性和患者安全：

| 渗透压类型 | 范围（mOsm/kg） | 临床影响                                               |
| ---------- | --------------- | ------------------------------------------------------ |
| 等渗       | 280～320        | 与血浆生理环境一致，耐受性最佳                         |
| 低渗       | < 280           | 大多数注射部位可接受（眼内等除外），但可能引起细胞肿胀 |
| 高渗       | > 320           | 引起注射部位刺激、疼痛和不适，患者顺应性差             |

**渗透压的设计原则**

- **首选等渗**：推荐配方渗透压与注射环境的生理渗透压保持一致（280～320 mOsm/kg）
- **避免高渗**：高渗溶液即便不影响药物活性，也会因引起注射部位刺激而降低患者依从性
- **早期整合**：在最初溶解度、稳定性优化阶段，即应将渗透压因素纳入配方设计，避免后期被动调整

**配方设计的基本原则**

- **尽可能简单**：避免引入过多不必要辅料，以减少辅料间的复杂相互作用，并在出现问题时更容易定位根本原因
- **辅料选择的必要性原则**：每种辅料的引入均须有明确的功能依据（如渗透压调节剂、稳定剂、表面活性剂），不引入无益辅料
- **辅料与蛋白的相互作用**：某些辅料（如聚山梨醇酯）可能与蛋白质发生相互作用，需在开发早期通过强制降解和相容性试验进行系统评估

**渗透压调节常用辅料**

| 辅料           | 渗透压贡献     | 注意事项                         |
| -------------- | -------------- | -------------------------------- |
| 氯化钠（NaCl） | 高效，常用     | 离子强度增加可能影响蛋白聚集行为 |
| 蔗糖/海藻糖    | 温和，不带电荷 | 冻干制剂首选，具有冷冻保护功能   |
| 甘露醇         | 中等           | 冻干赋形剂，注意结晶行为         |
| 甘氨酸         | 低             | 常与蔗糖联用                     |

:::

## 细菌内毒素限值的计算方法与设定逻辑

:::answer

**限值计算公式**

药品和生物制品细菌内毒素限值（L）按以下公式确定：

$$L = \frac{K}{M}$$

**参数定义**

| 参数 | 含义                                                        | 常用值                                           |
| ---- | ----------------------------------------------------------- | ------------------------------------------------ |
| $L$  | 供试品细菌内毒素限值，单位 EU/mL、EU/mg 或 EU/U（活性单位） | —                                                |
| $K$  | 人每千克体重每小时最大可接受内毒素剂量（EU/kg·h）           | 注射剂：**5 EU/kg·h**；鞘内注射：**0.2 EU/kg·h** |
| $M$  | 人用每千克体重每小时最大供试品剂量（mL/kg·h 或 mg/kg·h）    | 按实际临床给药方案计算                           |

**计算参数说明**

- 人均体重按 **60 kg** 计算
- 人体表面积按 **1.62 m²** 计算
- 注射时间若不足 1 小时，**按 1 小时计算**
- 若给药剂量以每平方米体表面积（m²）表示，乘以 **0.027** 即可换算为每千克体重剂量（M）

**计算示例**

以某静脉注射单抗为例：

- 最大临床单次剂量：400 mg，输注时间 30 min（按 1 h 计算）
- 体重换算后 M = 400 mg / 60 kg / 1 h = 6.67 mg/kg·h
- 内毒素限值 L = 5 EU/kg·h ÷ 6.67 mg/kg·h = **0.75 EU/mg**

**不同给药途径的 K 值差异**

| 给药途径            | K 值（EU/kg·h） | 说明                           |
| ------------------- | --------------- | ------------------------------ |
| 静脉注射 / 输注     | 5               | 最常用标准                     |
| 鞘内注射            | 0.2             | 中枢神经系统敏感性高，限值严格 |
| 肌内注射 / 皮下注射 | 5               | 同静脉注射                     |

**生物制品的特殊考量**

生物制品的内毒素限值设定还需考虑：产品纯度（高纯度蛋白制品通常以 EU/mg 表达）、临床给药频率（每日多次给药须按小时累积计算）以及目标适应症人群（儿科用药须以儿童体重计算）。

:::

## ADC 药物研发关键要素：抗体、连接子与毒素的协同设计

:::answer

**三大关键技术要素**

ADC 研发的成败由三个核心要素决定，三者相互依存、缺一不可：

| 要素             | 核心决定作用                              |
| ---------------- | ----------------------------------------- |
| 抗体（靶点）     | 决定 ADC 对肿瘤细胞的亲和力与靶向特异性   |
| 连接子（Linker） | 决定 ADC 在体循环中的稳定性及胞内释药效率 |
| 毒素（Payload）  | 决定 ADC 的杀伤力与脱靶毒性风险           |

**关键要素一：抗体的选择与生产**

**选择标准（理想靶抗原特征）**

- 肿瘤特异性或相关性高：肿瘤细胞**高表达**，正常组织**低/不表达**
- 表面抗原密度足够，支持有效药物负载
- 内吞效率高：抗体-抗原复合物能被细胞快速、高效地内化（Internalization Rate 是关键参数）
- 抗原亲和力适当：过高亲和力可能产生"结合位点屏障效应"，影响肿瘤内部穿透
- 低非特异性结合（FcγR 介导的非靶向摄取须最小化）
- 良好 PK 特性：低清除率，维持足够肿瘤暴露量
- 无免疫原性：全人源化或高度人源化

**生产要求**

与普通单抗生产流程一致，须严格控制上游培养工艺（防止细胞应激引起的质量变异）和下游纯化工艺（确保抗体纯度和均一性），为后续偶联步骤提供高质量的抗体底物。

**关键要素二：连接子的选择与偶联方式**

**连接子核心设计矛盾**

- **体循环中**：必须高度稳定，防止 Payload 提前释放导致系统毒性
- **肿瘤细胞内**：必须快速、高效裂解，确保活性 Payload 充分释放

**可裂解 vs. 不可裂解连接子的权衡**

| 特性维度   | 可裂解连接子                     | 不可裂解连接子           |
| ---------- | -------------------------------- | ------------------------ |
| 释药机制   | pH、蛋白酶、还原剂（GSH）敏感    | 抗体完全溶酶体降解后释放 |
| 血浆稳定性 | 中等（设计优化后可改善）         | 最高                     |
| 旁观者效应 | 强（游离 Payload 可穿膜扩散）    | 弱/无                    |
| 脱靶毒性   | 相对较高                         | 较低                     |
| 适用肿瘤   | 抗原表达异质性肿瘤（旁效应弥补） | 抗原表达均一性高的肿瘤   |

**偶联方式的选择**

- **非定点偶联**（早期方法）：直接利用化学方法与抗体表面氨基酸（赖氨酸/半胱氨酸）随机偶联，DAR 分布宽，产品不均一，现已逐步被取代
- **定点偶联**（主流趋势）：通过抗体工程改造引入特异性偶联位点，实现 DAR 值精确控制和高均一性产品，方法包括工程化半胱氨酸（THIOMAB™）、非天然氨基酸引入、酶催化偶联等

**DAR 值的关键控制**

- DAR < 2：药物负载不足，疗效下降
- DAR 2～4：传统随机偶联最优范围
- DAR > 8（均一定点偶联）：如 DS-8201（DAR=8），依赖定点偶联实现高均一性，规避高 DAR 引起的聚集问题

**关键要素三：毒素（Payload）的选择与生产**

**选择标准**

- 极高细胞毒性：IC₅₀ 通常须在 **nM 甚至 pM** 范围（比常规化疗药物高出 100～1000 倍）
- 可修饰性：含有可与 Linker 共价结合的化学功能基团（-NH₂、-SH、-OH 等）
- 适当亲疏水平衡：过于疏水的 Payload 会导致 ADC 聚集，须通过亲水性修饰改善
- 高化学稳定性：在血浆条件下不自发降解
- 胞内靶点：作用靶点位于细胞内（微管蛋白、DNA、RNA 聚合酶等），避免胞外提前作用

**主流 Payload 类型**

| 类型                     | 作用机制                   | 代表化合物           | 代表 ADC                          |
| ------------------------ | -------------------------- | -------------------- | --------------------------------- |
| 微管蛋白抑制剂           | 阻止微管聚合，阻滞 G2/M 期 | MMAE、MMAF、DM1、DM4 | Adcetris（MMAE）、Kadcyla（DM1）  |
| DNA 损伤剂（卡奇霉素类） | DNA 双链断裂               | 卡奇霉素             | Mylotarg、Besylona                |
| DNA 损伤剂（喜树碱类）   | 拓扑异构酶 I 抑制          | DXd、SN-38           | Enhertu（DXd）、Trodelvy（SN-38） |
| PBD 二聚体               | DNA 链间交联               | SG3199               | Zynlonta                          |

**生产要求**

毒素小分子的合成和生产须遵循化学药品原料药（API）的生产规范（ICH Q7），并须建立完整的杂质谱控制和稳定性研究体系。

:::

## ADC 连接子的类型选择、稳定性设计与偶联方法比较

:::answer

**连接子的双重功能定位**

连接子是 ADC 分子的"保险丝"——在血液中保护 Payload 不提前释放，在肿瘤细胞内精准引爆释放活性毒素。连接子的选择直接决定 ADC 的治疗窗口宽度。

**可裂解连接子的四种裂解机制**

**pH 敏感型（腙键，Hydrazone）**

- 裂解条件：溶酶体酸性环境（pH 4～5）
- 优点：设计简单，早期产品广泛应用
- 缺点：血浆 pH 7.4 条件下稳定性不足，可能提前水解，系统毒性风险较高
- 代表产品：第一代 Mylotarg（已基本被更稳定的 Linker 替代）

**还原敏感型（二硫键）**

- 裂解条件：细胞内高浓度还原型谷胱甘肽（GSH）；肿瘤细胞 GSH 浓度约为血浆的 **500～1000 倍**
- 优点：利用肿瘤细胞特有的氧化还原梯度实现选择性释放
- 缺点：血浆中仍存在一定浓度 GSH 和蛋白质二硫键，可能发生一定程度的非特异性裂解

**蛋白酶敏感型（肽键，Val-Cit-PABC）**

- 裂解条件：溶酶体组织蛋白酶 B（Cathepsin B），在癌细胞溶酶体中过度表达
- 优点：血浆中存在蛋白酶抑制剂，酶裂解 Linker 在体循环中高度稳定；肿瘤特异性好
- 缺点：不同肿瘤组织蛋白酶 B 表达水平存在差异，影响释药效率
- 代表产品：Adcetris（Val-Cit-PABC-MMAE）

**葡萄糖苷酸敏感型（β-葡萄糖苷酸键）**

- 裂解条件：β-葡萄糖苷酸酶（在癌细胞溶酶体及坏死肿瘤区域过表达）
- 优点：亲水性强（葡萄糖苷酸基团）显著降低 ADC 聚集倾向，有利于高 DAR 产品开发
- 代表应用：与疏水性 Payload（如 SN-38）联用，改善整体溶解性

**不可裂解连接子**

- 代表结构：硫醚键（Thioether）、马来酰亚胺己酰基（MCC）
- 释放机制：ADC 被内化后在溶酶体中被蛋白酶完全降解，最终以**氨基酸-Linker-Payload** 复合物形式释放
- 核心优势：对体内化学和酶环境高度惰性，血浆稳定性最高，脱靶毒性最低
- 核心劣势：由于释放的是带极性基团的 Payload 衍生物（而非游离小分子），**膜穿透能力弱，旁观者效应几乎缺失**
- 代表产品：Kadcyla（T-DM1，硫醚键连接）

**偶联方法的技术演进**

| 偶联方法                   | 偶联位点                    | DAR 均一性 | 适用阶段   | 关键技术                       |
| -------------------------- | --------------------------- | ---------- | ---------- | ------------------------------ |
| 赖氨酸偶联                 | 随机（80～100 个 Lys）      | 极低       | 早期探索   | NHS 酯活化                     |
| 链间二硫键还原半胱氨酸偶联 | 相对随机（8 个 Cys）        | 中等       | 第二代主流 | TCEP 部分还原 + 马来酰亚胺反应 |
| 工程化半胱氨酸定点偶联     | 精确定点（1～2 个工程 Cys） | 高         | 第三代主流 | THIOMAB™ 技术                  |
| 非天然氨基酸定点偶联       | 精确定点（nnAA 引入位点）   | 极高       | 前沿技术   | 密码子扩展 + 点击化学          |
| 酶催化定点偶联             | 精确定点（酶识别序列）      | 极高       | 前沿技术   | TGase、Sortase、糖基工程       |

## CAR-T 细胞的结构设计：从第一代到第五代的技术演进

:::answer

**CAR 分子的基本结构**

嵌合抗原受体（Chimeric Antigen Receptor, CAR）是工程化 T 细胞的核心功能模块，由三个结构域组成：

| 结构域          | 组成                                      | 功能                                                   |
| --------------- | ----------------------------------------- | ------------------------------------------------------ |
| 胞外抗原识别区  | 通常为单链抗体（scFv = VH + Linker + VL） | 识别并特异性结合靶抗原（无需 MHC 提呈，突破 MHC 限制） |
| 跨膜区 / 铰链区 | CD8α、CD28 等跨膜结构域                   | 将 scFv 锚定于 T 细胞膜上，传导信号                    |
| 胞内信号域      | CD3ζ 激活域 + 共刺激域（CD28、4-1BB 等）  | 接收抗原结合信号，激活 T 细胞杀伤与增殖                |

**五代 CAR 结构的演进对比**

**第一代 CAR（1989 年提出）**

- 结构：scFv + 跨膜区 + **CD3ζ**（单一激活域）
- 特点：仅有激活信号，无共刺激
- 局限：T 细胞激活后增殖能力弱、持久性差，体内抗肿瘤活性有限
- 临床意义：验证了 CAR 概念可行性

**第二代 CAR（临床主流）**

- 结构：scFv + 跨膜区 + **共刺激域（CD28 或 4-1BB）** + CD3ζ
- 关键进步：引入一个共刺激信号，显著增强 T 细胞增殖能力、体内持久性和细胞因子分泌
- CD28 vs. 4-1BB 的选择：CD28 起效快但持久性稍逊；4-1BB 促进记忆 T 细胞形成，持久性更强
- 代表产品：Kymriah（4-1BB）、Yescarta（CD28）

**第三代 CAR**

- 结构：scFv + 跨膜区 + **两个共刺激域（CD28 + 4-1BB 或 CD28 + OX40）** + CD3ζ
- 关键进步：双共刺激信号协同增强，理论上进一步提高激活强度
- 现状：临床数据尚未证明相较第二代有显著优势，研究仍在进行中

**第四代 CAR（"武装化"CAR-T / TRUCK）**

- 结构：在第二代基础上，增加**细胞因子分泌模块**（IL-2、IL-12、IL-15 等可诱导表达）
- 关键进步：通过分泌促炎细胞因子改造肿瘤免疫微环境（TME），克服 TME 的免疫抑制；同时募集和激活其他内源性免疫细胞（NK 细胞、树突状细胞等），形成协同抗肿瘤效应
- 特别适用：实体瘤（TME 免疫抑制是实体瘤 CAR-T 疗效差的核心原因）

**第五代 CAR（通用型 CAR-T / UCAR-T）**

- 核心技术：通过 CRISPR/Cas9 等基因编辑工具，敲除异体 T 细胞的以下基因：
  - TCR（T 细胞受体）基因 → 避免移植物抗宿主病（GvHD）
  - MHC-I（HLA）基因 → 避免宿主对输注 T 细胞的排斥
  - 相关免疫检查点基因（PD-1、TIGIT 等）→ 增强持久性
- 战略意义：实现<strong>"即用型"（off-the-shelf）</strong>CAR-T 产品，从异体健康供者制备，大幅降低生产成本，突破自体 CAR-T 定制化生产的瓶颈

:::

## CAR-T 细胞的制备流程：从白细胞采集到产品放行

:::answer

**制备流程总览**

CAR-T 产品制备是一个高度复杂的个体化生物制造过程（自体 CAR-T），全程约需 **2～4 周**，每一步骤均对最终产品的质量、安全性和疗效产生直接影响。

**第一步：白细胞单采（Leukapheresis）与细胞清洗**

- **采集原理**：利用血液成分分离机，基于密度梯度离心从患者（自体）或健康志愿者（异体/通用型）外周血中分离白细胞
- **常用设备**：Trima、UVAR-XTS、COBE Spectra
- **关键操作**：采集后洗涤去除分离过程中添加的抗凝剂（如 ACD-A 溶液），减少对后续细胞培养的干扰
- **质控要点**：记录起始材料（白细胞）的细胞活力、数量、T 细胞比例，作为后续工艺的基准

**第二步：T 细胞富集与激活**

- **富集方法**：单克隆抗体磁珠法（CD4/CD8 特异性抗体偶联磁珠）进行阳性选择，或去除非 T 细胞的阴性选择
- **激活方法**：加入 CD3/CD28 双功能单克隆抗体磁珠或人工抗原提呈细胞（aAPC），模拟树突状细胞对休眠 T 细胞的生理激活信号
- **激活的必要性**：仅活化 T 细胞才能高效分裂增殖；且 T 细胞仅在活化状态下才对转导的 CAR 基因表达响应良好
- **质控要点**：监测激活标志物（CD25、CD69、CD137 表达），确认 T 细胞有效激活

**第三步：CAR 基因导入（转染 / 转导）**

这是 CAR-T 制备最核心的步骤，直接决定 CAR 表达效率和产品质量。

| 导入方法     | 代表载体/工具                   | 优点                               | 缺点                                                               |
| ------------ | ------------------------------- | ---------------------------------- | ------------------------------------------------------------------ |
| 病毒载体转导 | 慢病毒（LV）、γ-逆转录病毒      | 稳定整合，高转导效率，临床验证充分 | 制造复杂、成本高、GMP 合规要求严格、整合随机性带来潜在插入突变风险 |
| 非病毒转染   | 电穿孔（电转 DNA/mRNA）         | 成本低，无病毒相关安全顾虑         | 瞬时表达（mRNA），或需依赖转座子系统实现稳定整合                   |
| 转座子系统   | Sleeping Beauty（SB）、PiggyBac | 基因整合具有一定靶向性，成本低     | 整合效率低于病毒载体，临床数据尚不如病毒载体成熟                   |

**当前趋势**：非病毒基因递送（尤其是 mRNA 电转 + 转座子系统）是降低 CAR-T 生产成本的重要方向，也是实现通用型 CAR-T 规模化生产的关键使能技术。

**第四步：T 细胞体外扩增**

- 在含有 IL-2、IL-7、IL-15 等细胞因子的专用培养基中，在生物反应器（波浪袋、G-Rex 平板等）中扩增至临床所需的细胞数量（通常 10⁸～10¹⁰ 个细胞/次）
- 扩增期间须监测细胞活力、CAR 表达率、T 细胞亚群（CD4/CD8 比例）、表型（效应/记忆亚群分布）

**第五步：收获、浓缩、制剂与冷冻保存**

- 扩增完成后收获细胞，洗涤去除残留培养成分
- 配制至目标浓度（含冷冻保护剂，通常为 DMSO + HSA）
- 分装至输液袋，液氮（-196°C）或超低温（-80°C）冷冻储存
- 放行检测：无菌、支原体、内毒素、细胞活力、CAR 表达率、效价（体外杀伤活性）、细胞身份（CD3+）等

:::

## FDA 对 CAR-T 产品 CMC 的监管建议：申报框架与质量控制要求

:::answer

**申报资料组织要求（CTD 格式）**

FDA 要求申请人以**通用技术文件（CTD）格式**组织 CAR-T 产品的 CMC 信息：

| CTD 模块       | 内容归属                                                            |
| -------------- | ------------------------------------------------------------------- |
| 模块 2（摘要） | CAR-T 生产工艺概述；DS/DP 划分说明（尤其连续工艺时）                |
| 模块 3（质量） | 载体 CMC（独立原料药部分）+ CAR-T 细胞 CMC（独立原料药 + 制剂部分） |

**注意**：当采用连续工艺制造 CAR-T 细胞，原料药（DS）与制剂（DP）之间无明确中间储存步骤时，FDA 建议在模块 2 摘要中加以解释，明确 DS/DP 划分依据。

**CMC 质量控制核心理念**

FDA 倡导对 CAR-T 产品采用**生命周期管理（Lifecycle Approach）**：

- 在产品开发全过程中**持续收集数据**，不断完善质量标准
- IND 阶段提交的 CMC 信息量取决于**临床研究阶段和范围**，初始 IND 无需完成所有 CTD 部分
- 早期临床研究收集的**细胞特征数据**（表型、功能、基因组整合位点等）为后期放行标准的制定提供关键依据

**生产工艺控制的关键要求**

**起始材料的变异性管控**

CAR-T 生产面临双重变异来源：多步骤工艺本身的变异性，以及**供体间变异性**（患者疾病状态、既往治疗方案、年龄等均影响 T 细胞质量）。

FDA 建议的管控措施：

- 使用**优质辅助材料**（激活试剂、细胞因子、血清等须通过来料资格认证）
- 建立**关键工艺参数（CPP）**的过程中控制和过程中测试体系
- 对<strong>关键质量属性（CQA）</strong>的中间体和终产品进行全面检测

**辅助材料资格认证**

对所有辅助材料（选择试剂、激活磁珠、抗体、细胞因子、血清、生长因子）须建立供应商资格认证体系，包括：供应商审计、分析证书（COA）和原产地证书（COO）评估、目视检查和必要时的入厂检验。

**无菌生产的特殊要求**

CAR-T 终产品**不能进行终端灭菌**（细胞须保持完全存活和功能状态），因此：

- 须在**cGMP 条件下的封闭无菌系统**中进行全程无菌操作
- 须建立经验证的无菌工艺（Validated Aseptic Process）
- 依据 USP <71> 进行无菌检测，或使用经合格认证和验证的替代检测方法

**患者来源起始材料的特殊考量**

与健康供者来源的起始材料相比，患者来源 T 细胞可能因疾病状态或既往治疗（如化疗、放疗、免疫抑制剂）而存在固有特性改变（如 T 细胞数量减少、功能受损、耗竭表型增加），需进行**额外的工艺开发验证**，以确认商业化生产工艺在患者起始材料条件下的适用性。

:::

## 基因治疗的定义、技术分类与核心治疗策略

:::answer

**定义**

基因治疗（Gene Therapy）是指将外源正常基因（或基因编辑工具）导入靶细胞，以纠正或补偿因基因突变或异常表达引起的疾病，从而实现治疗目的。广义上，基因治疗还包括在 DNA/RNA 水平采取的所有干预措施。

**疾病中基因表达异常的两大类型**

| 类型                   | 表现                                               | 举例                                    |
| ---------------------- | -------------------------------------------------- | --------------------------------------- |
| 基因突变导致蛋白质异常 | 蛋白质无功能、功能减弱、功能过强，或产生有毒性蛋白 | 囊性纤维化（CFTR 功能缺失）、镰状细胞病 |
| 表达强度异常           | 基因表达水平过高或过低                             | 肿瘤抑癌基因低表达、癌基因过表达        |

**七种核心基因治疗技术策略**

**基因矫正（Gene Correction）**

- 原理：仅纠正致病基因中的异常碱基（点突变等），保留正常序列
- 技术工具：碱基编辑器（Base Editor）、先导编辑（Prime Editing）
- 优势：最精准，不改变基因组整体结构

**基因置换（Gene Replacement）**

- 原理：通过同源重组技术，原位替换致病基因，使细胞 DNA 完全恢复正常
- 技术工具：AAV 介导的同源重组、CRISPR-Cas9 + HDR（同源定向修复）
- 挑战：同源重组效率在分裂后细胞中极低

**基因增补（Gene Addition/Augmentation）**

- 原理：不删除突变基因，额外插入正常功能基因拷贝，通过额外表达的正常蛋白补偿功能缺失
- 技术工具：AAV、慢病毒载体介导的基因整合或附加体表达
- 适用：功能缺失性遗传病（如 ADA-SCID、SMA、血友病 A/B）
- 代表产品：Zolgensma（SMA，AAV9-SMN1 基因增补）

**基因失活（Gene Silencing）**

- 原理：将反义核酸（反义 RNA/DNA）、核酶（Ribozyme）、siRNA 或 shRNA 导入细胞，在转录或翻译水平阻断异常基因表达
- 适用：功能获得性突变疾病、肿瘤中的癌基因过表达
- 技术工具：ASO（反义寡核苷酸）、RNAi、CRISPR 干扰（CRISPRi）

**自杀基因疗法（Suicide Gene Therapy）**

- 原理：将"自杀基因"（来自病毒或细菌，编码特定酶）导入靶细胞（肿瘤细胞）；该酶可将原本无毒或低毒的前药（Prodrug）代谢为高毒性细胞毒素，选择性杀伤含自杀基因的细胞
- 代表系统：HSV-TK（单纯疱疹病毒胸苷激酶）/ 更昔洛韦（Ganciclovir）系统；CD / 5-FC 系统
- 应用场景：肿瘤局部基因治疗；CAR-T 安全开关（自杀基因用于控制过度激活的 CAR-T 细胞）

**免疫基因治疗（Immune Gene Therapy）**

- 原理：将产生抗病毒或抗肿瘤免疫力的相关基因（如细胞因子基因、肿瘤抗原基因、共刺激分子基因）导入机体细胞，增强免疫识别和杀伤
- 应用：细胞因子基因治疗（IL-2、IFN-γ、TNF-α 等导入肿瘤细胞，改造 TME）；肿瘤疫苗

**耐药基因治疗（Drug Resistance Gene Therapy）**

- 原理：将抗药物毒性基因（如 MDR1、MGMT 等）导入造血干细胞，使骨髓细胞对化疗药物产生耐受性，从而允许使用更大剂量化疗来消灭肿瘤
- 应用场景：配合强化化疗方案保护正常造血功能

:::

## 基因治疗的发展历程：从伦理争议到首批商业化产品上市

:::answer

**三个关键历史阶段**

**第一阶段（1989 年以前）：受限期**

早期基因相关研究因涉及对人类遗传物质的人为干预，受到宗教、伦理和法律层面的严格限制与阻碍，基础研究虽持续推进，但人体临床应用被明确禁止。

**第二阶段（1989—1995）：突破期**

- **1989 年**：FDA 批准将病毒载体导入人体作为"基因标记"的临床试验，打开了临床应用的大门
- **1990 年**：临床基因治疗正式被批准
- **1990 年 9 月**（里程碑事件）：美国国立卫生研究院（NIH）将腺苷脱氨酶（ADA）基因利用反转录病毒成功导入一名因 ADA 基因缺陷导致重症联合免疫缺陷（SCID）的 4 岁女孩的 T 淋巴细胞，并取得显著治疗效果——这是人类历史上第一例成功的基因治疗
- 随后几年内，美国 FDA 批准了超过 100 个基因治疗临床方案，中国也在此阶段开始系统性的基因治疗研究

**第三阶段（1996 年至今）：成熟期（历经挫折后的重新崛起）**

- **1999 年**（重大挫折）：美国宾夕法尼亚大学报道首例死于基因治疗的患者（Jesse Gelsinger，因腺病毒载体引发的严重免疫反应死亡），导致全球基因治疗临床研究的暂停和严格审查
- **2000 年代**：逆转录病毒整合位点引起的插入突变致癌事件（X-SCID 患者中出现白血病样疾病）进一步推动载体安全性改进
- **持续投入**：美国每年基因治疗研究投入超过 **10 亿美元**，推动技术快速迭代
- **2012 年**：欧盟批准首个商业化基因治疗产品 **Glybera**（AAV1-LPL，脂蛋白脂肪酶缺乏症）
- **2017 年**：FDA 批准 Kymriah（CAR-T）和 Luxturna（AAV2 视网膜基因疗法），基因治疗进入商业化快车道
- **2019 年**：Zolgensma（AAV9-SMN1，脊髓性肌萎缩症）获批，成为当时全球最贵药物
- **当前**：AAV 基因疗法、慢病毒基因修正、CRISPR 体内基因编辑等多条技术路线并行推进，血友病、遗传性视网膜病变、溶酶体贮积症等领域已有多款获批产品

:::

## 单抗药物的核心热门靶点：PD-1/PD-L1、CD20、TNF-α、VEGF 与 EGFR

:::answer

**靶点选择的核心逻辑**

优质单抗靶点通常需满足：在疾病（肿瘤/炎症）中具有关键致病作用、表达具有选择性（疾病组织高于正常组织）、可被抗体有效接触（胞外域可及）、结合后能产生明确的生物学效应（阻断、激活或清除）。

**靶点一：PD-1 / PD-L1（免疫检查点）**

**生物学背景**

PD-1（程序性死亡受体-1）是表达于激活 T 细胞表面的抑制性受体，其配体 PD-L1（程序性死亡配体-1）在多种肿瘤细胞及肿瘤相关免疫细胞上过表达。PD-1/PD-L1 结合后导致 T 细胞功能抑制（"刹车"效应），使肿瘤细胞逃避免疫清除。

**治疗策略**

- **抗 PD-1 抗体**：阻断 PD-1 受体（T 细胞侧），解除 T 细胞抑制；代表药物：Nivolumab（O药）、Pembrolizumab（K药）、国内信迪利单抗、特瑞普利单抗等
- **抗 PD-L1 抗体**：阻断 PD-L1 配体（肿瘤细胞侧）；代表药物：Atezolizumab、Durvalumab

**靶点二：CD20（B 细胞表面标志物）**

**生物学特征**

CD20 是人类 B 淋巴细胞表面的特有标志，对 B 细胞增殖和分化具有调节作用，仅表达于：

- 未成熟 B 淋巴细胞、成熟 B 淋巴细胞、激活 B 淋巴细胞
- **不表达于**：浆细胞、淋巴多能干细胞及其他非 B 细胞组织

**作为 ADC/单抗靶点的优势**

- 超过 **95%** 的 B 细胞淋巴瘤均有 CD20 表达
- 与抗体结合后**不易脱落**（低内化率），有利于 CDC/ADCC 效应充分发挥
- 由于正常 B 细胞功能可通过浆细胞代偿，靶向 CD20 的毒性相对可接受
- 代表药物：利妥昔单抗（Rituximab）、奥法木单抗（Ofatumumab）、奥滨尤妥珠单抗（Obinutuzumab）

**非肿瘤应用**：基于 CD20 在免疫通路中的作用，抗 CD20 单抗同样用于类风湿关节炎、多发性硬化等自身免疫疾病。

**靶点三：TNF-α（肿瘤坏死因子-α）**

**生物学背景**

TNF-α 是炎症反应的强效诱导剂，主要由活化的巨噬细胞和单核细胞产生，处于炎症级联反应的**上游启动阶段**，介导多种炎性疾病并诱导组织破坏。

**治疗应用**

TNF-α 抑制剂通过高亲和力、特异性结合 TNF-α，阻断其与细胞表面 TNF-α 受体的结合，从而抑制 TNF-α 生物活性：

| 靶向 TNF-α 药物类型    | 代表产品                   | 结构类型          |
| ---------------------- | -------------------------- | ----------------- |
| 全人源单抗             | Adalimumab（阿达木单抗）   | 完整 IgG1         |
| 人源化单抗             | Infliximab（英夫利昔单抗） | 嵌合 IgG1         |
| Fc 融合蛋白（受体-Fc） | Etanercept（依那西普）     | TNFR2-Fc 融合蛋白 |

**适应症**：类风湿关节炎（RA）、强直性脊柱炎（AS）、银屑病（PS）、克罗恩病、溃疡性结肠炎等多种自身免疫性疾病。

**靶点四：VEGF（血管内皮生长因子）**

**生物学背景**

VEGF（又称血管通透因子 VPF）是高度特异性的促血管内皮细胞生长因子，参与肿瘤血管新生的核心调控，同时与多种疾病（癌症、炎性疾病、糖尿病视网膜病变等）的发病和进展密切相关。

**治疗策略**

- 抗 VEGF 单抗（如 Bevacizumab/贝伐珠单抗）：直接结合并中和 VEGF，阻断肿瘤新生血管形成
- VEGF 受体 Fc 融合蛋白（如 Aflibercept/阿柏西普）：模拟 VEGF 受体胞外域，竞争性捕获 VEGF

**靶点五：EGFR（表皮生长因子受体）**

**分子特征**

EGFR 是 HER（ErbB）受体家族成员之一，属于酪氨酸激酶型跨膜受体。与配体结合后由单体转化为二聚体，激活胞内 RAS-MAPK、PI3K-AKT 等下游通路，驱动细胞增殖与存活。在多种实体肿瘤（结直肠癌、头颈部鳞癌、非小细胞肺癌等）中存在 EGFR 高表达或异常激活。

**单抗治疗机制**

抗 EGFR 单克隆抗体与 EGFR 胞外域特异性结合，通过：

- 竞争性阻断内源性配体（EGF、TGF-α）与受体的结合
- 诱导受体内化和降解
- 介导 ADCC 效应（尤其是 IgG1 类抗体）

发挥综合抗肿瘤效力。代表药物：Cetuximab（西妥昔单抗）、Panitumumab（帕尼单抗）、国产尼妥珠单抗。

## 疫苗的定义、分类体系与免疫保护原理

:::answer

**定义**

疫苗（Vaccine）是指为预防和控制传染病的发生、流行，用于人体预防接种的**疫苗类预防性生物制品**。生物制品的原料来源包括微生物或其毒素、酶，以及人或动物的血清、细胞等，用于制备供预防、诊断和治疗使用的制剂。

**疫苗的广义分类体系**

| 来源/原料              | 类别名称                  | 举例                             |
| ---------------------- | ------------------------- | -------------------------------- |
| 细菌                   | 菌苗（Bacterial Vaccine） | 卡介苗（BCG）、百白破疫苗（DPT） |
| 病毒、立克次体、螺旋体 | 病毒疫苗（Viral Vaccine） | 流感疫苗、HPV 疫苗、新冠疫苗     |
| 细菌毒素（减毒或灭活） | 类毒素（Toxoid）          | 破伤风类毒素、白喉类毒素         |

**按供应与接种政策分类（中国）**

| 类别                             | 获取方式                     | 代表品种                                                 |
| -------------------------------- | ---------------------------- | -------------------------------------------------------- |
| **第一类疫苗**（免疫规划疫苗）   | 政府免费提供，公民应依规接种 | 卡介苗、脊髓灰质炎疫苗、百白破疫苗、麻风疫苗、乙肝疫苗等 |
| **第二类疫苗**（非免疫规划疫苗） | 公民自费自愿接种             | 流感疫苗、HPV 疫苗、带状疱疹疫苗、肺炎球菌疫苗等         |

**免疫保护原理**

疫苗的核心机制是利用病原体的抗原性但去除其致病性，诱导机体产生**主动免疫记忆**：

```
接种疫苗（含无害抗原）
    ↓
抗原提呈细胞（DC）处理抗原 → 激活 B 细胞和 T 细胞
    ↓
B 细胞分化为浆细胞（产生特异性抗体）+ 记忆 B 细胞
T 细胞分化为效应 T 细胞 + 记忆 T 细胞
    ↓
抗体和免疫细胞对抗原产生保护性免疫应答
    ↓
再次接触真实病原体时
    ↓
记忆细胞快速大量增殖 → 在病原体致病前迅速清除
```

**关键免疫产物**

- 特异性中和抗体（IgG、IgA）
- 效应 T 细胞（CD8+ 细胞毒性 T 细胞）
- 免疫记忆细胞（长期保护）

:::

## 疫苗的重要性与技术演进：从天花根除到 mRNA 疫苗革命

:::answer

**疫苗的历史战略价值**

人类与传染病斗争的历史证明，**预防优于治疗**，接种疫苗是控制乃至消灭传染病最行之有效的公共卫生手段。

**里程碑事件**

- **天花的消灭**：牛痘疫苗的推广使天花成为人类历史上唯一通过疫苗接种彻底消灭的传染病（WHO 1980 年宣布消灭），这是疫苗史上最伟大的胜利
- **脊髓灰质炎的控制**：全球脊灰疫苗接种计划使野生株脊髓灰质炎病毒感染病例下降超过 **99.9%**，多数地区已实现消灭

**疫苗技术代际演进**

| 代次     | 类型         | 原理                                             | 代表产品                          | 优缺点                                   |
| -------- | ------------ | ------------------------------------------------ | --------------------------------- | ---------------------------------------- |
| 传统疫苗 | 减毒活疫苗   | 病原体经体外传代减毒，保留免疫原性但失去致病性   | 卡介苗、脊灰口服疫苗（OPV）       | 免疫效果好，但存在回复突变风险           |
| 传统疫苗 | 灭活疫苗     | 物理/化学方法杀灭病原体，保留抗原结构            | 流感灭活疫苗、乙肝灭活疫苗        | 安全性高，但免疫原性相对较弱，需多次接种 |
| 新型疫苗 | 亚单位疫苗   | 仅使用病原体特定蛋白抗原                         | HPV 疫苗（VLP）、重组乙肝疫苗     | 高度安全，但通常需佐剂增强免疫原性       |
| 新型疫苗 | 病毒载体疫苗 | 用无致病性病毒载体（腺病毒等）递送抗原基因       | AstraZeneca 新冠疫苗（ChAdOx1）   | 可诱导细胞免疫，但预存免疫可能降低效果   |
| 新型疫苗 | mRNA 疫苗    | 将编码抗原的 mRNA 递送入体内，由细胞自行生产抗原 | Pfizer/BioNTech、Moderna 新冠疫苗 | 开发周期极短，安全，但储存要求高         |
| 新型疫苗 | DNA 疫苗     | 质粒 DNA 编码抗原基因，在体内转录翻译            | 多款在研疫苗                      | 稳定性好，但转染效率待提升               |

目前全球用于人类疾病防治的疫苗已超过 **30 种**，覆盖细菌性和病毒性传染病，新型疫苗平台（尤其是 mRNA 和病毒载体技术）的突破正在大幅压缩新疫苗的研发周期。

## 疫苗研发的全流程：从免疫原获取到上市注册的两阶段路径

:::answer

**研发周期概述**

传统疫苗从概念到上市通常需要 **10～15 年**，而 mRNA 等新平台技术（以新冠疫苗为例）将这一周期压缩至不足 **1 年**，但各临床阶段的核心监管要求基本一致。

**第一阶段：疫苗前期研发**

| 步骤               | 内容                                                                        | 关键考量                               |
| ------------------ | --------------------------------------------------------------------------- | -------------------------------------- |
| 免疫原获取         | 活病毒培养分离；纯化蛋白亚单位；基因重组技术表达抗原蛋白；合成 DNA/RNA 序列 | 抗原的免疫原性、稳定性和可规模化生产性 |
| 免疫反应测试       | 体外评估免疫原激活免疫细胞的能力（ELISA、中和抗体试验、T 细胞激活试验）     | 确认免疫原性信号                       |
| 动物保护试验       | 在动物模型（小鼠、豚鼠、非人灵长类）中验证疫苗的保护效力                    | 相关动物模型的选择至关重要             |
| 免疫原生产工艺放大 | 将实验室规模工艺放大至中试和生产规模，优化发酵/培养和纯化工艺               | 工艺放大过程中抗原结构和质量的一致性   |
| 临床前毒理研究     | 系统毒性、局部耐受性、生殖毒性等（按 ICH S5、S6 等指南）                    | 支持首次人体试验剂量选择               |

**第二阶段：临床研究与注册**

| 临床阶段                   | 规模                       | 主要目标                                                         |
| -------------------------- | -------------------------- | ---------------------------------------------------------------- |
| **临床前研究**（IND 申报） | —                          | 汇总所有临床前数据，支持 IND 申报，获得首次人体试验批准          |
| **I 期临床**（安全性）     | 数十人（健康受试者）       | 评估疫苗安全性、耐受性、免疫原性；确定安全剂量范围               |
| **II 期临床**（免疫原性）  | 数百人（目标人群）         | 评估免疫原性（抗体滴度、细胞免疫）；优化剂量、接种程序和佐剂配方 |
| **III 期临床**（有效性）   | 数千至数万人（多中心 RCT） | 评估疫苗对目标疾病的保护效力（VE）和大规模安全性                 |
| **上市注册**（NDA/BLA）    | —                          | 汇总所有数据提交监管机构审批；通过 GMP 生产和质量标准审查        |
| **上市后监测（IV 期）**    | 上市人群                   | 持续监测真实世界有效性和长期安全性；监测罕见不良反应             |

**疫苗注册的特殊要求**

- 须建立免疫原性替代终点（Surrogate Endpoint）的相关性证据（如中和抗体滴度与保护效力的相关性）
- 生产工艺须经 GMP 认证，成品须通过官方批签发
- 佐剂（如铝佐剂、AS04、AS01B、MF59 等）须单独进行安全性评估

## mRNA 疫苗的原理、核心优势与技术挑战

:::answer

**基本原理**

mRNA 疫苗通过特定的递送系统（通常为脂质纳米颗粒，LNP）将编码靶标抗原的**修饰 mRNA**导入体内。mRNA 进入细胞质后，利用宿主细胞的核糖体翻译体系生产目标抗原蛋白，诱导机体产生特异性免疫应答，从而获得对病原体的保护性免疫。

**与传统疫苗的根本差异**

| 特性           | mRNA 疫苗                                   | 传统灭活/亚单位疫苗 |
| -------------- | ------------------------------------------- | ------------------- |
| 抗原来源       | 体内自行合成（细胞翻译）                    | 体外生产后注射      |
| 是否含病毒成分 | 否（无感染风险）                            | 部分含（灭活病毒）  |
| 是否整合基因组 | 否（mRNA 在细胞质中发挥作用，不进入细胞核） | 否                  |
| 诱导免疫类型   | 体液免疫 + 细胞免疫（双重机制）             | 主要体液免疫        |

**五大核心优势**

| 优势               | 说明                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| **研发周期极短**   | 一旦获得病原体基因序列，mRNA 序列设计可在数天内完成；COVID-19 疫苗从序列公布到首次人体试验仅耗时约 66 天 |
| **快速应对变异**   | 针对病毒新变株，只需更新 mRNA 序列，生产工艺无需大幅改动                                                 |
| **安全性高**       | 不含活病毒，无感染风险；mRNA 自然降解，不整合至基因组                                                    |
| **免疫原性强**     | 同时诱导 B 细胞（抗体）和 CD8+ T 细胞（细胞毒性）双重免疫应答，通常无需佐剂                              |
| **易于规模化生产** | 基于体外转录（IVT）工艺，生产工艺相对标准化，适合快速扩产                                                |

**关键技术要素**

**mRNA 结构优化**

- **5' 帽子结构（m7G Cap）**：防止 mRNA 被核酸酶降解，并促进翻译起始
- **5' 和 3' 非翻译区（UTR）**：优化 mRNA 稳定性和翻译效率
- **密码子优化**：将病原体密码子替换为人类细胞偏好的密码子，提高翻译效率
- **核苷修饰**（如 N1-甲基假尿嘧啶，m1Ψ）：Karikó 和 Weissman 的关键发现，降低 mRNA 的固有免疫原性，减少炎症反应，提高翻译水平

**递送系统（LNP）**

脂质纳米颗粒（LNP）是 mRNA 疫苗的核心递送载体，由四种脂质组成：可电离脂质（pH 依赖性正电荷，促进内体逃逸）、磷脂（结构稳定）、胆固醇（膜稳定性）、PEG-脂质（防止聚集，延长循环）。LNP 的粒径（通常 80～100 nm）、封装效率和表面性质直接影响 mRNA 的递送效率和免疫应答质量。

**主要技术挑战**

- **低温储存要求**：mRNA 稳定性对温度敏感，需要超低温（-70°C）或冷链（2～8°C）储存，给全球供应链带来挑战
- **LNP 的局部副反应**：注射部位疼痛、红肿等，与 LNP 的炎症反应有关
- **心肌炎风险**：在年轻男性中观察到罕见的心肌炎事件（发生率约 1/10000），机制尚不完全明确
- **非传统抗原的适用性**：对于需要翻译后修饰（如复杂糖基化）的抗原，mRNA 疫苗的应用受到限制

## ADC 药物的作用机制全解析：六步靶向递送与旁观者效应

:::answer

**ADC 作用机制概述**

ADC 药物的设计精髓在于将"导弹"（抗体靶向）和"弹头"（细胞毒素）整合为一体，实现对肿瘤细胞的精准杀伤，同时最大限度地保护正常组织。其完整作用过程分为六个关键步骤：

**第一步：静脉注射进入血液循环**

ADC 药物口服生物利用度极低（蛋白质类药物消化道降解），须采用**静脉注射**给药。由于 ADC 分子量大（约 150 kDa），在体内循环方式与普通单抗相似，依赖 FcRn 介导的再循环维持较长半衰期（通常 1～3 周）。

**第二步：抗体特异性识别结合靶抗原**

ADC 的抗体部分在肿瘤组织处与靶细胞表面特异性抗原结合，形成 ADC-抗原复合物。结合的特异性和亲和力决定了 ADC 在肿瘤和正常组织间的分布差异，是安全窗口的关键决定因素。

**第三步：受体介导的内吞（Internalization）**

ADC-抗原复合物通过受体介导的内吞作用被肿瘤细胞摄入，形成早期内体（Early Endosome）。内吞效率（Internalization Rate）是 ADC 疗效的关键参数——低内化效率的靶点不适合作为 ADC 靶点。

**第四步：FcRn 介导的再循环（针对非靶向摄取的缓冲机制）**

部分 ADC 被正常细胞（如内皮细胞）误吞后，在早期内体中与 FcRn（新生 Fc 受体）结合，通过胞内体途径被转运回细胞外（胞吞-转运），不进入溶酶体降解途径，从而避免正常细胞受到 Payload 损伤。这是 ADC 系统毒性的一道天然缓冲机制。

**第五步：溶酶体降解与 Payload 释放**

内体沿内化途径逐步酸化（早期内体 → 晚期内体 → 溶酶体，pH 从 6.5 降至 4.5），并富集蛋白酶。在溶酶体环境中：

- **可裂解 Linker**：在特定 pH/蛋白酶/还原剂条件下断裂，释放游离活性小分子 Payload
- **不可裂解 Linker**：抗体在溶酶体中被蛋白酶完全降解，释放含氨基酸的 Payload 衍生物

**第六步：细胞毒效应与旁观者效应**

活性 Payload 从溶酶体逸出进入细胞质，作用于特定胞内靶点：

- **微管蛋白抑制剂（MMAE、DM1 等）**：抑制微管聚合，阻止有丝分裂，诱导 G2/M 期停滞和细胞凋亡
- **DNA 损伤剂（DXd、卡奇霉素等）**：造成 DNA 双链断裂或交联，激活 DDR（DNA 损伤应答）通路，诱导细胞死亡

**旁观者效应（Bystander Effect）**

部分亲脂性 Payload（如 MMAE、DXd）在杀死靶细胞后可**穿透细胞膜**，扩散至周围肿瘤细胞并发挥杀伤作用。旁观者效应的意义：

- 弥补肿瘤内抗原表达异质性（靶抗原阴性的肿瘤细胞也可被杀伤）
- 对实体瘤（抗原表达不均一）尤为重要
- 不可裂解 Linker 的 ADC 旁观者效应弱，更适合抗原表达均一的肿瘤

:::

## ADC 药物开发的技术难点与系统性解决策略

:::answer

**为什么 ADC 开发如此困难**

ADC 概念提出逾百年，但真正进入成熟商业化阶段不过十余年，核心原因在于其开发难度极高——需要同时满足体循环稳定性、靶向选择性、胞内释药效率和强效杀伤四个相互制约的要求。

**五大核心技术难点逐一解析**

**难点一：靶细胞表面抗原的识别与结合**

- **挑战**：对靶抗原的密度和肿瘤特异性要求极高；低密度靶点导致 ADC 结合量不足，无法达到有效胞内药物浓度
- **解决策略**：
  - 靶点选择优先考虑高表达密度（建议 > 10⁵ 个受体/细胞）
  - 采用伴随诊断（CDx）筛选高表达患者，精准富集获益人群
  - 选择高亲和力抗体，但注意避免"结合位点屏障效应"（过高亲和力导致肿瘤边缘结合饱和）

**难点二：ADC 内化效率**

- **挑战**：ADC 须被细胞高效内化才能完成胞内释药；内化效率低下直接降低疗效
- **解决策略**：
  - 靶点筛选阶段即纳入内化效率评估（流式细胞术追踪 ADC-荧光标记物的胞内转运）
  - 选择具有已知高内化率特性的靶抗原（如 HER2、CD79b、TROP2）
  - 研究抗体表位对内化效率的影响（同一靶点不同表位的内化效率可差异显著）

**难点三：Payload 从溶酶体的高效逃逸与释放**

- **挑战**：溶酶体降解不完全，或 Payload 在溶酶体中被进一步代谢失活，导致有效 Payload 量不足
- **解决策略**：
  - 选择耐溶酶体环境的 Payload 分子（在酸性和蛋白酶环境中保持活性）
  - 优化 Linker 裂解动力学，确保快速、高效释放
  - 采用可促进内体逃逸的功能性辅料

**难点四：Payload 的胞内靶点到达与杀伤效力**

- **挑战**：Payload 须在释放后快速到达其作用靶点（微管蛋白、DNA 等），并具有足够强的毒性
- **解决策略**：
  - 选择高效 Payload（IC₅₀ 在 nM～pM 级别）
  - 确保 Payload 不被细胞内的 ABC 转运蛋白（如 P-gp）主动外排（耐药机制）
  - 对于 P-gp 过表达的耐药肿瘤，选择非 P-gp 底物类 Payload（如 PBD、DXd）

**难点五：旁观者效应的实现与控制**

- **挑战**：旁观者效应是把双刃剑——既可扩大抗肿瘤杀伤，也可能伤及周围正常细胞
- **解决策略**：
  - 对于抗原表达异质性高的肿瘤（如实体瘤），优先选择具有旁观者效应的亲脂性 Payload
  - 对于系统毒性风险高的场景，选择膜穿透能力弱的极性 Payload，限制旁观者效应范围

**ADC 靶点选择的综合约束条件**

ADC 靶点须同时满足以下特性（与普通单抗靶点相比要求更严格）：

| 约束条件             | 具体要求                               | 原因                                                    |
| -------------------- | -------------------------------------- | ------------------------------------------------------- |
| 位置                 | 仅限于**细胞表面膜蛋白**               | 须被抗体识别且支持内化，胞内或分泌型靶点不适用          |
| 表达特异性           | 肿瘤高表达 / 正常组织极低表达          | Payload 毒性极强，微量脱靶即可致严重毒性                |
| 内化能力             | 高效、快速内化                         | 确保足够胞内药物浓度                                    |
| 抗原脱落（Shedding） | 抗原脱落率低                           | 高脱落率导致大量 ADC 在血液中与脱落抗原结合而失去靶向性 |
| 抗体可及性           | 无空间位阻，抗体可充分接触抗原结合位点 | 确保抗体结合效率                                        |

正是这些严苛的靶点选择标准，导致目前已上市和主要在研 ADC 产品的靶点高度集中（HER2、TROP2、CD79b、FOLR1、CD33、CD22 等），新靶点的开发验证是 ADC 领域的重大挑战和差异化竞争机会。

:::

## ADC 靶抗原的选择策略：表达水平、脱靶毒性与内化特性的综合评估

:::answer

**核心选择原则**

ADC 靶抗原的选择是整个 ADC 开发项目成败的基础决策，需综合平衡以下核心目标：

- **效力（Efficacy）**：肿瘤细胞上足够高的抗原表达密度，确保 ADC 有效递送
- **选择性（Selectivity）**：肿瘤 vs. 正常组织的表达差异足够大，确保治疗窗口
- **可递送性（Deliverability）**：支持高效内化和胞内 Payload 释放

**关键评估维度一：靶标表达水平**

抗原表达量需超过一定的**活性阈值**，ADC 才能产生有效的细胞毒作用：

| 影响表达阈值的因素       | 说明                                                     |
| ------------------------ | -------------------------------------------------------- |
| 特定靶点本身的生物学特性 | 不同靶点的信号放大效率不同                               |
| 识别的抗原表位           | 同一靶点不同表位对抗体结合和内化的影响不同               |
| 癌症适应症               | 同一靶点在不同肿瘤类型中表达量可差异数倍至数十倍         |
| Payload 效力             | 高效 Payload（pM 级 IC₅₀）可在较低靶点密度下实现有效杀伤 |

**实体瘤的特殊挑战**：实体瘤内抗原表达常呈高度异质性（肿瘤内不同细胞克隆间表达差异显著），靶点表达阈值效应在实体瘤中尤为明显，旁观者效应因此对实体瘤 ADC 尤为关键。

**关键评估维度二：脱靶毒性与抗原脱落**

**抗原脱落（Antigen Shedding）**的定义：靶抗原从细胞表面经蛋白酶（如 ADAM 家族蛋白酶）介导裂解，以可溶性形式释放入血清，作为一种生理调节机制。

| 抗原脱落的影响 | 机制                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------- |
| ADC 疗效降低   | 血液中的游离可溶性抗原与 ADC 抗体结合，形成无效的 ADC-可溶性抗原复合物，阻止 ADC 到达肿瘤细胞 |
| PK 改变        | ADC-抗原免疫复合物的清除速率与游离 ADC 不同，影响 PK 预测                                     |
| 对治疗窗的影响 | 高脱落率抗原的 ADC 可能需要更高剂量，增加系统毒性风险                                         |

**脱靶毒性的来源**

- **靶点依赖性脱靶毒性**（On-target/Off-tumor Toxicity）：正常组织也表达靶抗原，ADC 结合后诱导 Payload 释放，造成正常组织损伤
- **非靶点依赖性脱靶毒性**（Off-target Toxicity）：Payload 提前从 Linker 脱落，在肿瘤外释放，造成系统毒性（如骨髓抑制、肝毒性）

**关键评估维度三：内化特性与受体生物学**

| 评估参数                         | 方法                                               | 理想值                                |
| -------------------------------- | -------------------------------------------------- | ------------------------------------- |
| 内化速率（Internalization Rate） | 流式细胞术（荧光标记 ADC 的胞内化动力学）          | 快速（< 2 h 即可检测到显著内化）      |
| 内化效率                         | 胞表面残余 ADC vs. 胞内 ADC 比值                   | 高效率（> 70% ADC 在数小时内内化）    |
| 溶酶体路径                       | 共聚焦显微镜追踪 ADC 与 LAMP1/LysoTracker 的共定位 | ADC 须最终到达溶酶体                  |
| 受体循环（Receptor Recycling）   | 抗体结合后受体是否重新回到细胞表面                 | 低循环率（避免反复释放 ADC 至细胞外） |

**靶抗原评估的完整框架**

```
靶点发现（基因组学/蛋白质组学数据挖掘）
    ↓
肿瘤 vs. 正常组织表达谱分析（IHC、RNA-seq、蛋白质图谱数据库）
    ↓
靶点验证（细胞系 / PDX 模型中的抗原表达和功能确认）
    ↓
内化效率评估（流式 / 共聚焦显微镜）
    ↓
抗原脱落评估（ELISA 检测细胞培养上清中的可溶性抗原）
    ↓
正常组织安全性评估（人体组织芯片 IHC）
    ↓
靶点成药性综合评分 → 进入抗体筛选阶段
```
