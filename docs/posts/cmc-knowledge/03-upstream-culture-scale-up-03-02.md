## 抗体一级结构（氨基酸序列）的鉴定与质控要点

:::answer

### 核心定义

抗体药物的一级结构即完整氨基酸序列，是生物活性与临床疗效的分子基础。对于<strong>生物类似药（Biosimilar）</strong>开发而言，确保氨基酸序列与原研参比药（RDP）高度一致，是相似性评价的首要前提。

### 鉴定方法

标准鉴定流程如下：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 蛋白酶切 | LysC、AspN 或 GluC | 根据切割位点选择酶种，覆盖不同肽段 |
| 液相分离 | 反相 HPLC | 实现肽段高分辨分离 |
| 质谱鉴定 | LC-MS/MS | 串联质谱获得肽质量图谱，确认序列覆盖度 |
| 数据分析 | 肽质量图谱比对 | 与理论序列及参比品比对，定位差异位点 |

### 关键要点

- **序列覆盖度要求高：** 通常要求 > 95% 的氨基酸序列得到质谱数据支持。
- **差异位点定位精确：** 如曲妥珠生物类似药经肽质量图谱分析，可将分子量差异精确定位至胰蛋白酶酶切肽段 T35。
- **早期筛选同样适用：** 在生物类似药开发的克隆筛选阶段，一级结构的突变或改变（如点突变）也可通过质谱技术及时鉴定，避免带入后续开发。
- **与高级结构联动评估：** 一级结构异常往往预示二、三、四级结构的潜在变化，须结合 SEC、CD、DSF 等手段综合判断。

:::

## 氨基酸修饰分析：主要修饰类型、位置鉴定与 CQA 关联

:::answer

### 核心概念

抗体在生产、储存和体内代谢过程中，部分氨基酸残基会发生化学或酶促修饰，这类变化统称为**翻译后修饰（PTM, Post-Translational Modification）**。肽图分析可同时获得修饰类型及其在序列中的精确位置。

### 常见修饰类型汇总

| 修饰类型 | 发生位点 | 驱动因素 | 对活性的潜在影响 |
|----------|----------|----------|----------------|
| 脱酰胺（Deamidation） | Asn、Gln | 高温、碱性 pH | 可能影响结构稳定性与结合活性 |
| 甲硫氨酸氧化（Met Oxidation） | Met（Fc 区为主） | 氧化压力 | 降低 FcRn 结合，影响半衰期 |
| N-糖基化 | Asn-X-Ser/Thr 序列 | 宿主细胞糖基化酶系 | 直接影响 Fc 效应功能与 PK |
| N 端焦谷氨酸环化（pyroGlu） | N 端 Gln/Glu | 自发或酶促 | 通常对活性影响较小 |
| C 端赖氨酸切除（Lys clipping） | Hc C 端 Lys | 宿主细胞羧肽酶 | 通常对活性影响较小，但需监控 |
| 二硫键错配 | Cys 残基 | 氧化还原状态 | 影响结构稳定性与活性 |

### 关键要点

- **CDR 区修饰需重点关注：** 已有研究证实，在加速降解条件下，CDR 区氨基酸的化学修饰（尤其是脱酰胺和氧化）可显著影响抗体亲和力和中和活性，应将其纳入 **CQA（关键质量属性）** 评估体系。
- **修饰比例的定量监控：** 仅鉴定修饰类型不足，还须定量各修饰比例，设定可接受范围并纳入放行检测或稳定性研究。
- **工艺敏感性评估：** 不同批次间修饰比例的变化可用于反向指示工艺一致性，是工艺理解与变更评估的重要工具。

:::

## 细胞生长状态的影响因素全景：过程控制核心变量解析

:::answer

### 核心概念

细胞生长状态是上游工艺表现的综合体现，受**物理、化学和生物**多维因素共同调控。各参数均存在适宜窗口——偏离上限或下限均可能触发细胞凋亡（Apoptosis）或坏死（Necrosis），直接影响活细胞密度（VCD）、细胞比生长速率（μ）及目标蛋白表达量（Titer）。

### 主要影响因素总览

| 因素 | 适宜范围（CHO 为例） | 失控风险 |
|------|---------------------|----------|
| 温度 | 36～38℃ | 高温：蛋白变性、酶失活；低温：代谢降低、生长迟缓 |
| 渗透压 | 290～320 mOsm/kg | 高渗：细胞皱缩；低渗：细胞胀裂 |
| 溶氧（DO） | 20%～80%（通常控制 40%） | 缺氧：酸中毒；过氧：氧化损伤 |
| pH | 6.8～7.4 | 偏酸/碱：酶活改变，代谢紊乱 |
| 二氧化碳（pCO₂） | 5%～10%（约 30～80 mmHg） | 过高：pH 下降，渗透压升高 |
| 搅拌转速 | 取决于反应器规模 | 过快：剪切损伤；过慢：混合不均、DO 不足 |
| 可见光 | 应避免直射 | 引起细胞退变，降低贴壁能力 |
| 紫外线 | 应严格屏蔽 | DNA 损伤，有丝分裂异常 |

> 以上各因素在后续小节中逐一详细展开。在工艺开发阶段，建议通过**风险评估 + 单因素/多因素 DOE 实验**系统鉴定各参数的关键性，并设定合理的控制策略。

:::

## 温度对细胞培养的影响：机制、窗口与工艺意义

:::answer

### 适宜温度范围

哺乳类及禽类细胞体外培养的适宜温度为 **36～38℃**，其中 **37℃** 是最常用的标准条件。

### 温度耐受规律

| 温度区间 | 细胞响应 |
|----------|---------|
| > 0℃，< 25℃ | 代谢受抑，但无不可逆损伤 |
| 25～35℃ | 细胞可存活生长，速度减缓 |
| 37～39℃ | 最适生长区间 |
| 39～40℃（短期） | 有一定损伤，尚可恢复 |
| 41～42℃（持续 1h） | 损伤严重，难以逆转 |
| ≥ 43℃ | 大多数细胞死亡 |
| < 0℃（无保护剂） | 胞外水及胞质结冰，细胞死亡 |
| 液氮（−196℃，含保护剂） | 可长期保存，复苏后生物性状不变 |

> **低温保存要点：** 在培养液中加入**甘油或二甲亚砜（DMSO）**等冷冻保护剂，封入安瓿后置于液氮中，可耐受 −70℃ 以下温度，是细胞长期保存的主要手段。

### 高温损伤机制

高温主要通过以下机制损伤细胞：
- 蛋白质变性与凝固
- 酶的灭活（尤其是参与能量代谢和信号传导的关键酶）
- 类脂质结构破坏，导致膜完整性丧失
- 核分裂（有丝分裂）过程中纺锤体破坏

### 温度对产品质量的影响

温度不仅影响细胞生长，更直接影响**蛋白质量异质性**：

- **较高培养温度** → 蛋白片段增多、酸性变体比例上升，同时影响 N-糖合成关键酶（如 ST6Gal、FUT8）活性，导致糖型谱改变。
- **温度转变策略（Temperature Shift）：** 常见策略为生长期维持 37℃，指数后期/生产期降温至 33～34℃，可在一定程度上提高比生产速率（qP）、降低乳酸堆积，并改善某些糖型分布。
- **纯度与糖型通常为 CQA：** 须对培养温度进行工艺研究并严格控制，纳入工艺控制策略（Control Strategy）。

:::

## 渗透压的调控机制与工艺应用要点

:::answer

### 核心定义

渗透压（Osmolality/Osmotic Pressure）是溶液中溶质粒子（分子和离子）浓度的综合体现，与单位体积溶媒内溶质的分子数和离子数成正比，单位通常为 **mOsm/kg** 或 **Osmo/kg**。

### 细胞对渗透压的响应

| 情境 | 细胞响应 |
|------|---------|
| 高渗溶液 | 细胞失水皱缩，代谢受抑 |
| 低渗溶液 | 细胞吸水膨胀，严重时破裂 |
| 适宜渗透压 | 维持细胞张力，保障正常代谢 |

### 物种与细胞类型的参考范围

| 物种/细胞类型 | 适宜渗透压（mOsm/kg） |
|--------------|----------------------|
| 人血浆（参考值） | 290 |
| 哺乳动物细胞（通用） | 290～300 |
| 人胚肺成纤维细胞 | 250～325 |
| 鼠源细胞 | ~310 |
| 工业细胞培养实践范围 | 260～320 |

### 渗透压的工艺调控意义

- **主要来源：** NaCl 贡献最大，不可忽视其他电解质（氨基酸、糖类、补料组分）的累积效应，尤其是**流加培养后期**渗透压往往持续升高。
- **适当提高渗透压的益处：**
  - 促进细胞向胞外分泌目标蛋白，提高 Titer。
  - 降低蛋白聚集水平。
  - 提升产物的唾液酸（Sialic Acid）含量，有助于改善 PK 特性。
- **生产后期策略：** 通常将渗透压维持在 **350 mOsm/kg 以上**以促进分泌，但须防止过高渗透压引起细胞应激与活力下降。
- **离子平衡的重要性：** 细胞外离子浓度变化影响氨基酸、蔗糖等营养物质的跨膜转运，进而影响细胞基本合成系统，须按比例控制各离子平衡。

:::

## 溶氧（DO）控制策略与 CHO 细胞耐受特性

:::answer

### 氧气的生理作用

氧是细胞有氧代谢的核心底物，参与**三羧酸循环（TCA Cycle）**，通过氧化磷酸化高效产生 ATP，供给细胞生长、增殖与蛋白合成所需能量。

### 供氧方式与工程挑战

- 动物细胞为**好氧生物**，充足氧供是维持细胞活力的前提。
- 氧气在水中溶解度极低（约 0.2 mmol/L at 37℃），须通过**连续通气**（空气/O₂混合）方式持续补充。
- 通气过程中须防止气泡过多导致剪切损伤，通常结合消泡剂（如 Pluronic F-68）使用。

### DO 控制策略

| 参数 | 典型设定 |
|------|---------|
| DO 控制目标 | 40%（空气饱和度） |
| 可接受范围 | 20%～80% |
| 控制方式 | PID 闭环控制（调节通气量/搅拌转速/氧气比例） |
| 最低安全阈值 | > 20%（防止缺氧代谢切换） |

### CHO 细胞的特殊耐受性

- 研究表明，DO 在 **20%～80%** 范围内对 CHO 细胞的生长速率和产品质量无显著影响。
- 过高 DO（> 100%）：可能产生活性氧（ROS），引起氧化应激，影响细胞活力与产品质量。
- 过低 DO（< 20%）：细胞切换为糖酵解供能，乳酸大量堆积，pH 下降。
- 基于以上特性，**DO 通常不被列为关键工艺参数（CPP）**，一般采用平台控制策略即可。

:::

## 可见光与紫外线对细胞的损伤机制及防护要点

:::answer

### 可见光

- 可见光波长范围：**3900～7800 Å（390～780 nm）**。
- 各波段有色光均可引起细胞退变，主要表现为：
  - 延长细胞核分裂间期（G₁/G₂期延长）
  - 显著降低贴壁细胞的黏附能力
  - 长期照射可导致氧化性损伤
- **防护措施：** 体外培养细胞应避免日光直接照射，培养箱及短期储存区域应保持黑暗，培养操作在避光或红光环境下进行。

### 紫外线（UV）

UV 辐射的生物学效应更为显著，取决于辐射剂量和细胞敏感性：

| UV 剂量 | 细胞响应 |
|---------|---------|
| 弱 UV（低剂量） | 耐受能力强的细胞变化不大；敏感细胞出现有丝分裂异常 |
| 中等 UV | 有丝分裂时脱水收缩增加；胞质起泡减少；细胞膜形成水泡 |
| 强 UV | 细胞膨胀、损伤加剧，可导致细胞死亡 |

- **UV 损伤机制：** 主要通过形成**嘧啶二聚体（Thymine Dimer）**损伤 DNA，干扰复制与转录；同时破坏细胞膜磷脂结构。

### 其他辐射类型

| 辐射类型 | 主要效应 |
|----------|---------|
| X 射线 | 明显损伤细胞，导致 DNA 双链断裂 |
| β 射线 | 影响细胞核分裂进程 |
| γ 射线 | 核分裂数减少，出现异常核分裂，可致细胞死亡 |

**实践建议：** 培养操作区域须严格屏蔽 UV，UV 灯消毒须在无细胞状态下进行，且消毒后须充分通风方可操作。

:::

## 搅拌转速的选择原则与工艺放大策略

:::answer

### 搅拌的双重作用

搅拌在生物反应器中承担两项核心功能：
1. **混合（Mixing）：** 均匀分布营养物质、pH 缓冲剂与溶氧，防止局部梯度形成。
2. **传质（Mass Transfer）：** 促进气液界面的氧气溶解（提高 kLa）。

### 搅拌速度的临界平衡

| 转速状态 | 主要风险 |
|----------|---------|
| 过低 | 细胞结团、沉降，DO 分布不均，混合时间过长 |
| 过高 | 泡沫过多，细胞在气液界面受剪切损伤；叶轮区局部剪切过强致细胞破裂 |

### 搅拌放大的核心原则

工业上最常用的放大准则为**等比功率输入（P/V 恒定）**：

$$\frac{P}{V} = \text{const} \Rightarrow N_p \cdot \rho \cdot n^3 \cdot d^5 / V = \text{const}$$

- **P/V（单位体积功率输入）：** 反映混合强度与剪切力水平，是描述搅拌效果的核心参数。
- **混合时间（θ_m）：** 大规模反应器混合时间显著延长，须评估其对 pH、DO 局部梯度的影响。
- **叶端线速度（tip speed）：** 大规模放大时须评估叶端线速度是否超过细胞损伤阈值（通常 < 1.5～2.0 m/s）。

> 不同规模（2L → 200L → 2000L）的搅拌转速须根据上述准则重新计算设定，不能直接沿用小规模参数。更多放大方法详见《生物反应器放大基础知识》专题。

:::

## pH 的生物学基础、适宜范围与细胞培养控制策略

:::answer

### 基本定义

**pH** 是溶液中氢离子活度的负十进制对数，是衡量溶液酸碱程度的无量纲指标：

$$\text{pH} = -\log_{10}[\text{H}^+]$$

pH 源自拉丁语 *"potentia hydrogenii"*（氢的力量），是细胞培养过程中最关键的过程参数之一。

### pH 对细胞的影响机制

- **酶活性：** 细胞内外 pH 变化直接改变酶的构象与活性，影响整个代谢网络。
- **蛋白质结构：** pH 偏离正常范围可导致蛋白质二级结构（α-螺旋、β-折叠）受损，引起不可逆变性。
- **DNA 稳定性：** 极端 pH 可破坏 DNA 双链的氢键，影响复制与转录。
- **膜转运：** 细胞膜上的离子通道与转运体对 pH 高度敏感，pH 异常影响营养物质的跨膜摄取。

### 不同细胞类型的适宜 pH 范围

| 细胞类型 | 适宜 pH 范围 |
|----------|-------------|
| 大多数哺乳动物细胞 | 7.2～7.4 |
| 转化细胞系（如 CHO、HEK293） | 6.8～7.4 |
| 正常成纤维细胞系 | 7.4～7.7 |
| 杂交瘤细胞 | 7.0～7.4 |

### 工艺控制策略

- **缓冲体系：** 常用 NaHCO₃/CO₂ 缓冲对，结合通 CO₂ 量和碱液（NaOH 或 Na₂CO₃）添加实现闭环 PID 控制。
- **pH 对代谢的影响：** 较低 pH（约 6.8～7.0）可在一定程度上抑制乳酸生成；较高 pH 可能加速谷氨酰胺降解产氨。
- **pH 对产品质量的影响：** 酸性/碱性偏移可影响糖基化修饰（尤其是唾液酸水平）、电荷变体分布，须纳入工艺控制策略。

:::

## 提高活细胞密度（VCD）的系统方法

:::answer

### 核心目标

**VCD（Viable Cell Density，活细胞密度）** 是决定上游工艺总产量（Titer × VCD × 培养时间）的核心参数之一。提高 VCD 是增加产量的直接手段。

### 主要策略与方法

**1. 培养基优化**

- **由有血清转向无血清（SFM）：** 传统有血清培养基（FBS 5%～10%）可促进细胞生长，但引入批次差异和安全风险（病毒、TSE 等）；无血清培养基（SFM）在基础培养基（DMEM/F12 等）基础上添加成分明确的血清替代物，在提高可控性的同时可将最大 VCD 提升 **≥ 35%**（析因设计研究数据）。
- **化学成分限定培养基（CDM）：** 所有组分成分和浓度完全明确，利于工艺理解和法规申报，为行业发展方向。
- **补料策略优化（Fed-batch）：** 基于葡萄糖/氨基酸消耗速率设计补料配方和时序，避免营养限制或代谢副产物积累导致的生长抑制。

**2. 工艺参数优化**

- **温度转换（Temperature Shift）：** 生长期 37℃，生产期降温至 33～34℃，延长培养时间，提高最终 VCD 和 Titer。
- **渗透压调控：** 生产后期适当提高渗透压（至 350 mOsm/kg 以上）促进分泌。
- **DO 和 pH 精确控制：** 避免代谢失衡导致的细胞早期凋亡。

**3. 细胞株改造**

- 过表达抗凋亡基因（如 Bcl-2、Bcl-xL）降低细胞凋亡率。
- 代谢工程改造降低乳酸和氨的生成（如敲除 LDHA、GS 增强）。

**4. 灌流/高密度培养模式**

- 采用灌流培养（Perfusion）可实现 VCD > 10⁸ cells/mL，显著超越流加培养的典型峰值（1～3 × 10⁷ cells/mL）。

:::

## 低 pH 孵育法病毒灭活：原理、参数与局限性

:::answer

### 背景：病毒安全性要求

在以哺乳动物细胞（如 CHO）为宿主的抗体生产工艺中，**病毒安全性（Viral Safety）** 是法规（ICH Q5A）强制要求的核心内容，须通过**病毒灭活（Inactivation）+ 病毒去除（Removal）**的组合工艺提供足够的病毒清除能力（通常总计 ≥ 4 log₁₀ 的灭活因子）。

### 低 pH 孵育法（Low pH Inactivation）

**原理：** 利用脂包膜病毒（Enveloped Virus）的囊膜蛋白和衣壳蛋白在酸性条件下发生变性/聚集，导致病毒失去感染性。

**典型工艺参数：**

| 参数 | 典型范围 |
|------|---------|
| pH 范围 | 3.0～4.0 |
| 孵育时间 | 0.5～24 小时 |
| 孵育温度 | 20～37℃ |
| 应用阶段 | Protein A 洗脱液（pH 已较低，适合直接孵育） |

**影响灭活效果的关键因素：**

1. **pH 值：** pH < 3.8 时灭活效果最佳；pH 越低，灭活速率越快，但蛋白变性风险也越高。
2. **缓冲液体系：** 缓冲液组成（如柠檬酸 vs. 乙酸）对灭活效果有显著影响，须在工艺验证中明确。
3. **孵育温度：** 温度越高灭活效率越高；须兼顾目标蛋白的热稳定性。
4. **样品浓度：** 在一定范围内，浓度越低灭活效果越好（粘度低，pH 均匀）。

### 局限性

- **仅对脂包膜病毒有效**（如逆转录病毒、疱疹病毒）；对无包膜病毒（如 Parvovirus B19、腺病毒）无效，须配合**纳滤（Nanofiltration）**等方法。
- **目标蛋白的稳定性风险：** 不同 IgG 亚类/融合蛋白对低 pH 耐受程度不同；低 pH 可能诱导蛋白聚集（二聚体、多聚体），须在工艺开发阶段评估并确认回调 pH 后聚集水平可接受。

:::

## 药物代谢动力学（PK）研究的目的与核心内容

:::answer

### 学科定义

**药物代谢动力学（Pharmacokinetics, PK）** 是定量研究药物在生物体内**吸收（Absorption）、分布（Distribution）、代谢（Metabolism）、排泄（Excretion）**（即 ADME）过程的学科，运用数学模型阐述药物体内动态变化规律。

### 研究目的

PK 研究的核心目的是确定**安全有效**的给药剂量和给药频率：通过描述药物在作用部位的浓度-时间动态关系，为临床用药方案设计提供依据。

### 在药物开发中的地位

PK 研究与**药效学（PD）研究**、**毒理学研究**处于同等重要的地位，是临床前研究（IND 申报）和临床研究（NDA/BLA 申报）的必要组成部分，且通常需开展**PK/PD 联合分析**，建立暴露量-效应关系。

### 药物消除动力学类型

| 类型 | 特征 | 数学描述 |
|------|------|---------|
| **一级消除动力学** | 单位时间消除量与血浆浓度成正比，即"恒比消除" | dC/dt = −k·C |
| **零级消除动力学** | 单位时间内恒定量消除，与浓度无关，即"恒量消除" | dC/dt = −k₀ |

> 大多数抗体药物在低浓度时表现为**靶点介导的药物处置（TMDD）**，在较高浓度时呈现线性一级动力学，须结合非线性 PK 模型（如 Michaelis-Menten 模型）综合分析。

:::

## 药代动力学关键参数详解与临床意义

:::answer

### 核心 PK 参数汇总

| 参数 | 英文/缩写 | 定义 | 临床意义 |
|------|-----------|------|---------|
| **清除半衰期** | t₁/₂ | 血浆药物浓度下降 50% 所需时间 | 决定给药频率和稳态达到时间（约 4～5 个 t₁/₂） |
| **清除率** | CL | 单位时间内被清除的血浆体积 | 反映机体总消除能力，决定维持剂量 |
| **表观分布容积** | Vd | 体内药量与血浆浓度之比 | 反映药物组织分布程度；Vd 大说明组织摄取多 |
| **曲线下面积** | AUC | 浓度-时间曲线积分面积 | 代表全身药物暴露量，是有效性和安全性的核心指标 |
| **峰浓度** | Cmax | 给药后达到的最高血浆浓度 | 评估峰值暴露与毒性风险 |
| **生物利用度** | F | 给药后进入体循环的药物比例 | F = AUC_ev / AUC_iv；评估非静脉给药的吸收效率 |
| **最低有效浓度** | MEC | 产生疗效所需最低浓度 | 决定给药剂量下限 |

### 关键公式

$$t_{1/2} = \frac{0.693}{k_e} = \frac{0.693 \cdot V_d}{CL}$$

$$F_{abs} = \frac{AUC_{ev}}{AUC_{iv}} \times \frac{D_{iv}}{D_{ev}} \times 100\%$$

### 抗体药物 PK 的特殊性

- 单克隆抗体（mAb）的 t₁/₂ 通常为 **7～21 天**，受 FcRn（新生儿 Fc 受体）介导的再循环机制影响。
- 抗原靶点高表达时会发生 TMDD，导致低剂量时 CL 升高（非线性 PK）。
- Fc 糖基化修饰（如岩藻糖基化程度）可影响 FcγRIII 结合，进而影响 ADCC 效应但不直接影响 t₁/₂。

:::

## 药物代谢（生物转化）的器官分布与酶系

:::answer

### 基本概念

**药物代谢（Drug Metabolism）**，又称**生物转化（Biotransformation）**，是指药物进入机体后，在酶（主要是肝脏酶系）的催化下发生化学结构改变的过程，其目的是使药物极性增大，利于从肾脏排泄。

### 代谢的两个阶段

| 阶段 | 类型 | 主要反应 | 主要酶系 |
|------|------|---------|---------|
| **I 相代谢** | 功能化反应 | 氧化、还原、水解 | CYP450 酶系（CYP3A4 最重要） |
| **II 相代谢** | 结合反应 | 葡萄糖醛酸化、硫酸化、乙酰化、甲基化 | UGT、SULT、NAT |

### 代谢器官分布

- **主要器官：肝脏**（肝微粒体 CYP450 酶系最丰富）
- **次要器官：** 肠道（首过效应）、肾脏、肺、血浆（酯酶）、胎盘

### 抗体药物的代谢特殊性

- 单克隆抗体**不经 CYP450 酶系代谢**，主要通过蛋白水解（靶细胞内吞后溶酶体降解、FcRn 再循环）进行处置。
- 抗体药物偶联物（ADC）中的小分子毒素部分通常遵循传统小分子代谢规律，须单独评估。
- 抗体基本不存在传统意义上的"首过效应"，皮下注射的生物利用度通常为 **50%～90%**。

:::

## 动物细胞培养基的组成体系与选择原则

:::answer

### 培养基的战略地位

细胞培养基是上游工艺中最关键的物料之一，直接决定：
- **细胞生长密度（VCD）和活力（Viability）**
- **重组蛋白的表达量（Titer）**
- **产品质量属性（糖型、电荷变体等 CQA）**
- **工艺成本与可控性**

### 培养基的发展历程

| 发展阶段 | 培养基类型 | 特征 |
|----------|-----------|------|
| 早期 | 天然培养基 | 血浆、血清、胚胎提取物；成分不明确 |
| 过渡期 | 含血清培养基（+ FBS） | 添加 5%～10% FBS；成分部分已知 |
| 工业主流 | 无血清培养基（SFM） | 用血清替代物取代 FBS；成分基本明确 |
| 先进阶段 | 化学成分限定培养基（CDM） | 所有成分及浓度完全确定，符合法规要求 |

### 培养基的基本组成

| 组分类别 | 代表成分 | 主要功能 |
|----------|---------|---------|
| **能源与碳源** | 葡萄糖、半乳糖 | 提供 ATP 和碳骨架 |
| **氨基酸** | 必需氨基酸 + 谷氨酰胺 | 蛋白质合成原料，氮源 |
| **无机盐** | Na⁺、K⁺、Ca²⁺、Mg²⁺、Cl⁻、HCO₃⁻ | 维持渗透压、pH 和细胞功能 |
| **微量元素** | Fe、Zn、Cu、Se、Mo 等 | 酶辅因子，调节代谢通路 |
| **维生素** | B 族维生素、维生素 C | 辅酶、抗氧化保护 |
| **缓冲液** | NaHCO₃/CO₂、HEPES | 维持 pH 稳定 |
| **生长因子** | EGF、IGF-1、FGF 等 | 促进细胞增殖与存活 |
| **脂类** | 胆固醇、脂肪酸、磷脂 | 细胞膜合成原料 |
| **水** | 注射用水（WFI）或超纯水 | 溶剂基础 |

> 商业化培养基配方通常为**商业机密**，不可直接获取。工艺开发中须通过基础培养基出发，结合 DOE 系统优化，积累工艺理解。

## 葡萄糖代谢调控：乳酸积累机制与工艺优化策略

:::answer

### 葡萄糖的双重角色

葡萄糖是动物细胞培养最重要的**碳源和能源**，添加量通常在 **5～25 mM** 之间。

### 主要代谢途径

```
葡萄糖
  ├── 糖酵解（约70~80%）→ 丙酮酸 → 乳酸（主要产物）
  ├── TCA循环（约20~30%）→ CO₂ + H₂O + ATP
  └── 戊糖磷酸旁路 → NADPH + 核糖-5-磷酸
```

### 乳酸积累的危害

- 培养基 pH 下降（乳酸为弱酸）
- 渗透压升高（渗透压补偿需加碱）
- 直接抑制细胞生长（高浓度乳酸的细胞毒性）
- 降低营养物质代谢效率（体外条件下约 **95% 的葡萄糖转化为乳酸**）

### 乳酸过度积累的分子机制

1. **NADH 氧化磷酸化受阻：** 氧气供应不足或苹果酸-天冬氨酸穿梭系统（NADH 跨线粒体膜转运）活性低下，NADH 无法有效进入 TCA 循环，细胞激活乳酸脱氢酶（LDH）：丙酮酸 + NADH → 乳酸 + NAD⁺。
2. **关键酶活性低下：** 连接糖酵解与 TCA 循环的酶（丙酮酸脱氢酶复合物 PDC、磷酸丙酮酸羧化酶激酶 PDHK、丙酮酸羧化酶 PC）活性不足，导致两条通路失衡。

### 优化策略

| 策略 | 方法 | 注意事项 |
|------|------|---------|
| 限制葡萄糖供给 | 按需补料，控制残余葡萄糖 < 4 mM | 须防止营养饥饿，需在线监控 |
| 温度转换 | 生产期降温至 33～34℃ | 降低代谢通量，减少乳酸生成 |
| 葡萄糖替代物 | 部分替代为半乳糖、果糖 | 半乳糖代谢速率慢，乳酸生成少 |
| 代谢流向调控 | 流加谷氨酸或天冬氨酸作为 TCA 补底物 | 促进线粒体代谢，减少糖酵解压力 |
| 细胞株改造 | 敲减 LDHA 或过表达 PDC | 需评估对生长和表达的综合影响 |

:::

## 氨基酸在细胞培养中的分类、作用与谷氨酰胺的特殊地位

:::answer

### 氨基酸的分类

| 类型 | 定义 | 代表氨基酸 |
|------|------|-----------|
| **必需氨基酸** | 细胞自身不能合成，须从培养基中直接获取 | His、Ile、Leu、Lys、Met、Phe、Thr、Trp、Val、Cys、**Gln** |
| **非必需氨基酸** | 可由前体物质在细胞内合成 | Ala、Arg、Asn、Asp、Glu、Gly、Pro、Ser、Tyr |

### 氨基酸的核心功能

- **蛋白质合成的直接原料：** 所有氨基酸均为合成目标蛋白不可缺少的底物。
- **能量与氮源：** 部分氨基酸（尤其是 Gln）可作为能量来源和核苷酸合成的氮源。
- **信号调节：** 某些氨基酸（如 Arg）参与信号通路的调控。

### 谷氨酰胺（Glutamine, Gln）的特殊地位

谷氨酰胺是细胞培养中最重要的单一氨基酸，具有以下不可替代的功能：

1. **促进氨基酸膜转运：** 能促进各种氨基酸进入细胞膜。
2. **核酸合成的氮源：** 其含氮基团是嘌呤和嘧啶合成的氮来源。
3. **能量代谢底物：** 参与 ATP（AMP、ADP、ATP）的合成。
4. **维持细胞活力：** Gln 缺乏可导致细胞生长不良甚至死亡。

**谷氨酰胺的不稳定性及应对措施：**

| 问题 | 原因 | 应对策略 |
|------|------|---------|
| 4℃储存 1 周可降解约 50% | 自发水解为焦谷氨酸 + NH₃ | 单独配制，保存于 −20℃，用前添加 |
| 分解产物氨（NH₃）积累 | Gln 代谢及自发降解均产氨 | 替代方案：L-丙氨酰-L-谷氨酰胺（GlutaMAX™），稳定性显著提高 |

:::

## 无机盐的生理功能与培养基渗透压管理

:::answer

### 主要无机盐离子及其功能

| 离子 | 主要功能 |
|------|---------|
| **Na⁺** | 维持渗透压、膜电位；驱动营养物质共转运 |
| **K⁺** | 维持膜电位；参与细胞信号传导 |
| **Ca²⁺** | 细胞间黏附（整合素信号）；酶反应辅因子；信号分子 |
| **Mg²⁺** | 酶反应辅因子（ATP 酶、激酶）；DNA 复制所需 |
| **Cl⁻** | 维持电中性和渗透压平衡 |
| **SO₄²⁻** | 参与含硫氨基酸代谢、蛋白质硫酸化修饰 |
| **PO₄³⁻** | ATP 合成原料；参与 DNA/RNA 骨架构成；缓冲 pH |
| **HCO₃⁻** | 与 CO₂ 共同构成生理缓冲体系，维持 pH |

### 渗透压管理原则

- 标准生理渗透压：**300 mOsm/kg**，适用于绝大多数哺乳动物细胞。
- 细胞可承受范围：**270～330 mOsm/kg**。
- 加盐时须注意：盐类对渗透压贡献显著（NaCl 完全解离，1 mM NaCl → 2 mOsm/kg），添加时须计算总渗透压影响。
- 补料培养后期渗透压逐渐升高是常见现象，须监控并纳入工艺控制。

## 微量元素在细胞培养中的关键作用

:::answer

### 基本特征

培养基中微量元素（Trace Elements）的有效浓度极低，有时低于标准分析仪器（如 ICP-MS 以外的方法）的检测阈值，但其在细胞代谢中扮演不可替代的角色。

### 主要微量元素及其功能

| 微量元素 | 主要功能 |
|----------|---------|
| **铁（Fe）** | 血红素和铁硫簇的核心组分；参与电子传递链；影响糖酵解和 TCA 循环酶活 |
| **锌（Zn）** | 锌指蛋白（转录因子）的结构组分；DNA 修复酶辅因子 |
| **铜（Cu）** | 细胞色素 C 氧化酶、SOD（超氧化物歧化酶）辅因子；影响抗氧化能力 |
| **硒（Se）** | 谷胱甘肽过氧化物酶（GPx）的活性中心；抗氧化应激 |
| **钼（Mo）** | 黄嘌呤氧化酶等的辅因子 |
| **锰（Mn）** | Mn-SOD 辅因子；参与糖基化酶（甘露糖苷酶）活性 |

### 工艺注意事项

- **铁的形态影响可用性：** 游离 Fe²⁺/Fe³⁺ 可通过 Fenton 反应产生活性氧（ROS），通常以络合形式（如柠檬酸铁、硫酸亚铁-EDTA 络合物）添加。
- **培养基中微量元素的批次差异：** 水质（WFI 级别）和原料纯度对微量元素背景值有影响，是培养基批次差异的潜在来源之一。

:::

## 维生素对细胞培养的保护作用与产品质量影响

:::answer

### 维生素的生理功能

维生素是细胞培养基中的**必需微量组分**，即使需求量极少，缺乏时细胞功能会显著受损。其核心功能包括：

- **抗氧化保护：** 高还原能力（如维生素 C、维生素 E）可清除活性氧（ROS），保护细胞膜和 DNA 免受氧化损伤。
- **辅酶功能：** B 族维生素（B₁/B₂/B₃/B₅/B₆/B₇/B₉/B₁₂）作为酶的辅酶，参与能量代谢、氨基酸代谢和核苷酸合成。

### B 族维生素在培养基中的主要成员

| 维生素 | 别名 | 主要代谢功能 |
|--------|------|------------|
| 生物素（B₇） | Biotin | 羧化酶辅因子（脂肪酸合成、TCA 循环） |
| 叶酸（B₉） | Folic Acid | 一碳单位转移（核苷酸合成、甲基化） |
| 肌醇 | Inositol | 磷脂酰肌醇信号分子前体；细胞膜组分 |
| 烟酰胺（B₃） | Niacinamide | NAD⁺/NADP⁺ 前体；能量代谢核心辅酶 |
| 泛酸（B₅） | Pantothenic Acid | CoA 合成前体；脂肪酸代谢 |
| 吡哆醇（B₆） | Pyridoxine | 氨基酸转氨酶辅酶 |
| 核黄素（B₂） | Riboflavin | FAD/FMN 前体；氧化还原酶辅酶 |
| 硫胺素（B₁） | Thiamine | 丙酮酸脱氢酶辅因子（连接糖酵解与 TCA） |
| 钴胺素（B₁₂） | Cobalamin | 甲基转移、叶酸循环 |
| 4-氨基苯甲酸（PABA） | — | 叶酸合成前体 |

### 维生素对产量和质量的影响

- **提高单位产量：** 研究表明，对培养基中全部维生素浓度的优化，可使 CHO 细胞表达 mAb 的单位产量提升 **3 倍以上**；叶酸、钴胺素、生物素和 PABA 对提高细胞生长密度和表达量贡献最显著。
- **影响原液颜色：** 维生素（尤其是核黄素/B₂）是抗体原液产生黄色的主要因素之一，须在工艺开发中关注并控制其引入量。

:::

## 缓冲液体系的组成原理与离子平衡管理

:::answer

### 缓冲液的核心功能

缓冲液（Buffer System）的作用是维持细胞培养过程中 **pH 的动态稳定**，防止代谢副产物（乳酸、CO₂）导致的 pH 剧烈波动。

### 生理溶液中的主要阳离子及其功能

| 阳离子 | 主要功能 |
|--------|---------|
| **Na⁺** | 决定细胞外液渗透压；驱动多种膜转运（葡萄糖、氨基酸共转运） |
| **K⁺** | 决定细胞内液渗透压；维持静息膜电位（Na⁺/K⁺-ATPase） |
| **Ca²⁺** | 细胞间黏附基质（整合素激活）；关键酶反应辅助因子；第二信使 |
| **Mg²⁺** | 稳定 DNA/RNA 结构；ATP 酶、聚合酶等多种酶的辅因子 |

### 主要缓冲体系

| 缓冲体系 | 适用场景 | 特点 |
|---------|---------|------|
| **NaHCO₃/CO₂ 体系** | 密闭/半密闭生物反应器 | 生理相关，但受 pCO₂ 影响大 |
| **HEPES** | 开放式培养（如摇瓶、T 瓶） | 缓冲能力强，不依赖 CO₂；但高浓度有细胞毒性，且不适合大规模使用 |
| **磷酸盐缓冲体系** | 配合特定工艺 | 缓冲范围宽（pH 5.8～8.0），但磷酸根浓度过高影响 Ca²⁺/Mg²⁺ 可用性 |

### 离子平衡的工艺意义

- **Ca²⁺ 和 Mg²⁺ 是细胞黏附的物质基础**，培养基中这两种离子的缺乏会影响细胞间连接和贴壁培养的细胞-基质相互作用。
- **Na⁺ 和 K⁺ 的比例**影响渗透压维持和营养物质的跨膜转运效率；比例失衡可干扰氨基酸、糖类等营养物质的摄取，直接影响细胞基本合成系统。
- **HCO₃⁻ 的工艺挑战：** 流加补料时补入大量富含氨基酸/糖类的补料液会摊薄 HCO₃⁻ 浓度，须通过碱液补加和 CO₂ 精确控制协同维持 pH 稳定。

:::

## 生长因子的分类、作用机制与无血清培养基中的应用

:::answer

### 广义与狭义定义

| 概念范畴 | 定义 | 主要包含内容 |
|----------|------|------------|
| **广义生长因子** | 微生物/细胞正常生长代谢所必需、但不能自行合成的有机小分子和大分子 | 维生素、碱基（嘌呤/嘧啶）、生物素、烟酸及某些氨基酸 |
| **狭义生长因子** | 通过与特异细胞膜受体结合、调节细胞生长与多效功能的多肽类分子 | EGF、IGF、FGF、PDGF、TGF、NGF 等 |

### 主要多肽类生长因子

| 生长因子 | 全称 | 主要功能 |
|---------|------|---------|
| **EGF** | 表皮生长因子（Epidermal Growth Factor） | 促细胞增殖；激活 EGFR/RAS/MAPK 通路 |
| **IGF-1** | 类胰岛素生长因子-1（Insulin-like Growth Factor-1） | 模拟胰岛素信号；促进合成代谢和细胞存活 |
| **FGF（酸性/碱性）** | 成纤维细胞生长因子（Fibroblast Growth Factor） | 促进细胞增殖和分化 |
| **PDGF** | 血小板衍生生长因子（Platelet-derived Growth Factor） | 促进间质细胞增殖 |
| **TGF-α/β** | 转化生长因子（Transforming Growth Factor） | α 亚型促增殖；β 亚型调节分化和免疫抑制 |
| **NGF** | 神经生长因子（Nerve Growth Factor） | 神经元存活与分化（神经元相关细胞培养） |

### 作用机制

生长因子通过以下方式发挥作用：

1. **与高亲和膜受体结合**（多为酪氨酸激酶受体，RTK）。
2. **受体激活后触发下游信号级联**（PI3K/AKT、RAS/MAPK、JAK/STAT 等）。
3. 调控基因表达，促进细胞进入分裂周期（G₀→G₁→S 期）或抑制凋亡。

### 在无血清培养基中的工业应用

| 特性 | 说明 |
|------|------|
| **活性浓度范围** | 1～10 ng/mL（极低用量即有显著效果） |
| **替代血清的功能** | 在 SFM/CDM 中提供血清中相应的促生长信号 |
| **稳定性挑战** | 多肽类生长因子容易降解，储存和使用须注意温度、pH 和蛋白酶活性 |
| **成本考量** | 重组生长因子单价较高，须优化最低有效添加量 |
| **法规要求** | 须选用来源明确、无动物源组分的重组生长因子，以满足 ICH Q5D 等法规要求 |

:::
