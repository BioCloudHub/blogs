## 高浓度单抗制剂的定义、给药优势与商业化背景

:::answer

高浓度单抗制剂（High-Concentration Monoclonal Antibody Formulation）通常指蛋白质浓度超过 **100 mg/mL** 的注射制剂，其开发驱动力来源于皮下给药体积限制与高治疗剂量之间的工程矛盾。

**皮下给药的体积约束**

皮下注射（Subcutaneous Injection, SC）是优于静脉输注的给药方式，可实现患者自我给药，但皮下组织的物理特性限制了单次注射体积：

- 标准皮下注射体积：**≤ 1.5–2 mL**（超过此体积会引起注射部位疼痛、局部积液和吸收率下降）
- 对于需要高剂量治疗的单抗（如自身免疫疾病用单抗剂量 100–300 mg/剂），若蛋白浓度不够高，则无法在 2 mL 内装载足量药物
- 由此倒推蛋白浓度要求：100 mg / 1 mL → 100 mg/mL；300 mg / 1.5 mL → 200 mg/mL

目前已上市的高浓度制剂中，最高蛋白浓度达到 **200 mg/mL**（如阿达木单抗皮下注射高浓度规格）。

**高浓度制剂的多维优势**

| 优势维度 | 具体效益 |
|---|---|
| 患者依从性 | 皮下注射可在家中自行操作，减少医院就诊频次 |
| 患者舒适度 | 注射体积小，注射时间短（通常 < 10 秒） |
| 替代静脉输注 | 降低输液相关不良反应风险；无需静脉置管 |
| 降低医疗费用 | 无需门诊/住院输注，减少医疗资源消耗 |
| 生产成本优化 | 灌装体积减少 → 西林瓶规格降低 → 显著节约包材和灌装成本 |
| 预灌封注射器适配 | 高浓度制剂可直接灌装于预灌封注射器（PFS），进一步提升患者便利性 |

**已批准高浓度单抗制剂的辅料使用频率（FDA 数据）**

在 FDA 批准的 34 个高浓度（≥ 100 mg/mL）制剂中，辅料使用频率的统计数据为处方开发提供了宝贵的先验知识参考：

| 辅料 | 使用频率 | 主要功能 |
|---|---|---|
| 聚山梨酯 80 / 聚山梨酯 20 | **94%** | 表面活性剂，防止界面吸附和剪切力聚集 |
| 组氨酸 | **82%** | 缓冲体系（pH 5.5–6.5），兼具抗氧化作用 |
| 蔗糖 | **48%** | 稳定剂，冻融保护，等渗调节 |
| 精氨酸 | **27%** | 降低黏度，抑制聚集 |
| 氯化钠 | **18%** | 等渗调节，离子强度调节 |
| 甲硫氨酸 | **18%** | 抗氧化剂，保护 Met 残基 |
| 醋酸 | **12%** | 缓冲体系（较低 pH） |
| 海藻糖 | **12%** | 冻干保护剂，热稳定剂 |
| 脯氨酸 | **9%** | 降低黏度，稳定剂 |
| 泊洛沙姆 188 | **6%** | 表面活性剂（替代聚山梨酯） |

## 高浓度制剂的三大核心挑战：溶解度、聚集与黏度的分子机制解析

:::answer

高浓度单抗制剂开发的挑战本质上来源于高分子浓度条件下的**分子间相互作用增强**，三类问题相互关联、相互放大。

**挑战一：蛋白溶解度限制**

溶解度是高浓度制剂的基础约束，决定了目标蛋白浓度是否在物理上可以实现。

溶解度降低的主要分子机制：

- **疏水自缔合（Hydrophobic Self-Association）**：蛋白质表面暴露的疏水斑块（尤其是 CDR 区疏水残基）在高浓度下因分子间碰撞频率增加，通过疏水相互作用形成可逆低聚体，最终导致沉淀
- **带电斑块的静电自缔合**：若蛋白质在某些区域带有高密度的同种电荷补丁，也可能在特定 pH / 离子强度下因静电排斥不足而自缔合
- **构象变化诱导溶解性下降**：氧化、脱酰胺等化学修饰改变局部构象，暴露原本被遮蔽的疏水核心
- **溶液理化性质的调制**：溶解度还受缓冲液组成、离子强度（Hofmeister 效应）、pH（在 pI 附近溶解度最低）和温度的直接影响

低溶解度的后果：影响生物利用度、增加皮下注射部位的局部聚集和潜在免疫原性。

**挑战二：蛋白质聚集**

在高浓度制剂（通常 100–200 mg/mL）中，蛋白质分子间距减小至与分子尺寸相当的范围，分子间相互作用从可忽略变为显著：

- 高浓度条件下蛋白质有效排除体积（Excluded Volume Effect）增加，促进可逆非共价聚集体的形成
- 非共价聚集体由范德华力、氢键、疏水和静电相互作用共同维系，**不涉及一级结构变化**，因此在常规 CE-SDS 中可能被 SDS 解离而低估
- 随浓度进一步增加，可逆聚集体可能转化为不可逆共价聚集体（通过分子间二硫键），成为不可修复的质量缺陷

聚集的外在驱动因素：pH 偏离、离子强度变化、温度升高、机械应力（搅拌、剪切、冻融）。

**挑战三：溶液黏度**

黏度（Viscosity）随蛋白浓度增加呈**指数级**升高，是高浓度皮下注射制剂最突出的工程挑战：

- 皮下注射操作的黏度上限：通常要求 **≤ 20 cP**（厘泊）
- 超过此限值的后果：抽取注射器困难；注射时背压增大，需要更细（高规格）针头；增加患者注射时的痛苦和操作难度
- 黏度的影响因素：蛋白浓度（主要驱动因素）、pH、温度（温度升高黏度降低）、剪切速率（非牛顿流体行为）

**三大挑战的相互关联性**

$$\text{浓度} \uparrow \rightarrow \text{分子间距} \downarrow \rightarrow \text{相互作用} \uparrow \rightarrow \begin{cases} \text{可逆聚集} \uparrow \\ \text{黏度} \uparrow \text{（指数级）}\\ \text{溶解度} \text{（接近极限）} \end{cases}$$

:::

## 应对高浓度制剂挑战的系统性策略：从早期风险评估到处方工程

:::answer

高浓度制剂挑战的应对须贯穿从成药性评估到商业化处方开发的全链路，而非仅在出现问题时被动解决。

**策略一：早期成药性风险评估（风险前置）**

在候选分子进入制剂开发前，通过以下工具评估高浓度成药风险，提前筛选低风险分子或预判需要重点解决的挑战：

- **热稳定性（Tm）**：DSF/DSC 测定，Tm 越高表明构象稳定性越好，聚集阈值越高
- **胶体稳定性（B₂₂ 值）**：通过动态/静态光散射测定第二维里系数，B₂₂ > 0 表明分子间排斥占主导，有利于高浓度稳定；B₂₂ < 0 表明吸引力占主导，高浓度聚集风险高
- **自相互作用强度（CSI-BLI / AC-SINS）**：直接量化分子自缔合倾向，是黏度和溶解度的早期预测指标
- **等电点（pI）**：pI 越接近生理 pH（7.4），在体内的溶解度越低，须调整处方 pH

**策略二：辅料筛选——以先验知识为起点，DoE 为优化工具**

处方开发的起点参考已上市高浓度制剂的辅料使用频率（见上节），在此基础上进行系统优化：

| 辅料类别 | 优先候选 | 主要作用 |
|---|---|---|
| 缓冲液 | 组氨酸（pH 5.5–6.5）、柠檬酸盐 | 维持 pH，防止酸碱降解 |
| 稳定剂 | 蔗糖（5–10%）、海藻糖 | 优化水分子层，防止展开和聚集 |
| 表面活性剂 | PS80（0.01–0.05%）、PS20 | 保护气液界面和机械应力位置 |
| 抗氧化剂 | 甲硫氨酸（0.1–1 mmol/L）、组氨酸 | 保护 Met/Trp 残基免受 ROS 攻击 |
| 黏度降低剂 | 精氨酸（50–150 mmol/L）、脯氨酸、NaCl | 减少分子间静电和疏水相互作用 |

**策略三：剂型选择——液体制剂与冻干制剂的抉择**

- **液体制剂优先**：若高浓度液体制剂在 2–8°C 条件下能满足 18–24 个月的稳定性要求，优先选择液体制剂（成本低、患者使用便捷）
- **冻干制剂的适用场景**：当液体制剂在任何可行处方条件下均无法满足稳定性要求时，转为冻干制剂；冻干制剂去除水分后大幅降低化学降解速率，可有效解决蛋白不稳定问题，但需验证冻干保护剂（蔗糖/海藻糖）对高浓度蛋白的有效保护能力

**策略四：制剂工艺参数优化**

冻融操作、灌装工艺、过滤步骤均可对高浓度蛋白产生额外的机械应力，须系统验证：

- 冻融速率控制（控速冻融 vs. 快速冻融对聚集体的影响）
- 灌装速度和灌针设计（减少局部剪切力）
- 过滤膜材质兼容性（避免蛋白在膜表面吸附导致浓度损失）

:::

## 降低高浓度单抗溶液黏度的辅料策略：机制与风险权衡

:::answer

黏度控制是高浓度皮下注射制剂处方开发的核心工程挑战，需要在有效降低黏度与维持蛋白质稳定性之间寻求平衡。

**三种主要降黏辅料的分子作用机制**

**精氨酸（Arginine，Arg）**

精氨酸是两亲性分子（含胍基侧链和疏水骨架），通过多重机制降低黏度：

- **静电屏蔽**：Arg 的胍基可与蛋白质表面带电残基形成离子对，减少分子间长程静电吸引
- **疏水竞争**：Arg 的疏水骨架与蛋白质暴露的疏水斑块竞争相互作用，减少蛋白质分子间的疏水自缔合
- **氢键形成**：Arg 可与蛋白质骨架形成氢键，改善蛋白质分子的水化层状态

典型使用浓度：**50–150 mmol/L**

**潜在风险：** 精氨酸的胍基结构与强变性剂盐酸胍（GuHCl）结构相似。在高温或长期储存条件下，精氨酸可能：
- 降低蛋白热转变温度（Tm），削弱构象稳定性
- 高温时促进蛋白片段增加（类变性剂效应）

因此须通过强制降解实验（高温、加速稳定性）验证 Arg 在目标浓度和储存条件下对蛋白稳定性的净效应。

**氯化钠（NaCl）**

- 离子型辅料，通过提高溶液离子强度实现**长程静电屏蔽**，降低分子间静电排斥（避免同种电荷引起的应力）或静电吸引（减少异种电荷区域的静电自缔合）
- 适用于因静电相互作用主导黏度升高的分子
- 典型使用浓度：**50–150 mmol/L**

**潜在风险：** 高 NaCl 浓度会提高溶液渗透压（每 100 mmol/L NaCl 贡献约 200 mOsm/kg），在皮下注射体积限制下，须注意渗透压控制在可接受范围（≤ 350–400 mOsm/kg）。

**脯氨酸（Proline，Pro）**

- 脯氨酸的吡咯烷环疏水基团可与单抗暴露的疏水区域形成弱相互作用，占据疏水斑块，降低蛋白质分子间的疏水自缔合
- 同时脯氨酸能减少蛋白质表面对氧化剂的暴露，具有一定的抗氧化保护作用（降低脱酰胺和水解风险）
- 典型使用浓度：**50–200 mmol/L**

**降黏辅料选择的整体策略**

| 评估步骤 | 内容 |
|---|---|
| **1. 黏度-浓度曲线测定** | 测定目标蛋白在基础处方下的黏度-浓度关系，确定黏度超标的浓度阈值 |
| **2. 机制初步判断** | 通过调节 pH 和离子强度的影响，判断黏度主要由静电相互作用还是疏水相互作用驱动 |
| **3. 降黏辅料高通量筛选** | 在小体积（< 0.5 mL）条件下测试 Arg/NaCl/Pro 及其组合的降黏效果 |
| **4. 稳定性兼容性验证** | 对筛选出的低黏度处方进行加速稳定性（40°C，4 周），评估辅料对聚集体、片段和化学修饰的影响 |
| **5. 最终处方确认** | 平衡黏度、稳定性、渗透压和可注射性，确定最优处方 |

## 稳定性试验的目的、法规框架与方案要素

:::answer

**稳定性研究的核心定位**

稳定性试验是贯穿药品研发、临床、上市及上市后质量研究全生命周期的核心活动，直接决定产品有效期的设定，并为生产工艺、制剂处方、包装材料、贮存和运输条件提供科学依据。

对于生物制品，由于蛋白质对温度、湿度、光照等环境因素的敏感性远高于化学小分子药物，稳定性研究的系统性和覆盖深度尤为重要。

**主要法规指南体系**

| 指南 | 核心内容 |
|---|---|
| **ICH Q1A（R2）** | 新原料药和制剂稳定性试验的通用要求（试验条件、批次要求、时间节点） |
| **ICH Q1B** | 光稳定性试验（照度要求、样品暴露量、评价方法） |
| **ICH Q1C** | 新剂型的稳定性试验（相对于已申报剂型的增量要求） |
| **ICH Q1D** | 括号法和矩阵法设计（减少稳定性试验批次和样品的统计学方法） |
| **ICH Q1E** | 稳定性数据的统计评价（有效期的统计学确定方法） |
| **ICH Q5C** | 生物技术/生物制品稳定性试验（生物制品特有要求，如活性测定、生物学活性的稳定性指示性） |
| **国内指导原则** | 《生物制品稳定性研究技术指导原则（试行）》 |

**完整稳定性方案的必备要素**

一份完整的稳定性评价方案须包含以下内容，且在试验开始前须经过充分科学论证：

- 试验类别（影响因素/加速/长期）及各类别的设计原则
- 试验样品的批次数量、来源（原液批次）和规格
- 检测项目清单（须涵盖稳定性指示性方法）
- 试验条件（温度、湿度、光照）和包装容器密闭系统规格
- 取样时间节点安排
- 接受标准和统计分析方法
- 结果分析策略（含降解产物的处理原则）

:::

## 稳定性试验的三类别与样品设计要求

:::answer

**三类稳定性试验的定位**

| 试验类别 | 条件特征 | 核心目的 | 最小批次数 |
|---|---|---|---|
| **影响因素试验（强制降解）** | 极端条件（高温/高光/极端 pH/强氧化/冻融循环） | 揭示固有稳定性弱点，识别降解路径和产物，为方法专属性验证提供样品 | 生物制品直接 **3 批** |
| **加速试验** | 高于实际贮存条件（如 40°C，75% RH） | 加速降解以预测长期稳定性，快速支持制剂决策和早期申报 | **3 批** |
| **长期试验** | 与实际贮存条件一致（如 5°C 或 -20°C） | 建立有效期的直接法律依据 | **3 批** |

**试验样品的批次、包装和规格要求**

**批次要求**

- 上市前稳定性：至少 **3 批** 样品；若发生影响稳定性的变更，须重新取 3 批进行稳定性试验
- 稳定性试验样品须来自不同批次的原液（Different DS Lots），不得使用同一批次原液灌装的多批成品代替三批独立样品

**包装要求**

- 原液或中间体：尽量采用与规模化生产时**相同材质**的容器和密闭系统
- 成品：采用与规模化生产时**相同的包装容器和密闭系统**
- 成品须尽量使用**临近有效期的原液**灌装，以模拟生产过程中可能的最长原液储存情况（最差场景覆盖）

**规格（装量）代表性策略**

对于仅有装量不同的同一品种：

- 原则上不同规格须分别开展稳定性试验
- 在充分论证代表性的前提下，可通过合理实验设计选择极端规格：**最大装量和最小装量**的稳定性结果通常可代表其他中间规格的产品

:::

## 生物制品稳定性试验的关键检测项目：生物活性、纯度与理化参数的层次框架

:::answer

生物制品稳定性试验的检测体系远比化学小分子复杂，须兼顾生物活性、分子完整性和物理化学参数三个维度。

**核心检测项目一：生物学活性 / 效价（最关键指标）**

生物学活性是生物制品稳定性评价的核心指标，因为活性测定能直接反映蛋白质功能构象的保持程度，而理化方法无法完全替代：

- 须与**经标准化的参考品/标准品**比较，以相对效价（Relative Potency, RP）报告
- 稳定性研究中使用的标准品须是经过标定的，且与批次放行检测使用同一批参比品
- 某些生物制品须与结合物解离后才产生活性（如抗体-药物偶联物 ADC），需评估活性成分与结合物的解离程度

**核心检测项目二：纯度（侧重降解/聚集）**

- 须采用**多种不同原理**的分析方法综合评估（如 SEC-HPLC 检测聚集体 + CE-SDS 检测片段 + iCIEF 检测电荷变体）
- 稳定性研究中的纯度检测应侧重于**降解/聚合**情况，而非仅报告初始纯度值
- 降解/聚合产物的限度须基于临床前和临床研究所用批次样品分析结果的**统计总体**来制定
- 若长期稳定性中出现新降解产物，应尽可能进行定性鉴别，并评估其安全性和有效性影响

**其他重要检测项目**

| 检测项目 | 在稳定性研究中的重要性 |
|---|---|
| 含量（蛋白浓度） | 确认储存期间无蛋白损失（如吸附至容器） |
| 外观 / 颜色 | 颜色加深是化学降解的早期信号（见颜色变化章节） |
| 可见异物 | 检测蛋白颗粒形成（目视检查 + 光散射） |
| 不溶性微粒 | 亚可见颗粒（10 μm / 25 μm 分级）定量 |
| pH | 缓冲能力的维持，pH 漂移影响蛋白稳定性 |
| 水分（冻干品） | 残余水分升高会加速降解 |
| 无菌 | 特定稳定性时间点确认无微生物污染 |
| 辅料降解产物 | 若有证据表明辅料降解影响产品质量，须纳入监测（如 PS80 氧化产物） |

**包装容器-密闭系统对稳定性的潜在影响**

稳定性试验须将样品以**倒立、水平、正立**三种放置方式进行，以充分评估液体制剂与密闭系统（胶塞、瓶底）的相互作用。对于多次使用的包装，须模拟实际使用情况（多次开封取样）评估稳定性。

:::

## 稳定性试验条件的全面设计：温度、冻融、运输与包材的协同考察

:::answer

生物制品稳定性试验的条件设计须全面覆盖产品从生产到患者使用全链路中可能遭遇的环境条件。

**各类储存温度的推荐稳定性试验条件**

| 储存类型 | 长期试验 | 加速试验 |
|---|---|---|
| 常温（室温）贮存 | 25°C ± 2°C 或 30°C ± 2°C | **40°C ± 2°C**，75% ± 5% RH |
| 冷藏（冰箱）贮存 | **5°C ± 3°C** | **25°C ± 2°C**，60% ± 5% RH |
| 冷冻（-20°C）贮存 | **-20°C ± 5°C** | 5°C ± 3°C 或 25°C ± 2°C |
| 超低温（-60~-80°C）贮存 | -60 ~ -80°C（依产品特性） | 依具体产品制定合适试验温度 |

**温度试验的设计原则**

- 影响因素试验的温度须能观察到样品失活、变性或发生超出质量标准的降解
- 加速试验温度反映产品**可能短期偏离**贮存条件的情况（如运输中断链）
- 长期试验温度须与实际标签规定的贮存条件一致

**反复冻融稳定性研究**

对需要冷冻保存的原液（DS）和中间产物，须专门开展**多次反复冻融**研究：

- 典型考察：3 次、5 次、10 次冻融循环
- 评估参数：聚集体变化、活性变化、外观变化
- 冻融保护剂（蔗糖、海藻糖）的保护效果须通过此研究验证
- 研究结果为原液冻融次数限制的设定提供数据依据

**运输条件稳定性研究**

生物制品通常要求冷链运输，须开展系统的运输条件模拟试验，考察要素包括：

- 运输路线（国内/国际）、交通工具（陆运/航运/空运）
- 运输温度波动（模拟断链情境）
- 运输时间（最长时间的最差情况覆盖）
- 振动和机械应力（模拟装卸和道路颠簸）
- 对脱离冷链（温度、次数、总时间）的可接受标准设定

**湿度试验的豁免条件**

若能证明包装容器与密闭系统具有**良好的密封性能**（如通过密封完整性检测，如色水法、激光顶空分析等），则不同湿度条件下的稳定性试验可以省略。使用半渗透性容器（如某些塑料注射器）的产品须考虑不同湿度对产品的影响。

:::

## 包材相容性研究：可提取物与浸出物的系统评估框架

:::answer

可提取物（Extractables）与浸出物（Leachables）研究（E&L Study）是评估包装材料和过滤器对药品安全性影响的核心质量研究，须纳入稳定性研究和工艺验证的整体框架。

**核心概念辨析**

| 概念 | 定义 | 获取条件 |
|---|---|---|
| **可提取物（Extractables）** | 在极端条件（溶剂、高温、长时间）下可从包材中被提取出的化学物质 | 最差条件下的极端提取实验 |
| **浸出物（Leachables）** | 在实际产品接触条件下，从包材迁移到药品中的物质 | 真实产品/接近真实条件的浸泡实验 |

可提取物反映浸出物的**最大可能上限**。无论是否开展浸出物研究，可提取物的测试和安全性评估都是**必须进行的**基础工作。

**可提取物试验的设计要点**

- **模型溶剂选择**：须全面评估产品处方，选择与产品相同或相似理化性质（pH、极性、离子强度）的模型溶剂，模拟实际产品对包材的溶出行为
- **试验方法**：静态浸泡法（模拟储存）或循环流动法（模拟工艺过程）
- **最差条件覆盖**：最长接触时间、最高温度、最多次灭菌循环、最多次 γ 辐照
- **试验用滤器要求**：使用**灭菌后**的滤器进行试验；尽量不进行预冲洗（模拟最差状态）

**分析检测方法体系**

| 方法 | 适用分析物 |
|---|---|
| 非挥发性残留物（NVR） | 总浸出物水平评估 |
| 紫外光谱（UV） | 芳香族化合物的快速初筛 |
| 反相高效液相色谱（RP-HPLC） | 有机化合物定量 |
| 气相色谱-质谱（GC-MS） | 挥发性 / 半挥发性有机物鉴别 |
| 液相色谱-质谱（LC-MS） | 非挥发性有机物结构鉴别 |
| 傅立叶变换红外光谱（FTIR） | 聚合物降解产物的功能团分析 |
| 总有机碳（TOC） | 总有机物浸出量的综合评估 |
| 电感耦合等离子体质谱（ICP-MS） | 无机金属元素（如 Zn、Ti、Sb）的痕量分析 |

**安全性评估路径**

可提取物/浸出物研究完成后，须结合以下信息进行安全性评估：

- 浸出物在最终药品中的浓度（考虑稀释倍数）
- 最大日剂量和给药途径（静脉 vs. 皮下 vs. 眼内）
- 给药周期（单次给药 vs. 慢性给药的累积暴露量）
- 各浸出物的毒理学性质（已知毒性数据库查询）
- 与许可阈值（Safety Concern Threshold, SCT）的比较

:::

## 过滤器化学兼容性、吸附效应与完整性测试的系统管理

:::answer

除菌过滤器是无菌生物制品生产的关键风险控制点，其管理须覆盖化学兼容性、蛋白吸附、使用前/后完整性测试三个维度。

**化学兼容性试验**

化学兼容性试验评估产品（待过滤介质）对过滤装置（不只是滤膜，还包括外壳、支撑材料）的化学影响：

- **试验设计覆盖原则**：过滤时间须 **≥** 实际生产最长工艺时间；温度须 **≥** 生产过程最高温度
- **核心检测项目**：接触前后目视检查；过滤过程中流速变化；滤膜重量/厚度变化；起泡点等完整性测试数值变化；滤膜拉伸强度变化；电镜扫描形貌确认

**吸附效应评估**

待过滤介质中的活性成分（蛋白质）或关键辅料（如表面活性剂 PS80）可能因静电或疏水相互作用吸附在过滤器表面，导致：

- 产品中有效成分浓度下降（需确认回收率 ≥ 98–99%）
- 处方中 PS80 等关键辅料浓度改变，影响产品稳定性

影响吸附的因素：流速、过滤时间、蛋白浓度、pH 值和温度。吸附评估须在实际产品和工艺条件下（而非模型溶剂）进行。

**完整性测试：三种方法的原理与适用场景**

| 测试方法 | 原理 | 适用过滤器类型 | 定量/定性 |
|---|---|---|---|
| **起泡点试验（Bubble Point）** | 湿润滤膜在某一压力下气体突破，该压力即为泡点（与孔径负相关） | 亲水性过滤器 | **定性**（泡点是范围值） |
| **扩散流/前进流试验（Diffusion Flow）** | 在泡点的 80% 压力下，气体溶解并扩散通过液膜，测定扩散流量 | 亲水性过滤器 | **定量**（精确数值）；可反映孔隙率、流量和有效过滤面积 |
| **水侵入法（Water Intrusion）** | 疏水膜抗拒液体，在一定压力下测量被挤入疏水膜的水流量，反映孔径大小 | **疏水性过滤器**（亲水法无法润湿）| **定量** |
| **压力保持法（Pressure Hold）** | 在泡点 80% 压力下密闭 10 分钟，若压降 < 5% 则合格 | 亲水/疏水均可 | 定性（通过/不通过） |

扩散流法的优势显著：不仅能准确确定过滤器完整性，还能反映膜孔隙率、流量和有效过滤面积的变化，因此被国际主流厂家优先采用。

**完整性测试的 GMP 管理要点**

- 除菌过滤器**使用后须立即**进行完整性测试并记录（使用后测试是强制性的）
- 使用前是否需要完整性测试，须通过**风险评估**确定
- **冗余过滤（两级串联）的处置逻辑**：
  1. 先对**主过滤器**进行使用后完整性测试
  2. 主过滤器通过 → 冗余过滤器无需测试
  3. 主过滤器失败 → 必须对冗余过滤器进行测试；冗余过滤器结果可作为**产品放行**的依据
- 完整性测试**失败后的再测试**：须根据原因分析采取相应措施（加强润湿、改善润湿介质、检查系统密封性），并完备记录再测试过程
- 应尽可能使用**自动化完整性测试仪**（IQ/OQ/PQ 验证），避免人工操作偏差

**非标准介质（产品润湿）的完整性测试要求**

若实际工艺需要用产品（非水）润湿进行完整性测试，须通过**以实际产品为润湿介质的验证**获得产品专属的泡点或扩散流标准，不可直接套用厂家水润湿参数。

:::

## 抗体溶液外观变色：颜色异常对产品质量与临床研究的双重影响

:::answer

抗体溶液的外观颜色是批次放行检测中的重要质量参数，颜色异常不仅是产品质量问题的信号，还可能对临床研究的盲法设计产生直接冲击。

**颜色异常的两层质量影响**

**影响一：产品质量与安全性**

- 储存过程中颜色显著加深意味着产品可能发生化学降解（氧化、Maillard 反应）、被污染或含有异常降解产物
- 颜色超标的批次须立即启动根本原因（Root Cause）调查，并根据调查结果评估是否影响产品安全性和有效性
- 一旦确认颜色异常由化学降解引起，该批次通常须报废，导致直接经济损失

**影响二：临床研究双盲的破坏**

在双盲临床试验设计中，活性药物（单抗）与安慰剂（通常为注射用水或生理盐水，无色透明）须在外观上无法区分。若抗体产品颜色在储存过程中显著变深（如从淡黄色变为深棕色），外观差异将破坏研究的双盲性，导致：

- 患者或研究者无意识地识别出治疗分组（去盲）
- 导致测量偏倚（Measurement Bias），影响临床结果的可解释性
- 严重时须重新设计或中止临床试验

**实践管理建议**

- 在临床试验供药阶段，须对成品颜色进行严格的出库检测和稳定性监测，确保整个临床研究周期内颜色符合规格
- 若存在颜色随时间加深的趋势，须在临床研究方案中预先设定颜色接受标准，并建立监盲委员会（DSMB）的评估程序

:::

## 铁离子通过 ROS 催化的 Trp 氧化是导致抗体溶液变黄的主要机制

:::answer

**铁离子诱导变色的分子通路**

铁离子并非直接引起产品颜色变化，而是通过催化活性氧（ROS）的产生，间接介导特定氨基酸的氧化降解，形成有色产物：

$$\text{Fe}^{2+} + \text{H}_2\text{O}_2 \xrightarrow{\text{Fenton 反应}} \text{Fe}^{3+} + \cdot\text{OH} \xrightarrow{\text{氧化}} \text{Trp} \rightarrow \text{N-formylkynurenine（黄色）} + \text{Kynurenine（黄色）}$$

**关键研究发现**

- 当 CHO 细胞化学成分限定培养基（CD 培养基）中铁离子浓度达到 **75 mM** 时，可显著加深最终产品颜色
- 通过 LC-MS 分析证实：高铁培养基表达纯化的抗体中，**暴露于蛋白质表面的两个色氨酸**在近紫外-可见光（400–700 nm）条件下被逐渐氧化，生成 **N-甲酰犬尿氨酸（N-formylkynurenine）** 和 **犬尿氨酸（Kynurenine）**，两种化合物均呈黄色
- 高铁培养基中产生的 ROS 在下游纯化后大部分被去除，但最终产品中仍有极少量铁离子残留，足以在长期储存中催化缓慢的 Trp 氧化反应

**铁离子风险控制的实践要点**

- 监控培养基中铁离子的形态（游离 Fe²⁺ vs. 螯合铁）和总浓度，避免游离铁离子浓度过高
- 在培养基中添加抗氧化剂（如 L-蛋氨酸、N-乙酰半胱氨酸）清除 ROS，从源头阻断氧化链
- 在制剂配方中加入 Met 作为竞争性氧化靶点（牺牲保护）
- 产品避光储存，减少光照催化的 Trp 氧化

:::

## 维生素 B12 与抗体直接结合：导致粉红色或红色原液的特殊污染机制

:::answer

维生素 B12（Cobalamin）是 CHO 细胞培养中碳单元转移和 DNA 合成的必需辅酶，是培养基的标准组分，但在特定条件下可与抗体形成稳定的有色复合物，导致最终原液（DS）出现异常的粉红色或红色。

**B12 的颜色来源**

维生素 B12 有四种异构体：cyano-cobalamin（氰钴胺素）、hydroxo-cobalamin（羟钴胺素）、adenosyl-cobalamin（腺苷钴胺素）和 methyl-cobalamin（甲基钴胺素）。四种异构体在水溶液中均呈**深红色**（来自钴（III）离子的金属配位发色团）。

**B12 与抗体共价结合的机制**

研究表明，**hydroxo-B12** 的钴（III）离子可与抗体中游离半胱氨酸（Cys）的巯基（-SH）形成**配位共价键**：

- 抗体中二硫键（Disulfide Bonds）的不完全配对会产生游离巯基（Free Thiol, -SH）
- 一个抗体分子中若存在多个游离巯基（来自多个二硫键还原），理论上可结合多个 B12 分子
- **颜色与 B12 结合量正相关**：培养基中 B12 浓度与最终原液的红色/粉色深度呈比例关系

**cyano-B12 转化为 hydroxo-B12 的光催化过程**

B12 的 cyano 异构体须先转化为 hydroxo 异构体才能与抗体结合，该转化反应主要在**波长 400–600 nm** 的可见光照射下发生。

**基于此机制的针对性控制策略**

| 控制措施 | 理论依据 | 实际可行性 |
|---|---|---|
| **减少培养基中 B12 浓度** | 直接降低游离 B12 的可用量，减少潜在结合 | 须验证对细胞生长和抗体产量无显著影响 |
| **培养区域采用红光（波长 > 600 nm）** | 阻断 cyano-B12 向 hydroxo-B12 的光催化转化 | 培养基配制、储存和培养操作区域均须实施 |
| **减少抗体中游离巯基** | 从结合靶点角度切断结合路径 | 优化细胞培养条件，减少二硫键不完全形成 |
| **下游纯化工艺去除 B12-抗体复合物** | 利用 B12 结合改变了抗体的电荷或疏水性 | 需验证离子交换或疏水层析对复合物的去除效果 |

:::

## 抗体溶液变色的综合调控策略：上游、下游与制剂三层防线

:::answer

抗体溶液颜色变化可能在生产工艺的任何阶段发生，须建立从上游到制剂的三层调控防线，而非仅在产品放行时发现颜色超标后被动处置。

**第一防线：上游工艺控制（消除颜色产生的根本来源）**

| 控制目标 | 具体措施 |
|---|---|
| 控制铁离子水平 | 优先使用螯合形态铁（柠檬酸铁、EDTA 铁）替代游离 Fe²⁺；监控培养基铁离子总量 |
| 控制 B12 相关风险 | 优化 CD 培养基中 B12 浓度（通常可在不影响产量的前提下适度减少）；培养区域使用红光照明（波长 > 600 nm），阻断 cyano-B12 光转化 |
| 控制 B2（核黄素）水平 | 维生素 B2（核黄素）也是光敏感有色物质，浓度须适当控制；避免 B2 过量引入 |
| 减少 ROS 产生 | 在培养基中加入抗氧化剂（L-Met、N-乙酰半胱氨酸） |

**第二防线：下游纯化工艺控制（去除已产生的颜色相关杂质）**

- 通过颜色监测早期发现：在未处理收获液（UPB）和各层析步骤的洗脱液中监测颜色，定位颜色变化发生的工艺步骤
- 评估离子交换层析（IEX）或疏水相互作用层析（HIC）对 B12-抗体复合物的分离去除能力
- 优化 Protein A 洗脱条件，确保 B12 复合物被充分清除

**第三防线：制剂与储存控制（防止在储存期间颜色进一步加深）**

| 控制措施 | 作用机制 |
|---|---|
| 制剂中加入甲硫氨酸（Met） | 自由基猝灭剂，竞争性保护 Trp 免受光氧化，同时保护 Fc 区 Met252/428 |
| 制剂中加入精氨酸（Arg） | 提升光学和热稳定性，减缓构象相关的颜色变化 |
| 产品全程避光储存 | 阻断光催化的 Trp 氧化和 B12 光转化反应 |
| 优化储存温度 | 低温（2–8°C）显著降低化学降解（氧化、Maillard 反应）速率 |
| 选用遮光包材 | 一级包材（棕色玻璃瓶或铝膜外覆）提供持续的光保护 |

**早期颜色评估的战略意义**

在工艺开发早期（IND 批次）即开始系统评估 DS 颜色，而非仅在出现问题时才排查，可以：

- 在工艺设计阶段即识别颜色风险来源并纳入控制策略
- 为后续工艺变更和可比性研究提供颜色基线数据
- 降低临床阶段因颜色超标导致批次报废的风险

:::

## 常见单抗原液颜色与质量标准：正常范围与变色信号的判断边界

:::answer

**单抗原液的典型颜色**

正常状态下，单克隆抗体原液（DS）的外观颜色取决于蛋白质浓度和分子本身的特性：

| 颜色描述 | 常见原因 | 是否正常 |
|---|---|---|
| **无色透明** | 低浓度（< 10 mg/mL），芳香氨基酸含量较低 | 正常 |
| **浅黄色** | 高浓度（> 50 mg/mL）时芳香氨基酸（Tyr、Trp）的累积吸收效应 | **正常**（多数高浓度单抗的典型颜色） |
| **棕红色** | B12-抗体复合物的形成；铁催化的 Trp 大量氧化 | 异常，须立即调查 |
| **浅粉色** | 少量 B12 结合 | 须调查 B12 暴露情况，评估是否超标 |
| **深棕色** | 严重的化学降解（Maillard 产物大量积累、高度 Trp 氧化） | 严重异常，须报废并调查 |

**质量标准的典型描述**

- 欧洲药典规定用于临床试验的 DS 应为**无色或接近无色**
- 产品放行质量标准通常描述为：**无色至浅黄色**（Near Colorless to Pale Yellow）
- 半定量颜色标准：若有颜色限度要求，通常参照比色标准液（如**黄色 Y5 号标准液**），要求颜色 **≤ Y5**
- 颜色的仪器定量：分光光度计在 **450 nm** 处测定吸光度（A₄₅₀），建立定量限度

**颜色超标的快速处置流程**

一旦发现 DS 颜色异常或超标，须立即：

1. **隔离该批次**，暂停后续处理（配制、灌装）
2. **启动偏差调查**，按以下顺序排查根本原因：培养基铁离子/B12 水平 → 培养过程光照暴露 → 纯化过程异常 → 储存条件偏差
3. **评估产品可用性**：根据颜色成因和程度，结合其他质量指标（活性、纯度、聚集体）综合评估是否可用于临床
4. **制定 CAPA**：针对根本原因制定纠正和预防措施，在后续批次中验证效果

:::
