## 层析载量的定义：静态结合载量与动态结合载量的区分与应用

:::answer

载量（Binding Capacity）是层析纯化工艺设计的核心参数，直接决定单次运行的最大处理量和填料的经济性，在工艺放大和工艺验证中均是关键工艺参数（KPP）。

**两种载量类型的定义与区别**

| 参数 | 动态结合载量（DBC） | 静态结合载量（SBC） |
|---|---|---|
| **定义** | 在真实流动条件下，固定相可吸附靶蛋白且不发生明显穿透损失的最大量（通常以 10% 穿透点 DBC₁₀% 为工艺设计依据） | 在静态平衡条件下，填料完全饱和后可结合的最大样品量（即热力学理论最大载量） |
| **测定方式** | 上样至目标蛋白开始穿透（监测流出液 UV 吸收值），绘制穿透曲线，从 10% 穿透点计算已结合量 | 将已知浓度样品与填料充分混合平衡（过夜），离心后测定上清液浓度，计算已结合量 |
| **实验条件** | 真实流速、柱压、缓冲液条件（接近生产操作条件） | 静态搅拌或摇床振荡，无流速影响 |
| **与 SBC 的关系** | 通常 DBC < SBC（约为 SBC 的 50~80%），因流速条件下传质不完全） | 代表填料的理论上限，不直接用于工艺设计 |
| **工艺设计依据** | **是**，DBC₁₀% 是确定每个层析循环最大上样量的直接依据 | 用于填料选型比较，不直接用于操作参数设定 |

**载量在工艺开发中的实践意义**

- **Protein A 亲和层析：** DBC 通常为 20~50 mg IgG/mL 填料（依填料品牌不同），工艺操作载量通常设定为 DBC₁₀% 的 **70~80%**（留出安全余量，保证高批次一致性）
- **离子交换层析（IEX）：** 载量受 pH、电导率、蛋白质表面电荷密度影响，需在目标洗脱条件下单独测定 DBC
- **载量是工艺放大的关键计算基础：** 生产规模层析柱体积 = 上样总量 ÷ 工艺操作载量（mg/mL 填料），直接决定柱子规格选型

**载量的影响因素**

| 因素 | 影响方向 | 说明 |
|---|---|---|
| 流速（线速度）升高 | DBC ↓ | 接触时间缩短，传质不充分 |
| 样品黏度升高 | DBC ↓ | 扩散系数降低，传质受阻 |
| pH 接近 pI | DBC ↓（IEX） | 蛋白表面净电荷减少，结合力降低 |
| 电导率升高 | DBC ↓（IEX） | 盐离子竞争结合位点 |
| 填料颗粒粒径减小 | DBC ↑ | 比表面积增大，传质距离缩短 |

## 宿主细胞蛋白（HCP）残留的安全性影响与全流程控制策略

:::answer

宿主细胞蛋白（Host Cell Protein，HCP）是生物药最重要的工艺相关杂质之一，来源于生产细胞（通常为 CHO 细胞）在培养和收获过程中释放的内源性蛋白质组分。

**HCP 残留对产品安全性的多维影响**

| 风险类型 | 具体影响 | 典型案例 |
|---|---|---|
| **免疫原性风险** | 异源蛋白触发患者免疫应答，产生针对 HCP 的抗体，可能引发过敏反应或超敏反应 | 已有文献报告特定 HCP 组分与患者过敏反应相关 |
| **产品聚集** | 部分 HCP 具有蛋白酶活性，可降解产品；脂质相关 HCP 可改变蛋白局部环境，促进聚集 | 磷脂酶 B-like 2（PLBL2）是已知的高风险 HCP |
| **产品片段化** | 蛋白酶类 HCP（如组织蛋白酶、金属蛋白酶）可水解单抗铰链区，产生半抗体或 Fab/Fc 片段 | 收获后样品在 2~8°C 保存时仍可发生 HCP 介导的蛋白降解 |
| **辅料降解** | 脂肪酶类 HCP 可降解制剂中的聚山梨酯 80（PS80），产生脂肪酸，形成可见异物颗粒 | PS80 降解是近年来 HCP 相关产品质量事件的主要类型之一 |
| **可见异物** | HCP 介导的 PS80 降解产物（脂肪酸颗粒）在制剂中析出，形成可见或亚可见颗粒 | 可见白色或乳白色颗粒，影响产品外观和安全性 |

**HCP 控制策略（上游 + 下游协同）**

**上游控制**

- 控制收获时细胞活率尽可能高（建议 > 70%，最好 > 85%）：细胞活率越高，细胞裂解越少，胞内 HCP 释放越少
- 通过优化培养周期和降温策略，减少培养后期大量细胞死亡带来的 HCP 释放峰值
- 收获操作（离心/深层过滤）应在低温（2~8°C）下快速完成，避免 HCP 长时间接触产品

**下游清除**

| 纯化步骤 | HCP 清除能力 | 主要机制 |
|---|---|---|
| 深层过滤（Depth Filtration） | 中等 | 物理截留和静电吸附，清除 DNA-HCP 复合物 |
| Protein A 亲和层析 | 高（1~3 log） | 选择性结合 IgG，大部分 HCP 流穿去除 |
| 阳离子交换（CEX） | 中~高 | 调节 pH/电导率使 HCP 流穿，IgG 保留 |
| 阴离子交换（AEX，流穿模式） | 中~高 | 大多数 CHO HCP 在中性 pH 带负电荷，被 AEX 保留清除 |

**质量标准要求**

各国监管机构均将 HCP 定义为工艺相关杂质，推荐原液 HCP 残留限度为：
- **≤ 100 ppm（ng/mg 蛋白）**，即蛋白质总量的 **0.01%** 以下
- HCP 检测通常作为**原液**（DS）的放行检测项，不要求在成品（DP）中逐批检测（因 DS→DP 灌装过程不引入额外 HCP）
- 对于已知高风险 HCP 组分（如 PLBL2、组织蛋白酶），应建立**特异性检测方法**单独监控，不能仅依赖总 HCP ELISA

:::

## HCP ELISA 检测方法的原理、覆盖率评估与技术局限性

:::answer

**HCP ELISA 的方法原理**

HCP ELISA（酶联免疫吸附试验）是目前检测生物药中 HCP 残留应用最广泛的分析方法，采用**三明治（Sandwich）夹心法**：

```
固相包被：多克隆抗 HCP 抗体（Capture Ab）固定于微孔板
         ↓ 加入样品
样品结合：各 HCP 组分与包被抗体特异性结合
         ↓ 洗涤，去除未结合物质
检测信号：加入酶标多克隆抗 HCP 抗体（Detection Ab，通常为 HRP 标记）
         ↓ 底物显色（TMB 等）
定量分析：以标准曲线计算 HCP 浓度（ng/mL），换算为 ppm（ng/mg 蛋白）
```

**方法特点与优势**

- **检测对象：** 总 HCP 混合组分（非单一蛋白），反映所有可被抗体识别的 HCP 的综合水平
- **灵敏度：** 可达 1~10 ng/mL，满足 100 ppm 以下的残留控制要求
- **重复性：** 良好（批内 CV < 15%，批间 CV < 20%），适合常规批次放行
- **法规认可：** USP < 1132 > 和 EP < 2.6.34 > 均详细规定了 HCP ELISA 方法的开发、验证和抗体表征要求

**核心技术局限性：覆盖率（Coverage）问题**

HCP 是复杂的蛋白质混合物（CHO 细胞可表达 > 5000 种蛋白），不同 HCP 组分的免疫原性差异悬殊：
- 高分子量、高免疫原性 HCP → 易激发动物产生高滴度抗体 → 被 ELISA 有效检测
- 低分子量（< 10 kDa）、低免疫原性 HCP → 难以产生高亲和力抗体 → 可能"漏检"

**覆盖率（Coverage）的定义**

$$\text{覆盖率} = \frac{\text{ELISA 抗体可识别的 HCP 蛋白点数}}{\text{HCP 总蛋白点数（2-DE 银染）}} \times 100\%$$

行业通常要求覆盖率 ≥ **50%（蛋白点数）** 或基于特定高丰度 HCP 组分的覆盖验证。

**覆盖率评估方法对比**

| 方法 | 操作流程 | 优点 | 局限性 |
|---|---|---|---|
| **2-DE + Western Blot（经典法）** | 同一样品跑两块 2-DE 胶，一块银染（总蛋白），一块 WB 显色（ELISA 抗体识别蛋白）；软件叠加匹配 | 操作较简便，直观 | 重复性差；WB 中 HCP 为变性状态，与 ELISA 天然状态不完全一致 |
| **2D-DIGE（双色荧光差异凝胶电泳）** | cy3 标记总 HCP，cy5 标记经抗 HCP 抗体免疫亲和捕获后的 HCP；同一块胶双通道成像 | 一块胶同时比较，重复性更好；节省时间和试剂 | 需要专业荧光成像设备 |
| **免疫亲和捕获 + 2-DE** | 将 HCP 抗体偶联至层析填料→上样 HCP→流穿（未识别）+ 洗脱（已识别）→分别 2-DE 银染比较 | 在接近天然状态下评估；可分别分析"识别"与"未识别"组分 | 操作复杂，需制备免疫亲和柱 |

:::

## HCP ELISA 方法的开发策略：从商品化试剂盒到自建平台方法

:::answer

HCP ELISA 方法的选择策略随产品开发阶段的推进而演变，需在灵活性、成本和法规合规性之间动态平衡。

**分阶段方法选择策略**

**阶段一：早期开发至临床 I/II 期**

- 优先选择商品化 HCP 试剂盒（如 Cygnus Technologies F550 CHO HCP Kit）
- 理由：开发周期短，成本低，方法验证相对简单；临床早期监管要求相对宽松
- 注意：商品化试剂盒的抗体是针对通用 CHO HCP 制备，对特定工艺的专属性有限

**阶段二：临床 III 期至上市**

- 应优先建立**平台工艺 HCP 方法**（Platform HCP Method）或**上游工艺专属 HCP 方法**
- 工艺专属方法使用与实际生产工艺高度匹配的 HCP 抗原制备抗体，覆盖率和专属性更强
- 若坚持使用商品化试剂盒至上市，需充分证明：试剂盒中主要试剂（标准品、抗体）适用于本工艺的 HCP 谱，提供覆盖率验证数据

**关键试剂更换的可比性要求**

由于商品化试剂盒关键试剂（抗体批次、标准品）来自外部供应商，生产方对其质量控制能力有限：
- 每次关键试剂批次更换时，需执行**方法可比性研究**（Comparability Study）
- 使用新旧两批试剂平行检测相同的 HCP 样品（包括标准曲线、QC 样品和实际批次样品），证明方法一致性（结果偏差通常要求 ≤ 20%）
- 关键试剂更换应通知监管机构（视变更类型决定报告类别）

**自建 HCP 方法的核心步骤总结**

```
① HCP 抗原制备（空载细胞培养 + 与生产工艺匹配的收获处理）
② HCP 抗原质量分析（总量、无产品污染确认、2-DE 蛋白点数）
③ 动物免疫接种（多次加强免疫，提高滴度）
④ 抗血清筛选（滴度测定 + WB 筛选，去除低滴度和非特异性抗体）
⑤ 抗 HCP 抗体纯化（Protein G 亲和纯化）
⑥ 覆盖率评估（2D-DIGE 或免疫亲和捕获法，目标 ≥ 50%）
⑦ 方法开发（标准曲线范围、稀释线性、Hook Effect 评估）
⑧ 方法验证（专属性、准确性、精密度、线性、LOD/LOQ）
```

## HCP 抗原与抗 HCP 抗体的制备流程与质控要求

:::answer

高质量的 HCP 抗原和抗 HCP 抗体是 HCP ELISA 方法性能的根基，制备过程的每一步骤均需严格质控并留存完整记录。

**HCP 抗原的制备**

**① 空载细胞培养**

- 使用与生产细胞系相同遗传背景的**空载质粒转染细胞**（Mock-transfected cells），在接近实际生产工艺的条件下培养
- 目的：产生与实际生产工艺 HCP 组成高度相似的 HCP 混合物，同时避免产品蛋白的干扰
- 可有意改变培养条件以获得更广泛的 HCP 谱：延长培养周期、升高培养温度、降低 pH 等
- 可合并多个小批次以提高 HCP 谱代表性，降低单批次变异的影响

**② 纯化制备**

- 选择与实际生产工艺相同或相似的 HCCF（Harvested Cell Culture Fluid）澄清步骤（离心 + 深层过滤），去除细胞碎片
- 通过超滤/渗滤（UF/DF）置换缓冲液（PBS 或 HEPES）并浓缩
- 超滤膜截留分子量应 ≤ 10 kDa，以尽量减少低分子量 HCP 的损失（低分子量 HCP 免疫原性弱，需要特别保留）

**③ 抗原质量分析**

| 检测项目 | 要求 |
|---|---|
| 总蛋白含量 | 定量（BCA 法或 A280 法） |
| 产品污染确认 | 免疫测定或 LC-MS 确认无目标产品蛋白残留（确保免疫原性来自 HCP，非产品） |
| 蛋白多样性 | 1-D 或 2-D 凝胶电泳确认尽可能多的 HCP 蛋白条带/点，评估组成复杂度 |
| 稳定性 | 分装后在 -80°C 保存，建立稳定性监测计划，避免反复冻融 |
| 制备记录 | 详细记录每步操作（时间、体积、浓度、批次），便于再生产时的溯源和重现 |

**抗 HCP 抗体的制备**

**① 免疫接种**

- 将 HCP 抗原（配合佐剂）分多次注射动物（通常为兔或羊），进行初次免疫 + 多次加强免疫
- 对低分子量 HCP 可单独提取并实施不同免疫策略（如偶联载体蛋白），增强免疫效果
- 免疫接种前需确认动物对产品蛋白无预存抗体，排除预免疫阳性个体

**② 抗血清筛选与纯化**

- 合并前对每个个体血清进行单独评估（滴度测定 + WB 分析），筛选条件：
  - 滴度足够高（ELISA EC₅₀ < 1:10000 为参考）
  - WB 显示对 HCP 各分子量范围均有覆盖
  - 排除对目标产品蛋白有非特异性交叉反应的血清
- 提取动物血清后通过 Protein G 亲和层析纯化，获得 IgG 级抗 HCP 抗体库

**③ 最终抗体库质控**

- 覆盖率验证（2D-DIGE 或免疫亲和捕获，详见 Q7）
- 专属性确认：确认抗体不与产品蛋白发生非特异性结合
- 稳定性评估：分装后 -80°C 保存，建立效价稳定性监测计划

## HCP 抗体覆盖率的两种评估方法及其选择依据

:::answer

覆盖率（Antibody Coverage）是衡量 HCP ELISA 抗体是否能全面检测 HCP 混合物中各组分的核心指标，直接决定 ELISA 方法的检测完整性。

**方法一：二维电泳结合蛋白质免疫印迹（2-D Western Blot）**

**操作流程**

```
同一 HCP 样品
    ├── 胶 A（总蛋白）：2-DE 分离 → 银染/荧光染色（显示所有蛋白点）
    └── 胶 B（抗体识别蛋白）：2-DE 分离 → 转膜 → 抗 HCP 抗体孵育 → ECL 显色

软件叠加分析：
匹配两块胶的蛋白点位置
覆盖率 = 匹配点数（抗体识别）/ 总点数（银染总蛋白）× 100%
```

**方法特点**

- 优点：操作较为标准化，仪器普及
- 局限性：需跑两块独立的胶，批间对齐误差较大；WB 中 HCP 处于 SDS 变性状态，与 ELISA 中天然构象状态下的识别能力存在差异，可能导致覆盖率被高估或低估

**方法二：2D-DIGE（双色荧光差异凝胶电泳）**

**操作流程**

```
HCP 样品分两份：
  份 A：cy3 荧光染料标记（总 HCP）
  份 B：先用抗 HCP 抗体免疫亲和捕获，捕获到的 HCP 用 cy5 标记

两份混合后在同一块胶上进行 2-DE
双通道荧光成像（cy3 通道 = 总蛋白；cy5 通道 = 抗体识别蛋白）
覆盖率 = cy5 通道显色点数 / cy3 通道总点数 × 100%
```

**方法特点**

- 优点：同一块胶同步比较，消除胶间对齐误差；减少实验操作步骤（节省时间和试剂）；重复性更好
- 局限性：需要专业双通道荧光凝胶成像系统（设备要求较高）

**方法三：免疫亲和捕获结合 2-DE（Immunoaffinity Capture, IAC）**

**操作流程**

```
将抗 HCP 抗体偶联至亲和填料
上样 HCP 样品 → 过柱
  ├── 流穿组分（未识别 HCP）→ 2-DE 银染分析
  └── 洗脱组分（已识别 HCP）→ 2-DE 银染分析

覆盖率 = 洗脱组分蛋白点数 / （流穿 + 洗脱）总点数 × 100%
```

**方法特点**

- 优点：HCP 在接近天然状态下被评估，与 ELISA 检测条件更接近；可分别收集和分析"识别"与"未识别"HCP，为方法改进提供针对性线索
- 局限性：需制备亲和层析柱（操作复杂，成本较高）

**选择建议**

- 常规覆盖率评估：**2D-DIGE** 是目前行业最优推荐，兼顾准确性和操作效率
- 深度覆盖率研究（监管申报支持文件）：同时采用 **2D-DIGE + IAC** 提供双重证据
- 行业普遍接受的覆盖率目标：蛋白点数覆盖 ≥ **50%**；高丰度 HCP（top 10 组分）覆盖 ≥ 80%

:::

## 基于细胞因子释放的 ELISA 生物活性检测方法（Cell-based ELISA）

:::answer

细胞 ELISA 法（Cell-based ELISA）是通过检测效应细胞（靶细胞）与抗体共培养后分泌的特异性细胞因子来定量评价抗体生物学活性的一类功能性检测方法，广泛应用于靶向细胞因子或免疫调节靶点的单抗效价检测。

**方法原理**

```
靶细胞（含目标受体）
    + 配体（如 IL-17）→ 激活细胞因子分泌通路
    + 待测抗体（如抗 IL-17 mAb）→ 竞争性阻断配体-受体结合

检测：共培养后采集上清液 → ELISA 定量细胞因子浓度（如 IL-6 或 GROα）

活性计算：
抗体活性越强 → 配体信号阻断越充分 → 细胞因子分泌量越低
细胞因子浓度与抗体活性成反比
相对效价 = f（参比品曲线 vs. 样品曲线）的 EC₅₀ 比值
```

**以抗 IL-17 单抗检测为例的完整操作流程**

1. 将靶细胞（如皮肤成纤维细胞或 HEK293-NF-κB 报告细胞）铺板至 96 孔板
2. 将 IL-17（固定浓度，用于激活细胞）与系列浓度的待测抗 IL-17 单抗预混孵育（竞争结合）
3. 将预混液加至靶细胞，37°C 共培养（通常 16~24 小时）
4. 收取细胞培养上清液，通过 IL-6 或 GROα ELISA 定量读数
5. 拟合剂量-效应曲线（四参数逻辑回归，4PL），与参比品曲线比较，计算相对效价

**方法特点与适用场景**

| 特征 | 说明 |
|---|---|
| **功能相关性** | 直接反映抗体在细胞水平的阻断/激活功能，比非细胞 ELISA 结合检测更接近体内作用机制 |
| **变异来源多** | 细胞状态、传代次数、培养基批次均影响结果，批间变异（CV）通常 10~25% |
| **适用靶点** | 靶向细胞因子（IL-17、TNFα、IL-6 等）或其受体的抗体；阻断受体配体相互作用类抗体 |
| **法规要求** | ICH Q6B 要求生物学活性检测方法应与产品作用机制相关；批放行用效价方法需经过全面验证 |

:::

## 分析方法开发与验证的体系框架：ICH Q14 与 Q2(R2) 要点

:::answer

分析方法是质量标准的执行工具，其开发质量和验证完整性直接决定产品检测数据的可信度。ICH Q14（分析方法开发）和 ICH Q2(R2)（分析方法验证）于 2023 年联合更新，构成当前行业分析方法管理的核心法规框架。

**分析方法开发的关键要素（ICH Q14）**

ICH Q14 引入了基于科学和风险的结构化开发方法，关键要素包括：

| 开发要素 | 具体内容 |
|---|---|
| **样品特性评估** | 基于对生产工艺的了解，评估样品组成、预期变异性及潜在干扰物 |
| **分析目标概况（ATP）** | 定义方法的预期用途、性能目标（精密度、准确性要求）和可接受标准 |
| **风险评估** | 识别可能影响方法性能的关键方法参数（Critical Method Attributes, CMAs），如色谱柱温度、流动相 pH、样品稀释倍数等 |
| **实验设计（DOE）** | 通过单变量或多变量实验探索方法参数的范围和相互作用，建立方法知识空间 |
| **方法控制策略** | 定义关键方法参数的设定值和/或操作范围，确保方法性能持续符合 ATP |
| **生命周期变更管理** | 定义已证实的分析方法可接受范围（PAR）或方法可操作设计区域（MODR），明确变更报告类别 |

**分析方法验证的关键参数（ICH Q2(R2)）**

不同检测目的（鉴别、杂质定量、含量测定）对应不同的验证参数组合：

| 验证参数 | 鉴别试验 | 杂质限度检查 | 杂质定量 | 含量/效价测定 |
|---|---|---|---|---|
| **专属性（Specificity）** | ✓ | ✓ | ✓ | ✓ |
| **准确性（Accuracy）** | — | — | ✓ | ✓ |
| **精密度（Precision）** | — | — | ✓ | ✓ |
| **线性（Linearity）** | — | — | ✓ | ✓ |
| **范围（Range）** | — | — | ✓ | ✓ |
| **检测限（LOD）** | — | ✓ | ✓ | — |
| **定量限（LOQ）** | — | — | ✓ | — |
| **耐用性（Robustness）** | — | ✓ | ✓ | ✓ |

**生物学测定方法验证的特殊性**

与理化方法相比，生物学测定方法（如效价 ELISA、细胞活性检测、ADCC 等）存在更多变异来源（细胞状态、操作人员差异），验证参数的可接受标准通常更宽松：
- 精密度：批内 CV ≤ 15%，批间 CV ≤ 20%（理化方法通常要求 CV ≤ 2~5%）
- 线性：相关系数 R² ≥ 0.99（理化），生物学方法 ≥ 0.95
- CDE 于 2005 年发布的《生物制品质量控制分析方法验证技术一般原则》专门适用于免疫化学和生物学试验方法的验证

:::

## 异常毒性检查法：定义、检测目的与法规沿革

:::answer

异常毒性检查（Abnormal Toxicity Test）是注射剂安全性控制的传统生物学检查项目，其法规地位和适用范围随着各国药典更新而发生显著变化。

**异常毒性的定义**

异常毒性是指产品中由生产过程引入的外来物质（非药物本身固有毒性）导致的毒性反应，包括：
- 生产过程中引入的外源性污染物（如细菌毒素）
- 辅料杂质（特定辅料批次中的有毒杂质）
- 光敏感性药物的光敏毒性产物
- 高温降解产生的毒性物质

**检测目的**

通过活体动物实验，在分子检测方法难以完全覆盖所有潜在毒性物质时，从整体生物学层面评估注射剂的安全性。异常毒性检测通常作为**成品（DP）**的放行检测项，而非原液。

**各国法规的历史变迁**

| 法规/药典 | 现行状态 | 说明 |
|---|---|---|
| **美国 USP** | 已删除（USP 26 版，2003 年起） | 随分析化学方法提升，认为现代纯度检测已足够保证安全性 |
| **欧洲药典（EP）** | 仍保留（EP 2.6.9 Test for abnormal toxicity） | 部分品种仍要求，但整体适用范围收窄 |
| **中国药典（ChP）** | 部分保留 | 2005 版起已对多个品种删除该项（如静脉用氨基糖甙类抗生素等） |

**中国药典的现行立场**

中国 2005 版以后，异常毒性检查已从多个长期检测无不合格记录的品种中删除，但建议结合产品特点考虑是否保留：
- 化学合成肽类药物、抗生素类：仍建议保留
- 合成工艺成熟、纯度检查完善的品种：可申请豁免
- 生物制品：因产品本身质量属性的特殊性（如某些蛋白制品直接给动物注射会产生免疫反应，影响判定），可在提供充分依据并经评估后申请豁免

:::

## 异常毒性检查的法规要求演变与豁免考量

:::answer

异常毒性检查的存废之争折射出生物制药从"功能性安全验证"向"分子级质量控制"转变的行业趋势。

**各国法规对异常毒性检查态度的演变逻辑**

早期引入异常毒性检查的背景是：当时分析技术有限，难以检测所有潜在毒性物质，需借助活体实验进行兜底性安全验证。随着以下技术进步，各国监管机构逐步缩减该检查的适用范围：

- 高效液相色谱（HPLC）和质谱（MS）等分析手段的普及，可精确检测极微量杂质
- 生物活性检测（LAL 内毒素检查、细胞毒性检测）的灵敏度大幅提升
- 对特定毒性物质的分子机理认知加深，可建立针对性检测方法

**中国药典的豁免评估框架**

依据《国家药品标准工作手册》的建议，以下情况可考虑申请豁免：
1. 产品长期多批次检测历史中无不合格记录（通常建议 ≥ 3 年、≥ 10 批数据）
2. 现行纯度检测方法已可全面控制产品中潜在毒性物质
3. 产品性质本身导致动物试验结果不可解读（如蛋白制品引发的非特异性免疫反应）

**豁免申请的文件要求**

- 提供充分的历史检测数据（无不合格批次的统计依据）
- 提供替代检测方法验证报告（证明替代方法可等效或更灵敏地控制安全性风险）
- 经过科学评估和监管机构审批，方可豁免
- 豁免后仍需在稳定性研究和工艺变更时重新评估豁免条件是否仍然成立

:::

## 生物制品异常毒性检查的操作规程与判定标准

:::answer

当异常毒性检查仍适用时，需严格按照药典规定的操作规程执行，任何偏差均可能导致结果无效或误判。

**试验动物与操作要求**

**小鼠试验**

| 要素 | 规程要求 |
|---|---|
| 动物数量 | 5 只（初次），如不符合则 10 只复试 |
| 体重要求 | 初次：18~22 g；复试：19~21 g |
| 给药途径 | 腹腔注射（i.p.） |
| 给药体积 | 0.5 mL/只 |
| 观察期 | 7 天 |
| 合格判定 | 7 天内全部存活 + 无异常反应 + 每只体重增加 |

**豚鼠试验**

| 要素 | 规程要求 |
|---|---|
| 动物数量 | 2 只（初次），如不符合则 4 只复试 |
| 体重要求 | 250~350 g |
| 给药途径 | 腹腔注射（i.p.） |
| 给药体积 | 5.0 mL/只 |
| 观察期 | 7 天 |
| 合格判定 | 7 天内全部存活 + 无异常反应 + 每只体重增加 |

**试验成立条件**

试验中应设同批动物的空白对照组：观察期内空白对照动物应全部健存，且无异常反应，体重增加。若空白对照不符合要求，则本次试验无效，需重新进行。

**结果判定逻辑**

```
初次试验（5只小鼠 / 2只豚鼠）
    ↓
全部存活 + 无异常 + 体重增加？
    ├── 是 → 符合规定，放行
    └── 否 → 复试（10只小鼠 / 4只豚鼠）
                ↓
          全部符合？
              ├── 是 → 符合规定
              └── 否 → 不符合规定，不放行
```

**生物制品豁免的法规依据**

中国药典明确注明：因生物制品本身质量属性不适合进行异常毒性检查的（如蛋白制品对动物产生免疫反应影响结果解读），在提供充分依据并经过评估的基础上，经批准可不设立该项检查。

:::

## 质量标准与关键质量属性（CQA）的逻辑关系与本质区别

:::answer

质量标准（Specification）与关键质量属性（CQA）是产品质量管理体系中两个密切相关但概念不同的维度，准确理解两者的关系是建立科学质量控制策略的前提。

**质量标准的定义（ICH Q6B）**

质量标准是**一个包括检测项目、参照分析方法和验收标准的列表**，验收标准以限度值、范围或其他定量标准表示。

质量标准的核心要素：
- **检测项目**（What to test）：如效价、纯度、HCP、内毒素等
- **分析方法**（How to test）：ELISA、SEC-HPLC、LAL 等
- **可接受标准**（Pass/Fail Criteria）：如效价 ≥ 80% 参比品，HCP ≤ 100 ppm

**CQA 与质量标准的核心关系矩阵**

| 情形 | CQA 属性 | 纳入质量标准？ | 说明 |
|---|---|---|---|
| **CQA，工艺无法持续保证** | 是 | **是** | 需逐批检测放行，如效价、糖型 |
| **CQA，工艺已验证可持续保证** | 是 | **不必须** | 如病毒清除（仅工艺验证，不逐批检测） |
| **非 CQA，但用于工艺监控** | 否 | **可以** | 如渗透压、pH（对患者无直接危害，但监控工艺一致性） |
| **非 CQA，历史数据充分** | 否 | **可删除** | 数据证明该项目从未超标且检测无附加价值时，可申请删除 |

**关键认知**

CQA ≠ 质量标准项目，两者的核心差异在于：
- **CQA** 是对产品质量属性重要性的**科学判断**（与患者安全/有效性相关）
- **质量标准** 是对产品批次放行的**管理决策**（是否需要逐批检测）

PDA TR 60 明确指出：关键质量属性不等同于标准，二者也未必一一关联。产品的 CQA 确定是一个始于研发早期的持续性活动，需随产品和工艺知识的增加不断更新。

:::

## 抗体药物放行检测的标准体系架构

:::answer

对于抗体药物，放行检测（Release Testing）是产品批次上市前的最终质量门禁，其检测项目覆盖产品相关杂质、工艺相关杂质、生物学活性、安全性和常规理化五大类别。

**单抗原液（DS）放行检测项目框架**

| 检测类别 | 典型检测项目 | 常用方法 |
|---|---|---|
| **鉴别** | 肽图（一级序列确认） | LC-MS/MS Peptide Mapping |
| **含量** | 蛋白浓度 | A280 / BCA / 分析用 HPLC |
| **纯度/产品相关杂质** | 聚集体（HMW）、片段（LMW） | SEC-HPLC、CE-SDS（非还原/还原） |
| **产品相关变体** | 电荷变体（酸性/主峰/碱性峰比例） | iCIEF 或 CEX-HPLC |
| **糖型** | G0F、G1F、G2F、Man5 等 | 2-AB UPLC（N-糖谱） |
| **生物学活性** | 效价（Potency）、FcRn 结合、ADCC | 细胞 ELISA 或 SPR 结合 |
| **工艺相关杂质** | HCP、HCD（宿主细胞 DNA）、Protein A 残留 | ELISA（各项专属方法） |
| **安全性** | 内毒素、微生物限度 | LAL 鲎试剂法、细菌培养法 |

**灯检合格后方可放行检测**

放行检测的前提是产品已通过灯检（可见异物检查），灯检合格的产品方进入常规放行检测流程；发现可见异物的批次不进入放行检测，直接判定不合格。

**放行检测结果的综合判定**

所有项目均符合可接受标准时，批次方可放行。若任一项不符合标准，需启动 OOS（超标）调查程序，在调查结论明确前批次不得放行。

:::

## 生物制品质量标准的制定原则与全生命周期管理

:::answer

生物制品质量标准的建立是产品注册上市的核心文件之一，其制定原则与化学药物相比存在重要差异，需充分体现生物制品的结构复杂性和工艺依赖性。

**生物制品质量标准的特殊性**

| 特征 | 说明 |
|---|---|
| **工艺依赖性** | 生物制品的质量属性由生产工艺决定，工艺细微差异可导致产品质量差异；不同企业的同类产品质量标准往往不能直接照搬 |
| **结构复杂性** | 大分子生物药（mAb ~ 150 kDa）的化学成分和修饰类型远比小分子化学药复杂，单一检测项目通常无法捕获所有质量维度 |
| **难仿制性** | 生物制品结构复杂，批次间天然存在一定异质性，质量标准的设定范围需合理反映工艺的正常变异 |

**质量标准的组成要素**

```
质量标准 = 检测项目（What）+ 分析方法（How）+ 可接受标准（Pass/Fail）
```

质量标准的建立是一个系统工程，需整合以下数据来源：
- 研发和工艺一致性批次的全面质量分析数据
- 分析方法的开发与验证数据
- 稳定性研究数据（确定降解敏感项目的上限）
- 临床前/临床研究与产品质量属性的相关性数据

**质量标准的全生命周期管理**

| 研发阶段 | 质量标准特点 | 管理重点 |
|---|---|---|
| **临床 I/II 期** | 基于有限批次数据（通常 3~5 批）制定，范围较宽 | 确保基本安全性和鉴别一致性 |
| **临床 III 期** | 基于 15~25 批数据，逐步收紧范围 | 支持上市申请（BLA/NDA）的质量档案 |
| **上市前** | 基于 ≥ 25~30 批数据，建立统计学可靠的范围 | 最终质量标准提交监管机构审批 |
| **上市后** | 累积 30~85 批以上数据后，通常需通过补充申请更新质量标准 | 精确化范围，删除冗余项目，增加新发现的 CQA 检测 |

**监管要求**

欧洲和美国监管机构通常要求上市后累积生产至 **30 批或累积生产 3 年**后，以补充申请方式更新产品质量标准，以确保质量标准真实反映成熟工艺的能力。

:::

## CQA 与放行检测项目的映射逻辑与决策框架

:::answer

将 CQA 转化为放行检测项目并不是机械的一一对应，而是基于风险评估和工艺知识的系统性决策过程。

**CQA 转化为放行检测项目的决策流程**

```
CQA 属性确定
    ↓
① 是否有适宜的检测方法？
    └── 否 → 暂不纳入质量标准，记录科学理由；持续开发检测方法
    └── 是 → 继续评估
         ↓
② 工艺是否能持续保证该属性？
    └── 是（有工艺验证数据支持）→ 可考虑仅做工艺验证，不逐批检测
    └── 否（存在批次间波动）→ 纳入放行检测质量标准
         ↓
③ 储存是否影响该属性？
    └── 是（降解敏感项目）→ 同时纳入稳定性检测
    └── 否 → 仅放行检测即可
```

**典型案例分析**

| CQA 属性 | 纳入放行检测？ | 原因 |
|---|---|---|
| 效价（Potency） | 是 | 核心安全有效性指标，工艺无法完全保证批次间一致性，必须逐批检测 |
| 病毒清除效果 | 否 | 通过工艺验证（特定清除步骤的验证）保证，无适宜的逐批检测方法 |
| 糖型（Man5） | 是（或工艺内控） | 下游无法调整糖型，需监控；但部分项目可通过工艺内控（IPC）替代放行检测 |
| 内毒素 | 是 | 直接影响注射安全性，工艺无法完全保证，必须逐批检测 |

**可接受标准的设定依据**

- **基于工艺能力：** 收集历史批次数据，以均值 ± 3σ（或均值 ± 3 倍批间标准差）为初始范围，随批次积累逐步收紧
- **基于临床相关性：** 在有明确临床数据支持时，以不影响安全性/有效性的边界值为限度（功能性限度优于统计性限度）
- **基于降解动力学：** 货架期末与货架期初的差异需在质量标准范围内（放行时留有足够余量）

:::

## 质量标准随产品生命周期的动态演进机制

:::answer

产品质量标准不是静态文件，而是随产品知识积累、工艺成熟和临床数据获得而动态演进的质量管理工具。

**检测项目的动态调整**

**增加检测项目的触发条件**

- 发现新的产品相关杂质（如新的降解途径）：需开发新检测方法并纳入质量标准
- 工艺变更引入新的添加物质：需增加对应的工艺相关杂质检测
- 上市后稳定性研究发现新的降解产物：需将其纳入稳定性检测和放行标准
- 临床使用中出现新的安全信号：可能需要增加对应的安全性检测项目

**删除检测项目的科学依据**

- 大量批次数据（建议 ≥ 30 批）证明某项目持续在范围内，且分析数据表明检测无附加价值
- 下游工艺验证证明某杂质被可靠清除（如 HCD 经多步工艺验证后去除因子 ≥ 10⁶）
- 产品改变（如从冻干剂型改为液体制剂）导致某检测项目不再适用

**可接受标准的精确化过程**

| 批次数量 | 可接受标准状态 | 统计依据 |
|---|---|---|
| < 10 批（早期） | 宽泛范围（基于工艺一致性研究批次） | 批次数据不足，留有较大保守余量 |
| 10~25 批（临床 III 期） | 逐步收紧 | 初步建立工艺能力数据集 |
| ≥ 25~30 批（上市前后） | 基于统计学的最终范围 | 辉瑞研究认为 25~30 批可较好预测工艺能力 |
| ≥ 85 批（成熟商业化） | 最终确定，高置信度范围 | 充足的统计功效支持长期预测 |

**监管沟通节点**

质量标准的重大变更（如增加 CQA 检测项目、大幅收紧可接受标准）通常需要通过补充申请（Supplemental Application）提交监管机构审批，而小幅调整（如在已批准范围内的微调）可能仅需年度报告提交。

:::

## 分析方法验证的核心要素与生物制品特殊考量

:::answer

分析方法验证（Analytical Method Validation）是证明某分析方法适合其预期用途的科学过程，是任何分析方法在产品质量控制中正式使用前必须完成的工作。

**验证的法规基础**

- **ICH Q2(R2)：** 适用于理化分析方法（色谱、光谱、电泳等），提供验证参数的通用定义和可接受标准
- **中国 CDE 2005 年指导原则：** 《生物制品质量控制分析方法验证技术一般原则》，专门适用于免疫化学（ELISA）和生物学测定方法（细胞活性、动物试验）

**何时需要进行方法验证**

- 建立新的药品质量标准（新分子实体申报）
- 对已批准方法进行重大变更（仪器平台更换、关键试剂替换）
- 修订现行分析方法（方法改进或简化）
- 工艺变更导致产品中引入新杂质，需建立新的杂质检测方法

**主要验证参数的详细说明**

| 验证参数 | 定义 | 可接受标准参考 |
|---|---|---|
| **专属性（Specificity）** | 方法在干扰物质存在下准确测定分析物的能力 | 加标回收率 ≥ 98%；空白/干扰物无假阳性信号 |
| **准确性（Accuracy）** | 方法测量值与真实值的接近程度 | 回收率 98~102%（理化）；85~115%（生物学） |
| **精密度（Precision）** | 重复测定结果的一致性（分重复性、中间精密度、重现性） | 理化方法 RSD ≤ 2%；生物学方法 RSD ≤ 15~25% |
| **线性（Linearity）** | 方法在一定范围内产生与分析物浓度成比例信号的能力 | 相关系数 r ≥ 0.999（理化）；≥ 0.95（生物学） |
| **检测限（LOD）** | 能被可靠检测到的最小分析物量 | 以信噪比（S/N）≥ 3 为判断标准 |
| **定量限（LOQ）** | 能被定量的最小分析物量（满足精度和准确度要求） | S/N ≥ 10；RSD ≤ 20% |
| **耐用性（Robustness）** | 方法对有意引入的小变动的耐受能力 | 关键参数（pH ± 0.1、温度 ± 5°C）变化时结果无显著偏差 |

:::

## 参比物质的建立：从工作参考品到国家标准品的体系架构

:::answer

参比物质（Reference Standard/Material）是产品量值溯源和批次一致性评估的关键锚点，其建立质量直接决定每批放行检测数据的可信度。

**参比物质体系的层级架构**

```
国际标准品（WHO International Standard）
    ↓ 标化（溯源）
国家标准品（中国药典委 / NIFDC）
    ↓ 标化（溯源）
企业一级参考品（Primary Reference Standard, PRS）
    ↓ 标化（溯源）
企业工作参考品（Working Reference Standard, WRS）
    ↓ 用于
批次放行检测、稳定性研究、可比性研究
```

**企业参考品建立的核心要求**

**① 批次选择**

- 推荐使用已完成**全面结构确证**的代表性工艺批次制备
- 上市阶段优先选择**关键性临床批次（Pivotal Clinical Batch）**作为参考品，或用其进行标化
- 理由：将放行检测数据与临床安全性/有效性数据直接桥联，保证上市产品与临床样品的质量一致性

**② 表征要求**

参考品在建立时需完成以下全面表征：

| 表征项目 | 分析方法 |
|---|---|
| 一级序列确认 | LC-MS/MS 肽图（Peptide Mapping）+ N 端测序 |
| 分子量 | 完整质量（Intact Mass）质谱 |
| 糖型分析 | 2-AB UPLC N-糖谱 |
| 等电点 | iCIEF 或 IEF |
| 纯度 | SEC-HPLC、CE-SDS（还原/非还原） |
| 二硫键 | LC-MS 二硫键 Mapping |
| 比活性 | 效价检测 + 蛋白浓度 |

**③ 工作参考品的使用规范**

- 每次使用工作参考品前，应与一级参考品进行平行测定（交叉验证），确认效价赋值一致
- 工作参考品应分装为小剂量（单次使用量），避免反复冻融导致活性损失
- 储存条件通常为 -70°C 以下，建立稳定性监测计划（通常 6 个月、12 个月、24 个月取样测定效价）

**④ 参考品更换管理**

当一级参考品库存耗尽需建立新批次时，必须进行**新旧参考品的可比性标化（Bridging Study）**：
- 使用多种分析方法（效价、纯度、糖型、电荷变体等）平行比较新旧参考品
- 新参考品的效价赋值应基于旧参考品（溯源链不断）
- 提供桥接研究数据，证明新参考品质量与旧参考品等效，并向监管机构报告（视变更程度确定报告类别）

:::

## 生物类似药质量标准的建立：相似性评估框架与标准制定策略

:::answer

生物类似药质量标准的建立以"相似性评估"为核心逻辑，与原研药质量标准的关系并非直接复制，而是基于全面比对研究的科学论证过程。

**生物类似药"相似性"的监管定义**

| 监管机构 | 相似性定义核心 |
|---|---|
| **美国 FDA（PHS Act §351(i)）** | 候选药与参照药高度相似，尽管非活性组分间可有微小差异，但在安全性、纯度和效力方面无临床意义的差异 |
| **欧洲 EMA** | 基于全面比对研究证明在质量特性、生物学活性、安全性和有效性方面与参照药具有相似性 |
| **中国 CDE** | 在质量、安全性和有效性方面与已获准注册的参照药具有相似性，基于整体证据链综合评估 |

三者虽表述不同，但核心均强调**整体证据链**（药学 + 非临床 + 临床）的综合评估，不允许任何单一指标的孤立判断。

**生物类似药质量标准建立的主要挑战**

1. **原研药工艺不透明：** 无法获知原研药的生产工艺细节，只能通过反向分析建立候选药的质量 Profile
2. **天然批次间差异：** 原研药本身存在批次间糖型、电荷变体等天然变异，相似性窗口的设定需基于多批次原研药的统计分析
3. **检测方法差异：** 同一质量属性，候选药与原研药可能使用不同的分析平台，需建立方法等效性数据

**生物类似药质量标准的制定策略**

**步骤一：购买多批次原研药（COA + 实物）**

- 购买 ≥ 10 批（建议 15~20 批）不同生产批次的原研药
- 收集原研药的 COA 数据（官方放行数据），同时对实物进行自行检测分析
- 建立原研药各关键质量属性的参考范围（均值 ± 3SD）

**步骤二：建立候选药与原研药的相似性目标区间**

- 相似性目标区间（Similarity Target Range）通常为：候选药的目标范围与原研药历史范围高度重叠
- 对于影响 ADCC/CDC 活性的关键糖型（岩藻糖化、Man5），设定最严格的相似性窗口
- 可基于原研药批次范围的统计上下限（如 90% 置信区间），结合功能影响评估设定候选药的目标范围

**步骤三：差异的科学论证**

若候选药与原研药在某些质量属性上存在可量化差异，需提供：
- 该差异对生物学功能（活性、PK）无临床意义的科学证据（文献和/或实验数据）
- 差异在整体相似性评估中可接受的综合论证

:::

## 原液（DS）与成品（DP）质量标准的关键差异解析

:::answer

DS 与 DP 的质量标准并不相同，其差异基于风险管理理念和各步骤引入杂质的实际情况，科学地分配检测资源。

**DS 与 DP 质量标准差异的总体逻辑**

DS → DP 的生产过程主要包括制剂配制和灌装封口，不涉及复杂的化学反应或新的纯化步骤，因此：
- DS 阶段已控制的工艺相关杂质（HCP、HCD、Protein A 残留）在 DS→DP 过程中不会额外引入，**通常只在 DS 中检测**
- DS→DP 增加的安全性风险主要来源于灌装操作的微生物风险和颗粒引入，因此 **DP 增加无菌和不溶性微粒检测**

**典型 DS 与 DP 质量标准差异对比**

| 检测项目 | DS 检测 | DP 检测 | 差异原因 |
|---|---|---|---|
| **宿主细胞蛋白（HCP）** | ✓ | 通常不检 | DS→DP 过程不引入新 HCP |
| **宿主细胞 DNA（HCD）** | ✓ | 通常不检 | 同上 |
| **Protein A 残留** | ✓ | 通常不检 | 同上 |
| **微生物限度** | ✓（DS 中检测微生物限度） | — | DS 非无菌，控制微生物总数 |
| **无菌** | — | ✓ | DP 经除菌过滤后灌装，需验证无菌 |
| **不溶性微粒** | 通常不检 | ✓ | 灌装操作可能引入微粒，DP 安全性关键项 |
| **异常毒性** | 通常不检 | ✓（适用时） | DP 终产品的整体安全性兜底检查 |
| **水分（冻干制剂）** | — | ✓ | 仅适用于冻干 DP，DS 通常为液态 |
| **效价** | ✓ | ✓ | 两端均需检测，确保活性在整个流程中未损失 |
| **电荷变体** | ✓ | 通常转为稳定性监控 | DP 制备过程通常不影响电荷变体 Profile |

**关键原则总结**

DS 质量标准侧重于纯度和工艺相关杂质控制；DP 质量标准侧重于制剂安全性（无菌、颗粒、异常毒性）和功能一致性（效价、鉴别）。两套质量标准共同构成产品上市前的完整质量防线。

:::

## 参比品、标准品与对照品的定义体系与实践区分

:::answer

在生物制品质量控制中，"参比品""标准品""对照品""参考品"等术语长期存在混用现象，中国药典 2020 版在统一规范上已有进展，但实践中仍需厘清各术语的准确含义。

**中国药典标准物质的五类分类（《0291 国家药品标准物质通则》）**

| 类别 | 定义 | 生物制品应用场景 |
|---|---|---|
| **标准品** | 用于生物检定（效价、毒价等生物学测定） | 抗体效价标准品、内毒素标准品 |
| **对照品** | 用于理化测定部分的检测及仪器校准（色谱、电泳等系统适用性） | 肽图对照品、等电点对照品 |
| **参考品** | 用于生物效价和生物活性试验中的标准物质 | 重组蛋白活性参考品 |
| **对照药品** | 仿制药一致性评价用对照品 | 生物类似药可比性研究用原研药 |
| **校正品** | 用于仪器校正 | 凝胶柱分子量校正品 |

**参比品（Reference Standard）的特殊地位**

中国药典 2015 版将"参比品"作为重组 DNA 蛋白制品标准物质的专有名词，2020 版统一更名为"标准物质"，但正文中仍出现"参比品"的表述。

从实践操作角度，**参比品 ≈ 标准品 + 对照品 + 参考品的综合体**，即企业内部建立的、用于指导产品各类检测的总体参考标准物质：

```
企业参比品（Reference Standard）
    │
    ├── 用于效价/生物活性检测 → 发挥"标准品"功能
    ├── 用于肽图/IEF等理化检测 → 发挥"对照品"功能
    └── 用于稳定性研究/DS&DP放行 → 发挥"参考品"功能
```

**参比品的核心作用**

| 应用场景 | 具体作用 |
|---|---|
| **批次放行检测** | 作为效价测定的参照（相对效价 = 样品 / 参比品），确保放行数据具有可比性 |
| **稳定性研究** | 与各时间点稳定性样品对比，追踪产品随储存时间的质量变化 |
| **可比性研究** | 工艺变更或设施转移时，通过与参比品对比证明变更前后产品一致性 |
| **生物类似药桥接** | 用于将候选生物类似药与原研药质量数据进行桥接比较 |

**建立参比品的关键合规要求**

- 参比品批次应进行全面结构确证（含肽图、完整质量、糖型、二硫键、等电点等）
- 推荐使用关键性临床批次（Pivotal Clinical Batch）进行参比品的建立或标化
- 建立参比品稳定性监测计划，在货架期内定期检测效价并与初始赋值比较
- 更换参比品批次时进行桥接研究，保证量值传递的连续性和可溯源性
- 可参考 WHO《Recommendations for the evaluation, establishment and maintenance of WHO reference preparations》建立参比品管理体系

:::
