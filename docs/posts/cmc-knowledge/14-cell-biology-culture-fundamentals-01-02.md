## 细胞死亡的三种主要形式：凋亡、坏死与自噬的本质区分

:::answer

细胞死亡并非单一机制，在生物制药细胞培养中，理解三种死亡形式的触发条件和结果，对于优化培养工艺、提升细胞活力和产品质量具有直接的实践意义。

**三种细胞死亡形式的核心对比**

| 特征维度 | 细胞凋亡（Apoptosis） | 细胞坏死（Necrosis） | 细胞自噬（Autophagy） |
|---|---|---|---|
| **死亡性质** | 主动、程序性 | 被动、非程序性 | 主动、可逆（适度）/ 不可逆（过度） |
| **触发来源** | 细胞内/外信号（DNA 损伤、生长异常） | 外部急性损伤（机械、化学、病原体） | 营养匮乏、缺氧、氧化应激 |
| **能量需求** | 需要 ATP | 不需要（被动过程） | 需要 ATP |
| **基因调控** | 高度调控（Bcl-2 家族、Caspase 级联） | 无特异性基因调控 | 受 ATG 基因家族调控 |
| **细胞形态** | 细胞萎缩、核固缩、凋亡小体形成 | 细胞肿胀、膜破裂、胞内物外溢 | 自噬小泡形成、溶酶体降解胞内物 |
| **炎症反应** | 通常不引发（凋亡小体被安静清除） | 强烈引发（胞内物溢出激活免疫） | 通常不引发 |
| **生物制药影响** | 限制细胞增殖和存活，产品质量风险 | 加重纯化负担，可能影响产品完整性 | 适度有益（营养再生）；过度导致细胞死亡 |

**细胞凋亡（Apoptosis）：受控的细胞自杀程序**

凋亡是由特定信号激活的程序性细胞死亡，是机体维持细胞数量平衡的核心机制：
- **生理意义：** 清除受损细胞、控制细胞数量、维持机体内稳态
- **失调后果：** 凋亡不足 → 细胞不受控增殖（癌症、自身免疫病）；凋亡过度 → 细胞萎缩、器官损伤
- **在细胞培养中：** 凋亡是限制细胞活力和批次产率的主要因素之一，是工艺优化的重点控制对象

**细胞坏死（Necrosis）：创伤性被动死亡**

坏死是细胞受到超过耐受阈值的急性损伤后的非受控死亡：
- 形态学特征：细胞体积增大、细胞器膨胀、质膜破裂、胞内物质外溢
- 可引发周围组织的炎症反应（免疫系统被激活）
- 在细胞培养中：高剪切力、过高的乳酸/氨积累、极端 pH 或温度均可触发坏死

**细胞自噬（Autophagy）：营养再生的双刃剑**

自噬是细胞通过溶酶体降解自身胞内物质实现物质循环的保守机制：
- **适度自噬（保护性）：** 营养匮乏时降解细胞器和大分子，为细胞提供氨基酸、核苷酸等基本营养，维持细胞存活
- **过度自噬（损伤性）：** 持续营养匮乏导致自噬超过生理限度，损伤细胞功能，引发 II 型程序性细胞死亡
- **在细胞培养中：** 氨基酸缺乏是诱发 CHO 细胞自噬的主要因素，提示补料策略须确保关键氨基酸不发生耗竭

:::

## 细胞凋亡的三条经典信号通路与分子机制

:::answer

细胞凋亡并非单一的信号通路，而是通过三条主要途径在不同条件下被激活，最终汇聚于 Caspase 级联反应，执行细胞死亡程序。深入理解这三条通路，有助于有针对性地设计细胞工程改造策略。

**通路一：线粒体介导的内源性凋亡途径（内源途径）**

```
细胞内/外应激信号（DNA 损伤、营养缺乏、氧化应激）
    ↓
促凋亡蛋白（Bax、Bak）活化
    ↓
线粒体外膜通透性增加（MOMP）
    ↓
细胞色素 C（Cytochrome C）从线粒体释放至胞质
    ↓
与 Apaf-1、pro-Caspase-9 形成凋亡体（Apoptosome）
    ↓
Caspase-9 激活
    ↓
级联激活 Caspase-3/7（执行型 Caspase）
    ↓
细胞凋亡执行（DNA 片段化、细胞骨架降解）
```

**关键调控节点：** Bcl-2 家族蛋白是该通路的核心开关。
- 抗凋亡蛋白（Bcl-2、Bcl-XL）：抑制 MOMP，阻止细胞色素 C 释放
- 促凋亡蛋白（Bax、Bak、Bad）：促进 MOMP，启动凋亡

**通路二：内质网应激诱导的凋亡途径**

内质网是细胞蛋白质折叠和钙离子储存的核心场所，对应激因子高度敏感：

```
触发因素：
  ├─ 缺氧 / 缺糖 / ATP 耗竭
  ├─ 钙离子超载
  └─ 蛋白质折叠错误积累

    ↓
内质网稳态失衡 → 未折叠蛋白积累（内质网应激）
    ↓
未折叠蛋白反应（UPR）激活（保护性适应）
    ↓
若应激持续过强：
    ↓
UPR 从"保护性"转向"促凋亡性"
    ↓
激活 CHOP（促凋亡转录因子）→ 细胞凋亡
```

**在细胞培养中的意义：** 培养液中错误折叠蛋白的积累（如高表达期产物聚集）会触发内质网应激，导致宿主细胞凋亡，降低活细胞密度和产率。

**通路三：死亡受体介导的外源性凋亡途径**

通过细胞表面死亡受体接收凋亡信号，主要包括两种模型：

| 信号模型 | 受体/配体 | 激活机制 |
|---|---|---|
| **TNF 模型** | TNF 受体（TNFR1）+ 肿瘤坏死因子（TNF） | TNF 与受体结合 → TRADD 募集 → Caspase-8 激活 |
| **Fas-FasL 模型** | Fas（CD95）+ FasL | FasL 与 Fas 结合 → FADD 募集 → Caspase-8 激活 |

两条途径在 Caspase-8 激活后汇聚，通过蛋白酶级联反应激活下游执行型 Caspase（Caspase-3/7），同时可通过 Bid 蛋白切割激活线粒体途径，放大凋亡信号。

**三条通路的汇聚点**

```
内源途径（Caspase-9）
          ↘
           → Caspase-3/7（执行型）→ 细胞凋亡执行
          ↗
外源途径（Caspase-8）
          ↘（通过 Bid 切割）
           → 线粒体途径（放大信号）
```

> **关键认知：** 细胞凋亡一旦启动即不可逆转，正如"细胞自杀程序一旦运行便无法中止"。在细胞培养过程中，凋亡信号的早期预警（如细胞活力下降速率异常、培养液中 LDH 释放增加）比等待凋亡发生后再干预更为重要。

:::

## 细胞坏死的分子机制与坏死性凋亡（Necroptosis）

:::answer

细胞坏死（Necrosis）长期被认为是纯粹被动的细胞死亡，但近年研究揭示存在一种受调控的坏死形式——坏死性凋亡（Necroptosis），为理解细胞死亡的复杂性提供了新视角。

**经典细胞坏死的形态学特征**

细胞坏死无特异性表面或生化标志物，主要通过排除凋亡特征来识别：

| 特征类型 | 坏死的表现 |
|---|---|
| 阳性形态学特征 | 细胞体积增大、细胞器膨胀、质膜破裂、胞内容物大量外泄 |
| 阴性生化标志 | 无 Caspase 激活、无细胞色素 C 释放、无凋亡特征性 DNA 梯形条带 |
| 膜通透性变化 | 细胞膜提前通透（可被碘化丙啶 PI 染色，流式细胞仪区分） |

**坏死检测的标准方法**

在凋亡检测中，通常添加 **碘化丙啶（Propidium Iodide，PI）** 作为坏死细胞的标记物：
- PI 不能通过完整的活细胞细胞膜
- PI 可通过已破裂的坏死细胞膜进入，与 DNA 结合发出红色荧光
- 配合 Annexin V（凋亡早期标志），通过流式细胞仪实现活细胞 / 凋亡细胞 / 坏死细胞的三区分

```
流式细胞仪象限解读：
  Annexin V⁻ / PI⁻ → 活细胞
  Annexin V⁺ / PI⁻ → 早期凋亡
  Annexin V⁺ / PI⁺ → 晚期凋亡 / 继发性坏死
  Annexin V⁻ / PI⁺ → 坏死（原发性）
```

**坏死性凋亡（Necroptosis）：受调控的坏死形式**

坏死性凋亡是一种由外部创伤信号触发、但具有一定调控机制的程序性坏死，其核心信号通路为 RIPK3 依赖性通路：

```
外部死亡信号（TNF、TRAIL 等）
    ↓（当 Caspase-8 被抑制时）
RIPK1（受体相互作用蛋白激酶 1）激活
    ↓
RIPK3（受体相互作用蛋白激酶 3）激活
    ↓
MLKL（混合谱系激酶结构域样蛋白）磷酸化
    ↓
MLKL 插入细胞膜，导致膜穿孔
    ↓
细胞内容物外溢 → 炎症反应激活 → 坏死性细胞死亡
```

**与凋亡坏死的关键区别：** 坏死性凋亡死亡的细胞残余物不会被吞噬细胞清除，而是直接激活周围细胞的免疫反应，放大炎症信号。

**凋亡进展为继发性坏死**

在细胞培养中，如果吞噬细胞（巨噬细胞）不能有效清除凋亡小体，凋亡细胞会进展为继发性坏死（Secondary Necrosis）——细胞膜最终破裂，胞内物质外溢，这也是长期培养末期产品质量下降的重要原因之一。

:::

## 细胞自噬的三种类型与五阶段执行机制

:::answer

细胞自噬（Autophagy）由日本科学家大隅良典系统研究并于 2016 年获得诺贝尔生理学或医学奖，是细胞应对营养匮乏和应激状态的核心生存策略。

**自噬的三种主要类型**

根据底物运达溶酶体的方式，哺乳动物细胞自噬分为三类：

| 类型 | 运输方式 | 选择性 | 特点 |
|---|---|---|---|
| **巨自噬（Macroautophagy）** | 双层膜自噬小泡包裹 → 自噬溶酶体融合降解 | 非选择性（通常） | 最主要的自噬形式，通常所说"自噬"即指此类 |
| **微自噬（Microautophagy）** | 溶酶体膜直接内陷吞入 | 非选择性 | 规模较小，持续进行 |
| **分子伴侣介导的自噬（CMA）** | 特定蛋白经分子伴侣识别 → 溶酶体受体转运 | 高度选择性 | 仅降解含 KFERQ 基序的特定蛋白 |

**巨自噬的五阶段执行机制**

```
阶段一：起始（Initiation）
  mTOR 抑制或 AMPK 激活 → ULK1 复合物激活 → 启动自噬信号

阶段二：延长（Elongation）
  PI3K III 复合物激活 → 隔离膜（Phagophore）形成并延伸
  ATG5-ATG12-ATG16L 复合物参与膜延伸

阶段三：膜闭合（Closure）
  LC3-I 转化为 LC3-II，插入自噬小泡双层膜
  自噬体（Autophagosome）形成完成（直径约 0.5～1.5μm）

阶段四：成熟（Maturation）
  自噬体与溶酶体融合
  形成自噬溶酶体（Autolysosome）

阶段五：细胞质降解（Degradation）
  溶酶体酶（蛋白酶、核酸酶、脂肪酶等）降解内含物
  降解产物（氨基酸、核苷酸、脂肪酸）释放至胞质循环利用
```

**自噬在生物制药细胞培养中的双面作用**

| 自噬状态 | 触发条件 | 对细胞培养的影响 |
|---|---|---|
| **适度自噬（保护性）** | 短暂营养匮乏、轻度应激 | 降解损伤细胞器，回收营养物质，延长细胞存活时间，维持产品质量 |
| **过度自噬（损伤性）** | 持续严重营养匮乏、极端应激 | 细胞器过度降解，ATP 耗竭，细胞功能损伤，最终引发 II 型程序性细胞死亡 |

**自噬研究的实践启示**

Daniela 等人证明氨基酸缺乏可诱发 CHO 细胞自噬，提示在补料培养策略设计中须特别关注：
- 谷氨酰胺、天冬酰胺等关键氨基酸的持续供应（避免在培养中后期耗竭）
- 实时监控培养液中氨基酸浓度，基于消耗速率动态调整补料策略
- 防止"过度补料"（导致有害代谢副产物积累）与"补料不足"（触发自噬性死亡）之间的失衡

## 细胞凋亡的调控策略：培养环境优化与基因工程改造

:::answer

在生物制药细胞培养中，抑制细胞凋亡是提高活细胞密度（VCD）、延长有效培养时间和提升总产率的核心工艺目标，可通过两大策略实现。

**策略一：优化外部培养环境**

通过培养基成分调控和工艺参数管理，维持细胞处于"舒适区"，从源头减少凋亡信号的触发：

**营养物质管理**

| 关键营养物质 | 缺乏后果 | 控制策略 |
|---|---|---|
| 葡萄糖 | 能量匮乏，ATP 下降，触发凋亡 | 实时检测，维持在 2～5 g/L 范围内 |
| 谷氨酰胺 | 氮源不足，同时产氨水平异常 | 使用谷氨酰胺二肽（稳定性更好）或动态补料 |
| 天冬酰胺 | CHO 细胞必需氨基酸，缺乏触发自噬和凋亡 | 纳入补料培养基，监控培养液浓度 |

**工艺参数控制**

- **代谢副产物控制：** 乳酸和氨是最主要的凋亡触发因素，须维持在可接受范围（乳酸 < 3～4 g/L，氨 < 4～6 mM）
- **pH 和 DO 的平稳控制：** 避免短时间内剧烈波动——外部环境急剧改变导致的凋亡往往延迟 2～3 天才表现为细胞死亡，须前瞻性预防
- **温度切换策略：** 培养后期降温（37℃ → 32℃）可降低代谢速率，减少凋亡信号积累，延长存活时间

**重要认知：延迟效应**

细胞凋亡的触发与表现之间存在时间差：
```
DO/温度/pH 异常（极端条件）
    ↓ 当时检测细胞活率可能正常
    ↓ 2～3 天后
细胞活率明显下降
```
这意味着在线监控数据正常并不代表细胞无凋亡风险，须前瞻性维持培养环境的稳定。

**策略二：基因工程改造（抗凋亡细胞工程）**

通过过表达抗凋亡基因，从分子水平阻断凋亡通路：

**① Bcl-2 和 Bcl-XL 过表达（线粒体通路阻断）**

Bcl-2 和 Bcl-XL 是最主要的抗凋亡蛋白，通过抑制促凋亡分子（细胞色素 C）从线粒体释放来阻断凋亡：

| 宿主细胞 | 过表达效果 |
|---|---|
| NS0、CHO、BHK 细胞转染 Bcl-2 | 在血清缺乏、葡萄糖/谷氨酸/天冬酰胺缺乏或毒素存在时，细胞活率和适应能力大幅提升 |
| CHO 和 BHK 细胞过量表达 Bcl-XL | 有效抑制凋亡，延长有效培养时间 |

**② XIAP 和 CrmA 过表达（Caspase 直接抑制）**

X 连锁凋亡抑制蛋白（XIAP）直接抑制 Caspase-9/3/7，在 Bcl-2/Bcl-XL 的下游发挥作用：

```
Bcl-2/Bcl-XL（上游）→ 抑制线粒体促凋亡信号
                                ↓
XIAP（下游）→ 直接抑制 Caspase-9/3/7 → 双重保护
```

在 CHO 和 HEK-293 细胞中表达重组 XIAP 可显著提高细胞活率。

**两种策略的协同应用**

在实际细胞株开发中，可将基因工程改造（稳定过表达 Bcl-2 或 XIAP）与培养环境优化（营养物质精准控制、温度切换策略）结合使用，实现协同增效，最大化延长有效培养时间和总产率。

:::

## Pluronic F68 与 MSX 在细胞培养中的安全性参考

:::answer

在生物制药细胞培养中，Pluronic F68 和 MSX 是两种常用的培养基添加物，了解其毒理学参数有助于评估其使用安全性。

**Pluronic F68（泊洛沙姆 188）**

Pluronic F68 是一种非离子型表面活性剂，在细胞培养中广泛用于保护细胞免受通气搅拌产生的剪切力损伤：

- **核心功能：** 插入细胞膜脂质双层，增强细胞膜的机械稳定性，显著降低搅拌和通气引起的细胞破损率
- **使用浓度：** 生物反应器培养中通常使用浓度为 0.1%～1.0%（g/v）
- **毒理学参数：** 小鼠静脉注射 LD₅₀ = 1000 mg/kg；人体安全性转换系数为 0.081
- **安全性评估：** LD₅₀ 高，毒性极低，长期在 FDA 认可的人用产品生产中安全使用

**MSX（蛋氨酸亚砜亚胺，Methionine Sulfoximine）**

MSX 是谷氨酰胺合成酶（Glutamine Synthetase，GS）的特异性抑制剂，在 GS/MSX 选择体系中发挥核心作用：

- **核心功能：** 抑制内源性 GS 活性，筛选出高拷贝整合目的基因并具有 GS 活性的高表达细胞株
- **在 CHO 细胞株开发中的应用：** 利用 GS 基因作为选择标记，通过 MSX 浓度梯度筛选（通常 25～50 μM），逐步选择出高表达细胞株
- **毒理学参数：** 小鼠静脉注射 LD₅₀ = 100 mg/kg；人体安全性转换系数为 0.081
- **残留风险：** MSX 须在后续纯化步骤中有效去除，并在成品中进行残留量检测，评估对患者的安全性风险

**两者的关键区别**

| 参数 | Pluronic F68 | MSX |
|---|---|---|
| 主要用途 | 细胞保护（剪切力防护） | 细胞株筛选（GS 选择压力） |
| LD₅₀（小鼠，iv） | 1000 mg/kg | 100 mg/kg |
| 相对毒性 | 极低 | 较低，但显著高于 Pluronic F68 |
| 成品中残留关注 | 低（大分子，易去除） | 须检测并评估 |

:::

## 抗体的发现历史与单克隆抗体技术的诞生

:::answer

抗体的发现和单克隆抗体技术的建立是现代生物医药史上的里程碑事件，奠定了抗体药物这一最重要生物制药品类的科学基础。

**抗体的基本定义**

抗体是由浆细胞（效应 B 细胞）分泌的、免疫系统用于识别和中和外来物质（抗原）的大型 Y 形糖蛋白，仅存在于脊椎动物的血液等体液中及 B 细胞细胞膜表面。每种抗体对应识别一个独特的抗原表位，这种高度特异性是抗体作为治疗药物的核心价值所在。

**抗体发现的历史脉络**

| 年代 | 里程碑事件 | 贡献者 |
|---|---|---|
| **1890 年** | 在暴露于白喉毒素和破伤风毒素的动物血液中发现可中和毒素的物质，命名为"抗体（antibody）" | Emil von Behring（德国）、Kitasato Shibasaburo（日本） |
| **1920 年代** | 发现抗原可被抗体沉淀，揭示抗体的化学本质为蛋白质 | Michael Heidelberger、Oswald Avery（美国） |
| **1948 年** | 发现浆细胞（B 细胞分化而成）是产生抗体的效应细胞 | Astrid Fagreaus（瑞典） |
| **1960 年代** | 发现多发性骨髓瘤（浆细胞来源肿瘤），其单克隆免疫球蛋白为抗体研究提供了同质性材料 | 多位研究者 |
| **1975 年** | 将免疫小鼠脾脏细胞与骨髓瘤细胞（P3-X67Ag8）融合，建立杂交瘤技术，成功制备单克隆抗体 | Köhler 和 Milstein（英国） |

**Köhler-Milstein 杂交瘤技术的核心原理**

```
免疫小鼠（注射 SRBC 抗原）
    ↓
获取脾脏细胞（含 SRBC 特异性 B 细胞，可产生抗体，但不能永生）
    ↓
与骨髓瘤细胞（P3-X67Ag8，永生但不产生抗体）融合
    ↓
杂交瘤细胞（具有 B 细胞的抗体产生能力 + 骨髓瘤细胞的永生增殖能力）
    ↓
HAT 培养基筛选（只有杂交瘤细胞存活）
    ↓
含 SRBC 琼脂平板克隆筛选
    ↓
单克隆抗体大量制备
```

**杂交瘤技术的历史意义**

此项技术获得 1984 年诺贝尔生理学或医学奖。自 1975 年至今，单克隆抗体技术历经近 50 年发展，衍生出噬菌体展示、转基因小鼠、单 B 细胞克隆等多种先进筛选平台，为制备各类治疗性抗体提供了技术基础。

:::

## 治疗性抗体的四代演进：从鼠源到全人源的人源化之路

:::answer

治疗性抗体自 1986 年第一个产品获批以来，经历了四个代际的系统性人源化改造，不断降低免疫原性、提升临床安全性和疗效。

**四代抗体的演进逻辑**

免疫原性是鼠源抗体最核心的临床障碍，人源化改造的本质是用人源序列逐步替换鼠源序列，在保留抗原结合特异性的同时，使抗体对人体免疫系统"更像自身蛋白"。

```
鼠源（100% 鼠源）→ 嵌合（~65% 人源）→ 人源化（>90% 人源）→ 全人源（100% 人源）

免疫原性：高 ────────────────────────────────────────→ 低
```

**第一代：鼠源单抗（Murine mAbs，后缀 -omab）**

- **代表药物：** Orthoclone OKT3（1986 年，强生），全球第一个 FDA 批准的治疗性单抗，用于防止肾脏移植后宿主排斥
- **氨基酸序列：** 100% 鼠源
- **临床问题：**
  - 人体将鼠源抗体识别为异体蛋白，产生人抗鼠抗体（HAMA，Human Anti-Mouse Antibody）
  - HAMA 反应加速药物清除，大幅降低疗效，尤其在需要长期用药的慢性病治疗中
  - 少数患者发生严重过敏反应，个别病例导致死亡

**第二代：嵌合抗体（Chimeric mAbs，后缀 -ximab）**

- **代表药物：** ReoPro（1994 年，礼来 + 强生），首个 FDA 批准的嵌合抗体
- **结构特点：** 鼠源可变区（VH + VL，约 35%）+ 人源恒定区（CH + CL，约 65%）
- **改进效果：** 显著降低 HAMA 反应，半衰期延长，疗效提升
- **残留问题：** 可变区中的框架区（Framework Region，FR）仍为鼠源，存在残留免疫原性，可诱发 HACA（Human Anti-Chimeric Antibody）反应

**第三代：人源化抗体（Humanized mAbs，后缀 -zumab）**

- **技术原理：** CDR 移植（CDR Grafting）——将鼠源抗体的 3 个互补决定区（CDR）移植到人源抗体的骨架上
- **人源化程度：** > 90%（仅 CDR 区域保留鼠源序列，其余均为人源）
- **代表药物：**
  - 帕利珠单抗（Palivizumab，Synagis，1998 年）：全球第一个获批的人源化单抗
  - 曲妥珠单抗（Trastuzumab，Herceptin，1998 年）：HER2 阳性乳腺癌明星药物
- **改进效果：** 基本解决鼠源性免疫原性，临床安全性大幅提升
- **技术挑战：** CDR 移植过程复杂（需要对 FR 区进行回复突变以保持结合活性），费时费力

**第四代：全人源化抗体（Fully Human mAbs，后缀 -umab）**

- **两种主要技术平台：**
  - **转基因小鼠平台（如 XenoMouse、VelocImmune）：** 将小鼠免疫球蛋白基因敲除，替换为人源免疫球蛋白基因，免疫后直接产生全人源抗体
  - **噬菌体展示技术（Phage Display）：** 构建人源抗体库，通过体外筛选获得全人源抗体
- **人源化程度：** 100% 人源
- **代表药物：** Adalimumab（Humira，2002 年），全球销售额长期占据首位的单抗药物
- **优势：** 免疫原性最低，临床安全性最优，无需复杂的人源化改造过程

**FDA 批准的单抗命名规则（后缀含义）**

| 后缀 | 来源类型 | 示例 |
|---|---|---|
| -omab | 鼠源（100%） | Muromonab（OKT3） |
| -ximab | 嵌合（鼠/人） | Rituximab、Infliximab |
| -zumab | 人源化（>90% 人源） | Trastuzumab、Bevacizumab |
| -umab | 全人源（100%） | Adalimumab、Pembrolizumab |

## 单抗药物市场的三大驱动力：老龄化、支付能力与医保扩容

:::answer

中国单抗药物市场的快速增长，由人口结构变化、消费能力提升和医疗保障政策三重力量共同驱动，形成了供需两侧协同扩张的良性格局。

**驱动力一：人口老龄化加速拉动需求**

老年人癌症、自身免疫病、心血管疾病等慢性疾病发病率显著高于其他人群，医疗保健支出与年龄呈正相关：

- 随着中国老龄化进程加快，肿瘤、风湿性疾病等单抗适应症的患者基数持续扩大
- 预测到 2030 年，中国 60 岁以上人口将超过 4 亿，相应的单抗药物需求将持续增长

**驱动力二：居民保健意识与支付能力提升**

- 随着人均 GDP 持续增长，居民医疗费用支出比例上升
- 越来越多的患者能够并愿意支付高价值创新药物的费用
- 医疗保险（含商业保险）覆盖范围扩大，进一步降低了患者的实际支付负担

**驱动力三：医保覆盖持续扩容（最核心的政策驱动力）**

医保目录纳入是单抗药物在中国实现放量的决定性因素：

- **2017 年里程碑事件：** 人社部将 36 种谈判药品纳入国家医保目录乙类范围，其中包括曲妥珠单抗等 5 个单抗药物
- **纳入医保后的连锁效应：**

```
单抗药物纳入医保
    ↓
医保报销 60%～70% 的费用
    ↓
药品价格谈判后大幅下降（降价幅度通常 40%～70%）
    ↓
患者实际支付压力大幅降低
    ↓
用药可及性显著提升 → 处方量快速增加
    ↓
市场规模快速扩大（量增价降，但总额显著上升）
```

- 自 2017 年起，每年国家医保目录动态调整已将更多单抗药物纳入，医保扩容趋势持续强化

**中国单抗市场的结构性机遇**

随着国产生物类似药的大量上市和创新单抗的持续获批，中国单抗市场正从"高价、低可及性"向"更合理价格、更高可及性"转变，进入患者受益与产业发展双赢的新阶段。

:::

## 生物类似药的全球定义体系与监管差异

:::answer

生物类似药（Biosimilar）在不同监管机构框架下的定义存在细微差异，但核心逻辑一致：通过全面的可比性研究证明与参照药的高度相似性。

**各主要监管机构的定义对比**

| 监管机构 | 定义核心要素 | 首批时间 |
|---|---|---|
| **中国 NMPA** | 在质量、安全性和有效性方面与已获准注册的参照药具有相似性的治疗用生物制品；氨基酸序列原则上应与参照药相同 | 2015 年 |
| **美国 FDA** | 与参照产品高度相似（尽管非活性成分可有差别）；在安全性、纯度和效价方面与参比药物没有临床意义的差别 | 2015 年（Zarxio） |
| **欧盟 EMA** | 包含 EEA 已批准的原研生物药活性成分变体的生物药物；须通过全面可比性研究在质量特性、生物活性、安全性和效力方面与参比药物建立相似性 | 2006 年（Omnitrope，全球最早） |
| **WHO** | 与已批准的参比生物治疗产品在质量、安全性和效力方面均相似的生物治疗产品 | — |

**全球生物类似药监管的里程碑**

```
2005 年：欧盟率先发布《生物类似药指南》，建立第一个生物类似药监管框架
2006 年：EMA 批准全球首款生物类似药 Omnitrope（生长激素 somatropin）
2010 年：美国推出《生物药价格竞争及创新法案》（BPCIA），建立生物类似药审批通道
2015 年：FDA 批准美国首款生物类似药 Zarxio（非格司亭生物类似药）
2015 年：中国出台《生物类似药研发与评价技术指导原则（试行）》
```

**中国 NMPA 对宿主细胞和表达体系差异的特殊要求**

若生物类似药研发过程中采用不同于参照药的宿主细胞（如 CHO vs NS0）或表达体系，须进行充分研究并提供相应数据，证明这种差异不影响最终产品的质量、安全性和有效性。这一要求体现了生物类似药监管的科学性和灵活性——允许工艺差异，但要求用数据证明结果相似。

## 生物类似药与化学仿制药的本质差异

:::answer

理解生物类似药与化学仿制药的根本区别，是理解为何生物类似药不称为"生物仿制药"的关键，也是理解其研发逻辑和定价策略的基础。

**分子层面的根本差异**

| 对比维度 | 化学仿制药（小分子） | 生物类似药（大分子） |
|---|---|---|
| 分子量 | 通常 < 1,000 Da | 通常 > 10,000 Da（单抗约 150,000 Da） |
| 结构特征 | 结构明确，化学结构式完整描述 | 结构高度复杂，含翻译后修饰（糖基化等） |
| 均一性 | 高度均一（单一化学实体） | 固有异质性（多种分子实体共存） |
| 分析表征充分性 | 现有方法可完整表征 | 现有方法无法完全描述所有分子特征 |
| "完全仿制"可行性 | 技术上完全可行 | 技术上几乎不可能（生产过程决定产品特性） |

**"生物类似药"而非"生物仿制药"的深层原因**

用一个形象的比喻：

```
化学仿制药 → 仿制一根绳子上系成的疙瘩：
  只需确保绳子成分（化学结构）完全相同即可

生物类似药 → 仿制一根绳子上系成的复杂立体疙瘩：
  不仅绳子每根纤维（一级序列）要相同
  还要立体结构（高级结构：二级/三级/四级）相同
  甚至表面的"装饰"（糖基化等翻译后修饰）也要相同
  → 几乎不可能完全一致，只能做到"高度相似"
```

**"相似"而非"相同"在监管中的体现**

FDA 明确指出：生物类似药与参照药"高度相似"，活性成分可有细微差别，但在产品的安全性、纯度和有效性方面没有**临床意义**的差别。这一定义接受了生物制品固有的分子异质性，同时对临床层面的等效性设定了明确要求。

**竞争格局与定价逻辑的差异**

| 维度 | 化学仿制药 | 生物类似药 |
|---|---|---|
| 研发难度 | 低（证明 BE 即可） | 高（须完整可比性研究体系） |
| 研发成本 | 低（数百万至数千万美元） | 高（通常 1～2 亿美元以上） |
| 竞争模式 | 纯价格竞争（同质化产品） | 差异化竞争（存在品牌、质量认知差异） |
| 定价折扣 | 通常原研价格的 20%～30% | 通常原研价格的 70%～85%（折扣相对较小） |
| 商品名授权 | 无商品名（仅通用名） | NMPA 等机构可授予商品名 |

> **核心价值：** 生物类似药的战略意义在于通过引入竞争降低高价生物药的市场价格，提高患者可及性，同时维持足以支撑研发投入的价格水平，实现患者、支付方和产业界的多方共赢。

:::

## 生物类似药对医疗健康生态的系统性价值

:::answer

生物类似药的到来对医疗健康体系的各个利益相关方——患者、医疗机构、医保部门和制药产业——均产生了深远的系统性影响，整体上推动了社会福利的提升。

**对患者：提升高价生物药的临床可及性**

- 原研生物药价格高昂（如利妥昔单抗、曲妥珠单抗），许多患者因经济原因无法获得
- 生物类似药以更低的价格（通常为原研药的 70%～85%）进入市场，配合医保报销，使更多患者能够负担得起
- 生物类似药的产能扩大也有效保障了药物供应的稳定性

**对医保：缓解支付压力，保障基金可持续性**

- 老龄化加剧、慢性病患者增加，医保基金面临持续上涨的支付压力
- 生物类似药通过竞争驱动降价，每个品种的医保支出降低，释放资金用于覆盖更多适应症和患者
- 估算显示，生物类似药上市后 5 年内可节省数十亿至数百亿人民币的医保支出

**对医疗机构：优化用药结构，提升诊疗质量**

- 生物类似药为临床医生提供了更多治疗选择，在疗效相当的前提下降低医疗成本
- 更多患者能够按照指南推荐的标准方案治疗，而非因经济原因降级用药

**对产业：倒逼创新升级，加速产业转型**

```
原研药专利到期 → 生物类似药进入市场
    ↓
原研企业市场份额被侵蚀
    ↓
原研企业被迫加大新药研发投入（创新 First-in-Class 产品）
    ↓
生物类似药企业在竞争中积累技术能力和资金
    ↓
部分企业向创新生物药转型
    ↓
整体产业加速技术升级和创新能力提升
```

**中国生物类似药产业的特殊意义**

中国生物类似药产业的快速发展（已有多个产品获批），不仅直接降低了国内患者的用药成本，也通过技术积累为中国生物药走向国际市场、参与全球竞争奠定了基础。

:::

## 癌症的本质：定义、特征与发生机制

:::answer

**医学定义**

癌（Cancer）在医学上特指起源于**上皮组织**的恶性肿瘤；起源于间叶组织的恶性肿瘤称为肉瘤（Sarcoma）。日常语境中"癌症"泛指所有恶性肿瘤。

**癌症的六大生物学特征（Hallmarks of Cancer）**

2000 年 Hanahan 和 Weinberg 在《Cell》发表的《癌症的标志》定义了癌细胞区别于正常细胞的核心特征，2011 年更新版进一步扩展：

```
原始六大特征：
  1. 自给自足生长信号（无需外部生长因子）
  2. 对抗生长信号不敏感
  3. 逃避凋亡
  4. 无限复制潜力（端粒酶激活）
  5. 持续血管生成（肿瘤血管新生）
  6. 组织侵袭和转移

更新增加特征：
  7. 能量代谢重编程（Warburg 效应）
  8. 免疫逃逸
```

**癌症的发生是多步骤、多因素的复杂过程**

```
正常细胞
    ↓（致癌因素长期作用，平均 15～20 年）
原癌基因激活 / 抑癌基因失活
    ↓
癌前病变（轻度 → 中度 → 重度不典型增生）
    ↓（轻中度可逆，重度为癌前病变）
原位癌（局限于上皮层内）
    ↓
浸润癌（突破基底膜）
    ↓
转移癌（经淋巴道、血液、种植方式扩散）
```

**与吸烟、感染、环境污染、遗传因素、慢性刺激和内分泌异常**密切相关（详见后续章节）。

:::

## 癌症的病因体系：外源性与内源性因素全解析

:::answer

恶性肿瘤的病因尚未完全阐明，目前较为明确的致癌因素可分为外源性和内源性两大类，两者常相互作用，协同促进癌症发生。

**外源性因素（环境因素）**

**① 生活习惯**

| 危险行为 | 相关癌症类型 |
|---|---|
| 吸烟（任何形式） | 约 90% 的肺癌由烟草引起；同时与口腔癌、咽喉癌、食管癌、膀胱癌等相关 |
| 过量饮酒 | 口腔癌、咽喉癌、食管癌、肝癌 |
| 高脂肪高热量饮食 | 乳腺癌、子宫内膜癌、前列腺癌、结肠癌 |
| 食用霉变食物 | 黄曲霉毒素 → 肝癌 |
| 饮用污染水 | 食管癌、胃癌 |

**② 环境污染与职业暴露**

WHO 确认的致癌物包括：砷、石棉、联苯胺、4-氨基联苯、铬、乙烯雌酚、煤焦油、矿物油、放射性氡气等，通过皮肤接触、呼吸和消化道进入人体。

**③ 生物因素（病原体）**

| 病原体类型 | 相关癌症 |
|---|---|
| EB 病毒（EBV，DNA 病毒） | 鼻咽癌、伯基特淋巴瘤 |
| 人乳头瘤病毒（HPV，DNA 病毒） | 宫颈癌（HPV 16/18 型） |
| 乙型肝炎病毒（HBV，DNA 病毒） | 肝细胞癌 |
| T 细胞白血病病毒（HTLV，RNA 病毒） | T 细胞白血病/淋巴瘤 |
| 幽门螺杆菌（Hp，细菌） | 胃癌、MALT 淋巴瘤 |
| 埃及血吸虫（寄生虫） | 膀胱癌 |
| 黄曲霉菌及其毒素（真菌） | 肝癌 |

**④ 医源性因素**

- 电离辐射（X 线、放射性核素）→ 皮肤癌、白血病
- 细胞毒药物（烷化剂）、免疫抑制剂 → 继发性肿瘤
- 雌激素 → 子宫内膜癌

**内源性因素**

**① 遗传因素（遗传易感性）**

直接遗传的肿瘤极少，更多是遗传了对致癌因素的易感性：

| 遗传改变 | 相关肿瘤 |
|---|---|
| APC 基因胚系突变 | 家族性腺瘤性息肉病（FAP）→ 几乎 100% 发展为结肠癌 |
| BRCA1/BRCA2 突变 | 乳腺癌发生率高达 80% 以上 |
| 染色体不稳定综合征 | 多种血液系统肿瘤 |

**② 免疫因素**

- 先天性或后天性免疫缺陷（如 AIDS 患者）恶性肿瘤发生率显著增高
- 正常免疫功能人群也可发生癌症，原因在于肿瘤能主动逃脱免疫监视

**③ 内分泌因素**

- 雌激素和催乳素与乳腺癌发生相关
- 生长激素过度分泌可刺激某些肿瘤生长

:::

## 癌症作为慢性病的重新定义：演进过程与带瘤生存的科学依据

:::answer

2016 年，世界卫生组织将癌症重新定义为"可以治疗、控制甚至治愈的慢性病"，这一定性改变了公众和医学界对癌症的传统认知，具有深远的临床和社会意义。

**慢性病的定义基础**

慢性病的核心特征：病程长、难以自愈、积累性发展、不具传染性。从正常细胞演变为癌症，通常需要 **10～20 年甚至更长时间**，完全符合慢性病的时间特征。

**癌症从正常细胞到晚期的发展时间轴**

```
正常细胞
    ↓ 10～20 年（致癌因素持续作用，基因突变积累）
单个癌细胞形成
    ↓ 1～5 年（倍增 20 次后）
约 1 万个细胞的微小病灶（针尖大小，影像学无法发现）
    ↓ 持续倍增至第 30 次
约 10 亿个细胞（豌豆大小，部分影像学可发现）
    ↓
临床可检测的肿瘤
    ↓ 数月至数年
浸润 → 转移 → 晚期
```

**不同癌症的自然病程参考**

| 癌症类型 | 典型特征 | 带癌生存可能性 |
|---|---|---|
| 乳腺癌 | 临床发现肿块前平均隐匿约 12 年；确诊后自然病程 2～3 年 | 早期患者 5 年生存率 > 95% |
| 肝细胞癌（"癌中之王"） | 从甲胎蛋白升高到晚期约 2 年；发现到死亡约 3～6 个月 | 早期治疗效果差异大 |
| 前列腺癌 | 许多老年男性带瘤生存但不影响寿命 | 高带瘤生存率 |

**尸检数据支持带癌生存的科学依据**

研究数据揭示了一个重要事实：

- 70 岁以上老年人因非癌症原因死亡的尸检中，**50% 发现有癌肿存在**，但生前从未出现临床症状
- 这证明并非所有癌症都会表现出临床症状，也不会对健康产生实质性损害
- "带瘤生存"不仅是临床现实，也是肿瘤生物学的内在规律

**对癌症治疗理念的深远影响**

将癌症定义为慢性病，推动了治疗目标从"彻底消灭肿瘤"向"长期控制疾病、维持生活质量"的转变，为靶向治疗、免疫治疗等新型疗法的发展提供了理论框架，也为癌症患者的全程管理（包括心理支持、康复管理、并发症预防）提供了新的指导方向。

:::

## 癌症的现代治疗体系：从传统疗法到免疫治疗的范式演进

:::answer

癌症治疗已从单一的手术切除演进为涵盖手术、化疗、放疗、靶向治疗和免疫治疗的综合治疗体系，不同疗法各有适用场景，通常需要联合使用以实现最优疗效。

**五大治疗方式的系统对比**

**① 手术治疗（Surgery）**

- **适用场景：** 实体瘤、局限性肿瘤（未发生广泛转移）
- **优势：** 直接去除肿瘤组织，对早期局限性肿瘤治愈率高
- **局限性：** 难以清除微小转移灶；部分肿瘤位于重要器官附近，手术风险高；无法用于血液系统恶性肿瘤
- **通常配合化疗或放疗使用**，以清除残留的少量癌细胞

**② 化学治疗（Chemotherapy）**

- **原理：** 通过干扰细胞周期的不同阶段（DNA 复制、有丝分裂等）抑制和杀死快速分裂的细胞（癌细胞分裂速度通常快于正常细胞）
- **给药方式：** 口服或注射，经血液运送至全身（全身化疗），或局部给药（区域化疗）
- **优势：** 可用于转移性癌症（全身覆盖），超过 100 种化疗药物可选
- **挑战：** 无法精确区分癌细胞和正常细胞，对快速分裂的正常细胞（造血细胞、消化道黏膜、毛囊）也有损伤
- **周期管理：** 化疗通常分多个周期，周期间隔允许正常细胞从损伤中恢复

**③ 放射治疗（Radiotherapy）**

- **原理：** 高能射线（X 射线、伽马射线）损伤癌细胞 DNA，阻止细胞分裂，最终导致癌细胞死亡
- **适用场景：** 局部肿瘤（外照射）；部分体内放射（近距离放疗）；放射性核素治疗
- **优势：** 局部精准，早期癌症效果好，副作用相对较小；超过 50% 的癌症患者接受放疗
- **局限性：** 对转移性癌症效果有限；有极小概率引发二次癌症

**④ 靶向治疗（Targeted Therapy）**

- **原理：** 针对癌细胞特有的分子靶点（基因突变、异常蛋白、信号通路）进行精准干预，最大程度避免对正常细胞的损伤
- **主要类型：**
  - 信号通路抑制剂（阻断癌细胞生长分裂信号）
  - 血管生成抑制剂（阻断肿瘤新血管形成，切断营养供应）
  - 蛋白质降解靶向嵌合体（PROTAC，降解致癌蛋白）
  - 抗体偶联药物（ADC，精确递送毒素至癌细胞）
- **优势：** 比传统化疗更精准，毒副作用相对较小
- **局限性：** 需要明确的靶点（须进行分子诊断）；肿瘤可发展耐药性

**⑤ 癌症免疫治疗（Cancer Immunotherapy，2018 年诺贝尔奖认可）**

- **核心理念：** 不直接攻击癌细胞，而是激活和增强患者自身的免疫系统，使其更有效地识别和消灭癌细胞
- **主要类型：**
  - **免疫检查点抑制剂：** 解除癌细胞对免疫细胞的抑制（PD-1/PD-L1 抗体、CTLA-4 抗体）
  - **CAR-T 细胞治疗：** 将患者 T 细胞进行基因改造，使其高效识别并杀伤癌细胞
  - **肿瘤疫苗：** 激活免疫系统对特定肿瘤抗原的识别
  - **细胞因子治疗：** 增强免疫细胞活性（IL-2、干扰素等）
- **优势：** 对部分癌症可实现长期缓解甚至治愈（尤其是黑色素瘤、肺癌）；副作用类型不同于化疗
- **局限性：** 仅对部分患者有效；免疫相关不良反应（irAE）可能严重

**联合治疗的趋势**

现代癌症治疗强调多模式综合治疗，如：化疗 + 免疫治疗、靶向治疗 + 免疫治疗、手术 + 术后化疗/放疗，通过协同机制提高总体疗效，同时管理各疗法的副作用。

:::

## 癌症的潜伏期：从基因突变到临床诊断的漫长进程

:::answer

癌症不是一夜之间发生的，而是一个历经数十年的基因损伤积累过程。理解癌症的潜伏期，有助于深刻认识早筛早诊的意义。

**癌症潜伏期的时间规律**

从接触致癌因素到癌症临床发生，平均潜伏期为 **15～20 年**，有的长达数十年。

```
致癌因素持续作用（如吸烟、病毒感染、化学物质暴露）
    ↓ 数年至数十年
基因突变积累（原癌基因激活、抑癌基因失活）
    ↓
正常细胞 → 轻度不典型增生 → 中度不典型增生
    （此阶段若致病因素消除，可自然恢复）
    ↓
重度不典型增生（癌前病变，已有癌变风险）
    ↓
原位癌
    ↓（数年）
浸润癌 → 转移癌
```

**单个癌细胞到可检测肿瘤的倍增过程**

| 倍增次数 | 细胞数量 | 肿瘤大小 | 可检测状态 |
|---|---|---|---|
| 20 次（约 1～5 年） | 约 1 万个 | 针尖大小（< 1 mm） | 影像学无法检出 |
| 30 次（更长时间） | 约 10 亿个 | 豌豆大小（约 1 cm） | 部分影像学可检出 |
| > 30 次 | 数十亿～数百亿 | 临床可触及 | 通常可检出 |

**从癌变到不同阶段的时间参考**

- 乳腺癌：临床发现肿块前平均隐匿 **12 年**
- 食管癌：从轻度不典型增生到重度不典型增生需数年
- 肝细胞癌：从甲胎蛋白升高（单个癌变细胞期）到晚期约 **2 年**

**潜伏期认知对癌症预防的意义**

- 致癌因素的早期干预（如戒烟）可在潜伏期内阻止或延缓癌症进展
- 定期体检的价值在于在潜伏期的早期阶段（轻中度不典型增生）即发现病变，实现可逆性干预
- 早发现可将治愈率从晚期的 < 20% 提升至早期的 > 80%～95%

:::

## 癌症诊断：从初步筛查到病理确诊的标准流程

:::answer

癌症诊断遵循从"初步影像学筛查"到"病理组织确诊"的标准两步法，病理诊断是所有癌症诊断的**金标准**，任何其他方法都只能作为初步参考。

**第一步：初步诊断（影像学筛查）**

通过非侵入性或微创方法发现可疑病变：

| 检查方法 | 原理 | 适用场景 | 局限性 |
|---|---|---|---|
| **CT（计算机断层扫描）** | 不同组织对 X 射线透过率差异 → 断面图像重建 | 发现微小病变、评估肿瘤范围 | 有辐射；无法确定良恶性 |
| **MRI（磁共振成像）** | 氢原子在磁场中的共振信号 | 软组织分辨率高，脑、脊髓、骨盆病变 | 费时，有禁忌症（金属植入物） |
| **超声检查（彩超）** | 超声波反射信号 | 腹部脏器、乳腺、甲状腺的初步筛查 | 分辨率有限，操作者依赖性强 |
| **PET-CT** | 氟代脱氧葡萄糖（FDG）代谢显像 | 全身肿瘤筛查、分期评估、治疗评效 | 费用高，辐射量较大 |
| **肿瘤标志物检测** | 血清中特定蛋白/抗原水平 | 辅助筛查（如 PSA 前列腺癌、AFP 肝癌）| 特异性和敏感性均有限，无法单独确诊 |

**第二步：病理诊断（确诊金标准）**

通过获取组织样本，在显微镜下由病理科医生直接观察细胞形态，作出最终诊断：

**获取组织样本的主要方式**

- **穿刺活检（Biopsy）：** 细针穿刺（FNA）或粗针穿刺（Core Needle Biopsy），创伤小，适合浅表或影像学可引导的肿瘤
- **内镜活检：** 消化道、支气管等腔道肿瘤的直视下取样
- **手术切除活检：** 切除可疑病变，提供完整的组织学信息

**病理诊断的核心内容**

- 是否为恶性肿瘤（癌症确诊）
- 肿瘤类型（如腺癌、鳞癌、大细胞癌等）
- 组织学分级（高分化 / 中分化 / 低分化）
- 免疫组化（IHC）标志物（如 HER2、PD-L1、Ki67）
- 分子病理检测（EGFR 突变、ALK 融合、MSI 状态等）——指导靶向治疗选择

> **临床核心原则：** 在没有病理诊断的情况下，无论影像学表现多么典型，都不能最终确诊癌症，也不应启动根治性治疗。"不明来源的癌"须持续寻找原发灶，直至获得病理确认。

:::

## 癌症的预防策略：从国家层面到个人行为的多维干预

:::answer

癌症是可以预防的，世界卫生组织估计约 30%～50% 的癌症死亡是可以预防的。预防策略涵盖国家政策、环境管理、生活方式干预和定期筛查多个层面。

**一级预防：消除致癌因素（最根本的预防）**

| 预防措施 | 科学依据 | 可预防的相关癌症 |
|---|---|---|
| **戒烟（优先级最高）** | 吸烟与 90% 以上肺癌相关，还与多种癌症有关 | 肺癌、口腔癌、食管癌、膀胱癌等 |
| **预防感染** | 接种 HPV 疫苗、乙肝疫苗；根除幽门螺杆菌 | 宫颈癌、肝癌、鼻咽癌、胃癌 |
| **控制体重（BMI 18.5～24.9）** | 肥胖是明确的癌症危险因素 | 乳腺癌、子宫内膜癌、结直肠癌等 |
| **科学运动（每周≥150 分钟中等强度）** | 运动降低多种癌症风险 | 结直肠癌、乳腺癌、子宫内膜癌 |
| **合理膳食** | 高纤维、低加工肉、限盐饮食 | 结直肠癌、胃癌 |
| **限制饮酒（最好不饮）** | 饮酒与多种癌症正相关 | 肝癌、食管癌、乳腺癌、口腔癌 |
| **减少环境暴露** | 减少职业性化学品、射线暴露 | 多种职业性癌症 |
| **母乳喂养** | 母乳喂养降低母亲乳腺癌风险 | 乳腺癌 |

**二级预防：早筛早诊早治**

定期体检是实现"三早"（早发现、早诊断、早治疗）的核心手段：

| 筛查项目 | 目标癌症 | 建议人群 |
|---|---|---|
| 低剂量 CT（LDCT） | 肺癌 | 55 岁以上吸烟高危人群 |
| 乳腺钼靶 / 超声 | 乳腺癌 | 40 岁以上女性，高危人群更早 |
| 宫颈 TCT + HPV | 宫颈癌 | 21 岁以上有性生活女性，定期检测 |
| 结肠镜检查 | 结直肠癌 | 45 岁以上，有家族史者更早 |
| 甲胎蛋白（AFP）+ 腹部超声 | 肝癌 | 乙肝、丙肝感染者及肝硬化患者 |
| 胃镜检查 | 胃癌 | 幽门螺杆菌感染者、胃癌高发地区人群 |

**三级预防：规范治疗，改善预后**

- 确诊后接受规范的综合治疗（手术、化疗、放疗、靶向、免疫）
- 定期随访，及时发现复发或转移
- 康复管理和支持性治疗（营养、心理、疼痛管理）

**心理健康与免疫功能的关联**

不良情绪（长期压力、焦虑、抑郁）可能通过神经-内分泌-免疫轴影响免疫功能，被认为是一种潜在的"促癌剂"。积极的心理状态和良好的社会支持是癌症预防和康复的重要组成部分。

> **国家层面的关键责任：** 通过立法控制大气污染和职业暴露、推动全民健康教育、扩大疫苗接种覆盖（HPV 疫苗、乙肝疫苗）、建立规范的癌症筛查体系，是降低全社会癌症负担的根本举措。

## 癌症与免疫：肿瘤免疫逃逸的三阶段模型与治疗靶点

:::answer

癌症的发生和进展本质上是肿瘤细胞与免疫系统之间长期"博弈"的过程。理解这一博弈的三个阶段，是理解现代免疫治疗（尤其是免疫检查点抑制剂）的生物学基础。

**癌细胞的核心生物学特点：端粒酶激活赋予无限增殖能力**

正常细胞具有有限的复制次数，由端粒体（Telomere）长度决定：
- 每次细胞分裂，端粒体缩短
- 端粒体缩短到临界值 → 细胞停止分裂（Hayflick 极限）→ 细胞衰老

癌细胞的关键突变之一是**端粒酶（Telomerase）的激活**，使端粒体不再缩短，癌细胞因此获得无限增殖能力，成为"永生化"细胞。

**三阶段癌症-免疫博弈模型**

**阶段一：肿瘤初期——隐藏与欺骗（Escape 早期）**

```
癌细胞数量少、能力弱
    ↓
主动躲避免疫监视的策略：
  ├─ 下调 MHC I 类分子（减少抗原呈递，难以被 T 细胞识别）
  ├─ 模拟正常细胞抗原（伪装成"自身组织"）
  └─ 分泌免疫抑制因子（TGF-β、IL-10 等，干扰 NK 细胞和 T 细胞功能）
    ↓
若免疫系统功能正常 → 识别并消灭癌细胞
若免疫系统存在缺陷 → 癌细胞得以存活并缓慢增殖（约 5～10 年）
```

**阶段二：肿瘤中期——对峙与消耗（Equilibrium/Escape 进展期）**

```
癌细胞达到一定数量，无法完全隐藏
    ↓
形成实体瘤，建立免疫抑制性肿瘤微环境（TME）：
  ├─ 实体瘤物理屏障（限制免疫细胞浸润）
  ├─ 招募调节性 T 细胞（Treg）和髓系抑制细胞（MDSC）
  ├─ 上调 PD-L1 表达（与 T 细胞 PD-1 结合，抑制 T 细胞功能）
  └─ 耗竭肿瘤浸润 T 细胞（TIL）的杀伤能力
    ↓
癌细胞利用这段时间通过血管和淋巴管向远处转移（暗度陈仓）
```

**阶段三：肿瘤后期——反扑与免疫崩溃（Escape 晚期）**

```
癌细胞数量达到临界，对免疫系统发动全面进攻：
  ├─ 分泌大量免疫抑制因子，系统性抑制免疫功能
  ├─ 破坏骨髓造血功能（减少免疫细胞生产）
  ├─ 侵犯淋巴组织（直接破坏免疫器官）
  └─ 引发恶病质（全身性营养消耗，间接削弱免疫功能）
    ↓
免疫系统崩溃
    ↓
晚期癌症患者常死于感染（免疫力极度低下）或恶病质（极度消耗）
```

**免疫检查点抑制剂的治疗逻辑**

以 PD-1/PD-L1 通路为例：

```
正常情况：
  PD-L1（肿瘤细胞）与 PD-1（T 细胞）结合
    ↓
  T 细胞功能被抑制（肿瘤免疫逃逸）

免疫检查点抑制剂治疗：
  抗 PD-1 抗体（如 Nivolumab、Pembrolizumab）阻断 PD-1
  或抗 PD-L1 抗体（如 Atezolizumab）阻断 PD-L1
    ↓
  T 细胞的"刹车"被解除
    ↓
  T 细胞重新激活，识别并攻击癌细胞
```

这正是 PD-1/PD-L1 抑制剂在肺癌、黑色素瘤、胃癌等多种癌症中实现长期缓解的生物学机制，也是 James Allison 和 Tasuku Honjo 荣获 2018 年诺贝尔生理学或医学奖的核心科学贡献。

:::
