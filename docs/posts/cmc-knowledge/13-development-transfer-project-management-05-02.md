## 第一部分：生物类似药与化学仿制药的关键差异

---

### 监管政策差异：自动替换与可互换性的全球分歧

:::answer

生物类似药与化学仿制药在上市后监管政策上存在根本性差异，这一差异源于两类产品的结构复杂性不同，直接影响药店替换政策、患者监测要求和市场准入策略。

**化学仿制药 vs 生物类似药：自动替换政策对比**

| 维度 | 化学仿制药 | 生物类似药 |
|------|-----------|-----------|
| **结构特征** | 与原研药结构完全相同（identical），分子量小，结构简单 | 与参照药高度相似（highly similar），分子量大，存在固有微观异质性 |
| **替换逻辑** | 结构相同 = 药效等同，可直接替换 | 高度相似 ≠ 完全相同，替换需额外证据支持 |
| **欧盟政策** | 药剂师可自主替换，无需通知处方医生 | **法规明确不允许自动替换**，各成员国可制定本地政策 |
| **美国政策** | FDA 批准的 ANDA 产品可直接替换 | 须获得 FDA"可互换性"（Interchangeability）认定才可在药剂师层面替换，标准极严格 |
| **中国政策** | 一致性评价通过后可纳入参比制剂目录，允许替换 | NMPA 尚未建立明确的自动替换机制，通常需医生处方 |

**可互换性认定的技术要求（FDA 标准）**

FDA 要求生物类似药申请可互换性认定时，除证明生物相似性外，还需提供额外的临床转换研究数据，证明：

```
可互换性研究设计要求
├── 转换研究（Switching Study）
│   ├── 比较稳定患者在原研药与生物类似药之间多次转换的安全性和有效性
│   ├── 通常需要至少 3 次转换（原研→生物类似药→原研或反之）
│   └── 主要终点：免疫原性（ADA 发生率）、PK 暴露量、安全性不良事件
│
└── 评估维度
    ├── 转换期间不良反应是否增加
    ├── ADA 产生率是否升高
    └── PK 暴露量的批间一致性
```

**欧盟各成员国的本地化政策差异**

尽管 EMA 层面不允许自动替换，部分欧盟成员国已在本地政策层面建立了生物类似药替换机制：

- **法国**：2020 年起允许在特定条件下（稳定患者、医生知情）进行生物类似药替换
- **德国**：允许基于参考价格制度的替换，但医生可拒绝（"aut idem"机制）
- **北欧国家**：多数已建立生物类似药首选处方政策，推动替换

**对商业策略的影响**

- 自动替换政策的缺失使生物类似药的市场渗透速度明显慢于化学仿制药
- 医生教育和品牌认知仍是生物类似药市场推广的核心竞争要素
- 可互换性认定在美国是重要的商业壁垒，获得认定的产品可显著提升市场份额

:::

### 研发成本与周期差异：生物类似药开发的经济学约束

:::answer

生物类似药与化学仿制药在研发投入上存在**数量级**的差异，这一差异决定了生物类似药开发的商业逻辑和立项策略与化学仿制药完全不同。

**研发投入的量化对比**

| 维度 | 化学仿制药 | 生物类似药 |
|------|-----------|-----------|
| **研发周期** | 3–5 年 | **8–10 年** |
| **研发成本** | 100 万–500 万美元 | **1 亿–2 亿美元** |
| **临床研究要求** | BE 试验（通常数十例受试者） | 完整 PK/PD + 临床疗效/安全性 III 期研究（数百至数千例） |
| **分析方法复杂度** | 相对简单，化学结构确证 | 极高，需多维度相似性比对（结构/功能/PK/免疫原性） |
| **生产工艺要求** | 化学合成，工艺相对成熟 | 活细胞体系，工艺复杂，GMP 要求严格 |

**成本差异的根本原因**

```
生物类似药高成本来源分析
├── 细胞株开发（12–18 个月，数百万美元）
│   └── 逆向工程参照药的表达系统，无法使用原研细胞株
├── 工艺开发（规模化 CHO 培养 + 多步纯化）
│   └── 需证明工艺能稳定产出与参照药高度相似的产品
├── 分析表征（多维度相似性评估）
│   └── 一级结构、高级结构、翻译后修饰、生物活性全套比对
├── 临床研究（III 期等效性研究）
│   └── 远比化学仿制药的 BE 试验规模大、费用高
└── 监管沟通（复杂的申报策略和与审评机构的持续互动）
```

**生物类似药立项的经济性判断框架**

基于高研发成本的现实，生物类似药立项必须满足更严格的商业逻辑：

| 判断维度 | 最低要求 | 理想状态 |
|----------|---------|---------|
| **参照药市场规模** | 年销售额 > 5 亿美元（支撑回本） | 年销售额 > 10 亿美元（重磅产品） |
| **专利到期时间窗口** | 目标市场专利将于 3–5 年内到期 | 专利已到期或即将到期，首仿机会 |
| **竞争格局** | 同品种研发管线 < 5 个 | 竞争对手少，先发优势明显 |
| **工艺可行性** | 有成熟的表达系统经验 | 已有相似分子的开发经验（平台共用） |
| **定价空间** | 预期折价 20–30% 仍可盈利 | 医保准入加速渗透，以量换价 |

:::

## 第二部分：单抗制品生产质量控制体系

---

### 单抗制品生产质量整体控制框架

:::answer

单抗制品的生产过程从细胞库到最终制剂，涉及多个不连续的生产工序，每个工序的质量控制均需系统性设计，以确保产品的安全性、有效性和批间一致性。

**质量控制体系的七大核心要素**

```
单抗制品生产质量控制体系（全链路）
│
├── ① 物料控制（Material Control）
│   ├── 原材料：TSE/BSE 风险、内毒素、微生物
│   ├── 关键耗材：E&L 风险评估、完整性验证
│   └── 细胞株：外源因子检定、遗传稳定性
│
├── ② 生产工艺（Manufacturing Process）
│   ├── 上游：种子扩增→生产培养→收获
│   ├── 下游：捕获→病毒灭活→精纯→制剂
│   └── 关键工艺参数（CPP）监控与控制
│
├── ③ 清洁工艺（Cleaning Process）
│   ├── 清洁验证（最差条件设计）
│   ├── 清洁限度（10 ppm 法则 / TOC 法）
│   └── 清洁效果监控（目视检查 + 化学/微生物检测）
│
├── ④ 技术转移（Technology Transfer）
│   ├── 工艺文件包转移（批记录/SOP/CPP 清单）
│   ├── 分析方法转移（并行验证）
│   └── 知识转移（工艺理解和操作经验）
│
├── ⑤ 分析检验（Analytical Testing）
│   ├── 过程中检测（IPC）
│   ├── 中间体放行检测
│   └── 原液/制剂放行检测
│
├── ⑥ 稳定性研究（Stability Studies）
│   ├── 中间体稳定性（收获液、各层析步骤洗脱液）
│   ├── 原液稳定性（DS 长期/加速/强制降解）
│   └── 制剂稳定性（DP 支持货架期的实时/加速数据）
│
└── ⑦ 污染控制（Contamination Control）
    ├── 生物污染（微生物、支原体、病毒）
    ├── 化学污染（宿主细胞蛋白、DNA、Protein A 残留）
    └── 物理污染（颗粒物、异物）
```

**生产工序不连续性的质量管理含义**

单抗生产中各工序之间通常是**不连续**的（存在中间体储存步骤），这意味着：
- 每个中间体需要定义独立的放行标准和储存条件
- 中间体储存时间（Hold Time）需要通过稳定性研究验证
- 不连续工序之间的质量状态传递须通过完整的文件和标识管理确保可追溯

**从细胞库到制剂的质量控制节点**

| 生产阶段 | 关键质量控制活动 | 主要风险 |
|----------|----------------|---------|
| 细胞库（MCB/WCB） | 全套外源因子检定、遗传特征确认 | 外源病毒、支原体污染 |
| 种子扩增 | 细胞活力/密度监控、无菌检查 | 微生物污染、遗传漂移 |
| 生产培养 | CPP 监控、UPB 全套检定 | 产品质量偏移、外源因子 |
| 收获/澄清 | 产量、微生物、内毒素 | 宿主细胞蛋白携带 |
| 层析纯化 | 步骤收率、杂质去除效果 | 纯化能力不足、损失 |
| 病毒灭活/过滤 | pH/温度/时间参数确认、完整性测试 | 病毒灭活不足 |
| 制剂配制 | 浓度、pH、渗透压、可见异物 | 制剂均匀性、聚集 |

:::

### 一次性使用系统（SUS）物料特性的评估要点

:::answer

一次性使用系统（Single-Use System，SUS）的物料特性评估是确保其在生产过程中功能完整性和产品安全性的基础性工作，需在供应商选择和工艺验证阶段系统开展。

**物料特性的四大评估维度**

**① 材料物理属性**

| 属性项目 | 评估方法 | 关键指标 |
|----------|---------|---------|
| 膜/管路厚度 | 千分尺测量 | 符合供应商规格，批间一致性 |
| 表面透明度 | 目视检查 + 光学显微镜 | 无明显杂质、气泡或不均匀区域 |
| 表面光滑度 | 表面粗糙度仪（Ra 值） | 光滑表面有助于降低微生物附着风险 |
| 材料颜色均一性 | 目视比对 | 批间颜色一致（排除原料变化） |

**② 系统及组件物理完整性**

- **压力完整性测试**：充气至规定压力，检测是否存在泄漏
- **密封性验证**：针对管路连接点、焊接接头和接口处的密封完整性
- **尺寸符合性**：连接接口尺寸须与工艺设备精确匹配，防止错误安装

**③ 材料机械性能**

| 机械性能 | 测试方法 | 关键场景 |
|----------|---------|---------|
| 耐刺穿性 | 刺穿力测试（N/mm²） | 一次性生物反应器袋体承受搅拌桨压力 |
| 延伸性/柔韧性 | 拉伸试验（断裂伸长率） | 管路在低温条件下的弯折不开裂 |
| 抗爆破压力 | 液压爆破试验 | 配液袋在最大工作压力下的安全余量 |
| 耐磨性 | 循环弯折试验 | 蠕动泵管路的使用寿命 |

**④ 组件连接强度**

- **热合强度（Heat Seal Strength）**：焊接部位在规定拉力下不分离，是储液袋质量的核心指标
- **连接强度（Connection Strength）**：管路接头与过滤器、传感器等组件的连接可靠性
- **重复性测试**：验证连接强度在实际操作条件下的一致性（尤其是无菌连接器的反复操作场景）

**SUS 物料特性评估的时机**

```
SUS 物料特性评估节点
├── 供应商选择阶段：文件审查 + 样品测试
├── 新产品引入阶段：工艺相容性评估
├── 定期再评估：年度供应商质量回顾
└── 变更后评估：供应商工艺或配方变更后的桥接测试
```

## 第三部分：抗体成药性评估

---

### 抗体药物成药性的四大关键属性

:::answer

抗体药物的成药性分析（Developability Analysis）是筛选具有临床应用前景和商业价值候选抗体的系统性评估策略，其核心价值在于在分子优化阶段早期识别开发风险，避免将资源投入到注定失败的候选分子。

**成药性分析的战略价值**

| 价值维度 | 描述 |
|----------|------|
| **缩小候选范围** | 从多个生物活性相当的候选分子中，基于可开发性排序，聚焦最具潜力的 1–2 个 |
| **降低开发风险** | 提前识别稳定性差、聚集倾向高、制造困难等根本性缺陷 |
| **节约时间和成本** | 避免在细胞株开发后期或临床阶段发现分子问题，届时修正成本极高 |
| **预测临床表现** | 为临床转化（PK、安全性、给药方案）和商业化开发提供早期指导 |

**四大关键成药性属性**

**① 同质性（Homogeneity）**

同质性反映抗体产品的**批间一致性和分子均一性**，是质量可控性的前提。

| 同质性评估维度 | 检测方法 | 理想状态 |
|-------------|---------|---------|
| 电荷分布均一性 | IEX-HPLC、cIEF | 主峰 > 80%，电荷变体可控 |
| 大小均一性 | SEC-HPLC | 单体 > 95%，无可见聚集 |
| 糖型均一性 | LC-MS（Glycan Profile） | 糖型分布批间一致，满足预期功效要求 |
| 翻译后修饰 | Peptide Map（LC-MS/MS） | 已知修饰位点可控，无非预期新修饰 |

**影响同质性的高风险序列特征：**
- CDR 区含有 N-X-S/T 基序（潜在 N-糖位点，影响抗原结合）
- CDR 区含有 NG/NS/NT motif（脱酰胺热点，导致电荷变体增加）
- 氧化敏感的 Met/Trp 残基暴露于溶剂（影响 Fc 功能和抗原结合）

**② 稳定性（Stability）**

稳定性是成药性评估中**权重最高**的属性，直接决定产品的货架期和可制造性。

```
抗体稳定性评估体系
├── 热稳定性（构象稳定性）
│   ├── DSF：Tm 值（解链温度）≥ 65°C 为佳
│   └── DSC：多个解链峰的归属分析
│
├── 胶体稳定性（抗聚集能力）
│   ├── DLS：kD 值（扩散相互作用参数）> 0 为佳
│   └── B22（第二维里系数）> 0 为引力不占优
│
├── 化学稳定性（共价修饰）
│   ├── 加速稳定性（40°C/75%RH，4 周）
│   ├── 关键指标：脱酰胺/氧化增量、酸性峰增加比例
│   └── 强制降解（酸/碱/氧化/光照/热）
│
└── 界面稳定性
    ├── 搅拌压力测试（模拟运输振动）
    └── 冻融循环（模拟储存和转运条件）
```

**③ 溶解度（Solubility）**

溶解度直接决定制剂的可行性，尤其对于需要高浓度皮下注射（SC）制剂的产品：

| 给药途径 | 浓度要求 | 溶解度挑战 |
|----------|---------|-----------|
| 静脉注射（IV） | 通常 1–20 mg/mL | 要求相对低，溶解度限制较少 |
| 皮下注射（SC） | 通常 100–200 mg/mL | 高浓度下黏度和聚集风险显著增加 |

**溶解度评估方法：**
- PEG 沉淀法（快速筛选，结果与实际相关性中等）
- 超滤浓缩法（在实际缓冲液条件下浓缩至目标浓度）
- 纳米差示扫描荧光（nanoDSF，高通量，小样品量）

**高浓度下的黏度问题：**

SC 制剂黏度须 < 20–50 cP（取决于注射装置），过高的黏度源于：
- 分子间相互作用（带电补丁、疏水暴露区域）
- CDR 区域的特殊序列特征（可通过 In silico 预测）

**④ 特异性（Specificity）**

特异性是保证 ADC、双抗等新型抗体药物疗效与安全性的关键：

| 特异性评估维度 | 评估方法 | 风险信号 |
|-------------|---------|---------|
| 靶点结合选择性 | 多靶点交叉反应筛选（Selectivity Panel） | 与非靶点蛋白结合（KD < 100 nM） |
| 组织交叉反应 | 人体组织免疫组化（IHC panel） | 关键正常组织非预期染色 |
| 多聚反应性 | 多聚反应性 ELISA（PSR 评分） | PSR > 50%提示非特异性结合风险 |
| 自身抗原结合 | 抗核抗体（ANA）测试 | 阳性结果提示自身免疫风险 |

:::

## 第四部分：临床安全性报告与监管要求

---

### 临床试验中"其他潜在严重安全性风险信息"的界定标准

:::answer

在临床试验安全性报告体系中，"其他潜在严重安全性风险信息"是除 SUSAR（可疑且非预期的严重不良反应）之外，申请人需要主动识别和快速报告的另一类重要安全性信号。

**"其他潜在严重安全性风险信息"的界定原则**

符合以下任一条件的信息，均可归属于此类别：

| 判断标准 | 具体表现 | 示例 |
|----------|---------|------|
| **明显影响风险-获益评估** | 新发现的安全性信息使药物的整体风险-获益平衡发生实质性改变 | 发现严重肝毒性信号，影响继续用药的获益判断 |
| **可能导致用法改变** | 需要修改给药剂量、给药频率、用药人群或联合用药禁忌 | 发现特定基因型患者代谢异常，需调整剂量 |
| **影响总体研发进程** | 可能导致临床试验方案修改、暂停或终止的安全性发现 | 非临床毒理研究发现致癌性信号 |

**三类具体触发情形**

**情形一：已知严重不良反应发生率显著增加**

- 适用前提：该不良反应已在产品信息或风险管理文件中有所记录
- 触发阈值：发生率增加且经临床判断具有**重要临床意义**（而非统计学偏差）
- 典型案例：预期发生率 1% 的严重输液反应，当前观察到 5% 发生率，且排除了批次或操作因素

**情形二：对暴露人群有明显危害**

- 最典型场景：在治疗**危及生命疾病**时观察到药物明显缺乏疗效
- 逻辑：对于替代治疗有限的重大疾病，无效本身构成严重安全性风险（患者失去治疗机会）
- 监管预期：申请人需及时报告，并评估是否需要修改入组标准或停止特定亚组入组

**情形三：动物实验重大安全性发现**

- 主要类型：新完成的长期毒理研究发现致癌性信号
- 报告逻辑：动物致癌性发现虽不直接等于人体风险，但对人体临床研究的继续开展具有重要参考意义
- 处置：通常需启动即时安全性评估，并与监管机构沟通继续研究的条件

**与 SUSAR 报告的区别**

| 维度 | SUSAR | 其他潜在严重安全性风险信息 |
|------|-------|------------------------|
| **触发条件** | 个例严重不良反应（非预期且可疑因果） | 汇总性安全信号或非个例的系统性风险 |
| **来源** | 临床试验受试者个体 | 汇总分析、动物研究、文献、其他研究 |
| **报告时限** | 致死/危及生命：7 天；其他：15 天 | 尽快，通常 15 天内 |

:::

### 个例安全性报告（ICSR）的责任主体识别：申请人 vs CRO

:::answer

当申请人委托 CRO 协助提交个例安全性报告（Individual Case Safety Report，ICSR）时，责任主体的清晰界定是合规运营的关键，也是监管机构审查的重点。

**核心原则：申请人是不可转移的安全性报告责任主体**

无论委托关系如何设置，**申请人（Sponsor）始终是临床试验安全性监管及报告的唯一法律责任主体**。CRO 仅是代为执行的服务提供方，不能替代或分担申请人的法律责任。

**报告提交的技术标识要求**

| 提交方式 | 企业识别 ID 要求 | 错误后果 |
|----------|----------------|---------|
| **Gateway 方式** | 必须使用**申请人的识别 ID**，不得使用 CRO 的 ID | 监管机构无法识别真实申报主体，可能导致报告无效 |
| **申请人之窗（XML 文件上传）** | XML 文件中的发送方标识必须为**申请人的标识信息** | 报告被归入 CRO 名下，责任链断裂 |

**申请人与 CRO 的职责边界划分**

| 职责维度 | 申请人责任 | CRO 可承担的活动 |
|----------|-----------|----------------|
| **安全性监管策略** | 制定安全性监测计划（Safety Monitoring Plan） | 按计划执行安全性数据收集和分析 |
| **SUSAR 判断** | 最终判断因果关系和严重性分级 | 辅助完成初步医学评估和分级 |
| **报告提交** | 法律责任主体，使用自身 ID 提交 | 代为撰写和技术性提交，但必须以申请人名义 |
| **与监管沟通** | 与 CDE 等监管机构的直接沟通责任 | 支持准备沟通材料，但不替代申请人出席 |

**合同安排的关键条款建议**

申请人与 CRO 签订服务合同时，安全性相关条款应明确：
- 安全性信息的传递时限和格式要求
- CRO 向申请人报告的触发条件和时限
- 申请人保留最终审核和提交决策权
- 数据所有权归申请人，CRO 不得向第三方披露

:::

### 影响因素试验的条件设计与实施要点

:::answer

影响因素试验（Stress Testing）是强制降解研究的核心组成部分，旨在评估候选药物在极端条件下的稳定性行为，识别降解途径，为分析方法开发和制剂处方优化提供关键信息。

**影响因素试验的定位与用途**

| 用途 | 描述 |
|------|------|
| **降解途径识别** | 确定主要降解类型（氧化/脱酰胺/水解/聚集），为制剂处方选择提供科学依据 |
| **分析方法适用性验证** | 证明分析方法能检测和定量各种降解产物，具有稳定性指示性 |
| **预测长期稳定性** | 加速条件下的降解规律为货架期预测提供参考 |
| **包装材料评估** | 评估包装容器对产品稳定性的影响（如光照保护性）|

**标准影响因素试验条件（原料药/原液）**

**① 高温试验**

```
标准试验设计：
├── 条件：开口放置，洁净容器，60°C
├── 时间：10 天，第 5 天和第 10 天取样
├── 降级方案：若 60°C 含量低于限度 → 改为 40°C 重复试验
└── 判读：60°C 无明显变化 → 不再进行 40°C 试验
```

**② 高湿度试验**

```
标准试验设计：
├── 条件：开口放置，恒湿密闭容器，25°C / 相对湿度 90% ± 5%
├── 时间：10 天，第 5 和 10 天取样
└── 特殊评估：称量试验前后重量，考察吸湿/潮解性能
```

对于液体制剂（如注射液），高湿度试验通常**不适用**（因密封容器隔绝了湿度影响），主要适用于固体原料药和冻干制剂。

**③ 强光照射试验**

```
标准试验设计：
├── 条件：开口放置，可调光照箱（参考《中国药典》二部附录 XIX C）
├── 照度：4500 lx ± 500 lx
├── 时间：10 天，第 5 和 10 天取样
└── 重点关注：外观变化（颜色、浑浊度）、含量、有关物质
```

**④ 反复冻融试验**（适用于需冷冻保存的原液和中间体）

```
标准试验设计：
├── 常规设计：3–5 次冻融循环（-80°C ↔ 室温或 2–8°C）
├── 评估项目：外观、含量、聚集体（SEC-HPLC）、活性
└── 典型风险：冻融导致蛋白变性、界面暴露、聚集体增加
```

**生物制品影响因素试验的特殊考量**

与化学小分子不同，蛋白类生物制品的影响因素试验需要额外关注：

| 特殊性 | 说明 |
|--------|------|
| **样品批次** | 影响因素试验通常只需 **1 个批次**样品 |
| **蛋白质特殊性** | 蛋白固有的物理化学稳定性制约了某些极端条件的适用性（如强酸/强碱会导致不可逆变性，不适合模拟实际降解） |
| **关键检测项目** | 外观（颜色、澄清度）、含量（效价）、纯度（SEC/CE-SDS）、生物活性、特定降解标志物 |
| **结果解读** | 关注降解规律而非绝对数值，主要目的是建立分析方法的稳定性指示性而非预测货架期 |

:::

### 仪器计量管理体系：校准、检定、标定与校验的概念辨析

:::answer

在生物制药 GMP 体系中，仪器设备的计量管理是确保测量数据可靠性和可溯源性的基础。实践中，"校准""检定""标定""校验"四个概念经常被混淆使用，但其法律地位、执行主体和适用范围存在根本差异。

**四个概念的系统对比**

| 概念 | 定义 | 执行主体 | 法律属性 | 溯源方向 |
|------|------|---------|---------|---------|
| **校准（Calibration）** | 对照计量标准，评定测量装置的示值误差，确保量值准确 | 具备资质的计量机构或内部实验室（需满足相应要求） | 非强制，自愿行为 | 自下而上（量值溯源） |
| **检定（Verification）** | 对测量装置进行强制性全面评定，评判误差范围是否在法定允许范围内 | 法定计量检定机构（政府授权） | **强制性**，法定要求 | 量值传递 |
| **标定（Calibration/Standardization）** | 使用标准计量仪器对所使用仪器的准确度进行检测 | 企业内部或外部机构 | 非强制 | 与校准基本等同 |
| **校验（Verification/Check）** | 组织自行对照计量标准，评定测量装置示值误差 | 企业内部自行执行 | 非强制，内部管理行为 | 自下而上（量值溯源） |

**关键区别总结**

```
计量管理概念层级关系
├── 检定：政府法定 → 强制执行 → 具有法律效力的合格证书
│         适用对象：列入强制检定目录的计量器具（如天平、温度计、压力表）
│
├── 校准：自愿行为 → 结果不带"合格"判定 → 出具校准证书（含示值误差）
│         适用对象：精密仪器、研究用设备（HPLC 检测器、pH 计等）
│
├── 标定：等同于校准，常用于分析仪器和标准溶液的量值确认
│
└── 校验：企业内部的自我验证，频率高（如每日/每周使用前核查）
          ← 不替代年度校准或法定检定，作为日常运行监控
```

**GMP 环境下的计量管理实践要求**

| 管理层次 | 频率 | 具体要求 |
|----------|------|---------|
| **法定检定** | 按计量法规周期（通常 1 年） | 列入强制检定目录的器具必须送法定机构检定 |
| **外部校准** | 通常年度 | 精密仪器由具备 CNAS 资质的实验室出具校准证书 |
| **内部校验** | 日常/使用前 | 使用经校准的参考标准品或砝码进行日常核查，记录留存 |
| **设备确认（IQ/OQ/PQ）** | 安装/重大维修后 | 设备投入使用前的全面功能验证（GMP 特有要求） |

**计量溯源链的完整性要求**

所有测量仪器的量值必须可以追溯至**国家计量基准（NIM）**或**国际单位制（SI）**，追溯链不得中断：

```
量值溯源链
国际计量基准（BIPM）
        ↓
国家计量基准（中国计量院/NIM）
        ↓
法定计量检定机构（省级计量院）
        ↓
企业参考标准器（经检定/校准）
        ↓
生产/检测用仪器（日常使用）
```

:::

### 上游生产工艺的标准步骤定义与风险评估前提

:::answer

在开展上游工艺的风险评估（如 FMEA 或关键工艺参数识别）之前，必须首先对上游生产工艺的完整流程有清晰、精确的定义，这是所有后续工艺理解和控制策略的基础。

**上游生产工艺的标准五步结构**

```
抗体原液上游生产工艺流程
①细胞复苏（Thawing）
   ├── 从工作细胞库（WCB）取出冻存安瓿
   ├── 37°C 水浴快速复苏，避免过慢（冰晶损伤）
   └── 转入含完全培养基的培养瓶，稀释 DMSO 至安全浓度
         ↓
②摇瓶种子扩增（Shake Flask Seed Expansion）
   ├── 在摇瓶中逐步扩增细胞数量
   ├── 典型规模：125 mL → 500 mL → 1000 mL 摇瓶
   └── 关键参数：转速、CO₂浓度、温度、传代密度和时间
         ↓
③反应器种子扩增（Bioreactor Seed Expansion）
   ├── 从摇瓶转接至小型→中型生物反应器（N-2 → N-1 级别）
   ├── 实现规模化细胞数量扩增
   └── 关键参数：DO、pH、温度、搅拌速度、接种密度、培养时间
         ↓
④反应器生产（Production Bioreactor）
   ├── 接种至生产规模生物反应器（N 级别）
   ├── 流加培养（Fed-batch）或灌注培养（Perfusion）
   ├── 实时监控：细胞密度、活力、代谢参数、产物滴度
   └── 关键决策：收获时机（通常活力 < 60% 或培养至预定天数）
         ↓
⑤收获（Harvest）
   ├── 离心澄清（去除细胞）
   ├── 深层过滤（去除细胞碎片）
   └── 得到未经处理的收获液（HCCF，Harvested Cell Culture Fluid）
```

**风险评估启动前的信息收集要求**

在开展上游工艺 FMEA 或 CQA-CPP 关联分析前，须系统收集：

| 信息类别 | 具体内容 | 用途 |
|----------|---------|------|
| **历史批次数据** | 各 CPP 的历史运行范围，产品 CQA 的历史分布 | 建立参考基准，识别异常批次 |
| **工艺知识文件** | 工艺描述、批生产记录（MBR）、SOP | 确认工艺步骤定义的完整性 |
| **失败批次记录** | 历史偏差报告、OOS 报告及其根本原因分析 | 识别已知风险点 |
| **科学文献** | 同类产品/平台的 CQA-CPP 关联研究 | 借鉴平台知识，缩短评估周期 |
| **专家知识** | 工艺开发人员、QA 和生产操作人员的经验判断 | 补充文档记录之外的隐性知识 |

**工艺参数的三类划分**

风险评估完成后，工艺参数须基于对 CQA 的影响程度进行分类：

| 类别 | 定义 | 控制要求 |
|------|------|---------|
| **关键工艺参数（CPP）** | 变化对 CQA 有显著影响，须受控 | 严格控制在定义范围内，超范围须触发偏差调查 |
| **非关键工艺参数（non-CPP）** | 正常操作范围内变化对 CQA 影响不显著 | 监控并记录，但无需严格的控制限 |
| **工艺参数（PP）** | 需监控以了解工艺性能，但无 CQA 影响 | 趋势分析，支持工艺理解 |

:::

### 细胞株质量控制要求体系概览

:::answer

生产用细胞株的质量控制是生物制品 GMP 的核心要求之一，覆盖从细胞株构建到商业化生产全生命周期，直接关系到产品的安全性、有效性和批间一致性。

**细胞株质量控制的监管框架**

| 监管文件 | 发布机构 | 核心要求 |
|----------|---------|---------|
| 《中国药典》三部 "生物制品生产用细胞基质" | NMPA | 国内法定要求，覆盖细胞库建立和检定 |
| ICH Q5B | ICH | 重组蛋白药物中 rDNA 来源的表达构建体分析 |
| ICH Q5D | ICH | 生物制品生产用细胞基质的来源和鉴定 |
| WHO TRS 978 | WHO | 细胞基质质量、安全和效力指南 |
| FDA "Points to Consider" | FDA | 重组 DNA 来源生物制品的生产考量 |

**细胞株质量控制的三大核心模块**

**① 细胞库体系建立与管理**

```
三层细胞库体系
主细胞库（MCB，Master Cell Bank）
    ├── 来源：单一克隆扩增后冻存，20–50 安瓿，-196°C 液氮
    ├── 检定：全套（见下表），一次性建立，长期保存
    └── 管理：异地双备份，严格访问控制

工作细胞库（WCB，Working Cell Bank）
    ├── 来源：MCB 单支复苏后扩增冻存
    ├── 检定：精简版（重点外源因子 + 遗传确认）
    └── 使用：每批生产从 WCB 取用，MCB 仅作备份

生产终末细胞（EOPC，End of Production Cells）
    ├── 来源：生产传代结束时的细胞
    ├── 检定：遗传稳定性评估（与 MCB 比较）
    └── 目的：证明生产过程中遗传稳定性维持
```

**② 细胞库全套检定项目**

| 检定类别 | 检定项目 | 检定方法 | MCB | WCB | EOPC |
|----------|---------|---------|-----|-----|------|
| **鉴别** | 物种确认 | 同工酶/STR | ✓ | ✓ | ✓ |
| **遗传特征** | 目的基因序列 | 全测序 | ✓ | – | ✓ |
| | 拷贝数 | qPCR | ✓ | – | ✓ |
| **外源因子** | 支原体 | 培养法 + 核酸法 | ✓ | ✓ | ✓ |
| | 细菌/真菌 | 无菌检查 | ✓ | ✓ | – |
| | 逆转录病毒 | 透射电镜 + 逆转录酶 | ✓ | – | – |
| | 体内/体外病毒 | 动物/细胞接种法 | ✓ | – | – |
| **遗传稳定性** | 表达量稳定性 | 效价比较 | – | – | ✓ |
| | 产品质量稳定性 | CQA 比较 | – | – | ✓ |

**③ 细胞株稳定性研究**

生产用细胞株的稳定性研究目的是证明在整个商业化生产传代周期内，细胞株能维持：
- 预期的表达水平（产量稳定性）
- 目的基因的序列完整性（遗传稳定性）
- 产品 CQA 的一致性（质量稳定性）

```
稳定性研究设计
传代范围：MCB 传代数 + 生产传代数 + 额外传代（安全余量）
                    ↓
                 = EOPC
评估时间点：MCB（起始）→ 中间时间点 → EOPC（终末）
评估内容：
├── 细胞表型（活力、形态、生长曲线）
├── 遗传稳定性（目的基因序列、拷贝数）
├── 表达量（效价）
└── 产品质量（糖型、电荷变体、纯度、生物活性）
```

**细胞株构建过程的安全性原则**

- **避免动物源性成分**：细胞株构建过程中应尽量避免使用动物血清（如牛血清白蛋白、胎牛血清）或使用经过严格处理的替代品
- **非动物源性培养基**：商业化生产细胞株应在化学成分明确（CDM）培养基中稳定生长
- **构建记录完整性**：从亲本细胞系到最终选定克隆的完整构建历程须有文件记录，支持监管审查

:::

### 生产控制过程中的浸出物（LER）研究考量

:::answer

浸出物（Leachables）研究（LER）是评估一次性使用系统和包装材料对产品安全性影响的关键活动，其研究设计须与实际生产工艺条件紧密结合。

**LER 研究设计的核心原则**

> LER 研究必须在**与工艺相关的温度和时间条件**下进行，而非简单的极端条件挑战测试。

**工艺相关条件的识别**

"工艺相关"是指最有可能对浸出物水平产生显著影响的工艺步骤，识别方法：

| 影响因素 | 典型场景 | 判断逻辑 |
|----------|---------|---------|
| **高温接触** | 高温 CIP/SIP（121°C）、高温缓冲液处理 | 温度升高显著加速浸出物迁移 |
| **化学品添加** | 添加聚山梨酯（表面活性剂增加浸出） | 表面活性剂增强疏水性浸出物的溶出 |
| **螯合剂** | EDTA 等螯合剂可能促进金属离子浸出 | 与包材中金属稳定剂相互作用 |
| **保持时间** | 产品在设备/容器中的长时间静置 | 接触时间越长，浸出量越大 |
| **开放/密闭系统** | 开放系统暴露于空气/光照，密闭系统更可控 | 光照和氧气可催化某些浸出物的降解 |

**LER 研究的时间和温度设置原则**

```
LER 研究条件设计
├── 温度：使用实际工艺温度（而非加速极端温度）
│         例：若过滤操作在 15°C 进行，LER 研究在 15°C 测试
│         若需加速研究，须建立温度-浸出量相关模型并验证
│
├── 时间：覆盖最长预期工艺接触时间 + 安全余量
│         例：产品在制剂袋中最长保持 72h → 测试 72h + 额外余量
│
└── 溶剂：使用实际产品基质（非仅纯化水），因基质成分影响浸出行为
```

**关键步骤的浸出物风险控制策略**

| 工艺步骤 | 浸出物风险等级 | 控制措施 |
|----------|-------------|---------|
| UF/DF 之前的上游步骤 | 低（浸出物可被 UF/DF 去除） | 供应商 E&L 数据 + 工艺相容性确认 |
| UF/DF 步骤本身 | 中（浸出物在此后不再被去除） | 浸出物测试 + 安全阈值评估 |
| 制剂配制 / 终容器 | 高（浸出物直接进入最终产品） | 完整 LER + ICH Q3C/Q3D 安全阈值计算 |

:::
