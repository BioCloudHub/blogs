## 蛋白质糖基化修饰的定义、类型与生物制药意义

:::answer

**基本定义**

蛋白质糖基化（Protein Glycosylation）是指碳水化合物分子（聚糖）通过共价键附着到蛋白质特定氨基酸残基上的**酶促翻译后修饰过程**。与非酶促的糖化（Glycation）不同，糖基化由高度特异性的糖基转移酶系统催化，发生在内质网（ER）和高尔基体（Golgi）中，对蛋白质折叠、分泌运输和细胞信号传导具有重要调控作用。

**在生物制药中的战略重要性**

目前已上市的生物技术药物中，**超过 60%** 为糖蛋白，包括单克隆抗体（mAb）、重组激素（EPO、FSH）和酶替代疗法产品（α-葡萄糖苷酶、拉罗尼酶）等。糖基修饰通过以下维度直接影响药物质量：

| 影响维度 | 具体体现 |
|---|---|
| 生物学活性 | Fc 糖型影响 ADCC（岩藻糖化）、CDC（半乳糖化）效应功能 |
| 药代动力学（PK） | 唾液酸化延长体内半衰期；高甘露糖型加速清除 |
| 免疫原性 | NGNA（非人源唾液酸）可诱导抗 NGNA 抗体；高甘露糖型具有较强免疫原性 |
| 溶解度与稳定性 | 糖链参与维持蛋白质折叠状态，防止聚集 |
| 批次一致性 | 糖型分布的批次间差异是生物制药可比性评估的核心指标 |

因此，对糖蛋白的糖基化修饰进行系统分析表征，是 ICH Q6B 要求的产品质量研究重要组成部分，部分关键糖型指标（如岩藻糖化比例、Man5 水平）已明确列为单抗的 CQA。

:::

## N-糖基化与 O-糖基化的类型特征、合成机制与异质性来源

:::answer

蛋白质糖基化主要分为 **N-糖基化**和 **O-糖基化**两大类型，二者在连接位点、合成机制和糖型结构上存在本质差异。

**N-糖基化（N-linked Glycosylation）**

- **连接位点：** 天冬酰胺（Asn）残基的酰胺氮，位于共识序列 **Asn-X-Ser/Thr**（X 为除脯氨酸外任意氨基酸）中
- **合成场所：** 内质网（核心聚糖 Glc₃Man₉GlcNAc₂ 整体转移）→ 高尔基体（逐步加工修饰）
- **三种主要 N-糖型：**

| N-糖型 | 结构特征 | 典型代表 |
|---|---|---|
| **高甘露糖型（High Mannose）** | 核心 GlcNAc₂ + 5~9 个甘露糖，无末端装饰糖 | Man5~Man9 |
| **复杂型（Complex）** | 核心岩藻糖化 + 末端 GlcNAc/Gal/Sia 双天线或多天线结构 | G0F、G1F、G2F |
| **杂合型（Hybrid）** | 一支臂为高甘露糖型，另一支臂为复杂型 | 杂合型糖链 |

**O-糖基化（O-linked Glycosylation）**

- **连接位点：** 丝氨酸（Ser）或苏氨酸（Thr）残基的羟基（-OH），**无共识序列**约束
- **合成场所：** 高尔基体（在 N-糖基化、折叠和聚合完成后进行）
- **核心糖基：** 最常见为 N-乙酰半乳糖胺（GalNAc）起始，延伸形成黏液素类似结构；也可以 GlcNAc、木糖、甘露糖或海藻糖为起始

**糖基化异质性的两个层次**

1. **点不均一性（Macroheterogeneity）：** 并非所有潜在糖基化位点（Asn-X-Ser/Thr 序列或 Ser/Thr）都必然发生修饰，部分位点修饰占有率（Occupancy）< 100%，导致"占位"层面的异质性
2. **微不均一性（Microheterogeneity）：** 在每个已占位的糖基化位点，由于高尔基体中多种糖基转移酶的竞争性作用，同一位点可携带多种不同结构的聚糖，产生糖型分布层面的异质性

**生物制药关注重点**

鉴于 N-糖基化对单抗稳定性、效应功能和 PK 的显著影响，本领域讨论的"糖型控制"主要针对 **N-糖基化**，尤其是 IgG Fc 段 **Asn297** 位的 N-糖型分布。O-糖基化在 IgG 标准结构中相对稀少（主要存在于铰链区），通常不作为常规 CQA 重点监控，但在 Fc 融合蛋白等其他生物制品中需要关注。

:::

## 高甘露糖型（High Mannose）的形成机制、含量标准与双向效应

:::answer

高甘露糖型是 N-糖基化加工过程中由于α-甘露糖苷酶修剪不完全而形成的中间或终态结构，是单抗质量控制中最受关注的糖型之一。

**高甘露糖型的形成路径**

高甘露糖型（Man5~Man9）是复杂型 N-糖的前体结构，在高尔基体内若甘露糖苷酶 I/II 的加工受阻，则 Man5~Man9 无法转化为复杂型糖链，以高甘露糖状态保留：

```
内质网：GlcNAc₂Man₅ → 添加 3Glc + 4Man → 3Glc-GlcNAc₂Man₉
         ↓ 葡萄糖苷酶 I/II + 甘露糖苷酶 IA
         GlcNAc₂Man₈ → 进入高尔基体

高尔基体正常路径：
Man₈ → α-甘露糖苷酶 I → Man₅ → GnT-I → 进入复杂型加工
                                    ↓ GnT-I 活性不足 / 底物缺乏
                                  Man₅ 停留 → 高甘露糖型积累
```

**影响高甘露糖型积累的主要因素**

| 影响因素 | 机制 |
|---|---|
| GnT-I 酶活性下降 | 高渗透压、低温等条件抑制 GnT-I，Man5 无法向复杂型转化 |
| 几夫碱（Kifunensine）添加 | α-甘露糖苷酶 I 抑制剂，人为阻断高甘露糖向复杂型的转化 |
| 高渗透压（> 400 mOsm/kg） | 抑制 GnT-I 酶活性，同时减少 GnT-I mRNA 翻译 |
| 谷氨酸胺浓度变化 | 影响 UDP-GlcNAc（GnT-I 底物）的胞内合成水平 |

**高甘露糖型的双向效应**

| 效应维度 | 影响方向 | 机理 |
|---|---|---|
| **ADCC 活性** | **显著增强** | 高甘露糖型 Fc 与 FcγRIIIa（CD16）结合亲和力高于岩藻糖化复杂型（~10 倍） |
| **体内半衰期（PK）** | **显著缩短** | 肝脏巨噬细胞（Kupffer 细胞）表面甘露糖受体（MMR/CD206）特异性识别和介导清除高甘露糖型 IgG |
| **免疫原性** | **升高** | 树突状细胞等 APC 表面 DC-SIGN 受体高效摄取高甘露糖糖蛋白，激活免疫应答 |

**可接受的含量标准**

新抗体药物研发早期，一般将 **Man5 含量控制在 ≤ 5%（通常可接受上限为 10%）** 作为工艺开发阶段的参考范围；在生物类似药开发中，应尽量与原研药的高甘露糖型 Profile 保持一致，并在可比性研究中提供科学证据支撑任何差异的可接受性。

:::

## 半乳糖化修饰（Galactosylation）的形成、影响因素与 CDC 功能关联

:::answer

半乳糖（Galactose, Gal）是 IgG Fc 段 N-糖的末端修饰糖之一，其修饰水平对 Fc 构象和 CDC（补体依赖细胞毒性）活性具有直接影响。

**半乳糖化的基本特征**

- 约 **95%** 的常规 CHO 细胞表达的重组 IgG 以半乳糖作为末端糖之一（G1F 或 G2F 主峰）
- 单个 IgG 分子可含 **0、1 或 2 个半乳糖残基**（对应 G0F、G1F、G2F），形成分布型糖型异质性
- 半乳糖由 β-1,4-半乳糖转移酶（B4GalT）在高尔基体反式网络（trans-Golgi）中催化添加，需要 UDP-Gal 作为底物

**半乳糖化对 Fc 构象的影响**

研究证实，末端半乳糖基化对 Fc 段 CH2 域的空间构象形成有重要贡献：
- 半乳糖残基参与稳定 Fc CH2 域的"开放"构象，使 C1q 结合位点充分暴露
- 仅有核心岩藻糖化（G0F）时，Fc CH2 域构象与 G1F/G2F 存在差异，C1q 结合面可及性降低
- 研究明确：**Fc 末端半乳糖化水平与 IgG 的 CDC 活性正相关，半乳糖化程度下降导致 CDC 活性减弱**

**影响半乳糖化水平的工艺因素**

| 工艺因素 | 影响方向 | 机理 |
|---|---|---|
| 葡萄糖浓度过低（限糖） | 半乳糖化↓ | 葡萄糖是 UDP-Gal 的碳源，限糖降低 UDP-Gal 供给 |
| 培养温度降低 | 半乳糖化↓ | B4GalT 酶活性随温度降低而下降 |
| D-半乳糖添加 | 半乳糖化↑ | 直接补充 Gal，提升胞内 UDP-Gal 水平 |
| 低 DO（< 20%） | 半乳糖化↓ | UDP-Gal 合成减少 + 二硫键不完全形成产生空间位阻 |
| 锰离子（Mn²⁺）添加 | 半乳糖化↑（协同效应） | 激活糖基转移酶活性 |
| 代谢废物（氨）积累 | 半乳糖化↓ | 高尔基体 pH 升高影响 B4GalT 活性 |

**对 PK 的影响**

目前尚无研究确证末端半乳糖残基对 IgG PK 特征（半衰期、清除率）的显著影响，与唾液酸化对 PK 的显著影响形成对比。半乳糖化水平的监控主要用于保证 CDC 活性的批次一致性。

:::

## 唾液酸化修饰（Sialylation）：NANA vs. NGNA、效应功能与 PK 影响

:::answer

唾液酸化是 N-糖链末端的最后一步修饰，对单抗的免疫效应功能和体内药代动力学均具有重要影响，同时在人源化安全性方面存在特殊风险（NGNA 问题）。

**两种唾液酸类型的区别**

在哺乳动物表达系统中，主要存在两种唾液酸形式：

| 类型 | 全称 | 物种分布 | 生物制药风险 |
|---|---|---|---|
| **NANA（Neu5Ac）** | N-乙酰神经氨酸 | 人类 IgG 的正常唾液酸形式 | 低风险，符合人体正常成分 |
| **NGNA（Neu5Gc）** | N-羟乙基神经氨酸 | 小鼠、大鼠、猪等哺乳动物（非人灵长类） | **高风险**：人体内含抗 NGNA 抗体，NGNA 含量升高可能触发免疫反应 |

**NGNA 的风险来源**

CHO 细胞（中国仓鼠卵巢细胞）的基因组中保留有 CMAH（CMP-Neu5Ac Hydroxylase）基因活性痕迹，可将 CMP-Neu5Ac 转化为 CMP-Neu5Gc，导致表达产品中含有一定量的 NGNA。由于人类血液中天然含有抗 Neu5Gc 抗体，NGNA 修饰的生物药可能加速免疫清除，因此**生产过程中需密切监测 NGNA/NANA 比例**，并在 ICH Q6B 产品表征中报告。

**唾液酸化对效应功能的影响**

- Fc 段唾液酸含量越高，与 FcγRs（Fc 受体，如 FcγRIIIa）的结合活性越低，**ADCC 活性降低**
- 高唾液酸化的 Fc 段与细胞表面抗原结合活性也随之降低（构象效应）
- 另一方面，Fab 段的唾液酸化通常不影响抗原结合亲和力

**唾液酸化对 PK 的影响（最重要的功能意义）**

末端唾液酸对糖蛋白的体内稳定性具有关键保护作用，这一机制早在 20 世纪 70 年代即被确认：

```
末端唾液酸存在（高 Sia 修饰）：
血清糖蛋白 → 唾液酸掩盖末端半乳糖 → 无法被肝脏 ASGPR 识别
→ 不被 ASGPR 介导清除 → 体内半衰期延长（数天～数周）

末端唾液酸缺失（低/无 Sia 修饰）：
血清糖蛋白 → 末端半乳糖暴露 → 被肝脏无唾液酸糖蛋白受体（ASGPR）识别
→ 受体介导内吞 → 溶酶体降解 → 体内快速清除（半衰期缩短至数小时）
```

对于 CHO 细胞表达的 IgG，唾液酸化水平通常较低（< 5%），对 PK 的影响有限；但对于 EPO、促卵泡素（FSH）等高度依赖唾液酸化的糖蛋白激素，唾液酸化程度是决定体内活性的关键质量属性。

## 糖化（Glycation）与糖基化（Glycosylation）的本质区别及药物影响

:::answer

"糖化"与"糖基化"是两个极易混淆的概念，其反应机制、发生位点和对产品质量的影响完全不同，在 CMC 开发中需严格区分。

**核心区别对比**

| 对比维度 | 糖基化（Glycosylation） | 糖化（Glycation） |
|---|---|---|
| **反应性质** | **酶促反应**，由特异性糖基转移酶催化 | **非酶促反应**（Maillard 反应），自发进行 |
| **反应位点** | Asn（N-糖）或 Ser/Thr（O-糖）特异性位点 | 主要攻击赖氨酸（Lys）ε-氨基，N-末端氨基也可被糖化 |
| **参与底物** | 活化核苷糖（UDP-Gal、CMP-Sia 等）经高尔基体转移 | 游离还原糖（葡萄糖、果糖、半乳糖等），与赖氨酸氨基形成 Schiff 碱 |
| **发生场所** | 细胞内（内质网、高尔基体），受酶系严格控制 | 胞外/体外，在含还原糖的溶液中自发发生 |
| **可控性** | 工艺参数可调控 | 与培养液葡萄糖浓度和接触时间正相关，可通过控糖降低 |
| **典型产物** | N-糖链（G0F、G1F、Man5 等） | 糖化 Lys（发生于特定 Lys 残基，早期产物为 Schiff 碱，稳定后为 Amadori 产物） |

**糖化对单抗质量的影响**

糖化修饰并非简单的化学噪音，其后果涵盖多个质量维度：

| 影响维度 | 具体效应 |
|---|---|
| **电荷异质性** | 赖氨酸 ε-氨基被糖化后正电荷丧失，pI 降低，形成**酸性电荷变体**（CEX 中提前洗脱） |
| **聚集体** | 赖氨酸的非特异性修饰改变局部电荷分布，可增加分子间疏水接触倾向，促进聚集 |
| **生物学活性** | CDR 区域赖氨酸糖化可改变抗原结合位点电荷分布，**影响抗原结合亲和力和生物学活性** |
| **批间一致性** | 糖化程度与培养液葡萄糖浓度的批次间差异直接相关，是批间一致性的潜在风险因素 |
| **晚期糖化终末产物（AGEs）** | 长期储存条件下，早期糖化产物可进一步转化为不可逆的 AGEs，影响蛋白质稳定性 |

**调控策略**

- 控制培养液葡萄糖浓度（维持在 1~4 g/L，避免长期高浓度葡萄糖暴露）
- 采用限糖补料策略（实时监控葡萄糖并动态补控）
- 缩短培养时间（减少葡萄糖与蛋白质的接触时间，尤其是培养后期活率下降阶段）
- 下游优化：通过 CEX 分离去除糖化比例高的酸性变体

## N-糖游离寡糖分析方法：酶切策略的选择与适用范围

:::answer

N-糖糖谱分析的第一步是将 N-聚糖从糖蛋白上定量、完整地释放，酶切方法的选择直接决定后续分析的完整性和准确性。

**三种主要 N-糖释放酶的对比**

| 酶 | 酶切位点 | 适用糖型 | 局限性 |
|---|---|---|---|
| **EndoH（内切糖苷酶 H）** | N-糖核心两个 GlcNAc 之间的糖苷键 | 高甘露糖型、部分杂合型 | 对复杂型 N-糖（双/三/四天线结构）**无效**，只释放一个 GlcNAc 保留在 Asn 上 |
| **PNGase F（N-糖苷酶 F）** | 天冬酰胺与 N-糖还原端 GlcNAc 之间的酰胺键 | 几乎所有 N-糖型（高甘露糖、复杂型、杂合型） | 对 **α(1,3)-岩藻糖**连接结构**无效**（此结构存在于植物和昆虫表达系统） |
| **PNGase A（N-糖苷酶 A）** | 同 PNGase F，但可切 α(1,3)-岩藻糖修饰的 N-糖 | 含 α(1,3)-岩藻糖连接的 N-糖 | 活性低于 PNGase F，反应条件要求较高 |

**实践中的选择原则**

对于哺乳动物细胞（CHO、HEK293）表达的重组 IgG，核心岩藻糖均为 **α(1,6)** 连接，PNGase F 完全适用，是行业标准选择。EndoH 主要用于质量研究中区分高甘露糖型与复杂型（EndoH 敏感性分析）。

**碱性水解法（β-消除）的局限性**

在碱性条件下进行的化学水解（β-消除）可释放 O-糖，但对 N-糖的特异性不强，且可能破坏部分糖型结构，通常不作为 N-糖分析的首选方法；更多用于 O-糖释放（配合 α-消除/β-消除 + 硼氢化还原）。

**释放后的分析流程**

酶切释放 N-糖 → 荧光标记（如 2-AB 或 2-AA 标记还原端）或直接 MS 分析 → UPLC（HILIC 柱）或 LC-MS 检测糖型分布 → 与参考标准品比对，计算各糖型相对比例（%）。

:::

## 生物类似药开发中糖型可比性的挑战与策略

:::answer

生物类似药（Biosimilar）开发中，将产品糖型调节至与原研药（RDP）高度相似是最具挑战性的质量目标之一，也是监管机构审批中重点审查的内容。

**核心挑战：糖型的不可"完美复刻"性**

原研药的糖型是其特定宿主细胞（通常为特定 CHO 细胞克隆）、培养基配方和工艺参数共同作用的结果，即使使用相同宿主细胞，不同克隆、不同培养基批次和工艺参数均会导致糖型 Profile 存在差异。因此，生物类似药的糖型往往无法与原研药完全一致，监管框架允许糖型存在一定范围的差异，但需提供科学证据证明差异不影响产品的安全性和有效性。

**生物类似药糖型策略的核心步骤**

1. **全面表征原研药糖型 Profile：** 通过多批次原研药样品（建议 ≥ 10 批）分析，建立糖型分布的参考范围（均值 ± 3SD），明确各关键糖型指标（G0F、G1F、G2F、Man5、岩藻糖化比例、唾液酸化水平等）的正常波动区间

2. **确定相似性目标区间（Similarity Target Range）：** 基于原研药参考范围和糖型对生物功能影响的文献证据，设定可接受的相似性窗口（通常不超过原研药波动范围的 1.5~2 倍）

3. **克隆筛选阶段整合糖型评估：** 在细胞株筛选中同步评估候选克隆的糖型倾向性，优先选择糖型与原研药接近的克隆，降低后续工艺调整的难度

4. **工艺调控至目标糖型区间：** 通过添加剂（D-半乳糖、Mn²⁺、GlcNAc）、培养参数（pH、温度、DO）的系统优化，将关键糖型指标调整至目标范围

5. **可比性研究文件准备：** 汇总糖型分析数据（多批次），配合活性分析（ADCC、CDC、FcRn 结合）和 PK/PD 数据，论证糖型相似性对临床等效性的支撑

:::

## 关键质量属性（CQA）的定义、识别原则与 KPI 区分

:::answer

CQA 的科学确定是 ICH Q8/Q9/Q10 体系下工艺开发的起点，其准确识别直接影响工艺表征研究的范围设计和放行标准的制定。

**ICH Q8(R2) 对 CQA 的正式定义**

> 关键质量属性（CQA）是指物理、化学、生物学或微生物的性质或特征，其应在适当的限度、范围或分布内，以**保证产品质量（安全性和有效性）**。

**CQA 的识别标准**

CQA 的确定以**对患者安全性和有效性的危害严重程度**为核心判断依据，具体评估维度包括：

| 评估维度 | 关键问题 |
|---|---|
| 生物学活性影响 | 该属性超出范围是否导致效价显著下降（> 20%）或靶点结合丧失？ |
| 安全性影响 | 该属性超出范围是否增加免疫原性或毒性风险？ |
| PK/PD 影响 | 该属性超出范围是否影响体内暴露量或作用持续时间？ |
| 结构完整性影响 | 该属性超出范围是否导致蛋白质不稳定或加速降解？ |

**CQA 不等于放行标准**

PDA 第 60 号技术报告明确指出：CQA ≠ 标准（Specification）。两者的关系如下：
- 放行标准是一系列分析检验及可接受限度的组合；CQA 是对产品质量维度的科学认知
- 某些 CQA（如病毒清除效果）可通过工艺验证控制，不必逐批检验，但仍属于 CQA
- 某些非 CQA 属性（如渗透压）可能纳入放行标准（用于工艺监控），但对患者危害有限

**关键工艺属性（KPA）的区分**

KPA（Key Process Attribute）是评估工艺**性能**的属性，如果超出范围可能导致**工艺失败**（如细胞活率、乳酸水平），但不直接影响产品对患者的安全性和有效性。KPA 与 CQA 的本质区别在于"危害对象"：KPA 危害工艺，CQA 危害患者。

:::

---

## CQA 与 KPA（关键工艺属性）的定义与实践区分

:::answer

在生物制药工艺开发体系中，CQA 和 KPA 是两个平行但不等同的质量管理维度，需在工艺表征研究设计中明确区分并分别管理。

**定义对比**

| 维度 | CQA（关键质量属性） | KPA（关键工艺属性） |
|---|---|---|
| **定义依据** | ICH Q8(R2) | PDA TR 60、ICH Q11 等行业实践 |
| **关注对象** | 产品质量（安全性、有效性） | 工艺性能（工艺过程的稳定性和可控性） |
| **超限后果** | 危害患者（药效下降、免疫原性风险） | 导致工艺失败（Titer 下降、活率崩溃、聚集体异常） |
| **典型单抗示例** | 岩藻糖化比例、聚集体水平、效价、ADCC 活性 | 峰值 VCD、乳酸浓度、葡萄糖消耗速率、细胞活率 |
| **控制策略** | 纳入放行标准或工艺验证 | 纳入工艺监控（In-Process Control, IPC） |

**上下游 KPA 的分级管理**

对于生物制药的每一个上下游工艺步骤（细胞培养、Protein A、病毒灭活、离子交换、UF/DF 等），均需单独识别该步骤的 KPA，并设定相应的操作范围（Operating Range）和可接受范围（Acceptable Range）。

**实践中的注意事项**

- CQA 的确定是贯穿产品全生命周期的持续性活动，需随产品知识积累（临床数据、稳定性数据、可比性研究数据）不断更新
- 部分属性在开发早期被初步归类为 CQA，随着知识积累可能降级（如确认某修饰对功能无影响）；也有属性随临床证据出现被升级为 CQA

:::

## 原液 CQA 的系统确定方法：从 QTPP 到 CQA 的四步流程

:::answer

原液（Drug Substance, DS）CQA 的确定是 CMC 策略文件（如 ICH Q8 Target Product Quality Profile 分析）的核心内容，遵循以下标准化四步流程。

**步骤一：建立 QTPP（目标产品质量概况）清单**

QTPP（Target Product Quality Profile）是对最终药品在满足安全性和有效性要求前提下的质量特征集合，通常包括：
- 剂型与给药途径（静脉注射/皮下注射）
- 效价与生物学活性指标
- 纯度与杂质（聚集体、片段、宿主蛋白残留等）
- 糖型分布
- 电荷变体 Profile
- 稳定性（货架期要求）

**步骤二：对 QTPP 各属性进行危害评估打分**

针对每个 QTPP 属性，从以下三个维度进行半定量打分（通常采用 1~3 分或 1~5 分量表）：
- **严重性（Severity）：** 超出限度对患者危害的严重程度
- **发生概率（Occurrence）：** 工艺中该属性超标的频率
- **可检测性（Detectability）：** 当前检测方法对超标情况的识别能力

风险优先数（RPN）= 严重性 × 发生概率 × 可检测性

**步骤三：按 RPN 排序，确定 CQA**

RPN 较高的属性优先确定为 CQA；RPN 较低（尤其是严重性评分低）的属性可暂时不列为 CQA，但需记录评估理由。

**步骤四：生命周期管理更新**

随以下信息的积累持续更新 CQA 清单：
- 临床试验数据（PK/PD、免疫原性结果）
- 加速稳定性和长期稳定性研究数据
- 工艺变更可比性研究数据
- 上市后不良反应监测数据

:::

## 上游工艺表征用 CQA 的评估原则与限度制定方法

:::answer

上游工艺表征（Process Characterization, PC）使用的 CQA 与原液/成品的 CQA 既有关联又有差异，需单独评估和设定，以准确反映上游工艺对产品质量的贡献范围。

**上游工艺表征 CQA 的基本评估原则**

| 原则 | 说明 |
|---|---|
| **参考原液和成品的 CQA** | 上游 CQA 是原液 CQA 的子集，但需根据上游工艺的特点进行适配 |
| **结合产品分子结构和作用机制** | 上游工艺直接影响的糖型、电荷变体等属性应纳入评估；与工艺无直接关联的终产品属性（如制剂 pH）不涉及 |
| **考虑中间体控制节点** | 上游工艺表征通常在 Protein A 亲和层析步骤后（Protein A 洗脱液，PA Eluate）进行质量评估，此步骤的数据代表上游批次质量 |
| **结合下游纯化能力综合考虑限度** | 下游能有效去除的杂质（如聚集体），上游限度可相应放宽；下游去除能力弱的属性（如糖型），上游限度应严于原液/成品规格 |

**关键质量属性的限度制定逻辑**

**① 聚集体（Aggregates）**

- PA 步骤后聚集体可被后续离子交换、SEC 等步骤有效去除（去除因子可达 10~100 倍）
- 上游 PC 研究的聚集体限度可结合**原液规格 × 安全系数 + 下游去除能力**制定
- 示例：若原液规格为 ≤ 2%，下游能将聚集体从 10% 降至 1%，则上游 PA Eluate 限度可设为 ≤ 10%

**② 糖型分布（Glycosylation Profile）**

- 下游纯化对糖型几乎没有选择性去除能力（糖型由细胞表达决定，各糖型的理化性质差异不足以在色谱步骤间实现分离）
- 上游工艺是糖型的唯一决定因素，因此**上游 CQA 的糖型限度应严于原液/成品规格**（通常留有 10~20% 的安全余量）
- 示例：若原液 Man5 规格为 ≤ 5%，则上游 PC 研究的 Man5 控制目标应为 ≤ 4%

:::

## 抗体聚集体的定义、形成机制与首要质量影响

:::answer

聚集体是单抗安全性评估中最核心的质量属性，其形成机制复杂，对免疫原性的潜在影响使其在所有生物制药开发阶段均受到重点关注。

**聚集体的定义与形成机制**

聚集体（Aggregate）是由两个或多个抗体分子通过以下分子间作用力形成的稳定复合物：

| 聚集驱动力 | 具体形式 | 可逆性 |
|---|---|---|
| 共价键 | 分子间错误二硫键（游离硫醇-SH 介导） | 不可逆 |
| 疏水相互作用 | Fab/Fc 疏水核心暴露后的分子间接触 | 部分可逆 |
| 静电吸引 | 低 pH 或低离子强度下正负电荷区域相互吸引 | 可逆 |
| 氢键 | β-折叠堆积形成淀粉样聚集核 | 不可逆 |

**聚集发生的关键结构驱动因素**

- **Fab 段错误折叠：** VH/VL 界面折叠不完全，疏水核心暴露，介导分子间接触
- **Fc 段错误折叠：** CH2 域在低 pH（如 Protein A 洗脱步骤）下部分展开
- **游离硫醇（Free Thiol）：** 半胱氨酸残基未形成正确二硫键，游离 -SH 通过硫醇-二硫键交换形成分子间共价聚集
- **可溶性聚集体分裂后不再溶解：** 一旦聚集体超过临界核（Nucleus）尺寸，便形成热力学稳定的不可逆结构

**聚集体的首要质量影响：免疫原性**

聚集体是 ADA（抗药抗体）形成的高风险因素，其原因在于：
- 聚集体的颗粒性使其更易被树突状细胞（DC）等 APC 摄取，激活 T 细胞介导的适应性免疫
- 重复性排列的 B 细胞表位（B-cell epitopes in repetitive array）可直接激活 B 细胞，产生 T 细胞非依赖性抗体应答
- 变性/错误折叠的聚集体可暴露正常折叠状态下被掩盖的新生抗原表位（Neoepitopes）

此外，聚集体还可能影响 FcγR、淋巴细胞-1 受体和 FcRn 受体的正常结合能力，干扰抗体的效应功能和体内 PK。

:::

## 半乳糖基化（Galactosylation）的完整认知：结构、形成与功能

:::answer

半乳糖基化是 IgG Fc 段 N-糖的重要末端修饰，其在 CDC 活性调控中的核心作用使其成为单抗不可忽视的 CQA 考量指标。

> 本条目系对 Q5 关键知识点的延伸整合，补充了半乳糖基化在 Fc 构象、C1q 招募和批次质量管理中的更多细节。

**Fc 末端半乳糖化的 CDC 激活机制**

```
G1F/G2F（高半乳糖化抗体）
    │ Fc CH2 域"开放"构象
    ├── C1q 结合位点（Glu318、Lys320、Lys322）充分暴露
    ├── 半乳糖残基参与稳定 CH2 构象
    ▼
C1q 高亲和力结合 → C1 激活 → C4 → C2 → C3 → C5-C9（MAC）
→ 靶细胞裂解 → CDC 效应发挥

G0F（低半乳糖化抗体）
    │ Fc CH2 域构象相对"封闭"
    ├── C1q 结合位点可及性降低
    ▼
C1q 结合弱化 → CDC 活性减弱
```

**批次间半乳糖化差异的管理**

在生产规模（GMP 批次）中，半乳糖化水平的批次间变异是最常见的糖型质量问题之一，其主要来源包括：
- 补料培养基批次间 D-半乳糖含量差异
- 培养温度的批次间波动（影响 B4GalT 活性）
- 接种细胞代次差异（影响 B4GalT 表达水平）

**管理建议：** 通过统计过程控制（SPC）建立半乳糖化水平（G0F%、G1F%、G2F%）的批次趋势图，设定控制图警戒线（均值 ± 2SD）和行动限（均值 ± 3SD），实现对生产过程的主动监控。

:::

## 去岩藻糖基化（Afucosylation）与核心岩藻糖化对 ADCC 的调控机制

:::answer

核心岩藻糖化（Core Fucosylation）是 IgG Fc 段 N-糖中最重要的结构修饰之一，其有无对 ADCC 活性的影响幅度远超其他任何糖型变化，是设计增强型抗体药物的核心靶标。

**核心岩藻糖化的结构基础**

核心岩藻糖（Core Fucose）通过 **α(1,6) 键**连接于 N-糖核心第一个 GlcNAc 的 6 位，由 α-1,6-岩藻糖基转移酶（FUT8）催化。约 **90%** 常规 CHO 细胞产生的重组 IgG Fc 段 N-糖含有核心岩藻糖（即岩藻糖化糖型，如 G0F、G1F、G2F 为主峰）。

**核心岩藻糖化影响 ADCC 的分子机制**

```
含核心岩藻糖（G0F/G1F/G2F）：
Fc（含 Fuc） + FcγRIIIa（Asn162 N-糖与 Fc 核心 Fuc 产生空间位阻）
→ 结合亲和力低（KD ~ 3~10 µM）
→ NK 细胞激活信号弱 → ADCC 效应弱

无核心岩藻糖（G0/G1/G2，Afucosylated）：
Fc（无 Fuc） + FcγRIIIa（空间位阻消除，Fc-FcγRIIIa 接触界面优化）
→ 结合亲和力显著提升（KD ~ 0.3~1 µM，约10倍增强）
→ NK 细胞强激活 → ADCC 效应显著增强（可达含 Fuc 的 10~100 倍）
```

**核心岩藻糖化与 CDC 的关系**

与 ADCC 不同，核心岩藻糖化对 CDC 活性**无显著影响**（CDC 主要受半乳糖化水平调控）。因此，对于以 ADCC 为主要效应机制的抗体（如靶向 CD20、CD30 的抗体），降低核心岩藻糖化是提升药效的优选策略；而对于以 CDC 为主要机制的抗体，岩藻糖化调控并非优先考量。

**降低岩藻糖化的工程策略**

| 策略 | 方法 | 典型案例 |
|---|---|---|
| FUT8 基因敲除 | 删除编码 α-1,6-岩藻糖转移酶的 FUT8 基因，产生 100% 无岩藻糖抗体 | Kyowa Hakko Kirin 的 Potelligent® 技术（Mogamulizumab） |
| GnT-III 过表达 | 平分型 GlcNAc 转移酶（GnT-III）的过表达导致平分型 GlcNAc 添加后 FUT8 无法作用，间接降低岩藻糖化 | Roche 的 GlycoMAb 技术（Obinutuzumab） |
| 培养基添加 Mn²⁺ | Mn²⁺ 干扰 GDP-岩藻糖的合成代谢途径，降低岩藻糖化 | 工艺层面的部分调控（效果有限，通常降低 5~20%） |
| 替代糖供给 | 添加 2-脱氧-D-半乳糖或岩藻糖类似物，竞争性抑制 FUT8 | 实验室研究阶段 |

:::

## 唾液酸化（Sialylation）的完整认知：NGNA 安全性与 PK 保护机制

:::answer

> 本条目系对 Q6 关键知识点的延伸整合，补充了 NGNA 产生的细胞生物学机制、检测要求和体内 ASGPR 清除机制的定量化描述。

**NGNA 在 CHO 细胞中的产生机制**

人类基因组中 CMAH 基因存在功能性缺失突变（2 号外显子缺失），导致人体无法合成 Neu5Gc（NGNA）。然而，CHO 细胞（及小鼠等啮齿类动物）的 CMAH 基因有活性，可将 CMP-Neu5Ac 转化为 CMP-Neu5Gc，进而将 NGNA 整合到抗体 N-糖链中：

```
CHO 细胞：
CMP-Neu5Ac ──CMAH酶──→ CMP-Neu5Gc
    │                          │
    ▼                          ▼
ST6Gal 将 Neu5Ac 添加到糖链末端    ST6Gal 将 Neu5Gc 添加到糖链末端
→ NANA 修饰（人源性，安全）      → NGNA 修饰（非人源性，有免疫原性风险）
```

**NGNA 的监测与控制要求**

- 生物制药 GMP 生产中需建立 NGNA/（NANA + NGNA）比值的批次检测和放行标准
- 典型控制目标：**NGNA < 0.3%~1%**（依据产品特性和申报地区要求）
- 降低 NGNA 的策略：优化培养基（减少外源 NGNA 来源）；通过基因工程敲除 CHO 细胞 CMAH 基因；避免使用动物来源培养基成分

**唾液酸化保护糖蛋白的 ASGPR 机制**

```
有末端唾液酸（Sia-Gal-GlcNAc-...）：
Sia 掩盖末端 Gal 残基
→ 肝脏 ASGPR（去唾液酸糖蛋白受体）无法识别
→ 血清糖蛋白正常循环 → 半衰期延长（IgG 类 ~21 天）

无末端唾液酸（Gal-GlcNAc-...）：
末端 Gal 暴露
→ 肝脏 ASGPR（主要在肝实质细胞 Kupffer 细胞表面）高亲和力识别
→ 受体介导内吞 → 溶酶体降解
→ 糖蛋白半衰期缩短（去唾液酸 EPO 从数小时→数分钟）
```

对于 IgG 类抗体，FcRn 介导的再循环是延长半衰期的主要机制（约 21 天），ASGPR 途径的贡献相对较小，故 IgG 唾液酸化对 PK 的影响有限；但对 EPO、FSH 等 **非 IgG 类糖蛋白**，唾液酸化水平是决定体内 PK 的关键 CQA。

:::

## 高甘露糖型（High Mannose）的完整合成路径与功能双刃剑效应

:::answer

> 本条目系 Q4 的内容精华版，聚焦高甘露糖型的合成路径还原与 ADCC/PK 双向效应的定量认知。

**高甘露糖型在 N-糖合成路径中的位置**

```
内质网合成阶段：
GlcNAc₂Man₅（多聚醇载体组装）
  + 3Glc + 4Man → 3Glc-GlcNAc₂Man₉（14 糖前体，en bloc 转移至 Asn297）
  ↓ 葡萄糖苷酶 I/II + α-甘露糖苷酶 IA
  GlcNAc₂Man₈ → 进入高尔基体

高尔基体加工阶段：
Man₈ → α-甘露糖苷酶 I → Man₅（正常路径起点）
         ↓ [GnT-I 活性不足 / 底物 UDP-GlcNAc 缺乏 / 酶活性受抑]
       Man₅~Man₈ 停留 → 高甘露糖型积累
         ↓ [GnT-I 正常作用]
       GlcNAc-Man₅ → 继续复杂型加工 → G0F/G1F/G2F
```

**高甘露糖型的双刃剑效应总结**

| 效应 | 影响方向 | 程度 | 机理 |
|---|---|---|---|
| ADCC 活性 | ↑ 显著增强 | 强（~10 倍于 G0F） | Man5 Fc 与 FcγRIIIa 亲和力更高（岩藻糖缺失效应） |
| FcRn 结合 | 基本不变 | 弱 | Man5 Fc 段 CH2 构象改变对 FcRn 结合影响有限 |
| 体内半衰期（PK） | ↓ 显著缩短 | 强 | 肝脏巨噬细胞甘露糖受体（MMR/CD206）快速清除 |
| CDC 活性 | 轻微降低 | 弱 | C1q 招募依赖半乳糖化，与高甘露糖化关联弱 |
| 免疫原性 | ↑ 升高 | 中 | DC-SIGN 受体摄取，激活 T 细胞应答 |

**生产控制建议**

对于常规治疗性单抗：Man5 **≤ 5%**（严格）至 **≤ 10%**（宽松）为行业接受标准；对于有意提高 ADCC 的设计分子（如 Fc 工程化抗体），可允许更高的高甘露糖水平，但需同步评估 PK 缩短对给药方案的影响。

:::

## 脱酰胺化修饰（Deamidation）：位点特异性、影响评估与 CQA 判定

:::answer

脱酰胺化是单抗最常见的化学降解途径，其 CQA 属性判定取决于修饰位点与关键功能区域的位置关系。

**脱酰胺化发生的氨基酸类型与速率差异**

| 位点 | 去酰胺速率 | 典型半衰期（pH 7.4, 37°C） |
|---|---|---|
| **Asn-Gly（NG）** | 极快 | ~1 天 |
| **Asn-Ser（NS）** | 快 | 数天 |
| **Asn-His（NH）** | 中 | 数周 |
| **Asn-Ala（NA）** | 慢 | 数月~数年 |
| **Gln（所有位点）** | 极慢 | > Asn 的 100 倍（实际几乎检测不到） |

**IgG 恒定区的保守脱酰胺位点**

IgG 的 CH2 域中存在保守的 **Asn-Gly** 序列，在生理条件下该位点会发生自发脱酰胺，产生 Asp 或 isoAsp。该位点的脱酰胺化对 Fc 功能（ADCC、CDC、FcRn 结合）的影响相对有限，但会改变电荷 Profile，是酸性变体的来源之一。

**脱酰胺化的 CQA 分类判断**

| 位点位置 | CQA 判定 | 原因 |
|---|---|---|
| **CDR 区域（直接参与抗原接触）** | **通常为 CQA** | 脱酰胺化改变 CDR 构象，直接影响抗原结合亲和力（如 Herceptin Asn30） |
| **CDR 附近（不直接接触但影响 loop 构象）** | **需逐案评估** | 通过改变 CDR loop 结构间接影响结合活性 |
| **Fc 段恒定区（远离功能位点）** | **通常不列为 CQA** | 对抗原结合、PK、ADCC/CDC 影响有限；目前无文献报告对免疫原性有显著影响 |

**监控与分析**

- 通过肽图（LC-MS/MS Peptide Mapping）定位脱酰胺化位点并定量每个位点的修饰程度（%脱酰胺）
- 对于 CDR 位点脱酰胺化，建议建立批次放行的定量限度（如特定 CDR Asn 位点脱酰胺化 ≤ 5%）
- 实时稳定性样品中脱酰胺化的增量趋势是长期储存中最重要的化学降解监控指标之一

:::

## 蛋氨酸氧化（Methionine Oxidation）：易氧化位点、电荷影响与 FcRn 功能损伤

:::answer

蛋氨酸（Met）氧化是单抗在生产、储存和体内循环过程中另一重要的化学降解途径，其独特之处在于对 FcRn 结合功能的直接损伤，可能缩短抗体体内半衰期。

**蛋氨酸氧化的化学机制**

在较高的氧化压力（H₂O₂、金属离子催化的 Fenton 反应、光照）条件下，Met 侧链硫醚基（-S-）被氧化为甲硫亚砜（-S(O)-，Met-sulfoxide）：

```
Met（-CH₂-CH₂-S-CH₃）
    ↓ 氧化（[O]：H₂O₂, •OH, ¹O₂）
Met-sulfoxide（-CH₂-CH₂-S(O)-CH₃）  ← 可由甲硫亚砜还原酶（Msr）还原
    ↓ 过度氧化
Met-sulfone（-CH₂-CH₂-S(O₂)-CH₃）  ← 不可逆
```

**氧化对电荷变体的影响（无净电荷变化）**

Met 氧化过程中**无净电荷变化**（硫醚→亚砜均为中性），但由于氧化后 Met 侧链极性增加、局部空间构象发生变化，导致：
- 抗体**空间电荷分布**改变（表面暴露的荷电基团重新排列）
- CEX 或 iCIEF 图谱中可能出现酸性变体或碱性变体偏移（具体方向取决于氧化位点的局部环境）

**关键氧化位点及其功能影响**

| 位点 | 溶剂暴露程度 | 对 FcRn 结合的影响 | 功能后果 |
|---|---|---|---|
| **Met252**（CH2 域） | 中等 | FcRn 结合亲和力显著降低 | 抗体 FcRn 介导的再循环受损，体内半衰期缩短 |
| **Met428**（CH3 域） | 高（高度暴露） | FcRn 结合亲和力显著降低 | 同 Met252，两者协同增加 PK 风险 |
| **Met33**（VH 域，若存在） | 低（埋藏） | 通常无影响 | 不影响 Fc 功能，但影响 Fab 稳定性 |

**Met252 和 Met428 是 IgG 中最重要的氧化热点**，两者的氧化会抑制 Fc 与 FcRn 受体（新生儿 Fc 受体）的结合，导致 IgG 更容易被溶酶体降解，体内半衰期缩短，临床 PK 暴露量降低。

**工艺控制策略**

- 控制培养液 DO（避免过度氧化压力）
- 避免强光照射（尤其 UVA/UVB 触发的光氧化）
- 评估培养基中铜离子浓度（Cu²⁺ 是 Fenton 反应的催化剂，高浓度加速氧化）
- 下游缓冲液去氧处理（充氮饱和），低温操作
- 制剂中添加抗氧化剂（如蛋氨酸氨基酸本身作为牺牲性抗氧化剂）

:::

### 蛋白质等电点（pI）的定义、测定意义与分析方法

:::answer

等电点（Isoelectric Point, pI）是蛋白质的基本理化特征，也是理解电荷异质性、开发离子交换纯化工艺和制剂 pH 选择的重要参数。

**等电点的定义与物理含义**

蛋白质是含有正电荷（Arg、Lys、His、N-末端 -NH₂）和负电荷（Asp、Glu、C-末端 -COOH，以及翻译后修饰如唾液酸）官能团的两性分子。

$$\text{当 pH} = pI \text{ 时：正电荷总量} = \text{负电荷总量，净电荷} = 0$$

- **pH < pI：** 蛋白质带净正电荷（阳离子形式），在阳离子交换（CEX）中被保留
- **pH > pI：** 蛋白质带净负电荷（阴离子形式），在阴离子交换（AEX）中被保留
- **pH = pI：** 净电荷为零，蛋白质溶解度最低，聚集倾向最高（制剂开发中需注意避开 pI）

**pI 的决定因素**

特定蛋白质的 pI 由其氨基酸组成（所有可电离基团的 pKa 组合）和翻译后修饰（去酰胺化使 pI 降低，C-末端赖氨酸保留使 pI 升高）共同决定，是蛋白质结构的固有特征，可用于鉴别蛋白质一致性。

**分析方法对比**

| 方法 | 原理 | 分辨率 | 特点 |
|---|---|---|---|
| **等电聚焦电泳（IEF，平板胶）** | 蛋白质在 pH 梯度凝胶中迁移至 pI 处停止 | 中等（0.02~0.1 pH 单位） | 传统方法，直观，适合鉴别性检测 |
| **毛细管等电聚焦（cIEF）** | 毛细管 + pH 梯度 + 全柱紫外检测 | 高（~0.01 pH 单位） | 自动化高，定量准确，适合批次放行 |
| **成像毛细管等电聚焦（iCIEF）** | cIEF + CCD 相机全柱实时成像 | 最高（~0.005 pH 单位） | 目前行业主流的电荷变体定量分析方法 |
| **毛细管区带电泳（CZE）** | 在均一 pH 缓冲液中按电泳迁移率分离 | 中等 | 不基于 pI，但可分辨电荷变体 |

**pI 在 CMC 开发中的应用**

- **纯化策略设计：** 根据 pI 选择离子交换模式（CEX 适用于 pI > 6 的抗体，AEX 适用于 pI < 5 的蛋白）
- **制剂 pH 优化：** 避免制剂 pH 接近 pI（防止聚集），通常选择 pI ± 2 以上的 pH
- **批次一致性监控：** 电荷变体 Profile（iCIEF 图谱）中主峰位置与翻译后修饰引起的 pI 偏移是批次可比性的核心指标

:::

## 单抗 N-糖分析策略：三大分析层次与主流检测方法

:::answer

N-糖分析是单抗质量表征的核心内容，根据分析对象（游离糖、糖肽或完整蛋白/亚基）的不同，形成了三个各具优势的分析层次。

**单抗 N-糖分析的三大策略层次**

**层次一：游离糖水平分析（Released Glycan Analysis）**

- **流程：** PNGase F 酶切释放 N-糖 → 荧光标记（2-AB 或 2-AA 标记还原端氨基）→ UPLC-FLD（HILIC 反相柱）分离定量
- **信息输出：** 全面的糖型 Profile（G0F、G1F、G2F、Man5 等各糖型的相对摩尔比例，%）
- **优点：** 分辨率高，定量准确，灵敏度好，是行业金标准方法（常见 2-AB UPLC 法）
- **局限：** 步骤多（酶切 + 标记 + 分析），耗时较长（通常 1~2 天）

**层次二：糖肽水平分析（Glycopeptide Analysis, LC-MS/MS）**

- **流程：** 蛋白质酶解（Trypsin 或其他蛋白酶）→ 糖肽 LC-MS/MS 分析
- **信息输出：** 各糖基化位点的糖型分布（位点特异性信息，Site-specific Glycosylation Profile）
- **优点：** 可同时获得糖型分布和修饰位点占有率（Occupancy）信息；适用于多糖基化位点蛋白的分位点分析
- **局限：** 数据解析复杂，方法开发难度较高

**层次三：完整蛋白/亚基水平分析（Intact Mass Analysis）**

- **流程：** 完整 IgG 或经 IdeS 酶切产生的 Fc/2 亚基 → 质谱直接分析
- **信息输出：** 主要糖型的质量信息（G0F、G1F、G2F 等离子簇的质荷比和相对强度）
- **优点：** 快速（< 1 天），无需酶切释放和标记；适合高通量筛选和快速批次鉴定
- **局限：** 分辨率低于游离糖分析，微量糖型（< 1~2%）难以检测；定量依赖离子强度（需验证与真实摩尔比例的相关性）

**行业推荐分析方法选择**

| 应用场景 | 推荐方法 |
|---|---|
| 批次放行定量分析 | **2-AB（或 2-AA）UPLC**（游离糖水平，FLD 检测） |
| 位点特异性表征（ICH Q6B 要求） | **LC-MS/MS 糖肽分析** |
| 快速克隆筛选 / 工艺开发中间体 | **完整质量（Intact MS）或 MS-based 快速方法** |
| 生物类似药可比性研究 | **2-AB UPLC + LC-MS/MS 糖肽**（双方法互为佐证） |

:::
