## 大小异质性分析：SEC-HPLC 与 SEC-UPLC 的原理、对比与应用场景

:::answer

### 方法原理

分子排阻色谱（Size Exclusion Chromatography, SEC）基于**流体动力学体积**分离蛋白质：大分子在多孔填料孔隙中的通道有限，洗脱较快；小分子能进入更多孔隙，洗脱较慢。因此 SEC 谱图从左至右依次为**高分子量物质（HMWS，聚集体）→ 单体（主峰）→ 低分子量物质（LMWS，片段）**。

SEC 是研究、开发和生产生物治疗性蛋白过程中分析聚集体的**行业标准方法**，也是原液和成品放行检测的必检项目。

### SEC-HPLC 与 SEC-UPLC 对比

| 维度 | SEC-HPLC（传统） | SEC-UPLC（超高效） |
|------|-----------------|------------------|
| 分析时间 | 20～30 min/样品 | **< 5 min/样品** |
| 分辨率 | 标准 | 更高（小粒径填料，< 2 μm） |
| 样品用量 | 较多 | 更少 |
| 溶剂消耗 | 较多 | 显著减少 |
| 与 HPLC 可比性 | — | 聚集体结果高度可比 |
| 适用场景 | 常规放行检测 | 高通量工艺开发、克隆筛选 |

### 关键注意事项

- **流动相选择：** 通常使用含 NaCl 或 Na₂SO₄ 的磷酸盐缓冲液（PBS），高盐有助于抑制蛋白与填料的非特异性相互作用，防止部分聚集体因吸附导致假阴性。
- **SEC 对可溶性寡聚体的局限性：** SEC 无法区分可逆聚集体（稀释后可解离）和不可逆聚集体，须结合 AUC（分析超速离心）进行辅助判断。
- **可见颗粒与亚可见颗粒：** SEC 仅能检测可溶性聚集体（通常 < 100 nm），对亚可见颗粒（≥ 2 μm）须配合 MFI（微流成像）或 LO（光阻法）检测。

## 糖型异质性分析：糖基化类型、分析方法与生物学意义

:::answer

### 糖基化的基本概念

糖基化（Glycosylation）是最广泛、最重要的蛋白质翻译后修饰之一，由**糖基转移酶催化**，将特定的糖分子转移至蛋白质氨基酸残基上形成糖苷键。人体正常运转依赖约 10⁶ 个糖蛋白分子的作用。

### 抗体糖基化的主要类型

| 糖基化类型 | 修饰位点 | 连接方式 | 在抗体中的主要位置 |
|-----------|---------|---------|-----------------|
| **N-糖基化** | 天冬酰胺（Asn-X-Ser/Thr 序列） | N-糖苷键 | Fc 区 Asn297（最关键）；部分 Fab 区 |
| **O-糖基化** | 丝氨酸（Ser）或苏氨酸（Thr） | O-糖苷键 | 铰链区（Hinge）；较少见 |

### N-糖结构的四个关键修饰维度

```
核心岩藻糖（Fucose）
  └── 影响 FcγRIIIa 结合 → ADCC 效应
      岩藻糖缺失 → ADCC 增强（约 10 倍）

半乳糖（Galactose）
  └── 影响 CDC 效应（C1q 结合）和炎症反应

甘露糖（Mannose）
  └── 影响 FcγR 结合；高甘露糖型加速清除（影响 PK）

唾液酸（Sialic Acid）
  └── 增加分子负电荷；延长半衰期；可能影响 ADCP 和抗炎活性
```

### 主要分析方法

| 方法 | 分析维度 | 特点 |
|------|---------|------|
| **HILIC-UPLC-FLD** | 释放 N-糖谱图（糖型分布） | 高通量，荧光标记（2-AB 或 RapiFluor-MS）后定量 |
| **LC-MS/MS（糖肽分析）** | 糖基化位点 + 糖型 | 精确定位位点占用率，区分不同位点糖型 |
| **CE（毛细管电泳）** | 电荷相关糖型（如唾液酸） | 与 CEX 电荷谱联动分析 |
| **Lectin Blot** | 特定糖结构定性 | 快速筛选，定量精度较低 |

### 判断蛋白是否糖基化的直接方法

- **酶法去糖基化（PNGase F 处理）：** PNGase F 可切除全部 N-糖，处理前后分子量差异（SDS-PAGE 或 LC-MS）即为糖基化的直接证据。
- **分子量变化计算：** IgG1 的 Fc N-糖通常贡献约 2～3 kDa 的分子量，去糖基化后重链分子量显著下移。

:::

## 电荷异质性分析：主要来源、分析技术与 CQA 关联

:::answer

### 电荷异质性的生物学意义

单抗的电荷异质性是多种翻译后修饰（PTM）共同作用的结果，其中部分电荷变体对**稳定性和生物学功能**具有重要影响，因此被列为关键质量属性（CQA）。电荷异质性谱图的批间一致性同时也是生产工艺稳定性的直接体现。

### 电荷变体的来源分类

| 变体类型 | 主要来源修饰 |
|---------|------------|
| **碱性变体（Basic Peaks）** | C 端赖氨酸未切除（+1 正电荷）；N 端焦谷氨酸化（电荷丢失较少）；脯氨酸酰胺化 |
| **酸性变体（Acidic Peaks）** | 天冬酰胺脱酰胺化（Asn → Asp，引入负电荷）；唾液酸修饰；赖氨酸糖化（正电荷被中和）；二硫键错配；三硫键 |

### 主要分析方法

| 方法 | 原理 | 特点 |
|------|------|------|
| **icIEF（成像毛细管等电聚焦电泳）** | 按 pI 聚焦分离 | **行业主流**；快速、高分辨；可同时测定 pI |
| **CEX-HPLC（阳离子交换色谱）** | 按表面电荷结合强度分离 | 样品量较大，便于收集各峰组分进行深入表征 |
| **CZE（毛细管区带电泳）** | 在均匀电场中按电荷/大小比分离 | 高分辨；适合复杂电荷变体谱 |

### 案例：Ustekinumab 电荷异质性解析

以 Ustekinumab（SP2/0 细胞表达）为例，通过逐步酶切法鉴定电荷变体来源：

```
原始 icIEF 谱图
  │
  ├─ 羧肽酶 B 处理（切除 C 端 Lys）
  │     → 碱性峰消失，证实碱性峰来自 C 端 Lys 不均一性
  │     → 主峰前仍有 2 个显著酸性峰
  │
  └─ 继续用神经氨酸酶（Neuraminidase）处理（切除唾液酸）
        → 图谱基本只剩 1 个主峰
        → 证实酸性峰主要由 C 端 Lys 不均一性 + 唾液酸修饰共同引起
```

> **方法论启示：** 电荷变体鉴定应遵循"逐步酶切 + 逐步归因"的策略，结合质谱肽图进行精确位点定位。

:::

## 唾液酸的结构、分类与抗体质量属性关联

:::answer

### 基本结构

唾液酸（Sialic Acid, SA）是一类**9 碳氨基糖酸**的统称，系统命名为 5-氨基-3,5-二脱氧-D-甘油-D-半乳壬酮糖，具有吡喃糖构型。其广泛分布于动物细胞膜糖蛋白、糖脂及分泌液中，参与细胞识别、信号传导和免疫调节等多种生物学过程。

### 主要唾液酸种类

| 种类 | 缩写 | 结构特征 | 在抗体中的意义 |
|------|------|---------|--------------|
| **N-乙酰神经氨酸** | Neu5Ac（NANA） | 5 号碳连接乙酰氨基 | 人源抗体主要唾液酸形式；影响电荷分布和 PK |
| **N-羟乙酰神经氨酸** | Neu5Gc（NGNA） | 5 号碳乙酰基发生羟基化 | **免疫原性风险！** 人体缺乏合成 Neu5Gc 的酶（CMAH 基因失活），但 CHO 细胞可产生少量 Neu5Gc，须监控 |
| **3-脱氧-D-甘油-D-半乳壬酮糖** | KDN | 5 号碳无氨基 | 较少见于哺乳动物抗体 |

### 唾液酸对抗体质量属性的影响

| 影响维度 | 机制 | 重要性 |
|---------|------|--------|
| **电荷异质性** | 唾液酸含羧基（pKa ≈ 2.6），引入负电荷，使抗体向酸性方向偏移 | 高（直接影响 icIEF/CEX 谱图） |
| **药代动力学（PK）** | 唾液酸末端修饰延缓 Asialoglycoprotein Receptor（ASGPR）介导的肝脏清除，延长血清半衰期 | 中～高（对 Fc 融合蛋白影响更显著） |
| **免疫调节活性** | 高唾液酸化 IgG Fc 具有抗炎活性（通过 DC-SIGN 受体），与低唾液酸化 IgG 的促炎效应形成对比 | 高（对 IVIG 类产品尤为重要） |
| **免疫原性（Neu5Gc）** | Neu5Gc 在人体内可触发免疫反应，形成抗 Neu5Gc 抗体，须通过细胞系选择和工艺控制将其降至最低 | 高（安全性关键） |

### 唾液酸分析方法

- **荧光标记 HPLC：** DMB（1,2-diamino-4,5-methylenedioxybenzene）衍生后 HPLC 定量，可区分 Neu5Ac 与 Neu5Gc。
- **LC-MS：** 精确定量各种唾液酸的绝对含量及在糖链末端的占比。

:::

## 蛋白糖化（非酶糖化）的定义、化学机制与产物特征

:::answer

### 概念辨析：糖基化 vs. 糖化

| 维度 | 糖基化（Glycosylation） | 糖化（Glycation） |
|------|----------------------|-----------------|
| 反应类型 | **酶促反应**（糖基转移酶催化） | **非酶促反应**（美拉德反应） |
| 发生位置 | 内质网/高尔基体 | 胞外培养液中；储存阶段 |
| 修饰位点 | Asn（N-糖）；Ser/Thr（O-糖） | 赖氨酸（Lys）ε-氨基；N 端 α-氨基 |
| 参与糖类 | 核苷糖（UDP-Glc 等活化供体） | 还原性单糖（葡萄糖、果糖、半乳糖等） |
| 可控性 | 通过工艺参数可调控 | 需通过糖浓度和 pH 控制 |

### 糖化的化学反应机制（美拉德反应路径）

```
还原糖（葡萄糖等）+ 蛋白质伯胺（Lys 侧链/N 端）
          │
          ▼  [席夫碱形成，可逆]
     醛亚胺（Schiff Base）
          │
          ▼  [Amadori 重排，相对稳定]
     Amadori 产物（酮胺加合物）
          │ 压力条件（高温、氧化环境）
          ▼
   活性羰基/二羰基中间体
          │
          ▼  [不可逆反应]
  高级糖化终末产物（AGEs, Advanced Glycation End-products）
```

**关键特征：**
- **席夫碱阶段**：可逆，去除葡萄糖后可逆转（去糖化）。
- **Amadori 产物阶段**：相对稳定但理论上仍可逆。
- **AGEs 阶段**：**不可逆**，引发蛋白质颜色变黄褐色（吸收可见光）、交联和功能改变。

:::

## 影响蛋白糖化程度的关键因素：还原糖浓度、pH 与温度

:::answer

### 主控因素：还原糖浓度

还原糖浓度是驱动糖化反应速率和程度的**最主要因素**，呈浓度依赖性：

| 葡萄糖浓度 | 糖化行为 |
|-----------|---------|
| **< 6 mM** | 糖化反应速率极低，通常不显著 |
| **≥ 6 mM** | 糖化开始显现，且浓度越高，糖化速率越快、程度越高 |
| **达到平衡后** | 在恒定葡萄糖浓度下，糖化达到动态平衡后趋于稳定 |
| **极低或无葡萄糖** | 呈现去糖化趋势（席夫碱可逆解离） |

### 次要影响因素

| 因素 | 影响规律 | 工艺意义 |
|------|---------|---------|
| **pH** | 较高 pH 下氨基去质子化程度更高（游离胺比例增加），糖化速率升高 | 发酵 pH 控制策略须兼顾糖化风险 |
| **温度** | 温度越高，反应活化能降低，糖化速率加快 | 储存温度对冻干和液体制剂均有显著影响 |
| **缓冲盐种类** | 不同缓冲液中糖化速率差异显著（见下表） | 制剂配方优化须考量缓冲盐的催化效应 |

### 不同缓冲盐对糖化速率的影响

| 缓冲液类型 | 相对糖化速率 |
|-----------|------------|
| HEPES | 低 |
| 柠檬酸盐 | 低 |
| 磷酸盐 | **明显升高** |
| 碳酸盐 | **最高** |

> **实践建议：** 对于糖化敏感的单抗，制剂配方应优先选择柠檬酸盐或组氨酸缓冲体系，避免磷酸盐或碳酸盐缓冲液。

:::

## 单抗生产全周期中糖化的形成与控制节点

:::answer

### 糖化发生的两个阶段

**阶段一：发酵培养阶段**

由于葡萄糖是 CHO 细胞培养最核心的碳源和能源，培养液中始终存在较高浓度的还原性葡萄糖（通常 > 6 mM），糖化难以完全避免，但可通过以下工艺参数加以控制：

| 工艺参数 | 对糖化的影响 | 调控建议 |
|---------|------------|---------|
| 培养基葡萄糖浓度 | 浓度越高，糖化越严重 | 按需补料，避免葡萄糖过度积累 |
| 培养液 pH | pH 升高，糖化加速 | 维持 pH 在目标范围下限 |
| 培养温度 | 温度越高，糖化越快 | 合理设计温度转变策略 |
| 培养时间 | 时间越长，糖化累积越多 | 在产量达标时尽早收获 |

**阶段二：原液/制剂储存阶段**

即使在生产完成后的储存阶段，若制剂配方中存在还原性糖，糖化仍会持续发生：

- 制剂中直接使用葡萄糖（罕见）→ 高风险。
- **蔗糖在酸性条件或高温下水解为葡萄糖 + 果糖** → 常见风险来源，须在稳定性研究中监控。
- 冻干剂型中同样会发生糖化，且**较高储存温度（如 25℃）**对冻干和液体两种剂型均会加剧糖化。

### 糖化控制的全链路策略

```
发酵阶段
  ├── 控制葡萄糖浓度（按需补料策略）
  ├── 优化 pH 和温度窗口
  └── 建立糖化动力学模型，预测并控制糖化水平

纯化阶段
  └── CEX/AEX 步骤适当去除酸性组分（糖化单抗主要富集于酸性峰）

制剂阶段
  ├── 避免使用葡萄糖等还原性糖作为赋形剂
  ├── 评估蔗糖水解风险，选择适宜 pH（蔗糖在 pH > 5 时相对稳定）
  └── 选择低糖化催化活性的缓冲盐（如 His、柠檬酸盐）

分子设计阶段（如适用）
  └── 将高糖化风险位点的 Lys 突变为 Arg（保留正电荷，消除糖化位点）
```

:::

## 糖化对单抗异质性、聚集与颜色的影响

:::answer

### 对电荷异质性的影响

糖化修饰会**直接改变单抗的电荷分布**：赖氨酸的 ε-氨基（pKa ≈ 10.5，正常带正电荷）与还原糖共价结合后，正电荷被中和丧失，导致：
- 修饰位点上**净正电荷减少** → 分子整体向酸性方向偏移。
- icIEF/CEX 图谱中酸性峰面积增加，主峰比例下降。
- **澄清收获液放置期间酸性变体比例持续增加**，对批间一致性造成挑战。

### 对聚集体的影响

- Amadori 产物和 AGEs 可引发蛋白质**交联**，形成共价连接的聚集体。
- 糖化改变蛋白质局部构象，可能暴露疏水性区域，促进非共价聚集。
- 糖化诱导的聚集体在常规 SEC 检测中表现为 HMWS 峰增加，影响批间一致性。

### 对溶液颜色的影响

CHO 细胞表达的单抗制品通常呈现**轻微黄棕色**，AGEs 是重要的颜色贡献因子之一（AGEs 含有发色团，吸收蓝绿光，呈现黄棕色），与氧化反应共同导致原液颜色加深：
- 颜色深浅可作为糖化（及氧化）程度的**间接指示指标**。
- 制品颜色须符合药典标准（EP 黄色系列，通常不深于 Y5 或 BY5）。

### 对 CDR 区活性的影响

- 若糖化位点位于 CDR 区（赖氨酸残基），可能**直接阻碍抗原-抗体相互作用**，降低结合亲和力和中和活性。
- 不同抗体分子的影响差异显著，须在研发阶段进行专项评估。

:::

## 糖化对单抗生物学活性的影响及 CQA 评估策略

:::answer

### 糖化影响活性的决定因素

糖化对单抗活性的影响**高度依赖于糖化位点的数量与空间位置**，而非糖化程度本身：

| 糖化位点位置 | 对活性的潜在影响 |
|------------|---------------|
| **CDR 区（互补决定区）** | 风险最高；可直接阻断抗原结合；可能使活性完全消失 |
| **框架区（FR）** | 风险中等；可能通过构象改变间接影响 CDR 活性 |
| **Fc 区** | 风险较低；主要影响 FcγR 结合（ADCC/CDC），通常不影响抗原结合 |
| **铰链区** | 风险低；主要影响结构柔性 |

### 评估框架

```
分子表征阶段
  ├── 质谱肽图定位糖化位点（重点关注 CDR 区 Lys）
  └── 强制糖化样品制备（高葡萄糖培养 / 体外糖化反应）

活性评估阶段
  ├── 抗原结合亲和力（SPR 或 ELISA）比较正常 vs. 高糖化样品
  ├── 细胞活性（ADCC、CDC、中和活性）评估
  └── 建立糖化程度-活性的量效关系

CQA 判定
  ├── 若 CDR 区存在糖化位点 且 糖化程度-活性相关性显著 → 评定为 CQA
  └── 若糖化对活性无显著影响 → 可评定为非 CQA，但仍需监控批间一致性
```

### CQA 确定后的控制策略

- **严格控制：** 建立糖化比例的放行标准（通常以 CEX 酸性峰或专项糖化分析方法监控）。
- **工艺验证覆盖：** 在 PV 批次中确认糖化比例的批间一致性。
- **商业化生产持续监控：** 将糖化纳入过程控制（IPQC）和趋势分析，及时识别工艺漂移。

:::

## 蛋白聚集体的形成机制：成核与聚体生长的两阶段模型

:::answer

### 聚集的本质

蛋白质聚集是**分子内（构象变化）与分子间（相互作用）**双重因素共同驱动的动态过程，经历从可溶性寡聚体→较大多聚体→不溶性颗粒的连续演化。

### 两阶段聚集模型

**第一阶段：初始成核（Nucleation）**

蛋白质存在固有的构象不稳定性或扭曲，在应激条件下：

1. 局部构象变化暴露**聚集倾向性"热点序列"**（Aggregation-prone Regions, APRs）——通常为疏水性连续片段，常见于 Fab 结构域的 CDR 区附近。
2. 暴露的热点序列与其他单体的相应区域发生相互作用，形成**二聚体或寡聚体（成核种子）**。
3. 成核是整个聚集过程的**速率决定步骤**，成核能垒越高，聚集越难被触发。

**蛋白间相互作用的类型：**

| 相互作用类型 | 特征 | 对聚集的贡献 |
|------------|------|------------|
| **疏水相互作用** | 最主要驱动力；温度依赖 | 高（APR 序列暴露后） |
| **静电相互作用** | 可以促进（同种电荷排斥）或抑制聚集 | 双向（取决于条件） |
| **氢键** | 增强β-折叠间相互作用（淀粉样聚集） | 中 |
| **共价键（链间二硫键）** | 不可逆聚集 | 形成后极难去除 |
| **范德华力** | 近距离相互作用 | 低（辅助） |

**第二阶段：聚体生长（Growth）**

成核种子形成后，通过以下机制持续增大：

- **单体加成：** 可溶性单体不断加入到成核种子末端。
- **链式聚集：** 多个寡聚体端对端连接，形成链状结构。
- **聚体-聚体合并：** 两个较小聚体合并为更大聚体。
- **凝聚（Coalescence）：** 疏水驱动的颗粒融合。

随着时间推移，聚体数目呈**指数增长**，最终形成不溶性颗粒（形态多样，取决于疏水/芳香族氨基酸比例和聚集阶段）。值得注意的是，不溶性颗粒随时间推移可**部分解离**为可溶性聚集体，形成动态平衡。

:::

## 影响蛋白聚集体形成的多维因素分析

:::answer

### 因素分类框架

蛋白聚集的驱动因素可从**分子内在特性**和**外部环境条件**两个维度分类：

**维度一：蛋白质内在特性**

| 因素 | 影响机制 |
|------|---------|
| **一级结构（氨基酸序列）** | APR 序列的数量和位置；CDR 序列的疏水性 |
| **二/三级结构稳定性（Tm、Tagg）** | 热力学稳定性低 → 更易局部展开 → 暴露 APR |
| **分子电荷分布（pI）** | 在 pI 附近净电荷为零，静电排斥最小，聚集倾向最强 |
| **翻译后修饰** | 糖基化可"屏蔽"疏水区域（保护作用）；氧化/脱酰胺可改变局部构象 |

**维度二：外部环境条件**

| 环境因素 | 对聚集的影响 | 调控建议 |
|---------|------------|---------|
| **蛋白浓度** | 浓度增加→分子间距缩小→相互作用增强（浓度依赖性） | 高浓度制品须强化制剂保护 |
| **pH** | 接近 pI 时聚集风险最高；极端 pH 引起构象变化 | 避开 pI ± 1 范围；优化制剂 pH |
| **温度** | 高温加速局部展开；冻融循环引起浓缩效应 | 控制冻融循环次数；选择适宜冷冻保护剂 |
| **盐浓度/种类** | Hofmeister 效应；高盐可屏蔽静电排斥 | 优化离子强度；避免促盐析离子 |
| **机械应力（搅拌、振荡）** | 剪切力引起局部展开；气液界面诱导聚集 | 添加 Polysorbate 20/80 保护气液界面 |
| **光照/氧化环境** | Met/Trp 氧化→构象变化→聚集 | 避光保存；添加抗氧化剂 |
| **冷冻干燥** | 冰晶形成的固液界面应力；浓度效应 | 优化冻干保护剂（蔗糖、海藻糖） |

:::

## 细胞培养参数对蛋白聚集体形成的影响与调控机制

:::answer

### 上游工艺对聚集体的调控全景

| 培养参数 | 对聚集体的影响方向 | 作用机制 |
|---------|----------------|---------|
| **培养温度** | 降温 → 聚集体**升高** | 低温增加 LC/HC mRNA 稳定性，促进轻链/重链过量表达，但内质网（ER）加工折叠能力受限，未正确折叠的蛋白聚集增加 |
| **搅拌转速** | 转速升高 → 聚集体**升高** | 高转速产生更大剪切力，影响细胞翻译后修饰加工（如二硫键形成），导致错折叠蛋白增多 |
| **消泡剂（Pluronic F-68）** | 添加消泡剂 → 聚集体**降低** | 消泡剂保护细胞免受气泡和搅拌引起的剪切力损伤，有利于蛋白翻译后修饰的正确加工 |
| **渗透压** | 适当提高渗透压 → 聚集体**降低** | 渗透压影响蛋白折叠的细胞内环境；高渗透压条件下分泌蛋白的折叠质控更严格 |
| **pH** | pH 升高 → 聚集体**降低** | 较高 pH 增加蛋白静电排斥力（电荷效应），同时可能影响高尔基体内糖基化加工 |
| **培养时间** | 培养时间越长 → 聚集体**升高** | 长期培养积累更多降解和氧化产物，且细胞活力下降释放胞内酶，催化聚集 |
| **氧化还原物质** | 谷胱甘肽/半胱氨酸/胱氨酸/硫酸铜优化 → 聚集体**降低** | 维持培养液中适宜的氧化还原电位，促进正确二硫键形成，减少错配二硫键引起的聚集 |

### 综合调控策略建议

- **温度转变（Temperature Shift）：** 权衡降温带来的聚集体增加与产量/其他质量属性的改善，须通过 DOE 找到最优降温时机和目标温度。
- **搅拌/通气优化：** 在满足混合和溶氧需求的前提下，尽量降低搅拌转速并配合消泡剂使用。
- **氧化还原平衡：** 在培养基中添加半胱氨酸/胱氨酸对，维持胞外适宜的硫醇/二硫化物比例，促进 ER 中正确折叠。

:::

## 关键质量属性（CQA）的定义、评估框架与放行标准关系

:::answer

### CQA 定义（ICH Q8(R2)）

> **关键质量属性（CQA）**：是一个物理、化学、生物学或微生物学性质或特征，应具备适当的限度、范围或分布，以确保目标产品质量。可与药用物质、药品、辅料、中间产品及容器/密闭构件相关联。

CQA 是产品符合预期用途（安全性、有效性、稳定性）的**核心质量保障基础**。

### CQA 评估的目的与价值

- **指导工艺开发：** 明确哪些质量属性需要通过工艺参数重点控制。
- **建立控制策略：** 确定 CPP（关键工艺参数）与 CQA 的因果关系，形成工艺控制策略。
- **支持法规申报：** 系统、科学的 CQA 评估是 QbD 申报的核心组成部分。
- **持续工艺保证：** 明确商业化生产中须持续监控的项目，保持工艺稳健性。

### CQA 评估方法论

**常用评估工具：**

| 工具 | 用途 |
|------|------|
| **鱼骨图（Ishikawa）** | 识别影响某 QA 的所有潜在工艺因素 |
| **风险矩阵（Risk Matrix）** | 按"对患者安全性/有效性的影响程度"排序，识别关键属性 |
| **FMEA（失效模式影响分析）** | 定量评估各质量属性异常的风险等级（严重性 × 发生频率 × 可检测性） |
| **文献/平台知识** | 借鉴已上市同类产品的 CQA 清单作为参考基准 |

**评估维度：**
1. 该质量属性对**安全性**（免疫原性、毒性）的影响
2. 该质量属性对**有效性**（作用机制、PK/PD）的影响
3. **工艺可控性**：现有工艺对该属性的控制能力
4. **分析方法可及性**：是否有可靠的检测方法

### CQA 与辅料的关联

辅料 CQA 的判定受多重因素影响（API 特性、处方组成、生产工艺等），某种辅料属性对特定药物可能是关键的，对另一种药物则可能不关键。辅料 CQA 若在研发早期未被充分识别，可能在放大生产或临床阶段才暴露问题，造成不可逆的损失。

:::

---

## CQA 与放行质量标准的关系：不等同原则与检测前移策略

:::answer

### 核心原则：CQA ≠ 放行标准项目（一一对应）

PDA 第 60 号技术报告明确指出：**关键质量属性不等同于质量标准，二者不需要一一对应**。

| 情形 | 处理方式 |
|------|---------|
| **CQA 可由工艺良好控制（工艺保证型）** | 可不纳入逐批放行检验（如病毒清除），仅需定期验证或工艺监控 |
| **CQA 需逐批监控** | 须纳入放行标准，建立可接受准则 |
| **非 CQA，但与产品特性相关** | 可纳入标准作为一般质量控制项目（如外观、渗透压） |
| **方法不成熟或技术限制** | 可暂以工艺控制替代，待方法建立后补充到标准 |

### 质量标准的构成

质量标准是**一系列检验列表**，包含：
- 分析规程（方法）
- 可接受标准（数值限度、范围或其他要求）

一个 CQA 可由单项检验评价（如用溶出度评价活性成分溶解度），也可由多项检验综合评价。

### 检测点前移策略

在某些情况下，放行检测点可从成品向上游工序前移：

| 典型场景 | 前移原因 | 前移至 |
|---------|---------|-------|
| 含佐剂疫苗的 DNA、HCP 检测 | 佐剂对检测方法产生严重干扰 | 吸附工艺前的原液阶段 |
| 病毒安全性 | 逐批检测成本高；工艺清除效果稳定 | 工艺验证 + 定期再验证 |
| 某些糖型指标 | 制剂阶段处理可能影响检测 | 原液阶段 |

### 动态更新原则

CQA 的确定是**始于研发早期、贯穿全生命周期的持续性活动**，须随产品和工艺知识的积累不断更新，在上市后变更、适应症扩展或工艺改进时重新评估。

:::

## 上游质量调控：N-糖型的形成规律与工艺参数影响

:::answer

### N-糖形成的细胞生物学基础

抗体 N-糖的组装发生在**内质网（ER）和高尔基体**中，由一系列糖基转移酶和糖苷酶按顺序催化。高尔基体的腔内 pH（通常 pH 5.5～6.5）对这些酶的活性有直接影响，而细胞外培养液 pH 可间接调节胞内高尔基体 pH，从而影响糖型分布。

### 主要工艺参数对四种关键糖修饰的影响

**① 岩藻糖（Fucosylation）**

| 调控手段 | 效果 |
|---------|------|
| 添加 2-氟岩藻糖（2-FF） | 竞争性抑制岩藻糖转移酶，显著降低岩藻糖化比例 |
| 锰离子（Mn²⁺）添加 | 降低岩藻糖化，机制涉及高尔基体转运改变 |
| 基因敲除（FUT8⁻/⁻） | 完全去岩藻糖化，ADCC 效应增强 10 倍以上 |

**② 半乳糖（Galactosylation）**

| 工艺参数 | 影响 | 机制 |
|---------|------|------|
| pH（6.8～7.2） | 部分研究：pH 升高→半乳糖化降低；另有研究：G1F+G2F 随 pH（6.9～7.1）升高而增加 | 高尔基体 pH 影响半乳糖转移酶活性 |
| 溶氧（DO） | 低 DO → 半乳糖化降低 | UDP-Gal（半乳糖供体）在低溶氧下减少；低溶氧影响二硫键形成，产生空间位阻 |
| 培养温度 | 低温 → 半乳糖化降低 | 低温减少细胞内核苷糖供体浓度 |
| 半乳糖/尿苷补料 | 补充 UDP-Gal 前体 → 半乳糖化升高 | 直接提供底物 |

**③ 甘露糖（Mannosylation）**

- 高甘露糖型（High Mannose, HM）比例升高通常与细胞内高尔基体加工受限有关（内质网滞留）。
- **低温培养**、高蛋白表达量、培养末期细胞活力下降均可导致高甘露糖比例升高。
- 高甘露糖型可被血清甘露糖受体识别，加速清除，影响 PK。

**④ 唾液酸（Sialylation）**

| 工艺参数 | 影响 |
|---------|------|
| 低温（降温策略） | 部分研究：低温升高唾液酸；另有研究：低温降低唾液酸（结果因细胞系和条件而异） |
| 渗透压升高 | 通常升高唾液酸水平 |
| 谷氨酰胺浓度 | 影响 CMP-唾液酸（供体）合成 |
| 铜离子（Cu²⁺） | 影响唾液酸转移酶活性 |

:::

## 上游质量调控：聚集体的工艺控制策略

:::answer

### 控制策略的双重维度

聚集体的上游控制须从**预防形成**和**促进去除**两个方向入手：

### 预防聚集体形成的工艺手段

| 手段 | 操作方式 | 原理 |
|------|---------|------|
| **温度优化** | 避免过度低温培养（若低温导致聚集体升高，须权衡温度转变时机和幅度） | 平衡 mRNA 稳定性与 ER 折叠加工能力 |
| **pH 优化** | 适当升高 pH（依产品特性而定） | 增加蛋白静电排斥，同时促进高尔基体糖基化加工 |
| **渗透压优化** | 适当提高渗透压（加入 NaCl 等） | 改善蛋白折叠细胞内环境，降低聚集倾向 |
| **氧化还原优化** | 添加谷胱甘肽、半胱氨酸、胱氨酸或硫酸铜 | 维持培养液适宜氧化还原电位，促进正确二硫键形成 |
| **培养时间控制** | 在产量达标时及时收获，不过度延长培养周期 | 减少氧化、降解和死细胞释放胞内蛋白的累积 |
| **消泡剂（Pluronic F-68）** | 添加至 0.01%～0.1% | 保护细胞和蛋白免受气液界面剪切力损伤 |
| **蛋氨酸保护** | 低温储存；添加抗氧化剂（如 N-乙酰半胱氨酸） | 防止 Met 氧化诱发的构象变化和聚集 |

### 聚集体已形成后的纯化去除

| 纯化步骤 | 去除聚集体的能力 | 备注 |
|---------|---------------|------|
| **CEX（阳离子交换）** | 高（> 90%去除率） | 聚集体等电点通常与单体不同，可分离 |
| **Protein A（亲和层析）** | 中（非特异去除，随洗涤条件变化） | 主要去除大聚集体和 HMW 片段 |
| **AEX（流穿模式）** | 中（带正电荷单体流穿，聚集体可能结合） | 依聚集体电荷状态 |
| **HIC（疏水相互作用）** | 高（聚集体疏水性强，结合更紧密） | 适用于疏水性较低的目标蛋白 |

:::

## 上游质量调控：电荷变体的工艺调控策略

:::answer

### 电荷变体的可控性特点

许多电荷变异修饰以**分子依赖的方式**在细胞外发生，预测和控制难度较大；因此，培养工艺参数和培养基组成是调节电荷异质性的最常用手段。

### 工艺参数对电荷变体的影响

| 工艺参数 | 主要影响的变体类型 | 影响规律 |
|---------|----------------|---------|
| **pH** | 酸性变体（脱酰胺） | pH 升高→脱酰胺速率加快→酸性变体增加（关键参数） |
| **温度** | 酸性变体（赖氨酸相关） | 降温→抑制羧肽酶 B 转录→赖氨酸变异体增加→酸性物质减少 |
| **溶氧（DO）** | 碱性变体 | 影响氧化修饰，间接影响电荷分布 |
| **接种密度** | 综合影响 | 高接种密度影响细胞代谢，可改变电荷变体谱 |

### 培养基成分对电荷变体的影响

| 培养基成分 | 对电荷变体的影响 |
|-----------|---------------|
| **铜离子（Cu²⁺）浓度升高** | C 末端赖氨酸变异体增加（碱性峰升高） |
| **锌离子（Zn²⁺）浓度降低** | C 末端赖氨酸变异体增加 |
| **丁酸钠（NaB）** | 提高表达量的同时显著增加碱性变体 |
| **丙三醇、NaCl、金属离子** | 抗体脱酰胺增加（酸性变体增多） |
| **生物类黄酮（Bioflavonoids）** | 减少酸性变体 |
| **硫代硫酸盐（Thiosulfate）** | 与抗体反应形成酸性加合物（酸性变体增加）|

### 分子设计层面的电荷调控

- **基因组学手段：** 调节唾液酸转移酶或羧肽酶活性（如通过基因沉默），直接控制特定翻译后修饰。
- **赖氨酸 → 精氨酸突变：** 去除高糖化/脱酰胺风险位点，稳定电荷分布，同时通常不影响活性。
- **带负电荷残基引入（提高 pI 稳定性）：** 增强蛋白间静电排斥，抑制聚集，间接改善电荷均一性。

:::

## 单抗电荷异质性的形成机制、临床相关性与控制优先级

:::answer

### 电荷异质性的本质

重组抗体的电荷异质性来源于**几乎所有翻译后修饰**——无论是直接改变表面带电基团（如脱酰胺引入负电荷），还是间接通过构象改变影响带电残基的暴露程度（如聚集、糖基化改变）。

```
翻译后修饰 → 表面电荷改变
  │
  ├── 直接途径：增减带电基团（脱酰胺、糖化、唾液酸、氧化等）
  └── 间接途径：构象改变 → 带电残基暴露状态改变（折叠/聚集）
```

### 酸性变体 vs. 碱性变体的临床相关性

**酸性变体对药效的影响通常更为显著：**

- 典型案例：曲妥珠单抗（Trastuzumab）的酸性电荷异质体显示出对 HER2 亲和力明显下降，抗增殖作用减弱。
- 机制：CDR 区的脱酰胺（酸性变体的主要来源之一）直接干扰抗原-抗体接触界面，降低结合能。

> **结论：** 在抗体药物开发中，**降低酸性电荷异质体的比例通常优先于碱性变体的控制**。

### 酸性与碱性变体形成原因汇总

| 变体类型 | 主要形成原因 | 是否可逆 |
|---------|------------|---------|
| **碱性变体** | C 末端赖氨酸未切除（+Lys） | 工艺控制可调节 |
| | N 端焦谷氨酸化（pyroGlu，电荷略降） | 通常稳定 |
| | 天冬氨酸异构化（Asp → isoAsp） | 不可逆 |
| | 脯氨酸酰胺化 | 不可逆 |
| **酸性变体** | 天冬酰胺脱酰胺化（Asn → Asp，引入—COOH） | 不可逆 |
| | 赖氨酸糖化（正电荷中和） | 席夫碱阶段可逆；Amadori 后不可逆 |
| | 二硫键错配（暴露额外—SH 或改变构象） | 不可逆 |
| | 三硫键形成 | 不可逆 |
| | 唾液酸修饰（引入—COOH） | 稳定 |

### 电荷变体分析与表征的完整工作流

```
Step 1：icIEF 或 CEX 图谱获取（建立基线，判断峰比例）
    ↓
Step 2：逐步酶切（羧肽酶 B、神经氨酸酶等）归因各峰组成
    ↓
Step 3：制备型 CEX 收集各峰组分
    ↓
Step 4：各峰组分质谱肽图分析（精确定位修饰类型和位点）
    ↓
Step 5：各峰组分活性评估（结合亲和力、效应功能）
    ↓
Step 6：基于以上数据，判定各变体是否为 CQA，制定控制策略
```

:::
