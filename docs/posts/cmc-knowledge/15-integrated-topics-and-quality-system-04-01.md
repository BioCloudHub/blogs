## 设备使用维护管理规范："三好四会"原则

:::answer

"三好四会"是 GMP 体系中对设备操作人员能力和责任的基础性要求，是确保设备持续处于良好使用状态、防止因设备问题影响产品质量的管理基础。

**"三好"：设备管理的三项核心职责**

| 职责     | 内容                                               | GMP 实践含义                                                 |
| -------- | -------------------------------------------------- | ------------------------------------------------------------ |
| **管好** | 负责任地保管和管理设备，防止损坏、丢失或私自挪用   | 设备须专人负责；设备状态标识（运行中/待清洁/停用）须清晰准确 |
| **用好** | 按规程正确操作设备，不超负荷、不违规使用           | 严格执行设备 SOP；操作记录完整、准确、及时填写               |
| **修好** | 发现设备问题及时报修，配合维修工作，保持设备完好率 | 设备缺陷须及时上报，不带病运行；维修记录完整                 |

**"四会"：设备操作人员的四项基本能力**

| 能力               | 具体内容                                                 | 验证方式         |
| ------------------ | -------------------------------------------------------- | ---------------- |
| **会使用**         | 熟悉设备的操作程序、工艺参数范围和紧急停机程序           | 上岗前培训考核   |
| **会保养**         | 掌握日常保养（清洁、润滑、紧固）的方法和周期要求         | 保养记录的完整性 |
| **会检查**         | 能进行操作前点检（外观、功能、安全装置）并识别异常       | 点检记录的规范性 |
| **会排除一般故障** | 能识别并处理简单故障（如卡料、参数偏移），区分哪些须报修 | 故障处理记录     |

**在 GMP 体系中的延伸意义**

"三好四会"不仅是操作规范，更是 GMP 人员培训体系的核心考核维度。新版 GMP 要求对所有操作设备的人员进行资质验证，培训记录须归档保存，设备变更后须重新培训和评估。

:::

## 计量工作与药品生产验证的法规要求

:::answer

计量工作是药品生产质量管理的基础性保障活动，直接影响生产过程的可控性和产品质量数据的可靠性。

**药品生产验证的法规覆盖范围**

根据 GMP 要求，药品生产验证应覆盖以下系统和活动：

| 验证类别             | 主要内容                                                       |
| -------------------- | -------------------------------------------------------------- |
| **空气净化系统验证** | 洁净区级别确认（IQ/OQ/PQ）；粒子数、微生物、换气次数、压差验证 |
| **工艺用水系统验证** | 纯化水/注射用水系统的设计确认、运行确认和性能确认              |
| **生产工艺验证**     | 关键工艺参数（CPP）的范围确认；工艺性能确认（PPQ）             |
| **工艺变更验证**     | 任何可能影响产品质量的工艺变更须经验证评估                     |
| **设备验证**         | 生产和检测设备的 IQ/OQ/PQ；设备清洗验证                        |
| **清洁方法验证**     | 清洁效果验证；最差条件设计；残留限度评估                       |
| **无菌/灭菌验证**    | 灭菌设备（高压蒸汽灭菌器）验证；药液过滤和灌封系统验证         |
| **原辅料变更验证**   | 主要原辅料变更对产品质量影响的可比性研究                       |

**计量工作的战略地位**

计量是验证工作的数据基础——如果使用的测量仪器未经校准或校准失效，所有验证数据的可靠性均受到根本性质疑。因此，计量管理须先于验证活动开展，并贯穿整个产品生命周期。

:::

## 事故处理的"三不放过"原则

:::answer

"三不放过"原则是 GMP 体系中处理生产质量事故的基本准则，旨在通过系统性的事故分析，确保同类问题不再复发。

**三不放过的具体内容**

| 原则                                 | 内容                                                                      | 实践含义                                                                            |
| ------------------------------------ | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **事故原因分析不清不放过**           | 必须追溯到问题的根本原因（Root Cause），不能停留于表面现象                | 采用鱼骨图、5-Why 分析、FMEA 等根本原因分析工具；需排除实验室错误后再确认系统性原因 |
| **事故责任者和群众未受到教育不放过** | 相关责任人须受到适当的纪律处分或教育，其他人员须了解事故经过以引以为戒    | 偏差报告需在相关团队中分享；培训记录需体现事故案例学习                              |
| **没有防范措施不放过**               | 必须制定并实施针对性的预防措施（Preventive Action），防止同类问题再次发生 | CAPA（纠正措施和预防措施）须经过有效性验证；定期跟踪措施落实情况                    |

**与 CAPA 体系的关联**

"三不放过"在实践中与现代 GMP 的 CAPA（Corrective Action and Preventive Action）体系高度契合：

- 原因分析 → CAPA 的调查阶段
- 教育责任者/群众 → CAPA 的沟通和培训要素
- 防范措施 → CAPA 的预防措施（PA），并须进行有效性验证

:::

## 企业内控标准高于法定标准的逻辑与法律地位

:::answer

**内控标准与法定标准的层级关系**

```
质量标准体系层级
国家法定标准（中国药典/注册标准）← 法律强制最低要求，仲裁依据
        ↑
企业内控标准（企业自行制定）← 高于法定标准，出厂放行依据
        ↑
工艺过程控制标准（IPC 标准）← 更严格的过程控制窗口
```

**内控标准高于法定标准的逻辑依据**

| 原因             | 说明                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------- |
| **质量安全余量** | 产品在流通和储存过程中可能发生降解，内控标准须留有足够余量，确保产品在有效期末仍符合法定标准 |
| **批间变异控制** | 内控标准更窄的范围有助于识别工艺漂移，提前预警，避免接近法定标准边界时的放行风险             |
| **质量持续改进** | 严于法定的内控标准是质量持续改进的驱动力，促使企业不断优化工艺                               |
| **仲裁风险规避** | 内控标准合格的产品，在法定仲裁时必然合格，降低法律风险                                       |

**法律地位的明确界定**

- **出厂放行**：按企业内控标准执行
- **仲裁时**：仍以**法定标准**（药典/注册标准）为依据

这意味着：超出内控标准但符合法定标准的产品，经质量调查和评估后，由质量受权人决定是否可以放行；而超出法定标准的产品，无论如何不得放行出厂。

:::

## 因质量原因退货的分类处理规范

:::answer

退货和收回药品须根据**质量问题的类型**（外在质量 vs 内在质量）区分处理路径，不能一律销毁，也不能未经评估直接流向市场。

**外在质量问题：可能允许返工再销售**

| 典型情形                         | 处置路径                                  | 关键要求                     |
| -------------------------------- | ----------------------------------------- | ---------------------------- |
| 包装损坏（标签脱落、外包装破损） | 质保部门检查确认内在质量无变化 → 批准返工 | 内在质量确认须有文件证明     |
| 数量短缺（无产品质量问题）       | 与上同                                    | 调查短缺原因，确认批次完整性 |
| 销售积压（未过期，内质完好）     | 与上同                                    | 需确认储运条件符合要求       |

**返工处理的关键合规要求**

- 返工批次必须**在批号上加注返工标识**，与正常批次明确区分，保证可追溯性
- 返工产品须经质检部门**重新检验合格**，签收检验合格报告单后方可再销售
- 返工过程须在 QA 监督下进行，并有完整的返工批记录

**内在质量变化：必须销毁**

| 情形                                 | 处置路径             |
| ------------------------------------ | -------------------- |
| 产品有效成分含量超标或不足           | 在质保部门监督下销毁 |
| 微生物/内毒素超标                    | 在质保部门监督下销毁 |
| 性状改变（颜色、澄清度异常）         | 在质保部门监督下销毁 |
| 稳定性失效（已过期或稳定性研究失败） | 在质保部门监督下销毁 |

**关联批次的连带处理**

当发现内在质量问题时，须同时评估**同期生产的其他批次**是否受到相同问题的影响，若有关联批次，应一并处理，不得选择性处置。

:::

## 药品监管体系核心规范缩写解读：GSP、GLP、GCP、GAP

:::answer

生物制药行业涉及从研发到流通的多个监管规范体系，各规范针对不同环节制定，相互配合构成完整的药品质量保障体系。

**四大规范的定义与适用范围**

| 缩写    | 英文全称                   | 中文名称                   | 适用对象                             | 核心要求                                             |
| ------- | -------------------------- | -------------------------- | ------------------------------------ | ---------------------------------------------------- |
| **GSP** | Good Supply Practice       | 药品经营质量管理规范       | 医药商品经营企业（批发/零售/配送）   | 药品采购、验收、储存、销售、运输的全链路质量管理     |
| **GLP** | Good Laboratory Practice   | 药品非临床研究质量管理规范 | 承担临床前安全性评价研究的实验室     | 动物实验、毒理学研究、药代研究的规范性和数据可靠性   |
| **GCP** | Good Clinical Practice     | 药品临床试验管理规范       | 临床试验申办者、研究机构、伦理委员会 | 保障临床试验受试者权益；确保临床数据的真实性和可靠性 |
| **GAP** | Good Agricultural Practice | 中药材质量管理规范         | 中药材种植、采收、初加工企业         | 中药材源头质量控制（农药残留、重金属、产地溯源）     |

**与 GMP 的关系**

GMP（Good Manufacturing Practice，药品生产质量管理规范）是贯穿整个产品生命周期的核心规范，其他规范从不同维度与 GMP 互补：

```
药品质量保障体系
GAP（原料端）→ GLP（研发安全评价）→ GCP（临床试验）→ GMP（生产）→ GSP（流通）
```

:::

## 处方药与非处方药（OTC）的界定与管理差异

:::answer

**OTC 药的定义**

OTC（Over-the-Counter，非处方药）是不经医生处方即可由消费者**自行判断、购买和使用**的药品，在我国分为甲类（须在药师指导下使用）和乙类（可在普通商超销售）两类。

**处方药与 OTC 的核心区别**

| 维度           | 处方药（Rx）                       | 非处方药（OTC）                         |
| -------------- | ---------------------------------- | --------------------------------------- |
| **购买方式**   | 须凭医师处方，到医院药房或药店取药 | 无需处方，可自行到药店/超市购买（乙类） |
| **使用监督**   | 须在医师或医务人员指导下使用       | 消费者按说明书自行判断使用              |
| **安全性要求** | 高风险，需专业监督                 | 低风险，使用安全，副作用小              |
| **典型品种**   | 抗生素、降压药、化疗药、生物制品   | 常用感冒药、外用消炎药、维生素等        |
| **标识要求**   | 处方药标识                         | OTC 甲类（红色标识）/ 乙类（绿色标识）  |
| **广告限制**   | 不得在大众媒体做广告               | 可以在大众媒体做广告                    |

**生物制品与 OTC 的关系**

几乎所有生物制品（单克隆抗体、重组蛋白、疫苗、细胞治疗产品）均属于处方药范畴，须在医疗机构或具备资质的医务人员监督下使用。生物制品的复杂性、较高的免疫原性风险和严格的储运要求（冷链），决定了其不适合作为 OTC 药品管理。

:::

## 新药保护期制度：各类新药的保护年限

:::answer

**新药保护期的法规依据与启动时间**

新药经国家药品监督管理局（NMPA）批准颁发**新药证书**后，即自动获得相应年限的市场独占保护期。在保护期内，任何单位不得仿制该新药。

**各类新药保护期年限（旧分类体系）**

| 新药类别           | 保护期    | 类别说明                               |
| ------------------ | --------- | -------------------------------------- |
| **第一类新药**     | **12 年** | 境内外均未上市的新化学实体或创新生物药 |
| **第二、三类新药** | **8 年**  | 含已知成分的新组合/新剂型/新适应症等   |
| **第四、五类新药** | **6 年**  | 仿制国外已上市但境内未上市的药品等     |

**现行新药注册制度下的保护体系**

2020 年后，随着药品注册分类改革，中国建立了与国际接轨的更完善保护体系，包括：

| 保护类型                 | 保护期限                   | 适用范围                                  |
| ------------------------ | -------------------------- | ----------------------------------------- |
| **化学药品新药行政保护** | 6 年数据保护               | 新化学实体（NCE）首次批准上市             |
| **生物制品新药行政保护** | 12 年数据保护              | 创新生物制品（参考 FDA Biologics 独占权） |
| **孤儿药保护**           | 7 年独占期                 | 用于治疗罕见病的药品                      |
| **专利保护**             | 基于专利申请日，通常 20 年 | 需主动申请，与行政保护期可叠加            |

**对 CMC 开发策略的影响**

理解新药保护期对于生物类似药的立项时机至关重要：须在参照药的数据保护期届满后才能申请仿制；专利保护期届满后才能上市销售。两者需分别评估，且可能不同步到期。

:::

## 法定计量单位名称与符号速查

:::answer

在生物制药的 CMC 文件撰写、批记录填写和检验报告中，计量单位的规范使用是数据完整性（ALCOA+）的基本要求。以下是生物制药领域最常用的法定计量单位。

**长度单位**

| 单位名称 | 符号 | 换算关系 | 生物制药常用场景              |
| -------- | ---- | -------- | ----------------------------- |
| 米       | m    | 基本单位 | 生产设备尺寸                  |
| 分米     | dm   | 10⁻¹ m   | 较少使用                      |
| 厘米     | cm   | 10⁻² m   | 层析柱床高                    |
| 毫米     | mm   | 10⁻³ m   | 过滤器孔径（μm 级）           |
| 微米     | μm   | 10⁻⁶ m   | 过滤器孔径（0.2 μm 除菌过滤） |
| 纳米     | nm   | 10⁻⁹ m   | 病毒过滤器孔径（20 nm）       |

**体积单位**

| 单位名称 | 符号 | 生物制药常用场景           |
| -------- | ---- | -------------------------- |
| 升       | L    | 生物反应器体积、缓冲液配制 |
| 毫升     | mL   | 样品检测、制剂分装         |
| 微升     | μL   | PCR 体系、ELISA 加样       |

**质量（重量）单位**

| 单位名称 | 符号 | 生物制药常用场景              |
| -------- | ---- | ----------------------------- |
| 千克     | kg   | 原辅料投料量                  |
| 克       | g    | 缓冲液组分称量                |
| 毫克     | mg   | 蛋白质称量、效价计算          |
| 微克     | μg   | 微量成分检测（HCP、DNA 残留） |

**压力单位**

| 单位名称 | 符号 | 生物制药常用场景                   |
| -------- | ---- | ---------------------------------- |
| 兆帕     | MPa  | 高压蒸汽灭菌压力                   |
| 千帕     | kPa  | 过滤器跨膜压差（TMP）              |
| 帕       | Pa   | 洁净区压差控制（5–15 Pa 级间压差） |

**其他常用单位**

| 量       | 单位名称     | 符号  | 常用场景       |
| -------- | ------------ | ----- | -------------- |
| 动力黏度 | 帕秒         | Pa·s  | 高浓度制剂黏度 |
| 运动黏度 | 平方毫米每秒 | mm²/s | 工艺用油润滑性 |
| 密度     | 千克每立方米 | kg/m³ | 培养基密度     |
| 密度     | 克每立方厘米 | g/cm³ | 原料药密度     |

## 设备使用日志与设备运行记录的本质区别

:::answer

新版 GMP 明确要求对生产和检验设备建立规范的记录体系，但"使用日志"和"运行记录"是两种**关注维度不同**的记录，须加以区分，不可混用。

**使用日志（Equipment Use Log）**

**关注点**：**追溯与产品质量相关的人员活动**——这台设备在什么时间、由谁、用于哪个产品批次的什么操作。

| 记录项目          | 示例内容                            |
| ----------------- | ----------------------------------- |
| 使用日期和时间段  | 2024-03-15 08:00–16:00              |
| 操作人员姓名/工号 | 张三（操作员）/ 李四（复核）        |
| 操作类型          | 生产使用 / 清洁 / 维护 / 校准       |
| 关联产品信息      | 品名：XX 单抗注射液；批号：20240315 |
| 清洁或维护情况    | 生产后执行 XXX-SOP-015 清洁程序     |
| 异常情况记录      | 无 / 记录具体异常                   |

**运行记录（Equipment Operation Log）**

**关注点**：**设备本身的运行性能和参数状态**——设备在运行过程中各关键参数是否正常、性能是否稳定。

| 记录项目     | 示例内容                               |
| ------------ | -------------------------------------- |
| 记录时间间隔 | 每 30 分钟或每小时                     |
| 关键运行参数 | 温度、压力、转速、溶氧、pH（实时数据） |
| 报警记录     | 参数偏离设定值的报警事件及处置         |
| 设备状态     | 正常运行 / 暂停 / 故障                 |
| 维护状态     | 润滑、更换部件等维护活动记录           |

**核心区别总结**

| 维度         | 使用日志                           | 运行记录                             |
| ------------ | ---------------------------------- | ------------------------------------ |
| **核心关注** | 人的活动与产品关联                 | 设备本身的性能状态                   |
| **追溯目的** | 产品批次可追溯性（与哪个批次相关） | 设备维护历史和性能趋势               |
| **记录触发** | 每次使用开始/结束时                | 按时间间隔连续记录                   |
| **GMP 要求** | 新版 GMP 明确要求                  | GMP 要求，同时也是设备管理的良好实践 |

:::

## 仪器校验失效的规范处置流程

:::answer

**"检定"与"校准"的法规区分**

仪器计量管理中，"检定"和"校准"是两个法律属性不同的概念，其失效后的处置路径也有所不同：

| 特性         | 检定（Verification）                          | 校准（Calibration）                               |
| ------------ | --------------------------------------------- | ------------------------------------------------- |
| **法律属性** | **强制性**（法定计量检定），有合格/不合格判定 | 非强制，自愿行为，无合格/不合格判定，只给出偏差值 |
| **执行主体** | 法定计量检定机构（政府授权）                  | 具备资质的实验室或内部计量人员                    |
| **输出文件** | 检定证书（合格）或不合格报告                  | 校准证书（含示值误差，不含合格判定）              |

**仪器失准/校验失效的分步处置流程**

```
仪器校验失效或出现示值偏差
        ↓
步骤 1：立即记录（不得修改原始数据）
        ↓
步骤 2：标识仪器状态（张贴"校验失效/停用"标签）
        ↓
步骤 3：联系计量专业人员进行调整或维修
        ↓
调整/维修后能否恢复至合格范围？
    ↙ 是                              ↘ 否
重新校准确认合格               记录误差修正值（仅适用于校准）
更新校准记录                   降级使用 or 报废处理
        ↓
步骤 4：启动偏差程序（强制要求）
        ├── 评估仪器失准期间的所有相关检验活动
        ├── 回顾使用该仪器的产品批次
        └── 评估产品质量受到的影响（风险评估）
        ↓
步骤 5：CAPA（纠正及预防措施）
```

**几种常见情形的具体处置方式**

| 情形                               | 处置方式                                                   |
| ---------------------------------- | ---------------------------------------------------------- |
| 校准发现示值偏差但在技术要求范围内 | 记录偏差值，使用时加修正值，校准本身无合格/不合格判定      |
| 校准调整后恢复合格                 | 更新校准证书；偏差程序评估历史影响                         |
| 检定不合格，无法修复               | 出具不合格报告；仪器停用；评估历史影响；考虑降级使用或报废 |
| 不能正常使用                       | 降级至精度要求较低的使用场景，或直接报废                   |

**关键原则**

无论校准还是检定出现问题，**偏差程序是必须启动的强制要求**——这是 GMP 数据完整性的基本要求，不能因为"只是仪器问题"而跳过对历史数据影响的评估。

:::

## 洁净区更衣后段的静态级别管理要求

:::answer

**GMP 对更衣区的洁净级别要求**

GMP 对更衣后段（穿戴高级别洁净服的区域）有明确的洁净度要求，其管理逻辑基于以下分级原则：

| 区域                               | 静态洁净级别要求                  | 动态管理                         |
| ---------------------------------- | --------------------------------- | -------------------------------- |
| **更衣前段**（穿低级别洁净服区域） | 符合低洁净级别要求（如 D 级背景） | 按 D 级要求管理                  |
| **更衣后段**（穿高级别洁净服区域） | 符合**高洁净级别的静态要求**      | 自行制定可接受标准（过渡区性质） |

**关键理解**

更衣后段在性质上是**过渡区**，而非严格意义上的高洁净级别生产区，因此：

- **静态要求**：须符合高级别洁净区（如 B 级）的静态粒子和微生物限度要求
- **动态要求**：由于人员更衣活动本身会产生颗粒和微生物，动态状态必然有别于静态，允许企业根据风险评估**自行制定可接受的动态标准**

**洁净区分级的 ISO 标准对应关系（参考）**

| GMP 级别 | ISO 等级                    | 静态 ≥0.5μm 粒子限度（个/m³） |
| -------- | --------------------------- | ----------------------------- |
| A 级     | ISO 5                       | ≤ 3,520                       |
| B 级     | ISO 5（静态）/ISO 7（动态） | 静态 ≤ 3,520                  |
| C 级     | ISO 7（静态）/ISO 8（动态） | 静态 ≤ 352,000                |
| D 级     | ISO 8（静态）               | ≤ 3,520,000                   |

**实践建议**

更衣后段的动态监控频率和可接受标准应在企业的<strong>环境监控计划（EM Plan）</strong>中明确规定，并有历史数据支持标准的合理性。当 EM 数据显示动态状态持续超出内控标准时，须启动调查并评估洁净区控制措施的有效性。

:::

## 蒸汽管路异常噪声的类型识别与分析

:::answer

生物制药生产中，纯蒸汽（Pure Steam）和工业蒸汽系统的正常运行对灭菌验证和工艺用蒸汽的质量至关重要。管路噪声往往是系统异常的早期信号，须能正确识别。

**蒸汽管路噪声的分类与成因**

| 噪声类型                 | 典型声音特征                 | 主要成因                                                             | 处置建议                                        |
| ------------------------ | ---------------------------- | -------------------------------------------------------------------- | ----------------------------------------------- |
| **撞击声/噼啪声**        | 周期性金属撞击声             | ① 阀门开启过快，蒸汽高速冲击管道；② 冷管道突然接触热蒸汽，热应力形变 | 降低阀门开启速度（手动/自动调节）；增设暖管程序 |
| **水击（Steam Hammer）** | 剧烈的锤击声，可伴有管道振动 | 冷凝水未排净，高速蒸汽推动冷凝水团冲击管道弯头或阀门                 | 检查疏水阀功能；确保系统排净；优化管道坡度      |
| **轻微流动摩擦声**       | 持续的低沉嗡嗡声或摩擦声     | 蒸汽在管道内高速流动与管壁摩擦，属正常现象                           | 通常无需处置；若响声突然增大则调查原因          |
| **共鸣声**               | 特定频率的嗡嗡声或共振声     | 蒸汽流速与管道固有频率形成共振                                       | 调整管道支撑或改变蒸汽流速                      |
| **泄漏排气声**           | 持续的嘶嘶声                 | 管道接头、阀门密封处蒸汽泄漏                                         | 立即定位泄漏点；停机检修，更换密封件            |

**蒸汽管路管理的 GMP 含义**

在生物制品生产中，纯蒸汽质量（内毒素、不凝性气体、干燥值）直接影响灭菌效果和接触产品的设备/容器的洁净度。蒸汽系统的任何异常（噪声、压力波动、温度偏差）都须记录并评估对工艺的影响，必要时启动偏差调查。

:::

## "纠正"与"纠正措施"的本质区别：CAPA 体系的核心概念

:::answer

**精确定义**

| 概念                                  | 作用对象                           | 定义                                         | 目的                       |
| ------------------------------------- | ---------------------------------- | -------------------------------------------- | -------------------------- |
| **纠正（Correction）**                | 不合格**现象**（已发生的问题本身） | 消除已发现的不合格现象，恢复到合规状态       | **处理眼前问题**（止血）   |
| **纠正措施（Corrective Action，CA）** | 不合格的**根本原因**               | 消除不合格的原因，防止问题再次发生           | **防止问题复发**（治本）   |
| **预防措施（Preventive Action，PA）** | **潜在的**不合格原因               | 消除潜在不合格的原因，防止尚未发生的问题发生 | **主动防范**（防患于未然） |

**CAPA 的完整框架**

```
CAPA（Corrective Action and Preventive Action）
├── 纠正（Correction）
│   └── 对已发生的不合格立即采取的措施
│       示例：召回不合格批次；重新检验；隔离异常样品
│
├── 纠正措施（CA，Corrective Action）
│   └── 根本原因分析后针对原因制定的措施
│       示例：修订 SOP；更换设备部件；增加培训
│
└── 预防措施（PA，Preventive Action）
    └── 针对潜在风险主动制定的措施（无需先发生问题）
        示例：FMEA 识别高风险步骤后提前增设控制点
```

**一个不合格多个原因的处理**

如果根本原因分析识别出**多个根本原因**，须针对**每个根本原因分别制定对应的纠正措施**，而不是用一个措施笼统应对所有原因。例如：

- 原因 1（操作人员培训不足）→ 措施 1（重新培训 + 培训记录）
- 原因 2（SOP 描述不清晰）→ 措施 2（修订 SOP）
- 原因 3（仪器校准失效）→ 措施 3（校准计划优化）

**ICH/ISO 对 GMP 的影响**

中国 GMP（2010 版）虽未明确定义纠正与纠正措施的区别，但随着法规向 ICH 和 ISO 标准看齐，制药企业在建立 CAPA 程序时，应在企业 SOP 中明确定义纠正、纠正措施和预防措施的术语标准，确保团队对这些概念有统一准确的理解。

:::

## 药典精确度规定："精密称定"与"称定"的法规含义

:::answer

《中国药典》凡例对称量操作有明确的精确度规定，这些规定直接影响 CMC 研究和质量控制中投料和检验操作的精度要求。

**两个核心精确度等级**

| 术语         | 精确度要求                                     | 示例                                                  |
| ------------ | ---------------------------------------------- | ----------------------------------------------------- |
| **精密称定** | 称取重量应准确至所取重量的**千分之一（0.1%）** | 称取约 100 mg → 须精确至 0.1 mg（需使用万分之一天平） |
| **称定**     | 称取重量应准确至所取重量的**百分之一（1%）**   | 称取约 100 mg → 须精确至 1 mg（千分之一天平即可）     |

**"约"字的法规含义**

当取用量前标注"约"若干时，系指取用量**不得超过规定量的 ± 10%**：

```
示例：称取"约 50 mg"某物质
可接受范围：50 mg × (1 ± 10%) = 45–55 mg
```

**对称量器具精度的要求**

| 操作类型     | 所需天平精度（至少）      | 适用场景                           |
| ------------ | ------------------------- | ---------------------------------- |
| **精密称定** | 万分之一（0.1 mg 分辨率） | 标准品称量、效价测定、微量成分定量 |
| **称定**     | 千分之一（1 mg 分辨率）   | 一般辅料称量、较大量的制剂原料     |
| 生产投料     | 根据工艺精度要求确定      | 须匹配工艺对该物料的允许偏差范围   |

**GMP 合规要求**

- 生产过程的投料称量精度应结合该物料在工艺中的**临界性（Criticality）**确定——关键物料（如 pH 调节剂、API）须更高精度
- 所使用的称量器具精度须与工艺要求**相匹配或更高**，不得使用精度不足的器具
- 称量过程须双人复核，结果记入批记录，并有操作人员和复核人员签字

:::

## 质量管理部 GMP 现场检查的关注重点

:::answer

质量管理部在 GMP 自检和迎接监管机构检查时，需关注以下核心质量体系要素，这也是监管检查员的重点关注领域。

**GMP 现场检查的九大核心关注点**

| 检查领域                       | 检查重点                                                    | 常见缺陷                                        |
| ------------------------------ | ----------------------------------------------------------- | ----------------------------------------------- |
| **产品年度回顾（APR/PQR）**    | 是否按规定周期完成；回顾内容是否全面；是否识别改进趋势      | 回顾不及时；结论不支持工艺持续受控              |
| **GMP 自检（Internal Audit）** | 自检频率和覆盖范围；缺陷整改情况；供应商审计资料            | 未覆盖高风险区域；整改措施未有效落实            |
| **变更控制**                   | 所有重大变更是否经批准；变更对质量的影响评估是否充分        | 未申报的工艺变更（最严重的缺陷之一）            |
| **投诉管理**                   | 产品质量投诉的记录、调查和响应；药品不良反应报告的及时性    | 投诉调查不充分；严重不良事件未及时上报          |
| **偏差管理**                   | 偏差识别是否全面；根本原因分析深度；CAPA 的及时性和有效性   | 偏差漏报；根本原因停留于表面；CAPA 未能防止复发 |
| **产品放行**                   | QP 放行决策的依据；放行记录的完整性；放行前所有检验是否合格 | 放行记录不完整；部分检验结果未经审核            |
| **返工/再加工管理**            | 是否有书面批准；返工后是否重新检验；批号标识是否规范        | 未经批准的返工；批号标识不清晰                  |
| **SOP 管理**                   | SOP 是否现行有效；版本控制是否规范；执行与 SOP 的一致性     | 执行中的 SOP 版本已被废止；SOP 与实际操作不一致 |
| **人员和培训**                 | 培训记录的完整性；关键岗位人员资质；培训有效性评估          | 上岗前培训不充分；培训与实际操作脱节            |

:::

## GMP 现场检查应对规范：文件提供与人员沟通的黄金法则

:::answer

GMP 现场检查（监管机构检查/客户审计）的成功与否，不仅取决于实际的质量管理水平，更取决于检查过程中文件提供和人员回答的规范性。以下是经过实践验证的核心应对准则。

**文件提供的四项原则**

| 原则             | 具体要求                                                                   |
| ---------------- | -------------------------------------------------------------------------- |
| **按需提供**     | 仅提供检查员要求的文件，不主动展示未被要求的文件                           |
| **预先审查**     | 所有递交给检查员的文件，事先须由部门负责人快速审查（发现问题及时准备说明） |
| **原始数据谨慎** | 对原始数据和记录相关问题谨慎回答，避免使检查员形成"数据完整性问题"的错觉   |
| **统一口径**     | 不同人员对同一问题的回答须一致（检查员会在不同时间向不同人问同样的问题）   |

**回答问题的六条铁律**

| 铁律           | 内容                                               |
| -------------- | -------------------------------------------------- |
| ① **不拒绝**   | 不能以任何理由拒绝回答检查员的合理提问             |
| ② **直接明确** | 直接回答问题，不含糊，不绕圈子                     |
| ③ **无矛盾**   | 绝不出现与文件记录或其他人员回答相矛盾的内容       |
| ④ **不懂就说** | 确实不知道时，坦诚承认并提出由更了解的人来回答     |
| ⑤ **言出必行** | 承诺检查员的事项（提供资料、完成确认）必须兑现     |
| ⑥ **绝不说谎** | 诚信是检查成功的基础，任何欺骗行为都会导致严重后果 |

**检查中绝对禁止的六句话**

| 禁忌话语               | 检查员的负面解读                                                     |
| ---------------------- | -------------------------------------------------------------------- |
| **"我想这可能是……"**   | 表明不了解自己负责的工作，不可接受；不要试图猜测                     |
| **"是的，通常是……"**   | 立即引出"那不正常情况呢"——若没有文件支持非常规情况，绝对不要说这句话 |
| **"那不是我的问题"**   | 极度负面的印象；引发对部门间协调和职责划分的全面调查                 |
| **"那太贵了"**         | 表明变更管理失控；成本从来不是拒绝改正合规问题的理由                 |
| **"说实话……"**         | 暗示之前的回答不是实话——诚信是一切的基础                             |
| **"我们一直就是这样"** | 表明无改进意愿；欠缺培训；不接受检查建议的负面信号                   |

**人员准备的关键要点**

- 检查前所有相关人员须**提前集中就位**
- 由公司指定专人负责迎接检查员，减少陪同人员（通常仅 1–2 人陪同）
- 各部门负责人须在当天下班前将**被检查内容、被质疑问题、被指出问题**汇总到质量部，以便及时跟进

:::

## QA 与 QC 的定义、职责边界与协同关系

:::answer

**精准定义**

| 概念   | 英文全称                      | 定义                                                                                                               | 核心定位                                         |
| ------ | ----------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| **QA** | Quality Assurance（质量保证） | 为了提供足够的信任表明实体能够满足质量要求，而在质量管理体系中实施并根据需要进行证实的**全部有计划和有系统的活动** | **系统层面**：建立、维护和改善整个质量管理体系   |
| **QC** | Quality Control（质量控制）   | 为达到品质要求所采取的**作业技术和活动**，包括产品质量检验、问题分析改善和不合格品控制                             | **操作层面**：通过检验和控制确保产品符合质量标准 |

**QA 的职能细分**

| QA 职能类型          | 英文缩写 | 职责内容                                     |
| -------------------- | -------- | -------------------------------------------- |
| **设计质量保证**     | DQA      | 产品研发阶段的质量介入，确保设计满足质量要求 |
| **制程质量工程师**   | PQE      | 生产工艺过程的质量保证和改善                 |
| **质量工程师**       | QE       | 综合质量体系的建立与维护                     |
| **供应商质量工程师** | SQE      | 对供应商的质量评估、审计和管理               |

**QC 的职能细分**

| QC 类型          | 英文缩写 | 职责内容                          |
| ---------------- | -------- | --------------------------------- |
| **来料质量控制** | IQC      | 原辅料和包装材料的入场检验与放行  |
| **制程质量控制** | IPQC     | 生产过程中的过程检验和监控（IPC） |
| **成品质量检验** | FQC      | 成品在放行前的全套质量检验        |
| **出厂检验**     | OQC      | 出厂前的最终质量确认              |

**QA 与 QC 的五维关键差异**

| 差异维度     | QA                                                         | QC                                             |
| ------------ | ---------------------------------------------------------- | ---------------------------------------------- |
| **工作性质** | **事前预防**为主（系统性保障）                             | **事后检验**为主（发现并纠正问题）             |
| **覆盖范围** | **全局性**，涉及公司所有质量相关职能                       | **局部性**，主要集中在产品质量检验             |
| **核心目标** | 提供**质量信任**（体系运转的可靠性证明）                   | 保证**产品合格**（检验结果符合标准）           |
| **知识要求** | 须知道问题出在哪里，还须知道**如何制定解决方案和预防措施** | 须知道如何对问题进行控制，但不一定须深究为什么 |
| **客户视角** | 对外提供体系运作的信任（内外部审计、供应商管理）           | 直接保证出厂产品质量符合规定                   |

**QA 包含 QC 的层级关系**

```
质量管理（Quality Management）
        ↑
质量保证（QA）← 包含 QC 及其他体系性活动
        ↑
质量控制（QC）← 检验、测量、分析活动
```

**QA 与 QC 的协同联系**

- QC 是质量管理的**基础检验环节**，提供产品是否合格的客观数据
- QA 以 QC 数据为输入，在此基础上进行更广泛的体系性管理（内审、文件管理、培训、CAPA 等）
- 两者都涉及验证活动：QC 验证产品是否符合质量标准；QA 验证体系运作是否符合法规要求
- **质量管理（QM）** 是比 QA 更广泛的范畴，不仅包含 QA 和 QC，还包含对质量体系的战略思考和整体管理

**生物制药中 QA/QC 设立的必要性**

仅有 QC 检验不足以保证药品质量——因为批量生产的药品无法做到 100% 检验，统计抽样检验存在漏网风险。必须有 QA 从**全局和体系层面**管控所有影响产品质量的环节（原材料、工厂环境、设备、生产工艺、人员能力等），确保每个环节都在受控状态下运行，才能真正保证产品质量的持续稳定。

:::

## 企业内部校准的资质要求与操作规范

:::answer

**内部校准不需要政府颁发的官方资质证书**，企业只需建立科学合理的内部校准体系，满足以下三个核心条件：

**条件一：具备合格的计量人员**

- 须经过**专业技术培训**，掌握相关计量知识和操作技能
- **无需政府颁发的官方资质证书**，也无强制要求接受官方培训
- 须经企业内部考核合格，证明其能胜任校准工作
- 实质要求：能保证"量值的可靠传递与可靠追溯"

**条件二：具备高一级标准计量器具**

- 用于内部校准的标准器具（标准器、标准物质）须**高出被校准器具一个精度等级**
- 通常配备经过法定机构**强制检定**的"企业最高标准器"
- 企业可从该最高标准器出发，逐级向下传递量值，实现全部在用计量器具的内部校准

**条件三：具备必要的校准环境和规程**

| 要求            | 说明                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------- |
| 校准环境        | 若在现场校准，环境条件须满足仪器现场使用条件；若在计量室校准，须满足校准规范要求的温湿度等条件           |
| 校准规程（SOP） | 依据国家《校准规范》和《检定规程》编写；对于无法定依据的仪器，可根据出厂说明和权威资料制定合理的校准方法 |
| 校准周期        | 在 SOP 中明确规定，并建立到期提醒机制                                                                    |

**内部校准与对外承担业务的边界**

- 上述内部校准体系**仅适用于企业内部**，不得对外提供校准服务
- 若需对外承担校准业务，须按照计量法规要求进行**实验室计量建标**，通过资质认定

**内部校准记录要求（GMP 视角）**

- 每次校准活动须有完整的校准记录（校准日期、结果、执行人、校准所用标准器）
- 校准合格的器具须张贴有效的校准标识（校准日期 + 下次校准截止日期）
- 校准记录须归档保存（通常不少于仪器寿命期）

:::
