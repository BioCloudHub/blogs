## 鲎试剂：内毒素检测核心试剂的来源、原理与质量标准

:::answer

### 鲎试剂的来源与制备

鲎试剂（Limulus Amebocyte Lysate, LAL）是由海洋节肢动物**鲎（Limulus polyphemus，美洲鲎；或 Tachypleus tridentatus，东方鲎）** 的蓝色血液中提取变形细胞（Amebocyte）溶解物，经低温冷冻干燥制成的生物试剂。

鲎试剂含有能被微量**细菌内毒素（Endotoxin，LPS）** 和**真菌（1,3)-β-D-葡聚糖（β-Glucan）** 激活的两个关键蛋白：

- **凝固酶原（Coagulogen Precursor）：** 被内毒素/β-葡聚糖激活后触发凝固级联反应。
- **凝固蛋白原（Coagulin Precursor）：** 被活化的凝固酶切割，形成不溶性凝胶（G 蛋白纤维）。

### 鲎试剂的检测原理

```
细菌内毒素（LPS）/ (1,3)-β-葡聚糖
  │
  └─ 激活鲎试剂中的凝固酶原
        │
        └─ 凝固酶原 → 活性凝固酶
              │
              └─ 裂解凝固蛋白原 → 凝胶（G 蛋白纤维）
                    │
                    └─ 通过肉眼（凝胶法）或仪器（动态比浊法、终点比色法）检测
```

### 鲎试剂的三种检测方法

| 方法                                    | 原理                                                 | 优势                       | 适用场景                                    |
| --------------------------------------- | ---------------------------------------------------- | -------------------------- | ------------------------------------------- |
| **凝胶法（Gel-Clot）**                  | 阳性样品与鲎试剂混合后形成坚实凝胶，翻转 180° 不破坏 | 操作简单；成本低；无需仪器 | **定性（是/否）及半定量检测**；日常快速筛查 |
| **动态比浊法（Kinetic Turbidimetric）** | 实时检测吸光度变化速率，与内毒素浓度相关             | 定量精准；自动化程度高     | 放行检测；高通量检测                        |
| **终点比色法（End-point Chromogenic）** | 凝固酶切割合成底物（pNA），释放黄色（405 nm 吸收）   | 线性范围宽；重现性好       | 定量检测；方法验证                          |

### 鲎试剂的质量关键指标

优质鲎试剂须满足以下三方面质量要求：

| 质量维度                  | 要求                                             | 不合格风险                                             |
| ------------------------- | ------------------------------------------------ | ------------------------------------------------------ |
| **灵敏度（Sensitivity）** | 稳定，不随存放时间发生显著变化                   | 灵敏度改变会使测定结果的允许限值发生变化，导致错误判断 |
| **自凝时间**              | 不低于 **24 小时**（排除非内毒素触发的自发凝固） | 自凝时间过短导致假阳性                                 |
| **成胶状态**              | 阳性样品形成坚实凝胶，翻转 180° 后不破坏         | 凝胶松散提示批次质量不稳定                             |

> **选择建议：** 须选择具有国家批准文号、灵敏度稳定的品牌鲎试剂。如仅需检测内毒素限量，可选用凝胶法；通过测定内毒素限值（L = K/M）和最大有效稀释倍数（MVD）先做干扰试验，再确定合适的鲎试剂灵敏度规格（λ 值）。

### 内毒素限度计算公式

$$L = K / M$$

$$MVD = cL / \lambda$$

其中：$L$ 为内毒素限值（EU/mL 或 EU/mg）；$K$ 为阈值常量（注射剂静脉给药为 5 EU/kg·h）；$M$ 为每千克体重每小时最大给药剂量；$\lambda$ 为所选鲎试剂灵敏度；$c$ 为供试品浓度。

## 病毒污染控制合理性的 CDE 挑战点与应对策略：风险评估、全过程控制与全生命周期管理

:::answer

### CDE 常见挑战点

药品评审中心（CDE）在技术审评中针对病毒安全性的挑战主要集中在三方面：

| 挑战类型               | 具体表现                           | 潜在影响                       |
| ---------------------- | ---------------------------------- | ------------------------------ |
| **验证缺失**           | 未开展病毒去除验证研究             | 无法证明工艺可控制病毒污染风险 |
| **验证不充分**         | 验证研究仅覆盖部分病毒类型或步骤   | 存在特定病毒的安全性空白       |
| **缩小模型不具代表性** | 缩小模型未被充分确认可代表生产规模 | 验证结论不能外推至商业化生产   |

### 三大核心法规原则

**原则一：风险评估（Risk-based Approach）**

不同生物制品的病毒安全风险存在客观差异，须基于以下维度进行差异化评估：

| 评估维度         | 关键考量因素                                                     |
| ---------------- | ---------------------------------------------------------------- |
| 产品来源         | 细胞系来源（CHO vs. 人源细胞）；原材料（是否含动物源成分）       |
| 潜在污染病毒特性 | 有/无包膜；耐受性；感染范围                                      |
| 生产工艺         | 是否已包含有效去除/灭活步骤                                      |
| 临床应用         | 给药途径（静脉 > 皮下 > 口服）；患者人群（免疫缺陷患者风险更高） |

**原则二：全过程控制（Holistic Process Control）**

病毒安全控制须贯穿生产全链条，不可仅依赖单一步骤：

```
原材料/起始物料
  └── 来源控制 + 病毒筛查（血清、胰蛋白酶等动物源材料）
        ↓
细胞库（MCB/WCB）
  └── 全面病毒因子检测（14 项，见细胞库专题）
        ↓
细胞培养（上游）
  └── 支原体、微生物限度过程监控
        ↓
收获与澄清
  └── 生物负荷控制；深层过滤
        ↓
下游纯化（多步骤正交病毒清除）
  └── 低 pH 灭活 + 病毒过滤 + AEX 辅助去除
        ↓
成品
  └── 内毒素、无菌检查放行
```

**原则三：全生命周期管理（Lifecycle Management）**

- 工艺变更须评估对病毒清除能力的影响，根据影响程度进行**确认（Qualification）或再验证（Re-validation）**。
- 上市后须通过持续监测和必要时的回顾性追踪，保证商业化生产全生命周期的病毒安全性。

### 应对策略的技术核心

**策略一：多步骤正交组合（至少两种不同原理的步骤）**

| 步骤              | 主要作用原理                   | 覆盖病毒类型             |
| ----------------- | ------------------------------ | ------------------------ |
| 低 pH 孵育        | 化学灭活（破坏包膜）           | 有包膜病毒               |
| 阴离子交换（AEX） | 静电吸附（负电荷病毒结合填料） | 有/无包膜病毒            |
| 纳滤（20 nm）     | 物理尺寸排阻                   | 有/无包膜病毒（≥ 20 nm） |

**策略二：缩小模型须经充分确认**

缩小模型须在以下参数上与生产规模等同：柱床高度、线性流速、产品载量（g/L）、缓冲液组成。若无法完全等同，须在**最差条件（Worst Case）** 下进行研究，以证明最低安全性。

:::

## 生物制品病毒污染风险的来源分类：外源性与内源性风险的系统管控

:::answer

### 病毒风险的两大来源

**来源一：外源性病毒（Adventitious Viruses）**

外源性病毒是指在生产过程中通过外部途径**意外引入**的病毒，主要渠道包括：

| 引入途径           | 具体风险物料                                         | 代表性病毒                         |
| ------------------ | ---------------------------------------------------- | ---------------------------------- |
| **生物来源原材料** | 牛胎血清（FBS）、牛血白蛋白                          | 牛腺病毒（BAV）、牛细小病毒（BPV） |
| **猪源原材料**     | 猪源胰蛋白酶                                         | 猪圆环病毒（PCV-1/2）              |
| **基因工程操作**   | 病毒诱导表达载体（如腺病毒、杆状病毒）               | 载体病毒的潜在污染                 |
| **层析耗材**       | 单克隆抗体亲和柱（制备过程中使用的腹水源杂交瘤细胞） | 鼠源内源病毒                       |
| **制剂赋形剂**     | 含动物源成分的辅料                                   | 依来源而定                         |
| **操作人员/环境**  | 细胞培养暴露操作                                     | 腺病毒、流感病毒等                 |

**来源二：内源性病毒（Endogenous Viruses）**

内源性病毒是宿主细胞基因组中整合的病毒序列，无法通过原材料控制消除：

| 内源性病毒类型                | 宿主细胞                       | 特点                                                                           |
| ----------------------------- | ------------------------------ | ------------------------------------------------------------------------------ |
| **逆转录病毒样颗粒（RVLPs）** | CHO、NS0、Sp2/0 等啮齿动物细胞 | 由内源性逆转录病毒序列表达；**对人类无感染性**；须作为工艺清除验证的起始值参照 |
| **内源性逆转录病毒（ERVs）**  | 所有哺乳动物细胞               | 基因组整合序列；部分可产生病毒颗粒                                             |

> **RVLPs 的监控方法：** 取未经纯化的细胞培养上清液，通过透射电子显微镜（TEM）检测 RVLPs 含量，并将其作为下游纯化工艺病毒清除验证的**初始病毒滴度参照值**（起算点）。

### 风险管理的三条互补原则（ICH Q5A）

```
原则一：细胞系和原料的检定与筛选
  └── 确保不含对人有感染/致病作用的病毒

原则二：评估生产工艺清除感染性病毒的能力
  └── 通过多步骤病毒清除验证（LRV 评估）

原则三：检测生产关键步骤的产品
  └── 确保产品未受到感染性病毒的污染
```

### CMC 层面的三维控制框架

| 维度             | 控制措施                                                 |
| ---------------- | -------------------------------------------------------- |
| **上游物料控制** | 供应商审计；原材料病毒安全证书；动物源材料的病毒灭活处理 |
| **中控检测**     | 收获液的外源病毒检测；过程生物负荷监控                   |
| **下游纯化**     | 多步骤正交病毒清除；低 pH + 纳滤 + AEX 组合              |

## 微生物污染控制策略：污染来源识别、控制体系设计与工艺保持条件验证

:::answer

### 微生物污染的系统性风险认知

微生物在自然界无处不在，能在极端条件下适应生存，对生物产品的影响可体现在：

- **产品降解：** 蛋白酶分泌导致目标蛋白降解，降低 Titer 和纯度。
- **内毒素产生：** 革兰氏阴性菌产生 LPS，引发患者热原反应。
- **工艺偏差：** 污染触发批次报废，影响生产进度和成本。

### 微生物污染的九大来源

| 污染来源            | 主要风险点                             | 控制措施                             |
| ------------------- | -------------------------------------- | ------------------------------------ |
| **设施/洁净室**     | 空调过滤器失效；正压失去；表面清洁不足 | 环境监测；压差监控；定期清洁和消毒   |
| **设备**            | 密封件老化；死角积液；连接管路裂缝     | 预防性维护；设备设计（避免死角）     |
| **工艺操作**        | 开放式操作（加样、取样）               | 最小化开放操作；使用生物安全柜       |
| **原材料**          | 培养基（液体培养基最易）；缓冲液       | 供应商检测证书；使用前微生物限度检测 |
| **层析填料/过滤膜** | 再生不彻底；CIP 失效                   | 填料寿命验证；CIP 有效性验证         |
| **水**              | 循环系统微生物滋生（WFI > 70℃ 循环）   | TOC 和微生物日检；循环系统维护       |
| **工艺气体**        | 压缩空气/N₂ 中的微生物                 | 0.22 μm 气体过滤器；定期完整性测试   |
| **操作人员**        | 皮肤脱落物；呼出气体；操作失误         | gowning 规程；更衣培训和考核         |
| **交叉污染**        | 多产品设施中不同产品/批次间交叉        | 设施分区隔离；病毒前/后区域严格分开  |

### 微生物控制策略的核心要素

**① 设施设计原则：**

- 人流、物流、废物流须从**洁净区流向非洁净区**（单向流动）。
- 易受污染的关键上游开放式操作须在**指定生物安全柜（BSC）** 区域进行。
- **多产品设施中**，病毒清除步骤前后区域须实施物理隔离，防止工艺内交叉污染。

**② 工艺设计原则：**

- 最大化**密闭系统**的使用，减少开放操作暴露时间和次数。
- 在工艺关键节点设置**生物负荷减少过滤器**（0.22 μm 或 0.1 μm）。
- 明确各中间体的**保持时间和温度（Hold Time & Temperature）** 限制，并通过验证证明在此条件下微生物无显著增殖。

**③ 工艺保持条件验证要点：**

| 中间体类型                               | 关键风险         | 验证方法                                                         |
| ---------------------------------------- | ---------------- | ---------------------------------------------------------------- |
| 营养丰富的中间体（收获液、低纯度洗脱液） | 微生物生长速率快 | 在最差条件下（最高温度、最长保持时间）接种挑战微生物，验证不超标 |
| 缓冲液（含碳源）                         | 低风险但须监控   | 制备后设定使用有效期；期满前微生物限度测试                       |
| 高纯度中间体（CEX 洗脱液）               | 低风险           | 有效期验证 + 理论支持                                            |

## 支原体的生物学基础：定义、致病种类与免疫清除机制

:::answer

### 支原体的定义与生物学特征

**支原体（Mycoplasma）** 是迄今已知最小的能独立复制的原核微生物，具有以下独特的生物学特征：

| 特征           | 描述                                             | 工艺意义                                              |
| -------------- | ------------------------------------------------ | ----------------------------------------------------- |
| **无细胞壁**   | 无肽聚糖细胞壁                                   | 对青霉素类抗生素天然耐药；无法被 β-内酰胺类抗生素杀灭 |
| **体积极小**   | 直径 **0.1～0.3 μm（100～300 nm）**              | 能通过 0.22 μm 除菌滤膜（！）；须用 0.1 μm 滤器截留   |
| **高度多形性** | 球形、丝状、分枝状等多种形态                     | 镜检鉴别困难                                          |
| **可人工培养** | 在含血清的专用培养基（如 SP-4 培养基）上缓慢生长 | 培养法仍为检测金标准                                  |
| **无核膜**     | 原核细胞型微生物                                 | 基因组小（~1 Mb），代谢依赖宿主                       |

> **最关键的工艺含义：** 支原体直径（100～300 nm）处于细菌（> 300 nm）和病毒（20～450 nm）之间，且**能通过 0.22 μm 除菌滤器**。这意味着标准除菌过滤无法保证支原体的去除，须采用 **0.1 μm 滤器**或其他专项措施。

### 对人致病的主要支原体种类

| 支原体种类                        | 主要致病部位 | 相关疾病                 |
| --------------------------------- | ------------ | ------------------------ |
| **肺炎支原体（M. pneumoniae）**   | 呼吸道       | 非典型肺炎（"行走肺炎"） |
| **溶脲脲原体（U. urealyticum）**  | 泌尿生殖道   | 非淋菌性尿道炎；不孕不育 |
| **人型支原体（M. hominis）**      | 泌尿生殖道   | 盆腔炎；产后发热         |
| **生殖器支原体（M. genitalium）** | 泌尿生殖道   | 尿道炎；宫颈炎           |

### 机体对支原体的免疫清除

- **巨噬细胞：** 吞噬和非特异性杀伤支原体；巨噬细胞激活后分泌 TNF-α、NO 等杀菌物质。
- **IgG：** 通过调理作用（Opsonization）增强吞噬；与支原体表面蛋白结合阻断其黏附宿主细胞。
- **IgM：** 感染早期的首要抗体；通过凝集和补体激活发挥杀伤作用。

## 支原体污染的危害链：从隐匿感染到生物制品质量失控的全景分析

:::answer

### 支原体污染为何难以察觉

支原体污染的"隐蔽性"是其最危险的特质，即使培养液中支原体生长密度高达 **10⁷～10⁹ CFU/mL**（相当于细菌可见浑浊的浓度），也难以出现肉眼可见的污染迹象：

| 污染指标     | 细菌污染（易察觉）                     | 支原体污染（难察觉）             |
| ------------ | -------------------------------------- | -------------------------------- |
| 培养液浑浊度 | **明显浑浊**（革兰阴性菌产生大量 LPS） | **保持澄清**                     |
| pH 变化      | **急剧下降**（酸性代谢产物大量产生）   | **轻微变化或无变化**             |
| 细胞死亡速率 | 快（数小时至数天）                     | 慢（数天至数周，细胞"慢性消耗"） |
| 细胞形态     | 迅速恶化                               | 轻微改变，早期难以区分           |

### 支原体污染的系统性危害

| 危害类别         | 具体影响                                  | 对生产的实际影响                         |
| ---------------- | ----------------------------------------- | ---------------------------------------- |
| **核酸损伤**     | 支原体核酸酶导致 DNA 片段化；干扰核酸合成 | PCR、测序、转染等实验结果不准确          |
| **代谢干扰**     | 竞争氨基酸和核苷酸；改变碳水化合物代谢    | 细胞生长速率下降；蛋白表达量降低         |
| **细胞表面改变** | 改变细胞膜抗原性                          | 免疫学实验假阳性/阴性；影响效能检测      |
| **染色体不稳定** | 诱发染色体突变                            | 细胞基因型漂移；产品质量属性批间差异增大 |
| **凋亡敏感性**   | 使细胞对凋亡诱导剂更敏感                  | 药效/毒性实验偏差                        |
| **生物制品质量** | DNA、RNA 及蛋白表达改变                   | 产品纯度下降；质量属性异常               |

### 支原体的传播链与实验室污染扩散

```
一支污染细胞（感染率高达 63%）
  │
  ├─ 共用培养箱 → 气溶胶传播 → 同箱其他细胞继发污染
  │
  ├─ 液氮罐 → 液氮直接接触安瓿泄漏 → 细胞库交叉污染
  │
  └─ 操作人员 → 手部/飞沫 → 开放操作时引入
```

> **最重要的实践建议：** 受支原体污染的细胞**极难再净化**（无细胞壁使得常规消毒剂效果有限）。最经济的处理方案是**无害化处理**（高压灭菌后丢弃），从冷冻细胞库复苏未污染的备份细胞株。

### 主要污染来源

| 污染来源                | 支原体种类（常见）                  |
| ----------------------- | ----------------------------------- |
| 细胞系（人源/啮齿动物） | M. hyorhinis、M. orale、M. arginini |
| 血清（牛血清）          | M. hyorhinis、M. bovis              |
| 鸡胚（病毒疫苗生产）    | M. gallisepticum                    |
| 原代细胞（人/动物组织） | M. fermentans、M. pneumoniae        |
| 操作人员（口腔/呼吸道） | M. orale、M. salivarium             |

## 支原体检测方法全解析：培养法、DNA 染色法与 PCR 法的原理对比及适用选择

:::answer

### 三种主要检测方法对比

| 方法                                 | 检验原理                                                                                                                           | 检验周期              | 主要优势                                                 | 主要局限                                                            |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- | --------------------- | -------------------------------------------------------- | ------------------------------------------------------------------- |
| **培养法（Gold Standard）**          | 将供试品接种于固体和液体培养基（SP-4、Friis 等），在 37℃ 有氧/无氧条件下培养，观察典型菌落（"煎蛋"形态）                           | **28 天（ChP 要求）** | 可检测活菌；灵敏度高；药典法定方法                       | 耗时极长；部分支原体不易培养；实验室污染风险（须用活菌作阳性对照）  |
| **DNA 荧光染色法（指示细胞培养法）** | 将供试品接种于指示细胞（Vero 细胞），培养富集后用 Hoechst 33258 或 DAPI 荧光染料染色，荧光显微镜下观察细胞外荧光颗粒（支原体 DNA） | **4～15 天**          | 比培养法快；无需支原体活菌阳性对照                       | 部分支原体不适应指示细胞生长（假阴性）；死亡细胞 DNA 干扰（假阳性） |
| **PCR 法（推荐补充方法）**           | 用支原体 16S rRNA 基因特异性引物和探针扩增支原体核酸；阳性结果可进一步测序鉴定种属                                                 | **< 24 小时**         | 快速；高灵敏度；无需活菌阳性对照（安全）；可溯源污染种属 | 检测核酸而非活菌，无法区分死/活支原体；须注意引物覆盖范围           |

### 药典规定的联合检测要求

**《中国药典》2020 版通则 3301** 规定，对以下物料进行支原体检查时，须**同时采用培养法和指示细胞培养法（DNA 染色法）**：

- 主细胞库（MCB）
- 工作细胞库（WCB）
- 病毒种子批
- 对照细胞
- 临床治疗用细胞

**以下物料仅需培养法：**

- 病毒类疫苗的病毒收获液
- 原液

### PCR 法的核心优势：安全性与溯源能力

PCR 法不使用支原体**活菌**作为阳性对照，从根本上消除了阳性对照样品污染实验室的风险——这是药典培养法的固有安全隐患。此外，PCR 阳性结果可通过**测序分析**确认支原体种属，为污染溯源提供直接证据，这是培养法和 DNA 染色法均无法实现的功能。

### 各阶段检测节点推荐

| 检测节点              | 推荐方法                   | 目的                             |
| --------------------- | -------------------------- | -------------------------------- |
| MCB/WCB 建立          | 培养法 + DNA 染色法        | 药典要求；全面确认细胞库无支原体 |
| 生产过程（EOPC、UPB） | PCR 法（快速）+ 培养法确认 | 过程监控；快速预警               |
| 原液                  | 培养法                     | 产品放行依据                     |
| 研发阶段快速筛查      | PCR 法                     | 快速排查，缩短决策周期           |

:::

## 支原体污染的早期预警信号与细胞培养过程中的异常表现识别

:::answer

### 早期预警的重要性

支原体污染的"沉默期"可长达数周乃至数月，在此期间细胞持续表达，但产品质量和实验数据可能已经受到干扰。建立**早期预警体系**可将损失降至最低。

### 生产过程中的异常信号

| 监控指标                  | 正常状态            | 支原体污染可能信号                     | 监控频率     |
| ------------------------- | ------------------- | -------------------------------------- | ------------ |
| **细胞生长速率（μ）**     | 与历史批次一致      | **明显低于历史基线**（支原体竞争营养） | 每日         |
| **细胞活力（Viability）** | ≥ 90%（对数生长期） | 异常缓慢下降                           | 每日         |
| **细胞形态**              | 边界清晰，均匀分布  | 细胞变圆；形态不规则；出现细小运动颗粒 | 每日镜检     |
| **葡萄糖消耗速率**        | 与历史批次一致      | 异常降低（支原体改变细胞代谢）         | 每日         |
| **乳酸产生速率**          | 与历史批次一致      | 异常偏低                               | 每日         |
| **pH**                    | 稳定，受 CO₂ 控制   | 轻微异常（但通常不显著）               | 持续在线监控 |
| **溶氧（DO）**            | 稳定                | 异常波动                               | 持续在线监控 |

> **关键识别要点：** 支原体污染与细菌/真菌污染的最大区别在于——前者不引起培养液浑浊和 pH 急剧下降，但会导致**细胞生长和代谢参数与历史批次的系统性偏差**。当多个参数同时出现轻微偏差时须高度警惕。

### 确认污染的操作流程

```
发现异常 → 立即取样（培养上清液）
  │
  ├─ PCR 快速筛查（< 24 h）
  │     阳性 → 确认污染类型和种属
  │
  ├─ 显微镜检查（Hoechst/DAPI 染色）
  │     检查细胞外荧光颗粒
  │
  └─ 培养法检测（28 天，药典确认方法）

确认污染后：
  ├─ 立即隔离并销毁污染细胞和培养物
  ├─ 深度清洁培养箱（70% 乙醇 + UVC 照射 + 密闭熏蒸）
  ├─ 从未污染的冻存细胞库复苏备份细胞
  └─ 排查污染源（取样供试品、培养基、添加物、环境）
```

:::

## 支原体全链条控制策略：物料、人员、环境、过滤与过程监控的系统整合

:::answer

### 控制策略框架

支原体控制须形成**预防为主、过程监控、终点确认**的全链条体系，而非仅依赖终产品检测：

### 五维控制体系详解

**① 物料控制（Material Control）**

| 物料类别      | 支原体风险来源         | 控制措施                                     |
| ------------- | ---------------------- | -------------------------------------------- |
| 细胞系        | 原代细胞携带支原体     | 引入前强制支原体检测；从经认证的细胞库获取   |
| 牛血清（FBS） | 牛支原体（M. bovis）等 | 要求供应商提供支原体阴性证书；采购前批次检测 |
| 鸡胚成分      | M. gallisepticum       | 来源控制；检测合格后使用                     |
| 胰蛋白酶      | 猪/牛源成分            | 使用重组胰蛋白酶（规避风险）；或供应商证书   |
| 培养基        | 液体培养基易受污染     | 每批次微生物限度检测；冷链储存               |

**② 人员操作（Personnel Control）**

- 所有细胞培养操作人员须接受支原体风险培训，了解其传播途径和预防措施。
- 患有呼吸道疾病（咳嗽、流感）的操作人员须避免进行开放式细胞培养操作，因口腔/呼吸道支原体（M. orale、M. salivarium）是常见污染源。
- 严格执行生物安全柜使用规程，戴口罩和手套后方可进行开放操作。

**③ 生产环境（Environment Control）**

- 定期对培养箱、生物安全柜、液氮罐等关键设备进行表面支原体检测（环境监测）。
- 液氮储存须使用**气相液氮罐**而非液相，防止液氮直接接触安瓿造成批次间交叉污染。
- 洁净室维持适当的正压差，防止外部污染物进入。

**④ 支原体物理去除（Filtration）**

- **最终过滤须使用 0.1 μm 滤器**（而非常规 0.22 μm），以物理截留支原体（直径 100～300 nm）。
- 注意：0.1 μm 过滤通量显著低于 0.22 μm，须在工艺设计阶段评估对过滤效率和载量的影响。
- 0.1 μm 滤器同时也是中间体保持期间微生物控制的重要手段。

**⑤ 过程监控节点（In-process Monitoring）**

| 监控节点                   | 检测方法            | 检测频率         |
| -------------------------- | ------------------- | ---------------- |
| **MCB/WCB 建立**           | 培养法 + DNA 染色法 | 每次建库         |
| **EOPC（生产终末细胞）**   | 培养法 + DNA 染色法 | 每次生产周期末   |
| **未纯化收获液（UPB）**    | PCR 快速筛查        | 每批次           |
| **原液（DS）**             | 培养法（药典法）    | 每批次（放行前） |
| **下游中间体（关键步骤）** | PCR 法              | 定期或风险导向   |

:::

## 无菌检查（Sterility Test）的方法原理、样品选择逻辑与操作规范

:::answer

### 无菌检查的法规定义与目的

无菌检查（Sterility Test）是验证无菌药品和无菌医疗器械中**是否存在污染性活微生物**的官方检验方法。根据各国药典要求，无菌药品在销售前每批产品须经过无菌检查并证明无菌，是常规产品放行的必检项目。

### 两种检测方法原理与选择

| 维度         | 薄膜过滤法（Membrane Filtration）                                                                             | 直接接种法（Direct Inoculation）                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **操作原理** | 将规定量的供试品过滤，用冲洗液冲洗滤膜（去除抑菌物质），再向膜两侧容器中注入培养基，37℃（FTM）/25℃（TSB）培养 | 将规定量的供试品**直接转移**至含硫代乙醇酸盐液体培养基（FTM，检测需氧/厌氧菌）和胰酪大豆胨液体培养基（TSB，检测真菌及需氧菌）中 |
| **培养条件** | FTM：30～35℃，14 天；TSB：20～25℃，14 天                                                                      | 同薄膜过滤法                                                                                                                    |
| **优先级**   | **首选**（USP<71>；EP 2.6.1：产品性质允许时必须使用）                                                         | 当产品性质不允许使用薄膜过滤时（黏度过高等）使用                                                                                |
| **优势**     | 可处理大体积样品；通过冲洗去除抑菌成分（抗生素、防腐剂）；灵敏度更高                                          | 操作简单；适合小体积、低黏度样品                                                                                                |
| **局限性**   | 操作较复杂；时间较长                                                                                          | 抑菌成分可能干扰培养，导致假阴性                                                                                                |

### 生物制品无菌检查的样品选择逻辑

对于抗体类生物制品，无菌检查的检测节点选择基于以下考量：

```
DS（原液）→ 经 0.22 μm 除菌过滤 → DP 灌装 → 成品（DP）
                                         ↑
                          ← 无菌检查在成品放行中进行（更有实际意义）

生产过程中（DS 到 DP 中间）：
  └── 通过微生物限度检测（而非无菌检查）来监控和控制无菌水平
```

**选择对成品进行无菌检查而非原液的核心逻辑：**

- 原液经过除菌过滤后制备成品，除菌过滤是引入微生物污染风险的最后关键步骤。
- 灌装过程（分装、加塞、封口）在 A 级环境下进行，也是潜在污染节点。
- 成品无菌检查是对最终产品安全性的直接证明，与患者用药安全最相关。

### 无菌检查操作的关键规范

- **环境要求：** 须在 B 级背景下的 **A 级单向流通风空气区域**（或等效隔离系统/RABS）内进行，整个操作须严格无菌。
- **培养基灵敏度验证：** 须定期验证两种培养基（FTM 和 TSB）对各类微生物的促生长能力（阳性对照）。
- **方法适用性确认：** 对于特定产品（含抑菌成分），须先完成方法适用性试验，确认所用冲洗液量和冲洗次数可有效消除产品对微生物生长的抑制。

:::

## 支原体检查法的法规要求：检测样品范围、方法选择与过程监控节点

:::answer

### 法规要求的检测对象

**《中国药典》2020 版**（通则 3301）规定，在生物制品生产过程中须对以下关键物料进行支原体检查：

| 检测对象                      | 检测方法要求                                          | 检测时机               |
| ----------------------------- | ----------------------------------------------------- | ---------------------- |
| **主细胞库（MCB）**           | 培养法 **+** 指示细胞培养法（DNA 染色法）**同时进行** | 建立时（一次全面检定） |
| **工作细胞库（WCB）**         | 培养法 + DNA 染色法                                   | 每次建立新 WCB         |
| **病毒种子批**                | 培养法 + DNA 染色法                                   | 建立时                 |
| **对照细胞**                  | 培养法 + DNA 染色法                                   | 定期                   |
| **临床治疗用细胞**            | 培养法 + DNA 染色法                                   | 每批                   |
| **病毒类疫苗病毒收获液/原液** | **仅培养法**（必要时辅以 DNA 染色法筛选培养基）       | 每批                   |
| **原液（DS）**                | 培养法（放行前）                                      | 每批                   |
| **EOPC（生产终末细胞）**      | 培养法 + DNA 染色法                                   | 每生产周期             |
| **UPB（未纯化收获液）**       | 推荐 PCR 法（过程监控）                               | 每批                   |

### 方法选择的灵活性

药典通则同时规定：在经国家药品检定机构认可的情况下，**也可采用其他方法**（如经验证的 qPCR 法）代替培养法，这为工业界采用更快速的检测方法提供了法规空间。

### 检测节点的工艺整合建议

```
MCB/WCB 建立
  └── 培养法 + DNA 染色法（药典强制）

生产过程
  ├── 收获液（UPB）→ PCR 快速筛查（24 h 内出结果，可提前预警）
  ├── EOPC → 培养法 + DNA 染色法（药典要求）
  └── 过程异常时 → 立即 PCR 检测，必要时培养法确认

放行前
  └── 原液 → 培养法（放行依据）
```

> **实践建议：** 对于商业化生产批次，建议在收获液阶段引入 PCR 快速筛查作为**早期预警**手段（非药典放行依据，而是过程控制工具），一旦发现阳性信号可立即启动调查，避免在下游纯化耗费大量资源后才发现问题。

## 细胞培养污染的早期判断：五类污染的特征识别与鉴别要点

:::answer

### 污染的宏观早期信号

当细胞培养液出现以下任何异常，应立即取样进行显微镜检查：

| 异常信号                         | 可能的污染类型             | 紧急程度              |
| -------------------------------- | -------------------------- | --------------------- |
| 培养液出现**明显浑浊**           | 细菌（最常见）、酵母菌     | 🔴 极高（立即处理）   |
| 细胞**氧气消耗速率显著升高**     | 细菌（大量代谢）           | 🔴 极高               |
| **pH 大幅度降低**（短时间内）    | 产酸菌（如大肠杆菌）       | 🔴 极高               |
| 显微镜下可见**运动的微小生物**   | 细菌、支原体（颗粒状移动） | 🔴 极高               |
| 培养液澄清但**细胞生长持续缓慢** | 支原体、原虫（早期）       | 🟡 中（需进一步确认） |
| 出现**丝状漂浮物**               | 霉菌                       | 🔴 高                 |

### 五类常见污染的特征鉴别

**① 细菌（Bacteria）**

- **外观：** 培养液明显浑浊，颜色可能变化（取决于菌种）；pH 急剧下降。
- **镜下形态：** 黑色细沙状（球菌）或短杆状（杆菌），弥散分布于培养液中，无方向性运动。
- **识别要点：** 污染发展极快（数小时内即可使细胞严重受损）；是最易发现的污染类型。
- **应对：** 立即丢弃；寻找培养基、灭菌锅程序、操作规范等污染源。

**② 霉菌（Mold/Filamentous Fungi）**

- **外观：** 培养液可能清亮或轻微浑浊；可见絮状、棉花状漂浮物。
- **镜下形态：** 细丝状菌丝（Hyphae）和孢子，典型的分枝结构；明显区别于细胞碎片（菌丝有规则的分叉）。
- **识别要点：** 生长速度比细菌慢（数天）；一旦可见菌丝，细胞污染已较严重；空气中孢子为主要来源。
- **应对：** 立即丢弃；检查培养箱密封性、HEPA 过滤器状态。

**③ 支原体（Mycoplasma）**

- **外观：** 培养液**保持清亮**；pH **无明显变化**；最难察觉。
- **镜下形态（荧光染色后）：** 附着于细胞表面的荧光颗粒（Hoechst/DAPI 染色），在标准光学显微镜下难以看见（0.1～0.3 μm，低于光学分辨率极限）。
- **识别要点：** 细胞生长缓慢；代谢参数异常；**需 PCR 或荧光染色才能确认**。
- **应对：** 无害化处理；从冻存细胞库复苏干净细胞。

**④ 真菌/酵母菌（Yeast/Fungi）**

- **外观：** 培养液通常**保持清亮**；可能出现轻微浑浊（晚期）。
- **镜下形态：** 初期类似死细胞碎片，但呈**清晰的珊瑚状或芽生出芽结构**，折光性强；后期出现细丝状黑色丝状物（霉菌阶段）。
- **识别要点：** 生长比细菌慢；发展到肉眼可见时细胞往往已无法救治。
- **应对：** 立即丢弃；检查洁净室状态和操作人员更衣规范。

**⑤ 原虫（Protozoa）**

- **外观：** 培养液可轻微浑浊。
- **镜下形态：** 细小点状物，**数量非常多，轻微活动**；细胞可勉强生长但速度明显减慢，状态不好，边缘不清晰。
- **识别要点：** 与细胞存在"共生"关系，数量少时不影响细胞生长，数量达到阈值后形成恶性循环；在国内细胞培养中相对少见。
- **应对：** 原虫通常来源于污染的水源或土壤；须从培养用水质量和环境控制入手排查。

:::

## 细胞培养污染的根因分析与预防控制体系

:::answer

### 污染根因的系统性排查路径

一旦发现污染，须立即启动有序的根因排查，避免项目时间线大幅延迟：

```
Step 1：确认污染类型（镜检 + PCR/培养）
  │
Step 2：按"由近及远"原则逐步排查
  │
  ├─ 检查培养基是否出现污染
  │     → 取相同批次未开封培养基做无菌检查
  │
  ├─ 检查添加物是否出现污染
  │     → 取血清、生长因子等添加物做无菌检查
  │
  ├─ 检查反应器管路连接
  │     → 目视检查所有接头、管路是否有裂缝或松动
  │
  ├─ 检查安全柜状态
  │     → 验证正压和风速；检查 HEPA 过滤器完整性；检查上次清洁记录
  │
  ├─ 检查灭菌锅灭菌程序
  │     → 查阅灭菌记录；验证温度和时间参数是否到位；检查指示带是否变色
  │
  └─ 检查操作人员操作规范
        → 回顾培养操作录像；复核操作记录；评估操作人员技能
```

### 全面的污染预防体系

**环境层面：**

- 细胞培养操作须在**层流（Laminar Flow）** 安全柜或隔离器中进行，维持 A 级洁净空气。
- 定期进行洁净室环境监测（浮游菌、沉降菌、表面微生物）。

**物料层面：**

- 所用培养基须**无菌**，最好现配现用；液体培养基开瓶后限时使用。
- 培养所用器皿（瓶、管、板）须经过**高压灭菌或辐射灭菌**。

**操作层面：**

- 严格执行**无菌技术（Aseptic Technique）** 核心原则：除必要的已灭菌物品，任何可能带菌的物品（包括手）**不得越过无菌区上方空间**。
- 工作台面操作前后用 75% 乙醇擦拭，再用 UVC 照射 15～20 min。
- 最小化开放操作时间；快速完成加样/取样操作后立即关闭安全柜。

**人员层面：**

- 细胞培养是一门需要持续练习的技能，**操作的熟练与规范**是最重要的污染防控保障。
- 新人须经过正式培训和考核，通过无菌操作能力评估后方可独立操作。

:::

## 终端灭菌工艺与无菌生产工艺：定义、SAL 差异与生物制品的适用选择

:::answer

### 两种工艺的核心定义

| 维度             | 终端灭菌工艺（Terminal Sterilization）                                     | 无菌生产工艺（Aseptic Processing）                                       |
| ---------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **定义**         | 在控制微生物污染量的基础上，药品**灌封后**通过湿热灭菌方式除菌             | 以防止污染为目的，在无菌系统环境下通过除菌过滤或无菌操作法保证无菌       |
| **除菌时机**     | 灌装**完成后**（最终产品灭菌）                                             | 灌装**过程中**（全程防止引入污染）                                       |
| **主要灭菌方法** | 湿热高压蒸汽灭菌（121℃，15 min，F₀ > 8 min）                               | 0.22 μm 除菌过滤 + A/B 级无菌灌装                                        |
| **适用剂型**     | **大容量注射剂**（葡萄糖注射液、氯化钠注射液等）；热稳定性好的小容量注射剂 | **粉针剂**；对热不稳定的小容量注射剂；**所有生物大分子注射剂（单抗等）** |

### 无菌保证水平（SAL）的对比

**无菌保证水平（Sterility Assurance Level, SAL）** 是产品经灭菌（除菌）后微生物残存的概率，数值越小代表越安全：

| 工艺类型                                | SAL 水平        | 含义                                                          |
| --------------------------------------- | --------------- | ------------------------------------------------------------- |
| **终端灭菌（湿热灭菌）**                | ≤ **10⁻⁶**      | 每百万支产品中微生物残存概率不超过 1 支                       |
| **无菌生产工艺（除菌过滤 + 无菌灌装）** | 通常约 **10⁻³** | 每千支产品中微生物残存概率不超过 1 支（比终端灭菌低 1000 倍） |

> **政策含义：** 无菌生产工艺的 SAL（10⁻³）远低于终端灭菌（10⁻⁶），因此**仅限于临床必须注射给药而确实无法耐受终端灭菌**的产品。

### 为什么生物制品必须采用无菌生产工艺

```
生物制品（单抗、重组蛋白等）的热敏感性
  │
  ├─ 121℃ 高压灭菌 → 蛋白质不可逆变性 → 生物活性完全丧失
  │
  └─ 因此，只能采用无菌生产工艺：
        ├─ 原液经 0.22 μm 除菌过滤（去除细菌和真菌）
        ├─ 在 A 级洁净区（层流）灌装
        └─ 注意：0.22 μm 过滤无法去除病毒，须依靠下游工艺的专属病毒清除步骤
```

### GMP 中的关键条款

**《药品生产质量管理规范》第六十一条规定：**

- 无菌药品应当**尽可能采用加热方式进行灭菌**（优先终端灭菌）。
- 终端灭菌的 SAL 不得高于 **10⁻⁶**；采用湿热灭菌时，标准灭菌时间 F₀ 值须 **> 8 分钟**（注：流通蒸汽灭菌不属于最终灭菌）。
- 对热不稳定的产品，可采用**无菌生产操作或过滤除菌**的替代方法。

## 微生物限度检查与无菌检查的本质区别：检测目标、适用范围与环境要求全解析

:::answer

### 两者的根本区别

| 比较维度         | 无菌检查（Sterility Test）               | 微生物限度检查（Microbial Limit Test, MLT）               |
| ---------------- | ---------------------------------------- | --------------------------------------------------------- |
| **检测目标**     | 检查是否有**任何活微生物存在**（定性）   | 检查活微生物数量是否**超出规定限度**（定量）              |
| **控制严格程度** | **极严格**：不允许任何活微生物存在       | **较宽松**：允许一定数量的微生物存在                      |
| **适用产品**     | 注射剂、眼用制剂、用于严重创伤的外用制剂 | 口服固体/液体制剂（片剂、胶囊、口服液等）；非无菌外用制剂 |
| **培养时间**     | **14 天**（细菌和真菌均须 14 天培养）    | 细菌 **3 天**；霉菌/酵母菌 **5 天**                       |

### 口服给药制剂的微生物限度标准（ChP 2020）

| 剂型         | 细菌数限度   | 霉菌/酵母菌限度 |
| ------------ | ------------ | --------------- |
| 口服液体制剂 | ≤ 100 CFU/mL | ≤ 100 CFU/mL    |
| 口服固体制剂 | ≤ 1000 CFU/g | ≤ 100 CFU/g     |

### 两种检查的方法差异

**无菌检查方法：**

- **薄膜过滤法（首选）：** 大体积样品通过滤膜，冲洗后注入 FTM（30～35℃/14 天，检测厌氧和需氧菌）和 TSB（20～25℃/14 天，检测真菌及需氧菌）培养基。
- **直接接种法（备用）：** 直接转移供试品至两种培养基，适用于无法过滤的样品（高黏度等）。

**微生物限度检查方法：**

- **平皿法（倾注法/涂布法）：** 将样品与培养基混合（倾注）或涂布于培养基表面，计数菌落（CFU）。
- **薄膜过滤法：** 大体积样品过滤后置于培养基上计数。

### 操作环境要求对比

| 环境要求     | 无菌检查                                                        | 微生物限度检查                                  |
| ------------ | --------------------------------------------------------------- | ----------------------------------------------- |
| **洁净级别** | **A 级**单向流通风区域（B 级背景下的 A 级）或隔离器/RABS        | 10000 级（C 级）背景下的局部 100 级（A 级）层流 |
| **共同点**   | 两者均须在 **10000 级下的局部 100 级（A 级）** 无菌区域进行操作 | 同左                                            |
| **验证要求** | 须验证单向气流区域的洁净度和工作台面的清洁消毒效果              | 相对宽松                                        |

### 生物制品的无菌检查执行依据

生物制品的无菌检验须按照<strong>《中国生物制品规程》</strong>中有关无菌检验的规定执行，并结合产品特点进行方法适用性验证，确保供试品中的抑菌成分（如防腐剂、缓冲液成分）不影响检测的灵敏度。

:::
