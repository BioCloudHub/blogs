## 皮内注射（ID）的技术特征、注射深度与主要应用场景

:::answer

**皮内注射的解剖学定位**

皮内注射（Intradermal Injection, ID）是将药液注入**表皮（Epidermis）与真皮（Dermis）之间**的给药方式，注射深度最浅（约 1～2 mm），不进入皮下组织。

| 解剖层次                   | 深度（约）   | 皮内注射的位置       |
| -------------------------- | ------------ | -------------------- |
| 表皮（角质层→基底层）      | 0.05～0.2 mm | 起点（进针穿过表皮） |
| **真皮（皮内注射目标层）** | 0.2～2 mm    | **药液沉积处**       |
| 皮下组织（脂肪层）         | 2～5 mm      | 皮内注射不到达       |
| 肌肉层                     | > 5 mm       | 皮内注射不到达       |

**皮内注射的操作要点**

- 进针角度：**几乎平行于皮肤表面（5～15°角）**，针头斜面向上；
- 注射成功的标志：注射后可见皮肤表面形成**橘皮样皮丘（Wheal）**（皮肤隆起的小泡），提示药液正确注入真皮层；
- 注射量：通常极小（0.05～0.1 mL），真皮层空间有限。

**皮内注射的主要应用场景**

| 应用类型             | 典型示例                           | 选择皮内注射的理由                                         |
| -------------------- | ---------------------------------- | ---------------------------------------------------------- |
| 皮肤过敏试验         | 青霉素皮试、头孢皮试、碘过敏试验   | 局部皮肤反应（红晕、风团）可直接目视观察，结果判断直观     |
| 预防接种（部分疫苗） | BCG 卡介苗（结核疫苗）             | 皮内途径激活局部免疫应答，产生特异性免疫保护，所需抗原量少 |
| 局麻的前驱操作       | 大手术局部浸润麻醉前的皮肤标记注射 | 减少深层注射时的疼痛刺激                                   |

**皮内注射 vs. 其他给药途径的吸收速度比较**

皮内注射吸收速度是四类注射途径中**最慢**的，这恰恰是皮试和疫苗接种选用此途径的原因：

- 皮试：慢吸收使过敏反应局限于注射局部（皮肤风团），避免全身过敏；
- 疫苗：皮内丰富的树突状细胞（抗原递呈细胞）提升免疫原性，但全身暴露少，全身不良反应减少。

:::

## 皮下注射（SC）的技术要点、常用部位与生物药的皮下给药优势

:::answer

**皮下注射的解剖学定位**

皮下注射（Subcutaneous Injection, SC/SQ）是将药液注入<strong>皮下组织（真皮层以下、肌肉层以上的疏松脂肪结缔组织）</strong>中的给药方式。

**皮下注射的操作技术要点**

- **进针角度：** 通常 **30～45°角**（较瘦受试者可提捏皮肤后垂直注射）；
- **进针深度：** 穿过真皮，进入皮下脂肪层，通常 12.5 mm 左右；
- **注射量：** 通常不超过 1.5 mL（脂肪层空间有限，过大注射量会引起局部疼痛和组织损伤）。

**常用皮下注射部位及选择原则**

| 注射部位                    | 吸收速度 | 特点                                         | 典型药物                 |
| --------------------------- | -------- | -------------------------------------------- | ------------------------ |
| **腹部**（脐旁 3～5 cm 外） | 最快     | 脂肪层厚，毛细血管丰富，吸收稳定             | 胰岛素（优先选择）、肝素 |
| **上臂外侧三角肌下缘**      | 中等     | 操作方便，可自行注射                         | 疫苗、抗体药物           |
| **大腿前外侧**              | 较慢     | 脂肪较厚，吸收稳定                           | 胰岛素、GLP-1 受体激动剂 |
| **臀部外上象限**            | 最慢     | 脂肪层厚，吸收慢，不推荐用于需快速起效的药物 | 疫苗（部分）             |

**注射部位轮换的重要性**

对于需长期重复注射的药物（如胰岛素、单抗类生物药），须**有计划地轮换注射部位**：

- 同一部位反复注射会导致脂肪营养不良（Lipodystrophy）——局部脂肪萎缩或增生；
- 脂肪营养不良部位的吸收速率异常，可能导致血药浓度不稳定。

**皮下注射的典型适用药物类型**

- **不能口服的蛋白质类药物：** 胰岛素口服会在胃肠道被蛋白酶降解失活，皮下注射可绕过消化道直接吸收；
- **单抗类生物药（SC 制剂）：** 越来越多的抗体药物开发 SC 剂型（如依那西普、阿达木单抗、曲妥珠单抗 SC），SC 途径相比 IV 途径具有：患者可自行注射（提高便利性和依从性）、门诊/居家给药（降低医疗成本）、注射时间短（5～15 秒 vs. IV 输注 30～90 分钟）等优势；
- **需缓慢吸收、维持一定血药浓度的药物：** 皮下脂肪层的血流速度相对较慢，可实现药物较缓慢的持续吸收，有利于维持较平稳的血药浓度曲线。

**处方标注识别**

在医嘱和处方中，皮下注射通常标注为：**H**（来自 Hypodermal 或 Hypodermic）或 **IH**（Intra-Hypodermic）或 **SC/SQ**。

:::

## 肌肉注射（IM）的解剖定位、适应条件与臀大肌定位四区法

:::answer

**肌肉注射的解剖学定位**

肌肉注射（Intramuscular Injection, IM）是将药液注入**肌肉组织**中的给药方式，注射深度深于皮下注射，穿过表皮→真皮→皮下组织后进入肌肉。

**肌肉注射的适用条件**

| 适用情形               | 具体说明                                                   |
| ---------------------- | ---------------------------------------------------------- |
| 不宜或不能静脉注射     | 药物不能用于静脉内（如油性制剂、混悬液）                   |
| 需比皮下注射更快起效   | 肌肉血供丰富，吸收速度快于皮下，慢于静脉                   |
| 注射刺激性较强的药物   | 刺激性药物注入皮下可引起疼痛和局部坏死；肌肉组织耐受性更强 |
| 注射量较大（> 1.5 mL） | 肌肉组织空间大，单次可注射 2～5 mL                         |

**禁止肌肉注射的情形**

- 注射部位有**硬结**（已形成纤维组织，药物无法弥散）；
- 注射部位有**感染**（可扩散感染灶）；
- **出血倾向患者**（凝血功能障碍，如血友病、使用华法林）——IM 可引起肌肉内血肿。

**最常用注射部位：臀大肌（四区法定位）**

臀大肌是最常用的肌肉注射部位，准确定位可避免损伤坐骨神经：

**四区定位法（最常用）：**

```
从臀裂顶点向左或右侧划一水平线
从髂脊最高点作一垂直平分线
将臀部分为四个区象限
          ↓
外上象限（1/4 区域）= 肌肉注射的安全区域
（此区域无重要神经血管走行）
```

**其他常用注射部位**

| 部位                   | 特点                                   | 适用药物       |
| ---------------------- | -------------------------------------- | -------------- |
| 臀中肌、臀小肌         | 较厚，血管丰富，安全性高（婴幼儿优选） | 疫苗、抗菌药物 |
| 股外侧肌（大腿前外侧） | 自行注射方便，局部无重要神经           | 胰岛素、疫苗   |
| 三角肌（上臂外侧）     | 面积小，仅适合小量注射（< 1 mL）       | 疫苗接种       |

**肌肉注射后的正确按压原则**

注射后须用干棉球按压注射部位 1～2 分钟（但避免按摩），防止药液从针孔渗漏；**对于注射凝血因子、抗凝药物的患者**，须适当延长按压时间（5～10 分钟）。

:::

## 静脉注射（IV）与静脉滴注（IV Drip）的关键区别：药量、时间与安全性特征对比

:::answer

**静脉给药的解剖学基础**

静脉注射（Intravenous Injection, IV）和静脉滴注（IV Infusion/IV Drip）均是将药物直接送入血液循环的给药方式，具有**吸收最快、起效最迅速**的特点，但也伴随着最高的安全性风险。

**静脉注射 vs. 静脉滴注的核心差异**

| 比较维度             | 静脉注射（IV Push/Bolus）                      | 静脉滴注（IV Infusion）                            |
| -------------------- | ---------------------------------------------- | -------------------------------------------------- |
| **药物量**           | 通常**较小**（数 mL～数十 mL，浓缩制剂）       | 通常**较大**（须稀释至较大体积，50 mL～1000 mL）   |
| **注射速度**         | 快速推注（数秒～数分钟内完成）                 | 缓慢、受控速率滴注（30 分钟～数小时）              |
| **浓度峰值（Cmax）** | 高（短时间内大量药物进入血液）                 | 低（药物缓慢、持续输入，峰谷差小）                 |
| **安全性**           | 相对风险高（短时高浓度可引起心脏毒性、过敏等） | 相对安全（可实时调节滴速，发现不良反应可立即停止） |
| **医护参与**         | 需医护人员全程在场推注                         | 建立通道后可有一定监测间隔（但仍需定期巡视）       |
| **典型药物**         | 急救药（肾上腺素、阿托品）、利尿剂             | 抗生素、单抗类生物药、化疗药、补液                 |

**单抗类生物药首选 IV 滴注的理由**

大多数单抗药物的首次给药采用静脉滴注而非推注，原因在于：

- 高剂量蛋白质短时间内快速进入血液可能触发<strong>细胞因子释放综合征（CRS）</strong>或输液相关反应（IRR）；
- 静脉滴注通过设置首次给药低速率（Slow Rate）→ 耐受后逐步加快（Step-up Rate Protocol），降低 IRR 风险；
- 大容量稀释液缓冲了药物的局部高浓度。

**输液相关反应（IRR）的识别与处置**

这是单抗 IV 制剂的特有风险，须建立：

- **输注前预处理方案**（如抗组胺药、解热镇痛药、糖皮质激素）；
- **输注期间实时监测**（生命体征、过敏征象）；
- **输液反应发生时的处置 SOP**（减速→停止输注→紧急处置）。

## 单抗药物的临床应用领域：肿瘤、自身免疫与新兴适应症的格局与机制逻辑

:::answer

**单抗药物的市场规模与临床应用格局**

单克隆抗体（mAb）是当今全球最重要的药物类别之一，在过去 20 年中持续主导全球药品销售榜单。从临床应用角度，单抗药物覆盖三大核心领域：

**第一领域：抗肿瘤（最大市场）**

抗肿瘤是单抗药物应用最广泛的领域，已上市的代表性单抗药物覆盖几乎所有主要瘤种：

| 靶点/机制 | 代表药物                   | 适应症                           |
| --------- | -------------------------- | -------------------------------- |
| HER2      | 曲妥珠单抗（赫赛汀）       | HER2+ 乳腺癌、胃癌               |
| VEGF      | 贝伐珠单抗（安维汀）       | 结直肠癌、肺癌、胶质母细胞瘤     |
| CD20      | 利妥昔单抗（美罗华）       | B 细胞淋巴瘤、慢性淋巴细胞白血病 |
| PD-1      | 帕博利珠单抗（可瑞达）     | 黑色素瘤、NSCLC、多瘤种（MSI-H） |
| PD-L1     | 阿替利珠单抗、度伐利尤单抗 | NSCLC、膀胱癌、TNBC              |
| EGFR      | 西妥昔单抗（爱必妥）       | KRAS 野生型结直肠癌、头颈鳞癌    |

**抗肿瘤单抗的核心作用机制**

- **直接靶向肿瘤细胞：** 通过封闭促生长受体（如 HER2、EGFR），阻断下游信号传导（PI3K/AKT/MAPK），抑制肿瘤细胞增殖和生存；
- **免疫效应功能：** ADCC（NK 细胞依赖的细胞毒性）、CDC（补体溶解）、ADCP（巨噬细胞吞噬），招募免疫系统杀伤肿瘤；
- **免疫检查点封闭：** 解除肿瘤微环境中的免疫抑制，恢复 T 细胞对肿瘤的监视和杀伤能力。

**第二领域：自身免疫疾病（第二大市场）**

自身免疫疾病是单抗药物销售额最高、增速最快的领域之一：

| 靶点     | 代表药物                                     | 适应症                                       |
| -------- | -------------------------------------------- | -------------------------------------------- |
| TNF-α    | 阿达木单抗（修美乐，连续多年全球销售额第一） | 类风湿关节炎、强直性脊柱炎、克罗恩病、银屑病 |
| IL-6R    | 托珠单抗（雅美罗）                           | 类风湿关节炎、巨细胞动脉炎                   |
| IL-17A   | 司库奇尤单抗（可善挺）                       | 银屑病、强直性脊柱炎                         |
| IL-12/23 | 乌司奴单抗（喜达诺）                         | 银屑病、克罗恩病                             |
| CD20     | 利妥昔单抗                                   | 类风湿关节炎（DMARDs 失败后）                |

**作用机制共性：** 拦截炎性细胞因子或封闭免疫细胞活化受体，在不完全抑制整体免疫的前提下，特异性阻断驱动自身免疫损伤的关键炎症回路。

**第三领域：新兴适应症**

单抗药物已逐步扩展至以下新兴领域：

| 领域     | 代表靶点/药物                                 | 市场潜力                     |
| -------- | --------------------------------------------- | ---------------------------- |
| 抗感染   | 帕利珠单抗（预防 RSV）、REGEN-COV（COVID-19） | 高，尤其传染病大流行情境     |
| 心血管   | PCSK9 抑制剂（依洛尤单抗、阿利西尤单抗）      | 极高，高胆固醇血症患者基数大 |
| 神经系统 | 阿杜那单抗（靶向 β-淀粉样蛋白，阿尔兹海默症） | 前景广阔，但开发挑战大       |
| 器官移植 | 巴利昔单抗（IL-2R 拮抗，抗排斥）              | 相对稳定                     |

## 毒理试验中 DS 与 DP 的选择策略：成分一致性原则与临床安全预测的核心要求

:::answer

**核心问题：毒理试验应使用 DS（原液）还是 DP（制剂）？**

在 IND 申报阶段，毒理试验（包括一般毒性、安全药理、遗传毒性等）通常需要大量样品，而 DP 制剂的生产复杂性较高、周期较长。许多企业出于**缩短开发时间线**的考虑，选择用 DS 样品（原液，未加辅料的纯蛋白样品）开展毒理试验。

**关键判断原则：DS 与 DP 成分是否实质一致？**

| 情形                                                                                   | DS 与 DP 关系 | 是否可用 DS 开展毒理    | 原因                             |
| -------------------------------------------------------------------------------------- | ------------- | ----------------------- | -------------------------------- |
| **DS 和 DP 的活性成分及辅料成分实质一致**（或差异极小，辅料安全性已知）                | 等同或接近    | **可以**                | 毒理结果可以代表 DP 在体内的行为 |
| **DS 和 DP 的成分存在实质差异**（如 DP 含有具备独立药理/毒理活性的特殊辅料、共价修饰） | 不一致        | **不建议**，建议使用 DP | DS 不能代表 DP 的安全性特征      |

**典型需要注意的不一致情形**

- **DP 含有 SC 增强制剂（如透明质酸酶）：** 透明质酸酶本身具有药理活性（促进 SC 吸收），若毒理试验仅用 DS，则无法评估透明质酸酶的毒性贡献；
- **DP 的 pH、离子强度与 DS 显著不同：** 可能影响蛋白质的聚集状态和免疫原性，毒性特征可能不同；
- **ADC 产品：** DS 和 DP 之间若存在药物-抗体比（DAR）差异或偶联方式不同，毒性特征可能显著改变。

**"样品一致性"原则的法规背景**

监管机构要求毒理试验受试品须代表拟用于临床试验的产品，《ICH M3(R2)》明确指出：

> "非临床安全性研究所用的受试物应尽可能与拟用于临床试验的药物在质量（纯度、配方）上保持一致。"

**DS 替代 DP 开展毒理时的额外工作**

若选择 DS 开展毒理试验，在 IND 申报资料中须：

- 提供 DS 与 DP 的可比性分析（成分组成、质量属性的头对头比较）；
- 说明 DS 能够代表 DP 的科学依据；
- 若辅料有可能产生独立毒性，须额外提供辅料的安全性数据。

:::

## 临床前阶段细胞培养工艺开发策略：克隆筛选流程、放大风险识别与平台工艺的应用

:::answer

**临床前工艺开发的核心目标**

临床前细胞培养工艺开发的首要目标是**在 14～18 个月内完成从转染到 IND 申报的全流程**，以快速满足毒理试验和 IND 申报样品的需求为首要驱动力，而非追求工艺的完美优化。

**克隆筛选与工艺开发的标准流程（四阶段）**

**第一阶段：多克隆起始筛选**

- 从 **3～5 个备选克隆**出发，在实验室规模小反应器（1～3 L）上进行系统筛选；
- 每个条件（1 克隆 × 1 工艺）建议做 **2 个平行重复**，同时考察工艺重现性和克隆间的差异；
- 在**一致的既定工艺**（平台工艺条件）下运行，排除工艺变量的干扰，专注于克隆本身的差异。

**第二阶段：多维度克隆综合评价**

克隆评价不应仅基于表达量，须建立基于**打分系统**的综合评价体系（>10 个指标）：

| 评价维度 | 核心指标                                   | 高风险信号（须谨慎）                               |
| -------- | ------------------------------------------ | -------------------------------------------------- |
| 细胞生长 | IVCD（积分活细胞密度）、峰值细胞密度       | 超高细胞密度（>50×10⁶ cells/mL，可能预示放大问题） |
| 细胞健康 | 活率下降曲线、细胞凋亡率                   | 快速活率下降（预示细胞适应差）                     |
| 代谢特征 | 乳酸产量、氨积累量、葡萄糖消耗量           | 高乳酸（>4 g/L）、高氨（>5 mM），影响 pH 控制      |
| 氧气需求 | 比耗氧速率（OUR）                          | 高耗氧量（放大时可能引起溶氧控制困难）             |
| 产品产量 | 蛋白表达量（Titer）和 Qp（比生产速率）     | 低 Qp 在高密度下维持表达量                         |
| 产品质量 | 糖型、聚体、电荷变体                       | 异常高的聚体水平（> 5%）                           |
| 放大风险 | 工艺重现性（2 个重复的 CV%）、CO₂ 分压预测 | CV% > 15%，预示工艺稳定性差                        |

**第三阶段：工艺优化（OFAT 或小型 DoE）**

- 第一轮克隆筛选通常会暴露工艺中不够理想的地方（如 pH 控制不稳定、活率下降过快）；
- 进行 1～3 轮小反应器工艺优化，常见优化因素：pH 控制策略（静态 vs. 梯度）、通气策略（CO₂ 控制、溶氧设定）、接种密度和降温时机（从 37℃→33℃ 等降温对提高 Qp 有帮助）；
- 若有与反应器表现匹配的**摇瓶替代系统**（如 TubeSpin、Erlenmeyer），可在摇瓶中完成部分因子筛选，节约时间。

**第四阶段：工艺确认与放大（Pre-GMP 规模）**

- 工艺优化后，通常在**实验室最大规模（15 L 反应器）**进行工艺确认；
- 工艺确认须使用与放大生产中相同的细胞库（MCB 或 WCB）；
- 种子链设计（扩种容器类型、扩种步骤数）须尽量与最终生产规模的种子链匹配；
- 工艺确认成功后，进行规模放大（200 L → 2000 L），生产 2 批 IND 申报所需的样品（毒理批 + GMP 临床批）。

**平台工艺的战略价值（加速 IND Timeline）**

- 成熟的平台工艺（如已有多个项目验证的 CHO Fed-batch 工艺）可以**跳过大部分工艺开发步骤**，直接从克隆筛选过渡到工艺确认，大幅节约 2～4 个月时间；
- 平台工艺的先验知识还可支持 IND 申报中减少实验性数据（引用平台数据支持参数选择的合理性）。

:::

## 缩短临床前 IND Timeline 的上游工艺策略：平台工艺放大与细胞株稳定性研究加速

:::answer

**IND Timeline 的瓶颈识别**

生物药 IND 项目的标准周期约为 18 个月，细胞培养工艺开发和细胞株稳定性研究是两个最常见的关键路径（Critical Path）限速步骤。以下两类策略可系统性地压缩这两个瓶颈。

**策略一：采用平台工艺进行快速放大**

**标准流程（无平台工艺）：**

```
克隆筛选（1L/3L）→ 工艺开发（多轮优化）→ 工艺确认（15L）
→ 放大（200L）→ 放大（2000L，PPQ 前规模）→ IND 样品生产
（总耗时：10～12 个月）
```

**平台工艺加速流程：**

```
克隆筛选（1L/3L，在平台工艺条件下筛选）
→ 工艺确认（15L，直接在平台工艺下确认）
→ 放大（200L → 2000L）→ IND 样品生产
（总耗时：6～8 个月）
```

**节约时间的关键：** 跳过多轮工艺开发优化周期，利用平台先验知识直接确认克隆在规模化生产中的表现。

**策略二：缩短细胞株稳定性研究时间**

细胞株稳定性研究（通常需要研究至 EOPC 对应的最高 PDL，周期 5～8 个月）是 IND Timeline 中最典型的限速步骤。

**加速策略一：提高传代扩增倍数缩短实时时间**

- 通过优化接种密度和传代间隔，提高每次传代的 PDL 增量（每次传代增加 3～4 PDL 而非 2～3 PDL）；
- 在相同实时时间内完成更多 PDL 的积累，压缩研究周期。

**加速策略二：稳定性研究与毒理批生产并行**

- 将细胞株稳定性研究的进行期与毒理样品的生产、毒理研究的执行**并行推进**，而非顺序执行；
- 稳定性研究完成后，结合毒理批的表达数据，综合判断细胞株稳定性。

**风险认知**

> **须注意：** 细胞株不稳定性具有随机性。若过早锁定细胞株（稳定性研究尚未完全确认），后期发现不稳定则须重选克隆，反而可能增加总时间成本。须根据具体项目的分子特性和历史平台经验评估风险后决策。

**加速策略三：并行下游开发**

上游工艺开发期间，利用**转染细胞混合池（Clonal Pool）**生产的蛋白原料，同步启动：

- 下游纯化工艺开发（Protein A 等平台层析步骤的初步确认）；
- 分析方法开发（建立效价、纯度、聚体等关键方法）；
- 制剂处方开发（初步稳定性筛选）。

:::

## 临床阶段细胞培养工艺开发的目标转变：从快速交付到工艺理解深度的系统建立

:::answer

**临床前 vs. 临床阶段工艺开发的本质差异**

随着产品从临床前进入 I、II、III 期临床，受试者从少数健康志愿者扩展到越来越多的患者，**产品质量的可靠性和批间一致性要求大幅提升**，工艺开发的目标和深度也须相应升级。

**两个阶段的系统对比**

| 维度             | 临床前工艺开发                 | 临床阶段工艺开发                                             |
| ---------------- | ------------------------------ | ------------------------------------------------------------ |
| **核心驱动**     | 速度（快速产生毒理/临床样品）  | 深度（系统理解工艺，建立稳健性证据）                         |
| **知识来源**     | 主要依赖平台先验知识和经验     | 须通过系统实验（DoE）建立产品/工艺特异性知识                 |
| **工艺研究深度** | 简单的 OFAT 工艺开发和工艺确认 | 系统 DoE：研究各参数（pH、DO、温度、补料策略等）的多变量影响 |
| **参数控制**     | 经验性设定目标值和操作范围     | 基于实验数据确定 PAR（Proven Acceptable Range）和设计空间    |
| **工艺验证**     | 通常无正式 PPQ 要求            | 商业化前须完成 PPQ（≥3 批次连续验证）                        |
| **申报要求**     | IND 阶段提供基本工艺描述       | BLA 阶段须提供完整工艺表征报告（CPP、PAR、设计空间）         |

**临床阶段工艺开发的核心研究内容**

**第一步：工艺表征（Process Characterization, PC）**

- 利用已确认的缩小模型，通过 DoE 系统研究关键工艺参数（CPP）对关键质量属性（CQA）的定量影响；
- 识别 CPP（如培养 pH 对岩藻糖化比例的影响）、KPP（重要但非关键参数）和 GPP（一般工艺参数）；
- 建立 CPP-CQA 定量关系（为 PAR 设定和设计空间建立提供数据基础）。

**第二步：设计空间的确立（如采用增强开发方法）**

- 基于 PC 数据，定义多维参数空间中能保证 CQA 满足要求的有效区域（设计空间）；
- 设计空间须在 BLA 申报资料中提交，并获得监管机构的正式批准（批准后，设计空间内的参数变化不视为变更）。

**第三步：工艺性能确认（PPQ）**

- 商业化规模，连续 3 批成功验证，确认工艺在 PAR 内的稳健性；
- PPQ 须在预定验收标准下进行，不能事后修改接受标准。

:::

## 单抗药物 Fab/Fc 双功能结构的作用机制体系：三类 Fc 效应功能的分子基础

:::answer

**单克隆抗体的双功能结构**

单克隆抗体（mAb）由两个关键结构域构成，各自承担不同的功能：

```
┌─────────────────────────────────┐
│  Fab 段（抗原结合片段）           │
│  ├── 轻链（VL + CL）            │
│  └── 重链 N 端（VH + CH1）      │
│  功能：特异性识别靶抗原，         │
│  决定抗体的靶点特异性             │
├─────────────────────────────────┤
│  铰链区（Hinge Region）          │
│  功能：赋予 Fab 臂柔性            │
├─────────────────────────────────┤
│  Fc 段（可结晶片段）              │
│  ├── 重链 CH2 域                │
│  └── 重链 CH3 域                │
│  功能：与 Fc 受体/补体结合，       │
│  介导免疫效应功能                 │
└─────────────────────────────────┘
```

**三类 Fc 效应功能的分子机制**

**① ADCC（抗体依赖性细胞毒性，Antibody-Dependent Cellular Cytotoxicity）**

- **关键受体：** 自然杀伤细胞（NK 细胞）表面的 <strong>FcγRIIIa（CD16a）</strong>；
- **机制：** 抗体 Fab 结合靶细胞抗原 → Fc 与 NK 细胞 FcγRIIIa 结合 → NK 细胞释放穿孔素/颗粒酶 → 靶细胞凋亡；
- **糖型影响：** 去岩藻糖化 Fc（无岩藻糖）与 FcγRIIIa 亲和力提升 50～100 倍 → ADCC 活性大幅增强；
- **代表药物：** 奥比妥珠单抗（去岩藻糖化，增强 ADCC）、奥法木单抗。

**② ADCP（抗体依赖性细胞吞噬，Antibody-Dependent Cellular Phagocytosis）**

- **关键受体：** 巨噬细胞和中性粒细胞表面的 **FcγRI（CD64）、FcγRIIa（CD32a）**；
- **机制：** 抗体 Fab 结合靶细胞 → Fc 与巨噬细胞 Fc 受体结合 → 巨噬细胞吞噬靶细胞 → 溶酶体降解；
- **意义：** 尤其对实体瘤内部（NK 细胞难以渗透的区域）的肿瘤细胞清除具有重要贡献。

**③ CDC（补体依赖性细胞毒性，Complement-Dependent Cytotoxicity）**

- **关键蛋白：** C1q（补体经典途径的启动分子）；
- **机制：** 抗体 Fc CH2 区 → C1q 识别六聚化 Fc → 补体级联（C4→C2→C3→C5→MAC）→ 靶细胞膜穿孔裂解；
- **亚类差异：** IgG3 > IgG1 >> IgG2 ≈ IgG4（CDC 活性从强到弱）；
- **代表药物：** 利妥昔单抗（B 细胞 CD20，显著 CDC）、奥法木单抗（增强 CDC 设计）。

**Fc 效应功能的定向工程化**

根据适应症的需求，可通过以下手段调节各 Fc 效应功能：

| 工程化手段                   | 效果                          | 典型应用                         |
| ---------------------------- | ----------------------------- | -------------------------------- |
| FUT8 基因敲除（去岩藻糖化）  | ADCC ↑↑（10～100 倍）         | 肿瘤治疗（需强 ADCC）            |
| Fc 氨基酸突变（S239D/I332E） | ADCC ↑、ADCP ↑                | 肿瘤治疗增效                     |
| 末端半乳糖含量提升           | CDC ↑                         | B 细胞肿瘤（需强 CDC）           |
| LALA 突变（L234A/L235A）     | ADCC ↓、CDC ↓（效应功能沉默） | 自身免疫（减少免疫活化相关毒性） |

:::

## N-糖末端结构与 CDC 活性的定量关系：半乳糖、高甘露糖与唾液酸修饰的作用机制

:::answer

**N-糖末端结构是 CDC 活性的精细调控开关**

抗体 Fc 区 CH2 域的 Asn297 位点 N-糖修饰，不仅影响 ADCC（岩藻糖化），还通过末端糖基结构（特别是半乳糖和唾液酸）精细调控 CDC 活性，且这两类效应的调控机制相互独立。

**半乳糖修饰（G0/G1/G2）与 CDC 的定量关系**

Fc N-糖的末端可携带 0、1 或 2 个半乳糖残基，分别称为 G0F（无末端半乳糖）、G1F（一个末端半乳糖）和 G2F（两个末端半乳糖）：

| 糖型 | 末端半乳糖数量 | CDC 活性             | ADCC 活性 | FcRn 结合/半衰期 |
| ---- | -------------- | -------------------- | --------- | ---------------- |
| G0F  | 0              | **最低**（基线）     | 不影响    | 不影响           |
| G1F  | 1              | **中等**（升高）     | 不影响    | 不影响           |
| G2F  | 2              | **最高**（显著升高） | 不影响    | 不影响           |

**机制：** 末端半乳糖通过**增加抗体 Fc 与 C1q 的结合亲和力**来增强 CDC，而不影响与 FcγRIIIa 的结合（因此对 ADCC 无影响）——半乳糖修饰是 CDC 和 ADCC 的**独立调控轴**。

**实验证据（利妥昔单抗）：**

> 去除利妥昔单抗 Fc N-糖的末端半乳糖（从 G1F/G2F 变为 G0F），可使其 CDC 活性**减少约一半**，而 ADCC 活性不变。

这一发现强调了在生产工艺中监控**末端半乳糖水平**（G1F + G2F 的比例）对于 CDC 依赖型单抗的质量控制具有重要意义。

**工艺调控半乳糖水平的策略**

在细胞培养和纯化过程中，可通过以下手段提升末端半乳糖水平：

- 添加**尿苷（Uridine）：** 增加 UDP-半乳糖供体的供应；
- 添加**氯化锰（MnCl₂）：** 激活高尔基体中的半乳糖基转移酶活性；
- 添加**半乳糖：** 直接补充底物。

研究表明，在 GS-CHO 流加培养中，通过调节尿嘧啶、氯化锰和半乳糖的浓度，可显著提升 N-糖末端半乳糖水平。

**高甘露糖型 N-糖与 CDC 的关系**

高甘露糖型（Man5/Man8/Man9）N-糖由于末端不含半乳糖，其 CDC 活性与 G0F（无半乳糖）相当（较低），且因甘露糖受体介导的快速清除导致**半衰期缩短**。

**唾液酸修饰（高唾液酸 N-糖）与 CDC 的关系**

含有高唾液酸修饰的 N-糖（唾液酸末端覆盖半乳糖位点），其 CDC 活性**降低**，可能机制为：

- 唾液酸的负电荷可能空间性地阻碍 C1q 与 Fc 的结合；
- 唾液酸修饰同时降低与 FcγRIIIa 的结合（ADCC 也降低），但通过减少非特异性清除延长半衰期。

**当前知识的局限性**

> 目前**仅有利妥昔单抗**的 Fc N-糖末端半乳糖水平与 CDC 活性关系的详细报道。这一关联是否在所有靶向不同抗原的单抗上均成立，仍需针对各具体产品进行个案验证，不可盲目外推。

:::

## 化学仿制药与生物类似药的临床研究差异：生物等效性研究的局限与更严格相似性要求

:::answer

**核心差异：化学仿制药 vs. 生物类似药的评价逻辑根本不同**

| 比较维度                             | 化学仿制药（Generic Drug）                               | 生物类似药（Biosimilar）                                                                               |
| ------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **活性成分特征**                     | 与原研药有效成分**完全相同**（化学结构确定，可精确复制） | 与参照药高度**相似但不完全相同**（蛋白结构复杂，批间存在固有变异）                                     |
| **临床评价策略**                     | 人体药动学**生物等效性研究（BE 研究）**                  | **全面的药学相似性研究**（分析特征化）+ 必要的非临床和临床研究                                         |
| **为何 BE 研究不足以评价生物类似药** | —                                                        | 单一 PK 参数（AUC/Cmax）不能全面反映复杂蛋白分子的安全性和有效性特征；免疫原性差异无法通过 BE 研究检测 |
| **临床试验起点**                     | 直接 BE 研究（无需重复 I～III 期）                       | 须通过 PK 等效性研究（PK Bioequivalence）+ 必要的临床有效性相似性研究                                  |
| **申报路径（美国）**                 | ANDA（Abbreviated New Drug Application）                 | BLA 351(k)（Abbreviated Biologics License Application）                                                |

**生物类似药临床开发的"阶梯式证据"策略**

```
第一步：全面的药学可比性研究（Analytical Similarity）
（理化/生化特征、生物学活性的多维头对头比较）
        ↓
第二步：临床药代动力学（PK）等效性研究（Clinical PK Bridging）
（通常为交叉设计，确认 AUC、Cmax 等效性）
        ↓ 若药学相似性已充分支持，且 PK 等效，可减少后续临床数据要求
第三步：临床有效性和安全性等效性研究（Clinical Efficacy Equivalence）
（等效性比对试验，仅在必要时要求）
```

**生物类似药不需要重新进行剂量探索的原因**

由于生物类似药与参照药的**使用剂量和给药方案完全相同**（剂量已由参照药的原研临床开发确定），生物类似药开发商**无须重新开展剂量探索的早期临床试验（I/II 期剂量研究）**，可直接开展 PK 等效性和（必要时）疗效等效性研究。

**主要监管机构的法规框架**

| 地区/机构    | 核心法规                                                        | 特点                                        |
| ------------ | --------------------------------------------------------------- | ------------------------------------------- |
| 美国（FDA）  | BPCIA（2010），PHS Act § 351(k）                                | 12 年生物制品独占期；需经历完整的相似性研究 |
| 欧盟（EMA）  | EMA 生物类似药指南（2004 年首发，持续更新）                     | 全球最早建立生物类似药监管体系，经验最丰富  |
| 中国（NMPA） | 《生物类似药研发与评价技术指导原则（试行）》（2015，2022 更新） | 参照 EMA/FDA 框架，结合国内实际             |
| ICH          | ICH Q5E（生物技术产品可比性）                                   | 可比性研究的核心国际标准                    |

:::

## 生物类似药临床试验与适应症外推：等效性比对设计原则与多适应症外推的科学依据

:::answer

**生物类似药临床相似性研究的核心目标**

生物类似药临床试验作为相似性评估的**最后一步（Confirmatory Step）**，旨在**解决在药学和非临床研究阶段仍存在的残余不确定性（Residual Uncertainty）**，而非从头证明安全性和有效性（这已由参照药的历史临床数据证明）。

**相似性临床研究的核心设计要求**

| 设计要素     | 要求                                                                   | 理由                                                               |
| ------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **研究人群** | 须在**能检测到产品相关临床差异的敏感人群**中进行                       | 低敏感性人群可能掩盖真实差异（假阴性结论）                         |
| **临床终点** | 须选用**对产品活性差异最敏感的终点指标**                               | 通常非最终临床终点（OS），而是 ORR、PFS 等可更快检测差异的替代终点 |
| **研究目的** | 证明生物类似药与参照药在临床上**无有意义的差异**（等效性，而非优效性） | 等效性检验（Two One-Sided Tests, TOST）                            |
| **样本量**   | 通常**小于**原研创新药的 III 期临床                                    | 无需重新确证疗效，只须排除有临床意义的差异                         |

**参照药的选择原则（单一参照药原则）**

- 整个生物类似药研发项目须使用**单一参照药**（确保研究的科学一致性）；
- EMA 允许使用在 EEA 以外获批（但在 ICH 国家获批）的参照药，前提是须通过"桥接研究"证明两者（EEA 内外参照药）的等同性；
- **桥接研究的必要组成：** 三个产品（生物类似药 + EEA 内参照药 + 非 EEA 参照药）的药学分析和体外研究的头对头比较，必要时包含临床 PK/PD 比对数据。

**适应症外推（Extrapolation of Indications）的科学逻辑**

适应症外推是生物类似药独有的重要机制——通过在**一个适应症**中证明相似性后，可能**外推至参照药已批准的其他适应症**，而无需在每个适应症中单独进行临床研究。

**适应症外推的科学前提**

| 前提条件                             | 说明                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------ |
| 参照药的作用机制在各适应症中相同     | 如利妥昔单抗在 B 细胞淋巴瘤和类风湿关节炎中均通过 CD20-ADCC/CDC 发挥作用 |
| 药学相似性和非临床数据充分支持       | 各效应功能（ADCC、CDC、靶点结合）均已在药学研究中证明相似                |
| 安全性特征已在充分暴露的人群中评估   | 若某适应症的患者需要更高剂量（更高暴露），安全性外推须格外谨慎           |
| 已批准适应症的患者群体中有足够的数据 | 免疫系统状态（如肿瘤患者 vs. 自身免疫患者）差异须在外推时充分讨论        |

**适应症外推的监管立场**

- **EMA 和 FDA** 均接受基于科学的适应症外推，但需要针对每个外推适应症提供具体的科学理由；
- 若外推适应症涉及的**作用机制**与已研究适应症**根本不同**（如从 ADCC 依赖型肿瘤外推至受体阻断型适应症），则不能简单外推，须另行临床研究。

:::

## 生物类似药非临床研究策略：体内毒理学研究的必要性评估与体外数据的优先应用

:::answer

**生物类似药非临床研究的定位**

生物类似药的非临床研究策略与原研创新药**根本不同**——创新药的非临床研究旨在首次建立安全性数据包；而生物类似药的非临床研究**服务于比较目的**（发现与参照药之间的差异），不需要重新建立完整的安全性数据。

**欧盟 EMA 的最新监管立场（主流导向）**

> 欧盟监管机构根据丰富的审评经验认为：**在一般情况下，生物类似药不需要开展体内毒理学研究（In Vivo Toxicology Studies）**。

这一立场的科学依据是：

- 综合分析和比较**体外功能数据**（如受体结合、细胞效力、ADCC/CDC）比体内动物实验能**更敏感地检测到产品相关差异**；
- 动物毒理学研究中，ADA（抗药抗体）的产生可能混淆毒理学解读（生物类似药在动物体内可能被识别为外源蛋白）；
- 充分的药学可比性数据（在分析层面已证明高度相似）可以取代体内毒理学研究的部分信息价值。

**生物类似药非临床研究的推荐内容**

| 研究类型                                      | 建议                                                                                   | 优先级                   |
| --------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------ |
| **体外比较功能研究**                          | 须进行：结合亲和力（SPR）、细胞效力（细胞增殖抑制/激活）、Fc 效应功能（ADCC/CDC 检测） | **最高**（通常必须）     |
| **体内 PK/PD 比较研究**（如相关动物种属存在） | 视药学和体外数据的充分性决定，通常在相关动物种属中进行单剂量比较                       | 中等（具体情况具体分析） |
| **体内重复给药毒理学研究**                    | EMA 通常认为**不必要**（仅在体外数据不足以解答特定安全性问题时才考虑）                 | 通常豁免                 |
| **遗传毒性/生殖毒性研究**                     | 通常不需要（生物类似药的安全性特征已由参照药临床数据证明）                             | 通常豁免                 |

**何时仍须开展体内非临床研究**

尽管 EMA 总体上不要求体内毒理学研究，但以下情形可能触发体内研究需求：

- 药学可比性研究发现了无法通过体外研究解释的差异；
- 生物类似药含有创新性辅料或递送系统（与参照药不同）；
- 靶标或作用机制的特殊性使得体内研究对安全性评估不可替代。

:::

## III 期临床适应症可行性评估：多适应症场景下的研究人群选择与注册策略

:::answer

**III 期临床适应症选择的战略重要性**

当参照药（对于生物类似药）或被研究药物（对于创新药）已获批或拟获批多个适应症时，须在开展 III 期注册用等效性/确证性临床试验之前，系统评估**哪个适应症最适合作为注册临床试验的研究场景**。这一决策直接影响试验的可行性、速度和后续适应症外推的可能性。

**适应症可行性评估的五个核心维度**

**维度一：疾病发病率与患者可及性**

| 评估问题                                     | 核心考量                                             |
| -------------------------------------------- | ---------------------------------------------------- |
| 目标国家/地区该适应症的患病率是多少？        | 发病率过低（如罕见病）→ 入组困难 → 延误 III 期时间线 |
| 目标人群是否集中在可参与临床研究的医疗机构？ | 分散 → 多中心入组效率低                              |
| 该适应症是否有竞争性临床试验？               | 同期竞争研究多 → 患者分流 → 入组缓慢                 |

**维度二：治疗方案的地区适用性**

- 参照药/候选药在该适应症中的使用方案（剂量、给药频率、联合用药）须符合**试验所在地区的当地临床常规**；
- 若参照药的批准适应症在某国使用剂量或给药方案与其他地区不一致（如 SC 给药 vs. IV 给药），则须评估此差异对等效性比较的影响。

**维度三：临床终点的敏感性**

- 须选择**对产品相关差异最敏感**的临床终点；
- 不同适应症的标准临床终点敏感性差异很大：例如，ORR（较短时间可观察到差异，敏感性高）优于 OS（随访时间长，被混杂因素稀释）；
- 对于生物类似药，选择**能在相对小的样本量内检测到产品相关差异**的适应症，可显著降低试验的时间和成本。

**维度四：等效性界值的可行性**

- 等效性试验的界值（Equivalence Margin, Δ）须在临床上有意义且统计上可实现；
- Δ 的设定须基于参照药疗效的 Meta 分析估算，并结合临床意义确定；
- 若参照药在该适应症中的疗效本身变异性很大（CI 宽），则 Δ 设定困难，可能导致样本量估计失真。

**维度五：适应症外推的可能性**

- 若成功完成 III 期注册试验的适应症机制具有代表性（如 Fab 和 Fc 效应功能均在此适应症中充分评估），则可支持外推至其他适应症；
- 规划 III 期时即应前瞻性考虑适应症外推策略，选择**外推价值最高**的适应症作为注册研究场景。

**生物类似药 III 期适应症选择的决策框架**

```
Step 1：列出参照药已批准的全部适应症
        ↓
Step 2：根据五个维度对各适应症打分（发病率/方案适用性/终点敏感性/Δ可行性/外推价值）
        ↓
Step 3：确定"锚定"适应症（综合评分最高，用于注册 III 期研究）
        ↓
Step 4：基于"锚定"适应症的机制代表性，评估可外推的其他适应症
        ↓
Step 5：与监管机构（EMA/FDA/NMPA）就适应症选择和外推策略进行正式沟通（Type B 会议或 Scientific Advice）
```

:::
