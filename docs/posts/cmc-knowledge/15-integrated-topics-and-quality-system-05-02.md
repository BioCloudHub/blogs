## 上市申请阶段的 CMC 分析方法与质量标准要求

:::answer

上市申请（BLA/NDA）阶段的分析方法和质量标准要求是整个药物开发周期中最为严格的阶段，须在临床试验积累的数据基础上进行系统性整合和完善。

**分析方法的申报要求**

研究者须在上市申报资料中提供：

- **完整的分析方法文件：** 方法原理、操作步骤、系统适用性要求、结果计算方法
- **方法学验证报告：** 覆盖 ICH Q2R1 规定的所有适用验证参数（专属性、准确性、精密度、线性、范围、检测限、定量限、耐用性）
- **临床试验期间方法学优化总结：** 对方法从 IND 到 BLA 阶段的演进历程进行系统梳理
- **方法科学性、合理性、可行性论证：** 充分表明分析方法符合检测目的和要求

**质量标准的修订与对比**

上市申请须提供不同阶段质量标准的系统对比和修订依据：

```
质量标准演进路径：

IND 申报质量标准
    ↓（基于初步批次数据 + 文献参考，范围相对宽泛）
临床试验各阶段质量标准
    ↓（随工艺优化和批次积累逐步收紧）
拟上市质量标准
    ↓（基于充分批次数据 + 临床相关性 + 稳定性数据）
上市后质量标准更新
    （累积 25～30 批以上数据后修订）
```

修订依据须综合包含：
- **工艺能力数据：** 多批次生产的实际检验数据（统计分析，建立操作区间）
- **批放行历史数据：** 放行数据的分布规律和趋势
- **非临床和临床研究结果：** 支持质量属性与临床效果关联性的数据
- **稳定性研究数据：** 证明在货架期内质量标准的合理性
- **分析方法变异性：** 确保质量标准限度覆盖方法本身的测量不确定度

**CDE 重点关注的 8 个 CMC 关键模块**

| 序号 | CMC 模块 | 核心关注点 |
|---|---|---|
| 1 | 临床试验用药物制备 | 制备方法的充分性和代表性 |
| 2 | 细胞库 | MCB/WCB/EOPC 检定的完整性 |
| 3 | 生产用原材料 | 动物源性材料的安全性评估 |
| 4 | 生产工艺和过程控制 | CPP 识别和控制策略的科学性 |
| 5 | 病毒灭活/去除验证 | 正交策略和清除因子的充分性 |
| 6 | 质量研究 | 产品表征的全面性和代表性批次 |
| 7 | 稳定性研究 | 货架期支持数据的充分性 |
| 8 | 容器密闭系统 | 相容性研究的完整性 |

## 工艺表征（PC）与工艺验证（PV）的逻辑关系：PC 是 PV 的科学依据

:::answer

工艺表征（Process Characterization，PC）和工艺验证（Process Validation，PV）是生物药商业化生产体系建立的两个紧密相连但功能不同的阶段，二者的先后顺序和逻辑关联须清晰理解。

**明确结论：PV 之前必须开展 PC 研究**

PC 研究的核心目的是为 PV 的工艺参数设定提供科学依据——没有 PC 数据的支撑，PV 的参数设定将缺乏科学基础，PV 的意义也将大打折扣。

**PC 与 PV 的角色分工**

```
工艺表征研究（PC / Process Characterization）：
  ├─ 目的：理解工艺参数与产品质量属性的关系
  ├─ 方法：规模缩小模型（Scale-down Model）+ DoE 实验设计
  ├─ 输出：CPP 识别、操作范围（NOR）、可接受范围（PAR）、设计空间
  └─ 阶段：工艺开发后期至 BLA 申报前（Stage 1）

工艺验证（PV / Process Qualification）：
  ├─ 目的：证明以已确定的参数设定可重复生产合格产品
  ├─ 方法：商业化规模批次（通常 ≥3 批 PPQ 批次）
  ├─ 输出：工艺验证报告，证明工艺处于受控状态
  └─ 阶段：BLA 申报前完成（Stage 2）
```

**PC 研究的前提：分析方法须经过至少确认**

用于 PC 研究的分析方法无需达到完整验证（Validation）的状态，但至少须经过**方法确认（Verification）**：

- 确认方法的适用性（在本实验室条件下可可靠执行）
- 确认方法的精密度和准确性满足研究目的
- 确认方法能够区分不同工艺条件下的质量差异

> **实践建议：** PC 研究结果直接决定 PV 的参数设定点（Set-point）和操作范围（NOR），因此 PC 研究质量越高，PV 成功率越高。投资 PC 研究实际上是在降低 PV 失败的风险和成本。

:::

## 仿制原料药与原研原料药可比性研究的替代策略

:::answer

当原研原料药难以获得时，仿制药的可比性研究须采用替代策略，并在申报材料中进行规范的关联申报和信息填写。

**申报表填写要求**

申请人须在制剂申请表"同品种已被受理或同期申报的原料药、制剂或不同规格品种"项中填写：

| 填写内容 | 具体要求 |
|---|---|
| 关联原料药 | 受理号/登记号及名称 |
| 关联辅料 | 受理号/登记号及名称 |
| 关联药包材 | 受理号/登记号及名称 |
| 关联制剂（不同规格）| 受理号/登记号及名称 |
| 临床申请信息（完成临床后上市）| 原临床申请受理号、临床试验批件号、临床试验登记号或 BE 试验备案号 |

**原研原料药难以获得时的可比性研究替代路径**

当无法直接获取原研原料药进行对比研究时，可考虑以下替代策略：

**策略一：使用市售参照药（制剂）进行间接比较**

- 对市售的原研制剂进行分析（从制剂中提取或直接分析）
- 明确说明分析方法对提取过程的适用性
- 数据须说明制剂辅料对分析结果的影响已被排除

**策略二：基于文献和公开数据建立参照数据库**

- 收集原研产品的公开临床前和临床数据
- 参考原研产品的 FDA/EMA 审评公开信息
- 建立产品质量属性的参照范围

**策略三：开展桥接研究（Bridging Study）**

- 证明仿制原料药与参照制剂在体外等效性（如溶出度）
- 必要时开展 BE（生物等效性）研究

## 总有机碳（TOC）：定义、水质标准与制药应用

:::answer

总有机碳（Total Organic Carbon，TOC）是评价制药用水有机物污染程度的核心指标，是生物制药生产中注射用水（WFI）和纯化水（PW）质量控制的必检项目。

**TOC 的基本定义**

TOC 是以碳的质量浓度表示水中有机物总量的综合指标，结果以碳（C）的质量浓度（mg/L 或 μg/L，ppb）表示。

- 碳是一切有机物的共同成分和主要元素
- TOC 值越高，说明水中有机物含量越高
- TOC 可作为评价水质有机污染的宏观指标

**TOC 的局限性**

TOC 以 C 计结果，不能反映含 N、S、P 等高含量元素有机物（如含氮杂环化合物）的全部污染，须与其他水质指标综合评估。

**各药典 TOC 水质标准对比**

| 法规来源 | 适用水种 | 限值 | 特殊要求 |
|---|---|---|---|
| **USP（美国药典，1998 年起）** | 注射用水 + 纯化水 | ≤ 0.5 mg/L（500 ppb）| 所有均须检测 |
| **EP（欧洲药典）** | 注射用水（必检）| ≤ 0.5 mg/L | 纯化水可选 TOC 或易氧化物检查（二选一）|
| **JP（日本药典）** | 超滤法制注射用水 | 在线 ≤ 300 ppb；离线 ≤ 400 ppb | 同时考虑塑料包装释放的 TOC 贡献 |
| **ChP（中国药典 2020 版）** | 注射用水（必检）+ 纯化水（可选）| ≤ 500 μg/L | 纯化水可选 TOC 或易氧化物检查；质控实验用水 TOC ≤ 100 μg/L |

**TOC 超标的健康风险**

水中有机物超标可能带来以下健康风险：

- **急性/慢性中毒：** 重金属有机络合物（甲基汞、镉、铅等）通过饮用或食物链进入体内
- **致癌作用：** 全球水体中已识别有机化合物 2000 余种，饮用水中含 769 种，其中 26 种已知致癌物、18 种促癌物、45 种致突变物
- **水传染病：** 生物性污染物（粪便中病原体）进入水体，引发伤寒、痢疾、霍乱等肠道传染病

**TOC 测试误差的常见来源**

- **颗粒物干扰：** TOC 进样时液体不经过滤膜直接进入，若样品含有小颗粒或沉淀，颗粒携带的有机物也会被测入，导致结果偏高
- **进样管路污染：** 仪器内部管路的有机物残留（若清洗不充分）
- **标准溶液老化：** TOC 标准溶液（通常为蔗糖或苯二甲酸氢钾）存放时间过长导致浓度变化
- **系统水空白不稳定：** 系统水（用于稀释和系统冲洗）的 TOC 背景值波动

**在生物制药生产中的特殊应用**

- **清洁验证：** TOC 作为清洁验证的非专属性指示物，用于证明清洁后残留有机物水平符合要求
- **WFI 系统在线监测：** 连续 TOC 监测可实时反映 WFI 制备和分配系统的有机物控制状态
- **批放行检测：** 注射用水批次放行须符合 TOC 限值

:::

## 生物制品质量属性的系统分类与全面表征框架

:::answer

质量属性（Quality Attribute，QA）是产品质量研究的核心对象，系统理解其分类体系，是建立产品表征方案和质量标准的基础。

**质量属性的标准定义**

质量属性是指物理、化学、生物学、微生物学等特性，其变化会对产品的安全性和有效性产生潜在影响。全面的质量属性表征是产品质量标准制定的重要基础。

**生物制品质量属性的三大类别**

**第一类：产品相关物质/杂质**

| 子类别 | 定义 | 典型示例（单抗）| 典型示例（疫苗）|
|---|---|---|---|
| 产品相关物质 | 分子变异体，活性与目标产品可比，视为产品组成部分 | 脱 C-端赖氨酸变体、N 端焦谷氨酸化 | 特定糖型的抗原蛋白 |
| 产品相关杂质 | 分子变异体，活性/有效性/安全性与目标产品不可比 | 聚集体、降解片段、电荷异构体（非预期的）、疏水变体 | 无活性病毒颗粒、包装不完整的 VLP |

**第二类：工艺相关杂质**

| 来源 | 典型杂质 |
|---|---|
| 细胞基质 | 宿主细胞蛋白（HCP）、宿主细胞 DNA（HC-DNA）|
| 细胞培养物 | 诱导剂、抗生素、培养基成分残留 |
| 下游工艺 | Protein A 浸出物、有机试剂残留、层析填料碎片 |

**第三类：组成及含量**

- **重组蛋白产品：** 蛋白质含量（通常采用 A280 法或 BCA 法）
- **疫苗产品：** 抗原含量（ELISA 或功能性测定）
- **检测方法：** 适宜的物理化学方法（如 UV 分光法）和/或免疫化学方法（如 ELISA）

**质量属性研究的方法体系**

| 质量属性类别 | 分析方法 |
|---|---|
| 一级结构（序列）| 肽图（LC-MS/MS）、N/C 端测序 |
| 大小变异体 | SEC-HPLC、SDS-PAGE（还原/非还原）、CE-SDS |
| 电荷变异体 | CEX-HPLC、iCIEF |
| 糖基化 | HILIC-UPLC、LC-MS 糖型分析 |
| 高级结构 | CD 光谱、DSC、HX-MS |
| 生物学活性（效价）| 细胞法（细胞增殖抑制、ADCC、CDC）、ELISA、SPR |
| 工艺相关杂质 | HCP-ELISA、qPCR（HC-DNA）、Protein A ELISA |

:::

## 产品质量属性与放行检测项目的生命周期管理

:::answer

产品质量属性的检测项目并非固定不变，而是随研发阶段的推进、工艺知识的积累和监管法规的更新持续动态调整，须建立系统化的生命周期管理机制。

**检测项目动态调整的驱动因素**

| 调整驱动因素 | 具体情形 | 相应行动 |
|---|---|---|
| 产品认知深化 | 发现新的 CQA 或新的杂质类型 | 建立新的检测项目，开发对应方法 |
| 工艺放大变更 | 放大导致产品相关物质/杂质分布变化 | 评估现有标准的适用性，必要时修订 |
| 原材料变更 | 新供应商引入新的工艺杂质 | 增加针对新杂质的检测项目 |
| 法规更新 | 新发布的指导原则对检测项目提出新要求 | 按要求补充相应检测 |
| 稳定性数据积累 | 发现新的降解途径和降解产物 | 将明显降解产物纳入质量标准 |

**不同研发阶段的检测项目成熟度**

```
临床前阶段：
  基础安全性检测项目（无菌、内毒素、含量、外观）
  初步纯度检测（SEC 单体含量）
    ↓
I 期临床阶段：
  增加生物学活性测定
  增加关键杂质检测（HCP、HC-DNA）
  初步建立电荷变异体检测
    ↓
II/III 期临床阶段：
  系统建立产品相关杂质检测
  完善工艺相关杂质检测体系
  建立稳定性指示性方法
    ↓
上市申请（BLA/NDA）：
  完整的产品质量属性检测体系
  所有放行检测方法经过完整验证
    ↓
上市后（商业化阶段）：
  持续监控（CPV），随批次积累优化标准
  定期质量标准更新（欧美通常累积 30 批或 3 年后更新）
```

**放行检测 vs 表征检测的区别**

| 检测类型 | 频率 | 目的 | 方法状态要求 |
|---|---|---|---|
| **放行检测（Lot Release）** | 每批必检 | 判断批次合格/不合格 | 须完整验证（Validated）|
| **工艺监控（Process Monitoring）** | 定期（如每季度）| 趋势分析，发现工艺漂移 | 须确认（Verified）|
| **表征检测（Characterization）** | 工艺变更时/定期 | 深入产品理解，支持变更评估 | 须确认或验证 |
| **可比性检测（Comparability）** | 工艺变更前后 | 证明变更前后产品质量相似 | 须完整验证 |

## 可接受标准的制定原则：数据驱动与临床关联的双重维度

:::answer

可接受标准（Acceptance Criteria）是质量标准的核心，其科学性和合理性直接影响产品的放行决策和质量保证水平。

**可接受标准的定义**

可接受标准是指原液、制剂或生产中间阶段的样品应符合的数值限度、范围或其他适宜的测量值，是判定批次合格与否的法规依据。

**两类可接受标准的制定逻辑**

**第一类：通用安全性项目（不得低于药典要求）**

对于安全性相关的常规项目，产品限度须至少满足药典规定：

| 项目 | 典型药典限度 | 参考标准 |
|---|---|---|
| 宿主细胞 DNA 残留 | ≤ 10 ng/剂（WHO 建议）| WHO Technical Report |
| 细菌内毒素 | 注射用制剂通常 < 0.5 EU/mL | 中国药典/USP |
| 无菌 | 符合无菌检查法要求 | 中国药典/USP |
| 微生物限度（原液）| 通常 ≤ 10 CFU/mL | 企业内控为主 |

**第二类：产品特异性项目（须基于数据制定）**

产品相关杂质、效价等特异性项目须通过科学数据支撑：

```
制定依据的数据来源（须综合分析）：

① 工艺能力数据：
   多批次批放行数据的统计分析
   确定工艺稳定区间（±3σ 或 ±2σ）

② 临床研究相关性：
   哪些批次用于临床试验？
   这些批次的质量属性值范围是什么？
   → 限度须覆盖临床批次质量属性的历史范围

③ 稳定性数据：
   产品在货架期内的降解趋势
   → 放行标准须预留足够的降解余量，确保货架期末仍符合货架期标准

④ 非临床毒理学数据：
   杂质限度与毒理学安全阈值的关系

⑤ 分析方法变异性：
   方法本身的精密度决定了限度的最小可设定宽度
   → 限度范围不应窄于方法变异性（否则误放行率过高）
```

**统计学方法的应用**

- 利用历史批次数据的均值（μ）和标准差（σ）制定初始限度：通常设置为 μ ± 3σ
- 统计学上，25～30 批数据可较好预测工艺能力
- 积累至 85 批以上时可最终确定稳健的质量标准

:::

## 工艺相关杂质可接受标准的制定：ISF 评估与毒理学依据

:::answer

工艺相关杂质的可接受标准制定须在工艺去除能力和毒理学安全性之间寻求科学平衡，ISF（杂质安全系数）是主要的定量评估工具。

**工艺相关杂质的常见来源与典型示例**

| 来源类别 | 典型杂质 | 控制优先级 |
|---|---|---|
| 细胞培养基质 | HCP、宿主细胞 DNA | 高（须放行检测）|
| 细胞培养添加物 | Pluronic F68、消泡剂、抗生素 | 中（可 ISF 评估后决定）|
| 下游工艺 | Protein A 浸出物、有机试剂（Triton、DMSO）| 中高 |

**ISF 评估的核心公式与判定标准**

```
ISF = LD₅₀ / 每剂产品中的杂质潜在限度

判定标准：
  ISF > 1000 → 安全风险可忽略，可不纳入放行质量标准
              （仅需提供工艺清除数据）
  ISF < 1000 → 须进行工艺去除验证
              或调整生产工艺降低杂质水平
              或开展额外的毒理学研究
```

**当 LD₅₀ 数据缺失时的替代策略**

对于缺少 LD₅₀ 历史数据的杂质：
- 须通过毒理学研究获取 LD₅₀ 数据
- 或通过 NOAEL（无观察到有害作用剂量水平）数据进行评估
- NOAEL 通常为更保守（更小）的安全阈值，与 LD₅₀ 相比更接近临床安全性评估

**有机溶剂残留的特殊规定**

有机溶剂（如 Triton X-100、聚山梨酯-80）残留限度可参照：
- **ICH Q3C 指南：** 按溶剂类别（Class 1/2/3）制定可耐受日摄入量（TDI）限度
- **已上市药品限度参考：** 参照同类已上市产品相同杂质的限度标准

**制定原则的层次优先级**

```
优先级从高到低：

1. 参照药典通用限度（最高权威）
2. 参照已上市同类产品限度（行业惯例）
3. 基于 ISF 评估自行制定（须有毒理学数据支撑）
4. 基于非临床研究数据制定（须有充分的临床前安全性数据）
```

:::

## 可接受标准与稳定性研究的系统整合

:::answer

质量标准中的可接受标准不能独立于稳定性研究数据之外制定，两者须紧密整合，确保在产品货架期内质量始终符合预期。

**稳定性考量对可接受标准的影响**

**① 降解产物须纳入质量标准**

在贮藏过程中，原液和制剂不可避免地会发生不同程度的降解：
- 应对生产过程中和/或贮存过程中产生的**明显降解产物**进行充分分析
- 须将贮存相关的降解产物纳入质量标准（通常以"降解产物 ≤ X%"或"特定降解产物 ≤ Y%"的形式）

**② 放行标准与货架期标准的双重设置**

对于**易受贮存过程影响、变化幅度较大且与安全/有效性相关**的检测项目，建议同时设置两套标准：

| 标准类型 | 时间点 | 通常要求 | 设置目的 |
|---|---|---|---|
| **放行标准（Release Specification）** | 生产完成后立即检测 | 通常比货架期标准更严格 | 确保放行时的质量余量，覆盖货架期的降解 |
| **货架期标准（Shelf-life Specification）** | 整个货架期内有效 | 基于终点质量的临床安全有效性要求 | 确保使用时的最低质量要求 |

**③ 放行标准与货架期标准的差值设计**

```
示例（SEC 单体纯度）：

初始产品：单体纯度 99.5%
稳定性数据显示：2～8℃储存 24 个月后，单体纯度下降约 1.5%

放行标准设计：
  单体纯度 ≥ 98.5%（留有 1.5% 的降解余量）

货架期标准设计：
  单体纯度 ≥ 97.0%（基于临床安全性可接受的最低纯度）
```

**④ 加速稳定性数据的局限性**

须注意：加速稳定性试验结果不能完全替代实时稳定性数据——对于蛋白质类生物药，加速条件下的降解途径可能与实时储存条件下不同（如聚集体的形成机制在高温下可能不同于冷藏储存）。

:::

## 可接受标准的生命周期管理：从早期到上市后的动态更新机制

:::answer

可接受标准不是一次性制定的静态文件，而是随产品研发阶段、批次积累和法规环境变化持续更新的动态管理体系。

**质量标准演进的主要驱动因素**

| 驱动因素 | 导致的标准变化 | 申报要求 |
|---|---|---|
| 批次数据积累 | 基于统计分析收紧或验证现有限度 | 通常须补充申请 |
| 工艺变更 | 新工艺引入新杂质或改变产品质量谱 | 可比性研究 + 标准修订 |
| 法规更新 | 新指导原则对某些项目提出新要求 | 强制性更新 |
| 稳定性数据积累 | 发现新降解途径，修订降解产物限度 | 通常须补充申请 |
| 临床数据反馈 | 特定质量属性与临床效果关联性数据 | 基于科学评估修订 |

**基于批次数据统计分析的标准更新路径**

```
研发早期（批次数据有限，< 10 批）：
  基于工艺一致性研究批次 + 方法变异
  → 制定较宽的初始限度范围

上市申请阶段（10～30 批）：
  结合临床批次数据和工艺能力统计分析
  → 制定更有依据的临床相关限度

上市后累积生产阶段（25～30 批）：
  辉瑞公司研究证明：25～30 批数据可较好预测工艺能力
  → 进行系统性统计分析，优化限度设置

上市后长期监控（> 85 批）：
  可最终确定稳健的产品质量标准
  欧美监管机构通常要求：
    → 累积生产 30 批后，以补充申请方式更新质量标准
    → 或累积生产 3 年后进行系统性标准更新
```

**标准更新的监管申报策略**

不同类型的标准变更对应不同的申报路径：

- **限度收紧（范围变小）：** 通常属于较小的变更，部分情况可在年度报告中说明
- **限度放宽（范围变大）：** 须提供充分的科学依据，通常需要补充申请
- **新增检测项目：** 须提供方法验证报告和历史批次数据，通常需要补充申请
- **删除检测项目：** 须证明删除不影响产品质量保证，通常需要补充申请

:::

## 抗体原液下游工艺全流程：工序目的、原理与中间体控制体系

:::answer

下游纯化工艺（Downstream Processing）是将细胞培养收获液转化为高纯度抗体原液的完整过程。以下系统梳理典型单抗下游工艺各步骤的工序目的、作用原理和质量控制要点。

**标准下游工艺流程总览**

```
细胞培养收获（Harvest）
    ↓
深层过滤（Depth Filtration）—— 澄清
    ↓
Protein A 亲和层析（Capture）—— 捕获、初步纯化
    ↓
低 pH 病毒灭活（Viral Inactivation）—— 病毒安全性
    ↓
二次深层过滤（pH 中和后澄清）
    ↓
阳离子交换层析（CEX，结合-洗脱）—— 精纯
    ↓
阴离子交换层析（AEX，流穿模式）—— 精纯
    ↓
除病毒过滤（Nanofiltration）—— 病毒安全性
    ↓
超滤/渗滤（UF/DF）—— 浓缩换液
    ↓
原液（Drug Substance）
```

:::

---

## 下游工艺步骤一：细胞培养液收获的工艺控制与法规要求

:::answer

**工序目的**

从生物反应器收获培养液，将含有目的抗体的细胞培养液转入下游纯化工序，同时进行生物安全性检测。

**收获方法**

- **储液袋收集：** 直接将细胞培养液泵入一次性储液袋，适用于分批收获
- **直接连接下游：** 收获液通过管路直接与深层过滤器连接，减少中间储存步骤

**中间体控制项目（来源于中国药典三部规定）**

收获时须检测以下关键参数：

| 检测项目 | 目的 | 频率要求 |
|---|---|---|
| 细胞密度（VCD）| 确认收获时机的合理性 | 每次收获 |
| 细胞活率（Viability）| 评估细胞死亡程度，判断污染风险 | 每次收获 |
| 浊度（Turbidity）| 评估细胞碎片和颗粒含量 | 每次收获 |
| 抗体含量（Titer）| 确认目的产物产量 | **每次收获** |
| 细菌内毒素 | 生物安全性控制 | **每次收获**（药典要求）|
| 支原体 | 外源因子污染检测 | **每次收获**（药典要求）|

**法规重点：外源病毒检测的特殊要求**

中国药典三部明确规定：

```
"每次收获后均应检测抗体含量、细菌内毒素及支原体。
 应根据生产过程及所用材料的特点，在合适的阶段进行常规或特定的外源病毒污染检查。
 除另有规定外，应对限定细胞传代次数的生产方式，
 采用适当的体外方法至少对3次收获物进行外源病毒检测。"
```

**企业通行做法**

- **UPB（Unprocessed Bulk）检测：** 对收获液进行外源病毒检测，控制培养过程中的病毒污染风险
- **EOPC（End of Production Cells）建立：** 将培养过程中的细胞进行传代冻存，建立生产终末细胞库，对种子污染进行控制

**MCB/WCB/EOPC 的检定关系**

- 细胞库建立后须对 MCB 和 EOPC 进行至少一次全面检定
- 生产工艺发生改变时，须重新对 EOPC 进行检测
- 每次从 MCB 建立新的 WCB，均须按规定项目进行检定

:::

## 下游工艺步骤二：深层过滤的澄清机制与工艺控制

:::answer

**工序目的**

对细胞收获液进行澄清，去除细胞和细胞碎片，同时通过电荷相互作用去除部分内毒素、宿主细胞蛋白（HCP）、宿主细胞 DNA（HC-DNA）等带负电荷的杂质。

**作用原理（双重机制）**

```
机制一：粒径截留（物理过滤）
  当颗粒尺寸小于介质孔道直径时，颗粒进入介质内部
  通过惯性和扩散作用趋近孔道壁面
  在静电和表面力作用下沉积，从而与流体分离

机制二：电荷吸附（静电相互作用）
  深层过滤介质中含有硅藻土等带正电荷的物质
  可吸附带负电荷的杂质：
    ├─ 内毒素（带负电）
    ├─ 宿主细胞蛋白（大多数带负电）
    └─ 宿主细胞 DNA（强负电）
```

**滤材的典型构成**

| 成分 | 作用 |
|---|---|
| 纤维素纤维 | 提供支撑骨架，形成过滤床 |
| 硅藻土（DE）| 正电荷来源，吸附带负电杂质 |
| 珍珠岩 | 助滤剂，增加过滤通量 |

**关键工艺参数与中间体控制**

| 控制参数 | 控制目的 | 典型范围 |
|---|---|---|
| 过滤流速 | 避免过快导致过滤质量下降 | 根据膜面积设定（L/m²·hr）|
| 跨膜压差（TMP）| 避免过高压差导致滤材损坏 | 通常 < 1 bar |

**过滤后检测项目**

| 检测项目 | 目的 |
|---|---|
| 蛋白浓度 | 评估步骤回收率 |
| 宿主细胞蛋白（HCP）| 评估 HCP 初步去除效果 |
| 宿主细胞 DNA（HC-DNA）| 评估 DNA 初步去除效果 |
| 内毒素 | 评估内毒素去除效果 |
| 微生物限度 | 生物安全性控制 |

:::

## 下游工艺步骤三：Protein A 亲和层析的捕获策略与质量控制

:::answer

**工序目的**

Protein A 亲和层析是抗体纯化的捕获步骤（Capture Step），具有高度选择性，能一步将抗体从复杂培养液中捕获并浓缩，同时去除大量工艺杂质。

**工序核心价值**

- 一步去除培养上清中大部分杂质（核酸、HCP、培养基成分）
- 抗体纯度可达 **95% 以上**，收率接近 **100%**
- 同时实现抗体浓缩，洗脱液中抗体浓度可达 **10 g/L 以上**
- 大幅缩小后续精纯步骤的液体处理量

**作用原理**

```
Protein A 来源：金黄色葡萄球菌膜蛋白（rProtein A 为重组形式）

结合机制：
  Protein A 的 E/D 结构域特异性结合 IgG 的 Fc 区（CH2-CH3 界面）
  结合亲和力常数 Ka ≈ 10⁸ M⁻¹（高亲和力）

操作流程：
  上样（澄清培养液直接加载，无需预处理）
      ↓
  清洗（中性缓冲液，去除非特异性结合杂质）
      ↓
  洗脱（低 pH 缓冲液，pH 3.0～3.5，使 Protein A 与 IgG 解离）
      ↓
  再生（更低 pH 或低浓度碱液，去除强结合残留）
```

**可结合的抗体类型**

Protein A 可纯化多种哺乳动物不同亚型的抗体和 Fc 融合蛋白，但对各亚型亲和力有差异（IgG3 亲和力较弱，可能无法用 Protein A 纯化）。

**关键工艺参数与中间体控制**

| 控制参数 | 说明 |
|---|---|
| 上样载量（Loading Capacity）| 通常 ≤ 40 g/L 填料（须经工艺表征验证）|
| 上样 pH | 通常 7.0～7.4（IgG 与 Protein A 最佳结合 pH）|
| 洗脱 pH | 通常 3.0～3.5（须平衡洗脱效率和蛋白稳定性）|
| 收集 AU（A280）| 设定收集峰的上下限阈值（通常基于峰高百分比）|

**过滤后检测项目（典型）**

蛋白浓度、SEC 单体纯度、CEX 电荷变异体、糖型（必要时）、HCP、HC-DNA、CE-SDS、细菌内毒素、微生物限度

**Protein A 介质的特殊关注点**

- **Protein A 浸出物（Leaching）：** 重组 Protein A 配基会随使用次数增加而浸出，须通过使用寿命研究确定介质更换周期，并在原液中监测 Protein A 浸出物水平（通常 < 5 ng/mg API）
- **介质寿命管理：** Protein A 介质价格昂贵（约为离子交换介质的 10 倍），须建立使用寿命研究数据，最大化介质使用次数

:::

## 下游工艺步骤四：低 pH 病毒灭活的机制、参数控制与替代方案

:::answer

**工序目的**

低 pH 病毒灭活是单抗下游工艺中第一个正交病毒清除步骤，专门针对有包膜病毒（如鼠白血病病毒 MuLV）进行灭活。

**法规要求**

法规要求至少采用**两种不同原理**的方法对病毒进行控制，低 pH 病毒灭活通常是其中之一（另一种通常为除病毒过滤或阴离子交换层析）。

**作用原理**

```
低 pH 灭活机制：
  弱酸性条件（pH 3.6～3.7）破坏有包膜病毒的脂质包膜结构
    ↓
  病毒脂膜溶解，蛋白质变性
    ↓
  病毒无法再与宿主细胞结合，完全失去感染能力

对包膜病毒（如 MuLV、HIV）：灭活效果极强
对非包膜病毒（如 CPV、PPV、HAV）：低 pH 灭活效果有限
```

**关键工艺参数（严格控制的三要素）**

| 参数 | 典型控制范围 | 重要性说明 |
|---|---|---|
| pH 值 | 3.6～3.7（须经验证）| **最关键参数**：pH > 3.8 灭活效果明显减少；pH < 3.6 可能形成聚集体 |
| 孵育时间 | 通常 ≥ 60 分钟 | 需满足法规要求的最短孵育时间 |
| 孵育温度 | 通常 15～25℃ | 影响灭活效率和蛋白稳定性 |

**操作流程**

```
低 pH 孵育：
  ① 将 Protein A 洗脱液的 pH 调至目标值
  ② 在搅拌槽中孵育规定时间（在线 pH 监测）
  ③ 孵育完成后调节 pH 至中性（通常 pH 6.0～7.0）
```

**中间体控制项目**

| 检测项目 | 目的 |
|---|---|
| pH 值（整个孵育过程）| 确认病毒灭活条件的维持 |
| 孵育时间记录 | 法规符合性证明 |
| 温度记录 | 工艺参数合规性 |
| 蛋白浓度 | 步骤回收率监控 |
| SEC 单体纯度 | 监控低 pH 对蛋白聚集的影响 |

**低 pH 不稳定蛋白的替代方案**

若蛋白在低 pH 条件下稳定性差（易聚集），可采用**溶剂/去污剂（S/D）混合物灭活**替代：

```
S/D 法（Solvent/Detergent）：
  有机溶剂（如 TNBP）+ 去污剂（如 Triton X-100 或吐温 80）
  破坏包膜病毒的脂质包膜
  
优势：pH 中性条件，对蛋白质温和
局限：仅能灭活有包膜病毒，对非包膜病毒无效
      须在后续步骤中去除 S/D 残留
```

:::

## 下游工艺步骤五：二次深层过滤（中和后澄清）

:::answer

**工序目的**

去除低 pH 病毒灭活步骤结束后，因 pH 中和过程中蛋白质可能发生的沉淀和聚集体，避免颗粒物进入后续层析步骤影响填料性能。

**与第一次深层过滤的差异**

| 比较维度 | 第一次深层过滤（收获后）| 第二次深层过滤（中和后）|
|---|---|---|
| **主要目的** | 料液澄清（去除细胞和细胞碎片）| 去除中和过程中形成的蛋白沉淀 |
| **处理量** | 较大（完整培养液体积）| 较小（Protein A 洗脱液体积）|
| **杂质特征** | 细胞碎片、颗粒为主 | 蛋白沉淀、聚集体为主 |

**工艺控制**

- 过滤流速和跨膜压差（TMP）的监控
- 检测项目：蛋白浓度（评估步骤回收率，同时监控因沉淀导致的蛋白损失）

**过滤后质量评估**

若二次深层过滤后蛋白回收率明显低于预期，须调查原因：
- 低 pH 孵育条件是否过于剧烈（蛋白不稳定）
- 中和速率是否过快（局部 pH 过高导致沉淀）
- 蛋白浓度是否过高（高浓度条件下中和过程中聚集风险增加）

:::

## 下游工艺步骤六：阳离子交换层析（CEX）的精纯机制与优势

:::answer

**工序目的**

阳离子交换层析（Cation Exchange Chromatography，CEX）是下游精纯（Polishing）的核心步骤之一，主要去除 HCP、脱落的 Protein A、抗体聚集体、片段及各种电荷异构体。

**作用原理**

```
离子交换基本原理：
  目标物质与带相反电荷的介质通过静电力结合
  通过改变盐浓度或 pH 实现选择性洗脱

CEX 的特殊之处：
  介质上带负电荷（磺酸基 -SO₃⁻ 或羧酸基 -COO⁻）
  吸附带正电荷的物质（即阳性离子）

单抗在 CEX 中的行为：
  大多数单抗等电点（pI）> 7
  → 在 pH 6.0 左右的缓冲液中，单抗带正电荷
  → 结合到 CEX 介质上（结合-洗脱模式）
  → 通过盐梯度或 pH 梯度选择性洗脱
```

**CEX 与 Protein A 的关键比较**

| 比较维度 | CEX | Protein A |
|---|---|---|
| **特异性** | 较低（基于电荷，非专属性）| 极高（Fc 特异性结合）|
| **通用性** | 较差（需针对各抗体优化 pH）| 好（适用于大多数 IgG）|
| **载量** | 高（≥ 100 g/L 填料）| 中等（40～50 g/L）|
| **成本** | 低（约为 Protein A 的 1/10）| 高 |
| **耐碱性** | 好（可用 NaOH 清洗）| 差（需温和的清洗条件）|

**关键工艺参数与中间体控制**

| 控制参数 | 说明 |
|---|---|
| 上样载量 | 须经工艺表征确定最大载量（考虑动态结合容量）|
| 上样 pH | 决定抗体与介质的结合程度（通常 pH 5.5～6.5）|
| 洗脱条件 | 盐浓度梯度（NaCl）或 pH 梯度 |
| 收集 AU 阈值 | 设定洗脱峰的收集起始和终止阈值 |

**CEX 步骤的技术挑战**

- 不同抗体的等电点（pI）不同，需针对每个分子优化 pH 设置
- 同一抗体不同翻译后修饰（如脱酰胺、C-末端赖氨酸变体）等电点不同，影响 CEX 分辨效果
- 高浓度盐洗脱液须在下一步调节至适合阴离子交换的条件

:::

## 下游工艺步骤七：阴离子交换层析（AEX）的流穿模式与杂质去除

:::answer

**工序目的**

阴离子交换层析（Anion Exchange Chromatography，AEX）通常采用流穿（Flow-through）模式，使抗体通过层析柱，而带负电荷的杂质被吸附留在柱上，实现高效去除多种关键杂质。

**作用原理**

```
AEX 介质特征：
  介质上带正电荷（季铵基 -N⁺(CH₃)₃ 等）
  吸附带负电荷的阴性离子

流穿模式的逻辑：
  大多数单抗 pI > 7
  → 在 pH 7.0～8.0 的缓冲液中，单抗表面净电荷接近中性或微负
  → 抗体与 AEX 介质亲和力弱，随流动相穿过层析柱（流穿）
  
  带负电荷的杂质被高效吸附：
    ├─ 宿主细胞 DNA（强负电）
    ├─ 内毒素（脂多糖，带负电）
    ├─ 宿主细胞蛋白（大多数带负电）
    ├─ Protein A 浸出物（部分带负电）
    └─ 病毒（部分病毒颗粒带负电）
```

**AEX 的多重杂质去除能力**

| 杂质类型 | AEX 去除效率 | 去除机制 |
|---|---|---|
| 宿主细胞 DNA | 极高（> 99%）| 强负电荷，与正电荷介质强结合 |
| 内毒素 | 高 | 脂多糖带负电，有效吸附 |
| 宿主细胞蛋白 | 较高（视具体 HCP 种类）| 大多数 HCP 带负电 |
| 病毒（部分）| 中等（对某些病毒有效）| 病毒表面电荷依赖性 |
| 聚集体 | 部分（不是主要去除机制）| 聚集体可能有不同电荷特征 |

**关键工艺参数与中间体控制**

| 控制参数 | 说明 |
|---|---|
| 上样载量 | 须确保流穿体积不超过柱容量限制 |
| 上样 pH 和电导率 | 决定杂质的结合程度和抗体的流穿效率 |
| 流速 | 影响动态结合容量和杂质去除效率 |

**与 CEX 的协同关系**

经典抗体精纯策略采用 AEX + CEX 两步精纯协同：
- **AEX（流穿）：** 优势在于去除 DNA、内毒素、HCP——去除带负电杂质
- **CEX（结合-洗脱）：** 优势在于去除聚集体、碎片、电荷变异体——通过抗体结合实现选择性分离

两步结合互为补充，覆盖了产品相关杂质和工艺相关杂质的全面去除。

:::

## 下游工艺步骤八：除病毒过滤（纳滤）的机制与病毒安全性保证

:::answer

**工序目的**

除病毒过滤（Virus Filtration / Nanofiltration）是下游工艺中第二个正交病毒清除步骤，通过物理粒径截留机制去除病毒，与低 pH 病毒灭活（破坏包膜）形成正交互补，实现病毒的全面控制。

**法规要求**

按照 ICH Q5A(R1) 指南，须采用至少两种不同原理的方法确保病毒安全性，建议采用三种互补方法：

```
三重保障策略（推荐）：

① 源头控制：
   MCB/WCB 全面病毒检定
   原材料病毒安全性（动物源性物料证明）
   生产过程中 UPB 检测

② 低 pH 病毒灭活（第一道工艺清除）：
   针对有包膜病毒

③ 除病毒过滤（第二道工艺清除）：
   针对有包膜和无包膜病毒（基于粒径）
   与低 pH 灭活形成正交互补
```

**作用原理（双重机制）**

```
机制一：粒径排阻（主要机制）
  病毒粒径大于滤膜孔径 → 被物理截留
  产品（抗体，约 10 nm）< 膜孔（20 nm）→ 穿过滤膜
  
  对象：>20 nm 的病毒（如 MuLV，约 80～100 nm）→ 高效去除（LRV > 4 log₁₀）

机制二：电荷吸附（补充机制）
  对于尺寸接近孔径的小病毒（如细小病毒，约 20 nm）
  通过电荷、范德华力、氢键等捕获病毒颗粒
```

**典型病毒去除效果**

| 病毒类型 | 粒径 | 除病毒过滤去除效果 |
|---|---|---|
| 鼠白血病病毒（MuLV，有包膜）| 80～100 nm | 极高（> 4 log₁₀，通常 > 6 log₁₀）|
| 细小病毒（PPV，无包膜）| 18～26 nm | 中等（取决于膜孔径，通常 2～4 log₁₀）|
| 流感病毒（有包膜）| 80～120 nm | 极高 |

**关键工艺参数与中间体控制**

| 控制参数 | 说明 |
|---|---|
| 过滤压力（TMP）| 过滤驱动力，须控制在验证范围内 |
| 蛋白浓度 | 高浓度可能导致膜堵塞，影响过滤通量 |
| 过滤体积 | 监控累计过滤量，评估膜的使用寿命 |

**过滤完整性测试（Integrity Test）**

除病毒过滤器须在使用前后进行完整性测试，证明过滤膜无缺陷：
- 起泡点测试（Bubble Point Test）
- 扩散流量测试（Diffusion Flow Test）
- 压力保持测试（Pressure Hold Test）

:::

## 下游工艺步骤九：超滤/渗滤（UF/DF）的浓缩换液工艺控制

:::answer

**工序目的**

超滤/渗滤（Ultrafiltration/Diafiltration，UF/DF）是下游工艺的最终步骤，实现两个并行目标：
- **浓缩（UF）：** 将抗体浓度提升至制剂所需的目标浓度
- **换液（DF）：** 将缓冲体系从上步工艺缓冲液置换为制剂缓冲液

**作用原理**

```
基于分子大小的膜分离原理：

大分子（抗体，~150 kDa）> 超滤膜截留分子量（通常 30 kDa）
    ↓ 被截留，浓度逐渐升高

小分子（缓冲液成分：盐、酸碱）< 超滤膜截留分子量
    ↓ 通过膜（称为"透过液"），从系统中排出

渗滤（DF）操作：
  向截留侧持续补充制剂缓冲液
  → 同时将旧缓冲液成分置换出
  → 通常需要 5～10 个渗滤体积（DV）完成充分置换
```

**超滤膜选择要点**

| 参数 | 典型规格 | 说明 |
|---|---|---|
| 截留分子量（MWCO）| 通常 30 kDa（单抗 150 kDa）| MWCO 约为目标蛋白分子量的 1/5～1/3 |
| 膜材质 | 再生纤维素、聚醚砜（PES）| 须考虑对蛋白的吸附性 |
| 配置 | 切向流过滤（TFF）| 减少浓差极化，提高通量 |

**关键工艺参数与中间体控制**

| 控制参数 | 说明 | 风险 |
|---|---|---|
| 跨膜压差（TMP）| 驱动液体穿过超滤膜 | 过高导致蛋白凝胶极化，降低通量 |
| 蛋白浓度（终浓度）| 目标制剂浓度 | 过高易导致聚集体形成 |
| 渗滤体积（DV）| 确保旧缓冲液成分被充分置换 | DV 不足导致残留旧缓冲液影响制剂稳定性 |
| 温度 | 通常 2～8℃或室温 | 过高加速蛋白聚集和降解 |

**过滤后检测项目**

| 检测项目 | 检测目的 |
|---|---|
| 蛋白浓度 | 确认达到目标浓度 |
| SEC 单体纯度 | 监控 UF/DF 过程中的聚集体变化 |
| 渗透压 | 确认缓冲液置换充分（与制剂配方一致）|
| pH | 确认缓冲体系符合要求 |
| 细菌内毒素 | 生物安全性控制 |
| 微生物限度 | 生物安全性控制 |

**工艺优化关键点**

经过 UF/DF 步骤后，通常将蛋白浓缩并置换到制剂缓冲液，可直接用于后续灌装，减少中间处理步骤。过滤后的原液通常储存在低温冰箱（-70℃ 或 -20℃）中，须确认储存条件已经验证。

---

**下游工艺各步骤综合对比速查表**

| 步骤 | 工序类型 | 主要去除对象 | 病毒控制 | 关键参数 |
|---|---|---|---|---|
| 收获 | 收集 | — | UPB 检测 | 细胞密度、活率 |
| 深层过滤 | 澄清 | 细胞碎片、部分 HCP/DNA/内毒素 | 无 | 流速、TMP |
| Protein A | 捕获 | 大部分非 IgG 杂质 | 部分 | 载量、洗脱 pH |
| 低 pH 灭活 | 病毒灭活 | 有包膜病毒 | **一级**（灭活）| pH、时间、温度 |
| 二次深层过滤 | 澄清 | pH 中和后蛋白沉淀 | 无 | 流速、TMP |
| CEX | 精纯（结合-洗脱）| 聚集体、片段、HCP、Protein A 浸出物 | 无 | 载量、洗脱条件 |
| AEX | 精纯（流穿）| DNA、内毒素、HCP、部分病毒 | 辅助 | pH、电导率 |
| 除病毒过滤 | 病毒过滤 | 病毒（有/无包膜均可）| **二级**（去除）| TMP、浓度 |
| UF/DF | 浓缩换液 | 旧缓冲液成分 | 无 | TMP、DV |

:::
