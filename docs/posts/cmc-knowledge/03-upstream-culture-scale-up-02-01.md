## 温度：双阶段策略与产量质量的权衡

:::answer

**基本原则**

温度是哺乳动物细胞培养中最重要的物理控制参数之一。细胞培养通常在 37°C 启动，此温度最接近体内生理环境，有利于细胞的快速增殖与代谢。

**降温策略的生物学机制**

大量研究表明，在培养中后期（通常在细胞密度达到峰值后）实施降温策略，可带来以下益处：

- **提高目标蛋白 mRNA 稳定性**，延长转录产物半衰期，从而上调比生产速率（Specific Productivity，Qp）
- **诱导 G1 期细胞积累**，使更多细胞处于产物合成活跃阶段
- **减缓细胞代谢速率**，降低乳酸和氨的积累，间接延长培养周期
- **减少蛋白聚集与降解**，有助于提升产物质量

典型的降温操作策略为：前期 36–37°C 促进细胞扩增，中后期降至 31–34°C 提升生产效率，最优降温点与目标温度需通过实验设计（DoE）确定。

**对产物质量的双重影响**

| 温度效应 | 质量属性变化 |
|---|---|
| 温度升高 | 蛋白片段增多、酸性异构体比例升高 |
| 温度升高 | 影响 N-糖基化关键酶活性，糖型谱发生偏移 |
| 温度降低 | 唾液酸含量可能下降（取决于细胞系） |
| 温度降低 | 部分研究报道活细胞数量减少，抑制细胞增殖 |

> **重要提示：** 温度对产量和质量的影响高度依赖于细胞系与目标蛋白特性，结论不可跨项目直接套用，须以实验数据为准。由于纯度和糖型通常为 CQA，后期培养温度的选择需系统研究并纳入 CPP 管理。

## pH：代谢联动与质量调控的核心参数

:::answer

**基本控制范围**

哺乳动物细胞生长的最适 pH 为 **6.6–7.4**，通常以 7.0 为目标值进行控制。pH 偏低或偏高均会引起细胞代谢紊乱，影响活力与表达。对于 CHO 细胞，常规控制范围为 **6.7–7.3**，最优控制策略须通过实验优化确定。

**pH 与代谢的相互作用**

- pH 从 6.8 升至 7.2 时，细胞对葡萄糖和谷氨酰胺的比消耗率显著增加，代谢活动增强
- 细胞代谢产生乳酸和 CO₂，持续消耗培养液缓冲能力，导致 pH 下降
- 为维持 pH 稳定，常采用碱液（如 Na₂CO₃）补加，但大量补碱会导致渗透压升高，形成次生压力

**pH 漂移的控制策略**

| 策略 | 原理 | 注意事项 |
|---|---|---|
| 补加碳酸钠 / 碳酸氢钠 | 中和乳酸，快速纠正 pH | 大量补入导致渗透压升高 |
| 增大 CO₂ 移除速率 | 采用大孔径 sparger，加强通气 | 需兼顾泡沫与剪切力控制 |
| 以半乳糖替代葡萄糖 | 减少乳酸生成，从源头控制 pH | 细胞利用效率不同，需验证 |
| 优化补料策略 | 限制葡萄糖浓度，降低 Warburg 效应 | 补料时机与量需精确控制 |

**pH 对产物质量的影响**

- 较低 pH 抑制酸性蛋白变体的生成，可调节电荷异构体分布
- pH 降低会减少唾液酸含量，影响糖基化质量属性
- pH 过高或过低均可能加剧蛋白脱酰胺或氧化风险

:::

## 溶氧（DO）：供氧平衡与糖基化调控

:::answer

**基本生理需求**

动物细胞为专性好氧生物，充足的氧气供应是维持有氧代谢和 ATP 生成的基础。由于 O₂ 在水中溶解度极低（约 0.2 mmol/L at 37°C），生物反应器中需持续通氧以补充消耗。

**常规控制范围与策略**

- DO 通常控制在 **30–70%** 空气饱和度，典型目标值为 **40%**
- 通过 PID 控制器自动调节通气量（空气/O₂混合比）和搅拌转速实现精确控制
- 根据先验知识，**DO 在 20–80% 范围内**对 CHO 细胞生长和多数质量属性无显著影响，通常 DO 不作为关键工艺参数（CPP）纳入系统研究，多采用平台控制策略

**DO 对质量属性的影响**

| DO 水平 | 已报道的质量影响 |
|---|---|
| 高 DO（>80%） | 抗体半乳糖化水平升高；细胞内 UDP-半乳糖含量随之增加 |
| 高 DO | 甲硫氨酸（Met）氧化程度增加，影响抗体结构与 FcRn 结合功能 |
| 低 DO（<20%） | 细胞代谢转为糖酵解，乳酸积累，影响 pH 和培养性能 |
| 低 DO | 糖基化酶活性受抑，可能导致糖型谱偏移 |

> **实践建议：** 在产品表征阶段，若产品 Met 氧化或半乳糖化为关键 CQA，应将 DO 纳入 DoE 考察，而非简单沿用平台默认值。

:::

## 渗透压：细胞应激响应与蛋白分泌的调控杠杆

:::answer

**基本概念与生理意义**

渗透压（Osmolality）反映溶液中溶质粒子的总浓度，是影响细胞水分平衡的关键参数。细胞培养液的渗透压一般维持在 **280–400 mOsm/kg** 之间。

当培养液渗透压高于细胞内渗透压时，细胞失水皱缩；过低则导致细胞吸水膨胀，均损害细胞活力。CO₂ 分压过高（>140 mmHg）也会导致渗透压异常升高，抑制细胞生长。

**渗透压升高的生物学效应**

适当高渗透压（350 mOsm/kg 以上）在细胞培养中后期被广泛应用，其机制与效应如下：

- **促进蛋白分泌**：高渗条件下细胞代谢减缓，但分泌通路活跃，有助于目标蛋白向胞外释放
- **降低聚集体水平**：细胞内蛋白折叠环境发生改变，有利于减少错误折叠聚集
- **提升唾液酸含量**：高渗条件下细胞唾液酸转移酶活性可能增强
- **诱导凋亡风险**：渗透压过高会触发细胞凋亡程序，需权衡利弊

**高渗透压的保护与缓解策略**

在培养基中添加渗透压保护剂可有效缓解细胞应激：

| 保护剂 | 作用机制 |
|---|---|
| 甘氨酸甜菜碱 | 相容性溶质，维持细胞内水分平衡 |
| 脯氨酸 | 稳定蛋白质结构，缓解氧化应激 |
| 苏氨酸 / 甘氨酸 | 参与渗透调节，保护细胞膜完整性 |

:::

## 细胞培养工艺设计的核心目标

:::answer

细胞培养工艺开发围绕两个核心维度展开：**产量最大化**与**质量可控性**，二者需在工艺设计中同步优化。

**目标维度一：抗体产量**

抗体总产量（Titer）由以下三个变量共同决定：

$$\text{Titer} = Q_p \times \text{IVCD} = Q_p \times \int VCD \cdot dt$$

- **比生产速率（Qp）**：单细胞单位时间内分泌的抗体量，受培养条件和细胞株特性影响
- **积分活细胞密度（IVCD）**：反映整个培养过程中"有效细胞工作量"的总和
- **培养周期**：在不显著降低细胞活率前提下，延长培养天数可增加 IVCD

工艺优化的核心在于：通过基因工程、培养工程、代谢调控和反应器工程等手段，协同提升 Qp 和 IVCD。

**目标维度二：抗体质量**

工艺开发前应预设目标产品质量概况（QTPP），并明确关键质量属性（CQA）。常见的抗体 CQA 及其潜在影响如下：

| CQA 属性 | 潜在影响 |
|---|---|
| 糖基化（N-糖型，如岩藻糖、半乳糖、唾液酸） | ADCC/CDC 功能活性、PK 特征 |
| 聚集体 / 多聚体 | 免疫原性风险 |
| 电荷异构体 | 结合活性、清除率 |
| 氧化（Met、Trp） | 结合活性、稳定性 |
| 脱酰胺（Asn、Gln） | 结构稳定性、效力 |
| 二硫键错配 / 游离巯基 | 折叠完整性 |
| C 末端 Lys 截短 | 电荷异构体来源 |

> **实践建议：** CQA 的确定应基于结构-活性关系（SAR）分析和风险评估，不同产品分子的 CQA 清单存在差异，不可一概而论。

:::

## 细胞培养工艺开发的基本原则与决策路径

:::answer

**核心决策依据：细胞株的初始表现**

获得生产细胞株后，需先评估其产量和质量是否满足项目需求，并以此确定后续开发策略：

**路径一：产量与质量均符合要求**

- 目标：快速满足 IND 申报时间节点
- 策略：直接沿用平台工艺（Platform Process），跳过系统优化，直接开展工艺确认与放大
- 适用场景：成熟平台、标准分子、早期临床阶段

**路径二：产量或质量不达预期**

- 目标：通过系统工艺优化将质量和产量调整至预期范围
- 策略：开展多轮优化实验，工作量根据偏差程度和分子复杂性确定
- 特殊场景：**生物类似药**要求质量图谱与原研高度相似，通常需要多轮定向优化，以实现关键 CQA 的精准匹配

**工艺开发的总体原则**

1. 质量优先，产量其次：不以牺牲 CQA 为代价换取高 Titer
2. 平台先行，差异化后行：先验证平台工艺适用性，再针对性开展差异化优化
3. 从简到繁：摇瓶→小反应器→中试，逐步放大验证
4. 数据驱动：每个工艺决策均应有实验数据支撑，避免纯经验判断

:::

## 细胞培养工艺开发全流程

:::answer

**IND 申报前工艺开发的目标**

在进入临床前，工艺开发的首要任务是建立一个质量可接受、产量达标、工艺稳定的生产流程，以保障临床前研究和 Phase I 临床研究的样品供应。

**标准开发流程**

```
培养基筛选
    ↓
摇瓶规模工艺参数研究
    ↓
小型反应器（2–20L）工艺参数研究
    ↓
种子链工艺参数研究
    ↓
反应器规模工艺确认（3 批次为宜）
    ↓
工艺锁定 & 转移至生产场地
    ↓
中试 / 商业规模放大
```

各阶段核心任务与关注点：

| 阶段 | 主要任务 | 关键输出 |
|---|---|---|
| 培养基筛选 | 基础培养基与补料培养基匹配性评估 | 最优培养基组合 |
| 摇瓶研究 | 接种密度、降温策略、补料方案初筛 | 工艺参数范围初稿 |
| 小反应器研究 | pH、DO、搅拌、通气等参数精细化研究 | CPP 鉴别与范围确认 |
| 种子链研究 | 各代次传代条件、活力与密度控制 | 种子链工艺规程 |
| 工艺确认 | 工艺重复性与稳健性验证 | 工艺确认报告 |
| 工艺放大 | 规模效应评估与参数调整 | 放大工艺规程 |

:::

## 摇瓶规模工艺开发：高通量筛选的基础平台

:::answer

**摇瓶在工艺开发中的定位**

摇瓶是细胞培养工艺开发中不可替代的小规模研究工具，具有以下核心优势：

- **通量高**：可同时开展数十个条件的并行实验
- **成本低**：相较反应器实验，消耗资源少，周期短
- **代表性强**：摇瓶实验结果通常与反应器规模结果趋势一致，具有良好的可预测性

**摇瓶阶段可重点研究的工艺参数**

| 工艺参数 | 研究目的 |
|---|---|
| 初始接种密度 | 优化适应期长度与活细胞密度峰值 |
| 初始培养温度 | 确定最适细胞增殖温度 |
| 降温温度与时机 | 平衡产量与质量 |
| 补料策略（时间/量/频率） | 营养供给优化，减少代谢废物积累 |
| 培养基组合 | 基础培养基 + 补料培养基最优匹配 |
| 培养周期 | 确定最佳收获时间节点 |

**摇瓶的局限性**

摇瓶无法精确控制 pH 和 DO，搅拌方式（振荡）和通气方式（气液界面扩散）与反应器存在本质差异，因此摇瓶实验不能完全替代反应器研究，尤其是 pH、DO、搅拌和通气相关参数必须在反应器中开展。

:::

## 反应器规模工艺开发：精细化参数研究的核心平台

:::answer

**反应器研究的必要性**

生物药的最终生产工艺在生物反应器中进行。尽管摇瓶研究为工艺开发提供了宝贵的方向性数据，但以下参数只能在反应器中系统研究：

| 参数类型 | 反应器可研究 | 摇瓶可研究 |
|---|---|---|
| pH | ✅（精确 PID 控制） | ❌（无法控制） |
| DO | ✅（精确 PID 控制） | ❌（无法控制） |
| 搅拌转速 / 剪切力 | ✅ | ❌（振荡方式不同） |
| 通气方式 / 泡沫控制 | ✅ | ❌ |
| 初始接种密度 | ✅ | ✅ |
| 降温策略 | ✅ | ✅ |
| 补料策略 | ✅ | ✅ |

**反应器工艺开发的常用规模**

小型生物反应器（2L、5L、10L、20L）是工艺参数研究的主力平台，兼顾数据代表性与实验成本。通常以 DoE（实验设计）方法开展多参数联合优化，高效鉴别关键工艺参数（CPP）及其操作范围。

**数据质量要求**

反应器实验应确保：

- 工艺参数在目标范围内稳定控制
- 在线监测（pH、DO、CO₂、搅拌转速）与离线分析（活细胞密度、葡萄糖、乳酸、谷氨酰胺、氨）数据齐全
- 每个条件至少双重复，关键条件三重复以上

:::

## 工艺确认与放大：从实验室到生产的关键跨越

:::answer

**IND 阶段的工艺锁定策略**

IND 申报阶段时间紧迫，工艺开发以"满足要求、工艺稳健"为首要目标，而非追求最优化。

- 通常经过 **1–3 轮工艺优化**后，在 **2–20L 反应器**中完成工艺确认与锁定
- 工艺确认推荐开展 **3 批次**（以建立重复性数据），紧急情况下可缩减至 1 批次，但风险较高，需在申报文件中说明风险评估
- IND 申报的工艺参数范围通常参照平台经验设定，范围较宽；实际执行时按目标值操作

**放大阶段的核心任务**

工艺锁定后，需将工艺参数体系从小规模向中试（如 200L）乃至商业规模（500L、1000L、2000L 以上）转移，重点包括：

| 放大考察维度 | 关键问题 |
|---|---|
| 混合时间与均一性 | 大体积反应器中 pH、DO、温度的空间分布均匀性 |
| 质量传递（kLa） | 溶氧传质系数是否满足细胞需氧量 |
| 剪切力 | 搅拌与通气引起的剪切对细胞活力的影响 |
| 泡沫控制 | 通气泡沫对细胞损伤及消泡剂对产品质量的影响 |
| 种子链适配 | 种子反应器与生产反应器接种密度与活力的匹配 |
| CO₂ 积累 | 大规模培养中 CO₂ 移除效率下降对 pH 的影响 |

**IND → BLA 的工艺演进**

进入后期开发（Phase III / BLA 阶段）后，需通过系统的工艺表征研究（Process Characterization）：

- 鉴别影响 CQA 的 **CPP（关键工艺参数）**
- 建立设计空间（Design Space）
- 对 CPP 范围进行严格的证据支持与法规申报

> **现场跟进建议：** 首次工艺放大时，强烈建议研发人员亲赴生产现场全程陪同，以快速响应放大过程中出现的偏差与异常，确保知识有效传递。

:::

## pH 检测：方法、标准与药典依据

:::answer

**检测方法**

采用 pH 计（酸度计）测定，以玻璃电极为指示电极、饱和甘汞电极或银-氯化银电极为参比电极，组成电化学电池进行电位法测定。仪器使用前需以标准缓冲液进行两点校正。

**控制标准**

- 目标值：依目标蛋白设计 pH 值
- 可接受范围：目标 pH ± 0.5
- 放行依据：每批次均需记录并满足限度要求

**药典依据**

《中国药典》2020 版三部通则 **0631 pH 值测定法**

**注意事项**

- 测量温度对 pH 读数有显著影响，应在恒温条件下测量或进行温度补偿
- 玻璃电极需定期保养，避免干燥保存
- 对于粘度较高或含蛋白的样品，需注意电极污染及清洗规程

:::

## 渗透压检测：原理、标准与临床安全边界

:::answer

**检测原理**

渗透压摩尔浓度（Osmolality，单位 mOsm/kg）通过**冰点降低法**测定，由渗透压摩尔浓度测定仪（Osmometer）完成。溶液中溶质粒子数量越多，冰点降低越大，对应渗透压越高。

渗透压是溶液的依数性之一，反映全部溶质（包括蛋白、盐类、糖类等）对渗透压的综合贡献。

**控制标准与临床意义**

| 参考范围 | 数值 |
|---|---|
| 正常人体血液渗透压 | 285–310 mOsm/kg |
| 0.9% NaCl（生理盐水） | ≈ 308 mOsm/kg |
| 5% 葡萄糖溶液 | ≈ 278 mOsm/kg |
| 注射制剂推荐控制范围 | **220–360 mOsm/kg** |

- **等渗溶液（与血浆接近）**：患者耐受性最佳，适用于所有注射途径
- **低渗溶液**：大多数注射部位可接受，但眼内注射等特殊部位须谨慎
- **高渗溶液**：通常导致注射部位刺激与不适，应尽量避免，或在配方设计时予以补偿

**申报阶段的限度要求**

- **IND 阶段**：限度可适当放宽，参照平台经验设定
- **BLA 阶段**：需基于多批次数据进行统计分析，合理收紧限度，提供充分的临床安全性支持数据

**药典依据**

《中国药典》2020 版三部通则 **0632 渗透压摩尔浓度测定法**

**配方设计原则**

- 最初进行溶解度与稳定性研究时，应将渗透压因素纳入考量
- 配方辅料选择遵循"最简化原则"：不引入非必要辅料，降低辅料间相互作用的复杂性，也便于出现问题时快速定位原因

:::

## 缓冲液体积管理：大规模生产中的工程挑战

:::answer

**问题背景**

随着工艺放大至中试（如 2000L）乃至商业规模，上下游各步骤所需的缓冲液体积同步大幅增加——从实验室的数十升，扩大至数百升乃至数千升，对厂房面积和物料管理提出严峻挑战。

**典型问题**

- 储存容器（缓冲液桶/袋）占地面积庞大
- 工业化生产厂房空间固定，难以灵活扩容
- 现配现用模式在大规模下操作复杂度高，质控风险增加

**解决方案：在线稀释（Inline Dilution）策略**

将缓冲液制备为 **5–10 倍浓缩液**，临用前通过在线精密稀释系统（Inline Dilution System）稀释至目标浓度，直接进入层析柱或下游操作单元。

| 优势 | 说明 |
|---|---|
| 显著节省储存空间 | 相同工艺量下，储液体积缩减 5–10 倍 |
| 降低污染风险 | 高浓度缓冲液微生物生长受抑，稳定性更优 |
| 提高操作灵活性 | 减少大型容器的搬运与清洁验证工作量 |
| 支持连续化制造 | 与连续层析（Periodic Counter-Current Chromatography, PCC）等技术兼容性好 |

> **验证要点：** 在线稀释系统的稀释精度、混合均一性及过程内控（电导率、pH 在线监测）是方法验证的核心，需确保稀释后缓冲液在目标范围内。

:::

## 氨基酸序列分析：从一级结构到序列变异体的全面表征

:::answer

**序列变异体的产生机制**

即使细胞株的 mRNA 序列完全正确，以下原因仍可导致氨基酸水平的序列变异（Sequence Variants）：

- **培养基中氨基酸耗尽**：氨基酸供应不足时，核糖体可能以结构相似的氨基酸替代，发生**氨基酸错误掺入（Amino Acid Misincorporation）**
- **密码子读码框偏差**：合成过程中偶发的错义突变
- **翻译后修饰**：酶促或非酶促修饰引入的化学变化（脱酰胺、氧化等）

**主要分析技术：LC-MS/MS 多层次表征**

液相色谱与质谱联用（LC-MS 或 LC-MS/MS）是一级结构表征的金标准技术，通过不同样品前处理方式，可获取以下多层次结构信息：

| 分析层次 | 可获得信息 |
|---|---|
| 完整分子量（Intact Mass） | 总分子量确认，宏观质量属性概览 |
| 脱糖分子量 | 去除糖链后的蛋白骨架分子量 |
| 还原分子量 | 轻链、重链的分子量确认 |
| 肽图分析（Peptide Mapping） | 氨基酸序列覆盖率，翻译后修饰定位与定量 |
| N/C 末端分析 | 末端异质性（C 末端 Lys 截短、信号肽切除）确认 |
| 糖基化位点分析 | N-糖型谱，糖化位点鉴别 |
| 翻译后修饰定量 | 脱酰胺、Met 氧化、二硫键配对、游离巯基 |
| 序列变异体检测 | 氨基酸错误掺入的定性定量分析 |

**补充技术：MALDI-TOF MS**

基质辅助激光解吸电离（MALDI-TOF）质谱可有效分析分子量 > 500 kDa 的大分子，产生单电荷离子，适用于：

- 完整抗体分子量快速确认
- 大分子翻译后修饰的初步筛查
- 与 ESI-MS 互补，提升表征覆盖度

**序列变异体分析的方法学要求**

序列变异体通常比例极低（< 0.1%），与正常序列抗体在理化性质上差异细微，对分析方法提出严苛要求：

- 需采用**高分辨率、高质量精度**的液质联用仪器（如 Orbitrap 系列）
- 分析方法应经过适当的**性能确认（Method Performance Qualification）**，涵盖专属性、灵敏度、定量范围
- 定量结果需与生物活性评估结合，评估序列变异体对安全性和有效性的潜在影响

> **工艺控制启示：** 序列变异体分析结果若提示特定氨基酸耗尽相关的变异，应回溯至上游培养工艺，优化补料策略，确保氨基酸（尤其是 Cys、Trp、Met、Asn 等易变异氨基酸）在整个培养过程中维持充足水平。

:::

## 温度：蛋白降解的驱动力与储存条件设计

:::answer

**温度与蛋白稳定性的基本关系**

温度是影响抗体制剂稳定性最关键的环境因素。根据阿伦尼乌斯（Arrhenius）方程，温度每升高 10°C，化学反应速率约增加 2–3 倍，蛋白降解速率随之显著加快。

**高温诱导的主要降解途径**

| 降解类型 | 机制 | 影响 |
|---|---|---|
| 氧化（Met、Trp、His） | 活性氧（ROS）与氨基酸侧链反应 | 结合活性下降，FcRn 亲和力改变 |
| 脱酰胺（Asn、Gln） | 酸碱催化，生成 Asp 或 iso-Asp | 电荷异构体增加，效力变化 |
| 骨架断裂 | 肽键水解，生成片段 | 纯度下降，免疫原性风险 |
| 聚集 | 蛋白去折叠后疏水暴露 | 安全性风险，通常不可逆 |

> **重要原则：** 高温导致的多数蛋白损伤（尤其是聚集和骨架断裂）具有**不可逆性**，一旦发生无法通过降温恢复，因此温度控制是制剂储存与运输管理的优先事项。

**储存温度的选择逻辑**

- 若分子在 **25°C** 下稳定性充分（加速稳定性实验验证），可选择室温储存，降低冷链成本
- 若 25°C 下不稳定，则需设定在 **2–8°C**，严苛情况下（如某些蛋白或核酸类药物）需 **-20°C 或 -80°C** 储存
- 储存温度选择应有系统的实时稳定性（Real-Time Stability）和加速稳定性（Accelerated Stability）数据支撑

:::

## 剪切力：生产全链路中的隐性蛋白损伤风险

:::answer

**剪切力的来源**

在单抗药物生产和使用全链路中，多个环节可产生不同程度的剪切应力（Shear Stress）：

| 来源 | 典型场景 |
|---|---|
| 生物反应器搅拌 | 桨叶旋转产生的湍流剪切 |
- 通气搅拌 | 气泡破裂时的界面剪切（气液界面） |
| 过滤操作 | 切向流过滤（TFF）中的膜面剪切 |
| 液体输送 | 泵、管道、阀门处的流动剪切 |
| 制剂灌装 | 灌装针头、蠕动泵处的局部高剪切 |
| 患者给药 | 注射器、输液管道产生的剪切 |
| 振动与摇晃 | 运输、混合过程中的机械振动 |

**剪切力诱导蛋白损伤的分子机制**

剪切力作用下，蛋白质分子所受的流体动力学应力超过其内部稳定力时，会发生：

1. 蛋白质构象展开，疏水核心暴露
2. 暴露的疏水区域相互吸引，形成聚集体
3. 气液界面处蛋白吸附，进一步促进聚集

含有高度疏水性区域的蛋白分子（疏水性氨基酸比例高、疏水性互补决定区 CDR）更容易受剪切力的影响。

**剪切力防护策略**

| 策略 | 机制 | 典型辅料 / 操作 |
|---|---|---|
| 添加非离子型表面活性剂 | 竞争占据气液界面，降低蛋白暴露 | Polysorbate 20/80（PS20/PS80）、Poloxamer 188 |
| 优化操作参数 | 降低搅拌转速、减少过滤压力 | 工艺设计优化 |
| 降低蛋白浓度 | 减少分子间碰撞概率 | 适用于高浓度制剂风险评估 |
| 配方缓冲体系优化 | 维持蛋白稳定折叠状态 | 赋形剂（蔗糖、海藻糖、精氨酸）协同稳定 |

> **实践提示：** 在商业化生产工艺开发中，应对全流程剪切力来源进行系统评估，并通过强制降解实验（Forced Degradation Study）验证各辅料（尤其是表面活性剂）的保护效果及其最适浓度。

:::

## 反应器生产工序：中间体控制与法规要求

:::answer

**工序目的**

生产生物反应器（Production Bioreactor）的目标是使细胞在受控条件下稳定表达足够量的目标蛋白，并确保其质量属性符合既定 CQA 要求，为后续纯化工序提供合格的细胞培养液（Harvest）。

**常见生产规模**

根据产品需求，生产规模通常涵盖：200L、500L、1000L、2000L、5000L、20000L，大规模灌注工艺下可实现更高的体积生产效率。

**中间体控制参数体系**

生产反应器中需对以下参数进行全程监控与控制：

| 控制参数 | 典型目标值 | 典型控制范围 | 监测方式 |
|---|---|---|---|
| 初始接种密度 | 0.3–0.8 × 10⁶ cells/mL | 目标值 ± 20% | 离线（细胞计数仪） |
| 接种细胞活率 | ≥ 90% | > 85% | 离线（台盼蓝排除法）|
| 培养温度 | 36–37°C（前期）/ 31–34°C（后期） | ± 0.5°C | 在线（热电阻） |
| 培养 pH | 7.0（典型） | ± 0.3 | 在线（pH 探头） |
| 溶氧（DO） | 40% | > 20% | 在线（DO 探头） |
| 搅拌转速 | 依规模而定 | ± 5 rpm | 在线 |
| 培养天数 | 依工艺而定 | 目标天数 ± 1 天 | 离线（取样监测活率） |

**IND vs. BLA 申报阶段的参数管理差异**

| 维度 | IND 阶段 | BLA 阶段 |
|---|---|---|
| 参数范围来源 | 平台经验 / 先验知识，范围较宽 | 系统工艺表征研究，基于数据的合理范围 |
| CPP 鉴定 | 非强制，可初步标注 | 必须系统鉴别 CPP，并与 CQA 关联 |
| 设计空间 | 不要求 | 需建立经实验验证的设计空间 |
| KPP 控制 | 目标值控制为主 | KPPs 须有严格范围，并通过 PAT 实时监控 |

**药典合规要求**

《中国药典》三部规定：在整个培养过程中，应监测细胞的生长状况，监测频率及指标应根据生产系统特点确定；应基于培养一致性研究，制定终止培养、废弃培养物及摒弃收获物的技术判定标准。

:::
