## 分析方法验证专属性（Specificity）：定义、验证策略与不同方法类型的应用逻辑

:::answer

**定义**

专属性（Specificity，也称特异性）是指在可能存在干扰组分（如杂质、降解物、基质成分等）的情况下，分析方法对目标被分析物进行**准确、可靠测定的能力**。专属性验证旨在证明该方法测定的结果能够准确反映供试品的真实鉴别特征、效价或纯度，而非受干扰因素影响的假阳性或假阴性结论。

**专属性在不同用途方法中的验证要求**

| 方法用途      | 专属性验证核心目标                   | 典型验证策略                                         |
| ------------- | ------------------------------------ | ---------------------------------------------------- |
| 鉴别试验      | 证明该方法能区分目标物与结构类似物   | 与已知类似物/降解物对照比较；阴性对照验证无交叉反应  |
| 含量/效价测定 | 证明干扰组分不影响目标物定量准确性   | 添加已知量杂质/降解物，考察回收率偏差                |
| 纯度/杂质测定 | 证明主峰与杂质峰能有效分离，无峰重叠 | 强制降解实验（热、酸、碱、氧化、光照）验证主峰特异性 |

**量化表达方式**

专属性与准确性相似，通常以<strong>偏差（Bias）</strong>或<strong>测定值与已知真值之间的误差率（%）</strong>表达。当专属性受到质疑时，可采用加标（Spike）对比实验量化干扰程度。

**重要实践原则：多方法组合验证**

单一分析方法往往难以对特定被分析物实现完全特异性。以重组蛋白纯度分析为例，除了常规 SDS-PAGE 和 SEC-HPLC 外，以下属性分析也能从不同维度间接反映产品纯度，形成互补的专属性验证体系：

- **生物学比活性：** 功能纯度的直接指标
- **等电点（iCIEF/cIEF）：** 电荷异质性层面的纯度验证
- **HCP ELISA：** 工艺相关蛋白杂质的专属性验证
- **肽图 + LC-MS：** 一级结构层面的序列特异性确认

**监管要求**

ICH Q2(R1) 明确要求：鉴别、杂质控制和含量测定的方法学论证均须包含专属性研究，且须根据方法的预期目的选择适当的验证策略，并提供证明性数据（如色谱图、光谱图等）。

:::

## 分析方法验证线性（Linearity）：建立要求、统计评价与不同类型方法的接受标准

:::answer

**定义**

线性（Linearity）是指在特定测量范围内，分析方法的测定结果与样品中被测物浓度（或含量）之间存在**直接比例关系**的能力。线性决定了方法的有效测量范围，是建立定量关系的基础。

**线性的量化表达**

线性关系通常通过以下统计参数描述：

| 统计参数          | 含义                    | 评估方式 |
| ----------------- | ----------------------- | -------- |
| 相关系数（r）     | 线性程度，越接近 1 越好 | 回归分析 |
| 决定系数（R²）    | 线性解释的变异比例      | 回归分析 |
| 斜率（Slope）     | 方法灵敏度的量化表征    | 线性回归 |
| 截距（Intercept） | 理想情况下应接近 0      | 线性回归 |
| 残差图            | 判断是否需要数学转换    | 图形检验 |

**建立线性的操作规范**

- 至少采用 **5 个浓度点**（覆盖高、中、低范围，包含 0% 和 150% 以上），特殊情况少于 5 点须有充分理由；
- 浓度点应均匀分布于测量范围内，避免集中在某一区域；
- 以测定信号（Y 轴）对浓度/含量（X 轴）作图，判断是否呈线性；
- 若散点图显示非线性，应在回归分析前进行数学转换（如对数转换、平方根转换等）；
- 用适当统计方法（推荐最小二乘法）估算回归参数，并报告 r 或 R²。

**不同类型方法的接受标准差异**

| 方法类型                           | 相关系数（r）要求                 | 背景                                 |
| ---------------------------------- | --------------------------------- | ------------------------------------ |
| 化学定量测定（如蛋白含量、纯度）   | ≥ 0.99                            | 方法精密，允许高线性要求             |
| 生物学活性测定（细胞法、动物模型） | ≥ 0.90                            | 生物学固有变异较大，接受标准相对宽松 |
| 杂质定量方法                       | 通常 ≥ 0.99（低浓度段须特别验证） | 须覆盖 LOQ 至 120% 规格上限          |

**非线性方法的处理**

部分生物学活性方法（如 ELISA 竞争法、细胞增殖法）本身呈"S"型（Sigmoidal）剂量-反应关系，不适合简单的线性回归分析。此类方法须通过<strong>平行线分析（Parallel Line Assay）</strong>或<strong>四参数 Logistic 模型（4PL）</strong>处理，评估样品与标准品之间的剂量-响应关系是否平行（即相对效价的有效性前提）。

:::

## 分析方法验证测定范围（Range）：确定依据、边界条件与特殊方法的范围设定

:::answer

**定义**

测定范围（Range）是指分析方法能够提供满足**准确性、精密性和线性**要求的最高浓度至最低浓度的区间。换言之，范围的两端（高限和低限）均须满足所有定量验证参数的接受标准。

**测定范围与线性范围的关系**

测定范围通常从线性研究中推导，但两者不完全相同：

- **线性范围：** 测定信号与浓度呈线性关系的区间
- **测定范围：** 在该区间内准确性、精密性和线性**同时满足要求**的区间

测定范围通常略小于或等于线性范围，因为在浓度极高（接近检测器饱和）或极低（接近 LOQ）时，线性可能仍然成立，但精密性或准确性已不满足要求。

**不同方法用途的最低范围要求（ICH Q2(R1) 推荐）**

| 方法用途               | 建议测定范围下限        | 建议测定范围上限                   |
| ---------------------- | ----------------------- | ---------------------------------- |
| 原料药/制剂含量测定    | 80% of 规格浓度         | 120% of 规格浓度                   |
| 杂质定量测定           | LOQ（定量限）           | 120% of 规格上限（或已知最高水平） |
| 溶出度测定             | 最低溶出规格的 20% 以下 | 最高溶出规格的 120% 以上           |
| 效价测定（生物学活性） | 参考标准品相对效价 50%  | 参考标准品相对效价 200%            |

**确定范围的验证逻辑**

范围的确认须通过实验证明：在范围内（包括高限和低限处）的样品测定，均能获得满足要求的准确性（≥回收率目标，偏差 <2%～5%）、精密度（CV% 满足要求）和线性（r ≥ 0.99 或方法特定标准）。范围两端的样品须特别验证，不能仅凭中间浓度数据外推。

**范围超出的判断**

当样品浓度高于测定范围上限时，须进行适当稀释后重新测定，稀释须在验证的线性范围内，且稀释操作须经过稀释线性（Dilutional Linearity）验证。

:::

## 分析方法验证精密度（Precision）：重复性、中间精密度与重现性的层次定义与验证设计

:::answer

**重要说明**

原文中将该条目标题写为"准确性（Accuracy）"，但实际内容描述的是**精密度（Precision）**。本节按实际内容（精密度）进行系统整理，同时在末尾补充准确性的核心要点。

---

**精密度的定义与三层结构**

精密度（Precision）是指在相同实验条件下，对同一均匀样品进行多次测定，各测定值之间的**一致性或接近程度**，通常以变异系数（CV%）= 标准差（SD）/ 均值 × 100% 表示。

精密度分为三个层次，须分别验证：

| 层次   | 名称                                 | 定义                                                                   | 变化因素                 |
| ------ | ------------------------------------ | ---------------------------------------------------------------------- | ------------------------ |
| 第一层 | 重复性（Repeatability）              | 同一次实验内，同一操作者、相同仪器、相同试剂，短时间内重复测定的一致性 | 仅随机误差               |
| 第二层 | 中间精密度（Intermediate Precision） | 同一实验室内，不同日期、不同操作者、不同仪器批次间的一致性             | 实验室内系统变量         |
| 第三层 | 重现性（Reproducibility）            | 不同实验室之间对同一样品测定的一致性                                   | 实验室间差异（协作研究） |

**重复性（Repeatability）验证设计**

- 配制 **3 个浓度水平**（测量范围的高、中、低，通常为 80%、100%、120% 目标浓度）；
- 每个浓度水平在**同一次实验内**独立重复测定 **≥ 6 份**（也可用 9 份：3 浓度 × 每浓度 3 份，但须整体 CV 满足要求）；
- 计算每个浓度水平的均值、SD 和 CV%；
- 接受标准：生物制品含量测定通常要求重复性 CV% ≤ 5%；生物学活性方法通常放宽至 CV% ≤ 25%～30%（视方法固有变异而定）。

**中间精密度（Intermediate Precision）验证设计**

- 配制 **3 个浓度水平**（同重复性）；
- 在 **≥ 3 次独立实验**中，每次对每个浓度各测定 ≥ 3 份；
- 3 次独立实验须涵盖以下变量中的至少两项：不同工作日、不同批次实验材料（试剂、标准品等）、不同操作员；
- 计算各次实验间的 CV%（实验间精密度）；
- 此验证数据是支持方法转移和在不同实验室使用的重要依据。

**重现性（Reproducibility）验证要求**

重现性主要通过**实验室间协作研究**评估，对于须收载至药典或供多个实验室使用的方法尤为重要。通常须有 ≥ 2 家合格实验室参与，使用统一的参考标准品和方法 SOP，统计各实验室测定结果的总体 CV%。

---

**准确性（Accuracy）补充**

准确性是指测定值与真实值（或已知参考值）之间的**接近程度**，通常以回收率（Recovery %）或偏差（Bias）表达：

```
回收率（%）= 测定值 / 已知真值 × 100%
偏差（%）= （测定值 - 真值）/ 真值 × 100%
```

验证设计：在测量范围内至少 3 个浓度水平（每个 ≥ 3 份），计算各浓度回收率；典型接受标准为回收率 98%～102%（化学定量方法），生物学方法可放宽至 85%～115%。

:::

## 分析方法验证检测限（LOD）：信噪比法、标准差法的计算原理与不同分析场景的适用性

:::answer

**定义**

检测限（Limit of Detection, LOD）是指分析方法能够从背景信号中**可靠地识别和区分**被分析物的最低量或最低浓度。LOD 不要求对被分析物进行准确定量，仅要求能够被检测到（即信号显著高于背景/噪声）。

**LOD 的三种确定方法**

**方法一：直观评价法（Visual Evaluation）**

- 适用范围：仪器法和非仪器法（如目视比色、TLC 等）均可使用；
- 操作：对一系列**已知浓度逐步降低**的样品进行测定，以能够**可靠地检测到**被分析物的最低浓度作为 LOD；
- 须同时提供证明性数据（如色谱图，标注最低可检测浓度对应的峰）。

**方法二：信噪比法（Signal-to-Noise Ratio, S/N）**

- 适用范围：仅适用于存在**基线噪声**的仪器分析方法（如 HPLC、GC、荧光检测等）；
- 操作：比较含已知低浓度被分析物的样品信号与空白样品信号，确定被分析物可被可靠检测的最低浓度；
- 接受标准：**S/N = 3:1 或 2:1** 时的浓度通常被认定为 LOD（不同法规/应用场景有所不同，须说明采用标准）；
- 须提供代表性色谱图（含目标浓度处的峰和基线噪声）。

**方法三：基于标准差和斜率的计算法**

$$LOD = \frac{3.3\sigma}{S}$$

其中 σ 为响应值的标准差，S 为校正曲线的斜率。σ 可通过以下三种方式估算：① 空白样品多次测定的响应值标准差；② 校正曲线在低浓度段的残差标准差；③ 截距的标准误差。

**LOD 验证后的确认要求**

无论采用何种方法确定 LOD 估算值，均须通过实验**逐个分析接近或等于 LOD 的样品**，验证在该浓度下能够被可靠检测。须同时报告 LOD 值和确定 LOD 所采用的方法。

**生物测定（生物学活性方法）的 LOD 特殊规定**

对于生物学活性测定，LOD 定义为产生**始终如一地高于空白对照**的最低浓度。具体接受标准：产生的信号比空白对照高 **2～3 个 SD** 通常被认为满足 LOD 检测要求（须在方法 SOP 中明确统计规则）。

## 分析方法验证定量限（LOQ）：信噪比法、标准差法的计算与杂质检测方法中的关键意义

:::answer

**定义**

定量限（Limit of Quantitation, LOQ）是指在**准确性和精密性均满足方法要求**的前提下，分析方法能够可靠定量测定的样品中被分析物的**最低量或最低浓度**。LOQ 是杂质定量检测方法的核心参数之一，直接决定方法能否满足低水平杂质的质量控制需求。

**LOQ 与 LOD 的关系**

```
LOD < LOQ（LOQ > LOD，通常 LOQ ≈ 3 × LOD）
LOD：可检测的最低量（不要求定量准确）
LOQ：可准确定量的最低量（须满足精密性和准确性要求）
```

**LOQ 的三种确定方法**

**方法一：直观评价法**

在准确度（回收率目标）和精密度（CV% 目标）均满足要求的条件下，对一系列含已知浓度被分析物的样品进行测定，找出能被**准确和精密地定量测定**的最低浓度，即为 LOQ。须同时满足：回收率达到方法要求（如 80%～120%），CV% 满足要求（如 ≤ 20%）。

**方法二：信噪比法**

测量含已知低浓度被分析物的样品与空白的信号比，建立被测物能被**准确定量**的最低浓度。典型接受标准：**S/N = 10:1** 时对应的浓度作为 LOQ（区别于 LOD 的 S/N = 3:1）。

**方法三：基于标准差和斜率的计算法**

$$LOQ = \frac{10\sigma}{S}$$

其中 σ 为响应值的标准差，S 为校正曲线的斜率（计算方式同 LOD，但系数为 10 而非 3.3）。

**LOQ 在杂质检测中的实践意义**

| 场景                                        | LOQ 的作用                                                   |
| ------------------------------------------- | ------------------------------------------------------------ |
| 工艺相关杂质（HCP、HCD、Protein A）限度设定 | LOQ 必须低于质量标准限度，否则无法有效监控                   |
| 降解杂质监控（氧化、脱酰胺等）              | LOQ 决定可检测的最低降解水平，影响稳定性方法的灵敏度要求     |
| 基因组 DNA 残留（目标：≤10ng/剂量）         | LOQ 须远低于 10ng/剂量，一般 qPCR 方法可达 pg 级别           |
| 毒性杂质（元素杂质、有机溶剂残留）          | LOQ 须满足 ICH Q3C/Q3D 要求的可接受每日暴露量（PDE）相关浓度 |

**LOQ 验证后的实验确认**

确定 LOQ 估算值后，须通过实验在该浓度下验证：精密度（重复性 CV%）和准确度（回收率）均达到预定标准。建议同时在 LOQ 浓度进行 ≥ 6 次重复测定，报告 CV% 和平均回收率。

:::

## 分析方法验证耐用性（Robustness）：参数扰动设计、系统适用性的建立与方法风险识别

:::answer

**定义**

耐用性（Robustness）是指分析方法在**各种实验参数发生小幅度有意变化**时，其测定结果保持**不受显著影响的能力**，体现了方法在日常使用中的可靠性和稳定性。

**耐用性验证的时机**

耐用性研究应在方法研制阶段（方法开发完成、正式验证开始前）进行，以便及时发现敏感参数并在方法 SOP 中加以规定，防止日后出现批放行失败或实验室间结果不一致的问题。

**常见耐用性考察参数（典型示例）**

| 方法类型             | 典型考察参数                                              | 扰动范围示例                     |
| -------------------- | --------------------------------------------------------- | -------------------------------- |
| HPLC 方法            | 流动相组成（有机相比例）、pH、柱温、流速、色谱柱批次/品牌 | 有机相 ± 2%；pH ± 0.2；柱温 ± 5℃ |
| 生物学活性（细胞法） | 细胞传代次数、孵育温度、孵育时间、培养基批次              | 温度 ± 1℃；时间 ± 30min          |
| ELISA 方法           | 孵育温度、包被液/封闭液条件、显色时间、读板波长           | 温度 ± 2℃；时间 ± 5min           |
| 生化法（如福林酚法） | 室温（季节/地区差异）、显色时间、试剂浓度                 | 室温 ± 5℃；时间 ± 2min           |

**耐用性研究的设计方法**

推荐采用 **Plackett-Burman 设计（部分因子实验设计）**同时考察多个参数的影响，效率远高于单变量逐一扰动。对于参数较少（≤ 3 个）的方法，也可采用单变量扰动设计。

**耐用性结果的处理**

- 若某参数的变化对结果影响**显著**（超出方法接受标准）：须在方法 SOP 中明确该参数的严格控制范围，并将其纳入系统适用性检查项目；
- 若所有考察参数的变化对结果影响**不显著**：说明方法耐用性良好，可在该参数波动范围内正常使用。

**与系统适用性的衔接**

耐用性验证的结果是建立**系统适用性参数（System Suitability Parameters, SSP）**的依据：通过耐用性研究识别出的敏感参数，需要转化为系统适用性检查项，确保每次使用方法时均能验证方法处于受控状态。

:::

## HPLC 分析方法的系统适用性参数：理论塔板数、分离度、重复性与拖尾因子的接受标准

:::answer

**定义与目的**

系统适用性（System Suitability）是对**分析仪器系统整体性能**（设备、电子仪器、实验操作和被分析样品共同构成的系统）的综合评估，在每次正式分析前执行，以确认该次实验的分析系统满足方法要求，从而保证测定结果的有效性。

系统适用性不是方法验证的组成部分，而是**每次使用分析方法时的质量保障手段**，是方法 SOP 的固定组成部分。

**HPLC 系统适用性的四个核心参数**

**① 理论塔板数（Theoretical Plate Number, N）**

$$N = 16 \times \left(\frac{t_R}{W}\right)^2 = 5.54 \times \left(\frac{t_R}{W_{1/2}}\right)^2$$

其中 tR 为保留时间，W 为峰宽（基线），W₁/₂ 为半高峰宽。

- **物理意义：** 反映色谱柱的分离效能，N 越大，峰越窄，分离能力越强；
- **影响因素：** 柱长、填料粒径、填充均匀性、流速、温度；
- **处理原则：** 若实测 N 低于方法要求，须调整色谱条件（更换柱型、调整流速/温度）或更换色谱柱，直至 N 满足要求后方可进行正式分析。

**② 分离度（Resolution, Rs）**

$$R_s = \frac{2(t_{R2} - t_{R1})}{W_1 + W_2}$$

- **接受标准：** Rs ≥ **1.5**（基线分离；Rs ≥ 2.0 为完全分离）；
- **适用场景：** 含两个或以上组分的定量分析（如主峰与相邻杂质峰之间）须验证分离度是否满足准确定量的要求；
- **重要性：** 分离度不足会导致峰重叠，影响面积积分准确性，进而影响含量/纯度计算结果。

**③ 重复性（Repeatability of Injection）**

- **操作方式：** 对照品/标准品连续进样 **≥ 5 次**（通常 5～6 次），计算各次进样峰面积或峰高的 RSD%；
- **接受标准：** 峰面积 RSD% ≤ **2.0%**（ICH Q2(R1) 通用要求；对于低浓度杂质可适当放宽至 5%）；
- **意义：** 确认进样系统（自动进样器/手动进样）、检测器和数据处理系统的稳定性。

**④ 拖尾因子（Tailing Factor, T）**

$$T = \frac{W_{0.05}}{2f}$$

其中 W₀.₀₅ 为峰高 5% 处的峰宽，f 为峰高 5% 处从峰起始到峰顶所对应的宽度。

- **接受标准：** T 应在 **0.95～1.05** 范围内（理想对称峰 T = 1.0）；
- **适用场景：** 主要用于**峰高法**定量分析；峰面积法受拖尾影响相对较小，但仍建议监控；
- **实践意义：** T > 1.5 通常意味着色谱柱老化、流动相条件不当或有强保留杂质，须排查原因。

**系统适用性失败的处理原则**

若系统适用性任一参数不满足要求，须停止正式分析，排查并解决问题（重新平衡色谱柱、更换流动相/色谱柱、重新校准仪器等），问题解决后重新进行系统适用性测试，通过后方可开始正式样品分析。系统适用性失败的记录和处理须完整文件化。

:::

## 抗体分子量检测方法的原理与选型：还原型 SDS-PAGE 与质谱法的互补应用策略

:::answer

**两类主要方法的原理对比**

**还原型 SDS-PAGE**

在 SDS（十二烷基硫酸钠）和 β-巯基乙醇（还原剂，打开二硫键）的共同作用下，蛋白质在沸水浴（95℃，5 min）后充分变性展开，形成带大量均匀负电荷的线性杆状分子，消除了分子形态和自身电荷差异对电泳迁移率的影响。在电场中，蛋白质的迁移率**基本仅与分子量相关**，通过与已知分子量的标准蛋白标记对比，可估算供试品的分子量。

| 优势                                | 局限性                                     |
| ----------------------------------- | ------------------------------------------ |
| 操作简便、快速，成本低              | 测定误差较大（≥10000 Da 的蛋白误差约 10%） |
| 直观可视化（染色后可见条带）        | 对小分子蛋白和多肽误差更大                 |
| 可同时鉴别多条链（如抗体重链/轻链） | 无法区分同分异构体                         |
| 适合日常批放行质控                  | 无法准确测定含糖基化修饰蛋白的真实分子量   |

**质谱法（Mass Spectrometry）**

质谱法通过测定蛋白离子的<b>质荷比（m/z）</b>计算分子量，精确度可达千分之三（3‰），远超 SDS-PAGE。两种主要电离技术：

| 电离技术                  | 全称                                        | 特点                                                                               | 适用场景                                                                 |
| ------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| ESI（电喷雾离子化）       | Electrospray Ionization                     | 产生多电荷态峰系列（多个 m/z 峰），从峰系列计算真实分子量；可与 HPLC 联用（LC-MS） | 均一蛋白、肽图分析；不适用于高度不均一样品（如复杂糖蛋白、PEG 修饰蛋白） |
| MALDI（基质辅助激光解析） | Matrix-Assisted Laser Desorption/Ionization | 通常产生单/双电荷峰，计算简单；样品需极少（微升级别）                              | 不均一样品的平均分子量（如复杂糖基化蛋白）；凝胶中蛋白的直接鉴定         |

**ESI vs. MALDI 的选型逻辑**

- 均一重组蛋白（确认一级结构）→ **ESI-MS（LC-MS）**，精度高，可与 HPLC 分离联用；
- 高度不均一样品（含复杂糖基化修饰的抗体、PEG 修饰蛋白）→ **MALDI-TOF-MS**，可测定平均分子量；
- 酶切肽图分析 → **ESI-MS（LC-MS/MS）**，兼顾肽段分离与序列鉴定。

**实际质控策略：SDS-PAGE 与质谱的互补应用**

鉴于 SDS-PAGE 测定分子量的局限性和质谱仪器的高成本，实践中通常采用以下分层策略：

1. **参比品/对照品建立阶段（一次性深入表征）：** 采用质谱法（LC-MS）对参比品进行精确分子量测定，作为真实分子量的权威依据；
2. **日常批放行阶段（高频率快速检测）：** 采用还原型 SDS-PAGE，证明供试品与参比品的条带位置一致，确认分子量在可接受范围内——**无需每批进行高精度质谱测定**。

这一策略将质谱的准确性与 SDS-PAGE 的便捷性有机结合，实现了质控效率与成本的最优平衡。

:::

## 抗体等电点的测定方法与原理：IEF 电泳、cIEF/iCIEF 的技术特征与质控意义

:::answer

**等电点（pI）的定义与质控意义**

等电点（Isoelectric Point, pI）是蛋白质在电场中净电荷为零时对应的溶液 pH 值。对于重组抗体药物，pI 的测定具有以下质控价值：

- **产品鉴别：** 每种蛋白质具有特定的等电点或等电聚焦图谱（pI 带/峰分布），是分子特征性标志；
- **工艺稳定性监控：** 批间 pI 分布图谱的一致性直接反映生产工艺的稳定性，pI 发生漂移可能提示糖基化或修饰状态发生变化；
- **电荷变体分析：** 重组蛋白普遍存在多个 pI 带（由翻译后修饰导致），通过 pI 分析可监控电荷变体的分布状态。

**重组蛋白 pI 不均一性的来源**

| 变异来源                   | 对 pI 的影响                     |
| -------------------------- | -------------------------------- |
| N 端焦谷氨酸化（pyroGlu）  | 失去正电荷 → pI 降低（酸性漂移） |
| C 端赖氨酸不完全剪切       | 保留正电荷 → pI 升高（碱性漂移） |
| 脱酰胺（Asn → Asp/isoAsp） | 引入负电荷 → pI 降低             |
| 唾液酸化（糖型差异）       | 唾液酸携带负电荷 → pI 降低       |
| N 端甲硫氨酸有无           | 影响末端电荷                     |
| 二硫键错配                 | 影响局部电荷分布                 |

**三种主要 pI 检测方法的对比**

| 方法          | 全称                 | 操作特点                                         | 优势                                   | 局限                             |
| ------------- | -------------------- | ------------------------------------------------ | -------------------------------------- | -------------------------------- |
| 传统 IEF 电泳 | Isoelectric Focusing | 在两性电解质 pH 梯度中电泳，银染或考马斯染色显色 | 直观，成本低                           | 操作繁琐，分辨率有限，定量能力差 |
| cIEF          | Capillary IEF        | 毛细管中进行 IEF，紫外检测                       | 自动化程度高，灵敏度高，样品用量少     | 需要专用仪器                     |
| iCIEF         | Imaging cIEF         | 全柱实时成像检测，无需动员（Mobilization）步骤   | 分辨率最高，操作最简便，结果可直接定量 | 仪器成本最高                     |

**测定流程要点（以 iCIEF 为例）**

1. 样品须提前**脱盐**（盐离子会干扰 pH 梯度的建立）；
2. 配制含样品、两性电解质（Ampholyte）、pI 标准品（用于校准）和稳定剂的混合液；
3. 进样至毛细管，施加高压聚焦，全柱实时成像检测各 pI 带的迁移位置；
4. 以 pI 标准品为参照，计算样品各峰的 pI 值；
5. 统计主峰和酸性峰/碱性峰的相对百分比，与参比品或历史数据比对。

**质控要求**

重组蛋白的 pI 往往不均一（呈多个 pI 带），但**批与批之间的电泳图谱（峰位置和相对面积分布）应保持一致**，这是评判生产工艺稳定性的重要指标。质量标准中通常规定主要 pI 范围（如 pI 主峰须在 X.X ± 0.X 范围内）和酸性/碱性峰的比例上限。

:::

## 重组抗体一级结构鉴别方法：肽图分析的原理、裂解策略与质控应用

:::answer

**肽图分析（Peptide Mapping）的定位与用途**

肽图分析是重组蛋白一级结构鉴定与比较的**核心手段**，通过特异性裂解蛋白质（化学法或酶法），将蛋白质切割成固定大小的多个肽段，再通过色谱分离并结合质谱检测，实现对一级结构的精确表征。

**肽图分析的主要用途：**

- **产品鉴别（Identification）：** 与对照品肽图对比，确认氨基酸序列一致性；
- **序列确证（Sequence Confirmation）：** 配合 LC-MS/MS，逐肽段验证氨基酸序列；
- **修饰位点鉴定：** 定位脱酰胺、氧化、糖基化、二硫键等翻译后修饰的具体位置；
- **工艺稳定性监控：** 同种产品不同批次的肽图一致性是工艺稳定性的验证指标；
- **可比性研究基础：** 工艺变更前后的肽图比对是可比性评估的关键数据。

**蛋白裂解策略的比较与选择**

**① 化学裂解法（以溴化氰 CNBr 为例）**

| 特点     | 描述                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 裂解位点 | 甲硫氨酸（Met）C 端，特异性高，裂解位点少                                        |
| 优势     | 裂解简单，结果可重复，对一级结构的基本骨架确认有效                               |
| 局限     | 裂解位点少，对一级结构变化的检出灵敏度低；试剂毒性强（HCN 等），须在通风橱中操作 |
| 实验要求 | 须与阳性对照同时操作，进行比较分析                                               |

**② 蛋白酶裂解法（以胰蛋白酶为例，最常用）**

| 特点       | 描述                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------- |
| 裂解位点   | Lys 和 Arg 的 C 端（赖氨酸/精氨酸），裂解位点多，肽段覆盖全面                                |
| 优势       | 操作安全，非特异性降解少；位点多，能全面检出氨基酸变化；LC-MS/MS 联用可完整测定序列          |
| 局限       | 不易降解完全（尤其含二硫键结构复杂的区域）；酶自身属于蛋白质，对结果有一定干扰               |
| 常见辅助酶 | Lys-C（仅切 Lys C 端）、Asp-N（切 Asp N 端）、Glu-C（切 Glu C 端）——多酶组合可提高序列覆盖度 |

**含二硫键蛋白的特殊处理流程**

对于含有复杂二硫键结构的蛋白（如 IgG 的链间/链内二硫键），直接酶切往往因二硫键连接导致肽段未完全分离，须先进行还原烷基化处理：

```
蛋白 + 还原剂（DTT/β-巯基乙醇）→ 二硫键打开为巯基（-SH）
        ↓
烷基化试剂（碘乙酰胺/IAA）封闭巯基（-S-CH₂CONH₂）
        ↓
防止巯基重新氧化形成二硫键
        ↓
按常规流程进行酶切和 LC-MS 分析
```

**样品纯度与缓冲液要求**

肽图分析对样品纯度要求较高（须 ≥ 95.0%），且须对样品进行**脱盐处理**（透析至水或低盐裂解缓冲液，盐离子会影响酶活性和 LC-MS 检测）。

**检测与数据分析**

| 分析平台             | 信息维度                                                     |
| -------------------- | ------------------------------------------------------------ |
| RP-HPLC（UV 检测）   | 肽段色谱图谱（峰个数、相对保留时间），与对照品比对一致性     |
| LC-MS（精确质量数）  | 确认各肽段的分子量，检出修饰（如脱酰胺、氧化导致的质量偏移） |
| LC-MS/MS（序列测定） | 通过碎片离子系列（b/y 离子）逐氨基酸确认序列                 |

:::

## 分析方法开发的时间线规划：从瞬转样品到方法验证的阶段性里程碑

:::answer

**分析方法开发的整体时间框架**

分析方法开发应尽早启动，从项目立项（分子确定）开始，贯穿整个研发生命周期，直至商业化阶段的方法持续改进。关键里程碑如下：

```
分子确定 / 瞬转样品获得
        ↓
平台方法适用性评估（快速了解检测难点）
        ↓
IND 前方法开发与初步确认（~18 个月）
        ↓
IND 申报（放行方法已初步确认）
        ↓
方法持续优化（临床 I～II 期）
        ↓
中式生产（Pilot Scale）前完成放行与表征方法确认
        ↓
BLA 前完成全面方法验证（耗时 1～2 个月）
        ↓
BLA 申报 / 商业化生产
```

**各开发阶段的方法要求差异**

| 阶段              | 放行方法要求                     | 表征方法要求        |
| ----------------- | -------------------------------- | ------------------- |
| 临床前/毒理学研究 | 无需经过验证，但须基本可行       | 用于产品特征分析    |
| IND 申报          | 须完成方法初步确认（非全面验证） | 须支持 CQA 初步评估 |
| 临床 I 期         | 放行方法须经过初步验证           | 持续完善            |
| 临床 II/III 期    | 放行方法须完成全面验证           | 须支持工艺表征研究  |
| BLA 申报          | 全面验证，验证报告齐全           | 须支持 CQA 最终确认 |

**生物学活性方法：潜在关键路径（Critical Path）**

生物学活性（Biological Activity）方法由于其固有复杂性，通常是方法开发周期中**最长的瓶颈**，须重点关注并提前规划：

- 细胞法（细胞增殖、细胞杀伤、报告基因法）开发周期长，须建立稳定的细胞库；
- 须完成细胞库的表征、方法的稳健性优化、参比品的标定（至少两个实验室，≥15 次赋值）；
- 方法转移至 QC 部门后须进行实验室间精密度验证；
- 建议将生物学活性方法开发列为独立的 Critical Path 项目，单独跟踪进度。

**验证周期规划**

完整的分析方法验证（含专属性、线性、范围、准确性、精密度、LOD/LOQ、耐用性）通常需要 **1～2 个月**。考虑到 BLA 申报时间节点，须提前规划验证批次的选择（建议在 PPQ 批次后进行，以验证用于商业化批放行的方法）。

:::

## 理化对照品与生物学活性标准品的建立策略：赋值方法、稳定性要求与质量标准框架

:::answer

**两类标准品的定位与用途**

| 标准品类型                                        | 主要用途                                               | 建立时机                           |
| ------------------------------------------------- | ------------------------------------------------------ | ---------------------------------- |
| 理化对照品（Reference Standard）                  | 用于分子量、pI、肽图、纯度等理化方法的参照             | 生产工艺稳定、开始质量控制研究初期 |
| 生物学活性标准品（Biological Reference Standard） | 用于生物学活性测定方法（报告基因、细胞法等）的效价赋值 | 同上，但建立周期更长               |

**理化对照品的建立要求**

**① 原料选择**

- 选取至少一批由**稳定工艺**生产的原液（须有完整的工艺记录和批检验数据）；
- 首选工艺锁定后的批次，确保对照品与未来商业化产品的工艺一致性。

**② 表征要求（深度结构确证）**

| 分析维度   | 主要检测项目                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------- |
| 一级结构   | 氨基酸序列（肽图 + LC-MS/MS）、N/C 端序列（Edman 降解）、质量肽图（全序列覆盖度）、精确分子量   |
| 二硫键     | 二硫键组成（非还原肽图 + LC-MS）、游离巯基                                                      |
| 翻译后修饰 | 糖谱（N-糖亚型分布）、糖基化位点（糖肽 + LC-MS）、修饰类型（Man5、G0F、G1F 等比例）、唾液酸含量 |
| 高阶结构   | SEC（聚体/单体）、IEX/cIEF（电荷变体分布）                                                      |

**③ 稳定性研究**

须在建立时启动**加速和实时稳定性研究**，确认对照品在规定储存条件（通常 -70℃ 分装冻存）下的稳定性，建立有效期。

**生物学活性标准品的赋值方法**

**① 赋值设计要求**

- 选至少 **2 家实验室**（建议 3 家以上，含使用单位和独立第三方实验室）参与赋值协作研究；
- 每个实验室进行 **≥ 15 次独立测定**（分布在不同工作日，涵盖不同试剂批次和操作员）；
- 赋值结果汇总后进行统计分析（通常采用方差分析 ANOVA + 几何均数法），确定活性赋值及其不确定度（95% 置信区间）。

**② 国际单位（IU）的使用**

若 WHO 对该产品类型已建立国际参考品，应将活性标准品与 WHO 参考品进行比对，以 IU（国际单位）表示生物学活性，确保全球实验室间的可比性。

**③ 标准品使用中的管理要求**

- 分装冻存，每次从冻存管取用一份，不得反复冻融（反复冻融导致活性损失）；
- 建立工作标准品（Working Reference Standard，WRS），以主标准品（Primary Reference Standard）标定，减少主标准品的消耗；
- 定期监控在用工作标准品的稳定性，与主标准品比对一致性。

:::

## 重组蛋白药物的鉴别策略：免疫学、理化特性与一级结构三维度的多方法组合

:::answer

**鉴别的监管要求与目的**

鉴别（Identification）是质量标准中确认产品身份的核心项目，须证明供试品确实是目标产品，而非其他蛋白或错误产品。对于生物药物，单一方法往往不足以实现完整鉴别，通常须采用多维度方法组合。

**三大鉴别维度**

**① 免疫学鉴别（Immunological Identification）**

利用**抗原-抗体特异性结合**原理进行鉴别，方法包括：

| 方法                     | 检测形式                | 特点                         |
| ------------------------ | ----------------------- | ---------------------------- |
| 免疫印迹（Western Blot） | 膜转印 + 特异性抗体显色 | 可同时确认分子量和免疫特异性 |
| 免疫斑点（Dot Blot）     | 膜点样 + 特异性抗体显色 | 操作简便，半定量             |
| ELISA                    | 液相竞争或夹心法        | 灵敏度高，可定量             |

对于**融合蛋白药物（如 Fc 融合蛋白、抗体偶联药物）**，须分别针对**目标蛋白域**和<strong>载体蛋白域（如 Fc 区）</strong>进行免疫鉴别，以同时确认融合蛋白的免疫结合特性和分子完整性。

**② 理化特性鉴别（Physicochemical Identification）**

- **等电点（pI）：** 每种蛋白具有特征性的 pI 或 pI 带分布图谱，通过 IEF、cIEF 或 iCIEF 测定，与参比品图谱比对；
- **分子量：** 还原型 SDS-PAGE（与参比品条带位置一致）或质谱法（精确分子量）；
- **糖基化图谱：** 对于糖蛋白，N-糖谱（HILIC-HPLC 或 LC-MS）也可作为特征性鉴别指标。

**③ 一级结构鉴别（Primary Structure Identification）**

| 方法                     | 信息维度                                           |
| ------------------------ | -------------------------------------------------- |
| Edman 降解（N 端测序）   | 给出 N 端特征性 15 个氨基酸序列，快速确认 N 端身份 |
| 肽图分析（RP-HPLC 肽图） | 与经过结构确证的对照品比对，确认整体一级结构一致性 |
| LC-MS/MS 肽图            | 精确氨基酸序列确认，检出修饰，序列覆盖度最高       |

**鉴别方法的组合策略（实际应用）**

在放行检测中，通常不要求每批次都进行全套三维度鉴别，而是：

- **日常放行：** 选择 1～2 种快速、操作简便的鉴别方法（如 iCIEF/SDS-PAGE 与靶抗原结合 ELISA 组合）；
- **对照品建立/工艺变更可比性研究：** 进行全套三维度、多方法深度鉴别；
- **IND 阶段：** 须证明关键鉴别方法的基本可行性；BLA 阶段须提供完整的鉴别方法验证数据。

:::

## 纯度与异质性分析策略：多方法互补体系的构建与产品变异体的监控要求

:::answer

**多方法互补的必要性**

重组蛋白药物的纯度分析须采用**多种分析方法**，因为单一方法只能检测某一维度的杂质或异质性，而不同方法分别基于不同的分离原理，各有检测盲区。

**主流纯度/纯度相关分析方法体系**

| 分析方法         | 分离原理                     | 主要检测维度               | 代表性检测项            |
| ---------------- | ---------------------------- | -------------------------- | ----------------------- |
| SEC-HPLC         | 分子大小                     | 聚体/单体/片段             | HMW%、主峰%、LMW%       |
| CE-SDS（非还原） | 分子大小 + SDS 变性          | 分子量分布（保留共价聚体） | 非还原纯度、共价聚体%   |
| CE-SDS（还原）   | 分子大小（还原，打开二硫键） | 重链/轻链纯度，链间片段    | HC%、LC%                |
| SDS-PAGE         | 分子大小（凝胶电泳）         | 条带纯度（半定量）         | 主条带纯度、杂质条带    |
| IEX-HPLC         | 表面电荷                     | 电荷变异体                 | 酸性峰%、主峰%、碱性峰% |
| iCIEF/cIEF       | 等电点                       | 电荷变异体，pI 分布        | pI 主峰位置和比例       |
| RP-HPLC          | 疏水性                       | 氧化变体、聚体（部分）     | 主峰%、氧化变体%        |

**SEC-HPLC vs. CE-SDS 在聚体检测中的重要差异**

两种方法均常用于聚体检测，但测定原理和结果有显著差异：

| 对比维度       | SEC-HPLC                                               | CE-SDS                                               |
| -------------- | ------------------------------------------------------ | ---------------------------------------------------- |
| 聚体维持条件   | 天然状态（保留非共价相互作用，NCI 和 CI 聚体均可检测） | SDS 存在（破坏非共价相互作用，**仅能检测共价聚体**） |
| 测定的聚体类型 | 共价聚体 + 非共价聚体                                  | 仅共价聚体                                           |
| 测定聚体水平   | **通常高于 CE-SDS**                                    | 通常低于 SEC-HPLC                                    |
| 监管认可度     | 聚体 CQA 控制的**首选方法**                            | 作为互补方法，用于共价聚体的专属性检测               |

> **结论：** SEC-HPLC 更能代表实际的总聚体水平，是放行标准中聚体控制的首选方法。CE-SDS 可作为互补，专属地检测共价聚体（对热稳定性和病毒去除工艺评估有价值）。

**产品变异体的监控框架**

重组蛋白在生产或储存过程中易产生的变异体及其分析方法：

| 变异体类型    | 形成原因                    | 推荐分析方法                  | 质控关注度                       |
| ------------- | --------------------------- | ----------------------------- | -------------------------------- |
| 聚集体（HMW） | 工艺应力、蛋白-蛋白相互作用 | SEC-HPLC（主要）、DLS（辅助） | 高（免疫原性风险）               |
| 片段（LMW）   | 化学降解、蛋白酶水解        | SEC-HPLC、CE-SDS              | 高（效力降低风险）               |
| 氧化变体      | 光照、金属离子、H₂O₂        | RP-HPLC、肽图 + LC-MS         | 高（活性位点氧化影响效力）       |
| 脱酰胺变体    | 热降解、碱性 pH             | IEX-HPLC、肽图 + LC-MS        | 中～高（CDR 区脱酰胺影响亲和力） |
| 电荷变体      | 多种翻译后修饰              | IEX-HPLC、iCIEF               | 中（PK/活性影响需评估）          |

:::

## 工艺相关杂质检测体系：HCP、宿主 DNA 与 Protein A 残留的检测方法、限度与监管要求

:::answer

**工艺相关杂质的分类框架**

参照《人用重组 DNA 蛋白制品总论》，工艺相关杂质来源于三个阶段，须系统建立检测体系：

```
细胞基质来源：宿主细胞蛋白（HCP）、宿主细胞 DNA（HCD）
        ↓
细胞培养来源：培养基组分（血清/水解物残留）、诱导物
        ↓
下游工艺来源：Protein A 残留（亲和层析配基脱落）、色谱介质浸出物、
              过滤膜浸出物、病毒灭活试剂（如 TNBP/Polysorbate 80）
```

---

**宿主细胞蛋白（HCP）**

**风险：** HCP 可能引起机体免疫反应，影响产品安全性；不同来源宿主细胞的 HCP 危害程度不同——哺乳动物细胞（CHO、Sp2/0、NS0）HCP 的潜在危害高于原核生物（大肠杆菌），须在质控方面更严格对待。

**检测方法：**

| 方法                            | 原理                           | 优势                                     | 局限                                                           |
| ------------------------------- | ------------------------------ | ---------------------------------------- | -------------------------------------------------------------- |
| 双抗体夹心 ELISA                | 多克隆抗体捕获+检测多种 HCP    | 简便、高通量、灵敏度高；商业化试剂盒可用 | 对低/无免疫活性的 HCP 无法检出；抗体覆盖度依赖于试剂盒开发质量 |
| 2D-DIGE（荧光差异二维凝胶电泳） | 基于蛋白质组学，可视化分离 HCP | 可识别具体 HCP 种类，发现 ELISA 漏检组分 | 操作复杂，通量低，定量精度有限                                 |
| 2D-LC/MS（蛋白质组学）          | 双向液相色谱 + 质谱            | 高灵敏度，可精确鉴定 HCP 种类和含量      | 仪器昂贵，数据分析复杂，通量低                                 |

**接受标准：** 通常 **< 100 ppm**（即 HCP 含量 < 总蛋白量的 0.01%）。具体限度须结合临床风险评估和工艺能力综合确定，不同产品的可接受标准可能有所不同。

---

**宿主细胞 DNA（HCD）**

**风险：** 宿主 DNA 残留的潜在致癌性风险（理论上外源 DNA 可能整合至受者基因组），虽然目前认为实际风险较低（小片段 DNA 致癌可能性有限），但相关风险尚未完全明确，仍须严格控制。

**检测方法：**

| 方法                         | 原理                            | 当前状态                                   |
| ---------------------------- | ------------------------------- | ------------------------------------------ |
| DNA 斑点杂交法               | 放射性或荧光标记探针与 DNA 杂交 | 《中国药典》收录方法，但周期长、结果较主观 |
| 实时定量 PCR（qPCR）         | 扩增特异性 DNA 序列，荧光定量   | 灵敏度高（pg 级），可定量；目前应用最广泛  |
| ELISA（基于 DNA 单克隆抗体） | 识别 dsDNA 的单克隆抗体         | 灵敏度高，特异性强，操作简便               |

**接受标准：** WHO 和各主要监管机构推荐：**每剂量 DNA 残留 ≤ 10 ng**（WHO Expert Committee on Biological Standardization 规定）。DNA 片段大小应控制在 200 bp 以下（小片段降低整合风险）。

---

**Protein A 残留**

**风险：** Protein A 配基在亲和层析洗脱过程中不可避免地部分脱落，混入洗脱液。Protein A 本身具有多克隆刺激活性，可能引起非特异性免疫反应，须通过后续纯化步骤（如离子交换层析）去除，并在原液中建立检测和控制标准。

**检测方法：** ELISA 法（最常用），多种商业化试剂盒可用。USP 已建立多种 Protein A 标准物质（天然型、重组型等），使检测进一步标准化。

**接受标准：** 通常 **< 1～10 ng/mg**（即 < 1～10 ppm），具体标准须根据产品的给药量和给药频率结合安全性评估确定。

**综合检测策略**

| 工艺相关杂质   | 首选检测方法        | 典型放行接受标准 |
| -------------- | ------------------- | ---------------- |
| HCP            | ELISA（双抗体夹心） | < 100 ppm        |
| HCD            | qPCR                | ≤ 10 ng/剂量     |
| Protein A 残留 | ELISA               | < 1～10 ppm      |
| 残余培养基组分 | 产品特异性方法      | 基于安全评估     |

:::

## 蛋白聚体的检测方法比较：SEC-HPLC、CE-SDS 和 SDS-PAGE 的测量原理差异与方法选型

:::answer

**聚体检测方法的选型逻辑**

蛋白聚体（Aggregates）是生物药物中最重要的产品相关杂质之一，其免疫原性风险促使监管机构将聚体控制列为高优先级 CQA。不同检测方法基于不同原理，对聚体的检出范围和测量值存在系统性差异，须在质量标准中明确指定主要检测方法。

**三种主要方法的全面对比**

| 维度           | SEC-HPLC                     | CE-SDS                   | SDS-PAGE             |
| -------------- | ---------------------------- | ------------------------ | -------------------- |
| 检测原理       | 分子排阻（天然状态分离）     | SDS 存在下的分子大小     | SDS 存在下的电泳迁移 |
| 样品状态       | 天然（非变性）               | SDS 变性                 | SDS 变性             |
| 检测的聚体类型 | **共价聚体 + 非共价聚体**    | **仅共价聚体**           | **仅共价聚体**       |
| 测量值         | **通常最高**（含全部类型）   | 低于 SEC-HPLC            | 低于 SEC-HPLC        |
| 定量精度       | 高（UV 面积积分）            | 高（毛细管电泳，自动化） | 低（凝胶图像半定量） |
| 适用规模       | 研发到放行均可               | 放行质控                 | 研发/初步评估        |
| 监管地位       | **首选放行方法**（CQA 控制） | 互补方法                 | 补充性参考           |

**关键认知：SEC-HPLC vs. CE-SDS 的测量差异来源**

CE-SDS 方法中存在 SDS，而 **SDS 可破坏蛋白聚体的非共价相互作用（氢键、范德华力、疏水相互作用等）**，使得非共价聚体在测定前已解聚，因此 CE-SDS 测量的聚体水平**系统性低于** SEC-HPLC 的测量值。

这一差异在以下场景中尤为重要：

- **高应力条件下的聚体评估：** 若产品经历加热、搅拌等应力后，非共价聚体会显著增加，此时 CE-SDS 会严重低估实际聚体水平；
- **制剂稳定性研究：** 应始终以 SEC-HPLC 数据作为聚体控制的主要依据。

**其他聚体检测技术（补充）**

| 技术                    | 检测范围         | 应用场景                                     |
| ----------------------- | ---------------- | -------------------------------------------- |
| DLS（动态光散射）       | 约 1 nm～10 μm   | 聚体大小分布初步筛查，尤其是 nm 级可溶性聚体 |
| AUC（分析超速离心）     | 单体～大聚体均可 | 最准确的聚体形态分析，科学研究和方法开发阶段 |
| MFI（微流成像颗粒分析） | 2～100 μm        | 亚可见微粒分析（不溶性微粒）                 |
| NTA（纳米颗粒追踪分析） | 50 nm～1 μm      | 亚可见微粒的数量和大小分布                   |

:::

## 单抗药物放行检测项目体系：常规物理检查的检测方法、规范与接受标准

:::answer

单抗药物的放行检测体系涵盖外观（物理）检查、理化指标、纯度杂质检测、效力检测和安全性检测等多个维度。本节重点介绍常规物理检查（外观和物理状态检测）的具体要求和检测规范。

**ICH Q5C 和 Q6B 对物理检查的要求**

- **ICH Q5C（生物技术药物稳定性试验）：** 规定须进行澄清度、颜色、溶解时间（冻干产品）、可见颗粒等产品特性检查；
- **ICH Q6B（生物技术药物试验规程及可接受标准）：** 规定物理状态描述（颜色、澄清度等）对评价成品功能非常重要。

**常规物理检测项目汇总**

| 检测项目       | 检测目的                                                            | 主要适用剂型     |
| -------------- | ------------------------------------------------------------------- | ---------------- |
| 澄清度（浊度） | 检测溶液中是否存在可见或亚可见颗粒，评估制剂稳定性                  | 液体制剂（主要） |
| 颜色外观       | 确认产品颜色在规定范围内，检出明显的产品降解（如棕色化）            | 所有制剂         |
| 可见异物       | 检测 ≥ 10 μm 的颗粒（玻璃碎片、纤维、蛋白颗粒等），直接危害患者安全 | 所有注射剂       |
| 不溶性微粒     | 检测 ≥ 10 μm 和 ≥ 25 μm 的微粒数量（按颗粒计数法或光阻法）          | 注射液           |
| 溶解时间       | 评估冻干粉重溶时间，确保患者可操作性                                | 冻干制剂         |
| 装量差异       | 确保每支装量在规定范围内，保证给药剂量准确                          | 所有制剂         |

:::

## pH 测定法的规范要求：酸度计校准流程、缓冲液管理与判定标准

:::answer

**法规依据**

《中国药典》三部（第 474 页）明确规定了 pH 测定的技术规范，以下为核心要点及实践扩展。

**pH 测定的仪器与校准**

**仪器要求：** 采用**玻璃电极酸度计（pH 计）**进行 pH 检测，仪器须具备温度补偿功能（自动或手动），并经过计量校准。

**两点校准程序（标准操作）**

```
选择两种标准缓冲液（pH 值须跨越待测样品的预期 pH 范围）
        ↓
第一缓冲液校准（调零点）
        ↓
第二缓冲液验证（确认斜率）
        ↓
验收标准：校准后实测值与标准值相差 ≤ 0.05 pH 单位
        ↓
校准通过后，方可进行样品测定
        ↓
样品测定值须在两种标准缓冲液的 pH 值之间
```

**标准缓冲液的管理**

- 标准缓冲液一般可保存 **2～3 个月**（密封、避光、冷藏保存）；
- 发现有浑浊、沉淀或超过有效期时须更换，不可使用变质的缓冲液；
- 不同 pH 范围的常用标准缓冲液：pH 4.00（苯二甲酸氢钾）、pH 6.86（磷酸盐混合液）、pH 9.18（硼砂）；具体配制须按药典要求进行。

**测定操作要点**

- 测定前须用纯化水冲洗电极，再用待测样品溶液润洗（减少交叉污染和稀释效应）；
- 测定时须等待读数稳定（通常 30 秒～1 分钟）后记录；
- 样品须达到测定温度（通常 20～25℃），若样品温度与室温差异较大，须在方法中注明并控制；
- 单抗制剂典型 pH 范围：**5.0～7.0**（根据制剂缓冲液体系），质量标准中通常设定 ± 0.3～0.5 的接受范围。

:::

## 渗透压测定法：冰点下降原理、测定操作规范与单抗制剂的典型接受标准

:::answer

**法规依据**

《中国药典》三部（第 475 页）明确规定采用**冰点下降法**进行渗透压摩尔浓度（Osmolality）测定，以下为核心原理、操作规范及单抗制剂的典型接受标准。

**冰点下降法原理**

溶液的冰点（凝固点）随溶质浓度的增加而降低，这一现象称为冰点下降（Freezing Point Depression）。冰点下降值与溶质的**渗透压摩尔浓度**成正比（依数性）：

$$\Delta T_f = K_f \times m_{osm}$$

其中 ΔTf 为冰点下降值（℃），Kf 为水的冰点下降常数（1.86℃·kg/mol），m_osm 为溶质的渗透压摩尔浓度（mOsmol/kg）。

通过精确测量样品的冰点，即可换算得到渗透压摩尔浓度。

**典型参考数据**

| 溶液                  | 理论渗透压（mOsmol/kg） | 实际渗透压（mOsmol/kg） | 差异原因                                                                                                      |
| --------------------- | ----------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| 0.9% NaCl（生理盐水） | 308                     | 286                     | 在此浓度下，Na⁺ 和 Cl⁻ 之间存在一定程度的离子缔合（Ion Pair Formation），有效离子数减少，实际渗透压低于理论值 |
| 5% Glucose            | 277                     | 278                     | 非电解质，无离子缔合，理论与实际接近                                                                          |

**单抗制剂的典型渗透压范围**

- 一般单抗溶液的渗透压在 **240～320 mOsmol/kg** 之间；
- 接近等渗（生理渗透压约 280～310 mOsmol/kg）的制剂对患者注射部位刺激最小；
- 高渗制剂（> 350 mOsmol/kg）在皮下注射时可能引起注射部位疼痛；
- 低渗制剂（< 240 mOsmol/kg）可能导致红细胞溶血，应避免。

**测定操作要点**

- 冰点渗透压计须用已知渗透压的参考溶液（如 290 mOsmol/kg 或 0.9% NaCl）进行校准；
- 测定时样品须处于室温，严格按照仪器操作规程控制降温速率和检测时机；
- 每次测定至少重复 2 次，取平均值（两次结果差异须 ≤ 5 mOsmol/kg）；
- 样品体积通常为 50～200 μL（根据仪器型号要求）。

:::

## 单抗药物常规物理检查项目的检测标准与操作规范

:::answer

**物理检查在质量控制中的定位**

物理检查（Physical Testing）是单抗药物质量控制的必要组成部分，通过外观和物理状态的检查，从宏观到亚可见颗粒层面全面评估产品的物理质量。ICH Q6B 明确指出：颜色、澄清度等物理状态描述对于评价成品功能非常重要。

**主要物理检测项目的检测方法与接受标准**

**① 澄清度（浊度）**

- **检测方法：** 目视检查（与标准浑浊度参比液比对）或仪器法（浊度计，NTU/FTU 单位）；
- **接受标准：** 供试品与参比液（药典规定的浑浊度参比液 I～IV 号）比较，通常要求澄清或不超过参比液 1 号浑浊度；
- **检测场景：** 光照下目视观察，背景为黑色（检测白色/无色颗粒）和白色（检测有色颗粒）背景交替使用。

**② 颜色（外观）**

- **检测方法：** 在规定光照强度下目视观察，与标准比色液（棕色系列、黄色系列）比对；
- **接受标准：** 通常规定颜色不深于特定标准比色液（如 BY3、B3 等），液体注射剂通常为无色至微黄色；
- **注意事项：** 批次间颜色一致性是工艺稳定性监控的重要指标。

**③ 可见异物（Visible Particles）**

- **检测方法：** 在规定光照（1000 lx 以上）和背景（黑、白背景各用）下，手工旋转容器目视检查；须由经过培训的检验员执行；
- **接受标准：** 不得检出金属颗粒、玻璃碎片、纤维等异物；不得有肉眼可见的白色或有色颗粒（蛋白颗粒须特别关注）；
- **监管要求：** 100% 检验（每支）。

**④ 不溶性微粒（Sub-visible Particles）**

- **检测方法：** 光阻法（Light Obscuration，推荐方法）或显微镜计数法（膜过滤后显微镜计数）；
- **《中国药典》接受标准：**
  - ≥ 10 μm：每容器不超过 6000 个（对于 100 mL 以下的注射液）
  - ≥ 25 μm：每容器不超过 600 个
- **蛋白质颗粒监控：** 对于高浓度单抗制剂，蛋白亚可见颗粒（Protein Particles，2～10 μm）须特别关注，MFI 或 NTA 方法可提供更详细的颗粒计数和形态信息。

**⑤ 溶解时间（冻干制剂）**

- **检测方法：** 按标签规定的溶剂（注射用水或 0.9% NaCl）复溶，计时直至目视完全溶解；
- **接受标准：** 通常 < 5 分钟（须在研究阶段确认并在质量标准中规定）；
- **意义：** 直接影响临床使用的可操作性，溶解时间过长可能提示冻干产品孔隙结构异常或蛋白质发生聚集。

:::

## 杂质质量标准的设定依据：IND 阶段的宽范围起点与 BLA 阶段的收窄逻辑

:::answer

**杂质质量标准的设定原则**

质量标准（Specifications）中的杂质限度是基于**安全性、有效性、工艺能力和临床数据**的综合判断，不是简单的分析方法检测值的累加，须随开发阶段的推进不断更新完善。

**IND 阶段：宽泛起点，知识驱动**

IND 申报时，可参考的批次数据有限（通常 < 3 批），质量标准的设定主要依赖：

| 依据来源           | 具体内容                                  |
| ------------------ | ----------------------------------------- |
| 临床前研究数据     | 毒理学研究批次的实测数据范围              |
| 文献报道和同类产品 | 已上市类似产品的质量标准公开信息          |
| 法规指南           | WHO 指南、ICH 指南（如 HCD ≤ 10 ng/剂量） |
| 企业平台经验       | 同平台其他分子的历史数据                  |

**IND 阶段典型起始限度（行业参考）**

| 质量属性                 | IND 阶段典型起始限度                                             |
| ------------------------ | ---------------------------------------------------------------- |
| SEC 主峰（单体纯度）     | ≥ 90%                                                            |
| 高甘露糖型（Man5）       | ≤ 10%                                                            |
| NR-CE-SDS 主峰（非还原） | ≥ 90%                                                            |
| HCP                      | ≤ 100 ppm（或 ng/mg）                                            |
| HCD                      | ≤ 10 ng/剂量（WHO 要求）                                         |
| Protein A 残留           | ≤ 10 ppm（产品特异性评估）                                       |
| 细菌内毒素               | 依 USP <85> / 《中国药典》（通常 ≤ 1 EU/mg 或 ≤ 5 EU/kg 体重/h） |

**BLA 阶段：基于数据的收窄与精确化**

BLA 申报阶段须根据以下数据来源**重新制定或收窄质量标准**：

**1. 临床前和临床研究批次数据**

系统收集 IND 批准后所有用于临床研究的批次（通常 ≥ 10 批）的实测数据，以均值 ± 3SD（或 95% 置信区间）作为质量标准的数据基础，确保覆盖历史批次的正常变异范围。

**2. 商业化生产一致性数据（PPQ 批次）**

工艺性能确认（PPQ）批次的数据是 BLA 质量标准的核心数据基础，通常须有 ≥ 3 批 PPQ 批次的数据。

**3. 稳定性研究数据的整合**

质量标准的限度须考虑产品在**货架期内**的正常变化（如氧化、脱酰胺随时间增加），避免放行时处于质量标准边缘的批次在货架期内超标。通常：

```
放行限度 = 货架期末期限度 - 货架期内预期变化量（稳定性趋势）
```

**4. 临床 PK/PD 相关性数据**

若临床研究建立了某些质量属性与 PK/PD 之间的定量关系，须将这些相关性纳入限度制定的依据。

**IND vs. BLA 质量标准的典型对比**

| 质量属性                  | IND 阶段典型限度 | BLA 阶段典型限度（上市产品）              |
| ------------------------- | ---------------- | ----------------------------------------- |
| SEC 主峰（单体纯度）      | ≥ 90%            | ≥ 95%，甚至 ≥ 98%（视工艺能力和产品特性） |
| 聚体（HMW）               | ≤ 5%             | ≤ 2%（通常随工艺成熟而收窄）              |
| 脱酰胺/氧化变体           | 宽泛范围         | 基于批数据 + 稳定性趋势精确制定           |
| 电荷变体（酸性峰/碱性峰） | 宽泛范围         | 基于批数据精确范围                        |

**质量标准的动态更新机制**

IND 申报后，质量标准须随着临床数据积累、工艺理解深入和稳定性数据完善而持续更新：

- 每次 IND 修订或新的临床阶段启动时，都是重新评估并更新质量标准的机会；
- BLA 申报前须提交包含完整数据支持的最终质量标准，并经过监管机构审评认可。

:::
