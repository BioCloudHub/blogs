## 第一部分：内毒素基础与检测

---

### 内毒素的本质：结构、特性与危害

:::answer

**定义与化学本质**

内毒素是革兰氏阴性细菌细胞壁的核心成分——**脂多糖（Lipopolysaccharide，LPS）**，由脂质 A（毒性核心）、核心多糖和 O 抗原侧链三部分组成。脂质 A 是内毒素发挥生物毒性的关键结构域。

**释放机制**

内毒素并非仅在细菌死亡裂解时释放，正常细胞生长与分裂过程中也会持续向周围环境释放，因此**无菌不等于无内毒素**，这是生物制品生产中极易忽视的误区。

**物理化学特性**

| 特性       | 描述                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| 分子量     | 单体约 10–20 kDa，聚集体可超过 1000 kDa                                    |
| 热稳定性   | 100°C / 1h 不破坏；需 160°C / 2–4h 或强酸碱 / 强氧化剂煮沸 30 min 方可灭活 |
| 电荷特性   | 等电点约 pH 2，pH 4–8 范围内带负电荷                                       |
| 疏水性     | 强于一般蛋白，在高盐条件下聚集成超大分子                                   |
| 非蛋白本质 | 不可通过蛋白酶降解灭活                                                     |

**生物学危害**

进入血液可激活免疫级联反应，引发发热、低血压、弥散性血管内凝血（DIC），严重时导致感染性休克，是生物制品安全性控制的核心指标之一。

**计量单位**

内毒素的量用<strong>内毒素单位（EU）</strong>表示，1 EU 等同于 1 个内毒素国际单位（IU）。

:::

### 内毒素检测方法：鲎试剂法与法规依据

:::answer

**法规依据**

参照《中国药典》2020 版三部通则 **1143 细菌内毒素检查法**，该通则规定了限值确定原则与具体检测方法。

**主要检测方法对比**

| 方法                     | 原理                                 | 特点                                       |
| ------------------------ | ------------------------------------ | ------------------------------------------ |
| **凝胶法**               | 鲎试剂与内毒素发生凝集反应           | 限度检测或半定量，操作简便，是经典法定方法 |
| **终点显色法**           | 内毒素激活鲎试剂中的酶，水解底物显色 | 定量，灵敏度高，适合大批量检测             |
| **动态浊度法**           | 实时检测凝胶形成过程中浊度变化       | 定量，线性范围宽                           |
| **重组因子 C 法（rFC）** | 基因重组单一因子替代鲎血             | 动物资源友好，特异性强，FDA 已接受         |

**凝胶法核心要点**

凝胶法的判读以凝胶形成与否为终点（"+"或"-"），操作需严格控制温度（37°C ± 1°C）、时间（60 min）及干扰因素（pH、阳离子浓度等），干扰确认试验（PPC/NPC/SPC）是保障结果可靠性的关键步骤。

**限值计算原则**

$$L = K / M$$

其中 L 为内毒素限值（EU/mL 或 EU/mg），K 为阈值常量（静脉给药 5 EU/kg/h，鞘内给药 0.2 EU/kg/h），M 为最大给药剂量。

:::

## 第二部分：内毒素去除技术体系

---

### 超滤去除法：基于分子量差异的物理截留

:::answer

**原理**

利用内毒素分子量远大于小分子目标物的特点实施截留。内毒素单体分子量 ≥ 10 kDa，聚集体可超过 100 kDa，直径约 0.1 μm。

**适用膜孔径**

通常选用 **30–100 kDa** MWCO 的超滤膜，可有效截留内毒素聚集体，同时使目标小分子透过。

**适用范围与局限**

- ✅ 适合：目标分子较小（<10 kDa）的小分子药物、多肽类物质
- ❌ 不适合：目标分子本身分子量与内毒素接近的蛋白类产品
- ⚠️ 注意：过滤介质本身也可能吸附或释放内毒素，需进行系统验证

:::

---

### 活性炭吸附法：非选择性物理吸附

:::answer

**原理**

活性炭通过巨大比表面积非特异性吸附内毒素，同时依赖疏水和静电相互作用发挥吸附效能。

**关键特点**

- ✅ 适合：简单小分子溶液（如氨基酸注射液、葡萄糖注射液）的内毒素去除
- ❌ 局限：选择性差，易吸附有效成分，目标分子回收率损失显著
- 💡 优化策略：与**超滤法联用**，可发挥协同效果，先活性炭降低内毒素总量，再超滤精细截留残余聚集体

**工业应用建议**

该方法在小分子注射液生产中仍有应用，但对蛋白类生物制品一般不作为首选，须通过验证明确吸附容量与目标物回收率之间的平衡点。

:::

---

### 离子交换层析法：工业首选的高效去除手段

:::answer

**原理**

内毒素等电点约 pH 2，在 **pH 4–8** 的常用操作范围内带负电荷，可被阴离子交换层析介质有效结合，而目标蛋白在适当 pH 和盐浓度下流穿或选择性洗脱，从而实现分离。

**技术优势**

| 优势维度 | 描述                                 |
| -------- | ------------------------------------ |
| 成本     | 离子交换填料价格低廉，可反复再生使用 |
| 吸附容量 | 大，适合工业规模                     |
| 操作简便 | 条件温和，兼容大多数缓冲体系         |
| 去除效率 | 可实现 2–4 log 级别内毒素去除        |

**操作策略选择**

- **流穿模式（Flow-through）**：目标蛋白流穿，内毒素结合柱床——适用于目标蛋白在操作 pH 下带正电或中性的情形
- **结合-洗脱模式（Bind-elute）**：目标蛋白结合，内毒素在特定条件下不结合——需精细优化盐浓度与 pH

**工业地位**

离子交换层析是目前生物制品工艺中**去除内毒素最主流的方法**，在单抗纯化平台（Protein A 亲和 + 阳离子交换 + 阴离子交换"三柱平台"）中，阴离子交换步骤兼具内毒素去除功能。

:::

---

### 疏水层析法：盐浓度调控的双模式分离

:::answer

**原理**

内毒素的疏水性强于一般蛋白，但其疏水性受盐浓度影响显著：

- **高盐（如 1.5 M 硫酸铵）**：内毒素聚集，疏水结构暴露减少，疏水性反而**降低** → 内毒素流穿，目标蛋白结合柱床
- **低盐（如 0.5 M 硫酸铵）**：目标蛋白流穿，内毒素被柱床结合 → 实现分离

**两种操作模式**

| 模式     | 上样条件      | 目标蛋白去向       | 内毒素去向 |
| -------- | ------------- | ------------------ | ---------- |
| 高盐流穿 | ~1.5 M 硫酸铵 | 结合柱床，梯度洗脱 | 流穿       |
| 低盐流穿 | ~0.5 M 硫酸铵 | 流穿收集           | 结合柱床   |

**适用场景**

疏水层析常作为 Protein A 亲和层析之后的抛光步骤，兼顾宿主蛋白（HCP）、聚集体和内毒素的协同去除。

:::

---

### 凝胶过滤层析法：高盐诱导超大聚集体的尺寸排阻

:::answer

**原理**

在 **0.4 M 硫酸铵**等盐溶液中，内毒素聚集形成超大分子（通常 **>1000 kDa**），而目标小分子蛋白相对较小，通过凝胶过滤层析（如 Sephacryl S-200）可依据分子大小实现分离，内毒素被排阻在柱外，目标分子进入凝胶孔道后延迟洗脱。

**适用范围**

- 适用于：分子量与内毒素聚集体差异显著的目标分子
- 局限：凝胶过滤通量低、稀释效应明显，工业规模应用受限，多作为研究阶段或抛光精制步骤

:::

---

### 亲和层析法（多粘菌素 B 亲和）：高特异性的科研级工具

:::answer

**原理**

<strong>多粘菌素 B（Polymyxin B）</strong>是内毒素脂质 A 的天然类似物，将其固定化至琼脂糖微球制成填料（如 Detoxi-Gel），可特异性识别并结合内毒素分子中的脂质 A 结构域。

**优势与局限**

| 维度     | 描述                                     |
| -------- | ---------------------------------------- |
| 特异性   | 高，靶向脂质 A                           |
| 结合容量 | 有限，不同批次内毒素结构差异影响去除效率 |
| 成本     | 昂贵，难以工业规模化                     |
| 适用场景 | 科研样品、少量珍贵蛋白的内毒素精制       |

**工业现状**

工业生产中由于成本、容量和内毒素结构异质性等限制，多粘菌素 B 亲和层析**不作为首选**，工业首选仍为离子交换层析。该方法更多用于临床前研究中对注射级蛋白样品的快速内毒素去除。

:::

## 第三部分：ADC 药物基础与机制

---

### ADC 药物的组成、结构与作用机制

:::answer

**定义**

抗体偶联药物（Antibody-Drug Conjugate，ADC）是将**单克隆抗体**通过<strong>偶联臂（Linker）</strong>与高效<strong>细胞毒性小分子（Payload）</strong>共价连接形成的复合物，旨在利用抗体的靶向性将高毒性载药精准递送至肿瘤细胞。

**三大核心组件**

| 组件                    | 功能                               | 关键设计考量                           |
| ----------------------- | ---------------------------------- | -------------------------------------- |
| **单克隆抗体**          | 靶向识别肿瘤细胞表面抗原，介导内吞 | 靶点表达谱、内化效率、Fc 效应功能      |
| **Linker（连接子）**    | 连接抗体与载药，控制释放时机与位置 | 稳定性、可裂解类型（pH/蛋白酶/还原型） |
| **Payload（有效载荷）** | 细胞毒性杀伤效应                   | 毒力（IC₅₀）、膜通透性、旁观者效应潜力 |

**药物-抗体比（DAR）**

DAR 值（Drug-to-Antibody Ratio）是衡量每个抗体分子连接载药数量的关键参数，通常 DAR 2–4 为最优窗口，过高 DAR 导致疏水性增加、体内稳定性下降、非特异性清除加剧。

**作用机制（五步内化-释放-杀伤流程）**

```
① 静脉注射 → 血液/淋巴系统转运
         ↓
② 抗体识别靶抗原 → ADC-抗原复合物形成
         ↓
③ Clathrin/Caveolin 介导内吞 → 进入 Endosome
         ↓
④ 早期/晚期 Endosome 成熟 → 与 Lysosome 融合
   （可裂解 Linker 在此阶段水解/还原/蛋白酶裂解）
         ↓
⑤ Payload 释放至胞质 → DNA 嵌入 / 微管抑制 → 细胞凋亡
   + 旁观者效应：活跃 Payload 扩散杀伤周围肿瘤细胞
```

**旁观者效应（Bystander Effect）**

当 Payload 具有良好膜通透性时，从靶细胞溶酶体释放后可扩散至周边细胞，杀伤抗原低表达或无表达的异质性肿瘤细胞，是 ADC 克服肿瘤异质性的重要机制，但同时也是脱靶毒性的来源之一。

:::

## 第四部分：ADC 药物毒性体系

---

### ADC 药物毒性的来源分类与核心逻辑

:::answer

ADC 毒性来源于**两个独立维度**的叠加，理解其来源是毒性管控的前提：

**维度一：抗体相关毒性**

- 来源于 Fc 效应功能（ADCC/CDC/ADCP）激活正常免疫细胞
- 与靶点在正常组织的表达谱高度相关，靶点不同毒性谱差异显著
- 典型案例：EGFR 靶向 ADC 引发皮疹（皮肤 EGFR 高表达）

**维度二：Payload 相关毒性**

早期 ADC 使用传统化疗药（阿霉素、丝裂霉素）作为载药，在 ADC 可接受剂量窗口内载药难以达到有效浓度，推动了**超高毒力 Payload**（如 MMAE、DM1、SN-38）的开发。高毒力 Payload 对快速增殖的正常细胞产生系统性损伤：

| 毒性表现            | 机制                 |
| ------------------- | -------------------- |
| 骨髓抑制/血细胞减少 | 造血干/祖细胞损伤    |
| 脱发                | 毛囊细胞快速增殖受抑 |
| 胃肠道反应          | 肠道上皮细胞损伤     |
| 肝毒性              | 非特异性肝摄取       |

**核心矛盾**

ADC 开发的根本张力在于：**Payload 毒力越强，治疗窗口越窄，脱靶风险越高**。Linker 稳定性与 Payload 毒力的平衡是 ADC 设计的核心工程问题。

:::

---

### 脱靶毒性：ADC 剂量限制性毒性的主因

:::answer

**定义**

脱靶毒性（Off-target Toxicity）指 ADC 在未结合肿瘤靶抗原的情况下，释放 Payload 并损伤正常组织，是目前**临床 ADC 剂量限制性毒性（DLT）的主要原因**。

**四大发生机制**

| 机制                      | 描述                                                   | 干预方向                     |
| ------------------------- | ------------------------------------------------------ | ---------------------------- |
| **① Linker 提前裂解**     | 循环中 Linker 不稳定，Payload 早期释放入血             | 优化 Linker 化学稳定性       |
| **② 旁观者效应过度**      | 靶细胞内吞后释放的 Payload 扩散损伤周围正常细胞        | 选择膜通透性适中的 Payload   |
| **③ 非特异性内吞**        | 胞饮（Pinocytosis）、非网格蛋白/胞膜窖依赖内吞摄入 ADC | 降低 ADC 疏水性，优化 DAR    |
| **④ Fc 介导非特异性内吞** | FcRn 或 FcγR 表达细胞摄取 ADC                          | 工程化 Fc 区域，降低 Fc 效应 |

**关键监控指标**

- 游离 Payload 血浆浓度（Free Drug Concentration）
- DAR 分布均一性
- ADC 血浆稳定性（Stability in Plasma）
- 肝脏非特异性摄取（IVIVE 模型预测）

:::

---

### 在靶毒性：靶点生物学决定的固有风险

:::answer

**定义**

在靶毒性（On-target Toxicity）指 ADC 按预期结合靶抗原，但靶抗原在正常组织也有表达，导致正常细胞损伤。

**典型靶点与在靶毒性举例**

| 靶点     | 肿瘤表达               | 正常组织表达       | 典型毒性表现         |
| -------- | ---------------------- | ------------------ | -------------------- |
| EGFR     | 多种实体瘤             | 皮肤、消化道       | 皮疹、腹泻           |
| HER2     | 乳腺癌、胃癌           | 心肌细胞（低表达） | 心脏毒性（剂量依赖） |
| TROP2    | 三阴乳腺癌、尿路上皮癌 | 皮肤、角膜         | 皮肤毒性、角膜炎     |
| Nectin-4 | 尿路上皮癌             | 皮肤、口腔黏膜     | 皮疹、口腔炎         |

**评估策略**

- 靶点组织表达谱分析（IHC/RNA-seq 正常组织图谱）
- 非人灵长类（NHP）毒理学研究
- 治疗指数（TI）= MTD / MED 的充分评估

:::

---

### Linker 稳定性与毒性的构效关系

:::answer

**核心逻辑**

Linker 的化学设计直接决定 Payload 在体内的释放时机与位置，进而影响 ADC 的安全性与有效性之间的平衡。

**理想 Linker 的双重要求**

```
血液循环中：足够稳定 → 防止 Payload 提前释放
肿瘤内/溶酶体中：足够响应 → 高效释放有效量 Payload
```

**Linker 稳定性与毒性的关系**

| Linker 稳定性 | 血液中游离 Payload | 细胞毒素峰值浓度 | 主要毒性表现                               |
| ------------- | ------------------ | ---------------- | ------------------------------------------ |
| 不稳定        | 高                 | 高               | 血细胞减少、脱发、胃肠道毒性（化疗样毒性） |
| 过度稳定      | 低                 | 溶酶体释放不足   | 疗效不足                                   |
| 最优平衡      | 低                 | 肿瘤内充分释放   | 治疗窗口最大化                             |

**可裂解 Linker 类型对比**

| 类型                 | 裂解触发条件           | 代表产品         | 特点                     |
| -------------------- | ---------------------- | ---------------- | ------------------------ |
| 酸敏感型（腙键）     | 溶酶体低 pH（~5）      | Mylotarg（早期） | 较早释放，稳定性有限     |
| 蛋白酶敏感型（二肽） | 组织蛋白酶 B（溶酶体） | T-DM1、Adcetris  | 主流设计，选择性佳       |
| 还原型（二硫键）     | 胞内谷胱甘肽           | 部分在研 ADC     | 肿瘤微环境氧化还原选择性 |
| 不可裂解型           | 抗体完全降解           | T-DM1 部分设计   | 稳定性最高，旁观者效应弱 |

:::

## 第五部分：ADC 毒性管控与风险最小化策略

---

### ADC 毒性风险最小化的临床策略框架

:::answer

**风险管控的两大目标**

1. **预防风险**：降低毒性事件发生频率
2. **降低风险**：毒性发生时减轻严重程度，保障患者可持续用药

**常规风险最小化措施**

每种药品均需建立的基础措施，通过**产品标签（说明书）**传递风险信息：

- 美国：美国处方信息（USPI）
- 欧洲：产品特征摘要（SmPC）
- 内容涵盖：特定风险警示、剂量调整方案、监测频率要求、禁忌症与特殊人群提示

**额外风险最小化措施（REMS）**

当常规措施不足以平衡效益-风险时，FDA 要求实施 REMS。

**典型案例：Belantamab Mafodotin（Blenrep）的眼部毒性 REMS**

Belantamab mafodotin 是**唯一需要 REMS 的已批准 ADC**，其眼部毒性（角膜微囊肿、视力下降）风险较高，REMS 要求：

| 执行层面 | 具体要求                                     |
| -------- | -------------------------------------------- |
| 医疗机构 | 处方前完成专项培训，获得认证资格             |
| 患者     | 每次给药前（每 3 周）进行角膜检查 + 视力评估 |
| 给药资格 | 基于眼科检查结果判断是否具备下次用药条件     |
| 患者注册 | 填写注册表格，知情同意，承诺遵守眼部监测计划 |

**剂量调整通则**

ADC 临床方案中通常预设基于毒性分级（CTCAE）的**剂量减量方案**（Dose Reduction Level），如 G2 毒性暂停给药，G3/G4 永久停药，为医生提供标准化决策路径。

:::

### 降低 ADC 药物毒性的工程化策略

:::answer

**策略一：Linker 与 Payload 的精准优化**

**（1）位点特异性偶联（Site-specific Conjugation）**

传统非特异性偶联（赖氨酸氨基或半胱氨酸巯基）导致 DAR 分布不均（DAR 0–8），高 DAR 组分血浆稳定性差、肝脏非特异摄取率高。

位点特异性偶联技术可实现：

- 精确 DAR 控制（通常 DAR 2 或 DAR 4 均一产品）
- 偶联位点远离抗原结合区域，保留结合活性
- 更稳定的化学键环境，降低载药脱落

**代表技术平台**

| 技术               | 原理                       | 代表企业/产品 |
| ------------------ | -------------------------- | ------------- |
| THIOMAB            | Cys 工程化引入特定位点     | Genentech     |
| pAMF 非天然氨基酸  | 基因密码子扩展引入偶联位点 | Ambrx         |
| 酶介导转谷氨酰胺酶 | 识别特定 Gln 序列位点偶联  | Mersana       |
| 糖工程位点         | 利用糖链偶联               | Synaffix      |

**（2）Linker 疏水性降低**

高 DAR 产品疏水性增加 → 血液中快速清除 → 脂肪组织积累 → 毒性增加。改善策略：

- **PEG 化修饰**：在 Linker 中引入 PEG 片段，降低整体疏水性
- **自消除连接子（Self-immolative Linker）**：裂解后 Linker 自动消除，防止残留 Linker-Payload 代谢物产生额外毒性
- **抗非特异性肽酶稳定连接剂**：引入空间位阻基团，防止循环中蛋白酶非特异性裂解

**策略二：抗体工程减毒**

**（1）前药形式 ADC（Prodrug Conjugate，PDC）**

将抗体结合区域用抗独特型肽（Anti-idiotype Peptide）通过蛋白酶敏感 Linker 掩蔽，在肿瘤微环境特异性蛋白酶（如 legumain、uPA）激活下暴露结合位点，实现**肿瘤选择性激活**，减少正常组织"在靶毒性"。

**（2）Fc 工程化**

针对 FcγR 介导的非特异性内吞导致的脱靶毒性，通过 Fc 突变（如 LALA 或 LALAPG 突变）减弱 Fc 效应功能，降低免疫效应细胞的非靶向内化。

**（3）双抗-ADC（Bispecific ADC）**

利用双特异性抗体设计，要求靶细胞**同时表达两个靶点**方能有效内化，提升肿瘤选择性，降低单靶点正常组织暴露。

**策略三：Payload 结构改造**

- 对现有 Payload 进行结构修饰，降低游离药物毒性同时保留偶联状态的高效性（如 DXd 相较 SN-38 具有更短体内半衰期）
- 开发新型作用机制 Payload（如 DNA 烷化剂、RNA 聚合酶抑制剂），扩展 ADC 毒性管理维度

:::

## 第六部分：糖型工程与效应功能调控

---

### N-糖结构对 ADCC 与 ADCP 效应的调控机制

:::answer

**核心背景**

抗体 Fc 区域 Asn297 位点携带 N-糖链，其糖型组成对 FcγR 结合亲和力和 ADCC（抗体依赖细胞介导的细胞毒性）、ADCP（抗体依赖细胞介导的吞噬作用）效应功能具有显著调控作用。

**关键糖型修饰对 ADCC 的影响**

| 糖型修饰                              | 对 ADCC 的影响         | 机制                                                  |
| ------------------------------------- | ---------------------- | ----------------------------------------------------- |
| **去除核心岩藻糖（Afucosylation）**   | ↑↑ 显著增强（5–50 倍） | 增强 FcγRIIIa（CD16a）结合亲和力                      |
| **高甘露糖型 N-糖**                   | ↑ 增强                 | 本质上也缺乏核心岩藻糖                                |
| **增加分支 N-乙酰葡萄糖胺（GlcNAc）** | ↑ 增强                 | 空间位阻阻碍核心岩藻糖生成                            |
| **末端唾液酸化**                      | ↓ 减弱                 | FcγRIIIa 结合力降低；铰链区构象改变，Fab 由双价变单价 |
| **末端半乳糖**                        | 轻微增强               | 直接与 FcγRIIIa 接触面优化                            |

**已上市代表产品**

- **Obinutuzumab（Gazyva）**：应用罗氏 Glycart 技术（过表达 β1,4-N-乙酰葡萄糖胺转移酶 III，GnTIII），增加分支 GlcNAc 抑制岩藻糖化，显著增强 ADCC，用于 CLL 和 FL
- **Mogamulizumab（Poteligeo）**：使用岩藻糖缺陷型宿主细胞（α1,6-岩藻糖转移酶敲除），去岩藻糖化单抗，ADCC 增强

**N-糖对 ADCP 的调控（研究相对早期）**

| 修饰           | 对 ADCP 的影响 | 主要受体             |
| -------------- | -------------- | -------------------- |
| 去除核心岩藻糖 | ↑ 增强         | FcγRIIa（CD32a）为主 |
| 去除末端半乳糖 | ↑ 增强         | FcγRIIa              |
| 含 Neu5Gc 糖型 | ↑ 增强         | FcγRIIa              |

**工程化策略**

1. **宿主细胞工程**：FUT8（α1,6-岩藻糖转移酶）基因敲除（如 Biowa 的 Potelligent® 平台）
2. **糖苷酶处理**：体外酶促去岩藻糖化
3. **过表达 GnTIII**：增加分支 GlcNAc，间接抑制岩藻糖化（Glycart/Roche 技术）
4. **培养基优化**：控制岩藻糖供体（GDP-岩藻糖）合成途径，如添加 2-deoxy-2-fluorofucose（2FF）竞争性抑制岩藻糖基化

:::

### 融合蛋白糖型设计：O-糖与 N-糖的综合控制

:::answer

**设计阶段的关键关注点**

融合蛋白（如 Fc 融合蛋白、双功能融合蛋白）在分子序列设计阶段，需重点关注以下糖基化相关风险：

**O-糖基化位点识别**

- CDR 区域若引入 Ser/Thr 残基，可能产生**非预期 O-糖基化**，影响：
  - 抗原结合亲和力（空间位阻）
  - 批次间一致性
  - 免疫原性风险
- 建议：在序列设计阶段使用糖基化位点预测工具（如 NetOGlyc、GlycoMine）进行系统筛查，必要时通过定点突变规避

**N-糖基化控制维度**

| 控制层面 | 手段                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 序列层面 | 确认 Asn-X-Ser/Thr 基序的分布，避免在关键功能区引入新 N-糖位点         |
| 工艺层面 | 通过培养基成分（锰、半乳糖供体）和培养条件（pH、DO、温度）调控末端糖型 |
| 质控层面 | 液相色谱-质谱联用（LC-MS）糖肽分析建立糖型指纹图谱，设定放行标准       |

**成药性评估要点**

在分子成药性（Developability）评估中，糖型分析是重要维度，需关注：

- N-糖占比（高甘露糖型比例是否超标）
- O-糖基化是否影响结构均一性
- 唾液酸化水平对 PK（体内清除率）的影响

详见【融合蛋白药物基础知识学习】专题。

:::
