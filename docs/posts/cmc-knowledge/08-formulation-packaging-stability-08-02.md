## 溶液颜色检查的三类方法：标准比色法、分光光度法与色差计法的原理与适用场景

:::answer

**三类颜色检查方法概述**

单抗及重组蛋白产品的溶液颜色是重要的外观质量属性，其检查方法因适用场景和精度需求不同而有所差异：

| 检查方法                      | 原理                                                                                        | 适用场景                                               | 特点                                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| 标准比色法（目视比色法）      | 将供试液与一系列标准比色液目视比较，判断颜色深浅和色调                                      | 批放行检测（GMP 放行项目）、日常质量控制               | 操作简便、主观性较强；须训练有素的检验人员；中美欧三大药典均收载此法                                        |
| 紫外-可见分光光度法（UV-Vis） | 通过测定溶液在特定波长（如 450 nm、480 nm）的吸光度，定量表征颜色深浅                       | 方法学研究、工艺优化中的颜色变化监控、批间颜色比较     | 客观定量、高重复性；可监控特定波长的颜色变化趋势（尤其是棕黄色氧化相关变化）                                |
| 色差计法（Colorimetry）       | 通过颜色测量仪器（色差仪/分光测色仪）测定 CIE L\*a\*b\* 或 CIE L\*C\*h 色度值，全面描述颜色 | 精确的颜色定量描述、批间颜色一致性评估、颜色标准的建立 | 最客观准确；可提供颜色的亮度（L\*）、红绿方向（a\*）、黄蓝方向（b\*）的定量数据；适合用于建立数字化颜色标准 |

**色差计法的参数解读**

| 参数           | 含义                     | 与颜色异常的关联                                        |
| -------------- | ------------------------ | ------------------------------------------------------- |
| L\*（亮度）    | 100 = 纯白；0 = 纯黑     | L\* 降低 → 颜色变深，可能提示聚集或氧化                 |
| a\*（红-绿轴） | 正值 = 偏红；负值 = 偏绿 | 单抗通常 a\* 接近 0                                     |
| b\*（黄-蓝轴） | 正值 = 偏黄；负值 = 偏蓝 | b\* 升高 → 颜色偏黄，常见于氧化/棕色化                  |
| ΔE（总色差）   | 与参比的综合颜色差异     | ΔE < 2 通常认为人眼难以区分；ΔE > 3～5 时有明显可见差异 |

:::

## 中美欧药典溶液颜色检查法的关键差异：比色液组成、色号编排规律与跨区申报注意事项

:::answer

**三大药典目视比色法的共同点与核心差异**

目视比色法是《中国药典》（ChP）、《美国药典》（USP）和《欧洲药典》（EP）通用的溶液颜色检查方法，但三者在比色液配制和色号编排上存在显著差异，在进行跨地区申报时须特别关注。

**比色液体系的本质差异**

| 维度           | 中国药典（ChP）            | 美国药典（USP）                | 欧洲药典（EP）                                      |
| -------------- | -------------------------- | ------------------------------ | --------------------------------------------------- |
| 比色液配制原料 | 与 USP/EP 不同的原料体系   | 氯化钴、重铬酸钾、硫酸铜       | 与 USP 使用相同原料，但配制方法不同                 |
| 原料种类       | 独立体系                   | 三种标准原料溶液组合           | 三种标准原料溶液组合（配比与 USP 有差异）           |
| 色调范围       | 棕、棕绿、黄绿、黄、橙黄等 | BY（棕黄）、Y（黄）、R（红）等 | Y（黄）、BY（棕黄）、B（棕）、R（红）、GY（黄绿）等 |

**色号编排规律的重要差异**

| 药典     | 色号规律                           | 实践含义                                          |
| -------- | ---------------------------------- | ------------------------------------------------- |
| 中国药典 | **色号越大，颜色越深**（线性规律） | 易于按色号判断深浅，如 Y1 < Y2 < Y3               |
| 欧洲药典 | **色号越大，颜色越浅**（反向规律） | Y1 是最深的黄色，Y7 是最浅的黄色——与 ChP 完全相反 |
| 美国药典 | 各色号不按深浅排列，**无规律**可循 | 须逐个查阅具体色号的颜色深浅，不能按编号推断      |

**跨区申报的实操建议**

- 为同一产品在多个地区（中国、美国、欧洲）申报时，颜色质量标准须分别按照各药典的比色液体系制定，不能直接照搬；
- 建议在产品开发早期用三种药典方法同步评估样品，建立各药典体系下的颜色参比标准，避免申报后期发现标准不匹配；
- 对于颜色在临界范围（接近规格上限）的产品，三种方法均应进行系统的方法学适用性研究；
- 颜色参比品（Physical Reference Standard for Color）须妥善保存，避免自身因光照或氧化发生颜色变化。

:::

## 原液颜色异常的全链路调控策略：细胞株构建、上游培养与下游纯化的三阶段干预

:::answer

**颜色异常调控的战略定位**

抗体药物原液（Drug Substance, DS）的颜色变化可能在生产工艺的**任何阶段**发生，既可能在细胞培养过程中由代谢物积累引起，也可能在纯化后储存过程中由氧化降解引起。早期工艺开发中对颜色属性的系统评估，有助于在工艺优化阶段识别风险因素并采取针对性措施，而非等到最终产品颜色超标后再追溯。

**阶段一：细胞株构建阶段的颜色风险控制**

- **克隆筛选时的颜色考量：** 不同克隆在相同培养条件下产生的代谢产物组成有所差异，部分克隆可能产生更多的有色代谢物（如酮酸、有色辅酶类物质）；
- **培养基与细胞代谢优化：** 针对目标克隆的代谢特性进行培养基定制，减少可能导致颜色的前体物质（如维生素 B12、铁离子等）的积累；
- **在克隆筛选阶段即引入颜色评估指标**（UV-Vis 或色差计），筛选出天然颜色负担较低的候选克隆。

**阶段二：上游培养阶段的颜色控制措施**

**维生素 B12 与光照的关联机制：**

- 光照会诱导培养基中的**维生素 B12（氰钴胺素）降解为羟钴胺素**——后者呈红/棕色，是抗体原液颜色偏黄棕的重要来源之一；
- 光照同时增加培养物中的**氧化应激（Oxidative Stress）水平**，通过产生活性氧（ROS）引发蛋白氧化和辅料（如维生素、吐温）的氧化降解，进一步加重颜色变化。

**上游光照控制措施：**

| 控制手段     | 操作方式                                                    | 原理                                                       |
| ------------ | ----------------------------------------------------------- | ---------------------------------------------------------- |
| 物理避光     | 培养基/补料液容器用铝箔包裹，生物反应器包裹遮光材料         | 直接隔绝光线，阻断光化学反应                               |
| 安全照明     | 采用红光（波长 >600 nm）或绿光，或波长 >500 nm 的彩色光照明 | 避免维生素 B12 吸收峰（约 361 nm 和 550 nm）对应波长的光照 |
| 抗氧化剂添加 | 向培养基添加 N-乙酰-L-半胱氨酸、维生素 C 等                 | 消除 ROS，减轻氧化损伤                                     |

**铁和铜离子浓度的控制：**

研究发现，培养基中的<strong>铁（Fe³⁺）和铜（Cu²⁺）</strong>是颜色形成的重要金属离子——铁和铜可催化 Fenton 反应产生 ROS，加速色氨酸、组氨酸等芳香族氨基酸的氧化，并与蛋白质发生络合（铁离子与蛋白的螯合呈棕黄色）。

**阶段三：下游纯化阶段的颜色去除与控制**

**纯化步骤对颜色的局限性：**

- 高含量的铁离子和维生素（与蛋白非共价结合）**在常规纯化工艺中很难完全去除**，部分会随目标蛋白一起洗脱，成为持续的颜色来源；
- 层析过程中蛋白持续暴露于光照（UV 检测器光源、层析设备周边光线）会进一步诱导氧化；
- 储存于透明袋中的中间体（层析洗脱液、超滤液）也会受到光照刺激。

**下游颜色控制措施：**

- 纯化全程尽可能避光操作（尤其是长保持时间的步骤）；
- 选择低颜色影响的缓冲液体系（避免含铁的缓冲液组分）；
- 评估加入螯合剂（如 EDTA）控制游离金属离子的可行性（须评估对产品和工艺的影响）；
- 优化制剂辅料选择——若使用聚山梨酯（吐温 80/20），须关注其氧化降解产生 ROS 引起的继发性颜色变化。

:::

## 光照诱导颜色变化的分子机制：维生素 B12 降解路径、氧化应激与制剂辅料的关联影响

:::answer

**光照诱导颜色变化的核心分子路径**

抗体原液的颜色变化在多数情况下是由**光照介导的氧化反应**引起的，其分子路径涉及多个相互关联的化学过程：

**路径一：维生素 B12 光降解**

```
培养基中的维生素 B12（氰钴胺素，无色/粉红）
        ↓ 光照（尤其是蓝/绿光，360～550 nm）
羟钴胺素（Hydroxocobalamin，红/棕色）
        ↓ 进一步降解
钴离子释放（催化 Fenton 反应）→ ROS 产生
```

维生素 B12 降解产物（尤其是羟钴胺素）本身具有较强的可见光吸收，是培养液和纯化中间体颜色偏黄棕的重要来源。

**路径二：金属离子催化的氧化**

```
Fe²⁺/Cu⁺ + H₂O₂ → Fe³⁺/Cu²⁺ + OH• + OH⁻（Fenton 反应）
OH•（羟自由基，高活性）
        ↓
氧化蛋白质（Trp → 犬尿氨酸/N-甲酰犬尿氨酸，吸收紫外和可见光）
氧化培养基组分（有色氧化产物积累）
```

**路径三：辅料（吐温）的氧化与颜色关联**

制剂中常用的<strong>聚山梨酯 80/20（Polysorbate 80/20，PS80/PS20）</strong>在氧化条件下可发生自身降解：

```
PS80/PS20 氧化（光照/金属离子催化）
        ↓
产生过氧化物（Hydroperoxides）和醛类（Aldehydes）
        ↓
作为 ROS 来源或直接与蛋白质发生迈拉德反应
        ↓
蛋白质氧化 + 有色降解产物 → 制剂颜色变化
```

这解释了为什么在纯化"干净"的蛋白溶液中加入吐温辅料后，长期储存仍可能出现颜色加深的现象——吐温本身成为了颜色变化的间接促进因素。

**颜色异常问题的系统挑战**

- 层析过程的特殊曝光：蛋白洗脱液通过 UV 检测器时暴露于检测器光源；结合在柱子上的蛋白在色谱柱操作期间也暴露于环境光；
- 时间效应的延迟性：纯化后的抗体 DS 在刚完成时颜色可能完全正常，但随放置时间延长（数周至数月），上述氧化损伤的积累效应才会在颜色上显现；
- 这种"延迟显现"特性使得在工艺开发阶段仅凭新鲜样品的颜色评估不足以预判长期稳定性颜色变化。

## 蛋白质物理不稳定性：聚集机制的分类（非共价 vs. 共价）与对产品质量的影响

:::answer

**物理不稳定性的核心表现**

蛋白质的物理不稳定性（Physical Instability）主要表现为**蛋白质聚集（Aggregation）**——即两个或多个蛋白质分子通过非共价或共价相互作用形成更大的分子聚合体。聚集是生物药产品质量控制中的核心挑战之一，直接关联免疫原性风险（高分子量聚集体具有较高免疫原性）。

**蛋白质变性与聚集的关系**

聚集往往以<strong>蛋白质局部或全局去折叠（Unfolding）</strong>为先决条件：

```
天然折叠态蛋白质（N）
        ↓ 各种应力（热、剪切、冻融、光照、pH 极端）
部分去折叠态（I，中间态）← 暴露疏水区域
        ↓ 分子间相互作用
可逆聚集体（Reversible Aggregates）→ 进一步稳定 → 不可逆聚集体
```

**两类聚集体的本质区别**

| 特征         | 非共价聚集体                               | 共价聚集体                           |
| ------------ | ------------------------------------------ | ------------------------------------ |
| 结合键类型   | 范德华力、氢键、疏水相互作用、静电相互作用 | 二硫键（最常见）、非二硫键共价交联   |
| 可逆性       | 可逆（稀释、温度、pH 调节后可解聚）        | **不可逆**                           |
| 检测方法     | SEC-HPLC（天然条件，检出总聚体）           | CE-SDS（变性条件，检出共价聚体）     |
| 免疫原性风险 | 中等（可逆，但大颗粒风险高）               | 较高（不可逆，结构改变持久）         |
| 形成条件     | 多种应力均可触发                           | 通常需要氧化（错配二硫键）或化学交联 |

**促进聚集的主要因素**

| 因素类别 | 典型情形                                                        |
| -------- | --------------------------------------------------------------- |
| 温度应力 | 加热（超过 Tm 导致去折叠）；反复冻融（冰晶-液相界面的剪切应力） |
| 界面应力 | 气液界面（搅拌、鼓泡、振荡）；固液界面（与容器表面接触）        |
| 浓度依赖 | 高浓度制剂（蛋白-蛋白相互作用概率升高）                         |
| pH 偏差  | 接近等电点（pI）时净电荷接近零，静电排斥减弱                    |
| 化学修饰 | 甲硫氨酸氧化改变蛋白局部疏水性；脱酰胺改变局部电荷              |
| 辅料氧化 | 吐温氧化降解产生 ROS，诱导蛋白氧化性聚集                        |

**铰链区活动性与聚集的关系**

抗体 IgG 的铰链区（Hinge Region）提供了 Fab 臂相对于 Fc 区的柔性。化学修饰（如铰链区氧化、脱酰胺）或环境因素导致的结构变化可能**降低铰链区活动性**，使分子更趋刚性，增加暴露疏水面的倾向，从而升高聚集风险。

:::

## 化学不稳定性的位点依赖性影响：CDR 区与 Fc 区修饰对药效和安全性的差异化结局

:::answer

**"修饰≠失效"的关键认知：位点决定后果**

化学不稳定性（Chemical Instability，如脱酰胺、氧化、糖化、异构化等）对单抗药物性质的影响程度**高度依赖于其发生的位置**。同一类化学修饰，在 CDR 区和 Fc 区发生的后果可能有着天壤之别。

**脱酰胺（Deamidation）的位点依赖性影响**

| 修饰位置                 | 对药效的影响                                                 | 对 PK 的影响                         | 监管关注程度     |
| ------------------------ | ------------------------------------------------------------ | ------------------------------------ | ---------------- |
| **CDR 区（互补决定区）** | **显著降低抗原结合亲和力及效价**（亲和力可下降数倍至数十倍） | 可能通过影响靶标结合间接改变体内分布 | 极高（直接 CQA） |
| Fc 区（如 CH2/CH3）      | 影响相对较小（Fc 效应功能略变）                              | 通常不显著影响半衰期                 | 中等（需监控）   |
| 非功能性区域             | 通常可忽略                                                   | 通常无显著影响                       | 较低             |

**氧化（Oxidation）的位点依赖性影响**

| 修饰位置                    | 对药效的影响                             | 对 PK 的影响                                    | 监管关注程度 |
| --------------------------- | ---------------------------------------- | ----------------------------------------------- | ------------ |
| **CDR 区（Trp、His、Met）** | **降低靶抗原结合亲和力**（CDR 构象改变） | —                                               | 极高         |
| **Fc 区 Met252/428**        | 降低 FcRn 结合亲和力                     | **增加血浆清除速率，缩短半衰期**（PK 显著影响） | 高           |
| Fc 区其他位点               | 轻微影响                                 | 对半衰期影响有限                                | 中等         |

**化学修饰对蛋白聚集的继发影响**

化学不稳定性与物理不稳定性之间存在密切关联，化学修饰往往是聚集的上游驱动因素：

- **甲硫氨酸氧化（Met-O）：** 引起蛋白质局部疏水性增加（氧化 Met 的疏水性弱于原始 Met），改变二级结构稳定性，促进分子聚集；
- **脱酰胺（Asp/isoAsp 形成）：** 引入额外负电荷，改变蛋白表面电荷分布，在特定条件下降低分子间静电排斥，增加聚集倾向；
- **色氨酸氧化（犬尿氨酸形成）：** 引起芳香族氨基酸的结构变化，可能影响蛋白质整体折叠稳定性。

**非 CDR 区化学修饰的评估策略**

当化学修饰发生在非 CDR 区域时，若该药物无 Fc 相关效应功能（如 ADCC/CDC 非主要作用机制），则对药效的影响相对较低。此时评估重点应转向**安全性评估**：

- 化学修饰产物（如氧化变体、脱酰胺变体）是否具有新的免疫原性表位？
- 化学修饰是否引起蛋白构象改变，进而影响其代谢或组织分布？
- 化学修饰变体在批间的分布是否稳定可控？

:::

## 生物药稳定性研究体系：原液、制剂与中间体的多层次研究框架

:::answer

**稳定性研究的系统性意义**

由于抗体分子结构复杂、不稳定性影响因素多（物理、化学、微生物等多个维度），单一的稳定性研究无法全面评估产品的长期质量保障能力。须建立覆盖从中间体到最终制剂的**多层次、多条件**稳定性研究体系。

**稳定性研究体系的六大维度**

**① 原液（Drug Substance, DS）稳定性研究**

- **目的：** 确认原液在规定储存条件（通常 -70℃ 冻存）下的长期质量稳定性，建立原液有效期；
- **关键研究点：** 冻存条件的影响（温度均匀性）、储存容器（接触面浸出物）、长期冻存对蛋白高级结构的影响；
- **检测项目：** SEC（聚体/片段）、IEX/iCIEF（电荷变体）、效价、外观（颜色/澄清度）、蛋白浓度、HMW%。

**② 制剂（Drug Product, DP）稳定性研究**

- **目的：** 确认制剂在市售包装规格和指定储存条件（通常 2～8℃）下的货架期，建立制剂有效期；
- **ICH Q5C 要求：** 须包含加速稳定性（如 25℃/60% RH）和长期稳定性（如 2～8℃）条件；
- **冻干制剂额外要求：** 须包含复溶稳定性研究。

**③ 下游纯化中间体稳定性研究**

- **目的：** 确认各纯化步骤中间产物（如 Protein A 洗脱液、CEX 洗脱液、超滤液）在保存条件下的稳定保存时限；
- **关键参数：** 保存温度（2～8℃ vs. 室温）、保存时间上限（通常设定最长保存时间，如 24 h、48 h、72 h）；
- **意义：** 为生产计划（批次中间停顿时间）提供科学依据，支持批记录中的中间体保存参数设定。

**④ 药物使用中稳定性研究（In-Use Stability）**

- **目的：** 模拟患者实际使用场景，评估制剂从西林瓶/预充注射器打开（或复溶）到患者实际给药完成期间的稳定性；
- **关键考察因素：** 复溶稀释后的稳定性（与生理盐水/葡萄糖注射液相容性）；室温放置时间（光照、温度暴露）；输液袋材质与制剂的相容性；给药装置（注射器、输液器）引入的微粒。

**⑤ 冻融稳定性研究**

- **目的：** 评估原液在冻融过程中的质量变化，支持冻融操作规程的制定（冻融次数上限、解冻条件）；
- **关键挑战：** 冰晶形成/消融时的蛋白质聚集；冻融过程中浓度梯度形成（冰晶排斥效应导致局部高浓度区域）；冻融速率对聚集的影响（通常缓慢解冻比快速解冻更温和）。

**⑥ 光稳定性研究**

- **目的：** 评估产品对光照的敏感性，支持遮光包装设计和储存/使用过程中的光照控制要求；
- **ICH Q1B 要求：** 须进行光稳定性研究，对光敏感产品须在包装标签上注明避光保存要求。

:::

## 可提取物（Extractables）与浸出物（Leachables）的定义、区别与研究的逻辑关系

:::answer

**两个核心概念的精确定义**

**可提取物（Extractables, E）**

在**极端实验室条件**下（如有机溶剂、极端高温、强酸强碱、高离子强度、极端 pH、超长接触时间等），从过滤器、一次性系统、容器密封系统等包装/工艺接触组件的**接触表面提取出的化学物质**。

> 可提取物是对材料潜在化学迁移能力的**最大化表征**，代表该材料理论上可能释放的物质的总集合。

**浸出物（Leachables, L）**

在**正常储存或工艺条件**（实际接触时间、实际温度、实际 pH、实际溶液性质等）下，从接触产品或非接触产品的材料中**实际迁移进入药品或工艺流体中的化学物质**。

> 浸出物是在真实使用条件下患者实际暴露于的化学物质，是安全性评估的直接对象。

**两者的关键关系：子集关系**

```
可提取物（Extractables）
        ↓ 子集（Subset）
浸出物（Leachables）

可提取物 ⊇ 浸出物（浸出物是可提取物的子集）
```

- **多数情况下：** 浸出物是可提取物的子集——在实际使用条件下，只有可提取物中的部分物质会在常规条件下真正迁移进入产品；
- **例外情况（可提取物中有不包含于浸出物的成分）：** 某些可提取物只在极端提取条件下才能溶出，在实际产品接触条件下不会迁移——这些物质出现在可提取物研究中，但不会出现在浸出物研究中；此种情况通常是由于可提取物与浸出物的提取/接触条件差异所致。

**研究重点的本质差异**

| 维度         | 可提取物研究                             | 浸出物研究                           |
| ------------ | ---------------------------------------- | ------------------------------------ |
| 测试对象     | **材质本身**的化学特性                   | **药品与材质的实际相互作用**         |
| 测试条件     | 极端条件（模拟最坏情况）                 | 实际使用/储存条件（模拟真实场景）    |
| 研究目的     | 了解材料可能释放的物质全貌，用于包材筛选 | 确认患者实际暴露水平，用于安全性评估 |
| 研究时间节点 | 包材选型阶段（早期）                     | 制剂开发阶段（结合稳定性研究）       |

:::

## 浸出物与可提取物对产品安全性和质量的潜在影响及风险量化

:::answer

**E&L 的潜在危害类型**

浸出物和可提取物对生物制品的潜在影响涵盖两个层面：

**对患者安全性的直接影响**

| 影响类型      | 具体机制                             | 典型化合物                                         |
| ------------- | ------------------------------------ | -------------------------------------------------- |
| 细胞毒性      | 有毒化合物抑制细胞功能或诱导细胞死亡 | 某些残留单体（如丙烯酸酯类）；部分抗氧剂降解产物   |
| 致癌/遗传毒性 | 化合物损伤 DNA 或具有致癌潜力        | 苯类化合物（benzene）；N-亚硝胺类；多环芳烃（PAH） |
| 免疫毒性      | 引发过敏反应或免疫激活               | 某些橡胶添加剂；蛋白质变性诱导的新表位             |
| 内分泌干扰    | 干扰激素系统                         | 双酚 A（BPA）；邻苯二甲酸酯类                      |

**对产品质量的间接影响**

| 影响类型       | 机制                                                                  | 结果                           |
| -------------- | --------------------------------------------------------------------- | ------------------------------ |
| 蛋白聚集       | 金属离子浸出（Fe/Cu）催化氧化；特定有机化合物与蛋白的非特异性相互作用 | HMW 含量升高，免疫原性风险增加 |
| 蛋白沉淀       | pH 或离子强度的改变（由浸出的酸性或碱性物质引起）                     | 可见颗粒形成，产品外观不合格   |
| 蛋白失活       | 浸出的蛋白酶活性物质；与 CDR 区相互作用的化合物                       | 效价下降                       |
| 稳定性加速降解 | 过氧化物浸出（来自 PP/PE 加工助剂）催化吐温和蛋白的氧化               | 颜色变化、聚集体升高           |

**质量风险的识别不足带来的商业后果**

若生产企业无法对所有潜在的浸出物进行全面准确的鉴定，或无法建立有效的浸出物控制策略，可能导致：

- 产品召回（上市后发现浸出物超过安全限度）；
- 申报资料被监管机构要求补充大量数据（延误上市时间）；
- 批次废弃（浸出物导致产品质量属性超出规格）；
- 品牌信誉损失（患者安全事件报告）。

:::

## 浸出物与可提取物的法规要求框架：FDA 和 GMP 的核心条款与包材选型合规义务

:::answer

**美国 FDA 的法规依据**

美国 FDA 21 CFR Part 211.65 明确规定：

> "设备的构造应确保与成分、加工中材料或药品接触的表面**不会发生反应、添加或吸收**，从而改变药品的安全性、特性、强度、质量或纯度，超出官方或其他既定要求。"

这一条款确立了**包装材料不得对药品产生有害影响**的基本合规要求，E&L 研究是证明符合此要求的核心手段。

**中国 GMP 的法规依据**

《药品生产质量管理规范》（2010 年修订）第七十四条：

> "与药品直接接触的生产设备表面应当平整、光洁、易清洗或消毒、耐腐蚀，**不得与药品发生化学反应、吸附药品或向药品中释放物质**。"

**关键指导文件**

| 文件               | 适用范围               | 核心内容                          |
| ------------------ | ---------------------- | --------------------------------- |
| USP <661>          | 容器材料               | 注射制剂容器的 E&L 测试要求       |
| USP <1664>         | 容器密封系统（CSS）    | 容器密封系统的 E&L 研究方法       |
| ICH Q3E            | 元素杂质               | 对 E&L 中金属元素的安全限度要求   |
| ICH Q3D            | 药物制剂中的元素杂质   | 包材引入的元素杂质控制框架        |
| BioPhorum E&L 指南 | 生物制品一次性使用系统 | 一次性系统的 E&L 研究行业最佳实践 |
| FDA 注射剂指南     | 注射剂包材             | 容器密封系统的安全性评估要求      |

**合规义务的实践要点**

- **BLA 申报前须完成 E&L 研究**（IND 阶段无强制要求，但建议在包材确定时即启动评估）；
- 须对**所有与产品直接接触的材料**（西林瓶/预充注射器、胶塞/活塞、容器密封系统、输液袋、管路、过滤器）分别进行 E&L 评估；
- 每种包材的 E&L 研究数据须由**有资质的分析实验室**出具，并经过方法学验证；
- 供应商变更（即使是"等同"材质）可能需要重新进行 E&L 评估。

:::

## 影响浸出物与可提取物水平的关键因素：材料性质、接触条件与产品特性的多维分析

:::answer

**E&L 水平的影响因素体系**

浸出物和可提取物的种类和含量受多个因素共同影响，理解这些因素是设计科学合理的 E&L 研究方案的基础。

**因素一：材料本身的特性**

| 材料特性                         | 对 E&L 的影响                                                                                         |
| -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 聚合物骨架（PP/PE/PVC/硅橡胶等） | 不同骨架材料的单体和低聚物浸出倾向不同                                                                |
| 添加剂种类和含量                 | 塑化剂、抗氧化剂（Irganox、Irgafos 等）、稳定剂、润滑剂是主要 E&L 来源                                |
| 加工历史（灭菌方式）             | 辐射灭菌（γ/β射线）会引发聚合物分子链断裂，显著增加低分子量浸出物；高温蒸汽灭菌对某些聚合物有降解影响 |
| 材料批次差异                     | 同一牌号不同批次可能因添加剂批次差异导致 E&L 谱图差异                                                 |

**关键浸出物来源举例（聚合物添加剂）：**

```
聚合物添加剂类别 → 典型化合物 → 已知 E&L 风险
塑化剂 → 邻苯二甲酸酯（DEHP 等）→ 内分泌干扰，致癌风险
抗氧化剂 → BHT、BHA、Irganox 系列 → 部分具有遗传毒性
抗氧化剂降解产物 → 苯并呋喃衍生物、环状聚合物 → 细胞毒性/遗传毒性
残留催化剂 → 有机锡化合物（PVC 热稳定剂）→ 高毒性
润滑剂 → 硬脂酸盐系列 → 通常低风险
```

**因素二：接触产品的特性**

| 产品特性       | 对 E&L 的影响                                                                      |
| -------------- | ---------------------------------------------------------------------------------- |
| **溶液 pH**    | 酸性 pH（<5）通常增加金属离子和某些有机物的浸出量；碱性 pH（>8）可能降解特定添加剂 |
| **辅料组成**   | 有机辅料（乙醇、聚山梨酯）具有更强的浸出能力；高离子强度缓冲液可能影响金属浸出     |
| **蛋白质浓度** | 高浓度蛋白可能与某些浸出物发生特异性结合，改变其在产品中的形态                     |

**因素三：接触条件**

| 接触条件               | 对 E&L 的影响                                                                                                  |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| **接触面积（S/V 比）** | 接触面积/溶液体积比越大，浸出物浓度越高；小容量制剂（1～2 mL）比大容量（100 mL）S/V 比更高，浸出物浓度相对更大 |
| **接触时间**           | 随接触时间延长，浸出物浓度逐渐增加（达到溶解平衡前）；货架期研究须覆盖有效期全程                               |
| **接触温度**           | 升温显著加速浸出（Arrhenius 关系）；灭菌（高温短时）和长期储存（低温长时）均须考虑                             |
| **灭菌方式**           | 辐射灭菌 > 蒸汽灭菌 > 环氧乙烷灭菌（对聚合物结构的破坏程度顺序）                                               |

:::

## 浸出物研究的核心内容：稳定性样品中浸出物的检测分析与方法学要求

:::answer

**浸出物研究的目标与研究设计**

浸出物（Leachables）研究的核心目标是定量证明：在产品整个货架期内，从包材实际迁移进入药品中的化学物质种类和含量满足安全性要求，不超过监管机构规定的限度（AET，Analytical Evaluation Threshold；SCT，Safety Concern Threshold）。

**研究设计要点**

- **样品来源：** 须使用**拟商业化的最终容器密封系统**（而非替代容器）制备稳定性样品；
- **稳定性条件：** 须在加速条件（如 25℃/60% RH，40℃/75% RH）和长期条件（如 5℃）下同步进行；
- **取样时间点：** 与常规稳定性研究相同（通常 T0、T1、T3、T6、T9、T12 月，加速和长期各自设置）；
- **分析频率：** 须在整个研究期间采集足够时间点的浸出物谱图，建立浸出物随时间变化的动态曲线。

**分析方法的技术挑战**

浸出物研究的分析难度在于：须在**复杂药物制剂基质背景**下可靠地检测和定量通常处于**ppb～ppm 水平**的微量化学物质。

**推荐分析平台：**

| 分析技术                       | 检测范围                     | 典型检测对象                      |
| ------------------------------ | ---------------------------- | --------------------------------- |
| LC-MS/MS（液相色谱-串联质谱）  | 有机浸出物（极性～中等极性） | 添加剂及其降解产物、有机酸/碱     |
| GC-MS（气相色谱-质谱）         | 挥发性和半挥发性有机物       | 残留溶剂、小分子挥发物            |
| ICP-MS（电感耦合等离子体质谱） | 元素（金属）杂质             | 金属离子浸出（Fe、Cu、Ni、Cr 等） |
| HPLC-UV/DAD                    | 特定已知浸出物的定量         | 已鉴定浸出物的批放行控制          |

**方法学验证要求**

浸出物检测方法须进行规范的**方法学验证**，至少覆盖以下参数：

- **专属性（Specificity）：** 确保目标浸出物能在药物制剂基质中被准确识别，不受基质成分干扰；
- **检测限（LOD）和定量限（LOQ）：** 须低于 AET（分析评估阈值），确保有安全性意义的浸出物不被漏检；
- **准确度和精密度：** 覆盖预期浸出物浓度范围；
- **耐用性：** 评估关键参数微小变化对检测结果的影响。

:::

## 可提取物研究的核心内容：提取条件设计、模拟液选择与方法开发策略

:::answer

**可提取物研究的战略定位**

可提取物（Extractables）研究处于 E&L 研究流程的**上游**，其结果用于：① 包材筛选（在制剂开发早期快速评估候选包材的 E&L 风险级别）；② 提供浸出物研究的"候选物清单"（预测哪些化合物可能作为浸出物出现在最终产品中）；③ 支持包材的风险评估决策。

**提取条件设计的核心原则**

提取试验须在**比实际产品接触条件更剧烈**的极端条件下进行，以确保能充分暴露材料可能释放的化学物质，而不遗漏潜在的有害浸出物：

- **不可过于温和**（否则可提取物不能预测潜在浸出物，失去研究价值）；
- **不可过于剧烈**（避免"过度提取"——在超出任何可能实际接触条件的极端下提取出来的物质，实际上永远不会出现在浸出物中，会产生大量无意义的假阳性信息）。

**模拟液（Extraction Solvent）的选择策略**

模拟液须与制剂的理化性质相似，同时覆盖不同极性范围以全面捕获各类化学物质：

| 模拟液类型 | 典型溶剂           | 捕获目标化合物                         |
| ---------- | ------------------ | -------------------------------------- |
| 水性低极性 | 注射用水           | 高极性水溶性化合物                     |
| 水性中极性 | 稀乙醇（10%～20%） | 中极性化合物，模拟含辅料的制剂         |
| 有机溶剂   | 甲醇、乙酸乙酯     | 低极性有机化合物（添加剂及其降解产物） |
| 酸性溶液   | 0.1 M HCl          | 碱性化合物；酸性条件下的水解产物       |
| 碱性溶液   | 0.1 M NaOH         | 酸性化合物；碱性条件下的水解产物       |

**提取条件的关键变量**

| 变量     | 典型极端化方向                          | 理由                                 |
| -------- | --------------------------------------- | ------------------------------------ |
| 温度     | 超过实际储存/使用温度（如 40℃、60℃）    | 加速溶出，在短时间内获取长期浸出信息 |
| 时间     | 超过实际最长接触时间（如持续浸泡 72 h） | 确保达到溶解平衡                     |
| 溶剂强度 | 强有机溶剂辅助提取                      | 彻底提取低极性化合物                 |

**研究核心信息收集要求**

对于具有较强浸出能力（高风险）的包材，须尽可能收集以下信息以指导研究设计：

- **材料组成信息：** 聚合物骨架、牌号、添加剂种类（稳定剂、抗氧化剂、增塑剂等）；
- **加工信息：** 成型工艺、清洗工艺、灭菌方式；
- **历史 E&L 数据（来自供应商）：** 供应商提供的可提取物研究报告（Extractables Profile）。

**可提取物→浸出物的转化评估（Bridge Study）**

确定可提取物谱图后，须评估每种可提取物化合物在实际产品接触条件下的**预期浸出量**，判断其是否有可能出现在浸出物中，以确定浸出物研究的优先目标化合物清单（Target Compound List, TCL）。

:::

## E&L 研究的完整流程：从信息收集到安全性评估的八步标准化方法

:::answer

**E&L 研究的标准化流程概览**

```
① 收集相关信息
（材料组成、加工工艺、灭菌方式、产品接触条件）
        ↓
② 设计实验方案
（确定研究范围、模拟液选择、提取条件设定、分析技术平台）
        ↓
③ 进行材料提取试验（可提取物研究）
或浸出试验（稳定性样品中的浸出物研究）
        ↓
④ 收集实验数据
（色谱图、质谱谱图、元素分析数据）
        ↓
⑤ 可提取物相关成分分析鉴定
（化合物定性：结构鉴定、化合物类别归属）
        ↓
⑥ 确定潜在有害浸出物
（识别具有安全性关注的化合物，列入优先控制清单）
        ↓
⑦ 测定稳定性样品中有害浸出物含量
（建立针对性定量分析方法并进行方法学验证）
        ↓
⑧ 安全性评估（Safety Assessment）
（与 AET/SCT 等阈值比对，评估患者风险，得出合规结论）
```

**关键阈值的定义（ICH Q3E 框架）**

| 阈值 | 英文全称                                             | 含义                                     | 意义                                                |
| ---- | ---------------------------------------------------- | ---------------------------------------- | --------------------------------------------------- |
| AET  | Analytical Evaluation Threshold（分析评估阈值）      | 需要对浸出物进行定性和定量分析的最低浓度 | 低于 AET 的化合物可不进行进一步安全评估             |
| SCT  | Safety Concern Threshold（安全性关注阈值）           | 基于毒理学评估确定的最大可接受每日摄入量 | 超过 SCT 的化合物须进行详细安全性评估或采取降低措施 |
| TTC  | Threshold of Toxicological Concern（毒理学关注阈值） | 基于结构活性关系的默认安全限度           | 用于无特定毒理学数据时的默认安全性评估              |

**安全性评估的方法**

- **已知化合物：** 与现有毒理学数据库（ICH Q3C、IARC 致癌物分类、FDA 毒理学数据库）比对；
- **无毒理学数据的新化合物：** 采用结构活性关系（SAR/QSAR）预测毒性；
- **遗传毒性杂质：** 参照 ICH M7 框架进行评估（TTC 为 1.5 μg/day 终生每日摄入量）。

:::

## E&L 研究的启动时机与申报策略：IND 阶段的早期准备与 BLA 阶段的完整合规要求

:::answer

**申报阶段要求的分级管理**

| 申报阶段   | E&L 研究要求                                                            | 推荐实践                                                                     |
| ---------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| IND 申报   | **无强制要求**，监管机构一般不强制要求提交完整 E&L 数据                 | 但建议在 IND 前完成初步包材筛选，排除明显高风险材料                          |
| BLA 申报前 | **须完成完整的 E&L 研究**，包括可提取物研究和基于长期稳定性的浸出物研究 | 须在 BLA 申报前至少 12～18 个月启动 E&L 研究（考虑长期稳定性数据的累积时间） |

**不同接触部件的研究优先级**

不同来源的接触材料，其 E&L 引入风险不同，须差异化管理：

| 来源                                         | 接触强度 | 研究优先级 |
| -------------------------------------------- | -------- | ---------- |
| 原液储存容器（直接接触产品，长期储存）       | 高       | **最优先** |
| 制剂一次性包装（西林瓶+胶塞/预充注射器）     | 高       | **最优先** |
| 纯化工艺一次性系统（直接接触产品，较短时间） | 中～高   | 高优先级   |
| 给药输液器具（患者实际使用，短时接触）       | 中       | 中等优先级 |
| 非接触产品的包装（外包装）                   | 低       | 通常豁免   |

**E&L 研究的关键时间规划建议**

```
工艺开发阶段（IND 前）
└── 初步包材筛选：根据可提取物预筛选（Tier 1 Screening），排除高风险材料
        ↓
IND 申报后～临床 II/III 期
└── 确定商业化包材（容器密封系统最终确认）
        ↓
临床 III 期开始前（或不晚于 PPQ 批次生产前）
└── 启动完整 E&L 研究：可提取物 + 浸出物稳定性研究（至少 12 个月长期稳定性数据）
        ↓
BLA 申报前
└── 完成 E&L 研究、安全性评估报告，纳入 BLA 申报资料 Module 3.2.P.2 和 3.2.P.7
```

:::

## 细胞株稳定性研究的目标与双重验证维度：生产能力一致性与遗传稳定性的系统证明

:::answer

**细胞株稳定性研究的战略意义**

细胞株稳定性研究是生物制品 CMC 开发的关键活动之一，其根本目的是**证明用于生产的细胞株在整个商业化生产期间保持稳定**，从而保障产品的批间一致性、有效性和安全性。

**两个核心验证维度**

**维度一：生产能力的一致性验证**

- **表达量稳定性：** 多代次（从 MCB 至 EOPC）细胞株的蛋白质表达量（Titer）保持在可接受的一致性范围内；
- **产品质量稳定性：** 各代次生产的产物质量属性（糖基化谱、电荷变体、聚体含量等 CQA）无显著变化；
- **连续生产稳定性：** 在正常保存（如冻存 -70℃）和培养条件下，细胞保持持续高效生产目的蛋白的能力。

**维度二：遗传稳定性验证**

- **基因拷贝数稳定性：** 目的基因（如抗体重链/轻链基因）在多代次传代后的拷贝数保持稳定（无显著丢失）；
- **序列完整性：** 目的基因序列和表达框架序列在多代次后无突变或缺失；
- **载体整合稳定性：** 表达载体在宿主细胞染色体中的整合状态保持稳定（无重排）；
- **内源病毒因子稳定监测：** 对各关键时间点（MCB、EOPC）进行内源性逆转录病毒等安全性检查；
- **致瘤性监测：** 对新建细胞系在适当时候进行成瘤性检查。

**稳定性研究内容的具体要求**

| 研究内容       | 检测项目                                                         | 时间节点                 |
| -------------- | ---------------------------------------------------------------- | ------------------------ |
| 遗传稳定性     | 目的基因及表达框架序列分析（DNA 测序）、基因拷贝数（qPCR/ddPCR） | MCB、WCB、中间代次、EOPC |
| 表达量稳定性   | 蛋白产量（Titer）、细胞比生产速率（Qp）                          | 各传代代次               |
| 产物质量一致性 | 糖型分析、SEC 纯度、IEX 电荷变体、CE-SDS 分子量                  | 各传代代次               |
| 细胞安全性     | 内源性病毒因子检查（PERT 法）、成瘤性                            | 关键代次节点             |

:::

## 细胞株稳定性研究中的传代稳定性：带压传代与不带压传代的适用场景与权衡

:::answer

**选择压力（Selection Pressure）的含义**

在细胞株构建过程中，通常通过**筛选抗生素（如 G418、MTX、嘌呤霉素）**的选择压力（Selection Pressure）来维持表达载体的整合稳定性，使仅含有目的基因的细胞得以存活。

**带压传代（With Selection Pressure）**

- **操作方式：** 传代过程中持续保留筛选抗生素（维持选择压力）；
- **优点：** 强制维持外源基因的保留，细胞株遗传稳定性有保障；
- **缺点：**
  - 细胞可能因长期处于筛选压力下生长速率较缓慢；
  - 生产时筛选抗生素可能有残留，须控制其在产品中的残留量（潜在的安全性风险）；
  - 筛选抗生素可能影响某些质量属性；
- **适用场景：** 研究阶段评估细胞株稳定性基线；高度关注遗传稳定性的早期传代研究。

**不带压传代（Without Selection Pressure）**

- **操作方式：** 移除筛选抗生素，在无选择压力下传代；
- **优点：**
  - 更真实地模拟商业化生产条件（生产阶段通常不含筛选抗生素）；
  - 细胞生长不受抗生素抑制，增殖速率正常；
  - 节省原料成本；
- **缺点：** 失去选择压力后，高代次细胞株可能出现目的基因拷贝数降低，表达量和质量属性的稳定性可能较差；
- **适用场景：** 模拟商业化生产条件下的细胞株稳定性评估；验证细胞株在无抗生素压力下的真实稳定性。

**实践建议**

- 建议在细胞株稳定性研究中**同时开展带压和不带压传代**，对比分析两种条件下遗传稳定性和表达量的差异；
- 若不带压传代的稳定性数据与带压传代相当，则可支持商业化生产在无选择压力条件下进行，降低生产成本和产品中的抗生素残留风险；
- 商业化生产用的最终细胞株稳定性研究（用于支持 BLA 申报的 EOPC 检定数据）须在**不带压**或商业化生产实际条件下进行。

:::

## 细胞株稳定性的判断标准：基因拷贝数、产物质量与产量三维评估体系

:::answer

**三维稳定性判断标准体系**

细胞株稳定性的判断须从遗传、质量和产量三个维度综合评估，**三项标准须同时满足**方可认定细胞株在研究代次范围内具有稳定性。

**标准一：遗传稳定性（基因层面）**

| 检测项目                       | 接受标准                                                                         | 检测方法                     |
| ------------------------------ | -------------------------------------------------------------------------------- | ---------------------------- |
| 基因拷贝数（Gene Copy Number） | 研究代次内（从起始代次至最高代次）拷贝数无显著降低（通常要求 >70% 的起始拷贝数） | qPCR / ddPCR（绝对定量）     |
| 目的基因序列                   | 研究代次内与 MCB 序列 100% 一致（无点突变、插入、缺失）                          | Sanger 测序 / NGS 全序列覆盖 |
| 表达框序列完整性               | 无移码突变或剪接异常                                                             | 测序 + 转录组分析            |

**标准二：产物质量一致性（CQA 层面）**

| 评估内容                               | 接受标准                                        |
| -------------------------------------- | ----------------------------------------------- |
| 糖基化谱（高甘露糖型、岩藻糖化比例等） | 研究代次内各糖型比例无显著变化（通常 CV% <20%） |
| 电荷变体分布（酸性峰/主峰/碱性峰）     | 研究代次内无显著漂移（与 MCB 参比比较）         |
| 聚体含量（HMW%）                       | 研究代次内无显著升高                            |
| 生物学活性（相对效价）                 | 研究代次内在规格范围内，无显著下降              |
| 一级结构（序列完整性）                 | 无氨基酸序列变化（与设计序列一致）              |

**标准三：产量稳定性（生产效能层面）**

| 评估内容                                     | 行业通行接受标准                                                |
| -------------------------------------------- | --------------------------------------------------------------- |
| 各代次蛋白表达量（Titer）                    | 研究代次内的表达量变化幅度在可接受范围内                        |
| 高 PDL 与对照（低 PDL / MCB 建立初期）的比较 | **业界公认标准：高 PDL 的表达量与对照相比，下降幅度不超过 30%** |
| Qp（细胞比生产速率）                         | 与起始代次相比无显著下降（变化幅度在 ±20% 以内为常见要求）      |

**综合判定逻辑**

只有当上述三个维度的标准**同时满足**时，才能判定细胞株在研究代次/PDL 范围内具有稳定性，并支持以此范围确定细胞株的生产限传代次（MLPC，Maximum Limit of In Vitro Cell Age）。

:::

## 细胞株稳定性研究的时间节点选择：代次（Passage Number）与 PDL（群体倍增水平）的科学依据

:::answer

**代次与 PDL 的定义与区别**

| 概念                                           | 定义                                       | 计算方式                                           |
| ---------------------------------------------- | ------------------------------------------ | -------------------------------------------------- |
| 代次（Passage Number）                         | 细胞从一个容器转移到新容器并扩增的操作次数 | 每次传代 +1（计数操作次数）                        |
| PDL（Population Doubling Level，群体倍增水平） | 细胞群体实际发生的倍增次数                 | PDL = log₂（接种后细胞数 / 接种时细胞数）÷ log₂(2) |

**代次与 PDL 的关联性与本质差异**

| 维度             | 代次                                           | PDL                                          |
| ---------------- | ---------------------------------------------- | -------------------------------------------- |
| 反映细胞复制次数 | 间接（操作次数，不反映每次扩增倍数）           | **直接**（实际细胞倍增次数）                 |
| 受接种密度影响   | 是（低密度接种→高扩增倍数→同一代次含更多倍增） | 否（按实际倍增计算，与接种密度无关）         |
| 批间可比性       | 差（不同实验室/不同操作规程的代次不可比）      | 好（任何实验室的 PDL 在相同条件下可比）      |
| 监管认可度       | 基本（传统方法，各药典均认可）                 | **更高**（更具科学依据，ICH Q5D 等推荐使用） |

**关键参考数据（行业经验值）**

- **1 PDL/Day 的粗略估算：** 一般生物反应器中常用 CHO 细胞传代约每 3 天传代一次，增加约 **3 个 PDL**；
- 但这只是近似估算，实际 PDL 取决于接种密度、传代时的收获密度和细胞比增长速率（μ）；
- 代次与 PDL **不可直接等价**（1 代次 ≠ 特定 PDL 数）。

**PDL 计算公式**

$$PDL = \frac{\log_2(N_t) - \log_2(N_0)}{1}$$

其中 N_t 为传代结束时收获的活细胞总数，N_0 为接种时的活细胞总数。

**推荐以 PDL 为时间节点的原因**

1. **科学依据更充分：** PDL 直接量化了细胞 DNA 复制的次数，与遗传稳定性（基因突变积累）的相关性比代次操作次数更强；
2. **监管机构的期望：** ICH Q5D 等指南明确建议以 PDL 或 MLPA（最大允许体外细胞年龄）为限制指标，而非单纯的代次；
3. **批间可比性：** 不同规模（摇瓶→小罐→大罐）的 PDL 可以累加，而代次会因每次操作的扩增倍数不同而难以横向比较；
4. **支持限传代次的设定：** 以 PDL 表示的"生产限传代次（MLPC）"，可以更准确地对应验证研究中测试的实际细胞生物学年龄。

:::
