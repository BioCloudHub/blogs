## 工艺表征研究的核心目的与在 CMC 体系中的定位

:::answer

工艺表征研究（Process Characterization, PC）是生物药上市前 CMC 开发中连接工艺开发与工艺验证（PPQ）的关键科学桥梁，其质量直接决定申报资料的科学支撑力和工艺验证的合规性。

**精确定义**

工艺表征是一套文档证明的研究活动，通过**有目的性地系统改变工艺参数**，确定参数对产品质量属性（CQA）和工艺性能（KPA/KPI）的影响，以及参数间的交互作用。研究基于来源于风险评估的信息，采用一整套工艺表征研究方法检验工艺参数的预设范围。

**核心目的的三个层次**

| 层次 | 目的 | 输出交付物 |
|---|---|---|
| **识别** | 区分 CPP（显著影响 CQA）和 KPP（显著影响 KPI/KPA）与非关键参数 | 经实验证明的 CPP/KPP 清单 |
| **定量** | 建立工艺参数与 CQA/KPI 的量效关系曲线 | 参数-响应数学模型（回归方程） |
| **边界** | 确定 CPP 和 KPP 的可接受操作范围（PAR）和设计空间 | PAR 列表 + 多维设计空间模型 |

**在 CMC 体系中的位置**

```
工艺开发 → 工艺表征（PC）→ 工艺性能确认（PPQ）→ 持续工艺确认（CPV）
                ↑                     ↑
         阶段 1 核心活动        PC 输出成为 PPQ 方案的科学依据
```

**在申报文件中的体现位置**

工艺表征相关内容须在 BLA 申报资料的 **3.2.S.2.5**（原料药工艺验证/评价）章节中呈现，是 CDE/FDA/EMA 审评的重点核查内容之一。

:::

## 上游工艺表征研究的七步核心流程

:::answer

上游细胞培养工艺表征研究须按照系统性的七步流程有序推进，每一步均有明确的前置要求和输出交付物。

**七步流程总览**

```
第一步：确定 CQA 和 KPI（研究的评判标准）
    ↓
第二步：定义生产工艺（研究的对象范围）
    ↓
第三步：确定 pCPP 和 pKPP（通过 FMEA 风险评估）
    ↓
第四步：建立缩小模型（实验的执行平台）
    ↓
第五步：工艺表征实验（DOE/单因素/Worst-Case）
    ↓
第六步：数据整理与统计分析
    ↓
第七步：确定 CPP 和 KPP，定义 PAR/设计空间
```

**各步骤的输入-输出关系**

| 步骤 | 主要输入 | 主要输出 |
|---|---|---|
| 第一步 | 文献、历史数据、QTPP | CQA 清单 + 可接受限度；KPI 清单 + 参考范围 |
| 第二步 | 工艺规程、工艺流程图 | 完整的工艺参数清单（每步骤） |
| 第三步 | 工艺参数清单 + CQA/KPI 清单 | FMEA 矩阵；pCPP 和 pKPP 优先级排序 |
| 第四步 | 商业化规模工艺参数 | 缩小模型等效性确认报告 |
| 第五步 | 缩小模型 + 实验设计（DOE Protocol） | 原始实验数据 |
| 第六步 | 实验数据 | 统计分析结果（ANOVA、回归模型、交互效应图） |
| 第七步 | 统计分析结果 + CQA/KPI 限度 | 确认的 CPP/KPP 清单；PAR；设计空间 |

:::

## 工艺表征第三步：pCPP 和 pKPP 的识别方法

:::answer

识别潜在关键工艺参数（pCPP）和潜在关键过程参数（pKPP）是工艺表征研究中最关键的决策步骤，须基于系统性的风险评估工具，而非主观经验判断。

**上游工艺的步骤分解**

对于典型的单抗上游工艺，通常包含以下五个主要操作单元，须对每个步骤的工艺参数分别进行风险评估：

| 步骤 | 主要工艺参数类型 |
|---|---|
| **细胞复苏** | 复苏温度、复苏时间、解冻后细胞活率检查标准 |
| **摇瓶种子扩增** | 传代密度、传代频率、CO₂ 浓度、培养温度 |
| **反应器种子扩增（N-1）** | 接种密度、pH、DO、搅拌速率、传代标准（VCD/活率） |
| **反应器生产（N）** | 培养温度、pH、DO、搅拌速率、补料时机和量、降温时机、收获标准 |
| **收获（离心/深层过滤）** | 离心转速、处理时间、过滤条件 |

**风险评估工具的应用**

推荐采用 **FMEA（失效模式及后果分析）** 工具，对每个步骤的每个工艺参数，分别针对每个 CQA 和 KPI 进行以下三维度评分：

$$RPN = S \times O \times D$$

- **S（严重性）：** 参数偏离时对 CQA/KPI 影响的最大程度（1~5分）
- **O（发生率）：** 参数在正常生产中偏离设定值的概率（1~5分）  
- **D（可检测性）：** 现有过程控制发现偏差的能力（1~5分）

**评分结果的分类决策**

| RPN 范围 | 参数分类 | 后续实验策略 |
|---|---|---|
| 高 RPN（超过预设阈值） | pCPP 或 pKPP（须通过实验确认） | 列入 DOE 或单因素研究 |
| 中 RPN | 潜在 KPP（监控但影响可能较低） | Worst-Case 研究或历史数据确认 |
| 低 RPN | 潜在 Non-KPP | 文献 + 历史数据支持即可 |

:::

## 工艺表征第四步：缩小模型建立的目的与关键原则

:::answer

缩小模型（Scale-down Model, SDM）是工艺表征研究的核心实验平台，其建立质量直接决定工艺表征结论对商业化生产的预测可靠性。

**建立缩小模型的根本原因**

在商业化规模（如 2000 L 生物反应器）下直接开展大量 DOE 实验既不经济也不可行：
- 每批商业化规模生产成本极高（物料、人工、设施）
- 参数的精确调节在大型反应器中受设备控制精度限制
- DOE 实验通常需要数十到数百个实验条件，无法在商业化规模逐一完成

**监管对缩小模型的核心要求**

从监管角度（FDA/EMA/NMPA），用于工艺表征和工艺验证的缩小模型须经过**正式的等效性确认（Scale-down Model Qualification）**，证明其能够代表商业化生产规模工艺的性能。

**两类工艺参数的不同缩小策略**

上游细胞培养缩小模型（通常使用 1~10 L 生物反应器）须分两类处理工艺参数：

**① 规模不依赖参数（直接等同）**

| 参数 | 缩小要求 |
|---|---|
| 培养温度（工作温度、降温温度） | 与商业化规模完全一致 |
| pH 控制目标和范围 | 与商业化规模完全一致 |
| 溶氧（DO）控制目标 | 目标值一致（控制方式可调整） |
| 接种密度（VCD，cells/mL） | 与商业化规模完全一致 |
| 补料体积比（Feed%，占培养体积） | 与商业化规模完全一致 |
| 收获标准（活率阈值/培养时间） | 与商业化规模完全一致 |

**② 规模依赖参数（须按工程原则换算）**

| 参数 | 换算原则 |
|---|---|
| 搅拌转速 | 恒定体积功率（P/V）或恒定氧传质系数（kLa） |
| 通气量 | 维持等效的 kLa 值（结合搅拌共同调整） |
| 初始培养体积 | 通常等比缩小（保持初始体积/最终体积比） |

**缩小模型的重要局限性**

无论缩小设计如何精心，缩小模型通常**无法 100% 代表商业化生产规模**——这一局限性须在研究报告和申报文件中明确承认，并通过统计学等效性检验（TOST/PCA）量化两者的差异程度，以支持监管接受缩小模型数据。

:::

## 工艺表征第五步：工艺表征实验的设计选择

:::answer

工艺表征实验设计的选择须基于 FMEA 风险评估结论和研究资源约束，不同的参数特性和研究目的对应不同的实验设计方法。

**两大主要研究方法**

**传统工艺表征：单因素研究（OFAT，One Factor at a Time）**

- **适用场景：** 参数数量较少；参数间交互作用经先验知识判断不显著；资源有限时的快速筛选
- **操作方式：** 每次仅改变一个参数（在预定范围内取多个水平），其他参数固定在中心值，观察该参数对 CQA/KPI 的影响
- **优势：** 设计简单，结果易于解释，无需复杂统计软件
- **局限：** 无法检测参数间的交互作用；若两个参数存在交互作用，单因素研究可能给出误导性结论

**增强工艺表征：DOE 设计（Design of Experiments）**

- **适用场景：** 多个 pCPP 需要同时研究；参数间可能存在交互作用；需要建立设计空间数学模型
- **操作方式：** 系统改变多个参数的组合水平（按照统计实验设计安排），同时收集所有参数对响应变量的影响数据
- **优势：** 可识别参数主效应和交互作用；效率高（用较少实验次数覆盖多参数空间）；可建立预测模型
- **局限：** 设计和分析需要统计软件和专业知识；样本量需求较大

**实验方法的选择原则**

监管机构（特别是 FDA）对工艺表征的期望是基于科学原则而非固定方法——须根据具体情况综合评估：
- 若 FMEA 识别出多个高 RPN 参数且存在潜在交互效应 → 优先采用 DOE
- 若参数数量少（≤ 2~3 个）且无交互效应先验依据 → 单因素研究可接受
- 两种方法可组合使用：先用 DOE 筛选（识别显著参数），再对显著参数用 DOE 进一步细化（建立响应面模型）

:::

## 工艺表征第七步：CPP/KPP 确定与设计空间定义

:::answer

完成工艺表征实验和数据分析后，最终须将研究结论转化为 CPP/KPP 的正式确认和设计空间的定量定义，为后续工艺验证（PPQ）方案提供科学依据。

**从统计结果到 CPP/KPP 确认**

基于方差分析（ANOVA）或回归分析的统计结论：

| 统计显著性 | 影响对象 | 参数分类结论 |
|---|---|---|
| p < 0.05，对 **CQA** 有显著影响 | CQA（关键质量属性） | 确认为 **CPP**（关键工艺参数） |
| p < 0.05，对 **KPI/KPA** 有显著影响（但 CQA 不显著） | KPI/KPA（关键工艺/过程属性） | 确认为 **KPP**（关键过程参数） |
| p ≥ 0.05，对 CQA 和 KPI 均无显著影响 | — | 确认为 **Non-KPP**（非关键参数） |

**PAR（Proven Acceptable Range）的建立**

PAR 是"经实验证明的可接受范围"——在此范围内运行，CQA 均满足可接受标准：

- 对每个 CPP，基于实验数据确定：在满足所有 CQA 可接受标准的前提下，参数可接受的最大变化范围
- PAR 通常通过以下方式确定：
  - **图形方法：** 绘制参数水平 vs. CQA 的散点图和拟合曲线，找出 CQA 超出可接受范围的参数边界
  - **预测区间方法：** 基于回归模型，计算在特定参数值下 CQA 预测值的置信区间，确保置信区间在可接受范围内

**设计空间的建立**

设计空间是多个 CPP 的 PAR 的多维组合，在此空间内参数调整不会导致任何 CQA 超出可接受范围：

```
设计空间 = {所有 CPP 的 PAR 的多维交集}
（需通过响应面模型或多变量优化确定交集边界）
```

CPP₁ 的 PAR 内 + CPP₂ 的 PAR 内 + CPP₃ 的 PAR 内 = 设计空间（注意：各参数同时在 PAR 内，不一定等于设计空间，须通过交互效应分析验证）

**对设计空间内调整的监管含义**

在已批准的设计空间内调整工艺参数目标值，**不被认为是需要申报的变更**，赋予商业化生产一定的灵活性空间。

:::

## FMEA 风险评估工具：原理与在工艺表征中的应用

:::answer

失效模式及后果分析（FMEA, Failure Mode and Effects Analysis）是工艺表征研究中最广泛使用的系统性风险评估工具，其结构化方法确保了 pCPP/pKPP 识别的客观性和可追溯性。

**FMEA 的基本原理**

FMEA 是一种预防性的、系统化的、文件化的分析方法，其核心逻辑是：
- 系统识别每个工艺参数可能发生的偏差（失效模式）
- 评估该偏差对产品质量或工艺性能的影响（后果）
- 评估该偏差被及时发现的可能性
- 综合以上三个维度计算风险优先数（RPN）

**三维度评分体系**

| 维度 | 缩写 | 评分含义 | 典型评分标准（1~5分） |
|---|---|---|---|
| **严重性** | S（Severity） | 若该参数偏离，对 CQA/KPI 造成影响的最严重程度 | 1 = 几乎无影响；3 = 中等影响；5 = 严重影响（CQA 必然超标） |
| **发生率** | O（Occurrence） | 该参数在正常生产中偏离设定值的概率 | 1 = 极不可能（< 1%批次）；3 = 偶尔（约 5%）；5 = 频繁（> 20%） |
| **可检测性** | D（Detectability） | 若发生偏差，现有过程控制能及时检测到的能力 | 1 = 几乎肯定能检测；3 = 有时检测；5 = 几乎无法检测 |

**风险优先数（RPN）的计算与应用**

$$RPN = S \times O \times D \quad (\text{范围：} 1 \sim 125)$$

RPN 值越高，参数风险越大，须优先开展工艺表征实验。评分阈值须在研究开始前预先在 FMEA 方案中定义（不同企业阈值不同，须基于科学依据）。

**FMEA 的实施要求**

- **多学科团队参与：** 评分须由工艺开发、质量、分析等多专业背景的专家共同完成，避免单一视角的系统偏差
- **评分规则统一：** 在开始评分前明确各分级的判断标准，确保不同评分者对同一参数的理解一致
- **文件化记录：** 每个参数的评分依据须有明确的书面说明（不能仅有评分数字，无理由说明）
- **定期更新：** 随新知识（工艺数据、临床数据）的积累，须重新评估和更新 FMEA 结论

**FMEA 在上游工艺中的常见工具变体**

除标准 FMEA 外，以下工具在工艺表征中也常用：
- **FMECA（失效模式、后果及危害性分析）：** 在 FMEA 基础上增加危害性分析，更适合高风险步骤
- **因果矩阵（Cause and Effect Matrix）：** 直接列出工艺参数（输入）与 CQA/KPI（输出）的相关性矩阵，是 FMEA 的简化前置筛选工具

:::

## 上游工艺常见 pCPP 的类型与范围确定原则

:::answer

上游细胞培养工艺中，某些类型的工艺参数由于其对细胞生长和产品质量的普遍显著影响，通常在初始 FMEA 中被评为高 RPN，成为优先研究的 pCPP。

**上游工艺常见 pCPP 清单**

| pCPP 类型 | 影响的 CQA/KPI | 影响机制 |
|---|---|---|
| **培养温度** | 糖型（Man5、岩藻糖化程度）、电荷变体、产量 | 温度直接影响糖基转移酶活性、蛋白折叠速率和翻译后修饰 |
| **培养 pH** | 乳酸水平、酸性峰含量、产量 | pH 影响细胞糖酵解代谢、氨基酸转运和蛋白质糖化反应 |
| **溶氧（DO）** | 氧化修饰（Met/Trp 氧化）、产量 | DO 过高增加活性氧（ROS）水平，引发蛋白氧化；DO 过低影响细胞有氧呼吸 |
| **培养周期（收获时间）** | 产量、收获活率、杂质 Profile | 培养时间越长，产量越高，但细胞裂解释放的 HCP 也增加 |
| **补料时机和补料量** | 产量、糖型、渗透压 | 补料量影响细胞营养状态和代谢产物积累（乳酸、氨）；补料时机影响蛋白质翻译后修饰的时间窗口 |
| **接种密度** | 峰值 VCD、收获活率、产量 | 过高接种密度可能导致后期营养耗尽和活率提前下降 |

**pCPP 范围设定的三个参考维度**

在 FMEA 阶段须同时为每个 pCPP 设定初步的研究范围（高值和低值），范围设定须平衡科学合理性和实验可行性：

**维度一：当前工艺规程**

- 以当前 SOP 中的参数设定点（Setpoint）为基准
- 研究范围通常覆盖规程操作范围之外，以评估边界条件的安全性
- 典型做法：Setpoint ± X%（X% 基于设备控制精度和历史批次偏差范围确定）

**维度二：设备的控制能力**

- 研究范围不能超出设备的物理操作极限（如生物反应器最高搅拌速率、pH 控制器的有效范围）
- 须评估设备在极限水平下的控制精度（是否能稳定维持在设定值）

**维度三：参数本身的性质**

- 连续参数（如温度、pH）的范围通常可精确设定，研究层次可以更细
- 离散参数（如培养基批次、传代周期天数）的范围设定须结合实际操作限制

:::

## 缩小模型建立的重要性与在生物药生命周期中的角色

:::answer

缩小模型不是一次性使用的工具，而是贯穿生物药研发全生命周期、在多个关键节点反复发挥价值的核心实验平台。

**缩小模型的定义**

缩小模型（Scale-down Model, SDM）是工艺单元操作的实验室规模级别的操作模型，包括：
- 缩小的生物反应器（1~15 L 替代商业化 200~2000 L）
- 缩小的层析柱（1~10 mL 柱体积替代商业化 10~100 L）
- 缩小的超滤/渗滤装置（小型膜组件替代商业化系统）

**全生命周期应用场景**

| 阶段 | 缩小模型的应用 | 对商业化的支撑价值 |
|---|---|---|
| **工艺开发** | 培养基筛选、参数初步优化（通常 shake flask 或 2~5 L） | 确定工艺开发方向 |
| **临床后期工艺开发** | 参数 Fine-tuning，候选 CPP 初步识别 | 确定进入工艺表征的目标工艺 |
| **工艺表征（核心应用）** | 系统性 DOE 实验（需经等效性确认的缩小模型） | 建立 CPP/设计空间，支撑 PPQ 方案制定 |
| **工艺验证支持** | Worst-Case 验证（在参数边界下验证 CQA 合格性） | 为 PPQ 方案中的极端条件接受标准提供依据 |
| **商业化生产支持** | 根因调查（异常批次的偏差重现）、工艺改进验证 | 无需在商业化规模进行全批次实验 |

**监管对缩小模型使用的核心要求**

工艺表征和工艺验证所用缩小模型须经过**正式确认（Qualification）**，须提供：
- 缩小模型与商业化规模在关键参数和输出指标上的等效性数据（定量证明）
- 等效性确认报告（Qualification Report），经质量部门审批
- 识别并记录缩小模型与商业化规模之间已知的系统性差异（以及如何通过数据修正处理这些差异）

:::

## 缩小模型建立的前期准备工作

:::answer

缩小模型建立前须完成充分的前期调研和技术准备，这些准备工作的质量直接影响缩小模型能否顺利通过等效性确认。

**四项核心准备工作**

**准备一：收集生产规模和缩小规模反应器的工程参数信息**

须系统收集并对比两种规模设备的关键工程特性：

| 工程参数 | 商业化规模 | 缩小规模 | 差异评估 |
|---|---|---|---|
| 工作体积（L） | 如 2000 L | 如 10 L | 缩小比 200:1 |
| 搅拌桨型式 | 如 Rushton 涡轮桨 | 如小型 Rushton | 几何相似性评估 |
| 高径比（H/D） | 商业化规格 | 缩小规格 | 影响气体分布 |
| 通气方式 | 底部微孔通气头 | 底部通气 or 表面通气 | 影响 kLa |
| 传感器类型（pH、DO） | 在线传感器 | 在线传感器 | 验证控制精度一致 |

**准备二：完成 CQA 和 KPA 的识别**

缩小模型等效性确认须以 CQA 和 KPA 的比较为核心——若 CQA 尚未明确定义，则缩小模型建立缺乏评判标准。须在建立缩小模型前完成前期两步（CQA/KPI 确定和工艺参数定义）。

**准备三：研究规模依赖型参数的换算关系**

针对搅拌转速、通气量等规模依赖参数，须通过工程计算或预实验确定换算原则：
- 优先确定 kLa 目标值（对细胞供氧最关键），据此反推小型反应器的搅拌速率和通气量
- 通过实验验证换算参数在小型反应器中的实际 kLa 值（不能仅凭理论计算）

**准备四：确定缩小模型等效性验证的策略**

在开始运行缩小模型之前，须预先确定：
- 等效性评判的指标清单（哪些 CQA 和 KPA 须用于等效性判断）
- 等效性统计判定方法（TOST / PCA / 直观法）
- 等效区间（equivalence interval）的预设定义（通常为生产规模数据的 ±3SD 或预定百分比）

:::

## 缩小模型的检测指标体系

:::answer

缩小模型等效性确认须评估两类指标的一致性，分别对应"工艺运行是否等效"和"产品质量是否等效"两个独立维度。

**第一类：主要工艺属性（评价工艺性能等效性）**

| 指标 | 说明 | 等效性要求 |
|---|---|---|
| **产量（Titer, g/L）** | 最核心的工艺效率指标 | 缩小模型与生产规模的产量均值差异须在等价区间内 |
| **收获时细胞活率（%）** | 反映细胞在整个培养周期的健康状态 | 两规模收获活率须统计等效 |
| **峰值活细胞密度（VCD）** | 反映细胞增殖潜力 | VCD 随时间变化曲线须整体一致 |
| **乳酸水平（g/L）** | 代谢状态指标；高乳酸提示糖酵解失控 | 乳酸积累模式须可比 |
| **葡萄糖消耗速率** | 与乳酸互补，表征细胞糖代谢 | 消耗曲线须整体可比 |

**第二类：关键质量属性（评价产品质量等效性）**

这类指标的等效性是最关键的等效性证明——工艺性能指标等效但产品质量不等效，缩小模型仍不具有代表性：

| CQA 类别 | 检测项目 | 检测方法 |
|---|---|---|
| **聚集体** | 单体峰面积、HMW% | SEC-HPLC |
| **片段** | LMW 片段% | CE-SDS（非还原/还原） |
| **电荷变体** | 酸性峰%、主峰%、碱性峰% | iCIEF 或 CEX-HPLC |
| **糖型** | 主要 N-糖型的相对分布（Man5、G0F、G1F 等） | 2-AB UPLC N-糖谱 |
| **效价** | 结合活性或细胞活性 | ELISA 或细胞功能实验 |

**上游缩小模型 CQA 与原液 CQA 的关系**

上游细胞培养缩小模型的 CQA 与最终原液的 CQA 在指标选择上有一定差异：
- 上游缩小模型阶段通常检测**收获液（HCCF）中的产物质量属性**，作为 CQA 的早期预测指标
- 某些复杂 CQA（如特定糖型分布）在 HCCF 阶段与原液阶段的结果可能存在下游纯化带来的差异
- 须基于历史数据或同步研究，评估 HCCF 和原液 CQA 之间的相关性

:::

## 缩小模型等效性确认的判定标准

:::answer

缩小模型等效性确认须有明确的预先定义的成功标准，而非事后判断，这是监管合规的基本要求。

**等效性确认的通过标准**

缩小模型等效性确认通过的核心标准是：**所有预定的 KPA 和 CQA 的评价结果均满足预先设定的等效性限度要求**。

具体而言：
- 对于每个评价指标，缩小模型与生产规模之间的差异须在**预设的等效区间内**（即差异在统计上不显著，或两组数据统计等效）
- 若某个指标的差异超出等效区间，须进行**根因分析**：判断该差异是否可通过模型修正消除，或是否存在不可避免的系统性差异需要在应用中考量

**预设等效区间的常见设定方法**

| 方法 | 等效区间定义 | 适用场景 |
|---|---|---|
| **历史批次 ±3SD** | 生产规模历史批次数据的均值 ± 3 倍标准差 | 最常用；需要足够的历史数据（通常 ≥ 6 批次） |
| **固定百分比** | 如生产规模均值的 ± 10%~20% | 适用于历史数据有限的场景；须基于科学判断选择百分比 |
| **CQA 规格限度** | 在产品质量标准范围内即视为等效 | 最保守的等效性标准；通常用于 CQA 指标 |

:::

## 缩小模型等效性验证：TOST 统计方法详解

:::answer

双单侧 t 检验（TOST, Two One-Sided Tests）是缩小模型等效性统计验证的推荐方法，其统计逻辑比标准 t 检验更适合"证明等效"而非"证明差异"的研究目的。

**为什么 TOST 优于标准 t 检验**

| 对比维度 | 标准 t 检验（双侧检验） | TOST（双单侧检验） |
|---|---|---|
| **零假设** | "两组均值相等"（H₀: μ₁ = μ₂） | "两组差值超出等价区间"（H₀: \|μ₁-μ₂\| ≥ Δ） |
| **备择假设** | "两组均值不相等" | "两组差值在等价区间内"（等效） |
| **拒绝零假设意义** | 证明"有显著差异" | 证明"统计等效" |
| **局限性** | 不能证明等效；"无显著差异"可能只是样本量不足导致统计功效不足 | 正确地以"证明等效"为目标 |

**TOST 的统计执行步骤**

1. **设定等价区间（Equivalence Interval）：** $[-\Delta, +\Delta]$，通常选择生产规模数据的 **3 倍标准差（±3SD）**
2. **计算两组数据差值：** $\bar{X}_{\text{缩小}} - \bar{X}_{\text{生产}}$
3. **计算差值的 90% 置信区间：** $[\bar{X}_{\text{diff}} - t_{0.05} \cdot SE, \bar{X}_{\text{diff}} + t_{0.05} \cdot SE]$
4. **判定等效性：** 若 90% 置信区间完全落在等价区间 $[-\Delta, +\Delta]$ 内，则判定两组数据**统计等效**

**TOST 的适用场景**

TOST 特别适合对**单个变量**（如产量、某个糖型的比例）进行等效性评估。当需要同时评估多个变量时，须分别对每个变量进行 TOST 检验，并结合 PCA 对整体等效性进行综合判断。

:::

---

## 缩小模型等效性验证：PCA 多变量分析方法

:::answer

主成分分析（PCA, Principal Components Analysis）是处理多变量缩小模型等效性评估的有效工具，能够在保留主要信息的前提下降低数据维度，并识别多元离群值。

**PCA 的基本原理**

PCA 通过数学变换将原始多个相关变量（如 VCD、乳酸、产量、糖型分布等）转化为少数几个**不相关的综合指标（主成分）**，每个主成分是原始变量的线性组合：

- **PC₁（第一主成分）：** 解释最大方差的方向
- **PC₂（第二主成分）：** 在垂直于 PC₁ 的方向上解释最多剩余方差
- 通常前 2~3 个主成分可以解释 70%~90% 的总方差

**在缩小模型等效性评估中的应用**

1. 将缩小模型批次和生产规模批次的所有评价指标数据合并输入 PCA
2. 在 PC₁-PC₂ 二维散点图中，绘制各批次的主成分得分点
3. **等效性判断：** 若缩小模型批次的数据点与生产规模批次的数据点在 PCA 空间中高度重叠（落在相同的椭圆置信区域内），则判定整体多变量等效

**PCA 的独特优势**

- **多元离群值识别：** 若某个缩小模型批次在 PCA 空间中偏离生产规模数据群，说明该批次在多个变量的组合效果上存在系统性差异，须进行根因分析
- **整体评估效率：** 一次 PCA 可同时评估所有变量的整体一致性，而无需分别对每个变量进行 TOST（TOST 和 PCA 互补使用：TOST 提供单变量的量化等效性证明，PCA 提供整体一致性的直观可视化）

:::

## 缩小模型不等效时的修正策略

:::answer

当建立的缩小模型在某些指标上与生产规模不完全等效时，须进行系统性的根因分析和修正，而非直接放弃或忽视差异。

**缩小模型不等效的常见原因**

| 不等效指标 | 常见原因 | 修正方向 |
|---|---|---|
| **产量（Titer）偏低** | 缩小模型 kLa 偏低（供氧不足）；补料精度差 | 优化通气策略；改进补料方式 |
| **乳酸积累异常高** | pH 控制响应速度不如商业化设备；CO₂ 去除效率不同 | 调整 pH 控制策略；评估通气对 CO₂ 的吹扫效果 |
| **糖型差异** | 培养温度均匀性差（小型反应器边壁传热效应更显著） | 优化温度控制策略；延长降温平衡时间 |
| **细胞活率曲线差异** | 接种密度计算误差；缩小模型剪切力偏高 | 校准活细胞计数方法；优化搅拌速率 |

**修正的两种主要策略**

**策略一：工艺参数修正（调整缩小模型参数）**

在缩小模型中**有意识地调整某些参数**，使其在等效的工艺条件下运行，而非完全等同于商业化规模的参数设定点：
- 示例：若缩小模型的 CO₂ 去除效率低于商业化规模（因为通气方式差异），可适当提高缩小模型的通气量，以获得与商业化规模等效的 pCO₂ 水平

**策略二：数据换算修正（建立校正模型）**

若工艺参数修正无法完全消除系统性差异，可建立**数学校正模型**：
- 通过回归分析建立缩小模型数据与生产规模数据之间的系统性偏差的量化关系
- 在使用缩小模型数据预测商业化生产结果时，应用校正因子

无论采用哪种修正策略，修正的方法和依据须在缩小模型等效性确认报告中完整文件化。

:::

## 上游工艺缩小模型建立的主要技术难点

:::answer

细胞培养缩小模型的建立在技术层面存在若干难以完全克服的挑战，须通过工程优化和统计方法学共同应对。

**四大核心技术难点**

**难点一：培养体积的缩小**

- 培养体积从商业化规模（如 2000 L）缩小到实验室规模（如 10 L）时，**高径比（H/D）**可能发生变化
- H/D 影响液体循环、气泡在液面停留时间和剪切力分布
- 现有实验室生物反应器的几何设计不总是与商业化反应器成几何相似，须在选型时仔细评估

**难点二：搅拌转速的设定**

- 商业化规模的搅拌桨直径较大，在较低转速下即可产生足够的流体动力学（高雷诺数）
- 缩小模型须通过**提高转速**维持等效的 P/V 或 kLa，但提高转速带来的**剪切力**也成比例增加
- P/V 等效性和剪切力安全性之间可能存在无法完全兼顾的矛盾，须权衡取舍

**难点三：通气控制与 CO₂ 去除**

- 细胞呼吸产生的 CO₂ 须通过通气去除，以防止 pCO₂ 过高（高 pCO₂ 影响 pH 和细胞代谢）
- 在缩小模型中，气体停留时间短（体积小）、CO₂ 去除效率可能高于或低于商业化规模
- 须通过调整通气流量，将缩小模型的平均 pCO₂ 控制在与商业化规模等效的范围

**难点四：CO₂ 移除与 pH 控制的耦合**

- pCO₂ 直接影响溶液 pH（CO₂ + H₂O → H₂CO₃），商业化规模中 pH 控制须同时考虑碱液添加和 CO₂ 吹扫的协同效果
- 在缩小模型中，这两个调控手段的响应速度和相对权重可能与商业化规模不同
- 须通过工艺研究确定缩小模型特异性的 pH 控制参数

:::

## 缩小模型建立所需的代表性批次数量

:::answer

缩小模型等效性确认所需的商业化生产规模批次数量，须满足统计学最低要求，以确保等效性结论具有足够的统计置信度。

**统计学最低要求：至少 3 批次**

**3 批次是开展统计等效性分析的最低门槛：**
- 对于等效性评估，至少需要在两组（缩小模型组和生产规模组）各有 3 个以上数据点，才能计算均值、标准差和置信区间
- 少于 3 批次时，统计检验的功效不足，无法可靠识别两组间的差异或等效性

**推荐批次数量：6 批次以上**

**6 批次或更多时等效性结论更可靠，原因如下：**
- 更大的样本量 → 更小的标准误（Standard Error）→ 更窄的置信区间 → 等效性结论的不确定性更低
- 6 批次以上的数据可以更可靠地反映批次间的正常变异范围，避免少量批次的"幸运"或"不幸"
- 监管审评人员对 6 批次以上数据的信心通常高于 3 批次

**实际操作的批次数量规划建议**

| 商业化规模可用批次数 | 建议策略 |
|---|---|
| < 3 批次 | 补充历史批次（若存在可比工艺的历史批次）；或说明批次有限的原因，同时增加缩小模型批次数量 |
| 3~5 批次 | 可接受，但须在等效性确认报告中说明数据量的局限性 |
| ≥ 6 批次 | 推荐；等效性结论的统计置信度充分 |

:::

## DOE 筛选实验：多因子初步效应识别的设计策略

:::answer

筛选实验（Screening Design）是 DOE 在工艺表征早期阶段的应用形式，适合因子数量较多时快速识别显著效应，为后续更深入的研究聚焦提供依据。

**筛选实验的适用场景**

- 初步 FMEA 识别出**较多的 pCPP/pKPP**（通常 ≥ 5 个因子），需要通过实验进一步筛选出真正显著的因子
- 在工艺表征的**早期阶段**，对因子-响应关系的了解有限，须先识别主效应
- 研究资源有限，须以最少的实验次数覆盖最多的因子

**主要筛选实验类型**

**① Plackett-Burman 设计（PB 设计）**

- 适用于因子数 **4~47 个**的大规模筛选
- 设计特点：每个因子只取高低两个水平；实验次数为 4 的倍数（如 12、16、20 次等）
- 局限性：**无法估计因子交互作用**（所有交互效应与主效应混叠）；仅能识别主效应的显著性

**② 部分因子设计（Fractional Factorial Design）**

- 适用于因子数 **4~8 个**，须同时评估部分交互效应
- 通过选择性运行全因子设计的一部分（Fraction），在减少实验次数的同时保留主效应和部分二阶交互效应的估计能力
- 常用设计：2^(k-p) 设计（如 2^(6-2)=16 次实验研究 6 个因子）

**筛选实验的输出与后续步骤**

筛选实验后，基于 ANOVA 结果识别显著因子：
- **显著因子（p < 0.05）：** 须在后续进一步研究（单因素研究或响应面设计）中详细表征其效应大小和操作范围
- **不显著因子（p ≥ 0.05）：** 结合 FMEA 评分和先验知识，判断是否可归类为 Non-KPP（若其他证据也支持其影响可忽略）

:::

## DOE 响应面实验：参数优化与设计空间建立的核心工具

:::answer

响应面设计（Response Surface Design, RSM）是工艺表征研究中用于深入理解显著参数影响、建立参数-CQA 数学模型和定义设计空间的核心实验设计方法。

**响应面设计的定义与目的**

响应面设计是利用合理的实验设计，通过实验获得定量数据，采用**多元二次回归方程**拟合因素与响应值之间的函数关系，通过对回归方程的分析来：
- 寻找最优工艺参数（优化目标）
- 定量表征参数对 CQA 的非线性影响
- 建立设计空间的预测模型

**响应面设计的适用条件**

使用响应面设计须同时满足以下条件：

| 条件 | 说明 |
|---|---|
| **存在非线性影响（或怀疑存在）** | 已知或有证据表明某些因子对 CQA 的影响为曲线型而非线性（DOE 中心点弯曲检验显著） |
| **因子数在适当范围** | 通常 **2~4 个**因子最适合响应面设计（超过 4 个因子时实验次数急剧增加） |
| **因子均为连续型计量数据** | 响应面设计不适用于离散型因子（如培养基类别） |
| **已聚焦到最优区域附近** | 通常须先通过筛选实验确认主要因子，再在最优区域附近使用响应面设计细化 |

**常用响应面设计类型**

| 设计类型 | 实验次数（3因子） | 特点 |
|---|---|---|
| **中心复合设计（CCD）** | 20 次 | 最常用；包含轴向点，可估计二次效应；预测精度均衡 |
| **Box-Behnken 设计（BBD）** | 15 次 | 不含角点，适合参数不能同时取极值的场景；比 CCD 实验次数更少 |

**响应面建模的输出**

响应面实验产生的数据经多元回归分析后，可生成：
- **响应面图（3D Surface Plot）：** 可视化两个参数对 CQA 的联合影响
- **等高线图（Contour Plot）：** 在二维参数空间中显示 CQA 等值线，用于直观识别设计空间边界
- **回归方程：** $y = \beta_0 + \sum\beta_i x_i + \sum\beta_{ii} x_i^2 + \sum\beta_{ij} x_i x_j$，可用于预测任意参数组合下的 CQA 预测值

:::

## DOE 实验设计的综合考量要点

:::answer

DOE 实验设计是一门需要在科学性、统计严谨性和资源约束之间取得平衡的工程实践，以下要点是开展高质量 DOE 实验的综合考量。

**选择 DOE 设计类型的决策逻辑**

```
因子数量 ≤ 3 个？
    └── 是 → 直接响应面设计（CCD 或 BBD）
    └── 否 → 因子数 4~8 个？
                 └── 是 → 部分因子设计（筛选）→ 显著因子再做 RSM
                 └── 否（> 8 个）→ PB 设计筛选 → 显著因子再做 RSM
```

**实验设计的关键参数设定**

| 考量要点 | 具体内容 |
|---|---|
| **因子水平范围** | 须覆盖正常操作范围（NOR）以外的区域（如 NOR ± 20%~30%），以探索参数边界效应 |
| **随机化** | 因子点试验须随机化排序，以消除时间漂移和操作顺序对结果的影响（中心点按开头/中间/结尾分布） |
| **重复（Replication）** | 关键 CQA 检测须有分析重复（每样品 ≥ 2 次独立检测），将分析误差与工艺变异分离 |
| **阻隔（Blocking）** | 若实验无法在单一批次细胞或单一批次培养基下完成，须使用阻隔设计消除批次效应 |
| **中心点** | 须包含中心点（通常 3~5 个），用于估计纯误差和检验线性假设 |

**数据分析的核心步骤**

1. **模型构建：** 以逐步回归（Stepwise Regression）或全模型筛选方法建立最佳拟合模型
2. **残差分析：** 检验残差的正态性（QQ 图）、方差齐性（残差 vs. 拟合值散点图）和独立性，确认模型假设成立
3. **ANOVA 显著性检验：** 判断各主效应和交互效应的 p 值，确认显著因子
4. **模型拟合度评估：** R²（解释的方差比例）和 R²ₐₒⱼ（调整后 R²）须足够高（通常 > 0.80）
5. **预测验证（Confirmation Runs）：** 在模型预测的最优区域运行 3~5 个验证实验，确认模型预测的准确性

**DOE 实验常见陷阱**

- **假阳性（Type I Error）：** 多个响应变量同时检验时，须进行多重检验校正（Bonferroni 校正），避免仅凭单个 p < 0.05 便判断因子显著
- **伪重复（Pseudoreplication）：** 将同一培养批次的多个取样点误认为独立重复——真正的重复须是独立的批次运行
- **外推陷阱：** 回归模型仅在实验设计的参数范围内有效，不得外推至实验范围以外进行预测

:::
