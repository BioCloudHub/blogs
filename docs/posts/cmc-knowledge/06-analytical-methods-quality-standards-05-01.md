## 生物制品蛋白质含量检测：主要方法对比、适用场景与方法选择原则

:::answer

### 核心挑战

蛋白质含量检测看似简单，实际上存在多种方法，不同方法的原理不同，受干扰因素也不同，结果之间可能存在系统性偏差。选择合适的方法需要综合考虑**检测目的、样品基质、精度要求和操作可行性**。

### 主要蛋白质含量检测方法对比

| 方法 | 原理 | 优势 | 局限性 | 适用场景 |
|------|------|------|-------|---------|
| **紫外分光光度法（A280）** | 芳香族氨基酸（Trp、Tyr）在 280 nm 处的特征吸收 | 无需试剂，操作简单，快速，不消耗样品 | 受核酸、聚山梨酯等干扰；消光系数需准确标定 | **放行检测首选**；过程控制实时监控 |
| **凯氏定氮法（Kjeldahl）** | 测定样品总氮量，换算为蛋白质含量 | 结果准确，不依赖于蛋白质结构；绝对定量 | 操作繁琐，耗时，含氮辅料会干扰 | **溯源分析**；消光系数的实验验证参照 |
| **BCA 法（双辛可酸法）** | Cu²⁺在碱性条件下被蛋白还原为 Cu⁺，BCA 试剂与 Cu⁺显色 | 灵敏度高（可检测 μg/mL 级）；兼容性较好 | 受还原剂（DTT、β-ME）、铜螯合剂（EDTA）干扰 | 低浓度样品；研发阶段中间体检测 |
| **Bradford 法（考马斯亮蓝）** | 染料与蛋白质疏水区域和碱性残基结合后，最大吸收波长从 465 nm 红移至 595 nm | 操作简单，灵敏度高 | 受去污剂（SDS、Triton X-100）强干扰；不同蛋白质响应差异大 | 细胞培养上清快速筛选；非放行场景 |
| **氨基酸分析法（AAA）** | 蛋白质水解后，定量分析各氨基酸组成 | 最高准确性；可同时验证氨基酸序列 | 耗时（12～24 h 水解）；成本高；操作复杂 | **参比品赋值**；消光系数实验确定的金标准 |

### 放行检测的方法选择逻辑

```
放行检测（高通量 + 简便）
  └── A280 法（首选）
        │
        ├── 消光系数须先通过 AAA 或 Kjeldahl 法实验验证
        └── 须评估制剂基质对 A280 的干扰（如高浓度聚山梨酯）

溯源与参比品赋值（高准确性）
  └── 凯氏定氮法 + AAA 法（组合使用）
```

### 多方法联用的意义

单一方法存在固有局限性，推荐在以下场景进行**多方法交叉验证**：
- 参比品制备时（须多方法确认赋值准确性）
- 消光系数首次实验测定时
- 遇到基质复杂或有干扰物质的特殊样品时

## 关键辅料含量检测：必要性、检测项目设计与聚山梨酯降解风险

:::answer

### 为什么须检测关键辅料含量

制剂中的关键辅料（稳定剂、抑菌剂、表面活性剂等）对产品的**安全性、稳定性和有效性**均有直接影响。辅料含量超出范围可能导致：
- 稳定剂不足 → 蛋白聚集、氧化加速
- 防腐剂过多 → 细胞毒性风险
- 表面活性剂降解 → 生成有害杂质，与蛋白相互作用形成微粒

### 通常须纳入放行标准的关键辅料

| 辅料类型 | 代表成分 | 检测必要性 | 检测方法 |
|---------|---------|-----------|---------|
| **表面活性剂** | 聚山梨酯 80（Polysorbate 80）、聚山梨酯 20（PS20） | **高**（降解产物风险）| HPLC（蒸发光散射检测器 ELSD 或 CAD）；比色法 |
| **糖类稳定剂** | 蔗糖、海藻糖、山梨醇 | 中（含量影响渗透压和冻干保护效果） | 折光率法、HPLC-RI |
| **氨基酸稳定剂** | 组氨酸（His）、精氨酸（Arg）、甘氨酸（Gly） | 中（同时作为缓冲盐） | pH + 滴定法；HPLC |
| **防腐剂** | 苯甲醇、间甲酚（用于多剂量制剂）| **高**（安全性直接相关）| HPLC |
| **螯合剂** | EDTA | 中（防止金属离子催化氧化） | 滴定法 |

### 聚山梨酯（PS80/PS20）的特殊风险：降解产物

聚山梨酯是单抗制剂中最常用的表面活性剂，但其**化学不稳定性**是行业关注的重要质量风险：

**主要降解途径：**

```
聚山梨酯（PS80/PS20）
  │
  ├─ 氧化降解（主要途径）
  │     → 过氧化物 → 酮、醛类次级产物
  │     → 脂肪酸氧化物（月桂酸、油酸等游离脂肪酸）
  │
  └─ 酶催化水解（宿主细胞残余脂肪酶）
        → 游离脂肪酸（不溶于水）
        → 与抗体蛋白相互作用 → 形成亚可见颗粒（SVPs）
```

**降解产物的风险：**
- **游离脂肪酸**（尤其是月桂酸、油酸）在水性制剂中溶解度低，可自发形成亚可见颗粒（2～100 μm），影响制剂外观和患者安全性。
- 过氧化物可氧化蛋白质中的 Met、Trp 残基，导致化学降解。

**监控策略：**
- 放行时检测 PS80/PS20 总量（确保含量在规格范围内）。
- 稳定性研究中监控游离脂肪酸含量和颗粒变化趋势。
- 必要时评估宿主细胞来源的脂肪酶（如 PLBL2）对 PS 降解的贡献。

:::

## 生物制品常规检测项目：药典方法、检测目的与典型限度参考

:::answer

### 常规检测项目全览

生物制品放行质量标准中的常规检测项目均有对应的药典方法，通常不需要开发新方法，但须进行**方法确认（Qualification）**以证明其适用于特定产品和基质。

| 检测项目 | 主要目的 | 典型方法/标准 | 注意事项 |
|---------|---------|-------------|---------|
| **外观（Appearance）** | 确认产品物理状态（颜色、澄清度）符合预期 | 目视检查（参照 EP/ChP 色度标准溶液） | 颜色须与参比品或色标对比，不同批次须一致 |
| **可见异物（Visible Particles）** | 排除肉眼可见的颗粒、纤维、玻璃屑等 | 灯检法（ChP 通则 0904）| 须在规定光照和背景条件下检查；半自动/自动检测仪可辅助 |
| **不溶性微粒（Subvisible Particles）** | 检测 ≥ 10 μm 和 ≥ 25 μm 的颗粒数 | 光阻法（ChP 通则 0903）；MFI（辅助表征） | 注射剂须符合药典限度（每毫升 ≤ 25 个 ≥ 10 μm；≤ 3 个 ≥ 25 μm） |
| **pH 值** | 确认产品 pH 在目标范围内（影响稳定性和注射耐受性） | pH 计法（ChP 通则 0631） | 须校正 pH 计（两点校正），温度补偿 |
| **渗透压摩尔浓度（Osmolality）** | 确认制剂渗透压符合注射用制剂要求（接近生理值） | 冰点降低法（ChP 通则 0632） | 静脉注射：290～310 mOsm/kg；皮下注射可适当放宽 |
| **装量/可抽取体积** | 确认每支/瓶的实际装量不低于标示量 | 注射器抽取法（ChP 通则 0102） | 须考虑注射器针头滞留量（Dead Volume）的影响 |
| **细菌内毒素（Bacterial Endotoxins）** | 排除革兰氏阴性菌内毒素污染 | LAL 法（鲎试剂法，ChP 通则 1143）；重组 C 因子法 | 限度：注射用，每小时每千克体重内毒素不超过 5 EU/kg |
| **无菌检查（Sterility）** | 确认产品中无存活微生物 | 直接接种法或薄膜过滤法（ChP 通则 1101） | 须在 B 级/A 级洁净区操作；阳性和阴性对照须同步 |
| **异常毒性（Abnormal Toxicity）** | 排除化学或生物来源的非特异性毒性物质 | 小鼠（+ 豚鼠）体内接种法（ChP 通则 1141）| 见下节详述 |

### 关键注意：不溶性微粒与 MFI 的联用

光阻法（Light Obscuration）对高度透明、折射率接近水的颗粒（如蛋白颗粒、硅油液滴）检测存在**灵敏度不足**的问题。**微流成像法（MFI, Micro-Flow Imaging）** 可提供颗粒的形态信息（圆形度、纵横比），帮助区分蛋白质颗粒、硅油液滴和玻璃碎片，在稳定性研究和异常调查中作为补充方法使用。

:::

## 分析方法确认（Qualification）与方法验证（Validation）：概念辨析与阶段对应

:::answer

### 两个概念的本质区别

方法确认（Qualification）和方法验证（Validation）是同一方法成熟度提升路径上的**两个不同阶段**，而非可互换的同义词。

| 维度 | 方法确认（Qualification） | 方法验证（Validation） |
|------|--------------------------|----------------------|
| **法规依据** | PDA TR57-2（2012）；ICH Q14（2023）| ICH Q2(R1)；FDA、USP、ChP 各有指南 |
| **适用阶段** | 产品开发早期（IND 前～临床 II 期）| 临床后期（临床 III 期）及工艺验证（PPQ）前 |
| **适用方法** | 非药典方法的早期适用性评估 | 非药典方法的全面证明 |
| **预设标准** | 可在执行前不制定预设接受标准 | **须预先制定**所有验证参数的接受标准 |
| **验证参数覆盖** | 部分参数（专属性、准确度、精密度、线性、LOD/LOQ） | **全参数**（专属性、准确度、精密度、线性、范围、LOD/LOQ、**耐用性**） |
| **文件要求** | 确认方案 + 确认记录 | 验证方案 + 验证报告 |

### 分析方法的全生命周期管理

```
方法开发（Method Development）
  ├── 探索性实验，确定方法参数
  ├── 评估耐用性（Ruggedness）和稳定性指示（SI）能力
  └── 输出：方法草案

      ↓ 进入 IND 阶段

方法确认（Qualification）
  ├── 证明方法满足早期临床阶段的预期用途
  ├── 评估参数：专属性、准确度、精密度、线性、LOD/LOQ
  └── 输出：确认报告（支持临床 I/II 期）

      ↓ 进入临床 III 期 / PPQ 前

方法验证（Validation）
  ├── 全面、系统地证明方法适合商业化放行
  ├── 参数：专属性、准确度（回收率）、精密度（重复性+中间精密度+重现性）、线性、范围、LOD/LOQ、耐用性
  └── 输出：验证报告（支持 BLA 申报）

      ↓ 上市后

方法转移（Method Transfer）
  ├── 从开发实验室转移至 QC 实验室或 CMO
  └── 需进行转移确认（再证明方法适用性）
```

### 各验证参数的含义与评估方式

| 验证参数 | 含义 | 评估方式 | 典型接受标准 |
|---------|------|---------|------------|
| **专属性（Specificity）** | 在共存组分（杂质、辅料）干扰下，准确检测目标组分的能力 | 强制降解样品 + 混合杂质样品 | 共存组分不干扰目标峰；降解产物可被检出 |
| **准确度（Accuracy）** | 测定值与真实值的接近程度 | 添加回收率实验（三浓度，各三次） | 回收率 98%～102%（含量测定）|
| **重复性（Repeatability）** | 同一操作者、同一天、同一仪器的精密度 | 同一水平，≥ 6 次重复 | RSD ≤ 2%（含量测定）|
| **中间精密度（Intermediate Precision）** | 不同日期、不同操作者或不同仪器的精密度 | 跨日、跨人员实验 | RSD ≤ 5%（含量测定）|
| **线性（Linearity）** | 在一定范围内，测定值与浓度的线性关系 | ≥ 5 浓度点（覆盖 50%～150% 规格）| r² ≥ 0.999；截距 t 检验不显著 |
| **定量限（LOQ）** | 可准确定量的最低浓度（S/N ≥ 10） | 信噪比法或标准偏差/斜率法 | LOQ ≤ 规格下限的 10% |
| **耐用性（Robustness）** | 方法参数小幅变化时结果的稳定性 | Youden 试验或单因素变化实验 | 关键参数变化对结果无显著影响 |

## 药用辅料检测委外策略：IND 与 BLA 阶段的差异化处理

:::answer

### 问题背景

药用辅料检测是否可以委托第三方实验室（CMO/CRO）完成，在不同申报阶段有不同的监管期望和风险考量。

### 各阶段的建议策略

| 申报阶段 | 委外可行性 | 建议策略 | 核心理由 |
|---------|-----------|---------|---------|
| **IND 阶段** | ✅ 可以委外检测 | 选择有资质的第三方实验室，保留检测报告和质量协议 | 早期阶段产品未用于商业化，监管灵活度较高 |
| **BLA 阶段（上市申报）** | ⚠️ 建议纳入自有体系 | 将主要辅料检测纳入公司内部 QC 体系 | 商业化阶段须对检测结果负全责；委外引入供应商审计负担 |

### BLA 阶段委外检测的两大挑战

**挑战一：供应商审计与信任成本**

- 须对委外实验室进行 GMP 资质审计（或 ISO 17025 认证确认），建立质量协议（Quality Agreement）。
- 委外实验室发生偏差时，调查责任归属复杂，影响批次放行时效。

**挑战二：经济性分析**

- 辅料检测通常**不是批批检**，而是按供应商批次或定期抽检，每次检测项目数量有限（通常 3～5 项）。
- 按项目外包单价计算，长期外包的累计成本往往**高于**建立内部能力的固定成本。
- 内部检测还可与其他 QC 工作共享仪器设备（如 HPLC、pH 计），进一步降低边际成本。

### 实操建议

- **IND 阶段**：优先委外，节省早期资源；同时积累方法和数据，为后期内部建立奠定基础。
- **BLA 阶段**：对高检测频率、高风险辅料（如 PS80/PS20、防腐剂）优先建立内部能力；低风险、低频次辅料可评估是否继续委外。

## DMSO 残留检测的必要性评估：ICH Q3C 分类框架与风险判定逻辑

:::answer

### 结论

一般情况下，DMSO（二甲亚砜）不需要在放行质量标准中设立残留检测项目，但须经过系统的**安全性风险评估（ISF, Impurity Safety Failure）** 后做出判断。

### ICH Q3C 溶剂分类框架

ICH Q3C 将制药工艺中使用的有机溶剂按安全风险分为三类：

| 类别 | 定义 | 控制策略 | DMSO 归属 |
|------|------|---------|---------|
| **Class 1** | 已知人类致癌物或严重毒性溶剂（如苯、四氯化碳） | 应避免使用；若必须使用须严格控制 | 不适用 |
| **Class 2** | 有毒性但非致癌性溶剂（如乙腈、甲醇、己烷） | 须控制至安全暴露限度（PDE）以下 | 不适用 |
| **Class 3** | 人类低毒性溶剂（如乙醇、乙酸乙酯、**DMSO**） | 无需设定严格残留限度；仅需 GMP 控制 | ✅ **DMSO 属于 Class 3** |

### DMSO 在生物药生产中的使用场景及残留风险

| 使用场景 | DMSO 用量 | 残留风险 |
|---------|----------|---------|
| 细胞冷冻保存液（通常 10% DMSO） | 仅用于细胞库储存，不直接接触产品 | **极低**（生产工艺中不引入） |
| 小分子化合物溶解（研发阶段体外活性测试） | 分析级，微量 | 不涉及 GMP 生产 |
| 某些偶联工艺（ADC 等）| 可能在偶联步骤使用 | 须评估；Class 3 通常 < 5000 ppm 可接受 |

### 风险评估流程

```
确认 DMSO 在工艺中的具体用途和使用量
  │
  ├─ 若不直接接触产品（仅用于细胞库储存）
  │     → 无需设定残留检测 ✅
  │
  ├─ 若偶然接触产品（清洁后可能有痕量残留）
  │     → Class 3 溶剂，PDE = 50 mg/day（ICH Q3C）
  │     → 评估实际暴露量是否远低于 PDE → 通常低风险 ✅
  │
  └─ 若大量直接添加至产品（如 ADC 偶联工艺）
        → 须建立残留检测方法并设定限度 ⚠️
```

:::

## 异常毒性检测：必要性、动物实验要求与中美申报差异

:::answer

### 检测目的

异常毒性检测（Abnormal Toxicity Test）旨在排除产品中可能存在的**非预期毒性物质**（如病原体污染物、化学毒素、生物毒素等），是对产品安全性的综合性体内验证。

### 中美两国的申报差异

| 申报维度 | NMPA（中国）IND 阶段 | NMPA BLA 阶段 | FDA 要求 |
|---------|---------------------|--------------|---------|
| **动物种类** | 仅开展**小鼠**实验可接受 | 须开展**小鼠 + 豚鼠**实验 | 可**不将异常毒性纳入质量标准** |
| **检测必要性** | 须开展 | 须开展 | 可不做（依产品特性评估）|
| **科学依据** | 强制要求（ChP 通则 1141）| 强制要求（ChP 通则 1141）| FDA 认为充分的工艺控制可替代此项体内检测 |

### 检测方法要点（ChP 通则 1141）

**小鼠试验：**
- 每组注射 5 只小鼠（SPF 级），静脉或腹腔注射规定剂量。
- 观察 48 小时，所有小鼠须存活且体重无显著下降（体重不低于注射前 90%）。

**豚鼠试验（BLA 要求）：**
- 每组 2 只豚鼠，腹腔注射。
- 观察 7 天，须全部存活，无不良反应。

### 豚鼠实验的科学意义

豚鼠对某些毒素（如内毒素、麦角毒素）和热原物质的敏感性与小鼠不同，两种动物联合使用可覆盖更广泛的潜在毒性物质。这是中国药典在 BLA 阶段要求两种动物实验的主要依据。

> **趋势说明：** 随着体外替代方法（如 MAT，单核细胞活化试验）的发展和 3R（替代、减少、优化动物实验）原则的推广，异常毒性检测的动物实验要求在国际层面正逐步被重新审视，但在中国 BLA 申报中目前仍须按药典要求执行。

:::

## 参比品（Reference Standard）的建立要求：全面鉴定、分级管理与赋值方法

:::answer

### 参比品的战略地位

参比品（Reference Standard / Reference Material）是生物药质量控制体系的**基石**，所有效能检测、质量属性检测的结果均相对于参比品表达。参比品质量直接决定放行数据的可靠性和批间可比性。

### 参比品的全面鉴定要求

参比品须**采用现有最先进的分析手段**，从多个维度进行系统表征：

| 表征维度 | 分析方法 | 目的 |
|---------|---------|------|
| **一级结构（序列）** | LC-MS/MS 肽图；Sanger/NGS 测序 | 确认氨基酸序列与设计完全一致 |
| **高级结构** | CD（二级结构）；DSF/DSC（热稳定性）；SEC（溶液构象）| 确认折叠状态正确 |
| **翻译后修饰** | 糖型分析（HILIC-FLD）；脱酰胺/氧化（肽图）| 建立 PTM 基线档案 |
| **电荷异质性** | icIEF | 建立电荷变体基线分布 |
| **大小均一性** | SEC-HPLC；CE-SDS（还原/非还原）| 确认聚集体和片段含量 |
| **生物学活性** | 效价检测（细胞活性 + 结合活性）| 确认生物学功能正常 |
| **免疫化学特性** | ELISA（配体/受体结合）；SPR（亲和力 Kd）| 建立结合活性基线 |
| **含量** | A280 + AAA 或 Kjeldahl | 精确定量，为效能检测赋值 |

### 参比品的三级管理体系

```
原始参比品（Primary Reference Standard, PRS）
  ├── 来源：关键临床批次（KCS, Key Clinical Sample）
  ├── 表征：全面（上述所有维度）
  ├── 用途：对一级参比品进行标定
  └── 储量：数量有限，不用于日常检测

      ↓ 标定

一级参比品（Working Reference Standard, WRS / First-tier RS）
  ├── 来源：代表性工艺批次（需与 PRS 可比性研究确认）
  ├── 用途：对工作参比品进行标定
  └── 储量：足够多批次使用

      ↓ 标定

工作参比品（In-house Working Standard）
  ├── 来源：从一级参比品分装，用于日常放行检测
  ├── 批量：通常数百至数千支
  └── 有效期：须通过稳定性验证确定
```

> **关键原则：** 参比品须追溯至原始临床批次，以确保上市后产品与临床样品之间的**质量桥接（Quality Bridge）** 清晰。

### 推荐的参比品来源策略

- **上市阶段**：将关键性临床样品（III 期临床确证疗效的批次）用于参比品制备或标定，实现放行检测数据与临床安全性/有效性数据的充分衔接。
- 在此基础上：待检品效价不低于参比品（关键临床批次），即可基本保证上市产品有效性。

:::

---

## 工作参比品的建立、标定与更换管理

:::answer

### 工作参比品的必要性

工作参比品（Working Reference Standard）是日常放行检测的直接使用对象，须具备：
- 足够的**批量**（满足整个商业化生命周期使用）
- 良好的**均一性**（分装后各支间差异 < 方法精密度）
- 稳定的**储存条件**（避免降解导致赋值偏移）

### 工作参比品的赋值方法

**相对活性赋值（效价赋值）**

工作参比品的活性相对于一级参比品赋值为 100%，判定标准如下：

> 采用多批次测定，当工作参比品相对效价的 **95% 置信区间**（CI）完全落入原批次参比品的 **90%～110%** 范围内时，可将新批次工作参比品的相对活性赋值为 **100%**。

**统计学依据：**
- 95% CI 须同时满足下限 ≥ 90% 和上限 ≤ 110%（双侧等效性检验）。
- 通常需要 ≥ 3 次独立实验（不同天/不同操作者），以确保 CI 的可靠性。

### 参比品更换时的可追溯性要求

当需要更换参比品批次时（因储存耗尽或稳定性问题），须进行**新旧参比品的相关性分析和赋值传递**：

```
现用参比品（旧批）
  │
  ├─ 多次平行测定新批次参比品
  │
  ├─ 统计分析：新批次相对于旧批次的相对效价（含 95% CI）
  │
  ├─ 判断：CI 落入 90%～110% → 新批次赋值为 100%，可替代旧批次
  │
  └─ 记录完整的桥接数据，确保参比品赋值的可溯源性
```

> **ICH Q6B 要求：** 如能获得国际标准品（IS）或国家标准品（NS），应尽可能溯源至这些权威参考物质，以保证参比品赋值在全球范围内的可比性。

:::

## HCP ELISA 覆盖率研究：开发阶段策略与商业化 ELISA 的适用性评估

:::answer

### 覆盖率（Coverage）的定义

HCP ELISA 的覆盖率是指所用多克隆抗 HCP 抗体能够**识别实际工艺产生的 HCP 组合**的比例。覆盖率低意味着实际 HCP 残留可能被低估，存在假阴性风险。

### 不同开发阶段的 HCP 方法策略

| 阶段 | 推荐方法 | 说明 |
|------|---------|------|
| **临床 I/II 期** | **商业化 CHO-HCP 试剂盒**（如 Cygnus Technologies F550）| 快速获得、无需验证，可满足早期临床阶段的检测需求 |
| **临床 III 期及以后** | **平台工艺 HCP 方法**或**上游工艺专属 HCP 方法** | 须证明方法对本工艺 HCP 谱的充分覆盖 |
| **上市后商业化放行** | 经全面验证的专属方法 | 须满足 ICH Q2(R1) 验证要求 |

### 若商业化试剂盒用于临床 III 期及以后，须证明的内容

若企业希望将商业化试剂盒延伸使用至临床 III 期和上市后，须充分证明以下内容：

1. **抗体覆盖率研究（Antibody Coverage Study）：** 采用 2D 免疫印迹（2D Western Blot）评估商业化抗体对本工艺模拟收获液（含 HCP，不含目标蛋白）的识别覆盖率，通常要求 ≥ 60%～70%（WHO 建议）。
2. **标准品适用性确认：** 商业化试剂盒的标准品通常为其他细胞系来源的 HCP，须评估是否与本工艺 HCP 具有足够的可比性。
3. **基质效应评估：** 在本品的实际基质（缓冲液、制剂辅料）中进行添加回收率实验，确认无基质干扰。

### 覆盖率研究的方法（2D 免疫印迹法）

```
制备"无产品"模拟收获液（NPCF, Null-Product Cell Fluid）
  │
  ├─ 2D SDS-PAGE（按 pI 和 Mw 分离所有 HCP）
  │
  ├─ 分别转膜：银染（可视化所有 HCP）+ 免疫印迹（可视化抗体识别的 HCP）
  │
  └─ 比较两张图的蛋白斑点数量
        ↓
        覆盖率（%）= 免疫印迹识别斑点数 / 银染总斑点数 × 100%
```

:::

## 分析方法验证报告的递交时机与 PPQ 联动要求

:::answer

### 监管时间节点要求

| 时间节点 | 方法验证要求 |
|---------|------------|
| **IND 申报前** | 主要方法须完成**方法确认（Qualification）**（NMPA 要求更严格，部分关键方法须完成全验证） |
| **PPQ（工艺性能确认）实施前** | 所有放行用非药典方法须完成**全面方法验证（Validation）** |
| **BLA 申报时** | 提交完整**分析方法验证报告**（支持上市许可） |

### 为什么须在 PPQ 前完成方法验证

PPQ 批次是上市申报的关键批次，PPQ 阶段产生的放行数据将直接进入 BLA 申报文件。若放行用方法未经充分验证，则 PPQ 数据的可靠性存疑，可能导致：
- 监管机构对 PPQ 批次质量数据提出质疑。
- 需要重新进行放行检测，延误申报时间。
- 在极端情况下，须额外开展 PPQ 批次。

### 方法验证的优先级排序

在资源有限的情况下，建议按以下顺序推进方法验证：

```
第一优先级：安全性相关方法（无菌、内毒素、异常毒性）
  → 监管机构对此无灵活度，须在早期 GMP 生产前完成

第二优先级：效能（Potency）检测方法
  → 生物学活性是核心 CQA，须最优先验证

第三优先级：纯度相关方法（SEC、CE-SDS、icIEF）
  → 产品相关杂质的定量须可靠

第四优先级：工艺相关杂质方法（HCP、HCD、Protein A）
  → 安全性重要，但相对成熟；通常可使用商业化方法

第五优先级：含量和常规理化方法
  → 多为药典方法，仅需确认（Qualification）而非全验证
```

:::

## 质量标准的完整定义、法规地位与全生命周期管理原则

:::answer

### 质量标准的法规定义

**ICH Q6B 定义：**

> 质量标准是包括检测项目、参照分析方法和验收标准的列表，验收标准以限度值、范围或描述检测项目的其他标准予以表示。

**药品质量标准的本质：** 是基于产品的质量属性，为确保获得预期产品质量，对产品处于适当限制、范围或分布内的**物理、化学、生物或微生物性质或特性**进行控制的技术要求。

质量标准是由生产商提出和验证、**由监管机构作为产品上市许可条件批准**的关键规范，具有法律约束力。

### 质量标准贯穿研发全周期的演化

| 研发阶段 | 质量标准特征 |
|---------|------------|
| **早期（临床 I/II 期）** | 较宽松的接受标准；基于有限批次数据；以安全性为导向 |
| **临床 III 期** | 逐步收紧；基于多批次工艺数据；开始建立与临床效果的关联 |
| **上市申报（BLA）** | 基于 PPQ 批次 + 商业化验证数据；达到最终水平 |
| **上市后** | 随商业化生产数据积累不断完善；可通过变更申请调整 |

> **原则：** 质量标准的建立具有**阶段性**，应根据产品上市后检测数据的积累**逐步提高和不断完善**，不应在缺乏足够数据支持的情况下人为压低限度。

### 质量标准与整体控制策略的关系

质量标准凝聚了以下各类研究的综合结论：
- 工艺控制及验证数据
- 产品质量全面特性分析（结构表征）
- 稳定性研究结果
- 临床前/临床研究批次质量数据
- 适当的统计学分析（均值 ± nσ；工艺能力 Cpk）

:::

## 质量标准与参比品的关联：质量传递机制与批检验数据的临床相关性

:::answer

### 参比品在质量标准执行中的核心作用

质量标准中的许多检测项目（尤其是效能类和鉴别类）须**与参比品进行比较**才能得出结论，因此参比品的质量直接决定质量标准的执行意义。

### 参比品与临床数据的质量桥接逻辑

```
关键临床批次（III 期确证有效批次）
  │
  ├── 全面结构表征（肽图、糖型、高级结构等）→ 建立"分子指纹"
  │
  ├── 用于制备/标定主参比品（PRS）
  │
  └── PRS → 标定一级参比品 → 标定工作参比品
                                    │
                                    └── 日常批检验比较
                                            │
                                            ▼
                                    放行数据（效价、纯度等）
                                    = 与临床批次的可比性证明
```

**关键质量桥接点：**

| 检测项目 | 质量传递的意义 |
|---------|-------------|
| **肽图鉴别** | 待检品与参比品图谱一致 → 间接证明一级序列与临床批次一致 |
| **效价（相对活性）** | 待检品效价 70%～130%（相对于参比品）→ 保证与临床批次生物学活性相当 |
| **纯度（SEC、CE-SDS）** | 与参比品基线一致 → 产品相关杂质水平与临床批次相当 |

### 参比品更换时的质量传递要求

当参比品批次更换时（储量耗尽、稳定性问题等），须进行**批次桥接（Bridging Study）**：

- 新旧参比品须在**多个质量维度**（效价、理化属性、纯度）进行并行比较。
- 统计学上确认新旧参比品之间的相当性（等效性检验）。
- 桥接数据需归档，确保质量标准执行的历史可溯源性。

**工艺相关杂质专属参比品：** 对于 HCP、HCD、Protein A 等工艺相关杂质的检测，有时须建立**专属杂质参比品（Impurity Reference Standard）**，用于 ELISA 检测方法的标准曲线制作，以保证定量结果的准确性。

:::

## 清洁验证分析方法的选择策略：专属性方法 vs. 非专属性方法的判定框架

:::answer

### 清洁验证的分析方法目的

清洁验证（Cleaning Validation）旨在证明设备清洁程序可将前一批次的**活性成分残留（API Residue）和清洁剂残留**降低至安全水平。分析方法须具备足够灵敏度，以检测预设的可接受限度（MACO, Maximum Allowable Carryover）。

### 两类方法的定义与选择逻辑

| 维度 | 专属性方法（Specific Methods） | 非专属性方法（Non-specific Methods） |
|------|-------------------------------|-------------------------------------|
| **检测对象** | 特定残留物（如目标 API 的特征吸收峰） | 一类性质（如总有机碳、电导率） |
| **代表方法** | HPLC（UV/FLD 检测）、UPLC、UV 光谱 | **TOC（总有机碳）**、电导率、pH |
| **优先级** | **优先选择**（能准确识别和定量特定残留物）| 次选（在专属方法不可行时使用） |
| **适用前提** | 清洁过程中 API 未发生显著降解；或方法对降解产物也具专属性 | 当 API 经极端 pH/温度清洁后降解，或大分子无法用色谱方法准确定量时 |

### 专属性方法的适用场景与验证要求

**适用场景：** 小分子 API 或稳定性较好的肽类；清洁剂本身可用色谱法定量。

**ICH Q2(R1) 全面验证要求（按"含量"类别）：**
- 准确度（Accuracy）
- 精密度（Precision：重复性 + 中间精密度）
- 专属性（Specificity）
- 线性（Linearity）和范围（Range）
- 定量限（LOQ）/ 检测限（LOD）

> **关键：LOQ 须与 MACO 匹配** —— 若 MACO = 10 μg/swab，则方法 LOQ 须 ≤ 10 μg/swab（通常要求 LOQ ≤ MACO 的 50%）。

### 非专属性方法（TOC）的适用场景

**适用场景：** 大分子生物制品（蛋白质、mAb、多糖）的清洁验证；清洁后 API 发生降解、难以用专属方法定量的情况。

**TOC 的工作原理：** 氧化所有含碳有机物为 CO₂，通过 NDIR（非分散红外）检测 CO₂ 量，间接反映有机物总含量（详见下节 TOC 专题）。

**擦拭回收率验证：** 无论使用专属或非专属方法，**擦拭（Swab）回收率**须在清洁验证前单独验证（在代表性材料表面进行添加回收实验），且检测方法须与清洁验证正式分析时一致，保证数据可比性。

:::

## 总有机碳（TOC）检测：原理、监管意义与制药工艺中的应用

:::answer

### TOC 检测的监管意义

总有机碳（Total Organic Carbon, TOC）检测是中国药典（ChP）和 USP 对**注射用水（WFI）和纯化水（PW）**质量控制的重要指标：

- **药典限度：** 注射用水和纯化水的 TOC ≤ **0.5 mg/L（500 ppb）**（ChP 2020；USP <643>）。
- **监管意义：** 当制药用水中 TOC 含量足够低时，代表其中有机污染物（包括微生物代谢产物、制药工艺残留等）的含量不会对人体产生影响，是保障注射液安全性的重要参数。
- **TOC 是 FDA 提倡的**评估水样中所有含碳有机化合物的综合方法，广泛用于制药水系统质控和**清洁验证**。

### 主要检测方法及原理

**方法一：差减法（TC - IC = TOC）**

```
水样分成两路同时进入：
  │
  ├─ 高温燃烧管（900℃，催化氧化）
  │     → 有机物 + 无机碳酸盐 → 全部转化为 CO₂
  │     → NDIR 检测器测定 → 得到总碳（TC）
  │
  └─ 低温反应管（150℃，磷酸酸化）
        → 仅无机碳酸盐分解为 CO₂（有机物不被氧化）
        → NDIR 检测器测定 → 得到无机碳（IC）
  │
  └── TOC = TC - IC
```

**方法二：直接法（去除无机碳后直接测定有机碳）**

```
水样酸化 + 曝气（吹出 CO₂）
  │     → 去除全部无机碳（CO₃²⁻、HCO₃⁻等）
  │
  └─ 进入高温燃烧管（900℃）
        → 有机物氧化为 CO₂
        → NDIR 测定
        → 直接得到 TOC
```

**注意：** 直接法中曝气过程会造成**挥发性有机物（VOCs）损失**，因此测定结果实为"不可吹出的有机碳（NPOC）"，不能完整反映全部有机污染。对于含 VOCs 的样品，差减法更准确。

### TOC 在制药中的三大应用场景

| 应用场景 | 检测对象 | 目的 |
|---------|---------|------|
| **制药用水质控** | WFI、纯化水 | 日常监控水质，确保符合药典限度 |
| **清洁验证** | 设备清洁后淋洗水 | 评估清洁效果，确认活性成分残留去除至安全水平 |
| **环境监控** | 实验室超纯水（仪器校准用）| 评估水质稳定性（超纯水放置 12 h 后微生物呈几何级数增长） |

### TOC 样品采集与保存的关键注意事项

| 注意事项 | 操作要点 |
|---------|---------|
| **容器洁净度** | 样品瓶须为专用 TOC 级玻璃瓶或聚四氟乙烯（PTFE）瓶，用超纯水冲洗后使用；避免任何有机溶剂残留 |
| **密封性** | 取样后立即密封，防止空气中 CO₂ 溶入（导致 IC 值偏高）和外部有机物污染 |
| **取样操作** | 尽量隔绝外界空气和人员接触，防止微生物和有机物污染（实验室 18 MΩ·cm 超纯水放置 12 h 后微生物呈几何级数繁殖） |
| **双层容器保护** | 建议将样品置于两层容器中（外层隔尘，内层直接加样），测试时内层容器直接倒入仪器，减少污染环节 |
| **及时检测** | 采样后尽快检测（通常 < 24 h）；若需保存，须在 4℃ 避光条件下，并加入磷酸酸化至 pH < 2（抑制微生物生长） |

## MCB 与 WCB 检测项目的差异化策略：风险管理原则的实际应用

:::answer

### 差异化的理论依据

MCB（主细胞库）已经过全面检定，WCB（工作细胞库）是从 MCB 直接扩增制备的，理论上其安全性风险已在 MCB 阶段得到充分评估。**基于风险管理原则**，WCB 可适当简化部分检测项目，减少不必要的资源消耗。

### MCB vs. WCB 检测项目差异对比

| 检测项目 | MCB | WCB | 简化依据 |
|---------|-----|-----|---------|
| 细胞鉴别 | ✅ | ✅ | 每次均须确认为目标细胞株（防止交叉污染） |
| 细菌真菌检查 | ✅ | ✅ | 新建库均须确认无菌 |
| 分枝杆菌检查 | ✅ | ✅ | 安全性基本项，不可省略 |
| 支原体检查 | ✅ | ✅ | 最常见隐性污染，不可省略 |
| 病毒因子—体外指示细胞法 | ✅ | ✅ | 基本病毒安全筛查 |
| 病毒因子—细胞形态/血吸附 | ✅ | ✅ | 基本病毒安全筛查 |
| **病毒因子—动物体内接种法** | ✅ | **❌ 可省略** | MCB 已完成；WCB 直接来源于 MCB，风险极低 |
| **病毒因子—鸡胚体内接种法** | ✅ | **❌ 可省略** | 同上 |
| 逆转录病毒检查 | ✅ | 视情况 | 通常 MCB 数据已充分，WCB 可减少频率 |
| 种属特异性病毒 | ✅ | 视情况 | 依监管要求和风险评估 |
| **成瘤性/致瘤性** | ✅ | **❌ 通常不做** | 与细胞株本身特性相关，MCB 表征已覆盖 |

### 关键简化逻辑

- **动物体内接种法（小鼠/豚鼠/鸡胚）：** 这类检测主要用于检测能在活体动物中复制的外源病毒。MCB 已完成此检测，WCB 是 MCB 的直接传代，引入新型动物传播性外源病毒的概率极低，故可省略。
- **成瘤性/致瘤性检测：** 这是对细胞株**固有遗传特性**的评估，与传代次数无关，MCB 完成一次即可代表整个细胞株的特性。

### 工艺变更后的重新检测要求

当发生以下变更时，须重新对 **EOPC（生产终末细胞）** 进行全面检定：
- 上游培养工艺发生重大变更（培养基、培养条件、规模）
- 生产规程中传代次数显著增加
- 细胞库储存条件发生变更
