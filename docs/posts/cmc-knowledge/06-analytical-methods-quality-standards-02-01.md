## NMPA 与 FDA 在结构表征、质量标准和方法验证上的关键申报差异

:::answer

### 背景说明

在生物药 IND/BLA 申报实践中，NMPA（中国国家药品监督管理局）与 FDA（美国食品药品管理局）对 CMC 文件的具体要求存在显著差异，理解这些差异对于双报策略和资源分配至关重要。

### 三大维度的差异对比

| 申报维度 | NMPA 要求 | FDA 要求 | 实践影响 |
|---------|----------|---------|---------|
| **结构表征批次数** | **2～3 批次**须进行完整结构表征研究 | **1 批次**即满足申报要求 | NMPA 需提前备好足够批次；早期研究批次须保留样品 |
| **质量标准完整性** | IND 阶段即须提交**完整质量标准**，建议涵盖电荷异质性、糖型等，须说明制定依据 | 提供质量标准，放行范围可较宽；重点关注**安全性相关**质量标准 | NMPA 对早期申报的数据完整性要求更高，须提前规划开发节奏 |
| **方法验证深度** | IND 申报前，**主要分析方法均需系统方法学验证**并出具方法验证报告 | 建议仅对**安全性相关**分析方法开展完整验证，其余方法做<b>方法确认(Qualification) </b>即可 | FDA 路径下早期资源消耗更少；NMPA 路径须前置方法开发和验证工作 |

### 方法验证（Validation）vs. 方法确认（Qualification）的区别

| 维度 | 方法验证（Validation） | 方法确认（Qualification） |
|------|----------------------|------------------------|
| 适用场景 | 新开发方法 / 关键质量属性方法 | 已验证方法的转移确认；非关键方法 |
| 验证参数 | 特异性、线性、范围、准确度、精密度（重复性+中间精密度+重现性）、检测限、定量限、耐用性 | 通常仅覆盖准确度、精密度、线性等部分参数 |
| 文件要求 | 完整验证方案 + 验证报告 | 确认方案 + 确认记录 |

> **双报策略建议：** 以 NMPA 要求为最高标准组织验证工作，可自然满足 FDA 的要求，避免重复开展验证实验。

:::

## 质量标准的法规定义、制定原则与在整体控制策略中的定位

:::answer

### 质量标准的法规定义（ICH Q6B）

> **质量标准**：定义为一个包括检测项目、参照分析方法和验收标准的列表，验收标准以限度值、范围或描述检测项目的其他标准予以表示。质量标准为原液、成品和生产阶段所用的其他材料制订了一套应遵循的、与其用途相适应的验收标准。

**"符合质量标准"** 的含义：原液和成品按所列分析方法检测，结果符合验收标准。

质量标准由**生产商提出和验证**，并由**监管机构作为产品上市许可条件批准**，是具有法律效力的关键产品质量规范。

### 质量标准在整体控制策略中的定位

质量标准是**总体控制策略（Overall Control Strategy）的一个组成部分**，而非全部。完整的控制策略还包括：

```
整体质量控制策略
  │
  ├── 研发阶段全面结构表征（为质量标准提供科学依据）
  ├── 原材料和辅料的质量控制
  ├── 生产工艺过程控制检测（IPQC）
  ├── 工艺评估与验证（PV）
  ├── GMP 合规生产
  ├── 稳定性研究（支撑有效期和贮存条件）
  ├── 批间一致性检测
  └── 质量标准（放行检验）← 本节重点
```

### 质量标准制定的四大核心原则

**原则一：与生产工艺相关联**

- 质量标准的数值范围须以**连续性工艺验证批次的实际数据**为基础，而非基于理论预期。
- 产品相关杂质、工艺相关杂质的限度须与实际工艺能力挂钩，并考虑工艺变更或规模放大可能带来的异质性变化。

**原则二：考虑产品稳定性**

- 制定标准时须预留**储存过程中降解的空间**，确保在货架期末端产品仍符合质量标准。
- 由于生物制品的复杂性，单一稳定性指标不足以反映产品稳定性全貌，须建立**联合检测图谱（Stability Indicating Panel）**。
- 参考 ICH Q5C《生物技术产品及生物制品的稳定性研究》。

**原则三：与临床前及临床研究相关联**

- 商业化产品的质量须与临床前和临床研究阶段所用批次具有可比性，质量标准须能覆盖这些参考批次的实际数据范围。
- 临床批次数据是制定上市申请质量标准的**核心依据**。

**原则四：与分析方法相关联**

- 同一质量属性可能由多种方法检测，结果不尽相同；须明确所选方法与历史研发数据的相关性，保证数据可比性。
- 分析技术发展与产品开发有时难以同步，须在申报文件中阐明方法选择的合理性和数据的可追溯性。

:::

## 抗体药质量标准的核心检测项目框架

:::answer

### 质量标准的五大模块

抗体药质量标准通常按以下五个模块组织，每个模块对应不同的质量属性类别：

**① 外观和性状**

提供原液物理性状及色泽的定性描述（如液体/固体、无色/淡黄色、澄明/轻度乳光等）。物理性状不符合预期是质量异常的早期信号，须纳入放行检验。

**② 鉴别（Identity）**

- 须采用以原液**特有分子结构和其他特性**为基础的高特异性方法。
- 通常需要多于一种的检测方法（物理化学、生物学和/或免疫化学）联合确认。
- 鉴别试验**只要求定性**（是/否），不要求定量。
- 典型方法：**肽图（LC-MS/MS）+ 等电点（icIEF）**。

**③ 纯度和杂质（Purity & Impurities）**

- 生物制品的绝对纯度难以用单一方法精确测定，须**多种方法联合评价**。
- 按杂质来源分：产品相关杂质（聚集体、片段、电荷变体）和工艺相关杂质（HCP、HCD、Protein A 等）。

**④ 效价（Potency）**

- 经验证的生物效价测定方法是质量标准的**必要组成部分**（ICH Q6B 要求）。
- 效价测定方法须与产品的作用机制（MOA）相关联，反映产品的生物学活性。
- 在某些情况下，成品采用效价法，原液可采用理化替代方法（相对结合活性等）。

**⑤ 含量（Quantity）**

- 原液定量一般采用**蛋白含量测定**（质量，如 UV A280 法）。
- 在以效价为基础的产品中，不必采用替代方法进行含量测定。

:::

## DS 与 DP 放行质量标准：检测项全览与分层逻辑

:::answer

### 放行质量标准检测项总览

单抗原液（DS）和成品（DP）的放行质量标准通常包含以下七大类检测：

| 检测类别 | 具体项目 | 主要分析方法 | 典型目的 |
|---------|---------|------------|---------|
| **① 鉴别** | 肽图、等电点 | LC-MS/MS、icIEF | 确认分子身份，防止混淆/替换 |
| **② 常规理化检查** | 外观、pH、渗透压、颜色 | 目视/仪器、pH 计、渗透压计、分光光度法 | 基本物理化学性质符合预期 |
| **③ 含量** | 蛋白含量 | UV 280 nm（A280 法）| 确认活性成分的定量水平 |
| **④ 产品纯度** | SEC（大小异质性）、CE-SDS（片段/完整性）、icIEF（电荷异质性） | SEC-HPLC、CE-SDS（还原/非还原）、icIEF | 表征产品相关物质和杂质 |
| **⑤ 效能（Potency）** | 结合活性、细胞活性 | ELISA、报告基因法、ADCC 细胞法等 | 证明产品具有预期生物学活性 |
| **⑥ 工艺相关杂质** | Protein A 残留、宿主细胞 DNA（HCD）、宿主细胞蛋白（HCP） | ELISA、qPCR | 证明杂质去除至安全水平 |
| **⑦ 安全性** | 内毒素、微生物限度、无菌检查、可见异物、不溶性微粒 | 各药典方法 | 确保产品对患者安全 |

### DS 与 DP 的检测项差异

| 检测项目 | 原液（DS） | 成品（DP） | 说明 |
|---------|-----------|-----------|------|
| 肽图 | ✅ | 通常不重复 | DS 完成后 DP 鉴别可采用更简便方法 |
| SEC | ✅ | ✅ | 灌装可能引入轻微聚集，须监控 |
| 效能 | ✅ 或替代方法 | ✅（必须） | DP 效能是放行的核心 |
| 无菌 | — | ✅ | DP 的关键安全项目 |
| 不溶性微粒 | — | ✅ | 灌装引入风险，须在 DP 层面检测 |
| HCP/HCD | ✅ | 通常不重复 | 已在 DS 层面验证控制 |

:::

## 鉴别方法一：肽图法（Peptide Mapping）——原理、适用场景与判定标准

:::answer

### 方法原理

肽图法是抗体分子鉴别和结构表征的**金标准方法**，通过以下步骤实现：

```
目标蛋白
  │
  ├─ 变性/还原（打开二硫键）
  │
  ├─ 特异性蛋白酶酶切（将蛋白质裂解为特征肽段）
  │     常用酶：胰蛋白酶（Trypsin）→ 切 Lys/Arg C 端
  │             Lys-C → 仅切 Lys C 端
  │             Asp-N → 切 Asp N 端
  │             Glu-C → 切 Glu C 端
  │
  ├─ LC-MS/MS 分离鉴定（反相 HPLC + 串联质谱）
  │
  └─ 与对照品肽图谱比对（保留时间 + 质谱信号双重比对）
```

### 肽图法的多重应用场景

| 应用场景 | 说明 |
|---------|------|
| **放行鉴别（Identification）** | 确认批次身份，防止产品混淆；与对照品图谱比对，定性判断 |
| **批间一致性评估** | 通过多批次肽图谱的一致性，表征生产工艺稳定性 |
| **细胞基质表达稳定性监测** | 验证生产细胞在传代过程中目标蛋白序列未发生突变 |
| **蛋白变异体定性分析** | 识别序列相关的变体（如脱酰胺、氧化的肽段） |
| **二硫键定位** | 采用非还原条件酶切，通过质谱鉴定含二硫键的肽段对 |
| **糖基化位点分析** | 鉴定 N-糖基化（Asn-X-Ser/Thr 序列）和 O-糖基化位点 |
| **PTM 定性与定量** | 脱酰胺、Met 氧化、糖化等修饰的位点定位与比例测定 |

### 放行判定标准

- **定性判定：** 供试品的肽图谱（峰的保留时间、相对峰面积分布）应与对照品图谱**一致**。
- **法规依据：** 《中国药典》2020 版三部通则 3405 肽图检查法。
- **方法专属性要求：** 肽图法须能区分结构相近的蛋白质分子（如不同亚型 IgG 或双特异性抗体的两条臂），须在方法开发阶段验证专属性。

:::

## 鉴别方法二：等电点测定（icIEF）——原理、分辨率优势与判定标准

:::answer

### 方法原理

**成像毛细管等电聚焦电泳（icIEF, imaged Capillary Isoelectric Focusing）** 是检测蛋白质等电点（pI）和电荷异质性的核心方法，其分离原理如下：

1. 毛细管两端施加高压直流电场，管内含载体两性电解质（Carrier Ampholytes）形成 **pH 梯度**（通常 pH 3～10 或更窄范围）。
2. 蛋白质依其所带电荷向阳极（碱性端）或阴极（酸性端）迁移，直至到达**净电荷为零的 pH 区域（即 pI 值）**时停止移动，聚焦成极窄的谱带。
3. 采用**全柱成像（Whole-column Imaging）** 技术实时检测，一次运行即可获得完整谱图（区别于传统 cIEF 的逐步洗脱检测）。

### icIEF 与传统方法的对比

| 维度 | 传统 IEF（平板凝胶） | cIEF（毛细管，逐步洗脱） | icIEF（全柱成像） |
|------|-------------------|----------------------|-----------------|
| 分析时间 | 数小时 | 30～60 min | **< 15 min** |
| 定量精度 | 低（目视估读） | 中 | **高**（面积定量） |
| 自动化程度 | 低 | 中 | 高 |
| 样品用量 | 较多 | 少 | **极少（< 5 μL）** |
| 图谱获取 | 染色后扫描 | 洗脱后紫外 | **实时成像** |

### 用于鉴别的判定标准

- **定性判定：** 供试品的主等电点（pI 主峰）应与对照品**相差不大于 ± 0.5 pH 单位**。
- **科学依据：** 每种蛋白质具有特定的等电点（由氨基酸组成和 PTM 决定），等电点偏差超过限度提示分子身份或修饰状态异常。

### icIEF 的双重功能

icIEF 在质量标准中同时承担两个角色：

| 用途 | 判定依据 | 限度示例 |
|------|---------|---------|
| **鉴别**（Identity） | pI 主峰与对照品的偏差 | ± 0.5 pH 单位以内 |
| **电荷异质性**（Purity） | 主峰（Main Peak）占所有峰总面积的比例 | 主峰 ≥ 50%（IND 阶段） |

:::

## 蛋白含量测定：UV A280 法的原理、消光系数与应用注意事项

:::answer

### 方法原理

**紫外分光光度法（UV 280 nm，A280 法）** 是蛋白质含量定量最常用的方法，基于以下原理：

- 蛋白质分子中含有**共轭双键的芳香族氨基酸**（主要是酪氨酸 Tyr 和色氨酸 Trp，次要是苯丙氨酸 Phe 和二硫键的贡献）在 **280 nm 波长处具有特征最大吸光度**。
- 在一定浓度范围内，吸光度与蛋白质浓度遵循 **Beer-Lambert 定律**：

$$A_{280} = \varepsilon \times c \times l$$

其中 $\varepsilon$ 为摩尔消光系数（M⁻¹·cm⁻¹），$c$ 为蛋白摩尔浓度，$l$ 为光程（cm）。

### 消光系数（ε）的确定

IgG1 抗体的理论消光系数可基于氨基酸序列通过 Pace 公式计算：

$$\varepsilon_{280} = (n_{Trp} \times 5500) + (n_{Tyr} \times 1490) + (n_{SS} \times 125) \quad \text{(单位: M}^{-1}\text{·cm}^{-1}\text{)}$$

典型 IgG1 的 $\varepsilon_{280}$ 约为 **210,000～230,000 M⁻¹·cm⁻¹**（以 A280 换算的吸光系数 $E_{280}^{1\%}$ 约为 1.4～1.5 mL·mg⁻¹·cm⁻¹）。

### 放行判定标准

- **通用标准：** 目标蛋白浓度 ×（1 ± 10%），即目标浓度 ± 10%。
- **法规依据：** 《中国药典》2020 版三部通则 0731 蛋白质含量测定法。

### 方法应用的注意事项

| 注意点 | 说明 |
|-------|------|
| **干扰物质** | 核酸（260 nm 处吸收）、聚山梨酯（Polysorbate，高浓度时影响基线）、有色赋形剂均可能干扰 A280 读数 |
| **浓度线性范围** | 通常 A280 < 1.5～2.0（Beer-Lambert 线性范围上限），高浓度样品须稀释后测定 |
| **双波长校正** | 可使用 A280/A320 双波长法校正非蛋白质背景吸收（A320 处蛋白无吸收） |
| **消光系数溯源** | 理论计算值须通过**氨基酸分析（AAA）或 Kjeldahl 法**进行实验验证，确保定量准确性 |
| **容量瓶/比色皿清洁** | 痕量蛋白污染可导致读数偏高，须严格清洁样品处理器具 |

:::

## 产品纯度检测一：SEC（分子排阻色谱）——分离原理、方法特点与放行标准

:::answer

### 分离原理

分子排阻色谱（Size Exclusion Chromatography, SEC）基于**流体动力学体积（Hydrodynamic Volume）**进行分离，而非化学相互作用：

- 色谱柱填料（亲水硅胶、Sephadex、Sepharose 等）颗粒内部分布着**不同孔径的孔道网络**。
- **大分子**（如聚集体）：无法进入孔道，直接随流动相洗脱，保留时间**最短**（最先出峰）。
- **中等大小分子**（如单体，~150 kDa）：部分进入孔道，中等保留时间（主峰）。
- **小分子**（如片段）：可进入更多孔道，保留时间**最长**（最后出峰）。

### 典型 SEC 谱图峰归属

```
洗脱时间（min）→
│
│   HMWS（聚集体）   单体（主峰）   LMWS（片段）
│       ↑              ↑↑↑↑           ↑
│    先出峰           主峰          后出峰
└──────────────────────────────────────────→
```

### 方法关键参数

| 参数 | 典型设置 | 重要性 |
|------|---------|--------|
| 流动相 | PBS（含 100～350 mM NaCl），pH 7.0～7.4 | 高盐抑制非特异性吸附；pH 接近生理值 |
| 色谱柱 | TSKgel G3000SWxL 或同等柱（300 mm × 7.8 mm） | 柱子规格决定分辨率和通量 |
| 流速 | 0.5～1.0 mL/min | 平衡分辨率与分析时间 |
| 检测波长 | 280 nm | 蛋白特征吸收 |
| 进样量 | 10～50 μg 蛋白 | 过少影响检测灵敏度；过多导致柱超载 |

### 放行判定标准

| 项目 | IND 阶段参考 | BLA 阶段（商业化）|
|------|------------|----------------|
| 单体纯度（SEC） | ≥ 90%（可放宽） | 根据多批次数据合理收紧（通常 ≥ 95%～98%） |

- **法规依据：** 《中国药典》2020 版三部通则 0514 分子排阻色谱法。
- **关键注意：** SEC 所测为特定流动相条件下的表观聚集体含量，可逆聚集体在稀释/换液后可能消散；须结合 AUC（分析超速离心）等方法综合评估。

:::

## 产品纯度检测二：CE-SDS——还原与非还原模式、原理与判定标准

:::answer

### 方法原理

**毛细管电泳-十二烷基磺酸钠（CE-SDS）** 是在 SDS-PAGE 原理基础上发展的毛细管电泳技术：

- **SDS（十二烷基磺酸钠）** 与蛋白质结合，使其变性并赋予均一的**负电荷-质量比**，消除蛋白质自身电荷差异的干扰。
- 在弹性石英毛细管中，蛋白质在高压直流电场驱动下，按**分子大小（分子量）**差异在筛分介质（SDS-凝胶或聚合物溶液）中分离。
- **分子量越小，迁移越快**（先到达检测器，保留时间短）；分子量越大，迁移越慢。

### 还原（R-CE-SDS）vs. 非还原（NR-CE-SDS）模式

| 维度 | 还原 CE-SDS（R-CE-SDS） | 非还原 CE-SDS（NR-CE-SDS） |
|------|------------------------|--------------------------|
| 样品处理 | 加入还原剂（DTT 或 β-ME）断裂二硫键 | 不加还原剂，保留二硫键 |
| 检测对象 | 轻链（LC，~25 kDa）、重链（HC，~50 kDa） | 完整 IgG（~150 kDa）、半抗体（~75 kDa）、片段 |
| 信息维度 | 重链/轻链完整性、比例；N/C 端截短 | 完整抗体分子完整性；非共价聚集体（SDS 条件下解离，仅检测共价聚集） |
| 用于放行的主要项目 | LC/HC 纯度（各峰面积百分比）| **NR-CE-SDS 纯度**（整体分子完整性） |

### 放行判定标准

| 项目 | 参考标准 | 说明 |
|------|---------|------|
| NR-CE-SDS 纯度 | ≥ 90%（IND 阶段可放宽） | BLA 阶段根据多批次数据合理缩小限度 |
| R-CE-SDS 主峰（HC+LC）比例 | 依产品特性设定 | 主要确认重链轻链比例正常 |

- **法规依据：** 《中国药典》2020 版三部通则 0542 毛细管电泳法。
- **CE-SDS 与 SEC 的互补性：** CE-SDS 检测共价键连接的片段和聚集，SEC 检测非共价聚集体，两者联用可全面覆盖大小异质性。

:::

## 产品纯度检测三：icIEF（成像毛细管等电聚焦）——电荷异质性表征与纯度判定

:::answer

### 方法在纯度检测中的应用

icIEF 不仅用于鉴别（pI 测定），同时是表征**电荷异质性（Charge Heterogeneity）**的核心方法，可定量分析酸性峰（Acidic Peaks）、主峰（Main Peak）和碱性峰（Basic Peaks）的比例分布。

### 典型 icIEF 谱图解读

```
峰面积百分比 (%)
│
│     酸性峰群          主峰（Main Peak）    碱性峰群
│    ─────────         ────────────────    ─────────
│   AP1  AP2  AP3           MP            BP1  BP2
│    ↑    ↑    ↑             ↑↑↑↑           ↑    ↑
│   低 pI ←───────────────────────────────────→ 高 pI
└────────────────────────────────────────────────→
```

### 各峰组的主要来源（参考）

| 峰组 | 主要修饰来源 |
|------|------------|
| **酸性峰** | 天冬酰胺脱酰胺化（Asn→Asp）；唾液酸修饰；赖氨酸糖化；二硫键错配 |
| **主峰** | 理想折叠、未修饰的主要分子形式 |
| **碱性峰** | C 末端赖氨酸未切除（+Lys）；N 末端焦谷氨酸化（pyroGlu）；天冬氨酸异构化（isoAsp） |

### 放行判定标准

| 项目 | IND 阶段 | BLA 阶段 |
|------|---------|---------|
| 主峰比例 | ≥ 50%（可放宽） | 根据多批次数据设定，通常收紧（如 ≥ 60%～70%）|
| 酸性峰/碱性峰 | 可不设具体限度 | 结合 CQA 评估，对影响活性的峰组设定上限 |

- **方法开发要点：** 须优化载体两性电解质的组成和 pH 范围，以获得最佳分辨率；同时须选择合适的 pI 标记物（pI Markers）进行 pI 定标。
- **批间一致性监控：** icIEF 谱图的整体形态（酸碱峰分布趋势）可作为工艺稳定性的敏感指示器。

:::

## 效能检测一：结合活性（Binding Activity）——ELISA 法原理与验收标准

:::answer

### 方法原理

**ELISA（酶联免疫吸附法）** 结合活性检测通过以下方式定量评估抗体与靶抗原的结合能力：

**典型操作流程（直接竞争或桥接 ELISA）：**

```
抗原包被固相（96 孔板）
  │
  ├─ 加入梯度稀释的待测样品（含目标抗体）
  │     对照：标准品（参考品）同步检测
  │
  ├─ 抗原-抗体结合（孵育）
  │
  ├─ 洗涤（去除未结合抗体）
  │
  ├─ 加入酶标二抗（检测结合的抗体）
  │
  ├─ 底物显色（TMB 等）
  │
  └─ 读取 OD 值 → 绘制剂量-响应曲线
        ↓
     与参考品曲线比较，计算相对结合活性（%）
```

### 结果计算方式

通常采用**平行线分析（Parallel Line Analysis, PLA）** 或**四参数 Logistic（4PL）拟合**，计算供试品相对于参考品的**相对效价（Relative Potency, RP）**：

$$RP(\%) = \frac{EC_{50,\text{参考品}}}{EC_{50,\text{供试品}}} \times 100\%$$

### 放行判定标准

| 项目 | 典型标准 | 依据 |
|------|---------|------|
| 结合活性（相对结合效价） | **70%～130%** | 参考已上市同类产品；结合多批次数据 |

- **方法依据：** 根据产品特性制定，参考已上市药品的限度和 ICH Q6B 要求。
- **参考品管理：** 效能检测的可靠性高度依赖于**参考品（Reference Standard）** 的质量和稳定性，须建立主参考品（Primary RS）和工作参考品（Working RS）的两级管理体系。
- **与细胞活性的关系：** 结合活性（ELISA 法）属于**理化替代方法**，不能完全代替细胞活性（功能性效价）；两者须联合使用，覆盖产品作用机制的不同维度。

:::

## 效能检测二：细胞活性（Cell-based Potency）——作用机制关联、方法类型与验收标准

:::answer

### 为什么须检测细胞活性

细胞活性检测是唯一能够**直接模拟体内作用机制（MOA）** 的效能测定方法，是 ICH Q6B 和各国监管机构对生物制品效价测定的核心要求。ELISA 结合活性是理化替代方法，不能捕捉涉及下游信号通路、效应细胞招募等的生物学活性。

### 细胞活性方法的分类（依作用机制选择）

| 作用机制 | 适用细胞活性方法 | 典型产品举例 |
|---------|---------------|------------|
| 受体信号通路激活/抑制 | **报告基因法（Reporter Gene Assay, RGA）**（NFAT、NF-κB、JAK-STAT 等）| 抗 IL-6R/IL-6 mAb（托珠单抗、司妥昔单抗） |
| 抗体依赖性细胞毒性 | **ADCC 报告基因法**（FcγRIIIa 激活型） | 抗 CD20（利妥昔单抗）、抗 HER2（曲妥珠单抗） |
| 补体依赖性细胞毒性 | **CDC 法**（靶细胞裂解率） | 抗 CD20 mAb |
| 细胞增殖抑制 | **增殖抑制法（MTT/CCK8）** | 抗 EGFR（西妥昔单抗） |
| 受体配体阻断 | **竞争性结合法 / 阻断细胞活化** | 抗 PD-1/PD-L1（纳武利尤单抗） |

### 报告基因法的原理（以 ADCC RGA 为例）

```
靶细胞（表达靶抗原）+ 效应细胞（表达 FcγRIIIa 的 Jurkat 报告基因细胞）+ 待测抗体
  │
  ├─ 抗体 Fc 与 FcγRIIIa 结合 → NFAT 信号通路激活
  │
  ├─ 荧光素酶（Luciferase）表达
  │
  └─ 加入底物，读取发光值（RLU）→ 与参考品比较计算相对效价
```

**报告基因法的优势：** 高重现性、低变异系数（CV < 15%），适合高通量检测，已逐步取代原代 PBMC ADCC 法用于常规放行。

### 放行判定标准

| 项目 | 典型标准 |
|------|---------|
| 细胞活性（相对效价） | **70%～130%** |

- **方法依据：** 根据产品特性和 MOA 制定；参考已上市同类产品及 ICH Q6B。
- **变异系数要求：** 细胞活性方法的精密度（CV）通常须 < 25%（重复性），方法验证须证明方法的特异性和线性。

:::

## 工艺相关杂质一：Protein A 残留检测——ELISA 法原理与可接受限度

:::answer

### 为什么须检测 Protein A 残留

Protein A 亲和层析填料中的 Protein A 配基在生产过程中会少量脱落并混入产品，进入最终制剂中的残余 Protein A 具有潜在**免疫原性和毒性风险**（天然 Protein A 对人体具有促有丝分裂活性），须严格控制。

### 检测方法

**酶联免疫吸附法（ELISA）**：采用抗 Protein A 抗体作为检测抗体，通过三明治或竞争 ELISA 格式，对样品中残余 Protein A 进行定量。

| 方法要素 | 说明 |
|---------|------|
| 检测原理 | 抗 Protein A 抗体捕获，酶标二抗检测（三明治 ELISA） |
| 检测下限 | 通常 ≤ 1 ng/mL（须满足限度要求下的灵敏度） |
| 干扰因素 | 样品基质（缓冲液、制剂辅料）对 ELISA 信号的影响，须通过添加回收率实验验证 |

### 放行判定标准

- **可接受限度：** 蛋白 A 残留量 **≤ 蛋白质总量的 0.001%**（即 10 ppm）。
- **换算示例：** 若产品蛋白含量为 5 mg/mL，则 Protein A 残留须 ≤ 50 ng/mL。
- **法规依据：** 《中国药典》2020 版三部通则 3429 酶联免疫吸附法；参考中国药典收录的尼妥珠单抗注射液质量标准。

### 下游工艺对 Protein A 残留的控制

Protein A 是碱性蛋白（pI ≈ 5.1），在单抗纯化的下游精纯步骤（CEX、AEX）中可被有效去除。通常经过 2～3 步层析后，Protein A 残留可降至 ppm 级以下，满足放行要求。

:::

## 工艺相关杂质二：宿主细胞 DNA（HCD）残留检测——qPCR 原理与限度依据

:::answer

### 为什么须控制 HCD 残留

CHO 等宿主细胞的 DNA 混入最终产品存在以下潜在风险：
- **致癌性风险：** 若宿主细胞 DNA 中含有癌基因序列，理论上存在通过整合引发肿瘤的风险（虽然实际风险极低，但监管机构持预防原则）。
- **免疫刺激风险：** 大量外源 DNA 可激活先天免疫（Toll-like Receptor 9 等）。

### 检测方法：荧光定量 PCR（qPCR）

**qPCR 法** 通过特异性引物和探针扩增宿主细胞基因组 DNA，实时监测荧光信号：

```
提取样品中的 DNA
  │
  ├─ 加入针对宿主细胞（CHO）特异性引物和荧光探针
  │
  ├─ PCR 循环扩增（实时监测荧光信号）
  │
  ├─ 根据标准曲线计算 Ct 值对应的 DNA 拷贝数
  │
  └─ 换算为每剂量（每支/瓶）的 DNA 含量（pg）
```

**qPCR 的优势：** 灵敏度极高（检测下限可达 1～10 pg/mL），特异性强，且可实现绝对定量（结合数字 PCR, ddPCR）。

### 放行判定标准

- **可接受限度：** 每 1 支/瓶（每剂量）**≤ 100 pg**（残余宿主细胞 DNA）。
- **法规依据：** WHO 建议（TRS 878, 1998）和《中国药典》2020 版三部通则 3407 荧光定量 PCR 法。
- **科学依据：** 100 pg/剂量的限度来源于理论致癌风险模型计算，认为在此限度下通过 DNA 整合引发肿瘤的概率可接受（< 10⁻¹¹/剂量）。

:::

## 工艺相关杂质三：宿主细胞蛋白（HCP）残留检测——ELISA 法、覆盖率挑战与限度

:::answer

### HCP 的安全性风险

宿主细胞蛋白（Host Cell Protein, HCP）是在生产过程中由宿主细胞（CHO）产生并混入产品的内源性蛋白质混合物，其风险包括：
- **免疫原性：** 非人源蛋白可引发患者免疫反应，导致 ADA（抗药抗体）产生，甚至影响产品有效性。
- **产品降解：** 某些 HCP 具有蛋白酶活性，可在储存过程中降解目标蛋白，影响稳定性。
- **安全性担忧：** 特定 HCP（如 PLBL2、Cathepsin D）已被证实具有潜在毒性或免疫调节活性。

### 检测方法：多克隆 ELISA（Platform CHO-HCP ELISA）

标准方法采用**抗 CHO 细胞蛋白的多克隆抗体**（通常为兔抗 CHO-HCP 多抗）进行三明治 ELISA 定量：

| 方法要素 | 说明 |
|---------|------|
| 捕获抗体 | 多克隆抗 CHO-HCP 抗体（涂板） |
| 检测抗体 | 多克隆抗 CHO-HCP 抗体（酶标） |
| 覆盖率挑战 | 多抗试剂盒仅能识别免疫原中存在的 HCP，对低丰度 HCP 存在漏检风险 |
| 补充方法 | 质谱（LC-MS/MS）——无需抗体，可检测 ELISA 漏检的特定 HCP（如 PLBL2） |

### 放行判定标准

- **可接受限度：** HCP 残留量 **≤ 蛋白质总量的 0.01%**（即 100 ppm）。
- **换算示例：** 若产品蛋白含量为 5 mg/mL，则 HCP 须 ≤ 500 ng/mL。
- **法规依据：** 《中国药典》2020 版三部通则 3429 酶联免疫吸附法；尼妥珠单抗注射液质量标准。

### HCP 检测的行业趋势

- **质谱补充检测：** 监管机构（尤其 FDA）日益要求在申报文件中提供质谱 HCP 分析数据，鉴定高风险 HCP 的种类并评估其风险。
- **过程监控：** 在纯化中间体（Protein A 洗脱液、CEX 洗脱液等）阶段监控 HCP，用于工艺理解和控制策略建立。

:::

## 细胞库表征的分层要求：研发细胞库与 GMP 细胞库的差异化策略

:::answer

### 细胞库分层管理体系

生物药生产细胞株的管理通常采用**两级细胞库体系**：

```
主细胞库（MCB, Master Cell Bank）
  │── GMP 条件下建立和保存
  │── 须进行全面表征（一次性）
  │
  └─ 工作细胞库（WCB, Working Cell Bank）
        │── 从 MCB 扩增制备；GMP 条件下建立
        │── 每次建立新 WCB 须按规定项目检定
        │
        └─ 生产终末细胞（EOPC, End of Production Cells）
              │── 代表实际生产终点的细胞状态
              └── 须进行全面表征（至少一次）
```

### 不同阶段细胞库的表征要求差异

| 细胞库类型 | 建立条件 | 样品用途 | 表征深度 |
|-----------|---------|---------|---------|
| **研发细胞库** | 研发实验室 | 不用于人体试验 | **有限表征**（如支原体、无菌检测等安全性基本项） |
| **MCB** | GMP 条件 | 支持临床试验及商业化生产 | **全面表征**（14 项，见下） |
| **WCB** | GMP 条件 | 每批生产起始 | 按规定项目检定（可简化，参考 MCB 结果） |
| **EOPC** | 对应生产终点 | 表征生产末期细胞遗传稳定性 | **全面表征**（至少一次；工艺变更时重新检测） |

### MCB/WCB 全面表征的 14 项检测

| 序号 | 检测项目 | 目的 |
|------|---------|------|
| 01 | 细胞鉴别 | 确认为目标细胞株（非交叉污染） |
| 02 | 细菌真菌检查 | 排除细菌/真菌污染 |
| 03 | 分枝杆菌检查 | 排除结核分枝杆菌等污染 |
| 04 | 支原体检查 | 排除支原体污染（最常见的隐性污染） |
| 05 | 病毒因子检查—细胞形态观察及血吸附试验 | 检测可致细胞形态改变的病毒 |
| 06 | 病毒因子检查—体外不同指示细胞接种培养法 | 广谱外源病毒检测 |
| 07 | 病毒因子检查—动物体内接种法 | 检测动物传染性外源病毒 |
| 08 | 病毒因子检查—逆转录病毒及内源性病毒/病毒核酸 | CHO 细胞含有内源性逆转录病毒样颗粒，须评估 |
| 09 | 病毒因子检查—种属特异性外源病毒 | 针对 CHO 来源（中国仓鼠）的特异性病毒 |
| 10 | 病毒因子检查—牛源性病毒 | 因生产过程可能接触牛血清等牛源材料 |

## QbD 理念下的工艺开发框架：从 CQA 识别到控制策略建立

:::answer

### 传统工艺开发 vs. QbD 工艺开发

| 维度 | 传统方法（"一致工艺"模式） | QbD 方法（质量源于设计） |
|------|------------------------|----------------------|
| 核心理念 | "如果操作过程一致，产品应该一致" | 系统理解工艺参数与产品质量的因果关系 |
| 工艺参数 | 固定在窄范围内操作 | 建立合理的设计空间（Design Space） |
| 质量保证方式 | 依赖终产品检测 | 工艺理解 + 过程控制 + 终产品检测 |
| 工艺变更 | 须重新验证 | 设计空间内变更可不经监管申报 |
| 灵活性 | 低 | 高 |

### QbD 工艺开发的核心步骤

```
Step 1：确定目标产品质量概况（QTPP）
  目标：明确产品的预期适应症、给药途径、剂量、稳定性等总体要求
      ↓
Step 2：识别关键质量属性（CQA）
  工具：风险评估（FMEA、鱼骨图）+ 文献/平台经验
      ↓
Step 3：识别关键工艺参数（CPP）和关键物料属性（CMA）
  方法：风险评估 → 初步筛选潜在关键参数
      ↓
Step 4：建立工艺设计空间（Design Space）
  实验：DOE（多参数实验设计）确定 CPP 的可接受范围（上下限）
  模型：建立 CPP-CQA 量化关系模型
      ↓
Step 5：建立控制策略（Control Strategy）
  内容：CPP 的操作范围和监控频率；IPQC 项目；放行标准
      ↓
Step 6：工艺验证（Process Validation）
  证明：在设计空间内，工艺可持续生产出符合 CQA 的产品
      ↓
Step 7：持续工艺确认（Continued Process Verification, CPV）
  目标：商业化生产中实时监控工艺状态，及时识别工艺漂移
```

### 早期分子可开发性评估（Developability Assessment）

在细胞株开发前，须对候选分子进行 CMC 风险评估，综合评估以下维度：

| 评估维度 | 关键指标 | 评估目的 |
|---------|---------|---------|
| 细胞株表达 | 表达量（Titer）；生长特性 | 判断生产可行性 |
| 上游工艺 | 培养稳定性；聚集体水平；糖型分布 | 识别上游质量风险 |
| 下游工艺 | 可纯化性（pI、疏水性）；杂质去除难度 | 评估纯化成本和风险 |
| 分析方法 | CQA 的可检测性 | 确认分析方法可及性 |
| 稳定性 | 加速稳定性（热应力、振荡、冻融） | 预测长期稳定性风险 |

> **关键判断逻辑：** 上游表达的聚集体水平较高，若下游工艺可将其去除至目标水平，该分子仍可进入后续开发；但若聚集体在下游无法有效去除，须考虑在分子设计阶段解决（序列改造或赋形剂优化）。

:::

## DNA 水平遗传稳定性分析：拷贝数、整合位点与序列变异的检测技术

:::answer

### 遗传稳定性的监管要求

生产细胞株的**遗传稳定性（Genetic Stability）** 是保证批间产品一致性的基础。ICH Q5B 要求对表达载体和细胞株进行全面分析，ICH Q5D 对细胞库的表征和测试提出具体要求。

DNA 水平遗传稳定性分析主要包含三个维度：

### 维度一：外源基因拷贝数（Copy Number）

| 方法 | 原理 | 优势 | 局限性 |
|------|------|------|-------|
| **qPCR（相对定量）** | 以内参基因（如 GAPDH）为参照，比较外源基因的相对拷贝数 | 快速、高通量、成本低 | 依赖参比品和参照基因；扩增效率差异影响准确性 |
| **ddPCR（数字 PCR，绝对定量）** | 将 DNA 模板分隔成单分子液滴，直接计数阳性液滴，经泊松分布计算绝对拷贝数 | **不依赖标准曲线和参照样本；精确绝对定量** | 成本较高；通量相对较低 |

> **ddPCR 的核心优势：** 通过分隔出单个模板分子的 PCR 扩增，直接读取阳性和阴性信号计数，通过泊松分布转换得到目标基因的**绝对拷贝数**，是拷贝数精确定量的首选方法。

### 维度二：整合位点（Integration Site）

- **荧光原位杂交技术（FISH）：** 利用荧光标记的 DNA 探针与染色体上的目的基因杂交，在荧光显微镜下直接观察目的基因在染色体上的**整合位置和拷贝数分布**。
- **下一代测序（NGS，整合位点测序）：** 通过靶向测序（如 LAM-PCR + NGS）精确鉴定整合位点的染色体坐标，适合早期细胞株筛选阶段的系统表征。

### 维度三：序列完整性和变异（Sequence Integrity）

- **测序分析：** 对目的基因进行桑格测序（Sanger）或 NGS 深度测序，确认序列与设计完全一致，排除点突变、缺失、插入等序列变异。
- **早期筛查的价值：** 研究发现，在细胞株开发早期对扩增子进行测序，可**发现并排除序列变异克隆**。在 4 个临床项目中的实践证明，此策略安全地加快了研发进度，避免了携带序列变异的克隆进入后续开发阶段。

### 遗传稳定性检测的时间节点

| 检测时机 | 检测内容 | 目的 |
|---------|---------|------|
| **MCB 建立时** | 全面遗传分析（拷贝数、整合位点、序列） | 建立基线数据 |
| **WCB 建立时** | 序列验证（至少确认目的基因序列） | 传代未引入突变 |
| **EOPC（生产终末细胞）** | 拷贝数稳定性 + 序列验证 | 证明生产全程遗传稳定 |
| **传代稳定性研究** | 不同代次的表达量和质量趋势 | 支持细胞库使用寿命声明 |

:::
