## 乳酸浓度的合理控制范围与代谢模式判断

:::answer

乳酸（Lactic Acid）是细胞糖酵解的主要代谢副产物，其在培养液中的积累水平和变化趋势是评估细胞代谢健康状态和工艺稳健性的核心过程指标。

### 两种代谢模式与控制标准

**① 乳酸消耗型（理想模式）**

| 参数 | 描述 |
|-----|-----|
| **代谢特征** | 培养前期（生长期）产生乳酸，培养中后期（通常第 8～10 天）细胞转换代谢方式，开始消耗乳酸 |
| **收获时乳酸浓度** | 通常 **< 1 g/L**，多数情况下接近 0 g/L |
| **工程优势** | 工艺稳健性好，pH 控制容易，易于放大至生产规模，批间一致性高 |
| **代谢切换机制** | 细胞在葡萄糖充足时偏向有氧糖酵解产乳酸（Warburg 效应），葡萄糖受限或工艺优化后转向 TCA 循环消耗乳酸 |

**② 乳酸积累型（需评估管理）**

| 参数 | 描述 |
|-----|-----|
| **代谢特征** | 培养全程乳酸浓度持续上升，无明显消耗阶段 |
| **可接受控制范围** | 培养后期乳酸浓度 **< 2 g/L**，认为风险较低 |
| **超出 2 g/L 的影响** | pH 持续下降 → 须消耗大量碱（NaOH）中和 → 渗透压升高 → 细胞活力下降 → 产量和质量风险升高 |

### 乳酸积累的工艺影响与决策逻辑

在克隆筛选阶段，不应仅因乳酸积累问题排除高产量/优质量的克隆，**应综合评估**：

| 评估因素 | 权重建议 |
|---------|---------|
| 产物表达量（滴度） | 高权重（商业可行性决定因素） |
| 产品质量属性（CQA） | 高权重（安全性/有效性核心） |
| 乳酸积累水平 | 中权重（可通过培养基和工艺优化改善） |

**改善乳酸积累的上游调控手段：**
- **葡萄糖控制策略：** 降低培养基中葡萄糖浓度或采用反馈控制补料，维持低葡萄糖浓度（< 5 mM）迫使细胞更多地利用氧化磷酸化
- **培养基优化：** 添加半乳糖替代葡萄糖（半乳糖代谢速率慢，产乳酸少）；补充谷氨酰胺类似物（如谷氨酰胺二肽）减少氨和乳酸的协同积累
- **温度偏移：** 培养后期降温（如 37°C → 33°C）可减缓糖酵解速率，促进线粒体代谢
- **CO₂ 控制：** 高 pCO₂ 会抑制乳酸消耗，须通过通气策略及时吹扫 CO₂

### 乳酸检测方法

生产过程中通常采用在线或离线生化分析仪（如 Bioprofile FLEX、Nova BioProfile）实时监测乳酸浓度，检测频率通常为每 12～24 小时一次，作为标准中间体过程控制（IPC）指标。

## 氨浓度的合理控制范围与对细胞培养的多维影响

:::answer

氨（NH₃/NH₄⁺）是细胞培养中谷氨酰胺代谢和氨基酸分解代谢的主要副产物，在培养液中随时间积累，是仅次于乳酸的第二大代谢毒性物质。

### 控制范围

**推荐控制上限：通常 ≤ 10 mM（Case by Case，须结合具体细胞系和工艺数据确定）**

### 文献报道的关键毒性阈值

| 研究来源 | 氨浓度 | 观察到的效应 |
|---------|-------|-----------|
| Kurano 等 | 8 mM | CHO 细胞**比生长速率下降 80%**（严重抑制增殖） |
| Hansen 等 | 8 mM | 目标产物（tPA）**比生产速率（qP）下降** |
| Borys 等 | — | CHO 细胞表达的抗体**糖基化受氨浓度影响**（糖型谱改变） |

### 氨对细胞培养的三重负面影响

**① 抑制细胞生长**

- 氨通过干扰 TCA 循环（抑制 α-酮戊二酸脱氢酶）和影响氨基酸代谢，导致细胞能量代谢障碍
- 高浓度氨（> 10 mM）诱导细胞周期停滞（G₁期阻滞）和细胞凋亡

**② 降低产品产量**

- 细胞生长受抑 → 有效生产细胞数量减少 → 单位体积产量（g/L）下降
- 高氨环境下细胞的比生产速率（qP）也可能降低

**③ 影响产品糖基化质量**

- 氨浓度升高影响高尔基体腔内 pH（氨为弱碱，穿透细胞膜进入细胞器），干扰 pH 依赖性糖基化酶的活性
- 可观察到的糖型变化：半乳糖化程度降低、唾液酸化程度改变、高甘露糖型比例波动

### 氨积累的控制策略

| 策略 | 原理 |
|-----|-----|
| **降低谷氨酰胺浓度** | 谷氨酰胺是氨的最大产生来源，降低初始浓度或采用分次补料可减少氨积累 |
| **使用谷氨酰胺二肽（Ala-Gln）** | 二肽形式在细胞外稳定，进入细胞后缓慢释放谷氨酰胺，减少胞外氨积累 |
| **优化补料策略** | 减少过量氨基酸的补加，避免氨基酸过剩引发分解代谢产氨 |
| **pH 控制精细化** | 维持培养液 pH 在设定范围内，避免碱性偏移促进氨的非离子化（NH₄⁺ ⇌ NH₃），NH₃ 渗透性更强，毒性更大 |

:::

## 常见 N 糖糖型的种类、控制范围与检测要求

:::answer

单克隆抗体 N 糖基化谱（Glycan Profile）是重要的 CQA，须在整个产品生命周期中系统监控。四种核心糖型修饰的控制范围基于 A-Mab 案例研究（行业参考值），具体产品须结合临床和工艺数据确定。

### 四种核心糖型控制范围汇总

| 糖型 | 控制范围参考值 | 对活性的主要影响 | 主要调控手段 |
|-----|------------|--------------|-----------|
| **岩藻糖化（Fucosylation）** | 2%～13%（去岩藻糖化比例） | 核心岩藻糖是 ADCC 活性的决定因素（去岩藻糖化 → ADCC ↑↑） | 渗透压、Mn²⁺；FUT8 细胞株工程 |
| **半乳糖化（Galactosylation）** | 10%～40% | 半乳糖化增加 → CDC ↑；与 ADCC 协同 | 添加微量 Mn²⁺（1～10 μM）；低温培养；延长培养时间 |
| **唾液酸化（Sialylation）** | 0%～2% | ADCC ↓；抗炎活性 ↑；增加负电荷（pI 降低） | CHO 细胞天然唾液酸化水平低，通常不需主动抑制 |
| **高甘露糖（High Mannose，Man5+）** | 0%～10%（通常 3%～10%） | 甘露糖受体介导加速清除（PK 影响）；ADCC 活性降低 | 保持充足 DO；优化温度和培养周期 |

### 糖型检测的主流方法

| 检测方法 | 原理 | 适用场景 |
|---------|-----|---------|
| **荧光标记 N 糖谱分析（HILIC-FLD）** | 用 2-AB（2-氨基苯甲酰胺）或 InstantAB 荧光标记释放的 N 糖，经亲水作用色谱（HILIC）分离后荧光检测 | 批放行糖型定量；稳定性研究 |
| **质谱（LC-MS/MS）** | 直接检测糖肽或完整 N 糖的分子量，精确鉴定糖型结构 | 糖型鉴定；异常糖型结构解析 |
| **毛细管电泳（CE-LIF）** | 荧光标记 N 糖后经毛细管电泳分离，激光诱导荧光检测 | 高通量筛选；部分批放行应用 |

### 批间糖型一致性的管理要求

- 须在稳定性研究中监测糖型随时间的变化趋势
- 工艺变更（如培养基批次变更、温度偏移策略调整）须评估对糖型谱的影响
- 商业化生产阶段须通过持续工艺验证（CPV）建立糖型批间变异的历史统计基准

:::

## 基因拷贝数的定义、检测方法与稳定性风险

:::answer

基因拷贝数（Gene Copy Number，GCN）是衡量外源目的基因在宿主细胞基因组中整合数量的关键参数，是细胞株遗传稳定性研究和细胞库表征的重要内容。

### 定义

基因拷贝数指某一特定基因或 DNA 序列在**单倍体基因组**中出现的数目。对于 CHO 细胞（二倍体），测定值通常以每个细胞的拷贝数表示。

### 检测方法

| 方法 | 原理 | 优势 | 局限性 |
|-----|-----|-----|-------|
| **Southern Blot** | 限制性内切酶消化基因组 DNA，电泳分离后转膜，与标记探针杂交 | 金标准方法，可同时分析整合位点模式 | 操作复杂；周期长；半定量 |
| **荧光定量 PCR（qPCR）** | 实时 PCR 扩增目的基因片段，以内参基因（单拷贝基因）为参照计算相对拷贝数 | 灵敏、快速、高通量；适合常规检测 | 须设计高特异性引物/探针；须有可靠内参 |
| **数字 PCR（ddPCR）** | 将样品分割为数万个微液滴，每液滴中进行单分子 PCR，直接计数阳性液滴数 | **绝对定量**，无需标准曲线；准确度最高 | 设备成本高；通量相对较低 |

### 拷贝数丢失（Gene Copy Loss）的原因与风险

基因拷贝数丢失是细胞株遗传不稳定性的重要体现，主要原因包括：

| 原因 | 机制 |
|-----|-----|
| **整合位点不稳定性** | 外源基因整合在基因组异染色质区或不稳定区域，易发生重排或缺失 |
| **选择压力撤除** | 使用药物筛选（MTX/MSX）建库后，一旦撤除选择压力，部分高拷贝细胞因维持额外拷贝的代谢负担而被低拷贝细胞超越 |
| **外源基因重组** | 多拷贝整合中，同源序列之间发生同源重组，导致拷贝数减少 |
| **传代过程中的随机丢失** | 长期传代过程中，自发的染色体重排可能影响整合位点完整性 |

**实践含义：** 细胞株稳定性研究须在最高限定代次（EOPC）时检测拷贝数，与 MCB 建库时的拷贝数进行比较，确认传代过程中拷贝数无显著变化（通常要求变化 < 30%）。

:::

## GMP 细胞库表征的检定项目体系

:::answer

GMP 细胞库（MCB 和 WCB）的检定是保证生物制品安全性的基础，须按照各国药典和指导原则的规定系统开展，不同监管市场的具体要求存在差异。

### 各国法规适用性

| 申报市场 | 适用法规依据 |
|---------|-----------|
| **中国（NMPA）** | 《中国药典》三部"生物制品生产检定用动物细胞基质制备和检定规程" |
| **美国（FDA）** | USP ⟨1050⟩（病毒安全性）、ICH Q5A/Q5D、21 CFR 相关要求 |
| **欧盟（EMA）** | EudraLex Volume 4 Annex 2、ICH Q5A/Q5D |

### GMP 细胞库表征核心检定项目

**① 细胞鉴别试验（Identity Testing）**

| 方法 | 检定内容 |
|-----|---------|
| STR（短串联重复序列）基因型分析 | 确认细胞系身份，排除细胞交叉污染 |
| 同工酶分析（Isoenzyme Analysis） | 确认物种来源（CHO 细胞的特征酶谱） |
| 核型分析（Karyotyping） | 评估染色体数目和结构的稳定性 |
| 目的基因测序 | 确认表达构建体的序列完整性（与 ICH Q5B 要求一致） |

**② 无菌检查（微生物安全性）**

- 细菌检查（需氧和厌氧条件）
- 真菌检查
- 分枝杆菌（Mycobacteria）检测

**③ 支原体检查**

- 培养法（周期约 28 天）+ 荧光染色法并行（药典双法要求）
- 可辅以 PCR 法（须经方法验证，作为补充）

**④ 内源性病毒因子检查**

- 逆转录病毒检测（透射电镜、逆转录酶活性检测、感染性测定）
- 特别针对 CHO 细胞：检测鼠白血病病毒相关序列（MLVS）

**⑤ 外源性病毒因子检查**

- 体内法：多种动物模型（乳鼠、豚鼠、兔子等）接种
- 体外法：多种指示细胞系（Vero、MRC-5 等）培养观察
- 特定病毒 PCR（针对猪源病毒 PPV、PCV；牛源病毒 BVDV 等）

**⑥ 成瘤性和致瘤性检查**

- 成瘤性（Tumorigenicity）：裸鼠皮下注射试验，观察肿瘤形成
- 致瘤性（Oncogenicity）：细胞 DNA 的转化能力检测

### 不同细胞库类型的检定要求差异

| 细胞库类型 | 检定深度 | 法规要求 |
|----------|---------|---------|
| RCB / PCB | 有限检定（支原体 + 无菌） | 非 GMP 阶段，最低要求 |
| **MCB** | **全面检定（一次性）** | GMP 建库后须完成 |
| **WCB** | **按规定项目检定（每次新建）** | 每次从 MCB 建立新 WCB 均须检定 |
| **EOPC** | **全面检定（至少一次）** | 工艺变更后须重新检定 |

:::

## 片段与聚体的检测方法：CE-SDS 与 SEC 的选择原则

:::answer

片段（Fragments）和聚体（Aggregates）是单抗制品中最重要的产品相关杂质，须采用互补的分析方法进行定量检测。

### 检测方法矩阵

| 杂质类型 | 推荐方法 | 备用方法 | 检测原理 |
|---------|---------|---------|---------|
| **片段（Fragments）** | **CE-SDS（NR 模式）** | SDS-PAGE（非还原） | 基于分子量大小的电泳分离；片段分子量小于完整抗体 |
| **聚体（Aggregates）** | **SEC-HPLC** | SDS-PAGE（非还原） | 基于分子大小的色谱分离；聚体分子量大于单体 |

### 两种方法的互补性

**CE-SDS 的优势：**
- 检测灵敏度高，可检出 < 1% 的低分子量变体（LMW）
- 可区分轻链（LC）、重链（HC）、半抗体（HL）等具体片段种类（还原模式）
- 自动化程度高，批间重现性好

**SEC-HPLC 的优势：**
- 在天然非变性条件下检测，反映蛋白质的真实聚合状态
- 可区分单体、二聚体和高聚体（基于保留时间）
- 定量准确，与光散射（MALS）联用可获得分子量信息

**SDS-PAGE 的局限性（作为参考）：**
- 半定量方法，检测灵敏度低于 CE-SDS 和 SEC-HPLC
- 消耗样品量大；银染法需 ≥ 5 μg，考马斯蓝法需 ≥ 10 μg
- 操作复杂，批间重现性相对较低
- 通常作为 CE-SDS 和 SEC-HPLC 的补充验证，不单独用于批放行

### 检测结果解读要点

- **SEC-HPLC 结果：** 主峰（单体）出峰时间晚，聚体先出峰（大分子被排阻，在多孔凝胶中停留时间短）；面积归一化后报告各峰百分比
- **CE-SDS（NR 模式）结果：** 轻链（LC）分子量最小，最先迁移；完整抗体（主峰）最后迁移；结果以主峰面积百分比报告产品纯度

:::

## 电荷异质性的表征方法：IEF 与 IEX 的原理与应用

:::answer

单克隆抗体的电荷异质性（Charge Heterogeneity）表征是产品质量属性分析的核心内容，须通过至少一种主要分析方法进行系统表征，并在批放行中纳入监控。

### 两大主流表征方法

**① 等电聚焦电泳（Isoelectric Focusing，IEF）及其衍生技术**

| 技术形式 | 检测原理 | 特点 |
|---------|---------|-----|
| 凝胶 IEF | 蛋白质在 pH 梯度凝胶中迁移，至净电荷为零（等电点）时停止 | 半定量；可目测 pI 值；分辨率中等 |
| **cIEF（毛细管等电聚焦）** | 毛细管中建立 pH 梯度，蛋白质聚焦后整体推动至检测窗口，UV 280 nm 检测 | 高分辨率；定量；给出 pI 分布 |
| **icIEF（成像 cIEF）** | cIEF 的升级版，全程 CCD 成像记录聚焦过程 | 最高通量；无需推动步骤；自动化程度最高 |

**② 离子交换层析（Ion Exchange Chromatography，IEX）**

| 技术形式 | 适用条件 | 峰出现顺序 |
|---------|---------|---------|
| **CEX-HPLC（阳离子交换，最常用）** | 单抗 pI 通常 > 7，在中性 pH 下带正电，与 CEX 填料结合；适合大多数 IgG | 酸性峰（pI 低，保留时间短）→ 主峰 → 碱性峰（pI 高，保留时间长） |
| **AEX-HPLC（阴离子交换）** | 与 CEX 互补；pI 偏低的蛋白质（如某些抗体片段）适用 | 碱性峰先洗脱 → 主峰 → 酸性峰 |

### 酸性/碱性变体在不同方法中的行为汇总

| 变体类型 | IEF 位置 | CEX-HPLC 位置 | AEX-HPLC 位置 |
|---------|---------|-------------|-------------|
| 酸性变体 | pI 低于主峰，位于低 pH 侧 | 早于主峰出峰（保留弱） | 晚于主峰出峰（保留强） |
| 主峰 | 中间位置 | 中间位置 | 中间位置 |
| 碱性变体 | pI 高于主峰，位于高 pH 侧 | 晚于主峰出峰（保留强） | 早于主峰出峰（保留弱） |

### 进阶分析：电荷变体结构鉴定

当批次间或批次内的电荷异质性谱发生变化时，须进行结构根因分析：

- **肽图（Peptide Mapping）+ LC-MS/MS：** 精确定位化学修饰（去酰胺化、氧化、糖化等）在序列中的位置
- **酶处理 + 色谱分析：** PNGase F 去除 N 糖后分析，区分糖基化引起的电荷变化与其他修饰

:::

## Protein A-HPLC（PA-HPLC）测定上清液滴度的原理与流程

:::answer

基于 Protein A 亲和色谱的 HPLC 方法（PA-HPLC）是细胞培养上清液中抗体浓度（Titer）测定的行业标准方法，兼具高特异性、高灵敏度和快速定量的优点。

### 检测原理

**核心利用金黄色葡萄球菌 Protein A 与 IgG Fc 区的高度特异性结合：**
```
上清液加载至 Protein A 色谱柱
        ↓
IgG 与 Protein A 特异性结合 → 吸附在柱上
杂质（HCP、培养基成分等）→ 流穿或被洗涤去除
        ↓
强酸性缓冲液洗脱（pH 3.0～3.4）
        ↓
紫外吸光度检测（280 nm）
        ↓
以已知浓度标准品建立标准曲线
        ↓
根据消光系数（Extinction Coefficient）换算 Titer 值
```

### 关键参数与注意事项

| 参数 | 说明 |
|-----|-----|
| **消光系数（ε₂₈₀）** | 不同抗体的 ε₂₈₀ 不同（通常 1.3～1.7 AU·mL/mg·cm），须根据氨基酸序列计算或实验测定 |
| **标准品选择** | 通常使用与待测样品同类型的参比抗体（Reference Standard），或使用氨基酸分析法校正的浓度标准品 |
| **线性范围** | 须在方法验证中确定，避免在线性范围外检测导致系统误差 |
| **洗脱液中性化** | 洗脱液 pH 约 3.0，须立即中和，避免蛋白在低 pH 下长时间暴露导致检测误差 |

### PA-HPLC 与其他 Titer 检测方法的比较

| 方法 | 原理 | 特点 | 适用场景 |
|-----|-----|-----|---------|
| **PA-HPLC** | Protein A 亲和色谱 + UV 检测 | 高特异性；定量准确；可批量检测 | 批放行；工艺监控 |
| **BCA/Bradford 法** | 总蛋白定量 | 非特异性（检测所有蛋白）；操作简便 | 样品预筛；非 GMP 环境 |
| **ELISA（抗体特异性）** | 免疫亲和检测 | 高灵敏度；可检测极低浓度 | 极低 Titer 样品；特异性要求高场景 |
| **BLI/SPR（生物层干涉/表面等离子体共振）** | 实时分子相互作用检测 | 快速；无需标记；可同时测定亲和力 | 高通量筛选；QC 过程监控 |

:::

## SEC-HPLC 的检测原理、方法要点与结果解读

:::answer

尺寸排阻色谱（Size Exclusion Chromatography，SEC）/ 分子排阻液相色谱法（SE-HPLC）是单抗制品聚体含量检测和单体纯度评估的最重要分析方法，也是批放行的必检项目。

### 检测原理

**以多孔性凝胶为固定相，依据分子流体力学体积（Hydrodynamic Volume）进行分离：**

| 分子类型 | 行为 | 洗脱顺序 |
|---------|-----|---------|
| **聚体（大分子，HMW）** | 分子尺寸超过凝胶孔径，被排阻，沿凝胶粒子外部空隙（死体积）快速通过 | **先洗脱** |
| **单体（目标产品，~150 kDa）** | 部分进入凝胶孔洞，停留时间中等 | **中间洗脱** |
| **片段（低分子量，LMW）** | 充分渗透入凝胶孔洞，保留时间最长 | **最后洗脱** |

### 方法开发关键要点

| 参数 | 优化原则 |
|-----|---------|
| **色谱柱选择** | 须选择合适的分子量分离范围（通常 10 kDa～1,000 kDa 覆盖范围）；常用柱型：TSKgel G3000SWXL、Tosoh G3000SW、Superdex 200 |
| **流动相** | 高盐磷酸盐缓冲液（通常 100～200 mM 磷酸钠 + 100 mM 硫酸钠，pH 6.8～7.0），高离子强度可抑制蛋白与填料的非特异性相互作用 |
| **流速** | 通常 0.5～1.0 mL/min（须在分辨率和运行时间之间平衡） |
| **检测波长** | 280 nm（蛋白质主要吸收波长） |
| **上样量** | 通常 50～200 μg（须在线性范围内） |
| **系统适用性** | 每次运行须通过系统适用性测试（SST）：分辨率、理论塔板数、拖尾因子须符合规定 |

### 结果解读与报告方式

- **面积归一化法：** 各峰面积 / 总峰面积 × 100% = 各组分百分比
- **典型报告指标：** 单体（Monomer）%、聚体（HMW）%、片段（LMW）%
- **放行标准示例：** 单体纯度 ≥ 95%，聚体 ≤ 5%（具体须基于产品 CQA 评估确定）

:::

## CEX-HPLC 的检测原理、洗脱模式与结果解读

:::answer

阳离子交换色谱（CEX-HPLC）是单克隆抗体电荷异质性检测的核心分析方法，通过高分辨率分离酸性变体、主峰和碱性变体，反映产品电荷分布的均一性。

### 检测原理

**基于蛋白质表面净电荷差异进行分离：**

- 在特定 pH 条件下（低于抗体 pI，通常 pH 4.5～6.5），单克隆抗体（pI 通常 > 8）带正电荷，与阳离子交换填料的负电荷配基（磺酸基 −SO₃⁻）发生静电结合
- 带电量不同的蛋白质（电荷变体）与填料的亲和力不同，通过改变离子强度（盐梯度）或 pH，按亲和力从小到大依次洗脱

### 两种洗脱方式的选择

| 洗脱方式 | 适用场景 | 缓冲液体系 | 优缺点 |
|---------|---------|---------|-------|
| **盐梯度洗脱（NaCl 梯度）** | 项目前期（未知目标 pI）；方法开发初期 | 常用 pH 6.5 的 MES 缓冲液 + NaCl 梯度 | 操作简单；对不同 pI 的蛋白质通用性好；但分辨率通常低于 pH 梯度 |
| **pH 梯度洗脱（最常用）** | 项目中后期；批放行方法 | 多种 pH 缓冲液组合形成 pH 梯度（通常从 pH 5.5 至 pH 9.0） | **分辨率更高**；峰形更好；对电荷变体区分能力强；须精确配制和质控缓冲液 |

### 典型 CEX 色谱图解读
```
↑ UV 280 nm 信号
|
|        酸性峰群          主峰           碱性峰群
|      (Acidic Peaks)   (Main Peak)    (Basic Peaks)
|    ___/\___           ___/\___         __/\__
|___/        \___________/       \_______/      \___
                                                   → 时间（分钟）
```

- **酸性变体**（先洗脱）：包含去酰胺化产物（Asn→Asp）、唾液酸化变体、糖化产物等
- **主峰**（中间洗脱）：产品主要组分，代表目标抗体
- **碱性变体**（后洗脱）：包含 C 末端 Lys 保留、N 末端 pyrGlu 未形成等变体

### CEX 方法在工艺开发中的应用

- **克隆筛选：** 比较不同克隆的电荷变体分布，选择电荷均一性好的克隆
- **工艺优化：** 评估 pH、温度、培养时间等工艺参数对电荷变体比例的影响
- **稳定性研究：** 监测电荷变体随储存时间的变化趋势（特别是酸性峰的增长）
- **可比性研究：** 工艺变更前后的电荷谱比较，判断变更对产品质量的影响

:::

## CE-SDS（NR 与 R 模式）的检测原理与结果解读

:::answer

毛细管凝胶电泳（Capillary Electrophoresis-Sodium Dodecyl Sulfate，CE-SDS）是替代传统 SDS-PAGE 进行蛋白质纯度和片段分析的自动化高精度方法，分为非还原（NR）和还原（R）两种模式，提供互补信息。

### 检测原理

**CE-SDS 的核心分离机制：**

- SDS（十二烷基硫酸钠）与蛋白质结合，使蛋白质变性并赋予均一的负电荷（按质量计），消除蛋白质自身电荷差异
- 在高压直流电场（通常 15～30 kV）驱动下，蛋白质在毛细管中的填充凝胶（分子筛）中按**分子量大小**迁移分离
- 分子量小的片段迁移速度快（先检测到），分子量大的聚体迁移速度慢（后检测到）

### NR 模式（非还原，Non-Reducing，NR-CE-SDS）

**样品处理：** 不添加还原剂，保留分子内二硫键，检测抗体的天然组装形式。

**典型峰型与成分（按迁移顺序，从快到慢）：**

| 峰名称 | 对应成分 | 说明 |
|-------|---------|-----|
| LMW 峰群 | 低分子量片段（如 LC 游离、Fab 片段等） | 聚合物的降解产物 |
| HC 峰 | 游离重链 | 通常极少量 |
| HL 峰 | 半抗体（一条重链 + 一条轻链） | 分子量约 75 kDa |
| HHL 峰 | 2/3 抗体（两条重链 + 一条轻链） | 分子量约 125 kDa |
| **主峰（mAb 峰）** | **完整抗体（主要成分）** | 分子量约 150 kDa，即产品纯度 |
| HMW 峰 | 聚体 | 分子量 > 150 kDa |

**结果报告：** 采用面积归一法，主峰面积 / 总峰面积 × 100% = 产品纯度；HHL 和其余片段归入 LMW 计算。

### R 模式（还原，Reducing，R-CE-SDS）

**样品处理：** 添加二硫苏糖醇（DTT）或 β-巯基乙醇，打断所有二硫键，将抗体拆解为独立的轻链（LC）和重链（HC）。

**典型峰型（按迁移顺序）：**

| 峰名称 | 对应成分 | 分子量（约） |
|-------|---------|-----------|
| LC 峰 | 轻链（Light Chain） | ~25 kDa |
| NGHC 峰 | 去糖基化重链（Non-glycosylated HC） | ~50 kDa |
| HC 峰 | 糖基化重链（Heavy Chain，含 N 糖） | ~55 kDa |

**结果报告：** 轻链（LC%）、NGHC%（去糖基化重链）、HC%（糖基化重链），三者比例反映产品链组成的均一性；LC：HC 的理想比例约为 1:1（IgG 型抗体）。

### NR 与 R 模式的互补应用

| 信息类型 | NR 模式 | R 模式 |
|---------|--------|-------|
| 产品纯度（完整抗体） | ✅ 直接检测 | — |
| 片段和聚体检测 | ✅ 检测 | — |
| 轻重链比例 | — | ✅ 检测 |
| 去糖基化重链比例 | — | ✅ 检测（反映糖基化效率） |
| 与传统 SDS-PAGE 比较 | 灵敏度高约 10 倍；重现性优；自动化 | 同上 |

:::

## 唾液酸检测原理：DMB 衍生化荧光 HPLC 法

:::answer

唾液酸（Sialic Acid，SA）是抗体 N 糖末端修饰的重要组成部分，其定量检测采用反相 HPLC-荧光法（RP-HPLC-FLD），以 1,2-二氨基-4,5-亚甲二氧基苯（DMB）为荧光衍生化试剂。

### 唾液酸的化学基础

唾液酸（Sialic Acid）是一类含 9 个碳原子的酸性氨基糖，具有吡喃糖环结构，最主要的两种形式为：

| 形式 | 缩写 | 结构特征 | 在单抗中的意义 |
|-----|-----|---------|------------|
| **N-乙酰神经氨酸（5 位连乙酰基）** | NANA / Neu5Ac | 最常见的唾液酸形式 | CHO 细胞产生的主要唾液酸形式 |
| **N-羟乙酰神经氨酸（5 位乙酰基发生羟基化）** | NGNA / Neu5Gc | NANA 的羟基化衍生物 | CHO 细胞可产生少量 NGNA；具有免疫原性风险（人体对 NGNA 存在天然抗体） |

### DMB 衍生化荧光检测原理

**衍生化反应机制：**

1. 在酸性水解条件下，将 N 糖末端的唾液酸从糖链上释放（通常用 2 M 乙酸，80°C，3 小时）
2. 释放的唾液酸与 DMB（1,2-二氨基-4,5-亚甲二氧基苯）在酸性条件下发生**柱前衍生反应**
3. DMB 与唾液酸的羰基反应，导致唾液酸吡喃糖环开环，形成具有荧光特性的喹喔啉衍生物
4. 衍生物的荧光激发/发射波长与 DMB 本身不同，大幅降低背景干扰

**检测灵敏度优势：** 该方法**高度灵敏和特异**，可检测到痕量唾液酸（ng 级别），适合单抗中低水平唾液酸（0%～2%）的精确定量。

### 检测流程
```
样品（含 N 糖唾液酸的单抗）
        ↓
酸性水解（2 M 乙酸，80°C，3 h）
        ↓
DMB 衍生化（50°C，2.5 h）
        ↓
RP-HPLC 分离（C18 柱，乙腈-水梯度洗脱）
        ↓
荧光检测器（Ex 373 nm / Em 448 nm）
        ↓
以 NANA 和 NGNA 外标定量
        ↓
报告 NANA%、NGNA%（及 NANA/NGNA 比值）
```

### NGNA 的特殊监管关注

- 人体对 NGNA 存在天然的 IgG 抗体，NGNA 修饰的单抗可能触发免疫反应
- 须监控批次间 NGNA 的水平，通常要求 NGNA 含量尽量低（< 1%）
- 不同培养基配方和细胞株的 NGNA 产生水平不同，须在工艺开发初期评估

:::

## 细胞库生长特性表征的核心检定内容

:::answer

细胞库表征（Cell Bank Characterization）不仅包括安全性检定（病毒/微生物），还须对细胞的生物学特性进行全面评估，以证明细胞库的均一性、遗传稳定性和生产适用性。

### 生长特性表征

| 检测内容 | 检测指标 | 评估目的 |
|---------|---------|---------|
| **细胞生长曲线** | 活细胞密度（VCD）、细胞活率、倍增时间 | 确认各代次细胞的增殖能力稳定 |
| **比生产速率（qP）** | 单位细胞·单位时间产生的目标蛋白量 | 评估生产性能的代次稳定性 |
| **代谢特征** | 葡萄糖消耗速率、乳酸产生速率、氨积累水平 | 确认代谢表型在代次间一致 |

### 细胞染色体检查

| 检测内容 | 方法 | 评估目的 |
|---------|-----|---------|
| **核型分析（Karyotyping）** | G 带染色 + 显微镜观察 | 确认染色体数目和结构的整体稳定性（CHO 细胞通常为近二倍体，含少量染色体重排） |
| **FISH（荧光原位杂交）** | 目的基因特异性探针 + 荧光显微镜 | 确认外源基因的整合位点和拷贝数分布 |

### 细胞均一性及稳定性检查

**基因型稳定性：**
- 目的基因拷贝数（建库时 vs EOPC，须无显著变化）
- 目的基因测序（MCB vs EOPC，序列须完全一致）
- 表达构建体完整性（Southern Blot 分析整合位点模式）

**表型稳定性：**
- 产品表达量（滴度）在批准代次范围内须稳定
- 产品质量属性（CQA：糖型、电荷变体、聚体等）在代次间须保持一致

### 各类细胞库的检定适用范围

> 《中国药典》三部规定：细胞库建立后应至少对 MCB 细胞及生产终末细胞（EOPC）进行一次全面检定。当生产工艺发生改变时，应重新对 EOPC 进行检测。每次从 MCB 建立一个新的 WCB，均应按规定项目进行检定。

:::

## 鉴别试验的法规要求与推荐方法

:::answer

鉴别试验（Identification Test）是证明产品身份特异性的基础检定项目，须在质量标准中明确规定，并具备高度特异性，能将目标产品与其他物质明确区分。

### 法规对鉴别试验特异性的要求

鉴别试验应**高度特异**——即在所有可能存在于制品中的其他成分存在的情况下，仍能唯一识别目标产品。可根据制品特性选择以下一种或多种方法：

| 方法类型 | 代表技术 | 特异性基础 |
|---------|---------|---------|
| **免疫学方法（最常用）** | 免疫印迹（Western Blot）、ELISA | 利用特异性抗体识别目标蛋白的抗原表位 |
| **理化方法** | 毛细管区带电泳（CZE）、毛细管等电聚焦（cIEF）、HPLC | 利用目标蛋白的理化特性（分子量、pI、保留时间）进行特征性比较 |
| **生物学方法** | 体外细胞结合活性、ELISA 亲和力测定 | 利用目标蛋白特有的生物学活性 |

### 免疫印迹法（Western Blot）的规范要求

- **须设置标准分子量 Marker：** 用于确认目标蛋白条带的分子量位置
- **建议设转移前电泳对照：** 确认上样均一性和转移效率
- **结合与参比品的比较：** 目标蛋白条带的分子量和染色强度须与参比品一致

### 色谱法鉴别的注意事项

当采用 HPLC（如 SEC-HPLC、CEX-HPLC）进行鉴别时：
- 须通过与参比品（Reference Standard）的保留时间比较确认身份
- **质量标准描述中须同时规定主要峰或条带的成分和比例控制**（仅凭保留时间一致不足以完整鉴别产品）
- 色谱法鉴别须与其他原理的方法联合使用，单一色谱法通常不足以作为完整的鉴别体系

:::

## 纯度与有关物质分析的法规要求与方法选择

:::answer

纯度和有关物质（Related Substances）分析是生物制品质量标准的核心内容，须采用多种互补原理的分析方法系统评估，全面覆盖产品相关杂质的种类和水平。

### 法规要求：双法原则

**须至少采用两种不同原理的分析方法进行检定**，现行版药典通常要求：

| 方法 | 原理 | 检测对象 |
|-----|-----|---------|
| **非还原 SDS-PAGE** | 按分子大小电泳分离，天然构象条件 | 完整性（主带）、聚体（高分子量条带）、片段（低分子量条带） |
| **HPLC（多种模式）** | 按不同理化性质色谱分离 | SEC（聚体/片段）、CEX（电荷变体）、反相（脱酰胺化等修饰） |

### SDS-PAGE 的操作规范要求

| 染色方式 | 最低上样量 | 特点 |
|---------|---------|-----|
| **银染法（灵敏度高）** | ≥ 5 μg | 可检出极低含量次带；检测限约 1 ng/条带 |
| **考马斯亮蓝染色** | ≥ 10 μg | 操作较简便；适合常规分析；线性范围更宽 |

**产品纯度接受标准（一般要求）：** 经扫描，产品纯度应至少 **> 95%**。

**次带（含量 < 5%）的处置原则：**
- 须对次带的性质进行分析（鉴定对应的蛋白成分）
- 须在质量标准的质控方法描述中体现次带的识别和控制
- 须评估次带与制品活性、体内代谢和免疫原性的关系

### HPLC 方法的多模式组合建议

建议同时采用多种分离原理的 HPLC 方法，须明确色谱柱型号及选择理由：

| HPLC 模式 | 色谱柱类型 | 主要检测对象 |
|---------|---------|-----------|
| **分子筛色谱（SEC-HPLC）** | TSKgel G3000SWXL 等 | 单体纯度、聚体、片段 |
| **离子交换色谱（CEX-HPLC）** | ProPac WCX-10 等 | 电荷变体（酸性峰、主峰、碱性峰） |
| **反相液相色谱（RP-HPLC）** | C4、C8 柱 | 氧化、去酰胺化等化学修饰产物 |

**多峰出现时的处置原则：** 当 HPLC 分离出现多个峰时，说明蛋白质存在不均一性，须尽可能鉴定各峰对应的异构体成分，分析其与制品活性、体内代谢或免疫原性的关系，必要时在质量标准中对各峰比例进行限度控制。

:::

## 残余宿主细胞 DNA 的检定要求与限度制定原则

:::answer

宿主细胞 DNA（Host Cell DNA，rDNA）是生物制品中重要的工艺相关杂质，残余 DNA 的检定须符合药典规定的方法要求，并依据产品暴露情况制定科学合理的限度。

### 法规要求的检测方法

| 方法 | 原理 | 当前状态 |
|-----|-----|---------|
| **DNA 探针杂交法（Slot Blot）** | 以放射性或酶标记的宿主细胞 DNA 探针检测样品中的残余 DNA | 中国药典和 WHO 认可的传统方法 |
| **荧光染色法（PicoGreen 法）** | PicoGreen 试剂与 dsDNA 结合后产生荧光，定量检测 DNA 浓度 | 操作简便，常用于工艺开发阶段 |
| **定量 PCR（qPCR）** | 针对宿主细胞特异性 DNA 序列进行实时定量 PCR | **正在研究用于替代传统方法**；灵敏度更高，特异性更好 |

### 限度制定原则

**一般要求：残余 DNA < 10 ng/剂量**

这一限度基于以下风险考量：
- 病毒致癌基因（Oncogene）的潜在转化风险
- DNA 片段大小影响风险：DNA 片段 < 200 bp 通常认为无法整合至宿主基因组

**提高限度标准的情形：**

| 情形 | 要求 |
|-----|-----|
| 采用**致瘤性风险较大的哺乳动物细胞系**（如某些 HEK293 来源）生产 | 须制定**更严格**的 DNA 残留量控制限度 |
| 人体**暴露量较大**的制品（高剂量、频繁给药） | 须制定更严格的限度，并考虑患者的累积暴露量 |
| 新产品拟用药剂量显著高于同类已批准产品 | 须根据临床实际适当提高标准，不能直接套用 10 ng/剂量的通用限度 |

### DNA 去除工艺验证

除批放行检测外，须对下游纯化工艺的 DNA 去除能力进行验证：
- 关键去除步骤：Protein A 层析（流穿，通常 > 99% 去除）、阴离子交换层析（结合去除）
- 验证须包含最差情况（Worst Case）研究，证明在参数边缘条件下仍能达到 DNA 去除目标

:::

## 残余宿主细胞蛋白（HCP）的检定要求与限度制定

:::answer

宿主细胞蛋白（Host Cell Proteins，HCP）是生物制品中最复杂的工艺相关杂质，其残留水平须通过经验证的方法精确检测，并结合临床用药暴露量制定合理限度。

### 主要检测方法：ELISA

**行业普遍采用 ELISA 法**，分为两类：

**① 商业化通用 HCP ELISA 试剂盒（如 CHO HCP ELISA，Cygnus Technologies）：**
- 针对 CHO 宿主细胞蛋白谱制备多克隆抗体，覆盖尽可能多的 HCP 种类
- 快速、便捷；适合常规批放行
- **须进行适用性分析（Suitability Analysis）：** 确认试剂盒抗体对本产品工艺产生的 HCP 谱具有充分覆盖率（Coverage Analysis），避免系统性低估某些 HCP 的含量

**② 定制化 HCP ELISA：**
- 针对具体生产工艺和细胞株制备专属抗体
- 适合商业化通用试剂盒覆盖率不足（< 70%）的情形
- 开发成本高，周期长，通常在后期开发阶段才建立

### 高级补充方法：LC-MS/MS HCP 分析

随着质谱技术的普及，LC-MS/MS 正成为 HCP 表征的重要补充手段：
- 可直接鉴定 HCP 的蛋白质种类（而非总量）
- 对 ELISA 无法覆盖的特定 HCP 进行靶向定量
- 特别适用于识别高风险 HCP（如蛋白酶类、磷脂酶等）

### HCP 限度制定原则

**通用参考限度：** 大部分已批准上市生物制品的残余 HCP 含量规定在 **< 0.1%（1,000 ppm，即 ≤ 1 ng HCP/mg 产品）以下**。

**须制定更严格限度的情形：**

| 情形 | 影响 |
|-----|-----|
| 高剂量给药（单次 > 100 mg） | 患者的绝对 HCP 暴露量大，须更严格控制 |
| 频繁重复给药（长期用药） | 累积 HCP 暴露量升高，免疫原性风险增加 |
| 特定高风险 HCP 类别（如磷脂酶 A2）残留 | 该类 HCP 具有生物活性，须单独设立限度 |

**注意：** HCP 限度须结合产品的临床给药方案（剂量、频率、给药途径、适应症人群）综合评估，不能一律套用已批准产品的限度。

:::

## 生物技术药物及其检测方法的特殊性

:::answer

生物技术药物（主要是蛋白质/多肽类药物）与小分子化学药物在理化性质和检测方法上存在根本性差异，这些差异决定了其质量标准和检定方法验证的特殊要求。

### 生物技术药物的固有特殊性

| 特殊性 | 具体体现 | 对检测方法的影响 |
|-------|---------|--------------|
| **分子量大** | 单抗 ~150 kDa，远大于小分子药物（< 500 Da） | 需要特殊分析工具（MS、SEC、电泳）；无法用 HPLC 简单分离 |
| **结构多样性和可变性** | 翻译后修饰（PTM）种类多，微小结构变化影响活性 | 须采用多种互补方法全面表征 |
| **稳定性差** | 对酸、碱、温度、氧化、光照敏感 | 须严格控制样品处理条件；须建立特定稳定性规程 |
| **批间生物学变异性** | 细胞培养的固有变异性导致批间质量属性存在一定范围的波动 | 质量标准须基于合理的批次数据设定，而非理想值 |

### 生物学测定方法的变异性

| 方法类型 | 典型结果变异系数（CV）范围 | 原因 |
|---------|----------------------|-----|
| 化学结合试验（如 ELISA） | 5%～20% | 生物体系较为稳定，重现性相对好 |
| 酶反应试验 | CV ≤ 20% | 酶促反应受温度和时间影响，须严格控制 |
| 体外细胞测定 | 约 30% | 细胞本身具有固有变异性 |
| 动物体内试验 | 可达 50% | 动物个体差异大，须使用足够样本量 |

**关键推论：** 生物技术药物质量标准的特殊性（宽松的接受标准、半定量方法的接受等）主要由**生物学测定方法的变异性**决定，这与小分子药物的精确理化测定有根本区别。

### 生物技术药物检测的双重挑战

1. **结构不均一性（Heterogeneity）：** 单抗本身具有固有异质性（糖型、电荷变体等），难以用单一数值描述，须用分布范围表征
2. **生物活性测量的复杂性：** 活性（Potency）检测依赖活体系统，须以标准品（Reference Standard）为参照进行相对效力（Relative Potency）计算

:::

## 生物制品检测实验室的三类方法与适用性评估

:::answer

生物制品检测实验室使用的分析方法按其来源和验证状态可分为三类，不同类别的方法在应用前须经过不同程度的验证，须根据方法类型制定相应的验证策略。

### 三类方法的定义与验证要求

**① 经过验证的方法（Validated Methods）**

| 特征 | 说明 |
|-----|-----|
| **定义** | 已被多家实验室广泛研究，或由政府部门/国际组织（WHO、NMPA、药典委员会）要求各级检定实验室使用的方法 |
| **代表** | 《中国药典》收录的方法；ICH 指南推荐的标准方法 |
| **验证要求** | 方法本身已完成正式验证；但在**第一次应用于某实验室时，须进行方法转移验证（Method Transfer）**，证明实验操作达到要求 |
| **转移验证内容** | 通常包括：精密度（中间精密度）、准确性（如适用）、系统适用性测试 |

**② 来自参考文献的方法（Literature Methods）**

| 特征 | 说明 |
|-----|-----|
| **定义** | 在专业杂志或书籍上发表并介绍的方法 |
| **适用性** | 通常较适合检测特定制品，但在应用于**同类制品或其他产品**时，须进行全面验证 |
| **验证要求** | **须进行全面验证**（包括专属性、准确性、精密度、线性等所有适用参数） |
| **注意事项** | 文献方法的验证数据通常来自特定样品基质，在不同基质中的适用性须重新评估 |

**③ 新建立的方法（New Methods）**

| 特征 | 说明 |
|-----|-----|
| **定义** | 为提高检测灵敏度或满足特定要求而新开发的方法，或对原方法进行实质性修改后的方法 |
| **验证要求** | **须进行最严格的完整验证**，须考虑并验证方法的专属性、灵敏度、精密度、准确性、方法适用性等全部参数 |
| **使用前提** | 在作为常规检定方法使用前，须完成所有验证工作并经质量管理体系批准 |

### 方法选择的优先级原则
```
优先级（从高到低）：
1. 药典方法（ChP/USP/EP）→ 法规可接受性最高
2. 监管机构认可的指导原则方法
3. 文献方法（须全面验证）
4. 内部新建方法（须最严格验证）
```

:::

## 生物技术药物活性测定的四类方法及其特点

:::answer

生物学活性（Biological Activity/Potency）是生物技术药物质量标准中最重要的效力指标，须采用能反映产品作用机制（Mechanism of Action，MoA）的生物学方法进行测定，并以国际或国家标准品为参照进行相对效力计算。

### 四类活性测定方法

**① 化学结合试验（Binding Assays）**

| 特征 | 说明 |
|-----|-----|
| **原理** | 不依赖活体生物系统，基于产品与靶分子的结合特性或化学反应 |
| **代表方法** | ELISA（抗原-抗体结合）、SPR（表面等离子体共振）、BLI（生物层干涉） |
| **结果变异** | 变异系数（CV）通常 5%～20% |
| **主要用途** | 纯化过程监测、清洁验证；辅助功能描述 |
| **局限性** | **不能作为制品效力测定的单一依据**——结合测定的分子不一定都具有完整生物活性（如脱酰胺化产物可能结合但活性降低） |

**② 酶反应试验（Enzyme-based Assays）**

| 特征 | 说明 |
|-----|-----|
| **原理** | 产品在体外能促进酶分子活化（辅助因子）或本身具备酶活性，通过底物变化（颜色、荧光、发光）检测酶活性 |
| **代表方法** | 溶圈法（重组链激酶活性）；酯酶活性法 |
| **结果变异** | CV 通常 ≤ 20% |
| **关键影响因素** | 温度和反应时间须严格控制（酶促反应对温度高度敏感） |

**③ 体外细胞测定试验（Cell-based Assays）**

| 特征 | 说明 |
|-----|-----|
| **原理** | 产品作用于靶细胞，产生可测定的应答（细胞增殖、抑制、凋亡、细胞因子释放等） |
| **代表方法** | 细胞增殖抑制法（肿瘤治疗性抗体）；ADCC 活性测定；CDC 活性测定；细胞结合法 |
| **结果变异** | CV 可达约 **30%** |
| **质量保证要求** | 须精心操作以保证试验结果一致性；须使用固定代次的细胞；须设标准品和阴性对照 |
| **监管首选** | 对于直接通过细胞效应发挥药效的产品，体外细胞测定通常是监管机构优先接受的效力方法 |

**④ 动物体内试验（In vivo Animal Studies）**

| 特征 | 说明 |
|-----|-----|
| **原理** | 在动物模型中评估产品的生物学效应，与已知标准品（未处理动物对照）比较 |
| **结果变异** | CV 可达约 **50%** |
| **主要挑战** | 动物个体差异大；操作周期长（数天至数周）；须使用大量动物（成本高，伦理压力大） |
| **适用场景** | 体外方法无法充分反映产品作用机制时（如疫苗效力测定、部分激素类产品） |
| **3R 原则** | 替代（Replace）、减少（Reduce）、优化（Refine）——监管机构鼓励用体外方法替代动物试验，须提供科学依据 |

### 方法选择的核心原则

**生物活性方法须与产品的作用机制（MoA）直接相关：**

- 以 ADCC 为主要机制的抗体 → 须有 ADCC 活性测定
- 以靶点结合抑制信号通路为机制的抗体 → 须有靶点结合或细胞功能抑制试验
- 单纯结合试验通常不足以作为效力测定的唯一方法

:::

## 生物技术药物检测方法验证的核心内容框架

:::answer

生物技术药物检测方法的验证（Analytical Method Validation）是方法合规性的核心要求，须根据方法的用途系统评估并记录一系列验证参数，为监管申报和日常质量控制提供科学依据。

### 方法验证的九大核心参数

| 验证参数 | 英文名称 | 定义 | 评估方式 |
|---------|---------|-----|---------|
| **专属性** | Specificity | 在其他组分共存时，方法检测目标分析物的能力 | 在干扰物存在时与纯净样品比较 |
| **准确性** | Accuracy | 测定值与真实值的接近程度 | 已知浓度加标回收实验；与参比方法比较 |
| **精密度** | Precision | 重复测定结果的一致程度 | 重复性（n ≥ 6）、中间精密度（不同日/人/仪器）、重现性（不同实验室） |
| **线性** | Linearity | 方法测定值与分析物浓度之间的线性关系 | 至少 5 个浓度水平；计算回归系数 R² |
| **测定范围** | Range | 方法可以精确测定分析物浓度的区间 | 由线性范围和精密度/准确性共同确定 |
| **检测限** | Detection Limit (LOD) | 可以检测到分析物存在的最低浓度（不要求定量） | 信噪比法（S/N = 3:1）；空白标准差法 |
| **定量限** | Quantitation Limit (LOQ) | 可以精确定量的最低分析物浓度 | 信噪比法（S/N = 10:1）；须同时满足精密度和准确性要求 |
| **特殊性（耐用性）** | Robustness | 方法在小幅偏离规定条件时的抗干扰能力 | 系统化改变小参数（pH ±0.1、温度 ±2°C、柱批次等），评估对结果的影响 |
| **耐用性** | Ruggedness | 方法在不同实验室、操作者之间的重现能力 | 与重现性验证相似；通常在方法转移验证中评估 |

### 不同方法类型对验证参数的要求

| 方法用途 | 须验证的核心参数 |
|---------|--------------|
| **鉴别试验** | 专属性（唯一能证明身份的关键参数） |
| **限量检查（纯度/杂质）** | 专属性、检测限、精密度、准确性 |
| **定量测定（主成分含量/效力）** | 所有九大参数（全面验证） |
| **生物活性方法（效力）** | 特别关注精密度（各层次）和线性；须确定相对效力计算方法 |

### 生物活性方法验证的特殊考量

生物活性方法（Cell-based Assay）的验证除上述参数外，还须特别关注：

- **系统适用性（System Suitability）：** 每次运行须设置标准品和阴性对照，确认细胞状态和试验条件合格
- **相对效力计算方法验证：** 须证明样品和标准品的量效曲线具有平行性（Parallelism），方可进行相对效力计算
- **参考标准品（Reference Standard）管理：** 须建立、表征并定期更新工作参考标准品；须规定每批次参考标准品的标化方案
