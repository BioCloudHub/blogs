## ADC 偶联后的抗原结合亲和力：维持靶向性的关键质量属性

:::answer

**核心问题**

对抗体进行任何结构改造或修饰（包括偶联细胞毒性 Payload）都会不同程度地改变抗体的三维构象，进而影响其与靶抗原的结合亲和力。ADC 开发中必须确认偶联后的抗体仍保留足够的靶向结合能力。

**亲和力受损的主要机制**

| 影响因素 | 机制 | 风险 |
|---|---|---|
| 偶联位点邻近 CDR 区 | Payload 的空间位阻直接干扰抗原结合口袋 | 亲和力显著下降，靶向性丧失 |
| 疏水性 Payload 引起构象变化 | Payload 疏水聚集导致抗体局部折叠改变 | CDR 构象失真，结合能力降低 |
| 高 DAR 值 | 多个 Payload 分布于抗体表面，叠加位阻效应 | 亲和力随 DAR 升高而下降 |
| 偶联反应副产物 | 化学修饰引入额外基团，改变电荷分布 | 非特异性结合增加，选择性下降 |

**亲和力评估的关键方法**

- **SPR（表面等离子体共振）**：测定偶联前后 kon、koff 和 KD 值，定量评估亲和力变化
- **ELISA / 细胞结合试验**：评估 ADC 与表达靶抗原的细胞系的结合 EC50
- **流式细胞术**：直接评估 ADC 与肿瘤细胞表面靶抗原的结合效率

**质控要求**

偶联后 ADC 的相对结合亲和力通常须与裸抗相比保持在合理范围（一般要求不低于裸抗的 50%～80%，具体限度依产品而定），并作为 ADC 原液的放行检测指标之一。

**定点偶联对亲和力保护的优势**

与随机偶联相比，定点偶联（工程化半胱氨酸、非天然氨基酸等）可将偶联位点远离 CDR 区，显著降低偶联对抗原结合亲和力的干扰，是高活性 ADC 开发的技术趋势。

## ADC 内化效率：肿瘤细胞摄取的瓶颈与优化策略

:::answer

**内化效率的核心地位**

ADC 发挥抗肿瘤效应的前提是肿瘤部位细胞毒 Payload 达到足够的胞内有效浓度。然而，肿瘤细胞对 ADC-抗原复合物的内吞效率受到多重因素制约，使有效胞内药物浓度的实现极具挑战性。

**制约内化效率的关键因素**

| 限制因素 | 机制 | 量化影响 |
|---|---|---|
| 靶抗原表面密度有限 | 单个细胞表面抗原数量（通常 10⁴～10⁶ 个/细胞）直接限制可结合 ADC 的量 | 抗原密度越低，可内化的 ADC 绝对量越少 |
| 抗原内化速率低 | 部分靶点（如 HER2）内化速率较慢，复合物在细胞表面停留时间过长 | 被蛋白酶裂解或从细胞表面脱落的风险增加 |
| 受体循环回收 | 内化后抗原-抗体复合物部分被重新循环至细胞表面，不进入溶酶体降解途径 | 减少有效释药量 |
| 肿瘤组织屏障 | 实体瘤高间质压力和致密基质阻碍 ADC 渗透至肿瘤深部 | 肿瘤边缘高浓度结合，中心区域暴露不足 |
| 抗原脱落 | 靶抗原被蛋白酶切除后以可溶性形式释放入血，与循环中 ADC 竞争性结合 | 减少到达肿瘤细胞的有效 ADC 量 |

**提高内化效率的策略**

- **靶点选择**：优先选择具有快速、持续内化特性的靶点（如 CD22、TROP2、HER3），内化速率是靶点筛选的重要参数
- **抗体表位优化**：针对同一靶点的不同表位，内化效率可差异显著；筛选促内化表位是提高 ADC 疗效的有效手段
- **双价/多价结合设计**：抗体与靶抗原的多价结合可促进受体交联，加速内化
- **pH 响应型抗体**：在内体酸性条件下降低对抗原的亲和力，使 ADC 从抗原上解离，抗原重新循环至细胞表面，而释放的 ADC 则进入溶酶体降解——"sweeping antibody"策略可提高单次内化递送效率

**内化效率的评估方法**

- **流式细胞术（荧光标记追踪）**：使用 pH 敏感荧光染料（如 pHrodo）标记 ADC，在内体/溶酶体酸性环境中荧光增强，定量内化动力学
- **共聚焦显微镜**：追踪 ADC 与溶酶体标志物（LAMP1、LysoTracker）的共定位，确认 ADC 到达溶酶体
- **放射性标记法**：精确定量胞内 ADC 绝对量随时间的变化

:::

## ADC 开发的核心挑战：从规模化生产到多药耐药的系统性难题

:::answer

**ADC 开发难度的根本来源**

ADC 是目前生物制药领域技术复杂度最高的分子类型之一，其开发挑战横跨分子设计、规模化生产、质量控制、PK/PD 研究和耐药机制多个维度，任何一个环节的瓶颈都可能导致项目失败。

**挑战一：规模化生产的质量控制**

ADC 的分子结构远比"裸抗"或单纯小分子药物复杂：

| 复杂性来源 | 具体表现 | 质控难点 |
|---|---|---|
| 结构异质性 | DAR 值分布（DAR 0～8+）、偶联位点多样性 | 确保批间 DAR 分布一致性 |
| 组分多样 | 抗体 + Linker + Payload 三者偶联产物的混合体 | 多组分同步质控，杂质谱复杂 |
| 工艺敏感性 | 偶联反应条件（pH、温度、时间、试剂比例）对产品质量影响显著 | 工艺参数窗口窄，批间重现性要求高 |

**当前解决方案**：高灵敏质谱（LC-MS/MS、native MS）已成为 ADC 结构鉴定、稳定性研究和批间质量一致性评估的核心技术；HIC（疏水相互作用色谱）用于 DAR 分布定量。

**挑战二：独特的 PK/PD 特性研究**

ADC 的 PK 行为远比单抗复杂，须同时追踪多个 PK 实体：

| PK 实体 | 定义 | 检测方法 |
|---|---|---|
| 总抗体（Total Antibody）| 所有含抗体的分子（不论是否偶联 Payload）| 抗体特异性 ELISA |
| ADC（偶联抗体）| 仅含有 Payload 的抗体 | Payload-抗体联合检测 |
| 游离 Payload | 从 ADC 上脱落的小分子毒素 | LC-MS/MS |
| 代谢产物 | Linker-Payload 的降解或代谢中间体 | LC-MS/MS 代谢组学 |

**关键 PK/PD 研究内容**：代谢产物谱分析（关注毒性代谢物）、DAR 值体内稳定性（循环过程中 DAR 值是否随时间降低）、给药方案优化（给药周期、负荷剂量设计）、生物标志物确定（靶抗原表达水平与疗效的相关性，支持 CDx 开发）。

**挑战三：多药耐药（MDR）**

尽管 ADC 在一定程度上可克服肿瘤细胞耐药（通过高效 Payload 绕过常规耐药机制），但多种耐药机制已被证实：

| 耐药机制 | 具体表现 | 应对策略 |
|---|---|---|
| ABC 转运蛋白过表达（P-gp/MDR1）| 将 MMAE、DM1 等 Payload 主动外排出细胞 | 选择非 P-gp 底物 Payload（如 DXd、PBD）|
| 靶抗原表达下调 | 肿瘤细胞在 ADC 选择压力下下调靶抗原表达 | 双靶点 ADC；联合其他机制药物 |
| 内化效率下降 | 靶点内化通路被下调，ADC 胞内浓度不足 | 联合内化促进剂 |
| 溶酶体功能异常 | 溶酶体酶活性降低，Payload 释放不完全 | 选择多种裂解机制的复合型 Linker |
| Payload 靶点突变 | 微管蛋白突变导致 MMAE 结合减弱 | 更换作用机制不同的 Payload |

**应对耐药的前沿方向**：双靶点 ADC（同时靶向两种肿瘤抗原）、ADC 与免疫检查点抑制剂联合（利用 ADC 诱导的免疫原性细胞死亡激活抗肿瘤免疫）、ADC 与 DNA 损伤修复抑制剂联合（增强 DNA 损伤类 Payload 疗效）。

:::

## ADC 靶抗原的合理设计：特异性、非分泌性与内化能力三要素

:::answer

**靶抗原选择的三维评估框架**

靶抗原的选择是 ADC 整体设计的基石，直接决定产品的治疗窗口和临床成功率。CDE《抗体偶联药物药学研究与评价技术指导原则》明确了三个核心维度：

**维度一：特异性（Specificity）**

靶抗原应仅在或主要在肿瘤细胞中表达，或仅在肿瘤细胞中高表达，而在正常组织中不表达或极低表达。

| 特异性评估策略 | 工具/方法 |
|---|---|
| 正常组织表达谱分析 | 人蛋白质图谱（HPA）数据库、GTEx 转录组数据 |
| 肿瘤 vs. 正常组织头对头 IHC | 肿瘤组织芯片（TMA）|
| 单细胞 RNA 测序 | 解析肿瘤微环境中不同细胞亚群的靶点表达 |

**注意**：即便靶点在正常组织中低表达，若其位于对毒性高度敏感的组织（如心肌、神经组织），仍可能引发严重脱靶毒性，需结合组织毒性敏感性综合评估。

**维度二：非分泌性（Non-shedding）**

选择的靶抗原须为**膜结合型**（非分泌型），即靶抗原须在肿瘤细胞表面稳定表达而不被主动分泌进入血液循环。

分泌型抗原的危害：

```
靶抗原被蛋白酶切割脱落 → 以可溶性形式进入血液循环
    ↓
血液中 ADC 与可溶性抗原结合形成无效复合物
    ↓
到达肿瘤部位的有效 ADC 量减少 → 疗效降低
ADC-可溶性抗原复合物被清除 → PK 改变，毒性风险上升
```

抗原脱落（Shedding Rate）应在靶点选择阶段通过体外细胞培养上清的 ELISA 定量检测，并纳入靶点成药性评估。

**维度三：有效内化能力（Efficient Internalization）**

ADC 药物必须通过**受体介导的内吞（Receptor-mediated Endocytosis）**进入细胞内部，才能在溶酶体内完成 Payload 的释放和激活。不能有效内化的靶点不适合作为 ADC 靶点（但可用于单纯抗体 CDC/ADCC 机制的药物）。

**内化评估关键参数**

| 参数 | 理想值 | 评估方法 |
|---|---|---|
| 内化半衰期（t₁/₂ internalization）| < 2 h（快速内化）| 流式细胞术时程实验 |
| 内化效率（24 h）| > 70% ADC 完成内化 | 胞表面残余 vs. 胞内信号比较 |
| 溶酶体共定位率 | > 60%（内化 ADC 到达溶酶体）| 共聚焦显微镜 LAMP1 共定位 |
| 受体循环率 | 越低越好 | 抗体再结合实验 |

:::

## ADC 抗体组分的设计要求：亲和力、内化与 PK 特性的综合优化

:::answer

**抗体在 ADC 中的核心功能**

ADC 的抗体组分承担双重职责：精准识别靶抗原（导航功能）和作为 Payload 的运载平台（载体功能）。理想的 ADC 抗体须在特异性结合、内化促进、PK 维持和偶联相容性之间取得精细平衡。

**抗体关键设计要素**

**要素一：特异性与亲和力**

- 高特异性是减少脱靶毒性的首要保障
- 亲和力（KD）须经过仔细优化：
  - **过高亲和力**的潜在问题：可能加速内化（有利），但同时导致"结合位点屏障效应"——ADC 在肿瘤边缘被大量结合，无法渗透至肿瘤中心
  - **适中亲和力**在某些实体瘤中反而有利于肿瘤穿透，提高整体递送效率
- 通常 KD 范围在 **0.1～10 nM** 为较理想区间，具体依靶点和肿瘤类型而定

**要素二：内化促进能力**

- 抗体结合的表位位置直接影响内化效率（并非所有表位结合后均能有效触发内化）
- 抗体对靶点的亲和力与内化效率并非正相关，需独立评估

**要素三：低免疫原性**

- 须为全人源化或高度人源化抗体（人源化率 > 90%）
- 偶联后须重新评估免疫原性风险（Payload/Linker 结构本身也可能成为新表位）

**要素四：药代动力学特性**

- 须保留与天然 IgG 相似的 FcRn 结合特性，维持较长循环半衰期（通常目标 > 7 天）
- 低非特异性结合（NSAB）：抗体在非靶组织的非特异摄取是系统毒性的重要来源，须通过体外聚电解质等评估方法早期筛除高 NSAB 候选抗体

**要素五：抗体本身的抗肿瘤活性**

- 部分裸抗本身具有一定抗肿瘤活性（如 Trastuzumab 通过 HER2 信号阻断），偶联后 ADC 可叠加裸抗活性和 Payload 毒性，产生协同效应
- 需评估偶联后抗体的信号通路抑制、ADCC/CDC 等效应功能是否受影响

**要素六：分子量与肿瘤穿透性**

- 全长 IgG（~150 kDa）肿瘤穿透性有限，尤其对致密实体瘤
- 较小格式的抗体（Fab、scFv、Nanobody 等）穿透性更强，但半衰期短——对 ADC 而言需权衡载药量和穿透性的平衡

**中间体质量控制**

裸抗（ADC 关键原料）须建立完善的中间体质量控制体系，主要检测指标包括：纯度（SEC-HPLC）、电荷变体（CEX 或 IEF）、糖型（寡糖图谱）、生物学活性（靶点结合）、残留 Protein A 含量等，为后续偶联工艺提供高质量、一致性的裸抗起始物料。

:::

## ADC 连接子的合理设计：稳定性、释放效率与类型选择策略

:::answer

**连接子的战略地位**

连接子（Linker）是 ADC 分子中"承上启下"的关键组件，对 ADC 的稳定性、Payload 释放动力学、治疗窗口和毒性特征产生决定性影响。连接子设计失败是早期 ADC 开发失败的最主要原因之一（第一代 ADC 的腙键连接子血浆稳定性不足，导致全身毒性过高）。

**理想连接子的双重要求**

```
在体循环中（血浆，pH 7.4，37°C）
    → 高度稳定，不发生非特异性断裂
    → 阻止 Payload 提前释放，避免系统毒性

在肿瘤细胞溶酶体内（pH 4～5，蛋白酶/GSH 富集）
    → 快速、高效裂解
    → 释放具有完整活性的游离 Payload
```

**两大类连接子的设计逻辑与比较**

**可裂解连接子（Cleavable Linker）**

设计核心：**精准识别并利用循环系统与肿瘤细胞内环境的差异**进行选择性裂解。

| 类型 | 裂解触发因素 | 代表结构 | 血浆稳定性 | 旁观者效应 |
|---|---|---|---|---|
| pH 敏感型 | 内体/溶酶体酸性（pH 4～5）| 腙键（Hydrazone）| 较低（已基本淘汰）| 强 |
| 还原敏感型 | 胞内高 GSH（肿瘤细胞 GSH 约为血浆 500～1000×）| 二硫键（Disulfide）| 中等 | 中等 |
| 蛋白酶敏感型 | 溶酶体组织蛋白酶 B（肿瘤细胞过表达）| Val-Cit-PABC 肽键 | 高（血浆蛋白酶抑制剂保护）| 强 |
| 葡萄糖苷酸型 | β-葡萄糖苷酸酶（肿瘤/坏死区域）| β-葡萄糖苷酸键 | 高 | 强（亲水性好，扩散能力强）|

**不可裂解连接子（Non-cleavable Linker）**

设计逻辑：利用肿瘤细胞溶酶体将 ADC 完整降解（包括抗体和 Linker），最终以**氨基酸-Linker-Payload 复合物**形式释放活性物质。

| 特性 | 优势 | 劣势 |
|---|---|---|
| 血浆稳定性 | 最高（对化学和酶环境均惰性）| — |
| 脱靶毒性 | 低（游离 Payload 不提前释放）| — |
| 旁观者效应 | — | 弱/无（释放的带极性基团的 Payload 衍生物膜穿透能力差）|
| 适用场景 | 抗原均一表达肿瘤，无需旁观者效应 | 不适合抗原表达异质性高的实体瘤 |

**连接子设计的其他关键考量**

- **不诱导 ADC 聚集**：疏水性强的 Linker-Payload 会增加 ADC 整体疏水性，导致聚集。葡萄糖苷酸等亲水型 Linker 可在高 DAR 下保持 ADC 溶解性，支持 DS-8201（DAR=8）等高负载 ADC 的开发
- **偶联位点兼容性**：Linker 的反应基团须与抗体偶联位点（赖氨酸、半胱氨酸或工程化位点）化学相容
- **代谢产物毒性**：须预测并检测 Linker 裂解后的代谢产物是否具有额外毒性

:::

## ADC 有效载荷（Payload）的选择标准：毒力、修饰性与稳定性的综合评估

:::answer

**Payload 的战略定位**

有效载荷（Payload）是 ADC 发挥抗肿瘤作用的"弹头"，是决定 ADC 杀伤力大小的核心因素。由于 ADC 静脉注射后仅约 **2%** 的药物能到达肿瘤部位，Payload 必须具备极高的固有细胞毒性，才能在有限的胞内浓度下实现有效杀伤。

**Payload 选择的四大核心标准**

**标准一：极高细胞毒性**

- Payload 单独使用时 IC₅₀ 须在 **nM 甚至 pM** 范围内（比传统化疗药物高 100～1000 倍）
- 高毒性的必要性：弥补肿瘤递送效率低（约 2%）和靶抗原密度有限带来的剂量损失

**标准二：可修饰性**

- Payload 须含有可与 Linker 共价连接的化学功能基团（-NH₂、-SH、-COOH、-OH 等）
- 修饰位点须经过精心选择：避免修饰影响 Payload 的药效团（靶点结合关键基团），同时确保修饰后 Payload 活性不受损
- 部分 Payload 需要化学前体改造（引入可供偶联的"handle"）以实现高效偶联

**标准三：适当的亲疏水平衡**

- Payload 本身通常疏水性较强（高毒性小分子普遍如此），与抗体偶联后可能导致 ADC 聚集
- 亲水性修饰策略：在 Linker 中引入 PEG 链、磺酸基、葡萄糖苷酸等亲水基团，抵消 Payload 的疏水性贡献
- DS-8201 中 DXd 通过四肽 Linker + 葡萄糖苷酸实现高 DAR（8）下的良好溶解性

**标准四：高化学和代谢稳定性**

- 在血浆生理条件（pH 7.4，37°C，蛋白酶存在）下须保持化学结构稳定，不自发降解
- 进入细胞后须能抵抗初步的胞内代谢，直至到达作用靶点

**主流 Payload 类型与特性比较**

| Payload 类型 | 靶点 | 代表化合物 | IC₅₀ 范围 | P-gp 底物 | 旁观者效应 |
|---|---|---|---|---|---|
| 微管抑制剂（Auristatin 类）| 微管蛋白 β | MMAE、MMAF | 0.1～10 nM | 是（MMAE）| 强（MMAE）/弱（MMAF）|
| 微管抑制剂（Maytansinoid 类）| 微管蛋白 | DM1、DM4 | 0.01～1 nM | 是 | 弱 |
| DNA 拓扑异构酶 I 抑制剂 | TopoI | DXd（喜树碱衍生物）、SN-38 | 1～100 pM（DXd）| 否 | 强 |
| DNA 烷化/交联剂（PBD 类）| DNA 小沟 | SG3199、PBD 二聚体 | pM 级 | 否 | 弱（极高毒性带来的旁杀 vs. 扩散能力）|
| RNA 聚合酶抑制剂 | RNA 聚合酶 II | Amanitin（鹅膏素）| pM 级 | 否 | 强 |

**Payload 开发的 CMC 要求**

Payload 小分子的合成和质量控制须遵循化学药品原料药（API）的生产规范（参照 ICH Q7），需建立完整的合成路线、工艺参数控制、杂质谱分析和稳定性研究体系，并须满足 GMP 生产要求。

:::

## ADC 偶联方式的设计要点：DAR 值控制与均一性对产品性质的影响

:::answer

**偶联方式的战略重要性**

偶联方式决定了 ADC 的 DAR 值（Drug-to-Antibody Ratio）及其分布均一性，而 DAR 直接影响 ADC 的疗效、安全性、PK 特征和生产批间一致性。偶联方式的选择是 ADC 分子设计中最具技术壁垒的环节之一。

**DAR 值对 ADC 性质的影响**

| DAR 范围 | 疗效影响 | 安全性影响 | PK 影响 |
|---|---|---|---|
| DAR < 2 | 药物负载不足，疗效低 | 毒性低 | 类似裸抗 |
| DAR 2～4 | 最优治疗窗（传统随机偶联）| 可接受 | 与裸抗接近 |
| DAR > 6（随机偶联）| 疗效可能提高 | 疏水性聚集加速清除，毒性升高 | 半衰期缩短，清除加快 |
| DAR 8（定点偶联）| 高疗效（如 DS-8201）| 通过亲水 Linker 缓解聚集 | 与 DAR 4 类似 |

**两大偶联策略的本质差异**

**非定点偶联（随机偶联）**

- **赖氨酸偶联**：利用抗体表面 80～100 个赖氨酸的 ε-氨基与活性酯反应，产生极宽的 DAR 分布（DAR 0～8+），每批产品实为多种 ADC 分子的混合物
- **半胱氨酸偶联（还原链间二硫键）**：还原 IgG1 的 4 对链间二硫键，产生 8 个游离 Cys，相对位置固定但仍有 DAR 0、2、4、6、8 分布

**定点偶联（Site-specific Conjugation）**——主流技术趋势

| 技术 | 原理 | DAR 均一性 | 代表技术 |
|---|---|---|---|
| 工程化半胱氨酸 | 在 Fc 非关键位点引入 Cys，提供特异偶联位点，不还原天然二硫键 | 极高（主要 DAR=2）| THIOMAB™（Genentech）|
| 非天然氨基酸（nnAA）| 密码子扩展技术在特定位置引入含叠氮/炔基的 nnAA，通过点击化学偶联 | 极高（精确控制）| Ambrx、Sutro 技术平台 |
| 酶催化偶联 | 转谷氨酰胺酶/糖基转移酶识别特定序列/糖型，在特定位点引入偶联基团 | 高 | Innate Pharma TGase 技术 |
| 糖基工程偶联 | 改造 Fc N297 糖链末端，引入可点击化学功能基团 | 高（偶联位点限于 N297）| Seattle Genetics SGD-CCAP 平台 |

**偶联位点选择的关键考量**

- **远离 CDR 区**：避免偶联位点影响抗原结合亲和力（尤其对高 DAR 产品）
- **抗体 PK 影响**：偶联位点不应干扰 FcRn 结合区域（IgG1 Fc 的 His310、His435），以维持正常半衰期
- **溶液可及性**：偶联位点须在溶液中具有足够的化学可及性（非掩埋位点）
- **Linker-Payload 空间兼容性**：偶联位点附近须有足够的空间容纳 Linker-Payload 结构，避免位阻影响抗原结合

:::

## 增强型抗体药物的分类体系：从 CAR-T 到 ARD 的全景概览

:::answer

**增强型抗体药物的背景**

普通单克隆抗体虽具有高度靶向性和低免疫原性，但随着临床应用时间延长，肿瘤细胞不可避免地通过多种机制产生耐药，导致疗效下降。增强型抗体药物正是在此背景下应运而生，旨在通过结构工程或联合策略克服单抗的固有局限。

**增强型抗体药物的八大类别**

| 类别 | 核心增强策略 | 代表产品/技术 |
|---|---|---|
| **CAR-T（嵌合抗原受体 T 细胞）**| 将特异性抗原识别能力（scFv）与 T 细胞杀伤机制整合，不受 MHC 限制 | Kymriah、Yescarta |
| **CAR-NK（嵌合抗原受体 NK 细胞）**| 利用 NK 细胞天然杀伤活性和 CAR 导向性，兼具天然杀伤和靶向杀伤双重机制 | 多款在研产品 |
| **ADC（抗体偶联药物）**| 抗体 + 高效细胞毒 Payload，将化疗药物精准递送至肿瘤细胞 | Enhertu、Kadcyla、Trodelvy |
| **双特异性抗体（BsAb）**| 同时结合两种抗原，桥联效应细胞与肿瘤细胞，或阻断双信号通路 | Blinatumomab、Emicizumab |
| **三特异性抗体（TriAb）**| 含 CD3 结合域 + TAA 结合域 + 完整 Fc（募集 FcR+ 效应细胞），三重效应叠加 | 多款临床阶段产品 |
| **组合抗体（Antibody Combination）**| 靶向同一靶点不同表位或多种靶点的抗体联合应用，克服单一抗体的耐药逃逸 | Pertuzumab + Trastuzumab（Perjeta 组合）|
| **ADCC 增强抗体**| 通过 Fc 工程（去岩藻糖化、氨基酸突变）增强 FcγRIIIa 亲和力，提高 ADCC 活性 | Mogamulizumab、Obinutuzumab |
| **CDC 增强抗体**| 通过多效价 Fc 设计（IgM 五/六聚体、人工二聚化抗体）增强 C1q 结合 | 多款在研产品 |
| **ARD（Antibody-Receptor Degrader）**| 抗体介导靶蛋白的胞内降解（结合 PROTAC 或降解子概念）| 前沿探索阶段 |

**选择增强策略的决策逻辑**

- 若**靶点可内化**且需精准细胞内递送 → ADC
- 若需**重定向 T 细胞**至肿瘤 → BsAb（CD3×TAA）或 CAR-T
- 若需克服**MHC 下调**导致的 T 细胞识别障碍 → CAR-T 或 CAR-NK
- 若需**双通路阻断**防止耐药 → BsAb 或组合抗体
- 若 CDC/ADCC 是主要效应机制且需增强 → CDC/ADCC 增强抗体

:::

## CAR-T 细胞疗法：核心原理、靶点选择与临床应用挑战

:::answer

**CAR-T 的核心创新**

嵌合抗原受体 T 细胞（CAR-T）疗法的革命性在于赋予 T 细胞**MHC 非依赖**的靶向杀伤能力：传统 T 细胞须通过 TCR-MHC-抗原肽三元复合物识别靶细胞，而肿瘤细胞常通过下调 MHC-I 表达逃避 T 细胞免疫；CAR-T 通过 scFv 直接识别肿瘤细胞表面抗原，彻底绕过 MHC 限制，极大扩展了 T 细胞能识别的靶点范围。

**CAR 的结构设计要素**

| 结构域 | 组成选择 | 功能 |
|---|---|---|
| 胞外抗原结合区 | scFv（最常用）；Nanobody；天然配体/受体胞外域 | 特异性识别靶抗原，决定 CAR 的靶向特异性 |
| 铰链区 | CD8α 铰链；IgG4 铰链（常用）| 提供适当的空间灵活性和刚性，影响 CAR-T 与靶细胞的接触效率 |
| 跨膜区 | CD3ζ；CD28；CD8α 跨膜域 | 锚定 CAR 分子于 T 细胞膜，影响 CAR 的表面表达水平和信号传导 |
| 共刺激域 | CD28；4-1BB（CD137）；OX40；ICOS | 提供 T 细胞完全激活所需的第二信号，影响 T 细胞增殖、持久性和代谢表型 |
| 激活域 | CD3ζ（ITAM 信号模块）| 触发 T 细胞效应功能（细胞毒、细胞因子分泌）|

**靶点选择的关键原则与挑战**

| 理想靶点特征 | 现实挑战 |
|---|---|
| 肿瘤特异性抗原（TSA），仅在肿瘤细胞表达 | 真正的 TSA 极少（新抗原除外），大多数为肿瘤相关抗原（TAA）|
| 细胞表面表达（非分泌型）| 可溶性抗原会在血液中中和 CAR-T，导致脱靶和疗效降低 |
| 稳定表达，不易下调 | 肿瘤细胞可通过下调靶抗原逃避 CAR-T 识别（抗原逃逸）|
| 高表达密度 | 低密度靶点导致 CAR-T 激活阈值不足 |

**CAR-T 的临床应用现状**

- **血液肿瘤**（已证实显著疗效）：B 细胞急性淋巴细胞白血病（B-ALL）、弥漫大 B 细胞淋巴瘤（DLBCL）、多发性骨髓瘤（MM）——完全缓解率可达 70%～90%（难治/复发患者）
- **实体瘤**（仍面临重大挑战）：肿瘤免疫抑制微环境（TME）、肿瘤异质性、CAR-T 难以有效浸润实体瘤，以及靶点特异性不足导致的脱靶毒性，是制约 CAR-T 在实体瘤中应用的核心障碍

:::

## CAR-NK 细胞疗法：天然杀伤机制与工程化改造的协同优势

:::answer

**NK 细胞的天然抗肿瘤机制**

NK（Natural Killer）细胞是天然免疫系统中对肿瘤细胞具有强力杀伤作用的淋巴细胞亚群，其识别和杀伤肿瘤细胞**不依赖 MHC 分子**，通过表面活化性受体和抑制性受体的相互交叉调控实现靶标选择：

| 受体类型 | 代表受体 | 功能 |
|---|---|---|
| 活化性受体 | NKG2D、NKp44、NKp46、NKp30、CD16（FcγRIIIa）| 识别肿瘤细胞应激配体（如 MICA/MICB），触发杀伤 |
| 抑制性受体 | KIR（杀伤细胞免疫球蛋白样受体）、NKG2A/CD94 | 识别正常细胞表面 MHC-I 分子，发出"别杀我"信号 |

正常细胞高表达 MHC-I → 抑制性信号占主导 → NK 细胞不杀伤  
肿瘤细胞下调 MHC-I + 上调应激配体 → 活化性信号占主导 → NK 细胞杀伤

**CAR-NK 相对于 CAR-T 的独特优势**

| 维度 | CAR-T | CAR-NK |
|---|---|---|
| 异体应用可行性 | 须基因敲除 TCR/HLA，制备复杂 | 天然不导致 GvHD，异体使用相对安全 |
| 细胞因子风暴风险 | 高（尤其 CD3 桥接机制）| 较低（NK 细胞因子释放谱不同）|
| MHC 依赖性 | 无（CAR 绕过 MHC 限制）| 无（NK 天然非 MHC 依赖）|
| 双重杀伤机制 | 仅 CAR 介导 | CAR 介导 + 天然 NK 受体介导（双重保障）|
| 抗原逃逸风险 | 高（靶抗原下调后失效）| 相对低（天然受体提供补充杀伤）|
| 来源 | 自体（主流）/异体（通用型）| 可从 iPSC、脐带血、外周血 NK 扩增 |

**CAR-NK 的工程化策略**

- **CAR 结构改造**：与 CAR-T 类似，引入 scFv + 跨膜区 + 共刺激域（IL-2Rβ/γ 或 2B4）+ CD3ζ
- **细胞因子自分泌增强**：在 CAR 构建体中引入 IL-15 或 IL-21 自分泌元件，克服 NK 细胞体内持久性差的弱点
- **CD16 保留/增强**：工程化保留或增强 CD16 表达，使 CAR-NK 能同时通过 ADCC 机制发挥效应（与治疗性抗体联合用药潜力大）
- **检查点抑制**：敲除 NKG2A、KIR 等抑制性受体基因，增强在 MHC-I 高表达肿瘤中的活性

:::

## ADC 药物的内化依赖性与早期/晚期设计演进的关键差异

:::answer

**内化依赖性是 ADC 设计的分水岭**

ADC 药物的发展史从某种意义上说是"非内化依赖"向"内化依赖"设计范式的演进史，这一转变从根本上提高了 ADC 的安全性和有效性。

**早期 ADC（非内化依赖型）的局限**

早期 ADC 设计中，单克隆抗体无法或仅能低效发生内化，其 Payload 释放依赖于**肿瘤微环境**的物理化学特性：

- 肿瘤特异性蛋白酶（基质金属蛋白酶 MMP）裂解连接子
- 肿瘤组织的酸性微环境（pH < 6.5）触发酸敏感型 Linker 断裂

**早期设计的根本缺陷**：这些肿瘤微环境特征并非绝对肿瘤特异，正常炎症组织也存在类似 MMP 和低 pH 条件，导致 Payload 在非肿瘤部位提前释放，脱靶毒性高、安全窗口窄。

**现代 ADC（内化依赖型）的设计优势**

- ADC 结合靶细胞表面抗原 → 受体介导内化 → 溶酶体内 Payload 释放
- Payload 在胞内才开始释放，完全避免了胞外非特异性释放
- 带来双重收益：**安全性大幅提升**（减少系统毒性）+ **有效性显著增强**（胞内高浓度 Payload 直接作用于细胞核心靶点）

| 维度 | 早期 ADC（非内化依赖）| 现代 ADC（内化依赖）|
|---|---|---|
| Payload 释放部位 | 肿瘤胞外微环境 | 肿瘤细胞溶酶体内 |
| 肿瘤特异性 | 低（依赖非特异性微环境）| 高（依赖特异性受体内吞）|
| 系统毒性 | 高 | 低 |
| 相对疗效 | 低于同靶点裸抗（部分早期产品）| 显著高于同靶点裸抗 |
| 代表思路 | 依赖 MMP/低 pH 释放 | 依赖溶酶体蛋白酶/pH 释放 |

:::

## 双特异性抗体在 ADC 生态中的定位：靶向双功能与免疫招募的协同应用

:::answer

**双特异性抗体的核心定义**

双特异性抗体（BsAb）是将两种结合不同抗原的特异性抗体可变区融合表达的非天然工程抗体，一个 Fab 臂结合肿瘤标志物，另一个 Fab 臂结合效应分子（药物、毒素、效应细胞）。

**在肿瘤治疗中的双重核心应用**

**应用一：导向药物（靶向递送）**

- BsAb 一臂结合肿瘤抗原，另一臂结合治疗性载体（药物、纳米粒子等）
- 相比单抗，BsAb 可以更高密度地将药物蓄积于肿瘤细胞，减少全身暴露和副作用
- 特别适用于小分子药物的靶向递送，小分子更容易快速接近靶位点，且被网状内皮系统清除的可能性相对较低

**应用二：导向细胞毒性细胞（免疫细胞招募）**

- BsAb 一臂结合肿瘤抗原，另一臂结合效应细胞表面受体（如 CD3、CD16a、NKp30）
- 可激活以下效应细胞类型：
  - **细胞毒 T 细胞（CTL）**：通过 CD3 桥接
  - **自然杀伤细胞（NK 细胞）**：通过 CD16a 桥接
  - **淋巴因子激活杀伤细胞（LAK 细胞）**：多激活途径

**BsAb 相对于化学偶联的独特优势**

- 自然状态下活跃，无需对抗体进行化学改变即可发挥双功能
- 抗体和有效功能分子使用前**无需预先化学结合**
- 偶联不会降低抗体和小分子药物各自的固有活性

**双特异性 ADC（BsAb-ADC）的前沿探索**

将 BsAb 技术与 ADC 结合，开发双靶点 ADC，是当前 ADC 领域的重要前沿方向：

- **优势**：同时靶向两种肿瘤抗原，克服单靶点抗原逃逸耐药；旁观者效应更广泛
- **挑战**：分子设计和工艺开发复杂性显著增加；DAR 控制和均一性更难保证
- **代表进展**：ZW49（HER2 双表位 BsAb-ADC）、MCLA-158（EGFR×LGR5 BsAb-ADC）等进入临床

:::

## 三特异性抗体的结构设计与三重效应叠加机制

:::answer

**定义与结构特征**

三特异性抗体（Trispecific Antibody, TriAb）是在双特异性抗体基础上进一步拓展的工程化分子，同时具备：

- **抗原结合位点 1**：结合 T 细胞膜表面 CD3 分子（招募 T 细胞）
- **抗原结合位点 2**：结合肿瘤细胞表面抗原（靶向肿瘤）
- **完整 Fc 片段**：结合 FcR+ 效应细胞，提供第三重效应

**三重效应的协同机制**

```
CD3 结合域 → 招募 T 细胞 → TCR 非依赖性 T 细胞激活 → 肿瘤细胞杀伤

TAA 结合域 → 靶向肿瘤细胞 → 物理桥联 T 细胞与肿瘤细胞

完整 Fc 结合域 → 结合单核细胞/巨噬细胞/NK 细胞/树突状细胞的 Fc 受体
    ↓
共同作用于肿瘤细胞：叠加杀伤效应
    ↓
Fc+ 辅助细胞（如巨噬细胞）直接接触，为 T 细胞提供协同刺激信号（第二信号补充）→ 增强 T 细胞活化
```

**与双特异性抗体的关键差异**

| 维度 | 双特异性抗体（含 Fc）| 三特异性抗体 |
|---|---|---|
| 效应细胞募集 | 单一效应细胞类型（T 细胞或 NK 细胞）| 同时募集 T 细胞（CD3）和 FcR+ 细胞（NK/MΦ/DC）|
| 协同刺激 | 无 | Fc+ 辅助细胞直接为 T 细胞提供共刺激信号 |
| 肿瘤杀伤机制 | 1～2 种（T 细胞杀伤 ± Fc 效应）| 3 种机制叠加（T 细胞 + NK + 巨噬细胞）|
| 结构复杂性 | 高 | 极高 |

**制备技术**

三特异性抗体主要利用基因工程技术和哺乳动物宿主细胞表达系统（CHO、HEK293）制备，面临与三种不同特异性结合域同时工程化的巨大设计挑战，链配对错误（Mispairing）是核心技术难题，通常需要结合 Knobs-into-Holes、CrossMab、正/负电荷配对等多种异二聚化技术解决。

:::

## 组合抗体策略：多表位协同与多靶点联合的临床增效逻辑

:::answer

**组合抗体的设计理念**

组合抗体（Combination Antibody）策略通过联合应用靶向以下目标的多种抗体，实现疗效叠加：

- **同一靶点的不同表位**（非竞争性表位协同）
- **同一信号通路的多个节点**
- **不同肿瘤驱动靶点**（双通路阻断）

**典型案例：Pertuzumab + Trastuzumab 联合方案**

| 抗体 | 结合表位 | 作用机制 |
|---|---|---|
| Trastuzumab（曲妥珠单抗）| HER2 胞外域 IV（近膜区）| 阻断 HER2 与其他 HER 家族成员的配体非依赖性二聚化；介导 ADCC |
| Pertuzumab（帕妥珠单抗）| HER2 胞外域 II（二聚化界面）| 直接阻断 HER2 与 HER3 的配体依赖性异二聚化（HER2-HER3 是最强促增殖异二聚体）|

两者结合不同表位，形成**互补性双表位阻断**，协同抑制 HER2 下游信号（RAS-MAPK 和 PI3K-AKT 通路），效果显著优于单药：

- **临床证据**：Pertuzumab + Trastuzumab + Docetaxel 作为一线治疗 HER2 阳性转移性乳腺癌，相较于 Placebo + Trastuzumab + Docetaxel，显著延长无进展生存期（PFS），无增加心脏毒性

**组合抗体策略的核心优势**

- 双靶点或双表位覆盖可阻断肿瘤通过**单靶点代偿逃逸**建立的耐药
- 两种抗体各自维持独立的安全性特征，联合毒性通常可预测
- 无需复杂的分子工程改造，可直接利用已批准单抗进行联合（减少研发风险）

**组合抗体 vs. 双特异性抗体的选择逻辑**

| 考量维度 | 组合抗体策略 | 双特异性抗体 |
|---|---|---|
| 开发速度 | 快（利用已有单抗）| 较慢（需从头工程化）|
| 给药便利性 | 两次独立给药 | 单次给药 |
| 成本 | 两种产品的制造成本 | 单一产品，长期可能更低 |
| 药学复杂性 | 相对简单 | 更复杂（异二聚化、链配对）|
| 监管路径 | 已有单抗已上市则路径清晰 | 新分子实体，需完整申报 |

:::

## ADCC 增强抗体：Fc 工程改造提升 NK 细胞杀伤效率的策略

:::answer

**ADCC 效应的分子机制**

抗体 Fc 区与表达 FcγRIIIa（CD16a）的效应细胞（NK 细胞、单核细胞、中性粒细胞等）结合后，触发效应细胞脱颗粒和细胞因子释放，溶解靶细胞。ADCC 是当前众多治疗性单抗（利妥昔单抗、曲妥珠单抗、奥滨尤妥珠单抗等）发挥抗肿瘤效应的核心机制之一。

**提高 ADCC 活性的主要工程策略**

**策略一：Fc 去岩藻糖化（Afucosylation）**

- 原理：去除 Fc N297 糖链核心岩藻糖残基，显著增强 Fc 与 FcγRIIIa 的亲和力（亲和力提升 10～100 倍）
- 机制：岩藻糖与 FcγRIIIa 糖链之间存在空间位阻；去除岩藻糖后二者结合界面更佳
- 实现方式：宿主细胞敲除 α-1,6-岩藻糖基转移酶（FUT8）（如 Potelligent® 技术）；或使用不添加岩藻糖的培养基策略
- 代表产品：Mogamulizumab（抗 CCR4，去岩藻糖化，ADCC 显著增强）、Obinutuzumab（抗 CD20，去岩藻糖化 + Fc 工程）

**策略二：Fc 氨基酸突变（点突变增强 FcγRIIIa 亲和力）**

常用的增强型 Fc 突变位点：

| 突变 | 效应 | 代表 |
|---|---|---|
| S239D/I332E（DE 突变）| FcγRIIIa 亲和力提升约 10 倍 | XmAb 平台（Xencor）|
| F243L/R292P/Y300L/V305I/P396L | 多位点协同增强 | 多种在研抗体 |
| G236A/S239D/I332E（GASDALIE）| 同时增强 ADCC 和 ADCP | — |

**策略三：Fc 区域改造降低 FcγRIIb 结合（减少抑制性信号）**

- FcγRIIb 是抑制性 FcR，其激活会抑制 ADCC
- 通过定向突变降低 Fc 对 FcγRIIb 的亲和力，同时维持对 FcγRIIIa 的高亲和力，净效果为 ADCC 增强

**ADCC 增强策略的临床意义**

NK 细胞介导的 ADCC 在体内的实际效力受多种因素影响（患者 FcγRIIIa 多态性：158V/V vs. 158F/F；肿瘤微环境中 NK 细胞的功能状态）。通过 Fc 工程增强抗体-FcγRIIIa 亲和力可在一定程度上克服 158F/F 低亲和力多态性带来的疗效差异，改善患者间的疗效均一性。

:::

## CDC 增强抗体：多效价 Fc 设计与补体激活强化策略

:::answer

**CDC 效应的机制优势**

CDC（补体依赖性细胞毒性）具有与 ADCC 不同的独特优势：

- **无需细胞成分**：补体蛋白直接存在于血清中，不依赖效应免疫细胞的招募和激活
- **反应快速**：级联激活反应可在数分钟内完成细胞溶解
- **不受免疫抑制微环境限制**：肿瘤微环境对 NK 细胞和 T 细胞的抑制不影响补体效应

**增强 CDC 的关键策略：多效价 Fc 设计**

C1q 与 IgG Fc 的结合具有多价依赖性——单个 C1q 分子须同时与多个（≥2 个）毗邻的 IgG Fc 区结合才能被有效激活。因此，提高 Fc 的空间聚集度是增强 CDC 的核心设计思路。

**策略一：人工二聚化抗体**

将两个 IgG 分子通过工程化二硫键或蛋白质工程手段共价连接形成二聚体，增加局部 Fc 密度，显著提高 C1q 结合亲和力。

**策略二：IgM 五聚体或六聚体**

- IgM 天然以五聚体（部分以六聚体）形式存在，提供 10～12 个 Fc 区的多聚 C1q 结合平台
- 人工 IgG-IgM 混合构建体或纯 IgM 五/六聚体被探索用于 CDC 增强
- 技术挑战：IgM 分子量极大（~950 kDa），组织穿透性差；生产工艺复杂（五聚体的正确组装难以控制）；临床应用的稳定性和毒性问题仍在解决中

**策略三：Fc 突变增强 C1q 亲和力**

| 突变位点 | 效应 |
|---|---|
| E345K（"星形"六聚体诱导突变）| 诱导抗体在细胞表面自发形成六聚体聚集，极大增强 CDC |
| E430G | 同上（诱导六聚体形成）|
| K326W/E333S | 增强 C1q-Fc 直接亲和力 |

**注意事项**

- 多聚体设计和 Fc 六聚体诱导突变虽能显著增强 CDC，但同时也可能增加系统性补体激活的风险（补体激活综合征）
- 须在 CDC 增强和系统毒性之间寻求平衡，通常需要在模拟生理浓度补体的体外系统和动物模型中充分评估安全性后再推进临床

:::

## 生物制品注射剂的三大安全检测：内毒素、无菌与可见异物的标准操作规范

:::answer

**三大安全检测的战略地位**

对于注射用生物制品，内毒素、无菌性和可见异物是确保患者安全的三项关键放行检测，任何一项不合格均导致产品不得放行。三者分别控制不同类型的污染风险，构成注射剂安全性控制的基础防线。

---

**检测一：细菌内毒素**

**方法体系**

《中国药典》2020 版三部通则 1143 规定两种方法：凝胶法（定性/半定量）和光度测定法（浊度法/显色基质法，定量）。当检测结果存在争议时，**以凝胶限度试验结果为准**。

**凝胶法标准操作（SOP）**

| 步骤 | 关键操作 | 注意事项 |
|---|---|---|
| 标准溶液制备 | 制备 2λ、λ、0.5λ、0.25λ 四梯度内毒素标准液；旋涡混匀 ≥15 min | 每步稀释后混匀 ≥30 s |
| 混合与孵育 | 标准液与等体积鲎试剂混合（如各 0.1 mL），每浓度平行 4 管，阴性对照 2 管；封口，垂直，37°C ± 1°C，60 min ± 2 min | 封闭管口防蒸发 |
| 结果判定 | 缓缓倒转 180°；凝胶坚实不滑脱 = 阳性；无凝胶或滑脱 = 阴性 | **全程避免振动，防假阴性** |

---

**检测二：无菌检测**

无菌检测验证注射用药品和医疗器械中是否存在污染性活微生物，是每批产品上市前的必须放行检测。

**两种检测方法**

| 方法 | 原理 | 适用情形 |
|---|---|---|
| **薄膜过滤法**（首选）| 将定量产品通过膜过滤器（0.45 µm），捕获潜在微生物，加入生长培养基孵育检测 | USP<71>、EP 2.6.1 均规定"只要产品性质允许，必须使用薄膜过滤法" |
| **直接接种法** | 将定量产品直接转移至需氧培养基和厌氧培养基，直接孵育检测 | 仅在薄膜过滤法不适用时使用（如高黏度产品）|

**培养基与孵育条件**

- 硫乙醇酸盐流体培养基（FTM）：用于培养厌氧菌，30～35°C，14 天
- 胰酪大豆胨液体培养基（SCDM）：用于培养需氧菌和真菌，20～25°C，14 天

**注意**：终产品（如 CAR-T、单抗制剂）通常无法进行终端灭菌，须完全依赖全程无菌生产工艺（Validated Aseptic Process）确保无菌性。

---

**检测三：可见异物**

**检测方法**：灯检法（人工灯检 + 机器视觉辅助）

**质量标准**：无可见异物（标准：无肉眼可见的颗粒、纤维、变色等异物）

**法规依据**：《中国药典》2020 版三部通则 0904《可见异物检查法》

**生物制品可见异物控制的特殊挑战**

抗体药物处方中常用辅料（聚山梨醇酯 20、聚山梨醇酯 80、泊洛沙姆 188 等）与抗体蛋白的相互作用是近年来高度关注的风险点：

| 辅料相关风险 | 机制 | 控制策略 |
|---|---|---|
| 聚山梨醇酯氧化降解 | PS20/PS80 在储存过程中氧化产生过氧化物，导致蛋白聚集形成可见颗粒 | 控制 PS 氧化质量（低过氧化物含量的 PS 规格）；优化储存条件（避光、惰性气体保护）|
| 蛋白-辅料相互作用 | 辅料与疏水蛋白区域的非特异性结合，可能诱发蛋白构象变化和聚集 | 处方开发阶段系统评估各辅料与目标蛋白的相容性 |
| 硅油颗粒 | 预填充注射器中的硅油脱落与蛋白相互作用 | 使用无硅油或低硅油注射器；蛋白质-硅油相互作用研究 |

**全生命周期管理视角**

随着全生命周期管理理念的深入，可见异物控制已不仅限于成品放行检测，还须贯穿：原料药稳定性研究（长期和加速条件下的颗粒监测）、制剂相容性研究（容器/密封系统）、运输振动研究（振动诱导的蛋白聚集）和使用过程模拟（配制、过滤、给药设备的相容性）。

:::

## ADC 产品的全面监管要求：产品设计、生产工艺、质量控制与处方开发四大维度

:::answer

**监管框架总览**

CDE《抗体偶联药物药学研究与评价技术指导原则》从四个维度对 ADC 产品的药学研究提出系统性要求，体现了 ADC 作为兼具大分子和小分子双重属性的高度复杂生物制品的特殊监管逻辑。

**维度一：产品设计——五大关键因素的协同优化**

ADC 产品的安全性和有效性取决于五个核心组分/参数的综合设计质量：

| 关键因素 | 核心设计考量 | 对安全性/有效性的影响 |
|---|---|---|
| 靶抗原 | 特异性、非分泌性、内化能力 | 决定靶向性和脱靶毒性基线 |
| 抗体 | 亲和力、人源化程度、PK 特性 | 决定递送效率、循环半衰期和免疫原性 |
| 有效载荷 | 毒性效价、可修饰性、稳定性 | 决定杀伤力和系统毒性潜力 |
| 连接子 | 血浆稳定性、胞内裂解效率、疏水性 | 决定治疗窗口宽度 |
| 偶联方式 | DAR 值及分布、定点 vs. 随机 | 决定产品均一性和批间一致性 |

**需综合考量的系统性因素**：靶向性（特异性 vs. 脱靶）、体内循环稳定性（Linker 血浆稳定性、DAR 稳定性）、生物学活性（抗体靶点结合 + Payload 细胞毒活性）。

**维度二：生产工艺——多模块工艺的整体风险管控**

ADC 生产工艺通常涉及四个独立但相互关联的生产环节：

```
裸抗生产（抗体原液 DS）
    ↓
有效载荷/连接子/有效载荷-连接子生产（小分子中间体）
    ↓
ADC 原液生产（偶联反应 + 纯化）
    ↓
ADC 制剂生产（DP 制剂灌装）
```

**工艺开发核心理念**

- **质量源于设计（QbD）**：从靶标产品质量概况（QTPP）出发，系统识别 CQA，通过实验设计（DoE）建立设计空间
- **风险评估优先**：在工艺开发初期即对各环节的杂质风险（工艺相关、产品相关）、病毒安全性和微生物控制进行全面评估
- **整体性原则**：须将裸抗、有效载荷/连接子和 ADC 各环节作为**一个整体**，综合考虑杂质的来源、迁移和累积，以及病毒/微生物安全性的综合控制

**维度三：质量研究与控制——ADC 特有 CQA 的分析表征策略**

除单抗常规 CQA 外，ADC 还引入了一系列特有的关键质量属性，需专属分析方法：

| ADC 特有 CQA | 分析方法 | 控制意义 |
|---|---|---|
| DAR 值（均值）| HIC、UV/Vis 比值法、LC-MS | 疗效与毒性的核心决定因素 |
| DAR 分布 | HIC（各 DAR 峰积分）、native MS | 批间一致性和产品均一性 |
| 偶联位点 | 肽图 + LC-MS/MS | 定点偶联位点验证 |
| 游离 Payload 含量 | RP-HPLC、HIC 后 LC-MS/MS | 系统毒性控制（通常 < 1 mol%）|
| 未偶联抗体（DAR=0）| HIC | 有效成分比例 |
| ADC 血浆稳定性 | 人血浆孵育 + 定时 HIC/LC-MS | 体内 DAR 稳定性预测 |
| Payload 分布（位置异质性）| 肽图 + LC-MS/MS | 定点偶联产品的位点均一性 |

**分析策略原则**：须采用适宜的技术手段或多种手段组合，对结构特点、纯度和杂质、异质性、生物学活性、有效载荷分布等 CQA 进行**充分表征**，不能仅依赖单一分析技术。

**维度四：处方开发——平衡裸抗、Payload 和偶联化学稳定性的复杂体系**

**双层处方开发要求**

- **裸抗处方开发**：在确保裸抗本身稳定性的同时，须考虑与后续偶联工艺的兼容性（如 pH 范围、盐浓度、稳定剂种类不能影响偶联反应效率和选择性）
- **ADC 制剂处方开发**：须在裸抗稳定性、Payload/Linker 化学稳定性和偶联化学稳定性三者之间寻找最优平衡点

**ADC 制剂处方的特殊挑战**

| 挑战 | 机制 | 应对策略 |
|---|---|---|
| 高疏水性导致聚集 | 偶联 Payload 增加整体疏水性，尤其高 DAR 产品 | 优化 pH、离子强度、表面活性剂浓度；引入亲水修饰 Linker |
| 不规则表面电荷 | 偶联位点破坏局部电荷分布，影响蛋白间静电相互作用 | pH 和盐浓度优化，筛选合适缓冲体系 |
| 构象稳定性降低 | 偶联引入的结构扰动降低蛋白热稳定性（Tm 下降）| 加入热稳定性辅料（蔗糖、海藻糖、精氨酸等）|
| Payload 脱落 | 储存过程中 Linker 缓慢水解，导致游离 Payload 累积 | 优化制剂 pH，低温储存，密切监测稳定性 |
| 高异质性 | 多种 DAR 物种和位点变体共存 | 接受 ADC 本身的固有异质性，建立合理的质量标准 |

**稳定性研究重点**

ADC 稳定性研究须同时监测：总抗体浓度、DAR 值变化（体外稳定性指标）、游离 Payload 含量变化、蛋白聚集（SEC-HPLC）和可见异物，覆盖加速（25°C/6 个月）、中间（30°C/6 个月）和长期（2～8°C/≥24 个月）三个条件。
